.. _D.5:

Proposition 5 [ε΄ · Prop. VI]
-----------------------------

.. folio:: Menge 10
   :page: 10

.. enunciation::

   If a magnitude have a given ratio to a part of itself, it will also have a given ratio to the remainder.

*Functional Signature*: ``Given(Ratio(AB : AC)) -> Determined(Ratio(AB : (AB - AC)))`` · *Dependencies*: :just:`[Data Def. 2] <D.def.2>`, :just:`[Data 1] <D.1>`, :just:`[Data 2] <D.2>`, :just:`[Data 4] <D.4>`, :just:`[V.19] <V.19>`

Let the magnitude :math:`AB` have a given ratio to its part :math:`AG`. I say that :math:`AB` also has a given ratio to the remaining part :math:`GB`.

Let :math:`DF` be set out as a given magnitude; since the ratio :math:`BA : AG` is given, let the ratio :math:`FD : DE` be made the same with it (:just:`[Data Def. 2] <D.def.2>`). Then :math:`FD : DE` is given, and :math:`FD` is given, so :math:`DE` is given (:just:`[Data 2] <D.2>`), whence the remainder :math:`EF` is given (:just:`[Data 4] <D.4>`). Since :math:`FD` is also given, the ratio :math:`DF : FE` is given (:just:`[Data 1] <D.1>`). Moreover, since :math:`AB : AG = DF : DE`, *convertendo* as :math:`AB` is to :math:`BG`, so is :math:`DF` to :math:`FE` (:just:`[V.19] <V.19>` Cor.). Because :math:`DF : FE` is given, the ratio :math:`AB : BG` is also given (:just:`[Data Def. 2] <D.def.2>`).
