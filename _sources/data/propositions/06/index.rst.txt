Proposition 6 [Ϛ΄ · Prop. VII]
------------------------------

.. enunciation::

   If two magnitudes having a given ratio to one another be compounded together, the whole magnitude will also have a given ratio to each of them.

*Functional Signature*: ``Given(Ratio(AB : BC)) -> Determined(Ratio((AB+BC) : AB), Ratio((AB+BC) : BC))`` · *Dependencies*: :just:`[Data Def. 2] <D.def.2>`, :just:`[Data 1] <D.1>`, :just:`[Data 2] <D.2>`, :just:`[Data 3] <D.3>`, :just:`[V.18] <V.18>`, :just:`[V.19] <V.19>`

Let the two magnitudes :math:`AB` and :math:`BC`, having a given ratio to one another, be compounded into :math:`AC`. I say that the whole :math:`AC` has a given ratio to each of :math:`AB` and :math:`BC`.

Let a given magnitude :math:`DE` be set out; since the ratio :math:`AB : BC` is given, let the same ratio :math:`DE : EF` be procured (:just:`[Data Def. 2] <D.def.2>`). Because :math:`DE` is given and :math:`DE : EF` is given, :math:`EF` is given (:just:`[Data 2] <D.2>`), so the whole :math:`DF` is given (:just:`[Data 3] <D.3>`). Since each of :math:`DE` and :math:`EF` is given, the ratios :math:`DF : DE` and :math:`DF : EF` are both given (:just:`[Data 1] <D.1>`). Now since :math:`AB : BC = DE : EF`, *componendo* :math:`AC : BC = DF : EF` (:just:`[V.18] <V.18>`), and by inversion and *componendo* :math:`AC : AB = DF : DE`. Since :math:`DF` has a given ratio to each of :math:`DE` and :math:`EF`, :math:`AC` likewise has a given ratio to each of :math:`AB` and :math:`BC` (:just:`[Data Def. 2] <D.def.2>`).
