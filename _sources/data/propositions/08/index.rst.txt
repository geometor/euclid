Proposition 8 [η΄ · Prop. IX]
-----------------------------

.. folio:: Menge 14
   :page: 14

.. enunciation::

   Magnitudes that have given ratios to the same magnitude will also have a given ratio to one another.

*Functional Signature*: ``Given(Ratio(A : B), Ratio(C : B)) -> Determined(Ratio(A : C))`` · *Dependencies*: :just:`[Data 1] <D.1>`, :just:`[Data 2] <D.2>`, :just:`[V.7] <V.7>`, :just:`[V.11] <V.11>`, :just:`[V.22] <V.22>`

Let :math:`A` have a given ratio to :math:`B`, and let :math:`C` have a given ratio to the same :math:`B`. I say that :math:`A` also has a given ratio to :math:`C`.

Let a given magnitude :math:`D` be set out. Since the ratio :math:`A : B` is given, let :math:`D : E` be made the same with it (:just:`[Data Def. 2] <D.def.2>`); because :math:`D` is given, :math:`E` is also given (:just:`[Data 2] <D.2>`). Again, since the ratio :math:`C : B` is given, let :math:`F : E` be made the same with :math:`C : B`, so that *invertendo* :math:`B : C = E : F` (:just:`[V.7] <V.7>` Cor.); because :math:`E` is given, :math:`F` is also given (:just:`[Data 2] <D.2>`). Since both :math:`D` and :math:`F` are given, the ratio :math:`D : F` is given (:just:`[Data 1] <D.1>`). And since :math:`A : B = D : E` while :math:`B : C = E : F`, *ex aequali* :math:`A : C = D : F` (:just:`[V.22] <V.22>`). Therefore the ratio :math:`A : C` is given (:just:`[Data Def. 2] <D.def.2>`).
