.. _D.24:

Proposition 24 [κδ΄ · Prop. XIII]
---------------------------------

.. folio:: Menge 44
   :page: 44

.. enunciation::

   If three straight lines be proportional, and the first have to the third a given ratio, it will also have to the second a given ratio.

*Functional Signature*: ``Given(A : B = B : C, Ratio(A : C)) -> Determined(Ratio(A : B))`` · *Dependencies*: :just:`[Data Def. 1] <D.def.1>`, :just:`[Data Def. 2] <D.def.2>`, :just:`[Data 1] <D.1>`, :just:`[Data 2] <D.2>`, :just:`[VI.13] <VI.13>`, :just:`[VI.17] <VI.17>`, :just:`[VI.22] <VI.22>`

Let three straight lines :math:`A, B, C` be in continued proportion (:math:`A : B = B : C`), and let the first :math:`A` have a given ratio to the third :math:`C`. I say that :math:`A` also has a given ratio to the second :math:`B`.

Let a given straight line :math:`D` be set out. Since the ratio :math:`A : C` is given, let the ratio :math:`D : F` be made the same with it (:just:`[Data Def. 2] <D.def.2>`); because :math:`D` is given, :math:`F` is also given (:just:`[Data 2] <D.2>`). Let the mean proportional :math:`E` be taken between :math:`D` and :math:`F` (:just:`[VI.13] <VI.13>`), so that the rectangle :math:`D \cdot F` is equal to the square :math:`E^2` (:just:`[VI.17] <VI.17>`). Since both :math:`D` and :math:`F` are given in magnitude, the rectangle :math:`D \cdot F` is given—and therefore :math:`E^2` is given, whence the straight line :math:`E` is given in magnitude (compare :just:`[Data 52] <D.52>` / :just:`[Data Def. 1] <D.def.1>`). Because :math:`D` is also given, the ratio :math:`D : E` is given (:just:`[Data 1] <D.1>`). Now since :math:`A : C = D : F`, while :math:`A : C = A^2 : (A \cdot C)` and :math:`D : F = D^2 : (D \cdot F)` (:just:`[VI.1] <VI.1>`), it follows that :math:`A^2 : (A \cdot C) = D^2 : (D \cdot F)` (:just:`[V.11] <V.11>`). Substituting :math:`B^2 = A \cdot C` (from :math:`A : B = B : C`, :just:`[VI.17] <VI.17>`) and :math:`E^2 = D \cdot F` gives :math:`A^2 : B^2 = D^2 : E^2`, whence for the sides themselves :math:`A : B = D : E` (:just:`[VI.22] <VI.22>`). Since :math:`D : E` is given, the ratio :math:`A : B` is also given (:just:`[Data Def. 2] <D.def.2>`).
