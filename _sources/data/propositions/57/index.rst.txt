Proposition 57 [νζ΄ · Prop. LXI]
--------------------------------

.. folio:: Menge 102
   :page: 102

.. enunciation::

   If a given area be applied to a given straight line in a given angle, the breadth of the application is given.

*Functional Signature*: ``Given(Mag(Area S), Mag(Base a), Mag(Angle theta)) -> Determined(Mag(Breadth x))`` · *Dependencies*: :just:`[Data 1] <D.1>`, :just:`[Data 2] <D.2>`, :just:`[Data 8] <D.8>`, :just:`[Data 52] <D.52>`, :just:`[I.31] <I.31>`, :just:`[I.46] <I.46>`, :just:`[VI.1] <VI.1>`

Let a given area :math:`AC` (a parallelogram in a given angle :math:`\angle CAB`) be :term:`applied <parabole>` to a straight line :math:`AB` given in magnitude (:just:`[I.44] <I.44>`). I say that its breadth :math:`CB` (or :math:`AD`) is given in magnitude.

On the given straight line :math:`AB`, describe the square :math:`AEFB` (:just:`[I.46] <I.46>`), which is given in magnitude (:just:`[Data 52] <D.52>`), and produce :math:`EA` to meet the opposite side :math:`CD` (or complete the equiangular auxiliary parallelogram :math:`AGHB` on :math:`AB` with :math:`AG = AB`). Since :math:`AC` is given in magnitude and :math:`AEFB` is given in magnitude, the ratio :math:`AC : AEFB` is given (:just:`[Data 1] <D.1>`). Moreover, comparing :math:`AC` with the rhombus :math:`AGHB` on :math:`AB` in the given angle :math:`\angle CAB` (whose species is given by :just:`[Data Def. 3] <D.def.3>`, so :math:`AGHB : AEFB` is given by :just:`[Data 49] <D.49>`), the ratio :math:`AC : AGHB` is given (:just:`[Data 8] <D.8>`). Yet on the common side :math:`AB` in the same angle, :math:`AC : AGHB = AD : AG = AD : AB` (:just:`[VI.1] <VI.1>`). Since :math:`AD : AB` is given and :math:`AB` is given in magnitude, the breadth :math:`AD` (:math:`= CB`) is given in magnitude (:just:`[Data 2] <D.2>`).
