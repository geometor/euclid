.. _D.82:

Proposition 82 [πβ΄ · Prop. LXXII]
----------------------------------

.. folio:: Menge 160
   :page: 160

.. enunciation::

   If four straight lines be proportional, as the first is to that straight line to which the second has a given ratio, so will the third be to that straight line to which the fourth has a given ratio.

*Functional Signature*: ``Given(A : B = C : D, Ratio(B : E) = k) -> Determined(Ratio(D : F) = k when A : E = C : F)`` · *Dependencies*: :just:`[Data 2] <D.2>`, :just:`[Data 8] <D.8>`, :just:`[V.11] <V.11>`, :just:`[V.16] <V.16>`, :just:`[V.22] <V.22>`

Let four straight lines :math:`A, B, C, D` be proportional (:math:`A : B = C : D`). I say that as the first :math:`A` is to the line :math:`E` to which the second :math:`B` has a given ratio, so is the third :math:`C` to a line :math:`F` to which the fourth :math:`D` has a given ratio.

Let :math:`E` be any straight line to which :math:`B` has a given ratio :math:`B : E`. Make :math:`D : F = B : E` (:just:`[Data Def. 2] <D.def.2>`), so :math:`D` has the same given ratio to :math:`F`. Now since :math:`A : B = C : D`, *alternando* :math:`A : C = B : D` (:just:`[V.16] <V.16>`), while from :math:`B : E = D : F` *alternando* :math:`B : D = E : F` (:just:`[V.16] <V.16>`). Therefore :math:`A : C = E : F` (:just:`[V.11] <V.11>`), and *alternando* :math:`A : E = C : F` (:just:`[V.16] <V.16>`), where :math:`D : F` is given.
