.. _D.83:

Proposition 83 [πγ΄ · Prop. LXXIII]
-----------------------------------

.. enunciation::

   If four straight lines be so related to one another that, when three of them are taken and a fourth is assumed to them to which the remaining one of the original four has a given ratio, the four straight lines are proportional, then as the fourth is to the third, so is the second to that straight line to which the first has a given ratio.

*Functional Signature*: ``Given(A * D = B * E, Ratio(C : E) = k) -> Determined(D : C = B : (A / k))`` · *Dependencies*: :just:`[Data 2] <D.2>`, :just:`[Data 8] <D.8>`, :just:`[Data 68] <D.68>`, :just:`[V.16] <V.16>`, :just:`[V.23] <V.23>`, :just:`[VI.16] <VI.16>`

Let four straight lines :math:`A, B, C, D` be so related to one another that when any three of them (:math:`A, B, C`) are taken, and a fourth :math:`E` is taken to which the remaining line :math:`D` has a given ratio :math:`D : E` such that :math:`A : B = C : E`, I say that :math:`D` is to :math:`C` as :math:`B` is to a straight line :math:`F` to which :math:`A` has a given ratio (and similarly for every permutation of the four lines).

Since :math:`A : B = C : E` and the ratio :math:`D : E` is given, make :math:`A : F = D : E` (:just:`[Data Def. 2] <D.def.2>`), so :math:`A` has a given ratio to :math:`F`. From :math:`A : F = D : E`, *alternando* :math:`A : D = F : E` (:just:`[V.16] <V.16>`); and from :math:`A : B = C : E`, *invertendo* and *ex aequali* (:just:`[V.7] <V.7>` Cor., :just:`[V.22] <V.22>`), since :math:`D : E = A : F` while :math:`E : C = B : A`, multiplying/chaining *ex aequali perturbed* (:just:`[V.23] <V.23>`) gives :math:`D : C = B : F`! Because :math:`A : F` is given, :math:`D` is to :math:`C` as :math:`B` is to :math:`F`, a straight line to which :math:`A` has a given ratio.
