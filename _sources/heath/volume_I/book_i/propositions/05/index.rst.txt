PROPOSITION 5.
==============

.. enunciation::

   In isosceles triangles the angles at the base are equal to one another, and, if the equal straight lines\ [#f1]_ be produced further, the angles under the base will be equal to one another.

.. picture:: 0265.g1.svg
   :alt: Proposition 5 figure

Let :g:`$ABC$ <0265.g1:< A B C >>` be an :eq:`isosceles <0265.g1:/ A B / = 0265.g1:/ A C />` triangle having the side :g:`$AB$ <0265.g1:/ A B />` :eq:`equal <0265.g1:/ A B / = 0265.g1:/ A C />` to the side :g:`$AC$ <0265.g1:/ A C />`;

and let the straight lines :g:`$BD$ <0265.g1:/ B D />`, :g:`$CE$ <0265.g1:/ C E />` be produced further in a straight line with :g:`$AB$ <0265.g1:/ A B />`, :g:`$AC$ <0265.g1:/ A C />`. :just:`[Post. 2] <I.post.2>`

I say that the angle :g:`$ABC$ <0265.g1:< A B C )>` is :eq:`equal <0265.g1:< A B C ) = 0265.g1:< A C B ); 0265.g1:< C B D ) = 0265.g1:< B C E )>` to the angle :g:`$ACB$ <0265.g1:< A C B )>`, and the angle :g:`$CBD$ <0265.g1:< C B D )>` to the angle :g:`$BCE$ <0265.g1:< B C E )>`.

Let a point :g:`$F$ <0265.g1:F>` be taken at random on :g:`$BD$ <0265.g1:/ B D />`;\ [#f2]_ from :g:`$AE$ <0265.g1:/ A E />` the greater let :g:`$AG$ <0265.g1:/ A G />` be cut off :eq:`equal <0265.g1:/ A G / = 0265.g1:/ A F />` to :g:`$AF$ <0265.g1:/ A F />` the less; :just:`[I. 3] <I.3>`

and let the straight lines :g:`$FC$ <0265.g1:/ F C />`, :g:`$GB$ <0265.g1:/ G B />` be joined. :just:`[Post. 1] <I.post.1>`

Then, since :g:`$AF$ <0265.g1:/ A F />` is :eq:`equal <0265.g1:/ A F / = 0265.g1:/ A G /; 0265.g1:/ A B / = 0265.g1:/ A C />` to :g:`$AG$ <0265.g1:/ A G />` and :g:`$AB$ <0265.g1:/ A B />` to :g:`$AC$ <0265.g1:/ A C />`,

.. subclause::

   the two sides :g:`$FA$ <0265.g1:/ F A />`, :g:`$AC$ <0265.g1:/ A C />` are :eq:`equal <0265.g1:/ F A / = 0265.g1:/ G A /; 0265.g1:/ A C / = 0265.g1:/ A B />` to the two sides :g:`$GA$ <0265.g1:/ G A />`, :g:`$AB$ <0265.g1:/ A B />`, respectively;\ [#f3]_

and they contain a common angle, the angle :g:`$FAG$ <0265.g1:< F A G )>`.

.. assertion::

   Therefore the base :g:`$FC$ <0265.g1:/ F C />` is :eq:`equal <0265.g1:/ F C / = 0265.g1:/ G B />` to the base :g:`$GB$ <0265.g1:/ G B />`,

and the triangle :g:`$AFC$ <0265.g1:< A F C >>` is :eq:`equal <0265.g1:< A F C > = 0265.g1:< A G B >>` to the triangle :g:`$AGB$ <0265.g1:< A G B >>`, and the remaining angles will be :eq:`equal <0265.g1:< A C F ) = 0265.g1:< A B G ); 0265.g1:< A F C ) = 0265.g1:< A G B )>` to the remaining angles respectively, namely those which the :eq:`equal <0265.g1:/ A F / = 0265.g1:/ A G /; 0265.g1:/ A C / = 0265.g1:/ A B />` sides subtend,

.. subclause::

   that is, the angle :g:`$ACF$ <0265.g1:< A C F )>` to the angle :g:`$ABG$ <0265.g1:< A B G )>`,

.. subclause:: [I. 4] <I.4>

   and the angle :g:`$AFC$ <0265.g1:< A F C )>` to the angle :g:`$AGB$ <0265.g1:< A G B )>`.

And, since the whole :g:`$AF$ <0265.g1:/ A F />` is :eq:`equal <0265.g1:/ A F / = 0265.g1:/ A G />` to the whole :g:`$AG$ <0265.g1:/ A G />`, and in these :g:`$AB$ <0265.g1:/ A B />` is :eq:`equal <0265.g1:/ A B / = 0265.g1:/ A C />` to :g:`$AC$ <0265.g1:/ A C />`,

.. assertion::

   the remainder :g:`$BF$ <0265.g1:/ B F />` is :eq:`equal <0265.g1:/ B F / = 0265.g1:/ C G />` to the remainder :g:`$CG$ <0265.g1:/ C G />`.

But :g:`$FC$ <0265.g1:/ F C />` was also proved :eq:`equal <0265.g1:/ F C / = 0265.g1:/ G B />` to :g:`$GB$ <0265.g1:/ G B />`; therefore the two sides :g:`$BF$ <0265.g1:/ B F />`, :g:`$FC$ <0265.g1:/ F C />` are :eq:`equal <0265.g1:/ B F / = 0265.g1:/ C G /; 0265.g1:/ F C / = 0265.g1:/ G B />` to the two sides :g:`$CG$ <0265.g1:/ C G />`, :g:`$GB$ <0265.g1:/ G B />` respectively; and the angle :g:`$BFC$ <0265.g1:< B F C )>` is :eq:`equal <0265.g1:< B F C ) = 0265.g1:< C G B )>` to the angle :g:`$CGB$ <0265.g1:< C G B )>`,

.. subclause::

   while the base :g:`$BC$ <0265.g1:/ B C />` is common to them;\ [#f4]_

therefore the triangle :g:`$BFC$ <0265.g1:< B F C >>` is also :eq:`equal <0265.g1:< B F C > = 0265.g1:< C G B >>` to the triangle :g:`$CGB$ <0265.g1:< C G B >>`, and the remaining angles will be :eq:`equal <0265.g1:< F B C ) = 0265.g1:< G C B ); 0265.g1:< B C F ) = 0265.g1:< C B G )>` to the remaining
angles respectively, namely those which the :eq:`equal <0265.g1:/ B F / = 0265.g1:/ C G /; 0265.g1:/ F C / = 0265.g1:/ G B />` sides subtend;

.. _folio-i-0266:

.. folio:: 0266
   :page: 252

.. subclause::

   therefore the angle :g:`$FBC$ <0265.g1:< F B C )>` is :eq:`equal <0265.g1:< F B C ) = 0265.g1:< G C B ); 0265.g1:< B C F ) = 0265.g1:< C B G )>` to the angle :g:`$GCB$ <0265.g1:< G C B )>`,

.. subclause::

   and the angle :g:`$BCF$ <0265.g1:< B C F )>` to the angle :g:`$CBG$ <0265.g1:< C B G )>`.

Accordingly, since the whole angle :g:`$ABG$ <0265.g1:< A B G )>` was proved :eq:`equal <0265.g1:< A B G ) = 0265.g1:< A C F )>` to the angle :g:`$ACF$ <0265.g1:< A C F )>`, and in these the angle :g:`$CBG$ <0265.g1:< C B G )>` is :eq:`equal <0265.g1:< C B G ) = 0265.g1:< B C F )>` to the angle :g:`$BCF$ <0265.g1:< B C F )>`, the remaining angle :g:`$ABC$ <0265.g1:< A B C )>` is :eq:`equal <0265.g1:< A B C ) = 0265.g1:< A C B )>` to the remaining angle :g:`$ACB$ <0265.g1:< A C B )>`;

.. subclause::

   and they are at the base of the triangle :g:`$ABC$ <0265.g1:< A B C >>`.

But the angle :g:`$FBC$ <0265.g1:< F B C )>` was also proved :eq:`equal <0265.g1:< F B C ) = 0265.g1:< G C B )>` to the angle :g:`$GCB$ <0265.g1:< G C B )>`;

.. subclause::

   and they are under the base.

.. qed::

   Therefore etc.\ [#f5]_ :just:`Q. E. D.`

.. [#f1] **the equal straight lines** (meaning the equal *sides*). Cf. note on the similar expression in Prop. 4, lines 2, 3.

.. [#f2] **Let a point F be taken at random on BD,** εἰλήφθω ἐπὶ τῆς ΒΔ τυχὸν :term:`σημεῖον <point>` τὸ Ζ, where τυχὸν :term:`σημεῖον <point>` means “a chance point.”

.. [#f3] **the two sides FA, AC are equal to the two sides GA, AB respectively,** δύο αἱ ΖΑ, ΑΓ δυσὶ ταῖς ΗΑ, ΑΒ ἴσαι εἰσὶν ἑκατέρα ἑκατέρᾳ. Here, and in numberless later passages, I have inserted the word “sides” for the reason given in the note on I. 1, line 20. It would have been permissible to supply either “straight lines” or “sides”; but on the whole “sides” seems to be more in accordance with the phraseology of I. 4.

.. [#f4] **the base BC is common to them,** i.e., apparently, common to the angles, as the αὐτῶν in :term:`βάσις <basis>` αὐτῶν κοινὴ can only refer to γωνίᾳ and γωνίᾳ preceding. :person:`Simson <simson>` wrote “and the base :g:`$BC$ <0265.g1:/ B C />` is common to the two triangles :g:`$BFC$ <0265.g1:< B F C >>`, :g:`$CGB$ <0265.g1:< C G B >>`”; :person:`Todhunter <todhunter>` left out these words as being of no use and tending to perplex a beginner. But :person:`Euclid <euclid>` evidently chose to quote the conclusion of I. 4 exactly; the first phrase of that conclusion is that the bases (of the two triangles) are equal, and, as the equal bases are here the *same* base, :person:`Euclid <euclid>` naturally substitutes the word “common” for “equal.”

.. [#f5] As “(Being) what it was required to prove” (or “do”) is somewhat long, I shall henceforth write the time-honoured “Q. E. D.” and “Q. E. F.” for :term:`ὅπερ ἔδει δεῖξαι <hoper-edei-deixai>` and :term:`ὅπερ ἔδει ποιῆσαι <hoper-edei-poiesai>`.
