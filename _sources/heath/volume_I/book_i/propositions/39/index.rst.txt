PROPOSITION 39.
===============

.. enunciation::

   Equal triangles which are on the same base and on the same side are also in the same parallels.

Let :g:`$ABC$ <0350.g2:< A B C >>`, :g:`$DBC$ <0350.g2:< D B C >>` be :eq:`equal <0350.g2:< A B C > = 0350.g2:< D B C >>` triangles which are on the same base :g:`$BC$ <0350.g2:/ B C />` and on the same side of it; [I say that they are also in the same parallels.]\ [#f1]_ And [For] let :g:`$AD$ <0350.g2:/ A D />` be joined;

I say that :g:`$AD$ <0350.g2:/ A D />` is parallel to :g:`$BC$ <0350.g2:/ B C />`.

.. picture:: 0350.g2.svg
   :alt: Folio 0350 Figure 2 - Proposition 39

For, if not, let :g:`$AE$ <0350.g2:/ A E />` be drawn through the point :g:`$A$ <0350.g2:A>` parallel to the straight line :g:`$BC$ <0350.g2:/ B C />`, :just:`[I. 31] <I.31>`

and let :g:`$EC$ <0350.g2:/ E C />` be joined.

Therefore the triangle :g:`$ABC$ <0350.g2:< A B C >>` is :eq:`equal <0350.g2:< A B C > = 0350.g2:< E B C >>` to the triangle :g:`$EBC$ <0350.g2:< E B C >>`; for it is on the same base :g:`$BC$ <0350.g2:/ B C />` with it and in the same parallels. :just:`[I. 37] <I.37>`

But :g:`$ABC$ <0350.g2:< A B C >>` is :eq:`equal <0350.g2:< A B C > = 0350.g2:< D B C >>` to :g:`$DBC$ <0350.g2:< D B C >>`;

.. assertion::

   therefore :g:`$DBC$ <0350.g2:< D B C >>` is also :eq:`equal <0350.g2:< D B C > = 0350.g2:< E B C >>` to :g:`$EBC$ <0350.g2:< E B C >>`, :just:`[C. N. 1] <I.cn.1>` the greater to the less: which is impossible.

.. assertion::

   Therefore :g:`$AE$ <0350.g2:/ A E />` is not parallel to :g:`$BC$ <0350.g2:/ B C />`.

Similarly we can prove that neither is any other straight line except :g:`$AD$ <0350.g2:/ A D />`;

.. assertion::

   therefore :g:`$AD$ <0350.g2:/ A D />` is parallel to :g:`$BC$ <0350.g2:/ B C />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`

.. [#f1] **[I say that they are also in the same parallels.]** :person:`Heiberg <heiberg>` has proved (*Hermes*, xxxviii., 1903, p. 50) from a recently discovered papyrus-fragment (*Fayūm towns and their papyri*, p. 96, No. ix.) that these words are an interpolation by some one who did not observe that the words “And let :g:`$AD$ <0350.g2:/ A D />` be joined” are part of the *setting-out* (:term:`ἔκθεσις <ekthesis>`), but took them as belonging to the *construction* (:term:`κατασκευή <kataskeue>`) and consequently thought that a :term:`διορισμός <diorismos>` or “definition” (of the thing to be proved) should precede. The interpolator then altered “And” into “For” in the next sentence.
