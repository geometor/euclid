PROPOSITION 24.
===============

.. enunciation::

   :term:`Similar segments of circles <similar-segments-of-circles>` on equal :term:`straight lines <straight-line>` are equal to one another.

For let :g:`AEB <0060.g1:( A E B )>`, :g:`CFD <0060.g1:( C F D )>` be similar segments of circles on
:eq:`equal <0060.g1:/ A B / = 0060.g1:/ C D />` straight lines :g:`AB <0060.g1:/ A B />`, :g:`CD <0060.g1:/ C D />`;
I say that the segment :g:`AEB <0060.g1:( A E B )>` is :eq:`equal <0060.g1:( A E B ) = 0060.g1:( C F D )>` to the segment :g:`CFD <0060.g1:( C F D )>`.

For, if the segment :g:`AEB <0060.g1:( A E B )>` be :coincide:`applied <0060.g1:( A E B ) ≡ 0060.g1:( C F D )>` to :g:`CFD <0060.g1:( C F D )>`, and if the
:term:`point <point>` :g:`A <0060.g1:A>` be :coincide:`placed on <0060.g1:A ≡ 0060.g1:C; 0060.g1:/ A B / ≡ 0060.g1:/ C D />` :g:`C <0060.g1:C>` and the straight line :g:`AB <0060.g1:/ A B />` on :g:`CD <0060.g1:/ C D />`,
the point :g:`B <0060.g1:B>` will also :coincide:`coincide <0060.g1:B ≡ 0060.g1:D>` with the point :g:`D <0060.g1:D>`, because
:g:`AB <0060.g1:/ A B />` is :eq:`equal <0060.g1:/ A B / = 0060.g1:/ C D />` to :g:`CD <0060.g1:/ C D />`;

.. _folio-ii-0060:

.. folio:: 0060
   :page: 54

.. subclause::

   and, :g:`AB <0060.g1:/ A B />` :coincide:`coinciding <0060.g1:/ A B / ≡ 0060.g1:/ C D />` with :g:`CD <0060.g1:/ C D />`,

the segment :g:`AEB <0060.g1:( A E B )>` will also :coincide:`coincide <0060.g1:( A E B ) ≡ 0060.g1:( C F D )>` with :g:`CFD <0060.g1:( C F D )>`.

.. picture:: 0060.g1.svg
   :alt: Diagram for Proposition 24

For, if the straight line :g:`AB <0060.g1:/ A B />` :coincide:`coincide <0060.g1:/ A B / ≡ 0060.g1:/ C D />` with :g:`CD <0060.g1:/ C D />` but the
segment :g:`AEB <0060.g1:( A E B )>` do not coincide with :g:`CFD <0060.g1:( C F D )>`,
it will either fall within it, or outside it;
or it will fall awry,\ [#f1]_ as :g:`CGD <0060.g1:( C G D )>`, and a :term:`circle <circle>` cuts a circle at more
points than two: which is impossible. :just:`[III. 10] <III.10>`

Therefore, if the straight line :g:`AB <0060.g1:/ A B />` be :coincide:`applied <0060.g1:/ A B / ≡ 0060.g1:/ C D />` to :g:`CD <0060.g1:/ C D />`, the
segment :g:`AEB <0060.g1:( A E B )>` will not fail to :coincide:`coincide <0060.g1:( A E B ) ≡ 0060.g1:( C F D )>` with :g:`CFD <0060.g1:( C F D )>` also;

.. assertion::

   therefore it will :coincide:`coincide <0060.g1:( A E B ) ≡ 0060.g1:( C F D )>` with it and will be :eq:`equal <0060.g1:( A E B ) = 0060.g1:( C F D )>` to it.

.. qed::

   Therefore etc. :just:`Q. E. D.`

.. [#f1] **fall awry**, :math:`\text{παραλλάξει}`, the same word as used in the like case in I. 8. The word implies that the applied figure will partly fall short of, and partly overlap, the figure to which it is applied.
