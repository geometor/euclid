PROPOSITION 12.
===============

.. enunciation::

   About a given circle to circumscribe an equilateral and equiangular pentagon.

Let :g:`$ABCDE$ <0108.g2:( A B C D E )>` be the given circle;
thus it is required to circumscribe an equilateral and equiangular
pentagon about the circle
:g:`$ABCDE$ <0108.g2:( A B C D E )>`.

Let :g:`$A$ <0108.g2:A>`, :g:`$B$ <0108.g2:B>`, :g:`$C$ <0108.g2:C>`, :g:`$D$ <0108.g2:D>`, :g:`$E$ <0108.g2:E>` be conceived to
be the angular points of the inscribed
pentagon, so that the circumferences
:g:`$AB$ <0108.g2:( A B )>`, :g:`$BC$ <0108.g2:( B C )>`, :g:`$CD$ <0108.g2:( C D )>`, :g:`$DE$ <0108.g2:( D E )>`, :g:`$EA$ <0108.g2:( E A )>` are :eq:`equal <0108.g2:( A B ) = 0108.g2:( B C ) = 0108.g2:( C D ) = 0108.g2:( D E ) = 0108.g2:( E A )>`;
:just:`[IV. 11] <IV.11>`
through :g:`$A$ <0108.g2:A>`, :g:`$B$ <0108.g2:B>`, :g:`$C$ <0108.g2:C>`, :g:`$D$ <0108.g2:D>`, :g:`$E$ <0108.g2:E>` let :g:`$GH$ <0108.g2:/ G H />`, :g:`$HK$ <0108.g2:/ H K />`,
:g:`$KL$ <0108.g2:/ K L />`, :g:`$LM$ <0108.g2:/ L M />`, :g:`$MG$ <0108.g2:/ M G />` be drawn touching the
circle;
:just:`[III. 16, Por.]`

.. picture:: 0108.g2.svg
   :alt: Proposition 12 diagram

let the centre :g:`$F$ <0108.g2:F>` of the circle :g:`$ABCDE$ <0108.g2:( A B C D E )>` be taken :just:`[III. 1] <III.1>`, and
let :g:`$FB$ <0108.g2:/ F B />`, :g:`$FK$ <0108.g2:/ F K />`, :g:`$FC$ <0108.g2:/ F C />`, :g:`$FL$ <0108.g2:/ F L />`, :g:`$FD$ <0108.g2:/ F D />` be joined.

Then, since the straight line :g:`$KL$ <0108.g2:/ K L />` touches the circle :g:`$ABCDE$ <0108.g2:( A B C D E )>`
at :g:`$C$ <0108.g2:C>`,
and :g:`$FC$ <0108.g2:/ F C />` has been joined from the centre :g:`$F$ <0108.g2:F>` to the point of
contact at :g:`$C$ <0108.g2:C>`,

.. assertion:: [III. 18] <III.18>

   therefore :g:`$FC$ <0108.g2:/ F C />` is perpendicular to :g:`$KL$ <0108.g2:/ K L />`;

.. assertion::

   therefore each of the angles at :g:`$C$ <0108.g2:< K C L )>` is right.

For the same reason

.. assertion::

   the angles at the points :g:`$B$ <0108.g2:< F B K )>`, :g:`$D$ <0108.g2:< F D L )>` are also :eq:`right <0108.g2:< F B K ) = 0108.g2:< F D L )>`.

.. _folio-ii-0109:

.. folio:: 0109
   :page: 103

And, since the angle :g:`$FCK$ <0108.g2:< F C K )>` is right,

.. assertion::

   therefore the square on :g:`$FK$ <0108.g2:/ F K />` is equal to the squares on :g:`$FC$ <0108.g2:/ F C />`, :g:`$CK$ <0108.g2:/ C K />`.

For the same reason :just:`[I. 47] <I.47>`

.. assertion::

   the square on :g:`$FK$ <0108.g2:/ F K />` is also equal to the squares on :g:`$FB$ <0108.g2:/ F B />`, :g:`$BK$ <0108.g2:/ B K />`;

so that the squares on :g:`$FC$ <0108.g2:/ F C />`, :g:`$CK$ <0108.g2:/ C K />` are equal to the squares
on :g:`$FB$ <0108.g2:/ F B />`, :g:`$BK$ <0108.g2:/ B K />`,

.. subclause::

   of which the square on :g:`$FC$ <0108.g2:/ F C />` is :eq:`equal <0108.g2:/ F C / = 0108.g2:/ F B />` to the square on :g:`$FB$ <0108.g2:/ F B />`;

.. assertion::

   therefore the square on :g:`$CK$ <0108.g2:/ C K />` which remains is :eq:`equal <0108.g2:/ C K / = 0108.g2:/ B K />` to the square on :g:`$BK$ <0108.g2:/ B K />`.

.. assertion::

   Therefore :g:`$BK$ <0108.g2:/ B K />` is :eq:`equal <0108.g2:/ B K / = 0108.g2:/ C K />` to :g:`$CK$ <0108.g2:/ C K />`.

And, since :g:`$FB$ <0108.g2:/ F B />` is :eq:`equal <0108.g2:/ F B / = 0108.g2:/ F C />` to :g:`$FC$ <0108.g2:/ F C />`,
and :g:`$FK$ <0108.g2:/ F K />` common,
the two sides :g:`$BF$ <0108.g2:/ B F />`, :g:`$FK$ <0108.g2:/ F K />` are :eq:`equal <0108.g2:/ B F / = 0108.g2:/ C F /; 0108.g2:/ F K / = 0108.g2:/ F K />` to the two sides :g:`$CF$ <0108.g2:/ C F />`, :g:`$FK$ <0108.g2:/ F K />`;
and the base :g:`$BK$ <0108.g2:/ B K />` :eq:`equal <0108.g2:/ B K / = 0108.g2:/ C K />` to the base :g:`$CK$ <0108.g2:/ C K />`;

.. assertion::

   therefore the angle :g:`$BFK$ <0108.g2:< B F K )>` is :eq:`equal <0108.g2:< B F K ) = 0108.g2:< K F C )>` to the angle :g:`$KFC$ <0108.g2:< K F C )>`, :just:`[I. 8] <I.8>` and the angle :g:`$BKF$ <0108.g2:< B K F )>` :eq:`to <0108.g2:< B K F ) = 0108.g2:< F K C )>` the angle :g:`$FKC$ <0108.g2:< F K C )>`.

.. assertion::

   Therefore the angle :g:`$BFC$ <0108.g2:< B F C )>` is double of the angle :g:`$KFC$ <0108.g2:< K F C )>`, and the angle :g:`$BKC$ <0108.g2:< B K C )>` of the angle :g:`$FKC$ <0108.g2:< F K C )>`.

For the same reason

.. assertion::

   the angle :g:`$CFD$ <0108.g2:< C F D )>` is also double of the angle :g:`$CFL$ <0108.g2:< C F L )>`, and the angle :g:`$DLC$ <0108.g2:< D L C )>` of the angle :g:`$FLC$ <0108.g2:< F L C )>`.

Now, since the circumference :g:`$BC$ <0108.g2:( B C )>` is :eq:`equal <0108.g2:( B C ) = 0108.g2:( C D )>` to :g:`$CD$ <0108.g2:( C D )>`,

.. assertion:: [III. 27] <III.27>

   the angle :g:`$BFC$ <0108.g2:< B F C )>` is also :eq:`equal <0108.g2:< B F C ) = 0108.g2:< C F D )>` to the angle :g:`$CFD$ <0108.g2:< C F D )>`.

And the angle :g:`$BFC$ <0108.g2:< B F C )>` is double of the angle :g:`$KFC$ <0108.g2:< K F C )>`, and the
angle :g:`$DFC$ <0108.g2:< D F C )>` of the angle :g:`$LFC$ <0108.g2:< L F C )>`;

.. assertion::

   therefore the angle :g:`$KFC$ <0108.g2:< K F C )>` is also :eq:`equal <0108.g2:< K F C ) = 0108.g2:< L F C )>` to the angle :g:`$LFC$ <0108.g2:< L F C )>`.

But the angle :g:`$FCK$ <0108.g2:< F C K )>` is also :eq:`equal <0108.g2:< F C K ) = 0108.g2:< F C L )>` to the angle :g:`$FCL$ <0108.g2:< F C L )>`;
therefore :g:`$FKC$ <0108.g2:< F K C >>`, :g:`$FLC$ <0108.g2:< F L C >>` are two triangles having two angles
equal to two angles and one side equal to one side, namely
:g:`$FC$ <0108.g2:/ F C />` which is common to them;
therefore they will also have the remaining sides equal to the
remaining sides, and the remaining angle to the remaining
angle; :just:`[I. 26] <I.26>`

.. assertion::

   therefore the straight line :g:`$KC$ <0108.g2:/ K C />` is :eq:`equal <0108.g2:/ K C / = 0108.g2:/ C L />` to :g:`$CL$ <0108.g2:/ C L />`, and the angle :g:`$FKC$ <0108.g2:< F K C )>` :eq:`to <0108.g2:< F K C ) = 0108.g2:< F L C )>` the angle :g:`$FLC$ <0108.g2:< F L C )>`.

And, since :g:`$KC$ <0108.g2:/ K C />` is :eq:`equal <0108.g2:/ K C / = 0108.g2:/ C L />` to :g:`$CL$ <0108.g2:/ C L />`,

.. assertion::

   therefore :g:`$KL$ <0108.g2:/ K L />` is double of :g:`$KC$ <0108.g2:/ K C />`.

.. _folio-ii-0110:

.. folio:: 0110
   :page: 104

For the same reason it can be proved that

.. assertion::

   :g:`$HK$ <0108.g2:/ H K />` is also double of :g:`$BK$ <0108.g2:/ B K />`.

And :g:`$BK$ <0108.g2:/ B K />` is :eq:`equal <0108.g2:/ B K / = 0108.g2:/ K C />` to :g:`$KC$ <0108.g2:/ K C />`;

.. assertion::

   therefore :g:`$HK$ <0108.g2:/ H K />` is also :eq:`equal <0108.g2:/ H K / = 0108.g2:/ K L />` to :g:`$KL$ <0108.g2:/ K L />`.

Similarly each of the straight lines :g:`$HG$ <0108.g2:/ H G />`, :g:`$GM$ <0108.g2:/ G M />`, :g:`$ML$ <0108.g2:/ M L />` can also
be proved :eq:`equal <0108.g2:/ H G / = 0108.g2:/ G M / = 0108.g2:/ M L / = 0108.g2:/ H K / = 0108.g2:/ K L />` to each of the straight lines :g:`$HK$ <0108.g2:/ H K />`, :g:`$KL$ <0108.g2:/ K L />`;

.. assertion::

   therefore the pentagon :g:`$GHKLM$ <0108.g2:< G H K L M >>` is :eq:`equilateral <0108.g2:/ G H / = 0108.g2:/ H K / = 0108.g2:/ K L / = 0108.g2:/ L M / = 0108.g2:/ M G />`.

I say next that it is also :eq:`equiangular <0108.g2:< G H K ) = 0108.g2:< H K L ) = 0108.g2:< K L M ) = 0108.g2:< L M G ) = 0108.g2:< M G H )>`.

For, since the angle :g:`$FKC$ <0108.g2:< F K C )>` is :eq:`equal <0108.g2:< F K C ) = 0108.g2:< F L C )>` to the angle :g:`$FLC$ <0108.g2:< F L C )>`,
and the angle :g:`$HKL$ <0108.g2:< H K L )>` was proved double of the angle :g:`$FKC$ <0108.g2:< F K C )>`,
and the angle :g:`$KLM$ <0108.g2:< K L M )>` double of the angle :g:`$FLC$ <0108.g2:< F L C )>`,

.. assertion::

   therefore the angle :g:`$HKL$ <0108.g2:< H K L )>` is also :eq:`equal <0108.g2:< H K L ) = 0108.g2:< K L M )>` to the angle :g:`$KLM$ <0108.g2:< K L M )>`.

Similarly each of the angles :g:`$KHG$ <0108.g2:< K H G )>`, :g:`$HGM$ <0108.g2:< H G M )>`, :g:`$GML$ <0108.g2:< G M L )>` can also
be proved :eq:`equal <0108.g2:< K H G ) = 0108.g2:< H G M ) = 0108.g2:< G M L ) = 0108.g2:< H K L ) = 0108.g2:< K L M )>` to each of the angles :g:`$HKL$ <0108.g2:< H K L )>`, :g:`$KLM$ <0108.g2:< K L M )>`;

.. assertion::

   therefore the five angles :g:`$GHK$ <0108.g2:< G H K )>`, :g:`$HKL$ <0108.g2:< H K L )>`, :g:`$KLM$ <0108.g2:< K L M )>`, :g:`$LMG$ <0108.g2:< L M G )>`, :g:`$MGH$ <0108.g2:< M G H )>` are :eq:`equal <0108.g2:< G H K ) = 0108.g2:< H K L ) = 0108.g2:< K L M ) = 0108.g2:< L M G ) = 0108.g2:< M G H )>` to one another.

.. assertion::

   Therefore the pentagon :g:`$GHKLM$ <0108.g2:< G H K L M >>` is :eq:`equiangular <0108.g2:< G H K ) = 0108.g2:< H K L ) = 0108.g2:< K L M ) = 0108.g2:< L M G ) = 0108.g2:< M G H )>`.

And it was also proved :eq:`equilateral <0108.g2:/ G H / = 0108.g2:/ H K / = 0108.g2:/ K L / = 0108.g2:/ L M / = 0108.g2:/ M G />`; and it has been
circumscribed about the circle :g:`$ABCDE$ <0108.g2:( A B C D E )>`.

.. qed::

   :just:`Q. E. F.`
