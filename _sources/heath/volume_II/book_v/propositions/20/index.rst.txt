PROPOSITION 20.
===============

.. enunciation::

   If there be three magnitudes, and others equal to them in multitude, which taken two and two are in the same ratio, and if :term:`*ex aequali* <ex-aequali>` the first be greater than the third, the fourth will also be greater than the sixth ; if equal, equal ; and, if less, less.

.. _folio-ii-0182:

.. folio:: 0182
   :page: 176

Let there be three magnitudes :g:`$A$ <0182.g1:A>`, :g:`$B$ <0182.g1:B>`, :g:`$C$ <0182.g1:C>`, and others :g:`$D$ <0182.g1:D>`, :g:`$E$ <0182.g1:E>`, :g:`$F$ <0182.g1:F>` equal to them in multitude, which taken two and two are in the same ratio, so that,

.. assertion::

   as :g:`$A$ <0182.g1:A>` is to :g:`$B$ <0182.g1:B>`, so is :g:`$D$ <0182.g1:D>` to :g:`$E$ <0182.g1:E>`,

and

.. assertion::

   as :g:`$B$ <0182.g1:B>` is to :g:`$C$ <0182.g1:C>`, so is :g:`$E$ <0182.g1:E>` to :g:`$F$ <0182.g1:F>`;

and let :g:`$A$ <0182.g1:A>` be greater than :g:`$C$ <0182.g1:C>` :term:`*ex aequali* <ex-aequali>` ;

I say that :g:`$D$ <0182.g1:D>` will also be greater than :g:`$F$ <0182.g1:F>`; if :g:`$A$ <0182.g1:A>` is :eq:`equal <0182.g1:A = 0182.g1:C>` to :g:`$C$ <0182.g1:C>`, :eq:`equal <0182.g1:D = 0182.g1:F>` ; and, if less, less.

.. picture:: 0182.g1.svg
   :alt: Proposition 20

For, since :g:`$A$ <0182.g1:A>` is greater than :g:`$C$ <0182.g1:C>`, and :g:`$B$ <0182.g1:B>` is some other magnitude, and the greater has to the same a greater ratio than the less has, :just:`[V. 8] <V.8>`

.. assertion::

   therefore :g:`$A$ <0182.g1:A>` has to :g:`$B$ <0182.g1:B>` a greater ratio than :g:`$C$ <0182.g1:C>` has to :g:`$B$ <0182.g1:B>`.

But, as :g:`$A$ <0182.g1:A>` is to :g:`$B$ <0182.g1:B>`, so is :g:`$D$ <0182.g1:D>` to :g:`$E$ <0182.g1:E>`, and, as :g:`$C$ <0182.g1:C>` is to :g:`$B$ <0182.g1:B>`, inversely, so is :g:`$F$ <0182.g1:F>` to :g:`$E$ <0182.g1:E>` ;

.. assertion:: [V. 13] <V.13>

   therefore :g:`$D$ <0182.g1:D>` has also to :g:`$E$ <0182.g1:E>` a greater ratio than :g:`$F$ <0182.g1:F>` has to :g:`$E$ <0182.g1:E>`.

.. subclause::

   But, of magnitudes which have a ratio to the same, that which has a greater ratio is greater ; :just:`[V. 10] <V.10>`

.. assertion::

   therefore :g:`$D$ <0182.g1:D>` is greater than :g:`$F$ <0182.g1:F>`.

Similarly we can prove that, if :g:`$A$ <0182.g1:A>` be :eq:`equal <0182.g1:A = 0182.g1:C>` to :g:`$C$ <0182.g1:C>`, :g:`$D$ <0182.g1:D>` will also be :eq:`equal <0182.g1:D = 0182.g1:F>` to :g:`$F$ <0182.g1:F>`; and if less, less.

.. qed::

   Therefore etc. :just:`Q. E. D.`
