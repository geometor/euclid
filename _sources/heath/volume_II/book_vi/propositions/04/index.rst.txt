PROPOSITION 4.
==============

.. enunciation::

   In equiangular triangles the sides about the equal angles are proportional, and those are corresponding sides which subtend the equal angles.

.. _folio-ii-0207:

.. folio:: 0207
   :page: 201

Let :g:`$ABC$ <0207.g1:< A B C >>`, :g:`$DCE$ <0207.g1:< D C E >>` be equiangular triangles having the angle :g:`$ABC$ <0207.g1:< A B C )>` equal to the angle :g:`$DCE$ <0207.g1:< D C E )>`, the angle :g:`$BAC$ <0207.g1:< B A C )>` to the angle :g:`$CDE$ <0207.g1:< C D E )>`, and further the angle :g:`$ACB$ <0207.g1:< A C B )>` to the angle :g:`$CED$ <0207.g1:< C E D )>`;

I say that in the triangles :g:`$ABC$ <0207.g1:< A B C >>`, :g:`$DCE$ <0207.g1:< D C E >>` the sides about the equal angles are proportional, and those are corresponding sides which subtend the equal angles.

.. picture:: 0207.g1.svg
   :alt: Proposition 4

For let :g:`$BC$ <0207.g1:/ B C />` be placed in a straight line with :g:`$CE$ <0207.g1:/ C E />`.

Then, since the angles :g:`$ABC$ <0207.g1:< A B C )>`, :g:`$ACB$ <0207.g1:< A C B )>` are less than two right angles, :just:`[I. 17] <I.17>`

and the angle :g:`$ACB$ <0207.g1:< A C B )>` is equal to the angle :g:`$DEC$ <0207.g1:< D E C )>`,

.. assertion::

   therefore the angles :g:`$ABC$ <0207.g1:< A B C )>`, :g:`$DEC$ <0207.g1:< D E C )>` are less than two right angles;

.. assertion:: [I. Post. 5] <I.post.5>

   therefore :g:`$BA$ <0207.g1:/ B A />`, :g:`$ED$ <0207.g1:/ E D />`, when produced, will meet.

Let them be produced and meet at :g:`$F$ <0207.g1:F>`.

Now, since the angle :g:`$DCE$ <0207.g1:< D C E )>` is equal to the angle :g:`$ABC$ <0207.g1:< A B C )>`,

.. assertion:: [I. 28] <I.28>

   :g:`$BF$ <0207.g1:/ B F />` is parallel to :g:`$CD$ <0207.g1:/ C D />`.

Again, since the angle :g:`$ACB$ <0207.g1:< A C B )>` is equal to the angle :g:`$DEC$ <0207.g1:< D E C )>`,

.. assertion:: [I. 28] <I.28>

   :g:`$AC$ <0207.g1:/ A C />` is parallel to :g:`$FE$ <0207.g1:/ F E />`.

.. assertion::

   Therefore :g:`$FACD$ <0207.g1:< F A C D >>` is a parallelogram;

.. assertion:: [I. 34] <I.34>

   therefore :g:`$FA$ <0207.g1:/ F A />` is equal to :g:`$DC$ <0207.g1:/ D C />`, and :g:`$AC$ <0207.g1:/ A C />` to :g:`$FD$ <0207.g1:/ F D />`.

And, since :g:`$AC$ <0207.g1:/ A C />` has been drawn parallel to :g:`$FE$ <0207.g1:/ F E />`, one side of the triangle :g:`$FBE$ <0207.g1:< F B E >>`,

.. assertion:: [VI. 2] <VI.2>

   therefore, as :g:`$BA$ <0207.g1:/ B A />` is to :g:`$AF$ <0207.g1:/ A F />`, so is :g:`$BC$ <0207.g1:/ B C />` to :g:`$CE$ <0207.g1:/ C E />`.

.. subclause::

   But :g:`$AF$ <0207.g1:/ A F />` is equal to :g:`$CD$ <0207.g1:/ C D />`;

.. assertion::

   therefore, as :g:`$BA$ <0207.g1:/ B A />` is to :g:`$CD$ <0207.g1:/ C D />`, so is :g:`$BC$ <0207.g1:/ B C />` to :g:`$CE$ <0207.g1:/ C E />`, and alternately, as :g:`$AB$ <0207.g1:/ A B />` is to :g:`$BC$ <0207.g1:/ B C />`, so is :g:`$DC$ <0207.g1:/ D C />` to :g:`$CE$ <0207.g1:/ C E />`. :just:`[V. 16] <V.16>`

Again, since :g:`$CD$ <0207.g1:/ C D />` is parallel to :g:`$BF$ <0207.g1:/ B F />`,

.. assertion:: [VI. 2] <VI.2>

   therefore, as :g:`$BC$ <0207.g1:/ B C />` is to :g:`$CE$ <0207.g1:/ C E />`, so is :g:`$FD$ <0207.g1:/ F D />` to :g:`$DE$ <0207.g1:/ D E />`.

.. subclause::

   But :g:`$FD$ <0207.g1:/ F D />` is equal to :g:`$AC$ <0207.g1:/ A C />`;

.. assertion::

   therefore, as :g:`$BC$ <0207.g1:/ B C />` is to :g:`$CE$ <0207.g1:/ C E />`, so is :g:`$AC$ <0207.g1:/ A C />` to :g:`$DE$ <0207.g1:/ D E />`, and alternately, as :g:`$BC$ <0207.g1:/ B C />` is to :g:`$CA$ <0207.g1:/ C A />`, so is :g:`$CE$ <0207.g1:/ C E />` to :g:`$ED$ <0207.g1:/ E D />`. :just:`[V. 16] <V.16>`

.. _folio-ii-0208:

.. folio:: 0208
   :page: 202

Since then it was proved that,

.. assertion::

   as :g:`$AB$ <0207.g1:/ A B />` is to :g:`$BC$ <0207.g1:/ B C />`, so is :g:`$DC$ <0207.g1:/ D C />` to :g:`$CE$ <0207.g1:/ C E />`, and, as :g:`$BC$ <0207.g1:/ B C />` is to :g:`$CA$ <0207.g1:/ C A />`, so is :g:`$CE$ <0207.g1:/ C E />` to :g:`$ED$ <0207.g1:/ E D />`;

.. assertion:: [V. 22] <V.22>

   therefore, :term:`*ex aequali* <ex-aequali>`, as :g:`$BA$ <0207.g1:/ B A />` is to :g:`$AC$ <0207.g1:/ A C />`, so is :g:`$CD$ <0207.g1:/ C D />` to :g:`$DE$ <0207.g1:/ D E />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
