PROPOSITION 31.
===============

.. enunciation::

   In right-angled triangles the figure on the side subtending the right angle is equal to the similar and similarly described figures on the sides containing the right angle.

Let :g:`$ABC$ <0275.g1:< A B C >>` be a right-angled triangle having the angle :g:`$BAC$ <0275.g1:< B A C )>` right ;

I say that the figure on :g:`$BC$ <0275.g1:/ B C />` is equal to the similar and similarly described figures on :g:`$BA$ <0275.g1:/ B A />`, :g:`$AC$ <0275.g1:/ A C />`.

Let :g:`$AD$ <0275.g1:/ A D />` be drawn perpendicular.

.. subclause::

   Then since, in the right-angled triangle :g:`$ABC$ <0275.g1:< A B C >>`, :g:`$AD$ <0275.g1:/ A D />` has

.. _folio-ii-0275:

.. folio:: 0275
   :page: 269

.. subclause::

   been drawn from the right angle at :g:`$A$ <0275.g1:A>` perpendicular to the base :g:`$BC$ <0275.g1:/ B C />`,

.. assertion::

   the triangles :g:`$ABD$ <0275.g1:< A B D >>`, :g:`$ADC$ <0275.g1:< A D C >>` adjoining the perpendicular are similar both to the whole :g:`$ABC$ <0275.g1:< A B C >>` and to one another. :just:`[VI. 8] <VI.8>`

.. picture:: 0275.g1.svg
   :alt: Proposition 31

.. subclause::

   And, since :g:`$ABC$ <0275.g1:< A B C >>` is similar to :g:`$ABD$ <0275.g1:< A B D >>`,

.. assertion::

   therefore, as :g:`$CB$ <0275.g1:/ C B />` is to :g:`$BA$ <0275.g1:/ B A />`, so is :g:`$AB$ <0275.g1:/ A B />` to :g:`$BD$ <0275.g1:/ B D />`. :just:`[VI. Def. 1] <VI.def.1>`

.. subclause::

   And, since three straight lines are proportional, as the first is to the third, so is the figure on the first to the similar and similarly described figure on the second. :just:`[VI. 19, Por.]`

.. assertion::

   Therefore, as :g:`$CB$ <0275.g1:/ C B />` is to :g:`$BD$ <0275.g1:/ B D />`, so is the figure on :g:`$CB$ <0275.g1:/ C B />` to the similar and similarly described figure on :g:`$BA$ <0275.g1:/ B A />`.

.. subclause::

   For the same reason also,

.. assertion::

   as :g:`$BC$ <0275.g1:/ B C />` is to :g:`$CD$ <0275.g1:/ C D />`, so is the figure on :g:`$BC$ <0275.g1:/ B C />` to that on :g:`$CA$ <0275.g1:/ C A />` ;

.. subclause::

   so that, in addition,

.. assertion::

   as :g:`$BC$ <0275.g1:/ B C />` is to :g:`$BD$ <0275.g1:/ B D />`, :g:`$DC$ <0275.g1:/ D C />`, so is the figure on :g:`$BC$ <0275.g1:/ B C />` to the similar and similarly described figures on :g:`$BA$ <0275.g1:/ B A />`, :g:`$AC$ <0275.g1:/ A C />`.

.. subclause::

   But :g:`$BC$ <0275.g1:/ B C />` is equal to :g:`$BD$ <0275.g1:/ B D />`, :g:`$DC$ <0275.g1:/ D C />` ;

.. assertion::

   therefore the figure on :g:`$BC$ <0275.g1:/ B C />` is also equal to the similar and similarly described figures on :g:`$BA$ <0275.g1:/ B A />`, :g:`$AC$ <0275.g1:/ A C />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
