PROPOSITION 4.
==============

.. enunciation::

   Any number is either a part or parts of any number, the less of the greater.

Let :g:`A <0309.g1:A>`, :g:`BC <0309.g1:/ B C />` be two numbers, and let :g:`BC <0309.g1:/ B C />` be the less ;

I say that :g:`BC <0309.g1:/ B C />` is either a part, or parts, of :g:`A <0309.g1:A>`.

.. subclause::

   For :g:`A <0309.g1:A>`, :g:`BC <0309.g1:/ B C />` are either prime to one another or not.

First, let :g:`A <0309.g1:A>`, :g:`BC <0309.g1:/ B C />` be prime to one another.

.. subclause::

   Then, if :g:`BC <0309.g1:/ B C />` be divided into the units in it, each unit of those in :g:`BC <0309.g1:/ B C />` will be some part of :g:`A <0309.g1:A>` ;

.. assertion::

   so that :g:`BC <0309.g1:/ B C />` is parts of :g:`A <0309.g1:A>`.

Next let :g:`A <0309.g1:A>`, :g:`BC <0309.g1:/ B C />` not be prime to one another ; then :g:`BC <0309.g1:/ B C />` either measures, or does not measure, :g:`A <0309.g1:A>`.

.. subclause::

   If now :g:`BC <0309.g1:/ B C />` measures :g:`A <0309.g1:A>`, :g:`BC <0309.g1:/ B C />` is a part of :g:`A <0309.g1:A>`.

.. picture:: 0309.g1.svg
   :alt: Proposition 4 Diagram

But, if not, let the greatest common measure :g:`D <0309.g1:D>` of :g:`A <0309.g1:A>`, :g:`BC <0309.g1:/ B C />` be taken ; :just:`[VII. 2] <VII.2>`

and let :g:`BC <0309.g1:/ B C />` be divided into the numbers :eq:`equal <0309.g1:/ B E / = 0309.g1:/ E F / = 0309.g1:/ F C / = 0309.g1:D>` to :g:`D <0309.g1:D>`, namely :g:`BE <0309.g1:/ B E />`, :g:`EF <0309.g1:/ E F />`, :g:`FC <0309.g1:/ F C />`.

.. subclause::

   Now, since :g:`D <0309.g1:D>` measures :g:`A <0309.g1:A>`, :g:`D <0309.g1:D>` is a part of :g:`A <0309.g1:A>`.

.. subclause::

   But :g:`D <0309.g1:D>` is :eq:`equal <0309.g1:D = 0309.g1:/ B E / = 0309.g1:/ E F / = 0309.g1:/ F C />` to each of the numbers :g:`BE <0309.g1:/ B E />`, :g:`EF <0309.g1:/ E F />`, :g:`FC <0309.g1:/ F C />` ;

.. assertion::

   therefore each of the numbers :g:`BE <0309.g1:/ B E />`, :g:`EF <0309.g1:/ E F />`, :g:`FC <0309.g1:/ F C />` is also a part of :g:`A <0309.g1:A>` ;

.. assertion::

   so that :g:`BC <0309.g1:/ B C />` is parts of :g:`A <0309.g1:A>`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
