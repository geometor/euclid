PROPOSITION 11.
===============

.. enunciation::

   If four magnitudes be proportional, and the first be commensurable with the second, the third will also be commensurable with the fourth ; and, if the first be incommensurable with the second, the third will also be incommensurable with the fourth.

Let :g:`$A$ <0037.g1:A>`, :g:`$B$ <0037.g1:B>`, :g:`$C$ <0037.g1:C>`, :g:`$D$ <0037.g1:D>` be four magnitudes in proportion, so that, as :g:`$A$ <0037.g1:A>` is to :g:`$B$ <0037.g1:B>`, so is :g:`$C$ <0037.g1:C>` to :g:`$D$ <0037.g1:D>`, and let :g:`$A$ <0037.g1:A>` be commensurable with :g:`$B$ <0037.g1:B>` ; I say that :g:`$C$ <0037.g1:C>` will also be commensurable with :g:`$D$ <0037.g1:D>`.

.. picture:: 0037.g1.svg
   :alt: Proposition 11 diagram

.. subclause::

   For, since :g:`$A$ <0037.g1:A>` is commensurable with :g:`$B$ <0037.g1:B>`,

.. assertion::

   therefore :g:`$A$ <0037.g1:A>` has to :g:`$B$ <0037.g1:B>` the ratio which a number has to a number. :just:`[X. 5] <X.5>`

.. subclause::

   And, as :g:`$A$ <0037.g1:A>` is to :g:`$B$ <0037.g1:B>`, so is :g:`$C$ <0037.g1:C>` to :g:`$D$ <0037.g1:D>` ;

.. assertion::

   therefore :g:`$C$ <0037.g1:C>` also has to :g:`$D$ <0037.g1:D>` the ratio which a number has to a number ; therefore :g:`$C$ <0037.g1:C>` is commensurable with :g:`$D$ <0037.g1:D>`. :just:`[X. 6] <X.6>`

Next, let :g:`$A$ <0037.g1:A>` be incommensurable with :g:`$B$ <0037.g1:B>` ; I say that :g:`$C$ <0037.g1:C>` will also be incommensurable with :g:`$D$ <0037.g1:D>`.

.. subclause::

   For, since :g:`$A$ <0037.g1:A>` is incommensurable with :g:`$B$ <0037.g1:B>`,

.. assertion::

   therefore :g:`$A$ <0037.g1:A>` has not to :g:`$B$ <0037.g1:B>` the ratio which a number has to a number. :just:`[X. 7] <X.7>`

.. _folio-iii-0038:

.. folio:: 0038
   :page: 34

.. subclause::

   And, as :g:`$A$ <0037.g1:A>` is to :g:`$B$ <0037.g1:B>`, so is :g:`$C$ <0037.g1:C>` to :g:`$D$ <0037.g1:D>`;

.. assertion::

   therefore neither has :g:`$C$ <0037.g1:C>` to :g:`$D$ <0037.g1:D>` the ratio which a number has to a number; therefore :g:`$C$ <0037.g1:C>` is incommensurable with :g:`$D$ <0037.g1:D>`. :just:`[X. 8] <X.8>`

.. qed::

   Therefore etc.
