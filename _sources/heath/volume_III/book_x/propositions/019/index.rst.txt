PROPOSITION 19.
===============

.. enunciation::

   The rectangle contained by rational straight lines commensurable in length is rational.

For let the rectangle :g:`$AC$ <0051.g1:< A C >>` be contained by the rational straight lines :g:`$AB$ <0051.g1:/ A B />`, :g:`$BC$ <0051.g1:/ B C />` commensurable in length; I say that :g:`$AC$ <0051.g1:< A C >>` is rational.

.. picture:: 0051.g1.svg
   :alt: Proposition 19

For on :g:`$AB$ <0051.g1:/ A B />` let the square :g:`$AD$ <0051.g1:< A D >>` be described;

.. assertion:: [X. Def. 4] <X.def.4>

   therefore :g:`$AD$ <0051.g1:< A D >>` is rational.

.. subclause::

   And, since :g:`$AB$ <0051.g1:/ A B />` is commensurable in length with :g:`$BC$ <0051.g1:/ B C />`, while :g:`$AB$ <0051.g1:/ A B />` is :eq:`equal <0051.g1:/ A B / = 0051.g1:/ B D />` to :g:`$BD$ <0051.g1:/ B D />`,

.. assertion::

   therefore :g:`$BD$ <0051.g1:/ B D />` is commensurable in length with :g:`$BC$ <0051.g1:/ B C />`.

.. _folio-iii-0052:

.. folio:: 0052
   :page: 48

.. subclause:: [VI. 1] <VI.1>

   And, as :g:`$BD$ <0051.g1:/ B D />` is to :g:`$BC$ <0051.g1:/ B C />`, so is :g:`$DA$ <0051.g1:< D A >>` to :g:`$AC$ <0051.g1:< A C >>`.

.. assertion:: [X. 11] <X.11>

   Therefore :g:`$DA$ <0051.g1:< D A >>` is commensurable with :g:`$AC$ <0051.g1:< A C >>`.

.. subclause::

   But :g:`$DA$ <0051.g1:< D A >>` is rational;

.. assertion:: [X. Def. 4] <X.def.4>

   therefore :g:`$AC$ <0051.g1:< A C >>` is also rational.

.. qed::

   Therefore etc.
