PROPOSITION 90.
===============

.. enunciation::

   To find the sixth apotome.

.. picture:: 0192.g1.svg
   :alt: Proposition 90

Let a rational straight line :g:`$A$ <0192.g1:A>` be set out, and three numbers :g:`$E$ <0192.g1:E>`, :g:`$BC$ <0192.g1:/ B C />`, :g:`$CD$ <0192.g1:/ C D />` not having to one another the ratio which a square number has to a square number ; and further let :g:`$CB$ <0192.g1:/ C B />` also not have to :g:`$BD$ <0192.g1:/ B D />` the ratio which a square number has to a square number.

Let it be contrived that, as :g:`$E$ <0192.g1:E>` is to :g:`$BC$ <0192.g1:/ B C />`, so is the square on :g:`$A$ <0192.g1:A>` to the square on :g:`$FG$ <0192.g1:/ F G />`, and, as :g:`$BC$ <0192.g1:/ B C />` is to :g:`$CD$ <0192.g1:/ C D />`, so is the square on :g:`$FG$ <0192.g1:/ F G />` to the square on :g:`$GH$ <0192.g1:/ G H />`. :just:`[X. 6, Por.]`

.. subclause::

   Now since, as :g:`$E$ <0192.g1:E>` is to :g:`$BC$ <0192.g1:/ B C />`, so is the square on :g:`$A$ <0192.g1:A>` to the square on :g:`$FG$ <0192.g1:/ F G />`,

.. assertion::

   therefore the square on :g:`$A$ <0192.g1:A>` is commensurable with the square on :g:`$FG$ <0192.g1:/ F G />`. :just:`[X. 6] <X.6>`

.. subclause::

   But the square on :g:`$A$ <0192.g1:A>` is rational ;

.. assertion::

   therefore the square on :g:`$FG$ <0192.g1:/ F G />` is also rational ; therefore :g:`$FG$ <0192.g1:/ F G />` is also rational.

.. subclause::

   And, since :g:`$E$ <0192.g1:E>` has not to :g:`$BC$ <0192.g1:/ B C />` the ratio which a square number has to a square number,

.. assertion::

   therefore neither has the square on :g:`$A$ <0192.g1:A>` to the square on :g:`$FG$ <0192.g1:/ F G />` the ratio which a square number has to a square number ; therefore :g:`$A$ <0192.g1:A>` is incommensurable in length with :g:`$FG$ <0192.g1:/ F G />`. :just:`[X. 9] <X.9>`

.. subclause::

   Again, since, as :g:`$BC$ <0192.g1:/ B C />` is to :g:`$CD$ <0192.g1:/ C D />`, so is the square on :g:`$FG$ <0192.g1:/ F G />` to the square on :g:`$GH$ <0192.g1:/ G H />`,

.. assertion::

   therefore the square on :g:`$FG$ <0192.g1:/ F G />` is commensurable with the square on :g:`$GH$ <0192.g1:/ G H />`. :just:`[X. 6] <X.6>`

.. subclause::

   But the square on :g:`$FG$ <0192.g1:/ F G />` is rational ;

.. assertion::

   therefore the square on :g:`$GH$ <0192.g1:/ G H />` is also rational ; therefore :g:`$GH$ <0192.g1:/ G H />` is also rational.

.. subclause::

   And, since :g:`$BC$ <0192.g1:/ B C />` has not to :g:`$CD$ <0192.g1:/ C D />` the ratio which a square number has to a square number,

.. _folio-iii-0193:

.. folio:: 0193
   :page: 189

.. assertion::

   therefore neither has the square on :g:`$FG$ <0192.g1:/ F G />` to the square on :g:`$GH$ <0192.g1:/ G H />` the ratio which a square number has to a square number; therefore :g:`$FG$ <0192.g1:/ F G />` is incommensurable in length with :g:`$GH$ <0192.g1:/ G H />`. :just:`[X. 9] <X.9>`

.. subclause::

   And both are rational;

.. assertion::

   therefore :g:`$FG$ <0192.g1:/ F G />`, :g:`$GH$ <0192.g1:/ G H />` are rational straight lines commensurable in square only; therefore :g:`$FH$ <0192.g1:/ F H />` is an apotome. :just:`[X. 73] <X.73>`

I say next that it is also a sixth apotome.

.. subclause::

   For since, as :g:`$E$ <0192.g1:E>` is to :g:`$BC$ <0192.g1:/ B C />`, so is the square on :g:`$A$ <0192.g1:A>` to the square on :g:`$FG$ <0192.g1:/ F G />`, and, as :g:`$BC$ <0192.g1:/ B C />` is to :g:`$CD$ <0192.g1:/ C D />`, so is the square on :g:`$FG$ <0192.g1:/ F G />` to the square on :g:`$GH$ <0192.g1:/ G H />`,

.. assertion::

   therefore, :term:`*ex aequali* <ex-aequali>`, as :g:`$E$ <0192.g1:E>` is to :g:`$CD$ <0192.g1:/ C D />`, so is the square on :g:`$A$ <0192.g1:A>` to the square on :g:`$GH$ <0192.g1:/ G H />`. :just:`[V. 22] <V.22>`

.. subclause::

   But :g:`$E$ <0192.g1:E>` has not to :g:`$CD$ <0192.g1:/ C D />` the ratio which a square number has to a square number;

.. assertion::

   therefore neither has the square on :g:`$A$ <0192.g1:A>` to the square on :g:`$GH$ <0192.g1:/ G H />` the ratio which a square number has to a square number; therefore :g:`$A$ <0192.g1:A>` is incommensurable in length with :g:`$GH$ <0192.g1:/ G H />`; :just:`[X. 9] <X.9>` therefore neither of the straight lines :g:`$FG$ <0192.g1:/ F G />`, :g:`$GH$ <0192.g1:/ G H />` is commensurable in length with the rational straight line :g:`$A$ <0192.g1:A>`.

Now let the square on :g:`$K$ <0192.g1:K>` be that by which the square on :g:`$FG$ <0192.g1:/ F G />` is greater than the square on :g:`$GH$ <0192.g1:/ G H />`.

.. subclause::

   Since then, as :g:`$BC$ <0192.g1:/ B C />` is to :g:`$CD$ <0192.g1:/ C D />`, so is the square on :g:`$FG$ <0192.g1:/ F G />` to the square on :g:`$GH$ <0192.g1:/ G H />`,

.. assertion::

   therefore, :term:`*convertendo* <convertendo>`, as :g:`$CB$ <0192.g1:/ C B />` is to :g:`$BD$ <0192.g1:/ B D />`, so is the square on :g:`$FG$ <0192.g1:/ F G />` to the square on :g:`$K$ <0192.g1:K>`. :just:`[V. 19, Por.]`

.. subclause::

   But :g:`$CB$ <0192.g1:/ C B />` has not to :g:`$BD$ <0192.g1:/ B D />` the ratio which a square number has to a square number;

.. assertion::

   therefore neither has the square on :g:`$FG$ <0192.g1:/ F G />` to the square on :g:`$K$ <0192.g1:K>` the ratio which a square number has to a square number; therefore :g:`$FG$ <0192.g1:/ F G />` is incommensurable in length with :g:`$K$ <0192.g1:K>`. :just:`[X. 9] <X.9>`

.. subclause::

   And the square on :g:`$FG$ <0192.g1:/ F G />` is greater than the square on :g:`$GH$ <0192.g1:/ G H />` by the square on :g:`$K$ <0192.g1:K>`;

.. assertion::

   therefore the square on :g:`$FG$ <0192.g1:/ F G />` is greater than the square on :g:`$GH$ <0192.g1:/ G H />` by the square on a straight line incommensurable in length with :g:`$FG$ <0192.g1:/ F G />`.

.. _folio-iii-0194:

.. folio:: 0194
   :page: 190

.. subclause::

   And neither of the straight lines :g:`$FG$ <0192.g1:/ F G />`, :g:`$GH$ <0192.g1:/ G H />` is commensurable with the rational straight line :g:`$A$ <0192.g1:A>` set out.

.. assertion:: [X. Deff. III. 6]

   Therefore :g:`$FH$ <0192.g1:/ F H />` is a sixth apotome.

.. qed::

   Therefore the sixth apotome :g:`$FH$ <0192.g1:/ F H />` has been found. :just:`Q. E. D.`
