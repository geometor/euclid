PROPOSITION 21.
===============

.. enunciation::

   Any solid angle is contained by plane angles less than four right angles.

Let the angle at :g:`$A$ <0313.g1:A>` be a solid angle contained by the plane angles :g:`$BAC$ <0313.g1:< B A C )>`, :g:`$CAD$ <0313.g1:< C A D )>`, :g:`$DAB$ <0313.g1:< D A B )>`; I say that the angles :g:`$BAC$ <0313.g1:< B A C )>`, :g:`$CAD$ <0313.g1:< C A D )>`, :g:`$DAB$ <0313.g1:< D A B )>` are less than four right angles.

For let points :g:`$B$ <0313.g1:B>`, :g:`$C$ <0313.g1:C>`, :g:`$D$ <0313.g1:D>` be taken at random on the straight lines :g:`$AB$ <0313.g1:/ A B />`, :g:`$AC$ <0313.g1:/ A C />`, :g:`$AD$ <0313.g1:/ A D />` respectively, and let :g:`$BC$ <0313.g1:/ B C />`, :g:`$CD$ <0313.g1:/ C D />`, :g:`$DB$ <0313.g1:/ D B />` be joined.

.. picture:: 0313.g1.svg
   :alt: Book XI, Proposition 21

.. subclause::

   Now, since the solid angle at :g:`$B$ <0313.g1:B>` is contained by the three plane angles :g:`$CBA$ <0313.g1:< C B A )>`, :g:`$ABD$ <0313.g1:< A B D )>`, :g:`$CBD$ <0313.g1:< C B D )>`,

.. assertion::

   any two are greater than the remaining one; :just:`[XI. 20] <XI.20>` therefore the angles :g:`$CBA$ <0313.g1:< C B A )>`, :g:`$ABD$ <0313.g1:< A B D )>` are greater than the angle :g:`$CBD$ <0313.g1:< C B D )>`.

.. assertion::

   For the same reason the angles :g:`$BCA$ <0313.g1:< B C A )>`, :g:`$ACD$ <0313.g1:< A C D )>` are also greater than the angle :g:`$BCD$ <0313.g1:< B C D )>`, and the angles :g:`$CDA$ <0313.g1:< C D A )>`, :g:`$ADB$ <0313.g1:< A D B )>` are greater than the angle :g:`$CDB$ <0313.g1:< C D B )>`; therefore the six angles :g:`$CBA$ <0313.g1:< C B A )>`, :g:`$ABD$ <0313.g1:< A B D )>`, :g:`$BCA$ <0313.g1:< B C A )>`, :g:`$ACD$ <0313.g1:< A C D )>`, :g:`$CDA$ <0313.g1:< C D A )>`, :g:`$ADB$ <0313.g1:< A D B )>` are greater than the three angles :g:`$CBD$ <0313.g1:< C B D )>`, :g:`$BCD$ <0313.g1:< B C D )>`, :g:`$CDB$ <0313.g1:< C D B )>`.

.. subclause::

   But the three angles :g:`$CBD$ <0313.g1:< C B D )>`, :g:`$BDC$ <0313.g1:< B D C )>`, :g:`$BCD$ <0313.g1:< B C D )>` are equal to two right angles; :just:`[I. 32] <I.32>`

.. assertion::

   therefore the six angles :g:`$CBA$ <0313.g1:< C B A )>`, :g:`$ABD$ <0313.g1:< A B D )>`, :g:`$BCA$ <0313.g1:< B C A )>`, :g:`$ACD$ <0313.g1:< A C D )>`, :g:`$CDA$ <0313.g1:< C D A )>`, :g:`$ADB$ <0313.g1:< A D B )>` are greater than two right angles.

.. _folio-iii-0314:

.. folio:: 0314
   :page: 310

.. subclause::

   And, since the three angles of each of the triangles :g:`$ABC$ <0313.g1:< A B C >>`, :g:`$ACD$ <0313.g1:< A C D >>`, :g:`$ADB$ <0313.g1:< A D B >>` are equal to two right angles,

.. assertion::

   therefore the nine angles of the three triangles, the angles :g:`$CBA$ <0313.g1:< C B A )>`, :g:`$ACB$ <0313.g1:< A C B )>`, :g:`$BAC$ <0313.g1:< B A C )>`, :g:`$ACD$ <0313.g1:< A C D )>`, :g:`$CDA$ <0313.g1:< C D A )>`, :g:`$CAD$ <0313.g1:< C A D )>`, :g:`$ADB$ <0313.g1:< A D B )>`, :g:`$DBA$ <0313.g1:< D B A )>`, :g:`$BAD$ <0313.g1:< B A D )>` are equal to six right angles ;

.. subclause::

   and of them the six angles :g:`$ABC$ <0313.g1:< A B C )>`, :g:`$BCA$ <0313.g1:< B C A )>`, :g:`$ACD$ <0313.g1:< A C D )>`, :g:`$CDA$ <0313.g1:< C D A )>`, :g:`$ADB$ <0313.g1:< A D B )>`, :g:`$DBA$ <0313.g1:< D B A )>` are greater than two right angles ;

.. assertion::

   therefore the remaining three angles :g:`$BAC$ <0313.g1:< B A C )>`, :g:`$CAD$ <0313.g1:< C A D )>`, :g:`$DAB$ <0313.g1:< D A B )>` containing the solid angle are less than four right angles.

.. qed::

   Therefore etc. :just:`Q. E. D.`
