Commentary on Proposition XII.7
===============================

Back to :ref:`Proposition XII.7 <XII.7>`.

.. folio:: 0399
   :page: 395

If we denote by :g:`$C\text{-}ABD$ <0398.g1:< C A B D >>` a pyramid with vertex :g:`$C$ <0398.g1:C>` and base :g:`$ABD$ <0398.g1:< A B D >>`, Euclid's argument is easily followed thus.

The $\square$ :g:`$ABED$ <0398.g1:< A B E D >>` being bisected by :g:`$BD$ <0398.g1:/ B D />`,
(pyramid :g:`$C\text{-}ABD$ <0398.g1:< C A B D >>`) $=$ (pyramid :g:`$C\text{-}DEB$ <0398.g1:< C D E B >>`) :just:`[XII. 5] <XII.5>`
$\equiv$ (pyramid :g:`$D\text{-}EBC$ <0398.g1:< D E B C >>`).

And, the $\square$ :g:`$EBCF$ <0398.g1:< E B C F >>` being bisected by :g:`$EC$ <0398.g1:/ E C />`,
(pyramid :g:`$D\text{-}EBC$ <0398.g1:< D E B C >>`) $=$ (pyramid :g:`$D\text{-}ECF$ <0398.g1:< D E C F >>`).

Thus (pyramid :g:`$C\text{-}ABD$ <0398.g1:< C A B D >>`) $=$ (pyramid :g:`$D\text{-}EBC$ <0398.g1:< D E B C >>`) $=$ (pyramid :g:`$D\text{-}ECF$ <0398.g1:< D E C F >>`), and these three pyramids make up the whole prism, so that each is one-third of the prism.

And, since (pyramid :g:`$C\text{-}ABD$ <0398.g1:< C A B D >>`) $\equiv$ (pyramid :g:`$D\text{-}ABC$ <0398.g1:< D A B C >>`),
(pyramid :g:`$D\text{-}ABC$ <0398.g1:< D A B C >>`) $= \frac{1}{3}$ (prism :g:`$ABC$ <0398.g1:< A B C >>`, :g:`$DEF$ <0398.g1:< D E F >>`).
