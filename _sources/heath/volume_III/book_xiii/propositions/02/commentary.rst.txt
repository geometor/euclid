Commentary on Proposition XIII.2
================================

Back to :ref:`Proposition XIII.2 <XIII.2>`.

.. folio:: 0448
   :page: 444

LEMMA.
~~~~~~

That the double of :g:`$AC$ <0447.g1:/ A C />` is greater than :g:`$BC$ <0447.g1:/ B C />` is to be proved thus.

.. subclause::

   If not, let :g:`$BC$ <0447.g1:/ B C />` be, if possible, double of :g:`$CA$ <0447.g1:/ C A />`.

.. assertion::

   Therefore the square on :g:`$BC$ <0447.g1:/ B C />` is quadruple of the square on :g:`$CA$ <0447.g1:/ C A />`; therefore the squares on :g:`$BC$ <0447.g1:/ B C />`, :g:`$CA$ <0447.g1:/ C A />` are five times the square on :g:`$CA$ <0447.g1:/ C A />`.

.. subclause::

   But, by hypothesis, the square on :g:`$BA$ <0447.g1:/ B A />` is also five times the square on :g:`$CA$ <0447.g1:/ C A />`;

.. assertion::

   therefore the square on :g:`$BA$ <0447.g1:/ B A />` is equal to the squares on :g:`$BC$ <0447.g1:/ B C />`, :g:`$CA$ <0447.g1:/ C A />`: which is impossible. :just:`[II. 4] <II.4>`

.. assertion::

   Therefore :g:`$CB$ <0447.g1:/ C B />` is not double of :g:`$AC$ <0447.g1:/ A C />`.

.. assertion::

   Similarly we can prove that neither is a straight line less than :g:`$CB$ <0447.g1:/ C B />` double of :g:`$CA$ <0447.g1:/ C A />`; for the absurdity is much greater.

.. assertion::

   Therefore the double of :g:`$AC$ <0447.g1:/ A C />` is greater than :g:`$CB$ <0447.g1:/ C B />`.

.. qed::

   Q. E. D.

----

This proposition is the converse of Prop. 1. We have to prove that, if :g:`$AB$ <0447.g1:/ A B />` be so divided at :g:`$C$ <0447.g1:C>` that (sq. on :g:`$AB$ <0447.g1:/ A B />`) = 5 (sq. on :g:`$AC$ <0447.g1:/ A C />`), and if :g:`$CD$ <0447.g1:/ C D />` = 2 :g:`$AC$ <0447.g1:/ A C />`, then (rect. :g:`$CD$ <0447.g1:/ C D />`, :g:`$DB$ <0447.g1:/ D B />`) = (sq. on :g:`$CB$ <0447.g1:/ C B />`).

.. _folio-iii-0449:

.. folio:: 0449
   :page: 445

Subtract from each side the sq. on :g:`$AC$ <0447.g1:/ A C />`; then

.. container:: center

   (gnomon :g:`$MNO$ <0447.g1:< M N O >>`) = 4 (sq. on :g:`$AC$ <0447.g1:/ A C />`) = (sq. on :g:`$CD$ <0447.g1:/ C D />`).

Now, as in the last proposition,

.. container:: center

   □ :g:`$CE$ <0447.g1:< C E >>` = 2 (□ :g:`$BH$ <0447.g1:< B H >>`) = □ :g:`$BH$ <0447.g1:< B H >>` + □ :g:`$HL$ <0447.g1:< H L >>`.

Subtracting these equals from the equals, the square on :g:`$CD$ <0447.g1:/ C D />` and the gnomon :g:`$MNO$ <0447.g1:< M N O >>` respectively, we have

.. container:: center

   □ :g:`$BG$ <0447.g1:< B G >>` = (square :g:`$HF$ <0447.g1:< H F >>`),

i.e.

.. container:: center

   (rect. :g:`$CD$ <0447.g1:/ C D />`, :g:`$DB$ <0447.g1:/ D B />`) = (sq. on :g:`$CB$ <0447.g1:/ C B />`).

Here again the proposition can readily be proved by means of a figure similar to that of II. 11.

Draw :g:`$CA$ <0449.g1:/ C A />` through :g:`$C$ <0449.g1:C>` at *right angles* to :g:`$CB$ <0449.g1:/ C B />` and of length equal to :g:`$CA$ <0449.g1:/ C A />` in the original figure; make :g:`$CD$ <0449.g1:/ C D />` double of :g:`$CA$ <0449.g1:/ C A />`; produce :g:`$AC$ <0449.g1:/ A C />` to :g:`$R$ <0449.g1:R>` so that :g:`$CR$ <0449.g1:/ C R />` = :g:`$CB$ <0449.g1:/ C B />`. Complete the squares on :g:`$CB$ <0449.g1:/ C B />` and :g:`$CD$ <0449.g1:/ C D />`, and join :g:`$AD$ <0449.g1:/ A D />`.

.. picture:: 0449.g1.svg
   :alt: Book XIII, Proposition 2 - Commentary Figure

Now we are given the fact that

.. container:: center

   (sq. on :g:`$AR$ <0449.g1:/ A R />`) = 5 (sq. on :g:`$CA$ <0449.g1:/ C A />`).

But

.. container:: center

   5 (sq. on :g:`$AC$ <0449.g1:/ A C />`) = (sq. on :g:`$AC$ <0449.g1:/ A C />`) + (sq. on :g:`$CD$ <0449.g1:/ C D />`) = (sq. on :g:`$AD$ <0449.g1:/ A D />`).

Therefore

.. container:: center

   (sq. on :g:`$AR$ <0449.g1:/ A R />`) = (sq. on :g:`$AD$ <0449.g1:/ A D />`),

or :g:`$AR$ <0449.g1:/ A R />` $= $ :g:`$AD$ <0449.g1:/ A D />`.

Now

.. container:: center

   (rect. :g:`$KR$ <0449.g1:/ K R />`, :g:`$RC$ <0449.g1:/ R C />`) + (sq. on :g:`$AC$ <0449.g1:/ A C />`) = (sq. on :g:`$AR$ <0449.g1:/ A R />`) = (sq. on :g:`$AD$ <0449.g1:/ A D />`) = (sq. on :g:`$AC$ <0449.g1:/ A C />`) + (sq. on :g:`$CD$ <0449.g1:/ C D />`).

Therefore

.. container:: center

   (rect. :g:`$KR$ <0449.g1:/ K R />` . :g:`$RC$ <0449.g1:/ R C />`) = (sq. on :g:`$CD$ <0449.g1:/ C D />`).

That is,

.. container:: center

   (rectangle :g:`$RE$ <0449.g1:< R E >>`) = (square :g:`$CG$ <0449.g1:< C G >>`).

Subtract the common part :g:`$CE$ <0449.g1:< C E >>`, and

.. container:: center

   (rect. :g:`$BG$ <0449.g1:< B G >>`) = (sq. :g:`$RB$ <0449.g1:< R B >>`),

or

.. container:: center

   rect. :g:`$CD$ <0449.g1:/ C D />`, :g:`$DB$ <0449.g1:/ D B />` = (sq. on :g:`$CB$ <0449.g1:/ C B />`).

:person:`Heiberg <heiberg>`, with reason, doubts the genuineness of the Lemma following this proposition.
