PROPOSITION 7.
==============

.. enunciation::

   If three angles of an equilateral pentagon, taken either in order or not in order, be equal, the pentagon will be equiangular.

For in the :eq:`equilateral <0455.g1:/ A B / = 0455.g1:/ B C / = 0455.g1:/ C D / = 0455.g1:/ D E / = 0455.g1:/ E A />` pentagon :g:`$ABCDE$ <0455.g1:< A B C D E >>` let, first, three angles taken in order, those at :g:`$A$ <0455.g1:A>`, :g:`$B$ <0455.g1:B>`, :g:`$C$ <0455.g1:C>`, be :eq:`equal <0455.g1:< B A E ) = 0455.g1:< C B A ) = 0455.g1:< B C D )>` to one another; I say that the pentagon :g:`$ABCDE$ <0455.g1:< A B C D E >>` is equiangular.

.. picture:: 0455.g1.svg
   :alt: Book XIII, Proposition 7

For let :g:`$AC$ <0455.g1:/ A C />`, :g:`$BE$ <0455.g1:/ B E />`, :g:`$FD$ <0455.g1:/ F D />` be joined.

.. subclause::

   Now, since the two sides :g:`$CB$ <0455.g1:/ C B />`, :g:`$BA$ <0455.g1:/ B A />` are :eq:`equal <0455.g1:/ C B / = 0455.g1:/ B A / = 0455.g1:/ A E />` to the two sides :g:`$BA$ <0455.g1:/ B A />`, :g:`$AE$ <0455.g1:/ A E />` respectively, and the angle :g:`$CBA$ <0455.g1:< C B A )>` is :eq:`equal <0455.g1:< C B A ) = 0455.g1:< B A E )>` to the angle :g:`$BAE$ <0455.g1:< B A E )>`,

.. assertion::

   therefore the base :g:`$AC$ <0455.g1:/ A C />` is :eq:`equal <0455.g1:/ A C / = 0455.g1:/ B E />` to the base :g:`$BE$ <0455.g1:/ B E />`, the triangle :g:`$ABC$ <0455.g1:< A B C >>` is :eq:`equal <0455.g1:< A B C > = 0455.g1:< A B E >>` to the triangle :g:`$ABE$ <0455.g1:< A B E >>`, and the remaining angles will be :eq:`equal <0455.g1:< B C A ) = 0455.g1:< B E A ); 0455.g1:< A B E ) = 0455.g1:< C A B )>` to the remaining angles, namely those which the equal sides subtend, :just:`[I. 4] <I.4>` that is, the angle :g:`$BCA$ <0455.g1:< B C A )>` to the angle :g:`$BEA$ <0455.g1:< B E A )>`, and the angle :g:`$ABE$ <0455.g1:< A B E )>` to the angle :g:`$CAB$ <0455.g1:< C A B )>`;

.. assertion:: [I. 6] <I.6>

   hence the side :g:`$AF$ <0455.g1:/ A F />` is also :eq:`equal <0455.g1:/ A F / = 0455.g1:/ B F />` to the side :g:`$BF$ <0455.g1:/ B F />`.

.. _folio-iii-0456:

.. folio:: 0456
   :page: 452

.. subclause::

   But the whole :g:`$AC$ <0455.g1:/ A C />` was also proved :eq:`equal <0455.g1:/ A C / = 0455.g1:/ B E />` to the whole :g:`$BE$ <0455.g1:/ B E />`;

.. assertion::

   therefore the remainder :g:`$FC$ <0455.g1:/ F C />` is also :eq:`equal <0455.g1:/ F C / = 0455.g1:/ F E />` to the remainder :g:`$FE$ <0455.g1:/ F E />`.

.. subclause::

   But :g:`$CD$ <0455.g1:/ C D />` is also :eq:`equal <0455.g1:/ C D / = 0455.g1:/ D E />` to :g:`$DE$ <0455.g1:/ D E />`. Therefore the two sides :g:`$FC$ <0455.g1:/ F C />`, :g:`$CD$ <0455.g1:/ C D />` are :eq:`equal <0455.g1:/ F C / = 0455.g1:/ F E /; 0455.g1:/ C D / = 0455.g1:/ E D />` to the two sides :g:`$FE$ <0455.g1:/ F E />`, :g:`$ED$ <0455.g1:/ E D />`; and the base :g:`$FD$ <0455.g1:/ F D />` is common to them;

.. assertion:: [I. 8] <I.8>

   therefore the angle :g:`$FCD$ <0455.g1:< F C D )>` is :eq:`equal <0455.g1:< F C D ) = 0455.g1:< F E D )>` to the angle :g:`$FED$ <0455.g1:< F E D )>`.

.. subclause::

   But the angle :g:`$BCA$ <0455.g1:< B C A )>` was also proved :eq:`equal <0455.g1:< B C A ) = 0455.g1:< A E B )>` to the angle :g:`$AEB$ <0455.g1:< A E B )>`;

.. assertion::

   therefore the whole angle :g:`$BCD$ <0455.g1:< B C D )>` is also :eq:`equal <0455.g1:< B C D ) = 0455.g1:< A E D )>` to the whole angle :g:`$AED$ <0455.g1:< A E D )>`.

.. subclause::

   But, by hypothesis, the angle :g:`$BCD$ <0455.g1:< B C D )>` is :eq:`equal <0455.g1:< B C D ) = 0455.g1:< B A E ) = 0455.g1:< C B A )>` to the angles at :g:`$A$ <0455.g1:A>`, :g:`$B$ <0455.g1:B>`;

.. assertion::

   therefore the angle :g:`$AED$ <0455.g1:< A E D )>` is also :eq:`equal <0455.g1:< A E D ) = 0455.g1:< B A E ) = 0455.g1:< C B A )>` to the angles at :g:`$A$ <0455.g1:A>`, :g:`$B$ <0455.g1:B>`.

.. assertion::

   Similarly we can prove that the angle :g:`$CDE$ <0455.g1:< C D E )>` is also :eq:`equal <0455.g1:< C D E ) = 0455.g1:< B A E ) = 0455.g1:< C B A ) = 0455.g1:< B C D )>` to the angles at :g:`$A$ <0455.g1:A>`, :g:`$B$ <0455.g1:B>`, :g:`$C$ <0455.g1:C>`; therefore the pentagon :g:`$ABCDE$ <0455.g1:< A B C D E >>` is equiangular.

Next, let the given equal angles not be angles taken in order, but let the angles at the points :g:`$A$ <0455.g1:A>`, :g:`$C$ <0455.g1:C>`, :g:`$D$ <0455.g1:D>` be :eq:`equal <0455.g1:< B A E ) = 0455.g1:< B C D ) = 0455.g1:< C D E )>`; I say that in this case too the pentagon :g:`$ABCDE$ <0455.g1:< A B C D E >>` is equiangular.

For let :g:`$BD$ <0455.g1:/ B D />` be joined.

.. subclause::

   Then, since the two sides :g:`$BA$ <0455.g1:/ B A />`, :g:`$AE$ <0455.g1:/ A E />` are :eq:`equal <0455.g1:/ B A / = 0455.g1:/ B C /; 0455.g1:/ A E / = 0455.g1:/ C D />` to the two sides :g:`$BC$ <0455.g1:/ B C />`, :g:`$CD$ <0455.g1:/ C D />`, and they contain :eq:`equal <0455.g1:< B A E ) = 0455.g1:< B C D )>` angles,

.. assertion::

   therefore the base :g:`$BE$ <0455.g1:/ B E />` is :eq:`equal <0455.g1:/ B E / = 0455.g1:/ B D />` to the base :g:`$BD$ <0455.g1:/ B D />`, the triangle :g:`$ABE$ <0455.g1:< A B E >>` is :eq:`equal <0455.g1:< A B E > = 0455.g1:< B C D >>` to the triangle :g:`$BCD$ <0455.g1:< B C D >>`, and the remaining angles will be equal to the remaining angles, namely those which the equal sides subtend; :just:`[I. 4] <I.4>` therefore the angle :g:`$AEB$ <0455.g1:< A E B )>` is :eq:`equal <0455.g1:< A E B ) = 0455.g1:< C D B )>` to the angle :g:`$CDB$ <0455.g1:< C D B )>`.

.. subclause::

   But the angle :g:`$BED$ <0455.g1:< B E D )>` is also :eq:`equal <0455.g1:< B E D ) = 0455.g1:< B D E )>` to the angle :g:`$BDE$ <0455.g1:< B D E )>`, since the side :g:`$BE$ <0455.g1:/ B E />` is also :eq:`equal <0455.g1:/ B E / = 0455.g1:/ B D />` to the side :g:`$BD$ <0455.g1:/ B D />`. :just:`[I. 5] <I.5>`

.. assertion::

   Therefore the whole angle :g:`$AED$ <0455.g1:< A E D )>` is :eq:`equal <0455.g1:< A E D ) = 0455.g1:< C D E )>` to the whole angle :g:`$CDE$ <0455.g1:< C D E )>`.

.. subclause::

   But the angle :g:`$CDE$ <0455.g1:< C D E )>` is, by hypothesis, :eq:`equal <0455.g1:< C D E ) = 0455.g1:< B A E ) = 0455.g1:< B C D )>` to the angles at :g:`$A$ <0455.g1:A>`, :g:`$C$ <0455.g1:C>`;

.. assertion::

   therefore the angle :g:`$AED$ <0455.g1:< A E D )>` is also :eq:`equal <0455.g1:< A E D ) = 0455.g1:< B A E ) = 0455.g1:< B C D )>` to the angles at :g:`$A$ <0455.g1:A>`, :g:`$C$ <0455.g1:C>`.

.. _folio-iii-0457:

.. folio:: 0457
   :page: 453

.. assertion::

   For the same reason the angle :g:`$ABC$ <0455.g1:< A B C )>` is also :eq:`equal <0455.g1:< A B C ) = 0455.g1:< B A E ) = 0455.g1:< B C D ) = 0455.g1:< C D E )>` to the angles at :g:`$A$ <0455.g1:A>`, :g:`$C$ <0455.g1:C>`, :g:`$D$ <0455.g1:D>`. Therefore the pentagon :g:`$ABCDE$ <0455.g1:< A B C D E >>` is equiangular.

.. qed::

   :just:`Q. E. D.`
