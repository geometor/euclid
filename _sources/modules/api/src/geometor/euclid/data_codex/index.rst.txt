src.geometor.euclid.data_codex
==============================

.. py:module:: src.geometor.euclid.data_codex

.. autoapi-nested-parse::

   Concordance loader, validator, and functional DAG query helpers for Euclid's *Data*.

   Provides stdlib-only typed structures and validation utilities over the static
   JSON apparatus in ``resources/data/`` (``concordance.json``, ``citations.json``,
   ``persons.json``, ``glossary.json``, and ``enunciations.json``).

.. py:class:: DataDefinitionEntry

   Structured record for one of the 15 Definitions of Euclid's *Data*.

   .. attribute:: id

      Canonical identifier (``D.def.1`` through ``D.def.15``).

   .. attribute:: number

      Sequential integer index (1 through 15).

   .. attribute:: greek_numeral

      Milesian Greek numeral header in Menge (1896).

   .. attribute:: menge_page

      Page number in Menge's 1896 Teubner edition.

   .. attribute:: simson_id

      Corresponding definition identifier in Simson (1762/1806).

   .. attribute:: authentic

      Whether Menge prints the definition outside editorial brackets.

   .. attribute:: category

      Epistemic/geometric category of givenness.

   .. attribute:: greek_text

      Polytonic Greek text from Menge (1896).
