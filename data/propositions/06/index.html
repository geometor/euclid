Proposition 6 [Ϛ΄ · Prop. VII]¶

If two magnitudes having a given ratio to one another be compounded together, the whole magnitude will also have a given ratio to each of them.

Functional Signature: Given(Ratio(AB : BC)) -> Determined(Ratio((AB+BC) : AB), Ratio((AB+BC) : BC)) · Dependencies: [Data Def. 2], [Data 1], [Data 2], [Data 3], [V.18], [V.19]

Let the two magnitudes $AB$ and $BC$, having a given ratio to one another, be compounded into $AC$. I say that the whole $AC$ has a given ratio to each of $AB$ and $BC$.

Let a given magnitude $DE$ be set out; since the ratio $AB : BC$ is given, let the same ratio $DE : EF$ be procured ([Data Def. 2]). Because $DE$ is given and $DE : EF$ is given, $EF$ is given ([Data 2]), so the whole $DF$ is given ([Data 3]). Since each of $DE$ and $EF$ is given, the ratios $DF : DE$ and $DF : EF$ are both given ([Data 1]). Now since $AB : BC = DE : EF$, componendo $AC : BC = DF : EF$ ([V.18]), and by inversion and componendo $AC : AB = DF : DE$. Since $DF$ has a given ratio to each of $DE$ and $EF$, $AC$ likewise has a given ratio to each of $AB$ and $BC$ ([Data Def. 2]).
