Proposition 24 [κδ΄ · Prop. XIII]¶

If three straight lines be proportional, and the first have to the third a given ratio, it will also have to the second a given ratio.

Functional Signature: Given(A : B = B : C, Ratio(A : C)) -> Determined(Ratio(A : B)) · Dependencies: [Data Def. 1], [Data Def. 2], [Data 1], [Data 2], [VI.13], [VI.17], [VI.22]

Let three straight lines \(A, B, C\) be in continued proportion (\(A : B = B : C\)), and let the first \(A\) have a given ratio to the third \(C\). I say that \(A\) also has a given ratio to the second \(B\).

Let a given straight line \(D\) be set out. Since the ratio \(A : C\) is given, let the ratio \(D : F\) be made the same with it ([Data Def. 2]); because \(D\) is given, \(F\) is also given ([Data 2]). Let the mean proportional \(E\) be taken between \(D\) and \(F\) ([VI.13]), so that the rectangle \(D \cdot F\) is equal to the square \(E^2\) ([VI.17]). Since both \(D\) and \(F\) are given in magnitude, the rectangle \(D \cdot F\) is given—and therefore \(E^2\) is given, whence the straight line \(E\) is given in magnitude (compare [Data 52] / [Data Def. 1]). Because \(D\) is also given, the ratio \(D : E\) is given ([Data 1]). Now since \(A : C = D : F\), while \(A : C = A^2 : (A \cdot C)\) and \(D : F = D^2 : (D \cdot F)\) ([VI.1]), it follows that \(A^2 : (A \cdot C) = D^2 : (D \cdot F)\) ([V.11]). Substituting \(B^2 = A \cdot C\) (from \(A : B = B : C\), [VI.17]) and \(E^2 = D \cdot F\) gives \(A^2 : B^2 = D^2 : E^2\), whence for the sides themselves \(A : B = D : E\) ([VI.22]). Since \(D : E\) is given, the ratio \(A : B\) is also given ([Data Def. 2]).
