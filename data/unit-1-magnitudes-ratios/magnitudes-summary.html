Unit 1: Magnitudes & Ratios (Propositions 1–24) — Analytical Summary¶

Unit Overview & Role in Greek Geometric Analysis¶

Deductive closure of given magnitudes and ratios over Elements Book V: addition, subtraction, inversion, composition, division, ex aequali chains, affine-linear offset relations (δοθέντι μεῖζον ἢ ἐν λόγῳ), non-singular linear combinations (D.22–D.23), and geometric mean proportions (D.24).

  • Scope: 24 propositions (D.1–D.24 (Simson I–XXVII), Menge pp. 4–42).

  • Analytical Function: Each proposition below compiles into a forward-chaining inference rule Given(...) -> Determined(...) within Pappus's Treasury of Analysis (Synagoge Book VII) and geometor.model symbolic DAGs.

Computational Primitives (geometor.model & SymPy)¶

  • D.1 (Prop. I): Exact symbolic ratio evaluation sp.simplify(A / B) from known magnitudes.

  • D.2 (Prop. II): Fourth-proportional solver B = A * (D / C) when homogeneous constructibility holds.

  • D.3 (Prop. III): Additive closure X + Y of constructible symbolic quantities.

  • D.4 (Prop. IV): Subtractive closure X - Y (with X > Y) of constructible symbolic quantities.

  • D.5 (Prop. VI): Conversio rationis closure: r = A/C -> A/(A-C) = r/(r-1).

  • D.6 (Prop. VII): Compositio rationis closure: r = A/B -> (A+B)/B = r+1 and (A+B)/A = (r+1)/r.

  • D.7 (Prop. VIII): Barycentric / internal ratio partition AC = r/(r+1)*AB, CB = 1/(r+1)*AB.

  • D.8 (Prop. IX): Transitive elimination of shared reference magnitude B via ex aequali (A/C = (A/B)/(C/B)).

  • D.9 (Prop. X): Diagonal scaling of a projective tuple (D, E, F) = (A/k1, B/k2, C/k3).

  • D.10 (Prop. XVI): Affine-ratio composition and converse bifurcation depending on whether given offset D < AB or D > AB.

  • D.11 (Prop. XVII): Bidirectional affine-linear substitution solving BC = (AB - D)/k into AB + BC and back.

  • D.12 (Prop. V): Elimination of common summand B: A - C = (A + B) - (B + C).

  • D.13 (Prop. XXIV): Scalar multiplication of an affine-ratio relation A = r*B = r*F + (r*k)*C.

  • D.14 (Prop. XVIII): Affine shift of proportional variables: (A+d1) - r*(C+d2) = d1 - r*d2.

  • D.15 (Prop. XIX): Subtractive affine shift: (A-d1) - r*(C-d2) = r*d2 - d1.

  • D.16 (Prop. XX): Mixed affine shift: A + d2 = r*(C - d1) + (r*d1 + d2), offset strictly positive.

  • D.17 (Prop. XXV): Elimination of parameter B between two affine-linear equations A = d1 + k1*B, C = d2 + k2*B.

  • D.18 (Prop. XXVI): Elimination of shared dominant variable C = d1 + k1*A = d2 + k2*E.

  • D.19 (Prop. XXVII): Composition of 1D affine maps f(g(C)) = d1 + k1*(d2 + k2*C) = (d1 + k1*d2) + (k1*k2)*C.

  • D.20 (Prop. XXIII): Parametric line segment difference: (A - x) + r*y = A, eliminating x = r*y.

  • D.21 (Omitted (cf. Prop. XVIII)): Dual of D.20 and symmetric restatement of D.14 (omitted as redundant by Simson).

  • D.22 (Prop. XI): Linearity of ratios over common denominator: (A + B)/C = A/C + B/C.

  • D.23 (Prop. XII): Non-singular 2x2 homogeneous linear solver (det = r1 - r2 != 0; Zamberti/Simson condition).

  • D.24 (Prop. XIII): Quadratic/mean-proportional root extraction over Q(sqrt(r)): A/B = sqrt(A/C).
