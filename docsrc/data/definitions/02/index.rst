Definition 2 [β΄ · Def. II]
~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. enunciation::

   A ratio is said to be given to which we can procure an identical ratio.

*Category*: **Ratio (λόγῳ)** · *Functional Predicate*: ``GivenRatio(A : B) := exists GivenMagnitude(C, D) with A : B = C : D``
