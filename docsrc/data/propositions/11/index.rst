.. _D.11:

Proposition 11 [ια΄ · Prop. XVII]
---------------------------------

.. folio:: Menge 20
   :page: 20

.. enunciation::

   If a magnitude be greater than a magnitude by a given magnitude than in ratio, the same will also be greater than the compounded magnitude by a given magnitude than in ratio; and if the same be greater than the compounded magnitude by a given magnitude than in ratio, the same will also be greater than the remainder by a given magnitude than in ratio.

*Functional Signature*: ``Given((AB - D) : BC = k) <-> Determined((AB - k/(k+1)*D) : (AB + BC) = k/(k+1))`` · *Dependencies*: :just:`[Data Def. 11] <D.def.11>`, :just:`[Data 2] <D.2>`, :just:`[Data 4] <D.4>`, :just:`[Data 6] <D.6>`, :just:`[V.12] <V.12>`, :just:`[V.16] <V.16>`, :just:`[V.18] <V.18>`, :just:`[V.19] <V.19>`

First, let the magnitude :math:`AB` be greater by a given magnitude than in ratio to :math:`BC`. I say that :math:`AB` is also greater by a given magnitude than in ratio to the compound :math:`AC`.

Subtract the given magnitude :math:`AD` from :math:`AB` (:just:`[Data Def. 11] <D.def.11>`); then the ratio :math:`DB : BC` is given. *Invertendo* and *componendo*, the ratio :math:`DC : DB` is given (:just:`[Data 6] <D.6>`), so *invertendo* :math:`DB : DC` is given. Let the ratio :math:`AD : DE` be made the same with :math:`DB : DC` (:just:`[Data Def. 2] <D.def.2>`); since :math:`DB : DC` is given and :math:`AD` is given, :math:`DE` is given (:just:`[Data 2] <D.2>`), whence the whole :math:`AE = AD + DE` is given (:just:`[Data 3] <D.3>`). Moreover, since :math:`AD : DE = DB : DC`, it follows by proportion manipulation (:just:`[V.12] <V.12>`, :just:`[V.19] <V.19>`) that the remainder :math:`EB` is to the compound :math:`AC` as :math:`DB` is to :math:`DC`. Thus the ratio :math:`EB : AC` is given while :math:`AE` is given; therefore :math:`AB` is greater by a given magnitude than in ratio to :math:`AC` (:just:`[Data Def. 11] <D.def.11>`).

Conversely, let :math:`AB` be greater by a given magnitude than in ratio to the compound :math:`AC`. I say that :math:`AB` is also greater by a given magnitude than in ratio to the remainder :math:`BC`.

Subtract from :math:`AB` the given magnitude :math:`AE` (:just:`[Data Def. 11] <D.def.11>`), so that the ratio :math:`EB : AC` is given, whence *invertendo* :math:`AC : EB` is given. Make :math:`AE : ED` have the same ratio as :math:`AC : EB` (:just:`[Data Def. 2] <D.def.2>`). Because :math:`AE` is given, :math:`ED` is given (:just:`[Data 2] <D.2>`), and therefore the remainder :math:`AD` is given (:just:`[Data 4] <D.4>`). Since :math:`AC : EB = AE : ED`, *convertendo*, *alternando*, and *separando* (:just:`[V.19] <V.19>`, :just:`[V.17] <V.17>`), the ratio :math:`BC : DB` (and hence :math:`DB : BC`) is given while :math:`AD` is given. Therefore :math:`AB` is greater by a given magnitude than in ratio to :math:`BC` (:just:`[Data Def. 11] <D.def.11>`).
