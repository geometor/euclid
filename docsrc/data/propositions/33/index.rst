Proposition 33 [λγ΄ · Prop. XXXVI]
----------------------------------

.. enunciation::

   If onto parallel straight lines given in position a straight line given in magnitude be drawn, it will make given angles with the parallels.

*Functional Signature*: ``Given(Pos(AB || CD), Mag(EF >= strip_width)) -> Determined(Mag(Angle BEF))`` · *Dependencies*: :just:`[Data Def. 1] <D.def.1>`, :just:`[Data Def. 4] <D.def.4>`, :just:`[Data 28] <D.28>`, :just:`[Data 31] <D.31>`, :just:`[I.29] <I.29>`, :just:`[I.34] <I.34>`

Between two parallel straight lines :math:`AB` and :math:`CD` given in position, let a straight line :math:`EF` of given magnitude be drawn. I say that :math:`EF` makes given angles :math:`\angle BEF` and :math:`\angle EFD` with the parallels.

Take a given point :math:`G` on :math:`AB`, and through :math:`G` draw :math:`GH` parallel to :math:`EF` meeting :math:`CD` at :math:`H` (:just:`[I.31] <I.31>`). Then :math:`GEFH` is a parallelogram, so :math:`GH = EF` (:just:`[I.34] <I.34>`); since :math:`EF` is given in magnitude, :math:`GH` is given in magnitude. With given centre :math:`G` and given distance :math:`GH`, describe the circle :math:`KHL` (:just:`[Post. 3] <I.post.3>`), which is given in position (:just:`[Data Def. 6] <D.def.6>`). Since :math:`CD` is given in position, the intersection :math:`H` is given in position (:just:`[Data 25] <D.25>`), whence the straight line :math:`GH` is given in position (:just:`[Data 26] <D.26>`). Because both :math:`AB` and :math:`GH` are given in position, the angle :math:`\angle BGH` is given; and by parallels :math:`\angle BEF = \angle BGH` and :math:`\angle EFD = 2\text{ rt.} - \angle BEF` (:just:`[I.29] <I.29>`), so :math:`\angle BEF` and :math:`\angle EFD` are given (:just:`[Data 4] <D.4>`).
