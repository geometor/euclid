Proposition 36 [λϛ΄ · Prop. XXXIX (pt. 2)]
------------------------------------------

.. enunciation::

   If from a given point onto a straight line given in position a straight line be drawn, and there be added to it a straight line having a given ratio to it, and through the extremity a parallel be drawn to the straight line given in position, that parallel is given in position.

*Functional Signature*: ``Given(Pos(Pole A), Pos(Line BC), ExternalRatio(AD : DE)) -> Determined(Pos(Line FEG || BC))`` · *Dependencies*: :just:`[Data 2] <D.2>`, :just:`[Data 6] <D.6>`, :just:`[Data 25] <D.25>`, :just:`[Data 26] <D.26>`, :just:`[Data 27] <D.27>`, :just:`[Data 28] <D.28>`, :just:`[Data 30] <D.30>`, :just:`[VI.2] <VI.2>`

From a given point :math:`A` to a straight line :math:`BC` given in position, let :math:`AD` be drawn, and on :math:`AD` (or its opposite ray through :math:`D`) let :math:`DE` be cut off toward :math:`A` having a given ratio :math:`DE : AD`. I say that :math:`E` lies on a straight line given in position.

Draw :math:`AF` perpendicular to :math:`BC` (:just:`[I.12] <I.12>`), so :math:`AF` is given in position (:just:`[Data 30] <D.30>`), :math:`F` is given (:just:`[Data 25] <D.25>`), and :math:`AF` is given in magnitude (:just:`[Data 26] <D.26>`). Cut off :math:`FG` toward :math:`A` (or beyond :math:`A` if :math:`DE > AD`) such that :math:`FG : FA = DE : DA` (:just:`[Data Def. 2] <D.def.2>`). Since :math:`FA` is given and :math:`FG : FA` is given, :math:`FG` is given in magnitude (:just:`[Data 2] <D.2>`), whence :math:`G` is given in position (:just:`[Data 27] <D.27>`). Because :math:`FD \parallel GE` follows from :math:`DA : DE = FA : FG` (and *separando* :math:`AE : ED = AG : GF`, :just:`[V.17] <V.17>`, :just:`[VI.2] <VI.2>`), the straight line :math:`GE` passes through the given point :math:`G` parallel to position-given :math:`BC`, and so is given in position (:just:`[Data 28] <D.28>`).
