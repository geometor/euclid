Proposition 61 [ξα΄ · Prop. LXIX]
---------------------------------

.. enunciation::

   If along one of the sides of a figure given in species a parallelogrammic area be applied in a given angle, and the figure have a given ratio to the parallelogram, the parallelogram is given in species.

*Functional Signature*: ``Given(Species(P on CB), Angle(CD), Ratio(Area(P) : Area(CD))) -> Determined(Species(CD))`` · *Dependencies*: :just:`[Data Def. 3] <D.def.3>`, :just:`[Data 8] <D.8>`, :just:`[Data 40] <D.40>`, :just:`[Data 49] <D.49>`, :just:`[I.13] <I.13>`, :just:`[I.29] <I.29>`, :just:`[I.31] <I.31>`, :just:`[I.35] <I.35>`, :just:`[VI.1] <VI.1>`

To a specified side :math:`CB` of a rectilinear figure :math:`AFCB` given in species, let a parallelogram :math:`CD` (:math:`= CBKL`) be applied in a given angle :math:`\angle LCB`, and let the figure :math:`AFCB` have a given ratio to the parallelogram :math:`CD`. I say that the parallelogram :math:`CD` is given in species.

On :math:`CB` construct the square :math:`CBEG` (or a reference parallelogram :math:`CBHM` in the given angle :math:`\angle LCB` with :math:`CM = CB`, whose species is given by :just:`[Data Def. 3] <D.def.3>`). Specifically, in Menge's proof, draw :math:`CK = CB` along :math:`CL` (or construct square :math:`CBHM` on :math:`CB` and compare): since both :math:`AFCB` and the unit-ratio parallelogram :math:`CBHM` (with :math:`\angle MCB = \angle LCB` and :math:`CM = CB`) are given in species on the same straight line :math:`CB`, the area ratio :math:`AFCB : CBHM` is given (:just:`[Data 49] <D.49>`). Combining this with the given hypothesis :math:`AFCB : CD` via :just:`[Data 8] <D.8>`, the ratio :math:`CBHM : CD` is given. Yet :math:`CBHM` and :math:`CD` share base :math:`CB` in the same angle :math:`\angle LCB`, so :math:`CBHM : CD = CM : CL = CB : CL` (:just:`[VI.1] <VI.1>`). Thus the side ratio :math:`CB : CL` is given together with the angle :math:`\angle LCB` (and hence all four angles of :math:`CD` by :just:`[I.29] <I.29>`, :just:`[I.34] <I.34>`); therefore the parallelogram :math:`CD` is given in species (:just:`[Data Def. 3] <D.def.3>`).
