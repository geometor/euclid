.. _D.85:

Proposition 85 [πε΄ · Prop. LXXXVI]
-----------------------------------

.. folio:: Menge 166
   :page: 166

.. enunciation::

   If two straight lines contain a given area in a given angle, and both taken together be given, each of them will also be given.

*Functional Signature*: ``Given(Angle B, Area(x, y) = S, x + y = s) -> Determined(Mag(x), Mag(y)) [diorismos]`` · *Dependencies*: :just:`[Data 4] <D.4>`, :just:`[Data 58] <D.58>`, :just:`[I.13] <I.13>`, :just:`[I.31] <I.31>`

Let two straight lines :math:`AB` and :math:`BC` contain a given area :math:`AB \cdot BC` in a given angle :math:`\angle ABC`, and let the sum :math:`AB + BC` be given in magnitude. I say that each of :math:`AB` and :math:`BC` is given in magnitude.

Produce :math:`CB` to :math:`D` so that :math:`BD = AB` (:just:`[I.3] <I.3>`). Since the compound :math:`AB + BC` is given, the whole straight line :math:`DC = DB + BC` is given in magnitude. Complete the given parallelogram :math:`ABCE` in the given angle :math:`\angle ABC`, and complete the supplementary rhombus :math:`ABDF` on :math:`BD = AB` between the same parallels :math:`DC` and :math:`FE` (:just:`[I.31] <I.31>`). Because :math:`BD = AB` and the adjacent angle :math:`\angle ABD = 2\\text{ rt.} - \angle ABC` is given (:just:`[I.13] <I.13>`, :just:`[Data 4] <D.4>`), the rhombus :math:`ABDF` is given in species (:just:`[Data Def. 3] <D.def.3>`). Thus the given area :math:`ABCE` has been applied to the given straight line :math:`DC`, :term:`deficient <elleipsis>` by the species-given figure :math:`ABDF`! By :just:`[Data 58] <D.58>`, the segments :math:`BD` (:math:`= AB`) and :math:`BC` are both given in magnitude.
