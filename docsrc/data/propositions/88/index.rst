Proposition 88 [πη΄ · Prop. XCII]
---------------------------------

.. enunciation::

   If in a circle given in magnitude a straight line given in magnitude be drawn, it will cut off a segment accepting a given angle.

*Functional Signature*: ``Given(CircleRadius R, Mag(Chord BC <= 2R)) -> Determined(Mag(InscribedAngle BAC))`` · *Dependencies*: :just:`[Data Def. 5] <D.def.5>`, :just:`[Data 1] <D.1>`, :just:`[Data 3] <D.3>`, :just:`[Data 43] <D.43>`, :just:`[III.21] <III.21>`, :just:`[III.22] <III.22>`, :just:`[III.31] <III.31>`

In a circle :math:`ABC` given in magnitude, let a chord :math:`AC` given in magnitude be drawn. I say that :math:`AC` cuts off a segment :math:`ABC` admitting a given angle :math:`\angle ABC`.

Take the centre :math:`D` (:just:`[III.1] <III.1>`), draw the diameter :math:`ADE`, and join :math:`EC`. Since the circle is given in magnitude, its diameter :math:`AE` is given in magnitude (:just:`[Data Def. 5] <D.def.5>`, :just:`[Data 3] <D.3>`). Because :math:`AC` is also given in magnitude, the ratio :math:`AE : AC` is given (:just:`[Data 1] <D.1>`). Now :math:`\\triangle ACE` is right-angled at :math:`C` (:just:`[III.31] <III.31>`) with the ratio of hypotenuse :math:`AE` to leg :math:`AC` given; hence :math:`\\triangle ACE` is uniquely given in species (:just:`[Data 43] <D.43>`). Therefore the angle :math:`\angle AEC` is given, whence the inscribed angle :math:`\angle ABC` (equal to :math:`\angle AEC` by :just:`[III.21] <III.21>`, or supplementary to it in the opposite arc by :just:`[III.22] <III.22>` and :just:`[Data 4] <D.4>`) is given, so segment :math:`ABC` admits a given angle (:just:`[Data Def. 8] <D.def.8>`).
