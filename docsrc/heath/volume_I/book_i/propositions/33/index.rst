PROPOSITION 33.
===============

.. enunciation::

   The straight lines joining equal and parallel straight lines (at the extremities which are) in the same directions (respectively) are themselves also equal and parallel.

| Let :g:`$AB$ <0336.g1:/ A B /; 0337.g1:/ A B />`, :g:`$CD$ <0336.g1:/ C D /; 0337.g1:/ C D />` be equal and parallel, and let the straight
| :line:`5` lines :g:`$AC$ <0336.g1:/ A C /; 0337.g1:/ A C />`, :g:`$BD$ <0336.g1:/ B D /; 0337.g1:/ B D />` join them (at the extremities which are) in the same directions (respectively);

.. folio:: 0337
   :page: 323

| I say that :g:`$AC$ <0337.g1:/ A C />`, :g:`$BD$ <0337.g1:/ B D />` are also equal and parallel.
| Let :g:`$BC$ <0337.g1:/ B C />` be joined.

.. picture:: 0337.g1.svg
   :alt: Folio 0337 Figure 1 - Proposition 33

| Then, since :g:`$AB$ <0337.g1:/ A B />` is parallel to :g:`$CD$ <0337.g1:/ C D />`,
| :line:`10` and :g:`$BC$ <0337.g1:/ B C />` has fallen upon them,

.. assertion:: [I. 29] <I.29>

   the alternate angles :g:`$ABC$ <0337.g1:< A B C )>`, :g:`$BCD$ <0337.g1:< B C D )>` are equal to one another.

| And, since :g:`$AB$ <0337.g1:/ A B />` is equal to :g:`$CD$ <0337.g1:/ C D />`,
| and :g:`$BC$ <0337.g1:/ B C />` is common,
| :line:`15` the two sides :g:`$AB$ <0337.g1:/ A B />`, :g:`$BC$ <0337.g1:/ B C />` are equal to the two sides :g:`$DC$ <0337.g1:/ D C />`, :g:`$CB$ <0337.g1:/ C B />`;
| and the angle :g:`$ABC$ <0337.g1:< A B C )>` is equal to the angle :g:`$BCD$ <0337.g1:< B C D )>`;

.. subclause::

   therefore the base :g:`$AC$ <0337.g1:/ A C />` is equal to the base :g:`$BD$ <0337.g1:/ B D />`,

.. subclause::

   and the triangle :g:`$ABC$ <0337.g1:< A B C >>` is equal to the triangle :g:`$DCB$ <0337.g1:< D C B >>`,

.. subclause::

   | and the remaining angles will be equal to the remaining angles
   | :line:`20` respectively, namely those which the equal sides subtend; :just:`[I. 4] <I.4>`

.. assertion::

   therefore the angle :g:`$ACB$ <0337.g1:< A C B )>` is equal to the angle :g:`$CBD$ <0337.g1:< C B D )>`.

And, since the straight line :g:`$BC$ <0337.g1:/ B C />` falling on the two straight lines :g:`$AC$ <0337.g1:/ A C />`, :g:`$BD$ <0337.g1:/ B D />` has made the alternate angles equal to one another,

.. assertion:: [I. 27] <I.27>

   :line:`25` :g:`$AC$ <0337.g1:/ A C />` is parallel to :g:`$BD$ <0337.g1:/ B D />`.

.. assertion::

   And it was also proved equal to it.

.. qed::

   Therefore etc. :just:`Q. E. D.`
