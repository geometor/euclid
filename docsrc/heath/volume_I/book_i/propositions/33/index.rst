PROPOSITION 33.
===============

.. enunciation::

   The straight lines joining equal and parallel straight lines (at the extremities which are) in the same directions (respectively)\ [#f1]_ are themselves also equal and parallel.

Let :g:`$AB$ <0336.g1:/ A B /; 0337.g1:/ A B />`, :g:`$CD$ <0336.g1:/ C D /; 0337.g1:/ C D />` be equal and parallel, and let the straight lines :g:`$AC$ <0336.g1:/ A C /; 0337.g1:/ A C />`, :g:`$BD$ <0336.g1:/ B D /; 0337.g1:/ B D />` join them (at the extremities which are) in the same directions (respectively);

.. _folio-i-0337:

.. folio:: 0337
   :page: 323

I say that :g:`$AC$ <0337.g1:/ A C />`, :g:`$BD$ <0337.g1:/ B D />` are also equal and parallel.

Let :g:`$BC$ <0337.g1:/ B C />` be joined.

.. picture:: 0337.g1.svg
   :alt: Folio 0337 Figure 1 - Proposition 33

Then, since :g:`$AB$ <0337.g1:/ A B />` is parallel to :g:`$CD$ <0337.g1:/ C D />`, and :g:`$BC$ <0337.g1:/ B C />` has fallen upon them,

.. assertion:: [I. 29] <I.29>

   the alternate angles :g:`$ABC$ <0337.g1:< A B C )>`, :g:`$BCD$ <0337.g1:< B C D )>` are equal to one another.

And, since :g:`$AB$ <0337.g1:/ A B />` is equal to :g:`$CD$ <0337.g1:/ C D />`, and :g:`$BC$ <0337.g1:/ B C />` is common, the two sides :g:`$AB$ <0337.g1:/ A B />`, :g:`$BC$ <0337.g1:/ B C />` are equal to the two sides :g:`$DC$ <0337.g1:/ D C />`, :g:`$CB$ <0337.g1:/ C B />`;\ [#f2]_ and the angle :g:`$ABC$ <0337.g1:< A B C )>` is equal to the angle :g:`$BCD$ <0337.g1:< B C D )>`;

.. subclause::

   therefore the base :g:`$AC$ <0337.g1:/ A C />` is equal to the base :g:`$BD$ <0337.g1:/ B D />`,

.. subclause::

   and the triangle :g:`$ABC$ <0337.g1:< A B C >>` is equal to the triangle :g:`$DCB$ <0337.g1:< D C B >>`,

.. subclause::

   and the remaining angles will be equal to the remaining angles respectively, namely those which the equal sides subtend; :just:`[I. 4] <I.4>`

.. assertion::

   therefore the angle :g:`$ACB$ <0337.g1:< A C B )>` is equal to the angle :g:`$CBD$ <0337.g1:< C B D )>`.

And, since the straight line :g:`$BC$ <0337.g1:/ B C />` falling on the two straight lines :g:`$AC$ <0337.g1:/ A C />`, :g:`$BD$ <0337.g1:/ B D />` has made the alternate angles equal to one another,

.. assertion:: [I. 27] <I.27>

   :g:`$AC$ <0337.g1:/ A C />` is parallel to :g:`$BD$ <0337.g1:/ B D />`.

.. assertion::

   And it was also proved equal to it.

.. qed::

   Therefore etc. :just:`Q. E. D.`

.. [#f1] **joining...(at the extremities which are) in the same directions (respectively).** I have for clearness' sake inserted the words in brackets though they are not in the original Greek, which has “joining...in the same directions” or “on the same sides,” ἐπὶ τὰ αὐτὰ μέρη ἐπιζευγνύουσαι. The expression “towards the same parts,” though usage has sanctioned it, is perhaps not quite satisfactory.

.. [#f2] **DC, CB and DCB.** The Greek has “:g:`$BC$ <0337.g1:/ B C />`, :g:`$CD$ <0337.g1:/ C D />`” and “:g:`$BCD$ <0337.g1:< B C D >>`” in these places respectively. :person:`Euclid <euclid>` is not always careful to write in corresponding order the letters denoting corresponding points in congruent figures. On the contrary, he evidently prefers the alphabetical order, and seems to disdain to alter it for the sake of beginners or others who might be confused by it. In the case of angles alteration is perhaps unnecessary; but in the case of triangles and pairs of corresponding sides I have ventured to alter the order to that which the mathematician of to-day expects.
