PROPOSITION 37.
===============

.. enunciation::

   Triangles which are on the same base and in the same parallels are equal to one another.

| Let :g:`$ABC$ <0346.g1:< A B C >>`, :g:`$DBC$ <0346.g1:< D B C >>` be triangles on the same base :g:`$BC$ <0346.g1:/ B C />` and in the same parallels :g:`$AD$ <0346.g1:/ A D />`, :g:`$BC$ <0346.g1:/ B C />`;
| :line:`5` I say that the triangle :g:`$ABC$ <0346.g1:< A B C >>` is equal to the triangle :g:`$DBC$ <0346.g1:< D B C >>`.

.. picture:: 0346.g1.svg
   :alt: Folio 0346 Figure 1 - Proposition 37

| Let :g:`$AD$ <0346.g1:[ A D ]>` be produced in both directions to :g:`$E$ <0346.g1:E>`, :g:`$F$ <0346.g1:F>`;
| through :g:`$B$ <0346.g1:B>` let :g:`$BE$ <0346.g1:/ B E />` be drawn parallel to :g:`$CA$ <0346.g1:/ C A />`, :just:`[I. 31] <I.31>`
| :line:`10` and through :g:`$C$ <0346.g1:C>` let :g:`$CF$ <0346.g1:/ C F />` be drawn parallel to :g:`$BD$ <0346.g1:/ B D />`. :just:`[I. 31] <I.31>`

| Then each of the figures :g:`$EBCA$ <0346.g1:< E B C A >>`, :g:`$DBCF$ <0346.g1:< D B C F >>` is a parallelogram;
| and they are equal,
| :line:`15` for they are on the same base :g:`$BC$ <0346.g1:/ B C />` and in the same parallels :g:`$BC$ <0346.g1:/ B C />`, :g:`$EF$ <0346.g1:/ E F />`. :just:`[I. 35] <I.35>`

| Moreover the triangle :g:`$ABC$ <0346.g1:< A B C >>` is half of the parallelogram :g:`$EBCA$ <0346.g1:< E B C A >>`; for the diameter :g:`$AB$ <0346.g1:/ A B />` bisects it. :just:`[I. 34] <I.34>`
| And the triangle :g:`$DBC$ <0346.g1:< D B C >>` is half of the parallelogram :g:`$DBCF$ <0346.g1:< D B C F >>`;
| :line:`20` for the diameter :g:`$DC$ <0346.g1:/ D C />` bisects it. :just:`[I. 34] <I.34>`
| [But the halves of equal things are equal to one another.]

.. assertion::

   Therefore the triangle :g:`$ABC$ <0346.g1:< A B C >>` is equal to the triangle :g:`$DBC$ <0346.g1:< D B C >>`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
