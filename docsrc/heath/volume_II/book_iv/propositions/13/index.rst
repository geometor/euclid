PROPOSITION 13.
===============

.. enunciation::

   In a given pentagon, which is equilateral and equiangular, to inscribe a circle.

Let :g:`$ABCDE$ <0111.g1:< A B C D E >>` be the given equilateral and equiangular
pentagon;
thus it is required to inscribe a circle in the pentagon
:g:`$ABCDE$ <0111.g1:< A B C D E >>`.

For let the angles :g:`$BCD$ <0111.g1:< B C D )>`, :g:`$CDE$ <0111.g1:< C D E )>` be bisected by the
straight lines :g:`$CF$ <0111.g1:/ C F />`, :g:`$DF$ <0111.g1:/ D F />` respectively; and from the point :g:`$F$ <0111.g1:F>`, at
which the straight lines :g:`$CF$ <0111.g1:/ C F />`, :g:`$DF$ <0111.g1:/ D F />` meet one another, let the
straight lines :g:`$FB$ <0111.g1:/ F B />`, :g:`$FA$ <0111.g1:/ F A />`, :g:`$FE$ <0111.g1:/ F E />` be joined.

.. _folio-ii-0111:

.. folio:: 0111
   :page: 105

Then, since :g:`$BC$ <0111.g1:/ B C />` is :eq:`equal <0111.g1:/ B C / = 0111.g1:/ C D />` to :g:`$CD$ <0111.g1:/ C D />`,
and :g:`$CF$ <0111.g1:/ C F />` common,
the two sides :g:`$BC$ <0111.g1:/ B C />`, :g:`$CF$ <0111.g1:/ C F />` are :eq:`equal <0111.g1:/ B C / = 0111.g1:/ D C /; 0111.g1:/ C F / = 0111.g1:/ C F />` to the
two sides :g:`$DC$ <0111.g1:/ D C />`, :g:`$CF$ <0111.g1:/ C F />`;
and the angle :g:`$BCF$ <0111.g1:< B C F )>` is :eq:`equal <0111.g1:< B C F ) = 0111.g1:< D C F )>` to the
angle :g:`$DCF$ <0111.g1:< D C F )>`;
therefore the base :g:`$BF$ <0111.g1:/ B F />` is :eq:`equal <0111.g1:/ B F / = 0111.g1:/ D F />`
to the base :g:`$DF$ <0111.g1:/ D F />`,
and the triangle :g:`$BCF$ <0111.g1:< B C F >>` is :eq:`equal <0111.g1:< B C F > = 0111.g1:< D C F >>` to the
triangle :g:`$DCF$ <0111.g1:< D C F >>`,
and the remaining angles will be equal to the remaining angles,
namely those which the equal sides subtend. :just:`[I. 4] <I.4>`

.. picture:: 0111.g1.svg
   :alt: Book IV Proposition 13: Circle GHKLM inscribed in regular pentagon ABCDE

.. assertion::

   Therefore the angle :g:`$CBF$ <0111.g1:< C B F )>` is :eq:`equal <0111.g1:< C B F ) = 0111.g1:< C D F )>` to the angle :g:`$CDF$ <0111.g1:< C D F )>`.

And, since the angle :g:`$CDE$ <0111.g1:< C D E )>` is double of the angle :g:`$CDF$ <0111.g1:< C D F )>`,
and the angle :g:`$CDE$ <0111.g1:< C D E )>` is :eq:`equal <0111.g1:< C D E ) = 0111.g1:< A B C )>` to the angle :g:`$ABC$ <0111.g1:< A B C )>`,

.. subclause::

   while the angle :g:`$CDF$ <0111.g1:< C D F )>` is :eq:`equal <0111.g1:< C D F ) = 0111.g1:< C B F )>` to the angle :g:`$CBF$ <0111.g1:< C B F )>`;

.. assertion::

   therefore the angle :g:`$CBA$ <0111.g1:< C B A )>` is also double of the angle :g:`$CBF$ <0111.g1:< C B F )>`;

.. assertion::

   therefore the angle :g:`$ABF$ <0111.g1:< A B F )>` is :eq:`equal <0111.g1:< A B F ) = 0111.g1:< F B C )>` to the angle :g:`$FBC$ <0111.g1:< F B C )>`;

.. assertion::

   therefore the angle :g:`$ABC$ <0111.g1:< A B C )>` has been :eq:`bisected <0111.g1:< A B F ) = 0111.g1:< F B C )>` by the straight line :g:`$BF$ <0111.g1:/ B F />`.

Similarly it can be proved that
the angles :g:`$BAE$ <0111.g1:< B A E )>`, :g:`$AED$ <0111.g1:< A E D )>` have also been bisected by the straight
lines :g:`$FA$ <0111.g1:/ F A />`, :g:`$FE$ <0111.g1:/ F E />` respectively.

Now let :g:`$FG$ <0111.g1:/ F G />`, :g:`$FH$ <0111.g1:/ F H />`, :g:`$FK$ <0111.g1:/ F K />`, :g:`$FL$ <0111.g1:/ F L />`, :g:`$FM$ <0111.g1:/ F M />` be drawn from the point
:g:`$F$ <0111.g1:F>` perpendicular to the straight lines :g:`$AB$ <0111.g1:/ A B />`, :g:`$BC$ <0111.g1:/ B C />`, :g:`$CD$ <0111.g1:/ C D />`, :g:`$DE$ <0111.g1:/ D E />`, :g:`$EA$ <0111.g1:/ E A />`.

Then, since the angle :g:`$HCF$ <0111.g1:< H C F )>` is :eq:`equal <0111.g1:< H C F ) = 0111.g1:< K C F )>` to the angle :g:`$KCF$ <0111.g1:< K C F )>`,
and the right angle :g:`$FHC$ <0111.g1:< F H C )>` is also :eq:`equal <0111.g1:< F H C ) = 0111.g1:< F K C )>` to the angle :g:`$FKC$ <0111.g1:< F K C )>`,
:g:`$FHC$ <0111.g1:< F H C >>`, :g:`$FKC$ <0111.g1:< F K C >>` are two triangles having two angles equal to two
angles and one side equal to one side, namely :g:`$FC$ <0111.g1:/ F C />` which is
common to them and subtends one of the equal angles;
therefore they will also have the remaining sides equal to the
remaining sides; :just:`[I. 26] <I.26>`

.. assertion::

   therefore the perpendicular :g:`$FH$ <0111.g1:/ F H />` is :eq:`equal <0111.g1:/ F H / = 0111.g1:/ F K />` to the perpendicular :g:`$FK$ <0111.g1:/ F K />`.

Similarly it can be proved that
each of the straight lines :g:`$FL$ <0111.g1:/ F L />`, :g:`$FM$ <0111.g1:/ F M />`, :g:`$FG$ <0111.g1:/ F G />` is also :eq:`equal <0111.g1:/ F L / = 0111.g1:/ F M / = 0111.g1:/ F G / = 0111.g1:/ F H / = 0111.g1:/ F K />` to each
of the straight lines :g:`$FH$ <0111.g1:/ F H />`, :g:`$FK$ <0111.g1:/ F K />`;

.. _folio-ii-0112:

.. folio:: 0112
   :page: 106

.. assertion::

   therefore the five straight lines :g:`$FG$ <0111.g1:/ F G />`, :g:`$FH$ <0111.g1:/ F H />`, :g:`$FK$ <0111.g1:/ F K />`, :g:`$FL$ <0111.g1:/ F L />`, :g:`$FM$ <0111.g1:/ F M />` are :eq:`equal <0111.g1:/ F G / = 0111.g1:/ F H / = 0111.g1:/ F K / = 0111.g1:/ F L / = 0111.g1:/ F M />` to one another.

Therefore the circle described with centre :g:`$F$ <0111.g1:F>` and distance
one of the straight lines :g:`$FG$ <0111.g1:/ F G />`, :g:`$FH$ <0111.g1:/ F H />`, :g:`$FK$ <0111.g1:/ F K />`, :g:`$FL$ <0111.g1:/ F L />`, :g:`$FM$ <0111.g1:/ F M />` will pass
also through the remaining points;
and it will touch the straight lines :g:`$AB$ <0111.g1:/ A B />`, :g:`$BC$ <0111.g1:/ B C />`, :g:`$CD$ <0111.g1:/ C D />`, :g:`$DE$ <0111.g1:/ D E />`, :g:`$EA$ <0111.g1:/ E A />`,
because the angles at the points :g:`$G$ <0111.g1:< F G B )>`, :g:`$H$ <0111.g1:< F H C )>`, :g:`$K$ <0111.g1:< F K C )>`, :g:`$L$ <0111.g1:< F L D )>`, :g:`$M$ <0111.g1:< F M E )>` are right.

For, if it does not touch them, but cuts them,
it will result that the straight line drawn at right angles to
the diameter of the circle from its extremity falls within the
circle: which was proved absurd. :just:`[III. 16] <III.16>`

Therefore the circle described with centre :g:`$F$ <0111.g1:F>` and distance
one of the straight lines :g:`$FG$ <0111.g1:/ F G />`, :g:`$FH$ <0111.g1:/ F H />`, :g:`$FK$ <0111.g1:/ F K />`, :g:`$FL$ <0111.g1:/ F L />`, :g:`$FM$ <0111.g1:/ F M />` will not
cut the straight lines :g:`$AB$ <0111.g1:/ A B />`, :g:`$BC$ <0111.g1:/ B C />`, :g:`$CD$ <0111.g1:/ C D />`, :g:`$DE$ <0111.g1:/ D E />`, :g:`$EA$ <0111.g1:/ E A />`;

.. assertion::

   therefore it will touch them.

Let it be described, as :g:`$GHKLM$ <0111.g1:( G H K L M )>`.

.. qed::

   Therefore in the given pentagon, which is equilateral and equiangular, a circle has been inscribed. :just:`Q. E. F.`
