PROPOSITION 13.
===============

.. enunciation::

   If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be prime, the greatest will not be measured by any except those which have a place among the proportional numbers.

Let there be as many numbers as we please, :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>`, :g:`$D$ <0405.g1:D>`, beginning from an unit and in continued proportion, and let :g:`$A$ <0405.g1:A>`, the number after the unit, be prime;

I say that :g:`$D$ <0405.g1:D>`, the greatest of them, will not be measured by any other number except :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>`.

.. picture:: 0405.g1.svg
   :alt: Proposition 13 diagram

For, if possible, let it be measured by :g:`$E$ <0405.g1:E>`, and let :g:`$E$ <0405.g1:E>` not be the same with any of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>`.

.. assertion::

   It is then manifest that :g:`$E$ <0405.g1:E>` is not prime.

.. subclause::

   For, if :g:`$E$ <0405.g1:E>` is prime and measures :g:`$D$ <0405.g1:D>`, it will also measure :g:`$A$ <0405.g1:A>` :just:`[IX. 12] <IX.12>`, which is prime, though it is not the same with it:

.. assertion::

   which is impossible.

.. _folio-ii-0406:

.. folio:: 0406
   :page: 400

.. assertion::

   Therefore :g:`$E$ <0405.g1:E>` is not prime.

.. assertion::

   Therefore it is composite.

.. subclause::

   But any composite number is measured by some prime number ; :just:`[VII. 31] <VII.31>`

.. assertion::

   therefore :g:`$E$ <0405.g1:E>` is measured by some prime number.

I say next that it will not be measured by any other prime except :g:`$A$ <0405.g1:A>`.

.. subclause::

   For, if :g:`$E$ <0405.g1:E>` is measured by another, and :g:`$E$ <0405.g1:E>` measures :g:`$D$ <0405.g1:D>`,

.. assertion::

   that other will also measure :g:`$D$ <0405.g1:D>` ; so that it will also measure :g:`$A$ <0405.g1:A>` :just:`[IX. 12] <IX.12>`, which is prime, though it is not the same with it : which is impossible.

.. assertion::

   Therefore :g:`$A$ <0405.g1:A>` measures :g:`$E$ <0405.g1:E>`.

And, since :g:`$E$ <0405.g1:E>` measures :g:`$D$ <0405.g1:D>`, let it measure it according to :g:`$F$ <0405.g1:F>`.

I say that :g:`$F$ <0405.g1:F>` is not the same with any of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>`.

.. subclause::

   For, if :g:`$F$ <0405.g1:F>` is the same with one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>`, and measures :g:`$D$ <0405.g1:D>` according to :g:`$E$ <0405.g1:E>`,

.. assertion::

   therefore one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>` also measures :g:`$D$ <0405.g1:D>` according to :g:`$E$ <0405.g1:E>`.

.. subclause::

   But one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>` measures :g:`$D$ <0405.g1:D>` according to some one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>` ; :just:`[IX. 11] <IX.11>`

.. assertion::

   therefore :g:`$E$ <0405.g1:E>` is also the same with one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>` : which is contrary to the hypothesis.

.. assertion::

   Therefore :g:`$F$ <0405.g1:F>` is not the same as any one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>`.

.. assertion::

   Similarly we can prove that :g:`$F$ <0405.g1:F>` is measured by :g:`$A$ <0405.g1:A>`, by proving again that :g:`$F$ <0405.g1:F>` is not prime.

.. subclause::

   For, if it is, and measures :g:`$D$ <0405.g1:D>`,

.. assertion::

   it will also measure :g:`$A$ <0405.g1:A>` :just:`[IX. 12] <IX.12>`, which is prime, though it is not the same with it : which is impossible ; therefore :g:`$F$ <0405.g1:F>` is not prime.

.. assertion::

   Therefore it is composite.

.. subclause::

   But any composite number is measured by some prime number ; :just:`[VII. 31] <VII.31>`

.. assertion::

   therefore :g:`$F$ <0405.g1:F>` is measured by some prime number.

.. _folio-ii-0407:

.. folio:: 0407
   :page: 401

I say next that it will not be measured by any other prime except :g:`$A$ <0405.g1:A>`.

.. subclause::

   For, if any other prime number measures :g:`$F$ <0405.g1:F>`, and :g:`$F$ <0405.g1:F>` measures :g:`$D$ <0405.g1:D>`,

.. assertion::

   that other will also measure :g:`$D$ <0405.g1:D>` ; so that it will also measure :g:`$A$ <0405.g1:A>` :just:`[IX. 12] <IX.12>`, which is prime, though it is not the same with it : which is impossible.

.. assertion::

   Therefore :g:`$A$ <0405.g1:A>` measures :g:`$F$ <0405.g1:F>`.

.. subclause::

   And, since :g:`$E$ <0405.g1:E>` measures :g:`$D$ <0405.g1:D>` according to :g:`$F$ <0405.g1:F>`,

.. assertion::

   therefore :g:`$E$ <0405.g1:E>` by multiplying :g:`$F$ <0405.g1:F>` has made :g:`$D$ <0405.g1:D>`.

.. subclause:: [IX. 11] <IX.11>

   But, further, :g:`$A$ <0405.g1:A>` has also by multiplying :g:`$C$ <0405.g1:C>` made :g:`$D$ <0405.g1:D>` ;

.. assertion::

   therefore the product of :g:`$A$ <0405.g1:A>`, :g:`$C$ <0405.g1:C>` is equal to the product of :g:`$E$ <0405.g1:E>`, :g:`$F$ <0405.g1:F>`.

.. assertion:: [VII. 19] <VII.19>

   Therefore, proportionally, as :g:`$A$ <0405.g1:A>` is to :g:`$E$ <0405.g1:E>`, so is :g:`$F$ <0405.g1:F>` to :g:`$C$ <0405.g1:C>`.

.. subclause::

   But :g:`$A$ <0405.g1:A>` measures :g:`$E$ <0405.g1:E>` ;

.. assertion::

   therefore :g:`$F$ <0405.g1:F>` also measures :g:`$C$ <0405.g1:C>`.

Let it measure it according to :g:`$G$ <0405.g1:G>`.

.. assertion::

   Similarly, then, we can prove that :g:`$G$ <0405.g1:G>` is not the same with any of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, and that it is measured by :g:`$A$ <0405.g1:A>`.

.. subclause::

   And, since :g:`$F$ <0405.g1:F>` measures :g:`$C$ <0405.g1:C>` according to :g:`$G$ <0405.g1:G>`,

.. assertion::

   therefore :g:`$F$ <0405.g1:F>` by multiplying :g:`$G$ <0405.g1:G>` has made :g:`$C$ <0405.g1:C>`.

.. subclause:: [IX. 11] <IX.11>

   But, further, :g:`$A$ <0405.g1:A>` has also by multiplying :g:`$B$ <0405.g1:B>` made :g:`$C$ <0405.g1:C>` ;

.. assertion::

   therefore the product of :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>` is equal to the product of :g:`$F$ <0405.g1:F>`, :g:`$G$ <0405.g1:G>`.

.. assertion:: [VII. 19] <VII.19>

   Therefore, proportionally, as :g:`$A$ <0405.g1:A>` is to :g:`$F$ <0405.g1:F>`, so is :g:`$G$ <0405.g1:G>` to :g:`$B$ <0405.g1:B>`.

.. subclause::

   But :g:`$A$ <0405.g1:A>` measures :g:`$F$ <0405.g1:F>` ;

.. assertion::

   therefore :g:`$G$ <0405.g1:G>` also measures :g:`$B$ <0405.g1:B>`.

Let it measure it according to :g:`$H$ <0405.g1:H>`.

.. assertion::

   Similarly then we can prove that :g:`$H$ <0405.g1:H>` is not the same with :g:`$A$ <0405.g1:A>`.

.. subclause::

   And, since :g:`$G$ <0405.g1:G>` measures :g:`$B$ <0405.g1:B>` according to :g:`$H$ <0405.g1:H>`,

.. assertion::

   therefore :g:`$G$ <0405.g1:G>` by multiplying :g:`$H$ <0405.g1:H>` has made :g:`$B$ <0405.g1:B>`.

.. subclause:: [IX. 8] <IX.8>

   But further :g:`$A$ <0405.g1:A>` has also by multiplying itself made :g:`$B$ <0405.g1:B>` ;

.. assertion::

   therefore the product of :g:`$H$ <0405.g1:H>`, :g:`$G$ <0405.g1:G>` is equal to the square on :g:`$A$ <0405.g1:A>`.

.. assertion:: [VII. 19] <VII.19>

   Therefore, as :g:`$H$ <0405.g1:H>` is to :g:`$A$ <0405.g1:A>`, so is :g:`$A$ <0405.g1:A>` to :g:`$G$ <0405.g1:G>`.

.. _folio-ii-0408:

.. folio:: 0408
   :page: 402

.. subclause::

   But :g:`$A$ <0405.g1:A>` measures :g:`$G$ <0405.g1:G>` ;

.. assertion::

   therefore :g:`$H$ <0405.g1:H>` also measures :g:`$A$ <0405.g1:A>`, which is prime, though it is not the same with it : which is absurd.

.. assertion::

   Therefore :g:`$D$ <0405.g1:D>` the greatest will not be measured by any other number except :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>`.

.. qed::

   :just:`Q. E. D.`
