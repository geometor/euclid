Commentary on Proposition V.14
==============================

Algebraically, if $a : b = c : d$, then, according as $a > = < c$, $b > = < d$.

:person:`Simson <simson>` adds the specific proof of the second and third parts of this proposition, which Euclid dismisses with "Similarly we can prove...."

"Secondly, if :g:`A <0168.g1:A>` be :eq:`equal <0168.g1:A = 0168.g1:C>` to :g:`C <0168.g1:C>`, :g:`B <0168.g1:B>` is :eq:`equal <0168.g1:B = 0168.g1:D>` to :g:`D <0168.g1:D>` ; for :g:`A <0168.g1:A>` is to :g:`B <0168.g1:B>` as :g:`C <0168.g1:C>`, that is :g:`A <0168.g1:A>`, is to :g:`D <0168.g1:D>` ;

.. assertion:: [V. 9] <V.9>

   therefore :g:`B <0168.g1:B>` is :eq:`equal <0168.g1:B = 0168.g1:D>` to :g:`D <0168.g1:D>`.

Thirdly, if :g:`A <0168.g1:A>` be less than :g:`C <0168.g1:C>`, :g:`B <0168.g1:B>` shall be less than :g:`D <0168.g1:D>`. For :g:`C <0168.g1:C>` is greater than :g:`A <0168.g1:A>` ; and, because :g:`C <0168.g1:C>` is to :g:`D <0168.g1:D>` as :g:`A <0168.g1:A>` is to :g:`B <0168.g1:B>`,

.. assertion::

   :g:`D <0168.g1:D>` is greater than :g:`B <0168.g1:B>`, by the first case.

Wherefore :g:`B <0168.g1:B>` is less than :g:`D <0168.g1:D>`."

:person:`Aristotle <aristotle>`, *Meteorol.* III. 5, 376 a 11—14, quotes the equivalent proposition that, if $a > b$, $c > d$.
