PROPOSITION 1.
==============

.. enunciation::

   Triangles and parallelograms which are under the same height are to one another as their bases.

Let :g:`$ABC$ <0197.g1:< A B C >>`, :g:`$ACD$ <0197.g1:< A C D >>` be triangles and :g:`$EC$ <0197.g1:< E C >>`, :g:`$CF$ <0197.g1:< C F >>` parallelograms under the same height;\ [#f1]_

I say that, as the base :g:`$BC$ <0197.g1:/ B C />` is to the base :g:`$CD$ <0197.g1:/ C D />`, so is the triangle :g:`$ABC$ <0197.g1:< A B C >>` to the triangle :g:`$ACD$ <0197.g1:< A C D >>`, and the parallelogram :g:`$EC$ <0197.g1:< E C >>` to the parallelogram :g:`$CF$ <0197.g1:< C F >>`.

.. picture:: 0197.g1.svg
   :alt: Book VI Proposition 1

For let :g:`$BD$ <0197.g1:/ B D />` be produced in both directions to the points :g:`$H$ <0197.g1:H>`, :g:`$L$ <0197.g1:L>` and let [any number of straight lines] :g:`$BG$ <0197.g1:/ B G />`, :g:`$GH$ <0197.g1:/ G H />` be made :eq:`equal <0197.g1:/ B G / = 0197.g1:/ G H / = 0197.g1:/ B C />` to the base :g:`$BC$ <0197.g1:/ B C />`, and any number of straight lines :g:`$DK$ <0197.g1:/ D K />`, :g:`$KL$ <0197.g1:/ K L />` :eq:`equal <0197.g1:/ D K / = 0197.g1:/ K L / = 0197.g1:/ C D />` to the base :g:`$CD$ <0197.g1:/ C D />`; let :g:`$AG$ <0197.g1:/ A G />`, :g:`$AH$ <0197.g1:/ A H />`, :g:`$AK$ <0197.g1:/ A K />`, :g:`$AL$ <0197.g1:/ A L />` be joined.

Then, since :g:`$CB$ <0197.g1:/ C B />`, :g:`$BG$ <0197.g1:/ B G />`, :g:`$GH$ <0197.g1:/ G H />` are :eq:`equal <0197.g1:/ C B / = 0197.g1:/ B G / = 0197.g1:/ G H />` to one another,

.. assertion::

   the triangles :g:`$ABC$ <0197.g1:< A B C >>`, :g:`$AGB$ <0197.g1:< A G B >>`, :g:`$AHG$ <0197.g1:< A H G >>`\ [#f2]_ are also :eq:`equal <0197.g1:< A B C > = 0197.g1:< A G B > = 0197.g1:< A H G >>` to one another. :just:`[I. 38] <I.38>`

.. assertion::

   Therefore, whatever multiple the base :g:`$HC$ <0197.g1:/ H C />` is of the base :g:`$BC$ <0197.g1:/ B C />`, that multiple also is the triangle :g:`$AHC$ <0197.g1:< A H C >>` of the triangle :g:`$ABC$ <0197.g1:< A B C >>`.

.. subclause::

   For the same reason,

.. assertion::

   whatever multiple the base :g:`$LC$ <0197.g1:/ L C />` is of the base :g:`$CD$ <0197.g1:/ C D />`, that multiple also is the triangle :g:`$ALC$ <0197.g1:< A L C >>` of the triangle :g:`$ACD$ <0197.g1:< A C D >>`;

.. assertion::

   and, if the base :g:`$HC$ <0197.g1:/ H C />` is :eq:`equal <0197.g1:/ H C / = 0197.g1:/ C L />` to the base :g:`$CL$ <0197.g1:/ C L />`, the triangle :g:`$AHC$ <0197.g1:< A H C >>` is also :eq:`equal <0197.g1:< A H C > = 0197.g1:< A C L >>` to the triangle :g:`$ACL$ <0197.g1:< A C L >>`, :just:`[I. 38] <I.38>`

.. _folio-ii-0198:

.. folio:: 0198
   :page: 192

.. assertion::

   if the base :g:`$HC$ <0197.g1:/ H C />` is in excess of the base :g:`$CL$ <0197.g1:/ C L />`, the triangle :g:`$AHC$ <0197.g1:< A H C >>` is also in excess of the triangle :g:`$ACL$ <0197.g1:< A C L >>`, and, if less, less.

Thus, there being four magnitudes, two bases :g:`$BC$ <0197.g1:/ B C />`, :g:`$CD$ <0197.g1:/ C D />` and two triangles :g:`$ABC$ <0197.g1:< A B C >>`, :g:`$ACD$ <0197.g1:< A C D >>`, equimultiples have been taken of the base :g:`$BC$ <0197.g1:/ B C />` and the triangle :g:`$ABC$ <0197.g1:< A B C >>`, namely the base :g:`$HC$ <0197.g1:/ H C />` and the triangle :g:`$AHC$ <0197.g1:< A H C >>`, and of the base :g:`$CD$ <0197.g1:/ C D />` and the triangle :g:`$ADC$ <0197.g1:< A D C >>` other, chance, equimultiples, namely the base :g:`$LC$ <0197.g1:/ L C />` and the triangle :g:`$ALC$ <0197.g1:< A L C >>`; and it has been proved that,

.. subclause::

   if the base :g:`$HC$ <0197.g1:/ H C />` is in excess of the base :g:`$CL$ <0197.g1:/ C L />`, the triangle :g:`$AHC$ <0197.g1:< A H C >>` is also in excess of the triangle :g:`$ALC$ <0197.g1:< A L C >>`; if :eq:`equal <0197.g1:/ H C / = 0197.g1:/ C L />`, :eq:`equal <0197.g1:< A H C > = 0197.g1:< A L C >>`; and, if less, less.

.. assertion::

   Therefore, as the base :g:`$BC$ <0197.g1:/ B C />` is to the base :g:`$CD$ <0197.g1:/ C D />`, so is the triangle :g:`$ABC$ <0197.g1:< A B C >>` to the triangle :g:`$ACD$ <0197.g1:< A C D >>`. :just:`[V. Def. 5] <V.def.5>`

Next, since the parallelogram :g:`$EC$ <0197.g1:< E C >>` is double of the triangle :g:`$ABC$ <0197.g1:< A B C >>`, :just:`[I. 41] <I.41>`

and the parallelogram :g:`$FC$ <0197.g1:< F C >>` is double of the triangle :g:`$ACD$ <0197.g1:< A C D >>`, while parts have the same ratio as the same multiples of them, :just:`[V. 15] <V.15>`

.. assertion::

   therefore, as the triangle :g:`$ABC$ <0197.g1:< A B C >>` is to the triangle :g:`$ACD$ <0197.g1:< A C D >>`, so is the parallelogram :g:`$EC$ <0197.g1:< E C >>` to the parallelogram :g:`$FC$ <0197.g1:< F C >>`.

Since, then, it was proved that, as the base :g:`$BC$ <0197.g1:/ B C />` is to :g:`$CD$ <0197.g1:/ C D />`, so is the triangle :g:`$ABC$ <0197.g1:< A B C >>` to the triangle :g:`$ACD$ <0197.g1:< A C D >>`,\ [#f3]_ and, as the triangle :g:`$ABC$ <0197.g1:< A B C >>` is to the triangle :g:`$ACD$ <0197.g1:< A C D >>`, so is the parallelogram :g:`$EC$ <0197.g1:< E C >>` to the parallelogram :g:`$CF$ <0197.g1:< C F >>`,

.. assertion::

   therefore also, as the base :g:`$BC$ <0197.g1:/ B C />` is to the base :g:`$CD$ <0197.g1:/ C D />`, so is the parallelogram :g:`$EC$ <0197.g1:< E C >>` to the parallelogram :g:`$FC$ <0197.g1:< F C >>`. :just:`[V. 11] <V.11>`

.. qed::

   Therefore etc. :just:`Q. E. D.`

.. [#f1] **Under the same height.** The Greek text has “under the same height :g:`$AC$ <0197.g1:/ A C />`,” with a figure in which the side :g:`$AC$ <0197.g1:/ A C />` common to the two triangles is perpendicular to the base and is therefore itself the “height.” But, even if the two triangles are placed contiguously so as to have a common side :g:`$AC$ <0197.g1:/ A C />`, it is quite gratuitous to require it to be perpendicular to the base. Theon, on this occasion making an improvement, altered to “which are (ὄντα) under the same height, (namely) the perpendicular drawn from :g:`$A$ <0197.g1:A>` to :g:`$BD$ <0197.g1:/ B D />`.” I have ventured to alter so far as to omit “:g:`$AC$ <0197.g1:/ A C />`” and to draw the figure in the usual way.

.. [#f2] **ABC, AGB**, :g:`$AHG$ <0197.g1:< A H G >>`. Euclid, indifferent to exact order, writes “$AHG$, :g:`$AGB$ <0197.g1:< A G B >>`, :g:`$ABC$ <0197.g1:< A B C >>`.”

.. [#f3] **Since then it was proved that, as the base** :g:`$BC$ <0197.g1:/ B C />` **is to** :g:`$CD$ <0197.g1:/ C D />`, **so is the triangle** :g:`$ABC$ <0197.g1:< A B C >>` **to the triangle** :g:`$ACD$ <0197.g1:< A C D >>`. Here again words have to be supplied in translating the extremely terse Greek ἐπεὶ οὖν ἐδείχθη, ὡς μὲν ἡ :term:`βάσις <basis>` ΒΓ πρὸς τὴν ΓΔ, οὕτως τὸ ΑΒΓ τρίγωνον πρὸς τὸ ΑΓΔ τρίγωνον, literally “since was proved, as the base $BC$ to $CD$, so the triangle $ABC$ to the triangle $ACD$.” Cf. note on **v. 16**, p. 165.
