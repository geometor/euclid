PROPOSITION 23.
===============

.. enunciation::

   Equiangular parallelograms have to one another the ratio compounded of the ratios of their sides.\ [#f1]_

Let :g:`$AC$ <0253.g1:< A C >>`, :g:`$CF$ <0253.g1:< C F >>` be equiangular parallelograms having the angle :g:`$BCD$ <0253.g1:< B C D )>` :eq:`equal <0253.g1:< B C D ) = 0253.g1:< E C G )>` to the angle :g:`$ECG$ <0253.g1:< E C G )>`;

I say that the parallelogram :g:`$AC$ <0253.g1:< A C >>` has to the parallelogram :g:`$CF$ <0253.g1:< C F >>` the ratio compounded of the ratios of the sides.\ [#f1]_

.. picture:: 0253.g1.svg
   :alt: Proposition 23 Diagram

For let them be placed so that :g:`$BC$ <0253.g1:/ B C />` is in a straight line with :g:`$CG$ <0253.g1:/ C G />`;

.. assertion::

   therefore :g:`$DC$ <0253.g1:/ D C />` is also in a straight line with :g:`$CE$ <0253.g1:/ C E />`.

Let the parallelogram :g:`$DG$ <0253.g1:< D G >>` be completed; let a straight line :g:`$K$ <0253.g1:K>` be set out, and let it be contrived that,\ [#f2]_

.. assertion::

   as :g:`$BC$ <0253.g1:/ B C />` is to :g:`$CG$ <0253.g1:/ C G />`, so is :g:`$K$ <0253.g1:K>` to :g:`$L$ <0253.g1:L>`,

.. assertion:: [VI. 12] <VI.12>

   and, as :g:`$DC$ <0253.g1:/ D C />` is to :g:`$CE$ <0253.g1:/ C E />`, so is :g:`$L$ <0253.g1:L>` to :g:`$M$ <0253.g1:M>`.

.. _folio-ii-0254:

.. folio:: 0254
   :page: 248

.. assertion::

   Then the ratios of :g:`$K$ <0253.g1:K>` to :g:`$L$ <0253.g1:L>` and of :g:`$L$ <0253.g1:L>` to :g:`$M$ <0253.g1:M>` are the same as the ratios of the sides, namely of :g:`$BC$ <0253.g1:/ B C />` to :g:`$CG$ <0253.g1:/ C G />` and of :g:`$DC$ <0253.g1:/ D C />` to :g:`$CE$ <0253.g1:/ C E />`.

.. subclause::

   But the ratio of :g:`$K$ <0253.g1:K>` to :g:`$M$ <0253.g1:M>` is compounded of the ratio of :g:`$K$ <0253.g1:K>` to :g:`$L$ <0253.g1:L>` and of that of :g:`$L$ <0253.g1:L>` to :g:`$M$ <0253.g1:M>`;

.. assertion::

   so that :g:`$K$ <0253.g1:K>` has also to :g:`$M$ <0253.g1:M>` the ratio compounded of the ratios of the sides.\ [#f1]_

.. subclause::

   Now since, as :g:`$BC$ <0253.g1:/ B C />` is to :g:`$CG$ <0253.g1:/ C G />`, so is the parallelogram :g:`$AC$ <0253.g1:< A C >>` to the parallelogram :g:`$CH$ <0253.g1:< C H >>`, :just:`[VI. 1] <VI.1>` while, as :g:`$BC$ <0253.g1:/ B C />` is to :g:`$CG$ <0253.g1:/ C G />`, so is :g:`$K$ <0253.g1:K>` to :g:`$L$ <0253.g1:L>`,

.. assertion:: [v. 11]

   therefore also, as :g:`$K$ <0253.g1:K>` is to :g:`$L$ <0253.g1:L>`, so is :g:`$AC$ <0253.g1:< A C >>` to :g:`$CH$ <0253.g1:< C H >>`.

.. subclause::

   Again, since, as :g:`$DC$ <0253.g1:/ D C />` is to :g:`$CE$ <0253.g1:/ C E />`, so is the parallelogram :g:`$CH$ <0253.g1:< C H >>` to :g:`$CF$ <0253.g1:< C F >>`, :just:`[VI. 1] <VI.1>` while, as :g:`$DC$ <0253.g1:/ D C />` is to :g:`$CE$ <0253.g1:/ C E />`, so is :g:`$L$ <0253.g1:L>` to :g:`$M$ <0253.g1:M>`,

.. assertion::

   therefore also, as :g:`$L$ <0253.g1:L>` is to :g:`$M$ <0253.g1:M>`, so is the parallelogram :g:`$CH$ <0253.g1:< C H >>` to the parallelogram :g:`$CF$ <0253.g1:< C F >>`. :just:`[v. 11]`

.. subclause::

   Since then it was proved that, as :g:`$K$ <0253.g1:K>` is to :g:`$L$ <0253.g1:L>`, so is the parallelogram :g:`$AC$ <0253.g1:< A C >>` to the parallelogram :g:`$CH$ <0253.g1:< C H >>`, and, as :g:`$L$ <0253.g1:L>` is to :g:`$M$ <0253.g1:M>`, so is the parallelogram :g:`$CH$ <0253.g1:< C H >>` to the parallelogram :g:`$CF$ <0253.g1:< C F >>`,

.. assertion::

   therefore, :term:`*ex aequali* <ex-aequali>`, as :g:`$K$ <0253.g1:K>` is to :g:`$M$ <0253.g1:M>`, so is :g:`$AC$ <0253.g1:< A C >>` to the parallelogram :g:`$CF$ <0253.g1:< C F >>`.

.. subclause::

   But :g:`$K$ <0253.g1:K>` has to :g:`$M$ <0253.g1:M>` the ratio compounded of the ratios of the sides;

.. assertion::

   therefore :g:`$AC$ <0253.g1:< A C >>` also has to :g:`$CF$ <0253.g1:< C F >>` the ratio compounded of the ratios of the sides.

.. qed::

   Therefore etc. :just:`Q. E. D.`

.. [#f1] **the ratio compounded of the ratios of the sides**, :term:`λόγον <ratio>` τὸν συγκείμενον ἐκ τῶν πλευρῶν which, meaning literally "the ratio compounded *of the sides*," is negligently written here and commonly for :term:`λόγον <ratio>` τὸν συγκείμενον ἐκ τῶν τῶν πλευρῶν (sc. :term:`λόγων <ratio>`).

.. [#f2] **let it be contrived that, as** :g:`$BC$ <0253.g1:/ B C />` **is to** :g:`$CG$ <0253.g1:/ C G />`, **so is** :g:`$K$ <0253.g1:K>` **to** :g:`$L$ <0253.g1:L>`. The Greek phrase is of the usual terse kind, untranslatable literally: καὶ γεγονέτω ὡς μὲν ἡ ΒΓ πρὸς τὴν ΓΗ, οὕτως ἡ Κ πρὸς τὸ Λ, the words meaning "and let (there) be made, as :g:`$BC$ <0253.g1:/ B C />` to :g:`$CG$ <0253.g1:/ C G />`, so :g:`$K$ <0253.g1:K>` to :g:`$L$ <0253.g1:L>`," where :g:`$L$ <0253.g1:L>` is the straight line which has to be constructed.
