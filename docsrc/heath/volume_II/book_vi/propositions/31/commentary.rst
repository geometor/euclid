Commentary on Proposition VI.31
===============================

Back to :ref:`Proposition VI.31 <VI.31>`.

.. folio:: 0275
   :page: 269

As we have seen (note on I. 47), this extension of I. 47 is credited by :person:`Proclus <proclus>` to Euclid personally.

There is one inference in the proof which requires examination. Euclid proves that

.. math::

   CB : BD = (\text{figure on } CB) : (\text{figure on } BA),

and that

.. math::

   BC : CD = (\text{figure on } BC) : (\text{figure on } CA),

and then infers directly that

.. math::

   BC : (BD + CD) = (\text{fig. on } BC) : (\text{sum of figs. on } BA \text{ and } AC).

Apparently V. 24 must be relied on as justifying this inference. But it is not directly applicable ; for what it proves is that, if

.. math::

   a : b = c : d,

and

.. math::

   e : b = f : d,

then

.. math::

   (a + e) : b = (c + f) : d.

Thus we should *invert* the first two proportions given above (by :person:`Simson <simson>`'s
Prop. B which, as we have seen, is a direct consequence of the definition of proportion), and thence infer by V. 24 that

.. _folio-ii-0276:

.. folio:: 0276
   :page: 270

.. container:: center

   (:g:`BD <0275.g1:/ B D />` + :g:`CD <0275.g1:/ C D />`) : :g:`BC <0275.g1:/ B C />` = (sum of figs. on :g:`BA <0275.g1:/ B A />`, :g:`AC <0275.g1:/ A C />`) : (fig. on :g:`BC <0275.g1:/ B C />`).

But :math:`BD + CD` is equal to :math:`BC`;
therefore (by :person:`Simson <simson>`'s Prop. A, which again is an immediate consequence of the definition of proportion) the sum of the figures on :math:`BA`, :g:`AC <0275.g1:/ A C />` is equal to the figure on :math:`BC`.

The MSS. again give an alternative proof which :person:`Heiberg <heiberg>` places in the Appendix. It first shows that the similar figures on the three sides have the same ratios to one another as the squares on the sides respectively. Whence, by using I. 47 and the same argument based on V. 24 as that explained above, the result is obtained.

If it is considered essential to have a proof which does not use :person:`Simson <simson>`'s Props. B and A or any proposition but those actually given by Euclid, no method occurs to me except the following.

Eucl. V. 22 proves that, if :math:`a, b, c` are three magnitudes, and :math:`d, e, f` three others, such that

.. math::

   a : b = d : e,

.. math::

   b : c = e : f,

then, :term:`*ex aequali* <ex-aequali>`,

.. math::

   a : c = d : f.

If now in addition

.. math::

   a : b = b : c,

so that, also,

.. math::

   d : e = e : f,

the ratio :math:`a : c` is duplicate of the ratio :math:`a : b`, and the ratio :math:`d : f` duplicate of the ratio :math:`d : e`, whence *the ratios which are duplicate of equal ratios are equal*.

Now (fig. on  AC) : (fig. on  :g:`AB <0275.g1:/ A B />`) = the ratio duplicate of  :g:`AC <0275.g1:/ A C />` : :g:`AB <0275.g1:/ A B />`

.. math::

   = \text{the ratio duplicate of } CD : DA

.. math::

   = CD : BD.

Hence (sum of figs. on  :g:`AC <0275.g1:/ A C />`, :g:`AB <0275.g1:/ A B />`) : (fig. on  :g:`AB <0275.g1:/ A B />`) = :g:`BC <0275.g1:/ B C />` : :g:`BD <0275.g1:/ B D />`. [V. 18]

But (fig. on  :g:`BC <0275.g1:/ B C />`) : (fig. on  :g:`AB <0275.g1:/ A B />`) = :g:`BC <0275.g1:/ B C />` : :g:`BD <0275.g1:/ B D />`
(as in Euclid's proof).

Therefore the sum of the figures on :g:`AC <0275.g1:/ A C />`, :g:`AB <0275.g1:/ A B />` has to the figure on :g:`AB <0275.g1:/ A B />` the same ratio as the figure on :g:`BC <0275.g1:/ B C />` has to the figure on :g:`AB <0275.g1:/ A B />`, whence
the figures on :g:`AC <0275.g1:/ A C />`, :g:`AB <0275.g1:/ A B />` are together equal to the figure on :g:`BC <0275.g1:/ B C />`. [V. 9]
