DEFINITIONS.
============

.. _VII.def.1:

1. An :term:`**unit** <unit>` is that by virtue of which each of the things that exist is called one.

.. _VII.def.2:

2. A :term:`**number** <number>` is a multitude composed of :term:`units <unit>`.

.. _VII.def.3:

3. A :term:`number <number>` is a :term:`**part** <part-aliquot>` of a number, the less of the greater, when it :term:`measures <part-aliquot>` the greater;

.. _VII.def.4:

4. but :term:`**parts** <parts-non-aliquot>` when it does not :term:`measure <part-aliquot>` it.

.. _VII.def.5:

5. The greater :term:`number <number>` is a :term:`**multiple** <multiple>` of the less when it is :term:`measured <part-aliquot>` by the less.

.. _VII.def.6:

6. An :term:`**even number** <even-number>` is that which is divisible into two equal parts.

.. _VII.def.7:

7. An :term:`**odd number** <odd-number>` is that which is not divisible into two equal parts, or that which differs by an :term:`unit <unit>` from an :term:`even number <even-number>`.

.. _VII.def.8:

8. An :term:`**even-times even number** <even-times-even-number>` is that which is :term:`measured <part-aliquot>` by an :term:`even number <even-number>` according to an even number.

.. _VII.def.9:

9. An :term:`**even-times odd number** <even-times-odd-number>` is that which is :term:`measured <part-aliquot>` by an :term:`even number <even-number>` according to an :term:`odd number <odd-number>`.

.. _VII.def.10:

10. An :term:`**odd-times odd number** <odd-times-odd-number>` is that which is :term:`measured <part-aliquot>` by an :term:`odd number <odd-number>` according to an odd number.

.. _folio-ii-0284:

.. folio:: 0284
   :page: 278

.. _VII.def.11:

11. A :term:`**prime number** <prime-number>` is that which is :term:`measured <part-aliquot>` by an :term:`unit <unit>` alone.

.. _VII.def.12:

12. :term:`**Numbers prime to one another** <prime-to-one-another>` are those which are :term:`measured <part-aliquot>` by an :term:`unit <unit>` alone as a common measure.

.. _VII.def.13:

13. A :term:`**composite number** <composite-number>` is that which is :term:`measured <part-aliquot>` by some :term:`number <number>`.

.. _VII.def.14:

14. :term:`**Numbers composite to one another** <composite-to-one-another>` are those which are :term:`measured <part-aliquot>` by some :term:`number <number>` as a common measure.

.. _VII.def.15:

15. A :term:`number <number>` is said to :term:`**multiply** <multiply>` a number when that which is multiplied is added to itself as many times as there are :term:`units <unit>` in the other, and thus some number is produced.

.. _VII.def.16:

16. And, when two :term:`numbers <number>` having :term:`multiplied <multiply>` one another make some number, the number so produced is called :term:`**plane** <plane-number>`, and its :term:`**sides** <side-of-number>` are the numbers which have multiplied one another.

.. _VII.def.17:

17. And, when three :term:`numbers <number>` having :term:`multiplied <multiply>` one another make some number, the number so produced is :term:`**solid** <solid-number>`, and its :term:`**sides** <side-of-number>` are the numbers which have multiplied one another.

.. _VII.def.18:

18. A :term:`**square number** <square-number>` is equal :term:`multiplied <multiply>` by equal, or a :term:`number <number>` which is contained by two equal numbers.

.. _VII.def.19:

19. And a :term:`**cube** <cube-number>` is equal :term:`multiplied <multiply>` by equal and again by equal, or a :term:`number <number>` which is contained by three equal numbers.

.. _VII.def.20:

20. **Numbers** are :term:`**proportional** <proportional>` when the first is the :term:`same multiple <multiple>`, or the :term:`same part <part-aliquot>`, or the :term:`same parts <parts-non-aliquot>`, of the second that the third is of the fourth.

.. _VII.def.21:

21. :term:`**Similar plane and solid numbers** <similar-plane-and-solid-numbers>` are those which have their sides :term:`proportional <proportional>`.

.. _VII.def.22:

22. A :term:`**perfect number** <perfect-number>` is that which is equal to its own parts.
