Commentary on Proposition VII.6
===============================

Back to :ref:`Proposition VII.6 <VII.6>`.

.. folio:: 0311
   :page: 305

If

$$a = \frac{m}{n}b, \text{ and } c = \frac{m}{n}d,$$

then

$$a + c = \frac{m}{n}(b + d).$$

More generally, if

$$a = \frac{m}{n}b,\ c = \frac{m}{n}d,\ e = \frac{m}{n}f, \dots$$

then

$$(a + c + e + g + \dots) = \frac{m}{n}(b + d + f + h + \dots).$$

.. _folio-ii-0312:

.. folio:: 0312
   :page: 306

In Euclid's proposition $m < n$, but the generality of the result is of course not affected. This proposition and the last are complementary to V. 1, which proves the corresponding result with *multiple* substituted for "*part*" or "*parts*."
