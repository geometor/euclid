PROPOSITION 15.
===============

.. enunciation::

   If an unit measure any number, and another number measure any other number the same number of times, alternately also, the unit will measure the third number the same number of times that the second measures the fourth.

.. _folio-ii-0321:

.. folio:: 0321
   :page: 315

For let the unit :g:`A <0321.g1:A>` measure any number :g:`BC <0321.g1:/ B C />`, and let another number :g:`D <0321.g1:D>` measure any other number :g:`EF <0321.g1:/ E F />` the same number of times;

I say that, alternately also, the unit :g:`A <0321.g1:A>` measures the number :g:`D <0321.g1:D>` the same number of times that :g:`BC <0321.g1:/ B C />` measures :g:`EF <0321.g1:/ E F />`.

.. picture:: 0321.g1.svg
   :alt: Proposition 15 Diagram

.. subclause::

   For, since the unit :g:`A <0321.g1:A>` measures the number :g:`BC <0321.g1:/ B C />` the same number of times that :g:`D <0321.g1:D>` measures :g:`EF <0321.g1:/ E F />`,

.. assertion::

   therefore, as many units as there are in :g:`BC <0321.g1:/ B C />`, so many numbers equal to :g:`D <0321.g1:D>` are there in :g:`EF <0321.g1:/ E F />` also.

Let :g:`BC <0321.g1:/ B C />` be divided into the units in it, :g:`BG <0321.g1:/ B G />`, :g:`GH <0321.g1:/ G H />`, :g:`HC <0321.g1:/ H C />`, and :g:`EF <0321.g1:/ E F />` into the numbers :g:`EK <0321.g1:/ E K />`, :g:`KL <0321.g1:/ K L />`, :g:`LF <0321.g1:/ L F />` :eq:`equal <0321.g1:/ E K / = 0321.g1:/ K L / = 0321.g1:/ L F / = 0321.g1:D>` to :g:`D <0321.g1:D>`.

.. assertion::

   Thus the multitude of :g:`BG <0321.g1:/ B G />`, :g:`GH <0321.g1:/ G H />`, :g:`HC <0321.g1:/ H C />` will be equal to the multitude of :g:`EK <0321.g1:/ E K />`, :g:`KL <0321.g1:/ K L />`, :g:`LF <0321.g1:/ L F />`.

.. subclause::

   And, since the units :g:`BG <0321.g1:/ B G />`, :g:`GH <0321.g1:/ G H />`, :g:`HC <0321.g1:/ H C />` are :eq:`equal <0321.g1:/ B G / = 0321.g1:/ G H / = 0321.g1:/ H C />` to one another, and the numbers :g:`EK <0321.g1:/ E K />`, :g:`KL <0321.g1:/ K L />`, :g:`LF <0321.g1:/ L F />` are also :eq:`equal <0321.g1:/ E K / = 0321.g1:/ K L / = 0321.g1:/ L F />` to one another, while the multitude of the units :g:`BG <0321.g1:/ B G />`, :g:`GH <0321.g1:/ G H />`, :g:`HC <0321.g1:/ H C />` is equal to the multitude of the numbers :g:`EK <0321.g1:/ E K />`, :g:`KL <0321.g1:/ K L />`, :g:`LF <0321.g1:/ L F />`,

.. assertion::

   therefore, as the unit :g:`BG <0321.g1:/ B G />` is to the number :g:`EK <0321.g1:/ E K />`, so will the unit :g:`GH <0321.g1:/ G H />` be to the number :g:`KL <0321.g1:/ K L />`, and the unit :g:`HC <0321.g1:/ H C />` to the number :g:`LF <0321.g1:/ L F />`.

.. assertion::

   Therefore also, as one of the antecedents is to one of the consequents, so will all the antecedents be to all the consequents; :just:`[VII. 12] <VII.12>` therefore, as the unit :g:`BG <0321.g1:/ B G />` is to the number :g:`EK <0321.g1:/ E K />`, so is :g:`BC <0321.g1:/ B C />` to :g:`EF <0321.g1:/ E F />`.

.. subclause::

   But the unit :g:`BG <0321.g1:/ B G />` is :eq:`equal <0321.g1:/ B G / = 0321.g1:A; 0321.g1:/ E K / = 0321.g1:D>` to the unit :g:`A <0321.g1:A>`, and the number :g:`EK <0321.g1:/ E K />` to the number :g:`D <0321.g1:D>`.

.. assertion::

   Therefore, as the unit :g:`A <0321.g1:A>` is to the number :g:`D <0321.g1:D>`, so is :g:`BC <0321.g1:/ B C />` to :g:`EF <0321.g1:/ E F />`.

.. assertion::

   Therefore the unit :g:`A <0321.g1:A>` measures the number :g:`D <0321.g1:D>` the same number of times that :g:`BC <0321.g1:/ B C />` measures :g:`EF <0321.g1:/ E F />`.

.. qed::

   :just:`Q. E. D.`
