Commentary on Proposition VII.28
================================

Back to :ref:`Proposition VII.28 <VII.28>`.

.. folio:: 0336
   :page: 330

If :math:`a`, :math:`b` are prime to one another, :math:`a + b` will be prime to both :math:`a` and :math:`b` ; and conversely.

For suppose :math:`(a + b)`, :math:`a` are not prime to one another. They must then have some common measure :math:`d`.

Therefore :math:`d` also divides the difference :math:`(a + b) - a`, or :math:`b`, as well as :math:`a` ; and therefore :math:`a`, :math:`b` are not prime to one another : which is contrary to the hypothesis.

.. math::

   \text{Therefore } a + b \text{ is prime to } a.

.. math::

   \text{Similarly } a + b \text{ is prime to } b.

The converse is proved in the same way.

:person:`Heiberg <heiberg>` remarks on Euclid's assumption that, if :math:`c` measures both :math:`a` and :math:`b`, it also measures :math:`a \pm b`. But it has already (VII. 1, 2) been assumed, more generally, as an axiom that, in the case supposed, :math:`c` measures :math:`a \pm pb`.
