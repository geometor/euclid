Commentary on Proposition VII.33
================================

Back to :ref:`Proposition VII.33 <VII.33>`.

.. folio:: 0341
   :page: 335

Given any numbers :math:`a, b, c, \dots`, to find the least numbers that are in the same ratio.

Euclid's method is the obvious one, and the result is verified by :term:`*reductio ad absurdum* <reductio-ad-absurdum>`.

We will, like Euclid, take three numbers only, :math:`a, b, c`.

Let :math:`g`, their greatest common measure, be found [VII. 3], and suppose that

.. math::

   a = mg, \text{ i.e. } gm, \quad \text{[VII. 16]}

.. math::

   b = ng, \text{ i.e. } gn,

.. math::

   c = pg, \text{ i.e. } gp.

It follows, by VII. Def. 20, that

.. math::

   m : n : p = a : b : c.

:math:`m, n, p` shall be the numbers required.

For, if not, let :math:`x, y, z` be the least numbers in the same ratio as :math:`a, b, c`, being less than :math:`m, n, p`.

Therefore

.. math::

   a = kx \text{ (or } xk \text{, VII. 16),}

.. math::

   b = ky \text{ (or } yk \text{),}

.. math::

   c = kz \text{ (or } zk \text{),} \quad \text{[VII. 20]}

where :math:`k` is some integer.

Thus

.. math::

   mg = a = xk.

Therefore

.. math::

   m : x = k : g. \quad \text{[VII. 19]}

And :math:`m > x`; therefore :math:`k > g`.

Since then :math:`k` measures :math:`a, b, c`, it follows that :math:`g` is not the greatest common measure: which contradicts the hypothesis.

Therefore etc.

It is to be observed that Euclid merely supposes that :math:`x, y, z` are smaller numbers than :math:`m, n, p` in the ratio of :math:`a, b, c`; but, in order to justify the next inference, which apparently can only depend on VII. 20, :math:`x, y, z` must also be assumed to be the *least* numbers in the ratio of :math:`a, b, c`.

The inference from the last proportion that, since :math:`m > x`, :math:`k > g` is supposed by :person:`Heiberg <heiberg>` to depend upon VII. 13 and V. 14 together. I prefer to regard Euclid as making the inference quite independently of Book V. E.g., the proportion could just as well be written

.. math::

   x : m = g : k,

when the definition of proportion in Book VII. (Def. 20) gives all that we want, since, whatever proper fraction :math:`x` is of :math:`m`, the same proper fraction is :math:`g` of :math:`k`.
