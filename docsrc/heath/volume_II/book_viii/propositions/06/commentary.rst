Commentary on Proposition VIII.6
================================

Back to :ref:`Proposition VIII.6 <VIII.6>`.

.. folio:: 0362
   :page: 356

Let :math:`a, b, c \dots k` be a geometrical progression in which :math:`a` does not measure :math:`b`.
Suppose, if possible, that :math:`a` measures some term of the series, as :math:`f`.
Take :math:`x, y, z, u, v, w` the *least* numbers in the ratio :math:`a, b, c, d, e, f`.
Since

.. math::

   x : y = a : b,

and :math:`a` does not measure :math:`b`,
:math:`x` does not measure :math:`y`; therefore :math:`x` cannot be unity.
And, :term:`*ex aequali* <ex-aequali>`,

.. math::

   x : w = a : f.

Now :math:`x`, :math:`w` are prime to one another. [VIII. 3]
Therefore :math:`a` does not measure :math:`f`.

We can of course prove that an intermediate term, as :math:`b`, does not measure a later term :math:`f` by using the series :math:`b, c, d, e, f` and remembering that, since :math:`b : c = a : b`, :math:`b` does not measure :math:`c`.
