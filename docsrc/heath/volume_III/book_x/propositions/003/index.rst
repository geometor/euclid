PROPOSITION 3.
==============

.. enunciation::

   Given two commensurable magnitudes, to find their greatest common measure.

Let the two given commensurable magnitudes be :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />` of which :g:`$AB$ <0024.g1:/ A B />` is the less ; thus it is required to find the greatest common measure of :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />`.

Now the magnitude :g:`$AB$ <0024.g1:/ A B />` either measures :g:`$CD$ <0024.g1:/ C D />` or it does not.

.. assertion::

   If then it measures it—and it measures itself also—:g:`$AB$ <0024.g1:/ A B />` is a common measure of :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />`.

.. assertion::

   And it is manifest that it is also the greatest ; for a greater magnitude than the magnitude :g:`$AB$ <0024.g1:/ A B />` will not measure :g:`$AB$ <0024.g1:/ A B />`.

.. picture:: 0024.g1.svg
   :alt: Book X, Proposition 3

Next, let :g:`$AB$ <0024.g1:/ A B />` not measure :g:`$CD$ <0024.g1:/ C D />`. Then, if the less be continually subtracted in turn from the greater, that which is left over will sometime measure the one before it, because :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />` are not incommensurable ; :just:`[cf. x. 2]` let :g:`$AB$ <0024.g1:/ A B />`, measuring :g:`$ED$ <0024.g1:/ E D />`, leave :g:`$EC$ <0024.g1:/ E C />` less than itself, let :g:`$EC$ <0024.g1:/ E C />`, measuring :g:`$FB$ <0024.g1:/ F B />`, leave :g:`$AF$ <0024.g1:/ A F />` less than itself, and let :g:`$AF$ <0024.g1:/ A F />` measure :g:`$CE$ <0024.g1:/ C E />`.

.. subclause::

   Since, then, :g:`$AF$ <0024.g1:/ A F />` measures :g:`$CE$ <0024.g1:/ C E />`, while :g:`$CE$ <0024.g1:/ C E />` measures :g:`$FB$ <0024.g1:/ F B />`,

.. assertion::

   therefore :g:`$AF$ <0024.g1:/ A F />` will also measure :g:`$FB$ <0024.g1:/ F B />`.

.. subclause::

   But it measures itself also ;

.. assertion::

   therefore :g:`$AF$ <0024.g1:/ A F />` will also measure the whole :g:`$AB$ <0024.g1:/ A B />`.

.. _folio-iii-0025:

.. folio:: 0025
   :page: 21

.. subclause::

   But :g:`$AB$ <0024.g1:/ A B />` measures :g:`$DE$ <0024.g1:/ D E />` ;

.. assertion::

   therefore :g:`$AF$ <0024.g1:/ A F />` will also measure :g:`$ED$ <0024.g1:/ E D />`.

.. subclause::

   But it measures :g:`$CE$ <0024.g1:/ C E />` also ;

.. assertion::

   therefore it also measures the whole :g:`$CD$ <0024.g1:/ C D />`.

.. assertion::

   Therefore :g:`$AF$ <0024.g1:/ A F />` is a common measure of :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />`.

I say next that it is also the greatest.

For, if not, there will be some magnitude greater than :g:`$AF$ <0024.g1:/ A F />` which will measure :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />`. Let it be :g:`$G$ <0024.g1:G>`.

.. subclause::

   Since then :g:`$G$ <0024.g1:G>` measures :g:`$AB$ <0024.g1:/ A B />`, while :g:`$AB$ <0024.g1:/ A B />` measures :g:`$ED$ <0024.g1:/ E D />`,

.. assertion::

   therefore :g:`$G$ <0024.g1:G>` will also measure :g:`$ED$ <0024.g1:/ E D />`.

.. subclause::

   But it measures the whole :g:`$CD$ <0024.g1:/ C D />` also ;

.. assertion::

   therefore :g:`$G$ <0024.g1:G>` will also measure the remainder :g:`$CE$ <0024.g1:/ C E />`.

.. subclause::

   But :g:`$CE$ <0024.g1:/ C E />` measures :g:`$FB$ <0024.g1:/ F B />` ;

.. assertion::

   therefore :g:`$G$ <0024.g1:G>` will also measure :g:`$FB$ <0024.g1:/ F B />`.

.. subclause::

   But it measures the whole :g:`$AB$ <0024.g1:/ A B />` also,

.. assertion::

   and it will therefore measure the remainder :g:`$AF$ <0024.g1:/ A F />`, the greater the less : which is impossible.

.. assertion::

   Therefore no magnitude greater than :g:`$AF$ <0024.g1:/ A F />` will measure :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />` ; therefore :g:`$AF$ <0024.g1:/ A F />` is the greatest common measure of :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />`.

.. qed::

   Therefore the greatest common measure of the two given commensurable magnitudes :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />` has been found. :just:`Q. E. D.`

.. assertion::

   PORISM. From this it is manifest that, if a magnitude measure two magnitudes, it will also measure their greatest common measure.
