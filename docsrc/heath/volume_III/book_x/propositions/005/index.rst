PROPOSITION 5.
==============

.. enunciation::

   Commensurable magnitudes have to one another the ratio which a number has to a number.

Let :g:`$A$ <0028.g1:A>`, :g:`$B$ <0028.g1:B>` be commensurable magnitudes; I say that :g:`$A$ <0028.g1:A>` has to :g:`$B$ <0028.g1:B>` the ratio which a number has to a number.

For, since :g:`$A$ <0028.g1:A>`, :g:`$B$ <0028.g1:B>` are commensurable, some magnitude will measure them. Let it measure them, and let it be :g:`$C$ <0028.g1:C>`.

.. picture:: 0028.g1.svg
   :alt: Proposition 5 diagram

And, as many times as :g:`$C$ <0028.g1:C>` measures :g:`$A$ <0028.g1:A>`, so many units let there be in :g:`$D$ <0028.g1:D>`; and, as many times as :g:`$C$ <0028.g1:C>` measures :g:`$B$ <0028.g1:B>`, so many units let there be in :g:`$E$ <0028.g1:E>`.

.. subclause::

   Since then :g:`$C$ <0028.g1:C>` measures :g:`$A$ <0028.g1:A>` according to the units in :g:`$D$ <0028.g1:D>`, while the unit also measures :g:`$D$ <0028.g1:D>` according to the units in it,

.. assertion::

   therefore the unit measures the number :g:`$D$ <0028.g1:D>` the same number of times as the magnitude :g:`$C$ <0028.g1:C>` measures :g:`$A$ <0028.g1:A>`;

.. assertion:: [VII. Def. 20] <VII.def.20>

   therefore, as :g:`$C$ <0028.g1:C>` is to :g:`$A$ <0028.g1:A>`, so is the unit to :g:`$D$ <0028.g1:D>`;

.. assertion::

   therefore, inversely, as :g:`$A$ <0028.g1:A>` is to :g:`$C$ <0028.g1:C>`, so is :g:`$D$ <0028.g1:D>` to the unit. :just:`[cf. V. 7, Por.]`

.. subclause::

   Again, since :g:`$C$ <0028.g1:C>` measures :g:`$B$ <0028.g1:B>` according to the units in :g:`$E$ <0028.g1:E>`, while the unit also measures :g:`$E$ <0028.g1:E>` according to the units in it,

.. _folio-iii-0029:

.. folio:: 0029
   :page: 25

.. assertion::

   therefore the unit measures :g:`$E$ <0028.g1:E>` the same number of times as :g:`$C$ <0028.g1:C>` measures :g:`$B$ <0028.g1:B>`;

.. assertion::

   therefore, as :g:`$C$ <0028.g1:C>` is to :g:`$B$ <0028.g1:B>`, so is the unit to :g:`$E$ <0028.g1:E>`.

.. subclause::

   But it was also proved that, as :g:`$A$ <0028.g1:A>` is to :g:`$C$ <0028.g1:C>`, so is :g:`$D$ <0028.g1:D>` to the unit;

.. assertion::

   therefore, :term:`*ex aequali* <ex-aequali>`, as :g:`$A$ <0028.g1:A>` is to :g:`$B$ <0028.g1:B>`, so is the number :g:`$D$ <0028.g1:D>` to :g:`$E$ <0028.g1:E>`. :just:`[V. 22] <V.22>`

.. qed::

   Therefore the commensurable magnitudes :g:`$A$ <0028.g1:A>`, :g:`$B$ <0028.g1:B>` have to one another the ratio which the number :g:`$D$ <0028.g1:D>` has to the number :g:`$E$ <0028.g1:E>`. :just:`Q. E. D.`
