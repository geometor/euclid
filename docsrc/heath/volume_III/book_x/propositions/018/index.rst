PROPOSITION 18.
===============

.. enunciation::

   If there be two unequal straight lines, and to the greater there be applied a parallelogram equal to the fourth part of the square on the less and deficient by a square figure, and if it divide it into parts which are incommensurable, the square on the greater will be greater than the square on the less by the square on a straight line incommensurable with the greater.

.. enunciation::

   And, if the square on the greater be greater than the square on the less by the square on a straight line incommensurable with the greater, and if there be applied to the greater a parallelogram equal to the fourth part of the square on the less and deficient by a square figure, it divides it into parts which are incommensurable.

Let :g:`$A$ <0049.g1:A>`, :g:`$BC$ <0049.g1:/ B C />` be two unequal straight lines, of which :g:`$BC$ <0049.g1:/ B C />` is the greater, and to :g:`$BC$ <0049.g1:/ B C />` let there be applied a parallelogram equal to the fourth part of the square on the less, :g:`$A$ <0049.g1:A>`, and deficient by a square figure. Let this be the rectangle :g:`$BD$ <0049.g1:/ B D />`, :g:`$DC$ <0049.g1:/ D C />`, :just:`[cf. Lemma before X. 17]` and let :g:`$BD$ <0049.g1:/ B D />` be incommensurable in length with :g:`$DC$ <0049.g1:/ D C />`; I say that the square on :g:`$BC$ <0049.g1:/ B C />` is greater than the square on :g:`$A$ <0049.g1:A>` by the square on a straight line incommensurable with :g:`$BC$ <0049.g1:/ B C />`.

.. picture:: 0049.g1.svg
   :alt: Proposition 18

For, with the same construction as before, we can prove similarly that the square on :g:`$BC$ <0049.g1:/ B C />` is greater than the square on :g:`$A$ <0049.g1:A>` by the square on :g:`$FD$ <0049.g1:/ F D />`.

It is to be proved that :g:`$BC$ <0049.g1:/ B C />` is incommensurable in length with :g:`$FD$ <0049.g1:/ F D />`.

.. folio:: 0050

.. subclause::

   Since :g:`$BD$ <0049.g1:/ B D />` is incommensurable in length with :g:`$DC$ <0049.g1:/ D C />`,

.. assertion:: [X. 16] <X.16>

   therefore :g:`$BC$ <0049.g1:/ B C />` is also incommensurable in length with :g:`$CD$ <0049.g1:/ C D />`.

.. subclause:: [X. 6] <X.6>

   But :g:`$DC$ <0049.g1:/ D C />` is commensurable with the sum of :g:`$BF$ <0049.g1:/ B F />`, :g:`$DC$ <0049.g1:/ D C />`;

.. assertion::

   therefore :g:`$BC$ <0049.g1:/ B C />` is also incommensurable with the sum of :g:`$BF$ <0049.g1:/ B F />`, :g:`$DC$ <0049.g1:/ D C />`; :just:`[X. 13] <X.13>` so that :g:`$BC$ <0049.g1:/ B C />` is also incommensurable in length with the remainder :g:`$FD$ <0049.g1:/ F D />`. :just:`[X. 16] <X.16>`

.. subclause::

   And the square on :g:`$BC$ <0049.g1:/ B C />` is greater than the square on :g:`$A$ <0049.g1:A>` by the square on :g:`$FD$ <0049.g1:/ F D />`;

.. assertion::

   therefore the square on :g:`$BC$ <0049.g1:/ B C />` is greater than the square on :g:`$A$ <0049.g1:A>` by the square on a straight line incommensurable with :g:`$BC$ <0049.g1:/ B C />`.

Again, let the square on :g:`$BC$ <0049.g1:/ B C />` be greater than the square on :g:`$A$ <0049.g1:A>` by the square on a straight line incommensurable with :g:`$BC$ <0049.g1:/ B C />`, and let there be applied to :g:`$BC$ <0049.g1:/ B C />` a parallelogram equal to the fourth part of the square on :g:`$A$ <0049.g1:A>` and deficient by a square figure. Let this be the rectangle :g:`$BD$ <0049.g1:/ B D />`, :g:`$DC$ <0049.g1:/ D C />`.

It is to be proved that :g:`$BD$ <0049.g1:/ B D />` is incommensurable in length with :g:`$DC$ <0049.g1:/ D C />`.

For, with the same construction, we can prove similarly that the square on :g:`$BC$ <0049.g1:/ B C />` is greater than the square on :g:`$A$ <0049.g1:A>` by the square on :g:`$FD$ <0049.g1:/ F D />`.

.. subclause::

   But the square on :g:`$BC$ <0049.g1:/ B C />` is greater than the square on :g:`$A$ <0049.g1:A>` by the square on a straight line incommensurable with :g:`$BC$ <0049.g1:/ B C />`;

.. assertion::

   therefore :g:`$BC$ <0049.g1:/ B C />` is incommensurable in length with :g:`$FD$ <0049.g1:/ F D />`, so that :g:`$BC$ <0049.g1:/ B C />` is also incommensurable with the remainder, the sum of :g:`$BF$ <0049.g1:/ B F />`, :g:`$DC$ <0049.g1:/ D C />`. :just:`[X. 16] <X.16>`

.. subclause::

   But the sum of :g:`$BF$ <0049.g1:/ B F />`, :g:`$DC$ <0049.g1:/ D C />` is commensurable in length with :g:`$DC$ <0049.g1:/ D C />`; :just:`[X. 6] <X.6>`

.. assertion::

   therefore :g:`$BC$ <0049.g1:/ B C />` is also incommensurable in length with :g:`$DC$ <0049.g1:/ D C />`, :just:`[X. 13] <X.13>` so that, :term:`*separando* <separando>`, :g:`$BD$ <0049.g1:/ B D />` is also incommensurable in length with :g:`$DC$ <0049.g1:/ D C />`. :just:`[X. 16] <X.16>`

.. qed::

   Therefore etc.
