PROPOSITION 37.
===============

.. enunciation::

   If two medial straight lines commensurable in square only and containing a rational rectangle be added together, the whole is irrational; and let it be called a :term:`**first bimedial straight line** <first-bimedial>`.

For let two medial straight lines :g:`$AB$ <0088.g1:/ A B />`, :g:`$BC$ <0088.g1:/ B C />` commensurable in square only and containing a rational rectangle be added together; I say that the whole :g:`$AC$ <0088.g1:/ A C />` is irrational.

.. picture:: 0088.g1.svg
   :alt: Proposition 37

.. subclause::

   For, since :g:`$AB$ <0088.g1:/ A B />` is incommensurable in length with :g:`$BC$ <0088.g1:/ B C />`,

.. assertion::

   therefore the squares on :g:`$AB$ <0088.g1:/ A B />`, :g:`$BC$ <0088.g1:/ B C />` are also incommensurable with twice the rectangle :g:`$AB$ <0088.g1:/ A B />`, :g:`$BC$ <0088.g1:/ B C />`; :just:`[cf. x. 36, ll. 9—20]`

.. _folio-iii-0089:

.. folio:: 0089
   :page: 85

.. assertion::

   and, :term:`*componendo* <componendo>`, the squares on :g:`$AB$ <0088.g1:/ A B />`, :g:`$BC$ <0088.g1:/ B C />` together with twice the rectangle :g:`$AB$ <0088.g1:/ A B />`, :g:`$BC$ <0088.g1:/ B C />`, that is, the square on :g:`$AC$ <0088.g1:/ A C />` :just:`[II. 4] <II.4>`, is incommensurable with the rectangle :g:`$AB$ <0088.g1:/ A B />`, :g:`$BC$ <0088.g1:/ B C />`. :just:`[x. 16]`

.. subclause::

   But the rectangle :g:`$AB$ <0088.g1:/ A B />`, :g:`$BC$ <0088.g1:/ B C />` is rational, for, by hypothesis, :g:`$AB$ <0088.g1:/ A B />`, :g:`$BC$ <0088.g1:/ B C />` are straight lines containing a rational rectangle;

.. assertion::

   therefore the square on :g:`$AC$ <0088.g1:/ A C />` is irrational; therefore :g:`$AC$ <0088.g1:/ A C />` is irrational. :just:`[x. Def. 4] <X.def.4>`

.. qed::

   And let it be called a :term:`**first bimedial** <first-bimedial>` straight line. :just:`Q. E. D.`
