PROPOSITION 43.
===============

.. enunciation::

   A first bimedial straight line is divided at one point only.

Let :g:`$AB$ <0098.g1:/ A B />` be a first bimedial straight line divided at :g:`$C$ <0098.g1:C>`, so that :g:`$AC$ <0098.g1:/ A C />`, :g:`$CB$ <0098.g1:/ C B />` are medial straight lines commensurable in square only and containing a rational rectangle; :just:`[X. 37] <X.37>`

.. picture:: 0098.g1.svg
   :alt: Proposition 43 diagram

I say that :g:`$AB$ <0098.g1:/ A B />` is not so divided at another point.

For, if possible, let it be divided at :g:`$D$ <0098.g1:D>` also, so that :g:`$AD$ <0098.g1:/ A D />`, :g:`$DB$ <0098.g1:/ D B />` are also medial straight lines commensurable in square only and containing a rational rectangle.

.. subclause::

   Since, then, that by which twice the rectangle :g:`$AD$ <0098.g1:/ A D />`, :g:`$DB$ <0098.g1:/ D B />` differs from twice the rectangle :g:`$AC$ <0098.g1:/ A C />`, :g:`$CB$ <0098.g1:/ C B />` is that by which the squares on :g:`$AC$ <0098.g1:/ A C />`, :g:`$CB$ <0098.g1:/ C B />` differ from the squares on :g:`$AD$ <0098.g1:/ A D />`, :g:`$DB$ <0098.g1:/ D B />`, while twice the rectangle :g:`$AD$ <0098.g1:/ A D />`, :g:`$DB$ <0098.g1:/ D B />` differs from twice the rectangle :g:`$AC$ <0098.g1:/ A C />`, :g:`$CB$ <0098.g1:/ C B />` by a rational area—for both are rational—

.. assertion::

   therefore the squares on :g:`$AC$ <0098.g1:/ A C />`, :g:`$CB$ <0098.g1:/ C B />` also differ from the squares on :g:`$AD$ <0098.g1:/ A D />`, :g:`$DB$ <0098.g1:/ D B />` by a rational area, though they are medial : which is absurd. :just:`[X. 26] <X.26>`

.. assertion::

   Therefore a first bimedial straight line is not divided into its terms at different points; therefore it is so divided at one point only.

In this case, with the same hypothesis, viz. that

$$x + y = x' + y',$$

and $x', y'$ are more nearly equal than $x, y$, we have as before

$$(x^2 + y^2) - (x'^2 + y'^2) = 2x'y' - 2xy.$$

But, from the given properties of $x, y$, and $x', y'$, it follows that $2xy, 2x'y'$ are *rational*, and $(x^2 + y^2), (x'^2 + y'^2)$ medial, areas.

Therefore the difference between two medial areas is rational : which is impossible. [x. 26]
