PROPOSITION 73.
===============

.. enunciation::

   If from a rational straight line there be subtracted a rational straight line commensurable with the whole in square only, the remainder is irrational ; and let it be called an :term:`**apotome** <apotome>`.

For from the rational straight line :g:`$AB$ <0162.g1:/ A B />` let the rational straight line :g:`$BC$ <0162.g1:/ B C />`, commensurable with the whole in square only, be subtracted ;

.. picture:: 0162.g1.svg
   :alt: Proposition 73

I say that the remainder :g:`$AC$ <0162.g1:/ A C />` is the irrational straight line called :term:`**apotome** <apotome>`.

.. subclause::

   For, since :g:`$AB$ <0162.g1:/ A B />` is incommensurable in length with :g:`$BC$ <0162.g1:/ B C />`, and, as :g:`$AB$ <0162.g1:/ A B />` is to :g:`$BC$ <0162.g1:/ B C />`, so is the square on :g:`$AB$ <0162.g1:/ A B />` to the rectangle :g:`$AB$ <0162.g1:/ A B />`, :g:`$BC$ <0162.g1:/ B C />`,

.. assertion::

   therefore the square on :g:`$AB$ <0162.g1:/ A B />` is incommensurable with the rectangle :g:`$AB$ <0162.g1:/ A B />`, :g:`$BC$ <0162.g1:/ B C />`. :just:`[X. 11] <X.11>`

.. subclause::

   But the squares on :g:`$AB$ <0162.g1:/ A B />`, :g:`$BC$ <0162.g1:/ B C />` are commensurable with the square on :g:`$AB$ <0162.g1:/ A B />`, :just:`[X. 15] <X.15>` and twice the rectangle :g:`$AB$ <0162.g1:/ A B />`, :g:`$BC$ <0162.g1:/ B C />` is commensurable with the rectangle :g:`$AB$ <0162.g1:/ A B />`, :g:`$BC$ <0162.g1:/ B C />`. :just:`[X. 6] <X.6>`

.. _folio-iii-0163:

.. folio:: 0163
   :page: 159

.. subclause::

   And, inasmuch as the squares on :g:`$AB$ <0162.g1:/ A B />`, :g:`$BC$ <0162.g1:/ B C />` are equal to twice the rectangle :g:`$AB$ <0162.g1:/ A B />`, :g:`$BC$ <0162.g1:/ B C />` together with the square on :g:`$CA$ <0162.g1:/ C A />`, :just:`[II. 7] <II.7>`

.. assertion::

   therefore the squares on :g:`$AB$ <0162.g1:/ A B />`, :g:`$BC$ <0162.g1:/ B C />` are also incommensurable with the remainder, the square on :g:`$AC$ <0162.g1:/ A C />`. :just:`[X. 13, 16]`

.. subclause::

   But the squares on :g:`$AB$ <0162.g1:/ A B />`, :g:`$BC$ <0162.g1:/ B C />` are rational;

.. assertion:: [X. Def. 4] <X.def.4>

   therefore :g:`$AC$ <0162.g1:/ A C />` is irrational.

.. qed::

   And let it be called an :term:`**apotome** <apotome>`. :just:`Q. E. D.`
