PROPOSITION 74.
===============

.. enunciation::

   If from a medial straight line there be subtracted a medial straight line which is commensurable with the whole in square only, and which contains with the whole a rational rectangle, the remainder is irrational. And let it be called a first apotome of a medial straight line.

.. _folio-iii-0164:

.. folio:: 0164
   :page: 160

For from the medial straight line :g:`AB <0164.g1:/ A B />` let there be subtracted the medial straight line :g:`BC <0164.g1:/ B C />` which is commensurable with :g:`AB <0164.g1:/ A B />` in square only and with :g:`AB <0164.g1:/ A B />` makes the rectangle :g:`AB <0164.g1:/ A B />`, :g:`BC <0164.g1:/ B C />` rational;

.. picture:: 0164.g1.svg
   :alt: Proposition 74

I say that the remainder :g:`AC <0164.g1:/ A C />` is irrational; and let it be called a first apotome of a medial straight line.

.. subclause::

   For, since :g:`AB <0164.g1:/ A B />`, :g:`BC <0164.g1:/ B C />` are medial,

.. assertion::

   the squares on :g:`AB <0164.g1:/ A B />`, :g:`BC <0164.g1:/ B C />` are also medial.

.. subclause::

   But twice the rectangle :g:`AB <0164.g1:/ A B />`, :g:`BC <0164.g1:/ B C />` is rational;

.. assertion::

   therefore the squares on :g:`AB <0164.g1:/ A B />`, :g:`BC <0164.g1:/ B C />` are incommensurable with twice the rectangle :g:`AB <0164.g1:/ A B />`, :g:`BC <0164.g1:/ B C />`;

.. assertion::

   therefore twice the rectangle :g:`AB <0164.g1:/ A B />`, :g:`BC <0164.g1:/ B C />` is also incommensurable with the remainder, the square on :g:`AC <0164.g1:/ A C />`, :just:`[cf. II. 7]` since, if the whole is incommensurable with one of the magnitudes, the original magnitudes will also be incommensurable. :just:`[X. 16] <X.16>`

.. subclause::

   But twice the rectangle :g:`AB <0164.g1:/ A B />`, :g:`BC <0164.g1:/ B C />` is rational;

.. assertion::

   therefore the square on :g:`AC <0164.g1:/ A C />` is irrational; therefore :g:`AC <0164.g1:/ A C />` is irrational. :just:`[X. Def. 4] <X.def.4>`

.. qed::

   And let it be called a :term:`**first apotome of a medial straight line** <first-apotome-of-a-medial-straight-line>`.
