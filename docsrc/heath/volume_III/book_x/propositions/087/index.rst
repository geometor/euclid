PROPOSITION 87.
===============

.. enunciation::

   To find the third apotome.

Let a rational straight line :g:`$A$ <0185.g1:A>` be set out, let three numbers :g:`$E$ <0185.g1:E>`, :g:`$BC$ <0185.g1:/ B C />`, :g:`$CD$ <0185.g1:/ C D />` be set out which have not to one another the ratio which a square number has to a square number, but let :g:`$CB$ <0185.g1:/ C B />` have to :g:`$BD$ <0185.g1:/ B D />` the ratio which a square number has to a square number.

.. picture:: 0185.g1.svg
   :alt: Proposition 87

Let it be contrived that, as :g:`$E$ <0185.g1:E>` is to :g:`$BC$ <0185.g1:/ B C />`, so is the square on :g:`$A$ <0185.g1:A>` to the square on :g:`$FG$ <0185.g1:/ F G />`,
and, as :g:`$BC$ <0185.g1:/ B C />` is to :g:`$CD$ <0185.g1:/ C D />`, so is the square on :g:`$FG$ <0185.g1:/ F G />` to the square on :g:`$GH$ <0185.g1:/ G H />`. :just:`[X. 6, Por.]`

.. _folio-iii-0186:

.. folio:: 0186
   :page: 182

.. subclause::

   Since then, as :g:`$E$ <0185.g1:E>` is to :g:`$BC$ <0185.g1:/ B C />`, so is the square on :g:`$A$ <0185.g1:A>` to the square on :g:`$FG$ <0185.g1:/ F G />`,

.. assertion::

   therefore the square on :g:`$A$ <0185.g1:A>` is commensurable with the square on :g:`$FG$ <0185.g1:/ F G />`. :just:`[X. 6] <X.6>`

.. subclause::

   But the square on :g:`$A$ <0185.g1:A>` is rational ;

.. assertion::

   therefore the square on :g:`$FG$ <0185.g1:/ F G />` is also rational ; therefore :g:`$FG$ <0185.g1:/ F G />` is rational.

.. subclause::

   And, since :g:`$E$ <0185.g1:E>` has not to :g:`$BC$ <0185.g1:/ B C />` the ratio which a square number has to a square number,

.. assertion::

   therefore neither has the square on :g:`$A$ <0185.g1:A>` to the square on :g:`$FG$ <0185.g1:/ F G />` the ratio which a square number has to a square number ; therefore :g:`$A$ <0185.g1:A>` is incommensurable in length with :g:`$FG$ <0185.g1:/ F G />`. :just:`[X. 9] <X.9>`

.. subclause::

   Again, since, as :g:`$BC$ <0185.g1:/ B C />` is to :g:`$CD$ <0185.g1:/ C D />`, so is the square on :g:`$FG$ <0185.g1:/ F G />` to the square on :g:`$GH$ <0185.g1:/ G H />`,

.. assertion::

   therefore the square on :g:`$FG$ <0185.g1:/ F G />` is commensurable with the square on :g:`$GH$ <0185.g1:/ G H />`. :just:`[X. 6] <X.6>`

.. subclause::

   But the square on :g:`$FG$ <0185.g1:/ F G />` is rational ;

.. assertion::

   therefore the square on :g:`$GH$ <0185.g1:/ G H />` is also rational ; therefore :g:`$GH$ <0185.g1:/ G H />` is rational.

.. subclause::

   And, since :g:`$BC$ <0185.g1:/ B C />` has not to :g:`$CD$ <0185.g1:/ C D />` the ratio which a square number has to a square number,

.. assertion::

   therefore neither has the square on :g:`$FG$ <0185.g1:/ F G />` to the square on :g:`$GH$ <0185.g1:/ G H />` the ratio which a square number has to a square number ; therefore :g:`$FG$ <0185.g1:/ F G />` is incommensurable in length with :g:`$GH$ <0185.g1:/ G H />`. :just:`[X. 9] <X.9>`

.. subclause::

   And both are rational ;

.. assertion::

   therefore :g:`$FG$ <0185.g1:/ F G />`, :g:`$GH$ <0185.g1:/ G H />` are rational straight lines commensurable in square only ; therefore :g:`$FH$ <0185.g1:/ F H />` is an apotome. :just:`[X. 73] <X.73>`

I say next that it is also a third apotome.

.. subclause::

   For since, as :g:`$E$ <0185.g1:E>` is to :g:`$BC$ <0185.g1:/ B C />`, so is the square on :g:`$A$ <0185.g1:A>` to the square on :g:`$FG$ <0185.g1:/ F G />`, and, as :g:`$BC$ <0185.g1:/ B C />` is to :g:`$CD$ <0185.g1:/ C D />`, so is the square on :g:`$FG$ <0185.g1:/ F G />` to the square on :g:`$HG$ <0185.g1:/ H G />`,

.. assertion::

   therefore, :term:`*ex aequali* <ex-aequali>`, as :g:`$E$ <0185.g1:E>` is to :g:`$CD$ <0185.g1:/ C D />`, so is the square on :g:`$A$ <0185.g1:A>` to the square on :g:`$HG$ <0185.g1:/ H G />`. :just:`[V. 22] <V.22>`

.. _folio-iii-0187:

.. folio:: 0187
   :page: 183

.. subclause::

   But :g:`$E$ <0185.g1:E>` has not to :g:`$CD$ <0185.g1:/ C D />` the ratio which a square number has to a square number ;

.. assertion::

   therefore neither has the square on :g:`$A$ <0185.g1:A>` to the square on :g:`$GH$ <0185.g1:/ G H />` the ratio which a square number has to a square number ; therefore :g:`$A$ <0185.g1:A>` is incommensurable in length with :g:`$GH$ <0185.g1:/ G H />`. :just:`[X. 9] <X.9>`

.. assertion::

   Therefore neither of the straight lines :g:`$FG$ <0185.g1:/ F G />`, :g:`$GH$ <0185.g1:/ G H />` is commensurable in length with the rational straight line :g:`$A$ <0185.g1:A>` set out.

Now let the square on :g:`$K$ <0185.g1:K>` be that by which the square on :g:`$FG$ <0185.g1:/ F G />` is greater than the square on :g:`$GH$ <0185.g1:/ G H />`.

.. subclause::

   Since then, as :g:`$BC$ <0185.g1:/ B C />` is to :g:`$CD$ <0185.g1:/ C D />`, so is the square on :g:`$FG$ <0185.g1:/ F G />` to the square on :g:`$GH$ <0185.g1:/ G H />`,

.. assertion::

   therefore, :term:`*convertendo* <convertendo>`, as :g:`$BC$ <0185.g1:/ B C />` is to :g:`$BD$ <0185.g1:/ B D />`, so is the square on :g:`$FG$ <0185.g1:/ F G />` to the square on :g:`$K$ <0185.g1:K>`. :just:`[V. 19, Por.]`

.. subclause::

   But :g:`$BC$ <0185.g1:/ B C />` has to :g:`$BD$ <0185.g1:/ B D />` the ratio which a square number has to a square number ;

.. assertion::

   therefore the square on :g:`$FG$ <0185.g1:/ F G />` also has to the square on :g:`$K$ <0185.g1:K>` the ratio which a square number has to a square number.

.. assertion::

   Therefore :g:`$FG$ <0185.g1:/ F G />` is commensurable in length with :g:`$K$ <0185.g1:K>`, :just:`[X. 9] <X.9>` and the square on :g:`$FG$ <0185.g1:/ F G />` is greater than the square on :g:`$GH$ <0185.g1:/ G H />` by the square on a straight line commensurable with :g:`$FG$ <0185.g1:/ F G />`.

.. subclause::

   And neither of the straight lines :g:`$FG$ <0185.g1:/ F G />`, :g:`$GH$ <0185.g1:/ G H />` is commensurable in length with the rational straight line :g:`$A$ <0185.g1:A>` set out ;

.. assertion:: [X. Deff. III. 3]

   therefore :g:`$FH$ <0185.g1:/ F H />` is a third apotome.

.. qed::

   Therefore the third apotome :g:`$FH$ <0185.g1:/ F H />` has been found. :just:`Q. E. D.`
