PROPOSITION 34.
===============

.. enunciation::

   In equal parallelepipedal solids the bases are reciprocally proportional to the heights; and those parallelepipedal solids in which the bases are reciprocally proportional to the heights are equal.

Let :g:`$AB$ <0350.g1:< A B >>`, :g:`$CD$ <0350.g1:< C D >>` be equal parallelepipedal solids; I say that in the parallelepipedal solids :g:`$AB$ <0350.g1:< A B >>`, :g:`$CD$ <0350.g1:< C D >>` the bases are reciprocally proportional to the heights, that is, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so is the height of the solid :g:`$CD$ <0350.g1:< C D >>` to the height of the solid :g:`$AB$ <0350.g1:< A B >>`.

First, let the sides which stand up, namely :g:`$AG$ <0350.g1:/ A G />`, :g:`$EF$ <0350.g1:/ E F />`, :g:`$LB$ <0350.g1:/ L B />`, :g:`$HK$ <0350.g1:/ H K />`, :g:`$CM$ <0350.g1:/ C M />`, :g:`$NO$ <0350.g1:/ N O />`, :g:`$PD$ <0350.g1:/ P D />`, :g:`$QR$ <0350.g1:/ Q R />`, be at right angles to their bases; I say that, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so is :g:`$CM$ <0350.g1:/ C M />` to :g:`$AG$ <0350.g1:/ A G />`.

.. subclause::

   If now the base :g:`$EH$ <0350.g1:< E H >>` is equal to the base :g:`$NQ$ <0350.g1:< N Q >>`, while the solid :g:`$AB$ <0350.g1:< A B >>` is also equal to the solid :g:`$CD$ <0350.g1:< C D >>`,

.. assertion::

   :g:`$CM$ <0350.g1:/ C M />` will also be equal to :g:`$AG$ <0350.g1:/ A G />`.

.. folio:: 0350

.. assertion::

   For parallelepipedal solids of the same height are to one another as the bases; :just:`[XI. 32] <XI.32>` and, as the base :g:`$EH$ <0350.g1:< E H >>` is to :g:`$NQ$ <0350.g1:< N Q >>`, so will :g:`$CM$ <0350.g1:/ C M />` be to :g:`$AG$ <0350.g1:/ A G />`, and it is manifest that in the parallelepipedal solids :g:`$AB$ <0350.g1:< A B >>`, :g:`$CD$ <0350.g1:< C D >>` the bases are reciprocally proportional to the heights.

Next, let the base :g:`$EH$ <0350.g1:< E H >>` not be equal to the base :g:`$NQ$ <0350.g1:< N Q >>`, but let :g:`$EH$ <0350.g1:< E H >>` be greater.

.. picture:: 0350.g1.svg
   :alt: Proposition 34, Diagram 1

.. subclause::

   Now the solid :g:`$AB$ <0350.g1:< A B >>` is equal to the solid :g:`$CD$ <0350.g1:< C D >>`;

.. assertion::

   therefore :g:`$CM$ <0350.g1:/ C M />` is also greater than :g:`$AG$ <0350.g1:/ A G />`.

Let then :g:`$CT$ <0350.g1:/ C T />` be made equal to :g:`$AG$ <0350.g1:/ A G />`, and let the parallelepipedal solid :g:`$VC$ <0350.g1:< V C >>` be completed on :g:`$NQ$ <0350.g1:< N Q >>` as base and with :g:`$CT$ <0350.g1:/ C T />` as height.

.. subclause::

   Now, since the solid :g:`$AB$ <0350.g1:< A B >>` is equal to the solid :g:`$CD$ <0350.g1:< C D >>`, and :g:`$CV$ <0350.g1:< C V >>` is outside them, while equals have to the same the same ratio, :just:`[V. 7] <V.7>`

.. assertion::

   therefore, as the solid :g:`$AB$ <0350.g1:< A B >>` is to the solid :g:`$CV$ <0350.g1:< C V >>`, so is the solid :g:`$CD$ <0350.g1:< C D >>` to the solid :g:`$CV$ <0350.g1:< C V >>`.

.. subclause::

   But, as the solid :g:`$AB$ <0350.g1:< A B >>` is to the solid :g:`$CV$ <0350.g1:< C V >>`, so is the base :g:`$EH$ <0350.g1:< E H >>` to the base :g:`$NQ$ <0350.g1:< N Q >>`, for the solids :g:`$AB$ <0350.g1:< A B >>`, :g:`$CV$ <0350.g1:< C V >>` are of equal height; :just:`[XI. 32] <XI.32>` and, as the solid :g:`$CD$ <0350.g1:< C D >>` is to the solid :g:`$CV$ <0350.g1:< C V >>`, so is the base :g:`$MQ$ <0350.g1:< M Q >>` to the base :g:`$TQ$ <0350.g1:< T Q >>` :just:`[XI. 25] <XI.25>` and :g:`$CM$ <0350.g1:/ C M />` to :g:`$CT$ <0350.g1:/ C T />` :just:`[VI. 1] <VI.1>`;

.. assertion::

   therefore also, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so is :g:`$MC$ <0350.g1:/ M C />` to :g:`$CT$ <0350.g1:/ C T />`.

.. subclause::

   But :g:`$CT$ <0350.g1:/ C T />` is equal to :g:`$AG$ <0350.g1:/ A G />`;

.. assertion::

   therefore also, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so is :g:`$MC$ <0350.g1:/ M C />` to :g:`$AG$ <0350.g1:/ A G />`.

.. assertion::

   Therefore in the parallelepipedal solids :g:`$AB$ <0350.g1:< A B >>`, :g:`$CD$ <0350.g1:< C D >>` the bases are reciprocally proportional to the heights.

Again, in the parallelepipedal solids :g:`$AB$ <0350.g1:< A B >>`, :g:`$CD$ <0350.g1:< C D >>` let the bases be reciprocally proportional to the heights, that is, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so let the height of the solid :g:`$CD$ <0350.g1:< C D >>` be to the height of the solid :g:`$AB$ <0350.g1:< A B >>`; I say that the solid :g:`$AB$ <0350.g1:< A B >>` is equal to the solid :g:`$CD$ <0350.g1:< C D >>`.

Let the sides which stand up be again at right angles to the bases.

.. subclause::

   Now, if the base :g:`$EH$ <0350.g1:< E H >>` is equal to the base :g:`$NQ$ <0350.g1:< N Q >>`, and, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so is the height of the solid :g:`$CD$ <0350.g1:< C D >>` to the height of the solid :g:`$AB$ <0350.g1:< A B >>`,

.. assertion::

   therefore the height of the solid :g:`$CD$ <0350.g1:< C D >>` is also equal to the height of the solid :g:`$AB$ <0350.g1:< A B >>`.

.. subclause::

   But parallelepipedal solids on equal bases and of the same height are equal to one another; :just:`[XI. 31] <XI.31>`

.. assertion::

   therefore the solid :g:`$AB$ <0350.g1:< A B >>` is equal to the solid :g:`$CD$ <0350.g1:< C D >>`.

.. subclause::

   Next, let the base :g:`$EH$ <0350.g1:< E H >>` not be equal to the base :g:`$NQ$ <0350.g1:< N Q >>`, but let :g:`$EH$ <0350.g1:< E H >>` be greater;

.. assertion::

   therefore the height of the solid :g:`$CD$ <0350.g1:< C D >>` is also greater than the height of the solid :g:`$AB$ <0350.g1:< A B >>`, that is, :g:`$CM$ <0350.g1:/ C M />` is greater than :g:`$AG$ <0350.g1:/ A G />`.

Let :g:`$CT$ <0350.g1:/ C T />` be again made equal to :g:`$AG$ <0350.g1:/ A G />`, and let the solid :g:`$CV$ <0350.g1:< C V >>` be similarly completed.

.. subclause::

   Since, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so is :g:`$MC$ <0350.g1:/ M C />` to :g:`$AG$ <0350.g1:/ A G />`, while :g:`$AG$ <0350.g1:/ A G />` is equal to :g:`$CT$ <0350.g1:/ C T />`,

.. assertion::

   therefore, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so is :g:`$CM$ <0350.g1:/ C M />` to :g:`$CT$ <0350.g1:/ C T />`.

.. subclause::

   But, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so is the solid :g:`$AB$ <0350.g1:< A B >>` to the solid :g:`$CV$ <0350.g1:< C V >>`, for the solids :g:`$AB$ <0350.g1:< A B >>`, :g:`$CV$ <0350.g1:< C V >>` are of equal height; :just:`[XI. 32] <XI.32>` and, as :g:`$CM$ <0350.g1:/ C M />` is to :g:`$CT$ <0350.g1:/ C T />`, so is the base :g:`$MQ$ <0350.g1:< M Q >>` to the base :g:`$QT$ <0350.g1:< Q T >>` :just:`[VI. 1] <VI.1>` and the solid :g:`$CD$ <0350.g1:< C D >>` to the solid :g:`$CV$ <0350.g1:< C V >>`. :just:`[XI. 25] <XI.25>`

.. assertion::

   Therefore also, as the solid :g:`$AB$ <0350.g1:< A B >>` is to the solid :g:`$CV$ <0350.g1:< C V >>`, so is the solid :g:`$CD$ <0350.g1:< C D >>` to the solid :g:`$CV$ <0350.g1:< C V >>`; therefore each of the solids :g:`$AB$ <0350.g1:< A B >>`, :g:`$CD$ <0350.g1:< C D >>` has to :g:`$CV$ <0350.g1:< C V >>` the same ratio.

.. assertion:: [V. 9] <V.9>

   Therefore the solid :g:`$AB$ <0352.g1:< A B >>` is equal to the solid :g:`$CD$ <0352.g1:< C D >>`.

Now let the sides which stand up, :g:`$FE$ <0352.g1:/ F E />`, :g:`$BL$ <0352.g1:/ B L />`, :g:`$GA$ <0352.g1:/ G A />`, :g:`$HK$ <0352.g1:/ H K />`, :g:`$ON$ <0352.g1:/ O N />`, :g:`$DP$ <0352.g1:/ D P />`, :g:`$MC$ <0352.g1:/ M C />`, :g:`$RQ$ <0352.g1:/ R Q />`, not be at right angles to their bases; let perpendiculars be drawn from the points :g:`$F$ <0352.g1:F>`, :g:`$G$ <0352.g1:G>`, :g:`$B$ <0352.g1:B>`, :g:`$K$ <0352.g1:K>`, :g:`$O$ <0352.g1:O>`, :g:`$M$ <0352.g1:M>`, :g:`$D$ <0352.g1:D>`, :g:`$R$ <0352.g1:R>` to the planes through :g:`$EH$ <0352.g1:< E H >>`, :g:`$NQ$ <0352.g1:< N Q >>`, and let them meet the planes at :g:`$S$ <0352.g1:S>`, :g:`$T$ <0352.g1:T>`, :g:`$U$ <0352.g1:U>`, :g:`$V$ <0352.g1:V>`, :g:`$W$ <0352.g1:W>`, :g:`$X$ <0352.g1:X>`, :g:`$Y$ <0352.g1:Y>`, :g:`$a$ <0352.g1:a>`, and let the solids :g:`$FV$ <0352.g1:< F V >>`, :g:`$Oa$ <0352.g1:< O a >>` be completed; I say that, in this case too, if the solids :g:`$AB$ <0352.g1:< A B >>`, :g:`$CD$ <0352.g1:< C D >>` are equal, the bases are reciprocally proportional to the heights, that is, as the base :g:`$EH$ <0352.g1:< E H >>` is to the base :g:`$NQ$ <0352.g1:< N Q >>`, so is the height of the solid :g:`$CD$ <0352.g1:< C D >>` to the height of the solid :g:`$AB$ <0352.g1:< A B >>`.

.. picture:: 0352.g1.svg
   :alt: Proposition 34, Diagram 2

.. subclause::

   Since the solid :g:`$AB$ <0352.g1:< A B >>` is equal to the solid :g:`$CD$ <0352.g1:< C D >>`, while :g:`$AB$ <0352.g1:< A B >>` is equal to :g:`$BT$ <0352.g1:< B T >>`, for they are on the same base :g:`$FK$ <0352.g1:< F K >>` and of the same height; :just:`[XI. 29, 30]` and the solid :g:`$CD$ <0352.g1:< C D >>` is equal to :g:`$DX$ <0352.g1:< D X >>`, for they are again on the same base :g:`$RO$ <0352.g1:< R O >>` and of the same height; :just:`[id.]`

.. assertion::

   therefore the solid :g:`$BT$ <0352.g1:< B T >>` is also equal to the solid :g:`$DX$ <0352.g1:< D X >>`.

.. assertion::

   Therefore, as the base :g:`$FK$ <0352.g1:< F K >>` is to the base :g:`$OR$ <0352.g1:< O R >>`, so is the height of the solid :g:`$DX$ <0352.g1:< D X >>` to the height of the solid :g:`$BT$ <0352.g1:< B T >>`. :just:`[Part 1.]`

.. subclause::

   But the base :g:`$FK$ <0352.g1:< F K >>` is equal to the base :g:`$EH$ <0352.g1:< E H >>`, and the base :g:`$OR$ <0352.g1:< O R >>` to the base :g:`$NQ$ <0352.g1:< N Q >>`;

.. assertion::

   therefore, as the base :g:`$EH$ <0352.g1:< E H >>` is to the base :g:`$NQ$ <0352.g1:< N Q >>`, so is the height of the solid :g:`$DX$ <0352.g1:< D X >>` to the height of the solid :g:`$BT$ <0352.g1:< B T >>`.

.. subclause::

   But the solids :g:`$DX$ <0352.g1:< D X >>`, :g:`$BT$ <0352.g1:< B T >>` and the solids :g:`$DC$ <0352.g1:< D C >>`, :g:`$BA$ <0352.g1:< B A >>` have the same heights respectively;

.. assertion::

   therefore, as the base :g:`$EH$ <0352.g1:< E H >>` is to the base :g:`$NQ$ <0352.g1:< N Q >>`, so is the height of the solid :g:`$DC$ <0352.g1:< D C >>` to the height of the solid :g:`$AB$ <0352.g1:< A B >>`.

.. assertion::

   Therefore in the parallelepipedal solids :g:`$AB$ <0352.g1:< A B >>`, :g:`$CD$ <0352.g1:< C D >>` the bases are reciprocally proportional to the heights.

Again, in the parallelepipedal solids :g:`$AB$ <0352.g1:< A B >>`, :g:`$CD$ <0352.g1:< C D >>` let the bases be reciprocally proportional to the heights, that is, as the base :g:`$EH$ <0352.g1:< E H >>` is to the base :g:`$NQ$ <0352.g1:< N Q >>`, so let the height of the solid :g:`$CD$ <0352.g1:< C D >>` be to the height of the solid :g:`$AB$ <0352.g1:< A B >>`; I say that the solid :g:`$AB$ <0352.g1:< A B >>` is equal to the solid :g:`$CD$ <0352.g1:< C D >>`.

.. subclause::

   For, with the same construction, since, as the base :g:`$EH$ <0352.g1:< E H >>` is to the base :g:`$NQ$ <0352.g1:< N Q >>`, so is the height of the solid :g:`$CD$ <0352.g1:< C D >>` to the height of the solid :g:`$AB$ <0352.g1:< A B >>`, while the base :g:`$EH$ <0352.g1:< E H >>` is equal to the base :g:`$FK$ <0352.g1:< F K >>`, and :g:`$NQ$ <0352.g1:< N Q >>` to :g:`$OR$ <0352.g1:< O R >>`,

.. assertion::

   therefore, as the base :g:`$FK$ <0352.g1:< F K >>` is to the base :g:`$OR$ <0352.g1:< O R >>`, so is the height of the solid :g:`$CD$ <0352.g1:< C D >>` to the height of the solid :g:`$AB$ <0352.g1:< A B >>`.

.. subclause::

   But the solids :g:`$AB$ <0352.g1:< A B >>`, :g:`$CD$ <0352.g1:< C D >>` and :g:`$BT$ <0352.g1:< B T >>`, :g:`$DX$ <0352.g1:< D X >>` have the same heights respectively;

.. assertion::

   therefore, as the base :g:`$FK$ <0352.g1:< F K >>` is to the base :g:`$OR$ <0352.g1:< O R >>`, so is the height of the solid :g:`$DX$ <0352.g1:< D X >>` to the height of the solid :g:`$BT$ <0352.g1:< B T >>`.

.. assertion::

   Therefore in the parallelepipedal solids :g:`$BT$ <0352.g1:< B T >>`, :g:`$DX$ <0352.g1:< D X >>` the bases are reciprocally proportional to the heights; therefore the solid :g:`$BT$ <0352.g1:< B T >>` is equal to the solid :g:`$DX$ <0352.g1:< D X >>`. :just:`[Part 1.]`

.. subclause::

   But :g:`$BT$ <0352.g1:< B T >>` is equal to :g:`$BA$ <0352.g1:< B A >>`, for they are on the same base :g:`$FK$ <0352.g1:< F K >>` and of the same height; :just:`[XI. 29, 30]` and the solid :g:`$DX$ <0352.g1:< D X >>` is equal to the solid :g:`$DC$ <0352.g1:< D C >>`. :just:`[id.]`

.. qed::

   Therefore the solid :g:`$AB$ <0352.g1:< A B >>` is also equal to the solid :g:`$CD$ <0352.g1:< C D >>`. :just:`Q. E. D.`
