Commentary on Proposition XII.18
================================

Back to :ref:`Proposition XII.18 <XII.18>`.

.. folio:: 0440
   :page: 436

It is the method of this proposition which :person:`Legendre <legendre>` adopted for his proof of XII. 2 (see note on that proposition).

The argument can be put very shortly. We will suppose :math:`S, S'` to be the volumes of the spheres, and :math:`d, d'` to be their diameters; and we will for brevity express the triplicate ratio of :math:`d` to :math:`d'` by :math:`d^3 : d'^3`.

If

.. math::

   d^3 : d'^3 \ne S : S',

then

.. math::

   d^3 : d'^3 = S : T,

where :math:`T` is the volume of some sphere either greater or less than :math:`S'`.

I. Suppose, if possible, that :math:`T < S'`.

Let :math:`T` be supposed concentric with :math:`S'`.

As in XII. 17, inscribe a polyhedron in :math:`S'` such that its faces do not anywhere touch :math:`T`; and inscribe in :math:`S` a polyhedron similar to that in :math:`S'`.

.. _folio-iii-0441:

.. folio:: 0441
   :page: 437

Then :math:`S : T = d^3 : d'^3` :math:`= (\text{polyhedron in } S) : (\text{polyhedron in } S');` or, alternately, :math:`S : (\text{polyhedron in } S) = T : (\text{polyhedron in } S').`

And :math:`S > (\text{polyhedron in } S);` therefore :math:`T > (\text{polyhedron in } S').`

But, by construction, :math:`T < (\text{polyhedron in } S'):` which is impossible.

Therefore :math:`T \not< S'`.

II. Suppose, if possible, that :math:`T > S'`.

Now :math:`d^3 : d'^3 = S : T` :math:`= X : S'`, where :math:`X` is the volume of some sphere less than :math:`S`, :just:`[XII. 2, Lemma]` or, inversely, :math:`d'^3 : d^3 = S' : X`, where :math:`X < S`.

This is proved impossible exactly as in Part I.

Therefore :math:`T \not> S'`.

Hence :math:`T`, not being greater or less than :math:`S'`, is equal to it, and :math:`d^3 : d'^3 = S : S'`.
