We have

.. container:: center

   (sq. :g:`DH <0452.g1:< D H >>`) = (sq. :g:`HC <0452.g1:< H C >>`) = (rect. :g:`CE <0452.g1:< C E >>`), by hypothesis, = (rect. :g:`HE <0452.g1:< H E >>`).

Add to each side the rectangle :g:`AK <0452.g1:< A K >>`, and

.. container:: center

   (rect. :g:`DK <0452.g1:< D K >>`) = (sq. :g:`AE <0452.g1:< A E >>`), or (rect. :g:`BD <0452.g1:/ B D />`, :g:`DA <0452.g1:/ D A />`) = (sq. on :g:`AB <0452.g1:/ A B />`).

The result is of course obvious from II. 11.

There is an alternative proof given in P after XIII. 6, which depends on Book V.

By hypothesis,

.. container:: center

   :g:`BA <0452.g1:/ B A />` : :g:`AC <0452.g1:/ A C />` = :g:`AC <0452.g1:/ A C />` : :g:`CB <0452.g1:/ C B />`,

or, inversely,

.. container:: center

   :g:`AC <0452.g1:/ A C />` : :g:`AB <0452.g1:/ A B />` = :g:`CB <0452.g1:/ C B />` : :g:`AC <0452.g1:/ A C />`.

   (:g:`AB <0452.g1:/ A B />` + :g:`AC <0452.g1:/ A C />`) : :g:`AB <0452.g1:/ A B />` = :g:`AB <0452.g1:/ A B />` : :g:`AC <0452.g1:/ A C />`,
