geometor.euclid.graph.generate_proof_chain_dot(graph: networkx.DiGraph, element_ref: str, current_dir: pathlib.Path, label_to_target: Dict[str, Tuple[pathlib.Path, str | None]], enunciations: Dict[str, str] | None = None) → str¶

Generate a Graphviz DOT string for the transitive proof chain of element_ref.

Note: Sphinx’s sphinx.ext.graphviz.fix_svg_relative_paths resolves URL attributes in DOT relative to the source RST document’s directory (current_dir) and rewrites them to be relative to _images/ in the output SVG.

geometor.euclid.graph.build_graph(heath_out_dir: pathlib.Path | None = None, inject_rst: bool = True) → Tuple[networkx.DiGraph, Dict[str, Any]]¶

Build the NetworkX dependency graph from the composed RST files under docsrc/heath/.

If inject_rst is True, updates :dependencies:, writes resources/heath/enunciations.json, and injects the ‘Dependency Graph’ (.. graphviz::) and ‘Required for’ sections into every proposition’s index.rst.
