src.geometor.euclid.data_codex¶

Concordance loader, validator, and functional DAG query helpers for Euclid’s Data.

Provides stdlib-only typed structures and validation utilities over the static JSON apparatus in resources/data/ (concordance.json, citations.json, persons.json, glossary.json, and enunciations.json).
