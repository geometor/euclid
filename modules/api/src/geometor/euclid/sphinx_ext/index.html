src.geometor.euclid.sphinx_ext¶

Runtime Sphinx & photon-platform/publish integration for geometor.euclid.

Registers the el (“Greek (Menge 1896)”) companion track in photon_platform.publish.book at build time (without modifying photon-platform/publish or affecting docsrc/heath/’s 2-track Proposition + Commentary pages) and configures offline-safe local intersphinx inventories when sister GEOMETOR codices are present on disk.

src.geometor.euclid.sphinx_ext.register_greek_book_track(label: str = GREEK_TRACK_LABEL) → None¶

Extend photon_platform.publish.book to recognize <stem>-el Greek tracks.

Pages without an -el sibling (such as all pages in docsrc/heath/) fall through immediately to the original detect_companion_tracks implementation without modification.
