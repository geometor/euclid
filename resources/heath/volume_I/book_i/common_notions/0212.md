But the first alternative (*a*) obviously contradicts the foregoing lemma [that two straight lines cannot enclose a space], since in that case the two lines <span data-ref="0211.g2:/ A X K /">$AXK$</span>, <span data-ref="0211.g2:/ A T K /">$ATK$</span>, which by hypothesis are straight, would enclose a space.

The second possibility (*b*) is at once seen to involve a similar absurdity. For the straight line <span data-ref="0211.g2:/ X B /">$XB$</span> must, when produced beyond <span data-ref="0211.g2:B">$B$</span>, ultimately meet <span data-ref="0211.g2:/ A P L M /">$APLM$</span> in a point <span data-ref="0211.g2:L">$L$</span>. Consequently the two lines <span data-ref="0211.g2:/ A X B L /">$AXBL$</span>, <span data-ref="0211.g2:/ A P L /">$APL$</span>, which by hypothesis are straight, would again enclose a space. If however we were to assume that the straight line <span data-ref="0211.g2:/ X B /">$XB$</span> produced beyond <span data-ref="0211.g2:B">$B$</span> will ultimately meet either the straight line <span data-ref="0211.g2:/ X M /">$XM$</span> or the straight line <span data-ref="0211.g2:/ X A /">$XA$</span> in another point, we should in the same way arrive at a contradiction.

From this it obviously follows that, on the assumption made, the line <span data-ref="0211.g2:/ A X M /">$AXM$</span> is itself the straight line which was drawn from the point <span data-ref="0211.g2:A">$A$</span> to the point <span data-ref="0211.g2:M">$M$</span>; and that is what was maintained.

The remaining stages are in substance these.

(ii) *If the straight line <span data-ref="0211.g2:/ A X B /">$AXB$</span>, regarded as rigid, revolves about <span data-ref="0211.g2:/ A X /">$AX$</span> as axis, it cannot assume two more positions in the same plane, so that, for example, in one position <span data-ref="0211.g2:/ X B /">$XB$</span> should coincide with <span data-ref="0211.g2:/ X C /">$XC$</span>, and in the other with <span data-ref="0211.g2:/ X M /">$XM$</span>.*

[This is proved by considerations of symmetry. <span data-ref="0211.g2:/ A X B /">$AXB$</span> cannot be altogether "similar or equal to" <span data-ref="0211.g2:/ A X C /">$AXC$</span>, if viewed from the same side (left or right) of both: otherwise they would coincide, which by hypothesis they do not. But there is nothing to prevent <span data-ref="0211.g2:/ A X B /">$AXB$</span> viewed from one side (say the left) being "similar or equal to" <span data-ref="0211.g2:/ A X C /">$AXC$</span> viewed from the other side (i.e. the right), so that <span data-ref="0211.g2:/ A X B /">$AXB$</span> *can*, without any change, be brought into the position <span data-ref="0211.g2:/ A X C /">$AXC$</span>.

<span data-ref="0211.g2:/ A X B /">$AXB$</span> cannot however take the position of the other straight line <span data-ref="0211.g2:/ A X M /">$AXM$</span> as well. If they were like on one side, they would coincide; if they were like on opposite sides, <span data-ref="0211.g2:/ A X M /">$AXM$</span>, <span data-ref="0211.g2:/ A X C /">$AXC$</span> would be like on the same side and therefore coincide.]

(iii) The other positions of <span data-ref="0211.g2:/ A X B /">$AXB$</span> during the revolution must be above or below the original plane.

(iv) It is next maintained that *there is a point <span data-ref="0211.g2:D">$D$</span> on the arc <span data-ref="0211.g2:( B C )">$BC$</span> such that, if <span data-ref="0211.g2:/ X D /">$XD$</span> is drawn, <span data-ref="0211.g2:/ A X D /">$AXD$</span> is not only a straight line but is such that viewed from the left side it is exactly "similar or equal" to what it is when viewed from the right side*.

[*First*, it is proved that points <span data-ref="0211.g2:M">$M$</span>, <span data-ref="0211.g2:F">$F$</span> can be found on the arc, corresponding in the same way as <span data-ref="0211.g2:B">$B$</span>, <span data-ref="0211.g2:C">$C$</span> do, but nearer together, and of course <span data-ref="0211.g2:/ A X M /">$AXM$</span>, <span data-ref="0211.g2:/ A X F /">$AXF$</span> are both straight lines.

*Secondly*, similar corresponding points can be found still nearer together, and so on continually, until either (*a*) we come to *one* point <span data-ref="0211.g2:D">$D$</span> such that <span data-ref="0211.g2:/ A X D /">$AXD$</span> *is exactly like itself when the right and left sides are compared*, or (*b*) there are *two* ultimate points of this sort <span data-ref="0211.g2:M">$M$</span>, <span data-ref="0211.g2:F">$F$</span>, so that *both <span data-ref="0211.g2:/ A X M /">$AXM$</span>, <span data-ref="0211.g2:/ A X F /">$AXF$</span> have this property*.

*Thirdly*, (*b*) is ruled out by reference to the definition of a straight line.
Hence (*a*) only is true, and there is only *one* point <span data-ref="0211.g2:D">$D$</span> such as described.]

(v) Lastly, Saccheri concludes that the straight line <span data-ref="0211.g2:/ A X D /">$AXD$</span> so determined "is *alone* a straight line, and the *immediate* prolongation from <span data-ref="0211.g2:A">$A$</span> beyond <span data-ref="0211.g2:X">$X$</span> to <span data-ref="0211.g2:D">$D$</span>," relying again on the definition of a straight line as "lying evenly."

Simson deduced the proposition that *two straight lines cannot have a common segment* as a corollary from I. 11; but his argument is a complete *petitio principii*, as shown by Todhunter in his note on that proposition.

Proclus (p. 217, 10) records an ancient proof also based on the proposition I. 11. Zeno, he says, propounded this proof and then criticised it.
