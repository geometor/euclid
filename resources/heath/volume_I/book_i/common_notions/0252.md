$$OM' < OM + MM'.$$

But

$$OM + MM' = OM + \sigma < R,$$

whence

$$OM' < R,$$

which is absurd.

A similar absurdity would follow if we suppose that <span data-ref="0251.g1:/ O M /">$OM$</span> > <span data-ref="0251.g1:/ O M /">$R$</span>.

And the proposition is proved.

### Intersections of two circles.

We can likewise use the Postulate of Dedekind to prove that

*If in a given plane a circle* <span data-ref="0252.g1:( O A )">$C$</span> *has one point* <span data-ref="0252.g1:X">$X$</span> *inside and one point* <span data-ref="0252.g1:Y">$Y$</span> *outside another circle* <span data-ref="0252.g1:( O' C' )">$C'$</span>, *the two circles intersect in two points.*

We must first prove the following

#### *Lemma.*

If <span data-ref="0252.g1:O">$O$</span>, <span data-ref="0252.g1:O'">$O'$</span> are the centres of two circles <span data-ref="0252.g1:( O A )">$C$</span>, <span data-ref="0252.g1:( O' C' )">$C'$</span>, and <span data-ref="0252.g1:/ A O /">$R$</span>, <span data-ref="0252.g1:( O' C' )">$R'$</span> their radii respectively, the straight line <span data-ref="0252.g1:[ O O' ]">$OO'$</span> meets the circle <span data-ref="0252.g1:( O A )">$C$</span> in two points <span data-ref="0252.g1:A">$A$</span>, <span data-ref="0252.g1:B">$B$</span>, one of which is inside <span data-ref="0252.g1:( O' C' )">$C'$</span> and the other outside it.

Now one of these points must fall (1) on the prolongation of <span data-ref="0252.g1:/ O O' /">$O'O$</span> beyond <span data-ref="0252.g1:O">$O$</span> or (2) on <span data-ref="0252.g2:/ O O' /">$OO'$</span> itself or (3) on the prolongation of <span data-ref="0253.g1:/ O O' /">$OO'$</span> beyond <span data-ref="0253.g1:O'">$O'$</span>.

![Intersections of two circles, Lemma Case 1](0252.g1.svg)

(1) First, suppose <span data-ref="0252.g1:A">$A$</span> to lie on <span data-ref="0252.g1:/ O O' /">$O'O$</span> produced.

Then

$$AO' = AO + OO' = R + OO' \ldots\ldots (\alpha).$$

But, in the triangle <span data-ref="0252.g1:< O O' Y >">$OO'Y$</span>,

$$O'Y < OY + OO',$$

and, since <span data-ref="0252.g1:/ O' Y /">$O'Y$</span> > <span data-ref="0252.g1:( O' C' )">$R'$</span>, <span data-ref="0252.g1:/ O Y /">$OY$</span> = <span data-ref="0252.g1:/ A O /">$R$</span>,

$$R' < R + OO'.$$

It follows from $(\alpha)$ that <span data-ref="0252.g1:/ A O' /">$AO'$</span> > <span data-ref="0252.g1:( O' C' )">$R'$</span>; and <span data-ref="0252.g1:A">$A$</span> therefore lies *outside* <span data-ref="0252.g1:( O' C' )">$C'$</span>.

![Intersections of two circles, Lemma Case 2](0252.g2.svg)

(2) Secondly, suppose <span data-ref="0252.g2:A">$A$</span> to lie on <span data-ref="0252.g2:/ O O' /">$OO'$</span>.

Then

$$OO' = OA + AO' = R + AO' \ldots (\beta).$$

From the triangle <span data-ref="0252.g2:< O O' X >">$OO'X$</span> we have

$$OO' < OX + O'X,$$

and, since <span data-ref="0252.g2:/ O X /">$OX$</span> = <span data-ref="0252.g2:/ O A /">$R$</span>, <span data-ref="0252.g2:/ O' X /">$O'X$</span> < <span data-ref="0252.g2:( O' C' )">$R'$</span>, it follows that

$$OO' < R + R',$$

whence, by $(\beta)$, <span data-ref="0252.g2:/ A O' /">$AO'$</span> < <span data-ref="0252.g2:( O' C' )">$R'$</span>, so that <span data-ref="0252.g2:A">$A$</span> lies *inside* <span data-ref="0252.g2:( O' C' )">$C'$</span>.
