# BOOK I. PROPOSITIONS.

### PROPOSITION 1.

<p class="enunciation">On a given finite straight line to construct an equilateral triangle.</p>

![Proposition 1 figure](0255.g1.svg)

Let <span data-ref="0255.g1:/ A B /">$AB$</span> be the given finite straight line.

Thus it is required to construct an equilateral triangle on the straight line <span data-ref="0255.g1:/ A B /">$AB$</span>.

With centre <span data-ref="0255.g1:A">$A$</span> and distance <span data-ref="0255.g1:/ A B /">$AB$</span> let the circle <span data-ref="0255.g1:( B C D )">$BCD$</span> be described; <span class="justification">[Post. 3]</span>  
<sup>10</sup> again, with centre <span data-ref="0255.g1:B">$B$</span> and distance <span data-ref="0255.g1:/ B A /">$BA$</span> let the circle <span data-ref="0255.g1:( A C E )">$ACE$</span> be described; <span class="justification">[Post. 3]</span>  
and from the point <span data-ref="0255.g1:C">$C$</span>, in which the circles cut one another, to the points <span data-ref="0255.g1:A">$A$</span>, <span data-ref="0255.g1:B">$B$</span> let the straight lines <span data-ref="0255.g1:/ C A /">$CA$</span>, <span data-ref="0255.g1:/ C B /">$CB$</span> be joined. <span class="justification">[Post. 1]</span>

<sup>15</sup> Now, since the point <span data-ref="0255.g1:A">$A$</span> is the centre of the circle <span data-ref="0255.g1:( C D B )">$CDB$</span>,
<p class="assertion"><span class="justification">[Def. 15]</span><span data-ref="0255.g1:/ A C /">$AC$</span> is equal to <span data-ref="0255.g1:/ A B /">$AB$</span>.</p>

Again, since the point <span data-ref="0255.g1:B">$B$</span> is the centre of the circle <span data-ref="0255.g1:( C A E )">$CAE$</span>,
<p class="assertion"><span class="justification">[Def. 15]</span><span data-ref="0255.g1:/ B C /">$BC$</span> is equal to <span data-ref="0255.g1:/ B A /">$BA$</span>.</p>

But <span data-ref="0255.g1:/ C A /">$CA$</span> was also proved equal to <span data-ref="0255.g1:/ A B /">$AB$</span>;  
<sup>20</sup> therefore each of the straight lines <span data-ref="0255.g1:/ C A /">$CA$</span>, <span data-ref="0255.g1:/ C B /">$CB$</span> is equal to <span data-ref="0255.g1:/ A B /">$AB$</span>.

And things which are equal to the same thing are also equal to one another; <span class="justification">[C. N. 1]</span>
<p class="assertion">therefore <span data-ref="0255.g1:/ C A /">$CA$</span> is also equal to <span data-ref="0255.g1:/ C B /">$CB$</span>.</p>

<sup>25</sup> Therefore the three straight lines <span data-ref="0255.g1:/ C A /">$CA$</span>, <span data-ref="0255.g1:/ A B /">$AB$</span>, <span data-ref="0255.g1:/ B C /">$BC$</span> are equal to one another.
