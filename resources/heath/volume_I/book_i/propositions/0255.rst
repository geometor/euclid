BOOK I. PROPOSITIONS.
=====================

PROPOSITION 1.
--------------

.. enunciation::

   On a given finite straight line\ [#f1]_ to construct an equilateral triangle.

.. picture:: 0255.g1.svg
   :alt: Proposition 1 figure

Let :g:`AB <0255.g1:/ A B />` be the given finite straight line.\ [#f2]_

Thus it is required to construct an equilateral triangle on the straight line :g:`AB <0255.g1:/ A B />`.

With centre :g:`A <0255.g1:A>` and distance :g:`AB <0255.g1:/ A B />` let the circle :g:`BCD <0255.g1:( B C D )>` be described;\ [#f3]_ :just:`[Post. 3] <I.post.3>`

again, with centre :g:`B <0255.g1:B>` and distance :g:`BA <0255.g1:/ B A />` let the circle :g:`ACE <0255.g1:( A C E )>` be described; :just:`[Post. 3] <I.post.3>`

and from the point :g:`C <0255.g1:C>`,\ [#f4]_ in which the circles cut one another, to the points :g:`A <0255.g1:A>`, :g:`B <0255.g1:B>` let the straight lines :g:`CA <0255.g1:/ C A />`, :g:`CB <0255.g1:/ C B />` be joined. :just:`[Post. 1] <I.post.1>`

Now, since the point :g:`A <0255.g1:A>` is the centre of the circle :g:`CDB <0255.g1:( C D B )>`,

.. assertion:: [Def. 15] <I.def.15>

   :g:`AC <0255.g1:/ A C />` is :eq:`equal <0255.g1:/ A C / = 0255.g1:/ A B />` to :g:`AB <0255.g1:/ A B />`.

Again, since the point :g:`B <0255.g1:B>` is the centre of the circle :g:`CAE <0255.g1:( C A E )>`,

.. assertion:: [Def. 15] <I.def.15>

   :g:`BC <0255.g1:/ B C />` is :eq:`equal <0255.g1:/ B C / = 0255.g1:/ B A />` to :g:`BA <0255.g1:/ B A />`.

But :g:`CA <0255.g1:/ C A />` was also proved :eq:`equal <0255.g1:/ C A / = 0255.g1:/ A B />` to :g:`AB <0255.g1:/ A B />`; therefore each of the straight lines :g:`CA <0255.g1:/ C A />`, :g:`CB <0255.g1:/ C B />`\ [#f5]_ is :eq:`equal <0255.g1:/ C A / = 0255.g1:/ C B / = 0255.g1:/ A B />` to :g:`AB <0255.g1:/ A B />`.

And things which are equal to the same thing are also equal to one another; :just:`[C. N. 1] <I.cn.1>`

.. assertion::

   therefore :g:`CA <0255.g1:/ C A />` is also :eq:`equal <0255.g1:/ C A / = 0255.g1:/ C B />` to :g:`CB <0255.g1:/ C B />`.

Therefore the three straight lines :g:`CA <0255.g1:/ C A />`, :g:`AB <0255.g1:/ A B />`, :g:`BC <0255.g1:/ B C />` are :eq:`equal <0255.g1:/ C A / = 0255.g1:/ A B / = 0255.g1:/ B C />` to one another.
