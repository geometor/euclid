### PROPOSITION 2.

<p class="enunciation">To place at a given point (as an extremity) a straight line equal to a given straight line.</p>

![Proposition 2 figure](0258.g1.svg)

Let <span data-ref="0258.g1:A">$A$</span> be the given point, and <span data-ref="0258.g1:/ B C /">$BC$</span> the given straight line.

Thus it is required to place at the point <span data-ref="0258.g1:A">$A$</span> (as an extremity) a straight line equal to the given straight line <span data-ref="0258.g1:/ B C /">$BC$</span>.

From the point <span data-ref="0258.g1:A">$A$</span> to the point <span data-ref="0258.g1:B">$B$</span> let the straight line <span data-ref="0258.g1:/ A B /">$AB$</span> be joined; <span class="justification">[Post. 1]</span>  
and on it let the equilateral triangle <span data-ref="0258.g1:< D A B >">$DAB$</span> be constructed. <span class="justification">[I. 1]</span>

Let the straight lines <span data-ref="0258.g1:/ A E /">$AE$</span>, <span data-ref="0258.g1:/ B F /">$BF$</span> be produced in a straight line with <span data-ref="0258.g1:/ D A /">$DA$</span>, <span data-ref="0258.g1:/ D B /">$DB$</span>; <span class="justification">[Post. 2]</span>  
with centre <span data-ref="0258.g1:B">$B$</span> and distance <span data-ref="0258.g1:/ B C /">$BC$</span> let the circle <span data-ref="0258.g1:( B C )">$CGH$</span> be described; <span class="justification">[Post. 3]</span>  
and again, with centre <span data-ref="0258.g1:D">$D$</span> and distance <span data-ref="0258.g1:/ D G /">$DG$</span> let the circle <span data-ref="0258.g1:( D G )">$GKL$</span> be described. <span class="justification">[Post. 3]</span>

Then, since the point <span data-ref="0258.g1:B">$B$</span> is the centre of the circle <span data-ref="0258.g1:( B C )">$CGH$</span>,
<p class="assertion"><span data-ref="0258.g1:/ B C /">$BC$</span> is equal to <span data-ref="0258.g1:/ B G /">$BG$</span>.</p>

<sup>20</sup> Again, since the point <span data-ref="0258.g1:D">$D$</span> is the centre of the circle <span data-ref="0258.g1:( D G )">$GKL$</span>,
<p class="assertion"><span data-ref="0258.g1:/ D L /">$DL$</span> is equal to <span data-ref="0258.g1:/ D G /">$DG$</span>.</p>

And in these <span data-ref="0258.g1:/ D A /">$DA$</span> is equal to <span data-ref="0258.g1:/ D B /">$DB$</span>;  
therefore the remainder <span data-ref="0258.g1:/ A L /">$AL$</span> is equal to the remainder <span data-ref="0258.g1:/ B G /">$BG$</span>. <span class="justification">[C.N. 3]</span>

<sup>25</sup> But <span data-ref="0258.g1:/ B C /">$BC$</span> was also proved equal to <span data-ref="0258.g1:/ B G /">$BG$</span>;  
therefore each of the straight lines <span data-ref="0258.g1:/ A L /">$AL$</span>, <span data-ref="0258.g1:/ B C /">$BC$</span> is equal to <span data-ref="0258.g1:/ B G /">$BG$</span>.

And things which are equal to the same thing are also equal to one another; <span class="justification">[C.N. 1]</span>
<p class="assertion"><sup>30</sup> therefore <span data-ref="0258.g1:/ A L /">$AL$</span> is also equal to <span data-ref="0258.g1:/ B C /">$BC$</span>.</p>

Therefore at the given point <span data-ref="0258.g1:A">$A$</span> the straight line <span data-ref="0258.g1:/ A L /">$AL$</span> is placed equal to the given straight line <span data-ref="0258.g1:/ B C /">$BC$</span>.

<p class="qed">(Being) what it was required to do.</p>

**1. (as an extremity).** I have inserted these words because “to place a straight line at a given point” (πρὸς τῷ δοθέντι σημείῳ) is not quite clear enough, at least in English.

**11.
