**20.** It would be natural to insert here the step “but the angle <span data-ref="0272.g2:< A C D )">$ACD$</span> is greater than the angle <span data-ref="0272.g2:< B C D )">$BCD$</span>. [C. N. 5.]”

**21. much greater,** literally “greater by much” (πολλῷ μείζων). Simson and those who follow him translate: “much more then is the angle <span data-ref="0272.g2:< B D C )">$BDC$</span> greater than the angle <span data-ref="0272.g2:< B C D )">$BCD$</span>,” but the Greek for this would have to be πολλῷ (or πολὺ) μᾶλλόν ἐστι...μείζων. πολλῷ μᾶλλον, however, though used by Apollonius, is not, apparently, found in Euclid or Archimedes.

Just as in I. 6 we need a Postulate to justify theoretically the statement that <span data-ref="0269.g1:/ C D /">$CD$</span> falls within the angle <span data-ref="0269.g1:< A C B )">$ACB$</span>, so that the triangle <span data-ref="0269.g1:< D B C >">$DBC$</span> is less than the triangle <span data-ref="0269.g1:< A B C >">$ABC$</span>, so here we need Postulates which shall satisfy us as to the relative positions of <span data-ref="0272.g2:/ C A /">$CA$</span>, <span data-ref="0272.g2:/ C B /">$CB$</span>, <span data-ref="0272.g2:/ C D /">$CD$</span> on the one hand and of <span data-ref="0272.g2:/ D C /">$DC$</span>, <span data-ref="0272.g2:/ D A /">$DA$</span>, <span data-ref="0272.g2:/ D B /">$DB$</span> on the other, in order that we may be able to infer that the angle <span data-ref="0272.g2:< B D C )">$BDC$</span> is greater than the angle <span data-ref="0272.g2:< A D C )">$ADC$</span>, and the angle <span data-ref="0272.g2:< A C D )">$ACD$</span> greater than the angle <span data-ref="0272.g2:< B C D )">$BCD$</span>.

De Morgan (*op. cit.* p. 7) observes that I. 7 would be made easy to beginners if they were first familiarised, as a common notion, with “if two magnitudes be equal, any magnitude greater than the one is greater than any magnitude less than the other.” I doubt however whether a beginner would follow this easily; perhaps it would be more easily apprehended in the form “if any magnitude $A$ is greater than a magnitude $B$, the magnitude $A$ is greater than any magnitude equal to $B$, and (*a fortiori*) greater than any magnitude less than $B$.”

It has been mentioned already (note on I. 5) that the second case of I. 7 given by Simson and in our text-books generally is not in the original text (the omission being in accordance with Euclid’s general practice of giving only one case, and that the most difficult, and leaving the others to be worked out by the reader for himself). The second case is given by Proclus as the answer to a possible objection to Euclid’s proposition, which should assert that the proposition is not proved to be universally true, since the proof given does not cover all possible cases. Here the objector is supposed to contend that what Euclid declares to be impossible may still be possible if one pair of lines lie wholly within the other pair of lines; and the second part of I. 5 enables the objection to be refuted.

If possible, let <span data-ref="0274.g1:/ A D /">$AD$</span>, <span data-ref="0274.g1:/ D B /">$DB$</span> be entirely within the triangle formed by <span data-ref="0274.g1:/ A C /">$AC$</span>, <span data-ref="0274.g1:/ C B /">$CB$</span> with <span data-ref="0274.g1:/ A B /">$AB$</span>, and let <span data-ref="0274.g1:/ A C /">$AC$</span> be equal to <span data-ref="0274.g1:/ A D /">$AD$</span> and <span data-ref="0274.g1:/ B C /">$BC$</span> to <span data-ref="0274.g1:/ B D /">$BD$</span>.

Join <span data-ref="0274.g1:/ C D /">$CD$</span>, and produce <span data-ref="0274.g1:[ A E ]">$AC$</span>, <span data-ref="0274.g1:[ A F ]">$AD$</span> to <span data-ref="0274.g1:E">$E$</span> and <span data-ref="0274.g1:F">$F$</span>.  
Then, since <span data-ref="0274.g1:/ A C /">$AC$</span> is equal to <span data-ref="0274.g1:/ A D /">$AD$</span>,  
the triangle <span data-ref="0274.g1:< A C D >">$ACD$</span> is isosceles,  
and the angles <span data-ref="0274.g1:< E C D )">$ECD$</span>, <span data-ref="0274.g1:< F D C )">$FDC$</span> under the base are equal.  
But the angle <span data-ref="0274.g1:< E C D )">$ECD$</span> is greater than the angle <span data-ref="0274.g1:< B C D )">$BCD$</span>,  
therefore the angle <span data-ref="0274.g1:< F D C )">$FDC$</span> is also greater than the angle <span data-ref="0274.g1:< B C D )">$BCD$</span>.  
Therefore the angle <span data-ref="0274.g1:< B D C )">$BDC$</span> is greater by far than the angle <span data-ref="0274.g1:< B C D )">$BCD$</span>.

Again, since <span data-ref="0274.g1:/ D B /">$DB$</span> is equal to <span data-ref="0274.g1:/ C B /">$CB$</span>,  
the angles at the base of the triangle <span data-ref="0274.g1:< B D C >">$BDC$</span> are equal, [I. 5]  
that is, the angle <span data-ref="0274.g1:< B D C )">$BDC$</span> is equal to the angle <span data-ref="0274.g1:< B C D )">$BCD$</span>.

Therefore the same angle <span data-ref="0274.g1:< B D C )">$BDC$</span> is both greater than and equal to the angle <span data-ref="0274.g1:< B C D )">$BCD$</span>: which is impossible.
