**20.** It would be natural to insert here the step “but the angle :g:`$ACD$ <0272.g2:< A C D )>` is greater than the angle :g:`$BCD$ <0272.g2:< B C D )>`. [C. N. 5.]”

**21. much greater,** literally “greater by much” (πολλῷ μείζων). :person:`Simson <simson>` and those who follow him translate: “much more then is the angle :g:`$BDC$ <0272.g2:< B D C )>` greater than the angle :g:`$BCD$ <0272.g2:< B C D )>`,” but the Greek for this would have to be πολλῷ (or πολὺ) μᾶλλόν ἐστι...μείζων. πολλῷ μᾶλλον, however, though used by :person:`Apollonius <apollonius>`, is not, apparently, found in :person:`Euclid <euclid>` or :person:`Archimedes <archimedes>`.

Just as in I. 6 we need a Postulate to justify theoretically the statement that :g:`$CD$ <0269.g1:/ C D />` falls within the angle :g:`$ACB$ <0269.g1:< A C B )>`, so that the triangle :g:`$DBC$ <0269.g1:< D B C >>` is less than the triangle :g:`$ABC$ <0269.g1:< A B C >>`, so here we need Postulates which shall satisfy us as to the relative positions of :g:`$CA$ <0272.g2:/ C A />`, :g:`$CB$ <0272.g2:/ C B />`, :g:`$CD$ <0272.g2:/ C D />` on the one hand and of :g:`$DC$ <0272.g2:/ D C />`, :g:`$DA$ <0272.g2:/ D A />`, :g:`$DB$ <0272.g2:/ D B />` on the other, in order that we may be able to infer that the angle :g:`$BDC$ <0272.g2:< B D C )>` is greater than the angle :g:`$ADC$ <0272.g2:< A D C )>`, and the angle :g:`$ACD$ <0272.g2:< A C D )>` greater than the angle :g:`$BCD$ <0272.g2:< B C D )>`.

:person:`De Morgan <de-morgan>` (*op. cit.* p. 7) observes that I. 7 would be made easy to beginners if they were first familiarised, as a common notion, with “if two magnitudes be equal, any magnitude greater than the one is greater than any magnitude less than the other.” I doubt however whether a beginner would follow this easily; perhaps it would be more easily apprehended in the form “if any magnitude $A$ is greater than a magnitude $B$, the magnitude $A$ is greater than any magnitude equal to $B$, and (*a fortiori*) greater than any magnitude less than $B$.”

It has been mentioned already (note on I. 5) that the second case of I. 7 given by :person:`Simson <simson>` and in our text-books generally is not in the original text (the omission being in accordance with Euclid’s general practice of giving only one case, and that the most difficult, and leaving the others to be worked out by the reader for himself). The second case is given by :person:`Proclus <proclus>` as the answer to a possible objection to Euclid’s proposition, which should assert that the proposition is not proved to be universally true, since the proof given does not cover all possible cases. Here the objector is supposed to contend that what :person:`Euclid <euclid>` declares to be impossible may still be possible if one pair of lines lie wholly within the other pair of lines; and the second part of I. 5 enables the objection to be refuted.

If possible, let :g:`$AD$ <0274.g1:/ A D />`, :g:`$DB$ <0274.g1:/ D B />` be entirely within the triangle formed by :g:`$AC$ <0274.g1:/ A C />`, :g:`$CB$ <0274.g1:/ C B />` with :g:`$AB$ <0274.g1:/ A B />`, and let :g:`$AC$ <0274.g1:/ A C />` be equal to :g:`$AD$ <0274.g1:/ A D />` and :g:`$BC$ <0274.g1:/ B C />` to :g:`$BD$ <0274.g1:/ B D />`.

| Join :g:`$CD$ <0274.g1:/ C D />`, and produce :g:`$AC$ <0274.g1:[ A E ]>`, :g:`$AD$ <0274.g1:[ A F ]>` to :g:`$E$ <0274.g1:E>` and :g:`$F$ <0274.g1:F>`.
| Then, since :g:`$AC$ <0274.g1:/ A C />` is equal to :g:`$AD$ <0274.g1:/ A D />`,
| the triangle :g:`$ACD$ <0274.g1:< A C D >>` is isosceles,
| and the angles :g:`$ECD$ <0274.g1:< E C D )>`, :g:`$FDC$ <0274.g1:< F D C )>` under the base are equal.
| But the angle :g:`$ECD$ <0274.g1:< E C D )>` is greater than the angle :g:`$BCD$ <0274.g1:< B C D )>`,
| therefore the angle :g:`$FDC$ <0274.g1:< F D C )>` is also greater than the angle :g:`$BCD$ <0274.g1:< B C D )>`.
| Therefore the angle :g:`$BDC$ <0274.g1:< B D C )>` is greater by far than the angle :g:`$BCD$ <0274.g1:< B C D )>`.

| Again, since :g:`$DB$ <0274.g1:/ D B />` is equal to :g:`$CB$ <0274.g1:/ C B />`,
| the angles at the base of the triangle :g:`$BDC$ <0274.g1:< B D C >>` are equal, [I. 5]
| that is, the angle :g:`$BDC$ <0274.g1:< B D C )>` is equal to the angle :g:`$BCD$ <0274.g1:< B C D )>`.

Therefore the same angle :g:`$BDC$ <0274.g1:< B D C )>` is both greater than and equal to the angle :g:`$BCD$ <0274.g1:< B C D )>`: which is impossible.

The case in which :g:`$D$ <0274.g1:D>` falls on :g:`$AC$ <0274.g1:/ A C />` or :g:`$BC$ <0274.g1:/ B C />` does not require proof.
