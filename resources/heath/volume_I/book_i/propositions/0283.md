### PROPOSITION 11.

<p class="enunciation">To draw a straight line at right angles to a given straight line from a given point on it.</p>

![Proposition 11 figure](0283.g1.svg)

Let <span data-ref="0283.g1:/ A B /">$AB$</span> be the given straight line, and <span data-ref="0283.g1:C">$C$</span> the given point on it.

<sup>5</sup> Thus it is required to draw from the point <span data-ref="0283.g1:C">$C$</span> a straight line at right angles to the straight line <span data-ref="0283.g1:/ A B /">$AB$</span>.

Let a point <span data-ref="0283.g1:D">$D$</span> be taken at random on <span data-ref="0283.g1:/ A C /">$AC$</span>;  
<sup>10</sup> let <span data-ref="0283.g1:/ C E /">$CE$</span> be made equal to <span data-ref="0283.g1:/ C D /">$CD$</span>; <span class="justification">[I. 3]</span>  
on <span data-ref="0283.g1:/ D E /">$DE$</span> let the equilateral triangle <span data-ref="0283.g1:< F D E >">$FDE$</span> be constructed, <span class="justification">[I. 1]</span>  
and let <span data-ref="0283.g1:/ F C /">$FC$</span> be joined;

I say that the straight line <span data-ref="0283.g1:/ F C /">$FC$</span> has been drawn at right  
<sup>15</sup> angles to the given straight line <span data-ref="0283.g1:/ A B /">$AB$</span> from <span data-ref="0283.g1:C">$C$</span> the given point on it.

For, since <span data-ref="0283.g1:/ D C /">$DC$</span> is equal to <span data-ref="0283.g1:/ C E /">$CE$</span>,  
and <span data-ref="0283.g1:/ C F /">$CF$</span> is common,  
<p class="assertion"><sup>20</sup> the two sides <span data-ref="0283.g1:/ D C /">$DC$</span>, <span data-ref="0283.g1:/ C F /">$CF$</span> are equal to the two sides <span data-ref="0283.g1:/ E C /">$EC$</span>, <span data-ref="0283.g1:/ C F /">$CF$</span> respectively;</p>
and the base <span data-ref="0283.g1:/ D F /">$DF$</span> is equal to the base <span data-ref="0283.g1:/ F E /">$FE$</span>;  
<p class="assertion">therefore the angle <span data-ref="0283.g1:< D C F )">$DCF$</span> is equal to the angle <span data-ref="0283.g1:< E C F )">$ECF$</span>; <span class="justification">[I. 8]</span></p>
and they are adjacent angles.

But, when a straight line set up on a straight line makes  
<sup>25</sup> the adjacent angles equal to one another, each of the equal angles is right; <span class="justification">[Def. 10]</span>  
<p class="assertion">therefore each of the angles <span data-ref="0283.g1:< D C F )">$DCF$</span>, <span data-ref="0283.g1:< F C E )">$FCE$</span> is right.</p>

Therefore the straight line <span data-ref="0283.g1:/ C F /">$CF$</span> has been drawn at right angles to the given straight line <span data-ref="0283.g1:/ A B /">$AB$</span> from the given point  
<sup>30</sup> <span data-ref="0283.g1:C">$C$</span> on it.

<p class="qed">Q. E. F.</p>
