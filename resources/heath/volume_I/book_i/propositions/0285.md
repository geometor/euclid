<sup>5</sup> thus it is required to draw to the given infinite straight line <span data-ref="0285.g1:[ A B ]">$AB$</span>, from the given point <span data-ref="0285.g1:C">$C$</span> which is not on it, a perpendicular straight line.

For let a point <span data-ref="0285.g1:D">$D$</span> be taken  
<sup>10</sup> at random on the other side of the straight line <span data-ref="0285.g1:[ A B ]">$AB$</span>, and with centre <span data-ref="0285.g1:C">$C$</span> and distance <span data-ref="0285.g1:/ C D /">$CD$</span> let the circle <span data-ref="0285.g1:( C D )">$EFG$</span> be described; <span class="justification">[Post. 3]</span>  
let the straight line <span data-ref="0285.g1:/ E G /">$EG$</span>  
<sup>15</sup> be bisected at <span data-ref="0285.g1:H">$H$</span>, <span class="justification">[I. 10]</span>  
and let the straight lines <span data-ref="0285.g1:/ C G /">$CG$</span>, <span data-ref="0285.g1:/ C H /">$CH$</span>, <span data-ref="0285.g1:/ C E /">$CE$</span> be joined. <span class="justification">[Post. 1]</span>

I say that <span data-ref="0285.g1:/ C H /">$CH$</span> has been drawn perpendicular to the given infinite straight line <span data-ref="0285.g1:[ A B ]">$AB$</span> from the given point <span data-ref="0285.g1:C">$C$</span> which is not on it.

<sup>20</sup> For, since <span data-ref="0285.g1:/ G H /">$GH$</span> is equal to <span data-ref="0285.g1:/ H E /">$HE$</span>,  
and <span data-ref="0285.g1:/ H C /">$HC$</span> is common,  
<p class="assertion">the two sides <span data-ref="0285.g1:/ G H /">$GH$</span>, <span data-ref="0285.g1:/ H C /">$HC$</span> are equal to the two sides <span data-ref="0285.g1:/ E H /">$EH$</span>, <span data-ref="0285.g1:/ H C /">$HC$</span> respectively;</p>
and the base <span data-ref="0285.g1:/ C G /">$CG$</span> is equal to the base <span data-ref="0285.g1:/ C E /">$CE$</span>;  
<p class="assertion"><sup>25</sup> therefore the angle <span data-ref="0285.g1:< C H G )">$CHG$</span> is equal to the angle <span data-ref="0285.g1:< E H C )">$EHC$</span>. <span class="justification">[I. 8]</span></p>

And they are adjacent angles.

But, when a straight line set up on a straight line makes the adjacent angles equal to one another, each of the equal angles is right, and the straight line standing on the other is  
<sup>30</sup> called a perpendicular to that on which it stands. <span class="justification">[Def. 10]</span>

Therefore <span data-ref="0285.g1:/ C H /">$CH$</span> has been drawn perpendicular to the given infinite straight line <span data-ref="0285.g1:[ A B ]">$AB$</span> from the given point <span data-ref="0285.g1:C">$C$</span> which is not on it.

<p class="qed">Q. E. F.</p>

**2. a perpendicular straight line**, κάθετον εὐθεῖαν γραμμήν. This is the full expression for a perpendicular, κάθετος meaning *let fall* or *let down*, so that the expression corresponds to our *plumb-line*. ἡ κάθετος is however constantly used alone for a perpendicular, γραμμή being understood.
