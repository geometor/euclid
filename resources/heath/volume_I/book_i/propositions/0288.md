If the circle intersects <span data-ref="0288.g1:[ A B ]">$AB$</span> as before in <span data-ref="0288.g1:G">$G$</span>, <span data-ref="0288.g1:E">$E$</span>, let <span data-ref="0288.g1:H">$H$</span> be the middle point of <span data-ref="0288.g1:/ G E /">$GE$</span>, and suppose, if possible, that the circle also intersects <span data-ref="0288.g1:[ A B ]">$AB$</span> in any other point <span data-ref="0288.g1:K">$K$</span> on <span data-ref="0288.g1:/ A H /">$AH$</span>.

From <span data-ref="0288.g1:H">$H$</span>, on the side of <span data-ref="0288.g1:[ A B ]">$AB$</span> opposite to <span data-ref="0288.g1:C">$C$</span>, draw <span data-ref="0288.g1:/ H L /">$HL$</span> at right angles to <span data-ref="0288.g1:[ A B ]">$AB$</span>, and make <span data-ref="0288.g1:/ H L /">$HL$</span> equal to <span data-ref="0288.g1:/ H C /">$HC$</span>.  
Join <span data-ref="0288.g1:/ C G /">$CG$</span>, <span data-ref="0288.g1:/ L G /">$LG$</span>, <span data-ref="0288.g1:/ C K /">$CK$</span>, <span data-ref="0288.g1:/ L K /">$LK$</span>.

![Heath Reflection Diagram for I. 12 via I. 7](0288.g1.svg)

Now, in the triangles <span data-ref="0288.g1:< C H G >">$CHG$</span>, <span data-ref="0288.g1:< L H G >">$LHG$</span>,  
<span data-ref="0288.g1:/ C H /">$CH$</span> is equal to <span data-ref="0288.g1:/ L H /">$LH$</span>, and <span data-ref="0288.g1:/ H G /">$HG$</span> is common.  
Also the angles <span data-ref="0288.g1:< C H G )">$CHG$</span>, <span data-ref="0288.g1:< L H G )">$LHG$</span>, being both right, are equal.  
Therefore the base <span data-ref="0288.g1:/ C G /">$CG$</span> is equal to the base <span data-ref="0288.g1:/ L G /">$LG$</span>.  
Similarly we prove that <span data-ref="0288.g1:/ C K /">$CK$</span> is equal to <span data-ref="0288.g1:/ L K /">$LK$</span>.  
But, by hypothesis, since <span data-ref="0288.g1:K">$K$</span> is on the circle,  
<span data-ref="0288.g1:/ C K /">$CK$</span> is equal to <span data-ref="0288.g1:/ C G /">$CG$</span>.  
Therefore <span data-ref="0288.g1:/ C G /">$CG$</span>, <span data-ref="0288.g1:/ C K /">$CK$</span>, <span data-ref="0288.g1:/ L G /">$LG$</span>, <span data-ref="0288.g1:/ L K /">$LK$</span> are all equal.

Now the next proposition, I. 13, will tell us that <span data-ref="0288.g1:/ C H /">$CH$</span>, <span data-ref="0288.g1:/ H L /">$HL$</span> are in a straight line; but we will not assume this. Join <span data-ref="0288.g1:/ C L /">$CL$</span>.  
Then on the same base <span data-ref="0288.g1:/ C L /">$CL$</span> and on the same side of it we have two pairs of straight lines drawn from <span data-ref="0288.g1:C">$C$</span>, <span data-ref="0288.g1:L">$L$</span> to <span data-ref="0288.g1:G">$G$</span> and <span data-ref="0288.g1:K">$K$</span> such that <span data-ref="0288.g1:/ C G /">$CG$</span> is equal to <span data-ref="0288.g1:/ C K /">$CK$</span> and <span data-ref="0288.g1:/ L G /">$LG$</span> to <span data-ref="0288.g1:/ L K /">$LK$</span>.  
But this is impossible [I. 7].  
Therefore the circle cannot cut <span data-ref="0288.g1:/ B A /">$BA$</span> or <span data-ref="0288.g1:[ B A ]">$BA$</span> produced in any point other than <span data-ref="0288.g1:G">$G$</span> on that side of <span data-ref="0288.g1:/ C L /">$CL$</span> on which <span data-ref="0288.g1:G">$G$</span> is.  
Similarly it cannot cut <span data-ref="0288.g1:/ A B /">$AB$</span> or <span data-ref="0288.g1:[ A B ]">$AB$</span> produced at any point other than <span data-ref="0288.g1:E">$E$</span> on the other side of <span data-ref="0288.g1:/ C L /">$CL$</span>.

The only possibility left therefore is that the circle might cut <span data-ref="0288.g1:[ A B ]">$AB$</span> in the same point as that in which <span data-ref="0288.g1:/ C L /">$CL$</span> cuts it. But this is shown to be impossible by an adaptation of the proof of I. 7.

For the assumption is that there may be some point <span data-ref="0288.g2:M">$M$</span> on <span data-ref="0288.g2:/ C L /">$CL$</span> such that <span data-ref="0288.g2:/ C M /">$CM$</span> is equal to <span data-ref="0288.g2:/ C G /">$CG$</span> and <span data-ref="0288.g2:/ L M /">$LM$</span> to <span data-ref="0288.g2:/ L G /">$LG$</span>.  
If possible, let this be the case, and produce <span data-ref="0288.g2:/ C G /">$CG$</span> to <span data-ref="0288.g2:N">$N$</span>.

![Heath Diagram for Point M on CL](0288.g2.svg)

Then, since <span data-ref="0288.g2:/ C M /">$CM$</span> is equal to <span data-ref="0288.g2:/ C G /">$CG$</span>,  
the angle <span data-ref="0288.g2:< N G M )">$NGM$</span> is equal to the angle <span data-ref="0288.g2:< G M L )">$GML$</span> [I. 5, part 2].  
Therefore the angle <span data-ref="0288.g2:< G M L )">$GML$</span> is greater than the angle <span data-ref="0288.g2:< M G L )">$MGL$</span>.  
Again, since <span data-ref="0288.g2:/ L G /">$LG$</span> is equal to <span data-ref="0288.g2:/ L M /">$LM$</span>,  
the angle <span data-ref="0288.g2:< G M L )">$GML$</span> is equal to the angle <span data-ref="0288.g2:< M G L )">$MGL$</span>.  
But it was also greater: which is impossible.  
Hence the circle in the original figure cannot cut <span data-ref="0288.g1:[ A B ]">$AB$</span> in the point in which <span data-ref="0288.g1:/ C L /">$CL$</span> cuts it.  
Therefore the circle cannot cut <span data-ref="0288.g1:[ A B ]">$AB$</span> in any point whatever except <span data-ref="0288.g1:G">$G$</span> and <span data-ref="0288.g1:E">$E$</span>.
