### PROPOSITION 19.

<p class="enunciation">In any triangle the greater angle is subtended by the greater side.</p>

![Proposition 19 figure](0298.g1.svg)

Let <span data-ref="0298.g1:< A B C >">$ABC$</span> be a triangle having the angle <span data-ref="0298.g1:< A B C )">$ABC$</span> greater than the angle <span data-ref="0298.g1:< B C A )">$BCA$</span>;  
I say that the side <span data-ref="0298.g1:/ A C /">$AC$</span> is also greater than the side <span data-ref="0298.g1:/ A B /">$AB$</span>.

For, if not, <span data-ref="0298.g1:/ A C /">$AC$</span> is either equal to <span data-ref="0298.g1:/ A B /">$AB$</span> or less.

Now <span data-ref="0298.g1:/ A C /">$AC$</span> is not equal to <span data-ref="0298.g1:/ A B /">$AB$</span>;  
for then the angle <span data-ref="0298.g1:< A B C )">$ABC$</span> would also have been equal to the angle <span data-ref="0298.g1:< A C B )">$ACB$</span>; <span class="justification">[I. 5]</span>  
but it is not;  
<p class="assertion">therefore <span data-ref="0298.g1:/ A C /">$AC$</span> is not equal to <span data-ref="0298.g1:/ A B /">$AB$</span>.</p>

Neither is <span data-ref="0298.g1:/ A C /">$AC$</span> less than <span data-ref="0298.g1:/ A B /">$AB$</span>,  
for then the angle <span data-ref="0298.g1:< A B C )">$ABC$</span> would also have been less than the angle <span data-ref="0298.g1:< A C B )">$ACB$</span>; <span class="justification">[I. 18]</span>  
but it is not;  
<p class="assertion">therefore <span data-ref="0298.g1:/ A C /">$AC$</span> is not less than <span data-ref="0298.g1:/ A B /">$AB$</span>.</p>

And it was proved that it is not equal either.  
<p class="assertion">Therefore <span data-ref="0298.g1:/ A C /">$AC$</span> is greater than <span data-ref="0298.g1:/ A B /">$AB$</span>.</p>

<p class="qed">Therefore etc. <span class="justification">Q. E. D.</span></p>

This proposition, like I. 6, can be proved by merely *logical* deduction from I. 5 and I. 18 taken together, as pointed out by De Morgan. The general form of the argument used by De Morgan is given in his *Formal Logic* (1847), p. 25, thus:

“*Hypothesis.* Let there be any number of propositions or assertions—three for instance, $X$, $Y$ and $Z$—of which it is the property that one or the other must be true, *and one only*. Let there be three other propositions $P$, $Q$ and $R$ of which it is also the property that one, and one only, must be true. Let it be a connexion of those assertions that:
$$
\begin{aligned}
&\text{when } X \text{ is true, } P \text{ is true,} \\
&\text{when } Y \text{ is true, } Q \text{ is true,} \\
&\text{when } Z \text{ is true, } R \text{ is true.}
\end{aligned}
$$
*Consequence:* then it follows that,
$$
\begin{aligned}
&\text{when } P \text{ is true, } X \text{ is true,} \\
&\text{when } Q \text{ is true, } Y \text{ is true,} \\
&\text{when } R \text{ is true, } Z \text{ is true.”}
\end{aligned}
$$
