PROPOSITION 19.
---------------

.. enunciation::

   In any triangle the greater angle is subtended by the greater side.

.. picture:: 0298.g1.svg
   :alt: Proposition 19 figure

Let :g:`$ABC$ <0298.g1:< A B C >>` be a triangle having the angle :g:`$ABC$ <0298.g1:< A B C )>` greater than the angle :g:`$BCA$ <0298.g1:< B C A )>`;

I say that the side :g:`$AC$ <0298.g1:/ A C />` is also greater than the side :g:`$AB$ <0298.g1:/ A B />`.

For, if not, :g:`$AC$ <0298.g1:/ A C />` is either equal to :g:`$AB$ <0298.g1:/ A B />` or less.

Now :g:`$AC$ <0298.g1:/ A C />` is not equal to :g:`$AB$ <0298.g1:/ A B />`; for then the angle :g:`$ABC$ <0298.g1:< A B C )>` would also have been equal to the angle :g:`$ACB$ <0298.g1:< A C B )>`; :just:`[I. 5] <I.5>`

but it is not;

.. assertion::

   therefore :g:`$AC$ <0298.g1:/ A C />` is not equal to :g:`$AB$ <0298.g1:/ A B />`.

Neither is :g:`$AC$ <0298.g1:/ A C />` less than :g:`$AB$ <0298.g1:/ A B />`, for then the angle :g:`$ABC$ <0298.g1:< A B C )>` would also have been less than the angle :g:`$ACB$ <0298.g1:< A C B )>`; :just:`[I. 18] <I.18>`

but it is not;

.. assertion::

   therefore :g:`$AC$ <0298.g1:/ A C />` is not less than :g:`$AB$ <0298.g1:/ A B />`.

And it was proved that it is not equal either.

.. assertion::

   Therefore :g:`$AC$ <0298.g1:/ A C />` is greater than :g:`$AB$ <0298.g1:/ A B />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`

----

This proposition, like I. 6, can be proved by merely *logical* deduction from I. 5 and I. 18 taken together, as pointed out by :person:`De Morgan <de-morgan>`. The general form of the argument used by :person:`De Morgan <de-morgan>` is given in his *Formal Logic* (1847), p. 25, thus:

“*Hypothesis.* Let there be any number of propositions or assertions—three for instance, $X$, $Y$ and $Z$—of which it is the property that one or the other must be true, *and one only*. Let there be three other propositions $P$, $Q$ and $R$ of which it is also the property that one, and one only, must be true. Let it be a connexion of those assertions that:

$$
\begin{aligned}
&\text{when } X \text{ is true, } P \text{ is true,} \\
&\text{when } Y \text{ is true, } Q \text{ is true,} \\
&\text{when } Z \text{ is true, } R \text{ is true.}
\end{aligned}
$$

*Consequence:* then it follows that,

$$
\begin{aligned}
&\text{when } P \text{ is true, } X \text{ is true,} \\
&\text{when } Q \text{ is true, } Y \text{ is true,} \\
&\text{when } R \text{ is true, } Z \text{ is true.”}
\end{aligned}
$$
