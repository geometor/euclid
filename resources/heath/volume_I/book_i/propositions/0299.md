To apply this to the case before us, let us denote the sides of the triangle <span data-ref="0298.g1:< A B C >">$ABC$</span> by <span data-ref="0298.g1:/ B C /">$a$</span>, <span data-ref="0298.g1:/ A C /">$b$</span>, <span data-ref="0298.g1:/ A B /">$c$</span>, and the angles opposite to these sides by <span data-ref="0298.g1:< B A C )">$A$</span>, <span data-ref="0298.g1:< A B C )">$B$</span>, <span data-ref="0298.g1:< A C B )">$C$</span> respectively, and suppose that <span data-ref="0298.g1:/ B C /">$a$</span> is the base.

Then we have the three propositions,
$$
\begin{aligned}
&\text{when } b \text{ is equal to } c\text{, } B \text{ is equal to } C\text{,} & [\textbf{I. } 5] \\
&\left.
\begin{aligned}
&\text{when } b \text{ is greater than } c\text{, } B \text{ is greater than } C\text{,} \\
&\text{when } b \text{ is less than } c\text{, } B \text{ is less than } C\text{,}
\end{aligned}
\right\} & [\textbf{I. } 18]
\end{aligned}
$$
and it follows logically that,
$$
\begin{aligned}
&\text{when } B \text{ is equal to } C\text{, } b \text{ is equal to } c\text{,} & [\textbf{I. } 6] \\
&\left.
\begin{aligned}
&\text{when } B \text{ is greater than } C\text{, } b \text{ is greater than } c\text{,} \\
&\text{when } B \text{ is less than } C\text{, } b \text{ is less than } c\text{.}
\end{aligned}
\right\} & [\textbf{I. } 19]
\end{aligned}
$$

**Reductio ad absurdum by exhaustion.**  
Here, says Proclus (p. 318, 16—23), Euclid proves the impossibility “by means of division” (ἐκ διαιρέσεως). This means simply the separation of different hypotheses, each of which is inconsistent with the truth of the theorem to be proved, and which therefore must be successively shown to be impossible. If a straight line is not greater than a straight line, it must be either equal to it or less; thus in a *reductio ad absurdum* intended to prove such a theorem as I. 19 it is necessary to dispose successively of *two* hypotheses inconsistent with the truth of the theorem.

**Alternative (direct) proof.**  
Proclus gives a direct proof (pp. 319—321) which an-Nairīzī also has and attributes to Heron. It requires a lemma and is consequently open to the slight objection of separating a theorem from its converse. But the lemma and proof are worth giving.

*Lemma.*

*If an angle of a triangle be bisected and the straight line bisecting it meet the base and divide it into unequal parts, the sides containing the angle will be unequal, and the greater will be that which meets the greater segment of the base, and the less that which meets the less.*

Let <span data-ref="0299.g1:/ A D /">$AD$</span>, the bisector of the angle <span data-ref="0299.g1:< B A C )">$A$</span> of the triangle <span data-ref="0299.g1:< A B C >">$ABC$</span>, meet <span data-ref="0299.g1:/ B C /">$BC$</span> in <span data-ref="0299.g1:D">$D$</span>, making <span data-ref="0299.g1:/ C D /">$CD$</span> greater than <span data-ref="0299.g1:/ B D /">$BD$</span>.  
I say that <span data-ref="0299.g1:/ A C /">$AC$</span> is greater than <span data-ref="0299.g1:/ A B /">$AB$</span>.

![Heron/an-Nairizi Lemma for Direct Proof of I. 19 Figure](0299.g1.svg)

Produce <span data-ref="0299.g1:/ A D /">$AD$</span> to <span data-ref="0299.g1:E">$E$</span> so that <span data-ref="0299.g1:/ D E /">$DE$</span> is equal to <span data-ref="0299.g1:/ A D /">$AD$</span>. And, since <span data-ref="0299.g1:/ D C /">$DC$</span> is greater than <span data-ref="0299.g1:/ B D /">$BD$</span>, cut off <span data-ref="0299.g1:/ D F /">$DF$</span> equal to <span data-ref="0299.g1:/ B D /">$BD$</span>.  
Join <span data-ref="0299.g1:/ E F /">$EF$</span> and produce it to <span data-ref="0299.g1:G">$G$</span>.  
Then, since the two sides <span data-ref="0299.g1:/ A D /">$AD$</span>, <span data-ref="0299.g1:/ D B /">$DB$</span> are equal to the two sides <span data-ref="0299.g1:/ E D /">$ED$</span>, <span data-ref="0299.g1:/ D F /">$DF$</span>, and the vertical angles at <span data-ref="0299.g1:D">$D$</span> are equal,  
<span data-ref="0299.g1:/ A B /">$AB$</span> is equal to <span data-ref="0299.g1:/ E F /">$EF$</span>,  
and the angle <span data-ref="0299.g1:< D E F )">$DEF$</span> to the angle <span data-ref="0299.g1:< B A D )">$BAD$</span>,  
i.e. to the angle <span data-ref="0299.g1:< D A G )">$DAG$</span> (by hypothesis).  
Therefore <span data-ref="0299.g1:/ A G /">$AG$</span> is equal to <span data-ref="0299.g1:/ E G /">$EG$</span>,  
and therefore greater than <span data-ref="0299.g1:/ E F /">$EF$</span>, or <span data-ref="0299.g1:/ A B /">$AB$</span>.  
Hence, *a fortiori*, <span data-ref="0299.g1:/ A C /">$AC$</span> is greater than <span data-ref="0299.g1:/ A B /">$AB$</span>.
