**Proof of I. 19.**

Let <span data-ref="0300.g1:< A B C >">$ABC$</span> be a triangle in which the angle <span data-ref="0300.g1:< A B C )">$ABC$</span> is greater than the angle <span data-ref="0300.g1:< A C B )">$ACB$</span>.  
Bisect <span data-ref="0300.g1:/ B C /">$BC$</span> at <span data-ref="0300.g1:D">$D$</span>, join <span data-ref="0300.g1:/ A D /">$AD$</span>, and produce it to <span data-ref="0300.g1:E">$E$</span> so that <span data-ref="0300.g1:/ D E /">$DE$</span> is equal to <span data-ref="0300.g1:/ A D /">$AD$</span>. Join <span data-ref="0300.g1:/ B E /">$BE$</span>.

![Heron/an-Nairizi Proof of I. 19 Figure](0300.g1.svg)

Then the two sides <span data-ref="0300.g1:/ B D /">$BD$</span>, <span data-ref="0300.g1:/ D E /">$DE$</span> are equal to the two sides <span data-ref="0300.g1:/ C D /">$CD$</span>, <span data-ref="0300.g1:/ D A /">$DA$</span>, and the vertical angles at <span data-ref="0300.g1:D">$D$</span> are equal;  
therefore <span data-ref="0300.g1:/ B E /">$BE$</span> is equal to <span data-ref="0300.g1:/ A C /">$AC$</span>,  
and the angle <span data-ref="0300.g1:< D B E )">$DBE$</span> to the angle at <span data-ref="0300.g1:< A C B )">$C$</span>.  
But the angle at <span data-ref="0300.g1:< A C B )">$C$</span> is less than the angle <span data-ref="0300.g1:< A B C )">$ABC$</span>;  
therefore the angle <span data-ref="0300.g1:< D B E )">$DBE$</span> is less than the angle <span data-ref="0300.g1:< A B D )">$ABD$</span>.  
Hence, if <span data-ref="0300.g1:/ B F /">$BF$</span> bisect the angle <span data-ref="0300.g1:< A B E )">$ABE$</span>, <span data-ref="0300.g1:/ B F /">$BF$</span> meets <span data-ref="0300.g1:/ A E /">$AE$</span> between <span data-ref="0300.g1:A">$A$</span> and <span data-ref="0300.g1:D">$D$</span>. Therefore <span data-ref="0300.g1:/ E F /">$EF$</span> is greater than <span data-ref="0300.g1:/ F A /">$FA$</span>.  
It follows, by the lemma, that <span data-ref="0300.g1:/ B E /">$BE$</span> is greater than <span data-ref="0300.g1:/ B A /">$BA$</span>,  
that is, <span data-ref="0300.g1:/ A C /">$AC$</span> is greater than <span data-ref="0300.g1:/ A B /">$AB$</span>.

### PROPOSITION 20.

<p class="enunciation">In any triangle two sides taken together in any manner are greater than the remaining one.</p>

For let <span data-ref="0300.g2:< A B C >">$ABC$</span> be a triangle;  
I say that in the triangle <span data-ref="0300.g2:< A B C >">$ABC$</span> two sides taken together in any manner are greater than the remaining one, namely  
<p class="sub-clause"><span data-ref="0300.g2:/ B A /">$BA$</span>, <span data-ref="0300.g2:/ A C /">$AC$</span> greater than <span data-ref="0300.g2:/ B C /">$BC$</span>,</p>
<p class="sub-clause"><span data-ref="0300.g2:/ A B /">$AB$</span>, <span data-ref="0300.g2:/ B C /">$BC$</span> greater than <span data-ref="0300.g2:/ A C /">$AC$</span>,</p>
<p class="sub-clause"><span data-ref="0300.g2:/ B C /">$BC$</span>, <span data-ref="0300.g2:/ C A /">$CA$</span> greater than <span data-ref="0300.g2:/ A B /">$AB$</span>.</p>

![Proposition 20 figure](0300.g2.svg)

For let <span data-ref="0300.g2:[ B A ]">$BA$</span> be drawn through to the point <span data-ref="0300.g2:D">$D$</span>, let <span data-ref="0300.g2:/ D A /">$DA$</span> be made equal to <span data-ref="0300.g2:/ C A /">$CA$</span>, and let <span data-ref="0300.g2:/ D C /">$DC$</span> be joined.

Then, since <span data-ref="0300.g2:/ D A /">$DA$</span> is equal to <span data-ref="0300.g2:/ A C /">$AC$</span>,  
the angle <span data-ref="0300.g2:< A D C )">$ADC$</span> is also equal to the angle <span data-ref="0300.g2:< A C D )">$ACD$</span>; <span class="justification">[I. 5]</span>  
<p class="assertion">therefore the angle <span data-ref="0300.g2:< B C D )">$BCD$</span> is greater than the angle <span data-ref="0300.g2:< A D C )">$ADC$</span>. <span class="justification">[C. N. 5]</span></p>

And, since <span data-ref="0300.g2:< D C B >">$DCB$</span> is a triangle having the angle <span data-ref="0300.g2:< B C D )">$BCD$</span> greater than the angle <span data-ref="0300.g2:< B D C )">$BDC$</span>,  
and the greater angle is subtended by the greater side, <span class="justification">[I. 19]</span>  
<p class="assertion">therefore <span data-ref="0300.g2:/ D B /">$DB$</span> is greater than <span data-ref="0300.g2:/ B C /">$BC$</span>.</p>
