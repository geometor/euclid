(3) If the triangle be *scalene*, we can arrange the sides in order of length. Suppose <span data-ref="0301.g2:/ B C /">$BC$</span> is the greatest, <span data-ref="0301.g2:/ A B /">$AB$</span> the intermediate and <span data-ref="0301.g2:/ A C /">$AC$</span> the least side. Then it is obvious that <span data-ref="0301.g2:/ A B /">$AB$</span>, <span data-ref="0301.g2:/ B C /">$BC$</span> are together greater than <span data-ref="0301.g2:/ A C /">$AC$</span>, and <span data-ref="0301.g2:/ B C /">$BC$</span>, <span data-ref="0301.g2:/ C A /">$CA$</span> together greater than <span data-ref="0301.g2:/ A B /">$AB$</span>.

It only remains therefore to prove that <span data-ref="0301.g2:/ C A /">$CA$</span>, <span data-ref="0301.g2:/ A B /">$AB$</span> are together greater than <span data-ref="0301.g2:/ B C /">$BC$</span>.

We cut off from <span data-ref="0301.g2:/ B C /">$BC$</span> a length <span data-ref="0301.g2:/ B D /">$BD$</span> equal to the adjacent side, join <span data-ref="0301.g2:/ A D /">$AD$</span>, and proceed exactly as in the above case of the isosceles triangle.

*Third proof.*

This proof is by *reductio ad absurdum*.

Suppose that <span data-ref="0302.g1:/ B C /">$BC$</span> is the greatest side and, as before, we have to prove that <span data-ref="0302.g1:/ B A /">$BA$</span>, <span data-ref="0302.g1:/ A C /">$AC$</span> are greater than <span data-ref="0302.g1:/ B C /">$BC$</span>.

If they are not, they must be either equal to or less than <span data-ref="0302.g1:/ B C /">$BC$</span>.

(1) Suppose <span data-ref="0302.g1:/ B A /">$BA$</span>, <span data-ref="0302.g1:/ A C /">$AC$</span> are together equal to <span data-ref="0302.g1:/ B C /">$BC$</span>.

From <span data-ref="0302.g1:/ B C /">$BC$</span> cut off <span data-ref="0302.g1:/ B D /">$BD$</span> equal to <span data-ref="0302.g1:/ B A /">$BA$</span>, and join <span data-ref="0302.g1:/ A D /">$AD$</span>.

![Folio 0302 Figure 1 - Third Alternative Proof of I. 20 (Case 1)](0302.g1.svg)

It follows from the hypothesis that <span data-ref="0302.g1:/ D C /">$DC$</span> is equal to <span data-ref="0302.g1:/ A C /">$AC$</span>.

Then, since <span data-ref="0302.g1:/ B A /">$BA$</span> is equal to <span data-ref="0302.g1:/ B D /">$BD$</span>,  
the angle <span data-ref="0302.g1:< B D A )">$BDA$</span> is equal to the angle <span data-ref="0302.g1:< B A D )">$BAD$</span>.

Similarly, since <span data-ref="0302.g1:/ A C /">$AC$</span> is equal to <span data-ref="0302.g1:/ C D /">$CD$</span>,  
the angle <span data-ref="0302.g1:< C D A )">$CDA$</span> is equal to the angle <span data-ref="0302.g1:< C A D )">$CAD$</span>.

By addition, the angles <span data-ref="0302.g1:< B D A )">$BDA$</span>, <span data-ref="0302.g1:< A D C )">$ADC$</span> are together equal to the whole angle <span data-ref="0302.g1:< B A C )">$BAC$</span>.

That is, the angle <span data-ref="0302.g1:< B A C )">$BAC$</span> is equal to two right angles: which is impossible.

(2) Suppose <span data-ref="0302.g2:/ B A /">$BA$</span>, <span data-ref="0302.g2:/ A C /">$AC$</span> are together less than <span data-ref="0302.g2:/ B C /">$BC$</span>.

From <span data-ref="0302.g2:/ B C /">$BC$</span> cut off <span data-ref="0302.g2:/ B D /">$BD$</span> equal to <span data-ref="0302.g2:/ B A /">$BA$</span>, and from <span data-ref="0302.g2:/ C B /">$CB$</span> cut off <span data-ref="0302.g2:/ C E /">$CE$</span> equal to <span data-ref="0302.g2:/ C A /">$CA$</span>. Join <span data-ref="0302.g2:/ A D /">$AD$</span>, <span data-ref="0302.g2:/ A E /">$AE$</span>.

![Folio 0302 Figure 2 - Third Alternative Proof of I. 20 (Case 2)](0302.g2.svg)

In this case, we prove in the same way that  
the angle <span data-ref="0302.g2:< B D A )">$BDA$</span> is equal to the angle <span data-ref="0302.g2:< B A D )">$BAD$</span>, and  
the angle <span data-ref="0302.g2:< C E A )">$CEA$</span> to the angle <span data-ref="0302.g2:< C A E )">$CAE$</span>.

By addition, the sum of the angles <span data-ref="0302.g2:< B D A )">$BDA$</span>, <span data-ref="0302.g2:< A E C )">$AEC$</span> is equal to the sum of the angles <span data-ref="0302.g2:< B A D )">$BAD$</span>, <span data-ref="0302.g2:< C A E )">$CAE$</span>.

Now, by I. 16, the angle <span data-ref="0302.g2:< B D A )">$BDA$</span> is greater than the angle <span data-ref="0302.g2:< D A C )">$DAC$</span>, and therefore, *a fortiori*, greater than the angle <span data-ref="0302.g2:< E A C )">$EAC$</span>.

Similarly the angle <span data-ref="0302.g2:< A E C )">$AEC$</span> is greater than the angle <span data-ref="0302.g2:< B A D )">$BAD$</span>.

Hence the sum of the angles <span data-ref="0302.g2:< B D A )">$BDA$</span>, <span data-ref="0302.g2:< A E C )">$AEC$</span> is greater than the sum of the angles <span data-ref="0302.g2:< B A D )">$BAD$</span>, <span data-ref="0302.g2:< E A C )">$EAC$</span>.

But the former sum was also equal to the latter: which is impossible.
