Let <span data-ref="0304.g2:< A B C >">$ABC$</span> be an isosceles triangle in which the base <span data-ref="0304.g2:/ A C /">$AC$</span> is greater than either of the equal sides <span data-ref="0304.g2:/ A B /">$AB$</span>, <span data-ref="0304.g2:/ B C /">$BC$</span>.  
With centre <span data-ref="0304.g2:A">$A$</span> and radius <span data-ref="0304.g2:/ A B /">$AB$</span> describe a circle meeting <span data-ref="0304.g2:/ A C /">$AC$</span> in <span data-ref="0304.g2:D">$D$</span>.  
Draw any radius <span data-ref="0304.g2:/ A E F /">$AEF$</span> such that it meets <span data-ref="0304.g2:/ B C /">$BC$</span> in a point <span data-ref="0304.g2:F">$F$</span> outside the circle.  
Take any point <span data-ref="0304.g2:G">$G$</span> on <span data-ref="0304.g2:/ E F /">$EF$</span>, and through it draw <span data-ref="0304.g2:/ G H /">$GH$</span> parallel to <span data-ref="0304.g2:/ A C /">$AC$</span>. Take any point <span data-ref="0304.g2:K">$K$</span> on <span data-ref="0304.g2:/ G H /">$GH$</span>, and draw <span data-ref="0304.g2:/ K L /">$KL$</span> parallel to <span data-ref="0304.g2:/ F A /">$FA$</span> meeting <span data-ref="0304.g2:/ A C /">$AC$</span> in <span data-ref="0304.g2:L">$L$</span>.  
From <span data-ref="0304.g2:/ B C /">$BC$</span> cut off <span data-ref="0304.g2:/ B N /">$BN$</span> equal to <span data-ref="0304.g2:/ E G /">$EG$</span>.  
Thus <span data-ref="0304.g2:/ A G /">$AG$</span>, or <span data-ref="0304.g2:/ L K /">$LK$</span>, is equal to the sum of <span data-ref="0304.g2:/ A B /">$AB$</span>, <span data-ref="0304.g2:/ B N /">$BN$</span>, and <span data-ref="0304.g2:/ C N /">$CN$</span> is less than <span data-ref="0304.g2:/ L K /">$LK$</span>.  
Now <span data-ref="0304.g2:/ G F /">$GF$</span>, <span data-ref="0304.g2:/ F H /">$FH$</span> are together greater than <span data-ref="0304.g2:/ G H /">$GH$</span>,  
and <span data-ref="0304.g2:/ C H /">$CH$</span>, <span data-ref="0304.g2:/ H K /">$HK$</span> together greater than <span data-ref="0304.g2:/ C K /">$CK$</span>.  
Therefore, by addition,  
<span data-ref="0304.g2:/ C F /">$CF$</span>, <span data-ref="0304.g2:/ F G /">$FG$</span>, <span data-ref="0304.g2:/ H K /">$HK$</span> are together greater than <span data-ref="0304.g2:/ C K /">$CK$</span>, <span data-ref="0304.g2:/ H G /">$HG$</span>.  
Subtracting <span data-ref="0304.g2:/ H K /">$HK$</span> from each side, we see that  
<span data-ref="0304.g2:/ C F /">$CF$</span>, <span data-ref="0304.g2:/ F G /">$FG$</span> are together greater than <span data-ref="0304.g2:/ C K /">$CK$</span>, <span data-ref="0304.g2:/ K G /">$KG$</span>;  
therefore, if we add <span data-ref="0304.g2:/ A G /">$AG$</span> to each,  
<span data-ref="0304.g2:/ A F /">$AF$</span>, <span data-ref="0304.g2:/ F C /">$FC$</span> are together greater than <span data-ref="0304.g2:/ A G /">$AG$</span>, <span data-ref="0304.g2:/ G K /">$GK$</span>, <span data-ref="0304.g2:/ K C /">$KC$</span>.  
And <span data-ref="0304.g2:/ A B /">$AB$</span>, <span data-ref="0304.g2:/ B C /">$BC$</span> are together greater than <span data-ref="0304.g2:/ A F /">$AF$</span>, <span data-ref="0304.g2:/ F C /">$FC$</span>. [I. 21]  
Therefore <span data-ref="0304.g2:/ A B /">$AB$</span>, <span data-ref="0304.g2:/ B C /">$BC$</span> are together greater than <span data-ref="0304.g2:/ A G /">$AG$</span>, <span data-ref="0304.g2:/ G K /">$GK$</span>, <span data-ref="0304.g2:/ K C /">$KC$</span>.  
But, by construction, <span data-ref="0304.g2:/ A B /">$AB$</span>, <span data-ref="0304.g2:/ B N /">$BN$</span> are together equal to <span data-ref="0304.g2:/ A G /">$AG$</span>;  
therefore, by subtraction, <span data-ref="0304.g2:/ N C /">$NC$</span> is greater than <span data-ref="0304.g2:/ G K /">$GK$</span>, <span data-ref="0304.g2:/ K C /">$KC$</span>,  
and *a fortiori* greater than <span data-ref="0304.g2:/ K C /">$KC$</span>.  
Take on <span data-ref="0304.g2:[ K C ]">$KC$</span> produced a point <span data-ref="0304.g2:M">$M$</span> such that <span data-ref="0304.g2:/ K M /">$KM$</span> is equal to <span data-ref="0304.g2:/ N C /">$NC$</span>;  
with centre <span data-ref="0304.g2:K">$K$</span> and radius <span data-ref="0304.g2:/ K M /">$KM$</span> describe a circle meeting <span data-ref="0304.g2:/ C L /">$CL$</span> in <span data-ref="0304.g2:O">$O$</span>, and join <span data-ref="0304.g2:/ K O /">$KO$</span>.  
Then shall <span data-ref="0304.g2:/ L K /">$LK$</span>, <span data-ref="0304.g2:/ K O /">$KO$</span> be equal to <span data-ref="0304.g2:/ A B /">$AB$</span>, <span data-ref="0304.g2:/ B C /">$BC$</span>.  
For, by construction, <span data-ref="0304.g2:/ L K /">$LK$</span> is equal to the sum of <span data-ref="0304.g2:/ A B /">$AB$</span>, <span data-ref="0304.g2:/ B N /">$BN$</span>, and <span data-ref="0304.g2:/ K O /">$KO$</span> is equal to <span data-ref="0304.g2:/ N C /">$NC$</span>;  
therefore <span data-ref="0304.g2:/ L K /">$LK$</span>, <span data-ref="0304.g2:/ K O /">$KO$</span> are together equal to <span data-ref="0304.g2:/ A B /">$AB$</span>, <span data-ref="0304.g2:/ B C /">$BC$</span>.

It is after I. 21 that (as remarked by De Morgan) the important proposition about the perpendicular and obliques drawn from a point to a straight line of unlimited length is best introduced:

*Of all straight lines that can be drawn to a given straight line of unlimited length from a given point without it:*  
*(a) the perpendicular is the shortest;*  
*(b) of the obliques, that is the greater the foot of which is further from the perpendicular;*  
*(c) given one oblique, only one other can be found of the same length, namely that the foot of which is equally distant with the foot of the given one from the perpendicular, but on the other side of it.*

Let <span data-ref="0305.g1:A">$A$</span> be the given point, <span data-ref="0305.g1:[ B C ]">$BC$</span> the given straight line; let <span data-ref="0305.g1:/ A D /">$AD$</span> be the perpendicular from <span data-ref="0305.g1:A">$A$</span> on <span data-ref="0305.g1:[ B C ]">$BC$</span>, and <span data-ref="0305.g1:/ A E /">$AE$</span>, <span data-ref="0305.g1:/ A F /">$AF$</span> any two obliques of which <span data-ref="0305.g1:/ A F /">$AF$</span> makes the greater angle with <span data-ref="0305.g1:/ A D /">$AD$</span>.

Produce <span data-ref="0305.g1:/ A D /">$AD$</span> to <span data-ref="0305.g1:A'">$A'$</span>, making <span data-ref="0305.g1:/ A' D /">$A'D$</span> equal to <span data-ref="0305.g1:/ A D /">$AD$</span>, and join <span data-ref="0305.g1:/ A' E /">$A'E$</span>, <span data-ref="0305.g1:/ A' F /">$A'F$</span>.  
Then the triangles <span data-ref="0305.g1:< A D E >">$ADE$</span>, <span data-ref="0305.g1:< A' D E >">$A'DE$</span> are equal in all respects; and so are the triangles <span data-ref="0305.g1:< A D F >">$ADF$</span>, <span data-ref="0305.g1:< A' D F >">$A'DF$</span>.
