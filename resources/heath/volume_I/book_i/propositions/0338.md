<sup>5</sup> I say that the opposite sides and angles of the parallelogram <span data-ref="0338.g1:&lt; A C D B &gt;">$ACDB$</span> are equal to one another, and the diameter <span data-ref="0338.g1:/ B C /">$BC$</span> bisects it.

![Folio 0338 Figure 1 - Proposition 34](0338.g1.svg)

For, since <span data-ref="0338.g1:/ A B /">$AB$</span> is parallel to <span data-ref="0338.g1:/ C D /">$CD$</span>,  
and the straight line <span data-ref="0338.g1:/ B C /">$BC$</span> has fallen  
<sup>10</sup> upon them,  
<p class="assertion">the alternate angles <span data-ref="0338.g1:&lt; A B C )">$ABC$</span>, <span data-ref="0338.g1:&lt; B C D )">$BCD$</span> are equal to one another. <span class="justification">[I. 29]</span></p>

Again, since <span data-ref="0338.g1:/ A C /">$AC$</span> is parallel to <span data-ref="0338.g1:/ B D /">$BD$</span>,  
and <span data-ref="0338.g1:/ B C /">$BC$</span> has fallen upon them,  
<p class="assertion"><sup>15</sup> the alternate angles <span data-ref="0338.g1:&lt; A C B )">$ACB$</span>, <span data-ref="0338.g1:&lt; C B D )">$CBD$</span> are equal to one another. <span class="justification">[I. 29]</span></p>

Therefore <span data-ref="0338.g1:&lt; A B C &gt;">$ABC$</span>, <span data-ref="0338.g1:&lt; D C B &gt;">$DCB$</span> are two triangles having the two angles <span data-ref="0338.g1:&lt; A B C )">$ABC$</span>, <span data-ref="0338.g1:&lt; B C A )">$BCA$</span> equal to the two angles <span data-ref="0338.g1:&lt; D C B )">$DCB$</span>, <span data-ref="0338.g1:&lt; C B D )">$CBD$</span> respectively, and one side equal to one side, namely that  
<sup>20</sup> adjoining the equal angles and common to both of them, <span data-ref="0338.g1:/ B C /">$BC$</span>;  
<p class="sub-clause">therefore they will also have the remaining sides equal to the remaining sides respectively, and the remaining angle to the remaining angle; <span class="justification">[I. 26]</span></p>
<p class="assertion">therefore the side <span data-ref="0338.g1:/ A B /">$AB$</span> is equal to <span data-ref="0338.g1:/ C D /">$CD$</span>,</p>
<p class="assertion"><sup>25</sup> and <span data-ref="0338.g1:/ A C /">$AC$</span> to <span data-ref="0338.g1:/ B D /">$BD$</span>,</p>
<p class="assertion">and further the angle <span data-ref="0338.g1:&lt; B A C )">$BAC$</span> is equal to the angle <span data-ref="0338.g1:&lt; C D B )">$CDB$</span>.</p>

And, since the angle <span data-ref="0338.g1:&lt; A B C )">$ABC$</span> is equal to the angle <span data-ref="0338.g1:&lt; B C D )">$BCD$</span>,  
and the angle <span data-ref="0338.g1:&lt; C B D )">$CBD$</span> to the angle <span data-ref="0338.g1:&lt; A C B )">$ACB$</span>,  
<p class="assertion">the whole angle <span data-ref="0338.g1:&lt; A B D )">$ABD$</span> is equal to the whole angle <span data-ref="0338.g1:&lt; A C D )">$ACD$</span>. <span class="justification">[C. N. 2]</span></p>
<p class="sub-clause"><sup>30</sup> And the angle <span data-ref="0338.g1:&lt; B A C )">$BAC$</span> was also proved equal to the angle <span data-ref="0338.g1:&lt; C D B )">$CDB$</span>.</p>
<p class="assertion">Therefore in parallelogrammic areas the opposite sides and angles are equal to one another.</p>

I say, next, that the diameter also bisects the areas.

For, since <span data-ref="0338.g1:/ A B /">$AB$</span> is equal to <span data-ref="0338.g1:/ C D /">$CD$</span>,  
<sup>35</sup> and <span data-ref="0338.g1:/ B C /">$BC$</span> is common,  
the two sides <span data-ref="0338.g1:/ A B /">$AB$</span>, <span data-ref="0338.g1:/ B C /">$BC$</span> are equal to the two sides <span data-ref="0338.g1:/ D C /">$DC$</span>, <span data-ref="0338.g1:/ C B /">$CB$</span> respectively;  
and the angle <span data-ref="0338.g1:&lt; A B C )">$ABC$</span> is equal to the angle <span data-ref="0338.g1:&lt; B C D )">$BCD$</span>;  
<p class="sub-clause">therefore the base <span data-ref="0338.g1:/ A C /">$AC$</span> is also equal to <span data-ref="0338.g1:/ D B /">$DB$</span>,</p>
<p class="assertion"><sup>40</sup> and the triangle <span data-ref="0338.g1:&lt; A B C &gt;">$ABC$</span> is equal to the triangle <span data-ref="0338.g1:&lt; D C B &gt;">$DCB$</span>. <span class="justification">[I. 4]</span></p>
<p class="assertion">Therefore the diameter <span data-ref="0338.g1:/ B C /">$BC$</span> bisects the parallelogram <span data-ref="0338.g1:&lt; A C D B &gt;">$ACDB$</span>.</p>

<p class="qed">Q. E. D.</p>
