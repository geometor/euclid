An-Nairīzī gives after I. 31 a neat construction for dividing a straight line into any number of equal parts (ed. Curtze, p. 74, ed. Besthorn-Heiberg, pp. 141–3) which requires only one measurement repeated, together with the properties of parallel lines including I. 33, 34. As I. 33, 34 are assumed, I place the problem here. The particular case taken is the problem of dividing a straight line into *three* equal parts.

![Folio 0340 Figure 1 - An-Nairīzī's Construction for Dividing a Straight Line into Equal Parts](0340.g1.svg)

Let <span data-ref="0340.g1:/ A B /">$AB$</span> be the given straight line. Draw <span data-ref="0340.g1:/ A C /">$AC$</span>, <span data-ref="0340.g1:/ B D /">$BD$</span> at right angles to it on opposite sides.

An-Nairīzī takes <span data-ref="0340.g1:/ A C /">$AC$</span>, <span data-ref="0340.g1:/ B D /">$BD$</span> of the same length and then bisects <span data-ref="0340.g1:/ A C /">$AC$</span> at <span data-ref="0340.g1:E">$E$</span> and <span data-ref="0340.g1:/ B D /">$BD$</span> at <span data-ref="0340.g1:F">$F$</span>. But of course it is even simpler to measure <span data-ref="0340.g1:/ A E /">$AE$</span>, <span data-ref="0340.g1:/ E C /">$EC$</span> along one perpendicular equal and of any length, and <span data-ref="0340.g1:/ B F /">$BF$</span>, <span data-ref="0340.g1:/ F D /">$FD$</span> along the other also equal and of the same length.

Join <span data-ref="0340.g1:/ E D /">$ED$</span>, <span data-ref="0340.g1:/ C F /">$CF$</span> meeting <span data-ref="0340.g1:/ A B /">$AB$</span> in <span data-ref="0340.g1:G">$G$</span>, <span data-ref="0340.g1:H">$H$</span> respectively.

Then shall <span data-ref="0340.g1:/ A G /">$AG$</span>, <span data-ref="0340.g1:/ G H /">$GH$</span>, <span data-ref="0340.g1:/ H B /">$HB$</span> all be equal.

Draw <span data-ref="0340.g1:/ H K /">$HK$</span> parallel to <span data-ref="0340.g1:/ A C /">$AC$</span>, or at right angles to <span data-ref="0340.g1:/ A B /">$AB$</span>.

Since now <span data-ref="0340.g1:/ E C /">$EC$</span>, <span data-ref="0340.g1:/ F D /">$FD$</span> are equal and parallel,  
<span data-ref="0340.g1:/ E D /">$ED$</span>, <span data-ref="0340.g1:/ C F /">$CF$</span> are equal and parallel. [I. 33]  
And <span data-ref="0340.g1:/ H K /">$HK$</span> was drawn parallel to <span data-ref="0340.g1:/ A C /">$AC$</span>.  
Therefore <span data-ref="0340.g1:&lt; E C H K &gt;">$ECHK$</span> is a parallelogram; whence <span data-ref="0340.g1:/ K H /">$KH$</span> is equal as well as parallel to <span data-ref="0340.g1:/ E C /">$EC$</span>, and therefore to <span data-ref="0340.g1:/ E A /">$EA$</span>.

The triangles <span data-ref="0340.g1:&lt; E A G &gt;">$EAG$</span>, <span data-ref="0340.g1:&lt; K H G &gt;">$KHG$</span> have now two angles respectively equal and the sides <span data-ref="0340.g1:/ A E /">$AE$</span>, <span data-ref="0340.g1:/ H K /">$HK$</span> equal.  
Thus the triangles are equal in all respects, and  
<span data-ref="0340.g1:/ A G /">$AG$</span> is equal to <span data-ref="0340.g1:/ G H /">$GH$</span>.

Similarly the triangles <span data-ref="0340.g1:&lt; K H G &gt;">$KHG$</span>, <span data-ref="0340.g1:&lt; F B H &gt;">$FBH$</span> are equal in all respects, and  
<span data-ref="0340.g1:/ G H /">$GH$</span> is equal to <span data-ref="0340.g1:/ H B /">$HB$</span>.

If now we wish to extend the problem to the case where <span data-ref="0340.g1:/ A B /">$AB$</span> is to be divided into $n$ parts, we have only to measure ($n - 1$) successive equal lengths along <span data-ref="0340.g1:/ A C /">$AC$</span> and ($n - 1$) successive lengths, each equal to the others, along <span data-ref="0340.g1:/ B D /">$BD$</span>. Then join the first point arrived at on <span data-ref="0340.g1:/ A C /">$AC$</span> to the last point on <span data-ref="0340.g1:/ B D /">$BD$</span>, the second on <span data-ref="0340.g1:/ A C /">$AC$</span> to the last but one on <span data-ref="0340.g1:/ B D /">$BD$</span>, and so on; and the joining lines cut <span data-ref="0340.g1:/ A B /">$AB$</span> in points dividing it into $n$ equal parts.

### PROPOSITION 35.

<p class="enunciation">
Parallelograms which are on the same base and in the same parallels are equal to one another.
</p>

Let <span data-ref="0341.g1:&lt; A B C D &gt;">$ABCD$</span>, <span data-ref="0341.g1:&lt; E B C F &gt;">$EBCF$</span> be parallelograms on the same base <span data-ref="0341.g1:/ B C /">$BC$</span> and in the same parallels <span data-ref="0341.g1:/ A F /">$AF$</span>, <span data-ref="0341.g1:/ B C /">$BC$</span>;  
<sup>5</sup>I say that <span data-ref="0341.g1:&lt; A B C D &gt;">$ABCD$</span> is equal to the parallelogram <span data-ref="0341.g1:&lt; E B C F &gt;">$EBCF$</span>.

For, since <span data-ref="0341.g1:&lt; A B C D &gt;">$ABCD$</span> is a parallelogram,  
<span data-ref="0341.g1:/ A D /">$AD$</span> is equal to <span data-ref="0341.g1:/ B C /">$BC$</span>. <span class="justification">[I. 34]</span>
