### PROPOSITION 39.

<p class="enunciation">Equal triangles which are on the same base and on the<br>
same side are also in the same parallels.</p>

Let <span data-ref="0350.g2:< A B C >">$ABC$</span>, <span data-ref="0350.g2:< D B C >">$DBC$</span> be equal triangles which are on the same base <span data-ref="0350.g2:/ B C /">$BC$</span> and on the same side of it;  
<sup>5</sup> [I say that they are also in the same parallels.]  
And [For] let <span data-ref="0350.g2:/ A D /">$AD$</span> be joined;  
I say that <span data-ref="0350.g2:/ A D /">$AD$</span> is parallel to <span data-ref="0350.g2:/ B C /">$BC$</span>.

![Folio 0350 Figure 2 - Proposition 39](0350.g2.svg)

For, if not, let <span data-ref="0350.g2:/ A E /">$AE$</span> be drawn through the point <span data-ref="0350.g2:A">$A$</span> parallel to the straight line  
<sup>10</sup> <span data-ref="0350.g2:/ B C /">$BC$</span>, <span class="justification">[I. 31]</span>  
and let <span data-ref="0350.g2:/ E C /">$EC$</span> be joined.

Therefore the triangle <span data-ref="0350.g2:< A B C >">$ABC$</span> is equal to the triangle <span data-ref="0350.g2:< E B C >">$EBC$</span>;  
for it is on the same base <span data-ref="0350.g2:/ B C /">$BC$</span> with it and in the same  
<sup>15</sup> parallels. <span class="justification">[I. 37]</span>

But <span data-ref="0350.g2:< A B C >">$ABC$</span> is equal to <span data-ref="0350.g2:< D B C >">$DBC$</span>;
<p class="assertion">therefore <span data-ref="0350.g2:< D B C >">$DBC$</span> is also equal to <span data-ref="0350.g2:< E B C >">$EBC$</span>, <span class="justification">[C. N. 1]</span><br>
the greater to the less: which is impossible.</p>

<p class="assertion">Therefore <span data-ref="0350.g2:/ A E /">$AE$</span> is not parallel to <span data-ref="0350.g2:/ B C /">$BC$</span>.</p>

<sup>20</sup> Similarly we can prove that neither is any other straight line except <span data-ref="0350.g2:/ A D /">$AD$</span>;
<p class="assertion">therefore <span data-ref="0350.g2:/ A D /">$AD$</span> is parallel to <span data-ref="0350.g2:/ B C /">$BC$</span>.</p>

<p class="qed">Therefore etc. <span class="justification">Q. E. D.</span></p>
