There is no necessity for :person:`Heron <heron>` to take account of the position of :g:`$F$ <0350.g1:F>` in relation to the side opposite :g:`$D$ <0350.g1:D>`. For in the first and third cases :g:`$F$ <0350.g1:F>` must fall

.. picture:: 0350.g1.svg
   :alt: Folio 0350 Figure 1 - Proposition 38 Commentary (Heron, Alternative Position)

in the position in which :person:`Euclid <euclid>` draws it in I. 24, whatever be the relative lengths of :g:`$AB$ <0350.g1:/ A B />`, :g:`$AC$ <0350.g1:/ A C />`. In the second case the figure may be as annexed, but the proof is the same, or rather the case needs no proof at all.

----

PROPOSITION 39.
---------------

.. enunciation::

   Equal triangles which are on the same base and on the same side are also in the same parallels.

Let :g:`$ABC$ <0350.g2:< A B C >>`, :g:`$DBC$ <0350.g2:< D B C >>` be equal triangles which are on the same base :g:`$BC$ <0350.g2:/ B C />` and on the same side of it; [I say that they are also in the same parallels.]\ [#f1]_ And [For] let :g:`$AD$ <0350.g2:/ A D />` be joined;

I say that :g:`$AD$ <0350.g2:/ A D />` is parallel to :g:`$BC$ <0350.g2:/ B C />`.

.. picture:: 0350.g2.svg
   :alt: Folio 0350 Figure 2 - Proposition 39

For, if not, let :g:`$AE$ <0350.g2:/ A E />` be drawn through the point :g:`$A$ <0350.g2:A>` parallel to the straight line :g:`$BC$ <0350.g2:/ B C />`, :just:`[I. 31] <I.31>`

and let :g:`$EC$ <0350.g2:/ E C />` be joined.

Therefore the triangle :g:`$ABC$ <0350.g2:< A B C >>` is equal to the triangle :g:`$EBC$ <0350.g2:< E B C >>`; for it is on the same base :g:`$BC$ <0350.g2:/ B C />` with it and in the same parallels. :just:`[I. 37] <I.37>`

But :g:`$ABC$ <0350.g2:< A B C >>` is equal to :g:`$DBC$ <0350.g2:< D B C >>`;

.. assertion::

   therefore :g:`$DBC$ <0350.g2:< D B C >>` is also equal to :g:`$EBC$ <0350.g2:< E B C >>`, :just:`[C. N. 1] <I.cn.1>` the greater to the less: which is impossible.

.. assertion::

   Therefore :g:`$AE$ <0350.g2:/ A E />` is not parallel to :g:`$BC$ <0350.g2:/ B C />`.

Similarly we can prove that neither is any other straight line except :g:`$AD$ <0350.g2:/ A D />`;

.. assertion::

   therefore :g:`$AD$ <0350.g2:/ A D />` is parallel to :g:`$BC$ <0350.g2:/ B C />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
