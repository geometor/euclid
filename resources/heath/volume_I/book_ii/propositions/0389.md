# BOOK II. PROPOSITIONS.

### PROPOSITION 1.

<p class="enunciation">If there be two straight lines, and one of them be cut into<br />
any number of segments whatever, the rectangle contained by<br />
the two straight lines is equal to the rectangles contained by the<br />
uncut straight line and each of the segments.</p>

<sup>5</sup> Let <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ B C /">$BC$</span> be two straight lines, and let <span data-ref="0389.g1:/ B C /">$BC$</span> be cut at random at the points <span data-ref="0389.g1:D">$D$</span>, <span data-ref="0389.g1:E">$E$</span>;  
I say that the rectangle contained by <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ B C /">$BC$</span> is equal to the rectangle contained by <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ B D /">$BD$</span>, that contained by <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ D E /">$DE$</span> and <sup>10</sup> that contained by <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ E C /">$EC$</span>.

![Diagram](0389.g1.svg)

For let <span data-ref="0389.g1:/ B F /">$BF$</span> be drawn from <span data-ref="0389.g1:B">$B$</span> at right angles to <span data-ref="0389.g1:/ B C /">$BC$</span>; <span class="justification">[I. 11]</span>  
let <span data-ref="0389.g1:/ B G /">$BG$</span> be made equal to <span data-ref="0389.g1:A">$A$</span>, <span class="justification">[I. 3]</span>  
through <span data-ref="0389.g1:G">$G$</span> let <span data-ref="0389.g1:/ G H /">$GH$</span> be drawn <sup>15</sup> parallel to <span data-ref="0389.g1:/ B C /">$BC$</span>, <span class="justification">[I. 31]</span>  
and through <span data-ref="0389.g1:D">$D$</span>, <span data-ref="0389.g1:E">$E$</span>, <span data-ref="0389.g1:C">$C$</span> let <span data-ref="0389.g1:/ D K /">$DK$</span>, <span data-ref="0389.g1:/ E L /">$EL$</span>, <span data-ref="0389.g1:/ C H /">$CH$</span> be drawn parallel to <span data-ref="0389.g1:/ B G /">$BG$</span>.

<p class="assertion">Then <span data-ref="0389.g1:&lt; B H &gt;">$BH$</span> is equal to <span data-ref="0389.g1:&lt; B K &gt;">$BK$</span>, <span data-ref="0389.g1:&lt; D L &gt;">$DL$</span>, <span data-ref="0389.g1:&lt; E H &gt;">$EH$</span>.</p>

<sup>20</sup> Now <span data-ref="0389.g1:&lt; B H &gt;">$BH$</span> is the rectangle <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ B C /">$BC$</span>, for it is contained by <span data-ref="0389.g1:/ B G /">$GB$</span>, <span data-ref="0389.g1:/ B C /">$BC$</span>, and <span data-ref="0389.g1:/ B G /">$BG$</span> is equal to <span data-ref="0389.g1:A">$A$</span>;  
<p class="sub-clause"><span data-ref="0389.g1:&lt; B K &gt;">$BK$</span> is the rectangle <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ B D /">$BD$</span>, for it is contained by <span data-ref="0389.g1:/ B G /">$GB$</span>, <span data-ref="0389.g1:/ B D /">$BD$</span>, and <span data-ref="0389.g1:/ B G /">$BG$</span> is equal to <span data-ref="0389.g1:A">$A$</span>;</p>  
<p class="sub-clause">and <span data-ref="0389.g1:&lt; D L &gt;">$DL$</span> is the rectangle <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ D E /">$DE$</span>, for <span data-ref="0389.g1:/ D K /">$DK$</span>, that is <span data-ref="0389.g1:/ B G /">$BG$</span> <span class="justification">[I. 34]</span>, <sup>25</sup> is equal to <span data-ref="0389.g1:A">$A$</span>.</p>  
<p class="sub-clause">Similarly also <span data-ref="0389.g1:&lt; E H &gt;">$EH$</span> is the rectangle <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ E C /">$EC$</span>.</p>

<p class="assertion">Therefore the rectangle <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ B C /">$BC$</span> is equal to the rectangle <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ B D /">$BD$</span>, the rectangle <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ D E /">$DE$</span> and the rectangle <span data-ref="0389.g1:A">$A$</span>, <span data-ref="0389.g1:/ E C /">$EC$</span>.</p>

<p class="qed">Therefore etc. <span class="justification">Q. E. D.</span></p>
