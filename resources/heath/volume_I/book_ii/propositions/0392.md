### PROPOSITION 3.

<p class="enunciation">If a straight line be cut at random, the rectangle contained<br />
by the whole and one of the segments is equal to the rectangle<br />
contained by the segments and the square on the aforesaid<br />
segment.</p>

For let the straight line <span data-ref="0392.g1:/ A B /">$AB$</span> be cut at random at <span data-ref="0392.g1:C">$C$</span>;  
I say that the rectangle contained by <span data-ref="0392.g1:/ A B /">$AB$</span>, <span data-ref="0392.g1:/ B C /">$BC$</span> is equal to the rectangle contained by <span data-ref="0392.g1:/ A C /">$AC$</span>, <span data-ref="0392.g1:/ B C /">$CB$</span> together with the square on <span data-ref="0392.g1:/ B C /">$BC$</span>.

![Diagram](0392.g1.svg)

For let the square <span data-ref="0392.g1:< C D E B >">$CDEB$</span> be described on <span data-ref="0392.g1:/ B C /">$CB$</span>; <span class="justification">[I. 46]</span>  
let <span data-ref="0392.g1:/ D E /">$ED$</span> be drawn through to <span data-ref="0392.g1:F">$F$</span>,  
and through <span data-ref="0392.g1:A">$A$</span> let <span data-ref="0392.g1:/ A F /">$AF$</span> be drawn parallel to either <span data-ref="0392.g1:/ C D /">$CD$</span> or <span data-ref="0392.g1:/ B E /">$BE$</span>. <span class="justification">[I. 31]</span>

<p class="assertion">Then <span data-ref="0392.g1:< A E >">$AE$</span> is equal to <span data-ref="0392.g1:< A D >">$AD$</span>, <span data-ref="0392.g1:< C E >">$CE$</span>.</p>

Now <span data-ref="0392.g1:< A E >">$AE$</span> is the rectangle contained by <span data-ref="0392.g1:/ A B /">$AB$</span>, <span data-ref="0392.g1:/ B C /">$BC$</span>, for it is contained by <span data-ref="0392.g1:/ A B /">$AB$</span>, <span data-ref="0392.g1:/ B E /">$BE$</span>, and <span data-ref="0392.g1:/ B E /">$BE$</span> is equal to <span data-ref="0392.g1:/ B C /">$BC$</span>;  
<p class="sub-clause"><span data-ref="0392.g1:< A D >">$AD$</span> is the rectangle <span data-ref="0392.g1:/ A C /">$AC$</span>, <span data-ref="0392.g1:/ B C /">$CB$</span>, for <span data-ref="0392.g1:/ C D /">$DC$</span> is equal to <span data-ref="0392.g1:/ B C /">$CB$</span>;</p>  
<p class="sub-clause">and <span data-ref="0392.g1:< D B >">$DB$</span> is the square on <span data-ref="0392.g1:/ B C /">$CB$</span>.</p>

<p class="assertion">Therefore the rectangle contained by <span data-ref="0392.g1:/ A B /">$AB$</span>, <span data-ref="0392.g1:/ B C /">$BC$</span> is equal to the rectangle contained by <span data-ref="0392.g1:/ A C /">$AC$</span>, <span data-ref="0392.g1:/ B C /">$CB$</span> together with the square on <span data-ref="0392.g1:/ B C /">$BC$</span>.</p>

<p class="qed">Therefore etc. <span class="justification">Q. E. D.</span></p>
