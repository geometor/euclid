This proposition is quoted by Pappus (p. 428, ed. Hultsch) and is used also by Euclid himself in the *Data*, Prop. 86. Further, it is of decided use in proving the fundamental property of a parabola.

Two alternative proofs are worth giving.

The first is that suggested by the consideration mentioned in the last note, though the proof is old enough, being given by Clavius and others. It is of the semi-algebraical type.

Produce <span data-ref="0404.g1:/ A B /">$AB$</span> to <span data-ref="0404.g1:D">$D$</span> (in the figure of the proposition), so that <span data-ref="0404.g1:/ B D /">$BD$</span> is equal to <span data-ref="0404.g1:/ B C /">$BC$</span>.

By II. 4, the square on <span data-ref="0404.g1:/ A D /">$AD$</span> is equal to the squares on <span data-ref="0404.g1:/ A B /">$AB$</span>, <span data-ref="0404.g1:/ B D /">$BD$</span> and twice the rectangle <span data-ref="0404.g1:/ A B /">$AB$</span>, <span data-ref="0404.g1:/ B D /">$BD$</span>, i.e. to the squares on <span data-ref="0404.g1:/ A B /">$AB$</span>, <span data-ref="0404.g1:/ B C /">$BC$</span> and twice the rectangle <span data-ref="0404.g1:/ A B /">$AB$</span>, <span data-ref="0404.g1:/ B C /">$BC$</span>.

By II. 7, the squares on <span data-ref="0404.g1:/ A B /">$AB$</span>, <span data-ref="0404.g1:/ B C /">$BC$</span> are equal to twice the rectangle <span data-ref="0404.g1:/ A B /">$AB$</span>, <span data-ref="0404.g1:/ B C /">$BC$</span> together with the square on <span data-ref="0404.g1:/ A C /">$AC$</span>.

Therefore the square on <span data-ref="0404.g1:/ A D /">$AD$</span> is equal to four times the rectangle <span data-ref="0404.g1:/ A B /">$AB$</span>, <span data-ref="0404.g1:/ B C /">$BC$</span> together with the square on <span data-ref="0404.g1:/ A C /">$AC$</span>.
