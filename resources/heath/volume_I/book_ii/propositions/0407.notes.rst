Semantic & SVG Correspondence
-----------------------------

1. **Right Isosceles Sub-Triangles**:

   - $\triangle EGF$ has angles $45^\circ, 45^\circ, 90^\circ \implies EG = GF$.
   - $\triangle FDB$ has angles $45^\circ, 45^\circ, 90^\circ \implies FD = DB$.

2. **Pythagorean Cascades**:

   - $EA^2 = AC^2 + CE^2 = 2AC^2$.
   - $EF^2 = EG^2 + GF^2 = 2GF^2 = 2CD^2$ (since $GF = CD$ by [I. 34]).
   - Hypotenuse $AF^2 = AE^2 + EF^2 = 2AC^2 + 2CD^2 = 2(AC^2 + CD^2)$.
   - But in right $\triangle ADF$, $AF^2 = AD^2 + DF^2$.
   - Hence $AD^2 + DF^2 = 2(AC^2 + CD^2)$.
