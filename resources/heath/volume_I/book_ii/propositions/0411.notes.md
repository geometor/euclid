## Semantic & SVG Correspondence
1. **Pythagorean Cascades**:
   - $EG^2 = GF^2 + FE^2 = 2EF^2 = 2CD^2$ (since $EF = CD$ by [I. 34]).
   - Combined sum: $AE^2 + EG^2 = 2AC^2 + 2CD^2 = 2(AC^2 + CD^2)$.
   - But in right $\triangle AEG$, $AG^2 = AE^2 + EG^2 \implies AG^2 = 2(AC^2 + CD^2)$.
   - And in right $\triangle ADG$, $AG^2 = AD^2 + DG^2 \implies AD^2 + DG^2 = 2(AC^2 + CD^2)$.
   - Since $DG = DB$, $AD^2 + DB^2 = 2(AC^2 + CD^2)$.
2. **Algebraic Identity**: $(2a+x)^2 + x^2 = 2[a^2 + (a+x)^2]$, where $AC = a$ and $BD = x$.
