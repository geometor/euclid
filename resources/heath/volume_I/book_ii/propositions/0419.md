Describe squares on <span data-ref="0419.g1:/ B C /">$BC$</span>, <span data-ref="0419.g1:/ C A /">$CA$</span>, <span data-ref="0419.g1:/ A B /">$AB$</span>, as <span data-ref="0419.g1:< B C E D >">$BCED$</span>, <span data-ref="0419.g1:< C A G F >">$CAGF$</span>, <span data-ref="0419.g1:< A B K H >">$ABKH$</span>.

Draw <span data-ref="0419.g1:/ A L /">$AL$</span>, <span data-ref="0419.g1:/ B M /">$BM$</span>, <span data-ref="0419.g1:/ C N /">$CN$</span>, perpendicular to <span data-ref="0419.g1:/ B C /">$BC$</span>, <span data-ref="0419.g1:[ C A ]">$CA$</span>, <span data-ref="0419.g1:[ A B ]">$AB$</span> (produced if necessary), and produce them to meet the further sides of the squares on them in <span data-ref="0419.g1:P">$P$</span>, <span data-ref="0419.g1:Q">$Q$</span>, <span data-ref="0419.g1:R">$R$</span> respectively.

![Diagram](0419.g1.svg)

Join <span data-ref="0419.g1:/ A D /">$AD$</span>, <span data-ref="0419.g1:/ C K /">$CK$</span>.

Then, as in I. 47, the triangles <span data-ref="0419.g1:< K B C >">$KBC$</span>, <span data-ref="0419.g1:< A B D >">$ABD$</span> are equal in all respects;

therefore their doubles, the parallelograms in the same parallels respectively, are equal;

that is, the rectangle <span data-ref="0419.g1:< B L P D >">$BP$</span> is equal to the rectangle <span data-ref="0419.g1:< B N R K >">$BR$</span>.

Similarly the rectangle <span data-ref="0419.g1:< L C E P >">$CP$</span> is equal to the rectangle <span data-ref="0419.g1:< C M Q F >">$CQ$</span>.

Also, if <span data-ref="0419.g1:/ B G /">$BG$</span>, <span data-ref="0419.g1:/ C H /">$CH$</span> be joined, we see that

the triangles <span data-ref="0419.g1:< B A G >">$BAG$</span>, <span data-ref="0419.g1:< H A C >">$HAC$</span> are equal in all respects;

therefore their doubles, the rectangles <span data-ref="0419.g1:< A M Q G >">$AQ$</span>, <span data-ref="0419.g1:< A N R H >">$AR$</span>, are equal.

Now the square on <span data-ref="0419.g1:/ B C /">$BC$</span> is equal to the sum of the rectangles <span data-ref="0419.g1:< B L P D >">$BP$</span>, <span data-ref="0419.g1:< L C E P >">$CP$</span>,

i.e. to the sum of the rectangles <span data-ref="0419.g1:< B N R K >">$BR$</span>, <span data-ref="0419.g1:< C M Q F >">$CQ$</span>,

i.e. to the sum of the squares <span data-ref="0419.g1:< A B K H >">$BH$</span>, <span data-ref="0419.g1:< C A G F >">$CG$</span> and the rectangles <span data-ref="0419.g1:< A N R H >">$AR$</span>, <span data-ref="0419.g1:< A M Q G >">$AQ$</span>.

But the rectangles <span data-ref="0419.g1:< A N R H >">$AR$</span>, <span data-ref="0419.g1:< A M Q G >">$AQ$</span> are equal, and they are respectively the rectangle contained by <span data-ref="0419.g1:/ B A /">$BA$</span>, <span data-ref="0419.g1:/ A N /">$AN$</span> and the rectangle contained by <span data-ref="0419.g1:/ C A /">$CA$</span>, <span data-ref="0419.g1:/ A M /">$AM$</span>.

Therefore the square on <span data-ref="0419.g1:/ B C /">$BC$</span> is equal to the squares on <span data-ref="0419.g1:/ B A /">$BA$</span>, <span data-ref="0419.g1:/ A C /">$AC$</span> together with twice the rectangle <span data-ref="0419.g1:/ B A /">$BA$</span>, <span data-ref="0419.g1:/ A N /">$AN$</span> or <span data-ref="0419.g1:/ C A /">$CA$</span>, <span data-ref="0419.g1:/ A M /">$AM$</span>.

Incidentally this proof shows that the rectangle <span data-ref="0419.g1:/ B A /">$BA$</span>, <span data-ref="0419.g1:/ A N /">$AN$</span> is equal to the rectangle <span data-ref="0419.g1:/ C A /">$CA$</span>, <span data-ref="0419.g1:/ A M /">$AM$</span>: a result which will be seen later on to be a particular case of the theorem in III. 35.

Heron (in an-Nairīzī, ed. Curtze, p. 109) gives a "converse" of II. 12 related to it as I. 48 is related to I. 47.

*In any triangle, if the square on one of the sides is greater than the squares on the other two sides, the angle contained by the latter is obtuse.*

Let <span data-ref="0419.g2:< A B C >">$ABC$</span> be a triangle such that the square on <span data-ref="0419.g2:/ B C /">$BC$</span> is greater than the squares on <span data-ref="0419.g2:/ B A /">$BA$</span>, <span data-ref="0419.g2:/ A C /">$AC$</span>.

Draw <span data-ref="0419.g2:/ A D /">$AD$</span> at right angles to <span data-ref="0419.g2:/ A C /">$AC$</span> and of length equal to <span data-ref="0419.g2:/ A B /">$AB$</span>.

![Diagram](0419.g2.svg)

Join <span data-ref="0419.g2:/ D C /">$DC$</span>.

Then, since <span data-ref="0419.g2:< D A C )">$DAC$</span> is a right angle, the square on <span data-ref="0419.g2:/ D C /">$DC$</span> is equal to the squares on <span data-ref="0419.g2:/ D A /">$DA$</span>, <span data-ref="0419.g2:/ A C /">$AC$</span>, [I. 47]

i.e. to the squares on <span data-ref="0419.g2:/ B A /">$BA$</span>, <span data-ref="0419.g2:/ A C /">$AC$</span>.

But the square on <span data-ref="0419.g2:/ B C /">$BC$</span> is greater than the squares on <span data-ref="0419.g2:/ B A /">$BA$</span>, <span data-ref="0419.g2:/ A C /">$AC$</span>; therefore the square on <span data-ref="0419.g2:/ B C /">$BC$</span> is greater than the square on <span data-ref="0419.g2:/ D C /">$DC$</span>.

Therefore <span data-ref="0419.g2:/ B C /">$BC$</span> is greater than <span data-ref="0419.g2:/ D C /">$DC$</span>.

Thus, in the triangles <span data-ref="0419.g2:< B A C >">$BAC$</span>, <span data-ref="0419.g2:< D A C >">$DAC$</span>, the two sides <span data-ref="0419.g2:/ B A /">$BA$</span>, <span data-ref="0419.g2:/ A C /">$AC$</span> are equal to the two sides <span data-ref="0419.g2:/ D A /">$DA$</span>, <span data-ref="0419.g2:/ A C /">$AC$</span> respectively,

but the base <span data-ref="0419.g2:/ B C /">$BC$</span> is greater than the base <span data-ref="0419.g2:/ D C /">$DC$</span>.
