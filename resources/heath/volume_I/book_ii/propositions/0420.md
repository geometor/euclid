### PROPOSITION 13.

<p class="enunciation">In acute-angled triangles the square on the side subtending<br />
the acute angle is less than the squares on the sides containing<br />
the acute angle by twice the rectangle contained by one of the<br />
sides about the acute angle, namely that on which the per-<br />
pendicular falls, and the straight line cut off within by the<br />
perpendicular towards the acute angle.</p>

Let <span data-ref="0420.g1:&lt; A B C &gt;">$ABC$</span> be an acute-angled triangle having the angle at <span data-ref="0420.g1:&lt; A B C )">$B$</span> acute, and let <span data-ref="0420.g1:/ A D /">$AD$</span> be drawn from the point <span data-ref="0420.g1:A">$A$</span> perpendicular to <span data-ref="0420.g1:/ B C /">$BC$</span>;  
I say that the square on <span data-ref="0420.g1:/ A C /">$AC$</span> is less than the squares on <span data-ref="0420.g1:/ C B /">$CB$</span>, <span data-ref="0420.g1:/ B A /">$BA$</span> by twice the rectangle contained by <span data-ref="0420.g1:/ C B /">$CB$</span>, <span data-ref="0420.g1:/ B D /">$BD$</span>.

![Diagram](0420.g1.svg)

For, since the straight line <span data-ref="0420.g1:/ C B /">$CB$</span> has been cut at random at <span data-ref="0420.g1:D">$D$</span>,  
the squares on <span data-ref="0420.g1:/ C B /">$CB$</span>, <span data-ref="0420.g1:/ B D /">$BD$</span> are equal to twice the rectangle contained by <span data-ref="0420.g1:/ C B /">$CB$</span>, <span data-ref="0420.g1:/ B D /">$BD$</span> and the square on <span data-ref="0420.g1:/ D C /">$DC$</span>. <span class="justification">[II. 7]</span>

Let the square on <span data-ref="0420.g1:/ D A /">$DA$</span> be added to each;  
<p class="assertion">therefore the squares on <span data-ref="0420.g1:/ C B /">$CB$</span>, <span data-ref="0420.g1:/ B D /">$BD$</span>, <span data-ref="0420.g1:/ D A /">$DA$</span> are equal to twice the rectangle contained by <span data-ref="0420.g1:/ C B /">$CB$</span>, <span data-ref="0420.g1:/ B D /">$BD$</span> and the squares on <span data-ref="0420.g1:/ A D /">$AD$</span>, <span data-ref="0420.g1:/ D C /">$DC$</span>.</p>

But the square on <span data-ref="0420.g1:/ A B /">$AB$</span> is equal to the squares on <span data-ref="0420.g1:/ B D /">$BD$</span>, <span data-ref="0420.g1:/ D A /">$DA$</span>, for the angle at <span data-ref="0420.g1:&lt; A D B )">$D$</span> is right; <span class="justification">[I. 47]</span>  
and the square on <span data-ref="0420.g1:/ A C /">$AC$</span> is equal to the squares on <span data-ref="0420.g1:/ A D /">$AD$</span>, <span data-ref="0420.g1:/ D C /">$DC$</span>;  
<p class="assertion">therefore the squares on <span data-ref="0420.g1:/ C B /">$CB$</span>, <span data-ref="0420.g1:/ B A /">$BA$</span> are equal to the square on <span data-ref="0420.g1:/ A C /">$AC$</span> and twice the rectangle <span data-ref="0420.g1:/ C B /">$CB$</span>, <span data-ref="0420.g1:/ B D /">$BD$</span>,</p>

<p class="assertion">so that the square on <span data-ref="0420.g1:/ A C /">$AC$</span> alone is less than the squares on <span data-ref="0420.g1:/ C B /">$CB$</span>, <span data-ref="0420.g1:/ B A /">$BA$</span> by twice the rectangle contained by <span data-ref="0420.g1:/ C B /">$CB$</span>, <span data-ref="0420.g1:/ B D /">$BD$</span>.</p>

<p class="qed">Therefore etc. <span class="justification">Q. E. D.</span></p>
