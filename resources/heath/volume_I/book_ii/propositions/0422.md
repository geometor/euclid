Next, by joining <span data-ref="0421.g2:/ B G /">$BG$</span>, <span data-ref="0421.g2:/ C H /">$CH$</span>, we prove in like manner that the rectangles <span data-ref="0421.g2:< A N R H >">$AR$</span>, <span data-ref="0421.g2:< A M Q G >">$AQ$</span> are equal.

Now the square on <span data-ref="0421.g2:/ B C /">$BC$</span> is equal to the sum of the rectangles <span data-ref="0421.g2:< B L P D >">$BP$</span>, <span data-ref="0421.g2:< L C E P >">$CP$</span>,

i.e. to the sum of the rectangles <span data-ref="0421.g2:< B N R K >">$BR$</span>, <span data-ref="0421.g2:< C M Q F >">$CQ$</span>,

i.e. to the sum of the squares <span data-ref="0421.g2:< A B K H >">$BH$</span>, <span data-ref="0421.g2:< C A G F >">$CG$</span> diminished by the rectangles <span data-ref="0421.g2:< A N R H >">$AR$</span>, <span data-ref="0421.g2:< A M Q G >">$AQ$</span>.

But the rectangles <span data-ref="0421.g2:< A N R H >">$AR$</span>, <span data-ref="0421.g2:< A M Q G >">$AQ$</span> are equal, and they are respectively the rectangles contained by <span data-ref="0421.g2:/ B A /">$BA$</span>, <span data-ref="0421.g2:/ A N /">$AN$</span> and by <span data-ref="0421.g2:/ C A /">$CA$</span>, <span data-ref="0421.g2:/ A M /">$AM$</span>.

Therefore the square on <span data-ref="0421.g2:/ B C /">$BC$</span> is less than the squares on <span data-ref="0421.g2:/ B A /">$BA$</span>, <span data-ref="0421.g2:/ A C /">$AC$</span> by twice the rectangle <span data-ref="0421.g2:/ B A /">$BA$</span>, <span data-ref="0421.g2:/ A N /">$AN$</span> or <span data-ref="0421.g2:/ C A /">$CA$</span>, <span data-ref="0421.g2:/ A M /">$AM$</span>.

Next suppose that we have to prove the theorem in the case where the triangle has an obtuse angle at <span data-ref="0422.g1:< B A C )">$A$</span>.

Take <span data-ref="0422.g1:< A B C )">$B$</span> as the acute angle under consideration, so that <span data-ref="0422.g1:/ A C /">$AC$</span> is the side opposite to it.

![Diagram](0422.g1.svg)

Now the square on <span data-ref="0422.g1:/ C A /">$CA$</span> is equal to the difference of the rectangles <span data-ref="0422.g1:< C M Q F >">$CQ$</span>, <span data-ref="0422.g1:< A M Q G >">$AQ$</span>,

i.e. to the difference between <span data-ref="0422.g1:< L C E P >">$CP$</span> and <span data-ref="0422.g1:< A M Q G >">$AQ$</span>,

i.e. to the difference between the square <span data-ref="0422.g1:< B C E D >">$BE$</span> and the sum of the rectangles <span data-ref="0422.g1:< B L P D >">$BP$</span>, <span data-ref="0422.g1:< A M Q G >">$AQ$</span>,

i.e. to the difference between the square <span data-ref="0422.g1:< B C E D >">$BE$</span> and the sum of the rectangles <span data-ref="0422.g1:< B L P D >">$BP$</span>, <span data-ref="0422.g1:< A N R H >">$AR$</span>,

i.e. to the difference between the sum of the squares <span data-ref="0422.g1:< B C E D >">$BE$</span>, <span data-ref="0422.g1:< A B K H >">$BH$</span> and the sum of the rectangles <span data-ref="0422.g1:< B L P D >">$BP$</span>, <span data-ref="0422.g1:< B N R K >">$BR$</span>

(since <span data-ref="0422.g1:< A N R H >">$AR$</span> is the difference between <span data-ref="0422.g1:< B N R K >">$BR$</span> and <span data-ref="0422.g1:< A B K H >">$BH$</span>).

But <span data-ref="0422.g1:< B L P D >">$BP$</span>, <span data-ref="0422.g1:< B N R K >">$BR$</span> are equal, and they are respectively the rectangles <span data-ref="0422.g1:/ C B /">$CB$</span>, <span data-ref="0422.g1:/ B L /">$BL$</span> and <span data-ref="0422.g1:/ A B /">$AB$</span>, <span data-ref="0422.g1:/ B N /">$BN$</span>.

Therefore the square on <span data-ref="0422.g1:/ C A /">$CA$</span> is less than the squares on <span data-ref="0422.g1:/ A B /">$AB$</span>, <span data-ref="0422.g1:/ B C /">$BC$</span> by twice the rectangle <span data-ref="0422.g1:/ C B /">$CB$</span>, <span data-ref="0422.g1:/ B L /">$BL$</span> or <span data-ref="0422.g1:/ A B /">$AB$</span>, <span data-ref="0422.g1:/ B N /">$BN$</span>.

Heron's proof of his converse proposition (an-Nairīzī, ed. Curtze, p. 110), which is also given by the Greek scholiast above quoted, is of course simple. For let <span data-ref="0422.g2:< A B C >">$ABC$</span> be a triangle in which the square on <span data-ref="0422.g2:/ A C /">$AC$</span> is less than the squares on <span data-ref="0422.g2:/ A B /">$AB$</span>, <span data-ref="0422.g2:/ B C /">$BC$</span>.

![Diagram](0422.g2.svg)

Draw <span data-ref="0422.g2:/ B D /">$BD$</span> at right angles to <span data-ref="0422.g2:/ B C /">$BC$</span> and of length equal to <span data-ref="0422.g2:/ B A /">$BA$</span>.

Join <span data-ref="0422.g2:/ D C /">$DC$</span>.

Then, since the angle <span data-ref="0422.g2:< C B D )">$CBD$</span> is right,
the square on <span data-ref="0422.g2:/ D C /">$DC$</span> is equal to the squares on <span data-ref="0422.g2:/ D B /">$DB$</span>, <span data-ref="0422.g2:/ B C /">$BC$</span>,
i.e. to the squares on <span data-ref="0422.g2:/ A B /">$AB$</span>, <span data-ref="0422.g2:/ B C /">$BC$</span>. [I. 47]

But the square on <span data-ref="0422.g2:/ A C /">$AC$</span> is less than the squares on <span data-ref="0422.g2:/ A B /">$AB$</span>, <span data-ref="0422.g2:/ B C /">$BC$</span>.

Therefore the square on <span data-ref="0422.g2:/ A C /">$AC$</span> is less than the square on <span data-ref="0422.g2:/ D C /">$DC$</span>.

Therefore <span data-ref="0422.g2:/ A C /">$AC$</span> is less than <span data-ref="0422.g2:/ D C /">$DC$</span>.

Hence in the two triangles <span data-ref="0422.g2:< D B C >">$DBC$</span>, <span data-ref="0422.g2:< A B C >">$ABC$</span> the sides about the angles <span data-ref="0422.g2:< D B C )">$DBC$</span>, <span data-ref="0422.g2:< A B C )">$ABC$</span> are respectively equal, but the base <span data-ref="0422.g2:/ D C /">$DC$</span> is greater than the base <span data-ref="0422.g2:/ A C /">$AC$</span>.
