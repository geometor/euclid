“But, if the segment <span data-ref="0056.g1:< B A E D )">$BAED$</span> be not greater than a semicircle, let <span data-ref="0056.g1:< B A D )">$BAD$</span>, <span data-ref="0056.g1:< B E D )">$BED$</span> be angles in it: these also are equal to one another.

Draw <span data-ref="0056.g1:/ A F /">$AF$</span> to the centre, and produce it to <span data-ref="0056.g1:C">$C$</span>, and join <span data-ref="0056.g1:/ C E /">$CE$</span>.

![Diagram for alternative proof of Proposition 21](0056.g1.svg)

Therefore the segment <span data-ref="0056.g1:< B A D C )">$BADC$</span> is greater than a semicircle, and the angles in it <span data-ref="0056.g1:< B A C )">$BAC$</span>, <span data-ref="0056.g1:< B E C )">$BEC$</span> are equal, by the first case.

For the same reason, because <span data-ref="0056.g1:< C B E D )">$CBED$</span> is greater than a semicircle,

<p class="assertion">the angles <span data-ref="0056.g1:< C A D )">$CAD$</span>, <span data-ref="0056.g1:< C E D )">$CED$</span> are equal.</p>

Therefore the whole angle <span data-ref="0056.g1:< B A D )">$BAD$</span> is equal to the whole angle <span data-ref="0056.g1:< B E D )">$BED$</span>.”

We can prove, by means of *reductio ad absurdum*, the important converse of this proposition, namely that, *if there be any two triangles on the same base and on the same side of it, and with equal vertical angles, the circle passing through the extremities of the base and the vertex of one triangle will pass through the vertex of the other triangle also*. That a circle can be thus described about a triangle is clear from Euclid's construction in III. 9, which shows how to draw a circle passing through any three points, though it is in IV. 5 only that we have the problem stated. Now, suppose a circle <span data-ref="0056.g2:( B A C )">$BAC$</span> drawn through the angular points of a triangle <span data-ref="0056.g2:< B A C >">$BAC$</span>, and let <span data-ref="0056.g2:< B D C >">$BDC$</span> be another triangle with the same base <span data-ref="0056.g2:/ B C /">$BC$</span> and on the same side of it, and having its vertical angle <span data-ref="0056.g2:< B D C )">$D$</span> equal to the angle <span data-ref="0056.g2:< B A C )">$A$</span>. Then shall the circle pass through <span data-ref="0056.g2:D">$D$</span>.

![Diagram for converse of Proposition 21](0056.g2.svg)

For, if it does not, it must pass through some point <span data-ref="0056.g2:E">$E$</span> on <span data-ref="0056.g2:/ B D /">$BD$</span> or on <span data-ref="0056.g2:/ B D /">$BD$</span> produced. If then <span data-ref="0056.g2:/ E C /">$EC$</span> be joined, the angle <span data-ref="0056.g2:< B E C )">$BEC$</span> is equal to the angle <span data-ref="0056.g2:< B A C )">$BAC$</span>, by III. 21, and therefore equal to the angle <span data-ref="0056.g2:< B D C )">$BDC$</span>. Therefore an exterior angle of a triangle is equal to the interior and opposite angle: which is impossible, by I. 16.
Therefore <span data-ref="0056.g2:D">$D$</span> lies on the circle <span data-ref="0056.g2:( B A C )">$BAC$</span>.

Similarly for any other triangle on the base <span data-ref="0056.g2:/ B C /">$BC$</span> and with vertical angle equal to <span data-ref="0056.g2:< B A C )">$A$</span>. Thus, *if any number of triangles be constructed on the same base and on the same side of it, with equal vertical angles, the vertices will all lie on the circumference of a segment of a circle*.

A useful theorem derivable from III. 21 is given by Serenus (*De sectione coni*, Props. 52, 53).

If <span data-ref="0056.g3:( A D B )">$ADB$</span> be any segment of a circle, and <span data-ref="0056.g3:C">$C$</span> be such a point on the circumference that <span data-ref="0056.g3:/ A C /">$AC$</span> is equal to <span data-ref="0056.g3:/ C B /">$CB$</span>, and if there be described with <span data-ref="0056.g3:C">$C$</span> as centre and radius <span data-ref="0056.g3:/ C A /">$CA$</span> or <span data-ref="0056.g3:/ C B /">$CB$</span> the circle <span data-ref="0056.g3:( A H B )">$AHB$</span>, then, <span data-ref="0056.g3:< A D B )">$ADB$</span> being any other angle in the segment <span data-ref="0056.g3:( A C B )">$ACB$</span>, and <span data-ref="0056.g3:/ B D /">$BD$</span> being produced to meet the outer segment in <span data-ref="0056.g3:E">$E$</span>, the sum of <span data-ref="0056.g3:/ A D /">$AD$</span>, <span data-ref="0056.g3:/ D B /">$DB$</span> is equal to <span data-ref="0056.g3:/ B E /">$BE$</span>.
