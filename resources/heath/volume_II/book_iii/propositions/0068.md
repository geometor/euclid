Let <span data-ref="0068.g1:( A B C D )">$ABCD$</span> be a circle, let <span data-ref="0068.g1:/ B C /">$BC$</span> be its diameter, and <span data-ref="0068.g1:E">$E$</span> its centre, and let <span data-ref="0068.g1:/ B A /">$BA$</span>, <span data-ref="0068.g1:/ A C /">$AC$</span>, <span data-ref="0068.g1:/ A D /">$AD$</span>, <span data-ref="0068.g1:/ D C /">$DC$</span> be joined;
I say that the angle <span data-ref="0068.g1:< B A C )">$BAC$</span> in the semicircle <span data-ref="0068.g1:( B A C )">$BAC$</span> is right,
the angle <span data-ref="0068.g1:< A B C )">$ABC$</span> in the segment <span data-ref="0068.g1:( A B C )">$ABC$</span> greater than the semicircle is less than a right angle,
and the angle <span data-ref="0068.g1:< A D C )">$ADC$</span> in the segment <span data-ref="0068.g1:( A D C )">$ADC$</span> less than the semicircle is greater than a right angle.

![Diagram](0068.g1.svg)

Let <span data-ref="0068.g1:/ A E /">$AE$</span> be joined, and let <span data-ref="0068.g1:/ B A /">$BA$</span> be carried through to <span data-ref="0068.g1:F">$F$</span>.

Then, since <span data-ref="0068.g1:/ B E /">$BE$</span> is equal to <span data-ref="0068.g1:/ E A /">$EA$</span>,
the angle <span data-ref="0068.g1:< A B E )">$ABE$</span> is also equal to the angle <span data-ref="0068.g1:< B A E )">$BAE$</span>. [I. 5]

Again, since <span data-ref="0068.g1:/ C E /">$CE$</span> is equal to <span data-ref="0068.g1:/ E A /">$EA$</span>,
the angle <span data-ref="0068.g1:< A C E )">$ACE$</span> is also equal to the angle <span data-ref="0068.g1:< C A E )">$CAE$</span>. [I. 5]

Therefore the whole angle <span data-ref="0068.g1:< B A C )">$BAC$</span> is equal to the two angles <span data-ref="0068.g1:< A B C )">$ABC$</span>, <span data-ref="0068.g1:< A C B )">$ACB$</span>.

But the angle <span data-ref="0068.g1:< F A C )">$FAC$</span> exterior to the triangle <span data-ref="0068.g1:< A B C >">$ABC$</span> is also equal to the two angles <span data-ref="0068.g1:< A B C )">$ABC$</span>, <span data-ref="0068.g1:< A C B )">$ACB$</span>; [I. 32]
therefore the angle <span data-ref="0068.g1:< B A C )">$BAC$</span> is also equal to the angle <span data-ref="0068.g1:< F A C )">$FAC$</span>;
therefore each is right; [I. Def. 10]
therefore the angle <span data-ref="0068.g1:< B A C )">$BAC$</span> in the semicircle <span data-ref="0068.g1:( B A C )">$BAC$</span> is right.

Next, since in the triangle <span data-ref="0068.g1:< A B C >">$ABC$</span> the two angles <span data-ref="0068.g1:< A B C )">$ABC$</span>, <span data-ref="0068.g1:< B A C )">$BAC$</span> are less than two right angles, [I. 17]
and the angle <span data-ref="0068.g1:< B A C )">$BAC$</span> is a right angle,
the angle <span data-ref="0068.g1:< A B C )">$ABC$</span> is less than a right angle;
and it is the angle in the segment <span data-ref="0068.g1:( A B C )">$ABC$</span> greater than the semicircle.

Next, since <span data-ref="0068.g1:< A B C D >">$ABCD$</span> is a quadrilateral in a circle,
and the opposite angles of quadrilaterals in circles are equal to two right angles, [III. 22]
while the angle <span data-ref="0068.g1:< A B C )">$ABC$</span> is less than a right angle,
therefore the angle <span data-ref="0068.g1:< A D C )">$ADC$</span> which remains is greater than a right angle;
and it is the angle in the segment <span data-ref="0068.g1:( A D C )">$ADC$</span> less than the semicircle.
