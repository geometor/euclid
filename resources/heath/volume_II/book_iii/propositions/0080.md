<p class="enunciation">line intercepted on it outside between the point and the convex<br />
circumference will be equal to the square on the tangent.</p>

For let a point <span data-ref="0080.g1:D">$D$</span> be taken outside the circle <span data-ref="0080.g1:( A B C )">$ABC$</span>,
and from <span data-ref="0080.g1:D">$D$</span> let the two straight lines <span data-ref="0080.g1:/ D C A /">$DCA$</span>,
<span data-ref="0080.g1:/ D B /">$DB$</span> fall on the circle <span data-ref="0080.g1:( A B C )">$ABC$</span>; let <span data-ref="0080.g1:/ D C A /">$DCA$</span> cut
the circle <span data-ref="0080.g1:( A B C )">$ABC$</span> and let <span data-ref="0080.g1:/ B D /">$BD$</span> touch it;
I say that the rectangle contained by <span data-ref="0080.g1:/ A D /">$AD$</span>,
<span data-ref="0080.g1:/ D C /">$DC$</span> is equal to the square on <span data-ref="0080.g1:/ D B /">$DB$</span>.

![Proposition 36 Case 1 diagram](0080.g1.svg)

Then <span data-ref="0080.g1:/ D C A /">$DCA$</span> is either through the centre
or not through the centre.

First let it be through the centre, and
let <span data-ref="0080.g1:F">$F$</span> be the centre of the circle <span data-ref="0080.g1:( A B C )">$ABC$</span>;
let <span data-ref="0080.g1:/ F B /">$FB$</span> be joined;
<p class="assertion">therefore the angle <span data-ref="0080.g1:< F B D )">$FBD$</span> is right. <span class="justification">[III. 18]</span></p>

And, since <span data-ref="0080.g1:/ A C /">$AC$</span> has been bisected at <span data-ref="0080.g1:F">$F$</span>, and <span data-ref="0080.g1:/ C D /">$CD$</span> is added
to it,
the rectangle <span data-ref="0080.g1:/ A D /">$AD$</span>, <span data-ref="0080.g1:/ D C /">$DC$</span> together with the square on <span data-ref="0080.g1:/ F C /">$FC$</span> is
equal to the square on <span data-ref="0080.g1:/ F D /">$FD$</span>. <span class="justification">[II. 6]</span>

But <span data-ref="0080.g1:/ F C /">$FC$</span> is equal to <span data-ref="0080.g1:/ F B /">$FB$</span>;
therefore the rectangle <span data-ref="0080.g1:/ A D /">$AD$</span>, <span data-ref="0080.g1:/ D C /">$DC$</span> together with the square on
<span data-ref="0080.g1:/ F B /">$FB$</span> is equal to the square on <span data-ref="0080.g1:/ F D /">$FD$</span>.

And the squares on <span data-ref="0080.g1:/ F B /">$FB$</span>, <span data-ref="0080.g1:/ B D /">$BD$</span> are equal to the square on
<span data-ref="0080.g1:/ F D /">$FD$</span>; <span class="justification">[I. 47]</span>
therefore the rectangle <span data-ref="0080.g1:/ A D /">$AD$</span>, <span data-ref="0080.g1:/ D C /">$DC$</span> together with the square on
<span data-ref="0080.g1:/ F B /">$FB$</span> is equal to the squares on <span data-ref="0080.g1:/ F B /">$FB$</span>, <span data-ref="0080.g1:/ B D /">$BD$</span>.

Let the square on <span data-ref="0080.g1:/ F B /">$FB$</span> be subtracted from each;
therefore the rectangle <span data-ref="0080.g1:/ A D /">$AD$</span>, <span data-ref="0080.g1:/ D C /">$DC$</span> which remains is equal to
the square on the tangent <span data-ref="0080.g1:/ D B /">$DB$</span>.

Again, let <span data-ref="0080.g2:/ D C A /">$DCA$</span> not be through the centre of the circle
<span data-ref="0080.g2:( A B C )">$ABC$</span>;
let the centre <span data-ref="0080.g2:E">$E$</span> be taken, and from <span data-ref="0080.g2:E">$E$</span>
let <span data-ref="0080.g2:/ E F /">$EF$</span> be drawn perpendicular to <span data-ref="0080.g2:/ A C /">$AC$</span>;
let <span data-ref="0080.g2:/ E B /">$EB$</span>, <span data-ref="0080.g2:/ E C /">$EC$</span>, <span data-ref="0080.g2:/ E D /">$ED$</span> be joined.

![Proposition 36 Case 2 diagram](0080.g2.svg)

Then the angle <span data-ref="0080.g2:< E B D )">$EBD$</span> is right.
<span class="justification">[III. 18]</span>

And, since a straight line <span data-ref="0080.g2:/ E F /">$EF$</span>
through the centre cuts a straight line
<span data-ref="0080.g2:/ A C /">$AC$</span> not through the centre at right angles,
<p class="assertion">it also bisects it; <span class="justification">[III. 3]</span></p>
<p class="assertion">therefore <span data-ref="0080.g2:/ A F /">$AF$</span> is equal to <span data-ref="0080.g2:/ F C /">$FC$</span>.</p>
