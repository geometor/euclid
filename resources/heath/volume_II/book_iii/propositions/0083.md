The undisguised indirect proof is easy. If <span data-ref="0082.g1:/ D B /">$DB$</span> does not touch the circle, it must cut it if produced, and it follows that the square on <span data-ref="0082.g1:/ D B /">$DB$</span> must be equal to the rectangle contained by <span data-ref="0082.g1:/ D B /">$DB$</span> and a longer line: which is absurd.
