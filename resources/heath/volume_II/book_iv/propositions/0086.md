# BOOK IV. PROPOSITIONS

### PROPOSITION 1.

<p class="enunciation">Into a given circle to fit a straight line equal to a given<br />
straight line which is not greater than the diameter of the<br />
circle.</p>

Let <span data-ref="0086.g1:( A B C )">$ABC$</span> be the given circle, and <span data-ref="0086.g1:D">$D$</span> the given straight
line not greater than the diameter
of the circle;
thus it is required to fit into the
circle <span data-ref="0086.g1:( A B C )">$ABC$</span> a straight line equal
to the straight line <span data-ref="0086.g1:D">$D$</span>.

![Diagram for Proposition 1](0086.g1.svg)

Let a diameter <span data-ref="0086.g1:/ B C /">$BC$</span> of the
circle <span data-ref="0086.g1:( A B C )">$ABC$</span> be drawn.

Then, if <span data-ref="0086.g1:/ B C /">$BC$</span> is equal to <span data-ref="0086.g1:D">$D$</span>,
that which was enjoined will have
been done; for <span data-ref="0086.g1:/ B C /">$BC$</span> has been fitted into the circle <span data-ref="0086.g1:( A B C )">$ABC$</span> equal
to the straight line <span data-ref="0086.g1:D">$D$</span>.

But, if <span data-ref="0086.g1:/ B C /">$BC$</span> is greater than <span data-ref="0086.g1:D">$D$</span>,
let <span data-ref="0086.g1:/ C E /">$CE$</span> be made equal to <span data-ref="0086.g1:D">$D$</span>, and with centre <span data-ref="0086.g1:C">$C$</span> and distance
<span data-ref="0086.g1:/ C E /">$CE$</span> let the circle <span data-ref="0086.g1:( E A F )">$EAF$</span> be described;
let <span data-ref="0086.g1:/ C A /">$CA$</span> be joined.

Then, since the point <span data-ref="0086.g1:C">$C$</span> is the centre of the circle <span data-ref="0086.g1:( E A F )">$EAF$</span>,
<p class="assertion"><span data-ref="0086.g1:/ C A /">$CA$</span> is equal to <span data-ref="0086.g1:/ C E /">$CE$</span>.</p>

But <span data-ref="0086.g1:/ C E /">$CE$</span> is equal to <span data-ref="0086.g1:D">$D$</span>;
<p class="assertion">therefore <span data-ref="0086.g1:D">$D$</span> is also equal to <span data-ref="0086.g1:/ C A /">$CA$</span>.</p>

Therefore into the given circle <span data-ref="0086.g1:( A B C )">$ABC$</span> there has been fitted
<span data-ref="0086.g1:/ C A /">$CA$</span> equal to the given straight line <span data-ref="0086.g1:D">$D$</span>.
