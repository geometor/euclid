### PROPOSITION 6.

<p class="enunciation">In a given circle to inscribe a square.</p>

Let <span data-ref="0097.g1:( A B C D )">$ABCD$</span> be the given circle;
thus it is required to inscribe a square in the circle <span data-ref="0097.g1:( A B C D )">$ABCD$</span>.

Let two diameters <span data-ref="0097.g1:/ A C /">$AC$</span>, <span data-ref="0097.g1:/ B D /">$BD$</span> of the
circle <span data-ref="0097.g1:( A B C D )">$ABCD$</span> be drawn at right angles
to one another, and let <span data-ref="0097.g1:/ A B /">$AB$</span>, <span data-ref="0097.g1:/ B C /">$BC$</span>, <span data-ref="0097.g1:/ C D /">$CD$</span>,
<span data-ref="0097.g1:/ D A /">$DA$</span> be joined.

![Proposition 6 diagram](0097.g1.svg)

Then, since <span data-ref="0097.g1:/ B E /">$BE$</span> is equal to <span data-ref="0097.g1:/ E D /">$ED$</span>, for
<span data-ref="0097.g1:E">$E$</span> is the centre,
and <span data-ref="0097.g1:/ E A /">$EA$</span> is common and at right angles,
therefore the base <span data-ref="0097.g1:/ A B /">$AB$</span> is equal to the
base <span data-ref="0097.g1:/ A D /">$AD$</span>. <span class="justification">[I. 4]</span>

For the same reason
each of the straight lines <span data-ref="0097.g1:/ B C /">$BC$</span>, <span data-ref="0097.g1:/ C D /">$CD$</span> is also equal to each of
the straight lines <span data-ref="0097.g1:/ A B /">$AB$</span>, <span data-ref="0097.g1:/ A D /">$AD$</span>;
<p class="assertion">therefore the quadrilateral <span data-ref="0097.g1:< A B C D >">$ABCD$</span> is equilateral.</p>

I say next that it is also right-angled.

For, since the straight line <span data-ref="0097.g1:/ B D /">$BD$</span> is a diameter of the circle
<span data-ref="0097.g1:( A B C D )">$ABCD$</span>,
therefore <span data-ref="0097.g1:( B A D )">$BAD$</span> is a semicircle;
<p class="assertion">therefore the angle <span data-ref="0097.g1:< B A D )">$BAD$</span> is right. <span class="justification">[III. 31]</span></p>

For the same reason
each of the angles <span data-ref="0097.g1:< A B C )">$ABC$</span>, <span data-ref="0097.g1:< B C D )">$BCD$</span>, <span data-ref="0097.g1:< C D A )">$CDA$</span> is also right;
<p class="assertion">therefore the quadrilateral <span data-ref="0097.g1:< A B C D >">$ABCD$</span> is right-angled.</p>

But it was also proved equilateral;
therefore it is a square; <span class="justification">[I. Def. 22]</span>
and it has been inscribed in the circle <span data-ref="0097.g1:( A B C D )">$ABCD$</span>.

Therefore in the given circle the square <span data-ref="0097.g1:< A B C D >">$ABCD$</span> has been
inscribed.
<p class="qed"><span class="justification">Q. E. F.</span></p>

Euclid here proceeds to consider problems corresponding to those in Props. 2—5 with reference to figures of four or more sides, but with the difference that, whereas he dealt with triangles of any form, he confines himself henceforth to regular figures. It happened to be as easy to divide a circle into *three* parts which are in the ratio of the angles, or of the supplements of the angles, of a triangle as into three *equal* parts.
