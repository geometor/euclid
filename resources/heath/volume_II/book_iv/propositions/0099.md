For the same reason
<span data-ref="0098.g2:/ A C /">$AC$</span> is also parallel to <span data-ref="0098.g2:/ F K /">$FK$</span>,
so that <span data-ref="0098.g2:/ G H /">$GH$</span> is also parallel to <span data-ref="0098.g2:/ F K /">$FK$</span>. [I. 30]

Similarly we can prove that
each of the straight lines <span data-ref="0098.g2:/ G F /">$GF$</span>, <span data-ref="0098.g2:/ H K /">$HK$</span> is parallel to <span data-ref="0098.g2:/ B E D /">$BED$</span>.

Therefore <span data-ref="0098.g2:< F G H K >">$GK$</span>, <span data-ref="0098.g2:< G H C A >">$GC$</span>, <span data-ref="0098.g2:< A C K F >">$AK$</span>, <span data-ref="0098.g2:< F G B D >">$FB$</span>, <span data-ref="0098.g2:< B H K D >">$BK$</span> are parallelograms;
therefore <span data-ref="0098.g2:/ G F /">$GF$</span> is equal to <span data-ref="0098.g2:/ H K /">$HK$</span>, and <span data-ref="0098.g2:/ G H /">$GH$</span> to <span data-ref="0098.g2:/ F K /">$FK$</span>. [I. 34]

And, since <span data-ref="0098.g2:/ A C /">$AC$</span> is equal to <span data-ref="0098.g2:/ B D /">$BD$</span>,
and <span data-ref="0098.g2:/ A C /">$AC$</span> is also equal to each of the straight lines <span data-ref="0098.g2:/ G H /">$GH$</span>, <span data-ref="0098.g2:/ F K /">$FK$</span>,
while <span data-ref="0098.g2:/ B D /">$BD$</span> is equal to each of the straight lines <span data-ref="0098.g2:/ G F /">$GF$</span>, <span data-ref="0098.g2:/ H K /">$HK$</span>, [I. 34]
therefore the quadrilateral <span data-ref="0098.g2:< F G H K >">$FGHK$</span> is equilateral.

I say next that it is also right-angled.

For, since <span data-ref="0098.g2:< G B E A >">$GBEA$</span> is a parallelogram,
and the angle <span data-ref="0098.g2:< A E B )">$AEB$</span> is right,
therefore the angle <span data-ref="0098.g2:< A G B )">$AGB$</span> is also right. [I. 34]

Similarly we can prove that
the angles at <span data-ref="0098.g2:< G H K )">$H$</span>, <span data-ref="0098.g2:< H K F )">$K$</span>, <span data-ref="0098.g2:< K F G )">$F$</span> are also right.

Therefore <span data-ref="0098.g2:< F G H K >">$FGHK$</span> is right-angled.

But it was also proved equilateral;
therefore it is a square;
and it has been circumscribed about the circle <span data-ref="0098.g2:( A B C D )">$ABCD$</span>.

Therefore about the given circle a square has been circumscribed.

Q. E. F.

It is just as easy to describe about a given circle a polygon equiangular to any given polygon as it is to describe a square about a given circle. We have only to use the method of IV. 3, i.e. to take any radius of the circle, to measure round the centre successive angles in one and the same direction equal to the supplements of the successive angles of the given polygon and, lastly, to draw tangents to the circle at the extremities of the several radii so determined; but again the polygon would in general not be of the same *form* as the given one; it would only be so if the given polygon happened to be such that a circle could be inscribed in it. To take the case of a *quadrilateral* only: it is easy to prove that, if a quadrilateral be described about a circle, the sum of one pair of opposite sides must be equal to the sum of the other pair. It may be proved, *conversely*, that, if a quadrilateral has the sums of the pairs of opposite sides equal, a circle can be inscribed in it. If then a given quadrilateral has the sums of the pairs of opposite sides equal, a quadrilateral can be described about any given circle not only equiangular with it but having the same *form* or, in the words of Book VI., *similar* to it.
