As was remarked in the last note, a circle can be inscribed in any *quadrilateral* which has the sum of one pair of opposite sides equal to the sum of the other pair. In particular, it follows that a circle can be inscribed in a *square* or a *rhombus*, but not in a rectangle or a rhomboid.

---

### PROPOSITION 9.

<p class="enunciation">About a given square to circumscribe a circle.</p>

Let <span data-ref="0101.g1:< A B C D >">$ABCD$</span> be the given square;
thus it is required to circumscribe a circle about the square
<span data-ref="0101.g1:< A B C D >">$ABCD$</span>.

For let <span data-ref="0101.g1:/ A C /">$AC$</span>, <span data-ref="0101.g1:/ B D /">$BD$</span> be joined, and let them
cut one another at <span data-ref="0101.g1:E">$E$</span>.

![Proposition IV. 9 Diagram](0101.g1.svg)

Then, since <span data-ref="0101.g1:/ D A /">$DA$</span> is equal to <span data-ref="0101.g1:/ A B /">$AB$</span>,
and <span data-ref="0101.g1:/ A C /">$AC$</span> is common,
therefore the two sides <span data-ref="0101.g1:/ D A /">$DA$</span>, <span data-ref="0101.g1:/ A C /">$AC$</span> are equal
to the two sides <span data-ref="0101.g1:/ B A /">$BA$</span>, <span data-ref="0101.g1:/ A C /">$AC$</span>;
and the base <span data-ref="0101.g1:/ D C /">$DC$</span> is equal to the base <span data-ref="0101.g1:/ B C /">$BC$</span>;
<p class="assertion">therefore the angle <span data-ref="0101.g1:< D A C )">$DAC$</span> is equal to<br />
the angle <span data-ref="0101.g1:< B A C )">$BAC$</span>. <span class="justification">[I. 8]</span></p>

Therefore the angle <span data-ref="0101.g1:< D A B )">$DAB$</span> is bisected by <span data-ref="0101.g1:/ A C /">$AC$</span>.

Similarly we can prove that each of the angles <span data-ref="0101.g1:< A B C )">$ABC$</span>,
<span data-ref="0101.g1:< B C D )">$BCD$</span>, <span data-ref="0101.g1:< C D A )">$CDA$</span> is bisected by the straight lines <span data-ref="0101.g1:/ A C /">$AC$</span>, <span data-ref="0101.g1:/ D B /">$DB$</span>.

Now, since the angle <span data-ref="0101.g1:< D A B )">$DAB$</span> is equal to the angle <span data-ref="0101.g1:< A B C )">$ABC$</span>,
and the angle <span data-ref="0101.g1:< E A B )">$EAB$</span> is half the angle <span data-ref="0101.g1:< D A B )">$DAB$</span>,
and the angle <span data-ref="0101.g1:< E B A )">$EBA$</span> half the angle <span data-ref="0101.g1:< A B C )">$ABC$</span>,
therefore the angle <span data-ref="0101.g1:< E A B )">$EAB$</span> is also equal to the angle <span data-ref="0101.g1:< E B A )">$EBA$</span>;
so that the side <span data-ref="0101.g1:/ E A /">$EA$</span> is also equal to <span data-ref="0101.g1:/ E B /">$EB$</span>. <span class="justification">[I. 6]</span>

Similarly we can prove that each of the straight lines
<span data-ref="0101.g1:/ E A /">$EA$</span>, <span data-ref="0101.g1:/ E B /">$EB$</span> is equal to each of the straight lines <span data-ref="0101.g1:/ E C /">$EC$</span>, <span data-ref="0101.g1:/ E D /">$ED$</span>.

Therefore the four straight lines <span data-ref="0101.g1:/ E A /">$EA$</span>, <span data-ref="0101.g1:/ E B /">$EB$</span>, <span data-ref="0101.g1:/ E C /">$EC$</span>, <span data-ref="0101.g1:/ E D /">$ED$</span> are
equal to one another.

Therefore the circle described with centre <span data-ref="0101.g1:E">$E$</span> and distance
one of the straight lines <span data-ref="0101.g1:/ E A /">$EA$</span>, <span data-ref="0101.g1:/ E B /">$EB$</span>, <span data-ref="0101.g1:/ E C /">$EC$</span>, <span data-ref="0101.g1:/ E D /">$ED$</span> will pass also
through the remaining points;
and it will have been circumscribed about the square <span data-ref="0101.g1:< A B C D >">$ABCD$</span>.

Let it be circumscribed, as <span data-ref="0101.g1:( A B C D )">$ABCD$</span>.

Therefore about the given square a circle has been
circumscribed.
