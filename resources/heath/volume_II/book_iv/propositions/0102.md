### PROPOSITION 10.

<p class="enunciation">To construct an isosceles triangle having each of the angles<br />
at the base double of the remaining one.</p>

Let any straight line <span data-ref="0102.g1:/ A B /">$AB$</span> be set out, and let it be cut at
the point <span data-ref="0102.g1:C">$C$</span> so that the rectangle
contained by <span data-ref="0102.g1:/ A B /">$AB$</span>, <span data-ref="0102.g1:/ B C /">$BC$</span> is equal to
the square on <span data-ref="0102.g1:/ C A /">$CA$</span>; <span class="justification">[II. 11]</span>
with centre <span data-ref="0102.g1:A">$A$</span> and distance <span data-ref="0102.g1:/ A B /">$AB$</span> let
the circle <span data-ref="0102.g1:( B D E )">$BDE$</span> be described,
and let there be fitted in the circle
<span data-ref="0102.g1:( B D E )">$BDE$</span> the straight line <span data-ref="0102.g1:/ B D /">$BD$</span> equal to
the straight line <span data-ref="0102.g1:/ A C /">$AC$</span> which is not
greater than the diameter of the
circle <span data-ref="0102.g1:( B D E )">$BDE$</span>. <span class="justification">[IV. 1]</span>

![Proposition IV. 10 Diagram](0102.g1.svg)

Let <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D C /">$DC$</span> be joined, and let
the circle <span data-ref="0102.g1:( A C D )">$ACD$</span> be circumscribed about the triangle <span data-ref="0102.g1:< A C D >">$ACD$</span>.
<span class="justification">[IV. 5]</span>

Then, since the rectangle <span data-ref="0102.g1:/ A B /">$AB$</span>, <span data-ref="0102.g1:/ B C /">$BC$</span> is equal to the square
on <span data-ref="0102.g1:/ A C /">$AC$</span>,
and <span data-ref="0102.g1:/ A C /">$AC$</span> is equal to <span data-ref="0102.g1:/ B D /">$BD$</span>,
<p class="assertion">therefore the rectangle <span data-ref="0102.g1:/ A B /">$AB$</span>, <span data-ref="0102.g1:/ B C /">$BC$</span> is equal to the square on <span data-ref="0102.g1:/ B D /">$BD$</span>.</p>

And, since a point <span data-ref="0102.g1:B">$B$</span> has been taken outside the circle
<span data-ref="0102.g1:( A C D )">$ACD$</span>,
and from <span data-ref="0102.g1:B">$B$</span> the two straight lines <span data-ref="0102.g1:/ B A /">$BA$</span>, <span data-ref="0102.g1:/ B D /">$BD$</span> have fallen on
the circle <span data-ref="0102.g1:( A C D )">$ACD$</span>, and one of them cuts it, while the other falls
on it,
and the rectangle <span data-ref="0102.g1:/ A B /">$AB$</span>, <span data-ref="0102.g1:/ B C /">$BC$</span> is equal to the square on <span data-ref="0102.g1:/ B D /">$BD$</span>,
<p class="assertion">therefore <span data-ref="0102.g1:/ B D /">$BD$</span> touches the circle <span data-ref="0102.g1:( A C D )">$ACD$</span>. <span class="justification">[III. 37]</span></p>

Since, then, <span data-ref="0102.g1:/ B D /">$BD$</span> touches it, and <span data-ref="0102.g1:/ D C /">$DC$</span> is drawn across
from the point of contact at <span data-ref="0102.g1:D">$D$</span>,
<p class="assertion">therefore the angle <span data-ref="0102.g1:< B D C )">$BDC$</span> is equal to the angle <span data-ref="0102.g1:< D A C )">$DAC$</span> in the<br />
alternate segment of the circle. <span class="justification">[III. 32]</span></p>

Since, then, the angle <span data-ref="0102.g1:< B D C )">$BDC$</span> is equal to the angle <span data-ref="0102.g1:< D A C )">$DAC$</span>,
<p class="sub-clause">let the angle <span data-ref="0102.g1:< C D A )">$CDA$</span> be added to each;</p>
<p class="assertion">therefore the whole angle <span data-ref="0102.g1:< B D A )">$BDA$</span> is equal to the two angles<br />
<span data-ref="0102.g1:< C D A )">$CDA$</span>, <span data-ref="0102.g1:< D A C )">$DAC$</span>.</p>
