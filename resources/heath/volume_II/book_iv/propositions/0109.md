And, since the angle <span data-ref="0108.g2:< F C K )">$FCK$</span> is right,
<p class="assertion">therefore the square on <span data-ref="0108.g2:/ F K /">$FK$</span> is equal to the squares on <span data-ref="0108.g2:/ F C /">$FC$</span>, <span data-ref="0108.g2:/ C K /">$CK$</span>.</p>

For the same reason <span class="justification">[I. 47]</span>
<p class="assertion">the square on <span data-ref="0108.g2:/ F K /">$FK$</span> is also equal to the squares on <span data-ref="0108.g2:/ F B /">$FB$</span>, <span data-ref="0108.g2:/ B K /">$BK$</span>;</p>
so that the squares on <span data-ref="0108.g2:/ F C /">$FC$</span>, <span data-ref="0108.g2:/ C K /">$CK$</span> are equal to the squares
on <span data-ref="0108.g2:/ F B /">$FB$</span>, <span data-ref="0108.g2:/ B K /">$BK$</span>,
<p class="sub-clause">of which the square on <span data-ref="0108.g2:/ F C /">$FC$</span> is equal to the square on <span data-ref="0108.g2:/ F B /">$FB$</span>;</p>
<p class="assertion">therefore the square on <span data-ref="0108.g2:/ C K /">$CK$</span> which remains is equal to the<br />
square on <span data-ref="0108.g2:/ B K /">$BK$</span>.</p>

<p class="assertion">Therefore <span data-ref="0108.g2:/ B K /">$BK$</span> is equal to <span data-ref="0108.g2:/ C K /">$CK$</span>.</p>

And, since <span data-ref="0108.g2:/ F B /">$FB$</span> is equal to <span data-ref="0108.g2:/ F C /">$FC$</span>,
and <span data-ref="0108.g2:/ F K /">$FK$</span> common,
the two sides <span data-ref="0108.g2:/ B F /">$BF$</span>, <span data-ref="0108.g2:/ F K /">$FK$</span> are equal to the two sides <span data-ref="0108.g2:/ C F /">$CF$</span>, <span data-ref="0108.g2:/ F K /">$FK$</span>;
and the base <span data-ref="0108.g2:/ B K /">$BK$</span> equal to the base <span data-ref="0108.g2:/ C K /">$CK$</span>;
<p class="assertion">therefore the angle <span data-ref="0108.g2:< B F K )">$BFK$</span> is equal to the angle <span data-ref="0108.g2:< K F C )">$KFC$</span>, <span class="justification">[I. 8]</span><br />
and the angle <span data-ref="0108.g2:< B K F )">$BKF$</span> to the angle <span data-ref="0108.g2:< F K C )">$FKC$</span>.</p>

<p class="assertion">Therefore the angle <span data-ref="0108.g2:< B F C )">$BFC$</span> is double of the angle <span data-ref="0108.g2:< K F C )">$KFC$</span>,<br />
and the angle <span data-ref="0108.g2:< B K C )">$BKC$</span> of the angle <span data-ref="0108.g2:< F K C )">$FKC$</span>.</p>

For the same reason
<p class="assertion">the angle <span data-ref="0108.g2:< C F D )">$CFD$</span> is also double of the angle <span data-ref="0108.g2:< C F L )">$CFL$</span>,<br />
and the angle <span data-ref="0108.g2:< D L C )">$DLC$</span> of the angle <span data-ref="0108.g2:< F L C )">$FLC$</span>.</p>

Now, since the circumference <span data-ref="0108.g2:( B C )">$BC$</span> is equal to <span data-ref="0108.g2:( C D )">$CD$</span>,
<p class="assertion">the angle <span data-ref="0108.g2:< B F C )">$BFC$</span> is also equal to the angle <span data-ref="0108.g2:< C F D )">$CFD$</span>. <span class="justification">[III. 27]</span></p>

And the angle <span data-ref="0108.g2:< B F C )">$BFC$</span> is double of the angle <span data-ref="0108.g2:< K F C )">$KFC$</span>, and the
angle <span data-ref="0108.g2:< D F C )">$DFC$</span> of the angle <span data-ref="0108.g2:< L F C )">$LFC$</span>;
<p class="assertion">therefore the angle <span data-ref="0108.g2:< K F C )">$KFC$</span> is also equal to the angle <span data-ref="0108.g2:< L F C )">$LFC$</span>.</p>

But the angle <span data-ref="0108.g2:< F C K )">$FCK$</span> is also equal to the angle <span data-ref="0108.g2:< F C L )">$FCL$</span>;
therefore <span data-ref="0108.g2:< F K C >">$FKC$</span>, <span data-ref="0108.g2:< F L C >">$FLC$</span> are two triangles having two angles
equal to two angles and one side equal to one side, namely
<span data-ref="0108.g2:/ F C /">$FC$</span> which is common to them;
therefore they will also have the remaining sides equal to the
remaining sides, and the remaining angle to the remaining
angle; <span class="justification">[I. 26]</span>
<p class="assertion">therefore the straight line <span data-ref="0108.g2:/ K C /">$KC$</span> is equal to <span data-ref="0108.g2:/ C L /">$CL$</span>,<br />
and the angle <span data-ref="0108.g2:< F K C )">$FKC$</span> to the angle <span data-ref="0108.g2:< F L C )">$FLC$</span>.</p>

And, since <span data-ref="0108.g2:/ K C /">$KC$</span> is equal to <span data-ref="0108.g2:/ C L /">$CL$</span>,
<p class="assertion">therefore <span data-ref="0108.g2:/ K L /">$KL$</span> is double of <span data-ref="0108.g2:/ K C /">$KC$</span>.</p>
