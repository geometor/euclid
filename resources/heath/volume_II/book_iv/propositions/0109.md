And, since the angle <span data-ref="0108.g2:< F C K )">$FCK$</span> is right,
therefore the square on <span data-ref="0108.g2:/ F K /">$FK$</span> is equal to the squares on <span data-ref="0108.g2:/ F C /">$FC$</span>, <span data-ref="0108.g2:/ C K /">$CK$</span>.

For the same reason [I. 47]
the square on <span data-ref="0108.g2:/ F K /">$FK$</span> is also equal to the squares on <span data-ref="0108.g2:/ F B /">$FB$</span>, <span data-ref="0108.g2:/ B K /">$BK$</span>;
so that the squares on <span data-ref="0108.g2:/ F C /">$FC$</span>, <span data-ref="0108.g2:/ C K /">$CK$</span> are equal to the squares on <span data-ref="0108.g2:/ F B /">$FB$</span>, <span data-ref="0108.g2:/ B K /">$BK$</span>,
of which the square on <span data-ref="0108.g2:/ F C /">$FC$</span> is equal to the square on <span data-ref="0108.g2:/ F B /">$FB$</span>;
therefore the square on <span data-ref="0108.g2:/ C K /">$CK$</span> which remains is equal to the square on <span data-ref="0108.g2:/ B K /">$BK$</span>.

Therefore <span data-ref="0108.g2:/ B K /">$BK$</span> is equal to <span data-ref="0108.g2:/ C K /">$CK$</span>.

And, since <span data-ref="0108.g2:/ F B /">$FB$</span> is equal to <span data-ref="0108.g2:/ F C /">$FC$</span>,
and <span data-ref="0108.g2:/ F K /">$FK$</span> common,
the two sides <span data-ref="0108.g2:/ B F /">$BF$</span>, <span data-ref="0108.g2:/ F K /">$FK$</span> are equal to the two sides <span data-ref="0108.g2:/ C F /">$CF$</span>, <span data-ref="0108.g2:/ F K /">$FK$</span>;
and the base <span data-ref="0108.g2:/ B K /">$BK$</span> equal to the base <span data-ref="0108.g2:/ C K /">$CK$</span>;
therefore the angle <span data-ref="0108.g2:< B F K )">$BFK$</span> is equal to the angle <span data-ref="0108.g2:< K F C )">$KFC$</span>, [I. 8]
and the angle <span data-ref="0108.g2:< B K F )">$BKF$</span> to the angle <span data-ref="0108.g2:< F K C )">$FKC$</span>.

Therefore the angle <span data-ref="0108.g2:< B F C )">$BFC$</span> is double of the angle <span data-ref="0108.g2:< K F C )">$KFC$</span>,
and the angle <span data-ref="0108.g2:< B K C )">$BKC$</span> of the angle <span data-ref="0108.g2:< F K C )">$FKC$</span>.

For the same reason
the angle <span data-ref="0108.g2:< C F D )">$CFD$</span> is also double of the angle <span data-ref="0108.g2:< C F L )">$CFL$</span>,
and the angle <span data-ref="0108.g2:< D L C )">$DLC$</span> of the angle <span data-ref="0108.g2:< F L C )">$FLC$</span>.

Now, since the circumference <span data-ref="0108.g2:( B C )">$BC$</span> is equal to <span data-ref="0108.g2:( C D )">$CD$</span>,
the angle <span data-ref="0108.g2:< B F C )">$BFC$</span> is also equal to the angle <span data-ref="0108.g2:< C F D )">$CFD$</span>. [III. 27]

And the angle <span data-ref="0108.g2:< B F C )">$BFC$</span> is double of the angle <span data-ref="0108.g2:< K F C )">$KFC$</span>, and the angle <span data-ref="0108.g2:< D F C )">$DFC$</span> of the angle <span data-ref="0108.g2:< L F C )">$LFC$</span>;
therefore the angle <span data-ref="0108.g2:< K F C )">$KFC$</span> is also equal to the angle <span data-ref="0108.g2:< L F C )">$LFC$</span>.

But the angle <span data-ref="0108.g2:< F C K )">$FCK$</span> is also equal to the angle <span data-ref="0108.g2:< F C L )">$FCL$</span>;
therefore <span data-ref="0108.g2:< F K C >">$FKC$</span>, <span data-ref="0108.g2:< F L C >">$FLC$</span> are two triangles having two angles equal to two angles and one side equal to one side, namely <span data-ref="0108.g2:/ F C /">$FC$</span> which is common to them;
therefore they will also have the remaining sides equal to the remaining sides, and the remaining angle to the remaining angle; [I. 26]
therefore the straight line <span data-ref="0108.g2:/ K C /">$KC$</span> is equal to <span data-ref="0108.g2:/ C L /">$CL$</span>,
and the angle <span data-ref="0108.g2:< F K C )">$FKC$</span> to the angle <span data-ref="0108.g2:< F L C )">$FLC$</span>.

And, since <span data-ref="0108.g2:/ K C /">$KC$</span> is equal to <span data-ref="0108.g2:/ C L /">$CL$</span>,
therefore <span data-ref="0108.g2:/ K L /">$KL$</span> is double of <span data-ref="0108.g2:/ K C /">$KC$</span>.
