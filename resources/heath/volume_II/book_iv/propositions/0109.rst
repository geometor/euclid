And, since the angle :g:`$FCK$ <0108.g2:< F C K )>` is right,

.. assertion::

   therefore the square on :g:`$FK$ <0108.g2:/ F K />` is equal to the squares on :g:`$FC$ <0108.g2:/ F C />`, :g:`$CK$ <0108.g2:/ C K />`.

For the same reason :just:`[I. 47] <I.47>`

.. assertion::

   the square on :g:`$FK$ <0108.g2:/ F K />` is also equal to the squares on :g:`$FB$ <0108.g2:/ F B />`, :g:`$BK$ <0108.g2:/ B K />`;

so that the squares on :g:`$FC$ <0108.g2:/ F C />`, :g:`$CK$ <0108.g2:/ C K />` are equal to the squares
on :g:`$FB$ <0108.g2:/ F B />`, :g:`$BK$ <0108.g2:/ B K />`,

.. subclause::

   of which the square on :g:`$FC$ <0108.g2:/ F C />` is equal to the square on :g:`$FB$ <0108.g2:/ F B />`;

.. assertion::

   | therefore the square on :g:`$CK$ <0108.g2:/ C K />` which remains is equal to the
   | square on :g:`$BK$ <0108.g2:/ B K />`.

.. assertion::

   Therefore :g:`$BK$ <0108.g2:/ B K />` is equal to :g:`$CK$ <0108.g2:/ C K />`.

And, since :g:`$FB$ <0108.g2:/ F B />` is equal to :g:`$FC$ <0108.g2:/ F C />`,
and :g:`$FK$ <0108.g2:/ F K />` common,
the two sides :g:`$BF$ <0108.g2:/ B F />`, :g:`$FK$ <0108.g2:/ F K />` are equal to the two sides :g:`$CF$ <0108.g2:/ C F />`, :g:`$FK$ <0108.g2:/ F K />`;
and the base :g:`$BK$ <0108.g2:/ B K />` equal to the base :g:`$CK$ <0108.g2:/ C K />`;

.. assertion::

   | therefore the angle :g:`$BFK$ <0108.g2:< B F K )>` is equal to the angle :g:`$KFC$ <0108.g2:< K F C )>`, :just:`[I. 8] <I.8>`
   | and the angle :g:`$BKF$ <0108.g2:< B K F )>` to the angle :g:`$FKC$ <0108.g2:< F K C )>`.

.. assertion::

   | Therefore the angle :g:`$BFC$ <0108.g2:< B F C )>` is double of the angle :g:`$KFC$ <0108.g2:< K F C )>`,
   | and the angle :g:`$BKC$ <0108.g2:< B K C )>` of the angle :g:`$FKC$ <0108.g2:< F K C )>`.

For the same reason

.. assertion::

   | the angle :g:`$CFD$ <0108.g2:< C F D )>` is also double of the angle :g:`$CFL$ <0108.g2:< C F L )>`,
   | and the angle :g:`$DLC$ <0108.g2:< D L C )>` of the angle :g:`$FLC$ <0108.g2:< F L C )>`.

Now, since the circumference :g:`$BC$ <0108.g2:( B C )>` is equal to :g:`$CD$ <0108.g2:( C D )>`,

.. assertion:: [III. 27] <III.27>

   the angle :g:`$BFC$ <0108.g2:< B F C )>` is also equal to the angle :g:`$CFD$ <0108.g2:< C F D )>`.

And the angle :g:`$BFC$ <0108.g2:< B F C )>` is double of the angle :g:`$KFC$ <0108.g2:< K F C )>`, and the
angle :g:`$DFC$ <0108.g2:< D F C )>` of the angle :g:`$LFC$ <0108.g2:< L F C )>`;

.. assertion::

   therefore the angle :g:`$KFC$ <0108.g2:< K F C )>` is also equal to the angle :g:`$LFC$ <0108.g2:< L F C )>`.

But the angle :g:`$FCK$ <0108.g2:< F C K )>` is also equal to the angle :g:`$FCL$ <0108.g2:< F C L )>`;
therefore :g:`$FKC$ <0108.g2:< F K C >>`, :g:`$FLC$ <0108.g2:< F L C >>` are two triangles having two angles
equal to two angles and one side equal to one side, namely
:g:`$FC$ <0108.g2:/ F C />` which is common to them;
therefore they will also have the remaining sides equal to the
remaining sides, and the remaining angle to the remaining
angle; :just:`[I. 26] <I.26>`

.. assertion::

   | therefore the straight line :g:`$KC$ <0108.g2:/ K C />` is equal to :g:`$CL$ <0108.g2:/ C L />`,
   | and the angle :g:`$FKC$ <0108.g2:< F K C )>` to the angle :g:`$FLC$ <0108.g2:< F L C )>`.

And, since :g:`$KC$ <0108.g2:/ K C />` is equal to :g:`$CL$ <0108.g2:/ C L />`,

.. assertion::

   therefore :g:`$KL$ <0108.g2:/ K L />` is double of :g:`$KC$ <0108.g2:/ K C />`.
