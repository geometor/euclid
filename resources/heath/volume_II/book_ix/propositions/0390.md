# BOOK IX.

### PROPOSITION 1.

<p class="enunciation">If two similar plane numbers by multiplying one another<br />
make some number, the product will be square.</p>

Let <span data-ref="0390.g1:A">$A$</span>, <span data-ref="0390.g1:B">$B$</span> be two similar plane numbers, and let <span data-ref="0390.g1:A">$A$</span> by<br />
multiplying <span data-ref="0390.g1:B">$B$</span> make <span data-ref="0390.g1:C">$C$</span>;<br />
I say that <span data-ref="0390.g1:C">$C$</span> is square.

![Proposition 1 Diagram](0390.g1.svg)

For let <span data-ref="0390.g1:A">$A$</span> by multiplying itself<br />
make <span data-ref="0390.g1:D">$D$</span>.

<p class="assertion">Therefore <span data-ref="0390.g1:D">$D$</span> is square.</p>

<p class="sub-clause">Since then <span data-ref="0390.g1:A">$A$</span> by multiplying itself has made <span data-ref="0390.g1:D">$D$</span>, and by<br />
multiplying <span data-ref="0390.g1:B">$B$</span> has made <span data-ref="0390.g1:C">$C$</span>,</p>

<p class="assertion">therefore, as <span data-ref="0390.g1:A">$A$</span> is to <span data-ref="0390.g1:B">$B$</span>, so is <span data-ref="0390.g1:D">$D$</span> to <span data-ref="0390.g1:C">$C$</span>. <span class="justification">[VII. 17]</span></p>

<p class="sub-clause">And, since <span data-ref="0390.g1:A">$A$</span>, <span data-ref="0390.g1:B">$B$</span> are similar plane numbers,</p>

<p class="assertion">therefore one mean proportional number falls between <span data-ref="0390.g1:A">$A$</span>, <span data-ref="0390.g1:B">$B$</span>.<br />
<span class="justification">[VIII. 18]</span></p>

<p class="sub-clause">But, if numbers fall between two numbers in continued<br />
proportion, as many as fall between them, so many also fall<br />
between those which have the same ratio; <span class="justification">[VIII. 8]</span></p>

<p class="assertion">so that one mean proportional number falls between <span data-ref="0390.g1:D">$D$</span>, <span data-ref="0390.g1:C">$C$</span> also.</p>

<p class="sub-clause">And <span data-ref="0390.g1:D">$D$</span> is square;</p>

<p class="assertion">therefore <span data-ref="0390.g1:C">$C$</span> is also square. <span class="justification">[VIII. 22]</span></p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

The product of two similar plane numbers is a square.<br />
Let $a$, $b$ be two similar plane numbers.<br />
Now
$$a : b = a^2 : ab. \hfill \text{[VII. 17]}$$
And between $a$, $b$ there is one mean proportional. <span class="justification">[VIII. 18]</span><br />
Therefore between $a^2 : ab$ there is one mean proportional. <span class="justification">[VIII. 8]</span><br />
And $a^2$ is square;<br />
therefore $ab$ is square. <span class="justification">[VIII. 22]</span>
