# BOOK IX.

### PROPOSITION 1.

*If two similar plane numbers by multiplying one another make some number, the product will be square.*

Let <span data-ref="0390.g1:A">$A$</span>, <span data-ref="0390.g1:B">$B$</span> be two similar plane numbers, and let <span data-ref="0390.g1:A">$A$</span> by multiplying <span data-ref="0390.g1:B">$B$</span> make <span data-ref="0390.g1:C">$C$</span>;  
I say that <span data-ref="0390.g1:C">$C$</span> is square.

![Proposition 1 Diagram](0390.g1.svg)

For let <span data-ref="0390.g1:A">$A$</span> by multiplying itself make <span data-ref="0390.g1:D">$D$</span>.  
Therefore <span data-ref="0390.g1:D">$D$</span> is square.

Since then <span data-ref="0390.g1:A">$A$</span> by multiplying itself has made <span data-ref="0390.g1:D">$D$</span>, and by multiplying <span data-ref="0390.g1:B">$B$</span> has made <span data-ref="0390.g1:C">$C$</span>, therefore, as <span data-ref="0390.g1:A">$A$</span> is to <span data-ref="0390.g1:B">$B$</span>, so is <span data-ref="0390.g1:D">$D$</span> to <span data-ref="0390.g1:C">$C$</span>. [VII. 17]

And, since <span data-ref="0390.g1:A">$A$</span>, <span data-ref="0390.g1:B">$B$</span> are similar plane numbers, therefore one mean proportional number falls between <span data-ref="0390.g1:A">$A$</span>, <span data-ref="0390.g1:B">$B$</span>. [VIII. 18]

But, if numbers fall between two numbers in continued proportion, as many as fall between them, so many also fall between those which have the same ratio; [VIII. 8] so that one mean proportional number falls between <span data-ref="0390.g1:D">$D$</span>, <span data-ref="0390.g1:C">$C$</span> also.

And <span data-ref="0390.g1:D">$D$</span> is square;  
therefore <span data-ref="0390.g1:C">$C$</span> is also square. [VIII. 22]

**Q. E. D.**

---

The product of two similar plane numbers is a square.  
Let $a$, $b$ be two similar plane numbers.  
Now
$$a : b = a^2 : ab. \hfill \text{[VII. 17]}$$
And between $a$, $b$ there is one mean proportional. [VIII. 18]  
Therefore between $a^2 : ab$ there is one mean proportional. [VIII. 8]  
And $a^2$ is square;  
therefore $ab$ is square. [VIII. 22]
