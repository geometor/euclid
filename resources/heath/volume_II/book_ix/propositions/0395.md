Therefore, as the unit is to <span data-ref="0394.g1:A">$A$</span>, so is <span data-ref="0394.g1:B">$B$</span> to <span data-ref="0394.g1:C">$C$</span>. [VII. Def. 20]

But, as the unit is to <span data-ref="0394.g1:A">$A$</span>, so is <span data-ref="0394.g1:A">$A$</span> to <span data-ref="0394.g1:B">$B$</span>; therefore also, as <span data-ref="0394.g1:A">$A$</span> is to <span data-ref="0394.g1:B">$B$</span>, so is <span data-ref="0394.g1:B">$B$</span> to <span data-ref="0394.g1:C">$C$</span>.

And, since <span data-ref="0394.g1:B">$B$</span>, <span data-ref="0394.g1:C">$C$</span> are cube, they are similar solid numbers.

Therefore there are two mean proportional numbers between <span data-ref="0394.g1:B">$B$</span>, <span data-ref="0394.g1:C">$C$</span>. [VIII. 19]

And, as <span data-ref="0394.g1:B">$B$</span> is to <span data-ref="0394.g1:C">$C$</span>, so is <span data-ref="0394.g1:A">$A$</span> to <span data-ref="0394.g1:B">$B$</span>.  
Therefore there are two mean proportional numbers between <span data-ref="0394.g1:A">$A$</span>, <span data-ref="0394.g1:B">$B$</span> also. [VIII. 8]

And <span data-ref="0394.g1:B">$B$</span> is cube;  
therefore <span data-ref="0394.g1:A">$A$</span> is also cube. [cf. VIII. 23]

**Q. E. D.**

---

If $a^2$ is a cube number, $a$ is also a cube.  
For
$$1 : a = a : a^2 = a^2 : a^3.$$
Now $a^2$, $a^3$ are both cubes, and therefore "similar solids"; therefore there are two mean proportionals between them. [VIII. 19]  
Therefore there are two mean proportionals between $a$, $a^2$. [VIII. 8]  
And $a^2$ is a cube:  
therefore $a$ is also a cube number. [VIII. 23]

It will be noticed that the last step is not an exact quotation of the result of VIII. 23, because it is there the *first* of four terms which is known to be a cube, and the *last* which is proved to be a cube; here the case is reversed. But there is no difficulty. Without inverting the proportions, we have only to refer to VIII. 21 which proves that $a$, $a^2$, having two mean proportionals between them, are two similar solid numbers; whence, since $a^2$ is a cube, $a$ is also a cube.

### PROPOSITION 7.

*If a composite number by multiplying any number make some number, the product will be solid.*

For let the composite number <span data-ref="0395.g1:A">$A$</span> by multiplying any number <span data-ref="0395.g1:B">$B$</span> make <span data-ref="0395.g1:C">$C$</span>;  
I say that <span data-ref="0395.g1:C">$C$</span> is solid.

![Proposition 7 Diagram](0395.g1.svg)

For, since <span data-ref="0395.g1:A">$A$</span> is composite, it will be measured by some number. [VII. Def. 13]

Let it be measured by <span data-ref="0395.g1:D">$D$</span>; and, as many times as <span data-ref="0395.g1:D">$D$</span> measures <span data-ref="0395.g1:A">$A$</span>, so many units let there be in <span data-ref="0395.g1:E">$E$</span>.
