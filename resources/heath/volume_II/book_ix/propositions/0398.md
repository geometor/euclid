### PROPOSITION 9.

*If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be square, all the rest will also be square. And, if the number after the unit be cube, all the rest will also be cube.*

Let there be as many numbers as we please, <span data-ref="0398.g1:A">$A$</span>, <span data-ref="0398.g1:B">$B$</span>, <span data-ref="0398.g1:C">$C$</span>, <span data-ref="0398.g1:D">$D$</span>, <span data-ref="0398.g1:E">$E$</span>, <span data-ref="0398.g1:F">$F$</span>, beginning from an unit and in continued proportion, and let <span data-ref="0398.g1:A">$A$</span>, the number after the unit, be square;  
I say that all the rest will also be square.

![Proposition 9 Diagram](0398.g1.svg)

Now it has been proved that <span data-ref="0398.g1:B">$B$</span>, the third from the unit, is square, as are also all those which leave out one; [ix. 8]  
I say that all the rest are also square.

For, since <span data-ref="0398.g1:A">$A$</span>, <span data-ref="0398.g1:B">$B$</span>, <span data-ref="0398.g1:C">$C$</span> are in continued proportion, and <span data-ref="0398.g1:A">$A$</span> is square,  
therefore <span data-ref="0398.g1:C">$C$</span> is also square. [VIII. 22]

Again, since <span data-ref="0398.g1:B">$B$</span>, <span data-ref="0398.g1:C">$C$</span>, <span data-ref="0398.g1:D">$D$</span> are in continued proportion, and <span data-ref="0398.g1:B">$B$</span> is square,  
<span data-ref="0398.g1:D">$D$</span> is also square. [VIII. 22]

Similarly we can prove that all the rest are also square.

Next, let <span data-ref="0398.g1:A">$A$</span> be cube;  
I say that all the rest are also cube.

Now it has been proved that <span data-ref="0398.g1:C">$C$</span>, the fourth from the unit, is cube, as also are all those which leave out two; [ix. 8]  
I say that all the rest are also cube.

For, since as the unit is to <span data-ref="0398.g1:A">$A$</span>, so is <span data-ref="0398.g1:A">$A$</span> to <span data-ref="0398.g1:B">$B$</span>,  
therefore the unit measures <span data-ref="0398.g1:A">$A$</span> the same number of times as <span data-ref="0398.g1:A">$A$</span> measures <span data-ref="0398.g1:B">$B$</span>.

But the unit measures <span data-ref="0398.g1:A">$A$</span> according to the units in it;  
therefore <span data-ref="0398.g1:A">$A$</span> also measures <span data-ref="0398.g1:B">$B$</span> according to the units in itself;  
therefore <span data-ref="0398.g1:A">$A$</span> by multiplying itself has made <span data-ref="0398.g1:B">$B$</span>.
