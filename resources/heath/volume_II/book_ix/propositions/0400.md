I say that neither will any other be square except the third<br />
from the unit <and those which<br />
leave out one>.

![Proposition 10 Diagram](0400.g1.svg)

<p class="sub-clause">For, if possible, let <span data-ref="0400.g1:C">$C$</span> be square.</p>
<p class="sub-clause">But <span data-ref="0400.g1:B">$B$</span> is also square ; <span class="justification">[ix. 8]</span></p>
<p class="assertion">[therefore <span data-ref="0400.g1:B">$B$</span>, <span data-ref="0400.g1:C">$C$</span> have to one another<br />
the ratio which a square number<br />
has to a square number].</p>

<p class="sub-clause">And, as <span data-ref="0400.g1:B">$B$</span> is to <span data-ref="0400.g1:C">$C$</span>, so is <span data-ref="0400.g1:A">$A$</span> to <span data-ref="0400.g1:B">$B$</span> ;</p>
<p class="assertion">therefore <span data-ref="0400.g1:A">$A$</span>, <span data-ref="0400.g1:B">$B$</span> have to one another the ratio which a square<br />
number has to a square number ;</p>
<p class="assertion">[so that <span data-ref="0400.g1:A">$A$</span>, <span data-ref="0400.g1:B">$B$</span> are similar plane numbers]. <span class="justification">[VIII. 26, converse]</span></p>

<p class="sub-clause">And <span data-ref="0400.g1:B">$B$</span> is square ;</p>
<p class="assertion">therefore <span data-ref="0400.g1:A">$A$</span> is also square :<br />
which is contrary to the hypothesis.</p>

<p class="assertion">Therefore <span data-ref="0400.g1:C">$C$</span> is not square.</p>

<p class="assertion">Similarly we can prove that neither is any other of the<br />
numbers square except the third from the unit and those which<br />
leave out one.</p>

Next, let <span data-ref="0400.g1:A">$A$</span> not be cube ;<br />
I say that neither will any other be cube except the fourth<br />
from the unit and those which leave out two.

<p class="sub-clause">For, if possible, let <span data-ref="0400.g1:D">$D$</span> be cube.</p>
<p class="sub-clause">Now <span data-ref="0400.g1:C">$C$</span> is also cube ; for it is fourth from the unit. <span class="justification">[ix. 8]</span></p>
<p class="sub-clause">And, as <span data-ref="0400.g1:C">$C$</span> is to <span data-ref="0400.g1:D">$D$</span>, so is <span data-ref="0400.g1:B">$B$</span> to <span data-ref="0400.g1:C">$C$</span> ;</p>
<p class="assertion">therefore <span data-ref="0400.g1:B">$B$</span> also has to <span data-ref="0400.g1:C">$C$</span> the ratio which a cube has to a cube.</p>

<p class="sub-clause">And <span data-ref="0400.g1:C">$C$</span> is cube ;</p>
<p class="assertion">therefore <span data-ref="0400.g1:B">$B$</span> is also cube. <span class="justification">[VIII. 25]</span></p>

<p class="sub-clause">And since, as the unit is to <span data-ref="0400.g1:A">$A$</span>, so is <span data-ref="0400.g1:A">$A$</span> to <span data-ref="0400.g1:B">$B$</span>,<br />
and the unit measures <span data-ref="0400.g1:A">$A$</span> according to the units in it,</p>
<p class="assertion">therefore <span data-ref="0400.g1:A">$A$</span> also measures <span data-ref="0400.g1:B">$B$</span> according to the units in itself ;</p>
<p class="assertion">therefore <span data-ref="0400.g1:A">$A$</span> by multiplying itself has made the cube number <span data-ref="0400.g1:B">$B$</span>.</p>

<p class="sub-clause">But, if a number by multiplying itself make a cube number,<br />
it is also itself cube. <span class="justification">[ix. 6]</span></p>

<p class="assertion">Therefore <span data-ref="0400.g1:A">$A$</span> is also cube :<br />
which is contrary to the hypothesis.</p>

<p class="assertion">Therefore <span data-ref="0400.g1:D">$D$</span> is not cube.</p>
