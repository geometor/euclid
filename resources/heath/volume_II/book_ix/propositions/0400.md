I say that neither will any other be square except the third from the unit <and those which leave out one>.

![Proposition 10 Diagram](0400.g1.svg)

For, if possible, let <span data-ref="0400.g1:C">$C$</span> be square.  
But <span data-ref="0400.g1:B">$B$</span> is also square; [ix. 8]  
[therefore <span data-ref="0400.g1:B">$B$</span>, <span data-ref="0400.g1:C">$C$</span> have to one another the ratio which a square number has to a square number].  
And, as <span data-ref="0400.g1:B">$B$</span> is to <span data-ref="0400.g1:C">$C$</span>, so is <span data-ref="0400.g1:A">$A$</span> to <span data-ref="0400.g1:B">$B$</span>;  
therefore <span data-ref="0400.g1:A">$A$</span>, <span data-ref="0400.g1:B">$B$</span> have to one another the ratio which a square number has to a square number;  
[so that <span data-ref="0400.g1:A">$A$</span>, <span data-ref="0400.g1:B">$B$</span> are similar plane numbers]. [VIII. 26, converse]  
And <span data-ref="0400.g1:B">$B$</span> is square;  
therefore <span data-ref="0400.g1:A">$A$</span> is also square:  
which is contrary to the hypothesis.  
Therefore <span data-ref="0400.g1:C">$C$</span> is not square.

Similarly we can prove that neither is any other of the numbers square except the third from the unit and those which leave out one.

Next, let <span data-ref="0400.g1:A">$A$</span> not be cube.  
I say that neither will any other be cube except the fourth from the unit and those which leave out two.

For, if possible, let <span data-ref="0400.g1:D">$D$</span> be cube.  
Now <span data-ref="0400.g1:C">$C$</span> is also cube; for it is fourth from the unit. [ix. 8]  
And, as <span data-ref="0400.g1:C">$C$</span> is to <span data-ref="0400.g1:D">$D$</span>, so is <span data-ref="0400.g1:B">$B$</span> to <span data-ref="0400.g1:C">$C$</span>;  
therefore <span data-ref="0400.g1:B">$B$</span> also has to <span data-ref="0400.g1:C">$C$</span> the ratio which a cube has to a cube.  
And <span data-ref="0400.g1:C">$C$</span> is cube;  
therefore <span data-ref="0400.g1:B">$B$</span> is also cube. [VIII. 25]

And since, as the unit is to <span data-ref="0400.g1:A">$A$</span>, so is <span data-ref="0400.g1:A">$A$</span> to <span data-ref="0400.g1:B">$B$</span>,  
and the unit measures <span data-ref="0400.g1:A">$A$</span> according to the units in it,  
therefore <span data-ref="0400.g1:A">$A$</span> also measures <span data-ref="0400.g1:B">$B$</span> according to the units in itself;  
therefore <span data-ref="0400.g1:A">$A$</span> by multiplying itself has made the cube number <span data-ref="0400.g1:B">$B$</span>.

But, if a number by multiplying itself make a cube number, it is also itself cube. [ix. 6]  
Therefore <span data-ref="0400.g1:A">$A$</span> is also cube:  
which is contrary to the hypothesis.  
Therefore <span data-ref="0400.g1:D">$D$</span> is not cube.
