Let there be as many numbers as we please, <span data-ref="0402.g1:B">$B$</span>, <span data-ref="0402.g1:C">$C$</span>, <span data-ref="0402.g1:D">$D$</span>, <span data-ref="0402.g1:E">$E$</span>, beginning from the unit <span data-ref="0402.g1:A">$A$</span> and in continued proportion;  
I say that <span data-ref="0402.g1:B">$B$</span>, the least of the numbers <span data-ref="0402.g1:B">$B$</span>, <span data-ref="0402.g1:C">$C$</span>, <span data-ref="0402.g1:D">$D$</span>, <span data-ref="0402.g1:E">$E$</span>, measures <span data-ref="0402.g1:E">$E$</span> according to some one of the numbers <span data-ref="0402.g1:C">$C$</span>, <span data-ref="0402.g1:D">$D$</span>.

![Proposition 11 Diagram](0402.g1.svg)

For since, as the unit <span data-ref="0402.g1:A">$A$</span> is to <span data-ref="0402.g1:B">$B$</span>, so is <span data-ref="0402.g1:D">$D$</span> to <span data-ref="0402.g1:E">$E$</span>,  
therefore the unit <span data-ref="0402.g1:A">$A$</span> measures the number <span data-ref="0402.g1:B">$B$</span> the same number of times as <span data-ref="0402.g1:D">$D$</span> measures <span data-ref="0402.g1:E">$E$</span>;  
therefore, alternately, the unit <span data-ref="0402.g1:A">$A$</span> measures <span data-ref="0402.g1:D">$D$</span> the same number of times as <span data-ref="0402.g1:B">$B$</span> measures <span data-ref="0402.g1:E">$E$</span>. [VII. 15]

But the unit <span data-ref="0402.g1:A">$A$</span> measures <span data-ref="0402.g1:D">$D$</span> according to the units in it;  
therefore <span data-ref="0402.g1:B">$B$</span> also measures <span data-ref="0402.g1:E">$E$</span> according to the units in <span data-ref="0402.g1:D">$D$</span>;  
so that <span data-ref="0402.g1:B">$B$</span> the less measures <span data-ref="0402.g1:E">$E$</span> the greater according to some number of those which have place among the proportional numbers.—

#### PORISM.

And it is manifest that, whatever place the measuring number has, reckoned from the unit, the same place also has the number according to which it measures, reckoned from the number measured, in the direction of the number before it.—

<p align="right">Q. E. D.</p>

---

The proposition and the porism together assert that, if $1, a, a_2, \dots a_n$ be a geometrical progression, $a_r$ measures $a_n$ and gives the quotient $a_{n-r}\ (r < n)$.

Euclid only proves that $a_n = a \cdot a_{n-1}$, as follows.
$$1 : a = a_{n-1} : a_n.$$
Therefore $1$ measures $a$ the same number of times as $a_{n-1}$ measures $a_n.$  
Hence $1$ measures $a_{n-1}$ the same number of times as $a$ measures $a_n;$ [VII. 15]  
that is,
$$a_n = a \cdot a_{n-1}.$$

We can supply the proof of the porism as follows.
$$\begin{aligned}
1 : a &= a_r : a_{r+1}, \\
a : a_2 &= a_{r+1} : a_{r+2}, \\
&\dots\dots\dots\dots\dots\dots \\
a_{n-r-1} : a_{n-r} &= a_{n-1} : a_n,
\end{aligned}$$
whence, *ex aequali*,
$$1 : a_{n-r} = a_r : a_n.\text{ \hfill [VII. 14]}$$

It follows, by the same argument as before, that
$$a_n = a_r \cdot a_{n-r}.$$

With our notation, we have the theorem of indices that
$$a^{m+n} = a^m \cdot a^n.$$
