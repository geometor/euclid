### PROPOSITION 12.

*If as many numbers as we please beginning from an unit be in continued proportion, by however many prime numbers the last is measured, the next to the unit will also be measured by the same.*

Let there be as many numbers as we please, <span data-ref="0403.g1:A">$A$</span>, <span data-ref="0403.g1:B">$B$</span>, <span data-ref="0403.g1:C">$C$</span>, <span data-ref="0403.g1:D">$D$</span>, beginning from an unit, and in continued proportion;  
I say that, by however many prime numbers <span data-ref="0403.g1:D">$D$</span> is measured, <span data-ref="0403.g1:A">$A$</span> will also be measured by the same.

![Proposition 12 Diagram](0403.g1.svg)

For let <span data-ref="0403.g1:D">$D$</span> be measured by any prime number <span data-ref="0403.g1:E">$E$</span>;  
I say that <span data-ref="0403.g1:E">$E$</span> measures <span data-ref="0403.g1:A">$A$</span>.

For suppose it does not;  
now <span data-ref="0403.g1:E">$E$</span> is prime, and any prime number is prime to any which it does not measure; [VII. 29]  
therefore <span data-ref="0403.g1:E">$E$</span>, <span data-ref="0403.g1:A">$A$</span> are prime to one another.

And, since <span data-ref="0403.g1:E">$E$</span> measures <span data-ref="0403.g1:D">$D$</span>, let it measure it according to <span data-ref="0403.g1:F">$F$</span>,  
therefore <span data-ref="0403.g1:E">$E$</span> by multiplying <span data-ref="0403.g1:F">$F$</span> has made <span data-ref="0403.g1:D">$D$</span>.

Again, since <span data-ref="0403.g1:A">$A$</span> measures <span data-ref="0403.g1:D">$D$</span> according to the units in <span data-ref="0403.g1:C">$C$</span>, [ix. 11 and Por.]  
therefore <span data-ref="0403.g1:A">$A$</span> by multiplying <span data-ref="0403.g1:C">$C$</span> has made <span data-ref="0403.g1:D">$D$</span>.

But, further, <span data-ref="0403.g1:E">$E$</span> has also by multiplying <span data-ref="0403.g1:F">$F$</span> made <span data-ref="0403.g1:D">$D$</span>;  
therefore the product of <span data-ref="0403.g1:A">$A$</span>, <span data-ref="0403.g1:C">$C$</span> is equal to the product of <span data-ref="0403.g1:E">$E$</span>, <span data-ref="0403.g1:F">$F$</span>.

Therefore, as <span data-ref="0403.g1:A">$A$</span> is to <span data-ref="0403.g1:E">$E$</span>, so is <span data-ref="0403.g1:F">$F$</span> to <span data-ref="0403.g1:C">$C$</span>. [VII. 19]

But <span data-ref="0403.g1:A">$A$</span>, <span data-ref="0403.g1:E">$E$</span> are prime,  
primes are also least, [VII. 21]  
and the least measure those which have the same ratio the same number of times, the antecedent the antecedent and the consequent the consequent; [VII. 20]  
therefore <span data-ref="0403.g1:E">$E$</span> measures <span data-ref="0403.g1:C">$C$</span>.

Let it measure it according to <span data-ref="0403.g1:G">$G$</span>;  
therefore <span data-ref="0403.g1:E">$E$</span> by multiplying <span data-ref="0403.g1:G">$G$</span> has made <span data-ref="0403.g1:C">$C$</span>.

But, further, by the theorem before this,  
<span data-ref="0403.g1:A">$A$</span> has also by multiplying <span data-ref="0403.g1:B">$B$</span> made <span data-ref="0403.g1:C">$C$</span>. [ix. 11 and Por.]
