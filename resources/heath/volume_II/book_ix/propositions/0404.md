Therefore the product of <span data-ref="0403.g1:A">$A$</span>, <span data-ref="0403.g1:B">$B$</span> is equal to the product of <span data-ref="0403.g1:E">$E$</span>, <span data-ref="0403.g1:G">$G$</span>.

Therefore, as <span data-ref="0403.g1:A">$A$</span> is to <span data-ref="0403.g1:E">$E$</span>, so is <span data-ref="0403.g1:G">$G$</span> to <span data-ref="0403.g1:B">$B$</span>. [^398_1]

But <span data-ref="0403.g1:A">$A$</span>, <span data-ref="0403.g1:E">$E$</span> are prime,  
primes are also least, [^398_2]  
and the least numbers measure those which have the same ratio with them the same number of times, the antecedent the antecedent and the consequent the consequent: [^398_3]  
therefore <span data-ref="0403.g1:E">$E$</span> measures <span data-ref="0403.g1:B">$B$</span>.

Let it measure it according to <span data-ref="0403.g1:H">$H$</span>;  
therefore <span data-ref="0403.g1:E">$E$</span> by multiplying <span data-ref="0403.g1:H">$H$</span> has made <span data-ref="0403.g1:B">$B$</span>.

But further <span data-ref="0403.g1:A">$A$</span> has also by multiplying itself made <span data-ref="0403.g1:B">$B$</span>; [^398_4]  
therefore the product of <span data-ref="0403.g1:E">$E$</span>, <span data-ref="0403.g1:H">$H$</span> is equal to the square on <span data-ref="0403.g1:A">$A$</span>.

Therefore, as <span data-ref="0403.g1:E">$E$</span> is to <span data-ref="0403.g1:A">$A$</span>, so is <span data-ref="0403.g1:A">$A$</span> to <span data-ref="0403.g1:H">$H$</span>. [^398_5]

But <span data-ref="0403.g1:A">$A$</span>, <span data-ref="0403.g1:E">$E$</span> are prime,  
primes are also least, [^398_6]  
and the least measure those which have the same ratio the same number of times, the antecedent the antecedent and the consequent the consequent; [^398_7]  
therefore <span data-ref="0403.g1:E">$E$</span> measures <span data-ref="0403.g1:A">$A$</span>, as antecedent antecedent.

But, again, it also does not measure it:  
which is impossible.

Therefore <span data-ref="0403.g1:E">$E$</span>, <span data-ref="0403.g1:A">$A$</span> are not prime to one another.

Therefore they are composite to one another.

But numbers composite to one another are measured by some number. [^398_8]

And, since <span data-ref="0403.g1:E">$E$</span> is by hypothesis prime,  
and the prime is not measured by any number other than itself,  
therefore <span data-ref="0403.g1:E">$E$</span> measures <span data-ref="0403.g1:A">$A$</span>, <span data-ref="0403.g1:E">$E$</span>,  
so that <span data-ref="0403.g1:E">$E$</span> measures <span data-ref="0403.g1:A">$A$</span>.

[But it also measures <span data-ref="0403.g1:D">$D$</span>;  
therefore <span data-ref="0403.g1:E">$E$</span> measures <span data-ref="0403.g1:A">$A$</span>, <span data-ref="0403.g1:D">$D$</span>.]

Similarly we can prove that, by however many prime numbers <span data-ref="0403.g1:D">$D$</span> is measured, <span data-ref="0403.g1:A">$A$</span> will also be measured by the same.

Q. E. D.

---

If $1, a, a_2, \dots a_n$ be a geometrical progression, and $a_n$ be measured by any prime number $p$, $a$ will also be measured by $p$.
