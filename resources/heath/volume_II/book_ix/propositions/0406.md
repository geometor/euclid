<p class="assertion">Therefore <span data-ref="0405.g1:E">$E$</span> is not prime.</p>

<p class="assertion">Therefore it is composite.</p>

<p class="sub-clause">But any composite number is measured by some prime<br />
number ; <span class="justification">[VII. 31]</span></p>
<p class="assertion">therefore <span data-ref="0405.g1:E">$E$</span> is measured by some prime number.</p>

I say next that it will not be measured by any other prime<br />
except <span data-ref="0405.g1:A">$A$</span>.

<p class="sub-clause">For, if <span data-ref="0405.g1:E">$E$</span> is measured by another,<br />
and <span data-ref="0405.g1:E">$E$</span> measures <span data-ref="0405.g1:D">$D$</span>,</p>
<p class="assertion">that other will also measure <span data-ref="0405.g1:D">$D$</span> ;<br />
so that it will also measure <span data-ref="0405.g1:A">$A$</span> <span class="justification">[IX. 12]</span>, which is prime, though<br />
it is not the same with it :<br />
which is impossible.</p>

<p class="assertion">Therefore <span data-ref="0405.g1:A">$A$</span> measures <span data-ref="0405.g1:E">$E$</span>.</p>

And, since <span data-ref="0405.g1:E">$E$</span> measures <span data-ref="0405.g1:D">$D$</span>, let it measure it according to <span data-ref="0405.g1:F">$F$</span>.

I say that <span data-ref="0405.g1:F">$F$</span> is not the same with any of the numbers<br />
<span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span>.

<p class="sub-clause">For, if <span data-ref="0405.g1:F">$F$</span> is the same with one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span>,<br />
and measures <span data-ref="0405.g1:D">$D$</span> according to <span data-ref="0405.g1:E">$E$</span>,</p>
<p class="assertion">therefore one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span> also measures <span data-ref="0405.g1:D">$D$</span> according<br />
to <span data-ref="0405.g1:E">$E$</span>.</p>

<p class="sub-clause">But one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span> measures <span data-ref="0405.g1:D">$D$</span> according to<br />
some one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span> ; <span class="justification">[IX. 11]</span></p>
<p class="assertion">therefore <span data-ref="0405.g1:E">$E$</span> is also the same with one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span> :<br />
which is contrary to the hypothesis.</p>

<p class="assertion">Therefore <span data-ref="0405.g1:F">$F$</span> is not the same as any one of the numbers<br />
<span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span>.</p>

<p class="assertion">Similarly we can prove that <span data-ref="0405.g1:F">$F$</span> is measured by <span data-ref="0405.g1:A">$A$</span>, by<br />
proving again that <span data-ref="0405.g1:F">$F$</span> is not prime.</p>

<p class="sub-clause">For, if it is, and measures <span data-ref="0405.g1:D">$D$</span>,</p>
<p class="assertion">it will also measure <span data-ref="0405.g1:A">$A$</span> <span class="justification">[IX. 12]</span>, which is prime, though it is not<br />
the same with it :<br />
which is impossible ;<br />
therefore <span data-ref="0405.g1:F">$F$</span> is not prime.</p>

<p class="assertion">Therefore it is composite.</p>

<p class="sub-clause">But any composite number is measured by some prime<br />
number ; <span class="justification">[VII. 31]</span></p>
<p class="assertion">therefore <span data-ref="0405.g1:F">$F$</span> is measured by some prime number.</p>
