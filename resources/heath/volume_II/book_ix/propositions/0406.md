Therefore <span data-ref="0405.g1:E">$E$</span> is not prime.

Therefore it is composite.

But any composite number is measured by some prime number; [^400_1]  
therefore <span data-ref="0405.g1:E">$E$</span> is measured by some prime number.

I say next that it will not be measured by any other prime except <span data-ref="0405.g1:A">$A$</span>.

For, if <span data-ref="0405.g1:E">$E$</span> is measured by another,  
and <span data-ref="0405.g1:E">$E$</span> measures <span data-ref="0405.g1:D">$D$</span>,  
that other will also measure <span data-ref="0405.g1:D">$D$</span>;  
so that it will also measure <span data-ref="0405.g1:A">$A$</span> [IX. 12], which is prime, though it is not the same with it:  
which is impossible.

Therefore <span data-ref="0405.g1:A">$A$</span> measures <span data-ref="0405.g1:E">$E$</span>.

And, since <span data-ref="0405.g1:E">$E$</span> measures <span data-ref="0405.g1:D">$D$</span>, let it measure it according to <span data-ref="0405.g1:F">$F$</span>.

I say that <span data-ref="0405.g1:F">$F$</span> is not the same with any of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span>.

For, if <span data-ref="0405.g1:F">$F$</span> is the same with one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span>, and measures <span data-ref="0405.g1:D">$D$</span> according to <span data-ref="0405.g1:E">$E$</span>,  
therefore one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span> also measures <span data-ref="0405.g1:D">$D$</span> according to <span data-ref="0405.g1:E">$E$</span>.

But one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span> measures <span data-ref="0405.g1:D">$D$</span> according to some one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span>; [^400_2]  
therefore <span data-ref="0405.g1:E">$E$</span> is also the same with one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span>:  
which is contrary to the hypothesis.

Therefore <span data-ref="0405.g1:F">$F$</span> is not the same as any one of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span>.

Similarly we can prove that <span data-ref="0405.g1:F">$F$</span> is measured by <span data-ref="0405.g1:A">$A$</span>, by proving again that <span data-ref="0405.g1:F">$F$</span> is not prime.

For, if it is, and measures <span data-ref="0405.g1:D">$D$</span>,  
it will also measure <span data-ref="0405.g1:A">$A$</span> [IX. 12], which is prime, though it is not the same with it:  
which is impossible;  
therefore <span data-ref="0405.g1:F">$F$</span> is not prime.

Therefore it is composite.

But any composite number is measured by some prime number; [^400_3]  
therefore <span data-ref="0405.g1:F">$F$</span> is measured by some prime number.
