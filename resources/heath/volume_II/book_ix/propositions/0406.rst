:title: Proposition 13 (continued)

.. assertion::

   Therefore :g:`$E$ <0405.g1:E>` is not prime.

.. assertion::

   Therefore it is composite.

.. subclause::

   But any composite number is measured by some prime number ; :just:`[VII. 31] <VII.31>`

.. assertion::

   therefore :g:`$E$ <0405.g1:E>` is measured by some prime number.

I say next that it will not be measured by any other prime except :g:`$A$ <0405.g1:A>`.

.. subclause::

   For, if :g:`$E$ <0405.g1:E>` is measured by another, and :g:`$E$ <0405.g1:E>` measures :g:`$D$ <0405.g1:D>`,

.. assertion::

   that other will also measure :g:`$D$ <0405.g1:D>` ; so that it will also measure :g:`$A$ <0405.g1:A>` :just:`[IX. 12] <IX.12>`, which is prime, though it is not the same with it : which is impossible.

.. assertion::

   Therefore :g:`$A$ <0405.g1:A>` measures :g:`$E$ <0405.g1:E>`.

And, since :g:`$E$ <0405.g1:E>` measures :g:`$D$ <0405.g1:D>`, let it measure it according to :g:`$F$ <0405.g1:F>`.

I say that :g:`$F$ <0405.g1:F>` is not the same with any of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>`.

.. subclause::

   For, if :g:`$F$ <0405.g1:F>` is the same with one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>`, and measures :g:`$D$ <0405.g1:D>` according to :g:`$E$ <0405.g1:E>`,

.. assertion::

   therefore one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>` also measures :g:`$D$ <0405.g1:D>` according to :g:`$E$ <0405.g1:E>`.

.. subclause::

   But one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>` measures :g:`$D$ <0405.g1:D>` according to some one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>` ; :just:`[IX. 11] <IX.11>`

.. assertion::

   therefore :g:`$E$ <0405.g1:E>` is also the same with one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>` : which is contrary to the hypothesis.

.. assertion::

   Therefore :g:`$F$ <0405.g1:F>` is not the same as any one of the numbers :g:`$A$ <0405.g1:A>`, :g:`$B$ <0405.g1:B>`, :g:`$C$ <0405.g1:C>`.

.. assertion::

   Similarly we can prove that :g:`$F$ <0405.g1:F>` is measured by :g:`$A$ <0405.g1:A>`, by proving again that :g:`$F$ <0405.g1:F>` is not prime.

.. subclause::

   For, if it is, and measures :g:`$D$ <0405.g1:D>`,

.. assertion::

   it will also measure :g:`$A$ <0405.g1:A>` :just:`[IX. 12] <IX.12>`, which is prime, though it is not the same with it : which is impossible ; therefore :g:`$F$ <0405.g1:F>` is not prime.

.. assertion::

   Therefore it is composite.

.. subclause::

   But any composite number is measured by some prime number ; :just:`[VII. 31] <VII.31>`

.. assertion::

   therefore :g:`$F$ <0405.g1:F>` is measured by some prime number.
