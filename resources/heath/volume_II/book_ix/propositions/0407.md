I say next that it will not be measured by any other prime except <span data-ref="0405.g1:A">$A$</span>.

For, if any other prime number measures <span data-ref="0405.g1:F">$F$</span>,  
and <span data-ref="0405.g1:F">$F$</span> measures <span data-ref="0405.g1:D">$D$</span>,  
that other will also measure <span data-ref="0405.g1:D">$D$</span>;  
so that it will also measure <span data-ref="0405.g1:A">$A$</span> [IX. 12], which is prime, though it is not the same with it:  
which is impossible.

Therefore <span data-ref="0405.g1:A">$A$</span> measures <span data-ref="0405.g1:F">$F$</span>.

And, since <span data-ref="0405.g1:E">$E$</span> measures <span data-ref="0405.g1:D">$D$</span> according to <span data-ref="0405.g1:F">$F$</span>,  
therefore <span data-ref="0405.g1:E">$E$</span> by multiplying <span data-ref="0405.g1:F">$F$</span> has made <span data-ref="0405.g1:D">$D$</span>.

But, further, <span data-ref="0405.g1:A">$A$</span> has also by multiplying <span data-ref="0405.g1:C">$C$</span> made <span data-ref="0405.g1:D">$D$</span>; [^401_1]  
therefore the product of <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:C">$C$</span> is equal to the product of <span data-ref="0405.g1:E">$E$</span>, <span data-ref="0405.g1:F">$F$</span>.

Therefore, proportionally, as <span data-ref="0405.g1:A">$A$</span> is to <span data-ref="0405.g1:E">$E$</span>, so is <span data-ref="0405.g1:F">$F$</span> to <span data-ref="0405.g1:C">$C$</span>. [^401_2]

But <span data-ref="0405.g1:A">$A$</span> measures <span data-ref="0405.g1:E">$E$</span>;  
therefore <span data-ref="0405.g1:F">$F$</span> also measures <span data-ref="0405.g1:C">$C$</span>.

Let it measure it according to <span data-ref="0405.g1:G">$G$</span>.

Similarly, then, we can prove that <span data-ref="0405.g1:G">$G$</span> is not the same with any of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, and that it is measured by <span data-ref="0405.g1:A">$A$</span>.

And, since <span data-ref="0405.g1:F">$F$</span> measures <span data-ref="0405.g1:C">$C$</span> according to <span data-ref="0405.g1:G">$G$</span>,  
therefore <span data-ref="0405.g1:F">$F$</span> by multiplying <span data-ref="0405.g1:G">$G$</span> has made <span data-ref="0405.g1:C">$C$</span>.

But, further, <span data-ref="0405.g1:A">$A$</span> has also by multiplying <span data-ref="0405.g1:B">$B$</span> made <span data-ref="0405.g1:C">$C$</span>; [^401_3]  
therefore the product of <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span> is equal to the product of <span data-ref="0405.g1:F">$F$</span>, <span data-ref="0405.g1:G">$G$</span>.

Therefore, proportionally, as <span data-ref="0405.g1:A">$A$</span> is to <span data-ref="0405.g1:F">$F$</span>, so is <span data-ref="0405.g1:G">$G$</span> to <span data-ref="0405.g1:B">$B$</span>. [^401_4]

But <span data-ref="0405.g1:A">$A$</span> measures <span data-ref="0405.g1:F">$F$</span>;  
therefore <span data-ref="0405.g1:G">$G$</span> also measures <span data-ref="0405.g1:B">$B$</span>.

Let it measure it according to <span data-ref="0405.g1:H">$H$</span>.

Similarly then we can prove that <span data-ref="0405.g1:H">$H$</span> is not the same with <span data-ref="0405.g1:A">$A$</span>.

And, since <span data-ref="0405.g1:G">$G$</span> measures <span data-ref="0405.g1:B">$B$</span> according to <span data-ref="0405.g1:H">$H$</span>,  
therefore <span data-ref="0405.g1:G">$G$</span> by multiplying <span data-ref="0405.g1:H">$H$</span> has made <span data-ref="0405.g1:B">$B$</span>.

But further <span data-ref="0405.g1:A">$A$</span> has also by multiplying itself made <span data-ref="0405.g1:B">$B$</span>; [^401_5]  
therefore the product of <span data-ref="0405.g1:H">$H$</span>, <span data-ref="0405.g1:G">$G$</span> is equal to the square on <span data-ref="0405.g1:A">$A$</span>.

Therefore, as <span data-ref="0405.g1:H">$H$</span> is to <span data-ref="0405.g1:A">$A$</span>, so is <span data-ref="0405.g1:A">$A$</span> to <span data-ref="0405.g1:G">$G$</span>. [^401_6]
