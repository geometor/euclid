I say next that it will not be measured by any other prime<br />
except <span data-ref="0405.g1:A">$A$</span>.

<p class="sub-clause">For, if any other prime number measures <span data-ref="0405.g1:F">$F$</span>,<br />
and <span data-ref="0405.g1:F">$F$</span> measures <span data-ref="0405.g1:D">$D$</span>,</p>
<p class="assertion">that other will also measure <span data-ref="0405.g1:D">$D$</span> ;<br />
so that it will also measure <span data-ref="0405.g1:A">$A$</span> <span class="justification">[IX. 12]</span>, which is prime, though it<br />
is not the same with it :<br />
which is impossible.</p>

<p class="assertion">Therefore <span data-ref="0405.g1:A">$A$</span> measures <span data-ref="0405.g1:F">$F$</span>.</p>

<p class="sub-clause">And, since <span data-ref="0405.g1:E">$E$</span> measures <span data-ref="0405.g1:D">$D$</span> according to <span data-ref="0405.g1:F">$F$</span>,</p>
<p class="assertion">therefore <span data-ref="0405.g1:E">$E$</span> by multiplying <span data-ref="0405.g1:F">$F$</span> has made <span data-ref="0405.g1:D">$D$</span>.</p>

<p class="sub-clause">But, further, <span data-ref="0405.g1:A">$A$</span> has also by multiplying <span data-ref="0405.g1:C">$C$</span> made <span data-ref="0405.g1:D">$D$</span> ; <span class="justification">[IX. 11]</span></p>
<p class="assertion">therefore the product of <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:C">$C$</span> is equal to the product of <span data-ref="0405.g1:E">$E$</span>, <span data-ref="0405.g1:F">$F$</span>.</p>

<p class="assertion">Therefore, proportionally, as <span data-ref="0405.g1:A">$A$</span> is to <span data-ref="0405.g1:E">$E$</span>, so is <span data-ref="0405.g1:F">$F$</span> to <span data-ref="0405.g1:C">$C$</span>. <span class="justification">[VII. 19]</span></p>

<p class="sub-clause">But <span data-ref="0405.g1:A">$A$</span> measures <span data-ref="0405.g1:E">$E$</span> ;</p>
<p class="assertion">therefore <span data-ref="0405.g1:F">$F$</span> also measures <span data-ref="0405.g1:C">$C$</span>.</p>

Let it measure it according to <span data-ref="0405.g1:G">$G$</span>.

<p class="assertion">Similarly, then, we can prove that <span data-ref="0405.g1:G">$G$</span> is not the same with<br />
any of the numbers <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, and that it is measured by <span data-ref="0405.g1:A">$A$</span>.</p>

<p class="sub-clause">And, since <span data-ref="0405.g1:F">$F$</span> measures <span data-ref="0405.g1:C">$C$</span> according to <span data-ref="0405.g1:G">$G$</span>,</p>
<p class="assertion">therefore <span data-ref="0405.g1:F">$F$</span> by multiplying <span data-ref="0405.g1:G">$G$</span> has made <span data-ref="0405.g1:C">$C$</span>.</p>

<p class="sub-clause">But, further, <span data-ref="0405.g1:A">$A$</span> has also by multiplying <span data-ref="0405.g1:B">$B$</span> made <span data-ref="0405.g1:C">$C$</span> ; <span class="justification">[IX. 11]</span></p>
<p class="assertion">therefore the product of <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span> is equal to the product of <span data-ref="0405.g1:F">$F$</span>, <span data-ref="0405.g1:G">$G$</span>.</p>

<p class="assertion">Therefore, proportionally, as <span data-ref="0405.g1:A">$A$</span> is to <span data-ref="0405.g1:F">$F$</span>, so is <span data-ref="0405.g1:G">$G$</span> to <span data-ref="0405.g1:B">$B$</span>. <span class="justification">[VII. 19]</span></p>

<p class="sub-clause">But <span data-ref="0405.g1:A">$A$</span> measures <span data-ref="0405.g1:F">$F$</span> ;</p>
<p class="assertion">therefore <span data-ref="0405.g1:G">$G$</span> also measures <span data-ref="0405.g1:B">$B$</span>.</p>

Let it measure it according to <span data-ref="0405.g1:H">$H$</span>.

<p class="assertion">Similarly then we can prove that <span data-ref="0405.g1:H">$H$</span> is not the same<br />
with <span data-ref="0405.g1:A">$A$</span>.</p>

<p class="sub-clause">And, since <span data-ref="0405.g1:G">$G$</span> measures <span data-ref="0405.g1:B">$B$</span> according to <span data-ref="0405.g1:H">$H$</span>,</p>
<p class="assertion">therefore <span data-ref="0405.g1:G">$G$</span> by multiplying <span data-ref="0405.g1:H">$H$</span> has made <span data-ref="0405.g1:B">$B$</span>.</p>

<p class="sub-clause">But further <span data-ref="0405.g1:A">$A$</span> has also by multiplying itself made <span data-ref="0405.g1:B">$B$</span> ; <span class="justification">[IX. 8]</span></p>
<p class="assertion">therefore the product of <span data-ref="0405.g1:H">$H$</span>, <span data-ref="0405.g1:G">$G$</span> is equal to the square on <span data-ref="0405.g1:A">$A$</span>.</p>

<p class="assertion">Therefore, as <span data-ref="0405.g1:H">$H$</span> is to <span data-ref="0405.g1:A">$A$</span>, so is <span data-ref="0405.g1:A">$A$</span> to <span data-ref="0405.g1:G">$G$</span>. <span class="justification">[VII. 19]</span></p>
