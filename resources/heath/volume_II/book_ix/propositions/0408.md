<p class="sub-clause">But <span data-ref="0405.g1:A">$A$</span> measures <span data-ref="0405.g1:G">$G$</span> ;</p>
<p class="assertion">therefore <span data-ref="0405.g1:H">$H$</span> also measures <span data-ref="0405.g1:A">$A$</span>, which is prime, though it is not<br />
the same with it :<br />
which is absurd.</p>

<p class="assertion">Therefore <span data-ref="0405.g1:D">$D$</span> the greatest will not be measured by any<br />
other number except <span data-ref="0405.g1:A">$A$</span>, <span data-ref="0405.g1:B">$B$</span>, <span data-ref="0405.g1:C">$C$</span>.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

If $1, a, a_2, \dots a_n$ be a geometrical progression, and if $a$ is prime, $a_n$ will not<br />
be measured by any numbers except the preceding terms of the series.

If possible, let $a_n$ be measured by $b$, a number different from all the<br />
preceding terms.

Now $b$ cannot be prime, for, if it were, it would measure $a$. <span class="justification">[IX. 12]</span>

Therefore $b$ is composite, and hence will be measured by *some* prime<br />
number <span class="justification">[VII. 31]</span>, say $p$.

Thus $p$ must measure $a_n$ and therefore $a$ <span class="justification">[IX. 12]</span>; so that $p$ cannot be<br />
different from $a$, and $b$ is not measured by any prime number except $a$.

Suppose that
$$a_n = b \cdot c.$$

Now $c$ cannot be identical with any of the terms $a, a_2, \dots a_{n-1}$; for, if it<br />
were, $b$ would be identical with another of them : <span class="justification">[IX. 11]</span><br />
which is contrary to the hypothesis.

We can now prove (just as for $b$) that $c$ cannot be prime and cannot be<br />
measured by any prime number except $a$.

Since
$$b \cdot c = a_n = a \cdot a_{n-1}, \quad \text{[IX. 11]}$$
$$a : b = c : a_{n-1},$$
whence, since $a$ measures $b$,
$$c \text{ measures } a_{n-1}.$$

Let
$$a_{n-1} = c \cdot d.$$

We now prove in the same way that $d$ is not identical with any of the terms<br />
$a, a_2, \dots a_{n-2}$, is not prime, and is not measured by any prime except $a$, and<br />
also that
$$d \text{ measures } a_{n-2}.$$

Proceeding in this way, we get a last factor, say $k$, which measures $a$<br />
though different from it :<br />
which is absurd, since $a$ is prime.

Thus the original supposition that $a_n$ can be measured by a number $b$<br />
different from all the terms $a, a_2, \dots a_{n-1}$ must be incorrect.

Therefore etc.
