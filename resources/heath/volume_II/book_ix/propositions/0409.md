I say that <span data-ref="0409.g1:A">$A$</span> will not be measured by any other prime number except <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.

For, if possible, let it be measured by the prime number <span data-ref="0409.g1:E">$E$</span>, and let <span data-ref="0409.g1:E">$E$</span> not be the same with any one of the numbers <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.

![Proposition 14 diagram](0409.g1.svg)

Now, since <span data-ref="0409.g1:E">$E$</span> measures <span data-ref="0409.g1:A">$A$</span>, let it measure it according to <span data-ref="0409.g1:F">$F$</span>;  
therefore <span data-ref="0409.g1:E">$E$</span> by multiplying <span data-ref="0409.g1:F">$F$</span> has made <span data-ref="0409.g1:A">$A$</span>.

And <span data-ref="0409.g1:A">$A$</span> is measured by the prime numbers <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.

But, if two numbers by multiplying one another make some number, and any prime number measure the product, it will also measure one of the original numbers; [^403_1]  
therefore <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span> will measure one of the numbers <span data-ref="0409.g1:E">$E$</span>, <span data-ref="0409.g1:F">$F$</span>.

Now they will not measure <span data-ref="0409.g1:E">$E$</span>;  
for <span data-ref="0409.g1:E">$E$</span> is prime and not the same with any one of the numbers <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.

Therefore they will measure <span data-ref="0409.g1:F">$F$</span>, which is less than <span data-ref="0409.g1:A">$A$</span>:  
which is impossible, for <span data-ref="0409.g1:A">$A$</span> is by hypothesis the least number measured by <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.

Therefore no prime number will measure <span data-ref="0409.g1:A">$A$</span> except <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.

Q. E. D.

---

In other words, a number can be resolved into prime factors in only one way.

Let $a$ be the least number measured by each of the prime numbers $b, c, d, \dots k$.

If possible, suppose that $a$ has a prime factor $p$ different from $b, c, d, \dots k$.

Let
$$a = p \cdot m.$$

Now $b, c, d, \dots k$, measuring $a$, must measure one of the two factors $p, m$. [^403_2]

They do not, by hypothesis, measure $p$;  
therefore they must measure $m$, a number less than $a$:  
which is contrary to the hypothesis.

Therefore $a$ has no prime factors except $b, c, d, \dots k$.
