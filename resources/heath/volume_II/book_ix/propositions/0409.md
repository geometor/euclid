I say that <span data-ref="0409.g1:A">$A$</span> will not be measured by any other prime number<br />
except <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.

For, if possible, let it be measured by the prime number<br />
<span data-ref="0409.g1:E">$E$</span>, and let <span data-ref="0409.g1:E">$E$</span> not be the same with any one of the numbers<br />
<span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.

![Proposition 14 diagram](0409.g1.svg)

<p class="sub-clause">Now, since <span data-ref="0409.g1:E">$E$</span> measures <span data-ref="0409.g1:A">$A$</span>, let it measure it according<br />
to <span data-ref="0409.g1:F">$F$</span> ;</p>
<p class="assertion">therefore <span data-ref="0409.g1:E">$E$</span> by multiplying <span data-ref="0409.g1:F">$F$</span> has made <span data-ref="0409.g1:A">$A$</span>.</p>

<p class="sub-clause">And <span data-ref="0409.g1:A">$A$</span> is measured by the prime numbers <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.</p>

<p class="sub-clause">But, if two numbers by multiplying one another make some<br />
number, and any prime number measure the product, it will<br />
also measure one of the original numbers ; <span class="justification">[VII. 30]</span></p>
<p class="assertion">therefore <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span> will measure one of the numbers <span data-ref="0409.g1:E">$E$</span>, <span data-ref="0409.g1:F">$F$</span>.</p>

<p class="sub-clause">Now they will not measure <span data-ref="0409.g1:E">$E$</span> ;<br />
for <span data-ref="0409.g1:E">$E$</span> is prime and not the same with any one of the numbers<br />
<span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.</p>

<p class="assertion">Therefore they will measure <span data-ref="0409.g1:F">$F$</span>, which is less than <span data-ref="0409.g1:A">$A$</span> :<br />
which is impossible, for <span data-ref="0409.g1:A">$A$</span> is by hypothesis the least number<br />
measured by <span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.</p>

<p class="assertion">Therefore no prime number will measure <span data-ref="0409.g1:A">$A$</span> except<br />
<span data-ref="0409.g1:B">$B$</span>, <span data-ref="0409.g1:C">$C$</span>, <span data-ref="0409.g1:D">$D$</span>.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

In other words, a number can be resolved into prime factors in only<br />
one way.

Let $a$ be the least number measured by each of the prime numbers<br />
$b, c, d, \dots k$.

If possible, suppose that $a$ has a prime factor $p$ different from $b, c, d, \dots k$.

Let
$$a = p \cdot m.$$

Now $b, c, d, \dots k$, measuring $a$, must measure one of the two factors $p, m$. <span class="justification">[VII. 30]</span>

They do not, by hypothesis, measure $p$ ;<br />
therefore they must measure $m$, a number less than $a$ :<br />
which is contrary to the hypothesis.

Therefore $a$ has no prime factors except $b, c, d, \dots k$.
