### PROPOSITION 16.

_If two numbers be prime to one another, the second will not be to any other number as the first is to the second._

For let the two numbers <span data-ref="0412.g1:A">$A$</span>, <span data-ref="0412.g1:B">$B$</span> be prime to one another; I say that <span data-ref="0412.g1:B">$B$</span> is not to any other number as <span data-ref="0412.g1:A">$A$</span> is to <span data-ref="0412.g1:B">$B$</span>.

![Proposition 16](0412.g1.svg)

For, if possible, as <span data-ref="0412.g1:A">$A$</span> is to <span data-ref="0412.g1:B">$B$</span>, so let <span data-ref="0412.g1:B">$B$</span> be to <span data-ref="0412.g1:C">$C$</span>.

Now <span data-ref="0412.g1:A">$A$</span>, <span data-ref="0412.g1:B">$B$</span> are prime, primes are also least, [VII. 21] and the least numbers measure those which have the same ratio the same number of times, the antecedent the antecedent and the consequent the consequent; [VII. 20] therefore <span data-ref="0412.g1:A">$A$</span> measures <span data-ref="0412.g1:B">$B$</span> as antecedent antecedent.

But it also measures itself; therefore <span data-ref="0412.g1:A">$A$</span> measures <span data-ref="0412.g1:A">$A$</span>, <span data-ref="0412.g1:B">$B$</span> which are prime to one another: which is absurd.

Therefore <span data-ref="0412.g1:B">$B$</span> will not be to <span data-ref="0412.g1:C">$C$</span>, as <span data-ref="0412.g1:A">$A$</span> is to <span data-ref="0412.g1:B">$B$</span>.

<p align="right">Q. E. D.</p>

---

If _a_, _b_ are prime to one another, they can have no integral third proportional.

If possible, let
$$a : b = b : x.$$

Therefore [VII. 20, 21] _a_ measures _b_; and _a_, _b_ have the common measure _a_, which is contrary to the hypothesis.

### PROPOSITION 17.

_If there be as many numbers as we please in continued proportion, and the extremes of them be prime to one another, the last will not be to any other number as the first to the second._

For let there be as many numbers as we please, <span data-ref="0412.g2:A">$A$</span>, <span data-ref="0412.g2:B">$B$</span>, <span data-ref="0412.g2:C">$C$</span>, <span data-ref="0412.g2:D">$D$</span>, in continued proportion, and let the extremes of them, <span data-ref="0412.g2:A">$A$</span>, <span data-ref="0412.g2:D">$D$</span>, be prime to one another; I say that <span data-ref="0412.g2:D">$D$</span> is not to any other number as <span data-ref="0412.g2:A">$A$</span> is to <span data-ref="0412.g2:B">$B$</span>.

![Proposition 17](0412.g2.svg)

For, if possible, as <span data-ref="0412.g2:A">$A$</span> is to <span data-ref="0412.g2:B">$B$</span>, so let <span data-ref="0412.g2:D">$D$</span> be to <span data-ref="0412.g2:E">$E$</span>; therefore, alternately, as <span data-ref="0412.g2:A">$A$</span> is to <span data-ref="0412.g2:D">$D$</span>, so is <span data-ref="0412.g2:B">$B$</span> to <span data-ref="0412.g2:E">$E$</span>.
