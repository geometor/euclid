### PROPOSITION 16.

<p class="enunciation">If two numbers be prime to one another, the second will not<br />
be to any other number as the first is to the second.</p>

For let the two numbers <span data-ref="0412.g1:A">$A$</span>, <span data-ref="0412.g1:B">$B$</span> be prime to one another ;<br />
I say that <span data-ref="0412.g1:B">$B$</span> is not to any other number as<br />
<span data-ref="0412.g1:A">$A$</span> is to <span data-ref="0412.g1:B">$B$</span>.

![Proposition 16](0412.g1.svg)

For, if possible, as <span data-ref="0412.g1:A">$A$</span> is to <span data-ref="0412.g1:B">$B$</span>, so let <span data-ref="0412.g1:B">$B$</span> be<br />
to <span data-ref="0412.g1:C">$C$</span>.

<p class="sub-clause">Now <span data-ref="0412.g1:A">$A$</span>, <span data-ref="0412.g1:B">$B$</span> are prime,<br />
primes are also least, <span class="justification">[VII. 21]</span><br />
and the least numbers measure those which have the same<br />
ratio the same number of times, the antecedent the antecedent<br />
and the consequent the consequent ; <span class="justification">[VII. 20]</span></p>
<p class="assertion">therefore <span data-ref="0412.g1:A">$A$</span> measures <span data-ref="0412.g1:B">$B$</span> as antecedent antecedent.</p>

<p class="sub-clause">But it also measures itself ;</p>
<p class="assertion">therefore <span data-ref="0412.g1:A">$A$</span> measures <span data-ref="0412.g1:A">$A$</span>, <span data-ref="0412.g1:B">$B$</span> which are prime to one another :<br />
which is absurd.</p>

<p class="assertion">Therefore <span data-ref="0412.g1:B">$B$</span> will not be to <span data-ref="0412.g1:C">$C$</span>, as <span data-ref="0412.g1:A">$A$</span> is to <span data-ref="0412.g1:B">$B$</span>.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

If *a*, *b* are prime to one another, they can have no integral third<br />
proportional.

If possible, let
$$a : b = b : x.$$

Therefore <span class="justification">[VII. 20, 21]</span> *a* measures *b* ; and *a*, *b* have the common measure<br />
*a*, which is contrary to the hypothesis.

### PROPOSITION 17.

<p class="enunciation">If there be as many numbers as we please in continued<br />
proportion, and the extremes of them be prime to one another,<br />
the last will not be to any other number as the first to the<br />
second.</p>

For let there be as many numbers as we please, <span data-ref="0412.g2:A">$A$</span>, <span data-ref="0412.g2:B">$B$</span>, <span data-ref="0412.g2:C">$C$</span>, <span data-ref="0412.g2:D">$D$</span>,<br />
in continued proportion,<br />
and let the extremes of them, <span data-ref="0412.g2:A">$A$</span>,<br />
<span data-ref="0412.g2:D">$D$</span>, be prime to one another ;<br />
I say that <span data-ref="0412.g2:D">$D$</span> is not to any other<br />
number as <span data-ref="0412.g2:A">$A$</span> is to <span data-ref="0412.g2:B">$B$</span>.

![Proposition 17](0412.g2.svg)

For, if possible, as <span data-ref="0412.g2:A">$A$</span> is to <span data-ref="0412.g2:B">$B$</span>, so let <span data-ref="0412.g2:D">$D$</span> be to <span data-ref="0412.g2:E">$E$</span> ;
<p class="assertion">therefore, alternately, as <span data-ref="0412.g2:A">$A$</span> is to <span data-ref="0412.g2:D">$D$</span>, so is <span data-ref="0412.g2:B">$B$</span> to <span data-ref="0412.g2:E">$E$</span>. <span class="justification">[VII. 13]</span></p>
