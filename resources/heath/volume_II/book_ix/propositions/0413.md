But <span data-ref="0412.g2:A">$A$</span>, <span data-ref="0412.g2:D">$D$</span> are prime, primes are also least, [VII. 21] and the least numbers measure those which have the same ratio the same number of times, the antecedent the antecedent and the consequent the consequent. [VII. 20]

Therefore <span data-ref="0412.g2:A">$A$</span> measures <span data-ref="0412.g2:B">$B$</span>.

And, as <span data-ref="0412.g2:A">$A$</span> is to <span data-ref="0412.g2:B">$B$</span>, so is <span data-ref="0412.g2:B">$B$</span> to <span data-ref="0412.g2:C">$C$</span>.

Therefore <span data-ref="0412.g2:B">$B$</span> also measures <span data-ref="0412.g2:C">$C$</span>; so that <span data-ref="0412.g2:A">$A$</span> also measures <span data-ref="0412.g2:C">$C$</span>.

And since, as <span data-ref="0412.g2:B">$B$</span> is to <span data-ref="0412.g2:C">$C$</span>, so is <span data-ref="0412.g2:C">$C$</span> to <span data-ref="0412.g2:D">$D$</span>, and <span data-ref="0412.g2:B">$B$</span> measures <span data-ref="0412.g2:C">$C$</span>, therefore <span data-ref="0412.g2:C">$C$</span> also measures <span data-ref="0412.g2:D">$D$</span>.

But <span data-ref="0412.g2:A">$A$</span> measured <span data-ref="0412.g2:C">$C$</span>; so that <span data-ref="0412.g2:A">$A$</span> also measures <span data-ref="0412.g2:D">$D$</span>.

But it also measures itself; therefore <span data-ref="0412.g2:A">$A$</span> measures <span data-ref="0412.g2:A">$A$</span>, <span data-ref="0412.g2:D">$D$</span> which are prime to one another: which is impossible.

Therefore <span data-ref="0412.g2:D">$D$</span> will not be to any other number as <span data-ref="0412.g2:A">$A$</span> is to <span data-ref="0412.g2:B">$B$</span>.

<p align="right">Q. E. D.</p>

If $a, a_2, a_3, \dots a_n$ be a geometrical progression, and $a, a_n$ are prime to one another, then $a, a_2, a_n$ can have no integral fourth proportional.

For, if possible, let
$$a : a_2 = a_n : x.$$

Therefore
$$a : a_n = a_2 : x,$$
and hence [VII. 20, 21] _a_ measures $a_2$.

Therefore $a_2$ measures $a_3$, [VII. Def. 20] and hence _a_ measures $a_3$, and therefore also ultimately $a_n$.

Thus $a, a_n$ are both measured by _a_: which is contrary to the hypothesis.

### PROPOSITION 18.

_Given two numbers, to investigate whether it is possible to find a third proportional to them._

Let <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:B">$B$</span> be the given two numbers, and let it be required to investigate whether it is possible to find a third proportional to them.

Now <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:B">$B$</span> are either prime to one another or not.

And, if they are prime to one another, it has been proved that it is impossible to find a third proportional to them. [IX. 16]
