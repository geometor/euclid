Next, let <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:B">$B$</span> not be prime to one another, and let <span data-ref="0414.g1:B">$B$</span> by multiplying itself make <span data-ref="0414.g1:C">$C$</span>.

Then <span data-ref="0414.g1:A">$A$</span> either measures <span data-ref="0414.g1:C">$C$</span> or does not measure it.

![Proposition 18](0414.g1.svg)

First, let it measure it according to <span data-ref="0414.g1:D">$D$</span>; therefore <span data-ref="0414.g1:A">$A$</span> by multiplying <span data-ref="0414.g1:D">$D$</span> has made <span data-ref="0414.g1:C">$C$</span>.

But, further, <span data-ref="0414.g1:B">$B$</span> has also by multiplying itself made <span data-ref="0414.g1:C">$C$</span>; therefore the product of <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:D">$D$</span> is equal to the square on <span data-ref="0414.g1:B">$B$</span>.

Therefore, as <span data-ref="0414.g1:A">$A$</span> is to <span data-ref="0414.g1:B">$B$</span>, so is <span data-ref="0414.g1:B">$B$</span> to <span data-ref="0414.g1:D">$D$</span>; [VII. 19] therefore a third proportional number <span data-ref="0414.g1:D">$D$</span> has been found to <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:B">$B$</span>.

Next, let <span data-ref="0414.g1:A">$A$</span> not measure <span data-ref="0414.g1:C">$C$</span>; I say that it is impossible to find a third proportional number to <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:B">$B$</span>.

For, if possible, let <span data-ref="0414.g1:D">$D$</span>, such third proportional, have been found.

Therefore the product of <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:D">$D$</span> is equal to the square on <span data-ref="0414.g1:B">$B$</span>.

But the square on <span data-ref="0414.g1:B">$B$</span> is <span data-ref="0414.g1:C">$C$</span>; therefore the product of <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:D">$D$</span> is equal to <span data-ref="0414.g1:C">$C$</span>.

Hence <span data-ref="0414.g1:A">$A$</span> by multiplying <span data-ref="0414.g1:D">$D$</span> has made <span data-ref="0414.g1:C">$C$</span>; therefore <span data-ref="0414.g1:A">$A$</span> measures <span data-ref="0414.g1:C">$C$</span> according to <span data-ref="0414.g1:D">$D$</span>.

But, by hypothesis, it also does not measure it: which is absurd.

Therefore it is not possible to find a third proportional number to <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:B">$B$</span> when <span data-ref="0414.g1:A">$A$</span> does not measure <span data-ref="0414.g1:C">$C$</span>.

<p align="right">Q. E. D.</p>

Given two numbers _a_, _b_, to find the condition that they may have an integral third proportional.

(1) _a_, _b_ must not be prime to one another. [IX. 16]

(2) _a_ must measure _b_².

For, if _a_, _b_, _c_ be in continued proportion,
$$ac = b^2.$$

Therefore _a_ measures _b_².

Condition (1) is included in condition (2) since, if $b^2 = ma$, _a_ and _b_ cannot be prime to one another.

The result is of course easily seen if the three terms in continued proportion be written
$$a,\quad a\frac{b}{a},\quad a\left(\frac{b}{a}\right)^2.$$
