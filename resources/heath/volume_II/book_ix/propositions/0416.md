<p class="sub-clause">But it also measures itself ;</p>
<p class="assertion">therefore <span data-ref="0415.g1:A">$A$</span> measures <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:C">$C$</span> which are prime to one another :<br />
which is impossible.</p>

<p class="assertion">Therefore it is not possible to find a fourth proportional<br />
to <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span>.†</p>

Next, let <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span> be again in continued proportion,<br />
but let <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:C">$C$</span> not be prime to one another.

I say that it is possible to find a fourth proportional to<br />
them.

For let <span data-ref="0415.g1:B">$B$</span> by multiplying <span data-ref="0415.g1:C">$C$</span> make <span data-ref="0415.g1:D">$D$</span> ;
<p class="assertion">therefore <span data-ref="0415.g1:A">$A$</span> either measures <span data-ref="0415.g1:D">$D$</span> or does not measure it.</p>

First, let it measure it according to <span data-ref="0415.g1:E">$E$</span> ;
<p class="assertion">therefore <span data-ref="0415.g1:A">$A$</span> by multiplying <span data-ref="0415.g1:E">$E$</span> has made <span data-ref="0415.g1:D">$D$</span>.</p>

<p class="sub-clause">But, further, <span data-ref="0415.g1:B">$B$</span> has also by multiplying <span data-ref="0415.g1:C">$C$</span> made <span data-ref="0415.g1:D">$D$</span> ;</p>
<p class="assertion">therefore the product of <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:E">$E$</span> is equal to the product of<br />
<span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span> ;<br />
therefore, proportionally, as <span data-ref="0415.g1:A">$A$</span> is to <span data-ref="0415.g1:B">$B$</span>, so is <span data-ref="0415.g1:C">$C$</span> to <span data-ref="0415.g1:E">$E$</span> ; <span class="justification">[VII. 19]</span><br />
therefore <span data-ref="0415.g1:E">$E$</span> has been found a fourth proportional to <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span>.</p>

Next, let <span data-ref="0415.g1:A">$A$</span> not measure <span data-ref="0415.g1:D">$D$</span> ;

I say that it is impossible to find a fourth proportional number<br />
to <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span>.

For, if possible, let <span data-ref="0415.g1:E">$E$</span> have been found ;
<p class="assertion">therefore the product of <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:E">$E$</span> is equal to the product of <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span>.<br />
<span class="justification">[VII. 19]</span></p>

<p class="sub-clause">But the product of <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span> is <span data-ref="0415.g1:D">$D$</span> ;</p>
<p class="assertion">therefore the product of <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:E">$E$</span> is also equal to <span data-ref="0415.g1:D">$D$</span>.</p>

<p class="assertion">Therefore <span data-ref="0415.g1:A">$A$</span> by multiplying <span data-ref="0415.g1:E">$E$</span> has made <span data-ref="0415.g1:D">$D$</span> ;<br />
therefore <span data-ref="0415.g1:A">$A$</span> measures <span data-ref="0415.g1:D">$D$</span> according to <span data-ref="0415.g1:E">$E$</span>,<br />
so that <span data-ref="0415.g1:A">$A$</span> measures <span data-ref="0415.g1:D">$D$</span>.</p>

<p class="sub-clause">But it also does not measure it :</p>
<p class="assertion">which is absurd.</p>

<p class="assertion">Therefore it is not possible to find a fourth proportional<br />
number to <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span> when <span data-ref="0415.g1:A">$A$</span> does not measure <span data-ref="0415.g1:D">$D$</span>.</p>

Next, let <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span> not be in continued proportion, nor the<br />
extremes prime to one another.

And let <span data-ref="0415.g1:B">$B$</span> by multiplying <span data-ref="0415.g1:C">$C$</span> make <span data-ref="0415.g1:D">$D$</span>.

<p class="assertion">Similarly then it can be proved that, if <span data-ref="0415.g1:A">$A$</span> measures <span data-ref="0415.g1:D">$D$</span>,<br />
it is possible to find a fourth proportional to them, but, if it<br />
does not measure it, impossible.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>
