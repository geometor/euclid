But it also measures itself; therefore <span data-ref="0415.g1:A">$A$</span> measures <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:C">$C$</span> which are prime to one another: which is impossible.

Therefore it is not possible to find a fourth proportional to <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span>.†

Next, let <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span> be again in continued proportion, but let <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:C">$C$</span> not be prime to one another.

I say that it is possible to find a fourth proportional to them.

For let <span data-ref="0415.g1:B">$B$</span> by multiplying <span data-ref="0415.g1:C">$C$</span> make <span data-ref="0415.g1:D">$D$</span>; therefore <span data-ref="0415.g1:A">$A$</span> either measures <span data-ref="0415.g1:D">$D$</span> or does not measure it.

First, let it measure it according to <span data-ref="0415.g1:E">$E$</span>; therefore <span data-ref="0415.g1:A">$A$</span> by multiplying <span data-ref="0415.g1:E">$E$</span> has made <span data-ref="0415.g1:D">$D$</span>.

But, further, <span data-ref="0415.g1:B">$B$</span> has also by multiplying <span data-ref="0415.g1:C">$C$</span> made <span data-ref="0415.g1:D">$D$</span>; therefore the product of <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:E">$E$</span> is equal to the product of <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span>; therefore, proportionally, as <span data-ref="0415.g1:A">$A$</span> is to <span data-ref="0415.g1:B">$B$</span>, so is <span data-ref="0415.g1:C">$C$</span> to <span data-ref="0415.g1:E">$E$</span>; [VII. 19] therefore <span data-ref="0415.g1:E">$E$</span> has been found a fourth proportional to <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span>.

Next, let <span data-ref="0415.g1:A">$A$</span> not measure <span data-ref="0415.g1:D">$D$</span>; I say that it is impossible to find a fourth proportional number to <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span>.

For, if possible, let <span data-ref="0415.g1:E">$E$</span> have been found; therefore the product of <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:E">$E$</span> is equal to the product of <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span>. [VII. 19]

But the product of <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span> is <span data-ref="0415.g1:D">$D$</span>; therefore the product of <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:E">$E$</span> is also equal to <span data-ref="0415.g1:D">$D$</span>.

Therefore <span data-ref="0415.g1:A">$A$</span> by multiplying <span data-ref="0415.g1:E">$E$</span> has made <span data-ref="0415.g1:D">$D$</span>; therefore <span data-ref="0415.g1:A">$A$</span> measures <span data-ref="0415.g1:D">$D$</span> according to <span data-ref="0415.g1:E">$E$</span>, so that <span data-ref="0415.g1:A">$A$</span> measures <span data-ref="0415.g1:D">$D$</span>.

But it also does not measure it: which is absurd.

Therefore it is not possible to find a fourth proportional number to <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span> when <span data-ref="0415.g1:A">$A$</span> does not measure <span data-ref="0415.g1:D">$D$</span>.

Next, let <span data-ref="0415.g1:A">$A$</span>, <span data-ref="0415.g1:B">$B$</span>, <span data-ref="0415.g1:C">$C$</span> not be in continued proportion, nor the extremes prime to one another.

And let <span data-ref="0415.g1:B">$B$</span> by multiplying <span data-ref="0415.g1:C">$C$</span> make <span data-ref="0415.g1:D">$D$</span>.

Similarly then it can be proved that, if <span data-ref="0415.g1:A">$A$</span> measures <span data-ref="0415.g1:D">$D$</span>, it is possible to find a fourth proportional to them, but, if it does not measure it, impossible.

<p align="right">Q. E. D.</p>
