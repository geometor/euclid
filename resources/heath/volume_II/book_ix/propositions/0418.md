### PROPOSITION 20.

*Prime numbers are more than any assigned multitude of prime numbers.*

Let <span data-ref="0418.g1:A">$A$</span>, <span data-ref="0418.g1:B">$B$</span>, <span data-ref="0418.g1:C">$C$</span> be the assigned prime numbers;  
I say that there are more prime numbers than <span data-ref="0418.g1:A">$A$</span>, <span data-ref="0418.g1:B">$B$</span>, <span data-ref="0418.g1:C">$C$</span>.

For let the least number measured by <span data-ref="0418.g1:A">$A$</span>, <span data-ref="0418.g1:B">$B$</span>, <span data-ref="0418.g1:C">$C$</span> be taken, and let it be <span data-ref="0418.g1:/ D E /">$DE$</span>;  
let the unit <span data-ref="0418.g1:/ D F /">$DF$</span> be added to <span data-ref="0418.g1:/ D E /">$DE$</span>.

![Book IX, Proposition 20](0418.g1.svg)

Then <span data-ref="0418.g1:/ E F /">$EF$</span> is either prime or not.

First, let it be prime;  
then the prime numbers <span data-ref="0418.g1:A">$A$</span>, <span data-ref="0418.g1:B">$B$</span>, <span data-ref="0418.g1:C">$C$</span>, <span data-ref="0418.g1:/ E F /">$EF$</span> have been found which are more than <span data-ref="0418.g1:A">$A$</span>, <span data-ref="0418.g1:B">$B$</span>, <span data-ref="0418.g1:C">$C$</span>.

Next, let <span data-ref="0418.g1:/ E F /">$EF$</span> not be prime;  
therefore it is measured by some prime number. [VII. 31]  
Let it be measured by the prime number <span data-ref="0418.g1:G">$G$</span>.  
I say that <span data-ref="0418.g1:G">$G$</span> is not the same with any of the numbers <span data-ref="0418.g1:A">$A$</span>, <span data-ref="0418.g1:B">$B$</span>, <span data-ref="0418.g1:C">$C$</span>.

For, if possible, let it be so.  
Now <span data-ref="0418.g1:A">$A$</span>, <span data-ref="0418.g1:B">$B$</span>, <span data-ref="0418.g1:C">$C$</span> measure <span data-ref="0418.g1:/ D E /">$DE$</span>;  
therefore <span data-ref="0418.g1:G">$G$</span> also will measure <span data-ref="0418.g1:/ D E /">$DE$</span>.

But it also measures <span data-ref="0418.g1:/ E F /">$EF$</span>.  
Therefore <span data-ref="0418.g1:G">$G$</span>, being a number, will measure the remainder, the unit <span data-ref="0418.g1:/ D F /">$DF$</span>:  
which is absurd.

Therefore <span data-ref="0418.g1:G">$G$</span> is not the same with any one of the numbers <span data-ref="0418.g1:A">$A$</span>, <span data-ref="0418.g1:B">$B$</span>, <span data-ref="0418.g1:C">$C$</span>.  
And by hypothesis it is prime.  
Therefore the prime numbers <span data-ref="0418.g1:A">$A$</span>, <span data-ref="0418.g1:B">$B$</span>, <span data-ref="0418.g1:C">$C$</span>, <span data-ref="0418.g1:G">$G$</span> have been found which are more than the assigned multitude of <span data-ref="0418.g1:A">$A$</span>, <span data-ref="0418.g1:B">$B$</span>, <span data-ref="0418.g1:C">$C$</span>.

<p align="right">Q. E. D.</p>
