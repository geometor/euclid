We have here the important proposition that *the number of prime numbers<br />
is infinite*.

The proof will be seen to be the same as that given in our algebraical<br />
text-books. Let *a, b, c, ... k* be any prime numbers.<br />
Take the product *abc ... k* and add unity.<br />
Then (*abc ... k* + 1) is either a prime number or not a prime number.<br />
(1) If it *is*, we have added another prime number to those given.<br />
(2) If it is *not*, it must be measured by some prime number <span class="justification">[VII. 31]</span>, say *p*.<br />
Now *p* cannot be identical with any of the prime numbers *a, b, c, ... k*.<br />
For, if it is, it will divide *abc ... k*.<br />
Therefore, since it divides (*abc ... k* + 1) also, it will measure the difference,<br />
or unity :<br />
which is impossible.<br />
Therefore in any case we have obtained one fresh prime number.<br />
And the process can be carried on to any extent.

### PROPOSITION 21.

<p class="enunciation">If as many even numbers as we please be added together,<br />
the whole is even.</p>

For let as many even numbers as we please, <span data-ref="0419.g1:/ A B /">$AB$</span>, <span data-ref="0419.g1:/ B C /">$BC$</span>, <span data-ref="0419.g1:/ C D /">$CD$</span>,<br />
<span data-ref="0419.g1:/ D E /">$DE$</span>, be added together ;<br />
I say that the whole <span data-ref="0419.g1:/ A E /">$AE$</span><br />
is even.

![Book IX, Proposition 21](0419.g1.svg)

<p class="sub-clause">For, since each of the numbers <span data-ref="0419.g1:/ A B /">$AB$</span>, <span data-ref="0419.g1:/ B C /">$BC$</span>, <span data-ref="0419.g1:/ C D /">$CD$</span>, <span data-ref="0419.g1:/ D E /">$DE$</span> is even,<br />
it has a half part ; <span class="justification">[VII. Def. 6]</span></p>
<p class="assertion">so that the whole <span data-ref="0419.g1:/ A E /">$AE$</span> also has a half part.</p>

<p class="sub-clause">But an even number is that which is divisible into two<br />
equal parts ; <span class="justification">[id.]</span></p>
<p class="assertion">therefore <span data-ref="0419.g1:/ A E /">$AE$</span> is even.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

### PROPOSITION 22.

<p class="enunciation">If as many odd numbers as we please be added together, and<br />
their multitude be even, the whole will be even.</p>

For let as many odd numbers as we please, <span data-ref="0420.g1:/ A B /">$AB$</span>, <span data-ref="0420.g1:/ B C /">$BC$</span>, <span data-ref="0420.g1:/ C D /">$CD$</span>,<br />
