### PROPOSITION 25.

*If from an even number an odd number be subtracted, the remainder will be odd.*

For from the even number <span data-ref="0421.g1:/ A B /">$AB$</span> let the odd number <span data-ref="0421.g1:/ B C /">$BC$</span> be subtracted;  
I say that the remainder <span data-ref="0421.g1:/ A C /">$CA$</span> is odd.

![Book IX, Proposition 25](0421.g1.svg)

For let the unit <span data-ref="0421.g1:/ C D /">$CD$</span> be subtracted from <span data-ref="0421.g1:/ B C /">$BC$</span>;  
therefore <span data-ref="0421.g1:/ B D /">$DB$</span> is even. [VII. Def. 7]  
But <span data-ref="0421.g1:/ A B /">$AB$</span> is also even;  
therefore the remainder <span data-ref="0421.g1:/ A D /">$AD$</span> is also even. [IX. 24]  
And <span data-ref="0421.g1:/ C D /">$CD$</span> is an unit;  
therefore <span data-ref="0421.g1:/ A C /">$CA$</span> is odd. [VII. Def. 7]

<p align="right">Q. E. D.</p>

### PROPOSITION 26.

*If from an odd number an odd number be subtracted, the remainder will be even.*

For from the odd number <span data-ref="0421.g2:/ A B /">$AB$</span> let the odd number <span data-ref="0421.g2:/ B C /">$BC$</span> be subtracted;  
I say that the remainder <span data-ref="0421.g2:/ A C /">$CA$</span> is even.

![Book IX, Proposition 26](0421.g2.svg)

For, since <span data-ref="0421.g2:/ A B /">$AB$</span> is odd, let the unit <span data-ref="0421.g2:/ B D /">$BD$</span> be subtracted;  
therefore the remainder <span data-ref="0421.g2:/ A D /">$AD$</span> is even. [VII. Def. 7]  
For the same reason <span data-ref="0421.g2:/ C D /">$CD$</span> is also even; [VII. Def. 7]  
so that the remainder <span data-ref="0421.g2:/ A C /">$CA$</span> is also even. [IX. 24]

<p align="right">Q. E. D.</p>
