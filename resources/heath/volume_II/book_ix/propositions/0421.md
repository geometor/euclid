### PROPOSITION 25.

<p class="enunciation">If from an even number an odd number be subtracted, the<br />
remainder will be odd.</p>

For from the even number <span data-ref="0421.g1:/ A B /">$AB$</span> let the odd number <span data-ref="0421.g1:/ B C /">$BC$</span> be<br />
subtracted ;<br />
I say that the remainder <span data-ref="0421.g1:/ A C /">$CA$</span> is odd.

![Book IX, Proposition 25](0421.g1.svg)

For let the unit <span data-ref="0421.g1:/ C D /">$CD$</span> be sub-<br />
tracted from <span data-ref="0421.g1:/ B C /">$BC$</span> ;

<p class="assertion">therefore <span data-ref="0421.g1:/ B D /">$DB$</span> is even. <span class="justification">[VII. Def. 7]</span></p>
<p class="sub-clause">But <span data-ref="0421.g1:/ A B /">$AB$</span> is also even ;</p>
<p class="assertion">therefore the remainder <span data-ref="0421.g1:/ A D /">$AD$</span> is also even. <span class="justification">[IX. 24]</span></p>
<p class="sub-clause">And <span data-ref="0421.g1:/ C D /">$CD$</span> is an unit ;</p>
<p class="assertion">therefore <span data-ref="0421.g1:/ A C /">$CA$</span> is odd. <span class="justification">[VII. Def. 7]</span></p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

### PROPOSITION 26.

<p class="enunciation">If from an odd number an odd number be subtracted, the<br />
remainder will be even.</p>

For from the odd number <span data-ref="0421.g2:/ A B /">$AB$</span> let the odd number <span data-ref="0421.g2:/ B C /">$BC$</span> be<br />
subtracted ;<br />
I say that the remainder <span data-ref="0421.g2:/ A C /">$CA$</span> is even.

![Book IX, Proposition 26](0421.g2.svg)

<p class="sub-clause">For, since <span data-ref="0421.g2:/ A B /">$AB$</span> is odd, let the unit<br />
<span data-ref="0421.g2:/ B D /">$BD$</span> be subtracted ;</p>
<p class="assertion">therefore the remainder <span data-ref="0421.g2:/ A D /">$AD$</span> is even. <span class="justification">[VII. Def. 7]</span></p>

<p class="sub-clause">For the same reason <span data-ref="0421.g2:/ C D /">$CD$</span> is also even ; <span class="justification">[VII. Def. 7]</span></p>
<p class="assertion">so that the remainder <span data-ref="0421.g2:/ A C /">$CA$</span> is also even. <span class="justification">[IX. 24]</span></p>

<p class="qed"><span class="justification">Q. E. D.</span></p>
