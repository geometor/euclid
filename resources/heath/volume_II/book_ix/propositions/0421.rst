PROPOSITION 25.
---------------

.. enunciation::

   If from an even number an odd number be subtracted, the remainder will be odd.

For from the even number :g:`$AB$ <0421.g1:/ A B />` let the odd number :g:`$BC$ <0421.g1:/ B C />` be subtracted ;

I say that the remainder :g:`$CA$ <0421.g1:/ A C />` is odd.

.. picture:: 0421.g1.svg
   :alt: Book IX, Proposition 25

For let the unit :g:`$CD$ <0421.g1:/ C D />` be subtracted from :g:`$BC$ <0421.g1:/ B C />` ;

.. assertion:: [VII. Def. 7] <VII.def.7>

   therefore :g:`$DB$ <0421.g1:/ B D />` is even.

.. subclause::

   But :g:`$AB$ <0421.g1:/ A B />` is also even ;

.. assertion:: [IX. 24] <IX.24>

   therefore the remainder :g:`$AD$ <0421.g1:/ A D />` is also even.

.. subclause::

   And :g:`$CD$ <0421.g1:/ C D />` is an unit ;

.. assertion:: [VII. Def. 7] <VII.def.7>

   therefore :g:`$CA$ <0421.g1:/ A C />` is odd.

.. qed::

   :just:`Q. E. D.`

PROPOSITION 26.
---------------

.. enunciation::

   If from an odd number an odd number be subtracted, the remainder will be even.

For from the odd number :g:`$AB$ <0421.g2:/ A B />` let the odd number :g:`$BC$ <0421.g2:/ B C />` be subtracted ;

I say that the remainder :g:`$CA$ <0421.g2:/ A C />` is even.

.. picture:: 0421.g2.svg
   :alt: Book IX, Proposition 26

.. subclause::

   For, since :g:`$AB$ <0421.g2:/ A B />` is odd, let the unit :g:`$BD$ <0421.g2:/ B D />` be subtracted ;

.. assertion:: [VII. Def. 7] <VII.def.7>

   therefore the remainder :g:`$AD$ <0421.g2:/ A D />` is even.

.. subclause:: [VII. Def. 7] <VII.def.7>

   For the same reason :g:`$CD$ <0421.g2:/ C D />` is also even ;

.. assertion:: [IX. 24] <IX.24>

   so that the remainder :g:`$CA$ <0421.g2:/ A C />` is also even.

.. qed::

   :just:`Q. E. D.`
