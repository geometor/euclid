### PROPOSITION 27.

*If from an odd number an even number be subtracted, the remainder will be odd.*

For from the odd number <span data-ref="0422.g1:/ A B /">$AB$</span> let the even number <span data-ref="0422.g1:/ B C /">$BC$</span> be subtracted;  
I say that the remainder <span data-ref="0422.g1:/ A C /">$CA$</span> is odd.

![Book IX, Proposition 27](0422.g1.svg)

Let the unit <span data-ref="0422.g1:/ A D /">$AD$</span> be subtracted;  
therefore <span data-ref="0422.g1:/ B D /">$DB$</span> is even. [VII. Def. 7]  
But <span data-ref="0422.g1:/ B C /">$BC$</span> is also even;  
therefore the remainder <span data-ref="0422.g1:/ C D /">$CD$</span> is even. [IX. 24]  
Therefore <span data-ref="0422.g1:/ A C /">$CA$</span> is odd. [VII. Def. 7]

<p align="right">Q. E. D.</p>

### PROPOSITION 28.

*If an odd number by multiplying an even number make some number, the product will be even.*

For let the odd number <span data-ref="0422.g2:A">$A$</span> by multiplying the even number <span data-ref="0422.g2:B">$B$</span> make <span data-ref="0422.g2:C">$C$</span>;  
I say that <span data-ref="0422.g2:C">$C$</span> is even.

![Book IX, Proposition 28](0422.g2.svg)

For, since <span data-ref="0422.g2:A">$A$</span> by multiplying <span data-ref="0422.g2:B">$B$</span> has made <span data-ref="0422.g2:C">$C$</span>,  
therefore <span data-ref="0422.g2:C">$C$</span> is made up of as many numbers equal to <span data-ref="0422.g2:B">$B$</span> as there are units in <span data-ref="0422.g2:A">$A$</span>. [VII. Def. 15]  
And <span data-ref="0422.g2:B">$B$</span> is even;  
therefore <span data-ref="0422.g2:C">$C$</span> is made up of even numbers.  
But, if as many even numbers as we please be added together, the whole is even. [IX. 21]  
Therefore <span data-ref="0422.g2:C">$C$</span> is even.

<p align="right">Q. E. D.</p>
