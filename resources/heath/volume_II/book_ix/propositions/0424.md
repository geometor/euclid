Let a number measure them, and let it be <span data-ref="0423.g2:D">$D$</span>.  
Now <span data-ref="0423.g2:A">$A$</span> is odd;  
therefore <span data-ref="0423.g2:D">$D$</span> is also odd.  
And since <span data-ref="0423.g2:D">$D$</span> which is odd measures <span data-ref="0423.g2:C">$C$</span>,  
and <span data-ref="0423.g2:C">$C$</span> is even,  
therefore [<span data-ref="0423.g2:D">$D$</span>] will measure the half of <span data-ref="0423.g2:C">$C$</span> also. [IX. 30]  
But <span data-ref="0423.g2:B">$B$</span> is half of <span data-ref="0423.g2:C">$C$</span>;  
therefore <span data-ref="0423.g2:D">$D$</span> measures <span data-ref="0423.g2:B">$B$</span>.  
But it also measures <span data-ref="0423.g2:A">$A$</span>;  
therefore <span data-ref="0423.g2:D">$D$</span> measures <span data-ref="0423.g2:A">$A$</span>, <span data-ref="0423.g2:B">$B$</span> which are prime to one another:  
which is impossible.  
Therefore <span data-ref="0423.g2:A">$A$</span> cannot but be prime to <span data-ref="0423.g2:C">$C$</span>.  
Therefore <span data-ref="0423.g2:A">$A$</span>, <span data-ref="0423.g2:C">$C$</span> are prime to one another.

<p align="right">Q. E. D.</p>

### PROPOSITION 32.

*Each of the numbers which are continually doubled beginning from a dyad is even-times even only.*

For let as many numbers as we please, <span data-ref="0424.g1:B">$B$</span>, <span data-ref="0424.g1:C">$C$</span>, <span data-ref="0424.g1:D">$D$</span>, have been continually doubled beginning from the dyad <span data-ref="0424.g1:A">$A$</span>;  
I say that <span data-ref="0424.g1:B">$B$</span>, <span data-ref="0424.g1:C">$C$</span>, <span data-ref="0424.g1:D">$D$</span> are even-times even only.

![Book IX, Proposition 32](0424.g1.svg)

Now that each of the numbers <span data-ref="0424.g1:B">$B$</span>, <span data-ref="0424.g1:C">$C$</span>, <span data-ref="0424.g1:D">$D$</span> is even-times even is manifest; for it is doubled from a dyad.  
I say that it is also even-times even only.  
For let an unit be set out.  
Since then as many numbers as we please beginning from an unit are in continued proportion,  
and the number <span data-ref="0424.g1:A">$A$</span> after the unit is prime,  
therefore <span data-ref="0424.g1:D">$D$</span>, the greatest of the numbers <span data-ref="0424.g1:A">$A$</span>, <span data-ref="0424.g1:B">$B$</span>, <span data-ref="0424.g1:C">$C$</span>, <span data-ref="0424.g1:D">$D$</span>, will not be measured by any other number except <span data-ref="0424.g1:A">$A$</span>, <span data-ref="0424.g1:B">$B$</span>, <span data-ref="0424.g1:C">$C$</span>. [IX. 13]  
And each of the numbers <span data-ref="0424.g1:A">$A$</span>, <span data-ref="0424.g1:B">$B$</span>, <span data-ref="0424.g1:C">$C$</span> is even;  
therefore <span data-ref="0424.g1:D">$D$</span> is even-times even only. [VII. Def. 8]  
Similarly we can prove that each of the numbers <span data-ref="0424.g1:B">$B$</span>, <span data-ref="0424.g1:C">$C$</span> is even-times even only.

<p align="right">Q. E. D.</p>
