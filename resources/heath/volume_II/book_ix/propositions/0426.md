### PROPOSITION 35.

*If as many numbers as we please be in continued proportion, and there be subtracted from the second and the last numbers equal to the first, then, as the excess of the second is to the first, so will the excess of the last be to all those before it.*

![Proposition 35 Diagram](0426.g1.svg)

Let there be as many numbers as we please in continued proportion, <span data-ref="0426.g1:A">$A$</span>, <span data-ref="0426.g1:/ B C /">$BC$</span>, <span data-ref="0426.g1:D">$D$</span>, <span data-ref="0426.g1:/ E F /">$EF$</span>, beginning from <span data-ref="0426.g1:A">$A$</span> as least, and let there be subtracted from <span data-ref="0426.g1:/ B C /">$BC$</span> and <span data-ref="0426.g1:/ E F /">$EF$</span> the numbers <span data-ref="0426.g1:/ B G /">$BG$</span>, <span data-ref="0426.g1:/ F H /">$FH$</span>, each equal to <span data-ref="0426.g1:A">$A$</span>;  
I say that, as <span data-ref="0426.g1:/ C G /">$GC$</span> is to <span data-ref="0426.g1:A">$A$</span>, so is <span data-ref="0426.g1:/ E H /">$EH$</span> to <span data-ref="0426.g1:A">$A$</span>, <span data-ref="0426.g1:/ B C /">$BC$</span>, <span data-ref="0426.g1:D">$D$</span>.

For let <span data-ref="0426.g1:/ F K /">$FK$</span> be made equal to <span data-ref="0426.g1:/ B C /">$BC$</span>, and <span data-ref="0426.g1:/ F L /">$FL$</span> equal to <span data-ref="0426.g1:D">$D$</span>.

Then, since <span data-ref="0426.g1:/ F K /">$FK$</span> is equal to <span data-ref="0426.g1:/ B C /">$BC$</span>, and of these the part <span data-ref="0426.g1:/ F H /">$FH$</span> is equal to the part <span data-ref="0426.g1:/ B G /">$BG$</span>, therefore the remainder <span data-ref="0426.g1:/ H K /">$HK$</span> is equal to the remainder <span data-ref="0426.g1:/ C G /">$GC$</span>.

And since, as <span data-ref="0426.g1:/ E F /">$EF$</span> is to <span data-ref="0426.g1:D">$D$</span>, so is <span data-ref="0426.g1:D">$D$</span> to <span data-ref="0426.g1:/ B C /">$BC$</span>, and <span data-ref="0426.g1:/ B C /">$BC$</span> to <span data-ref="0426.g1:A">$A$</span>, while <span data-ref="0426.g1:D">$D$</span> is equal to <span data-ref="0426.g1:/ F L /">$FL$</span>, <span data-ref="0426.g1:/ B C /">$BC$</span> to <span data-ref="0426.g1:/ F K /">$FK$</span>, and <span data-ref="0426.g1:A">$A$</span> to <span data-ref="0426.g1:/ F H /">$FH$</span>, therefore, as <span data-ref="0426.g1:/ E F /">$EF$</span> is to <span data-ref="0426.g1:/ F L /">$FL$</span>, so is <span data-ref="0426.g1:/ F L /">$LF$</span> to <span data-ref="0426.g1:/ F K /">$FK$</span>, and <span data-ref="0426.g1:/ F K /">$FK$</span> to <span data-ref="0426.g1:/ F H /">$FH$</span>.

Separando, as <span data-ref="0426.g1:/ E L /">$EL$</span> is to <span data-ref="0426.g1:/ F L /">$LF$</span>, so is <span data-ref="0426.g1:/ K L /">$LK$</span> to <span data-ref="0426.g1:/ F K /">$FK$</span>, and <span data-ref="0426.g1:/ H K /">$KH$</span> to <span data-ref="0426.g1:/ F H /">$FH$</span>. [VII. 11, 13]

Therefore also, as one of the antecedents is to one of the consequents, so are all the antecedents to all the consequents; [VII. 12] therefore, as <span data-ref="0426.g1:/ H K /">$KH$</span> is to <span data-ref="0426.g1:/ F H /">$FH$</span>, so are <span data-ref="0426.g1:/ E L /">$EL$</span>, <span data-ref="0426.g1:/ K L /">$LK$</span>, <span data-ref="0426.g1:/ H K /">$KH$</span> to <span data-ref="0426.g1:/ F L /">$LF$</span>, <span data-ref="0426.g1:/ F K /">$FK$</span>, <span data-ref="0426.g1:/ F H /">$HF$</span>.

But <span data-ref="0426.g1:/ H K /">$KH$</span> is equal to <span data-ref="0426.g1:/ C G /">$CG$</span>, <span data-ref="0426.g1:/ F H /">$FH$</span> to <span data-ref="0426.g1:A">$A$</span>, and <span data-ref="0426.g1:/ F L /">$LF$</span>, <span data-ref="0426.g1:/ F K /">$FK$</span>, <span data-ref="0426.g1:/ F H /">$HF$</span> to <span data-ref="0426.g1:D">$D$</span>, <span data-ref="0426.g1:/ B C /">$BC$</span>, <span data-ref="0426.g1:A">$A$</span>;  
therefore, as <span data-ref="0426.g1:/ C G /">$CG$</span> is to <span data-ref="0426.g1:A">$A$</span>, so is <span data-ref="0426.g1:/ E H /">$EH$</span> to <span data-ref="0426.g1:D">$D$</span>, <span data-ref="0426.g1:/ B C /">$BC$</span>, <span data-ref="0426.g1:A">$A$</span>.

Therefore, as the excess of the second is to the first, so is the excess of the last to all those before it.

**Q. E. D.**
