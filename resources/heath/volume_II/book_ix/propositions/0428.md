<p class="assertion">Therefore the product of <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:D">$D$</span> is equal to the product of<br />
<span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:M">$M$</span>. <span class="justification">[VII. 19]</span></p>

<p class="sub-clause">And the product of <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:D">$D$</span> is <span data-ref="0428.g1:/ F G /">$FG$</span> ;</p>
<p class="assertion">therefore the product of <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:M">$M$</span> is also <span data-ref="0428.g1:/ F G /">$FG$</span>.</p>

<p class="assertion">Therefore <span data-ref="0428.g1:A">$A$</span> by multiplying <span data-ref="0428.g1:M">$M$</span> has made <span data-ref="0428.g1:/ F G /">$FG$</span> ;<br />
therefore <span data-ref="0428.g1:M">$M$</span> measures <span data-ref="0428.g1:/ F G /">$FG$</span> according to the units in <span data-ref="0428.g1:A">$A$</span>.</p>

<p class="sub-clause">And <span data-ref="0428.g1:A">$A$</span> is a dyad ;</p>
<p class="assertion">therefore <span data-ref="0428.g1:/ F G /">$FG$</span> is double of <span data-ref="0428.g1:M">$M$</span>.</p>

![Proposition 36 Diagram](0428.g1.svg)

<p class="sub-clause">But <span data-ref="0428.g1:M">$M$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:E">$E$</span> are continuously double of each other ;</p>
<p class="assertion">therefore <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:M">$M$</span>, <span data-ref="0428.g1:/ F G /">$FG$</span> are continuously proportional in<br />
double proportion.</p>

Now let there be subtracted from the second <span data-ref="0428.g1:/ H K /">$HK$</span> and the<br />
last <span data-ref="0428.g1:/ F G /">$FG$</span> the numbers <span data-ref="0428.g1:/ H N /">$HN$</span>, <span data-ref="0428.g1:/ F O /">$FO$</span>, each equal to the first <span data-ref="0428.g1:E">$E$</span> ;

<p class="assertion">therefore, as the excess of the second is to the first, so is the<br />
excess of the last to all those before it. <span class="justification">[IX. 35]</span></p>

<p class="assertion">Therefore, as <span data-ref="0428.g1:/ K N /">$NK$</span> is to <span data-ref="0428.g1:E">$E$</span>, so is <span data-ref="0428.g1:/ G O /">$OG$</span> to <span data-ref="0428.g1:M">$M$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:/ H K /">$KH$</span>, <span data-ref="0428.g1:E">$E$</span>.</p>

<p class="sub-clause">And <span data-ref="0428.g1:/ K N /">$NK$</span> is equal to <span data-ref="0428.g1:E">$E$</span> ;</p>
<p class="assertion">therefore <span data-ref="0428.g1:/ G O /">$OG$</span> is also equal to <span data-ref="0428.g1:M">$M$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:E">$E$</span>.</p>

<p class="sub-clause">But <span data-ref="0428.g1:/ F O /">$FO$</span> is also equal to <span data-ref="0428.g1:E">$E$</span>,<br />
and <span data-ref="0428.g1:E">$E$</span> is equal to <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span> and the unit.</p>

<p class="assertion">Therefore the whole <span data-ref="0428.g1:/ F G /">$FG$</span> is equal to <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:M">$M$</span> and<br />
<span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span> and the unit ;<br />
and it is measured by them.</p>

I say also that <span data-ref="0428.g1:/ F G /">$FG$</span> will not be measured by any other<br />
number except <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span>, <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:M">$M$</span> and the unit.

For, if possible, let some number <span data-ref="0428.g1:P">$P$</span> measure <span data-ref="0428.g1:/ F G /">$FG$</span>,<br />
and let <span data-ref="0428.g1:P">$P$</span> not be the same with any of the numbers <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>,<br />
<span data-ref="0428.g1:D">$D$</span>, <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:M">$M$</span>.

<p class="sub-clause">And, as many times as <span data-ref="0428.g1:P">$P$</span> measures <span data-ref="0428.g1:/ F G /">$FG$</span>, so many units let<br />
there be in <span data-ref="0428.g1:Q">$Q$</span> ;</p>
<p class="assertion">therefore <span data-ref="0428.g1:Q">$Q$</span> by multiplying <span data-ref="0428.g1:P">$P$</span> has made <span data-ref="0428.g1:/ F G /">$FG$</span>.</p>
