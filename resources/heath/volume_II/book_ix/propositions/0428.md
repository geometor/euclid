Therefore the product of <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:D">$D$</span> is equal to the product of <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:M">$M$</span>. [VII. 19]

And the product of <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:D">$D$</span> is <span data-ref="0428.g1:/ F G /">$FG$</span>;  
therefore the product of <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:M">$M$</span> is also <span data-ref="0428.g1:/ F G /">$FG$</span>.

Therefore <span data-ref="0428.g1:A">$A$</span> by multiplying <span data-ref="0428.g1:M">$M$</span> has made <span data-ref="0428.g1:/ F G /">$FG$</span>;  
therefore <span data-ref="0428.g1:M">$M$</span> measures <span data-ref="0428.g1:/ F G /">$FG$</span> according to the units in <span data-ref="0428.g1:A">$A$</span>.

And <span data-ref="0428.g1:A">$A$</span> is a dyad;  
therefore <span data-ref="0428.g1:/ F G /">$FG$</span> is double of <span data-ref="0428.g1:M">$M$</span>.

![Proposition 36 Diagram](0428.g1.svg)

But <span data-ref="0428.g1:M">$M$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:E">$E$</span> are continuously double of each other;  
therefore <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:M">$M$</span>, <span data-ref="0428.g1:/ F G /">$FG$</span> are continuously proportional in double proportion.

Now let there be subtracted from the second <span data-ref="0428.g1:/ H K /">$HK$</span> and the last <span data-ref="0428.g1:/ F G /">$FG$</span> the numbers <span data-ref="0428.g1:/ H N /">$HN$</span>, <span data-ref="0428.g1:/ F O /">$FO$</span>, each equal to the first <span data-ref="0428.g1:E">$E$</span>;  
therefore, as the excess of the second is to the first, so is the excess of the last to all those before it. [IX. 35]

Therefore, as <span data-ref="0428.g1:/ K N /">$NK$</span> is to <span data-ref="0428.g1:E">$E$</span>, so is <span data-ref="0428.g1:/ G O /">$OG$</span> to <span data-ref="0428.g1:M">$M$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:/ H K /">$KH$</span>, <span data-ref="0428.g1:E">$E$</span>.

And <span data-ref="0428.g1:/ K N /">$NK$</span> is equal to <span data-ref="0428.g1:E">$E$</span>;  
therefore <span data-ref="0428.g1:/ G O /">$OG$</span> is also equal to <span data-ref="0428.g1:M">$M$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:E">$E$</span>.

But <span data-ref="0428.g1:/ F O /">$FO$</span> is also equal to <span data-ref="0428.g1:E">$E$</span>, and <span data-ref="0428.g1:E">$E$</span> is equal to <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span> and the unit.

Therefore the whole <span data-ref="0428.g1:/ F G /">$FG$</span> is equal to <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:M">$M$</span> and <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span> and the unit; and it is measured by them.

I say also that <span data-ref="0428.g1:/ F G /">$FG$</span> will not be measured by any other number except <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span>, <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:M">$M$</span> and the unit.

For, if possible, let some number <span data-ref="0428.g1:P">$P$</span> measure <span data-ref="0428.g1:/ F G /">$FG$</span>, and let <span data-ref="0428.g1:P">$P$</span> not be the same with any of the numbers <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span>, <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span>, <span data-ref="0428.g1:M">$M$</span>.

And, as many times as <span data-ref="0428.g1:P">$P$</span> measures <span data-ref="0428.g1:/ F G /">$FG$</span>, so many units let there be in <span data-ref="0428.g1:Q">$Q$</span>;  
therefore <span data-ref="0428.g1:Q">$Q$</span> by multiplying <span data-ref="0428.g1:P">$P$</span> has made <span data-ref="0428.g1:/ F G /">$FG$</span>.
