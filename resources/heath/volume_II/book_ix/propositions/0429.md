<p class="sub-clause">But, further, <span data-ref="0428.g1:E">$E$</span> has also by multiplying <span data-ref="0428.g1:D">$D$</span> made <span data-ref="0428.g1:/ F G /">$FG$</span> ;</p>
<p class="assertion">therefore, as <span data-ref="0428.g1:E">$E$</span> is to <span data-ref="0428.g1:Q">$Q$</span>, so is <span data-ref="0428.g1:P">$P$</span> to <span data-ref="0428.g1:D">$D$</span>. <span class="justification">[VII. 19]</span></p>

<p class="sub-clause">And, since <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span> are continuously proportional<br />
beginning from an unit,</p>
<p class="assertion">therefore <span data-ref="0428.g1:D">$D$</span> will not be measured by any other number except<br />
<span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>. <span class="justification">[IX. 13]</span></p>

<p class="sub-clause">And, by hypothesis, <span data-ref="0428.g1:P">$P$</span> is not the same with any of the<br />
numbers <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span> ;</p>
<p class="assertion">therefore <span data-ref="0428.g1:P">$P$</span> will not measure <span data-ref="0428.g1:D">$D$</span>.</p>

<p class="sub-clause">But, as <span data-ref="0428.g1:P">$P$</span> is to <span data-ref="0428.g1:D">$D$</span>, so is <span data-ref="0428.g1:E">$E$</span> to <span data-ref="0428.g1:Q">$Q$</span> ;</p>
<p class="assertion">therefore neither does <span data-ref="0428.g1:E">$E$</span> measure <span data-ref="0428.g1:Q">$Q$</span>. <span class="justification">[VII. Def. 20]</span></p>

<p class="sub-clause">And <span data-ref="0428.g1:E">$E$</span> is prime ;<br />
and any prime number is prime to any number which it does<br />
not measure. <span class="justification">[VII. 29]</span></p>

<p class="assertion">Therefore <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:Q">$Q$</span> are prime to one another.</p>

<p class="sub-clause">But primes are also least, <span class="justification">[VII. 21]</span><br />
and the least numbers measure those which have the same<br />
ratio the same number of times, the antecedent the antecedent<br />
and the consequent the consequent ; <span class="justification">[VII. 20]</span><br />
and, as <span data-ref="0428.g1:E">$E$</span> is to <span data-ref="0428.g1:Q">$Q$</span>, so is <span data-ref="0428.g1:P">$P$</span> to <span data-ref="0428.g1:D">$D$</span> ;</p>
<p class="assertion">therefore <span data-ref="0428.g1:E">$E$</span> measures <span data-ref="0428.g1:P">$P$</span> the same number of times that <span data-ref="0428.g1:Q">$Q$</span><br />
measures <span data-ref="0428.g1:D">$D$</span>.</p>

<p class="sub-clause">But <span data-ref="0428.g1:D">$D$</span> is not measured by any other number except<br />
<span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span> ;</p>
<p class="assertion">therefore <span data-ref="0428.g1:Q">$Q$</span> is the same with one of the numbers <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>.</p>

Let it be the same with <span data-ref="0428.g1:B">$B$</span>.

And, however many <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span> are in multitude, let so many<br />
<span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span> be taken beginning from <span data-ref="0428.g1:E">$E$</span>.

<p class="sub-clause">Now <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span> are in the same ratio with <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span> ;</p>
<p class="assertion">therefore, *ex aequali*, as <span data-ref="0428.g1:B">$B$</span> is to <span data-ref="0428.g1:D">$D$</span>, so is <span data-ref="0428.g1:E">$E$</span> to <span data-ref="0428.g1:L">$L$</span>. <span class="justification">[VII. 14]</span></p>

<p class="assertion">Therefore the product of <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:L">$L$</span> is equal to the product of<br />
<span data-ref="0428.g1:D">$D$</span>, <span data-ref="0428.g1:E">$E$</span>. <span class="justification">[VII. 19]</span></p>

<p class="sub-clause">But the product of <span data-ref="0428.g1:D">$D$</span>, <span data-ref="0428.g1:E">$E$</span> is equal to the product of <span data-ref="0428.g1:Q">$Q$</span>, <span data-ref="0428.g1:P">$P$</span> ;</p>
<p class="assertion">therefore the product of <span data-ref="0428.g1:Q">$Q$</span>, <span data-ref="0428.g1:P">$P$</span> is also equal to the product of<br />
<span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:L">$L$</span>.</p>

<p class="assertion">Therefore, as <span data-ref="0428.g1:Q">$Q$</span> is to <span data-ref="0428.g1:B">$B$</span>, so is <span data-ref="0428.g1:L">$L$</span> to <span data-ref="0428.g1:P">$P$</span>. <span class="justification">[VII. 19]</span></p>
