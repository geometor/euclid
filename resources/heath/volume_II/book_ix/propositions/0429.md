But, further, <span data-ref="0428.g1:E">$E$</span> has also by multiplying <span data-ref="0428.g1:D">$D$</span> made <span data-ref="0428.g1:/ F G /">$FG$</span>;  
therefore, as <span data-ref="0428.g1:E">$E$</span> is to <span data-ref="0428.g1:Q">$Q$</span>, so is <span data-ref="0428.g1:P">$P$</span> to <span data-ref="0428.g1:D">$D$</span>. [VII. 19]

And, since <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span> are continuously proportional beginning from an unit, therefore <span data-ref="0428.g1:D">$D$</span> will not be measured by any other number except <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>. [IX. 13]

And, by hypothesis, <span data-ref="0428.g1:P">$P$</span> is not the same with any of the numbers <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>;  
therefore <span data-ref="0428.g1:P">$P$</span> will not measure <span data-ref="0428.g1:D">$D$</span>.

But, as <span data-ref="0428.g1:P">$P$</span> is to <span data-ref="0428.g1:D">$D$</span>, so is <span data-ref="0428.g1:E">$E$</span> to <span data-ref="0428.g1:Q">$Q$</span>;  
therefore neither does <span data-ref="0428.g1:E">$E$</span> measure <span data-ref="0428.g1:Q">$Q$</span>. [VII. Def. 20]

And <span data-ref="0428.g1:E">$E$</span> is prime; and any prime number is prime to any number which it does not measure. [VII. 29]

Therefore <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:Q">$Q$</span> are prime to one another.

But primes are also least, [VII. 21] and the least numbers measure those which have the same ratio the same number of times, the antecedent the antecedent and the consequent the consequent; [VII. 20] and, as <span data-ref="0428.g1:E">$E$</span> is to <span data-ref="0428.g1:Q">$Q$</span>, so is <span data-ref="0428.g1:P">$P$</span> to <span data-ref="0428.g1:D">$D$</span>; therefore <span data-ref="0428.g1:E">$E$</span> measures <span data-ref="0428.g1:P">$P$</span> the same number of times that <span data-ref="0428.g1:Q">$Q$</span> measures <span data-ref="0428.g1:D">$D$</span>.

But <span data-ref="0428.g1:D">$D$</span> is not measured by any other number except <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>;  
therefore <span data-ref="0428.g1:Q">$Q$</span> is the same with one of the numbers <span data-ref="0428.g1:A">$A$</span>, <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>.

Let it be the same with <span data-ref="0428.g1:B">$B$</span>.

And, however many <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span> are in multitude, let so many <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span> be taken beginning from <span data-ref="0428.g1:E">$E$</span>.

Now <span data-ref="0428.g1:E">$E$</span>, <span data-ref="0428.g1:/ H K /">$HK$</span>, <span data-ref="0428.g1:L">$L$</span> are in the same ratio with <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:C">$C$</span>, <span data-ref="0428.g1:D">$D$</span>;  
therefore, *ex aequali*, as <span data-ref="0428.g1:B">$B$</span> is to <span data-ref="0428.g1:D">$D$</span>, so is <span data-ref="0428.g1:E">$E$</span> to <span data-ref="0428.g1:L">$L$</span>. [VII. 14]

Therefore the product of <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:L">$L$</span> is equal to the product of <span data-ref="0428.g1:D">$D$</span>, <span data-ref="0428.g1:E">$E$</span>. [VII. 19]

But the product of <span data-ref="0428.g1:D">$D$</span>, <span data-ref="0428.g1:E">$E$</span> is equal to the product of <span data-ref="0428.g1:Q">$Q$</span>, <span data-ref="0428.g1:P">$P$</span>;  
therefore the product of <span data-ref="0428.g1:Q">$Q$</span>, <span data-ref="0428.g1:P">$P$</span> is also equal to the product of <span data-ref="0428.g1:B">$B$</span>, <span data-ref="0428.g1:L">$L$</span>.

Therefore, as <span data-ref="0428.g1:Q">$Q$</span> is to <span data-ref="0428.g1:B">$B$</span>, so is <span data-ref="0428.g1:L">$L$</span> to <span data-ref="0428.g1:P">$P$</span>. [VII. 19]
