Let the first <span data-ref="0133.g1:A">$A$</span> be the same *multiple* of <span data-ref="0133.g1:B">$B$</span> the second that <span data-ref="0133.g1:C">$C$</span> the third is of the fourth <span data-ref="0133.g1:D">$D$</span> ;

<span data-ref="0133.g1:A">$A$</span> is to <span data-ref="0133.g1:B">$B$</span> as <span data-ref="0133.g1:C">$C$</span> is to <span data-ref="0133.g1:D">$D$</span>.

![Folio 0133 Figure 1](0133.g1.svg)

Take of <span data-ref="0133.g1:A">$A$</span>, <span data-ref="0133.g1:C">$C$</span> any equimultiples whatever <span data-ref="0133.g1:E">$E$</span>, <span data-ref="0133.g1:F">$F$</span> ; and of <span data-ref="0133.g1:B">$B$</span>, <span data-ref="0133.g1:D">$D$</span> any equimultiples whatever <span data-ref="0133.g1:G">$G$</span>, <span data-ref="0133.g1:H">$H$</span>.

Then, because <span data-ref="0133.g1:A">$A$</span> is the same multiple of <span data-ref="0133.g1:B">$B$</span> that <span data-ref="0133.g1:C">$C$</span> is of <span data-ref="0133.g1:D">$D$</span>,
and <span data-ref="0133.g1:E">$E$</span> is the same multiple of <span data-ref="0133.g1:A">$A$</span> that <span data-ref="0133.g1:F">$F$</span> is of <span data-ref="0133.g1:C">$C$</span>,
<span data-ref="0133.g1:E">$E$</span> is the same multiple of <span data-ref="0133.g1:B">$B$</span> that <span data-ref="0133.g1:F">$F$</span> is of <span data-ref="0133.g1:D">$D$</span>. [V. 3]

Therefore <span data-ref="0133.g1:E">$E$</span>, <span data-ref="0133.g1:F">$F$</span> are the same multiples of <span data-ref="0133.g1:B">$B$</span>, <span data-ref="0133.g1:D">$D$</span>.

But <span data-ref="0133.g1:G">$G$</span>, <span data-ref="0133.g1:H">$H$</span> are equimultiples of <span data-ref="0133.g1:B">$B$</span>, <span data-ref="0133.g1:D">$D$</span> ;
therefore, if <span data-ref="0133.g1:E">$E$</span> be a greater multiple of <span data-ref="0133.g1:B">$B$</span> than <span data-ref="0133.g1:G">$G$</span> is, <span data-ref="0133.g1:F">$F$</span> is a greater multiple of <span data-ref="0133.g1:D">$D$</span> than <span data-ref="0133.g1:H">$H$</span> is of <span data-ref="0133.g1:D">$D$</span> ;

that is, if <span data-ref="0133.g1:E">$E$</span> be greater than <span data-ref="0133.g1:G">$G$</span>, <span data-ref="0133.g1:F">$F$</span> is greater than <span data-ref="0133.g1:H">$H$</span>.

In like manner,
if <span data-ref="0133.g1:E">$E$</span> be equal to <span data-ref="0133.g1:G">$G$</span>, or less, <span data-ref="0133.g1:F">$F$</span> is equal to <span data-ref="0133.g1:H">$H$</span>, or less than it.

But <span data-ref="0133.g1:E">$E$</span>, <span data-ref="0133.g1:F">$F$</span> are equimultiples, any whatever, of <span data-ref="0133.g1:A">$A$</span>, <span data-ref="0133.g1:C">$C$</span> ;
and <span data-ref="0133.g1:G">$G$</span>, <span data-ref="0133.g1:H">$H$</span> any equimultiples whatever of <span data-ref="0133.g1:B">$B$</span>, <span data-ref="0133.g1:D">$D$</span>.

Therefore <span data-ref="0133.g1:A">$A$</span> is to <span data-ref="0133.g1:B">$B$</span> as <span data-ref="0133.g1:C">$C$</span> is to <span data-ref="0133.g1:D">$D$</span>. [V. Def. 5]

Next, let the first <span data-ref="0133.g2:A">$A$</span> be the same *part* of the second <span data-ref="0133.g2:B">$B$</span> that the third <span data-ref="0133.g2:C">$C$</span> is of the fourth <span data-ref="0133.g2:D">$D$</span> :

<span data-ref="0133.g2:A">$A$</span> is to <span data-ref="0133.g2:B">$B$</span> as <span data-ref="0133.g2:C">$C$</span> is to <span data-ref="0133.g2:D">$D$</span>.

![Folio 0133 Figure 2](0133.g2.svg)

For <span data-ref="0133.g2:B">$B$</span> is the same multiple of <span data-ref="0133.g2:A">$A$</span> that <span data-ref="0133.g2:D">$D$</span> is of <span data-ref="0133.g2:C">$C$</span> ;
wherefore, by the preceding case,

<span data-ref="0133.g2:B">$B$</span> is to <span data-ref="0133.g2:A">$A$</span> as <span data-ref="0133.g2:D">$D$</span> is to <span data-ref="0133.g2:C">$C$</span> ;

and, *inversely*, <span data-ref="0133.g2:A">$A$</span> is to <span data-ref="0133.g2:B">$B$</span> as <span data-ref="0133.g2:C">$C$</span> is to <span data-ref="0133.g2:D">$D$</span>.

[For this last inference Simson refers to his Proposition B. That proposition is very simply proved by taking any equimultiples $E$, $F$ of <span data-ref="0133.g2:B">$B$</span>, <span data-ref="0133.g2:D">$D$</span> and any equimultiples $G$, $H$ of <span data-ref="0133.g2:A">$A$</span>, <span data-ref="0133.g2:C">$C$</span> and then arguing as follows :

Since <span data-ref="0133.g2:A">$A$</span> is to <span data-ref="0133.g2:B">$B$</span> as <span data-ref="0133.g2:C">$C$</span> is to <span data-ref="0133.g2:D">$D$</span>,
$G$, $H$ are *simultaneously* greater than, equal to, or less than $E$, $F$ respectively ; so that
$E$, $F$ are *simultaneously* less than, equal to, or greater than $G$, $H$ respectively,
and therefore [Def. 5] <span data-ref="0133.g2:B">$B$</span> is to <span data-ref="0133.g2:A">$A$</span> as <span data-ref="0133.g2:D">$D$</span> is to <span data-ref="0133.g2:C">$C$</span>.]

We have now only to add to Prop. C the case where <span data-ref="0134.g1:/ A B /">$AB$</span> contains the *same parts* of <span data-ref="0134.g1:/ C D /">$CD$</span> that <span data-ref="0134.g1:/ E F /">$EF$</span> does of <span data-ref="0134.g1:/ G H /">$GH$</span> :
in this case likewise <span data-ref="0134.g1:/ A B /">$AB$</span> is to <span data-ref="0134.g1:/ C D /">$CD$</span> as <span data-ref="0134.g1:/ E F /">$EF$</span> to <span data-ref="0134.g1:/ G H /">$GH$</span>.

Let <span data-ref="0134.g1:/ C K /">$CK$</span> be a part of <span data-ref="0134.g1:/ C D /">$CD$</span>, and <span data-ref="0134.g1:/ G L /">$GL$</span> the same part of <span data-ref="0134.g1:/ G H /">$GH$</span> ; let <span data-ref="0134.g1:/ A B /">$AB$</span> be the same multiple of <span data-ref="0134.g1:/ C K /">$CK$</span> that <span data-ref="0134.g1:/ E F /">$EF$</span> is of <span data-ref="0134.g1:/ G L /">$GL$</span>.
