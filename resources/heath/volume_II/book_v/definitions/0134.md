Therefore, by Prop. C,

<span data-ref="0134.g1:/ A B /">$AB$</span> is to <span data-ref="0134.g1:/ C K /">$CK$</span> as <span data-ref="0134.g1:/ E F /">$EF$</span> to <span data-ref="0134.g1:/ G L /">$GL$</span>.

![Folio 0134 Figure 1](0134.g1.svg)

And <span data-ref="0134.g1:/ C D /">$CD$</span>, <span data-ref="0134.g1:/ G H /">$GH$</span> are equimultiples of <span data-ref="0134.g1:/ C K /">$CK$</span>, <span data-ref="0134.g1:/ G L /">$GL$</span>, the second and fourth.

Therefore <span data-ref="0134.g1:/ A B /">$AB$</span> is to <span data-ref="0134.g1:/ C D /">$CD$</span> as <span data-ref="0134.g1:/ E F /">$EF$</span> to <span data-ref="0134.g1:/ G H /">$GH$</span> [Simson's Cor. to V. 4, which however is the particular case of V. 4 in which the "equimultiples" of one pair are the pair itself, i.e. the pair multiplied by unity].

To prove the partial converse we begin with Prop. D.

*If the first be to the second as the third to the fourth, and if the first be a multiple or part of the second, the third is the same multiple or the same part of the fourth.*

Let <span data-ref="0134.g2:A">$A$</span> be to <span data-ref="0134.g2:B">$B$</span> as <span data-ref="0134.g2:C">$C$</span> is to <span data-ref="0134.g2:D">$D$</span> ;
and, first, let <span data-ref="0134.g2:A">$A$</span> be a multiple of <span data-ref="0134.g2:B">$B$</span> ;

<span data-ref="0134.g2:C">$C$</span> is the same multiple of <span data-ref="0134.g2:D">$D$</span>.

Take <span data-ref="0134.g2:E">$E$</span> equal to <span data-ref="0134.g2:A">$A$</span>, and whatever multiple <span data-ref="0134.g2:A">$A$</span> or <span data-ref="0134.g2:E">$E$</span> is of <span data-ref="0134.g2:B">$B$</span>, make <span data-ref="0134.g2:F">$F$</span> the same multiple of <span data-ref="0134.g2:D">$D$</span>.

Then, because <span data-ref="0134.g2:A">$A$</span> is to <span data-ref="0134.g2:B">$B$</span> as <span data-ref="0134.g2:C">$C$</span> is to <span data-ref="0134.g2:D">$D$</span>,
and of <span data-ref="0134.g2:B">$B$</span> the second and <span data-ref="0134.g2:D">$D$</span> the fourth equimultiples have been taken <span data-ref="0134.g2:E">$E$</span> and <span data-ref="0134.g2:F">$F$</span>,

<span data-ref="0134.g2:A">$A$</span> is to <span data-ref="0134.g2:E">$E$</span> as <span data-ref="0134.g2:C">$C$</span> is to <span data-ref="0134.g2:F">$F$</span>. [V. 4, Cor.]

But <span data-ref="0134.g2:A">$A$</span> is equal to <span data-ref="0134.g2:E">$E$</span> ;

therefore <span data-ref="0134.g2:C">$C$</span> is equal to <span data-ref="0134.g2:F">$F$</span>.

[In support of this inference Simson cites his Prop. A, which however we can directly deduce from V. Def. 5 by taking any, but *the same*, equimultiples of all four magnitudes.]

![Folio 0134 Figure 2](0134.g2.svg)

Now <span data-ref="0134.g2:F">$F$</span> is the same multiple of <span data-ref="0134.g2:D">$D$</span> that <span data-ref="0134.g2:A">$A$</span> is of <span data-ref="0134.g2:B">$B$</span> ;

therefore <span data-ref="0134.g2:C">$C$</span> is the same multiple of <span data-ref="0134.g2:D">$D$</span> that <span data-ref="0134.g2:A">$A$</span> is of <span data-ref="0134.g2:B">$B$</span>.

Next, let the first <span data-ref="0134.g2:A">$A$</span> be a part of the second <span data-ref="0134.g2:B">$B$</span> ;

<span data-ref="0134.g2:C">$C$</span> the third is the same part of the fourth <span data-ref="0134.g2:D">$D$</span>.

Because <span data-ref="0134.g2:A">$A$</span> is to <span data-ref="0134.g2:B">$B$</span> as <span data-ref="0134.g2:C">$C$</span> is to <span data-ref="0134.g2:D">$D$</span>,
*inversely*, <span data-ref="0134.g2:B">$B$</span> is to <span data-ref="0134.g2:A">$A$</span> as <span data-ref="0134.g2:D">$D$</span> is to <span data-ref="0134.g2:C">$C$</span>. [Prop. B]

But <span data-ref="0134.g2:A">$A$</span> is a part of <span data-ref="0134.g2:B">$B$</span> ; therefore <span data-ref="0134.g2:B">$B$</span> is a multiple of <span data-ref="0134.g2:A">$A$</span> ;
and, by the preceding case, <span data-ref="0134.g2:D">$D$</span> is the same multiple of <span data-ref="0134.g2:C">$C$</span>,
that is, <span data-ref="0134.g2:C">$C$</span> is the same part of <span data-ref="0134.g2:D">$D$</span> that <span data-ref="0134.g2:A">$A$</span> is of <span data-ref="0134.g2:B">$B$</span>.

We have, again, only to add to Prop. D the case where <span data-ref="0135.g1:/ A B /">$AB$</span> contains any parts of <span data-ref="0135.g1:/ C D /">$CD$</span>, and <span data-ref="0135.g1:/ A B /">$AB$</span> is to <span data-ref="0135.g1:/ C D /">$CD$</span> as <span data-ref="0135.g1:/ E F /">$EF$</span> to <span data-ref="0135.g1:/ G H /">$GH$</span> ;
then shall <span data-ref="0135.g1:/ E F /">$EF$</span> contain the same parts of <span data-ref="0135.g1:/ G H /">$GH$</span> that <span data-ref="0135.g1:/ A B /">$AB$</span> does of <span data-ref="0135.g1:/ C D /">$CD$</span>.
