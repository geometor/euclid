Multiply (1) by $q$ and (2) by $n$.

(We need here to assume that, where $rX, rY$ are any equimultiples of any magnitudes $X, Y$,

$$\text{according as } X > = < Y, \quad rX > = < rY.$$

This is contained in :person:`Simson <simson>`'s Axioms 1 and 3.)

We have then the pairs of equations

$$mqA > nqB, \quad mqC < nqD,$$

$$npA < nqB, \quad npC > nqD.$$

From the second equations in each pair it follows that

$$mqC < npC.$$

(We now need to assume that, if $rX, sX$ are any multiples of $X$, and $rY, sY$ the same multiples of $Y$, then,

$$\text{according as } rX > = < sX, \quad rY > = < sY.$$

:person:`Simson <simson>` uses this same assumption in his proof of V. 18.)

Therefore

$$mqA < npA.$$

But it follows from the first equations in each pair that

$$mqA > npA :$$

which is impossible.

Nor can Euclid's criterion for a greater ratio coexist with that for equal ratios.

DEFINITION 8.
-------------

**Ἀναλογία δὲ ἐν τρισὶν ὅροις ἐλαχίστη ἐστίν.**

This is the reading of :person:`Heiberg <heiberg>` and :person:`Camerer <camerer>` (who follow :person:`Peyrard <peyrard>`'s MS.) and is that translated above. The other reading has ἐλαχίστοις, which can only be translated "consists in three terms *at least*." :person:`Hankel <hankel>` regards the definition as a later interpolation, because it is superfluous, and because the word ὅρος for a *term* in a proportion is nowhere else used by Euclid, though it is common in later writers such as :person:`Nicomachus <nicomachus>` and :person:`Theon of Smyrna <theon-of-smyrna>`. The genuineness of the definition is however supported by the fact that :person:`Aristotle <aristotle>` not only uses ὅρος in this sense (:cite:`*Eth. Nic.* V. 6, 7 <aristotle:eth-nic:v-6-7>`, 1131 b 5, 9), but has a similar remark (*ibid.* 1131 a 31) that a "proportion is in *four* terms at least." The difference from Euclid is only formal; for :person:`Aristotle <aristotle>` proceeds: "The *discrete* (διῃρημένη) (proportion) is clearly in four (terms), but so also is the *continuous* (συνεχής). For it uses one as two and mentions it twice, e.g. (in stating) that, as $\alpha$ is to $\beta$, so also is $\beta$ to $\gamma$; thus $\beta$ is mentioned twice, so that, if $\beta$ be twice put down, the proportionals are four." The distinction between *discrete* and *continuous* seems to have been Pythagorean (cf. :person:`Nicomachus <nicomachus>`, :cite:`II. 21, 5 <nicomachus:intro-arith:ii-21-5>`; 23, 2, 3; where however συνημμένη is used instead of συνεχής); Euclid does not use the words διῃρημένη and συνεχής in this connexion.

So far as they go, the first words of the next definition (9), "When three magnitudes are proportionals," which seemingly refer to Def. 8, also support the view that the latter is, at least in substance, genuine.
