# BOOK V. PROPOSITIONS.

### PROPOSITION 1.

<p class="enunciation">If there be any number of magnitudes whatever which are,<br />
respectively, equimultiples of any magnitudes equal in multitude,<br />
then, whatever multiple one of the magnitudes is of one, that<br />
multiple also will all be of all.</p>

Let any number of magnitudes whatever <span data-ref="0144.g1:/ A B /">$AB$</span>, <span data-ref="0144.g1:/ C D /">$CD$</span> be  
respectively equimultiples of any magnitudes <span data-ref="0144.g1:E">$E$</span>, <span data-ref="0144.g1:F">$F$</span> equal in  
multitude;

I say that, whatever multiple <span data-ref="0144.g1:/ A B /">$AB$</span> is of <span data-ref="0144.g1:E">$E$</span>, that multiple will  
<span data-ref="0144.g1:/ A B /">$AB$</span>, <span data-ref="0144.g1:/ C D /">$CD$</span> also be of <span data-ref="0144.g1:E">$E$</span>, <span data-ref="0144.g1:F">$F$</span>.

![Proposition 1 diagram](0144.g1.svg)

For, since <span data-ref="0144.g1:/ A B /">$AB$</span> is the same multiple of <span data-ref="0144.g1:E">$E$</span> that <span data-ref="0144.g1:/ C D /">$CD$</span> is of <span data-ref="0144.g1:F">$F$</span>,  
as many magnitudes as there are in <span data-ref="0144.g1:/ A B /">$AB$</span> equal to <span data-ref="0144.g1:E">$E$</span>, so many  
also are there in <span data-ref="0144.g1:/ C D /">$CD$</span> equal to <span data-ref="0144.g1:F">$F$</span>.

Let <span data-ref="0144.g1:/ A B /">$AB$</span> be divided into the magnitudes <span data-ref="0144.g1:/ A G /">$AG$</span>, <span data-ref="0144.g1:/ G B /">$GB$</span> equal  
to <span data-ref="0144.g1:E">$E$</span>,  
and <span data-ref="0144.g1:/ C D /">$CD$</span> into <span data-ref="0144.g1:/ C H /">$CH$</span>, <span data-ref="0144.g1:/ H D /">$HD$</span> equal to <span data-ref="0144.g1:F">$F$</span>;  
then the multitude of the magnitudes <span data-ref="0144.g1:/ A G /">$AG$</span>, <span data-ref="0144.g1:/ G B /">$GB$</span> will be equal  
to the multitude of the magnitudes <span data-ref="0144.g1:/ C H /">$CH$</span>, <span data-ref="0144.g1:/ H D /">$HD$</span>.

Now, since <span data-ref="0144.g1:/ A G /">$AG$</span> is equal to <span data-ref="0144.g1:E">$E$</span>, and <span data-ref="0144.g1:/ C H /">$CH$</span> to <span data-ref="0144.g1:F">$F$</span>,
<p class="assertion">therefore <span data-ref="0144.g1:/ A G /">$AG$</span> is equal to <span data-ref="0144.g1:E">$E$</span>, and <span data-ref="0144.g1:/ A G /">$AG$</span>, <span data-ref="0144.g1:/ C H /">$CH$</span> to <span data-ref="0144.g1:E">$E$</span>, <span data-ref="0144.g1:F">$F$</span>.</p>

For the same reason
<p class="assertion"><span data-ref="0144.g1:/ G B /">$GB$</span> is equal to <span data-ref="0144.g1:E">$E$</span>, and <span data-ref="0144.g1:/ G B /">$GB$</span>, <span data-ref="0144.g1:/ H D /">$HD$</span> to <span data-ref="0144.g1:E">$E$</span>, <span data-ref="0144.g1:F">$F$</span>;</p>

<p class="assertion">therefore, as many magnitudes as there are in <span data-ref="0144.g1:/ A B /">$AB$</span> equal to <span data-ref="0144.g1:E">$E$</span>,<br />
so many also are there in <span data-ref="0144.g1:/ A B /">$AB$</span>, <span data-ref="0144.g1:/ C D /">$CD$</span> equal to <span data-ref="0144.g1:E">$E$</span>, <span data-ref="0144.g1:F">$F$</span>;</p>
