Let <span data-ref="0153.g1:/ C H /">$CH$</span> be subtracted from each ;

therefore the remainder <span data-ref="0153.g1:/ C K /">$KC$</span> is equal to the remainder <span data-ref="0153.g1:/ H D /">$HD$</span>.

But <span data-ref="0153.g1:F">$F$</span> is equal to <span data-ref="0153.g1:/ C K /">$KC$</span> ;

therefore <span data-ref="0153.g1:/ H D /">$HD$</span> is also equal to <span data-ref="0153.g1:F">$F$</span>.

Hence, if <span data-ref="0153.g1:/ G B /">$GB$</span> is equal to <span data-ref="0153.g1:E">$E$</span>, <span data-ref="0153.g1:/ H D /">$HD$</span> is also equal to <span data-ref="0153.g1:F">$F$</span>.

Similarly we can prove that, even if <span data-ref="0153.g1:/ G B /">$GB$</span> be a multiple of <span data-ref="0153.g1:E">$E$</span>, <span data-ref="0153.g1:/ H D /">$HD$</span> is also the same multiple of <span data-ref="0153.g1:F">$F$</span>.

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>

---

This proposition corresponds to V. 2, with subtraction taking the place of addition. It asserts namely that, if $n$ is less than $m$, $ma - na$ is the same multiple of $a$ that $mb - nb$ is of $b$. The enunciation distinguishes the cases in which $m - n$ is equal to $1$ and greater than $1$ respectively.

Simson observes that, while only the first case (the simpler one) is proved in the Greek, both are given in the Latin translation from the Arabic ; and he supplies accordingly the proof of the second case, which Euclid leaves to the reader. The fact is that it is exactly the same as the other except that, in the construction, <span data-ref="0153.g1:/ C K /">$CK$</span> is made the same multiple of <span data-ref="0153.g1:F">$F$</span> that <span data-ref="0153.g1:/ G B /">$GB$</span> is of <span data-ref="0153.g1:E">$E$</span>, and at the end, when it has been proved that <span data-ref="0153.g1:/ C K /">$KC$</span> is equal to <span data-ref="0153.g1:/ H D /">$HD$</span>, instead of concluding that <span data-ref="0153.g1:/ H D /">$HD$</span> is equal to <span data-ref="0153.g1:F">$F$</span>, we have to say "Because <span data-ref="0153.g1:/ G B /">$GB$</span> is the same multiple of <span data-ref="0153.g1:E">$E$</span> that <span data-ref="0153.g1:/ C K /">$KC$</span> is of <span data-ref="0153.g1:F">$F$</span>, and <span data-ref="0153.g1:/ C K /">$KC$</span> is equal to <span data-ref="0153.g1:/ H D /">$HD$</span>, therefore <span data-ref="0153.g1:/ H D /">$HD$</span> is the same multiple of <span data-ref="0153.g1:F">$F$</span> that <span data-ref="0153.g1:/ G B /">$GB$</span> is of <span data-ref="0153.g1:E">$E$</span>."

### PROPOSITION 7.

<p class="enunciation">Equal magnitudes have to the same the same ratio, as also<br />
has the same to equal magnitudes.</p>

Let <span data-ref="0154.g1:A">$A$</span>, <span data-ref="0154.g1:B">$B$</span> be equal magnitudes and <span data-ref="0154.g1:C">$C$</span> any other, chance, magnitude ;

I say that each of the magnitudes <span data-ref="0154.g1:A">$A$</span>, <span data-ref="0154.g1:B">$B$</span> has the same ratio to <span data-ref="0154.g1:C">$C$</span>, and <span data-ref="0154.g1:C">$C$</span> has the same ratio to each of the magnitudes <span data-ref="0154.g1:A">$A$</span>, <span data-ref="0154.g1:B">$B$</span>.

![Proposition 7 Diagram](0154.g1.svg)

For let equimultiples <span data-ref="0154.g1:D">$D$</span>, <span data-ref="0154.g1:E">$E$</span> of <span data-ref="0154.g1:A">$A$</span>, <span data-ref="0154.g1:B">$B$</span> be taken, and of <span data-ref="0154.g1:C">$C$</span> another, chance, multiple <span data-ref="0154.g1:F">$F$</span>.

Then, since <span data-ref="0154.g1:D">$D$</span> is the same multiple of <span data-ref="0154.g1:A">$A$</span> that <span data-ref="0154.g1:E">$E$</span> is of <span data-ref="0154.g1:B">$B$</span>, while <span data-ref="0154.g1:A">$A$</span> is equal to <span data-ref="0154.g1:B">$B$</span>,

therefore <span data-ref="0154.g1:D">$D$</span> is equal to <span data-ref="0154.g1:E">$E$</span>.

But <span data-ref="0154.g1:F">$F$</span> is another, chance, magnitude.
