### PROPOSITION 10.

*Of magnitudes which have a ratio to the same, that which has a greater ratio is greater; and that to which the same has a greater ratio is less.*

For let <span data-ref="0161.g1:A">$A$</span> have to <span data-ref="0161.g1:C">$C$</span> a greater ratio than <span data-ref="0161.g1:B">$B$</span> has to <span data-ref="0161.g1:C">$C$</span>;
I say that <span data-ref="0161.g1:A">$A$</span> is greater than <span data-ref="0161.g1:B">$B$</span>.

![Folio 0161 Figure 1](0161.g1.svg)

For, if not, <span data-ref="0161.g1:A">$A$</span> is either equal to <span data-ref="0161.g1:B">$B$</span> or less.
Now <span data-ref="0161.g1:A">$A$</span> is not equal to <span data-ref="0161.g1:B">$B$</span>;
for in that case each of the magnitudes <span data-ref="0161.g1:A">$A$</span>, <span data-ref="0161.g1:B">$B$</span> would have had the same ratio to <span data-ref="0161.g1:C">$C$</span>; [V. 7]
but they have not;
therefore <span data-ref="0161.g1:A">$A$</span> is not equal to <span data-ref="0161.g1:B">$B$</span>.

Nor again is <span data-ref="0161.g1:A">$A$</span> less than <span data-ref="0161.g1:B">$B$</span>;
for in that case <span data-ref="0161.g1:A">$A$</span> would have had to <span data-ref="0161.g1:C">$C$</span> a less ratio than <span data-ref="0161.g1:B">$B$</span> has to <span data-ref="0161.g1:C">$C$</span>; [V. 8]
but it has not;
therefore <span data-ref="0161.g1:A">$A$</span> is not less than <span data-ref="0161.g1:B">$B$</span>.

But it was proved not to be equal either;
therefore <span data-ref="0161.g1:A">$A$</span> is greater than <span data-ref="0161.g1:B">$B$</span>.

Again, let <span data-ref="0161.g1:C">$C$</span> have to <span data-ref="0161.g1:B">$B$</span> a greater ratio than <span data-ref="0161.g1:C">$C$</span> has to <span data-ref="0161.g1:A">$A$</span>;
I say that <span data-ref="0161.g1:B">$B$</span> is less than <span data-ref="0161.g1:A">$A$</span>.

For, if not, it is either equal or greater.
Now <span data-ref="0161.g1:B">$B$</span> is not equal to <span data-ref="0161.g1:A">$A$</span>;
for in that case <span data-ref="0161.g1:C">$C$</span> would have had the same ratio to each of the magnitudes <span data-ref="0161.g1:A">$A$</span>, <span data-ref="0161.g1:B">$B$</span>; [V. 7]
but it has not;
therefore <span data-ref="0161.g1:A">$A$</span> is not equal to <span data-ref="0161.g1:B">$B$</span>.
