### PROPOSITION 11.

<p class="enunciation">Ratios which are the same with the same ratio are also<br />
the same with one another.</p>

For, as <span data-ref="0164.g1:A">$A$</span> is to <span data-ref="0164.g1:B">$B$</span>, so let <span data-ref="0164.g1:C">$C$</span> be to <span data-ref="0164.g1:D">$D$</span>,<br />
and, as <span data-ref="0164.g1:C">$C$</span> is to <span data-ref="0164.g1:D">$D$</span>, so let <span data-ref="0164.g1:E">$E$</span> be to <span data-ref="0164.g1:F">$F$</span>;<br />
I say that, as <span data-ref="0164.g1:A">$A$</span> is to <span data-ref="0164.g1:B">$B$</span>, so is <span data-ref="0164.g1:E">$E$</span> to <span data-ref="0164.g1:F">$F$</span>.

![Folio 0164 Figure 1](0164.g1.svg)

For of <span data-ref="0164.g1:A">$A$</span>, <span data-ref="0164.g1:C">$C$</span>, <span data-ref="0164.g1:E">$E$</span> let equimultiples <span data-ref="0164.g1:G">$G$</span>, <span data-ref="0164.g1:H">$H$</span>, <span data-ref="0164.g1:K">$K$</span> be taken, and<br />
of <span data-ref="0164.g1:B">$B$</span>, <span data-ref="0164.g1:D">$D$</span>, <span data-ref="0164.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0164.g1:L">$L$</span>, <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:N">$N$</span>.

Then since, as <span data-ref="0164.g1:A">$A$</span> is to <span data-ref="0164.g1:B">$B$</span>, so is <span data-ref="0164.g1:C">$C$</span> to <span data-ref="0164.g1:D">$D$</span>,<br />
and of <span data-ref="0164.g1:A">$A$</span>, <span data-ref="0164.g1:C">$C$</span> equimultiples <span data-ref="0164.g1:G">$G$</span>, <span data-ref="0164.g1:H">$H$</span> have been taken,<br />
and of <span data-ref="0164.g1:B">$B$</span>, <span data-ref="0164.g1:D">$D$</span> other, chance, equimultiples <span data-ref="0164.g1:L">$L$</span>, <span data-ref="0164.g1:M">$M$</span>,

<p class="assertion">therefore, if <span data-ref="0164.g1:G">$G$</span> is in excess of <span data-ref="0164.g1:L">$L$</span>, <span data-ref="0164.g1:H">$H$</span> is also in excess of <span data-ref="0164.g1:M">$M$</span>,<br />
if equal, equal,<br />
and if less, less.</p>

Again, since, as <span data-ref="0164.g1:C">$C$</span> is to <span data-ref="0164.g1:D">$D$</span>, so is <span data-ref="0164.g1:E">$E$</span> to <span data-ref="0164.g1:F">$F$</span>,<br />
and of <span data-ref="0164.g1:C">$C$</span>, <span data-ref="0164.g1:E">$E$</span> equimultiples <span data-ref="0164.g1:H">$H$</span>, <span data-ref="0164.g1:K">$K$</span> have been taken,<br />
and of <span data-ref="0164.g1:D">$D$</span>, <span data-ref="0164.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:N">$N$</span>,

<p class="assertion">therefore, if <span data-ref="0164.g1:H">$H$</span> is in excess of <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:K">$K$</span> is also in excess of <span data-ref="0164.g1:N">$N$</span>,<br />
if equal, equal,<br />
and if less, less.</p>

But we saw that, if <span data-ref="0164.g1:H">$H$</span> was in excess of <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:G">$G$</span> was also<br />
in excess of <span data-ref="0164.g1:L">$L$</span>; if equal, equal; and if less, less;

<p class="assertion">so that, in addition, if <span data-ref="0164.g1:G">$G$</span> is in excess of <span data-ref="0164.g1:L">$L$</span>, <span data-ref="0164.g1:K">$K$</span> is also in excess<br />
of <span data-ref="0164.g1:N">$N$</span>,<br />
if equal, equal,<br />
and if less, less.</p>

And <span data-ref="0164.g1:G">$G$</span>, <span data-ref="0164.g1:K">$K$</span> are equimultiples of <span data-ref="0164.g1:A">$A$</span>, <span data-ref="0164.g1:E">$E$</span>,<br />
while <span data-ref="0164.g1:L">$L$</span>, <span data-ref="0164.g1:N">$N$</span> are other, chance, equimultiples of <span data-ref="0164.g1:B">$B$</span>, <span data-ref="0164.g1:F">$F$</span>;

<p class="assertion">therefore, as <span data-ref="0164.g1:A">$A$</span> is to <span data-ref="0164.g1:B">$B$</span>, so is <span data-ref="0164.g1:E">$E$</span> to <span data-ref="0164.g1:F">$F$</span>.</p>

<p class="qed">Therefore etc.</p>
