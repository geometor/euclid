### PROPOSITION 11.

<p class="enunciation">Ratios which are the same with the same ratio are also<br />
the same with one another.</p>

For, as <span data-ref="0164.g1:A">$A$</span> is to <span data-ref="0164.g1:B">$B$</span>, so let <span data-ref="0164.g1:C">$C$</span> be to <span data-ref="0164.g1:D">$D$</span>,
and, as <span data-ref="0164.g1:C">$C$</span> is to <span data-ref="0164.g1:D">$D$</span>, so let <span data-ref="0164.g1:E">$E$</span> be to <span data-ref="0164.g1:F">$F$</span>;
I say that, as <span data-ref="0164.g1:A">$A$</span> is to <span data-ref="0164.g1:B">$B$</span>, so is <span data-ref="0164.g1:E">$E$</span> to <span data-ref="0164.g1:F">$F$</span>.

![Folio 0164 Figure 1](0164.g1.svg)

For of <span data-ref="0164.g1:A">$A$</span>, <span data-ref="0164.g1:C">$C$</span>, <span data-ref="0164.g1:E">$E$</span> let equimultiples <span data-ref="0164.g1:G">$G$</span>, <span data-ref="0164.g1:H">$H$</span>, <span data-ref="0164.g1:K">$K$</span> be taken, and of <span data-ref="0164.g1:B">$B$</span>, <span data-ref="0164.g1:D">$D$</span>, <span data-ref="0164.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0164.g1:L">$L$</span>, <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:N">$N$</span>.

Then since, as <span data-ref="0164.g1:A">$A$</span> is to <span data-ref="0164.g1:B">$B$</span>, so is <span data-ref="0164.g1:C">$C$</span> to <span data-ref="0164.g1:D">$D$</span>,
and of <span data-ref="0164.g1:A">$A$</span>, <span data-ref="0164.g1:C">$C$</span> equimultiples <span data-ref="0164.g1:G">$G$</span>, <span data-ref="0164.g1:H">$H$</span> have been taken,
and of <span data-ref="0164.g1:B">$B$</span>, <span data-ref="0164.g1:D">$D$</span> other, chance, equimultiples <span data-ref="0164.g1:L">$L$</span>, <span data-ref="0164.g1:M">$M$</span>,
therefore, if <span data-ref="0164.g1:G">$G$</span> is in excess of <span data-ref="0164.g1:L">$L$</span>, <span data-ref="0164.g1:H">$H$</span> is also in excess of <span data-ref="0164.g1:M">$M$</span>,
if equal, equal,
and if less, less.

Again, since, as <span data-ref="0164.g1:C">$C$</span> is to <span data-ref="0164.g1:D">$D$</span>, so is <span data-ref="0164.g1:E">$E$</span> to <span data-ref="0164.g1:F">$F$</span>,
and of <span data-ref="0164.g1:C">$C$</span>, <span data-ref="0164.g1:E">$E$</span> equimultiples <span data-ref="0164.g1:H">$H$</span>, <span data-ref="0164.g1:K">$K$</span> have been taken,
and of <span data-ref="0164.g1:D">$D$</span>, <span data-ref="0164.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:N">$N$</span>,
therefore, if <span data-ref="0164.g1:H">$H$</span> is in excess of <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:K">$K$</span> is also in excess of <span data-ref="0164.g1:N">$N$</span>,
if equal, equal,
and if less, less.

But we saw that, if <span data-ref="0164.g1:H">$H$</span> was in excess of <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:G">$G$</span> was also in excess of <span data-ref="0164.g1:L">$L$</span>; if equal, equal; and if less, less;
so that, in addition, if <span data-ref="0164.g1:G">$G$</span> is in excess of <span data-ref="0164.g1:L">$L$</span>, <span data-ref="0164.g1:K">$K$</span> is also in excess of <span data-ref="0164.g1:N">$N$</span>,
if equal, equal,
and if less, less.

And <span data-ref="0164.g1:G">$G$</span>, <span data-ref="0164.g1:K">$K$</span> are equimultiples of <span data-ref="0164.g1:A">$A$</span>, <span data-ref="0164.g1:E">$E$</span>,
while <span data-ref="0164.g1:L">$L$</span>, <span data-ref="0164.g1:N">$N$</span> are other, chance, equimultiples of <span data-ref="0164.g1:B">$B$</span>, <span data-ref="0164.g1:F">$F$</span>;
therefore, as <span data-ref="0164.g1:A">$A$</span> is to <span data-ref="0164.g1:B">$B$</span>, so is <span data-ref="0164.g1:E">$E$</span> to <span data-ref="0164.g1:F">$F$</span>.

<p class="assertion">therefore, as $A$ is to $B$, so is $E$ to $F$.</p>

<p class="qed">Therefore etc.</p>
