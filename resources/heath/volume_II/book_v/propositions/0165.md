Algebraically, if
$$\begin{aligned}
a : b &= c : d, \\
\text{and}\qquad c : d &= e : f, \\
\text{then}\qquad a : b &= e : f.
\end{aligned}$$

The idiomatic use of the imperfect in quoting a result previously obtained<br />
is noteworthy. Instead of saying "But *it was proved that*, if <span data-ref="0164.g1:H">$H$</span> is in excess<br />
of <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:G">$G$</span> is also in excess of <span data-ref="0164.g1:L">$L$</span>," the Greek text has "But if <span data-ref="0164.g1:H">$H$</span> *was* in excess<br />
of <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:G">$G$</span> *was* also in excess of <span data-ref="0164.g1:L">$L$</span>," ἀλλὰ εἰ ὑπερεῖχε τὸ Θ τοῦ Μ, ὑπερεῖχε καὶ<br />
τὸ Η τοῦ Λ.

This proposition is tacitly used in combination with v. 16 and v. 24 in the<br />
geometrical passage in Aristotle, $Meteorologica$ III. 5, 376 a 22—26.

### PROPOSITION 12.

<p class="enunciation">If any number of magnitudes be proportional, as one of<br />
the antecedents is to one of the consequents, so will all the<br />
antecedents be to all the consequents.</p>

Let any number of magnitudes <span data-ref="0165.g1:A">$A$</span>, <span data-ref="0165.g1:B">$B$</span>, <span data-ref="0165.g1:C">$C$</span>, <span data-ref="0165.g1:D">$D$</span>, <span data-ref="0165.g1:E">$E$</span>, <span data-ref="0165.g1:F">$F$</span> be<br />
proportional, so that, as <span data-ref="0165.g1:A">$A$</span> is to <span data-ref="0165.g1:B">$B$</span>, so is <span data-ref="0165.g1:C">$C$</span> to <span data-ref="0165.g1:D">$D$</span> and <span data-ref="0165.g1:E">$E$</span><br />
to <span data-ref="0165.g1:F">$F$</span>;<br />
I say that, as <span data-ref="0165.g1:A">$A$</span> is to <span data-ref="0165.g1:B">$B$</span>, so are <span data-ref="0165.g1:A">$A$</span>, <span data-ref="0165.g1:C">$C$</span>, <span data-ref="0165.g1:E">$E$</span> to <span data-ref="0165.g1:B">$B$</span>, <span data-ref="0165.g1:D">$D$</span>, <span data-ref="0165.g1:F">$F$</span>.

![Proposition 12 diagram](0165.g1.svg)

For of <span data-ref="0165.g1:A">$A$</span>, <span data-ref="0165.g1:C">$C$</span>, <span data-ref="0165.g1:E">$E$</span> let equimultiples <span data-ref="0165.g1:G">$G$</span>, <span data-ref="0165.g1:H">$H$</span>, <span data-ref="0165.g1:K">$K$</span> be taken,<br />
and of <span data-ref="0165.g1:B">$B$</span>, <span data-ref="0165.g1:D">$D$</span>, <span data-ref="0165.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0165.g1:L">$L$</span>, <span data-ref="0165.g1:M">$M$</span>, <span data-ref="0165.g1:N">$N$</span>.

Then since, as <span data-ref="0165.g1:A">$A$</span> is to <span data-ref="0165.g1:B">$B$</span>, so is <span data-ref="0165.g1:C">$C$</span> to <span data-ref="0165.g1:D">$D$</span>, and <span data-ref="0165.g1:E">$E$</span> to <span data-ref="0165.g1:F">$F$</span>,<br />
and of <span data-ref="0165.g1:A">$A$</span>, <span data-ref="0165.g1:C">$C$</span>, <span data-ref="0165.g1:E">$E$</span> equimultiples <span data-ref="0165.g1:G">$G$</span>, <span data-ref="0165.g1:H">$H$</span>, <span data-ref="0165.g1:K">$K$</span> have been taken,<br />
and of <span data-ref="0165.g1:B">$B$</span>, <span data-ref="0165.g1:D">$D$</span>, <span data-ref="0165.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0165.g1:L">$L$</span>, <span data-ref="0165.g1:M">$M$</span>, <span data-ref="0165.g1:N">$N$</span>,

<p class="assertion">therefore, if <span data-ref="0165.g1:G">$G$</span> is in excess of <span data-ref="0165.g1:L">$L$</span>, <span data-ref="0165.g1:H">$H$</span> is also in excess of <span data-ref="0165.g1:M">$M$</span>,<br />
and <span data-ref="0165.g1:K">$K$</span> of <span data-ref="0165.g1:N">$N$</span>,<br />
if equal, equal,<br />
and if less, less;</p>

<p class="assertion">so that, in addition,<br />
if <span data-ref="0165.g1:G">$G$</span> is in excess of <span data-ref="0165.g1:L">$L$</span>, then <span data-ref="0165.g1:G">$G$</span>, <span data-ref="0165.g1:H">$H$</span>, <span data-ref="0165.g1:K">$K$</span> are in excess of <span data-ref="0165.g1:L">$L$</span>, <span data-ref="0165.g1:M">$M$</span>, <span data-ref="0165.g1:N">$N$</span>,<br />
if equal, equal,<br />
and if less, less.</p>
