Algebraically, if
$$\begin{aligned}
a : b &= c : d, \\
\text{and}\qquad c : d &= e : f, \\
\text{then}\qquad a : b &= e : f.
\end{aligned}$$

The idiomatic use of the imperfect in quoting a result previously obtained is noteworthy. Instead of saying "But *it was proved that*, if <span data-ref="0164.g1:H">$H$</span> is in excess of <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:G">$G$</span> is also in excess of <span data-ref="0164.g1:L">$L$</span>," the Greek text has "But if <span data-ref="0164.g1:H">$H$</span> *was* in excess of <span data-ref="0164.g1:M">$M$</span>, <span data-ref="0164.g1:G">$G$</span> *was* also in excess of <span data-ref="0164.g1:L">$L$</span>," ἀλλὰ εἰ ὑπερεῖχε τὸ Θ τοῦ Μ, ὑπερεῖχε καὶ τὸ Η τοῦ Λ.

This proposition is tacitly used in combination with V. 16 and V. 24 in the geometrical passage in Aristotle, *Meteorologica* III. 5, 376 a 22—26.

## PROPOSITION 12.

*If any number of magnitudes be proportional, as one of the antecedents is to one of the consequents, so will all the antecedents be to all the consequents.*

Let any number of magnitudes <span data-ref="0165.g1:A">$A$</span>, <span data-ref="0165.g1:B">$B$</span>, <span data-ref="0165.g1:C">$C$</span>, <span data-ref="0165.g1:D">$D$</span>, <span data-ref="0165.g1:E">$E$</span>, <span data-ref="0165.g1:F">$F$</span> be proportional, so that, as <span data-ref="0165.g1:A">$A$</span> is to <span data-ref="0165.g1:B">$B$</span>, so is <span data-ref="0165.g1:C">$C$</span> to <span data-ref="0165.g1:D">$D$</span> and <span data-ref="0165.g1:E">$E$</span> to <span data-ref="0165.g1:F">$F$</span>;
I say that, as <span data-ref="0165.g1:A">$A$</span> is to <span data-ref="0165.g1:B">$B$</span>, so are <span data-ref="0165.g1:A">$A$</span>, <span data-ref="0165.g1:C">$C$</span>, <span data-ref="0165.g1:E">$E$</span> to <span data-ref="0165.g1:B">$B$</span>, <span data-ref="0165.g1:D">$D$</span>, <span data-ref="0165.g1:F">$F$</span>.

![Proposition 12 diagram](0165.g1.svg)

For of <span data-ref="0165.g1:A">$A$</span>, <span data-ref="0165.g1:C">$C$</span>, <span data-ref="0165.g1:E">$E$</span> let equimultiples <span data-ref="0165.g1:G">$G$</span>, <span data-ref="0165.g1:H">$H$</span>, <span data-ref="0165.g1:K">$K$</span> be taken,
and of <span data-ref="0165.g1:B">$B$</span>, <span data-ref="0165.g1:D">$D$</span>, <span data-ref="0165.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0165.g1:L">$L$</span>, <span data-ref="0165.g1:M">$M$</span>, <span data-ref="0165.g1:N">$N$</span>.

Then since, as <span data-ref="0165.g1:A">$A$</span> is to <span data-ref="0165.g1:B">$B$</span>, so is <span data-ref="0165.g1:C">$C$</span> to <span data-ref="0165.g1:D">$D$</span>, and <span data-ref="0165.g1:E">$E$</span> to <span data-ref="0165.g1:F">$F$</span>,
and of <span data-ref="0165.g1:A">$A$</span>, <span data-ref="0165.g1:C">$C$</span>, <span data-ref="0165.g1:E">$E$</span> equimultiples <span data-ref="0165.g1:G">$G$</span>, <span data-ref="0165.g1:H">$H$</span>, <span data-ref="0165.g1:K">$K$</span> have been taken,
and of <span data-ref="0165.g1:B">$B$</span>, <span data-ref="0165.g1:D">$D$</span>, <span data-ref="0165.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0165.g1:L">$L$</span>, <span data-ref="0165.g1:M">$M$</span>, <span data-ref="0165.g1:N">$N$</span>,
therefore, if <span data-ref="0165.g1:G">$G$</span> is in excess of <span data-ref="0165.g1:L">$L$</span>, <span data-ref="0165.g1:H">$H$</span> is also in excess of <span data-ref="0165.g1:M">$M$</span>, and <span data-ref="0165.g1:K">$K$</span> of <span data-ref="0165.g1:N">$N$</span>,
if equal, equal,
and if less, less;
so that, in addition,
if <span data-ref="0165.g1:G">$G$</span> is in excess of <span data-ref="0165.g1:L">$L$</span>, then <span data-ref="0165.g1:G">$G$</span>, <span data-ref="0165.g1:H">$H$</span>, <span data-ref="0165.g1:K">$K$</span> are in excess of <span data-ref="0165.g1:L">$L$</span>, <span data-ref="0165.g1:M">$M$</span>, <span data-ref="0165.g1:N">$N$</span>,
if equal, equal,
and if less, less.
