### PROPOSITION 14.

<p class="enunciation">If a first magnitude have to a second the same ratio as a<br />
third has to a fourth, and the first be greater than the third,<br />
the second will also be greater than the fourth ; if equal, equal ;<br />
and if less, less.</p>

For let a first magnitude <span data-ref="0168.g1:A">$A$</span> have the same ratio to a<br />
second <span data-ref="0168.g1:B">$B$</span> as a third <span data-ref="0168.g1:C">$C$</span> has to a fourth <span data-ref="0168.g1:D">$D$</span> ; and let <span data-ref="0168.g1:A">$A$</span> be<br />
greater than <span data-ref="0168.g1:C">$C$</span> ;<br />
I say that <span data-ref="0168.g1:B">$B$</span> is also greater than <span data-ref="0168.g1:D">$D$</span>.

![Proposition 14 diagram](0168.g1.svg)

For, since <span data-ref="0168.g1:A">$A$</span> is greater than <span data-ref="0168.g1:C">$C$</span>,<br />
and <span data-ref="0168.g1:B">$B$</span> is another, chance, magnitude,<br />
<p class="assertion">therefore <span data-ref="0168.g1:A">$A$</span> has to <span data-ref="0168.g1:B">$B$</span> a greater ratio than <span data-ref="0168.g1:C">$C$</span> has to <span data-ref="0168.g1:B">$B$</span>. <span class="justification">[V. 8]</span></p>

But, as <span data-ref="0168.g1:A">$A$</span> is to <span data-ref="0168.g1:B">$B$</span>, so is <span data-ref="0168.g1:C">$C$</span> to <span data-ref="0168.g1:D">$D$</span> ;<br />
<p class="assertion">therefore <span data-ref="0168.g1:C">$C$</span> has also to <span data-ref="0168.g1:D">$D$</span> a greater ratio than <span data-ref="0168.g1:C">$C$</span> has to <span data-ref="0168.g1:B">$B$</span>. <span class="justification">[V. 13]</span></p>

<p class="sub-clause">But that to which the same has a greater ratio is less ; <span class="justification">[V. 10]</span></p>
<p class="assertion">therefore <span data-ref="0168.g1:D">$D$</span> is less than <span data-ref="0168.g1:B">$B$</span> ;<br />
so that <span data-ref="0168.g1:B">$B$</span> is greater than <span data-ref="0168.g1:D">$D$</span>.</p>

Similarly we can prove that, if <span data-ref="0168.g1:A">$A$</span> be equal to <span data-ref="0168.g1:C">$C$</span>, <span data-ref="0168.g1:B">$B$</span> will<br />
also be equal to <span data-ref="0168.g1:D">$D$</span> ;<br />
and, if <span data-ref="0168.g1:A">$A$</span> be less than <span data-ref="0168.g1:C">$C$</span>, <span data-ref="0168.g1:B">$B$</span> will also be less than <span data-ref="0168.g1:D">$D$</span>.

<p class="qed">Therefore etc.</p>
