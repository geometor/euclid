But, since $a : b = c : d$, therefore, according as $ma > = < nb$, $mc > = < nd$.

And $mc > nd$ ; therefore $ma > nb$, while (from above) $me \ngtr nf$.

.. assertion::

   Therefore $a : b > e : f$.

:person:`Simson <simson>` adds as a corollary the following :

"If the first have a greater ratio to the second than the third has to the fourth, but the third the same ratio to the fourth which the fifth has to the sixth, it may be demonstrated in like manner that the first has a greater ratio to the second than the fifth has to the sixth."

This however scarcely seems to be worth separate statement, since it only amounts to changing the order of the two parts of the hypothesis.

----

PROPOSITION 14.
---------------

.. enunciation::

   If a first magnitude have to a second the same ratio as a third has to a fourth, and the first be greater than the third, the second will also be greater than the fourth ; if equal, equal ; and if less, less.

For let a first magnitude :g:`A <0168.g1:A>` have the same ratio to a second :g:`B <0168.g1:B>` as a third :g:`C <0168.g1:C>` has to a fourth :g:`D <0168.g1:D>` ; and let :g:`A <0168.g1:A>` be greater than :g:`C <0168.g1:C>` ;

I say that :g:`B <0168.g1:B>` is also greater than :g:`D <0168.g1:D>`.

.. picture:: 0168.g1.svg
   :alt: Proposition 14 diagram

For, since :g:`A <0168.g1:A>` is greater than :g:`C <0168.g1:C>`, and :g:`B <0168.g1:B>` is another, chance, magnitude,

.. assertion:: [V. 8] <V.8>

   therefore :g:`A <0168.g1:A>` has to :g:`B <0168.g1:B>` a greater ratio than :g:`C <0168.g1:C>` has to :g:`B <0168.g1:B>`.

But, as :g:`A <0168.g1:A>` is to :g:`B <0168.g1:B>`, so is :g:`C <0168.g1:C>` to :g:`D <0168.g1:D>` ; 

.. assertion:: [V. 13] <V.13>

   therefore :g:`C <0168.g1:C>` has also to :g:`D <0168.g1:D>` a greater ratio than :g:`C <0168.g1:C>` has to :g:`B <0168.g1:B>`.

.. subclause:: [V. 10] <V.10>

   But that to which the same has a greater ratio is less ;

.. assertion::

   therefore :g:`D <0168.g1:D>` is less than :g:`B <0168.g1:B>` ; so that :g:`B <0168.g1:B>` is greater than :g:`D <0168.g1:D>`.

Similarly we can prove that, if :g:`A <0168.g1:A>` be :eq:`equal <0168.g1:A = 0168.g1:C>` to :g:`C <0168.g1:C>`, :g:`B <0168.g1:B>` will also be :eq:`equal <0168.g1:B = 0168.g1:D>` to :g:`D <0168.g1:D>` ; and, if :g:`A <0168.g1:A>` be less than :g:`C <0168.g1:C>`, :g:`B <0168.g1:B>` will also be less than :g:`D <0168.g1:D>`.

.. qed::

   Therefore etc.
