### PROPOSITION 16.

<p class="enunciation">If four magnitudes be proportional, they will also be<br />
proportional alternately.</p>

Let <span data-ref="0170.g1:A">$A$</span>, <span data-ref="0170.g1:B">$B$</span>, <span data-ref="0170.g1:C">$C$</span>, <span data-ref="0170.g1:D">$D$</span> be four proportional magnitudes,
so that, as <span data-ref="0170.g1:A">$A$</span> is to <span data-ref="0170.g1:B">$B$</span>, so is <span data-ref="0170.g1:C">$C$</span> to <span data-ref="0170.g1:D">$D$</span>;
I say that they will also be so alternately, that is, as <span data-ref="0170.g1:A">$A$</span> is to <span data-ref="0170.g1:C">$C$</span>, so is <span data-ref="0170.g1:B">$B$</span> to <span data-ref="0170.g1:D">$D$</span>.

![Proposition 16 diagram](0170.g1.svg)

For of <span data-ref="0170.g1:A">$A$</span>, <span data-ref="0170.g1:B">$B$</span> let equimultiples <span data-ref="0170.g1:E">$E$</span>, <span data-ref="0170.g1:F">$F$</span> be taken,
and of <span data-ref="0170.g1:C">$C$</span>, <span data-ref="0170.g1:D">$D$</span> other, chance, equimultiples <span data-ref="0170.g1:G">$G$</span>, <span data-ref="0170.g1:H">$H$</span>.

Then, since <span data-ref="0170.g1:E">$E$</span> is the same multiple of <span data-ref="0170.g1:A">$A$</span> that <span data-ref="0170.g1:F">$F$</span> is of <span data-ref="0170.g1:B">$B$</span>,
and parts have the same ratio as the same multiples of them, [V. 15]
therefore, as <span data-ref="0170.g1:A">$A$</span> is to <span data-ref="0170.g1:B">$B$</span>, so is <span data-ref="0170.g1:E">$E$</span> to <span data-ref="0170.g1:F">$F$</span>.

But as <span data-ref="0170.g1:A">$A$</span> is to <span data-ref="0170.g1:B">$B$</span>, so is <span data-ref="0170.g1:C">$C$</span> to <span data-ref="0170.g1:D">$D$</span>;
therefore also, as <span data-ref="0170.g1:C">$C$</span> is to <span data-ref="0170.g1:D">$D$</span>, so is <span data-ref="0170.g1:E">$E$</span> to <span data-ref="0170.g1:F">$F$</span>. [V. 11]

Again, since <span data-ref="0170.g1:G">$G$</span>, <span data-ref="0170.g1:H">$H$</span> are equimultiples of <span data-ref="0170.g1:C">$C$</span>, <span data-ref="0170.g1:D">$D$</span>,
therefore, as <span data-ref="0170.g1:C">$C$</span> is to <span data-ref="0170.g1:D">$D$</span>, so is <span data-ref="0170.g1:G">$G$</span> to <span data-ref="0170.g1:H">$H$</span>. [V. 15]

But, as <span data-ref="0170.g1:C">$C$</span> is to <span data-ref="0170.g1:D">$D$</span>, so is <span data-ref="0170.g1:E">$E$</span> to <span data-ref="0170.g1:F">$F$</span>;
therefore also, as <span data-ref="0170.g1:E">$E$</span> is to <span data-ref="0170.g1:F">$F$</span>, so is <span data-ref="0170.g1:G">$G$</span> to <span data-ref="0170.g1:H">$H$</span>. [V. 11]

<p class="sub-clause">But, if four magnitudes be proportional, and the first be<br />
greater than the third,<br />
the second will also be greater than the fourth ;<br />
if equal, equal ;<br />
and if less, less. <span class="justification">[V. 14]</span></p>

Therefore, if <span data-ref="0170.g1:E">$E$</span> is in excess of <span data-ref="0170.g1:G">$G$</span>, <span data-ref="0170.g1:F">$F$</span> is also in excess of <span data-ref="0170.g1:H">$H$</span>,
if equal, equal,
and if less, less.
