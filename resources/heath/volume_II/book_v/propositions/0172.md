\text{Therefore} \qquad \text{rect. } ac : \text{rect. } ag &= bc : bg, \\
\text{and} \qquad \text{rect. } be : \text{rect. } bk &= bc : bg. && [\text{VI. 1}] \\
\text{Therefore} \qquad \text{rect. } ac : \text{rect. } ag &= \text{rect. } be : \text{rect. } bk. && [\text{V. 11}] \\

\end{aligned}$$

and Cd : De = CD : DE. [VI. 1] <br />
But AB : BC = CD : DE. <br />

Hence, by the first case,

$$Ab : Cd = Bc : De,$$

and, since these rectangles have the same height,

$$AB : CD = BC : DE.$$

### PROPOSITION 17.

<p class="enunciation">If magnitudes be proportional componendo, they will also<br />
be proportional separando.</p>

Let $AB$, <span data-ref="0173.g1:/ E B /">$BE$</span>, <span data-ref="0173.g1:/ C D /">$CD$</span>, <span data-ref="0173.g1:/ F D /">$DF$</span> be magnitudes proportional *com-<br />
ponendo*, so that, as <span data-ref="0173.g1:/ A B /">$AB$</span> is to <span data-ref="0173.g1:/ E B /">$BE$</span>, so is <span data-ref="0173.g1:/ C D /">$CD$</span> to <span data-ref="0173.g1:/ F D /">$DF$</span>;<br />
I say that they will also be proportional *separando*, that is,<br />
as <span data-ref="0173.g1:/ A E /">$AE$</span> is to <span data-ref="0173.g1:/ E B /">$EB$</span>, so is <span data-ref="0173.g1:/ C F /">$CF$</span> to <span data-ref="0173.g1:/ F D /">$DF$</span>.

For of <span data-ref="0173.g1:/ A E /">$AE$</span>, <span data-ref="0173.g1:/ E B /">$EB$</span>, <span data-ref="0173.g1:/ C F /">$CF$</span>, <span data-ref="0173.g1:/ F D /">$FD$</span> let equimultiples <span data-ref="0173.g1:/ G H /">$GH$</span>, <span data-ref="0173.g1:/ H K /">$HK$</span>,<br />
<span data-ref="0173.g1:/ L M /">$LM$</span>, <span data-ref="0173.g1:/ M N /">$MN$</span> be taken,<br />
and of <span data-ref="0173.g1:/ E B /">$EB$</span>, <span data-ref="0173.g1:/ F D /">$FD$</span> other, chance, equimultiples, <span data-ref="0173.g1:/ K O /">$KO$</span>, <span data-ref="0173.g1:/ N P /">$NP$</span>.
