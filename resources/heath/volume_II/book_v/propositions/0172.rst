$$\begin{aligned}
\text{Therefore} \qquad \text{rect. } ac : \text{rect. } ag &= bc : bg, \\
\text{and} \qquad \text{rect. } be : \text{rect. } bk &= bc : bg. && [\text{VI. 1}] \\
\text{Therefore} \qquad \text{rect. } ac : \text{rect. } ag &= \text{rect. } be : \text{rect. } bk. && [\text{V. 11}] \\
\text{That is,} \qquad P : R &= Q : S.
\end{aligned}$$

   | Then Ab : Bc = :g:`$AB$ <0173.g1:/ A B />` : BC,
   | and Cd : De = CD : DE. [VI. 1]
   | But AB : BC = CD : DE.
   | Therefore Ab : Bc = Cd : De. [V. 11]

Hence, by the first case,

$$Ab : Cd = Bc : De,$$

and, since these rectangles have the same height,

$$AB : CD = BC : DE.$$

PROPOSITION 17.
---------------

.. enunciation::

   If magnitudes be proportional componendo, they will also be proportional separando.

| Let $AB$, :g:`$BE$ <0173.g1:/ E B />`, :g:`$CD$ <0173.g1:/ C D />`, :g:`$DF$ <0173.g1:/ F D />` be magnitudes proportional *com-
| ponendo*, so that, as :g:`$AB$ <0173.g1:/ A B />` is to :g:`$BE$ <0173.g1:/ E B />`, so is :g:`$CD$ <0173.g1:/ C D />` to :g:`$DF$ <0173.g1:/ F D />`;
| I say that they will also be proportional :term:`*separando* <separando>`, that is,
| as :g:`$AE$ <0173.g1:/ A E />` is to :g:`$EB$ <0173.g1:/ E B />`, so is :g:`$CF$ <0173.g1:/ C F />` to :g:`$DF$ <0173.g1:/ F D />`.

| For of :g:`$AE$ <0173.g1:/ A E />`, :g:`$EB$ <0173.g1:/ E B />`, :g:`$CF$ <0173.g1:/ C F />`, :g:`$FD$ <0173.g1:/ F D />` let equimultiples :g:`$GH$ <0173.g1:/ G H />`, :g:`$HK$ <0173.g1:/ H K />`,
| :g:`$LM$ <0173.g1:/ L M />`, :g:`$MN$ <0173.g1:/ M N />` be taken,
| and of :g:`$EB$ <0173.g1:/ E B />`, :g:`$FD$ <0173.g1:/ F D />` other, chance, equimultiples, :g:`$KO$ <0173.g1:/ K O />`, :g:`$NP$ <0173.g1:/ N P />`.
