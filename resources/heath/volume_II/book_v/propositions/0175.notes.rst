2. Textual, Lexical & Mathematical Observations
-----------------------------------------------

- **Euclid's Proof of V. 18 by** *Reductio ad Absurdum*:

  - Given $AE : EB = CF : FD$, Euclid assumes that if $AB : BE \neq CD : FD$, then $AB : BE = CD : DG$ where $DG < FD$ (or $DG > FD$).
  - Applying V. 17 (*separando*) to $AB : BE = CD : DG$ gives $AE : EB = CG : GD$, which by V. 11 yields $CG : GD = CF : FD$.
  - Since $DG < FD$, the remainder $CG > CF$, so by V. 14 $GD > FD$, contradicting $GD < FD$.
