$$\begin{aligned}
\text{Clearly, if} \qquad nb &\text{ is greater than } mb, \\
nd &\text{ is greater than } md;
\end{aligned}$$

if equal, equal; and if less, less.

I. Suppose $nb$ not greater than $mb$, so that $nd$ is also not greater than $md$.

$$\begin{aligned}
\text{Now} \qquad m(a + b) &\text{ is greater than } mb: \\
\text{therefore} \qquad m(a + b) &\text{ is greater than } nb. \\
\text{Similarly} \qquad m(c + d) &\text{ is greater than } nd.
\end{aligned}$$

II. Suppose $nb$ greater than $mb$.

Since $m(a + b), mb, m(c + d), md$ are equimultiples of $(a + b), b, (c + d), d$,
$ma$ is the same multiple of $a$ that $m(a + b)$ is of $(a + b)$,
and $mc$ is the same multiple of $c$ that $m(c + d)$ is of $(c + d)$,
so that $ma, mc$ are equimultiples of $a, c$. [V. 5]

Again $nb, nd$ are equimultiples of $b, d$,
and so are $mb, md$;
therefore $(n - m)b, (n - m)d$ are equimultiples of $b, d$ and, whether $n - m$ is equal to unity or to any other integer [V. 6], it follows, by Def. 5, that, since $a, b, c, d$ are proportionals,

$$\begin{aligned}
\text{if} \qquad ma &\text{ is greater than } (n - m)b, \\
\text{then} \qquad mc &\text{ is greater than } (n - m)d;
\end{aligned}$$

if equal, equal; and if less, less.

(1) If now $m(a + b)$ is greater than $nb$, subtracting $mb$ from each, we have

$$\begin{aligned}
ma &\text{ is greater than } (n - m)b; \\
\text{therefore} \qquad mc &\text{ is greater than } (n - m)d,
\end{aligned}$$

and, if we add $md$ to each,

$$m(c + d) \text{ is greater than } nd.$$

(2) Similarly it may be proved that,

$$\begin{aligned}
\text{if} \qquad m(a + b) &\text{ is equal to } nb, \\
\text{then} \qquad m(c + d) &\text{ is equal to } nd, \\
\text{and (3) that, if} \qquad m(a + b) &\text{ is less than } nb, \\
\text{then} \qquad m(c + d) &\text{ is less than } nd.
\end{aligned}$$

But (under I. above) it was proved that, in the case where $nb$ is not greater than $mb$,

$$\begin{aligned}
m(a + b) &\text{ is always greater than } nb, \\
\text{and} \qquad m(c + d) &\text{ is always greater than } nd.
\end{aligned}$$

Hence, whatever be the values of $m$ and $n$, $m(c + d)$ is always greater than, equal to, or less than $nd$ according as $m(a + b)$ is greater than, equal to, or less than $nb$.

Therefore, by Def. 5,

$$a + b \text{ is to } b \text{ as } c + d \text{ is to } d.$$
