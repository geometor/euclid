For, because <span data-ref="0179.g1:/ A E /">$AE$</span> is to <span data-ref="0179.g1:/ E B /">$EB$</span> as <span data-ref="0179.g1:/ C F /">$CF$</span> is to <span data-ref="0179.g1:/ F D /">$FD$</span>,
therefore, alternately,
$$AE \text{ is to } CF \text{ as } EB \text{ is to } FD. \quad [\text{V. } 16]$$
And, as one of the antecedents is to its consequent, so is the sum of the antecedents to the sum of the consequents: $[\text{V. } 12]$
therefore, as <span data-ref="0179.g1:/ E B /">$EB$</span> is to <span data-ref="0179.g1:/ F D /">$FD$</span>, so are <span data-ref="0179.g1:/ A E /">$AE$</span>, <span data-ref="0179.g1:/ E B /">$EB$</span> together to <span data-ref="0179.g1:/ C F /">$CF$</span>, <span data-ref="0179.g1:/ F D /">$FD$</span> together;
that is,
$$AB \text{ is to } CD \text{ as } EB \text{ is to } FD.$$
Therefore, alternately,
$$AB \text{ is to } BE \text{ as } CD \text{ is to } FD.\text{''}$$

![Simson's proof for V. 18](0179.g1.svg)

The objection to this proof is that it is only valid in the case where the proposition V. 16 used in it is valid, i.e. where all four magnitudes are of the same kind.

Smith and Bryant's proof avails where all four magnitudes are straight lines, where all four magnitudes are rectilineal areas, or where one antecedent and its consequent are straight lines and the other antecedent and its consequent rectilineal areas.

Suppose that
$$A : B = C : D.$$

*First*, let all the magnitudes be areas.
Construct a rectangle <span data-ref="0179.g2:< a b c d >">$abcd$</span> equal to <span data-ref="0179.g2:< a b c d >">$A$</span>, and to <span data-ref="0179.g2:/ c b /">$bc$</span> apply the rectangle <span data-ref="0179.g2:< b c e f >">$bcef$</span> equal to <span data-ref="0179.g2:< b c e f >">$B$</span>.
Also to <span data-ref="0179.g2:/ a b /">$ab$</span>, <span data-ref="0179.g2:/ b f /">$bf$</span> apply the rectangles <span data-ref="0179.g2:< a b g h >">$ag$</span>, <span data-ref="0179.g2:< b f k g >">$bk$</span> equal to <span data-ref="0179.g2:< a b g h >">$C$</span>, <span data-ref="0179.g2:< b f k g >">$D$</span> respectively.

![Smith and Bryant's proof for V. 18](0179.g2.svg)

Then, since the rectangles <span data-ref="0179.g2:< a b c d >">$ac$</span>, <span data-ref="0179.g2:< b c e f >">$be$</span> have equal heights <span data-ref="0179.g2:/ c b /">$bc$</span>, they are to one another as their bases. $[\text{VI. } 1]$
Hence
$$\begin{aligned}
ab : bf &= \text{rect. } ac : \text{rect. } be \\
&= A : B \\
&= C : D \\
&= \text{rect. } ag : \text{rect. } bk.
\end{aligned}$$

Therefore $[\text{VI. } 1\text{, converse}]$ the rectangles <span data-ref="0179.g2:< a b g h >">$ag$</span>, <span data-ref="0179.g2:< b f k g >">$bk$</span> have the same height, so that <span data-ref="0179.g2:k">$k$</span> is on the straight line <span data-ref="0179.g2:/ h g /">$hg$</span>.
Hence
$$\begin{aligned}
A + B : B &= \text{rect. } ae : \text{rect. } be \\
&= af : bf \\
&= \text{rect. } ak : \text{rect. } bk \\
&= C + D : D.
\end{aligned}$$

*Secondly*, let the magnitudes <span data-ref="0179.g2:/ a b /">$A$</span>, <span data-ref="0179.g2:/ b f /">$B$</span> be straight lines and the magnitudes <span data-ref="0179.g2:< a b g h >">$C$</span>, <span data-ref="0179.g2:< b f k g >">$D$</span> areas.
Let <span data-ref="0179.g2:/ a b /">$ab$</span>, <span data-ref="0179.g2:/ b f /">$bf$</span> be equal to the straight lines <span data-ref="0179.g2:/ a b /">$A$</span>, <span data-ref="0179.g2:/ b f /">$B$</span>, and to <span data-ref="0179.g2:/ a b /">$ab$</span>, <span data-ref="0179.g2:/ b f /">$bf$</span> apply the rectangles <span data-ref="0179.g2:< a b g h >">$ag$</span>, <span data-ref="0179.g2:< b f k g >">$bk$</span> equal to <span data-ref="0179.g2:< a b g h >">$C$</span>, <span data-ref="0179.g2:< b f k g >">$D$</span> respectively.
Then, as before, the rectangles <span data-ref="0179.g2:< a b g h >">$ag$</span>, <span data-ref="0179.g2:< b f k g >">$bk$</span> have the same height.
Now
$$\begin{aligned}
A + B : B &= af : bf \\
&= \text{rect. } ak : \text{rect. } bk \\
&= C + D : D.
\end{aligned}$$
