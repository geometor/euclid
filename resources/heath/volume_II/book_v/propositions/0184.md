### PROPOSITION 21.

*If there be three magnitudes, and others equal to them in multitude, which taken two and two together are in the same ratio, and the proportion of them be perturbed, then, if* ex aequali *the first magnitude is greater than the third, the fourth will also be greater than the sixth; if equal, equal; and if less, less.*

Let there be three magnitudes <span data-ref="0184.g1:A">$A$</span>, <span data-ref="0184.g1:B">$B$</span>, <span data-ref="0184.g1:C">$C$</span>, and others <span data-ref="0184.g1:D">$D$</span>, <span data-ref="0184.g1:E">$E$</span>, <span data-ref="0184.g1:F">$F$</span> equal to them in multitude, which taken two and two are in the same ratio, and let the proportion of them be perturbed, so that,
as <span data-ref="0184.g1:A">$A$</span> is to <span data-ref="0184.g1:B">$B$</span>, so is <span data-ref="0184.g1:E">$E$</span> to <span data-ref="0184.g1:F">$F$</span>,
and,
as <span data-ref="0184.g1:B">$B$</span> is to <span data-ref="0184.g1:C">$C$</span>, so is <span data-ref="0184.g1:D">$D$</span> to <span data-ref="0184.g1:E">$E$</span>,
and let <span data-ref="0184.g1:A">$A$</span> be greater than <span data-ref="0184.g1:C">$C$</span> *ex aequali*;
I say that <span data-ref="0184.g1:D">$D$</span> will also be greater than <span data-ref="0184.g1:F">$F$</span>; if <span data-ref="0184.g1:A">$A$</span> is equal to <span data-ref="0184.g1:C">$C$</span>, equal; and if less, less.

![Proposition 21](0184.g1.svg)

For, since <span data-ref="0184.g1:A">$A$</span> is greater than <span data-ref="0184.g1:C">$C$</span>,
and <span data-ref="0184.g1:B">$B$</span> is some other magnitude,
therefore <span data-ref="0184.g1:A">$A$</span> has to <span data-ref="0184.g1:B">$B$</span> a greater ratio than <span data-ref="0184.g1:C">$C$</span> has to <span data-ref="0184.g1:B">$B$</span>. $[\text{V. } 8]$

But, as <span data-ref="0184.g1:A">$A$</span> is to <span data-ref="0184.g1:B">$B$</span>, so is <span data-ref="0184.g1:E">$E$</span> to <span data-ref="0184.g1:F">$F$</span>,
and, as <span data-ref="0184.g1:C">$C$</span> is to <span data-ref="0184.g1:B">$B$</span>, inversely, so is <span data-ref="0184.g1:E">$E$</span> to <span data-ref="0184.g1:D">$D$</span>.
Therefore also <span data-ref="0184.g1:E">$E$</span> has to <span data-ref="0184.g1:F">$F$</span> a greater ratio than <span data-ref="0184.g1:E">$E$</span> has to <span data-ref="0184.g1:D">$D$</span>. $[\text{V. } 13]$

But that to which the same has a greater ratio is less; $[\text{V. } 10]$
therefore <span data-ref="0184.g1:F">$F$</span> is less than <span data-ref="0184.g1:D">$D$</span>;
therefore <span data-ref="0184.g1:D">$D$</span> is greater than <span data-ref="0184.g1:F">$F$</span>.
