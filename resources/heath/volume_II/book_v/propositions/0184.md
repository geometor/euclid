### PROPOSITION 21.

<p class="enunciation">If there be three magnitudes, and others equal to them in<br />
multitude, which taken two and two together are in the same<br />
ratio, and the proportion of them be perturbed, then, if ex<br />
aequali the first magnitude is greater than the third, the<br />
fourth will also be greater than the sixth; if equal, equal;<br />
and if less, less.</p>

Let there be three magnitudes <span data-ref="0184.g1:A">$A$</span>, <span data-ref="0184.g1:B">$B$</span>, <span data-ref="0184.g1:C">$C$</span>, and others <span data-ref="0184.g1:D">$D$</span>, <span data-ref="0184.g1:E">$E$</span>, <span data-ref="0184.g1:F">$F$</span><br />
equal to them in multitude, which taken two and two are in<br />
the same ratio, and let the proportion of them be perturbed,<br />
so that,
<p class="assertion">as <span data-ref="0184.g1:A">$A$</span> is to <span data-ref="0184.g1:B">$B$</span>, so is <span data-ref="0184.g1:E">$E$</span> to <span data-ref="0184.g1:F">$F$</span>,</p>
<p class="assertion">and, as <span data-ref="0184.g1:B">$B$</span> is to <span data-ref="0184.g1:C">$C$</span>, so is <span data-ref="0184.g1:D">$D$</span> to <span data-ref="0184.g1:E">$E$</span>,</p>
and let <span data-ref="0184.g1:A">$A$</span> be greater than <span data-ref="0184.g1:C">$C$</span> *ex aequali*;<br />
I say that <span data-ref="0184.g1:D">$D$</span> will also be greater than <span data-ref="0184.g1:F">$F$</span>; if <span data-ref="0184.g1:A">$A$</span> is equal to<br />
<span data-ref="0184.g1:C">$C$</span>, equal; and if less, less.

![Proposition 21](0184.g1.svg)

For, since <span data-ref="0184.g1:A">$A$</span> is greater than <span data-ref="0184.g1:C">$C$</span>,<br />
and <span data-ref="0184.g1:B">$B$</span> is some other magnitude,
<p class="assertion">therefore <span data-ref="0184.g1:A">$A$</span> has to <span data-ref="0184.g1:B">$B$</span> a greater ratio than <span data-ref="0184.g1:C">$C$</span> has to <span data-ref="0184.g1:B">$B$</span>. <span class="justification">[V. 8]</span></p>

But, as <span data-ref="0184.g1:A">$A$</span> is to <span data-ref="0184.g1:B">$B$</span>, so is <span data-ref="0184.g1:E">$E$</span> to <span data-ref="0184.g1:F">$F$</span>,<br />
and, as <span data-ref="0184.g1:C">$C$</span> is to <span data-ref="0184.g1:B">$B$</span>, inversely, so is <span data-ref="0184.g1:E">$E$</span> to <span data-ref="0184.g1:D">$D$</span>.<br />
<p class="assertion">Therefore also <span data-ref="0184.g1:E">$E$</span> has to <span data-ref="0184.g1:F">$F$</span> a greater ratio than <span data-ref="0184.g1:E">$E$</span> has to <span data-ref="0184.g1:D">$D$</span>. <span class="justification">[V. 13]</span></p>

<p class="sub-clause">But that to which the same has a greater ratio is less; <span class="justification">[V. 10]</span></p>
<p class="assertion">therefore <span data-ref="0184.g1:F">$F$</span> is less than <span data-ref="0184.g1:D">$D$</span>;</p>
<p class="assertion">therefore <span data-ref="0184.g1:D">$D$</span> is greater than <span data-ref="0184.g1:F">$F$</span>.</p>
