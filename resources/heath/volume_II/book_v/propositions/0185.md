Algebraically, if
$$\begin{aligned}
& a : b = e : f, \\
\text{and} \quad & b : c = d : e,
\end{aligned}$$
$$\text{then, according as } a > = < c, \quad d > = < f.$$

Simson's alterations correspond to those which he makes in Prop. 20. After<br />
the first case he proceeds thus.

"Secondly, let <span data-ref="0184.g1:A">$A$</span> be equal to <span data-ref="0184.g1:C">$C$</span>; then shall <span data-ref="0184.g1:D">$D$</span> be equal to <span data-ref="0184.g1:F">$F$</span>.
Because <span data-ref="0184.g1:A">$A$</span> and <span data-ref="0184.g1:C">$C$</span> are equal,

and, in like manner,
<span data-ref="0184.g1:B">$B$</span> is to <span data-ref="0184.g1:A">$A$</span> as <span data-ref="0184.g1:F">$F$</span> to <span data-ref="0184.g1:E">$E$</span>;
therefore <span data-ref="0184.g1:F">$F$</span> is greater than <span data-ref="0184.g1:D">$D$</span>, by the first case,

The proof may be shown thus.
$$\text{According as } a > = < c, \quad a : b > = < c : b.$$
But $a : b = e : f$, and, by inversion, $c : b = e : d$.<br />
$$\begin{aligned}
\text{Therefore, according as } a > = < c, \quad & e : f > = < e : d, \\
\text{and therefore } & d > = < f.
\end{aligned}$$

### PROPOSITION 22.

<p class="enunciation">If there be any number of magnitudes whatever, and others<br />
equal to them in multitude, which taken two and two together<br />
are in the same ratio, they will also be in the same ratio ex<br />
aequali.</p>

Let there be any number of magnitudes <span data-ref="0186.g1:A">$A$</span>, <span data-ref="0186.g1:B">$B$</span>, <span data-ref="0186.g1:C">$C$</span>, and others <span data-ref="0186.g1:D">$D$</span>, <span data-ref="0186.g1:E">$E$</span>, <span data-ref="0186.g1:F">$F$</span> equal to them in multitude, which taken two and two together are in the same ratio, so that,
as <span data-ref="0186.g1:A">$A$</span> is to <span data-ref="0186.g1:B">$B$</span>, so is <span data-ref="0186.g1:D">$D$</span> to <span data-ref="0186.g1:E">$E$</span>,
and,
as <span data-ref="0186.g1:B">$B$</span> is to <span data-ref="0186.g1:C">$C$</span>, so is <span data-ref="0186.g1:E">$E$</span> to <span data-ref="0186.g1:F">$F$</span>;
I say that they will also be in the same ratio *ex aequali*,
$\langle$that is, as <span data-ref="0186.g1:A">$A$</span> is to <span data-ref="0186.g1:C">$C$</span>, so is <span data-ref="0186.g1:D">$D$</span> to <span data-ref="0186.g1:F">$F$</span>$\rangle$.
