Algebraically, if
$$\begin{aligned}
& a : b = e : f, \\
\text{and} \quad & b : c = d : e,
\end{aligned}$$
$$\text{then, according as } a > = < c, \quad d > = < f.$$

Simson's alterations correspond to those which he makes in Prop. 20. After<br />
the first case he proceeds thus.

"Secondly, let <span data-ref="0184.g1:A">$A$</span> be equal to <span data-ref="0184.g1:C">$C$</span>; then shall <span data-ref="0184.g1:D">$D$</span> be equal to <span data-ref="0184.g1:F">$F$</span>.<br />
Because <span data-ref="0184.g1:A">$A$</span> and <span data-ref="0184.g1:C">$C$</span> are equal,
<p class="assertion"><span data-ref="0184.g1:A">$A$</span> is to <span data-ref="0184.g1:B">$B$</span> as <span data-ref="0184.g1:C">$C$</span> is to <span data-ref="0184.g1:B">$B$</span>. <span class="justification">[V. 7]</span></p>
But <span data-ref="0184.g1:A">$A$</span> is to <span data-ref="0184.g1:B">$B$</span> as <span data-ref="0184.g1:E">$E$</span> is to <span data-ref="0184.g1:F">$F$</span>,<br />
and <span data-ref="0184.g1:C">$C$</span> is to <span data-ref="0184.g1:B">$B$</span> as <span data-ref="0184.g1:E">$E$</span> is to <span data-ref="0184.g1:D">$D$</span>:
<p class="assertion">wherefore <span data-ref="0184.g1:E">$E$</span> is to <span data-ref="0184.g1:F">$F$</span> as <span data-ref="0184.g1:E">$E$</span> to <span data-ref="0184.g1:D">$D$</span>, <span class="justification">[V. 11]</span></p>
<p class="assertion">and therefore <span data-ref="0184.g1:D">$D$</span> is equal to <span data-ref="0184.g1:F">$F$</span>. <span class="justification">[V. 9]</span></p>

Next, let <span data-ref="0184.g1:A">$A$</span> be less than <span data-ref="0184.g1:C">$C$</span>; then shall <span data-ref="0184.g1:D">$D$</span> be less than <span data-ref="0184.g1:F">$F$</span>.<br />
For <span data-ref="0184.g1:C">$C$</span> is greater than <span data-ref="0184.g1:A">$A$</span>,<br />
and, as was shown,
<p class="assertion"><span data-ref="0184.g1:C">$C$</span> is to <span data-ref="0184.g1:B">$B$</span> as <span data-ref="0184.g1:E">$E$</span> to <span data-ref="0184.g1:D">$D$</span>,</p>
and, in like manner,
<p class="assertion"><span data-ref="0184.g1:B">$B$</span> is to <span data-ref="0184.g1:A">$A$</span> as <span data-ref="0184.g1:F">$F$</span> to <span data-ref="0184.g1:E">$E$</span>;</p>
therefore <span data-ref="0184.g1:F">$F$</span> is greater than <span data-ref="0184.g1:D">$D$</span>, by the first case,<br />
and therefore <span data-ref="0184.g1:D">$D$</span> is less than <span data-ref="0184.g1:F">$F$</span>."

The proof may be shown thus.
$$\text{According as } a > = < c, \quad a : b > = < c : b.$$
But $a : b = e : f$, and, by inversion, $c : b = e : d$.<br />
$$\begin{aligned}
\text{Therefore, according as } a > = < c, \quad & e : f > = < e : d, \\
\text{and therefore } & d > = < f.
\end{aligned}$$

### PROPOSITION 22.

<p class="enunciation">If there be any number of magnitudes whatever, and others<br />
equal to them in multitude, which taken two and two together<br />
are in the same ratio, they will also be in the same ratio ex<br />
aequali.</p>

Let there be any number of magnitudes <span data-ref="0186.g1:A">$A$</span>, <span data-ref="0186.g1:B">$B$</span>, <span data-ref="0186.g1:C">$C$</span>, and<br />
others <span data-ref="0186.g1:D">$D$</span>, <span data-ref="0186.g1:E">$E$</span>, <span data-ref="0186.g1:F">$F$</span> equal to them in multitude, which taken two<br />
and two together are in the same ratio, so that,
<p class="assertion">as <span data-ref="0186.g1:A">$A$</span> is to <span data-ref="0186.g1:B">$B$</span>, so is <span data-ref="0186.g1:D">$D$</span> to <span data-ref="0186.g1:E">$E$</span>,</p>
<p class="assertion">and, as <span data-ref="0186.g1:B">$B$</span> is to <span data-ref="0186.g1:C">$C$</span>, so is <span data-ref="0186.g1:E">$E$</span> to <span data-ref="0186.g1:F">$F$</span>;</p>
I say that they will also be in the same ratio *ex aequali*,
<p class="sub-clause">⟨that is, as  <span data-ref="0186.g1:A">$A$</span>  is to  <span data-ref="0186.g1:C">$C$</span>, so is  <span data-ref="0186.g1:D">$D$</span>  to  <span data-ref="0186.g1:F">$F$</span>⟩.</p>
