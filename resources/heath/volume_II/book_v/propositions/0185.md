Algebraically, if
$$\begin{aligned}
& a : b = e : f, \\
\text{and} \quad & b : c = d : e,
\end{aligned}$$
$$\text{then, according as } a > = < c, \quad d > = < f.$$

Simson's alterations correspond to those which he makes in Prop. 20. After the first case he proceeds thus.

"Secondly, let $A$ be equal to $C$; then shall $D$ be equal to $F$.
Because $A$ and $C$ are equal,
$$A \text{ is to } B \text{ as } C \text{ is to } B. \quad [\text{V. } 7]$$
But $A$ is to $B$ as $E$ is to $F$,
and $C$ is to $B$ as $E$ is to $D$:
wherefore $E$ is to $F$ as $E$ to $D$, $[\text{V. } 11]$
and therefore $D$ is equal to $F$. $[\text{V. } 9]$

Next, let $A$ be less than $C$; then shall $D$ be less than $F$.
For $C$ is greater than $A$,
and, as was shown,
$$C \text{ is to } B \text{ as } E \text{ to } D,$$
and, in like manner,
$$B \text{ is to } A \text{ as } F \text{ to } E;$$
therefore $F$ is greater than $D$, by the first case,
and therefore $D$ is less than $F$."

The proof may be shown thus.
$$\text{According as } a > = < c, \quad a : b > = < c : b.$$
But $a : b = e : f$, and, by inversion, $c : b = e : d$.
$$\begin{aligned}
\text{Therefore, according as } a > = < c, \quad & e : f > = < e : d, \\
\text{and therefore } & d > = < f.
\end{aligned}$$

### PROPOSITION 22.

*If there be any number of magnitudes whatever, and others equal to them in multitude, which taken two and two together are in the same ratio, they will also be in the same ratio* ex aequali.

Let there be any number of magnitudes $A$, $B$, $C$, and others $D$, $E$, $F$ equal to them in multitude, which taken two and two together are in the same ratio, so that,
$$\text{as } A \text{ is to } B\text{, so is } D \text{ to } E,$$
and,
$$\text{as } B \text{ is to } C\text{, so is } E \text{ to } F;$$
I say that they will also be in the same ratio *ex aequali*,
$$\langle\text{that is, as } A \text{ is to } C\text{, so is } D \text{ to } F\rangle.$$
