For of <span data-ref="0186.g1:A">$A$</span>, <span data-ref="0186.g1:D">$D$</span> let equimultiples <span data-ref="0186.g1:G">$G$</span>, <span data-ref="0186.g1:H">$H$</span> be taken,
and of <span data-ref="0186.g1:B">$B$</span>, <span data-ref="0186.g1:E">$E$</span> other, chance, equimultiples <span data-ref="0186.g1:K">$K$</span>, <span data-ref="0186.g1:L">$L$</span>;
and, further, of <span data-ref="0186.g1:C">$C$</span>, <span data-ref="0186.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0186.g1:M">$M$</span>, <span data-ref="0186.g1:N">$N$</span>.

![Book V, Proposition 22, Line Segments](0186.g1.svg)

Then, since, as <span data-ref="0186.g1:A">$A$</span> is to <span data-ref="0186.g1:B">$B$</span>, so is <span data-ref="0186.g1:D">$D$</span> to <span data-ref="0186.g1:E">$E$</span>,
and of <span data-ref="0186.g1:A">$A$</span>, <span data-ref="0186.g1:D">$D$</span> equimultiples <span data-ref="0186.g1:G">$G$</span>, <span data-ref="0186.g1:H">$H$</span> have been taken,
and of <span data-ref="0186.g1:B">$B$</span>, <span data-ref="0186.g1:E">$E$</span> other, chance, equimultiples <span data-ref="0186.g1:K">$K$</span>, <span data-ref="0186.g1:L">$L$</span>,
therefore, as <span data-ref="0186.g1:G">$G$</span> is to <span data-ref="0186.g1:K">$K$</span>, so is <span data-ref="0186.g1:H">$H$</span> to <span data-ref="0186.g1:L">$L$</span>. [v. 4]

For the same reason also,
as <span data-ref="0186.g1:K">$K$</span> is to <span data-ref="0186.g1:M">$M$</span>, so is <span data-ref="0186.g1:L">$L$</span> to <span data-ref="0186.g1:N">$N$</span>.

Since, then, there are three magnitudes <span data-ref="0186.g1:G">$G$</span>, <span data-ref="0186.g1:K">$K$</span>, <span data-ref="0186.g1:M">$M$</span>, and others <span data-ref="0186.g1:H">$H$</span>, <span data-ref="0186.g1:L">$L$</span>, <span data-ref="0186.g1:N">$N$</span> equal to them in multitude, which taken two and two together are in the same ratio,
therefore, *ex aequali*, if <span data-ref="0186.g1:G">$G$</span> is in excess of <span data-ref="0186.g1:M">$M$</span>, <span data-ref="0186.g1:H">$H$</span> is also in excess of <span data-ref="0186.g1:N">$N$</span>;
if equal, equal; and if less, less. [v. 20]

And <span data-ref="0186.g1:G">$G$</span>, <span data-ref="0186.g1:H">$H$</span> are equimultiples of <span data-ref="0186.g1:A">$A$</span>, <span data-ref="0186.g1:D">$D$</span>,
and <span data-ref="0186.g1:M">$M$</span>, <span data-ref="0186.g1:N">$N$</span> other, chance, equimultiples of <span data-ref="0186.g1:C">$C$</span>, <span data-ref="0186.g1:F">$F$</span>.

Therefore, as <span data-ref="0186.g1:A">$A$</span> is to <span data-ref="0186.g1:C">$C$</span>, so is <span data-ref="0186.g1:D">$D$</span> to <span data-ref="0186.g1:F">$F$</span>. [v. Def. 5]

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>

---

Euclid enunciates this proposition as true of *any number of magnitudes*<br />
*whatever* forming two sets connected in the manner described, but his proof is<br />
confined to the case where each set consists of three magnitudes only. The<br />
extension to any number of magnitudes is, however, easy, as shown by<br />
Simson.

"Next let there be four magnitudes <span data-ref="0186.g2:A">$A$</span>, <span data-ref="0186.g2:B">$B$</span>, <span data-ref="0186.g2:C">$C$</span>, <span data-ref="0186.g2:D">$D$</span>, and other four <span data-ref="0186.g2:E">$E$</span>, <span data-ref="0186.g2:F">$F$</span>, <span data-ref="0186.g2:G">$G$</span>, <span data-ref="0186.g2:H">$H$</span>, which two and two have the same ratio, viz.:
as <span data-ref="0186.g2:A">$A$</span> is to <span data-ref="0186.g2:B">$B$</span>, so is <span data-ref="0186.g2:E">$E$</span> to <span data-ref="0186.g2:F">$F$</span>,
and as <span data-ref="0186.g2:B">$B$</span> is to <span data-ref="0186.g2:C">$C$</span>, so is <span data-ref="0186.g2:F">$F$</span> to <span data-ref="0186.g2:G">$G$</span>,
and as <span data-ref="0186.g2:C">$C$</span> is to <span data-ref="0186.g2:D">$D$</span>, so is <span data-ref="0186.g2:G">$G$</span> to <span data-ref="0186.g2:H">$H$</span>;
<span data-ref="0186.g2:A">$A$</span> shall be to <span data-ref="0186.g2:D">$D$</span> as <span data-ref="0186.g2:E">$E$</span> to <span data-ref="0186.g2:H">$H$</span>.

![Simson's Four Magnitudes Table](0186.g2.svg)

Because <span data-ref="0186.g2:A">$A$</span>, <span data-ref="0186.g2:B">$B$</span>, <span data-ref="0186.g2:C">$C$</span> are three magnitudes, and <span data-ref="0186.g2:E">$E$</span>, <span data-ref="0186.g2:F">$F$</span>, <span data-ref="0186.g2:G">$G$</span> other three, which taken two and two have the same ratio,
by the foregoing case,
<span data-ref="0186.g2:A">$A$</span> is to <span data-ref="0186.g2:C">$C$</span> as <span data-ref="0186.g2:E">$E$</span> to <span data-ref="0186.g2:G">$G$</span>.
