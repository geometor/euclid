For of <span data-ref="0186.g1:A">$A$</span>, <span data-ref="0186.g1:D">$D$</span> let equimultiples <span data-ref="0186.g1:G">$G$</span>, <span data-ref="0186.g1:H">$H$</span> be taken,<br />
and of <span data-ref="0186.g1:B">$B$</span>, <span data-ref="0186.g1:E">$E$</span> other, chance, equimultiples <span data-ref="0186.g1:K">$K$</span>, <span data-ref="0186.g1:L">$L$</span>;<br />
and, further, of <span data-ref="0186.g1:C">$C$</span>, <span data-ref="0186.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0186.g1:M">$M$</span>, <span data-ref="0186.g1:N">$N$</span>.

![Book V, Proposition 22, Line Segments](0186.g1.svg)

Then, since, as <span data-ref="0186.g1:A">$A$</span> is to <span data-ref="0186.g1:B">$B$</span>, so is <span data-ref="0186.g1:D">$D$</span> to <span data-ref="0186.g1:E">$E$</span>,<br />
and of <span data-ref="0186.g1:A">$A$</span>, <span data-ref="0186.g1:D">$D$</span> equimultiples <span data-ref="0186.g1:G">$G$</span>, <span data-ref="0186.g1:H">$H$</span> have been taken,<br />
and of <span data-ref="0186.g1:B">$B$</span>, <span data-ref="0186.g1:E">$E$</span> other, chance, equimultiples <span data-ref="0186.g1:K">$K$</span>, <span data-ref="0186.g1:L">$L$</span>,
<p class="assertion">therefore, as <span data-ref="0186.g1:G">$G$</span> is to <span data-ref="0186.g1:K">$K$</span>, so is <span data-ref="0186.g1:H">$H$</span> to <span data-ref="0186.g1:L">$L$</span>. <span class="justification">[V. 4]</span></p>

For the same reason also,
<p class="assertion">as <span data-ref="0186.g1:K">$K$</span> is to <span data-ref="0186.g1:M">$M$</span>, so is <span data-ref="0186.g1:L">$L$</span> to <span data-ref="0186.g1:N">$N$</span>.</p>

Since, then, there are three magnitudes <span data-ref="0186.g1:G">$G$</span>, <span data-ref="0186.g1:K">$K$</span>, <span data-ref="0186.g1:M">$M$</span>, and<br />
others <span data-ref="0186.g1:H">$H$</span>, <span data-ref="0186.g1:L">$L$</span>, <span data-ref="0186.g1:N">$N$</span> equal to them in multitude, which taken two<br />
and two together are in the same ratio,
<p class="assertion">therefore, *ex aequali*, if <span data-ref="0186.g1:G">$G$</span> is in excess of <span data-ref="0186.g1:M">$M$</span>, <span data-ref="0186.g1:H">$H$</span> is also in excess<br />
of <span data-ref="0186.g1:N">$N$</span>;<br />
if equal, equal; and if less, less. <span class="justification">[V. 20]</span></p>

And <span data-ref="0186.g1:G">$G$</span>, <span data-ref="0186.g1:H">$H$</span> are equimultiples of <span data-ref="0186.g1:A">$A$</span>, <span data-ref="0186.g1:D">$D$</span>,<br />
and <span data-ref="0186.g1:M">$M$</span>, <span data-ref="0186.g1:N">$N$</span> other, chance, equimultiples of <span data-ref="0186.g1:C">$C$</span>, <span data-ref="0186.g1:F">$F$</span>.

<p class="assertion">Therefore, as <span data-ref="0186.g1:A">$A$</span> is to <span data-ref="0186.g1:C">$C$</span>, so is <span data-ref="0186.g1:D">$D$</span> to <span data-ref="0186.g1:F">$F$</span>. <span class="justification">[V. Def. 5]</span></p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>

---

Euclid enunciates this proposition as true of *any number of magnitudes*<br />
*whatever* forming two sets connected in the manner described, but his proof is<br />
confined to the case where each set consists of three magnitudes only. The<br />
extension to any number of magnitudes is, however, easy, as shown by<br />
Simson.

"Next let there be four magnitudes <span data-ref="0186.g2:A">$A$</span>, <span data-ref="0186.g2:B">$B$</span>, <span data-ref="0186.g2:C">$C$</span>, <span data-ref="0186.g2:D">$D$</span>, and other four <span data-ref="0186.g2:E">$E$</span>, <span data-ref="0186.g2:F">$F$</span>, <span data-ref="0186.g2:G">$G$</span>, <span data-ref="0186.g2:H">$H$</span>,<br />
which two and two have the same ratio, viz.:
<p class="assertion">as <span data-ref="0186.g2:A">$A$</span> is to <span data-ref="0186.g2:B">$B$</span>, so is <span data-ref="0186.g2:E">$E$</span> to <span data-ref="0186.g2:F">$F$</span>,</p>
<p class="assertion">and as <span data-ref="0186.g2:B">$B$</span> is to <span data-ref="0186.g2:C">$C$</span>, so is <span data-ref="0186.g2:F">$F$</span> to <span data-ref="0186.g2:G">$G$</span>,</p>
<p class="assertion">and as <span data-ref="0186.g2:C">$C$</span> is to <span data-ref="0186.g2:D">$D$</span>, so is <span data-ref="0186.g2:G">$G$</span> to <span data-ref="0186.g2:H">$H$</span>;</p>
<span data-ref="0186.g2:A">$A$</span> shall be to <span data-ref="0186.g2:D">$D$</span> as <span data-ref="0186.g2:E">$E$</span> to <span data-ref="0186.g2:H">$H$</span>.

![Simson's Four Magnitudes Table](0186.g2.svg)

Because <span data-ref="0186.g2:A">$A$</span>, <span data-ref="0186.g2:B">$B$</span>, <span data-ref="0186.g2:C">$C$</span> are three magnitudes, and <span data-ref="0186.g2:E">$E$</span>, <span data-ref="0186.g2:F">$F$</span>, <span data-ref="0186.g2:G">$G$</span> other three, which<br />
taken two and two have the same ratio,<br />
by the foregoing case,
<p class="assertion"><span data-ref="0186.g2:A">$A$</span> is to <span data-ref="0186.g2:C">$C$</span> as <span data-ref="0186.g2:E">$E$</span> to <span data-ref="0186.g2:G">$G$</span>.</p>
