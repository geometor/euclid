### PROPOSITION 23.

<p class="enunciation">If there be three magnitudes, and others equal to them in<br />
multitude, which taken two and two together are in the same<br />
ratio, and the proportion of them be perturbed, they will also<br />
be in the same ratio ex aequali.</p>

Let there be three magnitudes <span data-ref="0187.g1:A">$A$</span>, <span data-ref="0187.g1:B">$B$</span>, <span data-ref="0187.g1:C">$C$</span>, and others equal<br />
to them in multitude, which, taken two and two together, are<br />
in the same proportion, namely <span data-ref="0187.g1:D">$D$</span>, <span data-ref="0187.g1:E">$E$</span>, <span data-ref="0187.g1:F">$F$</span>; and let the propor-<br />
tion of them be perturbed, so that,
<p class="assertion">as <span data-ref="0187.g1:A">$A$</span> is to <span data-ref="0187.g1:B">$B$</span>, so is <span data-ref="0187.g1:E">$E$</span> to <span data-ref="0187.g1:F">$F$</span>,</p>
<p class="assertion">and, as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:C">$C$</span>, so is <span data-ref="0187.g1:D">$D$</span> to <span data-ref="0187.g1:E">$E$</span>;</p>
I say that, as <span data-ref="0187.g1:A">$A$</span> is to <span data-ref="0187.g1:C">$C$</span>, so is <span data-ref="0187.g1:D">$D$</span> to <span data-ref="0187.g1:F">$F$</span>.

![Book V, Proposition 23, Line Segments](0187.g1.svg)

Of <span data-ref="0187.g1:A">$A$</span>, <span data-ref="0187.g1:B">$B$</span>, <span data-ref="0187.g1:D">$D$</span> let equimultiples <span data-ref="0187.g1:G">$G$</span>, <span data-ref="0187.g1:H">$H$</span>, <span data-ref="0187.g1:K">$K$</span> be taken,<br />
and of <span data-ref="0187.g1:C">$C$</span>, <span data-ref="0187.g1:E">$E$</span>, <span data-ref="0187.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0187.g1:L">$L$</span>, <span data-ref="0187.g1:M">$M$</span>, <span data-ref="0187.g1:N">$N$</span>.

Then, since <span data-ref="0187.g1:G">$G$</span>, <span data-ref="0187.g1:H">$H$</span> are equimultiples of <span data-ref="0187.g1:A">$A$</span>, <span data-ref="0187.g1:B">$B$</span>,<br />
and parts have the same ratio as the same multiples of<br />
them, <span class="justification">[V. 15]</span>
<p class="assertion">therefore, as <span data-ref="0187.g1:A">$A$</span> is to <span data-ref="0187.g1:B">$B$</span>, so is <span data-ref="0187.g1:G">$G$</span> to <span data-ref="0187.g1:H">$H$</span>.</p>

For the same reason also,
<p class="assertion">as <span data-ref="0187.g1:E">$E$</span> is to <span data-ref="0187.g1:F">$F$</span>, so is <span data-ref="0187.g1:M">$M$</span> to <span data-ref="0187.g1:N">$N$</span>.</p>

And, as <span data-ref="0187.g1:A">$A$</span> is to <span data-ref="0187.g1:B">$B$</span>, so is <span data-ref="0187.g1:E">$E$</span> to <span data-ref="0187.g1:F">$F$</span>;<br />
<p class="assertion">therefore also, as <span data-ref="0187.g1:G">$G$</span> is to <span data-ref="0187.g1:H">$H$</span>, so is <span data-ref="0187.g1:M">$M$</span> to <span data-ref="0187.g1:N">$N$</span>. <span class="justification">[V. 11]</span></p>

Next, since, as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:C">$C$</span>, so is <span data-ref="0187.g1:D">$D$</span> to <span data-ref="0187.g1:E">$E$</span>,<br />
<p class="assertion">alternately, also, as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:D">$D$</span>, so is <span data-ref="0187.g1:C">$C$</span> to <span data-ref="0187.g1:E">$E$</span>. <span class="justification">[V. 16]</span></p>

And, since <span data-ref="0187.g1:H">$H$</span>, <span data-ref="0187.g1:K">$K$</span> are equimultiples of <span data-ref="0187.g1:B">$B$</span>, <span data-ref="0187.g1:D">$D$</span>,<br />
and parts have the same ratio as their equimultiples,
<p class="assertion">therefore, as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:D">$D$</span>, so is <span data-ref="0187.g1:H">$H$</span> to <span data-ref="0187.g1:K">$K$</span>. <span class="justification">[V. 15]</span></p>
