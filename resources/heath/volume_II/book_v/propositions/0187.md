### PROPOSITION 23.

<p class="enunciation">If there be three magnitudes, and others equal to them in<br />
multitude, which taken two and two together are in the same<br />
ratio, and the proportion of them be perturbed, they will also<br />
be in the same ratio ex aequali.</p>

Let there be three magnitudes <span data-ref="0187.g1:A">$A$</span>, <span data-ref="0187.g1:B">$B$</span>, <span data-ref="0187.g1:C">$C$</span>, and others equal to them in multitude, which, taken two and two together, are in the same proportion, namely <span data-ref="0187.g1:D">$D$</span>, <span data-ref="0187.g1:E">$E$</span>, <span data-ref="0187.g1:F">$F$</span>; and let the proportion of them be perturbed, so that,
as <span data-ref="0187.g1:A">$A$</span> is to <span data-ref="0187.g1:B">$B$</span>, so is <span data-ref="0187.g1:E">$E$</span> to <span data-ref="0187.g1:F">$F$</span>,
and,
as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:C">$C$</span>, so is <span data-ref="0187.g1:D">$D$</span> to <span data-ref="0187.g1:E">$E$</span>;
I say that, as <span data-ref="0187.g1:A">$A$</span> is to <span data-ref="0187.g1:C">$C$</span>, so is <span data-ref="0187.g1:D">$D$</span> to <span data-ref="0187.g1:F">$F$</span>.

![Book V, Proposition 23, Line Segments](0187.g1.svg)

Of <span data-ref="0187.g1:A">$A$</span>, <span data-ref="0187.g1:B">$B$</span>, <span data-ref="0187.g1:D">$D$</span> let equimultiples <span data-ref="0187.g1:G">$G$</span>, <span data-ref="0187.g1:H">$H$</span>, <span data-ref="0187.g1:K">$K$</span> be taken,
and of <span data-ref="0187.g1:C">$C$</span>, <span data-ref="0187.g1:E">$E$</span>, <span data-ref="0187.g1:F">$F$</span> other, chance, equimultiples <span data-ref="0187.g1:L">$L$</span>, <span data-ref="0187.g1:M">$M$</span>, <span data-ref="0187.g1:N">$N$</span>.

Then, since <span data-ref="0187.g1:G">$G$</span>, <span data-ref="0187.g1:H">$H$</span> are equimultiples of <span data-ref="0187.g1:A">$A$</span>, <span data-ref="0187.g1:B">$B$</span>,
and parts have the same ratio as the same multiples of them, [v. 15]
therefore, as <span data-ref="0187.g1:A">$A$</span> is to <span data-ref="0187.g1:B">$B$</span>, so is <span data-ref="0187.g1:G">$G$</span> to <span data-ref="0187.g1:H">$H$</span>.

For the same reason also,
as <span data-ref="0187.g1:E">$E$</span> is to <span data-ref="0187.g1:F">$F$</span>, so is <span data-ref="0187.g1:M">$M$</span> to <span data-ref="0187.g1:N">$N$</span>.

And, as <span data-ref="0187.g1:A">$A$</span> is to <span data-ref="0187.g1:B">$B$</span>, so is <span data-ref="0187.g1:E">$E$</span> to <span data-ref="0187.g1:F">$F$</span>;
therefore also, as <span data-ref="0187.g1:G">$G$</span> is to <span data-ref="0187.g1:H">$H$</span>, so is <span data-ref="0187.g1:M">$M$</span> to <span data-ref="0187.g1:N">$N$</span>. [v. 11]

Next, since, as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:C">$C$</span>, so is <span data-ref="0187.g1:D">$D$</span> to <span data-ref="0187.g1:E">$E$</span>,
alternately, also, as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:D">$D$</span>, so is <span data-ref="0187.g1:C">$C$</span> to <span data-ref="0187.g1:E">$E$</span>. [v. 16]

And, since <span data-ref="0187.g1:H">$H$</span>, <span data-ref="0187.g1:K">$K$</span> are equimultiples of <span data-ref="0187.g1:B">$B$</span>, <span data-ref="0187.g1:D">$D$</span>,
and parts have the same ratio as their equimultiples,
therefore, as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:D">$D$</span>, so is <span data-ref="0187.g1:H">$H$</span> to <span data-ref="0187.g1:K">$K$</span>. [v. 15]
