## Textual, Lexical & Mathematical Observations
- **Perturbed Proportion (*proportio perturbata* / τεταραγμένη ἀναλογία)**: Defined in V. Def. 18. Here $A : B = E : F$ and $B : C = D : E$, with the cross-relation between the antecedent/consequent pairs.
- **Use of Alternation (V. 16)**: Euclid uses alternation ($B : C = D : E \implies B : D = C : E$) to establish the ratio between multiples $H$ and $K$. Heath notes on the next folio that this requires magnitudes to be of the same kind, whereas Simson avoids this by directly applying V. 4.
