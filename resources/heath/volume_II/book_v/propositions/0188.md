But, as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:D">$D$</span>, so is <span data-ref="0187.g1:C">$C$</span> to <span data-ref="0187.g1:E">$E$</span>;
therefore also, as <span data-ref="0187.g1:H">$H$</span> is to <span data-ref="0187.g1:K">$K$</span>, so is <span data-ref="0187.g1:C">$C$</span> to <span data-ref="0187.g1:E">$E$</span>. [v. 11]

Again, since <span data-ref="0187.g1:L">$L$</span>, <span data-ref="0187.g1:M">$M$</span> are equimultiples of <span data-ref="0187.g1:C">$C$</span>, <span data-ref="0187.g1:E">$E$</span>,
therefore, as <span data-ref="0187.g1:C">$C$</span> is to <span data-ref="0187.g1:E">$E$</span>, so is <span data-ref="0187.g1:L">$L$</span> to <span data-ref="0187.g1:M">$M$</span>. [v. 15]

But, as <span data-ref="0187.g1:C">$C$</span> is to <span data-ref="0187.g1:E">$E$</span>, so is <span data-ref="0187.g1:H">$H$</span> to <span data-ref="0187.g1:K">$K$</span>;
therefore also, as <span data-ref="0187.g1:H">$H$</span> is to <span data-ref="0187.g1:K">$K$</span>, so is <span data-ref="0187.g1:L">$L$</span> to <span data-ref="0187.g1:M">$M$</span>, [v. 11]
and, alternately, as <span data-ref="0187.g1:H">$H$</span> is to <span data-ref="0187.g1:L">$L$</span>, so is <span data-ref="0187.g1:K">$K$</span> to <span data-ref="0187.g1:M">$M$</span>. [v. 16]

But it was also proved that,
as <span data-ref="0187.g1:G">$G$</span> is to <span data-ref="0187.g1:H">$H$</span>, so is <span data-ref="0187.g1:M">$M$</span> to <span data-ref="0187.g1:N">$N$</span>.

Since, then, there are three magnitudes <span data-ref="0187.g1:G">$G$</span>, <span data-ref="0187.g1:H">$H$</span>, <span data-ref="0187.g1:L">$L$</span>, and others equal to them in multitude <span data-ref="0187.g1:K">$K$</span>, <span data-ref="0187.g1:M">$M$</span>, <span data-ref="0187.g1:N">$N$</span>, which taken two and two together are in the same ratio,
and the proportion of them is perturbed,
therefore, *ex aequali*, if <span data-ref="0187.g1:G">$G$</span> is in excess of <span data-ref="0187.g1:L">$L$</span>, <span data-ref="0187.g1:K">$K$</span> is also in excess of <span data-ref="0187.g1:N">$N$</span>;
if equal, equal; and if less, less. [v. 21]

And <span data-ref="0187.g1:G">$G$</span>, <span data-ref="0187.g1:K">$K$</span> are equimultiples of <span data-ref="0187.g1:A">$A$</span>, <span data-ref="0187.g1:D">$D$</span>,
and <span data-ref="0187.g1:L">$L$</span>, <span data-ref="0187.g1:N">$N$</span> of <span data-ref="0187.g1:C">$C$</span>, <span data-ref="0187.g1:F">$F$</span>.

Therefore, as <span data-ref="0187.g1:A">$A$</span> is to <span data-ref="0187.g1:C">$C$</span>, so is <span data-ref="0187.g1:D">$D$</span> to <span data-ref="0187.g1:F">$F$</span>.

Therefore etc.

Q. E. D.

There is an important difference between the version given by Simson of one part of the proof of this proposition and that found in the Greek text of Heiberg. Peyrard's MS. has the version given by Heiberg, but Simson's version has the authority of other MSS. The Basel *editio princeps* gives both versions (Simson's being the first). After it has been proved by means of v. 15 and v. 11 that,
as <span data-ref="0187.g1:G">$G$</span> is to <span data-ref="0187.g1:H">$H$</span>, so is <span data-ref="0187.g1:M">$M$</span> to <span data-ref="0187.g1:N">$N$</span>,
or, with the notation used in the note on Prop. 20,
$$ma : mb = ne : nf,$$
it has to be proved further that,
as <span data-ref="0187.g1:H">$H$</span> is to <span data-ref="0187.g1:L">$L$</span>, so is <span data-ref="0187.g1:K">$K$</span> to <span data-ref="0187.g1:M">$M$</span>,
or
$$mb : nc = md : ne,$$
and it is clear that the latter result may be directly inferred from v. 4. The reading translated by Simson makes this inference:

"And because, as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:C">$C$</span>, so is <span data-ref="0187.g1:D">$D$</span> to <span data-ref="0187.g1:E">$E$</span>,
and <span data-ref="0187.g1:H">$H$</span>, <span data-ref="0187.g1:K">$K$</span> are equimultiples of <span data-ref="0187.g1:B">$B$</span>, <span data-ref="0187.g1:D">$D$</span>,
and <span data-ref="0187.g1:L">$L$</span>, <span data-ref="0187.g1:M">$M$</span> of <span data-ref="0187.g1:C">$C$</span>, <span data-ref="0187.g1:E">$E$</span>,
therefore, as <span data-ref="0187.g1:H">$H$</span> is to <span data-ref="0187.g1:L">$L$</span>, so is <span data-ref="0187.g1:K">$K$</span> to <span data-ref="0187.g1:M">$M$</span>." [v. 4]
