But, as <span data-ref="0187.g1:B">$B$</span> is to <span data-ref="0187.g1:D">$D$</span>, so is <span data-ref="0187.g1:C">$C$</span> to <span data-ref="0187.g1:E">$E$</span>;<br />
<p class="assertion">therefore also, as <span data-ref="0187.g1:H">$H$</span> is to <span data-ref="0187.g1:K">$K$</span>, so is <span data-ref="0187.g1:C">$C$</span> to <span data-ref="0187.g1:E">$E$</span>. <span class="justification">[V. 11]</span></p>

Again, since <span data-ref="0187.g1:L">$L$</span>, <span data-ref="0187.g1:M">$M$</span> are equimultiples of <span data-ref="0187.g1:C">$C$</span>, <span data-ref="0187.g1:E">$E$</span>,<br />
<p class="assertion">therefore, as <span data-ref="0187.g1:C">$C$</span> is to <span data-ref="0187.g1:E">$E$</span>, so is <span data-ref="0187.g1:L">$L$</span> to <span data-ref="0187.g1:M">$M$</span>. <span class="justification">[V. 15]</span></p>

But, as <span data-ref="0187.g1:C">$C$</span> is to <span data-ref="0187.g1:E">$E$</span>, so is <span data-ref="0187.g1:H">$H$</span> to <span data-ref="0187.g1:K">$K$</span>;<br />
<p class="assertion">therefore also, as <span data-ref="0187.g1:H">$H$</span> is to <span data-ref="0187.g1:K">$K$</span>, so is <span data-ref="0187.g1:L">$L$</span> to <span data-ref="0187.g1:M">$M$</span>, <span class="justification">[V. 11]</span><br />
and, alternately, as <span data-ref="0187.g1:H">$H$</span> is to <span data-ref="0187.g1:L">$L$</span>, so is <span data-ref="0187.g1:K">$K$</span> to <span data-ref="0187.g1:M">$M$</span>. <span class="justification">[V. 16]</span></p>

But it was also proved that,<br />
<p class="assertion">as <span data-ref="0187.g1:G">$G$</span> is to <span data-ref="0187.g1:H">$H$</span>, so is <span data-ref="0187.g1:M">$M$</span> to <span data-ref="0187.g1:N">$N$</span>.</p>

<p class="sub-clause">Since, then, there are three magnitudes <span data-ref="0187.g1:G">$G$</span>, <span data-ref="0187.g1:H">$H$</span>, <span data-ref="0187.g1:L">$L$</span>, and<br />
others equal to them in multitude <span data-ref="0187.g1:K">$K$</span>, <span data-ref="0187.g1:M">$M$</span>, <span data-ref="0187.g1:N">$N$</span>, which taken two<br />
and two together are in the same ratio,<br />
and the proportion of them is perturbed,</p>
<p class="assertion">therefore, <em>ex aequali</em>, if <span data-ref="0187.g1:G">$G$</span> is in excess of <span data-ref="0187.g1:L">$L$</span>, <span data-ref="0187.g1:K">$K$</span> is also in excess<br />
of <span data-ref="0187.g1:N">$N$</span>;<br />
if equal, equal; and if less, less. <span class="justification">[V. 21]</span></p>

And <span data-ref="0187.g1:G">$G$</span>, <span data-ref="0187.g1:K">$K$</span> are equimultiples of <span data-ref="0187.g1:A">$A$</span>, <span data-ref="0187.g1:D">$D$</span>,<br />
and <span data-ref="0187.g1:L">$L$</span>, <span data-ref="0187.g1:N">$N$</span> of <span data-ref="0187.g1:C">$C$</span>, <span data-ref="0187.g1:F">$F$</span>.

<p class="assertion">Therefore, as <span data-ref="0187.g1:A">$A$</span> is to <span data-ref="0187.g1:C">$C$</span>, so is <span data-ref="0187.g1:D">$D$</span> to <span data-ref="0187.g1:F">$F$</span>.</p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>

one part of the proof of this proposition and that found in the Greek text of<br />
Heiberg. Peyrard's ms. has the version given by Heiberg, but Simson's<br />
version has the authority of other mss. The Basel *editio princeps* gives both<br />
versions (Simson's being the first). After it has been proved by means of<br />
v. 15 and v. 11 that,
<p class="assertion">as <span data-ref="0187.g1:G">$G$</span> is to <span data-ref="0187.g1:H">$H$</span>, so is <span data-ref="0187.g1:M">$M$</span> to <span data-ref="0187.g1:N">$N$</span>,</p>
or, with the notation used in the note on Prop. 20,
<p class="assertion">$ma : mb = ne : nf$,</p>

<p class="assertion">as <span data-ref="0187.g1:H">$H$</span> is to <span data-ref="0187.g1:L">$L$</span>, so is <span data-ref="0187.g1:K">$K$</span> to <span data-ref="0187.g1:M">$M$</span>,</p>
