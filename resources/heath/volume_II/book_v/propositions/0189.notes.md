## Textual, Lexical & Mathematical Observations
- **Cross-Order Induction**: Simson demonstrates that $(A : B = G : H) \land (B : C = F : G) \implies A : C = F : H$, which then combines with $C : D = E : F$ to yield $A : D = E : H$.
- **Composition of Ratios with Identical Consequents (V. 24)**: Given $a : c = d : f$ and $b : c = e : f$, Proposition 24 proves $(a + b) : c = (d + e) : f$. Line segments $AB, BG$ are placed in a straight line to form $AG$, and $DE, EH$ to form $DH$.
