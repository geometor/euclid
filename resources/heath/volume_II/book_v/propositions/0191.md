### PROPOSITION 25.

<p class="enunciation">If four magnitudes be proportional, the greatest and the<br />
least are greater than the remaining two.</p>

Let the four magnitudes <span data-ref="0191.g1:/ A B /">$AB$</span>, <span data-ref="0191.g1:/ C D /">$CD$</span>, <span data-ref="0191.g1:E">$E$</span>, <span data-ref="0191.g1:F">$F$</span> be proportional<br />
so that, as <span data-ref="0191.g1:/ A B /">$AB$</span> is to <span data-ref="0191.g1:/ C D /">$CD$</span>, so is <span data-ref="0191.g1:E">$E$</span> to<br />
<span data-ref="0191.g1:F">$F$</span>, and let <span data-ref="0191.g1:/ A B /">$AB$</span> be the greatest of them<br />
and <span data-ref="0191.g1:F">$F$</span> the least;<br />
I say that <span data-ref="0191.g1:/ A B /">$AB$</span>, <span data-ref="0191.g1:F">$F$</span> are greater than<br />
<span data-ref="0191.g1:/ C D /">$CD$</span>, <span data-ref="0191.g1:E">$E$</span>.

For let <span data-ref="0191.g1:/ A G /">$AG$</span> be made equal to <span data-ref="0191.g1:E">$E$</span>,<br />
and <span data-ref="0191.g1:/ C H /">$CH$</span> equal to <span data-ref="0191.g1:F">$F$</span>.

![Book V, Proposition 25, Line Segments](0191.g1.svg)

Since, as <span data-ref="0191.g1:/ A B /">$AB$</span> is to <span data-ref="0191.g1:/ C D /">$CD$</span>, so is <span data-ref="0191.g1:E">$E$</span><br />
to <span data-ref="0191.g1:F">$F$</span>,<br />
and <span data-ref="0191.g1:E">$E$</span> is equal to <span data-ref="0191.g1:/ A G /">$AG$</span>, and <span data-ref="0191.g1:F">$F$</span> to <span data-ref="0191.g1:/ C H /">$CH$</span>,<br />
<p class="assertion">therefore, as <span data-ref="0191.g1:/ A B /">$AB$</span> is to <span data-ref="0191.g1:/ C D /">$CD$</span>, so is <span data-ref="0191.g1:/ A G /">$AG$</span> to <span data-ref="0191.g1:/ C H /">$CH$</span>.</p>

And since, as the whole <span data-ref="0191.g1:/ A B /">$AB$</span> is to the whole <span data-ref="0191.g1:/ C D /">$CD$</span>, so is<br />
the part <span data-ref="0191.g1:/ A G /">$AG$</span> subtracted to the part <span data-ref="0191.g1:/ C H /">$CH$</span> subtracted,<br />
<p class="assertion">the remainder <span data-ref="0191.g1:/ G B /">$GB$</span> will also be to the remainder <span data-ref="0191.g1:/ H D /">$HD$</span> as<br />
the whole <span data-ref="0191.g1:/ A B /">$AB$</span> is to the whole <span data-ref="0191.g1:/ C D /">$CD$</span>. <span class="justification">[V. 19]</span></p>

<p class="sub-clause">But <span data-ref="0191.g1:/ A B /">$AB$</span> is greater than <span data-ref="0191.g1:/ C D /">$CD$</span>;</p>
<p class="assertion">therefore <span data-ref="0191.g1:/ G B /">$GB$</span> is also greater than <span data-ref="0191.g1:/ H D /">$HD$</span>.</p>

And, since <span data-ref="0191.g1:/ A G /">$AG$</span> is equal to <span data-ref="0191.g1:E">$E$</span>, and <span data-ref="0191.g1:/ C H /">$CH$</span> to <span data-ref="0191.g1:F">$F$</span>,<br />
<p class="assertion">therefore <span data-ref="0191.g1:/ A G /">$AG$</span>, <span data-ref="0191.g1:F">$F$</span> are equal to <span data-ref="0191.g1:/ C H /">$CH$</span>, <span data-ref="0191.g1:E">$E$</span>.</p>

<p class="sub-clause">And if, <span data-ref="0191.g1:/ G B /">$GB$</span>, <span data-ref="0191.g1:/ H D /">$HD$</span> being unequal, and <span data-ref="0191.g1:/ G B /">$GB$</span> greater, <span data-ref="0191.g1:/ A G /">$AG$</span>, <span data-ref="0191.g1:F">$F$</span><br />
be added to <span data-ref="0191.g1:/ G B /">$GB$</span> and <span data-ref="0191.g1:/ C H /">$CH$</span>, <span data-ref="0191.g1:E">$E$</span> be added to <span data-ref="0191.g1:/ H D /">$HD$</span>,</p>
<p class="assertion">it follows that <span data-ref="0191.g1:/ A B /">$AB$</span>, <span data-ref="0191.g1:F">$F$</span> are greater than <span data-ref="0191.g1:/ C D /">$CD$</span>, <span data-ref="0191.g1:E">$E$</span>.</p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>

Algebraically, if
$$a : b = c : d\text{,}$$
and $a$ is the greatest of the four magnitudes and $d$ the least,
$$a + d > b + c.$$

Simson is right in inserting a word in the setting-out, "let <span data-ref="0191.g1:/ A B /">$AB$</span> be the<br />
greatest of them and *&lt;consequently&gt;* <span data-ref="0191.g1:F">$F$</span> the least." This follows from the<br />
particular case, really included in Def. 5, which Simson makes the subject of<br />
his proposition A, the case namely where the equimultiples taken are *once* the<br />
several magnitudes.

The proof is as follows.<br />
Since
$$a : b = c : d\text{,}$$
$$a - c : b - d = a : b. \qquad [\text{V. } 19]$$
