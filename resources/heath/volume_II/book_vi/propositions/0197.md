# BOOK VI. PROPOSITIONS.

### PROPOSITION 1.

<p class="enunciation">Triangles and parallelograms which are under the same<br />
height are to one another as their bases.</p>

Let <span data-ref="0197.g1:< A B C >">$ABC$</span>, <span data-ref="0197.g1:< A C D >">$ACD$</span> be triangles and <span data-ref="0197.g1:< E C >">$EC$</span>, <span data-ref="0197.g1:< C F >">$CF$</span> parallelograms  
under the same height;  
<sup>5</sup> I say that, as the base <span data-ref="0197.g1:/ B C /">$BC$</span> is to the base <span data-ref="0197.g1:/ C D /">$CD$</span>, so is the  
triangle <span data-ref="0197.g1:< A B C >">$ABC$</span> to the triangle <span data-ref="0197.g1:< A C D >">$ACD$</span>, and the parallelogram  
<span data-ref="0197.g1:< E C >">$EC$</span> to the parallelogram <span data-ref="0197.g1:< C F >">$CF$</span>.

![Book VI Proposition 1](0197.g1.svg)

For let <span data-ref="0197.g1:/ B D /">$BD$</span> be produced in both directions to the points  
<span data-ref="0197.g1:H">$H$</span>, <span data-ref="0197.g1:L">$L$</span> and let [any number of straight lines] <span data-ref="0197.g1:/ B G /">$BG$</span>, <span data-ref="0197.g1:/ G H /">$GH$</span> be  
<sup>10</sup> made equal to the base <span data-ref="0197.g1:/ B C /">$BC$</span>, and any number of straight lines  
<span data-ref="0197.g1:/ D K /">$DK$</span>, <span data-ref="0197.g1:/ K L /">$KL$</span> equal to the base <span data-ref="0197.g1:/ C D /">$CD$</span>;  
let <span data-ref="0197.g1:/ A G /">$AG$</span>, <span data-ref="0197.g1:/ A H /">$AH$</span>, <span data-ref="0197.g1:/ A K /">$AK$</span>, <span data-ref="0197.g1:/ A L /">$AL$</span> be joined.

Then, since <span data-ref="0197.g1:/ C B /">$CB$</span>, <span data-ref="0197.g1:/ B G /">$BG$</span>, <span data-ref="0197.g1:/ G H /">$GH$</span> are equal to one another,
<p class="assertion">the triangles <span data-ref="0197.g1:< A B C >">$ABC$</span>, <span data-ref="0197.g1:< A G B >">$AGB$</span>, <span data-ref="0197.g1:< A H G >">$AHG$</span> are also equal to one<br />
<sup>15</sup> another. <span class="justification">[I. 38]</span></p>

<p class="assertion">Therefore, whatever multiple the base <span data-ref="0197.g1:/ H C /">$HC$</span> is of the base<br />
<span data-ref="0197.g1:/ B C /">$BC$</span>, that multiple also is the triangle <span data-ref="0197.g1:< A H C >">$AHC$</span> of the triangle<br />
<span data-ref="0197.g1:< A B C >">$ABC$</span>.</p>

<p class="sub-clause">For the same reason,</p>
<p class="assertion"><sup>20</sup> whatever multiple the base <span data-ref="0197.g1:/ L C /">$LC$</span> is of the base <span data-ref="0197.g1:/ C D /">$CD$</span>, that<br />
multiple also is the triangle <span data-ref="0197.g1:< A L C >">$ALC$</span> of the triangle <span data-ref="0197.g1:< A C D >">$ACD$</span>;</p>
<p class="assertion">and, if the base <span data-ref="0197.g1:/ H C /">$HC$</span> is equal to the base <span data-ref="0197.g1:/ C L /">$CL$</span>, the triangle<br />
<span data-ref="0197.g1:< A H C >">$AHC$</span> is also equal to the triangle <span data-ref="0197.g1:< A C L >">$ACL$</span>, <span class="justification">[I. 38]</span></p>
