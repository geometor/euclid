BOOK VI. PROPOSITIONS.
======================

PROPOSITION 1.
--------------

.. enunciation::

   Triangles and parallelograms which are under the same height are to one another as their bases.

Let :g:`$ABC$ <0197.g1:< A B C >>`, :g:`$ACD$ <0197.g1:< A C D >>` be triangles and :g:`$EC$ <0197.g1:< E C >>`, :g:`$CF$ <0197.g1:< C F >>` parallelograms under the same height;\ [#f1]_

I say that, as the base :g:`$BC$ <0197.g1:/ B C />` is to the base :g:`$CD$ <0197.g1:/ C D />`, so is the triangle :g:`$ABC$ <0197.g1:< A B C >>` to the triangle :g:`$ACD$ <0197.g1:< A C D >>`, and the parallelogram :g:`$EC$ <0197.g1:< E C >>` to the parallelogram :g:`$CF$ <0197.g1:< C F >>`.

.. picture:: 0197.g1.svg
   :alt: Book VI Proposition 1

For let :g:`$BD$ <0197.g1:/ B D />` be produced in both directions to the points :g:`$H$ <0197.g1:H>`, :g:`$L$ <0197.g1:L>` and let [any number of straight lines] :g:`$BG$ <0197.g1:/ B G />`, :g:`$GH$ <0197.g1:/ G H />` be made equal to the base :g:`$BC$ <0197.g1:/ B C />`, and any number of straight lines :g:`$DK$ <0197.g1:/ D K />`, :g:`$KL$ <0197.g1:/ K L />` equal to the base :g:`$CD$ <0197.g1:/ C D />`; let :g:`$AG$ <0197.g1:/ A G />`, :g:`$AH$ <0197.g1:/ A H />`, :g:`$AK$ <0197.g1:/ A K />`, :g:`$AL$ <0197.g1:/ A L />` be joined.

Then, since :g:`$CB$ <0197.g1:/ C B />`, :g:`$BG$ <0197.g1:/ B G />`, :g:`$GH$ <0197.g1:/ G H />` are equal to one another,

.. assertion::

   the triangles :g:`$ABC$ <0197.g1:< A B C >>`, :g:`$AGB$ <0197.g1:< A G B >>`, :g:`$AHG$ <0197.g1:< A H G >>`\ [#f2]_ are also equal to one another. :just:`[I. 38] <I.38>`

.. assertion::

   Therefore, whatever multiple the base :g:`$HC$ <0197.g1:/ H C />` is of the base :g:`$BC$ <0197.g1:/ B C />`, that multiple also is the triangle :g:`$AHC$ <0197.g1:< A H C >>` of the triangle :g:`$ABC$ <0197.g1:< A B C >>`.

.. subclause::

   For the same reason,

.. assertion::

   whatever multiple the base :g:`$LC$ <0197.g1:/ L C />` is of the base :g:`$CD$ <0197.g1:/ C D />`, that multiple also is the triangle :g:`$ALC$ <0197.g1:< A L C >>` of the triangle :g:`$ACD$ <0197.g1:< A C D >>`;

.. assertion::

   and, if the base :g:`$HC$ <0197.g1:/ H C />` is equal to the base :g:`$CL$ <0197.g1:/ C L />`, the triangle :g:`$AHC$ <0197.g1:< A H C >>` is also equal to the triangle :g:`$ACL$ <0197.g1:< A C L >>`, :just:`[I. 38] <I.38>`
