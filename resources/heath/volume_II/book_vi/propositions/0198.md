**4.** **Under the same height.** The Greek text has “under the same height <span data-ref="0197.g1:/ A C /">$AC$</span>,” with a figure in which the side <span data-ref="0197.g1:/ A C /">$AC$</span> common to the two triangles is perpendicular to the base and is therefore itself the “height.” But, even if the two triangles are placed contiguously so as to have a common side <span data-ref="0197.g1:/ A C /">$AC$</span>, it is quite gratuitous to require it to be perpendicular to the base. Theon, on this occasion making an improvement, altered to “which are (ὄντα) under the same height, (namely) the perpendicular drawn from <span data-ref="0197.g1:A">$A$</span> to <span data-ref="0197.g1:/ B D /">$BD$</span>.” I have ventured to alter so far as to omit “<span data-ref="0197.g1:/ A C /">$AC$</span>” and to draw the figure in the usual way.

**14.** **ABC, AGB, AHG.** Euclid, indifferent to exact order, writes “<span data-ref="0197.g1:< A H G >">$AHG$</span>, <span data-ref="0197.g1:< A G B >">$AGB$</span>, <span data-ref="0197.g1:< A B C >">$ABC$</span>.”

**46.** **Since then it was proved that, as the base BC is to CD, so is the triangle ABC to the triangle ACD.** Here again words have to be supplied in translating the extremely terse Greek ἐπεὶ οὖν ἐδείχθη, ὡς μὲν ἡ βάσις ΒΓ πρὸς τὴν ΓΔ, οὕτως τὸ ΑΒΓ τρίγωνον πρὸς τὸ ΑΓΔ τρίγωνον, literally “since was proved, as the base <span data-ref="0197.g1:/ B C /">$BC$</span> to <span data-ref="0197.g1:/ C D /">$CD$</span>, so the triangle <span data-ref="0197.g1:< A B C >">$ABC$</span> to the triangle <span data-ref="0197.g1:< A C D >">$ACD$</span>.” Cf. note on **v. 16**, p. 165.
