<p class="enunciation">remaining sides of the triangle, the straight line joined from<br />
the vertex to the point of section will bisect the angle of the<br />
triangle.</p>

Let <span data-ref="0202.g1:< A B C >">$ABC$</span> be a triangle, and let the angle <span data-ref="0202.g1:< B A C )">$BAC$</span> be bisected  
by the straight line <span data-ref="0202.g1:/ A D /">$AD$</span>;

I say that, as <span data-ref="0202.g1:/ B D /">$BD$</span> is to <span data-ref="0202.g1:/ C D /">$CD$</span>, so  
is <span data-ref="0202.g1:/ B A /">$BA$</span> to <span data-ref="0202.g1:/ A C /">$AC$</span>.

![Proposition 3](0202.g1.svg)

For let <span data-ref="0202.g1:/ C E /">$CE$</span> be drawn through  
<span data-ref="0202.g1:C">$C$</span> parallel to <span data-ref="0202.g1:/ D A /">$DA$</span>, and let <span data-ref="0202.g1:/ B A /">$BA$</span>  
be carried through and meet it  
at <span data-ref="0202.g1:E">$E$</span>.

Then, since the straight line  
<span data-ref="0202.g1:/ A C /">$AC$</span> falls upon the parallels <span data-ref="0202.g1:/ A D /">$AD$</span>,  
<span data-ref="0202.g1:/ E C /">$EC$</span>,

<p class="assertion">the angle <span data-ref="0202.g1:< A C E )">$ACE$</span> is equal to the angle <span data-ref="0202.g1:< C A D )">$CAD$</span>. <span class="justification">[I. 29]</span></p>

But the angle <span data-ref="0202.g1:< C A D )">$CAD$</span> is by hypothesis equal to the angle  
<span data-ref="0202.g1:< B A D )">$BAD$</span>;

<p class="assertion">therefore the angle <span data-ref="0202.g1:< B A D )">$BAD$</span> is also equal to the angle <span data-ref="0202.g1:< A C E )">$ACE$</span>.</p>

Again, since the straight line <span data-ref="0202.g1:/ B A E /">$BAE$</span> falls upon the parallels  
<span data-ref="0202.g1:/ A D /">$AD$</span>, <span data-ref="0202.g1:/ E C /">$EC$</span>,

<p class="assertion">the exterior angle <span data-ref="0202.g1:< B A D )">$BAD$</span> is equal to the interior angle<br />
<span data-ref="0202.g1:< A E C )">$AEC$</span>. <span class="justification">[I. 29]</span></p>

But the angle <span data-ref="0202.g1:< A C E )">$ACE$</span> was also proved equal to the angle  
<span data-ref="0202.g1:< B A D )">$BAD$</span>;

<p class="assertion">therefore the angle <span data-ref="0202.g1:< A C E )">$ACE$</span> is also equal to the angle <span data-ref="0202.g1:< A E C )">$AEC$</span>,</p>

<p class="assertion">so that the side <span data-ref="0202.g1:/ A E /">$AE$</span> is also equal to the side <span data-ref="0202.g1:/ A C /">$AC$</span>. <span class="justification">[I. 6]</span></p>

And, since <span data-ref="0202.g1:/ A D /">$AD$</span> has been drawn parallel to <span data-ref="0202.g1:/ E C /">$EC$</span>, one of  
the sides of the triangle <span data-ref="0202.g1:< B C E >">$BCE$</span>,

<p class="assertion">therefore, proportionally, as <span data-ref="0202.g1:/ B D /">$BD$</span> is to <span data-ref="0202.g1:/ D C /">$DC$</span>, so is <span data-ref="0202.g1:/ B A /">$BA$</span> to <span data-ref="0202.g1:/ A E /">$AE$</span>.<br />
<span class="justification">[VI. 2]</span></p>

But <span data-ref="0202.g1:/ A E /">$AE$</span> is equal to <span data-ref="0202.g1:/ A C /">$AC$</span>;

<p class="assertion">therefore, as <span data-ref="0202.g1:/ B D /">$BD$</span> is to <span data-ref="0202.g1:/ D C /">$DC$</span>, so is <span data-ref="0202.g1:/ B A /">$BA$</span> to <span data-ref="0202.g1:/ A C /">$AC$</span>.</p>

Again, let <span data-ref="0202.g1:/ B A /">$BA$</span> be to <span data-ref="0202.g1:/ A C /">$AC$</span> as <span data-ref="0202.g1:/ B D /">$BD$</span> to <span data-ref="0202.g1:/ D C /">$DC$</span>, and let <span data-ref="0202.g1:/ A D /">$AD$</span> be  
joined;

I say that the angle <span data-ref="0202.g1:< B A C )">$BAC$</span> has been bisected by the straight  
line <span data-ref="0202.g1:/ A D /">$AD$</span>.
