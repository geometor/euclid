*remaining sides of the triangle, the straight line joined from the vertex to the point of section will bisect the angle of the triangle.*

Let <span data-ref="0202.g1:&lt; A B C &gt;">$ABC$</span> be a triangle, and let the angle <span data-ref="0202.g1:&lt; B A C )">$BAC$</span> be bisected by the straight line <span data-ref="0202.g1:/ A D /">$AD$</span>;

I say that, as <span data-ref="0202.g1:/ B D /">$BD$</span> is to <span data-ref="0202.g1:/ C D /">$CD$</span>, so is <span data-ref="0202.g1:/ B A /">$BA$</span> to <span data-ref="0202.g1:/ A C /">$AC$</span>.

![Proposition 3](0202.g1.svg)

For let <span data-ref="0202.g1:/ C E /">$CE$</span> be drawn through <span data-ref="0202.g1:C">$C$</span> parallel to <span data-ref="0202.g1:/ D A /">$DA$</span>, and let <span data-ref="0202.g1:/ B A /">$BA$</span> be carried through and meet it at <span data-ref="0202.g1:E">$E$</span>.

Then, since the straight line <span data-ref="0202.g1:/ A C /">$AC$</span> falls upon the parallels <span data-ref="0202.g1:/ A D /">$AD$</span>, <span data-ref="0202.g1:/ E C /">$EC$</span>,
the angle <span data-ref="0202.g1:&lt; A C E )">$ACE$</span> is equal to the angle <span data-ref="0202.g1:&lt; C A D )">$CAD$</span>. [I. 29]

But the angle <span data-ref="0202.g1:&lt; C A D )">$CAD$</span> is by hypothesis equal to the angle <span data-ref="0202.g1:&lt; B A D )">$BAD$</span>;
therefore the angle <span data-ref="0202.g1:&lt; B A D )">$BAD$</span> is also equal to the angle <span data-ref="0202.g1:&lt; A C E )">$ACE$</span>.

Again, since the straight line <span data-ref="0202.g1:/ B A E /">$BAE$</span> falls upon the parallels <span data-ref="0202.g1:/ A D /">$AD$</span>, <span data-ref="0202.g1:/ E C /">$EC$</span>,
the exterior angle <span data-ref="0202.g1:&lt; B A D )">$BAD$</span> is equal to the interior angle <span data-ref="0202.g1:&lt; A E C )">$AEC$</span>. [I. 29]

But the angle <span data-ref="0202.g1:&lt; A C E )">$ACE$</span> was also proved equal to the angle <span data-ref="0202.g1:&lt; B A D )">$BAD$</span>;
therefore the angle <span data-ref="0202.g1:&lt; A C E )">$ACE$</span> is also equal to the angle <span data-ref="0202.g1:&lt; A E C )">$AEC$</span>,
so that the side <span data-ref="0202.g1:/ A E /">$AE$</span> is also equal to the side <span data-ref="0202.g1:/ A C /">$AC$</span>. [I. 6]

And, since <span data-ref="0202.g1:/ A D /">$AD$</span> has been drawn parallel to <span data-ref="0202.g1:/ E C /">$EC$</span>, one of the sides of the triangle <span data-ref="0202.g1:&lt; B C E &gt;">$BCE$</span>,
therefore, proportionally, as <span data-ref="0202.g1:/ B D /">$BD$</span> is to <span data-ref="0202.g1:/ D C /">$DC$</span>, so is <span data-ref="0202.g1:/ B A /">$BA$</span> to <span data-ref="0202.g1:/ A E /">$AE$</span>. [VI. 2]

But <span data-ref="0202.g1:/ A E /">$AE$</span> is equal to <span data-ref="0202.g1:/ A C /">$AC$</span>;
therefore, as <span data-ref="0202.g1:/ B D /">$BD$</span> is to <span data-ref="0202.g1:/ D C /">$DC$</span>, so is <span data-ref="0202.g1:/ B A /">$BA$</span> to <span data-ref="0202.g1:/ A C /">$AC$</span>.

Again, let <span data-ref="0202.g1:/ B A /">$BA$</span> be to <span data-ref="0202.g1:/ A C /">$AC$</span> as <span data-ref="0202.g1:/ B D /">$BD$</span> to <span data-ref="0202.g1:/ D C /">$DC$</span>, and let <span data-ref="0202.g1:/ A D /">$AD$</span> be joined;

I say that the angle <span data-ref="0202.g1:&lt; B A C )">$BAC$</span> has been bisected by the straight line <span data-ref="0202.g1:/ A D /">$AD$</span>.
