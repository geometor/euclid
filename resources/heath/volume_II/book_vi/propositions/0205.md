We are told to take three straight lines $x$, <span data-ref="0205.g1:/ C O /">$CO$</span> (a length measured along <span data-ref="0205.g1:/ B C /">$BC$</span> produced beyond <span data-ref="0205.g1:C">$C$</span>, where <span data-ref="0205.g1:B">$B$</span>, <span data-ref="0205.g1:C">$C$</span> are the points at which the greater and smaller of the inflected lines respectively terminate), and $r$, such that, if $h : k$ be the given ratio and $h > k$,
<p align="center">$k : h = h : k + x$, $(\alpha)$</p>
<p align="center">$x :$ <span data-ref="0205.g1:/ B C /">$BC$</span> $= k :$ <span data-ref="0205.g1:/ C O /">$CO$</span> $= h : r$. $(\beta)$</p>

![Apollonius Circle Construction Diagram](0205.g1.svg)

This determines the position of <span data-ref="0205.g1:O">$O$</span>, and the length of $r$, the radius of the required circle. The circle is then drawn, any point <span data-ref="0205.g1:P">$P$</span> is taken on it and joined to <span data-ref="0205.g1:B">$B$</span>, <span data-ref="0205.g1:C">$C$</span> respectively, and it is proved that
<p align="center"><span data-ref="0205.g1:/ P B /">$PB$</span> $:$ <span data-ref="0205.g1:/ P C /">$PC$</span> $= h : k$.</p>

We may conjecture that the analysis proceeded somewhat as follows.

It would be seen that <span data-ref="0205.g1:B">$B$</span>, <span data-ref="0205.g1:C">$C$</span> are "conjugate points" with reference to the circle on <span data-ref="0205.g1:/ D E /">$DE$</span> as diameter. (*Cf.* Apollonius, *Conics*, I. 36, where it is proved, in terms, for a circle as well as for an ellipse and a hyperbola, that, if the polar of <span data-ref="0205.g1:B">$B$</span> meets the diameter <span data-ref="0205.g1:/ D E /">$DE$</span> in <span data-ref="0205.g1:C">$C$</span>, then <span data-ref="0205.g1:/ E C /">$EC$</span> $:$ <span data-ref="0205.g1:/ C D /">$CD$</span> $=$ <span data-ref="0205.g1:/ E B /">$EB$</span> $:$ <span data-ref="0205.g1:/ B D /">$BD$</span>.)

If <span data-ref="0205.g1:O">$O$</span> be the middle point of <span data-ref="0205.g1:/ D E /">$DE$</span>, and therefore the centre of the circle, <span data-ref="0205.g1:D">$D$</span>, <span data-ref="0205.g1:E">$E$</span> may be eliminated, as in the *Conics*, I. 37, thus.

Since
<p align="center"><span data-ref="0205.g1:/ E C /">$EC$</span> $:$ <span data-ref="0205.g1:/ C D /">$CD$</span> $=$ <span data-ref="0205.g1:/ E B /">$EB$</span> $:$ <span data-ref="0205.g1:/ B D /">$BD$</span>,</p>
it follows that <span data-ref="0205.g1:/ E C /">$EC$</span> $+$ <span data-ref="0205.g1:/ C D /">$CD$</span> $:$ <span data-ref="0205.g1:/ E C /">$EC$</span> $\sim$ <span data-ref="0205.g1:/ C D /">$CD$</span> $=$ <span data-ref="0205.g1:/ E B /">$EB$</span> $+$ <span data-ref="0205.g1:/ B D /">$BD$</span> $:$ <span data-ref="0205.g1:/ E B /">$EB$</span> $\sim$ <span data-ref="0205.g1:/ B D /">$BD$</span>,
or
<p align="center">$2$<span data-ref="0205.g1:/ O D /">$OD$</span> $: 2$<span data-ref="0205.g1:/ O C /">$OC$</span> $= 2$<span data-ref="0205.g1:/ O B /">$OB$</span> $: 2$<span data-ref="0205.g1:/ O D /">$OD$</span>,</p>
that is,
<p align="center"><span data-ref="0205.g1:/ B O /">$BO$</span> $\cdot$ <span data-ref="0205.g1:/ O C /">$OC$</span> $=$ <span data-ref="0205.g1:/ O D /">$OD^2$</span> $= r^2$, say.</p>

If therefore <span data-ref="0205.g1:P">$P$</span> be any point on the circle with centre <span data-ref="0205.g1:O">$O$</span> and radius $r$,
<p align="center"><span data-ref="0205.g1:/ B O /">$BO$</span> $:$ <span data-ref="0205.g1:/ O P /">$OP$</span> $=$ <span data-ref="0205.g1:/ O P /">$OP$</span> $:$ <span data-ref="0205.g1:/ O C /">$OC$</span>,</p>
so that <span data-ref="0205.g1:&lt; B O P &gt;">$BOP$</span>, <span data-ref="0205.g1:&lt; P O C &gt;">$POC$</span> are similar triangles.

In addition, $h : k =$ <span data-ref="0205.g1:/ B D /">$BD$</span> $:$ <span data-ref="0205.g1:/ D C /">$DC$</span> $=$ <span data-ref="0205.g1:/ B E /">$BE$</span> $:$ <span data-ref="0205.g1:/ E C /">$EC$</span>
<p align="center">$=$ <span data-ref="0205.g1:/ B D /">$BD$</span> $+$ <span data-ref="0205.g1:/ B E /">$BE$</span> $:$ <span data-ref="0205.g1:/ D E /">$DE$</span> $=$ <span data-ref="0205.g1:/ B O /">$BO$</span> $: r$.</p>

Hence we require that
<p align="center"><span data-ref="0205.g1:/ B O /">$BO$</span> $: r = r :$ <span data-ref="0205.g1:/ O C /">$OC$</span> $=$ <span data-ref="0205.g1:/ B P /">$BP$</span> $:$ <span data-ref="0205.g1:/ P C /">$PC$</span> $= h : k$. $(\delta)$</p>

Therefore, alternately,
<p align="center">$k :$ <span data-ref="0205.g1:/ C O /">$CO$</span> $= h : r$,</p>
which is the second relation in $(\beta)$ above.

Now assume a length $x$ such that each of the last ratios is equal to $x :$ <span data-ref="0205.g1:/ B C /">$BC$</span>, as in $(\beta)$.
