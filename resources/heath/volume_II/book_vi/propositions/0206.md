Then
<p align="center">x : <span data-ref="0205.g1:/ B C /">$BC$</span> = k : <span data-ref="0205.g1:/ C O /">$CO$</span> = h : r.</p>
Therefore
<p align="center">x + k : <span data-ref="0205.g1:/ B O /">$BO$</span> = h : r,</p>
and, alternately,
<p align="center">x + k : h = <span data-ref="0205.g1:/ B O /">$BO$</span> : r <br />
= h : k, from (\delta) above;</p>
and this is the relation $(\alpha)$ which remained to be found.

Apollonius' proof of the construction is given by Eutocius, who begins by<br />
saying that it is manifest that $r$ is a mean proportional between <span data-ref="0205.g1:/ B O /">$BO$</span> and <span data-ref="0205.g1:/ O C /">$OC$</span>.<br />
This is seen as follows.

From $(\beta)$ we derive
<p align="center">x : <span data-ref="0205.g1:/ B C /">$BC$</span> = k : <span data-ref="0205.g1:/ C O /">$CO$</span> = h : r = (k + x) : <span data-ref="0205.g1:/ B O /">$BO$</span>,</p>
whence
<p align="center"><span data-ref="0205.g1:/ B O /">$BO$</span> : r = (k + x) : h <br />
= h : k, by (\alpha), <br />
= r : <span data-ref="0205.g1:/ C O /">$CO$</span>, by (\beta),</p>
and therefore
<p align="center">r^2 = <span data-ref="0205.g1:/ B O /">$BO$</span> \,.\, <span data-ref="0205.g1:/ C O /">$CO$</span>.</p>

But the triangles <span data-ref="0205.g1:< B O P >">$BOP$</span>, <span data-ref="0205.g1:< P O C >">$POC$</span> have the angle at <span data-ref="0205.g1:< O )">$O$</span> common, and, since<br />
<span data-ref="0205.g1:/ B O /">$BO$</span> : <span data-ref="0205.g1:/ O P /">$OP$</span> = <span data-ref="0205.g1:/ O P /">$OP$</span> : <span data-ref="0205.g1:/ O C /">$OC$</span>, the triangles are similar and the angles <span data-ref="0205.g1:< O P C )">$OPC$</span>, <span data-ref="0205.g1:< O B P )">$OBP$</span><br />
are equal.

[Up to this point Aristotle's proof is exactly the same; from this point it<br />
diverges slightly.]

If now <span data-ref="0205.g1:/ C L /">$CL$</span> be drawn parallel to <span data-ref="0205.g1:/ B P /">$BP$</span> meeting <span data-ref="0205.g1:/ O P /">$OP$</span> in <span data-ref="0205.g1:L">$L$</span>, the angles <span data-ref="0205.g1:< B P C )">$BPC$</span>,<br />
<span data-ref="0205.g1:< L C P )">$LCP$</span> are equal also.

Therefore the triangles <span data-ref="0205.g1:< B P C >">$BPC$</span>, <span data-ref="0205.g1:< P C L >">$PCL$</span> are similar, and
<p align="center"><span data-ref="0205.g1:/ B P /">$BP$</span> : <span data-ref="0205.g1:/ P C /">$PC$</span> = <span data-ref="0205.g1:/ P C /">$PC$</span> : <span data-ref="0205.g1:/ C L /">$CL$</span>,</p>
whence
<p align="center"><span data-ref="0205.g1:/ B P /">$BP^2$</span> : <span data-ref="0205.g1:/ P C /">$PC^2$</span> = <span data-ref="0205.g1:/ B P /">$BP$</span> : <span data-ref="0205.g1:/ C L /">$CL$</span> <br />
= <span data-ref="0205.g1:/ B O /">$BO$</span> : <span data-ref="0205.g1:/ O C /">$OC$</span>, by parallels, <br />
= <span data-ref="0205.g1:/ B O /">$BO^2$</span> : <span data-ref="0205.g1:/ O P /">$OP^2$</span> (since <span data-ref="0205.g1:/ B O /">$BO$</span> : <span data-ref="0205.g1:/ O P /">$OP$</span> = <span data-ref="0205.g1:/ O P /">$OP$</span> : <span data-ref="0205.g1:/ O C /">$OC$</span>).</p>

Therefore
<p align="center"><span data-ref="0205.g1:/ B P /">$BP$</span> : <span data-ref="0205.g1:/ P C /">$PC$</span> = <span data-ref="0205.g1:/ B O /">$BO$</span> : <span data-ref="0205.g1:/ O P /">$OP$</span> <br />
= h : k (for <span data-ref="0205.g1:/ O P /">$OP$</span> = r).</p>

[Aristotle infers this more directly from the similar triangles <span data-ref="0205.g1:< P O B >">$POB$</span>, <span data-ref="0205.g1:< C O P >">$COP$</span>.<br />
Since these triangles are similar,
<p align="center"><span data-ref="0205.g1:/ O P /">$OP$</span> : <span data-ref="0205.g1:/ C P /">$CP$</span> = <span data-ref="0205.g1:/ O B /">$OB$</span> : <span data-ref="0205.g1:/ B P /">$BP$</span>,</p>
whence
<p align="center"><span data-ref="0205.g1:/ B P /">$BP$</span> : <span data-ref="0205.g1:/ P C /">$PC$</span> = <span data-ref="0205.g1:/ B O /">$BO$</span> : <span data-ref="0205.g1:/ O P /">$OP$</span> <br />
= h : k.]</p>

Apollonius proves lastly, by *reductio ad absurdum*, that the last equation<br />
cannot be true with reference to any point <span data-ref="0205.g1:P">$P$</span> which is not on the circle so<br />
described.

### PROPOSITION 4.

<p class="enunciation">In equiangular triangles the sides about the equal angles<br />
are proportional, and those are corresponding sides which<br />
subtend the equal angles.</p>
