Then

.. container:: center

   x : :g:`$BC$ <0205.g1:/ B C />` = k : :g:`$CO$ <0205.g1:/ C O />` = h : r.

Therefore

.. container:: center

   x + k : :g:`$BO$ <0205.g1:/ B O />` = h : r,

and, alternately,

.. container:: center

   | x + k : h = :g:`$BO$ <0205.g1:/ B O />` : r
   | = h : k, from (\delta) above;

and this is the relation $(\alpha)$ which remained to be found.

| :person:`Apollonius <apollonius>`' proof of the construction is given by :person:`Eutocius <eutocius>`, who begins by
| saying that it is manifest that $r$ is a mean proportional between :g:`$BO$ <0205.g1:/ B O />` and :g:`$OC$ <0205.g1:/ O C />`.
| This is seen as follows.

From $(\beta)$ we derive

.. container:: center

   x : :g:`$BC$ <0205.g1:/ B C />` = k : :g:`$CO$ <0205.g1:/ C O />` = h : r = (k + x) : :g:`$BO$ <0205.g1:/ B O />`,

whence

.. container:: center

   | :g:`$BO$ <0205.g1:/ B O />` : r = (k + x) : h
   | = h : k, by (\alpha),
   | = r : :g:`$CO$ <0205.g1:/ C O />`, by (\beta),

and therefore

.. container:: center

   r^2 = :g:`$BO$ <0205.g1:/ B O />` \,.\, :g:`$CO$ <0205.g1:/ C O />`.

| But the triangles :g:`$BOP$ <0205.g1:< B O P >>`, :g:`$POC$ <0205.g1:< P O C >>` have the angle at :g:`$O$ <0205.g1:< O )>` common, and, since
| :g:`$BO$ <0205.g1:/ B O />` : :g:`$OP$ <0205.g1:/ O P />` = :g:`$OP$ <0205.g1:/ O P />` : :g:`$OC$ <0205.g1:/ O C />`, the triangles are similar and the angles :g:`$OPC$ <0205.g1:< O P C )>`, :g:`$OBP$ <0205.g1:< O B P )>`
| are equal.

| [Up to this point :person:`Aristotle <aristotle>`'s proof is exactly the same; from this point it
| diverges slightly.]

| If now :g:`$CL$ <0205.g1:/ C L />` be drawn parallel to :g:`$BP$ <0205.g1:/ B P />` meeting :g:`$OP$ <0205.g1:/ O P />` in :g:`$L$ <0205.g1:L>`, the angles :g:`$BPC$ <0205.g1:< B P C )>`,
| :g:`$LCP$ <0205.g1:< L C P )>` are equal also.

Therefore the triangles :g:`$BPC$ <0205.g1:< B P C >>`, :g:`$PCL$ <0205.g1:< P C L >>` are similar, and

.. container:: center

   :g:`$BP$ <0205.g1:/ B P />` : :g:`$PC$ <0205.g1:/ P C />` = :g:`$PC$ <0205.g1:/ P C />` : :g:`$CL$ <0205.g1:/ C L />`,

whence

.. container:: center

   | :g:`$BP^2$ <0205.g1:/ B P />` : :g:`$PC^2$ <0205.g1:/ P C />` = :g:`$BP$ <0205.g1:/ B P />` : :g:`$CL$ <0205.g1:/ C L />`
   | = :g:`$BO$ <0205.g1:/ B O />` : :g:`$OC$ <0205.g1:/ O C />`, by parallels,
   | = :g:`$BO^2$ <0205.g1:/ B O />` : :g:`$OP^2$ <0205.g1:/ O P />` (since :g:`$BO$ <0205.g1:/ B O />` : :g:`$OP$ <0205.g1:/ O P />` = :g:`$OP$ <0205.g1:/ O P />` : :g:`$OC$ <0205.g1:/ O C />`).

Therefore

.. container:: center

   | :g:`$BP$ <0205.g1:/ B P />` : :g:`$PC$ <0205.g1:/ P C />` = :g:`$BO$ <0205.g1:/ B O />` : :g:`$OP$ <0205.g1:/ O P />`
   | = h : k (for :g:`$OP$ <0205.g1:/ O P />` = r).

| [:person:`Aristotle <aristotle>` infers this more directly from the similar triangles :g:`$POB$ <0205.g1:< P O B >>`, :g:`$COP$ <0205.g1:< C O P >>`.
| Since these triangles are similar,

.. container:: center

   :g:`$OP$ <0205.g1:/ O P />` : :g:`$CP$ <0205.g1:/ C P />` = :g:`$OB$ <0205.g1:/ O B />` : :g:`$BP$ <0205.g1:/ B P />`,

whence

.. container:: center

   | :g:`$BP$ <0205.g1:/ B P />` : :g:`$PC$ <0205.g1:/ P C />` = :g:`$BO$ <0205.g1:/ B O />` : :g:`$OP$ <0205.g1:/ O P />`
   | = h : k.]

| :person:`Apollonius <apollonius>` proves lastly, by :term:`*reductio ad absurdum* <reductio-ad-absurdum>`, that the last equation
| cannot be true with reference to any point :g:`$P$ <0205.g1:P>` which is not on the circle so
| described.

----

PROPOSITION 4.
--------------

.. enunciation::

   In equiangular triangles the sides about the equal angles are proportional, and those are corresponding sides which subtend the equal angles.
