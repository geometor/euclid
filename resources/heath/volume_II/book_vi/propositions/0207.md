Let <span data-ref="0207.g1:< A B C >">$ABC$</span>, <span data-ref="0207.g1:< D C E >">$DCE$</span> be equiangular triangles having the<br />
angle <span data-ref="0207.g1:< A B C )">$ABC$</span> equal to the angle<br />
<span data-ref="0207.g1:< D C E )">$DCE$</span>, the angle <span data-ref="0207.g1:< B A C )">$BAC$</span> to the<br />
angle <span data-ref="0207.g1:< C D E )">$CDE$</span>, and further the angle<br />
<span data-ref="0207.g1:< A C B )">$ACB$</span> to the angle <span data-ref="0207.g1:< C E D )">$CED$</span>;

I say that in the triangles <span data-ref="0207.g1:< A B C >">$ABC$</span>,<br />
<span data-ref="0207.g1:< D C E >">$DCE$</span> the sides about the equal<br />
angles are proportional, and those<br />
are corresponding sides which<br />
subtend the equal angles.

![Proposition 4](0207.g1.svg)

For let <span data-ref="0207.g1:/ B C /">$BC$</span> be placed in a<br />
straight line with <span data-ref="0207.g1:/ C E /">$CE$</span>.

Then, since the angles <span data-ref="0207.g1:< A B C )">$ABC$</span>, <span data-ref="0207.g1:< A C B )">$ACB$</span> are less than two right<br />
angles, <span class="justification">[I. 17]</span><br />
and the angle <span data-ref="0207.g1:< A C B )">$ACB$</span> is equal to the angle <span data-ref="0207.g1:< D E C )">$DEC$</span>,
<p class="assertion">therefore the angles <span data-ref="0207.g1:< A B C )">$ABC$</span>, <span data-ref="0207.g1:< D E C )">$DEC$</span> are less than two right<br />
angles;</p>
<p class="assertion">therefore <span data-ref="0207.g1:/ B A /">$BA$</span>, <span data-ref="0207.g1:/ E D /">$ED$</span>, when produced, will meet. <span class="justification">[I. Post. 5]</span></p>

Let them be produced and meet at <span data-ref="0207.g1:F">$F$</span>.

Now, since the angle <span data-ref="0207.g1:< D C E )">$DCE$</span> is equal to the angle <span data-ref="0207.g1:< A B C )">$ABC$</span>,
<p class="assertion"><span data-ref="0207.g1:/ B F /">$BF$</span> is parallel to <span data-ref="0207.g1:/ C D /">$CD$</span>. <span class="justification">[I. 28]</span></p>

Again, since the angle <span data-ref="0207.g1:< A C B )">$ACB$</span> is equal to the angle <span data-ref="0207.g1:< D E C )">$DEC$</span>,
<p class="assertion"><span data-ref="0207.g1:/ A C /">$AC$</span> is parallel to <span data-ref="0207.g1:/ F E /">$FE$</span>. <span class="justification">[I. 28]</span></p>

<p class="assertion">Therefore <span data-ref="0207.g1:< F A C D >">$FACD$</span> is a parallelogram;</p>
<p class="assertion">therefore <span data-ref="0207.g1:/ F A /">$FA$</span> is equal to <span data-ref="0207.g1:/ D C /">$DC$</span>, and <span data-ref="0207.g1:/ A C /">$AC$</span> to <span data-ref="0207.g1:/ F D /">$FD$</span>. <span class="justification">[I. 34]</span></p>

And, since <span data-ref="0207.g1:/ A C /">$AC$</span> has been drawn parallel to <span data-ref="0207.g1:/ F E /">$FE$</span>, one side<br />
of the triangle <span data-ref="0207.g1:< F B E >">$FBE$</span>,
<p class="assertion">therefore, as <span data-ref="0207.g1:/ B A /">$BA$</span> is to <span data-ref="0207.g1:/ A F /">$AF$</span>, so is <span data-ref="0207.g1:/ B C /">$BC$</span> to <span data-ref="0207.g1:/ C E /">$CE$</span>. <span class="justification">[VI. 2]</span></p>

<p class="sub-clause">But <span data-ref="0207.g1:/ A F /">$AF$</span> is equal to <span data-ref="0207.g1:/ C D /">$CD$</span>;</p>
<p class="assertion">therefore, as <span data-ref="0207.g1:/ B A /">$BA$</span> is to <span data-ref="0207.g1:/ C D /">$CD$</span>, so is <span data-ref="0207.g1:/ B C /">$BC$</span> to <span data-ref="0207.g1:/ C E /">$CE$</span>,<br />
and alternately, as <span data-ref="0207.g1:/ A B /">$AB$</span> is to <span data-ref="0207.g1:/ B C /">$BC$</span>, so is <span data-ref="0207.g1:/ D C /">$DC$</span> to <span data-ref="0207.g1:/ C E /">$CE$</span>. <span class="justification">[V. 16]</span></p>

Again, since <span data-ref="0207.g1:/ C D /">$CD$</span> is parallel to <span data-ref="0207.g1:/ B F /">$BF$</span>,
<p class="assertion">therefore, as <span data-ref="0207.g1:/ B C /">$BC$</span> is to <span data-ref="0207.g1:/ C E /">$CE$</span>, so is <span data-ref="0207.g1:/ F D /">$FD$</span> to <span data-ref="0207.g1:/ D E /">$DE$</span>. <span class="justification">[VI. 2]</span></p>

<p class="sub-clause">But <span data-ref="0207.g1:/ F D /">$FD$</span> is equal to <span data-ref="0207.g1:/ A C /">$AC$</span>;</p>
<p class="assertion">therefore, as <span data-ref="0207.g1:/ B C /">$BC$</span> is to <span data-ref="0207.g1:/ C E /">$CE$</span>, so is <span data-ref="0207.g1:/ A C /">$AC$</span> to <span data-ref="0207.g1:/ D E /">$DE$</span>,<br />
and alternately, as <span data-ref="0207.g1:/ B C /">$BC$</span> is to <span data-ref="0207.g1:/ C A /">$CA$</span>, so is <span data-ref="0207.g1:/ C E /">$CE$</span> to <span data-ref="0207.g1:/ E D /">$ED$</span>. <span class="justification">[V. 16]</span></p>
