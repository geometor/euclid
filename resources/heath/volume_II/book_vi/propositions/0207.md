Let <span data-ref="0207.g1:&lt; A B C &gt;">$ABC$</span>, <span data-ref="0207.g1:&lt; D C E &gt;">$DCE$</span> be equiangular triangles having the angle <span data-ref="0207.g1:&lt; A B C )">$ABC$</span> equal to the angle <span data-ref="0207.g1:&lt; D C E )">$DCE$</span>, the angle <span data-ref="0207.g1:&lt; B A C )">$BAC$</span> to the angle <span data-ref="0207.g1:&lt; C D E )">$CDE$</span>, and further the angle <span data-ref="0207.g1:&lt; A C B )">$ACB$</span> to the angle <span data-ref="0207.g1:&lt; C E D )">$CED$</span>;

I say that in the triangles <span data-ref="0207.g1:&lt; A B C &gt;">$ABC$</span>, <span data-ref="0207.g1:&lt; D C E &gt;">$DCE$</span> the sides about the equal angles are proportional, and those are corresponding sides which subtend the equal angles.

![Proposition 4](0207.g1.svg)

For let <span data-ref="0207.g1:/ B C /">$BC$</span> be placed in a straight line with <span data-ref="0207.g1:/ C E /">$CE$</span>.

Then, since the angles <span data-ref="0207.g1:&lt; A B C )">$ABC$</span>, <span data-ref="0207.g1:&lt; A C B )">$ACB$</span> are less than two right angles, [I. 17]
and the angle <span data-ref="0207.g1:&lt; A C B )">$ACB$</span> is equal to the angle <span data-ref="0207.g1:&lt; D E C )">$DEC$</span>,
therefore the angles <span data-ref="0207.g1:&lt; A B C )">$ABC$</span>, <span data-ref="0207.g1:&lt; D E C )">$DEC$</span> are less than two right angles;
therefore <span data-ref="0207.g1:/ B A /">$BA$</span>, <span data-ref="0207.g1:/ E D /">$ED$</span>, when produced, will meet. [I. Post. 5]

Let them be produced and meet at <span data-ref="0207.g1:F">$F$</span>.

Now, since the angle <span data-ref="0207.g1:&lt; D C E )">$DCE$</span> is equal to the angle <span data-ref="0207.g1:&lt; A B C )">$ABC$</span>,
<span data-ref="0207.g1:/ B F /">$BF$</span> is parallel to <span data-ref="0207.g1:/ C D /">$CD$</span>. [I. 28]

Again, since the angle <span data-ref="0207.g1:&lt; A C B )">$ACB$</span> is equal to the angle <span data-ref="0207.g1:&lt; D E C )">$DEC$</span>,
<span data-ref="0207.g1:/ A C /">$AC$</span> is parallel to <span data-ref="0207.g1:/ F E /">$FE$</span>. [I. 28]

Therefore <span data-ref="0207.g1:&lt; F A C D &gt;">$FACD$</span> is a parallelogram;
therefore <span data-ref="0207.g1:/ F A /">$FA$</span> is equal to <span data-ref="0207.g1:/ D C /">$DC$</span>, and <span data-ref="0207.g1:/ A C /">$AC$</span> to <span data-ref="0207.g1:/ F D /">$FD$</span>. [I. 34]

And, since <span data-ref="0207.g1:/ A C /">$AC$</span> has been drawn parallel to <span data-ref="0207.g1:/ F E /">$FE$</span>, one side of the triangle <span data-ref="0207.g1:&lt; F B E &gt;">$FBE$</span>,
therefore, as <span data-ref="0207.g1:/ B A /">$BA$</span> is to <span data-ref="0207.g1:/ A F /">$AF$</span>, so is <span data-ref="0207.g1:/ B C /">$BC$</span> to <span data-ref="0207.g1:/ C E /">$CE$</span>. [VI. 2]

But <span data-ref="0207.g1:/ A F /">$AF$</span> is equal to <span data-ref="0207.g1:/ C D /">$CD$</span>;
therefore, as <span data-ref="0207.g1:/ B A /">$BA$</span> is to <span data-ref="0207.g1:/ C D /">$CD$</span>, so is <span data-ref="0207.g1:/ B C /">$BC$</span> to <span data-ref="0207.g1:/ C E /">$CE$</span>,
and alternately, as <span data-ref="0207.g1:/ A B /">$AB$</span> is to <span data-ref="0207.g1:/ B C /">$BC$</span>, so is <span data-ref="0207.g1:/ D C /">$DC$</span> to <span data-ref="0207.g1:/ C E /">$CE$</span>. [V. 16]

Again, since <span data-ref="0207.g1:/ C D /">$CD$</span> is parallel to <span data-ref="0207.g1:/ B F /">$BF$</span>,
therefore, as <span data-ref="0207.g1:/ B C /">$BC$</span> is to <span data-ref="0207.g1:/ C E /">$CE$</span>, so is <span data-ref="0207.g1:/ F D /">$FD$</span> to <span data-ref="0207.g1:/ D E /">$DE$</span>. [VI. 2]

But <span data-ref="0207.g1:/ F D /">$FD$</span> is equal to <span data-ref="0207.g1:/ A C /">$AC$</span>;
therefore, as <span data-ref="0207.g1:/ B C /">$BC$</span> is to <span data-ref="0207.g1:/ C E /">$CE$</span>, so is <span data-ref="0207.g1:/ A C /">$AC$</span> to <span data-ref="0207.g1:/ D E /">$DE$</span>,
and alternately, as <span data-ref="0207.g1:/ B C /">$BC$</span> is to <span data-ref="0207.g1:/ C A /">$CA$</span>, so is <span data-ref="0207.g1:/ C E /">$CE$</span> to <span data-ref="0207.g1:/ E D /">$ED$</span>. [V. 16]
