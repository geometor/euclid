Todhunter remarks that "the manner in which the two triangles are to be placed is very imperfectly described; their bases are to be in the same straight line and contiguous, their vertices are to be on the same side of the base, and each of the two angles which have a common vertex is to be equal to the remote angle of the other triangle." But surely Euclid's description is sufficient, except for not saying that <span data-ref="0207.g1:B">$B$</span> and <span data-ref="0207.g1:D">$D$</span> must be on the same side of <span data-ref="0207.g1:/ B C E /">$BCE$</span>.

$\small{VI}$. 4 can be immediately deduced from $\small{VI}$. 2 if we superpose one triangle on the other three times in succession, so that each angle successively coincides with its equal, the triangles being similarly situated, e.g. if (<span data-ref="0207.g1:< A )">$A$</span>, <span data-ref="0207.g1:< B )">$B$</span>, <span data-ref="0207.g1:< C )">$C$</span> and <span data-ref="0209.g2:< D )">$D$</span>, <span data-ref="0209.g2:< E )">$E$</span>, <span data-ref="0209.g2:< F )">$F$</span> being the equal angles respectively) we apply the angle <span data-ref="0209.g2:< D E F )">$DEF$</span> to the angle <span data-ref="0207.g1:< A B C )">$ABC$</span> so that <span data-ref="0209.g2:D">$D$</span> lies on <span data-ref="0207.g1:/ A B /">$AB$</span> (produced if necessary) and <span data-ref="0209.g2:F">$F$</span> on <span data-ref="0207.g1:/ B C /">$BC$</span> (produced if necessary). De Morgan prefers this method. "Abandon," he says, "the peculiar mode of construction by which Euclid proves two cases at once; make an angle coincide with its equal, and suppose this process repeated three times, one for each angle."

### PROPOSITION 5.

*If two triangles have their sides proportional, the triangles will be equiangular and will have those angles equal which the corresponding sides subtend.*

Let <span data-ref="0209.g1:< A B C >">$ABC$</span>, <span data-ref="0209.g2:< D E F >">$DEF$</span> be two triangles having their sides proportional, so that,
<p align="center">as <span data-ref="0209.g1:/ A B /">$AB$</span> is to <span data-ref="0209.g1:/ B C /">$BC$</span>, so is <span data-ref="0209.g2:/ D E /">$DE$</span> to <span data-ref="0209.g2:/ E F /">$EF$</span>,</p>
<p align="center">as <span data-ref="0209.g1:/ B C /">$BC$</span> is to <span data-ref="0209.g1:/ C A /">$CA$</span>, so is <span data-ref="0209.g2:/ E F /">$EF$</span> to <span data-ref="0209.g2:/ F D /">$FD$</span>,</p>
and further, as <span data-ref="0209.g1:/ B A /">$BA$</span> is to <span data-ref="0209.g1:/ A C /">$AC$</span>, so is <span data-ref="0209.g2:/ E D /">$ED$</span> to <span data-ref="0209.g2:/ D F /">$DF$</span>;
I say that the triangle <span data-ref="0209.g1:< A B C >">$ABC$</span> is equiangular with the triangle <span data-ref="0209.g2:< D E F >">$DEF$</span>, and they will have those angles equal which the corresponding sides subtend, namely the angle <span data-ref="0209.g1:< A B C )">$ABC$</span> to the angle <span data-ref="0209.g2:< D E F )">$DEF$</span>, the angle <span data-ref="0209.g1:< B C A )">$BCA$</span> to the angle <span data-ref="0209.g2:< E F D )">$EFD$</span>, and further the angle <span data-ref="0209.g1:< B A C )">$BAC$</span> to the angle <span data-ref="0209.g2:< E D F )">$EDF$</span>.
