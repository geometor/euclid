For, since the angle <span data-ref="0216.g1:&lt; B A C )">$BAC$</span> is equal to the angle <span data-ref="0216.g1:&lt; A D B )">$ADB$</span>, for each is right,
and the angle at <span data-ref="0216.g1:&lt; A B C )">$B$</span> is common to the two triangles <span data-ref="0216.g1:&lt; A B C &gt;">$ABC$</span> and <span data-ref="0216.g1:&lt; A B D &gt;">$ABD$</span>,
therefore the remaining angle <span data-ref="0216.g1:&lt; A C B )">$ACB$</span> is equal to the remaining angle <span data-ref="0216.g1:&lt; B A D )">$BAD$</span>; [I. 32]
therefore the triangle <span data-ref="0216.g1:&lt; A B C &gt;">$ABC$</span> is equiangular with the triangle <span data-ref="0216.g1:&lt; A B D &gt;">$ABD$</span>.

Therefore, as <span data-ref="0216.g1:/ B C /">$BC$</span> which subtends the right angle in the triangle <span data-ref="0216.g1:&lt; A B C &gt;">$ABC$</span> is to <span data-ref="0216.g1:/ B A /">$BA$</span> which subtends the right angle in the triangle <span data-ref="0216.g1:&lt; A B D &gt;">$ABD$</span>, so is <span data-ref="0216.g1:/ A B /">$AB$</span> itself which subtends the angle at <span data-ref="0216.g1:&lt; A C B )">$C$</span> in the triangle <span data-ref="0216.g1:&lt; A B C &gt;">$ABC$</span> to <span data-ref="0216.g1:/ B D /">$BD$</span> which subtends the equal angle <span data-ref="0216.g1:&lt; B A D )">$BAD$</span> in the triangle <span data-ref="0216.g1:&lt; A B D &gt;">$ABD$</span>, and so also is <span data-ref="0216.g1:/ A C /">$AC$</span> to <span data-ref="0216.g1:/ A D /">$AD$</span> which subtends the angle at <span data-ref="0216.g1:&lt; A B C )">$B$</span> common to the two triangles. [VI. 4]

Therefore the triangle <span data-ref="0216.g1:&lt; A B C &gt;">$ABC$</span> is both equiangular to the triangle <span data-ref="0216.g1:&lt; A B D &gt;">$ABD$</span> and has the sides about the equal angles proportional.

Therefore the triangle <span data-ref="0216.g1:&lt; A B C &gt;">$ABC$</span> is similar to the triangle <span data-ref="0216.g1:&lt; A B D &gt;">$ABD$</span>. [VI. Def. 1]

Similarly we can prove that the triangle <span data-ref="0216.g1:&lt; A B C &gt;">$ABC$</span> is also similar to the triangle <span data-ref="0216.g1:&lt; A D C &gt;">$ADC$</span>;
therefore each of the triangles <span data-ref="0216.g1:&lt; A B D &gt;">$ABD$</span>, <span data-ref="0216.g1:&lt; A D C &gt;">$ADC$</span> is similar to the whole <span data-ref="0216.g1:&lt; A B C &gt;">$ABC$</span>.

I say next that the triangles <span data-ref="0216.g1:&lt; A B D &gt;">$ABD$</span>, <span data-ref="0216.g1:&lt; A D C &gt;">$ADC$</span> are also similar to one another.

For, since the right angle <span data-ref="0216.g1:&lt; B D A )">$BDA$</span> is equal to the right angle <span data-ref="0216.g1:&lt; A D C )">$ADC$</span>,
and moreover the angle <span data-ref="0216.g1:&lt; B A D )">$BAD$</span> was also proved equal to the angle at <span data-ref="0216.g1:&lt; A C B )">$C$</span>,
therefore the remaining angle at <span data-ref="0216.g1:&lt; A B D )">$B$</span> is also equal to the remaining angle <span data-ref="0216.g1:&lt; D A C )">$DAC$</span>; [I. 32]
therefore the triangle <span data-ref="0216.g1:&lt; A B D &gt;">$ABD$</span> is equiangular with the triangle <span data-ref="0216.g1:&lt; A D C &gt;">$ADC$</span>.
