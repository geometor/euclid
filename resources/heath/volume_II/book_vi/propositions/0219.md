Because <span data-ref="0218.g2:/ E D /">$ED$</span> is parallel to one of the sides of the triangle <span data-ref="0218.g2:&lt; A B C &gt;">$ABC$</span>, viz. to <span data-ref="0218.g2:/ B C /">$BC$</span>,
as <span data-ref="0218.g2:/ C D /">$CD$</span> is to <span data-ref="0218.g2:/ D A /">$DA$</span>, so is <span data-ref="0218.g2:/ B E /">$BE$</span> to <span data-ref="0218.g2:/ E A /">$EA$</span>, [VI. 2]
and, *componendo*,
<span data-ref="0218.g2:/ C A /">$CA$</span> is to <span data-ref="0218.g2:/ A D /">$AD$</span>, as <span data-ref="0218.g2:/ B A /">$BA$</span> to <span data-ref="0218.g2:/ A E /">$AE$</span>. [V. 18]

But <span data-ref="0218.g2:/ C A /">$CA$</span> is a multiple of <span data-ref="0218.g2:/ A D /">$AD$</span>;
therefore <span data-ref="0218.g2:/ B A /">$BA$</span> is the same multiple of <span data-ref="0218.g2:/ A E /">$AE$</span>. [Prop. D]

Whatever part therefore <span data-ref="0218.g2:/ A D /">$AD$</span> is of <span data-ref="0218.g2:/ A C /">$AC$</span>, <span data-ref="0218.g2:/ A E /">$AE$</span> is the same part of <span data-ref="0218.g2:/ A B /">$AB$</span>;
wherefore from the straight line <span data-ref="0218.g2:/ A B /">$AB$</span> the part required is cut off."

The use of Simson's Prop. D can be avoided, as noted by Camerer after Baermann, in the following way. We first prove, as above, that
<span data-ref="0218.g2:/ C A /">$CA$</span> is to <span data-ref="0218.g2:/ A D /">$AD$</span> as <span data-ref="0218.g2:/ B A /">$BA$</span> is to <span data-ref="0218.g2:/ A E /">$AE$</span>.

Then we infer that, alternately,
<span data-ref="0218.g2:/ C A /">$CA$</span> is to <span data-ref="0218.g2:/ B A /">$BA$</span> as <span data-ref="0218.g2:/ A D /">$AD$</span> to <span data-ref="0218.g2:/ A E /">$AE$</span>. [V. 16]

But <span data-ref="0218.g2:/ A D /">$AD$</span> is to <span data-ref="0218.g2:/ A E /">$AE$</span> as $n \cdot$ <span data-ref="0218.g2:/ A D /">$AD$</span> to $n \cdot$ <span data-ref="0218.g2:/ A E /">$AE$</span>
(where $n$ is the number of times that <span data-ref="0218.g2:/ A D /">$AD$</span> is contained in <span data-ref="0218.g2:/ A C /">$AC$</span>); [V. 15]
whence <span data-ref="0218.g2:/ A C /">$AC$</span> is to <span data-ref="0218.g2:/ A B /">$AB$</span> as $n \cdot$ <span data-ref="0218.g2:/ A D /">$AD$</span> is to $n \cdot$ <span data-ref="0218.g2:/ A E /">$AE$</span>. [V. 11]

In this proportion the first term is equal to the third; therefore the second is equal to the fourth, [V. 14]
so that <span data-ref="0218.g2:/ A B /">$AB$</span> is equal to $n$ times <span data-ref="0218.g2:/ A E /">$AE$</span>.

Prop. 9 is of course only a particular case of Prop. 10.

### PROPOSITION 10.

*To cut a given uncut straight line similarly to a given cut straight line.*

Let <span data-ref="0219.g1:/ A B /">$AB$</span> be the given uncut straight line, and <span data-ref="0219.g1:/ A C /">$AC$</span> the straight line cut at the points <span data-ref="0219.g1:D">$D$</span>, <span data-ref="0219.g1:E">$E$</span>; and let them be so placed as to contain any angle;
let <span data-ref="0219.g1:/ C B /">$CB$</span> be joined, and through <span data-ref="0219.g1:D">$D$</span>, <span data-ref="0219.g1:E">$E$</span> let <span data-ref="0219.g1:/ D F /">$DF$</span>, <span data-ref="0219.g1:/ E G /">$EG$</span> be drawn parallel to <span data-ref="0219.g1:/ B C /">$BC$</span>, and through <span data-ref="0219.g1:D">$D$</span> let <span data-ref="0219.g1:/ D H K /">$DHK$</span> be drawn parallel to <span data-ref="0219.g1:/ A B /">$AB$</span>. [I. 31]

![Proposition 10](0219.g1.svg)

Therefore each of the figures <span data-ref="0219.g1:&lt; F H &gt;">$FH$</span>, <span data-ref="0219.g1:&lt; H B &gt;">$HB$</span> is a parallelogram;
therefore <span data-ref="0219.g1:/ D H /">$DH$</span> is equal to <span data-ref="0219.g1:/ F G /">$FG$</span> and <span data-ref="0219.g1:/ H K /">$HK$</span> to <span data-ref="0219.g1:/ G B /">$GB$</span>. [I. 34]

Now, since the straight line <span data-ref="0219.g1:/ H E /">$HE$</span> has been drawn parallel to <span data-ref="0219.g1:/ K C /">$KC$</span>, one of the sides of the triangle <span data-ref="0219.g1:&lt; D K C &gt;">$DKC$</span>,
therefore, proportionally, as <span data-ref="0219.g1:/ C E /">$CE$</span> is to <span data-ref="0219.g1:/ E D /">$ED$</span>, so is <span data-ref="0219.g1:/ K H /">$KH$</span> to <span data-ref="0219.g1:/ H D /">$HD$</span>. [VI. 2]
