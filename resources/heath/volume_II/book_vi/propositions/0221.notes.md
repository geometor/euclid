- **Rule of Three**: Heath identifies this classical construction as the exact geometric counterpart of the arithmetic "rule of three" ($A : B = C : x \implies x = \frac{B \cdot C}{A}$).
- **Anti-parallel Lines**: Heath introduces the concept of lines being *anti-parallel* with respect to an angle: when $\angle DGH = \angle DEF$, producing similar triangles in reverse orientation.

## Mathematical Observations
- **Proposition 12 (Fourth Proportional)**:
  - Given segments $A, B, C$, find $x$ such that $A : B = C : x$.
  - Construct angle $EDF$. On ray $DE$, set $DG = A, GE = B$. On ray $DF$, set $DH = C$.
  - Join $GH$, draw $EF \parallel GH$ meeting $DF$ at $F$.
  - By VI. 2, $DG : GE = DH : HF \implies A : B = C : HF$, so $HF$ is the sought fourth proportional.
- **Anti-parallel Construction**:
  - Sets $DE = A$ on one ray, $DF = B$ and $DG = C$ on the other ray.
  - Making $\angle DGH = \angle DEF$ makes $\triangle DGH \sim \triangle DEF$, yielding $DE : DF = DG : DH \implies A : B = C : DH$.
