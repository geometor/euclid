Let <span data-ref="0227.g1:< A B C >">$ABC$</span>, <span data-ref="0227.g1:< A D E >">$ADE$</span> be two triangles such that the angles <span data-ref="0227.g1:< B A C )">$BAC$</span>, <span data-ref="0227.g1:< D A E )">$DAE$</span> are<br />
supplementary, and also
<p class="assertion"><span data-ref="0227.g1:/ C A /">$CA$</span> : <span data-ref="0227.g1:/ A D /">$AD$</span> = <span data-ref="0227.g1:/ E A /">$EA$</span> : <span data-ref="0227.g1:/ A B /">$AB$</span>.</p>

![Proposition 15, supplementary case](0227.g1.svg)

In this case we can place the triangles so that<br />
<span data-ref="0227.g1:/ C A /">$CA$</span> is in a straight line with <span data-ref="0227.g1:/ A D /">$AD$</span>, and <span data-ref="0227.g1:/ A B /">$AB$</span> lies<br />
along <span data-ref="0227.g1:/ A E /">$AE$</span> (since the angle <span data-ref="0227.g1:< E A C )">$EAC$</span>, being supple-<br />
mentary to the angle <span data-ref="0227.g1:< E A D )">$EAD$</span>, is equal to the angle<br />
<span data-ref="0227.g1:< B A C )">$BAC$</span>).<br />
If we join <span data-ref="0227.g1:/ B D /">$BD$</span>, the proof given by Euclid<br />
applies to this case also.

It is true that VI. 15 can be immediately inferred from VI. 14, since a<br />
triangle is half of a parallelogram with the same base and height. But,<br />
Euclid's object being to give the student a grasp of *methods* rather than<br />
results, there seems to be no advantage in deducing one proposition from the<br />
other instead of using the same method on each.

### PROPOSITION 16.

<p class="enunciation">If four straight lines be proportional, the rectangle con-<br />
tained by the extremes is equal to the rectangle contained by<br />
the means; and, if the rectangle contained by the extremes be<br />
equal to the rectangle contained by the means, the four straight<br />
lines will be proportional.</p>

Let the four straight lines <span data-ref="0227.g2:/ A B /">$AB$</span>, <span data-ref="0227.g3:/ C D /">$CD$</span>, <span data-ref="0227.g2:/ E /">$E$</span>, <span data-ref="0227.g3:/ F /">$F$</span> be proportional,<br />
so that,
<p class="assertion">as <span data-ref="0227.g2:/ A B /">$AB$</span> is to <span data-ref="0227.g3:/ C D /">$CD$</span>, so is <span data-ref="0227.g2:/ E /">$E$</span> to <span data-ref="0227.g3:/ F /">$F$</span>;</p>
I say that the rectangle contained by <span data-ref="0227.g2:/ A B /">$AB$</span>, <span data-ref="0227.g3:/ F /">$F$</span> is equal to the<br />
rectangle contained by <span data-ref="0227.g3:/ C D /">$CD$</span>, <span data-ref="0227.g2:/ E /">$E$</span>.

![Book VI Proposition 16 (BG and E)](0227.g2.svg)
![Book VI Proposition 16 (DH and F)](0227.g3.svg)

Let <span data-ref="0227.g2:/ A G /">$AG$</span>, <span data-ref="0227.g3:/ C H /">$CH$</span> be drawn from the points <span data-ref="0227.g2:A">$A$</span>, <span data-ref="0227.g3:C">$C$</span> at right<br />
angles to the straight lines <span data-ref="0227.g2:/ A B /">$AB$</span>, <span data-ref="0227.g3:/ C D /">$CD$</span>, and let <span data-ref="0227.g2:/ A G /">$AG$</span> be made<br />
equal to <span data-ref="0227.g3:/ F /">$F$</span>, and <span data-ref="0227.g3:/ C H /">$CH$</span> equal to <span data-ref="0227.g2:/ E /">$E$</span>.

Let the parallelograms <span data-ref="0227.g2:< B G >">$BG$</span>, <span data-ref="0227.g3:< D H >">$DH$</span> be completed.

Then since, as <span data-ref="0227.g2:/ A B /">$AB$</span> is to <span data-ref="0227.g3:/ C D /">$CD$</span>, so is <span data-ref="0227.g2:/ E /">$E$</span> to <span data-ref="0227.g3:/ F /">$F$</span>,<br />
<p class="sub-clause">while <span data-ref="0227.g2:/ E /">$E$</span> is equal to <span data-ref="0227.g3:/ C H /">$CH$</span>, and <span data-ref="0227.g3:/ F /">$F$</span> to <span data-ref="0227.g2:/ A G /">$AG$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0227.g2:/ A B /">$AB$</span> is to <span data-ref="0227.g3:/ C D /">$CD$</span>, so is <span data-ref="0227.g3:/ C H /">$CH$</span> to <span data-ref="0227.g2:/ A G /">$AG$</span>.</p>

<p class="assertion">Therefore in the parallelograms <span data-ref="0227.g2:< B G >">$BG$</span>, <span data-ref="0227.g3:< D H >">$DH$</span> the sides about<br />
the equal angles are reciprocally proportional.</p>
