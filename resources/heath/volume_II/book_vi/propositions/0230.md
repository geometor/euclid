The following converse of Simson's Prop. B may be given: *If a straight line <span data-ref="0230.g1:/ A D /">$AD$</span> be drawn from the vertex <span data-ref="0230.g1:A">$A$</span> of a triangle to meet the base, so that the square on <span data-ref="0230.g1:/ A D /">$AD$</span> together with the rectangle <span data-ref="0230.g1:/ B D /">$BD$</span>, <span data-ref="0230.g1:/ D C /">$DC$</span> is equal to the rectangle <span data-ref="0230.g1:/ B A /">$BA$</span>, <span data-ref="0230.g1:/ A C /">$AC$</span>, the line <span data-ref="0230.g1:/ A D /">$AD$</span> will bisect the angle <span data-ref="0230.g1:&lt; B A C )">$BAC$</span> except when the sides <span data-ref="0230.g1:/ A B /">$AB$</span>, <span data-ref="0230.g1:/ A C /">$AC$</span> are equal, in which case every line drawn to the base will have the property mentioned.*

Let the circumscribed circle be drawn, and let <span data-ref="0230.g1:/ A D /">$AD$</span> produced meet it in <span data-ref="0230.g1:E">$E$</span>; join <span data-ref="0230.g1:/ C E /">$CE$</span>.

The rectangle <span data-ref="0230.g1:/ B D /">$BD$</span>, <span data-ref="0230.g1:/ D C /">$DC$</span> is equal to the rectangle <span data-ref="0230.g1:/ E D /">$ED$</span>, <span data-ref="0230.g1:/ D A /">$DA$</span>. [III. 35]

Add to each the square on <span data-ref="0230.g1:/ A D /">$AD$</span>;
therefore the rectangle <span data-ref="0230.g1:/ B A /">$BA$</span>, <span data-ref="0230.g1:/ A C /">$AC$</span> is equal to the rectangle <span data-ref="0230.g1:/ E A /">$EA$</span>, <span data-ref="0230.g1:/ A D /">$AD$</span>.
[hyp. and II. 3]

Hence
$$\text{<span data-ref="0230.g1:/ A B /">$AB$</span> is to <span data-ref="0230.g1:/ A D /">$AD$</span> as <span data-ref="0230.g1:/ A E /">$AE$</span> to <span data-ref="0230.g1:/ A C /">$AC$</span>.}\quad\text{[VI. 16]}$$
But the angle <span data-ref="0230.g1:&lt; A B D )">$ABD$</span> is equal to the angle <span data-ref="0230.g1:&lt; A E C )">$AEC$</span>. [III. 21]

Therefore the angles <span data-ref="0230.g1:&lt; B D A )">$BDA$</span>, <span data-ref="0230.g1:&lt; E C A )">$ECA$</span> are either equal or supplementary.
[VI. 7 and note]

(*a*) If they are equal, the angles <span data-ref="0230.g1:&lt; B A D )">$BAD$</span>, <span data-ref="0230.g1:&lt; E A C )">$EAC$</span> are also equal, and <span data-ref="0230.g1:/ A D /">$AD$</span> bisects the angle <span data-ref="0230.g1:&lt; B A C )">$BAC$</span>.

(*b*) If they are supplementary, the angle <span data-ref="0230.g1:&lt; A D C )">$ADC$</span> must be equal to the angle <span data-ref="0230.g1:&lt; A C E )">$ACE$</span>.

Therefore the angles <span data-ref="0230.g1:&lt; B A D )">$BAD$</span>, <span data-ref="0230.g1:&lt; A B D )">$ABD$</span> are together equal to the angles <span data-ref="0230.g1:&lt; A C B )">$ACB$</span>, <span data-ref="0230.g1:&lt; B C E )">$BCE$</span>, *i.e.* to the angles <span data-ref="0230.g1:&lt; A C D )">$ACD$</span>, <span data-ref="0230.g1:&lt; B A D )">$BAD$</span>.

Take away the common angle <span data-ref="0230.g1:&lt; B A D )">$BAD$</span>, and
$$\text{the angles <span data-ref="0230.g1:&lt; A B D )">$ABD$</span>, <span data-ref="0230.g1:&lt; A C D )">$ACD$</span> are equal, or}$$
$$\text{<span data-ref="0230.g1:/ A B /">$AB$</span> is equal to <span data-ref="0230.g1:/ A C /">$AC$</span>.}$$

![Converse of Simson's Prop. B](0230.g1.svg)

Euclid himself assumes, in Prop. 67 of the *Data*, the result of so much of this proposition as relates to the case where <span data-ref="0230.g1:/ B A /">$BA$</span> = <span data-ref="0230.g1:/ A C /">$AC$</span>. He assumes namely, without proof, that, if <span data-ref="0230.g1:/ B A /">$BA$</span> = <span data-ref="0230.g1:/ A C /">$AC$</span>, and if <span data-ref="0230.g1:D">$D$</span> be any point on <span data-ref="0230.g1:/ B C /">$BC$</span>, the rectangle <span data-ref="0230.g1:/ B D /">$BD$</span>, <span data-ref="0230.g1:/ D C /">$DC$</span> together with the square on <span data-ref="0230.g1:/ A D /">$AD$</span> is equal to the square on <span data-ref="0230.g1:/ A B /">$AB$</span>.

### PROPOSITION C.

*If from any angle of a triangle a straight line be drawn perpendicular to the opposite side, the rectangle contained by the other two sides of the triangle is equal to the rectangle contained by the perpendicular and the diameter of the circle circumscribed about the triangle.*

Let <span data-ref="0230.g3:&lt; A B C &gt;">$ABC$</span> be a triangle and <span data-ref="0230.g3:/ A D /">$AD$</span> the perpendicular on <span data-ref="0230.g3:/ B C /">$BC$</span>. Draw the diameter <span data-ref="0230.g3:/ A E /">$AE$</span> of the circle circumscribed about the triangle <span data-ref="0230.g3:&lt; A B C &gt;">$ABC$</span>.
