Another proof of this proposition, and of its converse, is indicated by<br />
Dr Lachlan (*Elements of Euclid*, pp. 273—4). It depends on two preliminary<br />
propositions.

(1) *If two circles be divided, by a chord in each, into segments which are<br />
similar respectively, the chords are proportional to the corresponding diameters.*

The proof is instantaneous if we join the ends of each chord to the centre<br />
of the circle which it divides, when we obtain two similar triangles.

(2) *If <span data-ref="0232.g2:D">$D$</span> be any point on the circle circumscribed about a triangle <span data-ref="0232.g2:< A B C >">$ABC$</span>, and<br />
<span data-ref="0232.g2:/ D X /">$DX$</span>, <span data-ref="0232.g2:/ D Y /">$DY$</span>, <span data-ref="0232.g2:/ D Z /">$DZ$</span> be perpendicular to the sides <span data-ref="0232.g2:/ B C /">$BC$</span>, <span data-ref="0232.g2:/ C A /">$CA$</span>, <span data-ref="0232.g2:/ A B /">$AB$</span> of the triangle<br />
respectively, then <span data-ref="0232.g2:X">$X$</span>, <span data-ref="0232.g2:Y">$Y$</span>, <span data-ref="0232.g2:Z">$Z$</span> lie in one straight line; and, conversely, if the feet of<br />
the perpendiculars from any point <span data-ref="0232.g2:D">$D$</span> on the sides of a triangle lie in one straight<br />
line, <span data-ref="0232.g2:D">$D$</span> lies on the circle circumscribed about the triangle.*

The proof depending on III. 21, 22 is well known.

Now suppose that <span data-ref="0232.g1:D">$D$</span> is any point in the plane of a triangle <span data-ref="0232.g1:< A B C >">$ABC$</span>, and<br />
that <span data-ref="0232.g1:/ D X /">$DX$</span>, <span data-ref="0232.g1:/ D Y /">$DY$</span>, <span data-ref="0232.g1:/ D Z /">$DZ$</span> are perpendicular to the sides<br />
<span data-ref="0232.g1:/ B C /">$BC$</span>, <span data-ref="0232.g1:/ C A /">$CA$</span>, <span data-ref="0232.g1:/ A B /">$AB$</span> respectively.

Join <span data-ref="0232.g1:/ Y Z /">$YZ$</span>, <span data-ref="0232.g1:/ D A /">$DA$</span>.

Then, since the angles at <span data-ref="0232.g1:Y">$Y$</span>, <span data-ref="0232.g1:Z">$Z$</span> are right,<br />
<span data-ref="0232.g1:A">$A$</span>, <span data-ref="0232.g1:Y">$Y$</span>, <span data-ref="0232.g1:D">$D$</span>, <span data-ref="0232.g1:Z">$Z$</span> lie on a circle of which <span data-ref="0232.g1:/ D A /">$DA$</span> is the<br />
diameter.

And <span data-ref="0232.g1:/ Y Z /">$YZ$</span> divides this circle into segments which<br />
are similar respectively to the segments into which<br />
<span data-ref="0232.g1:/ B C /">$BC$</span> divides the circle circumscribing <span data-ref="0232.g1:< A B C >">$ABC$</span>, since<br />
the angles <span data-ref="0232.g1:< Z A Y )">$ZAY$</span>, <span data-ref="0232.g1:< B A C )">$BAC$</span> coincide, and their supple-<br />

Therefore, if *d* be the diameter of the circle<br />
circumscribing <span data-ref="0232.g1:< A B C >">$ABC$</span>,
<p class="assertion"><span data-ref="0232.g1:/ B C /">$BC$</span> is to *d* as <span data-ref="0232.g1:/ Y Z /">$YZ$</span> is to <span data-ref="0232.g1:/ D A /">$DA$</span>;</p>
<p class="assertion">and therefore the rectangle <span data-ref="0232.g1:/ A D /">$AD$</span>, <span data-ref="0232.g1:/ B C /">$BC$</span> is equal to the rectangle *d*, <span data-ref="0232.g1:/ Y Z /">$YZ$</span>.</p>

<p class="assertion">Similarly the rectangle <span data-ref="0232.g1:/ B D /">$BD$</span>, <span data-ref="0232.g1:/ C A /">$CA$</span> is equal to the rectangle *d*, <span data-ref="0232.g1:/ Z X /">$ZX$</span>, and the<br />
rectangle <span data-ref="0232.g1:/ C D /">$CD$</span>, <span data-ref="0232.g1:/ A B /">$AB$</span> is equal to the rectangle *d*, <span data-ref="0232.g1:/ X Y /">$XY$</span>.</p>

Hence, in a quadrilateral in general, the rectangle<br />
contained by the diagonals is less than the sum of the<br />
rectangles contained by the pairs of opposite sides.
