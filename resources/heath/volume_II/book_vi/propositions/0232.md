Another proof of this proposition, and of its converse, is indicated by Dr Lachlan (*Elements of Euclid*, pp. 273—4). It depends on two preliminary propositions.

(1) *If two circles be divided, by a chord in each, into segments which are similar respectively, the chords are proportional to the corresponding diameters.*

The proof is instantaneous if we join the ends of each chord to the centre of the circle which it divides, when we obtain two similar triangles.

(2) *If <span data-ref="0232.g2:D">$D$</span> be any point on the circle circumscribed about a triangle <span data-ref="0232.g2:&lt; A B C &gt;">$ABC$</span>, and <span data-ref="0232.g2:/ D X /">$DX$</span>, <span data-ref="0232.g2:/ D Y /">$DY$</span>, <span data-ref="0232.g2:/ D Z /">$DZ$</span> be perpendicular to the sides <span data-ref="0232.g2:/ B C /">$BC$</span>, <span data-ref="0232.g2:/ C A /">$CA$</span>, <span data-ref="0232.g2:/ A B /">$AB$</span> of the triangle respectively, then <span data-ref="0232.g2:X">$X$</span>, <span data-ref="0232.g2:Y">$Y$</span>, <span data-ref="0232.g2:Z">$Z$</span> lie in one straight line; and, conversely, if the feet of the perpendiculars from any point <span data-ref="0232.g2:D">$D$</span> on the sides of a triangle lie in one straight line, <span data-ref="0232.g2:D">$D$</span> lies on the circle circumscribed about the triangle.*

The proof depending on III. 21, 22 is well known.

Now suppose that <span data-ref="0232.g1:D">$D$</span> is any point in the plane of a triangle <span data-ref="0232.g1:&lt; A B C &gt;">$ABC$</span>, and that <span data-ref="0232.g1:/ D X /">$DX$</span>, <span data-ref="0232.g1:/ D Y /">$DY$</span>, <span data-ref="0232.g1:/ D Z /">$DZ$</span> are perpendicular to the sides <span data-ref="0232.g1:/ B C /">$BC$</span>, <span data-ref="0232.g1:/ C A /">$CA$</span>, <span data-ref="0232.g1:/ A B /">$AB$</span> respectively.

Join <span data-ref="0232.g1:/ Y Z /">$YZ$</span>, <span data-ref="0232.g1:/ D A /">$DA$</span>.

Then, since the angles at <span data-ref="0232.g1:Y">$Y$</span>, <span data-ref="0232.g1:Z">$Z$</span> are right, <span data-ref="0232.g1:A">$A$</span>, <span data-ref="0232.g1:Y">$Y$</span>, <span data-ref="0232.g1:D">$D$</span>, <span data-ref="0232.g1:Z">$Z$</span> lie on a circle of which <span data-ref="0232.g1:/ D A /">$DA$</span> is the diameter.

And <span data-ref="0232.g1:/ Y Z /">$YZ$</span> divides this circle into segments which are similar respectively to the segments into which <span data-ref="0232.g1:/ B C /">$BC$</span> divides the circle circumscribing <span data-ref="0232.g1:&lt; A B C &gt;">$ABC$</span>, since the angles <span data-ref="0232.g1:&lt; Z A Y )">$ZAY$</span>, <span data-ref="0232.g1:&lt; B A C )">$BAC$</span> coincide, and their supplements are equal.

Therefore, if $d$ be the diameter of the circle circumscribing <span data-ref="0232.g1:&lt; A B C &gt;">$ABC$</span>,
<p align="center"><span data-ref="0232.g1:/ B C /">$BC$</span> is to $d$ as <span data-ref="0232.g1:/ Y Z /">$YZ$</span> is to <span data-ref="0232.g1:/ D A /">$DA$</span>;</p>
and therefore the rectangle <span data-ref="0232.g1:/ A D /">$AD$</span>, <span data-ref="0232.g1:/ B C /">$BC$</span> is equal to the rectangle $d$, <span data-ref="0232.g1:/ Y Z /">$YZ$</span>.

Similarly the rectangle <span data-ref="0232.g1:/ B D /">$BD$</span>, <span data-ref="0232.g1:/ C A /">$CA$</span> is equal to the rectangle $d$, <span data-ref="0232.g1:/ Z X /">$ZX$</span>, and the rectangle <span data-ref="0232.g1:/ C D /">$CD$</span>, <span data-ref="0232.g1:/ A B /">$AB$</span> is equal to the rectangle $d$, <span data-ref="0232.g1:/ X Y /">$XY$</span>.

Hence, in a quadrilateral in general, the rectangle contained by the diagonals is less than the sum of the rectangles contained by the pairs of opposite sides.
