### PROPOSITION E.

Lastly, the following proposition may be given which Playfair added as<br />
VI. E. It appears in the $Data$ of Euclid, Prop. 93, and may be thus<br />
enunciated.

<p class="enunciation">If the angle <span data-ref="0233.g1:< B A C )">$BAC$</span> of a triangle <span data-ref="0233.g1:< A B C >">$ABC$</span> be bisected by the straight line <span data-ref="0233.g1:/ A D /">$AD$</span><br />
meeting the circle circumscribed about the triangle in <span data-ref="0233.g1:D">$D$</span>, and if <span data-ref="0233.g1:/ B D /">$BD$</span> be joined,<br />
then<br />
the sum of <span data-ref="0233.g1:/ B A /">$BA$</span>, <span data-ref="0233.g1:/ A C /">$AC$</span> is to <span data-ref="0233.g1:/ A D /">$AD$</span> as <span data-ref="0233.g1:/ B C /">$BC$</span> is to <span data-ref="0233.g1:/ B D /">$BD$</span>.</p>

Join <span data-ref="0233.g1:/ C D /">$CD$</span>. Then, since <span data-ref="0233.g1:/ A D /">$AD$</span> bisects the angle <span data-ref="0233.g1:< B A C )">$BAC$</span>, the subtended arcs<br />
<span data-ref="0233.g1:( O B )< B O D >">$BD$</span>, <span data-ref="0233.g1:( O D )< D O C >">$DC$</span>, and therefore the chords <span data-ref="0233.g1:/ B D /">$BD$</span>, <span data-ref="0233.g1:/ D C /">$DC$</span>, are<br />
equal.

![Proposition E](0233.g1.svg)

(1) The result can now be easily deduced from<br />
Ptolemy's theorem.

For the rectangle <span data-ref="0233.g1:/ A D /">$AD$</span>, <span data-ref="0233.g1:/ B C /">$BC$</span> is equal to the sum of<br />
the rectangles <span data-ref="0233.g1:/ A B /">$AB$</span>, <span data-ref="0233.g1:/ D C /">$DC$</span> and <span data-ref="0233.g1:/ A C /">$AC$</span>, <span data-ref="0233.g1:/ B D /">$BD$</span>, *i.e.* (since<br />
<span data-ref="0233.g1:/ B D /">$BD$</span>, <span data-ref="0233.g1:/ C D /">$CD$</span> are equal) to the rectangle contained by<br />
<span data-ref="0233.g1:/ B A /">$BA$</span> + <span data-ref="0233.g1:/ A C /">$AC$</span> and <span data-ref="0233.g1:/ B D /">$BD$</span>.

<p class="assertion">Therefore the sum of <span data-ref="0233.g1:/ B A /">$BA$</span>, <span data-ref="0233.g1:/ A C /">$AC$</span> is to <span data-ref="0233.g1:/ A D /">$AD$</span> as <span data-ref="0233.g1:/ B C /">$BC$</span><br />
is to <span data-ref="0233.g1:/ B D /">$BD$</span>. <span class="justification">[VI. 16]</span></p>

(2) Euclid proves it differently in $Data$, Prop. 93.

Let <span data-ref="0233.g1:/ A D /">$AD$</span> meet <span data-ref="0233.g1:/ B C /">$BC$</span> in <span data-ref="0233.g1:E">$E$</span>.

Then, since <span data-ref="0233.g1:/ A E /">$AE$</span> bisects the angle <span data-ref="0233.g1:< B A C )">$BAC$</span>,
<p class="assertion"><span data-ref="0233.g1:/ B A /">$BA$</span> is to <span data-ref="0233.g1:/ A C /">$AC$</span> as <span data-ref="0233.g1:/ B E /">$BE$</span> to <span data-ref="0233.g1:/ E C /">$EC$</span>, <span class="justification">[VI. 3]</span></p>
or, alternately,
<p class="assertion"><span data-ref="0233.g1:/ A B /">$AB$</span> is to <span data-ref="0233.g1:/ B E /">$BE$</span> as <span data-ref="0233.g1:/ A C /">$AC$</span> to <span data-ref="0233.g1:/ C E /">$CE$</span>. <span class="justification">[V. 16]</span></p>

Therefore also
<p class="assertion"><span data-ref="0233.g1:/ B A /">$BA$</span> + <span data-ref="0233.g1:/ A C /">$AC$</span> is to <span data-ref="0233.g1:/ B C /">$BC$</span> as <span data-ref="0233.g1:/ A C /">$AC$</span> to <span data-ref="0233.g1:/ C E /">$CE$</span>. <span class="justification">[V. 12]</span></p>

Again, since the angles <span data-ref="0233.g1:< B A D )">$BAD$</span>, <span data-ref="0233.g1:< E A C )">$EAC$</span> are equal, and the angles <span data-ref="0233.g1:< A D B )">$ADB$</span>, <span data-ref="0233.g1:< A C E )">$ACE$</span><br />
are also equal, <span class="justification">[III. 21]</span>
<p class="assertion">the triangles <span data-ref="0233.g1:< A B D >">$ABD$</span>, <span data-ref="0233.g1:< A E C >">$AEC$</span> are equiangular.</p>

Therefore
<p class="assertion"><span data-ref="0233.g1:/ A C /">$AC$</span> is to <span data-ref="0233.g1:/ C E /">$CE$</span> as <span data-ref="0233.g1:/ A D /">$AD$</span> to <span data-ref="0233.g1:/ B D /">$BD$</span>. <span class="justification">[VI. 4]</span></p>
