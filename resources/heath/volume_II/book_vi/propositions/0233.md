*Conversely*, if the latter statement is true, while we are supposed to know nothing about the position of <span data-ref="0232.g2:D">$D$</span>, it follows that
<p align="center"><span data-ref="0232.g2:/ X Z /">$XZ$</span> must be equal to the sum of <span data-ref="0232.g2:/ X Y /">$XY$</span>, <span data-ref="0232.g2:/ Y Z /">$YZ$</span>,</p>

Hence, from the theorem (2) above, it follows that <span data-ref="0232.g2:D">$D$</span> must lie on the circle circumscribed about <span data-ref="0232.g2:&lt; A B C &gt;">$ABC$</span>, *i.e.* that <span data-ref="0232.g2:&lt; A B C D &gt;">$ABCD$</span> is a quadrilateral about which a circle can be described.

All the above propositions can be proved on the basis of Book III. and without using Book VI., since it is possible by the aid of III. 21 and 35 alone to prove that *in equiangular triangles the rectangles contained by the non-corresponding sides about equal angles are equal to one another* (a result arrived at by combining VI. 4 and VI. 16). This is the method adopted by Casey, H. M. Taylor, and Lachlan; but I fail to see any particular advantage in it.

Lastly, the following proposition may be given which Playfair added as VI. E. It appears in the *Data* of Euclid, Prop. 93, and may be thus enunciated.

*If the angle <span data-ref="0233.g1:&lt; B A C )">$BAC$</span> of a triangle <span data-ref="0233.g1:&lt; A B C &gt;">$ABC$</span> be bisected by the straight line <span data-ref="0233.g1:/ A D /">$AD$</span> meeting the circle circumscribed about the triangle in <span data-ref="0233.g1:D">$D$</span>, and if <span data-ref="0233.g1:/ B D /">$BD$</span> be joined, then*
<p align="center"><i>the sum of <span data-ref="0233.g1:/ B A /">$BA$</span>, <span data-ref="0233.g1:/ A C /">$AC$</span> is to <span data-ref="0233.g1:/ A D /">$AD$</span> as <span data-ref="0233.g1:/ B C /">$BC$</span> is to <span data-ref="0233.g1:/ B D /">$BD$</span>.</i></p>

Join <span data-ref="0233.g1:/ C D /">$CD$</span>. Then, since <span data-ref="0233.g1:/ A D /">$AD$</span> bisects the angle <span data-ref="0233.g1:&lt; B A C )">$BAC$</span>, the subtended arcs <span data-ref="0233.g1:( O B )&lt; B O D &gt;">$BD$</span>, <span data-ref="0233.g1:( O D )&lt; D O C &gt;">$DC$</span>, and therefore the chords <span data-ref="0233.g1:/ B D /">$BD$</span>, <span data-ref="0233.g1:/ D C /">$DC$</span>, are equal.

(1) The result can now be easily deduced from Ptolemy's theorem.

For the rectangle <span data-ref="0233.g1:/ A D /">$AD$</span>, <span data-ref="0233.g1:/ B C /">$BC$</span> is equal to the sum of the rectangles <span data-ref="0233.g1:/ A B /">$AB$</span>, <span data-ref="0233.g1:/ D C /">$DC$</span> and <span data-ref="0233.g1:/ A C /">$AC$</span>, <span data-ref="0233.g1:/ B D /">$BD$</span>, *i.e.* (since <span data-ref="0233.g1:/ B D /">$BD$</span>, <span data-ref="0233.g1:/ C D /">$CD$</span> are equal) to the rectangle contained by <span data-ref="0233.g1:/ B A /">$BA$</span> $+$ <span data-ref="0233.g1:/ A C /">$AC$</span> and <span data-ref="0233.g1:/ B D /">$BD$</span>.

Therefore the sum of <span data-ref="0233.g1:/ B A /">$BA$</span>, <span data-ref="0233.g1:/ A C /">$AC$</span> is to <span data-ref="0233.g1:/ A D /">$AD$</span> as <span data-ref="0233.g1:/ B C /">$BC$</span> is to <span data-ref="0233.g1:/ B D /">$BD$</span>. [VI. 16]

(2) Euclid proves it differently in *Data*, Prop. 93.

Let <span data-ref="0233.g1:/ A D /">$AD$</span> meet <span data-ref="0233.g1:/ B C /">$BC$</span> in <span data-ref="0233.g1:E">$E$</span>.

Then, since <span data-ref="0233.g1:/ A E /">$AE$</span> bisects the angle <span data-ref="0233.g1:&lt; B A C )">$BAC$</span>,
<p align="center"><span data-ref="0233.g1:/ B A /">$BA$</span> is to <span data-ref="0233.g1:/ A C /">$AC$</span> as <span data-ref="0233.g1:/ B E /">$BE$</span> to <span data-ref="0233.g1:/ E C /">$EC$</span>, [VI. 3]</p>
or, alternately,
<p align="center"><span data-ref="0233.g1:/ A B /">$AB$</span> is to <span data-ref="0233.g1:/ B E /">$BE$</span> as <span data-ref="0233.g1:/ A C /">$AC$</span> to <span data-ref="0233.g1:/ C E /">$CE$</span>. [V. 16]</p>

Therefore also
<p align="center"><span data-ref="0233.g1:/ B A /">$BA$</span> $+$ <span data-ref="0233.g1:/ A C /">$AC$</span> is to <span data-ref="0233.g1:/ B C /">$BC$</span> as <span data-ref="0233.g1:/ A C /">$AC$</span> to <span data-ref="0233.g1:/ C E /">$CE$</span>. [V. 12]</p>

Again, since the angles <span data-ref="0233.g1:&lt; B A D )">$BAD$</span>, <span data-ref="0233.g1:&lt; E A C )">$EAC$</span> are equal, and the angles <span data-ref="0233.g1:&lt; A D B )">$ADB$</span>, <span data-ref="0233.g1:&lt; A C E )">$ACE$</span> are also equal, [III. 21]
the triangles <span data-ref="0233.g1:&lt; A B D &gt;">$ABD$</span>, <span data-ref="0233.g1:&lt; A E C &gt;">$AEC$</span> are equiangular.

Therefore
<p align="center"><span data-ref="0233.g1:/ A C /">$AC$</span> is to <span data-ref="0233.g1:/ C E /">$CE$</span> as <span data-ref="0233.g1:/ A D /">$AD$</span> to <span data-ref="0233.g1:/ B D /">$BD$</span>. [VI. 4]</p>
