### PROPOSITION 18.

<p class="enunciation">On a given straight line to describe a rectilinear figure<br />
similar and similarly situated to a given rectilinear figure.</p>

Let <span data-ref="0235.g2:/ A B /">$AB$</span> be the given straight line and <span data-ref="0235.g1:< C E >">$CE$</span> the given<br />
rectilinear figure;<br />
thus it is required to describe on the straight line <span data-ref="0235.g2:/ A B /">$AB$</span> a<br />
rectilinear figure similar and similarly situated to the recti-<br />
lineal figure <span data-ref="0235.g1:< C E >">$CE$</span>.

![Proposition 18 (figure CE)](0235.g1.svg)
![Proposition 18 (figure AH)](0235.g2.svg)

Let <span data-ref="0235.g1:/ D F /">$DF$</span> be joined, and on the straight line <span data-ref="0235.g2:/ A B /">$AB$</span>, and at<br />
the points <span data-ref="0235.g2:A">$A$</span>, <span data-ref="0235.g2:B">$B$</span> on it, let the angle <span data-ref="0235.g2:< G A B )">$GAB$</span> be constructed<br />
equal to the angle at <span data-ref="0235.g1:< F C D )">$C$</span>, and the angle <span data-ref="0235.g2:< A B G )">$ABG$</span> equal to the<br />
angle <span data-ref="0235.g1:< C D F )">$CDF$</span>. <span class="justification">[I. 23]</span>

<p class="assertion">Therefore the remaining angle <span data-ref="0235.g1:< C F D )">$CFD$</span> is equal to the angle<br />
<span data-ref="0235.g2:< A G B )">$AGB$</span>; <span class="justification">[I. 32]</span></p>
<p class="assertion">therefore the triangle <span data-ref="0235.g1:< F C D >">$FCD$</span> is equiangular with the triangle<br />
<span data-ref="0235.g2:< G A B >">$GAB$</span>.</p>

<p class="assertion">Therefore, proportionally, as <span data-ref="0235.g1:/ F D /">$FD$</span> is to <span data-ref="0235.g2:/ G B /">$GB$</span>, so is <span data-ref="0235.g1:/ F C /">$FC$</span> to<br />
<span data-ref="0235.g2:/ G A /">$GA$</span>, and <span data-ref="0235.g1:/ C D /">$CD$</span> to <span data-ref="0235.g2:/ A B /">$AB$</span>.</p>
