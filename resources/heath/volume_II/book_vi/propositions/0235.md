For, with the same construction,
since the rectangle <span data-ref="0234.g1:A">$A$</span>, <span data-ref="0234.g1:C">$C$</span> is equal to the square on <span data-ref="0234.g1:B">$B$</span>,
while the square on <span data-ref="0234.g1:B">$B$</span> is the rectangle <span data-ref="0234.g1:B">$B$</span>, <span data-ref="0234.g1:D">$D$</span>, for <span data-ref="0234.g1:B">$B$</span> is equal to <span data-ref="0234.g1:D">$D$</span>,
therefore the rectangle <span data-ref="0234.g1:A">$A$</span>, <span data-ref="0234.g1:C">$C$</span> is equal to the rectangle <span data-ref="0234.g1:B">$B$</span>, <span data-ref="0234.g1:D">$D$</span>.

But, if the rectangle contained by the extremes be equal to that contained by the means, the four straight lines are proportional. [VI. 16]

Therefore, as <span data-ref="0234.g1:A">$A$</span> is to <span data-ref="0234.g1:B">$B$</span>, so is <span data-ref="0234.g1:D">$D$</span> to <span data-ref="0234.g1:C">$C$</span>.

But <span data-ref="0234.g1:B">$B$</span> is equal to <span data-ref="0234.g1:D">$D$</span>;
therefore, as <span data-ref="0234.g1:A">$A$</span> is to <span data-ref="0234.g1:B">$B$</span>, so is <span data-ref="0234.g1:B">$B$</span> to <span data-ref="0234.g1:C">$C$</span>.

Therefore etc.

### PROPOSITION 18.

*On a given straight line to describe a rectilinear figure similar and similarly situated to a given rectilinear figure.*

Let <span data-ref="0235.g2:/ A B /">$AB$</span> be the given straight line and <span data-ref="0235.g1:&lt; C E &gt;">$CE$</span> the given rectilinear figure;
thus it is required to describe on the straight line <span data-ref="0235.g2:/ A B /">$AB$</span> a rectilinear figure similar and similarly situated to the rectilinear figure <span data-ref="0235.g1:&lt; C E &gt;">$CE$</span>.

![Proposition 18 (figure CE)](0235.g1.svg)

![Proposition 18 (figure AH)](0235.g2.svg)

Let <span data-ref="0235.g1:/ D F /">$DF$</span> be joined, and on the straight line <span data-ref="0235.g2:/ A B /">$AB$</span>, and at the points <span data-ref="0235.g2:A">$A$</span>, <span data-ref="0235.g2:B">$B$</span> on it, let the angle <span data-ref="0235.g2:&lt; G A B )">$GAB$</span> be constructed equal to the angle at <span data-ref="0235.g1:&lt; F C D )">$C$</span>, and the angle <span data-ref="0235.g2:&lt; A B G )">$ABG$</span> equal to the angle <span data-ref="0235.g1:&lt; C D F )">$CDF$</span>. [I. 23]

Therefore the remaining angle <span data-ref="0235.g1:&lt; C F D )">$CFD$</span> is equal to the angle <span data-ref="0235.g2:&lt; A G B )">$AGB$</span>; [I. 32]
therefore the triangle <span data-ref="0235.g1:&lt; F C D &gt;">$FCD$</span> is equiangular with the triangle <span data-ref="0235.g2:&lt; G A B &gt;">$GAB$</span>.

Therefore, proportionally, as <span data-ref="0235.g1:/ F D /">$FD$</span> is to <span data-ref="0235.g2:/ G B /">$GB$</span>, so is <span data-ref="0235.g1:/ F C /">$FC$</span> to <span data-ref="0235.g2:/ G A /">$GA$</span>, and <span data-ref="0235.g1:/ C D /">$CD$</span> to <span data-ref="0235.g2:/ A B /">$AB$</span>.
