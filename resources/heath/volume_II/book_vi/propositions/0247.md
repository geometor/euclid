<p class="sub-clause">Then since, as <span data-ref="0247.g1:/ A B /">$AB$</span> is to <span data-ref="0247.g1:/ C D /">$CD$</span>, so is <span data-ref="0247.g1:/ E F /">$EF$</span> to <span data-ref="0247.g1:/ G H /">$GH$</span>,<br />
and, as <span data-ref="0247.g1:/ C D /">$CD$</span> is to <span data-ref="0247.g1:O">$O$</span>, so is <span data-ref="0247.g1:/ G H /">$GH$</span> to <span data-ref="0247.g1:P">$P$</span>,</p>
<p class="assertion">therefore, *ex aequali*, as <span data-ref="0247.g1:/ A B /">$AB$</span> is to <span data-ref="0247.g1:O">$O$</span>, so is <span data-ref="0247.g1:/ E F /">$EF$</span> to <span data-ref="0247.g1:P">$P$</span>. <span class="justification">[V. 22]</span></p>

<p class="assertion">But, as <span data-ref="0247.g1:/ A B /">$AB$</span> is to <span data-ref="0247.g1:O">$O$</span>, so is <span data-ref="0247.g1:< K A B >">$KAB$</span> to <span data-ref="0247.g1:< L C D >">$LCD$</span>,<br />
and, as <span data-ref="0247.g1:/ E F /">$EF$</span> is to <span data-ref="0247.g1:P">$P$</span>, so is <span data-ref="0247.g1:< M F >">$MF$</span> to <span data-ref="0247.g1:< N H >">$NH$</span>; <span class="justification">[VI. 19, Por.]</span></p>
<p class="assertion">therefore also, as <span data-ref="0247.g1:< K A B >">$KAB$</span> is to <span data-ref="0247.g1:< L C D >">$LCD$</span>, so is <span data-ref="0247.g1:< M F >">$MF$</span> to <span data-ref="0247.g1:< N H >">$NH$</span>. <span class="justification">[V. 11]</span></p>

![Book VI, Proposition 22](0247.g1.svg)

Next, let <span data-ref="0247.g1:< M F >">$MF$</span> be to <span data-ref="0247.g1:< N H >">$NH$</span> as <span data-ref="0247.g1:< K A B >">$KAB$</span> is to <span data-ref="0247.g1:< L C D >">$LCD$</span>;<br />
I say also that, as <span data-ref="0247.g1:/ A B /">$AB$</span> is to <span data-ref="0247.g1:/ C D /">$CD$</span>, so is <span data-ref="0247.g1:/ E F /">$EF$</span> to <span data-ref="0247.g1:/ G H /">$GH$</span>.

<p class="sub-clause">For, if <span data-ref="0247.g1:/ E F /">$EF$</span> is not to <span data-ref="0247.g1:/ G H /">$GH$</span> as <span data-ref="0247.g1:/ A B /">$AB$</span> to <span data-ref="0247.g1:/ C D /">$CD$</span>,</p>
<p class="assertion">let <span data-ref="0247.g1:/ E F /">$EF$</span> be to <span data-ref="0247.g1:/ Q R /">$QR$</span> as <span data-ref="0247.g1:/ A B /">$AB$</span> to <span data-ref="0247.g1:/ C D /">$CD$</span>, <span class="justification">[VI. 12]</span><br />
and on <span data-ref="0247.g1:/ Q R /">$QR$</span> let the rectilineal figure <span data-ref="0247.g1:< S R >">$SR$</span> be described similar<br />
and similarly situated to either of the two <span data-ref="0247.g1:< M F >">$MF$</span>, <span data-ref="0247.g1:< N H >">$NH$</span>. <span class="justification">[VI. 18]</span></p>

<p class="sub-clause">Since then, as <span data-ref="0247.g1:/ A B /">$AB$</span> is to <span data-ref="0247.g1:/ C D /">$CD$</span>, so is <span data-ref="0247.g1:/ E F /">$EF$</span> to <span data-ref="0247.g1:/ Q R /">$QR$</span>,<br />
and there have been described on <span data-ref="0247.g1:/ A B /">$AB$</span>, <span data-ref="0247.g1:/ C D /">$CD$</span> the similar and<br />
similarly situated figures <span data-ref="0247.g1:< K A B >">$KAB$</span>, <span data-ref="0247.g1:< L C D >">$LCD$</span>,<br />
and on <span data-ref="0247.g1:/ E F /">$EF$</span>, <span data-ref="0247.g1:/ Q R /">$QR$</span> the similar and similarly situated figures<br />
<span data-ref="0247.g1:< M F >">$MF$</span>, <span data-ref="0247.g1:< S R >">$SR$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0247.g1:< K A B >">$KAB$</span> is to <span data-ref="0247.g1:< L C D >">$LCD$</span>, so is <span data-ref="0247.g1:< M F >">$MF$</span> to <span data-ref="0247.g1:< S R >">$SR$</span>.</p>

<p class="sub-clause">But also, by hypothesis,<br />
as <span data-ref="0247.g1:< K A B >">$KAB$</span> is to <span data-ref="0247.g1:< L C D >">$LCD$</span>, so is <span data-ref="0247.g1:< M F >">$MF$</span> to <span data-ref="0247.g1:< N H >">$NH$</span>;</p>
<p class="assertion">therefore also, as <span data-ref="0247.g1:< M F >">$MF$</span> is to <span data-ref="0247.g1:< S R >">$SR$</span>, so is <span data-ref="0247.g1:< M F >">$MF$</span> to <span data-ref="0247.g1:< N H >">$NH$</span>. <span class="justification">[V. 11]</span></p>

<p class="assertion">Therefore <span data-ref="0247.g1:< M F >">$MF$</span> has the same ratio to each of the figures<br />
<span data-ref="0247.g1:< N H >">$NH$</span>, <span data-ref="0247.g1:< S R >">$SR$</span>;</p>
<p class="assertion">therefore <span data-ref="0247.g1:< N H >">$NH$</span> is equal to <span data-ref="0247.g1:< S R >">$SR$</span>. <span class="justification">[V. 9]</span></p>

<p class="sub-clause">But it is also similar and similarly situated to it;</p>
<p class="assertion">therefore <span data-ref="0247.g1:/ G H /">$GH$</span> is equal to <span data-ref="0247.g1:/ Q R /">$QR$</span>.</p>
