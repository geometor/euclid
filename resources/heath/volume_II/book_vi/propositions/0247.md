Then since, as <span data-ref="0247.g1:/ A B /">$AB$</span> is to <span data-ref="0247.g1:/ C D /">$CD$</span>, so is <span data-ref="0247.g1:/ E F /">$EF$</span> to <span data-ref="0247.g1:/ G H /">$GH$</span>,
and, as <span data-ref="0247.g1:/ C D /">$CD$</span> is to <span data-ref="0247.g1:O">$O$</span>, so is <span data-ref="0247.g1:/ G H /">$GH$</span> to <span data-ref="0247.g1:P">$P$</span>,
therefore, *ex aequali*, as <span data-ref="0247.g1:/ A B /">$AB$</span> is to <span data-ref="0247.g1:O">$O$</span>, so is <span data-ref="0247.g1:/ E F /">$EF$</span> to <span data-ref="0247.g1:P">$P$</span>. [V. 22]
But, as <span data-ref="0247.g1:/ A B /">$AB$</span> is to <span data-ref="0247.g1:O">$O$</span>, so is <span data-ref="0247.g1:< K A B >">$KAB$</span> to <span data-ref="0247.g1:< L C D >">$LCD$</span>, [VI. 19, Por.]
and, as <span data-ref="0247.g1:/ E F /">$EF$</span> is to <span data-ref="0247.g1:P">$P$</span>, so is <span data-ref="0247.g1:< M F >">$MF$</span> to <span data-ref="0247.g1:< N H >">$NH$</span>;
therefore also, as <span data-ref="0247.g1:< K A B >">$KAB$</span> is to <span data-ref="0247.g1:< L C D >">$LCD$</span>, so is <span data-ref="0247.g1:< M F >">$MF$</span> to <span data-ref="0247.g1:< N H >">$NH$</span>. [V. 11]

![Book VI, Proposition 22](0247.g1.svg)

Next, let <span data-ref="0247.g1:< M F >">$MF$</span> be to <span data-ref="0247.g1:< N H >">$NH$</span> as <span data-ref="0247.g1:< K A B >">$KAB$</span> is to <span data-ref="0247.g1:< L C D >">$LCD$</span>;
I say also that, as <span data-ref="0247.g1:/ A B /">$AB$</span> is to <span data-ref="0247.g1:/ C D /">$CD$</span>, so is <span data-ref="0247.g1:/ E F /">$EF$</span> to <span data-ref="0247.g1:/ G H /">$GH$</span>.

For, if <span data-ref="0247.g1:/ E F /">$EF$</span> is not to <span data-ref="0247.g1:/ G H /">$GH$</span> as <span data-ref="0247.g1:/ A B /">$AB$</span> to <span data-ref="0247.g1:/ C D /">$CD$</span>,
let <span data-ref="0247.g1:/ E F /">$EF$</span> be to <span data-ref="0247.g1:/ Q R /">$QR$</span> as <span data-ref="0247.g1:/ A B /">$AB$</span> to <span data-ref="0247.g1:/ C D /">$CD$</span>, [VI. 12]
and on <span data-ref="0247.g1:/ Q R /">$QR$</span> let the rectilineal figure <span data-ref="0247.g1:< S R >">$SR$</span> be described similar
and similarly situated to either of the two <span data-ref="0247.g1:< M F >">$MF$</span>, <span data-ref="0247.g1:< N H >">$NH$</span>. [VI. 18]

Since then, as <span data-ref="0247.g1:/ A B /">$AB$</span> is to <span data-ref="0247.g1:/ C D /">$CD$</span>, so is <span data-ref="0247.g1:/ E F /">$EF$</span> to <span data-ref="0247.g1:/ Q R /">$QR$</span>,
and there have been described on <span data-ref="0247.g1:/ A B /">$AB$</span>, <span data-ref="0247.g1:/ C D /">$CD$</span> the similar and
similarly situated figures <span data-ref="0247.g1:< K A B >">$KAB$</span>, <span data-ref="0247.g1:< L C D >">$LCD$</span>,
and on <span data-ref="0247.g1:/ E F /">$EF$</span>, <span data-ref="0247.g1:/ Q R /">$QR$</span> the similar and similarly situated figures
<span data-ref="0247.g1:< M F >">$MF$</span>, <span data-ref="0247.g1:< S R >">$SR$</span>,
therefore, as <span data-ref="0247.g1:< K A B >">$KAB$</span> is to <span data-ref="0247.g1:< L C D >">$LCD$</span>, so is <span data-ref="0247.g1:< M F >">$MF$</span> to <span data-ref="0247.g1:< S R >">$SR$</span>.
But also, by hypothesis,
as <span data-ref="0247.g1:< K A B >">$KAB$</span> is to <span data-ref="0247.g1:< L C D >">$LCD$</span>, so is <span data-ref="0247.g1:< M F >">$MF$</span> to <span data-ref="0247.g1:< N H >">$NH$</span>;
therefore also, as <span data-ref="0247.g1:< M F >">$MF$</span> is to <span data-ref="0247.g1:< S R >">$SR$</span>, so is <span data-ref="0247.g1:< M F >">$MF$</span> to <span data-ref="0247.g1:< N H >">$NH$</span>. [V. 11]

Therefore <span data-ref="0247.g1:< M F >">$MF$</span> has the same ratio to each of the figures
<span data-ref="0247.g1:< N H >">$NH$</span>, <span data-ref="0247.g1:< S R >">$SR$</span>;
therefore <span data-ref="0247.g1:< N H >">$NH$</span> is equal to <span data-ref="0247.g1:< S R >">$SR$</span>. [V. 9]
But it is also similar and similarly situated to it;
therefore <span data-ref="0247.g1:/ G H /">$GH$</span> is equal to <span data-ref="0247.g1:/ Q R /">$QR$</span>.
