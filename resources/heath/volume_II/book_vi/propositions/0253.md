It follows [VI. 17] that
> the rectangle $D$, $F$ is equal to the square on $E$.

But $D$, $F$ are both given;
> therefore the square on $E$ is given, so that $E$ is also given.

[Observe that De Morgan's lemma is here assumed without proof. It may be proved (1) as it is by De Morgan, whose proof is that given above, p. 245, (2) in the manner of the "minimum lemma," pp. 242—3 above, or (3) as it is by Proclus on I. 46 (see note on that proposition).]

Hence the ratio $D$ : $E$ is given.

Now, since
$$A : C = D : F\text{,}$$
and
$$A : C = (\text{square on } A) : (\text{rect. } A, C)\text{,}$$
while
$$D : F = (\text{square on } D) : (\text{rect. } D, F)\text{,}\qquad \text{[VI. 1]}$$
therefore
$$(\text{square on } A) : (\text{rect. } A, C) = (\text{square on } D) : (\text{rect. } D, F)\text{.}\qquad \text{[v. 11]}$$

But, since $A : B = B : C$, $(\text{rect. } A, C) = (\text{sq. on } B)$; [VI. 17]
and $(\text{rect. } D, F) = (\text{sq. on } E)$, from above;
therefore
$$(\text{square on } A) : (\text{square on } B) = (\text{sq. on } D) : (\text{sq. on } E)\text{.}$$

$Therefore$, says Euclid,
$$A : B = D : E\text{,}$$
that is, *he assumes the truth of* VI. 22 *for squares*.

Thus he deduces his proposition from VI. 22, instead of proving VI. 22 by means of it (or the corresponding proposition used by Mr Taylor and Dr Lachlan).

### PROPOSITION 23.

<p class="enunciation">Equiangular parallelograms have to one another the ratio<br />
compounded of the ratios of their sides.</p>

Let <span data-ref="0253.g1:< A C >">$AC$</span>, <span data-ref="0253.g1:< C F >">$CF$</span> be equiangular parallelograms having the<br />
angle <span data-ref="0253.g1:< B C D )">$BCD$</span> equal to the angle <span data-ref="0253.g1:< E C G )">$ECG$</span>;

<sup>5</sup> I say that the parallelogram <span data-ref="0253.g1:< A C >">$AC$</span> has to the parallelogram<br />
<span data-ref="0253.g1:< C F >">$CF$</span> the ratio compounded of the ratios of the sides.

![Proposition 23 Diagram](0253.g1.svg)

For let them be placed so that <span data-ref="0253.g1:/ B C /">$BC$</span> is in a straight line<br />
with <span data-ref="0253.g1:/ C G /">$CG$</span>;

<p class="assertion">therefore <span data-ref="0253.g1:/ D C /">$DC$</span> is also in a straight line with <span data-ref="0253.g1:/ C E /">$CE$</span>.</p>

<p class="assertion">as <span data-ref="0253.g1:/ B C /">$BC$</span> is to <span data-ref="0253.g1:/ C G /">$CG$</span>, so is <span data-ref="0253.g1:K">$K$</span> to <span data-ref="0253.g1:L">$L$</span>,</p>
