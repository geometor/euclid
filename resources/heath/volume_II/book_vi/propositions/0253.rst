:title: Proposition 23

It follows [VI. 17] that
> the rectangle $D$, $F$ is equal to the square on $E$.

But $D$, $F$ are both given;
> therefore the square on $E$ is given, so that $E$ is also given.

[Observe that :person:`De Morgan <de-morgan>`'s lemma is here assumed without proof. It may be proved (1) as it is by :person:`De Morgan <de-morgan>`, whose proof is that given above, p. 245, (2) in the manner of the "minimum lemma," pp. 242—3 above, or (3) as it is by :person:`Proclus <proclus>` on I. 46 (see note on that proposition).]

Hence the ratio $D$ : $E$ is given.

Now, since

$$A : C = D : F\text{,}$$

and

$$A : C = (\text{square on } A) : (\text{rect. } A, C)\text{,}$$

while

$$D : F = (\text{square on } D) : (\text{rect. } D, F)\text{,}\qquad \text{[VI. 1]}$$

therefore

$$(\text{square on } A) : (\text{rect. } A, C) = (\text{square on } D) : (\text{rect. } D, F)\text{.}\qquad \text{[v. 11]}$$

But, since $A : B = B : C$, $(\text{rect. } A, C) = (\text{sq. on } B)$; [VI. 17]
and $(\text{rect. } D, F) = (\text{sq. on } E)$, from above;
therefore

$$(\text{square on } A) : (\text{square on } B) = (\text{sq. on } D) : (\text{sq. on } E)\text{.}$$

$Therefore$, says Euclid,

$$A : B = D : E\text{,}$$

that is, *he assumes the truth of* VI. 22 *for squares*.

Thus he deduces his proposition from VI. 22, instead of proving VI. 22 by means of it (or the corresponding proposition used by Mr Taylor and Dr Lachlan).

PROPOSITION 23.
---------------

.. enunciation::

   Equiangular parallelograms have to one another the ratio compounded of the ratios of their sides.\ [#f1]_

Let :g:`AC <0253.g1:< A C >>`, :g:`CF <0253.g1:< C F >>` be equiangular parallelograms having the angle :g:`BCD <0253.g1:< B C D )>` :eq:`equal <0253.g1:< B C D ) = 0253.g1:< E C G )>` to the angle :g:`ECG <0253.g1:< E C G )>`;

I say that the parallelogram :g:`AC <0253.g1:< A C >>` has to the parallelogram :g:`CF <0253.g1:< C F >>` the ratio compounded of the ratios of the sides.\ [#f1]_

.. picture:: 0253.g1.svg
   :alt: Proposition 23 Diagram

For let them be placed so that :g:`BC <0253.g1:/ B C />` is in a straight line with :g:`CG <0253.g1:/ C G />`;

.. assertion::

   therefore :g:`DC <0253.g1:/ D C />` is also in a straight line with :g:`CE <0253.g1:/ C E />`.

Let the parallelogram :g:`DG <0253.g1:< D G >>` be completed; let a straight line :g:`K <0253.g1:K>` be set out, and let it be contrived that,\ [#f2]_

.. assertion::

   as :g:`BC <0253.g1:/ B C />` is to :g:`CG <0253.g1:/ C G />`, so is :g:`K <0253.g1:K>` to :g:`L <0253.g1:L>`,

.. assertion:: [VI. 12] <VI.12>

   and, as :g:`DC <0253.g1:/ D C />` is to :g:`CE <0253.g1:/ C E />`, so is :g:`L <0253.g1:L>` to :g:`M <0253.g1:M>`.
