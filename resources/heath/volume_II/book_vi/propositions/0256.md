250 [BOOK VI [VI. 23

But, since
<p align="center">
<span data-ref="0255.g1:&lt; K D &gt;">$KD$</span> = <span data-ref="0255.g1:&lt; C F &gt;">$CF$</span>,<br />
<span data-ref="0255.g1:/ C D /">$CD$</span> : <span data-ref="0255.g1:/ C E /">$CE$</span> = <span data-ref="0255.g1:/ C G /">$CG$</span> : <span data-ref="0255.g1:/ C K /">$CK$</span>. [VI. 14]
</p>
Hence <span data-ref="0255.g1:/ C G /">$CG$</span> : <span data-ref="0255.g1:/ C K /">$CK$</span> is a given ratio.
And <span data-ref="0255.g1:/ C B /">$CB$</span> : <span data-ref="0255.g1:/ C K /">$CK$</span> was proved to be a given ratio.
Therefore the ratio of <span data-ref="0255.g1:/ C B /">$CB$</span> to <span data-ref="0255.g1:/ C G /">$CG$</span> is given. [*Data*, Prop. 8]

Lastly we may refer to Prop. 70 of the *Data*, the first part of which proves what corresponds exactly to VI. 23, namely that, *If in two equiangular parallelograms the sides containing the equal angles have a given ratio to one another* [i.e. one side in one to one side in the other], *the parallelograms themselves will also have a given ratio to one another*. [Here the ratios of <span data-ref="0255.g1:/ B C /">$BC$</span> to <span data-ref="0255.g1:/ C G /">$CG$</span> and of <span data-ref="0255.g1:/ C D /">$CD$</span> to <span data-ref="0255.g1:/ C E /">$CE$</span> are given.]

The construction is the same as in the last case, and we have <span data-ref="0255.g1:&lt; K D &gt;">$KD$</span> equal to <span data-ref="0255.g1:&lt; C F &gt;">$CF$</span>, so that
<p align="center"><span data-ref="0255.g1:/ C D /">$CD$</span> : <span data-ref="0255.g1:/ C E /">$CE$</span> = <span data-ref="0255.g1:/ C G /">$CG$</span> : <span data-ref="0255.g1:/ C K /">$CK$</span>. [VI. 14]</p>
But the ratio of <span data-ref="0255.g1:/ C D /">$CD$</span> to <span data-ref="0255.g1:/ C E /">$CE$</span> is given;
therefore the ratio of <span data-ref="0255.g1:/ C G /">$CG$</span> to <span data-ref="0255.g1:/ C K /">$CK$</span> is given.
And, by hypothesis, the ratio of <span data-ref="0255.g1:/ C G /">$CG$</span> to <span data-ref="0255.g1:/ C B /">$CB$</span> is given.
Therefore, by dividing the ratios [*Data*, Prop. 8], we see that the ratio of <span data-ref="0255.g1:/ C B /">$CB$</span> to <span data-ref="0255.g1:/ C K /">$CK$</span>, and therefore [VI. 1] the ratio of <span data-ref="0255.g1:&lt; A C &gt;">$AC$</span> to <span data-ref="0255.g1:&lt; D K &gt;">$DK$</span>, or of <span data-ref="0255.g1:&lt; A C &gt;">$AC$</span> to <span data-ref="0255.g1:&lt; C F &gt;">$CF$</span>, is given.

Euclid extends these propositions to the case of two parallelograms which have *given* but not equal angles.

Pappus (VII. p. 928) exhibits the result of VI. 23 in a different way, which throws new light on compounded ratios. He proves, namely, that *a parallelogram is to an equiangular parallelogram as the rectangle contained by the adjacent sides of the first is to the rectangle contained by the adjacent sides of the second*.

Let <span data-ref="0256.g1:&lt; A C &gt;">$AC$</span>, <span data-ref="0256.g1:&lt; D F &gt;">$DF$</span> be equiangular parallelograms on the bases <span data-ref="0256.g1:/ B C /">$BC$</span>, <span data-ref="0256.g1:/ E F /">$EF$</span>, and let the angles at <span data-ref="0256.g1:&lt; A B G )">$B$</span>, <span data-ref="0256.g1:&lt; D E H )">$E$</span> be equal.

Draw perpendiculars <span data-ref="0256.g1:/ A G /">$AG$</span>, <span data-ref="0256.g1:/ D H /">$DH$</span> to <span data-ref="0256.g1:/ B C /">$BC$</span>, <span data-ref="0256.g1:/ E F /">$EF$</span> respectively.

Since the angles at <span data-ref="0256.g1:&lt; A B G )">$B$</span>, <span data-ref="0256.g1:&lt; A G B )">$G$</span> are equal to those at <span data-ref="0256.g1:&lt; D E H )">$E$</span>, <span data-ref="0256.g1:&lt; D H E )">$H$</span>,
> the triangles <span data-ref="0256.g1:&lt; A B G &gt;">$ABG$</span>, <span data-ref="0256.g1:&lt; D E H &gt;">$DEH$</span> are equiangular.

Therefore
<p align="center"><span data-ref="0256.g1:/ B A /">$BA$</span> : <span data-ref="0256.g1:/ A G /">$AG$</span> = <span data-ref="0256.g1:/ E D /">$ED$</span> : <span data-ref="0256.g1:/ D H /">$DH$</span>. [VI. 4]</p>
But
<p align="center"><span data-ref="0256.g1:/ B A /">$BA$</span> : <span data-ref="0256.g1:/ A G /">$AG$</span> = (rect. <span data-ref="0256.g1:/ B A /">$BA$</span>, <span data-ref="0256.g1:/ B C /">$BC$</span>) : (rect. <span data-ref="0256.g1:/ A G /">$AG$</span>, <span data-ref="0256.g1:/ B C /">$BC$</span>),</p>
and
<p align="center"><span data-ref="0256.g1:/ E D /">$ED$</span> : <span data-ref="0256.g1:/ D H /">$DH$</span> = (rect. <span data-ref="0256.g1:/ E D /">$ED$</span>, <span data-ref="0256.g1:/ E F /">$EF$</span>) : (rect. <span data-ref="0256.g1:/ D H /">$DH$</span>, <span data-ref="0256.g1:/ E F /">$EF$</span>). [VI. 1]</p>
Therefore [V. 11 and V. 16]
<p align="center">
(rect. <span data-ref="0256.g1:/ A B /">$AB$</span>, <span data-ref="0256.g1:/ B C /">$BC$</span>) : (rect. <span data-ref="0256.g1:/ D E /">$DE$</span>, <span data-ref="0256.g1:/ E F /">$EF$</span>) = (rect. <span data-ref="0256.g1:/ A G /">$AG$</span>, <span data-ref="0256.g1:/ B C /">$BC$</span>) : (rect. <span data-ref="0256.g1:/ D H /">$DH$</span>, <span data-ref="0256.g1:/ E F /">$EF$</span>)<br />
= (<span data-ref="0256.g1:&lt; A C &gt;">$AC$</span>) : (<span data-ref="0256.g1:&lt; D F &gt;">$DF$</span>).
</p>

Thus it is proved that the ratio compounded of the ratios <span data-ref="0256.g1:/ A B /">$AB$</span> : <span data-ref="0256.g1:/ D E /">$DE$</span> and <span data-ref="0256.g1:/ B C /">$BC$</span> : <span data-ref="0256.g1:/ E F /">$EF$</span> is equal to the ratio of the rectangle <span data-ref="0256.g1:/ A B /">$AB$</span>, <span data-ref="0256.g1:/ B C /">$BC$</span> to the rectangle <span data-ref="0256.g1:/ D E /">$DE$</span>, <span data-ref="0256.g1:/ E F /">$EF$</span>.
