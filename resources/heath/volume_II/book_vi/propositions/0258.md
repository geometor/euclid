252 [BOOK VI [VI. 24

the angle <span data-ref="0257.g1:&lt; A F G )">$AFG$</span> is equal to the angle <span data-ref="0257.g1:&lt; D C A )">$DCA$</span>;
and the angle <span data-ref="0257.g1:&lt; D A C )">$DAC$</span> is common to the two triangles <span data-ref="0257.g1:&lt; A D C &gt;">$ADC$</span>, <span data-ref="0257.g1:&lt; A G F &gt;">$AGF$</span>;
therefore the triangle <span data-ref="0257.g1:&lt; A D C &gt;">$ADC$</span> is equiangular with the triangle <span data-ref="0257.g1:&lt; A G F &gt;">$AGF$</span>.

For the same reason
the triangle <span data-ref="0257.g1:&lt; A C B &gt;">$ACB$</span> is also equiangular with the triangle <span data-ref="0257.g1:&lt; A F E &gt;">$AFE$</span>,
and the whole parallelogram <span data-ref="0257.g1:&lt; A B C D &gt;">$ABCD$</span> is equiangular with the parallelogram <span data-ref="0257.g1:&lt; E G &gt;">$EG$</span>.

Therefore, proportionally,
<p align="center">
as <span data-ref="0257.g1:/ A D /">$AD$</span> is to <span data-ref="0257.g1:/ D C /">$DC$</span>, so is <span data-ref="0257.g1:/ A G /">$AG$</span> to <span data-ref="0257.g1:/ G F /">$GF$</span>,<br />
as <span data-ref="0257.g1:/ D C /">$DC$</span> is to <span data-ref="0257.g1:/ C A /">$CA$</span>, so is <span data-ref="0257.g1:/ G F /">$GF$</span> to <span data-ref="0257.g1:/ F A /">$FA$</span>,<br />
as <span data-ref="0257.g1:/ A C /">$AC$</span> is to <span data-ref="0257.g1:/ C B /">$CB$</span>, so is <span data-ref="0257.g1:/ A F /">$AF$</span> to <span data-ref="0257.g1:/ F E /">$FE$</span>,<br />
and further, as <span data-ref="0257.g1:/ C B /">$CB$</span> is to <span data-ref="0257.g1:/ B A /">$BA$</span>, so is <span data-ref="0257.g1:/ F E /">$FE$</span> to <span data-ref="0257.g1:/ E A /">$EA$</span>.
</p>

And, since it was proved that,
<p align="center">
as <span data-ref="0257.g1:/ D C /">$DC$</span> is to <span data-ref="0257.g1:/ C A /">$CA$</span>, so is <span data-ref="0257.g1:/ G F /">$GF$</span> to <span data-ref="0257.g1:/ F A /">$FA$</span>,<br />
and, as <span data-ref="0257.g1:/ A C /">$AC$</span> is to <span data-ref="0257.g1:/ C B /">$CB$</span>, so is <span data-ref="0257.g1:/ A F /">$AF$</span> to <span data-ref="0257.g1:/ F E /">$FE$</span>,<br />
therefore, <em>ex aequali</em>, as <span data-ref="0257.g1:/ D C /">$DC$</span> is to <span data-ref="0257.g1:/ C B /">$CB$</span>, so is <span data-ref="0257.g1:/ G F /">$GF$</span> to <span data-ref="0257.g1:/ F E /">$FE$</span>. [V. 22]
</p>

Therefore in the parallelograms <span data-ref="0257.g1:&lt; A B C D &gt;">$ABCD$</span>, <span data-ref="0257.g1:&lt; E G &gt;">$EG$</span> the sides about the equal angles are proportional;
therefore the parallelogram <span data-ref="0257.g1:&lt; A B C D &gt;">$ABCD$</span> is similar to the parallelogram <span data-ref="0257.g1:&lt; E G &gt;">$EG$</span>. [VI. Def. 1]

For the same reason
the parallelogram <span data-ref="0257.g1:&lt; A B C D &gt;">$ABCD$</span> is also similar to the parallelogram <span data-ref="0257.g1:&lt; K H &gt;">$KH$</span>;
therefore each of the parallelograms <span data-ref="0257.g1:&lt; E G &gt;">$EG$</span>, <span data-ref="0257.g1:&lt; H K &gt;">$HK$</span> is similar to <span data-ref="0257.g1:&lt; A B C D &gt;">$ABCD$</span>.

But figures similar to the same rectilineal figure are also similar to one another; [VI. 21]
therefore the parallelogram <span data-ref="0257.g1:&lt; E G &gt;">$EG$</span> is also similar to the parallelogram <span data-ref="0257.g1:&lt; H K &gt;">$HK$</span>.

Therefore etc.

Q. E. D.
