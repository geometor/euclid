<p class="assertion">the angle <span data-ref="0257.g1:< A F G )">$AFG$</span> is equal to the angle <span data-ref="0257.g1:< D C A )">$DCA$</span> ;</p>
<p class="sub-clause">and the angle <span data-ref="0257.g1:< D A C )">$DAC$</span> is common to the two triangles <span data-ref="0257.g1:< A D C >">$ADC$</span>,<br />
<span data-ref="0257.g1:< A G F >">$AGF$</span> ;</p>
<p class="assertion">therefore the triangle <span data-ref="0257.g1:< A D C >">$ADC$</span> is equiangular with the triangle<br />
<span data-ref="0257.g1:< A G F >">$AGF$</span>.</p>

<p class="sub-clause">For the same reason</p>
<p class="assertion">the triangle <span data-ref="0257.g1:< A C B >">$ACB$</span> is also equiangular with the triangle<br />
<span data-ref="0257.g1:< A F E >">$AFE$</span>,</p>
<p class="assertion">and the whole parallelogram <span data-ref="0257.g1:< A B C D >">$ABCD$</span> is equiangular with the<br />
parallelogram <span data-ref="0257.g1:< E G >">$EG$</span>.</p>

<p class="sub-clause">Therefore, proportionally,</p>
<p class="assertion">as <span data-ref="0257.g1:/ A D /">$AD$</span> is to <span data-ref="0257.g1:/ D C /">$DC$</span>, so is <span data-ref="0257.g1:/ A G /">$AG$</span> to <span data-ref="0257.g1:/ G F /">$GF$</span>,<br />
as <span data-ref="0257.g1:/ D C /">$DC$</span> is to <span data-ref="0257.g1:/ C A /">$CA$</span>, so is <span data-ref="0257.g1:/ G F /">$GF$</span> to <span data-ref="0257.g1:/ F A /">$FA$</span>,<br />
as <span data-ref="0257.g1:/ A C /">$AC$</span> is to <span data-ref="0257.g1:/ C B /">$CB$</span>, so is <span data-ref="0257.g1:/ A F /">$AF$</span> to <span data-ref="0257.g1:/ F E /">$FE$</span>,<br />
and further, as <span data-ref="0257.g1:/ C B /">$CB$</span> is to <span data-ref="0257.g1:/ B A /">$BA$</span>, so is <span data-ref="0257.g1:/ F E /">$FE$</span> to <span data-ref="0257.g1:/ E A /">$EA$</span>.</p>

<p class="sub-clause">And, since it was proved that,<br />
as <span data-ref="0257.g1:/ D C /">$DC$</span> is to <span data-ref="0257.g1:/ C A /">$CA$</span>, so is <span data-ref="0257.g1:/ G F /">$GF$</span> to <span data-ref="0257.g1:/ F A /">$FA$</span>,<br />
and, as <span data-ref="0257.g1:/ A C /">$AC$</span> is to <span data-ref="0257.g1:/ C B /">$CB$</span>, so is <span data-ref="0257.g1:/ A F /">$AF$</span> to <span data-ref="0257.g1:/ F E /">$FE$</span>,</p>
<p class="assertion">therefore, *ex aequali*, as <span data-ref="0257.g1:/ D C /">$DC$</span> is to <span data-ref="0257.g1:/ C B /">$CB$</span>, so is <span data-ref="0257.g1:/ G F /">$GF$</span> to <span data-ref="0257.g1:/ F E /">$FE$</span>. <span class="justification">[V. 22]</span></p>

<p class="assertion">Therefore in the parallelograms <span data-ref="0257.g1:< A B C D >">$ABCD$</span>, <span data-ref="0257.g1:< E G >">$EG$</span> the sides<br />
about the equal angles are proportional ;</p>
<p class="assertion">therefore the parallelogram <span data-ref="0257.g1:< A B C D >">$ABCD$</span> is similar to the parallelo-<br />
gram <span data-ref="0257.g1:< E G >">$EG$</span>. <span class="justification">[VI. Def. 1]</span></p>

<p class="sub-clause">For the same reason</p>
<p class="assertion">the parallelogram <span data-ref="0257.g1:< A B C D >">$ABCD$</span> is also similar to the parallelogram<br />
<span data-ref="0257.g1:< K H >">$KH$</span> ;</p>
<p class="assertion">therefore each of the parallelograms <span data-ref="0257.g1:< E G >">$EG$</span>, <span data-ref="0257.g1:< H K >">$HK$</span> is similar to<br />
<span data-ref="0257.g1:< A B C D >">$ABCD$</span>.</p>

<p class="sub-clause">But figures similar to the same rectilineal figure are also<br />
similar to one another ; <span class="justification">[VI. 21]</span></p>
<p class="assertion">therefore the parallelogram <span data-ref="0257.g1:< E G >">$EG$</span> is also similar to the parallelo-<br />
gram <span data-ref="0257.g1:< H K >">$HK$</span>.</p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>
