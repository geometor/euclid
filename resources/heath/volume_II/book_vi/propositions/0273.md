### PROPOSITION 30.

<p class="enunciation">To cut a given finite straight line in extreme and mean<br />
ratio.</p>

Let <span data-ref="0273.g1:/ A B /">$AB$</span> be the given finite straight line ;<br />
thus it is required to cut <span data-ref="0273.g1:/ A B /">$AB$</span> in extreme and mean ratio.

![Book VI Proposition 30](0273.g1.svg)

<p class="sub-clause">On <span data-ref="0273.g1:/ A B /">$AB$</span> let the square <span data-ref="0273.g1:< B C >">$BC$</span> be described ;<br />
and let there be applied to <span data-ref="0273.g1:/ A C /">$AC$</span> the parallelo-<br />
gram <span data-ref="0273.g1:< C D >">$CD$</span> equal to <span data-ref="0273.g1:< B C >">$BC$</span> and exceeding by<br />
the figure <span data-ref="0273.g1:< A D >">$AD$</span> similar to <span data-ref="0273.g1:< B C >">$BC$</span>. <span class="justification">[VI. 29]</span></p>

<p class="sub-clause">Now <span data-ref="0273.g1:< B C >">$BC$</span> is a square ;</p>
<p class="assertion">therefore <span data-ref="0273.g1:< A D >">$AD$</span> is also a square.</p>

<p class="sub-clause">And, since <span data-ref="0273.g1:< B C >">$BC$</span> is equal to <span data-ref="0273.g1:< C D >">$CD$</span>,<br />
let <span data-ref="0273.g1:< C E >">$CE$</span> be subtracted from each ;</p>
<p class="assertion">therefore the remainder <span data-ref="0273.g1:< B F >">$BF$</span> is equal to<br />
the remainder <span data-ref="0273.g1:< A D >">$AD$</span>.</p>
