The MSS. again give an alternative proof which Heiberg places in the Appendix. It first shows that the similar figures on the three sides have the same ratios to one another as the squares on the sides respectively. Whence, by using I. 47 and the same argument based on V. 24 as that explained above, the result is obtained.

If it is considered essential to have a proof which does not use Simson's Props. B and A or any proposition but those actually given by Euclid, no method occurs to me except the following.

Eucl. V. 22 proves that, if $a, b, c$ are three magnitudes, and $d, e, f$ three others, such that
$$a : b = d : e,$$
$$b : c = e : f,$$
then, *ex aequali*,
$$a : c = d : f.$$
If now in addition
$$a : b = b : c,$$
so that, also,
$$d : e = e : f,$$
the ratio $a : c$ is duplicate of the ratio $a : b$, and the ratio $d : f$ duplicate of the ratio $d : e$, whence *the ratios which are duplicate of equal ratios are equal*.

Now (fig. on  AC) : (fig. on  <span data-ref="0275.g1:/ A B /">$AB$</span>) = the ratio duplicate of  <span data-ref="0275.g1:/ A C /">$AC$</span> : <span data-ref="0275.g1:/ A B /">$AB$</span>
$$= \text{the ratio duplicate of } CD : DA$$
$$= CD : BD.$$
Hence (sum of figs. on  <span data-ref="0275.g1:/ A C /">$AC$</span>, <span data-ref="0275.g1:/ A B /">$AB$</span>) : (fig. on  <span data-ref="0275.g1:/ A B /">$AB$</span>) = <span data-ref="0275.g1:/ B C /">$BC$</span> : <span data-ref="0275.g1:/ B D /">$BD$</span>. [V. 18]

But (fig. on  <span data-ref="0275.g1:/ B C /">$BC$</span>) : (fig. on  <span data-ref="0275.g1:/ A B /">$AB$</span>) = <span data-ref="0275.g1:/ B C /">$BC$</span> : <span data-ref="0275.g1:/ B D /">$BD$</span>

the figures on <span data-ref="0275.g1:/ A C /">$AC$</span>, <span data-ref="0275.g1:/ A B /">$AB$</span> are together equal to the figure on <span data-ref="0275.g1:/ B C /">$BC$</span>. [V. 9]

### PROPOSITION 32.

<p class="enunciation">If two triangles having two sides proportional to two sides<br />
be placed together at one angle so that their corresponding sides<br />
are also parallel, the remaining sides of the triangles will be<br />
in a straight line.</p>

Let <span data-ref="0277.g1:< A B C >">$ABC$</span>, <span data-ref="0277.g1:< D C E >">$DCE$</span> be two triangles having the two sides<br />
<span data-ref="0277.g1:/ B A /">$BA$</span>, <span data-ref="0277.g1:/ A C /">$AC$</span> proportional to the two sides <span data-ref="0277.g1:/ D C /">$DC$</span>, <span data-ref="0277.g1:/ D E /">$DE$</span>, so that, as<br />
<span data-ref="0277.g1:/ A B /">$AB$</span> is to <span data-ref="0277.g1:/ A C /">$AC$</span>, so is <span data-ref="0277.g1:/ D C /">$DC$</span> to <span data-ref="0277.g1:/ D E /">$DE$</span>, and <span data-ref="0277.g1:/ A B /">$AB$</span> parallel to <span data-ref="0277.g1:/ D C /">$DC$</span>, and<br />
<span data-ref="0277.g1:/ A C /">$AC$</span> to <span data-ref="0277.g1:/ D E /">$DE$</span>;

I say that <span data-ref="0277.g1:/ B C /">$BC$</span> is in a straight line with <span data-ref="0277.g1:/ C E /">$CE$</span>.
