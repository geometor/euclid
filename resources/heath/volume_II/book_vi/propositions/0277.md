For, since <span data-ref="0277.g1:/ A B /">$AB$</span> is parallel to <span data-ref="0277.g1:/ D C /">$DC$</span>,
and the straight line <span data-ref="0277.g1:/ A C /">$AC$</span> has fallen upon them,
the alternate angles <span data-ref="0277.g1:&lt; B A C )">$BAC$</span>, <span data-ref="0277.g1:&lt; A C D )">$ACD$</span> are equal to one another. [I. 29]

For the same reason
the angle <span data-ref="0277.g1:&lt; C D E )">$CDE$</span> is also equal to the angle <span data-ref="0277.g1:&lt; A C D )">$ACD$</span>;
so that the angle <span data-ref="0277.g1:&lt; B A C )">$BAC$</span> is equal to the angle <span data-ref="0277.g1:&lt; C D E )">$CDE$</span>.

![Proposition 32](0277.g1.svg)

And, since <span data-ref="0277.g1:&lt; A B C &gt;">$ABC$</span>, <span data-ref="0277.g1:&lt; D C E &gt;">$DCE$</span> are two triangles having one angle, the angle at <span data-ref="0277.g1:A">$A$</span>, equal to one angle, the angle at <span data-ref="0277.g1:D">$D$</span>,
and the sides about the equal angles proportional,
so that, as <span data-ref="0277.g1:/ B A /">$BA$</span> is to <span data-ref="0277.g1:/ A C /">$AC$</span>, so is <span data-ref="0277.g1:/ C D /">$CD$</span> to <span data-ref="0277.g1:/ D E /">$DE$</span>,
therefore the triangle <span data-ref="0277.g1:&lt; A B C &gt;">$ABC$</span> is equiangular with the triangle <span data-ref="0277.g1:&lt; D C E &gt;">$DCE$</span>; [vi. 6]
therefore the angle <span data-ref="0277.g1:&lt; A B C )">$ABC$</span> is equal to the angle <span data-ref="0277.g1:&lt; D C E )">$DCE$</span>.

But the angle <span data-ref="0277.g1:&lt; A C D )">$ACD$</span> was also proved equal to the angle <span data-ref="0277.g1:&lt; B A C )">$BAC$</span>;
therefore the whole angle <span data-ref="0277.g1:&lt; A C E )">$ACE$</span> is equal to the two angles <span data-ref="0277.g1:&lt; A B C )">$ABC$</span>, <span data-ref="0277.g1:&lt; B A C )">$BAC$</span>.

Let the angle <span data-ref="0277.g1:&lt; A C B )">$ACB$</span> be added to each;
therefore the angles <span data-ref="0277.g1:&lt; A C E )">$ACE$</span>, <span data-ref="0277.g1:&lt; A C B )">$ACB$</span> are equal to the angles <span data-ref="0277.g1:&lt; B A C )">$BAC$</span>, <span data-ref="0277.g1:&lt; A C B )">$ACB$</span>, <span data-ref="0277.g1:&lt; C B A )">$CBA$</span>.

But the angles <span data-ref="0277.g1:&lt; B A C )">$BAC$</span>, <span data-ref="0277.g1:&lt; A B C )">$ABC$</span>, <span data-ref="0277.g1:&lt; A C B )">$ACB$</span> are equal to two right angles; [I. 32]
therefore the angles <span data-ref="0277.g1:&lt; A C E )">$ACE$</span>, <span data-ref="0277.g1:&lt; A C B )">$ACB$</span> are also equal to two right angles.

Therefore with a straight line <span data-ref="0277.g1:/ A C /">$AC$</span>, and at the point <span data-ref="0277.g1:C">$C$</span> on it, the two straight lines <span data-ref="0277.g1:/ B C /">$BC$</span>, <span data-ref="0277.g1:/ C E /">$CE$</span> not lying on the same side make the adjacent angles <span data-ref="0277.g1:&lt; A C E )">$ACE$</span>, <span data-ref="0277.g1:&lt; A C B )">$ACB$</span> equal to two right angles;
therefore <span data-ref="0277.g1:/ B C /">$BC$</span> is in a straight line with <span data-ref="0277.g1:/ C E /">$CE$</span>. [I. 14]

Therefore etc.

$$\text{Q. E. D.}$$
