<p class="sub-clause">For, since <span data-ref="0277.g1:/ A B /">$AB$</span> is parallel to <span data-ref="0277.g1:/ D C /">$DC$</span>,<br />
and the straight line <span data-ref="0277.g1:/ A C /">$AC$</span> has fallen upon them,</p>
<p class="assertion">the alternate angles <span data-ref="0277.g1:< B A C )">$BAC$</span>, <span data-ref="0277.g1:< A C D )">$ACD$</span><br />
are equal to one another. <span class="justification">[I. 29]</span></p>

<p class="sub-clause">For the same reason</p>
<p class="assertion">the angle <span data-ref="0277.g1:< C D E )">$CDE$</span> is also<br />
equal to the angle <span data-ref="0277.g1:< A C D )">$ACD$</span>;</p>
<p class="assertion">so that the angle <span data-ref="0277.g1:< B A C )">$BAC$</span> is equal<br />
to the angle <span data-ref="0277.g1:< C D E )">$CDE$</span>.</p>

![Proposition 32](0277.g1.svg)

<p class="sub-clause">And, since <span data-ref="0277.g1:< A B C >">$ABC$</span>, <span data-ref="0277.g1:< D C E >">$DCE$</span> are<br />
two triangles having one angle, the angle at <span data-ref="0277.g1:A">$A$</span>, equal to one<br />
angle, the angle at <span data-ref="0277.g1:D">$D$</span>,<br />
and the sides about the equal angles proportional,<br />
so that, as <span data-ref="0277.g1:/ B A /">$BA$</span> is to <span data-ref="0277.g1:/ A C /">$AC$</span>, so is <span data-ref="0277.g1:/ C D /">$CD$</span> to <span data-ref="0277.g1:/ D E /">$DE$</span>,</p>
<p class="assertion">therefore the triangle <span data-ref="0277.g1:< A B C >">$ABC$</span> is equiangular with the<br />
triangle <span data-ref="0277.g1:< D C E >">$DCE$</span>; <span class="justification">[VI. 6]</span></p>
<p class="assertion">therefore the angle <span data-ref="0277.g1:< A B C )">$ABC$</span> is equal to the angle <span data-ref="0277.g1:< D C E )">$DCE$</span>.</p>

<p class="sub-clause">But the angle <span data-ref="0277.g1:< A C D )">$ACD$</span> was also proved equal to the angle<br />
<span data-ref="0277.g1:< B A C )">$BAC$</span>;</p>
<p class="assertion">therefore the whole angle <span data-ref="0277.g1:< A C E )">$ACE$</span> is equal to the two angles<br />
<span data-ref="0277.g1:< A B C )">$ABC$</span>, <span data-ref="0277.g1:< B A C )">$BAC$</span>.</p>

<p class="sub-clause">Let the angle <span data-ref="0277.g1:< A C B )">$ACB$</span> be added to each;</p>
<p class="assertion">therefore the angles <span data-ref="0277.g1:< A C E )">$ACE$</span>, <span data-ref="0277.g1:< A C B )">$ACB$</span> are equal to the angles <span data-ref="0277.g1:< B A C )">$BAC$</span>,<br />
<span data-ref="0277.g1:< A C B )">$ACB$</span>, <span data-ref="0277.g1:< C B A )">$CBA$</span>.</p>

<p class="sub-clause">But the angles <span data-ref="0277.g1:< B A C )">$BAC$</span>, <span data-ref="0277.g1:< A B C )">$ABC$</span>, <span data-ref="0277.g1:< A C B )">$ACB$</span> are equal to two right<br />
angles; <span class="justification">[I. 32]</span></p>
<p class="assertion">therefore the angles <span data-ref="0277.g1:< A C E )">$ACE$</span>, <span data-ref="0277.g1:< A C B )">$ACB$</span> are also equal to two<br />
right angles.</p>

<p class="sub-clause">Therefore with a straight line <span data-ref="0277.g1:/ A C /">$AC$</span>, and at the point <span data-ref="0277.g1:C">$C$</span> on<br />
it, the two straight lines <span data-ref="0277.g1:/ B C /">$BC$</span>, <span data-ref="0277.g1:/ C E /">$CE$</span> not lying on the same side<br />
make the adjacent angles <span data-ref="0277.g1:< A C E )">$ACE$</span>, <span data-ref="0277.g1:< A C B )">$ACB$</span> equal to two right<br />
angles;</p>
<p class="assertion">therefore <span data-ref="0277.g1:/ B C /">$BC$</span> is in a straight line with <span data-ref="0277.g1:/ C E /">$CE$</span>. <span class="justification">[I. 14]</span></p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>
