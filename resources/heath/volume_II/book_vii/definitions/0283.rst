BOOK VII.
=========

DEFINITIONS.
------------

1. An :term:`**unit** <unit>` is that by virtue of which each of the things that exist is called one.

2. A :term:`**number** <number>` is a multitude composed of units.

3. A number is a :term:`**part** <part-aliquot>` of a number, the less of the greater, when it measures the greater;

4. but :term:`**parts** <parts-non-aliquot>` when it does not measure it.

5. The greater number is a :term:`**multiple** <multiple>` of the less when it is measured by the less.

6. An :term:`**even number** <even-number>` is that which is divisible into two equal parts.

7. An :term:`**odd number** <odd-number>` is that which is not divisible into two equal parts, or that which differs by an unit from an even number.

8. An :term:`**even-times even number** <even-times-even-number>` is that which is measured by an even number according to an even number.

9. An :term:`**even-times odd number** <even-times-odd-number>` is that which is measured by an even number according to an odd number.

10. An :term:`**odd-times odd number** <odd-times-odd-number>` is that which is measured by an odd number according to an odd number.
