:title: Book VII: Definitions 11–22

11. A :term:`**prime number** <prime-number>` is that which is measured by an unit alone.

12. :term:`**Numbers prime to one another** <prime-to-one-another>` are those which are measured by an unit alone as a common measure.

13. A :term:`**composite number** <composite-number>` is that which is measured by some number.

14. :term:`**Numbers composite to one another** <composite-to-one-another>` are those which are measured by some number as a common measure.

15. A number is said to :term:`**multiply** <multiply>` a number when that which is multiplied is added to itself as many times as there are units in the other, and thus some number is produced.

16. And, when two numbers having multiplied one another make some number, the number so produced is called :term:`**plane** <plane-number>`, and its :term:`**sides** <side-of-number>` are the numbers which have multiplied one another.

17. And, when three numbers having multiplied one another make some number, the number so produced is :term:`**solid** <solid-number>`, and its :term:`**sides** <side-of-number>` are the numbers which have multiplied one another.

18. A :term:`**square number** <square-number>` is equal multiplied by equal, or a number which is contained by two equal numbers.

19. And a :term:`**cube** <cube-number>` is equal multiplied by equal and again by equal, or a number which is contained by three equal numbers.

20. **Numbers** are :term:`**proportional** <proportional>` when the first is the same multiple, or the same part, or the same parts, of the second that the third is of the fourth.

21. :term:`**Similar plane and solid numbers** <similar-plane-and-solid-numbers>` are those which have their sides proportional.

22. A :term:`**perfect number** <perfect-number>` is that which is equal to its own parts.
