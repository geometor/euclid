BOOK VII. PROPOSITIONS.

### PROPOSITION 1.

<p class="enunciation">Two unequal numbers being set out, and the less being<br />
continually subtracted in turn from the greater, if the number<br />
which is left never measures the one before it until an unit is<br />
left, the original numbers will be prime to one another.</p>

For, the less of two unequal numbers <span data-ref="0302.g1:/ A B /">$AB$</span>, <span data-ref="0302.g1:/ C D /">$CD$</span> being<br />
continually subtracted from the greater, let the<br />
number which is left never measure the one<br />
before it until an unit is left;

I say that <span data-ref="0302.g1:/ A B /">$AB$</span>, <span data-ref="0302.g1:/ C D /">$CD$</span> are prime to one another,<br />
that is, that an unit alone measures <span data-ref="0302.g1:/ A B /">$AB$</span>, <span data-ref="0302.g1:/ C D /">$CD$</span>.

![Proposition 1 Diagram](0302.g1.svg)

For, if <span data-ref="0302.g1:/ A B /">$AB$</span>, <span data-ref="0302.g1:/ C D /">$CD$</span> are not prime to one another,<br />
some number will measure them.

Let a number measure them, and let it be<br />
<span data-ref="0302.g1:E">$E$</span>; let <span data-ref="0302.g1:/ C D /">$CD$</span>, measuring <span data-ref="0302.g1:/ F B /">$BF$</span>, leave <span data-ref="0302.g1:/ A F /">$FA$</span> less than<br />
itself,<br />
let <span data-ref="0302.g1:/ A F /">$AF$</span>, measuring <span data-ref="0302.g1:/ G D /">$DG$</span>, leave <span data-ref="0302.g1:/ C G /">$GC$</span> less than itself,<br />
and let <span data-ref="0302.g1:/ C G /">$GC$</span>, measuring <span data-ref="0302.g1:/ H F /">$FH$</span>, leave an unit <span data-ref="0302.g1:/ A H /">$HA$</span>.

<p class="sub-clause">Since, then, <span data-ref="0302.g1:E">$E$</span> measures <span data-ref="0302.g1:/ C D /">$CD$</span>, and <span data-ref="0302.g1:/ C D /">$CD$</span> measures <span data-ref="0302.g1:/ F B /">$BF$</span>,</p>
<p class="assertion">therefore <span data-ref="0302.g1:E">$E$</span> also measures <span data-ref="0302.g1:/ F B /">$BF$</span>.</p>

<p class="sub-clause">But it also measures the whole <span data-ref="0302.g1:/ A B /">$BA$</span>;</p>
<p class="assertion">therefore it will also measure the remainder <span data-ref="0302.g1:/ A F /">$AF$</span>.</p>

<p class="sub-clause">But <span data-ref="0302.g1:/ A F /">$AF$</span> measures <span data-ref="0302.g1:/ G D /">$DG$</span>;</p>
<p class="assertion">therefore <span data-ref="0302.g1:E">$E$</span> also measures <span data-ref="0302.g1:/ G D /">$DG$</span>.</p>
