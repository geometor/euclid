BOOK VII. PROPOSITIONS.

### PROPOSITION 1.

*Two unequal numbers being set out, and the less being continually subtracted in turn from the greater, if the number which is left never measures the one before it until an unit is left, the original numbers will be prime to one another.*

For, the less of two unequal numbers <span data-ref="0302.g1:/ A B /">$AB$</span>, <span data-ref="0302.g1:/ C D /">$CD$</span> being continually subtracted from the greater, let the number which is left never measure the one before it until an unit is left;
I say that <span data-ref="0302.g1:/ A B /">$AB$</span>, <span data-ref="0302.g1:/ C D /">$CD$</span> are prime to one another, that is, that an unit alone measures <span data-ref="0302.g1:/ A B /">$AB$</span>, <span data-ref="0302.g1:/ C D /">$CD$</span>.

![Proposition 1 Diagram](0302.g1.svg)

For, if <span data-ref="0302.g1:/ A B /">$AB$</span>, <span data-ref="0302.g1:/ C D /">$CD$</span> are not prime to one another, some number will measure them.

Let a number measure them, and let it be <span data-ref="0302.g1:E">$E$</span>; let <span data-ref="0302.g1:/ C D /">$CD$</span>, measuring <span data-ref="0302.g1:/ F B /">$BF$</span>, leave <span data-ref="0302.g1:/ A F /">$FA$</span> less than itself,
let <span data-ref="0302.g1:/ A F /">$AF$</span>, measuring <span data-ref="0302.g1:/ G D /">$DG$</span>, leave <span data-ref="0302.g1:/ C G /">$GC$</span> less than itself,
and let <span data-ref="0302.g1:/ C G /">$GC$</span>, measuring <span data-ref="0302.g1:/ H F /">$FH$</span>, leave an unit <span data-ref="0302.g1:/ A H /">$HA$</span>.

Since, then, <span data-ref="0302.g1:E">$E$</span> measures <span data-ref="0302.g1:/ C D /">$CD$</span>, and <span data-ref="0302.g1:/ C D /">$CD$</span> measures <span data-ref="0302.g1:/ F B /">$BF$</span>, therefore <span data-ref="0302.g1:E">$E$</span> also measures <span data-ref="0302.g1:/ F B /">$BF$</span>.

But it also measures the whole <span data-ref="0302.g1:/ A B /">$BA$</span>;
therefore it will also measure the remainder <span data-ref="0302.g1:/ A F /">$AF$</span>.

But <span data-ref="0302.g1:/ A F /">$AF$</span> measures <span data-ref="0302.g1:/ G D /">$DG$</span>;
therefore <span data-ref="0302.g1:E">$E$</span> also measures <span data-ref="0302.g1:/ G D /">$DG$</span>.
