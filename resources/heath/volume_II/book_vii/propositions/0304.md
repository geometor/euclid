### PROPOSITION 2.

<p class="enunciation">Given two numbers not prime to one another, to find their<br />
greatest common measure.</p>

Let <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span> be the two given numbers not prime to one<br />
another.

Thus it is required to find the greatest<br />
common measure of <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span>.

If now <span data-ref="0304.g1:/ C D /">$CD$</span> measures <span data-ref="0304.g1:/ A B /">$AB$</span>—and it also<br />
measures itself—<span data-ref="0304.g1:/ C D /">$CD$</span> is a common measure of<br />
<span data-ref="0304.g1:/ C D /">$CD$</span>, <span data-ref="0304.g1:/ A B /">$AB$</span>.

And it is manifest that it is also the greatest;<br />
for no greater number than <span data-ref="0304.g1:/ C D /">$CD$</span> will measure<br />
<span data-ref="0304.g1:/ C D /">$CD$</span>.

![Proposition 2 Diagram](0304.g1.svg)

But, if <span data-ref="0304.g1:/ C D /">$CD$</span> does not measure <span data-ref="0304.g1:/ A B /">$AB$</span>, then, the less of the<br />
numbers <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span> being continually subtracted from the<br />
greater, some number will be left which will measure the one<br />
before it.

<p class="sub-clause">For an unit will not be left; otherwise <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span> will be<br />
prime to one another <span class="justification">[VII. 1]</span>, which is contrary to the<br />
hypothesis.</p>

<p class="assertion">Therefore some number will be left which will measure<br />
the one before it.</p>

Now let <span data-ref="0304.g1:/ C D /">$CD$</span>, measuring <span data-ref="0304.g1:/ E B /">$BE$</span>, leave <span data-ref="0304.g1:/ A E /">$EA$</span> less than itself,<br />
let <span data-ref="0304.g1:/ A E /">$EA$</span>, measuring <span data-ref="0304.g1:/ F D /">$DF$</span>, leave <span data-ref="0304.g1:/ C F /">$FC$</span> less than itself,<br />
and let <span data-ref="0304.g1:/ C F /">$CF$</span> measure <span data-ref="0304.g1:/ A E /">$AE$</span>.

<p class="sub-clause">Since then, <span data-ref="0304.g1:/ C F /">$CF$</span> measures <span data-ref="0304.g1:/ A E /">$AE$</span>, and <span data-ref="0304.g1:/ A E /">$AE$</span> measures <span data-ref="0304.g1:/ F D /">$DF$</span>,</p>
<p class="assertion">therefore <span data-ref="0304.g1:/ C F /">$CF$</span> will also measure <span data-ref="0304.g1:/ F D /">$DF$</span>.</p>

<p class="sub-clause">But it also measures itself;</p>
<p class="assertion">therefore it will also measure the whole <span data-ref="0304.g1:/ C D /">$CD$</span>.</p>

<p class="sub-clause">But <span data-ref="0304.g1:/ C D /">$CD$</span> measures <span data-ref="0304.g1:/ E B /">$BE$</span>;</p>
<p class="assertion">therefore <span data-ref="0304.g1:/ C F /">$CF$</span> also measures <span data-ref="0304.g1:/ E B /">$BE$</span>.</p>

<p class="sub-clause">But it also measures <span data-ref="0304.g1:/ A E /">$EA$</span>;</p>
<p class="assertion">therefore it will also measure the whole <span data-ref="0304.g1:/ A B /">$BA$</span>.</p>

<p class="sub-clause">But it also measures <span data-ref="0304.g1:/ C D /">$CD$</span>;</p>
<p class="assertion">therefore <span data-ref="0304.g1:/ C F /">$CF$</span> measures <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span>.</p>

<p class="assertion">Therefore <span data-ref="0304.g1:/ C F /">$CF$</span> is a common measure of <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span>.</p>
