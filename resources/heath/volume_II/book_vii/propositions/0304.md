### PROPOSITION 2.

*Given two numbers not prime to one another, to find their greatest common measure.*

Let <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span> be the two given numbers not prime to one another.

Thus it is required to find the greatest common measure of <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span>.

If now <span data-ref="0304.g1:/ C D /">$CD$</span> measures <span data-ref="0304.g1:/ A B /">$AB$</span>—and it also measures itself—<span data-ref="0304.g1:/ C D /">$CD$</span> is a common measure of <span data-ref="0304.g1:/ C D /">$CD$</span>, <span data-ref="0304.g1:/ A B /">$AB$</span>.

And it is manifest that it is also the greatest; for no greater number than <span data-ref="0304.g1:/ C D /">$CD$</span> will measure <span data-ref="0304.g1:/ C D /">$CD$</span>.

![Proposition 2 Diagram](0304.g1.svg)

But, if <span data-ref="0304.g1:/ C D /">$CD$</span> does not measure <span data-ref="0304.g1:/ A B /">$AB$</span>, then, the less of the numbers <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span> being continually subtracted from the greater, some number will be left which will measure the one before it.

For an unit will not be left; otherwise <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span> will be prime to one another [VII. 1], which is contrary to the hypothesis.

Therefore some number will be left which will measure the one before it.

Now let <span data-ref="0304.g1:/ C D /">$CD$</span>, measuring <span data-ref="0304.g1:/ E B /">$BE$</span>, leave <span data-ref="0304.g1:/ A E /">$EA$</span> less than itself, let <span data-ref="0304.g1:/ A E /">$EA$</span>, measuring <span data-ref="0304.g1:/ F D /">$DF$</span>, leave <span data-ref="0304.g1:/ C F /">$FC$</span> less than itself, and let <span data-ref="0304.g1:/ C F /">$CF$</span> measure <span data-ref="0304.g1:/ A E /">$AE$</span>.

Since then, <span data-ref="0304.g1:/ C F /">$CF$</span> measures <span data-ref="0304.g1:/ A E /">$AE$</span>, and <span data-ref="0304.g1:/ A E /">$AE$</span> measures <span data-ref="0304.g1:/ F D /">$DF$</span>, therefore <span data-ref="0304.g1:/ C F /">$CF$</span> will also measure <span data-ref="0304.g1:/ F D /">$DF$</span>.

But it also measures itself;
therefore it will also measure the whole <span data-ref="0304.g1:/ C D /">$CD$</span>.

But <span data-ref="0304.g1:/ C D /">$CD$</span> measures <span data-ref="0304.g1:/ E B /">$BE$</span>;
therefore <span data-ref="0304.g1:/ C F /">$CF$</span> also measures <span data-ref="0304.g1:/ E B /">$BE$</span>.

But it also measures <span data-ref="0304.g1:/ A E /">$EA$</span>;
therefore it will also measure the whole <span data-ref="0304.g1:/ A B /">$BA$</span>.

But it also measures <span data-ref="0304.g1:/ C D /">$CD$</span>;
therefore <span data-ref="0304.g1:/ C F /">$CF$</span> measures <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span>.

Therefore <span data-ref="0304.g1:/ C F /">$CF$</span> is a common measure of <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span>.
