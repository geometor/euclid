I say next that it is also the greatest.

For, if <span data-ref="0304.g1:/ C F /">$CF$</span> is not the greatest common measure of <span data-ref="0304.g1:/ A B /">$AB$</span>,<br />
<span data-ref="0304.g1:/ C D /">$CD$</span>, some number which is greater than <span data-ref="0304.g1:/ C F /">$CF$</span> will measure the<br />
numbers <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span>.

Let such a number measure them, and let it be <span data-ref="0304.g1:G">$G$</span>.

<p class="sub-clause">Now, since <span data-ref="0304.g1:G">$G$</span> measures <span data-ref="0304.g1:/ C D /">$CD$</span>, while <span data-ref="0304.g1:/ C D /">$CD$</span> measures <span data-ref="0304.g1:/ E B /">$BE$</span>,</p>
<p class="assertion"><span data-ref="0304.g1:G">$G$</span> also measures <span data-ref="0304.g1:/ E B /">$BE$</span>.</p>

<p class="sub-clause">But it also measures the whole <span data-ref="0304.g1:/ A B /">$BA$</span>;</p>
<p class="assertion">therefore it will also measure the remainder <span data-ref="0304.g1:/ A E /">$AE$</span>.</p>

<p class="sub-clause">But <span data-ref="0304.g1:/ A E /">$AE$</span> measures <span data-ref="0304.g1:/ F D /">$DF$</span>;</p>
<p class="assertion">therefore <span data-ref="0304.g1:G">$G$</span> will also measure <span data-ref="0304.g1:/ F D /">$DF$</span>.</p>

<p class="sub-clause">But it also measures the whole <span data-ref="0304.g1:/ C D /">$DC$</span>;</p>
<p class="assertion">therefore it will also measure the remainder <span data-ref="0304.g1:/ C F /">$CF$</span>, that is, the<br />
greater will measure the less: which is impossible.</p>

<p class="assertion">Therefore no number which is greater than <span data-ref="0304.g1:/ C F /">$CF$</span> will measure<br />
the numbers <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span>;<br />
therefore <span data-ref="0304.g1:/ C F /">$CF$</span> is the greatest common measure of <span data-ref="0304.g1:/ A B /">$AB$</span>, <span data-ref="0304.g1:/ C D /">$CD$</span>.</p>

<p class="assertion">PORISM. From this it is manifest that, if a number<br />
measure two numbers, it will also measure their greatest<br />
common measure.</p>

<p class="qed">Q. E. D.</p>

Here we have the exact method of finding the greatest common measure given in the text-books of algebra, including the *reductio ad absurdum* proof that the number arrived at is not only a common measure but the *greatest* common measure. The process of finding the greatest common measure is simply shown thus:

<pre>
         b) a ( p
            pb
            c) b ( q
               qc
               d) c ( r
                  rd
</pre>

We shall arrive, says Euclid, at some number, say $d$, which measures the one before it, i.e. such that $c = rd$. Otherwise the process would go on until we arrived at unity. This is impossible because in that case $a$, $b$ would be prime to one another, which is contrary to the hypothesis.

Next, like the text-books of algebra, he goes on to show that $d$ will be *some* common measure of $a$, $b$. For $d$ measures $c$; therefore it measures $qc + d$, that is, $b$, and hence it measures $pb + c$, that is, $a$.

Lastly, he proves that $d$ is the *greatest* common measure of $a$, $b$ as follows.

Suppose that $e$ is a common measure greater than $d$.

Then $e$, measuring $a$, $b$, must measure $a - pb$, or $c$.
