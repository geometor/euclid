<p class="sub-clause">For, if <span data-ref="0306.g1:D">$D$</span> is not the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>,<br />
some number which is greater than <span data-ref="0306.g1:D">$D$</span> will measure the numbers<br />
<span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>.</p>

Let such a number measure them, and let it be <span data-ref="0306.g1:E">$E$</span>.

<p class="sub-clause">Since then <span data-ref="0306.g1:E">$E$</span> measures <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>,<br />
it will also measure <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span> ;</p>
<p class="assertion">therefore it will also measure the greatest common measure<br />
of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>. <span class="justification">[VII. 2, Por.]</span></p>

<p class="sub-clause">But the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span> is <span data-ref="0306.g1:D">$D$</span> ;</p>
<p class="assertion">therefore <span data-ref="0306.g1:E">$E$</span> measures <span data-ref="0306.g1:D">$D$</span>, the greater the less : which is<br />
impossible.</p>

<p class="assertion">Therefore no number which is greater than <span data-ref="0306.g1:D">$D$</span> will measure<br />
the numbers <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span> ;</p>
<p class="assertion">therefore <span data-ref="0306.g1:D">$D$</span> is the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>.</p>

Next, let <span data-ref="0306.g1:D">$D$</span> not measure <span data-ref="0306.g1:C">$C$</span> ;<br />
I say first that <span data-ref="0306.g1:C">$C$</span>, <span data-ref="0306.g1:D">$D$</span> are not prime to one another.

<p class="sub-clause">For, since <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span> are not prime to one another, some<br />
number will measure them.</p>

<p class="sub-clause">Now that which measures <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span> will also measure <span data-ref="0306.g1:A">$A$</span>,<br />
<span data-ref="0306.g1:B">$B$</span>, and will measure <span data-ref="0306.g1:D">$D$</span>, the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>. <span class="justification">[VII. 2, Por.]</span></p>

<p class="sub-clause">But it measures <span data-ref="0306.g1:C">$C$</span> also ;</p>
<p class="assertion">therefore some number will measure the numbers <span data-ref="0306.g1:D">$D$</span>, <span data-ref="0306.g1:C">$C$</span> ;</p>
<p class="assertion">therefore <span data-ref="0306.g1:D">$D$</span>, <span data-ref="0306.g1:C">$C$</span> are not prime to one another.</p>

Let then their greatest common measure <span data-ref="0306.g1:E">$E$</span> be taken. <span class="justification">[VII. 2]</span>

<p class="sub-clause">Then, since <span data-ref="0306.g1:E">$E$</span> measures <span data-ref="0306.g1:D">$D$</span>,<br />
and <span data-ref="0306.g1:D">$D$</span> measures <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>,</p>
<p class="assertion">therefore <span data-ref="0306.g1:E">$E$</span> also measures <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>.</p>

<p class="sub-clause">But it measures <span data-ref="0306.g1:C">$C$</span> also ;</p>
<p class="assertion">therefore <span data-ref="0306.g1:E">$E$</span> measures <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span> ;</p>
<p class="assertion">therefore <span data-ref="0306.g1:E">$E$</span> is a common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>.</p>

I say next that it is also the greatest.

<p class="sub-clause">For, if <span data-ref="0306.g1:E">$E$</span> is not the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>,<br />
some number which is greater than <span data-ref="0306.g1:E">$E$</span> will measure the<br />
numbers <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>.</p>

Let such a number measure them, and let it be <span data-ref="0306.g1:F">$F$</span>.
