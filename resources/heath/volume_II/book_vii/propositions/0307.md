For, if <span data-ref="0306.g1:D">$D$</span> is not the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>, some number which is greater than <span data-ref="0306.g1:D">$D$</span> will measure the numbers <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>.

Let such a number measure them, and let it be <span data-ref="0306.g1:E">$E$</span>.

Since then <span data-ref="0306.g1:E">$E$</span> measures <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>, it will also measure <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>; therefore it will also measure the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>.
<p align="right">[VII. 2, Por.]</p>

But the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span> is <span data-ref="0306.g1:D">$D$</span>; therefore <span data-ref="0306.g1:E">$E$</span> measures <span data-ref="0306.g1:D">$D$</span>, the greater the less: which is impossible.

Therefore no number which is greater than <span data-ref="0306.g1:D">$D$</span> will measure the numbers <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>; therefore <span data-ref="0306.g1:D">$D$</span> is the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>.

Next, let <span data-ref="0306.g1:D">$D$</span> not measure <span data-ref="0306.g1:C">$C$</span>;
I say first that <span data-ref="0306.g1:C">$C$</span>, <span data-ref="0306.g1:D">$D$</span> are not prime to one another.

For, since <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span> are not prime to one another, some number will measure them.

Now that which measures <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span> will also measure <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, and will measure <span data-ref="0306.g1:D">$D$</span>, the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>.
<p align="right">[VII. 2, Por.]</p>

But it measures <span data-ref="0306.g1:C">$C$</span> also; therefore some number will measure the numbers <span data-ref="0306.g1:D">$D$</span>, <span data-ref="0306.g1:C">$C$</span>; therefore <span data-ref="0306.g1:D">$D$</span>, <span data-ref="0306.g1:C">$C$</span> are not prime to one another.

Let then their greatest common measure <span data-ref="0306.g1:E">$E$</span> be taken.
<p align="right">[VII. 2]</p>

Then, since <span data-ref="0306.g1:E">$E$</span> measures <span data-ref="0306.g1:D">$D$</span>, and <span data-ref="0306.g1:D">$D$</span> measures <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, therefore <span data-ref="0306.g1:E">$E$</span> also measures <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>.

But it measures <span data-ref="0306.g1:C">$C$</span> also; therefore <span data-ref="0306.g1:E">$E$</span> measures <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>; therefore <span data-ref="0306.g1:E">$E$</span> is a common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>.

I say next that it is also the greatest.

For, if <span data-ref="0306.g1:E">$E$</span> is not the greatest common measure of <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>, some number which is greater than <span data-ref="0306.g1:E">$E$</span> will measure the numbers <span data-ref="0306.g1:A">$A$</span>, <span data-ref="0306.g1:B">$B$</span>, <span data-ref="0306.g1:C">$C$</span>.

Let such a number measure them, and let it be <span data-ref="0306.g1:F">$F$</span>.
