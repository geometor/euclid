### PROPOSITION 4.

*Any number is either a part or parts of any number, the less of the greater.*

Let <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> be two numbers, and let <span data-ref="0309.g1:/ B C /">$BC$</span> be the less;
I say that <span data-ref="0309.g1:/ B C /">$BC$</span> is either a part, or parts, of <span data-ref="0309.g1:A">$A$</span>.

For <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> are either prime to one another or not.

First, let <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> be prime to one another.

Then, if <span data-ref="0309.g1:/ B C /">$BC$</span> be divided into the units in it, each unit of those in <span data-ref="0309.g1:/ B C /">$BC$</span> will be some part of <span data-ref="0309.g1:A">$A$</span>; so that <span data-ref="0309.g1:/ B C /">$BC$</span> is parts of <span data-ref="0309.g1:A">$A$</span>.

Next let <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> not be prime to one another; then <span data-ref="0309.g1:/ B C /">$BC$</span> either measures, or does not measure, <span data-ref="0309.g1:A">$A$</span>.

If now <span data-ref="0309.g1:/ B C /">$BC$</span> measures <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> is a part of <span data-ref="0309.g1:A">$A$</span>.

![Proposition 4 Diagram](0309.g1.svg)

But, if not, let the greatest common measure <span data-ref="0309.g1:D">$D$</span> of <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> be taken;
<p align="right">[VII. 2]</p>
and let <span data-ref="0309.g1:/ B C /">$BC$</span> be divided into the numbers equal to <span data-ref="0309.g1:D">$D$</span>, namely <span data-ref="0309.g1:/ B E /">$BE$</span>, <span data-ref="0309.g1:/ E F /">$EF$</span>, <span data-ref="0309.g1:/ F C /">$FC$</span>.

Now, since <span data-ref="0309.g1:D">$D$</span> measures <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:D">$D$</span> is a part of <span data-ref="0309.g1:A">$A$</span>.

But <span data-ref="0309.g1:D">$D$</span> is equal to each of the numbers <span data-ref="0309.g1:/ B E /">$BE$</span>, <span data-ref="0309.g1:/ E F /">$EF$</span>, <span data-ref="0309.g1:/ F C /">$FC$</span>; therefore each of the numbers <span data-ref="0309.g1:/ B E /">$BE$</span>, <span data-ref="0309.g1:/ E F /">$EF$</span>, <span data-ref="0309.g1:/ F C /">$FC$</span> is also a part of <span data-ref="0309.g1:A">$A$</span>; so that <span data-ref="0309.g1:/ B C /">$BC$</span> is parts of <span data-ref="0309.g1:A">$A$</span>.

Therefore etc.

<p align="right"><b>Q. E. D.</b></p>

---

The meaning of the enunciation is of course that, if $a$, $b$ be two numbers of which $b$ is the less, then $b$ is either a submultiple or *some proper fraction of* $a$.

(1) If $a$, $b$ are prime to one another, divide each into its units; then $b$ contains $b$ of the same parts of which $a$ contains $a$. Therefore $b$ is "parts" or *a proper fraction of* $a$.

(2) If $a$, $b$ be not prime to one another, either $b$ measures $a$, in which case $b$ is a submultiple or "part" of $a$, or, if $g$ be the greatest common measure of $a$, $b$, we may put $a = mg$ and $b = ng$, and $b$ will contain $n$ of the same parts ($g$) of which $a$ contains $m$, so that $b$ is again "parts," or *a proper fraction, of* $a$.
