### PROPOSITION 4.

<p class="enunciation">Any number is either a part or parts of any number, the<br />
less of the greater.</p>

Let <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> be two numbers, and let <span data-ref="0309.g1:/ B C /">$BC$</span> be the less ;<br />
I say that <span data-ref="0309.g1:/ B C /">$BC$</span> is either a part, or parts, of <span data-ref="0309.g1:A">$A$</span>.

<p class="sub-clause">For <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> are either prime to one another<br />
or not.</p>

First, let <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> be prime to one another.

<p class="sub-clause">Then, if <span data-ref="0309.g1:/ B C /">$BC$</span> be divided into the units in it,<br />
each unit of those in <span data-ref="0309.g1:/ B C /">$BC$</span> will be some part of <span data-ref="0309.g1:A">$A$</span> ;</p>
<p class="assertion">so that <span data-ref="0309.g1:/ B C /">$BC$</span> is parts of <span data-ref="0309.g1:A">$A$</span>.</p>

Next let <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> not be prime to one another ;<br />
then <span data-ref="0309.g1:/ B C /">$BC$</span> either measures, or does not measure, <span data-ref="0309.g1:A">$A$</span>.

<p class="sub-clause">If now <span data-ref="0309.g1:/ B C /">$BC$</span> measures <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span> is a part of <span data-ref="0309.g1:A">$A$</span>.</p>

![Proposition 4 Diagram](0309.g1.svg)

But, if not, let the greatest common measure <span data-ref="0309.g1:D">$D$</span> of <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:/ B C /">$BC$</span><br />
be taken ; <span class="justification">[VII. 2]</span><br />
and let <span data-ref="0309.g1:/ B C /">$BC$</span> be divided into the numbers equal to <span data-ref="0309.g1:D">$D$</span>, namely<br />
<span data-ref="0309.g1:/ B E /">$BE$</span>, <span data-ref="0309.g1:/ E F /">$EF$</span>, <span data-ref="0309.g1:/ F C /">$FC$</span>.

<p class="sub-clause">Now, since <span data-ref="0309.g1:D">$D$</span> measures <span data-ref="0309.g1:A">$A$</span>, <span data-ref="0309.g1:D">$D$</span> is a part of <span data-ref="0309.g1:A">$A$</span>.</p>

<p class="sub-clause">But <span data-ref="0309.g1:D">$D$</span> is equal to each of the numbers <span data-ref="0309.g1:/ B E /">$BE$</span>, <span data-ref="0309.g1:/ E F /">$EF$</span>, <span data-ref="0309.g1:/ F C /">$FC$</span> ;</p>
<p class="assertion">therefore each of the numbers <span data-ref="0309.g1:/ B E /">$BE$</span>, <span data-ref="0309.g1:/ E F /">$EF$</span>, <span data-ref="0309.g1:/ F C /">$FC$</span> is also a part of <span data-ref="0309.g1:A">$A$</span> ;</p>
<p class="assertion">so that <span data-ref="0309.g1:/ B C /">$BC$</span> is parts of <span data-ref="0309.g1:A">$A$</span>.</p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>

---

The meaning of the enunciation is of course that, if $a$, $b$ be two numbers<br />
of which $b$ is the less, then $b$ is either a submultiple or *some proper fraction of $a$*.

(1) If $a$, $b$ are prime to one another, divide each into its units; then $b$<br />
contains $b$ of the same parts of which $a$ contains $a$. Therefore $b$ is "parts" or<br />
*a proper fraction of $a$*.

(2) If $a$, $b$ be not prime to one another, either $b$ measures $a$, in which<br />
case $b$ is a submultiple or "part" of $a$, or, if $g$ be the greatest common<br />
measure of $a$, $b$, we may put $a = mg$ and $b = ng$, and $b$ will contain $n$ of the<br />
same parts ($g$) of which $a$ contains $m$, so that $b$ is again "parts," or *a proper<br />
fraction, of $a$*.
