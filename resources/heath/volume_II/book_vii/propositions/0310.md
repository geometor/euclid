### PROPOSITION 5.

*If a number be a part of a number, and another be the same part of another, the sum will also be the same part of the sum that the one is of the one.*

For let the number <span data-ref="0310.g1:A">$A$</span> be a part of <span data-ref="0310.g1:/ B C /">$BC$</span>,
and another, <span data-ref="0310.g1:D">$D$</span>, the same part of another <span data-ref="0310.g1:/ E F /">$EF$</span> that <span data-ref="0310.g1:A">$A$</span> is of <span data-ref="0310.g1:/ B C /">$BC$</span>;
I say that the sum of <span data-ref="0310.g1:A">$A$</span>, <span data-ref="0310.g1:D">$D$</span> is also the same
part of the sum of <span data-ref="0310.g1:/ B C /">$BC$</span>, <span data-ref="0310.g1:/ E F /">$EF$</span> that <span data-ref="0310.g1:A">$A$</span> is of <span data-ref="0310.g1:/ B C /">$BC$</span>.

![Book VII, Proposition 5](0310.g1.svg)

For since, whatever part <span data-ref="0310.g1:A">$A$</span> is of <span data-ref="0310.g1:/ B C /">$BC$</span>, <span data-ref="0310.g1:D">$D$</span>
is also the same part of <span data-ref="0310.g1:/ E F /">$EF$</span>,
therefore, as many numbers as there are in
<span data-ref="0310.g1:/ B C /">$BC$</span> equal to <span data-ref="0310.g1:A">$A$</span>, so many numbers are there
also in <span data-ref="0310.g1:/ E F /">$EF$</span> equal to <span data-ref="0310.g1:D">$D$</span>.

Let <span data-ref="0310.g1:/ B C /">$BC$</span> be divided into the numbers equal to <span data-ref="0310.g1:A">$A$</span>, namely
<span data-ref="0310.g1:/ B G /">$BG$</span>, <span data-ref="0310.g1:/ G C /">$GC$</span>,
and <span data-ref="0310.g1:/ E F /">$EF$</span> into the numbers equal to <span data-ref="0310.g1:D">$D$</span>, namely <span data-ref="0310.g1:/ E H /">$EH$</span>, <span data-ref="0310.g1:/ H F /">$HF$</span>;
then the multitude of <span data-ref="0310.g1:/ B G /">$BG$</span>, <span data-ref="0310.g1:/ G C /">$GC$</span> will be equal to the multitude
of <span data-ref="0310.g1:/ E H /">$EH$</span>, <span data-ref="0310.g1:/ H F /">$HF$</span>.

And, since <span data-ref="0310.g1:/ B G /">$BG$</span> is equal to <span data-ref="0310.g1:A">$A$</span>, and <span data-ref="0310.g1:/ E H /">$EH$</span> to <span data-ref="0310.g1:D">$D$</span>,
therefore <span data-ref="0310.g1:/ B G /">$BG$</span>, <span data-ref="0310.g1:/ E H /">$EH$</span> are also equal to <span data-ref="0310.g1:A">$A$</span>, <span data-ref="0310.g1:D">$D$</span>.

For the same reason
<span data-ref="0310.g1:/ G C /">$GC$</span>, <span data-ref="0310.g1:/ H F /">$HF$</span> are also equal to <span data-ref="0310.g1:A">$A$</span>, <span data-ref="0310.g1:D">$D$</span>.

Therefore, as many numbers as there are in <span data-ref="0310.g1:/ B C /">$BC$</span> equal to
<span data-ref="0310.g1:A">$A$</span>, so many are there also in <span data-ref="0310.g1:/ B C /">$BC$</span>, <span data-ref="0310.g1:/ E F /">$EF$</span> equal to <span data-ref="0310.g1:A">$A$</span>, <span data-ref="0310.g1:D">$D$</span>.

Therefore, whatever multiple <span data-ref="0310.g1:/ B C /">$BC$</span> is of <span data-ref="0310.g1:A">$A$</span>, the same multiple
also is the sum of <span data-ref="0310.g1:/ B C /">$BC$</span>, <span data-ref="0310.g1:/ E F /">$EF$</span> of the sum of <span data-ref="0310.g1:A">$A$</span>, <span data-ref="0310.g1:D">$D$</span>.

Therefore, whatever part <span data-ref="0310.g1:A">$A$</span> is of <span data-ref="0310.g1:/ B C /">$BC$</span>, the same part also
is the sum of <span data-ref="0310.g1:A">$A$</span>, <span data-ref="0310.g1:D">$D$</span> of the sum of <span data-ref="0310.g1:/ B C /">$BC$</span>, <span data-ref="0310.g1:/ E F /">$EF$</span>.

<p align="right">Q. E. D.</p>

If
$$a = \frac{1}{n}b, \text{ and } c = \frac{1}{n}d, \text{ then}$$
$$a + c = \frac{1}{n}(b + d).$$

The proposition is of course true for any quantity of pairs of numbers
similarly related, as is the next proposition also; and both propositions are
used in the extended form in VII. 9, 10.
