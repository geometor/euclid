### PROPOSITION 13.

*If four numbers be proportional, they will also be proportional alternately.*

Let the four numbers <span data-ref="0319.g1:A">$A$</span>, <span data-ref="0319.g1:B">$B$</span>, <span data-ref="0319.g1:C">$C$</span>, <span data-ref="0319.g1:D">$D$</span> be proportional, so that,

<p align="center">as <span data-ref="0319.g1:A">$A$</span> is to <span data-ref="0319.g1:B">$B$</span>, so is <span data-ref="0319.g1:C">$C$</span> to <span data-ref="0319.g1:D">$D$</span>;</p>

I say that they will also be proportional alternately, so that,

<p align="center">as <span data-ref="0319.g1:A">$A$</span> is to <span data-ref="0319.g1:C">$C$</span>, so will <span data-ref="0319.g1:B">$B$</span> be to <span data-ref="0319.g1:D">$D$</span>.</p>

![Proposition 13 Diagram](0319.g1.svg)

For since, as <span data-ref="0319.g1:A">$A$</span> is to <span data-ref="0319.g1:B">$B$</span>, so is <span data-ref="0319.g1:C">$C$</span> to <span data-ref="0319.g1:D">$D$</span>, therefore, whatever part or parts <span data-ref="0319.g1:A">$A$</span> is of <span data-ref="0319.g1:B">$B$</span>, the same part or the same parts is <span data-ref="0319.g1:C">$C$</span> of <span data-ref="0319.g1:D">$D$</span> also. [VII. Def. 20]

Therefore, alternately, whatever part or parts <span data-ref="0319.g1:A">$A$</span> is of <span data-ref="0319.g1:C">$C$</span>, the same part or the same parts is <span data-ref="0319.g1:B">$B$</span> of <span data-ref="0319.g1:D">$D$</span> also. [VII. 10]

Therefore, as <span data-ref="0319.g1:A">$A$</span> is to <span data-ref="0319.g1:C">$C$</span>, so is <span data-ref="0319.g1:B">$B$</span> to <span data-ref="0319.g1:D">$D$</span>. [VII. Def. 20]

<p align="right">Q. E. D.</p>

---

$$
\begin{aligned}
\text{If} \quad & a : b = c : d, \\
\text{then, alternately,} \quad & a : c = b : d.
\end{aligned}
$$

The proposition corresponds to V. 16 for magnitudes, and the proof consists in connecting VII. Def. 20 with the result of VII. 10.

### PROPOSITION 14.

*If there be as many numbers as we please, and others equal to them in multitude, which taken two and two are in the same ratio, they will also be in the same ratio ex aequali.*

Let there be as many numbers as we please <span data-ref="0319.g2:A">$A$</span>, <span data-ref="0319.g2:B">$B$</span>, <span data-ref="0319.g2:C">$C$</span>, and others equal to them in multitude <span data-ref="0319.g2:D">$D$</span>, <span data-ref="0319.g2:E">$E$</span>, <span data-ref="0319.g2:F">$F$</span>, which taken two and two are in the same ratio, so that,

<p align="center">as <span data-ref="0319.g2:A">$A$</span> is to <span data-ref="0319.g2:B">$B$</span>, so is <span data-ref="0319.g2:D">$D$</span> to <span data-ref="0319.g2:E">$E$</span>,</p>

and,

<p align="center">as <span data-ref="0319.g2:B">$B$</span> is to <span data-ref="0319.g2:C">$C$</span>, so is <span data-ref="0319.g2:E">$E$</span> to <span data-ref="0319.g2:F">$F$</span>;</p>

I say that, *ex aequali*,

<p align="center">as <span data-ref="0319.g2:A">$A$</span> is to <span data-ref="0319.g2:C">$C$</span>, so also is <span data-ref="0319.g2:D">$D$</span> to <span data-ref="0319.g2:F">$F$</span>.</p>

![Proposition 14 Diagram](0319.g2.svg)

For, since, as <span data-ref="0319.g2:A">$A$</span> is to <span data-ref="0319.g2:B">$B$</span>, so is <span data-ref="0319.g2:D">$D$</span> to <span data-ref="0319.g2:E">$E$</span>, therefore, alternately,

<p align="center">as <span data-ref="0319.g2:A">$A$</span> is to <span data-ref="0319.g2:D">$D$</span>, so is <span data-ref="0319.g2:B">$B$</span> to <span data-ref="0319.g2:E">$E$</span>. [VII. 13]</p>
