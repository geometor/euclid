### PROPOSITION 13.

<p class="enunciation">If four numbers be proportional, they will also be propor-<br />
tional alternately.</p>

Let the four numbers <span data-ref="0319.g1:A">$A$</span>, <span data-ref="0319.g1:B">$B$</span>, <span data-ref="0319.g1:C">$C$</span>, <span data-ref="0319.g1:D">$D$</span> be proportional, so that,<br />
as <span data-ref="0319.g1:A">$A$</span> is to <span data-ref="0319.g1:B">$B$</span>, so is <span data-ref="0319.g1:C">$C$</span> to <span data-ref="0319.g1:D">$D$</span>;

I say that they will also be proportional alternately, so that,<br />
as <span data-ref="0319.g1:A">$A$</span> is to <span data-ref="0319.g1:C">$C$</span>, so will <span data-ref="0319.g1:B">$B$</span> be to <span data-ref="0319.g1:D">$D$</span>.

![Proposition 13 Diagram](0319.g1.svg)

<p class="sub-clause">For since, as <span data-ref="0319.g1:A">$A$</span> is to <span data-ref="0319.g1:B">$B$</span>, so is <span data-ref="0319.g1:C">$C$</span> to <span data-ref="0319.g1:D">$D$</span>,</p>
<p class="assertion">therefore, whatever part or parts <span data-ref="0319.g1:A">$A$</span> is of <span data-ref="0319.g1:B">$B$</span>,<br />
the same part or the same parts is <span data-ref="0319.g1:C">$C$</span> of <span data-ref="0319.g1:D">$D$</span> also. <span class="justification">[VII. Def. 20]</span></p>

<p class="assertion">Therefore, alternately, whatever part or<br />
parts <span data-ref="0319.g1:A">$A$</span> is of <span data-ref="0319.g1:C">$C$</span>, the same part or the same<br />
parts is <span data-ref="0319.g1:B">$B$</span> of <span data-ref="0319.g1:D">$D$</span> also. <span class="justification">[VII. 10]</span></p>

<p class="assertion">Therefore, as <span data-ref="0319.g1:A">$A$</span> is to <span data-ref="0319.g1:C">$C$</span>, so is <span data-ref="0319.g1:B">$B$</span> to <span data-ref="0319.g1:D">$D$</span>. <span class="justification">[VII. Def. 20]</span></p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

$$
\begin{aligned}
\text{If} \quad & a : b = c : d, \\
\text{then, alternately,} \quad & a : c = b : d.
\end{aligned}
$$

The proposition corresponds to V. 16 for magnitudes, and the proof<br />
consists in connecting VII. Def. 20 with the result of VII. 10.

### PROPOSITION 14.

<p class="enunciation">If there be as many numbers as we please, and others equal<br />
to them in multitude, which taken two and two are in the same<br />
ratio, they will also be in the same ratio ex aequali.</p>

Let there be as many numbers as we please <span data-ref="0319.g2:A">$A$</span>, <span data-ref="0319.g2:B">$B$</span>, <span data-ref="0319.g2:C">$C$</span>,<br />
and others equal to them in multitude <span data-ref="0319.g2:D">$D$</span>, <span data-ref="0319.g2:E">$E$</span>, <span data-ref="0319.g2:F">$F$</span>, which taken<br />
two and two are in the same ratio, so that,<br />
as <span data-ref="0319.g2:A">$A$</span> is to <span data-ref="0319.g2:B">$B$</span>, so is <span data-ref="0319.g2:D">$D$</span> to <span data-ref="0319.g2:E">$E$</span>,<br />
and,<br />
as <span data-ref="0319.g2:B">$B$</span> is to <span data-ref="0319.g2:C">$C$</span>, so is <span data-ref="0319.g2:E">$E$</span> to <span data-ref="0319.g2:F">$F$</span>;

I say that, *ex aequali*,<br />
as <span data-ref="0319.g2:A">$A$</span> is to <span data-ref="0319.g2:C">$C$</span>, so also is <span data-ref="0319.g2:D">$D$</span> to <span data-ref="0319.g2:F">$F$</span>.

![Proposition 14 Diagram](0319.g2.svg)

<p class="sub-clause">For, since, as <span data-ref="0319.g2:A">$A$</span> is to <span data-ref="0319.g2:B">$B$</span>, so is <span data-ref="0319.g2:D">$D$</span> to <span data-ref="0319.g2:E">$E$</span>,</p>
<p class="assertion">therefore, alternately,<br />
as <span data-ref="0319.g2:A">$A$</span> is to <span data-ref="0319.g2:D">$D$</span>, so is <span data-ref="0319.g2:B">$B$</span> to <span data-ref="0319.g2:E">$E$</span>. <span class="justification">[VII. 13]</span></p>
