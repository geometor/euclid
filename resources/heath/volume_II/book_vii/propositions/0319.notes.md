# Transcription Notes: Folio 0319 (Page 313)

## Summary & Folio Continuity
- **Proposition 13 (complete)**: Alternando for proportional numbers: $A : B = C : D \implies A : C = B : D$. Cites VII. Def. 20 and VII. 10. Concludes with Q.E.D.
- **Heath Commentary on Prop 13**: Relates the theorem to Book V, Proposition 16 for magnitudes.
- **Proposition 14 (opening)**: Establishes proportion *ex aequali* for numbers ($A : B = D : E$ and $B : C = E : F \implies A : C = D : F$). Enunciation, specification, diagram, and the first step of proof (alternating $A : B = D : E$ to $A : D = B : E$ by VII. 13) appear on this page; the proof continues onto Page 314 (Folio 0320).

## Textual / Lexical / Mathematical Observations
- **Alternate Proportion Linkage**: Proposition 14 in Book VII is proved directly by alternating the terms using VII. 13, in sharp contrast to Book V, Proposition 22 where alternando cannot be used because magnitudes across different ratios might not be of the same kind.
- **Terminology**: The Latin technical term *ex aequali* is italicized in Heath's translation and commentary, representing the Greek δι᾽ ἴσου.
