For let the unit <span data-ref="0321.g1:A">$A$</span> measure any number <span data-ref="0321.g1:/ B C /">$BC$</span>, and let another number <span data-ref="0321.g1:D">$D$</span> measure any other number <span data-ref="0321.g1:/ E F /">$EF$</span> the same number of times;

I say that, alternately also, the unit <span data-ref="0321.g1:A">$A$</span> measures the number <span data-ref="0321.g1:D">$D$</span> the same number of times that <span data-ref="0321.g1:/ B C /">$BC$</span> measures <span data-ref="0321.g1:/ E F /">$EF$</span>.

![Proposition 15 Diagram](0321.g1.svg)

For, since the unit <span data-ref="0321.g1:A">$A$</span> measures the number <span data-ref="0321.g1:/ B C /">$BC$</span> the same number of times that <span data-ref="0321.g1:D">$D$</span> measures <span data-ref="0321.g1:/ E F /">$EF$</span>, therefore, as many units as there are in <span data-ref="0321.g1:/ B C /">$BC$</span>, so many numbers equal to <span data-ref="0321.g1:D">$D$</span> are there in <span data-ref="0321.g1:/ E F /">$EF$</span> also.

Let <span data-ref="0321.g1:/ B C /">$BC$</span> be divided into the units in it, <span data-ref="0321.g1:/ B G /">$BG$</span>, <span data-ref="0321.g1:/ G H /">$GH$</span>, <span data-ref="0321.g1:/ H C /">$HC$</span>, and <span data-ref="0321.g1:/ E F /">$EF$</span> into the numbers <span data-ref="0321.g1:/ E K /">$EK$</span>, <span data-ref="0321.g1:/ K L /">$KL$</span>, <span data-ref="0321.g1:/ L F /">$LF$</span> equal to <span data-ref="0321.g1:D">$D$</span>.

Thus the multitude of <span data-ref="0321.g1:/ B G /">$BG$</span>, <span data-ref="0321.g1:/ G H /">$GH$</span>, <span data-ref="0321.g1:/ H C /">$HC$</span> will be equal to the multitude of <span data-ref="0321.g1:/ E K /">$EK$</span>, <span data-ref="0321.g1:/ K L /">$KL$</span>, <span data-ref="0321.g1:/ L F /">$LF$</span>.

And, since the units <span data-ref="0321.g1:/ B G /">$BG$</span>, <span data-ref="0321.g1:/ G H /">$GH$</span>, <span data-ref="0321.g1:/ H C /">$HC$</span> are equal to one another, and the numbers <span data-ref="0321.g1:/ E K /">$EK$</span>, <span data-ref="0321.g1:/ K L /">$KL$</span>, <span data-ref="0321.g1:/ L F /">$LF$</span> are also equal to one another, while the multitude of the units <span data-ref="0321.g1:/ B G /">$BG$</span>, <span data-ref="0321.g1:/ G H /">$GH$</span>, <span data-ref="0321.g1:/ H C /">$HC$</span> is equal to the multitude of the numbers <span data-ref="0321.g1:/ E K /">$EK$</span>, <span data-ref="0321.g1:/ K L /">$KL$</span>, <span data-ref="0321.g1:/ L F /">$LF$</span>, therefore, as the unit <span data-ref="0321.g1:/ B G /">$BG$</span> is to the number <span data-ref="0321.g1:/ E K /">$EK$</span>, so will the unit <span data-ref="0321.g1:/ G H /">$GH$</span> be to the number <span data-ref="0321.g1:/ K L /">$KL$</span>, and the unit <span data-ref="0321.g1:/ H C /">$HC$</span> to the number <span data-ref="0321.g1:/ L F /">$LF$</span>.

Therefore also, as one of the antecedents is to one of the consequents, so will all the antecedents be to all the consequents; [VII. 12]

therefore, as the unit <span data-ref="0321.g1:/ B G /">$BG$</span> is to the number <span data-ref="0321.g1:/ E K /">$EK$</span>, so is <span data-ref="0321.g1:/ B C /">$BC$</span> to <span data-ref="0321.g1:/ E F /">$EF$</span>.

But the unit <span data-ref="0321.g1:/ B G /">$BG$</span> is equal to the unit <span data-ref="0321.g1:A">$A$</span>, and the number <span data-ref="0321.g1:/ E K /">$EK$</span> to the number <span data-ref="0321.g1:D">$D$</span>.

Therefore, as the unit <span data-ref="0321.g1:A">$A$</span> is to the number <span data-ref="0321.g1:D">$D$</span>, so is <span data-ref="0321.g1:/ B C /">$BC$</span> to <span data-ref="0321.g1:/ E F /">$EF$</span>.

Therefore the unit <span data-ref="0321.g1:A">$A$</span> measures the number <span data-ref="0321.g1:D">$D$</span> the same number of times that <span data-ref="0321.g1:/ B C /">$BC$</span> measures <span data-ref="0321.g1:/ E F /">$EF$</span>.

<p align="right">Q. E. D.</p>

---

If there be four numbers $1, m, a, ma$ (such that $1$ measures $m$ the same number of times that $a$ measures $ma$), $1$ measures $a$ the same number of times that $m$ measures $ma$.

Except that the first number is unity and the numbers are said to *measure* instead of being a *part* of others, this proposition and its proof do not differ from VII. 9; in fact this proposition is a particular case of the other.
