### PROPOSITION 16.

*If two numbers by multiplying one another make certain numbers, the numbers so produced[^316_1] will be equal to one another.*

Let <span data-ref="0322.g1:A">$A$</span>, <span data-ref="0322.g1:B">$B$</span> be two numbers, and let <span data-ref="0322.g1:A">$A$</span> by multiplying <span data-ref="0322.g1:B">$B$</span> make <span data-ref="0322.g1:C">$C$</span>, and <span data-ref="0322.g1:B">$B$</span> by multiplying <span data-ref="0322.g1:A">$A$</span> make <span data-ref="0322.g1:D">$D$</span>;

I say that <span data-ref="0322.g1:C">$C$</span> is equal to <span data-ref="0322.g1:D">$D$</span>.

![Proposition 16 Diagram](0322.g1.svg)

For, since <span data-ref="0322.g1:A">$A$</span> by multiplying <span data-ref="0322.g1:B">$B$</span> has made <span data-ref="0322.g1:C">$C$</span>, therefore <span data-ref="0322.g1:B">$B$</span> measures <span data-ref="0322.g1:C">$C$</span> according to the units in <span data-ref="0322.g1:A">$A$</span>.

But the unit <span data-ref="0322.g1:E">$E$</span> also measures the number <span data-ref="0322.g1:A">$A$</span> according to the units in it;

therefore the unit <span data-ref="0322.g1:E">$E$</span> measures <span data-ref="0322.g1:A">$A$</span> the same number of times that <span data-ref="0322.g1:B">$B$</span> measures <span data-ref="0322.g1:C">$C$</span>.

Therefore, alternately, the unit <span data-ref="0322.g1:E">$E$</span> measures the number <span data-ref="0322.g1:B">$B$</span> the same number of times that <span data-ref="0322.g1:A">$A$</span> measures <span data-ref="0322.g1:C">$C$</span>. [VII. 15]

Again, since <span data-ref="0322.g1:B">$B$</span> by multiplying <span data-ref="0322.g1:A">$A$</span> has made <span data-ref="0322.g1:D">$D$</span>, therefore <span data-ref="0322.g1:A">$A$</span> measures <span data-ref="0322.g1:D">$D$</span> according to the units in <span data-ref="0322.g1:B">$B$</span>.

But the unit <span data-ref="0322.g1:E">$E$</span> also measures <span data-ref="0322.g1:B">$B$</span> according to the units in it;

therefore the unit <span data-ref="0322.g1:E">$E$</span> measures the number <span data-ref="0322.g1:B">$B$</span> the same number of times that <span data-ref="0322.g1:A">$A$</span> measures <span data-ref="0322.g1:D">$D$</span>.

But the unit <span data-ref="0322.g1:E">$E$</span> measured the number <span data-ref="0322.g1:B">$B$</span> the same number of times that <span data-ref="0322.g1:A">$A$</span> measures <span data-ref="0322.g1:C">$C$</span>;

therefore <span data-ref="0322.g1:A">$A$</span> measures each of the numbers <span data-ref="0322.g1:C">$C$</span>, <span data-ref="0322.g1:D">$D$</span> the same number of times.

Therefore <span data-ref="0322.g1:C">$C$</span> is equal to <span data-ref="0322.g1:D">$D$</span>.

<p align="right">Q. E. D.</p>

[^316_1]: **2. The numbers so produced.** The Greek has οἱ γενόμενοι ἐξ αὐτῶν, "the (numbers) produced *from them*." By "from them" Euclid means "from the original numbers," though this is not very clear even in the Greek. I think ambiguity is best avoided by leaving out the words.

---

This proposition proves that, *if any numbers be multiplied together, the order of multiplication is indifferent*, or $ab = ba$.

It is important to get a clear understanding of what Euclid means when he speaks of *one number multiplying another*. VII. Def. 15 states that the effect of "$a$ multiplying $b$" is taking $a$ times $b$. We shall always represent "$a$ times $b$" by $ab$ and "$b$ times $a$" by $ba$.
