$$
\begin{aligned}
\text{By VII. Def. 20,} \quad & 1 : a = b : ab. \\
\text{Therefore, alternately,} \quad & 1 : b = a : ab. \quad \text{[VII. 13]} \\
\text{Again, by VII. Def. 20,} \quad & 1 : b = a : ba. \\
\text{Therefore} \quad & a : ab = a : ba, \\
\text{or} \quad & ab = ba.
\end{aligned}
$$

Euclid does not use the language of proportions but that of fractions or their equivalent measures, quoting VII. 15, a particular case of VII. 13 differently expressed, instead of VII. 13 itself.

### PROPOSITION 17.

*If a number by multiplying two numbers make certain numbers, the numbers so produced will have the same ratio as the numbers multiplied.*

For let the number <span data-ref="0323.g1:A">$A$</span> by multiplying the two numbers <span data-ref="0323.g1:B">$B$</span>, <span data-ref="0323.g1:C">$C$</span> make <span data-ref="0323.g1:D">$D$</span>, <span data-ref="0323.g1:E">$E$</span>;

I say that, as <span data-ref="0323.g1:B">$B$</span> is to <span data-ref="0323.g1:C">$C$</span>, so is <span data-ref="0323.g1:D">$D$</span> to <span data-ref="0323.g1:E">$E$</span>.

For, since <span data-ref="0323.g1:A">$A$</span> by multiplying <span data-ref="0323.g1:B">$B$</span> has made <span data-ref="0323.g1:D">$D$</span>, therefore <span data-ref="0323.g1:B">$B$</span> measures <span data-ref="0323.g1:D">$D$</span> according to the units in <span data-ref="0323.g1:A">$A$</span>.

![Proposition 17 Diagram](0323.g1.svg)

But the unit <span data-ref="0323.g1:F">$F$</span> also measures the number <span data-ref="0323.g1:A">$A$</span> according to the units in it;

therefore the unit <span data-ref="0323.g1:F">$F$</span> measures the number <span data-ref="0323.g1:A">$A$</span> the same number of times that <span data-ref="0323.g1:B">$B$</span> measures <span data-ref="0323.g1:D">$D$</span>.

Therefore, as the unit <span data-ref="0323.g1:F">$F$</span> is to the number <span data-ref="0323.g1:A">$A$</span>, so is <span data-ref="0323.g1:B">$B$</span> to <span data-ref="0323.g1:D">$D$</span>. [VII. Def. 20]

For the same reason,

<p align="center">as the unit <span data-ref="0323.g1:F">$F$</span> is to the number <span data-ref="0323.g1:A">$A$</span>, so also is <span data-ref="0323.g1:C">$C$</span> to <span data-ref="0323.g1:E">$E$</span>;</p>

therefore also, as <span data-ref="0323.g1:B">$B$</span> is to <span data-ref="0323.g1:D">$D$</span>, so is <span data-ref="0323.g1:C">$C$</span> to <span data-ref="0323.g1:E">$E$</span>.

Therefore, alternately, as <span data-ref="0323.g1:B">$B$</span> is to <span data-ref="0323.g1:C">$C$</span>, so is <span data-ref="0323.g1:D">$D$</span> to <span data-ref="0323.g1:E">$E$</span>. [VII. 13]

<p align="right">Q. E. D.</p>

<p align="center">$b : c = ab : ac$.</p>

In this case Euclid translates the language of measures into that of proportions, and the proof is exactly like that set out in the last note.

$$
\begin{aligned}
\text{By VII. Def. 20,} \quad & 1 : a = b : ab, \\
\text{and} \quad & 1 : a = c : ac. \\
\text{Therefore} \quad & b : ab = c : ac, \\
\text{and, alternately,} \quad & b : c = ab : ac. \quad \text{[VII. 13]}
\end{aligned}
$$
