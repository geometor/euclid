### PROPOSITION 18.

*If two numbers by multiplying any number make certain numbers, the numbers so produced will have the same ratio as the multipliers.*

For let two numbers <span data-ref="0324.g1:A">$A$</span>, <span data-ref="0324.g1:B">$B$</span> by multiplying any number <span data-ref="0324.g1:C">$C$</span> make <span data-ref="0324.g1:D">$D$</span>, <span data-ref="0324.g1:E">$E$</span>;
I say that, as <span data-ref="0324.g1:A">$A$</span> is to <span data-ref="0324.g1:B">$B$</span>, so is <span data-ref="0324.g1:D">$D$</span> to <span data-ref="0324.g1:E">$E$</span>.

![Book VII, Proposition 18](0324.g1.svg)

For, since <span data-ref="0324.g1:A">$A$</span> by multiplying <span data-ref="0324.g1:C">$C$</span> has made <span data-ref="0324.g1:D">$D$</span>,
therefore also <span data-ref="0324.g1:C">$C$</span> by multiplying <span data-ref="0324.g1:A">$A$</span> has made <span data-ref="0324.g1:D">$D$</span>. [VII. 16]
For the same reason also
<span data-ref="0324.g1:C">$C$</span> by multiplying <span data-ref="0324.g1:B">$B$</span> has made <span data-ref="0324.g1:E">$E$</span>.
Therefore the number <span data-ref="0324.g1:C">$C$</span> by multiplying the two numbers <span data-ref="0324.g1:A">$A$</span>, <span data-ref="0324.g1:B">$B$</span> has made <span data-ref="0324.g1:D">$D$</span>, <span data-ref="0324.g1:E">$E$</span>.
Therefore, as <span data-ref="0324.g1:A">$A$</span> is to <span data-ref="0324.g1:B">$B$</span>, so is <span data-ref="0324.g1:D">$D$</span> to <span data-ref="0324.g1:E">$E$</span>. [VII. 17]

---

It is here proved that
$$a : b = ac : bc.$$
The argument is as follows.
$$\begin{aligned}
ac &= ca. & \text{[VII. 16]} \\
\text{Similarly}\qquad bc &= cb. \\
\text{And}\qquad a : b &= ca : cb; & \text{[VII. 17]} \\
\text{therefore}\qquad a : b &= ac : bc.
\end{aligned}$$

### PROPOSITION 19.

*If four numbers be proportional, the number produced from the first and fourth will be equal to the number produced from the second and third; and, if the number produced from the first and fourth be equal to that produced from the second and third, the four numbers will be proportional.*

Let <span data-ref="0325.g1:A">$A$</span>, <span data-ref="0325.g1:B">$B$</span>, <span data-ref="0325.g1:C">$C$</span>, <span data-ref="0325.g1:D">$D$</span> be four numbers in proportion, so that,
as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:C">$C$</span> to <span data-ref="0325.g1:D">$D$</span>;
and let <span data-ref="0325.g1:A">$A$</span> by multiplying <span data-ref="0325.g1:D">$D$</span> make <span data-ref="0325.g1:E">$E$</span>, and let <span data-ref="0325.g1:B">$B$</span> by multiplying <span data-ref="0325.g1:C">$C$</span> make <span data-ref="0325.g1:F">$F$</span>;
I say that <span data-ref="0325.g1:E">$E$</span> is equal to <span data-ref="0325.g1:F">$F$</span>.
For let <span data-ref="0325.g1:A">$A$</span> by multiplying <span data-ref="0325.g1:C">$C$</span> make <span data-ref="0325.g1:G">$G$</span>.
