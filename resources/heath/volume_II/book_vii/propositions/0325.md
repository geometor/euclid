Since, then, <span data-ref="0325.g1:A">$A$</span> by multiplying <span data-ref="0325.g1:C">$C$</span> has made <span data-ref="0325.g1:G">$G$</span>, and by multiplying <span data-ref="0325.g1:D">$D$</span> has made <span data-ref="0325.g1:E">$E$</span>,
the number <span data-ref="0325.g1:A">$A$</span> by multiplying the two numbers <span data-ref="0325.g1:C">$C$</span>, <span data-ref="0325.g1:D">$D$</span> has made <span data-ref="0325.g1:G">$G$</span>, <span data-ref="0325.g1:E">$E$</span>.
Therefore, as <span data-ref="0325.g1:C">$C$</span> is to <span data-ref="0325.g1:D">$D$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:E">$E$</span>. [VII. 17]
But, as <span data-ref="0325.g1:C">$C$</span> is to <span data-ref="0325.g1:D">$D$</span>, so is <span data-ref="0325.g1:A">$A$</span> to <span data-ref="0325.g1:B">$B$</span>;
therefore also, as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:E">$E$</span>.

![Book VII, Proposition 19](0325.g1.svg)

Again, since <span data-ref="0325.g1:A">$A$</span> by multiplying <span data-ref="0325.g1:C">$C$</span> has made <span data-ref="0325.g1:G">$G$</span>,
but, further, <span data-ref="0325.g1:B">$B$</span> has also by multiplying <span data-ref="0325.g1:C">$C$</span> made <span data-ref="0325.g1:F">$F$</span>,
the two numbers <span data-ref="0325.g1:A">$A$</span>, <span data-ref="0325.g1:B">$B$</span> by multiplying a certain number <span data-ref="0325.g1:C">$C$</span> have made <span data-ref="0325.g1:G">$G$</span>, <span data-ref="0325.g1:F">$F$</span>.
Therefore, as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:F">$F$</span>. [VII. 18]
But further, as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:E">$E$</span> also;
therefore also, as <span data-ref="0325.g1:G">$G$</span> is to <span data-ref="0325.g1:E">$E$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:F">$F$</span>.
Therefore <span data-ref="0325.g1:G">$G$</span> has to each of the numbers <span data-ref="0325.g1:E">$E$</span>, <span data-ref="0325.g1:F">$F$</span> the same ratio;
therefore <span data-ref="0325.g1:E">$E$</span> is equal to <span data-ref="0325.g1:F">$F$</span>. [cf. V. 9]
Again, let <span data-ref="0325.g1:E">$E$</span> be equal to <span data-ref="0325.g1:F">$F$</span>;
I say that, as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:C">$C$</span> to <span data-ref="0325.g1:D">$D$</span>.
For, with the same construction,
since <span data-ref="0325.g1:E">$E$</span> is equal to <span data-ref="0325.g1:F">$F$</span>,
therefore, as <span data-ref="0325.g1:G">$G$</span> is to <span data-ref="0325.g1:E">$E$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:F">$F$</span>. [cf. V. 7]
But, as <span data-ref="0325.g1:G">$G$</span> is to <span data-ref="0325.g1:E">$E$</span>, so is <span data-ref="0325.g1:C">$C$</span> to <span data-ref="0325.g1:D">$D$</span>, [VII. 17]
and, as <span data-ref="0325.g1:G">$G$</span> is to <span data-ref="0325.g1:F">$F$</span>, so is <span data-ref="0325.g1:A">$A$</span> to <span data-ref="0325.g1:B">$B$</span>. [VII. 18]
Therefore also, as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:C">$C$</span> to <span data-ref="0325.g1:D">$D$</span>.

Q. E. D.

If
$$a : b = c : d,$$
then
$$ad = bc; \text{ and conversely.}$$

The proof is equivalent to the following.

(1)
$$\begin{aligned}
ac : ad &= c : d & \text{[VII. 17]} \\
&= a : b. \\
\text{But}\qquad a : b &= ac : bc. & \text{[VII. 18]} \\
\text{Therefore}\qquad ac : ad &= ac : bc, \\
\text{or}\qquad ad &= bc.
\end{aligned}$$
