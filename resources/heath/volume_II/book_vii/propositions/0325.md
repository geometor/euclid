<p class="sub-clause">Since, then, <span data-ref="0325.g1:A">$A$</span> by multiplying <span data-ref="0325.g1:C">$C$</span> has made <span data-ref="0325.g1:G">$G$</span>, and by<br />
multiplying <span data-ref="0325.g1:D">$D$</span> has made <span data-ref="0325.g1:E">$E$</span>,<br />
the number <span data-ref="0325.g1:A">$A$</span> by multiplying the two<br />
numbers <span data-ref="0325.g1:C">$C$</span>, <span data-ref="0325.g1:D">$D$</span> has made <span data-ref="0325.g1:G">$G$</span>, <span data-ref="0325.g1:E">$E$</span>.</p>

<p class="assertion">Therefore, as <span data-ref="0325.g1:C">$C$</span> is to <span data-ref="0325.g1:D">$D$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:E">$E$</span>. <span class="justification">[VII. 17]</span></p>

<p class="sub-clause">But, as <span data-ref="0325.g1:C">$C$</span> is to <span data-ref="0325.g1:D">$D$</span>, so is <span data-ref="0325.g1:A">$A$</span> to <span data-ref="0325.g1:B">$B$</span>;</p>
<p class="assertion">therefore also, as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:G">$G$</span><br />
to <span data-ref="0325.g1:E">$E$</span>.</p>

![Book VII, Proposition 19](0325.g1.svg)

<p class="sub-clause">Again, since <span data-ref="0325.g1:A">$A$</span> by multiplying <span data-ref="0325.g1:C">$C$</span><br />
has made <span data-ref="0325.g1:G">$G$</span>,<br />
but, further, <span data-ref="0325.g1:B">$B$</span> has also by multiplying<br />
<span data-ref="0325.g1:C">$C$</span> made <span data-ref="0325.g1:F">$F$</span>,<br />
the two numbers <span data-ref="0325.g1:A">$A$</span>, <span data-ref="0325.g1:B">$B$</span> by multiplying a certain number <span data-ref="0325.g1:C">$C$</span><br />
have made <span data-ref="0325.g1:G">$G$</span>, <span data-ref="0325.g1:F">$F$</span>.</p>

<p class="assertion">Therefore, as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:F">$F$</span>. <span class="justification">[VII. 18]</span></p>

<p class="sub-clause">But further, as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:E">$E$</span> also;</p>
<p class="assertion">therefore also, as <span data-ref="0325.g1:G">$G$</span> is to <span data-ref="0325.g1:E">$E$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:F">$F$</span>.</p>

<p class="assertion">Therefore <span data-ref="0325.g1:G">$G$</span> has to each of the numbers <span data-ref="0325.g1:E">$E$</span>, <span data-ref="0325.g1:F">$F$</span> the same<br />
ratio;</p>
<p class="assertion">therefore <span data-ref="0325.g1:E">$E$</span> is equal to <span data-ref="0325.g1:F">$F$</span>. <span class="justification">[cf. V. 9]</span></p>

Again, let <span data-ref="0325.g1:E">$E$</span> be equal to <span data-ref="0325.g1:F">$F$</span>;

I say that, as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:C">$C$</span> to <span data-ref="0325.g1:D">$D$</span>.

For, with the same construction,
<p class="sub-clause">since <span data-ref="0325.g1:E">$E$</span> is equal to <span data-ref="0325.g1:F">$F$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0325.g1:G">$G$</span> is to <span data-ref="0325.g1:E">$E$</span>, so is <span data-ref="0325.g1:G">$G$</span> to <span data-ref="0325.g1:F">$F$</span>. <span class="justification">[cf. V. 7]</span></p>

<p class="sub-clause">But, as <span data-ref="0325.g1:G">$G$</span> is to <span data-ref="0325.g1:E">$E$</span>, so is <span data-ref="0325.g1:C">$C$</span> to <span data-ref="0325.g1:D">$D$</span>, <span class="justification">[VII. 17]</span><br />
and, as <span data-ref="0325.g1:G">$G$</span> is to <span data-ref="0325.g1:F">$F$</span>, so is <span data-ref="0325.g1:A">$A$</span> to <span data-ref="0325.g1:B">$B$</span>. <span class="justification">[VII. 18]</span></p>

<p class="assertion">Therefore also, as <span data-ref="0325.g1:A">$A$</span> is to <span data-ref="0325.g1:B">$B$</span>, so is <span data-ref="0325.g1:C">$C$</span> to <span data-ref="0325.g1:D">$D$</span>.</p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>

If
$$a : b = c : d,$$
then
$$ad = bc; \text{ and conversely.}$$

The proof is equivalent to the following.

(1)
$$\begin{aligned}
ac : ad &= c : d & \text{[VII. 17]} \\
&= a : b. \\
\text{But}\qquad a : b &= ac : bc. & \text{[VII. 18]} \\
\text{Therefore}\qquad ac : ad &= ac : bc, \\
\text{or}\qquad ad &= bc.
\end{aligned}$$
