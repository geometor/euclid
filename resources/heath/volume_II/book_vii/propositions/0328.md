### PROPOSITION 21.

<p class="enunciation">Numbers prime to one another are the least of those which<br />
have the same ratio with them.</p>

Let <span data-ref="0328.g1:A">$A$</span>, <span data-ref="0328.g1:B">$B$</span> be numbers prime to one another;

I say that <span data-ref="0328.g1:A">$A$</span>, <span data-ref="0328.g1:B">$B$</span> are the least of<br />
those which have the same ratio<br />
with them.

![Book VII, Proposition 21](0328.g1.svg)

<p class="sub-clause">For, if not, there will be some<br />
numbers less than <span data-ref="0328.g1:A">$A$</span>, <span data-ref="0328.g1:B">$B$</span> which are<br />
in the same ratio with <span data-ref="0328.g1:A">$A$</span>, <span data-ref="0328.g1:B">$B$</span>.</p>

Let them be <span data-ref="0328.g1:C">$C$</span>, <span data-ref="0328.g1:D">$D$</span>.

<p class="sub-clause">Since, then, the least numbers of those which have the<br />
same ratio measure those which have the same ratio the<br />
same number of times, the greater the greater and the less<br />
the less, that is, the antecedent the antecedent and the<br />
consequent the consequent, <span class="justification">[VII. 20]</span></p>

<p class="assertion">therefore <span data-ref="0328.g1:C">$C$</span> measures <span data-ref="0328.g1:A">$A$</span> the same number of times that <span data-ref="0328.g1:D">$D$</span><br />
measures <span data-ref="0328.g1:B">$B$</span>.</p>

Now, as many times as <span data-ref="0328.g1:C">$C$</span> measures <span data-ref="0328.g1:A">$A$</span>, so many units let<br />
there be in <span data-ref="0328.g1:E">$E$</span>.

<p class="assertion">Therefore <span data-ref="0328.g1:D">$D$</span> also measures <span data-ref="0328.g1:B">$B$</span> according to the units in <span data-ref="0328.g1:E">$E$</span>.</p>
