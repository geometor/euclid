Here also Heiberg omits a proposition which was no doubt interpolated by Theon (B, V, p, $\phi$ have it as VII. 22, but P only has it in the margin and in a later hand; Campanus also omits it) proving for numbers the *ex aequali* proposition when "the proportion is perturbed," i.e. (cf. enunciation of V. 22) if
$$\begin{aligned}
a : b &= e : f, \dots\dots\dots\dots\dots\dots\dots\dots\dots(1) \\
\text{and}\qquad b : c &= d : e, \dots\dots\dots\dots\dots\dots\dots\dots\dots(2) \\
\text{then}\qquad a : c &= d : f.
\end{aligned}$$
The proof (see Heiberg's Appendix) depends on VII. 19.
From (1) we have
$$af = be,$$
and from (2)
$$be = cd. \qquad \text{[VII. 19]}$$
Therefore
$$af = cd,$$
and accordingly
$$a : c = d : f. \qquad \text{[VII. 19]}$$

### PROPOSITION 21.

*Numbers prime to one another are the least of those which have the same ratio with them.*

Let <span data-ref="0328.g1:A">$A$</span>, <span data-ref="0328.g1:B">$B$</span> be numbers prime to one another;
I say that <span data-ref="0328.g1:A">$A$</span>, <span data-ref="0328.g1:B">$B$</span> are the least of those which have the same ratio with them.

![Book VII, Proposition 21](0328.g1.svg)

For, if not, there will be some numbers less than <span data-ref="0328.g1:A">$A$</span>, <span data-ref="0328.g1:B">$B$</span> which are in the same ratio with <span data-ref="0328.g1:A">$A$</span>, <span data-ref="0328.g1:B">$B$</span>.
Let them be <span data-ref="0328.g1:C">$C$</span>, <span data-ref="0328.g1:D">$D$</span>.
Since, then, the least numbers of those which have the same ratio measure those which have the same ratio the same number of times, the greater the greater and the less the less, that is, the antecedent the antecedent and the consequent the consequent, [VII. 20]
therefore <span data-ref="0328.g1:C">$C$</span> measures <span data-ref="0328.g1:A">$A$</span> the same number of times that <span data-ref="0328.g1:D">$D$</span> measures <span data-ref="0328.g1:B">$B$</span>.
Now, as many times as <span data-ref="0328.g1:C">$C$</span> measures <span data-ref="0328.g1:A">$A$</span>, so many units let there be in <span data-ref="0328.g1:E">$E$</span>.
Therefore <span data-ref="0328.g1:D">$D$</span> also measures <span data-ref="0328.g1:B">$B$</span> according to the units in <span data-ref="0328.g1:E">$E$</span>.
