Euclid's proof amounts to this.

Since $a$, $b$ are prime to one another, so are $a^2$, $b$ [VII. 25], and therefore also $a^2$, $b^2$. [VII. 25]

Similarly [VII. 25] $a$, $b^2$ are prime to one another.

Therefore $a$, $a^2$ and $b$, $b^2$ satisfy the description in the enunciation of VII. 26.

Hence $a^3$, $b^3$ are prime to one another.

### Proposition 28.

*If two numbers be prime to one another, the sum will also be prime to each of them; and, if the sum of two numbers be prime to any one of them, the original numbers will also be prime to one another.*

![Book VII, Proposition 28](0335.g1.svg)

For let two numbers <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span> prime to one another be added;
I say that the sum <span data-ref="0335.g1:/ A C /">$AC$</span> is also prime to each of the numbers <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span>.

For, if <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span> are not prime to one another, some number will measure <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span>.

Let a number measure them, and let it be <span data-ref="0335.g1:D">$D$</span>.

Since then <span data-ref="0335.g1:D">$D$</span> measures <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span>, therefore it will also measure the remainder <span data-ref="0335.g1:/ B C /">$BC$</span>.

But it also measures <span data-ref="0335.g1:/ A B /">$BA$</span>; therefore <span data-ref="0335.g1:D">$D$</span> measures <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span> which are prime to one another: which is impossible. [VII. Def. 12]

Therefore no number will measure the numbers <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span>; therefore <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span> are prime to one another.

For the same reason
<span data-ref="0335.g1:/ A C /">$AC$</span>, <span data-ref="0335.g1:/ B C /">$CB$</span> are also prime to one another.

Therefore <span data-ref="0335.g1:/ A C /">$CA$</span> is prime to each of the numbers <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span>.

Again, let <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span> be prime to one another;
I say that <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span> are also prime to one another.

For, if <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span> are not prime to one another, some number will measure <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span>.
