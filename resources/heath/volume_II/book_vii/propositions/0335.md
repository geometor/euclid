### PROPOSITION 28.

<p class="enunciation">If two numbers be prime to one another, the sum will also<br />
be prime to each of them ; and, if the sum of two numbers be<br />
prime to any one of them, the original numbers will also be<br />
prime to one another.</p>

For let two numbers <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span> prime to one another be<br />
added ;<br />
I say that the sum <span data-ref="0335.g1:/ A C /">$AC$</span> is also prime<br />
to each of the numbers <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span>.

![Book VII, Proposition 28](0335.g1.svg)

<p class="sub-clause">For, if <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span> are not prime to<br />
one another,<br />
some number will measure <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span>.</p>

Let a number measure them, and let it be <span data-ref="0335.g1:D">$D$</span>.

<p class="sub-clause">Since then <span data-ref="0335.g1:D">$D$</span> measures <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span>,</p>
<p class="assertion">therefore it will also measure the remainder <span data-ref="0335.g1:/ B C /">$BC$</span>.</p>

<p class="sub-clause">But it also measures <span data-ref="0335.g1:/ A B /">$BA$</span> ;</p>
<p class="assertion">therefore <span data-ref="0335.g1:D">$D$</span> measures <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span> which are prime to one another :<br />
which is impossible. <span class="justification">[VII. Def. 12]</span></p>

<p class="assertion">Therefore no number will measure the numbers <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span> ;<br />
therefore <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span> are prime to one another.</p>

<p class="sub-clause">For the same reason</p>
<p class="assertion"><span data-ref="0335.g1:/ A C /">$AC$</span>, <span data-ref="0335.g1:/ B C /">$CB$</span> are also prime to one another.</p>

<p class="assertion">Therefore <span data-ref="0335.g1:/ A C /">$CA$</span> is prime to each of the numbers <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span>.</p>

Again, let <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span> be prime to one another ;<br />
I say that <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span> are also prime to one another.

<p class="sub-clause">For, if <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span> are not prime to one another,<br />
some number will measure <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span>.</p>
