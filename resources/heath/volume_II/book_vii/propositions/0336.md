Let a number measure them, and let it be <span data-ref="0335.g1:D">$D$</span>.

<p class="sub-clause">Now, since <span data-ref="0335.g1:D">$D$</span> measures each of the numbers <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span>,</p>
<p class="assertion">it will also measure the whole <span data-ref="0335.g1:/ A C /">$CA$</span>.</p>

<p class="sub-clause">But it also measures <span data-ref="0335.g1:/ A B /">$AB$</span> ;</p>
<p class="assertion">therefore <span data-ref="0335.g1:D">$D$</span> measures <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span> which are prime to one another :<br />
which is impossible. <span class="justification">[VII. Def. 12]</span></p>

<p class="assertion">Therefore no number will measure the numbers <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span>.</p>

<p class="assertion">Therefore <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span> are prime to one another.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

If $a$, $b$ are prime to one another, $a + b$ will be prime to both $a$ and $b$ ; and<br />
conversely.

For suppose $(a + b)$, $a$ are not prime to one another. They must then<br />
have some common measure $d$.

Therefore $d$ also divides the difference $(a + b) - a$, or $b$, as well as $a$ ; and<br />
therefore $a$, $b$ are not prime to one another : which is contrary to the<br />
hypothesis.

$$\text{Therefore } a + b \text{ is prime to } a.$$
$$\text{Similarly } a + b \text{ is prime to } b.$$

The converse is proved in the same way.

Heiberg remarks on Euclid's assumption that, if $c$ measures both $a$ and $b$,<br />
it also measures $a \pm b$. But it has already (VII. 1, 2) been assumed, more<br />
generally, as an axiom that, in the case supposed, $c$ measures $a \pm pb$.

### PROPOSITION 29.

<p class="enunciation">Any prime number is prime to any number which it does<br />
not measure.</p>

Let <span data-ref="0336.g1:A">$A$</span> be a prime number, and let it not measure <span data-ref="0336.g1:B">$B$</span>;<br />
I say that <span data-ref="0336.g1:B">$B$</span>, <span data-ref="0336.g1:A">$A$</span> are prime to one another.

![Book VII, Proposition 29](0336.g1.svg)

<p class="sub-clause">For, if <span data-ref="0336.g1:B">$B$</span>, <span data-ref="0336.g1:A">$A$</span> are not prime to one<br />
another,<br />
some number will measure them.</p>

Let <span data-ref="0336.g1:C">$C$</span> measure them.

<p class="sub-clause">Since <span data-ref="0336.g1:C">$C$</span> measures <span data-ref="0336.g1:B">$B$</span>,<br />
and <span data-ref="0336.g1:A">$A$</span> does not measure <span data-ref="0336.g1:B">$B$</span>,</p>
<p class="assertion">therefore <span data-ref="0336.g1:C">$C$</span> is not the same with <span data-ref="0336.g1:A">$A$</span>.</p>

<p class="sub-clause">Now, since <span data-ref="0336.g1:C">$C$</span> measures <span data-ref="0336.g1:B">$B$</span>, <span data-ref="0336.g1:A">$A$</span>,</p>
<p class="assertion">therefore it also measures <span data-ref="0336.g1:A">$A$</span> which is prime, though it is not<br />
the same with it :<br />
which is impossible.</p>
