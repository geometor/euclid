Let a number measure them, and let it be <span data-ref="0335.g1:D">$D$</span>.

Now, since <span data-ref="0335.g1:D">$D$</span> measures each of the numbers <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span>, it will also measure the whole <span data-ref="0335.g1:/ A C /">$CA$</span>.

But it also measures <span data-ref="0335.g1:/ A B /">$AB$</span>; therefore <span data-ref="0335.g1:D">$D$</span> measures <span data-ref="0335.g1:/ A C /">$CA$</span>, <span data-ref="0335.g1:/ A B /">$AB$</span> which are prime to one another: which is impossible. [VII. Def. 12]

Therefore no number will measure the numbers <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span>.

Therefore <span data-ref="0335.g1:/ A B /">$AB$</span>, <span data-ref="0335.g1:/ B C /">$BC$</span> are prime to one another.

$$\text{Q. E. D.}$$

---

If $a$, $b$ are prime to one another, $a + b$ will be prime to both $a$ and $b$; and conversely.

For suppose $(a + b)$, $a$ are not prime to one another. They must then have some common measure $d$.

Therefore $d$ also divides the difference $(a + b) - a$, or $b$, as well as $a$; and therefore $a$, $b$ are not prime to one another: which is contrary to the hypothesis.

$$\text{Therefore } a + b \text{ is prime to } a.$$
$$\text{Similarly } a + b \text{ is prime to } b.$$

The converse is proved in the same way.

Heiberg remarks on Euclid's assumption that, if $c$ measures both $a$ and $b$, it also measures $a \pm b$. But it has already (VII. 1, 2) been assumed, more generally, as an axiom that, in the case supposed, $c$ measures $a \pm pb$.

### Proposition 29.

*Any prime number is prime to any number which it does not measure.*

![Book VII, Proposition 29](0336.g1.svg)

Let <span data-ref="0336.g1:A">$A$</span> be a prime number, and let it not measure <span data-ref="0336.g1:B">$B$</span>;
I say that <span data-ref="0336.g1:B">$B$</span>, <span data-ref="0336.g1:A">$A$</span> are prime to one another.

For, if <span data-ref="0336.g1:B">$B$</span>, <span data-ref="0336.g1:A">$A$</span> are not prime to one another, some number will measure them.

Let <span data-ref="0336.g1:C">$C$</span> measure them.

Since <span data-ref="0336.g1:C">$C$</span> measures <span data-ref="0336.g1:B">$B$</span>, and <span data-ref="0336.g1:A">$A$</span> does not measure <span data-ref="0336.g1:B">$B$</span>, therefore <span data-ref="0336.g1:C">$C$</span> is not the same with <span data-ref="0336.g1:A">$A$</span>.

Now, since <span data-ref="0336.g1:C">$C$</span> measures <span data-ref="0336.g1:B">$B$</span>, <span data-ref="0336.g1:A">$A$</span>, therefore it also measures <span data-ref="0336.g1:A">$A$</span> which is prime, though it is not the same with it: which is impossible.
