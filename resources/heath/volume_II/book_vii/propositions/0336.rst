Let a number measure them, and let it be :g:`$D$ <0335.g1:D>`.

.. subclause::

   Now, since :g:`$D$ <0335.g1:D>` measures each of the numbers :g:`$AB$ <0335.g1:/ A B />`, :g:`$BC$ <0335.g1:/ B C />`,

.. assertion::

   it will also measure the whole :g:`$CA$ <0335.g1:/ A C />`.

.. subclause::

   But it also measures :g:`$AB$ <0335.g1:/ A B />` ;

.. assertion::

   therefore :g:`$D$ <0335.g1:D>` measures :g:`$CA$ <0335.g1:/ A C />`, :g:`$AB$ <0335.g1:/ A B />` which are prime to one another : which is impossible. :just:`[VII. Def. 12] <VII.def.12>`

.. assertion::

   Therefore no number will measure the numbers :g:`$AB$ <0335.g1:/ A B />`, :g:`$BC$ <0335.g1:/ B C />`.

.. assertion::

   Therefore :g:`$AB$ <0335.g1:/ A B />`, :g:`$BC$ <0335.g1:/ B C />` are prime to one another.

.. qed::

   :just:`Q. E. D.`

----

If $a$, $b$ are prime to one another, $a + b$ will be prime to both $a$ and $b$ ; and conversely.

For suppose $(a + b)$, $a$ are not prime to one another. They must then have some common measure $d$.

Therefore $d$ also divides the difference $(a + b) - a$, or $b$, as well as $a$ ; and therefore $a$, $b$ are not prime to one another : which is contrary to the hypothesis.

$$\text{Therefore } a + b \text{ is prime to } a.$$

$$\text{Similarly } a + b \text{ is prime to } b.$$

The converse is proved in the same way.

:person:`Heiberg <heiberg>` remarks on Euclid's assumption that, if $c$ measures both $a$ and $b$, it also measures $a \pm b$. But it has already (VII. 1, 2) been assumed, more generally, as an axiom that, in the case supposed, $c$ measures $a \pm pb$.

PROPOSITION 29.
---------------

.. enunciation::

   Any prime number is prime to any number which it does not measure.

Let :g:`$A$ <0336.g1:A>` be a prime number, and let it not measure :g:`$B$ <0336.g1:B>`;

I say that :g:`$B$ <0336.g1:B>`, :g:`$A$ <0336.g1:A>` are prime to one another.

.. picture:: 0336.g1.svg
   :alt: Book VII, Proposition 29

.. subclause::

   For, if :g:`$B$ <0336.g1:B>`, :g:`$A$ <0336.g1:A>` are not prime to one another, some number will measure them.

Let :g:`$C$ <0336.g1:C>` measure them.

.. subclause::

   Since :g:`$C$ <0336.g1:C>` measures :g:`$B$ <0336.g1:B>`, and :g:`$A$ <0336.g1:A>` does not measure :g:`$B$ <0336.g1:B>`,

.. assertion::

   therefore :g:`$C$ <0336.g1:C>` is not the same with :g:`$A$ <0336.g1:A>`.

.. subclause::

   Now, since :g:`$C$ <0336.g1:C>` measures :g:`$B$ <0336.g1:B>`, :g:`$A$ <0336.g1:A>`,

.. assertion::

   therefore it also measures :g:`$A$ <0336.g1:A>` which is prime, though it is not the same with it : which is impossible.
