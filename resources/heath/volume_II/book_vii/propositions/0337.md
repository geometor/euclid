### Proposition 30.

*If two numbers by multiplying one another make some number, and any prime number measure the product, it will also measure one of the original numbers.*

![Book VII, Proposition 30](0337.g1.svg)

For let the two numbers <span data-ref="0337.g1:A">$A$</span>, <span data-ref="0337.g1:B">$B$</span> by multiplying one another make <span data-ref="0337.g1:C">$C$</span>, and let any prime number <span data-ref="0337.g1:D">$D$</span> measure <span data-ref="0337.g1:C">$C$</span>;
I say that <span data-ref="0337.g1:D">$D$</span> measures one of the numbers <span data-ref="0337.g1:A">$A$</span>, <span data-ref="0337.g1:B">$B$</span>.

For let it not measure <span data-ref="0337.g1:A">$A$</span>.

Now <span data-ref="0337.g1:D">$D$</span> is prime; therefore <span data-ref="0337.g1:A">$A$</span>, <span data-ref="0337.g1:D">$D$</span> are prime to one another. [VII. 29]

And, as many times as <span data-ref="0337.g1:D">$D$</span> measures <span data-ref="0337.g1:C">$C$</span>, so many units let there be in <span data-ref="0337.g1:E">$E$</span>.

Since then <span data-ref="0337.g1:D">$D$</span> measures <span data-ref="0337.g1:C">$C$</span> according to the units in <span data-ref="0337.g1:E">$E$</span>, therefore <span data-ref="0337.g1:D">$D$</span> by multiplying <span data-ref="0337.g1:E">$E$</span> has made <span data-ref="0337.g1:C">$C$</span>. [VII. Def. 15]

Further, <span data-ref="0337.g1:A">$A$</span> by multiplying <span data-ref="0337.g1:B">$B$</span> has also made <span data-ref="0337.g1:C">$C$</span>; therefore the product of <span data-ref="0337.g1:D">$D$</span>, <span data-ref="0337.g1:E">$E$</span> is equal to the product of <span data-ref="0337.g1:A">$A$</span>, <span data-ref="0337.g1:B">$B$</span>.

Therefore, as <span data-ref="0337.g1:D">$D$</span> is to <span data-ref="0337.g1:A">$A$</span>, so is <span data-ref="0337.g1:B">$B$</span> to <span data-ref="0337.g1:E">$E$</span>. [VII. 19]

But <span data-ref="0337.g1:D">$D$</span>, <span data-ref="0337.g1:A">$A$</span> are prime to one another, primes are also least, [VII. 21] and the least measure the numbers which have the same ratio the same number of times, the greater the greater and the less the less, that is, the antecedent the antecedent and the consequent the consequent; [VII. 20] therefore <span data-ref="0337.g1:D">$D$</span> measures <span data-ref="0337.g1:B">$B$</span>.

Similarly we can also show that, if <span data-ref="0337.g1:D">$D$</span> do not measure <span data-ref="0337.g1:B">$B$</span>, it will measure <span data-ref="0337.g1:A">$A$</span>.

Therefore <span data-ref="0337.g1:D">$D$</span> measures one of the numbers <span data-ref="0337.g1:A">$A$</span>, <span data-ref="0337.g1:B">$B$</span>.

$$\text{Q. E. D.}$$
