If $c$, a prime number, measure $ab$, $c$ will measure either $a$ or $b$.
Suppose $c$ does not measure $a$.
Therefore $c$, $a$ are prime to one another. [VII. 29]
Suppose
$$ab = mc.$$
Therefore
$$c : a = b : m. \quad \text{[VII. 19]}$$
Hence [VII. 20, 21] $c$ measures $b$.
Similarly, if $c$ does not measure $b$, it measures $a$.
Therefore it measures one or other of the two numbers $a$, $b$.

### PROPOSITION 31.

<p class="enunciation">Any composite number is measured by some prime number.</p>

Let <span data-ref="0338.g1:A">$A$</span> be a composite number;<br />
I say that <span data-ref="0338.g1:A">$A$</span> is measured by some prime number.

<p class="sub-clause">For, since <span data-ref="0338.g1:A">$A$</span> is composite,<br />
<sup>5</sup> some number will measure it.</p>

Let a number measure it, and let it<br />
be <span data-ref="0338.g1:B">$B$</span>.

![Proposition 31 diagram](0338.g1.svg)

<p class="sub-clause">Now, if <span data-ref="0338.g1:B">$B$</span> is prime, what was en-<br />
joined will have been done.</p>

<p class="sub-clause"><sup>10</sup> But if it is composite, some number will measure it.</p>

Let a number measure it, and let it be <span data-ref="0338.g1:C">$C$</span>.

<p class="sub-clause">Then, since <span data-ref="0338.g1:C">$C$</span> measures <span data-ref="0338.g1:B">$B$</span>,<br />
and <span data-ref="0338.g1:B">$B$</span> measures <span data-ref="0338.g1:A">$A$</span>,</p>
<p class="assertion">therefore <span data-ref="0338.g1:C">$C$</span> also measures <span data-ref="0338.g1:A">$A$</span>.</p>

<p class="sub-clause"><sup>15</sup> And, if <span data-ref="0338.g1:C">$C$</span> is prime, what was enjoined will have been<br />
done.</p>

<p class="sub-clause">But if it is composite, some number will measure it.</p>

<p class="assertion">Thus, if the investigation be continued in this way, some<br />
prime number will be found which will measure the number<br />
<sup>20</sup> before it, which will also measure <span data-ref="0338.g1:A">$A$</span>.</p>

<p class="sub-clause">For, if it is not found, an infinite series of numbers will<br />
measure the number <span data-ref="0338.g1:A">$A$</span>, each of which is less than the other:<br />
which is impossible in numbers.</p>

<p class="assertion">Therefore some prime number will be found which will<br />
<sup>25</sup> measure the one before it, which will also measure <span data-ref="0338.g1:A">$A$</span>.</p>

<p class="assertion">Therefore any composite number is measured by some<br />
prime number.</p>
