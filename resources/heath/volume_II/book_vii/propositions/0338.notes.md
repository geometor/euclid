## Textual, Lexical & Mathematical Observations
- **Heath's Commentary on VII. 30**: Summarizes Euclid's proof in modern algebraic notation using ratios: if $c \mid ab$ and $c \nmid a$, then $(c, a) = 1$ by VII. 29; setting $ab = mc$ gives $c : a = b : m$ by VII. 19; by VII. 20, 21, $c$ measures $b$.
- **Proposition 31 Enunciation**: "Any composite number is measured by some prime number."
- **Mathematical Structure**: Classic reduction / finite descent argument: if $A$ is composite, it has a factor $B$; if $B$ is composite, it has a factor $C$, etc. The process must terminate because an infinite descending sequence of positive integers is impossible ("which is impossible in numbers" — implicit well-ordering principle / axiom of Archimedes in discrete form).
