:title: Proposition 31

If $c$, a prime number, measure $ab$, $c$ will measure either $a$ or $b$.
Suppose $c$ does not measure $a$.
Therefore $c$, $a$ are prime to one another. [VII. 29]
Suppose

$$ab = mc.$$

Therefore

$$c : a = b : m. \quad \text{[VII. 19]}$$

Hence [VII. 20, 21] $c$ measures $b$.
Similarly, if $c$ does not measure $b$, it measures $a$.
Therefore it measures one or other of the two numbers $a$, $b$.

----

PROPOSITION 31.
~~~~~~~~~~~~~~~

.. enunciation::

   Any composite number is measured by some prime number.

| Let :g:`$A$ <0338.g1:A>` be a composite number;
| I say that :g:`$A$ <0338.g1:A>` is measured by some prime number.

.. subclause::

   | For, since :g:`$A$ <0338.g1:A>` is composite,
   | :line:`5` some number will measure it.

| Let a number measure it, and let it
| be :g:`$B$ <0338.g1:B>`.

.. picture:: 0338.g1.svg
   :alt: Proposition 31 diagram

.. subclause::

   | Now, if :g:`$B$ <0338.g1:B>` is prime, what was en-
   | joined will have been done.

.. subclause::

   :line:`10` But if it is composite, some number will measure it.

Let a number measure it, and let it be :g:`$C$ <0338.g1:C>`.

.. subclause::

   | Then, since :g:`$C$ <0338.g1:C>` measures :g:`$B$ <0338.g1:B>`,
   | and :g:`$B$ <0338.g1:B>` measures :g:`$A$ <0338.g1:A>`,

.. assertion::

   therefore :g:`$C$ <0338.g1:C>` also measures :g:`$A$ <0338.g1:A>`.

.. subclause::

   | :line:`15` And, if :g:`$C$ <0338.g1:C>` is prime, what was enjoined will have been
   | done.

.. subclause::

   But if it is composite, some number will measure it.

.. assertion::

   | Thus, if the investigation be continued in this way, some
   | prime number will be found which will measure the number
   | :line:`20` before it, which will also measure :g:`$A$ <0338.g1:A>`.

.. subclause::

   | For, if it is not found, an infinite series of numbers will
   | measure the number :g:`$A$ <0338.g1:A>`, each of which is less than the other:
   | which is impossible in numbers.

.. assertion::

   | Therefore some prime number will be found which will
   | :line:`25` measure the one before it, which will also measure :g:`$A$ <0338.g1:A>`.

.. assertion::

   | Therefore any composite number is measured by some
   | prime number.
