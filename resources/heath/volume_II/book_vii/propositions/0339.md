VII. 31—33] PROPOSITIONS 30—33 333

**8. if <span data-ref="0338.g1:B">$B$</span> is prime, what was enjoined will have been done,** *i.e.* the implied *problem* of finding a prime number which measures <span data-ref="0338.g1:A">$A$</span>.

**18. some prime number will be found which will measure.** In the Greek the sentence stops here, but it is necessary to add the words "the number before it, which will also measure <span data-ref="0338.g1:A">$A$</span>," which are found a few lines further down. It is possible that the words may have fallen out of P here by a simple mistake due to ὁμοιοτέλευτον (Heiberg).

Heiberg relegates to the Appendix an alternative proof of this proposition, to the following effect. Since <span data-ref="0338.g1:A">$A$</span> is composite, some number will measure it. Let <span data-ref="0338.g1:B">$B$</span> be the *least* such number. I say that <span data-ref="0338.g1:B">$B$</span> is prime. For, if not, <span data-ref="0338.g1:B">$B$</span> is composite, and some number will measure it, say <span data-ref="0338.g1:C">$C$</span>; so that <span data-ref="0338.g1:C">$C$</span> is less than <span data-ref="0338.g1:B">$B$</span>. But, since <span data-ref="0338.g1:C">$C$</span> measures <span data-ref="0338.g1:B">$B$</span>, and <span data-ref="0338.g1:B">$B$</span> measures <span data-ref="0338.g1:A">$A$</span>, <span data-ref="0338.g1:C">$C$</span> must measure <span data-ref="0338.g1:A">$A$</span>. And <span data-ref="0338.g1:C">$C$</span> is less than <span data-ref="0338.g1:B">$B$</span>: which is contrary to the hypothesis.

### PROPOSITION 32.

*Any number either is prime or is measured by some prime number.*

Let <span data-ref="0339.g1:A">$A$</span> be a number;
I say that <span data-ref="0339.g1:A">$A$</span> either is prime or is measured by some prime number.

If now <span data-ref="0339.g1:A">$A$</span> is prime, that which was enjoined will have been done.

![Proposition 32 diagram](0339.g1.svg)

But if it is composite, some prime number will measure it. [VII. 31]

Therefore any number either is prime or is measured by some prime number.

<p align="right">Q. E. D.</p>
