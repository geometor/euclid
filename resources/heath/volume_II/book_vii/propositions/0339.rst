.. [#f1] **if** :g:`B <0338.g1:B>` **is prime, what was enjoined will have been done**, *i.e.* the implied *problem* of finding a prime number which measures :g:`A <0338.g1:A>`.

.. [#f2] **some prime number will be found which will measure.** In the Greek the sentence stops here, but it is necessary to add the words "the number before it, which will also measure :g:`A <0338.g1:A>`," which are found a few lines further down. It is possible that the words may have fallen out of P here by a simple mistake due to ὁμοιοτέλευτον (:person:`Heiberg <heiberg>`).

:person:`Heiberg <heiberg>` relegates to the Appendix an alternative proof of this proposition, to the following effect. Since :g:`A <0338.g1:A>` is composite, some number will measure it. Let :g:`B <0338.g1:B>` be the *least* such number. I say that :g:`B <0338.g1:B>` is prime. For, if not, :g:`B <0338.g1:B>` is composite, and some number will measure it, say :g:`C <0338.g1:C>`; so that :g:`C <0338.g1:C>` is less than :g:`B <0338.g1:B>`. But, since :g:`C <0338.g1:C>` measures :g:`B <0338.g1:B>`, and :g:`B <0338.g1:B>` measures :g:`A <0338.g1:A>`, :g:`C <0338.g1:C>` must measure :g:`A <0338.g1:A>`. And :g:`C <0338.g1:C>` is less than :g:`B <0338.g1:B>`: which is contrary to the hypothesis.

PROPOSITION 32.
---------------

.. enunciation::

   Any number either is prime or is measured by some prime number.

Let :g:`A <0339.g1:A>` be a number;

I say that :g:`A <0339.g1:A>` either is prime or is measured by some prime number.

.. subclause::

   If now :g:`A <0339.g1:A>` is prime, that which was enjoined will have been done.

.. picture:: 0339.g1.svg
   :alt: Proposition 32 diagram

.. subclause:: [VII. 31] <VII.31>

   But if it is composite, some prime number will measure it.

.. assertion::

   Therefore any number either is prime or is measured by some prime number.

.. qed::

   :just:`Q. E. D.`

PROPOSITION 33.
---------------

.. enunciation::

   Given as many numbers as we please, to find the least of those which have the same ratio with them.

Let :g:`A <0339.g2:A>`, :g:`B <0339.g2:B>`, :g:`C <0339.g2:C>` be the given numbers, as many as we please;

thus it is required to find the least of those which have the same ratio with :g:`A <0339.g2:A>`, :g:`B <0339.g2:B>`, :g:`C <0339.g2:C>`.

.. subclause::

   :g:`A <0339.g2:A>`, :g:`B <0339.g2:B>`, :g:`C <0339.g2:C>` are either prime to one another or not.

.. subclause::

   Now, if :g:`A <0339.g2:A>`, :g:`B <0339.g2:B>`, :g:`C <0339.g2:C>` are prime to one another, they are the least of those which have the same ratio with them. :just:`[VII. 21] <VII.21>`

.. picture:: 0339.g2.svg
   :alt: Proposition 33 diagram

But, if not, let :g:`D <0339.g2:D>` the greatest common measure of :g:`A <0339.g2:A>`, :g:`B <0339.g2:B>`, :g:`C <0339.g2:C>` be taken, :just:`[VII. 3] <VII.3>`
