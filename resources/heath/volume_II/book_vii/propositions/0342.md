336 BOOK VII [VII. 34

### PROPOSITION 34.

*Given two numbers, to find the least number which they measure.*

Let <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> be the two given numbers;
thus it is required to find the least number which they measure.

Now <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> are either prime to one another or not.

First, let <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> be prime to one another, and let <span data-ref="0342.g1:A">$A$</span> by multiplying <span data-ref="0342.g1:B">$B$</span> make <span data-ref="0342.g1:C">$C$</span>;
therefore also <span data-ref="0342.g1:B">$B$</span> by multiplying <span data-ref="0342.g1:A">$A$</span> has made <span data-ref="0342.g1:C">$C$</span>. [VII. 16]

Therefore <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> measure <span data-ref="0342.g1:C">$C$</span>.

![Proposition 34 diagram](0342.g1.svg)

I say next that it is also the least number they measure.

For, if not, <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> will measure some number which is less than <span data-ref="0342.g1:C">$C$</span>.

Let them measure <span data-ref="0342.g1:D">$D$</span>.

Then, as many times as <span data-ref="0342.g1:A">$A$</span> measures <span data-ref="0342.g1:D">$D$</span>, so many units let there be in <span data-ref="0342.g1:E">$E$</span>,
and, as many times as <span data-ref="0342.g1:B">$B$</span> measures <span data-ref="0342.g1:D">$D$</span>, so many units let there be in <span data-ref="0342.g1:F">$F$</span>;
therefore <span data-ref="0342.g1:A">$A$</span> by multiplying <span data-ref="0342.g1:E">$E$</span> has made <span data-ref="0342.g1:D">$D$</span>,
and <span data-ref="0342.g1:B">$B$</span> by multiplying <span data-ref="0342.g1:F">$F$</span> has made <span data-ref="0342.g1:D">$D$</span>; [VII. Def. 15]
therefore the product of <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:E">$E$</span> is equal to the product of <span data-ref="0342.g1:B">$B$</span>, <span data-ref="0342.g1:F">$F$</span>.

Therefore, as <span data-ref="0342.g1:A">$A$</span> is to <span data-ref="0342.g1:B">$B$</span>, so is <span data-ref="0342.g1:F">$F$</span> to <span data-ref="0342.g1:E">$E$</span>. [VII. 19]

But <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> are prime,
primes are also least, [VII. 21]
and the least measure the numbers which have the same ratio the same number of times, the greater the greater and the less the less; [VII. 20]
therefore <span data-ref="0342.g1:B">$B$</span> measures <span data-ref="0342.g1:E">$E$</span>, as consequent consequent.

And, since <span data-ref="0342.g1:A">$A$</span> by multiplying <span data-ref="0342.g1:B">$B$</span>, <span data-ref="0342.g1:E">$E$</span> has made <span data-ref="0342.g1:C">$C$</span>, <span data-ref="0342.g1:D">$D$</span>,
therefore, as <span data-ref="0342.g1:B">$B$</span> is to <span data-ref="0342.g1:E">$E$</span>, so is <span data-ref="0342.g1:C">$C$</span> to <span data-ref="0342.g1:D">$D$</span>. [VII. 17]

But <span data-ref="0342.g1:B">$B$</span> measures <span data-ref="0342.g1:E">$E$</span>;
therefore <span data-ref="0342.g1:C">$C$</span> also measures <span data-ref="0342.g1:D">$D$</span>, the greater the less:
which is impossible.
