336 BOOK VII [VII. 34

### PROPOSITION 34.

<p class="enunciation">Given two numbers, to find the least number which they<br />
measure.</p>

Let <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> be the two given numbers;<br />
thus it is required to find the least number which they<br />
measure.

<p class="sub-clause">Now <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> are either prime to one<br />
another or not.</p>

First, let <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> be prime to one<br />
another, and let <span data-ref="0342.g1:A">$A$</span> by multiplying <span data-ref="0342.g1:B">$B$</span><br />
make <span data-ref="0342.g1:C">$C$</span>;

<p class="assertion">therefore also <span data-ref="0342.g1:B">$B$</span> by multiplying <span data-ref="0342.g1:A">$A$</span> has<br />
made <span data-ref="0342.g1:C">$C$</span>. <span class="justification">[VII. 16]</span></p>

<p class="assertion">Therefore <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> measure <span data-ref="0342.g1:C">$C$</span>.</p>

![Proposition 34 diagram](0342.g1.svg)

I say next that it is also the least number they measure.

<p class="sub-clause">For, if not, <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> will measure some number which is less<br />
than <span data-ref="0342.g1:C">$C$</span>.</p>

Let them measure <span data-ref="0342.g1:D">$D$</span>.

Then, as many times as <span data-ref="0342.g1:A">$A$</span> measures <span data-ref="0342.g1:D">$D$</span>, so many units let<br />
there be in <span data-ref="0342.g1:E">$E$</span>,<br />
and, as many times as <span data-ref="0342.g1:B">$B$</span> measures <span data-ref="0342.g1:D">$D$</span>, so many units let<br />
there be in <span data-ref="0342.g1:F">$F$</span>;

<p class="assertion">therefore <span data-ref="0342.g1:A">$A$</span> by multiplying <span data-ref="0342.g1:E">$E$</span> has made <span data-ref="0342.g1:D">$D$</span>,<br />
and <span data-ref="0342.g1:B">$B$</span> by multiplying <span data-ref="0342.g1:F">$F$</span> has made <span data-ref="0342.g1:D">$D$</span>; <span class="justification">[VII. Def. 15]</span></p>

<p class="assertion">therefore the product of <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:E">$E$</span> is equal to the product of <span data-ref="0342.g1:B">$B$</span>, <span data-ref="0342.g1:F">$F$</span>.</p>

<p class="assertion">Therefore, as <span data-ref="0342.g1:A">$A$</span> is to <span data-ref="0342.g1:B">$B$</span>, so is <span data-ref="0342.g1:F">$F$</span> to <span data-ref="0342.g1:E">$E$</span>. <span class="justification">[VII. 19]</span></p>

<p class="sub-clause">But <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> are prime,<br />
primes are also least, <span class="justification">[VII. 21]</span><br />
and the least measure the numbers which have the same ratio<br />
the same number of times, the greater the greater and the less<br />
the less; <span class="justification">[VII. 20]</span></p>

<p class="assertion">therefore <span data-ref="0342.g1:B">$B$</span> measures <span data-ref="0342.g1:E">$E$</span>, as consequent consequent.</p>

<p class="sub-clause">And, since <span data-ref="0342.g1:A">$A$</span> by multiplying <span data-ref="0342.g1:B">$B$</span>, <span data-ref="0342.g1:E">$E$</span> has made <span data-ref="0342.g1:C">$C$</span>, <span data-ref="0342.g1:D">$D$</span>,</p>

<p class="assertion">therefore, as <span data-ref="0342.g1:B">$B$</span> is to <span data-ref="0342.g1:E">$E$</span>, so is <span data-ref="0342.g1:C">$C$</span> to <span data-ref="0342.g1:D">$D$</span>. <span class="justification">[VII. 17]</span></p>

<p class="sub-clause">But <span data-ref="0342.g1:B">$B$</span> measures <span data-ref="0342.g1:E">$E$</span>;</p>

<p class="assertion">therefore <span data-ref="0342.g1:C">$C$</span> also measures <span data-ref="0342.g1:D">$D$</span>, the greater the less:<br />
which is impossible.</p>
