VII. 34] PROPOSITION 34 337

<p class="assertion">Therefore <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> do not measure any number less than <span data-ref="0342.g1:C">$C$</span>;<br />
therefore <span data-ref="0342.g1:C">$C$</span> is the least that is measured by <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span>.</p>

Next, let <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:B">$B$</span> not be prime to one another,<br />
and let <span data-ref="0343.g1:F">$F$</span>, <span data-ref="0343.g1:E">$E$</span>, the least numbers of those which have the same<br />
ratio with <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:B">$B$</span>, be taken; <span class="justification">[VII. 33]</span>

<p class="assertion">therefore the product of <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:E">$E$</span> is equal to the product of <span data-ref="0343.g1:B">$B$</span>, <span data-ref="0343.g1:F">$F$</span>.<br />
<span class="justification">[VII. 19]</span></p>

And let <span data-ref="0343.g1:A">$A$</span> by multiplying <span data-ref="0343.g1:E">$E$</span><br />
make <span data-ref="0343.g1:C">$C$</span>;

<p class="assertion">therefore also <span data-ref="0343.g1:B">$B$</span> by multiplying <span data-ref="0343.g1:F">$F$</span><br />
has made <span data-ref="0343.g1:C">$C$</span>;</p>

<p class="assertion">therefore <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:B">$B$</span> measure <span data-ref="0343.g1:C">$C$</span>.</p>

![Proposition 34 diagram](0343.g1.svg)

I say next that it is also the least<br />
number that they measure.

<p class="sub-clause">For, if not, <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:B">$B$</span> will measure some number which is less<br />
than <span data-ref="0343.g1:C">$C$</span>.</p>

Let them measure <span data-ref="0343.g1:D">$D$</span>.

And, as many times as <span data-ref="0343.g1:A">$A$</span> measures <span data-ref="0343.g1:D">$D$</span>, so many units let<br />
there be in <span data-ref="0343.g1:G">$G$</span>,<br />
and, as many times as <span data-ref="0343.g1:B">$B$</span> measures <span data-ref="0343.g1:D">$D$</span>, so many units let there<br />
be in <span data-ref="0343.g1:H">$H$</span>.

<p class="assertion">Therefore <span data-ref="0343.g1:A">$A$</span> by multiplying <span data-ref="0343.g1:G">$G$</span> has made <span data-ref="0343.g1:D">$D$</span>,<br />
and <span data-ref="0343.g1:B">$B$</span> by multiplying <span data-ref="0343.g1:H">$H$</span> has made <span data-ref="0343.g1:D">$D$</span>.</p>

<p class="assertion">Therefore the product of <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:G">$G$</span> is equal to the product of<br />
<span data-ref="0343.g1:B">$B$</span>, <span data-ref="0343.g1:H">$H$</span>;</p>

<p class="assertion">therefore, as <span data-ref="0343.g1:A">$A$</span> is to <span data-ref="0343.g1:B">$B$</span>, so is <span data-ref="0343.g1:H">$H$</span> to <span data-ref="0343.g1:G">$G$</span>. <span class="justification">[VII. 19]</span></p>

<p class="sub-clause">But, as <span data-ref="0343.g1:A">$A$</span> is to <span data-ref="0343.g1:B">$B$</span>, so is <span data-ref="0343.g1:F">$F$</span> to <span data-ref="0343.g1:E">$E$</span>.</p>

<p class="assertion">Therefore also, as <span data-ref="0343.g1:F">$F$</span> is to <span data-ref="0343.g1:E">$E$</span>, so is <span data-ref="0343.g1:H">$H$</span> to <span data-ref="0343.g1:G">$G$</span>.</p>

<p class="sub-clause">But <span data-ref="0343.g1:F">$F$</span>, <span data-ref="0343.g1:E">$E$</span> are least,<br />
and the least measure the numbers which have the same ratio<br />
the same number of times, the greater the greater and the<br />
less the less; <span class="justification">[VII. 20]</span></p>

<p class="assertion">therefore <span data-ref="0343.g1:E">$E$</span> measures <span data-ref="0343.g1:G">$G$</span>.</p>

<p class="sub-clause">And, since <span data-ref="0343.g1:A">$A$</span> by multiplying <span data-ref="0343.g1:E">$E$</span>, <span data-ref="0343.g1:G">$G$</span> has made <span data-ref="0343.g1:C">$C$</span>, <span data-ref="0343.g1:D">$D$</span>,</p>

<p class="assertion">therefore, as <span data-ref="0343.g1:E">$E$</span> is to <span data-ref="0343.g1:G">$G$</span>, so is <span data-ref="0343.g1:C">$C$</span> to <span data-ref="0343.g1:D">$D$</span>. <span class="justification">[VII. 17]</span></p>

<p class="sub-clause">But <span data-ref="0343.g1:E">$E$</span> measures <span data-ref="0343.g1:G">$G$</span>;</p>

<p class="assertion">therefore <span data-ref="0343.g1:C">$C$</span> also measures <span data-ref="0343.g1:D">$D$</span>, the greater the less:<br />
which is impossible.</p>
