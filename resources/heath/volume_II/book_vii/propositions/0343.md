VII. 34] PROPOSITION 34 337

Therefore <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span> do not measure any number less than <span data-ref="0342.g1:C">$C$</span>;
therefore <span data-ref="0342.g1:C">$C$</span> is the least that is measured by <span data-ref="0342.g1:A">$A$</span>, <span data-ref="0342.g1:B">$B$</span>.

Next, let <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:B">$B$</span> not be prime to one another,
and let <span data-ref="0343.g1:F">$F$</span>, <span data-ref="0343.g1:E">$E$</span>, the least numbers of those which have the same ratio with <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:B">$B$</span>, be taken; [VII. 33]
therefore the product of <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:E">$E$</span> is equal to the product of <span data-ref="0343.g1:B">$B$</span>, <span data-ref="0343.g1:F">$F$</span>. [VII. 19]

And let <span data-ref="0343.g1:A">$A$</span> by multiplying <span data-ref="0343.g1:E">$E$</span> make <span data-ref="0343.g1:C">$C$</span>;
therefore also <span data-ref="0343.g1:B">$B$</span> by multiplying <span data-ref="0343.g1:F">$F$</span> has made <span data-ref="0343.g1:C">$C$</span>;
therefore <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:B">$B$</span> measure <span data-ref="0343.g1:C">$C$</span>.

![Proposition 34 diagram](0343.g1.svg)

I say next that it is also the least number that they measure.

For, if not, <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:B">$B$</span> will measure some number which is less than <span data-ref="0343.g1:C">$C$</span>.

Let them measure <span data-ref="0343.g1:D">$D$</span>.

And, as many times as <span data-ref="0343.g1:A">$A$</span> measures <span data-ref="0343.g1:D">$D$</span>, so many units let there be in <span data-ref="0343.g1:G">$G$</span>,
and, as many times as <span data-ref="0343.g1:B">$B$</span> measures <span data-ref="0343.g1:D">$D$</span>, so many units let there be in <span data-ref="0343.g1:H">$H$</span>.

Therefore <span data-ref="0343.g1:A">$A$</span> by multiplying <span data-ref="0343.g1:G">$G$</span> has made <span data-ref="0343.g1:D">$D$</span>,
and <span data-ref="0343.g1:B">$B$</span> by multiplying <span data-ref="0343.g1:H">$H$</span> has made <span data-ref="0343.g1:D">$D$</span>.

Therefore the product of <span data-ref="0343.g1:A">$A$</span>, <span data-ref="0343.g1:G">$G$</span> is equal to the product of <span data-ref="0343.g1:B">$B$</span>, <span data-ref="0343.g1:H">$H$</span>;
therefore, as <span data-ref="0343.g1:A">$A$</span> is to <span data-ref="0343.g1:B">$B$</span>, so is <span data-ref="0343.g1:H">$H$</span> to <span data-ref="0343.g1:G">$G$</span>. [VII. 19]

But, as <span data-ref="0343.g1:A">$A$</span> is to <span data-ref="0343.g1:B">$B$</span>, so is <span data-ref="0343.g1:F">$F$</span> to <span data-ref="0343.g1:E">$E$</span>.

Therefore also, as <span data-ref="0343.g1:F">$F$</span> is to <span data-ref="0343.g1:E">$E$</span>, so is <span data-ref="0343.g1:H">$H$</span> to <span data-ref="0343.g1:G">$G$</span>.

But <span data-ref="0343.g1:F">$F$</span>, <span data-ref="0343.g1:E">$E$</span> are least,
and the least measure the numbers which have the same ratio the same number of times, the greater the greater and the less the less; [VII. 20]
therefore <span data-ref="0343.g1:E">$E$</span> measures <span data-ref="0343.g1:G">$G$</span>.

And, since <span data-ref="0343.g1:A">$A$</span> by multiplying <span data-ref="0343.g1:E">$E$</span>, <span data-ref="0343.g1:G">$G$</span> has made <span data-ref="0343.g1:C">$C$</span>, <span data-ref="0343.g1:D">$D$</span>,
therefore, as <span data-ref="0343.g1:E">$E$</span> is to <span data-ref="0343.g1:G">$G$</span>, so is <span data-ref="0343.g1:C">$C$</span> to <span data-ref="0343.g1:D">$D$</span>. [VII. 17]

But <span data-ref="0343.g1:E">$E$</span> measures <span data-ref="0343.g1:G">$G$</span>;
therefore <span data-ref="0343.g1:C">$C$</span> also measures <span data-ref="0343.g1:D">$D$</span>, the greater the less:
which is impossible.
