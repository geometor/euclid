### PROPOSITION 35.

*If two numbers measure any number, the least number measured by them will also measure the same.*

For let the two numbers <span data-ref="0345.g1:A">$A$</span>, <span data-ref="0345.g1:B">$B$</span> measure any number <span data-ref="0345.g1:/ C D /">$CD$</span>, and let <span data-ref="0345.g1:E">$E$</span> be the least that they measure;
I say that <span data-ref="0345.g1:E">$E$</span> also measures <span data-ref="0345.g1:/ C D /">$CD$</span>.

![Proposition 35](0345.g1.svg)

For, if <span data-ref="0345.g1:E">$E$</span> does not measure <span data-ref="0345.g1:/ C D /">$CD$</span>, let <span data-ref="0345.g1:E">$E$</span>, measuring <span data-ref="0345.g1:/ F D /">$DF$</span>, leave <span data-ref="0345.g1:/ C F /">$CF$</span> less than itself.

Now, since <span data-ref="0345.g1:A">$A$</span>, <span data-ref="0345.g1:B">$B$</span> measure <span data-ref="0345.g1:E">$E$</span>, and <span data-ref="0345.g1:E">$E$</span> measures <span data-ref="0345.g1:/ F D /">$DF$</span>, therefore <span data-ref="0345.g1:A">$A$</span>, <span data-ref="0345.g1:B">$B$</span> will also measure <span data-ref="0345.g1:/ F D /">$DF$</span>.

But they also measure the whole <span data-ref="0345.g1:/ C D /">$CD$</span>; therefore they will also measure the remainder <span data-ref="0345.g1:/ C F /">$CF$</span> which is less than <span data-ref="0345.g1:E">$E$</span>: which is impossible.

Therefore <span data-ref="0345.g1:E">$E$</span> cannot fail to measure <span data-ref="0345.g1:/ C D /">$CD$</span>; therefore it measures it.

Q. E. D.

---

The *least common multiple* of any two numbers must measure any other common multiple.

The proof is obvious, depending on the fact that, if any number divides $a$ and $b$, it also divides $a - pb$.
