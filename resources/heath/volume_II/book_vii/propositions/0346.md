But <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span> also measure <span data-ref="0345.g2:D">$D$</span>;
therefore <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>, <span data-ref="0345.g2:C">$C$</span> measure <span data-ref="0345.g2:D">$D$</span>.

I say next that it is also the least that they measure.

For, if not, <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>, <span data-ref="0345.g2:C">$C$</span> will measure some number which is less than <span data-ref="0345.g2:D">$D$</span>.

Let them measure <span data-ref="0345.g2:E">$E$</span>.

Since <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>, <span data-ref="0345.g2:C">$C$</span> measure <span data-ref="0345.g2:E">$E$</span>, therefore also <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span> measure <span data-ref="0345.g2:E">$E$</span>.

Therefore the least number measured by <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span> will also measure <span data-ref="0345.g2:E">$E$</span>. [VII. 35]

But <span data-ref="0345.g2:D">$D$</span> is the least number measured by <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>; therefore <span data-ref="0345.g2:D">$D$</span> will measure <span data-ref="0345.g2:E">$E$</span>, the greater the less: which is impossible.

Therefore <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>, <span data-ref="0345.g2:C">$C$</span> will not measure any number which is less than <span data-ref="0345.g2:D">$D$</span>; therefore <span data-ref="0345.g2:D">$D$</span> is the least that <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>, <span data-ref="0345.g2:C">$C$</span> measure.

Again, let <span data-ref="0346.g1:C">$C$</span> not measure <span data-ref="0346.g1:D">$D$</span>, and let <span data-ref="0346.g1:E">$E$</span>, the least number measured by <span data-ref="0346.g1:C">$C$</span>, <span data-ref="0346.g1:D">$D$</span>, be taken. [VII. 34]

Since <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span> measure <span data-ref="0346.g1:D">$D$</span>, and <span data-ref="0346.g1:D">$D$</span> measures <span data-ref="0346.g1:E">$E$</span>, therefore also <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span> measure <span data-ref="0346.g1:E">$E$</span>.

But <span data-ref="0346.g1:C">$C$</span> also measures <span data-ref="0346.g1:E">$E$</span>; therefore also <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span>, <span data-ref="0346.g1:C">$C$</span> measure <span data-ref="0346.g1:E">$E$</span>.

I say next that it is also the least that they measure.

For, if not, <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span>, <span data-ref="0346.g1:C">$C$</span> will measure some number which is less than <span data-ref="0346.g1:E">$E$</span>.

Let them measure <span data-ref="0346.g1:F">$F$</span>.

Since <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span>, <span data-ref="0346.g1:C">$C$</span> measure <span data-ref="0346.g1:F">$F$</span>, therefore also <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span> measure <span data-ref="0346.g1:F">$F$</span>; therefore the least number measured by <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span> will also measure <span data-ref="0346.g1:F">$F$</span>. [VII. 35]

But <span data-ref="0346.g1:D">$D$</span> is the least number measured by <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span>; therefore <span data-ref="0346.g1:D">$D$</span> measures <span data-ref="0346.g1:F">$F$</span>.

But <span data-ref="0346.g1:C">$C$</span> also measures <span data-ref="0346.g1:F">$F$</span>; therefore <span data-ref="0346.g1:D">$D$</span>, <span data-ref="0346.g1:C">$C$</span> measure <span data-ref="0346.g1:F">$F$</span>, so that the least number measured by <span data-ref="0346.g1:D">$D$</span>, <span data-ref="0346.g1:C">$C$</span> will also measure <span data-ref="0346.g1:F">$F$</span>.
