<p class="sub-clause">But <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span> also measure <span data-ref="0345.g2:D">$D$</span>;</p>
<p class="assertion">therefore <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>, <span data-ref="0345.g2:C">$C$</span> measure <span data-ref="0345.g2:D">$D$</span>.</p>

I say next that it is also the least that they measure.

For, if not, <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>, <span data-ref="0345.g2:C">$C$</span> will measure some number which is<br />
less than <span data-ref="0345.g2:D">$D$</span>.

Let them measure <span data-ref="0345.g2:E">$E$</span>.

<p class="sub-clause">Since <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>, <span data-ref="0345.g2:C">$C$</span> measure <span data-ref="0345.g2:E">$E$</span>,</p>
<p class="assertion">therefore also <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span> measure <span data-ref="0345.g2:E">$E$</span>.</p>

<p class="assertion">Therefore the least number measured by <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span> will also<br />
measure <span data-ref="0345.g2:E">$E$</span>. <span class="justification">[VII. 35]</span></p>

<p class="sub-clause">But <span data-ref="0345.g2:D">$D$</span> is the least number measured by <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>;</p>
<p class="assertion">therefore <span data-ref="0345.g2:D">$D$</span> will measure <span data-ref="0345.g2:E">$E$</span>, the greater the less:<br />
which is impossible.</p>

<p class="assertion">Therefore <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>, <span data-ref="0345.g2:C">$C$</span> will not measure any number which is<br />
less than <span data-ref="0345.g2:D">$D$</span>;</p>
<p class="assertion">therefore <span data-ref="0345.g2:D">$D$</span> is the least that <span data-ref="0345.g2:A">$A$</span>, <span data-ref="0345.g2:B">$B$</span>, <span data-ref="0345.g2:C">$C$</span> measure.</p>

Again, let <span data-ref="0346.g1:C">$C$</span> not measure <span data-ref="0346.g1:D">$D$</span>,<br />
and let <span data-ref="0346.g1:E">$E$</span>, the least number measured by<br />
<span data-ref="0346.g1:C">$C$</span>, <span data-ref="0346.g1:D">$D$</span>, be taken. <span class="justification">[VII. 34]</span>

![Proposition 36](0346.g1.svg)

<p class="sub-clause">Since <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span> measure <span data-ref="0346.g1:D">$D$</span>,<br />
and <span data-ref="0346.g1:D">$D$</span> measures <span data-ref="0346.g1:E">$E$</span>,</p>
<p class="assertion">therefore also <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span> measure <span data-ref="0346.g1:E">$E$</span>.</p>

<p class="sub-clause">But <span data-ref="0346.g1:C">$C$</span> also measures <span data-ref="0346.g1:E">$E$</span>;</p>
<p class="assertion">therefore also <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span>, <span data-ref="0346.g1:C">$C$</span> measure <span data-ref="0346.g1:E">$E$</span>.</p>

I say next that it is also the least that they measure.

For, if not, <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span>, <span data-ref="0346.g1:C">$C$</span> will measure some number which<br />
is less than <span data-ref="0346.g1:E">$E$</span>.

Let them measure <span data-ref="0346.g1:F">$F$</span>.

<p class="sub-clause">Since <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span>, <span data-ref="0346.g1:C">$C$</span> measure <span data-ref="0346.g1:F">$F$</span>,</p>
<p class="assertion">therefore also <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span> measure <span data-ref="0346.g1:F">$F$</span>;</p>
<p class="assertion">therefore the least number measured by <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span> will also<br />
measure <span data-ref="0346.g1:F">$F$</span>. <span class="justification">[VII. 35]</span></p>

<p class="sub-clause">But <span data-ref="0346.g1:D">$D$</span> is the least number measured by <span data-ref="0346.g1:A">$A$</span>, <span data-ref="0346.g1:B">$B$</span>;</p>
<p class="assertion">therefore <span data-ref="0346.g1:D">$D$</span> measures <span data-ref="0346.g1:F">$F$</span>.</p>

<p class="sub-clause">But <span data-ref="0346.g1:C">$C$</span> also measures <span data-ref="0346.g1:F">$F$</span>;</p>
<p class="assertion">therefore <span data-ref="0346.g1:D">$D$</span>, <span data-ref="0346.g1:C">$C$</span> measure <span data-ref="0346.g1:F">$F$</span>,<br />
so that the least number measured by <span data-ref="0346.g1:D">$D$</span>, <span data-ref="0346.g1:C">$C$</span> will also measure <span data-ref="0346.g1:F">$F$</span>.</p>
