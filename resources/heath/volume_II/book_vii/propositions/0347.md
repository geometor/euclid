Euclid's rule for finding the L.C.M. of *three numbers* $a, b, c$ is the rule with<br />
which we are familiar. The L.C.M. of $a, b$ is first found, say $d$, and then the<br />
L.C.M. of $d$ and $c$ is found.<br />
Euclid distinguishes the cases (1) in which $c$ measures $d$, (2) in which $c$<br />
does not measure $d$. We need only reproduce the proof of the general case<br />
(2). The method is that of *reductio ad absurdum*.<br />
Let $e$ be the L.C.M. of $d, c$.<br />
Since $a, b$ both measure $d$, and $d$ measures $e$,
<p align="center">$a, b$ both measure $e$.</p>
So does $c$.<br />
Therefore $e$ is *some* common multiple of $a, b, c$.<br />
If it is not the *least*, let $f$ be the L.C.M.<br />
Now $a, b$ both measure $f$;<br />
therefore $d$, their L.C.M., also measures $f$. <span class="justification">[VII. 35]</span><br />
Thus $d, c$ both measure $f$;<br />
therefore $e$, their L.C.M., measures $f$: <span class="justification">[VII. 35]</span><br />
which is impossible, since $f < e$.<br />
Therefore etc.<br />
The process can be continued *ad libitum*, so that we can find the L.C.M.,<br />
not only of three, but of as many numbers as we please.

### PROPOSITION 37.

<p class="enunciation">If a number be measured by any number, the number which<br />
is measured will have a part called by the same name as the<br />
measuring number.</p>

For let the number <span data-ref="0347.g1:A">$A$</span> be measured by any number <span data-ref="0347.g1:B">$B$</span>;<br />
I say that <span data-ref="0347.g1:A">$A$</span> has a part called by the same<br />
name as <span data-ref="0347.g1:B">$B$</span>.
