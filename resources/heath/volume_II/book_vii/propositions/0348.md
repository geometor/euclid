If $b$ measures $a$, then $\frac{1}{b}\text{th}$ of $a$ is a whole number.

Let $a = m \cdot b$.

Now $m = m \cdot 1$.

Thus $1, m, b, a$ satisfy the enunciation of VII. 15; therefore $m$ measures $a$ the same number of times that $1$ measures $b$.

But $1$ is $\frac{1}{b}\text{th}$ part of $b$; therefore $m$ is $\frac{1}{b}\text{th}$ part of $a$.

### PROPOSITION 38.

*If a number have any part whatever, it will be measured by a number called by the same name as the part.*

For let the number <span data-ref="0348.g1:A">$A$</span> have any part whatever, <span data-ref="0348.g1:B">$B$</span>, and let <span data-ref="0348.g1:C">$C$</span> be a number called by the same name as the part <span data-ref="0348.g1:B">$B$</span>; I say that <span data-ref="0348.g1:C">$C$</span> measures <span data-ref="0348.g1:A">$A$</span>.

![Proposition 38](0348.g1.svg)

For, since <span data-ref="0348.g1:B">$B$</span> is a part of <span data-ref="0348.g1:A">$A$</span> called by the same name as <span data-ref="0348.g1:C">$C$</span>, and the unit <span data-ref="0348.g1:D">$D$</span> is also a part of <span data-ref="0348.g1:C">$C$</span> called by the same name as it, therefore, whatever part the unit <span data-ref="0348.g1:D">$D$</span> is of the number <span data-ref="0348.g1:C">$C$</span>, the same part is <span data-ref="0348.g1:B">$B$</span> of <span data-ref="0348.g1:A">$A$</span> also; therefore the unit <span data-ref="0348.g1:D">$D$</span> measures the number <span data-ref="0348.g1:C">$C$</span> the same number of times that <span data-ref="0348.g1:B">$B$</span> measures <span data-ref="0348.g1:A">$A$</span>.
