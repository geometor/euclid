.. assertion::

   Therefore, alternately, the unit :g:`D <0347.g1:D>` measures the number :g:`B <0347.g1:B>` the same number of times as :g:`C <0347.g1:C>` measures :g:`A <0347.g1:A>`; :just:`[VII. 15] <VII.15>` therefore, whatever part the unit :g:`D <0347.g1:D>` is of the number :g:`B <0347.g1:B>`, the same part is :g:`C <0347.g1:C>` of :g:`A <0347.g1:A>` also.

.. subclause::

   But the unit :g:`D <0347.g1:D>` is a part of the number :g:`B <0347.g1:B>` called by the same name as it;

.. assertion::

   therefore :g:`C <0347.g1:C>` is also a part of :g:`A <0347.g1:A>` called by the same name as :g:`B <0347.g1:B>`, so that :g:`A <0347.g1:A>` has a part :g:`C <0347.g1:C>` which is called by the same name as :g:`B <0347.g1:B>`.

.. qed::

   :just:`Q. E. D.`

----

If $b$ measures $a$, then $\frac{1}{b}\text{th}$ of $a$ is a whole number.

Let $a = m \cdot b$.

Now $m = m \cdot 1$.

Thus $1, m, b, a$ satisfy the enunciation of VII. 15; therefore $m$ measures $a$ the same number of times that $1$ measures $b$.

But $1$ is $\frac{1}{b}\text{th}$ part of $b$; therefore $m$ is $\frac{1}{b}\text{th}$ part of $a$.

PROPOSITION 38.
---------------

.. enunciation::

   If a number have any part whatever, it will be measured by a number called by the same name as the part.

For let the number :g:`A <0348.g1:A>` have any part whatever, :g:`B <0348.g1:B>`, and let :g:`C <0348.g1:C>` be a number called by the same name as the part :g:`B <0348.g1:B>`;

I say that :g:`C <0348.g1:C>` measures :g:`A <0348.g1:A>`.

.. picture:: 0348.g1.svg
   :alt: Proposition 38

.. subclause::

   For, since :g:`B <0348.g1:B>` is a part of :g:`A <0348.g1:A>` called by the same name as :g:`C <0348.g1:C>`, and the unit :g:`D <0348.g1:D>` is also a part of :g:`C <0348.g1:C>` called by the same name as it,

.. assertion::

   therefore, whatever part the unit :g:`D <0348.g1:D>` is of the number :g:`C <0348.g1:C>`, the same part is :g:`B <0348.g1:B>` of :g:`A <0348.g1:A>` also;

.. assertion::

   therefore the unit :g:`D <0348.g1:D>` measures the number :g:`C <0348.g1:C>` the same number of times that :g:`B <0348.g1:B>` measures :g:`A <0348.g1:A>`.
