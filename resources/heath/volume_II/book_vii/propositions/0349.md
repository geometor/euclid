<p class="assertion">Therefore, alternately, the unit <span data-ref="0348.g1:D">$D$</span> measures the number <span data-ref="0348.g1:B">$B$</span><br />
the same number of times that <span data-ref="0348.g1:C">$C$</span> measures <span data-ref="0348.g1:A">$A$</span>. <span class="justification">[VII. 15]</span></p>

<p class="assertion">Therefore <span data-ref="0348.g1:C">$C$</span> measures <span data-ref="0348.g1:A">$A$</span>.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

This proposition is practically a restatement of the preceding proposition.<br />
It asserts that, if $b$ is $\frac{1}{m}\text{th}$ part of $a$,<br />
i.e., if
$$b = \frac{1}{m} a,$$
then
$$m\text{ measures }a.$$
We have
$$b = \frac{1}{m} a,$$
and
$$1 = \frac{1}{m} m.$$
Therefore $1, m, b, a$, satisfy the enunciation of VII. 15, and therefore $m$<br />
measures $a$ the same number of times as $1$ measures $b$, or
$$m = \frac{1}{b} a.$$
