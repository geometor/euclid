.. assertion::

   Therefore, alternately, the unit :g:`D <0348.g1:D>` measures the number :g:`B <0348.g1:B>` the same number of times that :g:`C <0348.g1:C>` measures :g:`A <0348.g1:A>`. :just:`[VII. 15] <VII.15>`

.. assertion::

   Therefore :g:`C <0348.g1:C>` measures :g:`A <0348.g1:A>`.

.. qed::

   :just:`Q. E. D.`

----

This proposition is practically a restatement of the preceding proposition. It asserts that, if $b$ is $\frac{1}{m}\text{th}$ part of $a$, i.e., if

$$b = \frac{1}{m} a,$$

then

$$m\text{ measures }a.$$

We have

$$b = \frac{1}{m} a,$$

and

$$1 = \frac{1}{m} m.$$

Therefore $1, m, b, a$, satisfy the enunciation of VII. 15, and therefore $m$ measures $a$ the same number of times as $1$ measures $b$, or

$$m = \frac{1}{b} a.$$

----

PROPOSITION 39.
---------------

.. enunciation::

   To find the number which is the least that will have given parts.

Let :g:`A <0349.g1:A>`, :g:`B <0349.g1:B>`, :g:`C <0349.g1:C>` be the given parts;

thus it is required to find the number which is the least that will have the parts :g:`A <0349.g1:A>`, :g:`B <0349.g1:B>`, :g:`C <0349.g1:C>`.

   :alt: Proposition 39
