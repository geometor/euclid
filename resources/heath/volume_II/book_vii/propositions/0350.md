For, if not, there will be some number less than <span data-ref="0349.g1:G">$G$</span> which<br />
will have the parts <span data-ref="0349.g1:A">$A$</span>, <span data-ref="0349.g1:B">$B$</span>, <span data-ref="0349.g1:C">$C$</span>.

Let it be <span data-ref="0349.g1:H">$H$</span>.

<p class="sub-clause">Since <span data-ref="0349.g1:H">$H$</span> has the parts <span data-ref="0349.g1:A">$A$</span>, <span data-ref="0349.g1:B">$B$</span>, <span data-ref="0349.g1:C">$C$</span>,</p>
<p class="assertion">therefore <span data-ref="0349.g1:H">$H$</span> will be measured by numbers called by the same<br />
name as the parts <span data-ref="0349.g1:A">$A$</span>, <span data-ref="0349.g1:B">$B$</span>, <span data-ref="0349.g1:C">$C$</span>. <span class="justification">[VII. 38]</span></p>

<p class="sub-clause">But <span data-ref="0349.g1:D">$D$</span>, <span data-ref="0349.g1:E">$E$</span>, <span data-ref="0349.g1:F">$F$</span> are numbers called by the same name as the<br />
parts <span data-ref="0349.g1:A">$A$</span>, <span data-ref="0349.g1:B">$B$</span>, <span data-ref="0349.g1:C">$C$</span>;</p>
<p class="assertion">therefore <span data-ref="0349.g1:H">$H$</span> is measured by <span data-ref="0349.g1:D">$D$</span>, <span data-ref="0349.g1:E">$E$</span>, <span data-ref="0349.g1:F">$F$</span>.</p>

<p class="assertion">And it is less than <span data-ref="0349.g1:G">$G$</span>: which is impossible.</p>

<p class="assertion">Therefore there will be no number less than <span data-ref="0349.g1:G">$G$</span> that will<br />
have the parts <span data-ref="0349.g1:A">$A$</span>, <span data-ref="0349.g1:B">$B$</span>, <span data-ref="0349.g1:C">$C$</span>.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

This again is practically a restatement in another form of the problem of<br />
finding the L.C.M.

To find a number which has $\frac{1}{a}\text{th}$, $\frac{1}{b}\text{th}$ and $\frac{1}{c}\text{th}$ parts.

Let $d$ be the L.C.M. of $a, b, c$.

Thus $d$ has $\frac{1}{a}\text{th}$, $\frac{1}{b}\text{th}$ and $\frac{1}{c}\text{th}$ parts. <span class="justification">[VII. 37]</span>

If it is not the least number which has, let the least such number be $e$.<br />
Then, since $e$ has those parts,<br />
$e$ is measured by $a, b, c$; and $e < d$:<br />
which is impossible.
