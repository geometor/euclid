For, if not, there will be some number less than <span data-ref="0349.g1:G">$G$</span> which will have the parts <span data-ref="0349.g1:A">$A$</span>, <span data-ref="0349.g1:B">$B$</span>, <span data-ref="0349.g1:C">$C$</span>.

Let it be <span data-ref="0349.g1:H">$H$</span>.

Since <span data-ref="0349.g1:H">$H$</span> has the parts <span data-ref="0349.g1:A">$A$</span>, <span data-ref="0349.g1:B">$B$</span>, <span data-ref="0349.g1:C">$C$</span>, therefore <span data-ref="0349.g1:H">$H$</span> will be measured by numbers called by the same name as the parts <span data-ref="0349.g1:A">$A$</span>, <span data-ref="0349.g1:B">$B$</span>, <span data-ref="0349.g1:C">$C$</span>. [VII. 38]

But <span data-ref="0349.g1:D">$D$</span>, <span data-ref="0349.g1:E">$E$</span>, <span data-ref="0349.g1:F">$F$</span> are numbers called by the same name as the parts <span data-ref="0349.g1:A">$A$</span>, <span data-ref="0349.g1:B">$B$</span>, <span data-ref="0349.g1:C">$C$</span>; therefore <span data-ref="0349.g1:H">$H$</span> is measured by <span data-ref="0349.g1:D">$D$</span>, <span data-ref="0349.g1:E">$E$</span>, <span data-ref="0349.g1:F">$F$</span>.

And it is less than <span data-ref="0349.g1:G">$G$</span>: which is impossible.

Therefore there will be no number less than <span data-ref="0349.g1:G">$G$</span> that will have the parts <span data-ref="0349.g1:A">$A$</span>, <span data-ref="0349.g1:B">$B$</span>, <span data-ref="0349.g1:C">$C$</span>.

Q. E. D.

---

This again is practically a restatement in another form of the problem of finding the L.C.M.

To find a number which has $\frac{1}{a}\text{th}$, $\frac{1}{b}\text{th}$ and $\frac{1}{c}\text{th}$ parts.

Let $d$ be the L.C.M. of $a, b, c$.

Thus $d$ has $\frac{1}{a}\text{th}$, $\frac{1}{b}\text{th}$ and $\frac{1}{c}\text{th}$ parts. [VII. 37]

If it is not the least number which has, let the least such number be $e$.

Then, since $e$ has those parts,
$e$ is measured by $a, b, c$; and $e < d$:
which is impossible.
