# BOOK VIII.

## PROPOSITION 1.

<p class="enunciation">If there be as many numbers as we please in continued<br />
proportion, and the extremes of them be prime to one another,<br />
the numbers are the least of those which have the same ratio<br />
with them.</p>

Let there be as many numbers as we please, <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:B">$B$</span>, <span data-ref="0351.g1:C">$C$</span>, <span data-ref="0351.g1:D">$D$</span>,<br />
in continued proportion,<br />
and let the extremes of them<br />
<span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:D">$D$</span> be prime to one another;

I say that <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:B">$B$</span>, <span data-ref="0351.g1:C">$C$</span>, <span data-ref="0351.g1:D">$D$</span> are the<br />
least of those which have the<br />
same ratio with them.

![Proposition 1 Diagram](0351.g1.svg)

For, if not, let <span data-ref="0351.g1:E">$E$</span>, <span data-ref="0351.g1:F">$F$</span>, <span data-ref="0351.g1:G">$G$</span>, <span data-ref="0351.g1:H">$H$</span> be less than <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:B">$B$</span>, <span data-ref="0351.g1:C">$C$</span>, <span data-ref="0351.g1:D">$D$</span>, and<br />
in the same ratio with them.

<p class="sub-clause">Now, since <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:B">$B$</span>, <span data-ref="0351.g1:C">$C$</span>, <span data-ref="0351.g1:D">$D$</span> are in the same ratio with <span data-ref="0351.g1:E">$E$</span>, <span data-ref="0351.g1:F">$F$</span>,<br />
<span data-ref="0351.g1:G">$G$</span>, <span data-ref="0351.g1:H">$H$</span>,<br />
and the multitude of the numbers <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:B">$B$</span>, <span data-ref="0351.g1:C">$C$</span>, <span data-ref="0351.g1:D">$D$</span> is equal to the<br />
multitude of the numbers <span data-ref="0351.g1:E">$E$</span>, <span data-ref="0351.g1:F">$F$</span>, <span data-ref="0351.g1:G">$G$</span>, <span data-ref="0351.g1:H">$H$</span>,</p>
<p class="assertion">therefore, *ex aequali*,<br />
as <span data-ref="0351.g1:A">$A$</span> is to <span data-ref="0351.g1:D">$D$</span>, so is <span data-ref="0351.g1:E">$E$</span> to <span data-ref="0351.g1:H">$H$</span>. <span class="justification">[VII. 14]</span></p>

<p class="sub-clause">But <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:D">$D$</span> are prime,<br />
primes are also least, <span class="justification">[VII. 21]</span><br />
and the least numbers measure those which have the same<br />
ratio the same number of times, the greater the greater and<br />
the less the less, that is, the antecedent the antecedent and<br />
the consequent the consequent. <span class="justification">[VII. 20]</span></p>
