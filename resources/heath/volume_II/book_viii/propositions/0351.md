# BOOK VIII.

## PROPOSITION 1.

*If there be as many numbers as we please in continued proportion, and the extremes of them be prime to one another, the numbers are the least of those which have the same ratio with them.*

Let there be as many numbers as we please, <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:B">$B$</span>, <span data-ref="0351.g1:C">$C$</span>, <span data-ref="0351.g1:D">$D$</span>, in continued proportion, and let the extremes of them <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:D">$D$</span> be prime to one another;  
I say that <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:B">$B$</span>, <span data-ref="0351.g1:C">$C$</span>, <span data-ref="0351.g1:D">$D$</span> are the least of those which have the same ratio with them.

![Proposition 1 Diagram](0351.g1.svg)

For, if not, let <span data-ref="0351.g1:E">$E$</span>, <span data-ref="0351.g1:F">$F$</span>, <span data-ref="0351.g1:G">$G$</span>, <span data-ref="0351.g1:H">$H$</span> be less than <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:B">$B$</span>, <span data-ref="0351.g1:C">$C$</span>, <span data-ref="0351.g1:D">$D$</span>, and in the same ratio with them.

Now, since <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:B">$B$</span>, <span data-ref="0351.g1:C">$C$</span>, <span data-ref="0351.g1:D">$D$</span> are in the same ratio with <span data-ref="0351.g1:E">$E$</span>, <span data-ref="0351.g1:F">$F$</span>, <span data-ref="0351.g1:G">$G$</span>, <span data-ref="0351.g1:H">$H$</span>, and the multitude of the numbers <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:B">$B$</span>, <span data-ref="0351.g1:C">$C$</span>, <span data-ref="0351.g1:D">$D$</span> is equal to the multitude of the numbers <span data-ref="0351.g1:E">$E$</span>, <span data-ref="0351.g1:F">$F$</span>, <span data-ref="0351.g1:G">$G$</span>, <span data-ref="0351.g1:H">$H$</span>,  
therefore, *ex aequali*,
<div style="text-align: center;">as <span data-ref="0351.g1:A">$A$</span> is to <span data-ref="0351.g1:D">$D$</span>, so is <span data-ref="0351.g1:E">$E$</span> to <span data-ref="0351.g1:H">$H$</span>.</div>
<div style="text-align: right;">[VII. 14]</div>

But <span data-ref="0351.g1:A">$A$</span>, <span data-ref="0351.g1:D">$D$</span> are prime, primes are also least,
<div style="text-align: right;">[VII. 21]</div>
and the least numbers measure those which have the same ratio the same number of times, the greater the greater and the less the less, that is, the antecedent the antecedent and the consequent the consequent.
<div style="text-align: right;">[VII. 20]</div>
