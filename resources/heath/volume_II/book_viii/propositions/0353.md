Now, since <span data-ref="0352.g1:A">$A$</span> by multiplying itself has made <span data-ref="0352.g1:C">$C$</span>, and by multiplying <span data-ref="0352.g1:B">$B$</span> has made <span data-ref="0352.g1:D">$D$</span>, therefore, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:C">$C$</span> to <span data-ref="0352.g1:D">$D$</span>.
<div style="text-align: right;">[VII. 17]</div>

Again, since <span data-ref="0352.g1:A">$A$</span> by multiplying <span data-ref="0352.g1:B">$B$</span> has made <span data-ref="0352.g1:D">$D$</span>, and <span data-ref="0352.g1:B">$B$</span> by multiplying itself has made <span data-ref="0352.g1:E">$E$</span>, therefore the numbers <span data-ref="0352.g1:A">$A$</span>, <span data-ref="0352.g1:B">$B$</span> by multiplying <span data-ref="0352.g1:B">$B$</span> have made the numbers <span data-ref="0352.g1:D">$D$</span>, <span data-ref="0352.g1:E">$E$</span> respectively.

Therefore, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:D">$D$</span> to <span data-ref="0352.g1:E">$E$</span>.
<div style="text-align: right;">[VII. 18]</div>

But, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:C">$C$</span> to <span data-ref="0352.g1:D">$D$</span>;  
therefore also, as <span data-ref="0352.g1:C">$C$</span> is to <span data-ref="0352.g1:D">$D$</span>, so is <span data-ref="0352.g1:D">$D$</span> to <span data-ref="0352.g1:E">$E$</span>.

And, since <span data-ref="0352.g1:A">$A$</span> by multiplying <span data-ref="0352.g1:C">$C$</span>, <span data-ref="0352.g1:D">$D$</span> has made <span data-ref="0352.g1:F">$F$</span>, <span data-ref="0352.g1:G">$G$</span>,  
therefore, as <span data-ref="0352.g1:C">$C$</span> is to <span data-ref="0352.g1:D">$D$</span>, so is <span data-ref="0352.g1:F">$F$</span> to <span data-ref="0352.g1:G">$G$</span>.
<div style="text-align: right;">[VII. 17]</div>

But, as <span data-ref="0352.g1:C">$C$</span> is to <span data-ref="0352.g1:D">$D$</span>, so was <span data-ref="0352.g1:A">$A$</span> to <span data-ref="0352.g1:B">$B$</span>;  
therefore also, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:F">$F$</span> to <span data-ref="0352.g1:G">$G$</span>.

Again, since <span data-ref="0352.g1:A">$A$</span> by multiplying <span data-ref="0352.g1:D">$D$</span>, <span data-ref="0352.g1:E">$E$</span> has made <span data-ref="0352.g1:G">$G$</span>, <span data-ref="0352.g1:H">$H$</span>,  
therefore, as <span data-ref="0352.g1:D">$D$</span> is to <span data-ref="0352.g1:E">$E$</span>, so is <span data-ref="0352.g1:G">$G$</span> to <span data-ref="0352.g1:H">$H$</span>.
<div style="text-align: right;">[VII. 17]</div>

But, as <span data-ref="0352.g1:D">$D$</span> is to <span data-ref="0352.g1:E">$E$</span>, so is <span data-ref="0352.g1:A">$A$</span> to <span data-ref="0352.g1:B">$B$</span>.

Therefore also, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:G">$G$</span> to <span data-ref="0352.g1:H">$H$</span>.

And, since <span data-ref="0352.g1:A">$A$</span>, <span data-ref="0352.g1:B">$B$</span> by multiplying <span data-ref="0352.g1:E">$E$</span> have made <span data-ref="0352.g1:H">$H$</span>, <span data-ref="0352.g1:K">$K$</span>,  
therefore, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:H">$H$</span> to <span data-ref="0352.g1:K">$K$</span>.
<div style="text-align: right;">[VII. 18]</div>

But, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:F">$F$</span> to <span data-ref="0352.g1:G">$G$</span>, and <span data-ref="0352.g1:G">$G$</span> to <span data-ref="0352.g1:H">$H$</span>.

Therefore also, as <span data-ref="0352.g1:F">$F$</span> is to <span data-ref="0352.g1:G">$G$</span>, so is <span data-ref="0352.g1:G">$G$</span> to <span data-ref="0352.g1:H">$H$</span>, and <span data-ref="0352.g1:H">$H$</span> to <span data-ref="0352.g1:K">$K$</span>;  
therefore <span data-ref="0352.g1:C">$C$</span>, <span data-ref="0352.g1:D">$D$</span>, <span data-ref="0352.g1:E">$E$</span>, and <span data-ref="0352.g1:F">$F$</span>, <span data-ref="0352.g1:G">$G$</span>, <span data-ref="0352.g1:H">$H$</span>, <span data-ref="0352.g1:K">$K$</span> are proportional in the ratio of <span data-ref="0352.g1:A">$A$</span> to <span data-ref="0352.g1:B">$B$</span>.

I say next that they are the least numbers that are so.

For, since <span data-ref="0352.g1:A">$A$</span>, <span data-ref="0352.g1:B">$B$</span> are the least of those which have the same ratio with them, and the least of those which have the same ratio are prime to one another,
<div style="text-align: right;">[VII. 22]</div>
therefore <span data-ref="0352.g1:A">$A$</span>, <span data-ref="0352.g1:B">$B$</span> are prime to one another.

And the numbers <span data-ref="0352.g1:A">$A$</span>, <span data-ref="0352.g1:B">$B$</span> by multiplying themselves respectively have made the numbers <span data-ref="0352.g1:C">$C$</span>, <span data-ref="0352.g1:E">$E$</span>, and by multiplying the numbers <span data-ref="0352.g1:C">$C$</span>, <span data-ref="0352.g1:E">$E$</span> respectively have made the numbers <span data-ref="0352.g1:F">$F$</span>, <span data-ref="0352.g1:K">$K$</span>;  
therefore <span data-ref="0352.g1:C">$C$</span>, <span data-ref="0352.g1:E">$E$</span> and <span data-ref="0352.g1:F">$F$</span>, <span data-ref="0352.g1:K">$K$</span> are prime to one another respectively.
<div style="text-align: right;">[VII. 27]</div>
