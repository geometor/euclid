<p class="sub-clause">Now, since <span data-ref="0352.g1:A">$A$</span> by multiplying itself has made <span data-ref="0352.g1:C">$C$</span>,<br />
and by multiplying <span data-ref="0352.g1:B">$B$</span> has made <span data-ref="0352.g1:D">$D$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:C">$C$</span> to <span data-ref="0352.g1:D">$D$</span>. <span class="justification">[VII. 17]</span></p>

<p class="sub-clause">Again, since <span data-ref="0352.g1:A">$A$</span> by multiplying <span data-ref="0352.g1:B">$B$</span> has made <span data-ref="0352.g1:D">$D$</span>,<br />
and <span data-ref="0352.g1:B">$B$</span> by multiplying itself has made <span data-ref="0352.g1:E">$E$</span>,</p>
<p class="assertion">therefore the numbers <span data-ref="0352.g1:A">$A$</span>, <span data-ref="0352.g1:B">$B$</span> by multiplying <span data-ref="0352.g1:B">$B$</span> have made the<br />
numbers <span data-ref="0352.g1:D">$D$</span>, <span data-ref="0352.g1:E">$E$</span> respectively.</p>
<p class="assertion">Therefore, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:D">$D$</span> to <span data-ref="0352.g1:E">$E$</span>. <span class="justification">[VII. 18]</span></p>

<p class="sub-clause">But, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:C">$C$</span> to <span data-ref="0352.g1:D">$D$</span>;</p>
<p class="assertion">therefore also, as <span data-ref="0352.g1:C">$C$</span> is to <span data-ref="0352.g1:D">$D$</span>, so is <span data-ref="0352.g1:D">$D$</span> to <span data-ref="0352.g1:E">$E$</span>.</p>

<p class="sub-clause">And, since <span data-ref="0352.g1:A">$A$</span> by multiplying <span data-ref="0352.g1:C">$C$</span>, <span data-ref="0352.g1:D">$D$</span> has made <span data-ref="0352.g1:F">$F$</span>, <span data-ref="0352.g1:G">$G$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0352.g1:C">$C$</span> is to <span data-ref="0352.g1:D">$D$</span>, so is <span data-ref="0352.g1:F">$F$</span> to <span data-ref="0352.g1:G">$G$</span>. <span class="justification">[VII. 17]</span></p>

<p class="sub-clause">But, as <span data-ref="0352.g1:C">$C$</span> is to <span data-ref="0352.g1:D">$D$</span>, so was <span data-ref="0352.g1:A">$A$</span> to <span data-ref="0352.g1:B">$B$</span>;</p>
<p class="assertion">therefore also, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:F">$F$</span> to <span data-ref="0352.g1:G">$G$</span>.</p>

<p class="sub-clause">Again, since <span data-ref="0352.g1:A">$A$</span> by multiplying <span data-ref="0352.g1:D">$D$</span>, <span data-ref="0352.g1:E">$E$</span> has made <span data-ref="0352.g1:G">$G$</span>, <span data-ref="0352.g1:H">$H$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0352.g1:D">$D$</span> is to <span data-ref="0352.g1:E">$E$</span>, so is <span data-ref="0352.g1:G">$G$</span> to <span data-ref="0352.g1:H">$H$</span>. <span class="justification">[VII. 17]</span></p>

<p class="sub-clause">But, as <span data-ref="0352.g1:D">$D$</span> is to <span data-ref="0352.g1:E">$E$</span>, so is <span data-ref="0352.g1:A">$A$</span> to <span data-ref="0352.g1:B">$B$</span>.</p>
<p class="assertion">Therefore also, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:G">$G$</span> to <span data-ref="0352.g1:H">$H$</span>.</p>

<p class="sub-clause">And, since <span data-ref="0352.g1:A">$A$</span>, <span data-ref="0352.g1:B">$B$</span> by multiplying <span data-ref="0352.g1:E">$E$</span> have made <span data-ref="0352.g1:H">$H$</span>, <span data-ref="0352.g1:K">$K$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:H">$H$</span> to <span data-ref="0352.g1:K">$K$</span>. <span class="justification">[VII. 18]</span></p>

<p class="sub-clause">But, as <span data-ref="0352.g1:A">$A$</span> is to <span data-ref="0352.g1:B">$B$</span>, so is <span data-ref="0352.g1:F">$F$</span> to <span data-ref="0352.g1:G">$G$</span>, and <span data-ref="0352.g1:G">$G$</span> to <span data-ref="0352.g1:H">$H$</span>.</p>
<p class="assertion">Therefore also, as <span data-ref="0352.g1:F">$F$</span> is to <span data-ref="0352.g1:G">$G$</span>, so is <span data-ref="0352.g1:G">$G$</span> to <span data-ref="0352.g1:H">$H$</span>, and <span data-ref="0352.g1:H">$H$</span> to <span data-ref="0352.g1:K">$K$</span>;<br />
therefore <span data-ref="0352.g1:C">$C$</span>, <span data-ref="0352.g1:D">$D$</span>, <span data-ref="0352.g1:E">$E$</span>, and <span data-ref="0352.g1:F">$F$</span>, <span data-ref="0352.g1:G">$G$</span>, <span data-ref="0352.g1:H">$H$</span>, <span data-ref="0352.g1:K">$K$</span> are proportional in the<br />
ratio of <span data-ref="0352.g1:A">$A$</span> to <span data-ref="0352.g1:B">$B$</span>.</p>

I say next that they are the least numbers that are so.

<p class="sub-clause">For, since <span data-ref="0352.g1:A">$A$</span>, <span data-ref="0352.g1:B">$B$</span> are the least of those which have the<br />
same ratio with them,<br />
and the least of those which have the same ratio are prime<br />
to one another, <span class="justification">[VII. 22]</span></p>
<p class="assertion">therefore <span data-ref="0352.g1:A">$A$</span>, <span data-ref="0352.g1:B">$B$</span> are prime to one another.</p>

<p class="sub-clause">And the numbers <span data-ref="0352.g1:A">$A$</span>, <span data-ref="0352.g1:B">$B$</span> by multiplying themselves re-<br />
spectively have made the numbers <span data-ref="0352.g1:C">$C$</span>, <span data-ref="0352.g1:E">$E$</span>, and by multiplying<br />
the numbers <span data-ref="0352.g1:C">$C$</span>, <span data-ref="0352.g1:E">$E$</span> respectively have made the numbers <span data-ref="0352.g1:F">$F$</span>, <span data-ref="0352.g1:K">$K$</span>;</p>
<p class="assertion">therefore <span data-ref="0352.g1:C">$C$</span>, <span data-ref="0352.g1:E">$E$</span> and <span data-ref="0352.g1:F">$F$</span>, <span data-ref="0352.g1:K">$K$</span> are prime to one another respectively. <span class="justification">[VII. 27]</span></p>
