<p class="sub-clause">For, if <span data-ref="0356.g1:H">$H$</span>, <span data-ref="0356.g1:G">$G$</span>, <span data-ref="0356.g1:K">$K$</span>, <span data-ref="0356.g1:L">$L$</span> are not the least numbers continuously<br />
<sup>30</sup> proportional in the ratios of <span data-ref="0356.g1:A">$A$</span> to <span data-ref="0356.g1:B">$B$</span>, of <span data-ref="0356.g1:C">$C$</span> to <span data-ref="0356.g1:D">$D$</span>, and of <span data-ref="0356.g1:E">$E$</span><br />
to <span data-ref="0356.g1:F">$F$</span>, let them be <span data-ref="0356.g1:N">$N$</span>, <span data-ref="0356.g1:O">$O$</span>, <span data-ref="0356.g1:M">$M$</span>, <span data-ref="0356.g1:P">$P$</span>.</p>

<p class="sub-clause">Then since, as <span data-ref="0356.g1:A">$A$</span> is to <span data-ref="0356.g1:B">$B$</span>, so is <span data-ref="0356.g1:N">$N$</span> to <span data-ref="0356.g1:O">$O$</span>,<br />
while <span data-ref="0356.g1:A">$A$</span>, <span data-ref="0356.g1:B">$B$</span> are least,<br />
and the least numbers measure those which have the same<br />
<sup>35</sup> ratio the same number of times, the greater the greater and<br />
the less the less, that is, the antecedent the antecedent and the<br />
consequent the consequent;</p>
<p class="assertion">therefore <span data-ref="0356.g1:B">$B$</span> measures <span data-ref="0356.g1:O">$O$</span>. <span class="justification">[VII. 20]</span></p>

<p class="sub-clause">For the same reason<br />
<sup>40</sup> <span data-ref="0356.g1:C">$C$</span> also measures <span data-ref="0356.g1:O">$O$</span>;</p>
<p class="assertion">therefore <span data-ref="0356.g1:B">$B$</span>, <span data-ref="0356.g1:C">$C$</span> measure <span data-ref="0356.g1:O">$O$</span>;</p>
<p class="assertion">therefore the least number measured by <span data-ref="0356.g1:B">$B$</span>, <span data-ref="0356.g1:C">$C$</span> will also<br />
measure <span data-ref="0356.g1:O">$O$</span>. <span class="justification">[VII. 35]</span></p>

<p class="sub-clause">But <span data-ref="0356.g1:G">$G$</span> is the least number measured by <span data-ref="0356.g1:B">$B$</span>, <span data-ref="0356.g1:C">$C$</span>;</p>
<p class="assertion"><sup>45</sup> therefore <span data-ref="0356.g1:G">$G$</span> measures <span data-ref="0356.g1:O">$O$</span>, the greater the less :<br />
which is impossible.</p>

<p class="assertion">Therefore there will be no numbers less than <span data-ref="0356.g1:H">$H$</span>, <span data-ref="0356.g1:G">$G$</span>, <span data-ref="0356.g1:K">$K$</span>, <span data-ref="0356.g1:L">$L$</span><br />
which are continuously in the ratio of <span data-ref="0356.g1:A">$A$</span> to <span data-ref="0356.g1:B">$B$</span>, of <span data-ref="0356.g1:C">$C$</span> to <span data-ref="0356.g1:D">$D$</span>, and<br />
of <span data-ref="0356.g1:E">$E$</span> to <span data-ref="0356.g1:F">$F$</span>.</p>

<sup>50</sup> Next, let <span data-ref="0357.g1:E">$E$</span> not measure <span data-ref="0357.g1:K">$K$</span>.

![Proposition 4 Diagram 2](0357.g1.svg)

Let <span data-ref="0357.g1:M">$M$</span>, the least number measured by <span data-ref="0357.g1:E">$E$</span>, <span data-ref="0357.g1:K">$K$</span>, be taken.

And, as many times as <span data-ref="0357.g1:K">$K$</span> measures <span data-ref="0357.g1:M">$M$</span>, so many times let<br />
<span data-ref="0357.g1:H">$H$</span>, <span data-ref="0357.g1:G">$G$</span> measure <span data-ref="0357.g1:N">$N$</span>, <span data-ref="0357.g1:O">$O$</span> respectively,<br />
and, as many times as <span data-ref="0357.g1:E">$E$</span> measures <span data-ref="0357.g1:M">$M$</span>, so many times let <span data-ref="0357.g1:F">$F$</span><br />
<sup>55</sup> measure <span data-ref="0357.g1:P">$P$</span> also.

<p class="sub-clause">Since <span data-ref="0357.g1:H">$H$</span> measures <span data-ref="0357.g1:N">$N$</span> the same number of times that <span data-ref="0357.g1:G">$G$</span><br />
measures <span data-ref="0357.g1:O">$O$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0357.g1:H">$H$</span> is to <span data-ref="0357.g1:G">$G$</span>, so is <span data-ref="0357.g1:N">$N$</span> to <span data-ref="0357.g1:O">$O$</span>. <span class="justification">[VII. 13 and Def. 20]</span></p>
