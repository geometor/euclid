For, if <span data-ref="0356.g1:H">$H$</span>, <span data-ref="0356.g1:G">$G$</span>, <span data-ref="0356.g1:K">$K$</span>, <span data-ref="0356.g1:L">$L$</span> are not the least numbers continuously  
<sup>30</sup> proportional in the ratios of <span data-ref="0356.g1:A">$A$</span> to <span data-ref="0356.g1:B">$B$</span>, of <span data-ref="0356.g1:C">$C$</span> to <span data-ref="0356.g1:D">$D$</span>, and of <span data-ref="0356.g1:E">$E$</span> to <span data-ref="0356.g1:F">$F$</span>, let them be <span data-ref="0356.g1:N">$N$</span>, <span data-ref="0356.g1:O">$O$</span>, <span data-ref="0356.g1:M">$M$</span>, <span data-ref="0356.g1:P">$P$</span>.  
Then since, as <span data-ref="0356.g1:A">$A$</span> is to <span data-ref="0356.g1:B">$B$</span>, so is <span data-ref="0356.g1:N">$N$</span> to <span data-ref="0356.g1:O">$O$</span>,  
while <span data-ref="0356.g1:A">$A$</span>, <span data-ref="0356.g1:B">$B$</span> are least,  
and the least numbers measure those which have the same  
<sup>35</sup> ratio the same number of times, the greater the greater and the less the less, that is, the antecedent the antecedent and the consequent the consequent;  
therefore <span data-ref="0356.g1:B">$B$</span> measures <span data-ref="0356.g1:O">$O$</span>.
<div style="text-align: right;">[VII. 20]</div>
For the same reason  
<sup>40</sup> <span data-ref="0356.g1:C">$C$</span> also measures <span data-ref="0356.g1:O">$O$</span>;  
therefore <span data-ref="0356.g1:B">$B$</span>, <span data-ref="0356.g1:C">$C$</span> measure <span data-ref="0356.g1:O">$O$</span>;  
therefore the least number measured by <span data-ref="0356.g1:B">$B$</span>, <span data-ref="0356.g1:C">$C$</span> will also measure <span data-ref="0356.g1:O">$O$</span>.
<div style="text-align: right;">[VII. 35]</div>
But <span data-ref="0356.g1:G">$G$</span> is the least number measured by <span data-ref="0356.g1:B">$B$</span>, <span data-ref="0356.g1:C">$C$</span>;  
<sup>45</sup> therefore <span data-ref="0356.g1:G">$G$</span> measures <span data-ref="0356.g1:O">$O$</span>, the greater the less :  
which is impossible.  
Therefore there will be no numbers less than <span data-ref="0356.g1:H">$H$</span>, <span data-ref="0356.g1:G">$G$</span>, <span data-ref="0356.g1:K">$K$</span>, <span data-ref="0356.g1:L">$L$</span> which are continuously in the ratio of <span data-ref="0356.g1:A">$A$</span> to <span data-ref="0356.g1:B">$B$</span>, of <span data-ref="0356.g1:C">$C$</span> to <span data-ref="0356.g1:D">$D$</span>, and of <span data-ref="0356.g1:E">$E$</span> to <span data-ref="0356.g1:F">$F$</span>.  
<sup>50</sup> Next, let <span data-ref="0357.g1:E">$E$</span> not measure <span data-ref="0357.g1:K">$K$</span>.

Let <span data-ref="0357.g1:M">$M$</span>, the least number measured by <span data-ref="0357.g1:E">$E$</span>, <span data-ref="0357.g1:K">$K$</span>, be taken.  
And, as many times as <span data-ref="0357.g1:K">$K$</span> measures <span data-ref="0357.g1:M">$M$</span>, so many times let <span data-ref="0357.g1:H">$H$</span>, <span data-ref="0357.g1:G">$G$</span> measure <span data-ref="0357.g1:N">$N$</span>, <span data-ref="0357.g1:O">$O$</span> respectively,  
and, as many times as <span data-ref="0357.g1:E">$E$</span> measures <span data-ref="0357.g1:M">$M$</span>, so many times let <span data-ref="0357.g1:F">$F$</span>  
<sup>55</sup> measure <span data-ref="0357.g1:P">$P$</span> also.  
Since <span data-ref="0357.g1:H">$H$</span> measures <span data-ref="0357.g1:N">$N$</span> the same number of times that <span data-ref="0357.g1:G">$G$</span> measures <span data-ref="0357.g1:O">$O$</span>,  
therefore, as <span data-ref="0357.g1:H">$H$</span> is to <span data-ref="0357.g1:G">$G$</span>, so is <span data-ref="0357.g1:N">$N$</span> to <span data-ref="0357.g1:O">$O$</span>.
