But, as <span data-ref="0357.g1:H">$H$</span> is to <span data-ref="0357.g1:G">$G$</span>, so is <span data-ref="0357.g1:A">$A$</span> to <span data-ref="0357.g1:B">$B$</span>;  
<sup>60</sup> therefore also, as <span data-ref="0357.g1:A">$A$</span> is to <span data-ref="0357.g1:B">$B$</span>, so is <span data-ref="0357.g1:N">$N$</span> to <span data-ref="0357.g1:O">$O$</span>.  
For the same reason also,
<div style="text-align: center;">as <span data-ref="0357.g1:C">$C$</span> is to <span data-ref="0357.g1:D">$D$</span>, so is <span data-ref="0357.g1:O">$O$</span> to <span data-ref="0357.g1:M">$M$</span>.</div>
Again, since <span data-ref="0357.g1:E">$E$</span> measures <span data-ref="0357.g1:M">$M$</span> the same number of times that <span data-ref="0357.g1:F">$F$</span> measures <span data-ref="0357.g1:P">$P$</span>,  
<sup>65</sup> therefore, as <span data-ref="0357.g1:E">$E$</span> is to <span data-ref="0357.g1:F">$F$</span>, so is <span data-ref="0357.g1:M">$M$</span> to <span data-ref="0357.g1:P">$P$</span>;
<div style="text-align: right;">[VII. 13 and Def. 20]</div>
therefore <span data-ref="0357.g1:N">$N$</span>, <span data-ref="0357.g1:O">$O$</span>, <span data-ref="0357.g1:M">$M$</span>, <span data-ref="0357.g1:P">$P$</span> are continuously proportional in the ratios of <span data-ref="0357.g1:A">$A$</span> to <span data-ref="0357.g1:B">$B$</span>, of <span data-ref="0357.g1:C">$C$</span> to <span data-ref="0357.g1:D">$D$</span>, and of <span data-ref="0357.g1:E">$E$</span> to <span data-ref="0357.g1:F">$F$</span>.  
I say next that they are also the least that are in the ratios <span data-ref="0357.g1:A">$A$</span> : <span data-ref="0357.g1:B">$B$</span>, <span data-ref="0357.g1:C">$C$</span> : <span data-ref="0357.g1:D">$D$</span>, <span data-ref="0357.g1:E">$E$</span> : <span data-ref="0357.g1:F">$F$</span>.  
<sup>70</sup> For, if not, there will be some numbers less than <span data-ref="0357.g1:N">$N$</span>, <span data-ref="0357.g1:O">$O$</span>, <span data-ref="0357.g1:M">$M$</span>, <span data-ref="0357.g1:P">$P$</span> continuously proportional in the ratios <span data-ref="0357.g1:A">$A$</span> : <span data-ref="0357.g1:B">$B$</span>, <span data-ref="0357.g1:C">$C$</span> : <span data-ref="0357.g1:D">$D$</span>, <span data-ref="0357.g1:E">$E$</span> : <span data-ref="0357.g1:F">$F$</span>.  
Let them be <span data-ref="0357.g1:Q">$Q$</span>, <span data-ref="0357.g1:R">$R$</span>, <span data-ref="0357.g1:S">$S$</span>, <span data-ref="0357.g1:T">$T$</span>.  
Now since, as <span data-ref="0357.g1:Q">$Q$</span> is to <span data-ref="0357.g1:R">$R$</span>, so is <span data-ref="0357.g1:A">$A$</span> to <span data-ref="0357.g1:B">$B$</span>,  
<sup>75</sup> while <span data-ref="0357.g1:A">$A$</span>, <span data-ref="0357.g1:B">$B$</span> are least,  
and the least numbers measure those which have the same ratio with them the same number of times, the antecedent the antecedent and the consequent the consequent,
<div style="text-align: right;">[VII. 20]</div>
therefore <span data-ref="0357.g1:B">$B$</span> measures <span data-ref="0357.g1:R">$R$</span>.  
<sup>80</sup> For the same reason <span data-ref="0357.g1:C">$C$</span> also measures <span data-ref="0357.g1:R">$R$</span>;  
therefore <span data-ref="0357.g1:B">$B$</span>, <span data-ref="0357.g1:C">$C$</span> measure <span data-ref="0357.g1:R">$R$</span>.  
Therefore the least number measured by <span data-ref="0357.g1:B">$B$</span>, <span data-ref="0357.g1:C">$C$</span> will also measure <span data-ref="0357.g1:R">$R$</span>.
<div style="text-align: right;">[VII. 35]</div>
But <span data-ref="0357.g1:G">$G$</span> is the least number measured by <span data-ref="0357.g1:B">$B$</span>, <span data-ref="0357.g1:C">$C$</span>;  
<sup>85</sup> therefore <span data-ref="0357.g1:G">$G$</span> measures <span data-ref="0357.g1:R">$R$</span>.  
And, as <span data-ref="0357.g1:G">$G$</span> is to <span data-ref="0357.g1:R">$R$</span>, so is <span data-ref="0357.g1:K">$K$</span> to <span data-ref="0357.g1:S">$S$</span>:
<div style="text-align: right;">[VII. 13]</div>
therefore <span data-ref="0357.g1:K">$K$</span> also measures <span data-ref="0357.g1:S">$S$</span>.  
But <span data-ref="0357.g1:E">$E$</span> also measures <span data-ref="0357.g1:S">$S$</span>;  
therefore <span data-ref="0357.g1:E">$E$</span>, <span data-ref="0357.g1:K">$K$</span> measure <span data-ref="0357.g1:S">$S$</span>.  
<sup>90</sup> Therefore the least number measured by <span data-ref="0357.g1:E">$E$</span>, <span data-ref="0357.g1:K">$K$</span> will also measure <span data-ref="0357.g1:S">$S$</span>.
<div style="text-align: right;">[VII. 35]</div>
But <span data-ref="0357.g1:M">$M$</span> is the least number measured by <span data-ref="0357.g1:E">$E$</span>, <span data-ref="0357.g1:K">$K$</span>;  
therefore <span data-ref="0357.g1:M">$M$</span> measures <span data-ref="0357.g1:S">$S$</span>, the greater the less :  
which is impossible.  
<sup>95</sup> Therefore there will not be any numbers less than <span data-ref="0357.g1:N">$N$</span>, <span data-ref="0357.g1:O">$O$</span>, <span data-ref="0357.g1:M">$M$</span>, <span data-ref="0357.g1:P">$P$</span> continuously proportional in the ratios of <span data-ref="0357.g1:A">$A$</span> to <span data-ref="0357.g1:B">$B$</span>, of <span data-ref="0357.g1:C">$C$</span> to <span data-ref="0357.g1:D">$D$</span>, and of <span data-ref="0357.g1:E">$E$</span> to <span data-ref="0357.g1:F">$F$</span>;
