<p class="sub-clause">But, as <span data-ref="0357.g1:H">$H$</span> is to <span data-ref="0357.g1:G">$G$</span>, so is <span data-ref="0357.g1:A">$A$</span> to <span data-ref="0357.g1:B">$B$</span>;</p>
<p class="assertion"><sup>60</sup> therefore also, as <span data-ref="0357.g1:A">$A$</span> is to <span data-ref="0357.g1:B">$B$</span>, so is <span data-ref="0357.g1:N">$N$</span> to <span data-ref="0357.g1:O">$O$</span>.</p>

<p class="sub-clause">For the same reason also,<br />
<span style="display: block; text-align: center;">as <span data-ref="0357.g1:C">$C$</span> is to <span data-ref="0357.g1:D">$D$</span>, so is <span data-ref="0357.g1:O">$O$</span> to <span data-ref="0357.g1:M">$M$</span>.</span></p>

<p class="sub-clause">Again, since <span data-ref="0357.g1:E">$E$</span> measures <span data-ref="0357.g1:M">$M$</span> the same number of times that<br />
<span data-ref="0357.g1:F">$F$</span> measures <span data-ref="0357.g1:P">$P$</span>,</p>
<p class="assertion"><sup>65</sup> therefore, as <span data-ref="0357.g1:E">$E$</span> is to <span data-ref="0357.g1:F">$F$</span>, so is <span data-ref="0357.g1:M">$M$</span> to <span data-ref="0357.g1:P">$P$</span>; <span class="justification">[VII. 13 and Def. 20]</span></p>
<p class="assertion">therefore <span data-ref="0357.g1:N">$N$</span>, <span data-ref="0357.g1:O">$O$</span>, <span data-ref="0357.g1:M">$M$</span>, <span data-ref="0357.g1:P">$P$</span> are continuously proportional in the<br />
ratios of <span data-ref="0357.g1:A">$A$</span> to <span data-ref="0357.g1:B">$B$</span>, of <span data-ref="0357.g1:C">$C$</span> to <span data-ref="0357.g1:D">$D$</span>, and of <span data-ref="0357.g1:E">$E$</span> to <span data-ref="0357.g1:F">$F$</span>.</p>

I say next that they are also the least that are in the ratios<br />
<span data-ref="0357.g1:A">$A$</span> : <span data-ref="0357.g1:B">$B$</span>, <span data-ref="0357.g1:C">$C$</span> : <span data-ref="0357.g1:D">$D$</span>, <span data-ref="0357.g1:E">$E$</span> : <span data-ref="0357.g1:F">$F$</span>.

<p class="sub-clause"><sup>70</sup> For, if not, there will be some numbers less than <span data-ref="0357.g1:N">$N$</span>, <span data-ref="0357.g1:O">$O$</span>,<br />
<span data-ref="0357.g1:M">$M$</span>, <span data-ref="0357.g1:P">$P$</span> continuously proportional in the ratios <span data-ref="0357.g1:A">$A$</span> : <span data-ref="0357.g1:B">$B$</span>, <span data-ref="0357.g1:C">$C$</span> : <span data-ref="0357.g1:D">$D$</span>,<br />
<span data-ref="0357.g1:E">$E$</span> : <span data-ref="0357.g1:F">$F$</span>.</p>

Let them be <span data-ref="0357.g1:Q">$Q$</span>, <span data-ref="0357.g1:R">$R$</span>, <span data-ref="0357.g1:S">$S$</span>, <span data-ref="0357.g1:T">$T$</span>.

<p class="sub-clause">Now since, as <span data-ref="0357.g1:Q">$Q$</span> is to <span data-ref="0357.g1:R">$R$</span>, so is <span data-ref="0357.g1:A">$A$</span> to <span data-ref="0357.g1:B">$B$</span>,<br />
<sup>75</sup> while <span data-ref="0357.g1:A">$A$</span>, <span data-ref="0357.g1:B">$B$</span> are least,<br />
and the least numbers measure those which have the same<br />
ratio with them the same number of times, the antecedent the<br />
antecedent and the consequent the consequent, <span class="justification">[VII. 20]</span></p>
<p class="assertion">therefore <span data-ref="0357.g1:B">$B$</span> measures <span data-ref="0357.g1:R">$R$</span>.</p>

<p class="sub-clause"><sup>80</sup> For the same reason <span data-ref="0357.g1:C">$C$</span> also measures <span data-ref="0357.g1:R">$R$</span>;</p>
<p class="assertion">therefore <span data-ref="0357.g1:B">$B$</span>, <span data-ref="0357.g1:C">$C$</span> measure <span data-ref="0357.g1:R">$R$</span>.</p>
<p class="assertion">Therefore the least number measured by <span data-ref="0357.g1:B">$B$</span>, <span data-ref="0357.g1:C">$C$</span> will also<br />
measure <span data-ref="0357.g1:R">$R$</span>. <span class="justification">[VII. 35]</span></p>

<p class="sub-clause">But <span data-ref="0357.g1:G">$G$</span> is the least number measured by <span data-ref="0357.g1:B">$B$</span>, <span data-ref="0357.g1:C">$C$</span>;</p>
<p class="assertion"><sup>85</sup> therefore <span data-ref="0357.g1:G">$G$</span> measures <span data-ref="0357.g1:R">$R$</span>.</p>

<p class="sub-clause">And, as <span data-ref="0357.g1:G">$G$</span> is to <span data-ref="0357.g1:R">$R$</span>, so is <span data-ref="0357.g1:K">$K$</span> to <span data-ref="0357.g1:S">$S$</span> : <span class="justification">[VII. 13]</span></p>
<p class="assertion">therefore <span data-ref="0357.g1:K">$K$</span> also measures <span data-ref="0357.g1:S">$S$</span>.</p>

<p class="sub-clause">But <span data-ref="0357.g1:E">$E$</span> also measures <span data-ref="0357.g1:S">$S$</span>;</p>
<p class="assertion">therefore <span data-ref="0357.g1:E">$E$</span>, <span data-ref="0357.g1:K">$K$</span> measure <span data-ref="0357.g1:S">$S$</span>.</p>

<p class="assertion"><sup>90</sup> Therefore the least number measured by <span data-ref="0357.g1:E">$E$</span>, <span data-ref="0357.g1:K">$K$</span> will also<br />
measure <span data-ref="0357.g1:S">$S$</span>. <span class="justification">[VII. 35]</span></p>

<p class="sub-clause">But <span data-ref="0357.g1:M">$M$</span> is the least number measured by <span data-ref="0357.g1:E">$E$</span>, <span data-ref="0357.g1:K">$K$</span>;</p>
<p class="assertion">therefore <span data-ref="0357.g1:M">$M$</span> measures <span data-ref="0357.g1:S">$S$</span>, the greater the less :<br />
which is impossible.</p>

<p class="assertion"><sup>95</sup> Therefore there will not be any numbers less than <span data-ref="0357.g1:N">$N$</span>, <span data-ref="0357.g1:O">$O$</span>,<br />
<span data-ref="0357.g1:M">$M$</span>, <span data-ref="0357.g1:P">$P$</span> continuously proportional in the ratios of <span data-ref="0357.g1:A">$A$</span> to <span data-ref="0357.g1:B">$B$</span>, of<br />
<span data-ref="0357.g1:C">$C$</span> to <span data-ref="0357.g1:D">$D$</span>, and of <span data-ref="0357.g1:E">$E$</span> to <span data-ref="0357.g1:F">$F$</span>;</p>
