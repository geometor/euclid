If $l$ is the L.C.M. of $e$, $d$ and $l = me = nd$, the three numbers are
$$\left. \begin{array}{r} mc,\, me \\ = nd \end{array} \right\},\, nf.\hfill\text{[VIII. 4]}$$

Now
$$\begin{aligned}
dc : de &= c : e\hfill\text{[VII. 17]}\\
&= mc : me = mc : nd.
\end{aligned}$$

Also
$$\begin{aligned}
ed : ef &= d : f\hfill\text{[VII. 17]}\\
&= nd : nf.
\end{aligned}$$

Therefore, *ex aequali*,
$$\begin{aligned}
cd : ef &= mc : nf\\
&= (\text{ratio compounded of } c : e \text{ and } d : f).
\end{aligned}$$

It will be seen that this proof follows exactly the method of VI. 23 for parallelograms.

### PROPOSITION 6.

<p class="enunciation">If there be as many numbers as we please in continued<br />
proportion, and the first do not measure the second, neither<br />
will any other measure any other.</p>

Let there be as many numbers as we please, <span data-ref="0361.g1:A">$A$</span>, <span data-ref="0361.g1:B">$B$</span>, <span data-ref="0361.g1:C">$C$</span>, <span data-ref="0361.g1:D">$D$</span>, <span data-ref="0361.g1:E">$E$</span>,<br />
in continued proportion, and let <span data-ref="0361.g1:A">$A$</span> not measure <span data-ref="0361.g1:B">$B$</span>;

I say that neither will any other measure any other.

![Book VIII Proposition 6](0361.g1.svg)

<p class="assertion">Now it is manifest that <span data-ref="0361.g1:A">$A$</span>, <span data-ref="0361.g1:B">$B$</span>, <span data-ref="0361.g1:C">$C$</span>, <span data-ref="0361.g1:D">$D$</span>, <span data-ref="0361.g1:E">$E$</span> do not measure<br />
one another in order ; for <span data-ref="0361.g1:A">$A$</span> does not even measure <span data-ref="0361.g1:B">$B$</span>.</p>

I say, then, that neither will any other measure any other.

For, if possible, let <span data-ref="0361.g1:A">$A$</span> measure <span data-ref="0361.g1:C">$C$</span>.

And, however many <span data-ref="0361.g1:A">$A$</span>, <span data-ref="0361.g1:B">$B$</span>, <span data-ref="0361.g1:C">$C$</span> are, let as many numbers<br />
<span data-ref="0361.g1:F">$F$</span>, <span data-ref="0361.g1:G">$G$</span>, <span data-ref="0361.g1:H">$H$</span>, the least of those which have the same ratio with<br />
<span data-ref="0361.g1:A">$A$</span>, <span data-ref="0361.g1:B">$B$</span>, <span data-ref="0361.g1:C">$C$</span>, be taken. <span class="justification">[VII. 33]</span>

<p class="sub-clause">Now, since <span data-ref="0361.g1:F">$F$</span>, <span data-ref="0361.g1:G">$G$</span>, <span data-ref="0361.g1:H">$H$</span> are in the same ratio with <span data-ref="0361.g1:A">$A$</span>, <span data-ref="0361.g1:B">$B$</span>, <span data-ref="0361.g1:C">$C$</span>,<br />
and the multitude of the numbers <span data-ref="0361.g1:A">$A$</span>, <span data-ref="0361.g1:B">$B$</span>, <span data-ref="0361.g1:C">$C$</span> is equal to the<br />
multitude of the numbers <span data-ref="0361.g1:F">$F$</span>, <span data-ref="0361.g1:G">$G$</span>, <span data-ref="0361.g1:H">$H$</span>,</p>
<p class="assertion">therefore, *ex aequali*, as <span data-ref="0361.g1:A">$A$</span> is to <span data-ref="0361.g1:C">$C$</span>, so is <span data-ref="0361.g1:F">$F$</span> to <span data-ref="0361.g1:H">$H$</span>. <span class="justification">[VII. 14]</span></p>
