### PROPOSITION 8.

*If between two numbers there fall numbers in continued proportion with them, then, however many numbers fall between them in continued proportion, so many will also fall in continued proportion between the numbers which have the same ratio with the original numbers.*

Let the numbers <span data-ref="0363.g1:C">$C$</span>, <span data-ref="0363.g1:D">$D$</span> fall between the two numbers <span data-ref="0363.g1:A">$A$</span>, <span data-ref="0363.g1:B">$B$</span> in continued proportion with them, and let <span data-ref="0363.g1:E">$E$</span> be made in the same ratio to <span data-ref="0363.g1:F">$F$</span> as <span data-ref="0363.g1:A">$A$</span> is to <span data-ref="0363.g1:B">$B$</span>;
I say that, as many numbers as have fallen between <span data-ref="0363.g1:A">$A$</span>, <span data-ref="0363.g1:B">$B$</span> in continued proportion, so many will also fall between <span data-ref="0363.g1:E">$E$</span>, <span data-ref="0363.g1:F">$F$</span> in continued proportion.

![Book VIII Proposition 8](0363.g1.svg)

For, as many as <span data-ref="0363.g1:A">$A$</span>, <span data-ref="0363.g1:B">$B$</span>, <span data-ref="0363.g1:C">$C$</span>, <span data-ref="0363.g1:D">$D$</span> are in multitude, let so many numbers <span data-ref="0363.g1:G">$G$</span>, <span data-ref="0363.g1:H">$H$</span>, <span data-ref="0363.g1:K">$K$</span>, <span data-ref="0363.g1:L">$L$</span>, the least of those which have the same ratio with <span data-ref="0363.g1:A">$A$</span>, <span data-ref="0363.g1:C">$C$</span>, <span data-ref="0363.g1:D">$D$</span>, <span data-ref="0363.g1:B">$B$</span>, be taken; [VII. 33]
therefore the extremes of them <span data-ref="0363.g1:G">$G$</span>, <span data-ref="0363.g1:L">$L$</span> are prime to one another. [VIII. 3]

Now, since <span data-ref="0363.g1:A">$A$</span>, <span data-ref="0363.g1:C">$C$</span>, <span data-ref="0363.g1:D">$D$</span>, <span data-ref="0363.g1:B">$B$</span> are in the same ratio with <span data-ref="0363.g1:G">$G$</span>, <span data-ref="0363.g1:H">$H$</span>, <span data-ref="0363.g1:K">$K$</span>, <span data-ref="0363.g1:L">$L$</span>,
and the multitude of the numbers <span data-ref="0363.g1:A">$A$</span>, <span data-ref="0363.g1:C">$C$</span>, <span data-ref="0363.g1:D">$D$</span>, <span data-ref="0363.g1:B">$B$</span> is equal to the multitude of the numbers <span data-ref="0363.g1:G">$G$</span>, <span data-ref="0363.g1:H">$H$</span>, <span data-ref="0363.g1:K">$K$</span>, <span data-ref="0363.g1:L">$L$</span>,
therefore, *ex aequali*, as <span data-ref="0363.g1:A">$A$</span> is to <span data-ref="0363.g1:B">$B$</span>, so is <span data-ref="0363.g1:G">$G$</span> to <span data-ref="0363.g1:L">$L$</span>. [VII. 14]

But, as <span data-ref="0363.g1:A">$A$</span> is to <span data-ref="0363.g1:B">$B$</span>, so is <span data-ref="0363.g1:E">$E$</span> to <span data-ref="0363.g1:F">$F$</span>;
therefore also, as <span data-ref="0363.g1:G">$G$</span> is to <span data-ref="0363.g1:L">$L$</span>, so is <span data-ref="0363.g1:E">$E$</span> to <span data-ref="0363.g1:F">$F$</span>.

But <span data-ref="0363.g1:G">$G$</span>, <span data-ref="0363.g1:L">$L$</span> are prime,
primes are also least, [VII. 21]
and the least numbers measure those which have the same ratio the same number of times, the greater the greater and the less the less, that is, the antecedent the antecedent and the consequent the consequent. [VII. 20]
