Let them be taken, and let them be <span data-ref="0365.g1:M">$M$</span>, <span data-ref="0365.g1:N">$N$</span>, <span data-ref="0365.g1:O">$O$</span>, <span data-ref="0365.g1:P">$P$</span>.
It is now manifest that <span data-ref="0365.g1:F">$F$</span> by multiplying itself has made <span data-ref="0365.g1:H">$H$</span> and by multiplying <span data-ref="0365.g1:H">$H$</span> has made <span data-ref="0365.g1:M">$M$</span>, while <span data-ref="0365.g1:G">$G$</span> by multiplying itself has made <span data-ref="0365.g1:L">$L$</span> and by multiplying <span data-ref="0365.g1:L">$L$</span> has made <span data-ref="0365.g1:P">$P$</span>. And, since <span data-ref="0365.g1:M">$M$</span>, <span data-ref="0365.g1:N">$N$</span>, <span data-ref="0365.g1:O">$O$</span>, <span data-ref="0365.g1:P">$P$</span> are the least of those which have the same ratio with <span data-ref="0365.g1:F">$F$</span>, <span data-ref="0365.g1:G">$G$</span>,
and <span data-ref="0365.g1:A">$A$</span>, <span data-ref="0365.g1:C">$C$</span>, <span data-ref="0365.g1:D">$D$</span>, <span data-ref="0365.g1:B">$B$</span> are also the least of those which have the same ratio with <span data-ref="0365.g1:F">$F$</span>, <span data-ref="0365.g1:G">$G$</span>, [VIII. 1]

therefore <span data-ref="0365.g1:M">$M$</span>, <span data-ref="0365.g1:N">$N$</span>, <span data-ref="0365.g1:O">$O$</span>, <span data-ref="0365.g1:P">$P$</span> are equal to <span data-ref="0365.g1:A">$A$</span>, <span data-ref="0365.g1:C">$C$</span>, <span data-ref="0365.g1:D">$D$</span>, <span data-ref="0365.g1:B">$B$</span> respectively;
therefore <span data-ref="0365.g1:M">$M$</span> is equal to <span data-ref="0365.g1:A">$A$</span>, and <span data-ref="0365.g1:P">$P$</span> to <span data-ref="0365.g1:B">$B$</span>.

Now, since <span data-ref="0365.g1:F">$F$</span> by multiplying itself has made <span data-ref="0365.g1:H">$H$</span>,
therefore <span data-ref="0365.g1:F">$F$</span> measures <span data-ref="0365.g1:H">$H$</span> according to the units in <span data-ref="0365.g1:F">$F$</span>.
But the unit <span data-ref="0365.g1:E">$E$</span> also measures <span data-ref="0365.g1:F">$F$</span> according to the units in it;
therefore the unit <span data-ref="0365.g1:E">$E$</span> measures the number <span data-ref="0365.g1:F">$F$</span> the same number of times as <span data-ref="0365.g1:F">$F$</span> measures <span data-ref="0365.g1:H">$H$</span>.
Therefore, as the unit <span data-ref="0365.g1:E">$E$</span> is to the number <span data-ref="0365.g1:F">$F$</span>, so is <span data-ref="0365.g1:F">$F$</span> to <span data-ref="0365.g1:H">$H$</span>. [VII. Def. 20]
