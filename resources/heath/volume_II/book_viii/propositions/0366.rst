.. subclause::

   But the unit :g:`$E$ <0365.g1:E>` also measures the number :g:`$F$ <0365.g1:F>` according to the units in it ;

.. assertion::

   therefore the unit :g:`$E$ <0365.g1:E>` measures the number :g:`$F$ <0365.g1:F>` the same number of times as :g:`$H$ <0365.g1:H>` measures :g:`$M$ <0365.g1:M>`.

.. assertion::

   Therefore, as the unit :g:`$E$ <0365.g1:E>` is to the number :g:`$F$ <0365.g1:F>`, so is :g:`$H$ <0365.g1:H>` to :g:`$M$ <0365.g1:M>`.

.. subclause::

   But it was also proved that, as the unit :g:`$E$ <0365.g1:E>` is to the number :g:`$F$ <0365.g1:F>`, so is :g:`$F$ <0365.g1:F>` to :g:`$H$ <0365.g1:H>`;

.. assertion::

   therefore also, as the unit :g:`$E$ <0365.g1:E>` is to the number :g:`$F$ <0365.g1:F>`, so is :g:`$F$ <0365.g1:F>` to :g:`$H$ <0365.g1:H>`, and :g:`$H$ <0365.g1:H>` to :g:`$M$ <0365.g1:M>`.

.. subclause::

   But :g:`$M$ <0365.g1:M>` is equal to :g:`$A$ <0365.g1:A>` ;

.. assertion::

   therefore, as the unit :g:`$E$ <0365.g1:E>` is to the number :g:`$F$ <0365.g1:F>`, so is :g:`$F$ <0365.g1:F>` to :g:`$H$ <0365.g1:H>`, and :g:`$H$ <0365.g1:H>` to :g:`$A$ <0365.g1:A>`.

.. subclause::

   For the same reason also,

.. assertion::

   as the unit :g:`$E$ <0365.g1:E>` is to the number :g:`$G$ <0365.g1:G>`, so is :g:`$G$ <0365.g1:G>` to :g:`$L$ <0365.g1:L>` and :g:`$L$ <0365.g1:L>` to :g:`$B$ <0365.g1:B>`.

.. assertion::

   Therefore, as many numbers as have fallen between :g:`$A$ <0365.g1:A>`, :g:`$B$ <0365.g1:B>` in continued proportion, so many numbers also have fallen between each of the numbers :g:`$A$ <0365.g1:A>`, :g:`$B$ <0365.g1:B>` and the unit :g:`$E$ <0365.g1:E>` in continued proportion.

.. qed::

   :just:`Q. E. D.`

----

Suppose there are $n$ geometric means between $a$, $b$, two numbers prime to one another; there are the same number ($n$) of geometric means between $1$ and $a$ and between $1$ and $b$.

If $c, d\dots$ are the $n$ means between $a$, $b$,

$$a,\quad c,\quad d\dots b$$

are the least numbers in that ratio, since $a$, $b$ are prime to one another. :just:`[VIII. 1] <VIII.1>`

The terms are therefore respectively identical with

$$\alpha^{n+1},\quad \alpha^n\beta,\quad \alpha^{n-1}\beta^2\dots \alpha\beta^n,\quad \beta^{n+1},$$

where $\alpha$, $\beta$ is the common ratio in its lowest terms. :just:`[VIII. 2, Por.]`

Thus

$$a = \alpha^{n+1},\quad b = \beta^{n+1}.$$

Now

$$1 : \alpha = \alpha : \alpha^2 = \alpha^2 : \alpha^3 \dots = \alpha^n : \alpha^{n+1},$$

and

$$1 : \beta = \beta : \beta^2 = \beta^2 : \beta^3 \dots = \beta^n : \beta^{n+1};$$

whence there are $n$ geometric means between $1$, $a$, and between $1$, $b$.

----

PROPOSITION 10.
---------------

.. enunciation::

   If numbers fall between each of two numbers and an unit in continued proportion, however many numbers fall between each of them and an unit in continued proportion, so many also will fall between the numbers themselves in continued proportion.
