For let the numbers <span data-ref="0367.g1:D">$D$</span>, <span data-ref="0367.g1:E">$E$</span> and <span data-ref="0367.g1:F">$F$</span>, <span data-ref="0367.g1:G">$G$</span> respectively fall<br />
between the two numbers <span data-ref="0367.g1:A">$A$</span>, <span data-ref="0367.g1:B">$B$</span> and the unit <span data-ref="0367.g1:C">$C$</span> in continued<br />
proportion ;

I say that, as many numbers as have fallen between each of<br />
the numbers <span data-ref="0367.g1:A">$A$</span>, <span data-ref="0367.g1:B">$B$</span> and the unit <span data-ref="0367.g1:C">$C$</span> in continued proportion, so<br />
many numbers will also fall between <span data-ref="0367.g1:A">$A$</span>, <span data-ref="0367.g1:B">$B$</span> in continued pro-<br />
portion.

For let <span data-ref="0367.g1:D">$D$</span> by multiplying <span data-ref="0367.g1:F">$F$</span> make <span data-ref="0367.g1:H">$H$</span>, and let the numbers<br />
<span data-ref="0367.g1:D">$D$</span>, <span data-ref="0367.g1:F">$F$</span> by multiplying <span data-ref="0367.g1:H">$H$</span> make <span data-ref="0367.g1:K">$K$</span>, <span data-ref="0367.g1:L">$L$</span> respectively.

![Book VIII, Proposition 10](0367.g1.svg)

<p class="sub-clause">Now, since, as the unit <span data-ref="0367.g1:C">$C$</span> is to the number <span data-ref="0367.g1:D">$D$</span>, so is <span data-ref="0367.g1:D">$D$</span> to <span data-ref="0367.g1:E">$E$</span>,</p>
<p class="assertion">therefore the unit <span data-ref="0367.g1:C">$C$</span> measures the number <span data-ref="0367.g1:D">$D$</span> the same number<br />
of times as <span data-ref="0367.g1:D">$D$</span> measures <span data-ref="0367.g1:E">$E$</span>. <span class="justification">[VII. Def. 20]</span></p>

<p class="sub-clause">But the unit <span data-ref="0367.g1:C">$C$</span> measures the number <span data-ref="0367.g1:D">$D$</span> according to the<br />
units in <span data-ref="0367.g1:D">$D$</span>;</p>
<p class="assertion">therefore the number <span data-ref="0367.g1:D">$D$</span> also measures <span data-ref="0367.g1:E">$E$</span> according to the units<br />
in <span data-ref="0367.g1:D">$D$</span>;</p>
<p class="assertion">therefore <span data-ref="0367.g1:D">$D$</span> by multiplying itself has made <span data-ref="0367.g1:E">$E$</span>.</p>

<p class="sub-clause">Again, since, as <span data-ref="0367.g1:C">$C$</span> is to the number <span data-ref="0367.g1:D">$D$</span>, so is <span data-ref="0367.g1:E">$E$</span> to <span data-ref="0367.g1:A">$A$</span>,</p>
<p class="assertion">therefore the unit <span data-ref="0367.g1:C">$C$</span> measures the number <span data-ref="0367.g1:D">$D$</span> the same number<br />
of times as <span data-ref="0367.g1:E">$E$</span> measures <span data-ref="0367.g1:A">$A$</span>.</p>

<p class="sub-clause">But the unit <span data-ref="0367.g1:C">$C$</span> measures the number <span data-ref="0367.g1:D">$D$</span> according to the<br />
units in <span data-ref="0367.g1:D">$D$</span>;</p>
<p class="assertion">therefore <span data-ref="0367.g1:E">$E$</span> also measures <span data-ref="0367.g1:A">$A$</span> according to the units in <span data-ref="0367.g1:D">$D$</span>;</p>
<p class="assertion">therefore <span data-ref="0367.g1:D">$D$</span> by multiplying <span data-ref="0367.g1:E">$E$</span> has made <span data-ref="0367.g1:A">$A$</span>.</p>

<p class="sub-clause">For the same reason also</p>
<p class="assertion"><span data-ref="0367.g1:F">$F$</span> by multiplying itself has made <span data-ref="0367.g1:G">$G$</span>, and by multiplying <span data-ref="0367.g1:G">$G$</span> has<br />
made <span data-ref="0367.g1:B">$B$</span>.</p>

<p class="sub-clause">And, since <span data-ref="0367.g1:D">$D$</span> by multiplying itself has made <span data-ref="0367.g1:E">$E$</span> and by<br />
multiplying <span data-ref="0367.g1:F">$F$</span> has made <span data-ref="0367.g1:H">$H$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0367.g1:D">$D$</span> is to <span data-ref="0367.g1:F">$F$</span>, so is <span data-ref="0367.g1:E">$E$</span> to <span data-ref="0367.g1:H">$H$</span>. <span class="justification">[VII. 17]</span></p>
