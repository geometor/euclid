### PROPOSITION 11.

*Between two square numbers there is one mean proportional number, and the square has to the square the ratio duplicate of that which the side has to the side.*

Let <span data-ref="0369.g1:A">$A$</span>, <span data-ref="0369.g1:B">$B$</span> be square numbers, and let <span data-ref="0369.g1:C">$C$</span> be the side of <span data-ref="0369.g1:A">$A$</span>, and <span data-ref="0369.g1:D">$D$</span> of <span data-ref="0369.g1:B">$B$</span>;
I say that between <span data-ref="0369.g1:A">$A$</span>, <span data-ref="0369.g1:B">$B$</span> there is one mean proportional number, and <span data-ref="0369.g1:A">$A$</span> has to <span data-ref="0369.g1:B">$B$</span> the ratio duplicate of that which <span data-ref="0369.g1:C">$C$</span> has to <span data-ref="0369.g1:D">$D$</span>.

For let <span data-ref="0369.g1:C">$C$</span> by multiplying <span data-ref="0369.g1:D">$D$</span> make <span data-ref="0369.g1:E">$E$</span>.

![Book VIII, Proposition 11](0369.g1.svg)

Now, since <span data-ref="0369.g1:A">$A$</span> is a square and <span data-ref="0369.g1:C">$C$</span> is its side,
therefore <span data-ref="0369.g1:C">$C$</span> by multiplying itself has made <span data-ref="0369.g1:A">$A$</span>.

For the same reason also
<span data-ref="0369.g1:D">$D$</span> by multiplying itself has made <span data-ref="0369.g1:B">$B$</span>.

Since then <span data-ref="0369.g1:C">$C$</span> by multiplying the numbers <span data-ref="0369.g1:C">$C$</span>, <span data-ref="0369.g1:D">$D$</span> has made <span data-ref="0369.g1:A">$A$</span>, <span data-ref="0369.g1:E">$E$</span> respectively,
therefore, as <span data-ref="0369.g1:C">$C$</span> is to <span data-ref="0369.g1:D">$D$</span>, so is <span data-ref="0369.g1:A">$A$</span> to <span data-ref="0369.g1:E">$E$</span>. [VII. 17]

For the same reason also,
> as <span data-ref="0369.g1:C">$C$</span> is to <span data-ref="0369.g1:D">$D$</span>, so is <span data-ref="0369.g1:E">$E$</span> to <span data-ref="0369.g1:B">$B$</span>. [VII. 18]

Therefore also, as <span data-ref="0369.g1:A">$A$</span> is to <span data-ref="0369.g1:E">$E$</span>, so is <span data-ref="0369.g1:E">$E$</span> to <span data-ref="0369.g1:B">$B$</span>.

Therefore between <span data-ref="0369.g1:A">$A$</span>, <span data-ref="0369.g1:B">$B$</span> there is one mean proportional number.

I say next that <span data-ref="0369.g1:A">$A$</span> also has to <span data-ref="0369.g1:B">$B$</span> the ratio duplicate of that which <span data-ref="0369.g1:C">$C$</span> has to <span data-ref="0369.g1:D">$D$</span>.

For, since <span data-ref="0369.g1:A">$A$</span>, <span data-ref="0369.g1:E">$E$</span>, <span data-ref="0369.g1:B">$B$</span> are three numbers in proportion,
therefore <span data-ref="0369.g1:A">$A$</span> has to <span data-ref="0369.g1:B">$B$</span> the ratio duplicate of that which <span data-ref="0369.g1:A">$A$</span> has to <span data-ref="0369.g1:E">$E$</span>. [V. Def. 9]

But, as <span data-ref="0369.g1:A">$A$</span> is to <span data-ref="0369.g1:E">$E$</span>, so is <span data-ref="0369.g1:C">$C$</span> to <span data-ref="0369.g1:D">$D$</span>.

Therefore <span data-ref="0369.g1:A">$A$</span> has to <span data-ref="0369.g1:B">$B$</span> the ratio duplicate of that which the side <span data-ref="0369.g1:C">$C$</span> has to <span data-ref="0369.g1:D">$D$</span>.

<p align="right">Q. E. D.</p>

---

According to Nicomachus the theorems in this proposition and the next, that two squares have *one* geometric mean, and two cubes *two* geometric means, between them are Platonic. Cf. *Timaeus*, 32 A sqq. and the note thereon, p. 294 above.
