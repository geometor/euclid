Let there be as many numbers as we please, <span data-ref="0372.g1:A">$A$</span>, <span data-ref="0372.g1:B">$B$</span>, <span data-ref="0372.g1:C">$C$</span>, in continued proportion, so that, as <span data-ref="0372.g1:A">$A$</span> is to <span data-ref="0372.g1:B">$B$</span>, so is <span data-ref="0372.g1:B">$B$</span> to <span data-ref="0372.g1:C">$C$</span>;
let <span data-ref="0372.g1:A">$A$</span>, <span data-ref="0372.g1:B">$B$</span>, <span data-ref="0372.g1:C">$C$</span> by multiplying themselves make <span data-ref="0372.g1:D">$D$</span>, <span data-ref="0372.g1:E">$E$</span>, <span data-ref="0372.g1:F">$F$</span>, and by multiplying <span data-ref="0372.g1:D">$D$</span>, <span data-ref="0372.g1:E">$E$</span>, <span data-ref="0372.g1:F">$F$</span> let them make <span data-ref="0372.g1:G">$G$</span>, <span data-ref="0372.g1:H">$H$</span>, <span data-ref="0372.g1:K">$K$</span>;
I say that <span data-ref="0372.g1:D">$D$</span>, <span data-ref="0372.g1:E">$E$</span>, <span data-ref="0372.g1:F">$F$</span> and <span data-ref="0372.g1:G">$G$</span>, <span data-ref="0372.g1:H">$H$</span>, <span data-ref="0372.g1:K">$K$</span> are in continued proportion.

![Book VIII, Proposition 13](0372.g1.svg)

For let <span data-ref="0372.g1:A">$A$</span> by multiplying <span data-ref="0372.g1:B">$B$</span> make <span data-ref="0372.g1:L">$L$</span>,
and let the numbers <span data-ref="0372.g1:A">$A$</span>, <span data-ref="0372.g1:B">$B$</span> by multiplying <span data-ref="0372.g1:L">$L$</span> make <span data-ref="0372.g1:M">$M$</span>, <span data-ref="0372.g1:N">$N$</span> respectively.

And again let <span data-ref="0372.g1:B">$B$</span> by multiplying <span data-ref="0372.g1:C">$C$</span> make <span data-ref="0372.g1:O">$O$</span>,
and let the numbers <span data-ref="0372.g1:B">$B$</span>, <span data-ref="0372.g1:C">$C$</span> by multiplying <span data-ref="0372.g1:O">$O$</span> make <span data-ref="0372.g1:P">$P$</span>, <span data-ref="0372.g1:Q">$Q$</span> respectively.

Then, in manner similar to the foregoing, we can prove that
<span data-ref="0372.g1:D">$D$</span>, <span data-ref="0372.g1:L">$L$</span>, <span data-ref="0372.g1:E">$E$</span> and <span data-ref="0372.g1:G">$G$</span>, <span data-ref="0372.g1:M">$M$</span>, <span data-ref="0372.g1:N">$N$</span>, <span data-ref="0372.g1:H">$H$</span> are continuously proportional in the ratio of <span data-ref="0372.g1:A">$A$</span> to <span data-ref="0372.g1:B">$B$</span>,
and further <span data-ref="0372.g1:E">$E$</span>, <span data-ref="0372.g1:O">$O$</span>, <span data-ref="0372.g1:F">$F$</span> and <span data-ref="0372.g1:H">$H$</span>, <span data-ref="0372.g1:P">$P$</span>, <span data-ref="0372.g1:Q">$Q$</span>, <span data-ref="0372.g1:K">$K$</span> are continuously proportional in the ratio of <span data-ref="0372.g1:B">$B$</span> to <span data-ref="0372.g1:C">$C$</span>.

Now, as <span data-ref="0372.g1:A">$A$</span> is to <span data-ref="0372.g1:B">$B$</span>, so is <span data-ref="0372.g1:B">$B$</span> to <span data-ref="0372.g1:C">$C$</span>;
therefore <span data-ref="0372.g1:D">$D$</span>, <span data-ref="0372.g1:L">$L$</span>, <span data-ref="0372.g1:E">$E$</span> are also in the same ratio with <span data-ref="0372.g1:E">$E$</span>, <span data-ref="0372.g1:O">$O$</span>, <span data-ref="0372.g1:F">$F$</span>,
and further <span data-ref="0372.g1:G">$G$</span>, <span data-ref="0372.g1:M">$M$</span>, <span data-ref="0372.g1:N">$N$</span>, <span data-ref="0372.g1:H">$H$</span> in the same ratio with <span data-ref="0372.g1:H">$H$</span>, <span data-ref="0372.g1:P">$P$</span>, <span data-ref="0372.g1:Q">$Q$</span>, <span data-ref="0372.g1:K">$K$</span>.

And the multitude of <span data-ref="0372.g1:D">$D$</span>, <span data-ref="0372.g1:L">$L$</span>, <span data-ref="0372.g1:E">$E$</span> is equal to the multitude of <span data-ref="0372.g1:E">$E$</span>, <span data-ref="0372.g1:O">$O$</span>, <span data-ref="0372.g1:F">$F$</span>, and that of <span data-ref="0372.g1:G">$G$</span>, <span data-ref="0372.g1:M">$M$</span>, <span data-ref="0372.g1:N">$N$</span>, <span data-ref="0372.g1:H">$H$</span> to that of <span data-ref="0372.g1:H">$H$</span>, <span data-ref="0372.g1:P">$P$</span>, <span data-ref="0372.g1:Q">$Q$</span>, <span data-ref="0372.g1:K">$K$</span>;
therefore, *ex aequali*,
> as <span data-ref="0372.g1:D">$D$</span> is to <span data-ref="0372.g1:E">$E$</span>, so is <span data-ref="0372.g1:E">$E$</span> to <span data-ref="0372.g1:F">$F$</span>,
and, as <span data-ref="0372.g1:G">$G$</span> is to <span data-ref="0372.g1:H">$H$</span>, so is <span data-ref="0372.g1:H">$H$</span> to <span data-ref="0372.g1:K">$K$</span>. [VII. 14]
