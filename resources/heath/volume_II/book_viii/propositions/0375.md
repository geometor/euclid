For let <span data-ref="0375.g1:C">$C$</span> by multiplying itself make <span data-ref="0375.g1:E">$E$</span>,<br />
and let <span data-ref="0375.g1:D">$D$</span> by multiplying itself make <span data-ref="0375.g1:G">$G$</span>;<br />
further, let <span data-ref="0375.g1:C">$C$</span> by multiplying <span data-ref="0375.g1:D">$D$</span> make <span data-ref="0375.g1:F">$F$</span>,<br />
and let <span data-ref="0375.g1:C">$C$</span>, <span data-ref="0375.g1:D">$D$</span> by multiplying <span data-ref="0375.g1:F">$F$</span> make <span data-ref="0375.g1:H">$H$</span>, <span data-ref="0375.g1:K">$K$</span> respectively.

![Book VIII, Proposition 15](0375.g1.svg)

<p class="assertion">Now it is manifest that <span data-ref="0375.g1:E">$E$</span>, <span data-ref="0375.g1:F">$F$</span>, <span data-ref="0375.g1:G">$G$</span> and <span data-ref="0375.g1:A">$A$</span>, <span data-ref="0375.g1:H">$H$</span>, <span data-ref="0375.g1:K">$K$</span>, <span data-ref="0375.g1:B">$B$</span> are<br />
continuously proportional in the ratio of <span data-ref="0375.g1:C">$C$</span> to <span data-ref="0375.g1:D">$D$</span>. <span class="justification">[VIII. 11, 12]</span></p>

<p class="sub-clause">And, since <span data-ref="0375.g1:A">$A$</span>, <span data-ref="0375.g1:H">$H$</span>, <span data-ref="0375.g1:K">$K$</span>, <span data-ref="0375.g1:B">$B$</span> are continuously proportional,<br />
and <span data-ref="0375.g1:A">$A$</span> measures <span data-ref="0375.g1:B">$B$</span>,</p>
<p class="assertion">therefore it also measures <span data-ref="0375.g1:H">$H$</span>. <span class="justification">[VIII. 7]</span></p>

<p class="sub-clause">And, as <span data-ref="0375.g1:A">$A$</span> is to <span data-ref="0375.g1:H">$H$</span>, so is <span data-ref="0375.g1:C">$C$</span> to <span data-ref="0375.g1:D">$D$</span>;</p>
<p class="assertion">therefore <span data-ref="0375.g1:C">$C$</span> also measures <span data-ref="0375.g1:D">$D$</span>. <span class="justification">[VII. Def. 20]</span></p>

Next, let <span data-ref="0375.g1:C">$C$</span> measure <span data-ref="0375.g1:D">$D$</span>;<br />
I say that <span data-ref="0375.g1:A">$A$</span> will also measure <span data-ref="0375.g1:B">$B$</span>.

For, with the same construction, we can prove in a similar<br />
manner that <span data-ref="0375.g1:A">$A$</span>, <span data-ref="0375.g1:H">$H$</span>, <span data-ref="0375.g1:K">$K$</span>, <span data-ref="0375.g1:B">$B$</span> are continuously proportional in the<br />
ratio of <span data-ref="0375.g1:C">$C$</span> to <span data-ref="0375.g1:D">$D$</span>.

<p class="sub-clause">And, since <span data-ref="0375.g1:C">$C$</span> measures <span data-ref="0375.g1:D">$D$</span>,<br />
and, as <span data-ref="0375.g1:C">$C$</span> is to <span data-ref="0375.g1:D">$D$</span>, so is <span data-ref="0375.g1:A">$A$</span> to <span data-ref="0375.g1:H">$H$</span>,</p>
<p class="assertion">therefore <span data-ref="0375.g1:A">$A$</span> also measures <span data-ref="0375.g1:H">$H$</span>, <span class="justification">[VII. Def. 20]</span><br />
so that <span data-ref="0375.g1:A">$A$</span> measures <span data-ref="0375.g1:B">$B$</span> also.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

If $a^3$ measures $b^3$, $a$ measures $b$; and vice versa. The proof is, *mutatis<br />
mutandis*, the same as for squares.

(1) $a^3$, $a^2b$, $ab^2$, $b^3$ are continuously proportional in the ratio of $a$ to $b$;<br />
and $a^3$ measures $b^3$.

Therefore $a^3$ measures $a^2b$; <span class="justification">[VIII. 7]</span><br />
and hence $a$ measures $b$.

(2) Since $a$ measures $b$, $a^3$ measures $a^2b$.

And, $a^3$, $a^2b$, $ab^2$, $b^3$ being continuously proportional, each term measures the<br />
succeeding term;<br />
therefore $a^3$ measures $b^3$.
