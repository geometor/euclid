### PROPOSITION 16.

<p class="enunciation">If a square number do not measure a square number, neither<br />
will the side measure the side; and, if the side do not measure<br />
the side, neither will the square measure the square.</p>

Let <span data-ref="0376.g1:A">$A$</span>, <span data-ref="0376.g1:B">$B$</span> be square numbers, and let <span data-ref="0376.g1:C">$C$</span>, <span data-ref="0376.g1:D">$D$</span> be their sides;<br />
and let <span data-ref="0376.g1:A">$A$</span> not measure <span data-ref="0376.g1:B">$B$</span>;<br />
I say that neither does <span data-ref="0376.g1:C">$C$</span> measure <span data-ref="0376.g1:D">$D$</span>.

<p class="sub-clause">For, if <span data-ref="0376.g1:C">$C$</span> measures <span data-ref="0376.g1:D">$D$</span>, <span data-ref="0376.g1:A">$A$</span> will also<br />
measure <span data-ref="0376.g1:B">$B$</span>. <span class="justification">[VIII. 14]</span></p>

<p class="sub-clause">But <span data-ref="0376.g1:A">$A$</span> does not measure <span data-ref="0376.g1:B">$B$</span>;</p>

<p class="assertion">therefore neither will <span data-ref="0376.g1:C">$C$</span> measure <span data-ref="0376.g1:D">$D$</span>.</p>

![Book VIII, Proposition 16](0376.g1.svg)

Again, let <span data-ref="0376.g1:C">$C$</span> not measure <span data-ref="0376.g1:D">$D$</span>;<br />
I say that neither will <span data-ref="0376.g1:A">$A$</span> measure <span data-ref="0376.g1:B">$B$</span>.

<p class="sub-clause">For, if <span data-ref="0376.g1:A">$A$</span> measures <span data-ref="0376.g1:B">$B$</span>, <span data-ref="0376.g1:C">$C$</span> will also measure <span data-ref="0376.g1:D">$D$</span>. <span class="justification">[VIII. 14]</span></p>

<p class="sub-clause">But <span data-ref="0376.g1:C">$C$</span> does not measure <span data-ref="0376.g1:D">$D$</span>;</p>

<p class="assertion">therefore neither will <span data-ref="0376.g1:A">$A$</span> measure <span data-ref="0376.g1:B">$B$</span>.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

If $a^2$ does not measure $b^2$, $a$ will not measure $b$; and, if $a$ does not<br />
measure $b$, $a^2$ will not measure $b^2$.

The proof is a mere *reductio ad absurdum* using VIII. 14.

### PROPOSITION 17.

<p class="enunciation">If a cube number do not measure a cube number, neither<br />
will the side measure the side; and, if the side do not measure<br />
the side, neither will the cube measure the cube.</p>

For let the cube number <span data-ref="0376.g2:A">$A$</span> not measure the cube<br />
number <span data-ref="0376.g2:B">$B$</span>,<br />
and let <span data-ref="0376.g2:C">$C$</span> be the side of <span data-ref="0376.g2:A">$A$</span>, and <span data-ref="0376.g2:D">$D$</span><br />
of <span data-ref="0376.g2:B">$B$</span>;<br />
I say that <span data-ref="0376.g2:C">$C$</span> will not measure <span data-ref="0376.g2:D">$D$</span>.

<p class="sub-clause">For if <span data-ref="0376.g2:C">$C$</span> measures <span data-ref="0376.g2:D">$D$</span>, <span data-ref="0376.g2:A">$A$</span> will<br />
also measure <span data-ref="0376.g2:B">$B$</span>. <span class="justification">[VIII. 15]</span></p>

<p class="sub-clause">But <span data-ref="0376.g2:A">$A$</span> does not measure <span data-ref="0376.g2:B">$B$</span>;</p>

<p class="assertion">therefore neither does <span data-ref="0376.g2:C">$C$</span> measure <span data-ref="0376.g2:D">$D$</span>.</p>

![Book VIII, Proposition 17](0376.g2.svg)

Again, let <span data-ref="0376.g2:C">$C$</span> not measure <span data-ref="0376.g2:D">$D$</span>;<br />
I say that neither will <span data-ref="0376.g2:A">$A$</span> measure <span data-ref="0376.g2:B">$B$</span>.
