### PROPOSITION 16.

*If a square number do not measure a square number, neither will the side measure the side; and, if the side do not measure the side, neither will the square measure the square.*

Let <span data-ref="0376.g1:A">$A$</span>, <span data-ref="0376.g1:B">$B$</span> be square numbers, and let <span data-ref="0376.g1:C">$C$</span>, <span data-ref="0376.g1:D">$D$</span> be their sides; and let <span data-ref="0376.g1:A">$A$</span> not measure <span data-ref="0376.g1:B">$B$</span>; I say that neither does <span data-ref="0376.g1:C">$C$</span> measure <span data-ref="0376.g1:D">$D$</span>.

For, if <span data-ref="0376.g1:C">$C$</span> measures <span data-ref="0376.g1:D">$D$</span>, <span data-ref="0376.g1:A">$A$</span> will also measure <span data-ref="0376.g1:B">$B$</span>. [VIII. 14]

But <span data-ref="0376.g1:A">$A$</span> does not measure <span data-ref="0376.g1:B">$B$</span>; therefore neither will <span data-ref="0376.g1:C">$C$</span> measure <span data-ref="0376.g1:D">$D$</span>.

![Book VIII, Proposition 16](0376.g1.svg)

Again, let <span data-ref="0376.g1:C">$C$</span> not measure <span data-ref="0376.g1:D">$D$</span>; I say that neither will <span data-ref="0376.g1:A">$A$</span> measure <span data-ref="0376.g1:B">$B$</span>.

For, if <span data-ref="0376.g1:A">$A$</span> measures <span data-ref="0376.g1:B">$B$</span>, <span data-ref="0376.g1:C">$C$</span> will also measure <span data-ref="0376.g1:D">$D$</span>. [VIII. 14]

But <span data-ref="0376.g1:C">$C$</span> does not measure <span data-ref="0376.g1:D">$D$</span>; therefore neither will <span data-ref="0376.g1:A">$A$</span> measure <span data-ref="0376.g1:B">$B$</span>.

Q. E. D.

---

If $a^2$ does not measure $b^2$, $a$ will not measure $b$; and, if $a$ does not measure $b$, $a^2$ will not measure $b^2$.

The proof is a mere *reductio ad absurdum* using VIII. 14.

### PROPOSITION 17.

*If a cube number do not measure a cube number, neither will the side measure the side; and, if the side do not measure the side, neither will the cube measure the cube.*

For let the cube number <span data-ref="0376.g2:A">$A$</span> not measure the cube number <span data-ref="0376.g2:B">$B$</span>, and let <span data-ref="0376.g2:C">$C$</span> be the side of <span data-ref="0376.g2:A">$A$</span>, and <span data-ref="0376.g2:D">$D$</span> of <span data-ref="0376.g2:B">$B$</span>; I say that <span data-ref="0376.g2:C">$C$</span> will not measure <span data-ref="0376.g2:D">$D$</span>.

For if <span data-ref="0376.g2:C">$C$</span> measures <span data-ref="0376.g2:D">$D$</span>, <span data-ref="0376.g2:A">$A$</span> will also measure <span data-ref="0376.g2:B">$B$</span>. [VIII. 15]

But <span data-ref="0376.g2:A">$A$</span> does not measure <span data-ref="0376.g2:B">$B$</span>; therefore neither does <span data-ref="0376.g2:C">$C$</span> measure <span data-ref="0376.g2:D">$D$</span>.

Again, let <span data-ref="0376.g2:C">$C$</span> not measure <span data-ref="0376.g2:D">$D$</span>; I say that neither will <span data-ref="0376.g2:A">$A$</span> measure <span data-ref="0376.g2:B">$B$</span>.
