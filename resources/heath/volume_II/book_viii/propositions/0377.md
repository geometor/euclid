For, if <span data-ref="0376.g2:A">$A$</span> measures <span data-ref="0376.g2:B">$B$</span>, <span data-ref="0376.g2:C">$C$</span> will also measure <span data-ref="0376.g2:D">$D$</span>. [VIII. 15]

But <span data-ref="0376.g2:C">$C$</span> does not measure <span data-ref="0376.g2:D">$D$</span>; therefore neither will <span data-ref="0376.g2:A">$A$</span> measure <span data-ref="0376.g2:B">$B$</span>.

Q. E. D.

---

If $a^3$ does not measure $b^3$, $a$ will not measure $b$; and vice versa.

Proved by *reductio ad absurdum* employing VIII. 15.

### PROPOSITION 18.

*Between two similar plane numbers there is one mean proportional number; and the plane number has to the plane number the ratio duplicate of that which the corresponding side has to the corresponding side.*

Let <span data-ref="0377.g1:A">$A$</span>, <span data-ref="0377.g1:B">$B$</span> be two similar plane numbers, and let the numbers <span data-ref="0377.g1:C">$C$</span>, <span data-ref="0377.g1:D">$D$</span> be the sides of <span data-ref="0377.g1:A">$A$</span>, and <span data-ref="0377.g1:E">$E$</span>, <span data-ref="0377.g1:F">$F$</span> of <span data-ref="0377.g1:B">$B$</span>.

![Book VIII, Proposition 18](0377.g1.svg)

Now, since similar plane numbers are those which have their sides proportional, [VII. Def. 21] therefore, as <span data-ref="0377.g1:C">$C$</span> is to <span data-ref="0377.g1:D">$D$</span>, so is <span data-ref="0377.g1:E">$E$</span> to <span data-ref="0377.g1:F">$F$</span>.

I say then that between <span data-ref="0377.g1:A">$A$</span>, <span data-ref="0377.g1:B">$B$</span> there is one mean proportional number, and <span data-ref="0377.g1:A">$A$</span> has to <span data-ref="0377.g1:B">$B$</span> the ratio duplicate of that which <span data-ref="0377.g1:C">$C$</span> has to <span data-ref="0377.g1:E">$E$</span>, or <span data-ref="0377.g1:D">$D$</span> to <span data-ref="0377.g1:F">$F$</span>, that is, of that which the corresponding side has to the corresponding side.

Now since, as <span data-ref="0377.g1:C">$C$</span> is to <span data-ref="0377.g1:D">$D$</span>, so is <span data-ref="0377.g1:E">$E$</span> to <span data-ref="0377.g1:F">$F$</span>, therefore, alternately, as <span data-ref="0377.g1:C">$C$</span> is to <span data-ref="0377.g1:E">$E$</span>, so is <span data-ref="0377.g1:D">$D$</span> to <span data-ref="0377.g1:F">$F$</span>. [VII. 13]

And, since <span data-ref="0377.g1:A">$A$</span> is plane, and <span data-ref="0377.g1:C">$C$</span>, <span data-ref="0377.g1:D">$D$</span> are its sides, therefore <span data-ref="0377.g1:D">$D$</span> by multiplying <span data-ref="0377.g1:C">$C$</span> has made <span data-ref="0377.g1:A">$A$</span>.

For the same reason also <span data-ref="0377.g1:E">$E$</span> by multiplying <span data-ref="0377.g1:F">$F$</span> has made <span data-ref="0377.g1:B">$B$</span>.

Now let <span data-ref="0377.g1:D">$D$</span> by multiplying <span data-ref="0377.g1:E">$E$</span> make <span data-ref="0377.g1:G">$G$</span>.

Then, since <span data-ref="0377.g1:D">$D$</span> by multiplying <span data-ref="0377.g1:C">$C$</span> has made <span data-ref="0377.g1:A">$A$</span>, and by multiplying <span data-ref="0377.g1:E">$E$</span> has made <span data-ref="0377.g1:G">$G$</span>, therefore, as <span data-ref="0377.g1:C">$C$</span> is to <span data-ref="0377.g1:E">$E$</span>, so is <span data-ref="0377.g1:A">$A$</span> to <span data-ref="0377.g1:G">$G$</span>. [VII. 17]
