<p class="sub-clause">For, if <span data-ref="0376.g2:A">$A$</span> measures <span data-ref="0376.g2:B">$B$</span>, <span data-ref="0376.g2:C">$C$</span> will also measure <span data-ref="0376.g2:D">$D$</span>. <span class="justification">[VIII. 15]</span></p>

<p class="sub-clause">But <span data-ref="0376.g2:C">$C$</span> does not measure <span data-ref="0376.g2:D">$D$</span>;</p>

<p class="assertion">therefore neither will <span data-ref="0376.g2:A">$A$</span> measure <span data-ref="0376.g2:B">$B$</span>.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

If $a^3$ does not measure $b^3$, $a$ will not measure $b$; and vice versa.

Proved by *reductio ad absurdum* employing VIII. 15.

### PROPOSITION 18.

<p class="enunciation">Between two similar plane numbers there is one mean<br />
proportional number; and the plane number has to the plane<br />
number the ratio duplicate of that which the corresponding<br />
side has to the corresponding side.</p>

Let <span data-ref="0377.g1:A">$A$</span>, <span data-ref="0377.g1:B">$B$</span> be two similar plane numbers, and let the numbers<br />
<span data-ref="0377.g1:C">$C$</span>, <span data-ref="0377.g1:D">$D$</span> be the sides of <span data-ref="0377.g1:A">$A$</span>, and <span data-ref="0377.g1:E">$E$</span>, <span data-ref="0377.g1:F">$F$</span> of <span data-ref="0377.g1:B">$B$</span>.

![Book VIII, Proposition 18](0377.g1.svg)

<p class="sub-clause">Now, since similar plane numbers are those which have<br />
their sides proportional, <span class="justification">[VII. Def. 21]</span></p>
<p class="assertion">therefore, as <span data-ref="0377.g1:C">$C$</span> is to <span data-ref="0377.g1:D">$D$</span>, so is <span data-ref="0377.g1:E">$E$</span> to <span data-ref="0377.g1:F">$F$</span>.</p>

I say then that between <span data-ref="0377.g1:A">$A$</span>, <span data-ref="0377.g1:B">$B$</span> there is one mean propor-<br />
tional number, and <span data-ref="0377.g1:A">$A$</span> has to <span data-ref="0377.g1:B">$B$</span> the ratio duplicate of that<br />
which <span data-ref="0377.g1:C">$C$</span> has to <span data-ref="0377.g1:E">$E$</span>, or <span data-ref="0377.g1:D">$D$</span> to <span data-ref="0377.g1:F">$F$</span>, that is, of that which the corre-<br />
sponding side has to the corresponding side.

<p class="sub-clause">Now since, as <span data-ref="0377.g1:C">$C$</span> is to <span data-ref="0377.g1:D">$D$</span>, so is <span data-ref="0377.g1:E">$E$</span> to <span data-ref="0377.g1:F">$F$</span>,</p>
<p class="assertion">therefore, alternately, as <span data-ref="0377.g1:C">$C$</span> is to <span data-ref="0377.g1:E">$E$</span>, so is <span data-ref="0377.g1:D">$D$</span> to <span data-ref="0377.g1:F">$F$</span>. <span class="justification">[VII. 13]</span></p>

<p class="sub-clause">And, since <span data-ref="0377.g1:A">$A$</span> is plane, and <span data-ref="0377.g1:C">$C$</span>, <span data-ref="0377.g1:D">$D$</span> are its sides,</p>
<p class="assertion">therefore <span data-ref="0377.g1:D">$D$</span> by multiplying <span data-ref="0377.g1:C">$C$</span> has made <span data-ref="0377.g1:A">$A$</span>.</p>

<p class="sub-clause">For the same reason also</p>
<p class="assertion"><span data-ref="0377.g1:E">$E$</span> by multiplying <span data-ref="0377.g1:F">$F$</span> has made <span data-ref="0377.g1:B">$B$</span>.</p>

Now let <span data-ref="0377.g1:D">$D$</span> by multiplying <span data-ref="0377.g1:E">$E$</span> make <span data-ref="0377.g1:G">$G$</span>.

<p class="sub-clause">Then, since <span data-ref="0377.g1:D">$D$</span> by multiplying <span data-ref="0377.g1:C">$C$</span> has made <span data-ref="0377.g1:A">$A$</span>, and by<br />
multiplying <span data-ref="0377.g1:E">$E$</span> has made <span data-ref="0377.g1:G">$G$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0377.g1:C">$C$</span> is to <span data-ref="0377.g1:E">$E$</span>, so is <span data-ref="0377.g1:A">$A$</span> to <span data-ref="0377.g1:G">$G$</span>. <span class="justification">[VII. 17]</span></p>
