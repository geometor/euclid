### PROPOSITION 19.

<p class="enunciation">Between two similar solid numbers there fall two mean<br />
proportional numbers; and the solid number has to the similar<br />
solid number the ratio triplicate of that which the corresponding<br />
side has to the corresponding side.</p>

Let <span data-ref="0379.g1:A">$A$</span>, <span data-ref="0379.g1:B">$B$</span> be two similar solid numbers, and let <span data-ref="0379.g1:C">$C$</span>, <span data-ref="0379.g1:D">$D$</span>, <span data-ref="0379.g1:E">$E$</span><br />
be the sides of <span data-ref="0379.g1:A">$A$</span>, and <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:G">$G$</span>, <span data-ref="0379.g1:H">$H$</span> of <span data-ref="0379.g1:B">$B$</span>.

<p class="sub-clause">Now, since similar solid numbers are those which have<br />
their sides proportional, <span class="justification">[VII. Def. 21]</span></p>
<p class="assertion">therefore, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:D">$D$</span>, so is <span data-ref="0379.g1:F">$F$</span> to <span data-ref="0379.g1:G">$G$</span>,<br />
and, as <span data-ref="0379.g1:D">$D$</span> is to <span data-ref="0379.g1:E">$E$</span>, so is <span data-ref="0379.g1:G">$G$</span> to <span data-ref="0379.g1:H">$H$</span>.</p>

I say that between <span data-ref="0379.g1:A">$A$</span>, <span data-ref="0379.g1:B">$B$</span> there fall two mean proportional<br />
numbers, and <span data-ref="0379.g1:A">$A$</span> has to <span data-ref="0379.g1:B">$B$</span> the ratio triplicate of that which <span data-ref="0379.g1:C">$C$</span><br />
has to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and also <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>.

![Book VIII, Proposition 19](0379.g1.svg)

For let <span data-ref="0379.g1:C">$C$</span> by multiplying <span data-ref="0379.g1:D">$D$</span> make <span data-ref="0379.g1:K">$K$</span>, and let <span data-ref="0379.g1:F">$F$</span> by<br />
multiplying <span data-ref="0379.g1:G">$G$</span> make <span data-ref="0379.g1:L">$L$</span>.

<p class="sub-clause">Now, since <span data-ref="0379.g1:C">$C$</span>, <span data-ref="0379.g1:D">$D$</span> are in the same ratio with <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:G">$G$</span>,<br />
and <span data-ref="0379.g1:K">$K$</span> is the product of <span data-ref="0379.g1:C">$C$</span>, <span data-ref="0379.g1:D">$D$</span>, and <span data-ref="0379.g1:L">$L$</span> the product of <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:G">$G$</span>,<br />
<span data-ref="0379.g1:K">$K$</span>, <span data-ref="0379.g1:L">$L$</span> are similar plane numbers; <span class="justification">[VII. Def. 21]</span></p>
<p class="assertion">therefore between <span data-ref="0379.g1:K">$K$</span>, <span data-ref="0379.g1:L">$L$</span> there is one mean proportional number.<br />
<span class="justification">[VIII. 18]</span></p>

Let it be <span data-ref="0379.g1:M">$M$</span>.

<p class="assertion">Therefore <span data-ref="0379.g1:M">$M$</span> is the product of <span data-ref="0379.g1:D">$D$</span>, <span data-ref="0379.g1:F">$F$</span>, as was proved in the<br />
theorem preceding this. <span class="justification">[VIII. 18]</span></p>

<p class="sub-clause">Now, since <span data-ref="0379.g1:D">$D$</span> by multiplying <span data-ref="0379.g1:C">$C$</span> has made <span data-ref="0379.g1:K">$K$</span>, and by<br />
multiplying <span data-ref="0379.g1:F">$F$</span> has made <span data-ref="0379.g1:M">$M$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:F">$F$</span>, so is <span data-ref="0379.g1:K">$K$</span> to <span data-ref="0379.g1:M">$M$</span>. <span class="justification">[VII. 17]</span></p>

<p class="sub-clause">But, as <span data-ref="0379.g1:K">$K$</span> is to <span data-ref="0379.g1:M">$M$</span>, so is <span data-ref="0379.g1:M">$M$</span> to <span data-ref="0379.g1:L">$L$</span>.</p>

<p class="assertion">Therefore <span data-ref="0379.g1:K">$K$</span>, <span data-ref="0379.g1:M">$M$</span>, <span data-ref="0379.g1:L">$L$</span> are continuously proportional in the<br />
ratio of <span data-ref="0379.g1:C">$C$</span> to <span data-ref="0379.g1:F">$F$</span>.</p>
