And since, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:D">$D$</span>, so is <span data-ref="0379.g1:F">$F$</span> to <span data-ref="0379.g1:G">$G$</span>, alternately therefore, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:F">$F$</span>, so is <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>. [VII. 13]

For the same reason also, as <span data-ref="0379.g1:D">$D$</span> is to <span data-ref="0379.g1:G">$G$</span>, so is <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>.

Therefore <span data-ref="0379.g1:K">$K$</span>, <span data-ref="0379.g1:M">$M$</span>, <span data-ref="0379.g1:L">$L$</span> are continuously proportional in the ratio of <span data-ref="0379.g1:C">$C$</span> to <span data-ref="0379.g1:F">$F$</span>, in the ratio of <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and also in the ratio of <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>.

Next, let <span data-ref="0379.g1:E">$E$</span>, <span data-ref="0379.g1:H">$H$</span> by multiplying <span data-ref="0379.g1:M">$M$</span> make <span data-ref="0379.g1:N">$N$</span>, <span data-ref="0379.g1:O">$O$</span> respectively.

Now, since <span data-ref="0379.g1:A">$A$</span> is a solid number, and <span data-ref="0379.g1:C">$C$</span>, <span data-ref="0379.g1:D">$D$</span>, <span data-ref="0379.g1:E">$E$</span> are its sides, therefore <span data-ref="0379.g1:E">$E$</span> by multiplying the product of <span data-ref="0379.g1:C">$C$</span>, <span data-ref="0379.g1:D">$D$</span> has made <span data-ref="0379.g1:A">$A$</span>.

But the product of <span data-ref="0379.g1:C">$C$</span>, <span data-ref="0379.g1:D">$D$</span> is <span data-ref="0379.g1:K">$K$</span>; therefore <span data-ref="0379.g1:E">$E$</span> by multiplying <span data-ref="0379.g1:K">$K$</span> has made <span data-ref="0379.g1:A">$A$</span>.

For the same reason also <span data-ref="0379.g1:H">$H$</span> by multiplying <span data-ref="0379.g1:L">$L$</span> has made <span data-ref="0379.g1:B">$B$</span>.

Now, since <span data-ref="0379.g1:E">$E$</span> by multiplying <span data-ref="0379.g1:K">$K$</span> has made <span data-ref="0379.g1:A">$A$</span>, and further also by multiplying <span data-ref="0379.g1:M">$M$</span> has made <span data-ref="0379.g1:N">$N$</span>, therefore, as <span data-ref="0379.g1:K">$K$</span> is to <span data-ref="0379.g1:M">$M$</span>, so is <span data-ref="0379.g1:A">$A$</span> to <span data-ref="0379.g1:N">$N$</span>. [VII. 17]

But, as <span data-ref="0379.g1:K">$K$</span> is to <span data-ref="0379.g1:M">$M$</span>, so is <span data-ref="0379.g1:C">$C$</span> to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and also <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>; therefore also, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>, so is <span data-ref="0379.g1:A">$A$</span> to <span data-ref="0379.g1:N">$N$</span>.

Again, since <span data-ref="0379.g1:E">$E$</span>, <span data-ref="0379.g1:H">$H$</span> by multiplying <span data-ref="0379.g1:M">$M$</span> have made <span data-ref="0379.g1:N">$N$</span>, <span data-ref="0379.g1:O">$O$</span> respectively, therefore, as <span data-ref="0379.g1:E">$E$</span> is to <span data-ref="0379.g1:H">$H$</span>, so is <span data-ref="0379.g1:N">$N$</span> to <span data-ref="0379.g1:O">$O$</span>. [VII. 18]

But, as <span data-ref="0379.g1:E">$E$</span> is to <span data-ref="0379.g1:H">$H$</span>, so is <span data-ref="0379.g1:C">$C$</span> to <span data-ref="0379.g1:F">$F$</span> and <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>; therefore also, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>, so is <span data-ref="0379.g1:A">$A$</span> to <span data-ref="0379.g1:N">$N$</span> and <span data-ref="0379.g1:N">$N$</span> to <span data-ref="0379.g1:O">$O$</span>.

Again, since <span data-ref="0379.g1:H">$H$</span> by multiplying <span data-ref="0379.g1:M">$M$</span> has made <span data-ref="0379.g1:O">$O$</span>, and further also by multiplying <span data-ref="0379.g1:L">$L$</span> has made <span data-ref="0379.g1:B">$B$</span>, therefore, as <span data-ref="0379.g1:M">$M$</span> is to <span data-ref="0379.g1:L">$L$</span>, so is <span data-ref="0379.g1:O">$O$</span> to <span data-ref="0379.g1:B">$B$</span>. [VII. 17]

But, as <span data-ref="0379.g1:M">$M$</span> is to <span data-ref="0379.g1:L">$L$</span>, so is <span data-ref="0379.g1:C">$C$</span> to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>.

Therefore also, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>, so not only is <span data-ref="0379.g1:O">$O$</span> to <span data-ref="0379.g1:B">$B$</span>, but also <span data-ref="0379.g1:A">$A$</span> to <span data-ref="0379.g1:N">$N$</span> and <span data-ref="0379.g1:N">$N$</span> to <span data-ref="0379.g1:O">$O$</span>.

Therefore <span data-ref="0379.g1:A">$A$</span>, <span data-ref="0379.g1:N">$N$</span>, <span data-ref="0379.g1:O">$O$</span>, <span data-ref="0379.g1:B">$B$</span> are continuously proportional in the aforesaid ratios of the sides.

I say that <span data-ref="0379.g1:A">$A$</span> also has to <span data-ref="0379.g1:B">$B$</span> the ratio triplicate of that which the corresponding side has to the corresponding side, that is, of the ratio which the number <span data-ref="0379.g1:C">$C$</span> has to <span data-ref="0379.g1:F">$F$</span>, or <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and also <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>.
