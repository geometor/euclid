<p class="sub-clause">And since, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:D">$D$</span>, so is <span data-ref="0379.g1:F">$F$</span> to <span data-ref="0379.g1:G">$G$</span>,</p>
<p class="assertion">alternately therefore, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:F">$F$</span>, so is <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>. <span class="justification">[VII. 13]</span></p>

<p class="sub-clause">For the same reason also,</p>
<p class="assertion">as <span data-ref="0379.g1:D">$D$</span> is to <span data-ref="0379.g1:G">$G$</span>, so is <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>.</p>

<p class="assertion">Therefore <span data-ref="0379.g1:K">$K$</span>, <span data-ref="0379.g1:M">$M$</span>, <span data-ref="0379.g1:L">$L$</span> are continuously proportional in the<br />
ratio of <span data-ref="0379.g1:C">$C$</span> to <span data-ref="0379.g1:F">$F$</span>, in the ratio of <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and also in the ratio<br />
of <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>.</p>

Next, let <span data-ref="0379.g1:E">$E$</span>, <span data-ref="0379.g1:H">$H$</span> by multiplying <span data-ref="0379.g1:M">$M$</span> make <span data-ref="0379.g1:N">$N$</span>, <span data-ref="0379.g1:O">$O$</span> respectively.

<p class="sub-clause">Now, since <span data-ref="0379.g1:A">$A$</span> is a solid number, and <span data-ref="0379.g1:C">$C$</span>, <span data-ref="0379.g1:D">$D$</span>, <span data-ref="0379.g1:E">$E$</span> are its sides,</p>
<p class="assertion">therefore <span data-ref="0379.g1:E">$E$</span> by multiplying the product of <span data-ref="0379.g1:C">$C$</span>, <span data-ref="0379.g1:D">$D$</span> has made <span data-ref="0379.g1:A">$A$</span>.</p>

<p class="sub-clause">But the product of <span data-ref="0379.g1:C">$C$</span>, <span data-ref="0379.g1:D">$D$</span> is <span data-ref="0379.g1:K">$K$</span>;</p>
<p class="assertion">therefore <span data-ref="0379.g1:E">$E$</span> by multiplying <span data-ref="0379.g1:K">$K$</span> has made <span data-ref="0379.g1:A">$A$</span>.</p>

<p class="sub-clause">For the same reason also</p>
<p class="assertion"><span data-ref="0379.g1:H">$H$</span> by multiplying <span data-ref="0379.g1:L">$L$</span> has made <span data-ref="0379.g1:B">$B$</span>.</p>

<p class="sub-clause">Now, since <span data-ref="0379.g1:E">$E$</span> by multiplying <span data-ref="0379.g1:K">$K$</span> has made <span data-ref="0379.g1:A">$A$</span>, and further<br />
also by multiplying <span data-ref="0379.g1:M">$M$</span> has made <span data-ref="0379.g1:N">$N$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0379.g1:K">$K$</span> is to <span data-ref="0379.g1:M">$M$</span>, so is <span data-ref="0379.g1:A">$A$</span> to <span data-ref="0379.g1:N">$N$</span>. <span class="justification">[VII. 17]</span></p>

<p class="sub-clause">But, as <span data-ref="0379.g1:K">$K$</span> is to <span data-ref="0379.g1:M">$M$</span>, so is <span data-ref="0379.g1:C">$C$</span> to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and also <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>;</p>
<p class="assertion">therefore also, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>, so is <span data-ref="0379.g1:A">$A$</span> to <span data-ref="0379.g1:N">$N$</span>.</p>

<p class="sub-clause">Again, since <span data-ref="0379.g1:E">$E$</span>, <span data-ref="0379.g1:H">$H$</span> by multiplying <span data-ref="0379.g1:M">$M$</span> have made <span data-ref="0379.g1:N">$N$</span>, <span data-ref="0379.g1:O">$O$</span><br />
respectively,</p>
<p class="assertion">therefore, as <span data-ref="0379.g1:E">$E$</span> is to <span data-ref="0379.g1:H">$H$</span>, so is <span data-ref="0379.g1:N">$N$</span> to <span data-ref="0379.g1:O">$O$</span>. <span class="justification">[VII. 18]</span></p>

<p class="sub-clause">But, as <span data-ref="0379.g1:E">$E$</span> is to <span data-ref="0379.g1:H">$H$</span>, so is <span data-ref="0379.g1:C">$C$</span> to <span data-ref="0379.g1:F">$F$</span> and <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>;</p>
<p class="assertion">therefore also, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>, so is <span data-ref="0379.g1:A">$A$</span> to<br />
<span data-ref="0379.g1:N">$N$</span> and <span data-ref="0379.g1:N">$N$</span> to <span data-ref="0379.g1:O">$O$</span>.</p>

<p class="sub-clause">Again, since <span data-ref="0379.g1:H">$H$</span> by multiplying <span data-ref="0379.g1:M">$M$</span> has made <span data-ref="0379.g1:O">$O$</span>, and further<br />
also by multiplying <span data-ref="0379.g1:L">$L$</span> has made <span data-ref="0379.g1:B">$B$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0379.g1:M">$M$</span> is to <span data-ref="0379.g1:L">$L$</span>, so is <span data-ref="0379.g1:O">$O$</span> to <span data-ref="0379.g1:B">$B$</span>. <span class="justification">[VII. 17]</span></p>

<p class="sub-clause">But, as <span data-ref="0379.g1:M">$M$</span> is to <span data-ref="0379.g1:L">$L$</span>, so is <span data-ref="0379.g1:C">$C$</span> to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>.</p>

<p class="assertion">Therefore also, as <span data-ref="0379.g1:C">$C$</span> is to <span data-ref="0379.g1:F">$F$</span>, <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>, so not<br />
only is <span data-ref="0379.g1:O">$O$</span> to <span data-ref="0379.g1:B">$B$</span>, but also <span data-ref="0379.g1:A">$A$</span> to <span data-ref="0379.g1:N">$N$</span> and <span data-ref="0379.g1:N">$N$</span> to <span data-ref="0379.g1:O">$O$</span>.</p>

<p class="assertion">Therefore <span data-ref="0379.g1:A">$A$</span>, <span data-ref="0379.g1:N">$N$</span>, <span data-ref="0379.g1:O">$O$</span>, <span data-ref="0379.g1:B">$B$</span> are continuously proportional in the<br />
aforesaid ratios of the sides.</p>

I say that <span data-ref="0379.g1:A">$A$</span> also has to <span data-ref="0379.g1:B">$B$</span> the ratio triplicate of that which<br />
the corresponding side has to the corresponding side, that is,<br />
of the ratio which the number <span data-ref="0379.g1:C">$C$</span> has to <span data-ref="0379.g1:F">$F$</span>, or <span data-ref="0379.g1:D">$D$</span> to <span data-ref="0379.g1:G">$G$</span>, and<br />
also <span data-ref="0379.g1:E">$E$</span> to <span data-ref="0379.g1:H">$H$</span>.
