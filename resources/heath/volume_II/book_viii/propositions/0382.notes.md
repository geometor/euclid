- **Textual Criticism / Daggers**:
  - Heath marks lines 25–27 with obeli/daggers (`†`) indicating ancient textual corruption. As Heath explains in note `[^376_1]`, the deduction that $D : E = A : C$ is redundant (it was already in the hypothesis), while the crucial step that $F \times E = C$ is asserted without proof. Heath provides the elegant emendation.
- **Algebraic Representation**:
  - If $a : c = c : b = \alpha : \beta$ in lowest terms, then $a = m\alpha, c = m\beta$ and $c = n\alpha, b = n\beta$. Thus $a = m\alpha$ and $b = n\beta$, with sides $m, \alpha$ and $n, \beta$ proportional because $m\beta = n\alpha \implies m : n = \alpha : \beta$.
