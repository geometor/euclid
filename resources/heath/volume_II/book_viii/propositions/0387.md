For, since <span data-ref="0387.g1:C">$C$</span>, <span data-ref="0387.g1:D">$D$</span> are cube,
<span data-ref="0387.g1:C">$C$</span>, <span data-ref="0387.g1:D">$D$</span> are similar solid numbers.
Therefore two mean proportional numbers fall between <span data-ref="0387.g1:C">$C$</span>, <span data-ref="0387.g1:D">$D$</span>. [VIII. 19]

![Proposition 25](0387.g1.svg)

And, as many numbers as fall between <span data-ref="0387.g1:C">$C$</span>, <span data-ref="0387.g1:D">$D$</span> in continued proportion, so many will also fall between those which have the same ratio with them; [VIII. 8]
so that two mean proportional numbers fall between <span data-ref="0387.g1:A">$A$</span>, <span data-ref="0387.g1:B">$B$</span> also.
Let <span data-ref="0387.g1:E">$E$</span>, <span data-ref="0387.g1:F">$F$</span> so fall.
Since, then, the four numbers <span data-ref="0387.g1:A">$A$</span>, <span data-ref="0387.g1:E">$E$</span>, <span data-ref="0387.g1:F">$F$</span>, <span data-ref="0387.g1:B">$B$</span> are in continued proportion,
and <span data-ref="0387.g1:A">$A$</span> is cube,
therefore <span data-ref="0387.g1:B">$B$</span> is also cube. [VIII. 23]
Q. E. D.

If $a : b = c^3 : d^3$, and $a$ is a cube, then $b$ is also a cube.
For $c^3, d^3$ have two mean proportionals. [VIII. 19]
Therefore $a, b$ also have two mean proportionals. [VIII. 8]
And $a$ is a cube:
therefore $b$ is a cube. [VIII. 23]

### PROPOSITION 26.

*Similar plane numbers have to one another the ratio which a square number has to a square number.*

Let <span data-ref="0387.g2:A">$A$</span>, <span data-ref="0387.g2:B">$B$</span> be similar plane numbers;
I say that <span data-ref="0387.g2:A">$A$</span> has to <span data-ref="0387.g2:B">$B$</span> the ratio which a square number has to a square number.

![Proposition 26](0387.g2.svg)

For, since <span data-ref="0387.g2:A">$A$</span>, <span data-ref="0387.g2:B">$B$</span> are similar plane numbers,
therefore one mean proportional number falls between <span data-ref="0387.g2:A">$A$</span>, <span data-ref="0387.g2:B">$B$</span>. [VIII. 18]
