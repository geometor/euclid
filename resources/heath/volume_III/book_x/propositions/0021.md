### PROPOSITION 2.

*If, when the less of two unequal magnitudes is continually subtracted in turn from the greater, that which is left never measures the one before it, the magnitudes will be incommensurable.*

For, there being two unequal magnitudes <span data-ref="0021.g1:/ A B /">$AB$</span>, <span data-ref="0021.g1:/ C D /">$CD$</span>, and <span data-ref="0021.g1:/ A B /">$AB$</span> being the less, when the less is continually subtracted in turn from the greater, let that which is left over never measure the one before it;
I say that the magnitudes <span data-ref="0021.g1:/ A B /">$AB$</span>, <span data-ref="0021.g1:/ C D /">$CD$</span> are incommensurable.

![Book X, Proposition 2](0021.g1.svg)

For, if they are commensurable, some magnitude will measure them.
Let a magnitude measure them, if possible, and let it be <span data-ref="0021.g1:E">$E$</span>;
let <span data-ref="0021.g1:/ A B /">$AB$</span>, measuring <span data-ref="0021.g1:/ F D /">$FD$</span>, leave <span data-ref="0021.g1:/ C F /">$CF$</span> less than itself,
let <span data-ref="0021.g1:/ C F /">$CF$</span> measuring <span data-ref="0021.g1:/ B G /">$BG$</span>, leave <span data-ref="0021.g1:/ A G /">$AG$</span> less than itself,
and let this process be repeated continually, until there is left some magnitude which is less than <span data-ref="0021.g1:E">$E$</span>.

Suppose this done, and let there be left <span data-ref="0021.g1:/ A G /">$AG$</span> less than <span data-ref="0021.g1:E">$E$</span>.

Then, since <span data-ref="0021.g1:E">$E$</span> measures <span data-ref="0021.g1:/ A B /">$AB$</span>,
while <span data-ref="0021.g1:/ A B /">$AB$</span> measures <span data-ref="0021.g1:/ D F /">$DF$</span>,
therefore <span data-ref="0021.g1:E">$E$</span> will also measure <span data-ref="0021.g1:/ F D /">$FD$</span>.
But it measures the whole <span data-ref="0021.g1:/ C D /">$CD$</span> also;
therefore it will also measure the remainder <span data-ref="0021.g1:/ C F /">$CF$</span>.
But <span data-ref="0021.g1:/ C F /">$CF$</span> measures <span data-ref="0021.g1:/ B G /">$BG$</span>;
therefore <span data-ref="0021.g1:E">$E$</span> also measures <span data-ref="0021.g1:/ B G /">$BG$</span>.
But it measures the whole <span data-ref="0021.g1:/ A B /">$AB$</span> also;
therefore it will also measure the remainder <span data-ref="0021.g1:/ A G /">$AG$</span>, the greater the less :
which is impossible.

Therefore no magnitude will measure the magnitudes <span data-ref="0021.g1:/ A B /">$AB$</span>, <span data-ref="0021.g1:/ C D /">$CD$</span>;
therefore the magnitudes <span data-ref="0021.g1:/ A B /">$AB$</span>, <span data-ref="0021.g1:/ C D /">$CD$</span> are incommensurable.
