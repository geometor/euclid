### PROPOSITION 3.

*Given two commensurable magnitudes, to find their greatest common measure.*

Let the two given commensurable magnitudes be <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span> of which <span data-ref="0024.g1:/ A B /">$AB$</span> is the less;
thus it is required to find the greatest common measure of <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span>.

Now the magnitude <span data-ref="0024.g1:/ A B /">$AB$</span> either measures <span data-ref="0024.g1:/ C D /">$CD$</span> or it does not.

If then it measures it—and it measures itself also—<span data-ref="0024.g1:/ A B /">$AB$</span> is a common measure of <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span>.

And it is manifest that it is also the greatest;
for a greater magnitude than the magnitude <span data-ref="0024.g1:/ A B /">$AB$</span> will not measure <span data-ref="0024.g1:/ A B /">$AB$</span>.

![Book X, Proposition 3](0024.g1.svg)

Next, let <span data-ref="0024.g1:/ A B /">$AB$</span> not measure <span data-ref="0024.g1:/ C D /">$CD$</span>.
Then, if the less be continually subtracted in turn from the greater, that which is left over will sometime measure the one before it, because <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span> are not incommensurable;
[cf. x. 2]
let <span data-ref="0024.g1:/ A B /">$AB$</span>, measuring <span data-ref="0024.g1:/ E D /">$ED$</span>, leave <span data-ref="0024.g1:/ E C /">$EC$</span> less than itself,
let <span data-ref="0024.g1:/ E C /">$EC$</span>, measuring <span data-ref="0024.g1:/ F B /">$FB$</span>, leave <span data-ref="0024.g1:/ A F /">$AF$</span> less than itself,
and let <span data-ref="0024.g1:/ A F /">$AF$</span> measure <span data-ref="0024.g1:/ C E /">$CE$</span>.

Since, then, <span data-ref="0024.g1:/ A F /">$AF$</span> measures <span data-ref="0024.g1:/ C E /">$CE$</span>,
while <span data-ref="0024.g1:/ C E /">$CE$</span> measures <span data-ref="0024.g1:/ F B /">$FB$</span>,
therefore <span data-ref="0024.g1:/ A F /">$AF$</span> will also measure <span data-ref="0024.g1:/ F B /">$FB$</span>.
But it measures itself also;
therefore <span data-ref="0024.g1:/ A F /">$AF$</span> will also measure the whole <span data-ref="0024.g1:/ A B /">$AB$</span>.
