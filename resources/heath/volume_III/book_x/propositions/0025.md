<p class="sub-clause">But <span data-ref="0024.g1:/ A B /">$AB$</span> measures <span data-ref="0024.g1:/ D E /">$DE$</span> ;</p>
<p class="assertion">therefore <span data-ref="0024.g1:/ A F /">$AF$</span> will also measure <span data-ref="0024.g1:/ E D /">$ED$</span>.</p>

<p class="sub-clause">But it measures <span data-ref="0024.g1:/ C E /">$CE$</span> also ;</p>
<p class="assertion">therefore it also measures the whole <span data-ref="0024.g1:/ C D /">$CD$</span>.</p>

<p class="assertion">Therefore <span data-ref="0024.g1:/ A F /">$AF$</span> is a common measure of <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span>.</p>

I say next that it is also the greatest.

For, if not, there will be some magnitude greater than <span data-ref="0024.g1:/ A F /">$AF$</span><br />
which will measure <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span>.<br />
Let it be <span data-ref="0024.g1:G">$G$</span>.

<p class="sub-clause">Since then <span data-ref="0024.g1:G">$G$</span> measures <span data-ref="0024.g1:/ A B /">$AB$</span>,<br />
while <span data-ref="0024.g1:/ A B /">$AB$</span> measures <span data-ref="0024.g1:/ E D /">$ED$</span>,</p>
<p class="assertion">therefore <span data-ref="0024.g1:G">$G$</span> will also measure <span data-ref="0024.g1:/ E D /">$ED$</span>.</p>

<p class="sub-clause">But it measures the whole <span data-ref="0024.g1:/ C D /">$CD$</span> also ;</p>
<p class="assertion">therefore <span data-ref="0024.g1:G">$G$</span> will also measure the remainder <span data-ref="0024.g1:/ C E /">$CE$</span>.</p>

<p class="sub-clause">But <span data-ref="0024.g1:/ C E /">$CE$</span> measures <span data-ref="0024.g1:/ F B /">$FB$</span> ;</p>
<p class="assertion">therefore <span data-ref="0024.g1:G">$G$</span> will also measure <span data-ref="0024.g1:/ F B /">$FB$</span>.</p>

<p class="sub-clause">But it measures the whole <span data-ref="0024.g1:/ A B /">$AB$</span> also,</p>
<p class="assertion">and it will therefore measure the remainder <span data-ref="0024.g1:/ A F /">$AF$</span>, the greater<br />
the less :<br />
which is impossible.</p>

<p class="assertion">Therefore no magnitude greater than <span data-ref="0024.g1:/ A F /">$AF$</span> will measure<br />
<span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span> ;<br />
therefore <span data-ref="0024.g1:/ A F /">$AF$</span> is the greatest common measure of <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span>.</p>

<p class="qed">Therefore the greatest common measure of the two given<br />
commensurable magnitudes <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span> has been found.<span class="justification">Q. E. D.</span></p>

<p class="assertion">PORISM. From this it is manifest that, if a magnitude<br />
measure two magnitudes, it will also measure their greatest<br />
common measure.</p>

This proposition for two commensurable magnitudes is, *mutatis mutandis*,<br />
exactly the same as VII. 2 for numbers. We have the process

$$
\begin{array}{l}
b )\, a \,( p \\
\underline{\phantom{b )\,} pb\phantom{ )\,}} \\
\phantom{b )\,} c )\, b \,( q \\
\phantom{b )\,} \underline{\phantom{c )\,} qc\phantom{ )\,}} \\
\phantom{b )\, \phantom{c )\,}} d )\, c \,( r \\
\phantom{b )\, \phantom{c )\,}} \underline{\phantom{d )\,} rd\phantom{ )\,}}
\end{array}
$$
