But <span data-ref="0024.g1:/ A B /">$AB$</span> measures <span data-ref="0024.g1:/ D E /">$DE$</span>;
therefore <span data-ref="0024.g1:/ A F /">$AF$</span> will also measure <span data-ref="0024.g1:/ E D /">$ED$</span>.

But it measures <span data-ref="0024.g1:/ C E /">$CE$</span> also;
therefore it also measures the whole <span data-ref="0024.g1:/ C D /">$CD$</span>.

Therefore <span data-ref="0024.g1:/ A F /">$AF$</span> is a common measure of <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span>.

I say next that it is also the greatest.

For, if not, there will be some magnitude greater than <span data-ref="0024.g1:/ A F /">$AF$</span> which will measure <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span>.

Let it be <span data-ref="0024.g1:G">$G$</span>.

Since then <span data-ref="0024.g1:G">$G$</span> measures <span data-ref="0024.g1:/ A B /">$AB$</span>,
while <span data-ref="0024.g1:/ A B /">$AB$</span> measures <span data-ref="0024.g1:/ E D /">$ED$</span>,
therefore <span data-ref="0024.g1:G">$G$</span> will also measure <span data-ref="0024.g1:/ E D /">$ED$</span>.

But it measures the whole <span data-ref="0024.g1:/ C D /">$CD$</span> also;
therefore <span data-ref="0024.g1:G">$G$</span> will also measure the remainder <span data-ref="0024.g1:/ C E /">$CE$</span>.

But <span data-ref="0024.g1:/ C E /">$CE$</span> measures <span data-ref="0024.g1:/ F B /">$FB$</span>;
therefore <span data-ref="0024.g1:G">$G$</span> will also measure <span data-ref="0024.g1:/ F B /">$FB$</span>.

But it measures the whole <span data-ref="0024.g1:/ A B /">$AB$</span> also,
and it will therefore measure the remainder <span data-ref="0024.g1:/ A F /">$AF$</span>, the greater the less:
which is impossible.

Therefore no magnitude greater than <span data-ref="0024.g1:/ A F /">$AF$</span> will measure <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span>;
therefore <span data-ref="0024.g1:/ A F /">$AF$</span> is the greatest common measure of <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span>.

Therefore the greatest common measure of the two given commensurable magnitudes <span data-ref="0024.g1:/ A B /">$AB$</span>, <span data-ref="0024.g1:/ C D /">$CD$</span> has been found.

<p align="right">Q. E. D.</p>

**PORISM.** _From this it is manifest that, if a magnitude measure two magnitudes, it will also measure their greatest common measure._

---

This proposition for two commensurable magnitudes is, _mutatis mutandis_, exactly the same as VII. 2 for numbers. We have the process

$$
\begin{array}{l}
b )\, a \,( p \\
\underline{\phantom{b )\,} pb\phantom{ )\,}} \\
\phantom{b )\,} c )\, b \,( q \\
\phantom{b )\,} \underline{\phantom{c )\,} qc\phantom{ )\,}} \\
\phantom{b )\, \phantom{c )\,}} d )\, c \,( r \\
\phantom{b )\, \phantom{c )\,}} \underline{\phantom{d )\,} rd\phantom{ )\,}}
\end{array}
$$
