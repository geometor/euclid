.. subclause::

   But :g:`$AB$ <0024.g1:/ A B />` measures :g:`$DE$ <0024.g1:/ D E />` ;

.. assertion::

   therefore :g:`$AF$ <0024.g1:/ A F />` will also measure :g:`$ED$ <0024.g1:/ E D />`.

.. subclause::

   But it measures :g:`$CE$ <0024.g1:/ C E />` also ;

.. assertion::

   therefore it also measures the whole :g:`$CD$ <0024.g1:/ C D />`.

.. assertion::

   Therefore :g:`$AF$ <0024.g1:/ A F />` is a common measure of :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />`.

I say next that it is also the greatest.

For, if not, there will be some magnitude greater than :g:`$AF$ <0024.g1:/ A F />` which will measure :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />`. Let it be :g:`$G$ <0024.g1:G>`.

.. subclause::

   Since then :g:`$G$ <0024.g1:G>` measures :g:`$AB$ <0024.g1:/ A B />`, while :g:`$AB$ <0024.g1:/ A B />` measures :g:`$ED$ <0024.g1:/ E D />`,

.. assertion::

   therefore :g:`$G$ <0024.g1:G>` will also measure :g:`$ED$ <0024.g1:/ E D />`.

.. subclause::

   But it measures the whole :g:`$CD$ <0024.g1:/ C D />` also ;

.. assertion::

   therefore :g:`$G$ <0024.g1:G>` will also measure the remainder :g:`$CE$ <0024.g1:/ C E />`.

.. subclause::

   But :g:`$CE$ <0024.g1:/ C E />` measures :g:`$FB$ <0024.g1:/ F B />` ;

.. assertion::

   therefore :g:`$G$ <0024.g1:G>` will also measure :g:`$FB$ <0024.g1:/ F B />`.

.. subclause::

   But it measures the whole :g:`$AB$ <0024.g1:/ A B />` also,

.. assertion::

   and it will therefore measure the remainder :g:`$AF$ <0024.g1:/ A F />`, the greater the less : which is impossible.

.. assertion::

   Therefore no magnitude greater than :g:`$AF$ <0024.g1:/ A F />` will measure :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />` ; therefore :g:`$AF$ <0024.g1:/ A F />` is the greatest common measure of :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />`.

.. qed::

   Therefore the greatest common measure of the two given commensurable magnitudes :g:`$AB$ <0024.g1:/ A B />`, :g:`$CD$ <0024.g1:/ C D />` has been found. :just:`Q. E. D.`

.. assertion::

   PORISM. From this it is manifest that, if a magnitude measure two magnitudes, it will also measure their greatest common measure.

----

This proposition for two commensurable magnitudes is, *mutatis mutandis*, exactly the same as VII. 2 for numbers. We have the process

$$
\begin{array}{l}
b )\, a \,( p \\
\underline{\phantom{b )\,} pb\phantom{ )\,}} \\
\phantom{b )\,} c )\, b \,( q \\
\phantom{b )\,} \underline{\phantom{c )\,} qc\phantom{ )\,}} \\
\phantom{b )\, \phantom{c )\,}} d )\, c \,( r \\
\phantom{b )\, \phantom{c )\,}} \underline{\phantom{d )\,} rd\phantom{ )\,}}
\end{array}
$$

where $c$ is equal to $rd$ and therefore there is no remainder,
