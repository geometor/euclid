The process of finding the greatest common measure is probably given in this Book, not only for the sake of completeness, but because in X. 5 a common measure of two magnitudes <span data-ref="0028.g1:A">$A$</span>, <span data-ref="0028.g1:B">$B$</span> is assumed and used, and therefore it is important to show that such a measure can be _found_ if not already known.

### PROPOSITION 4.

_Given three commensurable magnitudes, to find their greatest common measure._

Let <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span> be the three given commensurable magnitudes; thus it is required to find the greatest common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>.

![Proposition 4 diagram](0026.g1.svg)

Let the greatest common measure of the two magnitudes <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span> be taken, and let it be <span data-ref="0026.g1:D">$D$</span>; <span style="float: right;">[X. 3]</span>  
then <span data-ref="0026.g1:D">$D$</span> either measures <span data-ref="0026.g1:C">$C$</span>, or does not measure it.

First, let it measure it.

Since then <span data-ref="0026.g1:D">$D$</span> measures <span data-ref="0026.g1:C">$C$</span>,  
while it also measures <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>,  
therefore <span data-ref="0026.g1:D">$D$</span> is a common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>.

And it is manifest that it is also the greatest;  
for a greater magnitude than the magnitude <span data-ref="0026.g1:D">$D$</span> does not measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>.

Next, let <span data-ref="0026.g1:D">$D$</span> not measure <span data-ref="0026.g1:C">$C$</span>.

I say first that <span data-ref="0026.g1:C">$C$</span>, <span data-ref="0026.g1:D">$D$</span> are commensurable.

For, since <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span> are commensurable,  
some magnitude will measure them,  
and this will of course measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span> also;  
so that it will also measure the greatest common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, namely <span data-ref="0026.g1:D">$D$</span>. <span style="float: right;">[X. 3, Por.]</span>

But it also measures <span data-ref="0026.g1:C">$C$</span>;  
so that the said magnitude will measure <span data-ref="0026.g1:C">$C$</span>, <span data-ref="0026.g1:D">$D$</span>;  
therefore <span data-ref="0026.g1:C">$C$</span>, <span data-ref="0026.g1:D">$D$</span> are commensurable.
