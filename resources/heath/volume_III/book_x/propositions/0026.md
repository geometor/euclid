### PROPOSITION 4.

<p class="enunciation">Given three commensurable magnitudes, to find their greatest<br />
common measure.</p>

Let <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span> be the three given commensurable magnitudes ;<br />
thus it is required to find the greatest<br />
common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>.

![Proposition 4 diagram](0026.g1.svg)

Let the greatest common measure<br />
of the two magnitudes <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span> be taken,<br />
and let it be <span data-ref="0026.g1:D">$D$</span> ; <span class="justification">[X. 3]</span><br />
then <span data-ref="0026.g1:D">$D$</span> either measures <span data-ref="0026.g1:C">$C$</span>, or does<br />
not measure it.

First, let it measure it.

<p class="sub-clause">Since then <span data-ref="0026.g1:D">$D$</span> measures <span data-ref="0026.g1:C">$C$</span>,<br />
while it also measures <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>,</p>
<p class="assertion">therefore <span data-ref="0026.g1:D">$D$</span> is a common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>.</p>

<p class="assertion">And it is manifest that it is also the greatest ;<br />
for a greater magnitude than the magnitude <span data-ref="0026.g1:D">$D$</span> does not<br />
measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>.</p>

Next, let <span data-ref="0026.g1:D">$D$</span> not measure <span data-ref="0026.g1:C">$C$</span>.

I say first that <span data-ref="0026.g1:C">$C$</span>, <span data-ref="0026.g1:D">$D$</span> are commensurable.

<p class="sub-clause">For, since <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span> are commensurable,<br />
some magnitude will measure them,<br />
and this will of course measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span> also ;</p>
<p class="assertion">so that it will also measure the greatest common measure of<br />
<span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, namely <span data-ref="0026.g1:D">$D$</span>. <span class="justification">[X. 3, Por.]</span></p>

<p class="sub-clause">But it also measures <span data-ref="0026.g1:C">$C$</span> ;</p>
<p class="assertion">so that the said magnitude will measure <span data-ref="0026.g1:C">$C$</span>, <span data-ref="0026.g1:D">$D$</span> ;<br />
therefore <span data-ref="0026.g1:C">$C$</span>, <span data-ref="0026.g1:D">$D$</span> are commensurable.</p>
