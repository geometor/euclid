Now let their greatest common measure be taken, and let<br />
it be <span data-ref="0026.g1:E">$E$</span>. <span class="justification">[X. 3]</span>

<p class="sub-clause">Since then <span data-ref="0026.g1:E">$E$</span> measures <span data-ref="0026.g1:D">$D$</span>,<br />
while <span data-ref="0026.g1:D">$D$</span> measures <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>,</p>
<p class="assertion">therefore <span data-ref="0026.g1:E">$E$</span> will also measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>.</p>

<p class="sub-clause">But it measures <span data-ref="0026.g1:C">$C$</span> also ;</p>
<p class="assertion">therefore <span data-ref="0026.g1:E">$E$</span> measures <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span> ;<br />
therefore <span data-ref="0026.g1:E">$E$</span> is a common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>.</p>

I say next that it is also the greatest.

For, if possible, let there be some magnitude <span data-ref="0026.g1:F">$F$</span> greater than<br />
<span data-ref="0026.g1:E">$E$</span>, and let it measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>.

<p class="sub-clause">Now, since <span data-ref="0026.g1:F">$F$</span> measures <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>,<br />
it will also measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>,<br />
and will measure the greatest common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>. <span class="justification">[X. 3, Por.]</span></p>

<p class="sub-clause">But the greatest common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span> is <span data-ref="0026.g1:D">$D$</span> ;</p>
<p class="assertion">therefore <span data-ref="0026.g1:F">$F$</span> measures <span data-ref="0026.g1:D">$D$</span>.</p>

<p class="sub-clause">But it measures <span data-ref="0026.g1:C">$C$</span> also ;</p>
<p class="assertion">therefore <span data-ref="0026.g1:F">$F$</span> measures <span data-ref="0026.g1:C">$C$</span>, <span data-ref="0026.g1:D">$D$</span> ;<br />
therefore <span data-ref="0026.g1:F">$F$</span> will also measure the greatest common measure<br />
of <span data-ref="0026.g1:C">$C$</span>, <span data-ref="0026.g1:D">$D$</span>. <span class="justification">[X. 3, Por.]</span></p>

<p class="sub-clause">But that is <span data-ref="0026.g1:E">$E$</span> ;</p>
<p class="assertion">therefore <span data-ref="0026.g1:F">$F$</span> will measure <span data-ref="0026.g1:E">$E$</span>, the greater the less :<br />
which is impossible.</p>

<p class="assertion">Therefore no magnitude greater than the magnitude <span data-ref="0026.g1:E">$E$</span><br />
will measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span> ;<br />
therefore <span data-ref="0026.g1:E">$E$</span> is the greatest common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span> if <span data-ref="0026.g1:D">$D$</span><br />
do not measure <span data-ref="0026.g1:C">$C$</span>,<br />
and, if it measure it, <span data-ref="0026.g1:D">$D$</span> is itself the greatest common measure.</p>

<p class="assertion">Therefore the greatest common measure of the three given<br />
commensurable magnitudes has been found.</p>

<p class="assertion">PORISM. From this it is manifest that, if a magnitude<br />
measure three magnitudes, it will also measure their greatest<br />
common measure.</p>

<p class="qed">Similarly too, with more magnitudes, the greatest common<br />
measure can be found, and the porism can be extended.<span class="justification">Q. E. D.</span></p>
