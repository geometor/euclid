Now let their greatest common measure be taken, and let it be <span data-ref="0026.g1:E">$E$</span>. <span style="float: right;">[X. 3]</span>

Since then <span data-ref="0026.g1:E">$E$</span> measures <span data-ref="0026.g1:D">$D$</span>,  
while <span data-ref="0026.g1:D">$D$</span> measures <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>,  
therefore <span data-ref="0026.g1:E">$E$</span> will also measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>.

But it measures <span data-ref="0026.g1:C">$C$</span> also;  
therefore <span data-ref="0026.g1:E">$E$</span> measures <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>;  
therefore <span data-ref="0026.g1:E">$E$</span> is a common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>.

I say next that it is also the greatest.

For, if possible, let there be some magnitude <span data-ref="0026.g1:F">$F$</span> greater than <span data-ref="0026.g1:E">$E$</span>, and let it measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>.

Now, since <span data-ref="0026.g1:F">$F$</span> measures <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>,  
it will also measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>,  
and will measure the greatest common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>. <span style="float: right;">[X. 3, Por.]</span>

But the greatest common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span> is <span data-ref="0026.g1:D">$D$</span>;  
therefore <span data-ref="0026.g1:F">$F$</span> measures <span data-ref="0026.g1:D">$D$</span>.

But it measures <span data-ref="0026.g1:C">$C$</span> also;  
therefore <span data-ref="0026.g1:F">$F$</span> measures <span data-ref="0026.g1:C">$C$</span>, <span data-ref="0026.g1:D">$D$</span>;  
therefore <span data-ref="0026.g1:F">$F$</span> will also measure the greatest common measure of <span data-ref="0026.g1:C">$C$</span>, <span data-ref="0026.g1:D">$D$</span>. <span style="float: right;">[X. 3, Por.]</span>

But that is <span data-ref="0026.g1:E">$E$</span>;  
therefore <span data-ref="0026.g1:F">$F$</span> will measure <span data-ref="0026.g1:E">$E$</span>, the greater the less:  
which is impossible.

Therefore no magnitude greater than the magnitude <span data-ref="0026.g1:E">$E$</span> will measure <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span>;  
therefore <span data-ref="0026.g1:E">$E$</span> is the greatest common measure of <span data-ref="0026.g1:A">$A$</span>, <span data-ref="0026.g1:B">$B$</span>, <span data-ref="0026.g1:C">$C$</span> if <span data-ref="0026.g1:D">$D$</span> do not measure <span data-ref="0026.g1:C">$C$</span>,  
and, if it measure it, <span data-ref="0026.g1:D">$D$</span> is itself the greatest common measure.

Therefore the greatest common measure of the three given commensurable magnitudes has been found.

<p align="right">Q. E. D.</p>

**PORISM.** _From this it is manifest that, if a magnitude measure three magnitudes, it will also measure their greatest common measure._

Similarly too, with more magnitudes, the greatest common measure can be found, and the porism can be extended.

<p align="right">Q. E. D.</p>
