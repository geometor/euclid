### PROPOSITION 6.

_If two magnitudes have to one another the ratio which a number has to a number, the magnitudes will be commensurable._

For let the two magnitudes <span data-ref="0030.g1:A">$A$</span>, <span data-ref="0030.g1:B">$B$</span> have to one another the ratio which the number <span data-ref="0030.g1:D">$D$</span> has to the number <span data-ref="0030.g1:E">$E$</span>;  
<sup>5</sup> I say that the magnitudes <span data-ref="0030.g1:A">$A$</span>, <span data-ref="0030.g1:B">$B$</span> are commensurable.

![Proposition 6 diagram](0030.g1.svg)

For let <span data-ref="0030.g1:A">$A$</span> be divided into as many equal parts as there are units in <span data-ref="0030.g1:D">$D$</span>,  
and let <span data-ref="0030.g1:C">$C$</span> be equal to one of them;  
and let <span data-ref="0030.g1:F">$F$</span> be made up of as many magnitudes equal to <span data-ref="0030.g1:C">$C$</span> as  
<sup>10</sup> there are units in <span data-ref="0030.g1:E">$E$</span>.

Since then there are in <span data-ref="0030.g1:A">$A$</span> as many magnitudes equal to <span data-ref="0030.g1:C">$C$</span> as there are units in <span data-ref="0030.g1:D">$D$</span>,  
whatever part the unit is of <span data-ref="0030.g1:D">$D$</span>, the same part is <span data-ref="0030.g1:C">$C$</span> of <span data-ref="0030.g1:A">$A$</span> also;  
therefore, as <span data-ref="0030.g1:C">$C$</span> is to <span data-ref="0030.g1:A">$A$</span>, so is the unit to <span data-ref="0030.g1:D">$D$</span>. <span style="float: right;">[VII. Def. 20]</span>  
<sup>15</sup> But the unit measures the number <span data-ref="0030.g1:D">$D$</span>;  
therefore <span data-ref="0030.g1:C">$C$</span> also measures <span data-ref="0030.g1:A">$A$</span>.[^27_1]

And since, as <span data-ref="0030.g1:C">$C$</span> is to <span data-ref="0030.g1:A">$A$</span>, so is the unit to <span data-ref="0030.g1:D">$D$</span>,  
therefore, inversely, as <span data-ref="0030.g1:A">$A$</span> is to <span data-ref="0030.g1:C">$C$</span>, so is the number <span data-ref="0030.g1:D">$D$</span> to the unit. <span style="float: right;">[cf. V. 7, Por.]</span>

<sup>20</sup> Again, since there are in <span data-ref="0030.g1:F">$F$</span> as many magnitudes equal to <span data-ref="0030.g1:C">$C$</span> as there are units in <span data-ref="0030.g1:E">$E$</span>,  
therefore, as <span data-ref="0030.g1:C">$C$</span> is to <span data-ref="0030.g1:F">$F$</span>, so is the unit to <span data-ref="0030.g1:E">$E$</span>. <span style="float: right;">[VII. Def. 20]</span>

But it was also proved that,  
as <span data-ref="0030.g1:A">$A$</span> is to <span data-ref="0030.g1:C">$C$</span>, so is <span data-ref="0030.g1:D">$D$</span> to the unit;  
<sup>25</sup> therefore, _ex aequali_, as <span data-ref="0030.g1:A">$A$</span> is to <span data-ref="0030.g1:F">$F$</span>, so is <span data-ref="0030.g1:D">$D$</span> to <span data-ref="0030.g1:E">$E$</span>. <span style="float: right;">[V. 22]</span>

But, as <span data-ref="0030.g1:D">$D$</span> is to <span data-ref="0030.g1:E">$E$</span>, so is <span data-ref="0030.g1:A">$A$</span> to <span data-ref="0030.g1:B">$B$</span>;  
therefore also, as <span data-ref="0030.g1:A">$A$</span> is to <span data-ref="0030.g1:B">$B$</span>, so is it to <span data-ref="0030.g1:F">$F$</span> also. <span style="float: right;">[V. 11]</span>

Therefore <span data-ref="0030.g1:A">$A$</span> has the same ratio to each of the magnitudes <span data-ref="0030.g1:B">$B$</span>, <span data-ref="0030.g1:F">$F$</span>;  
<sup>30</sup> therefore <span data-ref="0030.g1:B">$B$</span> is equal to <span data-ref="0030.g1:F">$F$</span>. <span style="float: right;">[V. 9]</span>

But <span data-ref="0030.g1:C">$C$</span> measures <span data-ref="0030.g1:F">$F$</span>;  
therefore it measures <span data-ref="0030.g1:B">$B$</span> also.

Further it measures <span data-ref="0030.g1:A">$A$</span> also;  
therefore <span data-ref="0030.g1:C">$C$</span> measures <span data-ref="0030.g1:A">$A$</span>, <span data-ref="0030.g1:B">$B$</span>.
