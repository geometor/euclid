### PROPOSITION 6.

<p class="enunciation">If two magnitudes have to one another the ratio which a<br />
number has to a number, the magnitudes will be commensurable.</p>

For let the two magnitudes <span data-ref="0030.g1:A">$A$</span>, <span data-ref="0030.g1:B">$B$</span> have to one another the<br />
ratio which the number <span data-ref="0030.g1:D">$D$</span> has to the number <span data-ref="0030.g1:E">$E$</span>;<br />
<sup>5</sup> I say that the magnitudes <span data-ref="0030.g1:A">$A$</span>, <span data-ref="0030.g1:B">$B$</span> are commensurable.

![Proposition 6 diagram](0030.g1.svg)

For let <span data-ref="0030.g1:A">$A$</span> be divided into as many equal parts as there<br />
are units in <span data-ref="0030.g1:D">$D$</span>,<br />
and let <span data-ref="0030.g1:C">$C$</span> be equal to one of them;<br />
and let <span data-ref="0030.g1:F">$F$</span> be made up of as many magnitudes equal to <span data-ref="0030.g1:C">$C$</span> as<br />
<sup>10</sup> there are units in <span data-ref="0030.g1:E">$E$</span>.

<p class="sub-clause">Since then there are in <span data-ref="0030.g1:A">$A$</span> as many magnitudes equal to <span data-ref="0030.g1:C">$C$</span><br />
as there are units in <span data-ref="0030.g1:D">$D$</span>,<br />
whatever part the unit is of <span data-ref="0030.g1:D">$D$</span>, the same part is <span data-ref="0030.g1:C">$C$</span> of <span data-ref="0030.g1:A">$A$</span> also;</p>
<p class="assertion">therefore, as <span data-ref="0030.g1:C">$C$</span> is to <span data-ref="0030.g1:A">$A$</span>, so is the unit to <span data-ref="0030.g1:D">$D$</span>. <span class="justification">[VII. Def. 20]</span></p>

<p class="sub-clause"><sup>15</sup> But the unit measures the number <span data-ref="0030.g1:D">$D$</span>;</p>
<p class="assertion">therefore <span data-ref="0030.g1:C">$C$</span> also measures <span data-ref="0030.g1:A">$A$</span>.[^27_1]</p>

<p class="sub-clause">And since, as <span data-ref="0030.g1:C">$C$</span> is to <span data-ref="0030.g1:A">$A$</span>, so is the unit to <span data-ref="0030.g1:D">$D$</span>,</p>
<p class="assertion">therefore, inversely, as <span data-ref="0030.g1:A">$A$</span> is to <span data-ref="0030.g1:C">$C$</span>, so is the number <span data-ref="0030.g1:D">$D$</span> to the<br />
unit. <span class="justification">[cf. V. 7, Por.]</span></p>

<p class="sub-clause"><sup>20</sup> Again, since there are in <span data-ref="0030.g1:F">$F$</span> as many magnitudes equal<br />
to <span data-ref="0030.g1:C">$C$</span> as there are units in <span data-ref="0030.g1:E">$E$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0030.g1:C">$C$</span> is to <span data-ref="0030.g1:F">$F$</span>, so is the unit to <span data-ref="0030.g1:E">$E$</span>. <span class="justification">[VII. Def. 20]</span></p>

<p class="sub-clause">But it was also proved that,<br />
as <span data-ref="0030.g1:A">$A$</span> is to <span data-ref="0030.g1:C">$C$</span>, so is <span data-ref="0030.g1:D">$D$</span> to the unit;</p>
<p class="assertion"><sup>25</sup> therefore, <em>ex aequali</em>, as <span data-ref="0030.g1:A">$A$</span> is to <span data-ref="0030.g1:F">$F$</span>, so is <span data-ref="0030.g1:D">$D$</span> to <span data-ref="0030.g1:E">$E$</span>. <span class="justification">[V. 22]</span></p>

<p class="sub-clause">But, as <span data-ref="0030.g1:D">$D$</span> is to <span data-ref="0030.g1:E">$E$</span>, so is <span data-ref="0030.g1:A">$A$</span> to <span data-ref="0030.g1:B">$B$</span>;</p>
<p class="assertion">therefore also, as <span data-ref="0030.g1:A">$A$</span> is to <span data-ref="0030.g1:B">$B$</span>, so is it to <span data-ref="0030.g1:F">$F$</span> also. <span class="justification">[V. 11]</span></p>

<p class="assertion">Therefore <span data-ref="0030.g1:A">$A$</span> has the same ratio to each of the magnitudes<br />
<span data-ref="0030.g1:B">$B$</span>, <span data-ref="0030.g1:F">$F$</span>;</p>
<p class="assertion"><sup>30</sup> therefore <span data-ref="0030.g1:B">$B$</span> is equal to <span data-ref="0030.g1:F">$F$</span>. <span class="justification">[V. 9]</span></p>

<p class="sub-clause">But <span data-ref="0030.g1:C">$C$</span> measures <span data-ref="0030.g1:F">$F$</span>;</p>
<p class="assertion">therefore it measures <span data-ref="0030.g1:B">$B$</span> also.</p>

<p class="sub-clause">Further it measures <span data-ref="0030.g1:A">$A$</span> also;</p>
<p class="assertion">therefore <span data-ref="0030.g1:C">$C$</span> measures <span data-ref="0030.g1:A">$A$</span>, <span data-ref="0030.g1:B">$B$</span>.</p>
