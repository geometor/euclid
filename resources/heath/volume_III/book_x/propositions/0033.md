For let <span data-ref="0033.g1:A">$A$</span>, <span data-ref="0033.g1:B">$B$</span> be commensurable in length;
I say that the square on <span data-ref="0033.g1:A">$A$</span> has to the square on <span data-ref="0033.g1:B">$B$</span> the ratio which a square number has to a square number.

![Proposition 9 diagram](0033.g1.svg)

For, since <span data-ref="0033.g1:A">$A$</span> is commensurable in length with <span data-ref="0033.g1:B">$B$</span>,
therefore <span data-ref="0033.g1:A">$A$</span> has to <span data-ref="0033.g1:B">$B$</span> the ratio which a number has to a number.
<span style="float: right;">[x. 5]</span>

Let it have to it the ratio which <span data-ref="0033.g1:C">$C$</span> has to <span data-ref="0033.g1:D">$D$</span>.
Since then, as <span data-ref="0033.g1:A">$A$</span> is to <span data-ref="0033.g1:B">$B$</span>, so is <span data-ref="0033.g1:C">$C$</span> to <span data-ref="0033.g1:D">$D$</span>,
while the ratio of the square on <span data-ref="0033.g1:A">$A$</span> to the square on <span data-ref="0033.g1:B">$B$</span> is duplicate of the ratio of <span data-ref="0033.g1:A">$A$</span> to <span data-ref="0033.g1:B">$B$</span>,
for similar figures are in the duplicate ratio of their corresponding sides;
<span style="float: right;">[VI. 20, Por.]</span>
and the ratio of the square on <span data-ref="0033.g1:C">$C$</span> to the square on <span data-ref="0033.g1:D">$D$</span> is duplicate of the ratio of <span data-ref="0033.g1:C">$C$</span> to <span data-ref="0033.g1:D">$D$</span>,
for between two square numbers there is one mean proportional number, and the square number has to the square number the ratio duplicate of that which the side has to the side;
<span style="float: right;">[VIII. 11]</span>
therefore also, as the square on <span data-ref="0033.g1:A">$A$</span> is to the square on <span data-ref="0033.g1:B">$B$</span>, so is the square on <span data-ref="0033.g1:C">$C$</span> to the square on <span data-ref="0033.g1:D">$D$</span>.

Next, as the square on <span data-ref="0033.g1:A">$A$</span> is to the square on <span data-ref="0033.g1:B">$B$</span>, so let the square on <span data-ref="0033.g1:C">$C$</span> be to the square on <span data-ref="0033.g1:D">$D$</span>;
I say that <span data-ref="0033.g1:A">$A$</span> is commensurable in length with <span data-ref="0033.g1:B">$B$</span>.

For since, as the square on <span data-ref="0033.g1:A">$A$</span> is to the square on <span data-ref="0033.g1:B">$B$</span>, so is the square on <span data-ref="0033.g1:C">$C$</span> to the square on <span data-ref="0033.g1:D">$D$</span>,
while the ratio of the square on <span data-ref="0033.g1:A">$A$</span> to the square on <span data-ref="0033.g1:B">$B$</span> is duplicate of the ratio of <span data-ref="0033.g1:A">$A$</span> to <span data-ref="0033.g1:B">$B$</span>,
and the ratio of the square on <span data-ref="0033.g1:C">$C$</span> to the square on <span data-ref="0033.g1:D">$D$</span> is duplicate of the ratio of <span data-ref="0033.g1:C">$C$</span> to <span data-ref="0033.g1:D">$D$</span>,
therefore also, as <span data-ref="0033.g1:A">$A$</span> is to <span data-ref="0033.g1:B">$B$</span>, so is <span data-ref="0033.g1:C">$C$</span> to <span data-ref="0033.g1:D">$D$</span>.

Therefore <span data-ref="0033.g1:A">$A$</span> has to <span data-ref="0033.g1:B">$B$</span> the ratio which the number <span data-ref="0033.g1:C">$C$</span> has to the number <span data-ref="0033.g1:D">$D$</span>;
therefore <span data-ref="0033.g1:A">$A$</span> is commensurable in length with <span data-ref="0033.g1:B">$B$</span>.
<span style="float: right;">[x. 6]</span>

Next, let <span data-ref="0033.g1:A">$A$</span> be incommensurable in length with <span data-ref="0033.g1:B">$B$</span>;
I say that the square on <span data-ref="0033.g1:A">$A$</span> has not to the square on <span data-ref="0033.g1:B">$B$</span> the ratio which a square number has to a square number.
