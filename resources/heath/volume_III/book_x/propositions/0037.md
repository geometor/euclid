### PROPOSITION 11.

<p class="enunciation">If four magnitudes be proportional, and the first be com-<br />
mensurable with the second, the third will also be commensurable<br />
with the fourth ; and, if the first be incommensurable with the<br />
second, the third will also be incommensurable with the fourth.</p>

Let <span data-ref="0037.g1:A">$A$</span>, <span data-ref="0037.g1:B">$B$</span>, <span data-ref="0037.g1:C">$C$</span>, <span data-ref="0037.g1:D">$D$</span> be four magnitudes in proportion, so<br />
that, as <span data-ref="0037.g1:A">$A$</span> is to <span data-ref="0037.g1:B">$B$</span>, so is <span data-ref="0037.g1:C">$C$</span><br />
to <span data-ref="0037.g1:D">$D$</span>,<br />
and let <span data-ref="0037.g1:A">$A$</span> be commensurable<br />
with <span data-ref="0037.g1:B">$B$</span> ;<br />
I say that <span data-ref="0037.g1:C">$C$</span> will also be commensurable with <span data-ref="0037.g1:D">$D$</span>.

![Proposition 11 diagram](0037.g1.svg)

<p class="sub-clause">For, since <span data-ref="0037.g1:A">$A$</span> is commensurable with <span data-ref="0037.g1:B">$B$</span>,</p>

<p class="assertion">therefore <span data-ref="0037.g1:A">$A$</span> has to <span data-ref="0037.g1:B">$B$</span> the ratio which a number has to a<br />
number. <span class="justification">[X. 5]</span></p>

<p class="sub-clause">And, as <span data-ref="0037.g1:A">$A$</span> is to <span data-ref="0037.g1:B">$B$</span>, so is <span data-ref="0037.g1:C">$C$</span> to <span data-ref="0037.g1:D">$D$</span> ;</p>

<p class="assertion">therefore <span data-ref="0037.g1:C">$C$</span> also has to <span data-ref="0037.g1:D">$D$</span> the ratio which a number has to a<br />
number ;<br />
therefore <span data-ref="0037.g1:C">$C$</span> is commensurable with <span data-ref="0037.g1:D">$D$</span>. <span class="justification">[X. 6]</span></p>

Next, let <span data-ref="0037.g1:A">$A$</span> be incommensurable with <span data-ref="0037.g1:B">$B$</span> ;<br />
I say that <span data-ref="0037.g1:C">$C$</span> will also be incommensurable with <span data-ref="0037.g1:D">$D$</span>.

<p class="sub-clause">For, since <span data-ref="0037.g1:A">$A$</span> is incommensurable with <span data-ref="0037.g1:B">$B$</span>,</p>

<p class="assertion">therefore <span data-ref="0037.g1:A">$A$</span> has not to <span data-ref="0037.g1:B">$B$</span> the ratio which a number has to a<br />
number. <span class="justification">[X. 7]</span></p>
