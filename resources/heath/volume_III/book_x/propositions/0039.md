Let it have the ratio which <span data-ref="0038.g1:D">$D$</span> has to <span data-ref="0038.g1:E">$E$</span>.

Again, since <span data-ref="0038.g1:C">$C$</span> is commensurable with <span data-ref="0038.g1:B">$B$</span>,
therefore <span data-ref="0038.g1:C">$C$</span> has to <span data-ref="0038.g1:B">$B$</span> the ratio which a number has to a
number. [x. 5]

Let it have the ratio which <span data-ref="0038.g1:F">$F$</span> has to <span data-ref="0038.g1:G">$G$</span>.

And, given any number of ratios we please, namely the
ratio which <span data-ref="0038.g1:D">$D$</span> has to <span data-ref="0038.g1:E">$E$</span> and that which <span data-ref="0038.g1:F">$F$</span> has to <span data-ref="0038.g1:G">$G$</span>,
let the numbers <span data-ref="0038.g1:H">$H$</span>, <span data-ref="0038.g1:K">$K$</span>, <span data-ref="0038.g1:L">$L$</span> be taken continuously in the given
ratios; [cf. viii. 4]
so that, as <span data-ref="0038.g1:D">$D$</span> is to <span data-ref="0038.g1:E">$E$</span>, so is <span data-ref="0038.g1:H">$H$</span> to <span data-ref="0038.g1:K">$K$</span>,
and, as <span data-ref="0038.g1:F">$F$</span> is to <span data-ref="0038.g1:G">$G$</span>, so is <span data-ref="0038.g1:K">$K$</span> to <span data-ref="0038.g1:L">$L$</span>.

Since, then, as <span data-ref="0038.g1:A">$A$</span> is to <span data-ref="0038.g1:C">$C$</span>, so is <span data-ref="0038.g1:D">$D$</span> to <span data-ref="0038.g1:E">$E$</span>,
while, as <span data-ref="0038.g1:D">$D$</span> is to <span data-ref="0038.g1:E">$E$</span>, so is <span data-ref="0038.g1:H">$H$</span> to <span data-ref="0038.g1:K">$K$</span>,
therefore also, as <span data-ref="0038.g1:A">$A$</span> is to <span data-ref="0038.g1:C">$C$</span>, so is <span data-ref="0038.g1:H">$H$</span> to <span data-ref="0038.g1:K">$K$</span>. [v. 11]

Again, since, as <span data-ref="0038.g1:C">$C$</span> is to <span data-ref="0038.g1:B">$B$</span>, so is <span data-ref="0038.g1:F">$F$</span> to <span data-ref="0038.g1:G">$G$</span>,
while, as <span data-ref="0038.g1:F">$F$</span> is to <span data-ref="0038.g1:G">$G$</span>, so is <span data-ref="0038.g1:K">$K$</span> to <span data-ref="0038.g1:L">$L$</span>,
therefore also, as <span data-ref="0038.g1:C">$C$</span> is to <span data-ref="0038.g1:B">$B$</span>, so is <span data-ref="0038.g1:K">$K$</span> to <span data-ref="0038.g1:L">$L$</span>. [v. 11]

But also, as <span data-ref="0038.g1:A">$A$</span> is to <span data-ref="0038.g1:C">$C$</span>, so is <span data-ref="0038.g1:H">$H$</span> to <span data-ref="0038.g1:K">$K$</span>;
therefore, *ex aequali*, as <span data-ref="0038.g1:A">$A$</span> is to <span data-ref="0038.g1:B">$B$</span>, so is <span data-ref="0038.g1:H">$H$</span> to <span data-ref="0038.g1:L">$L$</span>. [v. 22]

Therefore <span data-ref="0038.g1:A">$A$</span> has to <span data-ref="0038.g1:B">$B$</span> the ratio which a number has to a
number;
therefore <span data-ref="0038.g1:A">$A$</span> is commensurable with <span data-ref="0038.g1:B">$B$</span>. [x. 6]

Therefore etc.

<p align="right">Q. E. D.</p>

We have merely to go through the process of compounding two ratios in
numbers.

$$\begin{aligned}
&\text{Suppose } & a,\, b &\text{ each } ⌢ c. \\
&\text{Therefore } & a : c &= m : n\text{, say,} & \text{[x. 5]} \\
& & c : b &= p : q\text{, say.} \\
&\text{Now } & m : n &= mp : np, \\
&\text{and } & p : q &= np : nq. \\
&\text{Therefore } & a : c &= mp : np, \\
& & c : b &= np : nq, \\
&\text{whence, \textit{ex aequali},} & a : b &= mp : nq, \\
&\text{so that } & a &⌢ b. & \text{[x. 6]}
\end{aligned}$$
