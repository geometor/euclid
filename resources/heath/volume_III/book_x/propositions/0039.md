Let it have the ratio which <span data-ref="0038.g1:D">$D$</span> has to <span data-ref="0038.g1:E">$E$</span>.

<p class="sub-clause">Again, since <span data-ref="0038.g1:C">$C$</span> is commensurable with <span data-ref="0038.g1:B">$B$</span>,</p>
<p class="assertion">therefore <span data-ref="0038.g1:C">$C$</span> has to <span data-ref="0038.g1:B">$B$</span> the ratio which a number has to a<br />
number. <span class="justification">[X. 5]</span></p>

Let it have the ratio which <span data-ref="0038.g1:F">$F$</span> has to <span data-ref="0038.g1:G">$G$</span>.

And, given any number of ratios we please, namely the<br />
ratio which <span data-ref="0038.g1:D">$D$</span> has to <span data-ref="0038.g1:E">$E$</span> and that which <span data-ref="0038.g1:F">$F$</span> has to <span data-ref="0038.g1:G">$G$</span>,<br />
let the numbers <span data-ref="0038.g1:H">$H$</span>, <span data-ref="0038.g1:K">$K$</span>, <span data-ref="0038.g1:L">$L$</span> be taken continuously in the given<br />
ratios; <span class="justification">[cf. VIII. 4]</span>
<p class="assertion">so that, as <span data-ref="0038.g1:D">$D$</span> is to <span data-ref="0038.g1:E">$E$</span>, so is <span data-ref="0038.g1:H">$H$</span> to <span data-ref="0038.g1:K">$K$</span>,<br />
and, as <span data-ref="0038.g1:F">$F$</span> is to <span data-ref="0038.g1:G">$G$</span>, so is <span data-ref="0038.g1:K">$K$</span> to <span data-ref="0038.g1:L">$L$</span>.</p>

<p class="sub-clause">Since, then, as <span data-ref="0038.g1:A">$A$</span> is to <span data-ref="0038.g1:C">$C$</span>, so is <span data-ref="0038.g1:D">$D$</span> to <span data-ref="0038.g1:E">$E$</span>,<br />
while, as <span data-ref="0038.g1:D">$D$</span> is to <span data-ref="0038.g1:E">$E$</span>, so is <span data-ref="0038.g1:H">$H$</span> to <span data-ref="0038.g1:K">$K$</span>,</p>
<p class="assertion">therefore also, as <span data-ref="0038.g1:A">$A$</span> is to <span data-ref="0038.g1:C">$C$</span>, so is <span data-ref="0038.g1:H">$H$</span> to <span data-ref="0038.g1:K">$K$</span>. <span class="justification">[V. 11]</span></p>

<p class="sub-clause">Again, since, as <span data-ref="0038.g1:C">$C$</span> is to <span data-ref="0038.g1:B">$B$</span>, so is <span data-ref="0038.g1:F">$F$</span> to <span data-ref="0038.g1:G">$G$</span>,<br />
while, as <span data-ref="0038.g1:F">$F$</span> is to <span data-ref="0038.g1:G">$G$</span>, so is <span data-ref="0038.g1:K">$K$</span> to <span data-ref="0038.g1:L">$L$</span>,</p>
<p class="assertion">therefore also, as <span data-ref="0038.g1:C">$C$</span> is to <span data-ref="0038.g1:B">$B$</span>, so is <span data-ref="0038.g1:K">$K$</span> to <span data-ref="0038.g1:L">$L$</span>. <span class="justification">[V. 11]</span></p>

<p class="sub-clause">But also, as <span data-ref="0038.g1:A">$A$</span> is to <span data-ref="0038.g1:C">$C$</span>, so is <span data-ref="0038.g1:H">$H$</span> to <span data-ref="0038.g1:K">$K$</span>;</p>
<p class="assertion">therefore, *ex aequali*, as <span data-ref="0038.g1:A">$A$</span> is to <span data-ref="0038.g1:B">$B$</span>, so is <span data-ref="0038.g1:H">$H$</span> to <span data-ref="0038.g1:L">$L$</span>. <span class="justification">[V. 22]</span></p>

<p class="assertion">Therefore <span data-ref="0038.g1:A">$A$</span> has to <span data-ref="0038.g1:B">$B$</span> the ratio which a number has to a<br />
number;<br />
therefore <span data-ref="0038.g1:A">$A$</span> is commensurable with <span data-ref="0038.g1:B">$B$</span>. <span class="justification">[X. 6]</span></p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>

We have merely to go through the process of compounding two ratios in<br />
numbers.

$$\begin{aligned}
&\text{Suppose } & a,\, b &\text{ each } ⌢ c. \\
&\text{Therefore } & a : c &= m : n\text{, say,} & \text{[x. 5]} \\
& & c : b &= p : q\text{, say.} \\
&\text{Now } & m : n &= mp : np, \\
&\text{and } & p : q &= np : nq. \\
&\text{Therefore } & a : c &= mp : np, \\
& & c : b &= np : nq, \\
&\text{whence, \textit{ex aequali},} & a : b &= mp : nq, \\
&\text{so that } & a &⌢ b. & \text{[x. 6]}
\end{aligned}$$
