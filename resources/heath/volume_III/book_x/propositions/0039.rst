Let it have the ratio which :g:`$D$ <0038.g1:D>` has to :g:`$E$ <0038.g1:E>`.

.. subclause::

   Again, since :g:`$C$ <0038.g1:C>` is commensurable with :g:`$B$ <0038.g1:B>`,

.. assertion::

   therefore :g:`$C$ <0038.g1:C>` has to :g:`$B$ <0038.g1:B>` the ratio which a number has to a number. :just:`[X. 5] <X.5>`

Let it have the ratio which :g:`$F$ <0038.g1:F>` has to :g:`$G$ <0038.g1:G>`.

And, given any number of ratios we please, namely the ratio which :g:`$D$ <0038.g1:D>` has to :g:`$E$ <0038.g1:E>` and that which :g:`$F$ <0038.g1:F>` has to :g:`$G$ <0038.g1:G>`, let the numbers :g:`$H$ <0038.g1:H>`, :g:`$K$ <0038.g1:K>`, :g:`$L$ <0038.g1:L>` be taken continuously in the given ratios; :just:`[cf. VIII. 4]`

.. assertion::

   so that, as :g:`$D$ <0038.g1:D>` is to :g:`$E$ <0038.g1:E>`, so is :g:`$H$ <0038.g1:H>` to :g:`$K$ <0038.g1:K>`, and, as :g:`$F$ <0038.g1:F>` is to :g:`$G$ <0038.g1:G>`, so is :g:`$K$ <0038.g1:K>` to :g:`$L$ <0038.g1:L>`.

.. subclause::

   Since, then, as :g:`$A$ <0038.g1:A>` is to :g:`$C$ <0038.g1:C>`, so is :g:`$D$ <0038.g1:D>` to :g:`$E$ <0038.g1:E>`, while, as :g:`$D$ <0038.g1:D>` is to :g:`$E$ <0038.g1:E>`, so is :g:`$H$ <0038.g1:H>` to :g:`$K$ <0038.g1:K>`,

.. assertion:: [V. 11] <V.11>

   therefore also, as :g:`$A$ <0038.g1:A>` is to :g:`$C$ <0038.g1:C>`, so is :g:`$H$ <0038.g1:H>` to :g:`$K$ <0038.g1:K>`.

.. subclause::

   Again, since, as :g:`$C$ <0038.g1:C>` is to :g:`$B$ <0038.g1:B>`, so is :g:`$F$ <0038.g1:F>` to :g:`$G$ <0038.g1:G>`, while, as :g:`$F$ <0038.g1:F>` is to :g:`$G$ <0038.g1:G>`, so is :g:`$K$ <0038.g1:K>` to :g:`$L$ <0038.g1:L>`,

.. assertion:: [V. 11] <V.11>

   therefore also, as :g:`$C$ <0038.g1:C>` is to :g:`$B$ <0038.g1:B>`, so is :g:`$K$ <0038.g1:K>` to :g:`$L$ <0038.g1:L>`.

.. subclause::

   But also, as :g:`$A$ <0038.g1:A>` is to :g:`$C$ <0038.g1:C>`, so is :g:`$H$ <0038.g1:H>` to :g:`$K$ <0038.g1:K>`;

.. assertion:: [V. 22] <V.22>

   therefore, :term:`*ex aequali* <ex-aequali>`, as :g:`$A$ <0038.g1:A>` is to :g:`$B$ <0038.g1:B>`, so is :g:`$H$ <0038.g1:H>` to :g:`$L$ <0038.g1:L>`.

.. assertion::

   Therefore :g:`$A$ <0038.g1:A>` has to :g:`$B$ <0038.g1:B>` the ratio which a number has to a number; therefore :g:`$A$ <0038.g1:A>` is commensurable with :g:`$B$ <0038.g1:B>`. :just:`[X. 6] <X.6>`

.. qed::

   Therefore etc. :just:`Q. E. D.`

----

We have merely to go through the process of compounding two ratios in numbers.

$$\begin{aligned}
&\text{Suppose } & a,\, b &\text{ each } ⌢ c. \\
&\text{Therefore } & a : c &= m : n\text{, say,} & \text{[x. 5]} \\
& & c : b &= p : q\text{, say.} \\
&\text{Now } & m : n &= mp : np, \\
&\text{and } & p : q &= np : nq. \\
&\text{Therefore } & a : c &= mp : np, \\
& & c : b &= np : nq, \\
&\text{whence, \textit{ex aequali},} & a : b &= mp : nq, \\
&\text{so that } & a &⌢ b. & \text{[x. 6]}
\end{aligned}$$
