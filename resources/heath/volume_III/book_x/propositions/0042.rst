.. assertion::

   Therefore, as the squares on :g:`$E$ <0041.g1:E>`, :g:`$B$ <0041.g1:B>` are to the square on :g:`$B$ <0041.g1:B>`, so are the squares on :g:`$D$ <0041.g1:D>`, :g:`$F$ <0041.g1:F>` to the square on :g:`$D$ <0041.g1:D>`;

.. assertion::

   therefore, :term:`*separando* <separando>`, as the square on :g:`$E$ <0041.g1:E>` is to the square on :g:`$B$ <0041.g1:B>`, so is the square on :g:`$F$ <0041.g1:F>` to the square on :g:`$D$ <0041.g1:D>`; :just:`[V. 17] <V.17>`

.. assertion::

   therefore also, as :g:`$E$ <0041.g1:E>` is to :g:`$B$ <0041.g1:B>`, so is :g:`$F$ <0041.g1:F>` to :g:`$D$ <0041.g1:D>`; :just:`[VI. 22] <VI.22>` therefore, inversely, as :g:`$B$ <0041.g1:B>` is to :g:`$E$ <0041.g1:E>`, so is :g:`$D$ <0041.g1:D>` to :g:`$F$ <0041.g1:F>`.

.. subclause::

   But, as :g:`$A$ <0041.g1:A>` is to :g:`$B$ <0041.g1:B>`, so also is :g:`$C$ <0041.g1:C>` to :g:`$D$ <0041.g1:D>`;

.. assertion:: [V. 22] <V.22>

   therefore, :term:`*ex aequali* <ex-aequali>`, as :g:`$A$ <0041.g1:A>` is to :g:`$E$ <0041.g1:E>`, so is :g:`$C$ <0041.g1:C>` to :g:`$F$ <0041.g1:F>`.

.. assertion::

   Therefore, if :g:`$A$ <0041.g1:A>` is commensurable with :g:`$E$ <0041.g1:E>`, :g:`$C$ <0041.g1:C>` is also commensurable with :g:`$F$ <0041.g1:F>`, and, if :g:`$A$ <0041.g1:A>` is incommensurable with :g:`$E$ <0041.g1:E>`, :g:`$C$ <0041.g1:C>` is also incommensurable with :g:`$F$ <0041.g1:F>`. :just:`[X. 11] <X.11>`

.. qed::

   Therefore etc.

.. [#f1] **with the first.** Euclid speaks of the square on the first (third) being greater than the square on the second (fourth) by the square on a straight line commensurable (incommensurable) "with *itself* (ἑαυτῇ)," and similarly in all like phrases throughout the Book. For clearness' sake I substitute "the first," "the third," or whatever it may be, for "*itself*" in these cases.

Suppose $a$, $b$, $c$, $d$ to be straight lines such that

$$a : b = c : d \tag{1}$$

It follows [vi. 22] that

$$a^2 : b^2 = c^2 : d^2 \tag{2}$$

In order to prove that, :term:`*convertendo* <convertendo>`,

$$a^2 : (a^2 - b^2) = c^2 : (c^2 - d^2)$$

Euclid has to use a somewhat roundabout method owing to the absence of a :term:`*convertendo* <convertendo>` proposition in his Book v. (which omission :person:`Simson <simson>` supplied by his Prop. E).

It follows from (2) that

$$\{(a^2 - b^2) + b^2\} : b^2 = \{(c^2 - d^2) + d^2\} : d^2,$$

whence, :term:`*separando* <separando>`,

$$(a^2 - b^2) : b^2 = (c^2 - d^2) : d^2, \tag{v. 17}$$

and, inversely,

$$b^2 : (a^2 - b^2) = d^2 : (c^2 - d^2).$$

From this and (2), :term:`*ex aequali* <ex-aequali>`,

$$a^2 : (a^2 - b^2) = c^2 : (c^2 - d^2). \tag{v. 22}$$

Hence

$$a : \sqrt{a^2 - b^2} = c : \sqrt{c^2 - d^2}. \tag{vi. 22}$$

According therefore as

$$\begin{aligned}
a &⌢\text{ or } ⌣ \sqrt{a^2 - b^2}, \\
c &⌢\text{ or } ⌣ \sqrt{c^2 - d^2}. &&\text{[x. 11]}
\end{aligned}$$

If $a ⌢ \sqrt{a^2 - b^2}$, we may put $\sqrt{a^2 - b^2} = ka$, where $k$ is of the form $m/n$ and $m$, $n$ are integers. And if $\sqrt{a^2 - b^2} = ka$, it follows in this case that $\sqrt{c^2 - d^2} = kc$.
