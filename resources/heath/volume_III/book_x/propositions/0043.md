### PROPOSITION 15.

<p class="enunciation">If two commensurable magnitudes be added together, the<br />
whole will also be commensurable with each of them; and, if<br />
the whole be commensurable with one of them, the original<br />
magnitudes will also be commensurable.</p>

For let the two commensurable magnitudes <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span> be<br />
added together;<br />
I say that the whole <span data-ref="0043.g1:/ A C /">$AC$</span> is also<br />
commensurable with each of the<br />
magnitudes <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span>.

![Proposition 15 Diagram](0043.g1.svg)

For, since <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span> are commensurable, some magnitude<br />
will measure them.<br />
Let it measure them, and let it be <span data-ref="0043.g1:D">$D$</span>.

<p class="assertion">Since then <span data-ref="0043.g1:D">$D$</span> measures <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span>, it will also measure the<br />
whole <span data-ref="0043.g1:/ A C /">$AC$</span>.</p>

<p class="sub-clause">But it measures <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span> also;</p>
<p class="assertion">therefore <span data-ref="0043.g1:D">$D$</span> measures <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span>, <span data-ref="0043.g1:/ A C /">$AC$</span>;<br />
therefore <span data-ref="0043.g1:/ A C /">$AC$</span> is commensurable with each of the magnitudes<br />
<span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span>. <span class="justification">[X. Def. 1]</span></p>

Next, let <span data-ref="0043.g1:/ A C /">$AC$</span> be commensurable with <span data-ref="0043.g1:/ A B /">$AB$</span>;<br />
I say that <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span> are also commensurable.

For, since <span data-ref="0043.g1:/ A C /">$AC$</span>, <span data-ref="0043.g1:/ A B /">$AB$</span> are commensurable, some magnitude<br />
will measure them.<br />
Let it measure them, and let it be <span data-ref="0043.g1:D">$D$</span>.

<p class="assertion">Since then <span data-ref="0043.g1:D">$D$</span> measures <span data-ref="0043.g1:/ A C /">$CA$</span>, <span data-ref="0043.g1:/ A B /">$AB$</span>, it will also measure the<br />
remainder <span data-ref="0043.g1:/ B C /">$BC$</span>.</p>

<p class="sub-clause">But it measures <span data-ref="0043.g1:/ A B /">$AB$</span> also;</p>
<p class="assertion">therefore <span data-ref="0043.g1:D">$D$</span> will measure <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span>;<br />
therefore <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span> are commensurable. <span class="justification">[X. Def. 1]</span></p>

<p class="qed">Therefore etc.</p>

---

(1) If $a$, $b$ be any two commensurable magnitudes, they are of the form<br />
$mc$, $nc$, where $c$ is a common measure of $a$, $b$ and $m$, $n$ some integers.<br />
It follows that
$$a + b = (m + n) c;$$
therefore $(a + b)$, being measured by $c$, is commensurable with both $a$ and $b$.

(2) If $a + b$ is commensurable with either $a$ or $b$, say $a$, we may put<br />
$a + b = mc$, $a = nc$, where $c$ is a common measure of $(a + b)$, $a$, and $m$, $n$ are<br />
integers.<br />
Subtracting, we have
$$b = (m - n) c,$$
whence $b ⌢ a$.
