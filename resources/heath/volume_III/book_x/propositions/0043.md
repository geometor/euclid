### PROPOSITION 15.

*If two commensurable magnitudes be added together, the
whole will also be commensurable with each of them; and, if
the whole be commensurable with one of them, the original
magnitudes will also be commensurable.*

For let the two commensurable magnitudes <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span> be
added together;
I say that the whole <span data-ref="0043.g1:/ A C /">$AC$</span> is also
commensurable with each of the
magnitudes <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span>.

![Proposition 15 Diagram](0043.g1.svg)

For, since <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span> are commensurable, some magnitude
will measure them.
Let it measure them, and let it be <span data-ref="0043.g1:D">$D$</span>.
Since then <span data-ref="0043.g1:D">$D$</span> measures <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span>, it will also measure the
whole <span data-ref="0043.g1:/ A C /">$AC$</span>.
But it measures <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span> also;
therefore <span data-ref="0043.g1:D">$D$</span> measures <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span>, <span data-ref="0043.g1:/ A C /">$AC$</span>;
therefore <span data-ref="0043.g1:/ A C /">$AC$</span> is commensurable with each of the magnitudes
<span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span>. [x. Def. 1]

Next, let <span data-ref="0043.g1:/ A C /">$AC$</span> be commensurable with <span data-ref="0043.g1:/ A B /">$AB$</span>;
I say that <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span> are also commensurable.
For, since <span data-ref="0043.g1:/ A C /">$AC$</span>, <span data-ref="0043.g1:/ A B /">$AB$</span> are commensurable, some magnitude
will measure them.
Let it measure them, and let it be <span data-ref="0043.g1:D">$D$</span>.
Since then <span data-ref="0043.g1:D">$D$</span> measures <span data-ref="0043.g1:/ A C /">$CA$</span>, <span data-ref="0043.g1:/ A B /">$AB$</span>, it will also measure the
remainder <span data-ref="0043.g1:/ B C /">$BC$</span>.
But it measures <span data-ref="0043.g1:/ A B /">$AB$</span> also;
therefore <span data-ref="0043.g1:D">$D$</span> will measure <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span>;
therefore <span data-ref="0043.g1:/ A B /">$AB$</span>, <span data-ref="0043.g1:/ B C /">$BC$</span> are commensurable. [x. Def. 1]

Therefore etc.

---

(1) If $a$, $b$ be any two commensurable magnitudes, they are of the form
$mc$, $nc$, where $c$ is a common measure of $a$, $b$ and $m$, $n$ some integers.
It follows that
$$a + b = (m + n) c;$$
therefore $(a + b)$, being measured by $c$, is commensurable with both $a$ and $b$.

(2) If $a + b$ is commensurable with either $a$ or $b$, say $a$, we may put
$a + b = mc$, $a = nc$, where $c$ is a common measure of $(a + b)$, $a$, and $m$, $n$ are
integers.
Subtracting, we have
$$b = (m - n) c,$$
whence $b ⌢ a$.
