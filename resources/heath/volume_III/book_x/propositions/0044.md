### PROPOSITION 16.

<p class="enunciation">If two incommensurable magnitudes be added together, the<br />
whole will also be incommensurable with each of them; and, if<br />
the whole be incommensurable with one of them, the original<br />
magnitudes will also be incommensurable.</p>

For let the two incommensurable magnitudes <span data-ref="0044.g1:/ A B /">$AB$</span>, <span data-ref="0044.g1:/ B C /">$BC$</span> be<br />
added together;<br />
I say that the whole <span data-ref="0044.g1:/ A C /">$AC$</span> is also incommensurable<br />
with each of the magnitudes <span data-ref="0044.g1:/ A B /">$AB$</span>, <span data-ref="0044.g1:/ B C /">$BC$</span>.

![Proposition 16 Diagram](0044.g1.svg)

For, if <span data-ref="0044.g1:/ A C /">$CA$</span>, <span data-ref="0044.g1:/ A B /">$AB$</span> are not incommensurable, some<br />
magnitude will measure them.<br />
Let it measure them, if possible, and let it be <span data-ref="0044.g1:D">$D$</span>.

<p class="sub-clause">Since then <span data-ref="0044.g1:D">$D$</span> measures <span data-ref="0044.g1:/ A C /">$CA$</span>, <span data-ref="0044.g1:/ A B /">$AB$</span>,</p>
<p class="assertion">therefore it will also measure the remainder <span data-ref="0044.g1:/ B C /">$BC$</span>.</p>

<p class="sub-clause">But it measures <span data-ref="0044.g1:/ A B /">$AB$</span> also;</p>
<p class="assertion">therefore <span data-ref="0044.g1:D">$D$</span> measures <span data-ref="0044.g1:/ A B /">$AB$</span>, <span data-ref="0044.g1:/ B C /">$BC$</span>.</p>

<p class="assertion">Therefore <span data-ref="0044.g1:/ A B /">$AB$</span>, <span data-ref="0044.g1:/ B C /">$BC$</span> are commensurable;</p>
<p class="sub-clause">but they were also, by hypothesis, incommensurable:</p>
<p class="assertion">which is impossible.</p>

<p class="assertion">Therefore no magnitude will measure <span data-ref="0044.g1:/ A C /">$CA$</span>, <span data-ref="0044.g1:/ A B /">$AB$</span>;<br />
therefore <span data-ref="0044.g1:/ A C /">$CA$</span>, <span data-ref="0044.g1:/ A B /">$AB$</span> are incommensurable. <span class="justification">[X. Def. 1]</span></p>

<p class="assertion">Similarly we can prove that <span data-ref="0044.g1:/ A C /">$AC$</span>, <span data-ref="0044.g1:/ B C /">$CB$</span> are also incom-<br />
mensurable.</p>

<p class="assertion">Therefore <span data-ref="0044.g1:/ A C /">$AC$</span> is incommensurable with each of the magni-<br />
tudes <span data-ref="0044.g1:/ A B /">$AB$</span>, <span data-ref="0044.g1:/ B C /">$BC$</span>.</p>

Next, let <span data-ref="0044.g1:/ A C /">$AC$</span> be incommensurable with one of the magni-<br />
tudes <span data-ref="0044.g1:/ A B /">$AB$</span>, <span data-ref="0044.g1:/ B C /">$BC$</span>.

First, let it be incommensurable with <span data-ref="0044.g1:/ A B /">$AB$</span>;<br />
I say that <span data-ref="0044.g1:/ A B /">$AB$</span>, <span data-ref="0044.g1:/ B C /">$BC$</span> are also incommensurable.

For, if they are commensurable, some magnitude will<br />
measure them.<br />
Let it measure them, and let it be <span data-ref="0044.g1:D">$D$</span>.

<p class="sub-clause">Since then <span data-ref="0044.g1:D">$D$</span> measures <span data-ref="0044.g1:/ A B /">$AB$</span>, <span data-ref="0044.g1:/ B C /">$BC$</span>,</p>
<p class="assertion">therefore it will also measure the whole <span data-ref="0044.g1:/ A C /">$AC$</span>.</p>

<p class="sub-clause">But it measures <span data-ref="0044.g1:/ A B /">$AB$</span> also;</p>
<p class="assertion">therefore <span data-ref="0044.g1:D">$D$</span> measures <span data-ref="0044.g1:/ A C /">$CA$</span>, <span data-ref="0044.g1:/ A B /">$AB$</span>.</p>
