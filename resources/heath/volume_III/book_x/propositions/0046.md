<p class="enunciation"><sup>10</sup> the greater, and if there be applied to the greater a parallelogram<br />
equal to the fourth part of the square on the less and deficient<br />
by a square figure, it will divide it into parts which are com-<br />
mensurable in length.</p>

Let <span data-ref="0046.g1:A">$A$</span>, <span data-ref="0046.g1:/ B C /">$BC$</span> be two unequal straight lines, of which <span data-ref="0046.g1:/ B C /">$BC$</span> is<br />
<sup>15</sup> the greater,<br />
and let there be applied to <span data-ref="0046.g1:/ B C /">$BC$</span> a parallel-<br />
ogram equal to the fourth part of the<br />
square on the less, <span data-ref="0046.g1:A">$A$</span>, that is, equal to<br />
the square on the half of <span data-ref="0046.g1:A">$A$</span>, and deficient<br />
<sup>20</sup> by a square figure. Let this be the<br />
rectangle <span data-ref="0046.g1:/ B D /">$BD$</span>, <span data-ref="0046.g1:/ D C /">$DC$</span>, <span class="justification">[cf. Lemma]</span><br />
and let <span data-ref="0046.g1:/ B D /">$BD$</span> be commensurable in length with <span data-ref="0046.g1:/ D C /">$DC$</span>;<br />
I say that the square on <span data-ref="0046.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0046.g1:A">$A$</span><br />
by the square on a straight line commensurable with <span data-ref="0046.g1:/ B C /">$BC$</span>.

<sup>25</sup> For let <span data-ref="0046.g1:/ B C /">$BC$</span> be bisected at the point <span data-ref="0046.g1:E">$E$</span>,<br />
and let <span data-ref="0046.g1:/ F E /">$EF$</span> be made equal to <span data-ref="0046.g1:/ E D /">$DE$</span>.

<p class="assertion">Therefore the remainder <span data-ref="0046.g1:/ D C /">$DC$</span> is equal to <span data-ref="0046.g1:/ B F /">$BF$</span>.</p>

<p class="sub-clause">And, since the straight line <span data-ref="0046.g1:/ B C /">$BC$</span> has been cut into equal<br />
parts at <span data-ref="0046.g1:E">$E$</span>, and into unequal parts at <span data-ref="0046.g1:D">$D$</span>,</p>
<p class="assertion"><sup>30</sup> therefore the rectangle contained by <span data-ref="0046.g1:/ B D /">$BD$</span>, <span data-ref="0046.g1:/ D C /">$DC$</span>, together with<br />
the square on <span data-ref="0046.g1:/ E D /">$ED$</span>, is equal to the square on <span data-ref="0046.g1:/ E C /">$EC$</span>; <span class="justification">[II. 5]</span></p>

<p class="sub-clause">And the same is true of their quadruples;</p>
<p class="assertion">therefore four times the rectangle <span data-ref="0046.g1:/ B D /">$BD$</span>, <span data-ref="0046.g1:/ D C /">$DC$</span>, together with<br />
four times the square on <span data-ref="0046.g1:/ E D /">$DE$</span>, is equal to four times the square<br />
<sup>35</sup> on <span data-ref="0046.g1:/ E C /">$EC$</span>.</p>

<p class="sub-clause">But the square on <span data-ref="0046.g1:A">$A$</span> is equal to four times the rectangle<br />
<span data-ref="0046.g1:/ B D /">$BD$</span>, <span data-ref="0046.g1:/ D C /">$DC$</span>;<br />
and the square on <span data-ref="0046.g1:/ D F /">$DF$</span> is equal to four times the square on<br />
<span data-ref="0046.g1:/ E D /">$DE$</span>, for <span data-ref="0046.g1:/ D F /">$DF$</span> is double of <span data-ref="0046.g1:/ E D /">$DE$</span>.</p>

<p class="sub-clause"><sup>40</sup> And the square on <span data-ref="0046.g1:/ B C /">$BC$</span> is equal to four times the square<br />
on <span data-ref="0046.g1:/ E C /">$EC$</span>, for again <span data-ref="0046.g1:/ B C /">$BC$</span> is double of <span data-ref="0046.g1:/ E C /">$CE$</span>.</p>

<p class="assertion">Therefore the squares on <span data-ref="0046.g1:A">$A$</span>, <span data-ref="0046.g1:/ D F /">$DF$</span> are equal to the square<br />
on <span data-ref="0046.g1:/ B C /">$BC$</span>,<br />
so that the square on <span data-ref="0046.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0046.g1:A">$A$</span> by<br />
<sup>45</sup> the square on <span data-ref="0046.g1:/ D F /">$DF$</span>.</p>

It is to be proved that <span data-ref="0046.g1:/ B C /">$BC$</span> is also commensurable with <span data-ref="0046.g1:/ D F /">$DF$</span>.

<p class="sub-clause">Since <span data-ref="0046.g1:/ B D /">$BD$</span> is commensurable in length with <span data-ref="0046.g1:/ D C /">$DC$</span>,</p>
<p class="assertion">therefore <span data-ref="0046.g1:/ B C /">$BC$</span> is also commensurable in length with <span data-ref="0046.g1:/ D C /">$CD$</span>. <span class="justification">[X. 15]</span></p>
