<sup>10</sup> *the greater, and if there be applied to the greater a parallelogram equal to the fourth part of the square on the less and deficient by a square figure, it will divide it into parts which are commensurable in length.*

Let <span data-ref="0046.g1:A">$A$</span>, <span data-ref="0046.g1:/ B C /">$BC$</span> be two unequal straight lines, of which <span data-ref="0046.g1:/ B C /">$BC$</span> is <sup>15</sup> the greater, and let there be applied to <span data-ref="0046.g1:/ B C /">$BC$</span> a parallelogram equal to the fourth part of the square on the less, <span data-ref="0046.g1:A">$A$</span>, that is, equal to the square on the half of <span data-ref="0046.g1:A">$A$</span>, and deficient <sup>20</sup> by a square figure. Let this be the rectangle <span data-ref="0046.g1:/ B D /">$BD$</span>, <span data-ref="0046.g1:/ D C /">$DC$</span>, [cf. Lemma] and let <span data-ref="0046.g1:/ B D /">$BD$</span> be commensurable in length with <span data-ref="0046.g1:/ D C /">$DC$</span>;
I say that the square on <span data-ref="0046.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0046.g1:A">$A$</span> by the square on a straight line commensurable with <span data-ref="0046.g1:/ B C /">$BC$</span>.

<sup>25</sup> For let <span data-ref="0046.g1:/ B C /">$BC$</span> be bisected at the point <span data-ref="0046.g1:E">$E$</span>, and let <span data-ref="0046.g1:/ F E /">$EF$</span> be made equal to <span data-ref="0046.g1:/ E D /">$DE$</span>.
Therefore the remainder <span data-ref="0046.g1:/ D C /">$DC$</span> is equal to <span data-ref="0046.g1:/ B F /">$BF$</span>.
And, since the straight line <span data-ref="0046.g1:/ B C /">$BC$</span> has been cut into equal parts at <span data-ref="0046.g1:E">$E$</span>, and into unequal parts at <span data-ref="0046.g1:D">$D$</span>, <sup>30</sup> therefore the rectangle contained by <span data-ref="0046.g1:/ B D /">$BD$</span>, <span data-ref="0046.g1:/ D C /">$DC$</span>, together with the square on <span data-ref="0046.g1:/ E D /">$ED$</span>, is equal to the square on <span data-ref="0046.g1:/ E C /">$EC$</span>; [II. 5]
And the same is true of their quadruples; therefore four times the rectangle <span data-ref="0046.g1:/ B D /">$BD$</span>, <span data-ref="0046.g1:/ D C /">$DC$</span>, together with four times the square on <span data-ref="0046.g1:/ E D /">$DE$</span>, is equal to four times the square <sup>35</sup> on <span data-ref="0046.g1:/ E C /">$EC$</span>.
But the square on <span data-ref="0046.g1:A">$A$</span> is equal to four times the rectangle <span data-ref="0046.g1:/ B D /">$BD$</span>, <span data-ref="0046.g1:/ D C /">$DC$</span>; and the square on <span data-ref="0046.g1:/ D F /">$DF$</span> is equal to four times the square on <span data-ref="0046.g1:/ E D /">$DE$</span>, for <span data-ref="0046.g1:/ D F /">$DF$</span> is double of <span data-ref="0046.g1:/ E D /">$DE$</span>.
<sup>40</sup> And the square on <span data-ref="0046.g1:/ B C /">$BC$</span> is equal to four times the square on <span data-ref="0046.g1:/ E C /">$EC$</span>, for again <span data-ref="0046.g1:/ B C /">$BC$</span> is double of <span data-ref="0046.g1:/ E C /">$CE$</span>.
Therefore the squares on <span data-ref="0046.g1:A">$A$</span>, <span data-ref="0046.g1:/ D F /">$DF$</span> are equal to the square on <span data-ref="0046.g1:/ B C /">$BC$</span>, so that the square on <span data-ref="0046.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0046.g1:A">$A$</span> by <sup>45</sup> the square on <span data-ref="0046.g1:/ D F /">$DF$</span>.
It is to be proved that <span data-ref="0046.g1:/ B C /">$BC$</span> is also commensurable with <span data-ref="0046.g1:/ D F /">$DF$</span>.
Since <span data-ref="0046.g1:/ B D /">$BD$</span> is commensurable in length with <span data-ref="0046.g1:/ D C /">$DC$</span>, therefore <span data-ref="0046.g1:/ B C /">$BC$</span> is also commensurable in length with <span data-ref="0046.g1:/ D C /">$CD$</span>. [X. 15]
