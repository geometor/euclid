<p class="sub-clause">Since <span data-ref="0049.g1:/ B D /">$BD$</span> is incommensurable in length with <span data-ref="0049.g1:/ D C /">$DC$</span>,</p>
<p class="assertion">therefore <span data-ref="0049.g1:/ B C /">$BC$</span> is also incommensurable in length with <span data-ref="0049.g1:/ C D /">$CD$</span>. <span class="justification">[X. 16]</span></p>

<p class="sub-clause">But <span data-ref="0049.g1:/ D C /">$DC$</span> is commensurable with the sum of <span data-ref="0049.g1:/ B F /">$BF$</span>, <span data-ref="0049.g1:/ D C /">$DC$</span>; <span class="justification">[X. 6]</span></p>
<p class="assertion">therefore <span data-ref="0049.g1:/ B C /">$BC$</span> is also incommensurable with the sum of <span data-ref="0049.g1:/ B F /">$BF$</span>,<br />
<span data-ref="0049.g1:/ D C /">$DC$</span>; <span class="justification">[X. 13]</span><br />
so that <span data-ref="0049.g1:/ B C /">$BC$</span> is also incommensurable in length with the remainder<br />
<span data-ref="0049.g1:/ F D /">$FD$</span>. <span class="justification">[X. 16]</span></p>

<p class="sub-clause">And the square on <span data-ref="0049.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0049.g1:A">$A$</span><br />
by the square on <span data-ref="0049.g1:/ F D /">$FD$</span>;</p>
<p class="assertion">therefore the square on <span data-ref="0049.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0049.g1:A">$A$</span><br />
by the square on a straight line incommensurable with <span data-ref="0049.g1:/ B C /">$BC$</span>.</p>

Again, let the square on <span data-ref="0049.g1:/ B C /">$BC$</span> be greater than the square on<br />
<span data-ref="0049.g1:A">$A$</span> by the square on a straight line incommensurable with <span data-ref="0049.g1:/ B C /">$BC$</span>,<br />
and let there be applied to <span data-ref="0049.g1:/ B C /">$BC$</span> a parallelogram equal to the<br />
fourth part of the square on <span data-ref="0049.g1:A">$A$</span> and deficient by a square figure.<br />
Let this be the rectangle <span data-ref="0049.g1:/ B D /">$BD$</span>, <span data-ref="0049.g1:/ D C /">$DC$</span>.

It is to be proved that <span data-ref="0049.g1:/ B D /">$BD$</span> is incommensurable in length<br />
with <span data-ref="0049.g1:/ D C /">$DC$</span>.

For, with the same construction, we can prove similarly<br />
that the square on <span data-ref="0049.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0049.g1:A">$A$</span> by<br />
the square on <span data-ref="0049.g1:/ F D /">$FD$</span>.

<p class="sub-clause">But the square on <span data-ref="0049.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0049.g1:A">$A$</span> by<br />
the square on a straight line incommensurable with <span data-ref="0049.g1:/ B C /">$BC$</span>;</p>
<p class="assertion">therefore <span data-ref="0049.g1:/ B C /">$BC$</span> is incommensurable in length with <span data-ref="0049.g1:/ F D /">$FD$</span>,<br />
so that <span data-ref="0049.g1:/ B C /">$BC$</span> is also incommensurable with the remainder, the<br />
sum of <span data-ref="0049.g1:/ B F /">$BF$</span>, <span data-ref="0049.g1:/ D C /">$DC$</span>. <span class="justification">[X. 16]</span></p>

<p class="sub-clause">But the sum of <span data-ref="0049.g1:/ B F /">$BF$</span>, <span data-ref="0049.g1:/ D C /">$DC$</span> is commensurable in length with<br />
<span data-ref="0049.g1:/ D C /">$DC$</span>; <span class="justification">[X. 6]</span></p>
<p class="assertion">therefore <span data-ref="0049.g1:/ B C /">$BC$</span> is also incommensurable in length with <span data-ref="0049.g1:/ D C /">$DC$</span>,<br />
<span class="justification">[X. 13]</span><br />
so that, *separando*, <span data-ref="0049.g1:/ B D /">$BD$</span> is also incommensurable in length with<br />
<span data-ref="0049.g1:/ D C /">$DC$</span>. <span class="justification">[X. 16]</span></p>

<p class="qed">Therefore etc.</p>
