Since <span data-ref="0049.g1:/ B D /">$BD$</span> is incommensurable in length with <span data-ref="0049.g1:/ D C /">$DC$</span>, therefore <span data-ref="0049.g1:/ B C /">$BC$</span> is also incommensurable in length with <span data-ref="0049.g1:/ C D /">$CD$</span>. [X. 16]
But <span data-ref="0049.g1:/ D C /">$DC$</span> is commensurable with the sum of <span data-ref="0049.g1:/ B F /">$BF$</span>, <span data-ref="0049.g1:/ D C /">$DC$</span>; [X. 6]
therefore <span data-ref="0049.g1:/ B C /">$BC$</span> is also incommensurable with the sum of <span data-ref="0049.g1:/ B F /">$BF$</span>, <span data-ref="0049.g1:/ D C /">$DC$</span>; [X. 13]
so that <span data-ref="0049.g1:/ B C /">$BC$</span> is also incommensurable in length with the remainder <span data-ref="0049.g1:/ F D /">$FD$</span>. [X. 16]
And the square on <span data-ref="0049.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0049.g1:A">$A$</span> by the square on <span data-ref="0049.g1:/ F D /">$FD$</span>;
therefore the square on <span data-ref="0049.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0049.g1:A">$A$</span> by the square on a straight line incommensurable with <span data-ref="0049.g1:/ B C /">$BC$</span>.

Again, let the square on <span data-ref="0049.g1:/ B C /">$BC$</span> be greater than the square on <span data-ref="0049.g1:A">$A$</span> by the square on a straight line incommensurable with <span data-ref="0049.g1:/ B C /">$BC$</span>, and let there be applied to <span data-ref="0049.g1:/ B C /">$BC$</span> a parallelogram equal to the fourth part of the square on <span data-ref="0049.g1:A">$A$</span> and deficient by a square figure. Let this be the rectangle <span data-ref="0049.g1:/ B D /">$BD$</span>, <span data-ref="0049.g1:/ D C /">$DC$</span>.
It is to be proved that <span data-ref="0049.g1:/ B D /">$BD$</span> is incommensurable in length with <span data-ref="0049.g1:/ D C /">$DC$</span>.
For, with the same construction, we can prove similarly that the square on <span data-ref="0049.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0049.g1:A">$A$</span> by the square on <span data-ref="0049.g1:/ F D /">$FD$</span>.
But the square on <span data-ref="0049.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0049.g1:A">$A$</span> by the square on a straight line incommensurable with <span data-ref="0049.g1:/ B C /">$BC$</span>;
therefore <span data-ref="0049.g1:/ B C /">$BC$</span> is incommensurable in length with <span data-ref="0049.g1:/ F D /">$FD$</span>, so that <span data-ref="0049.g1:/ B C /">$BC$</span> is also incommensurable with the remainder, the sum of <span data-ref="0049.g1:/ B F /">$BF$</span>, <span data-ref="0049.g1:/ D C /">$DC$</span>. [X. 16]
But the sum of <span data-ref="0049.g1:/ B F /">$BF$</span>, <span data-ref="0049.g1:/ D C /">$DC$</span> is commensurable in length with <span data-ref="0049.g1:/ D C /">$DC$</span>; [X. 6]
therefore <span data-ref="0049.g1:/ B C /">$BC$</span> is also incommensurable in length with <span data-ref="0049.g1:/ D C /">$DC$</span>, [X. 13]
so that, *separando*, <span data-ref="0049.g1:/ B D /">$BD$</span> is also incommensurable in length with <span data-ref="0049.g1:/ D C /">$DC$</span>. [X. 16]

Therefore etc.
