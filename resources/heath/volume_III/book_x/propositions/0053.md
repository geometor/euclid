### PROPOSITION 20.

<p class="enunciation">If a rational area be applied to a rational straight line, it<br />
produces as breadth a straight line rational and commensurable<br />
in length with the straight line to which it is applied.</p>

For let the rational area <span data-ref="0053.g1:< A C >">$AC$</span> be applied to <span data-ref="0053.g1:/ A B /">$AB$</span>, a straight<br />
line once more rational in any of the aforesaid<br />
ways, producing <span data-ref="0053.g1:/ B C /">$BC$</span> as breadth;<br />
I say that <span data-ref="0053.g1:/ B C /">$BC$</span> is rational and commensurable in<br />
length with <span data-ref="0053.g1:/ B A /">$BA$</span>.

For on <span data-ref="0053.g1:/ A B /">$AB$</span> let the square <span data-ref="0053.g1:< A D >">$AD$</span> be described;

<p class="assertion">therefore <span data-ref="0053.g1:< A D >">$AD$</span> is rational. <span class="justification">[X. Def. 4]</span></p>

<p class="sub-clause">But <span data-ref="0053.g1:< A C >">$AC$</span> is also rational;</p>

<p class="assertion">therefore <span data-ref="0053.g1:< D A >">$DA$</span> is commensurable with <span data-ref="0053.g1:< A C >">$AC$</span>.</p>

<p class="sub-clause">And, as <span data-ref="0053.g1:< D A >">$DA$</span> is to <span data-ref="0053.g1:< A C >">$AC$</span>, so is <span data-ref="0053.g1:/ D B /">$DB$</span> to <span data-ref="0053.g1:/ B C /">$BC$</span>. <span class="justification">[VI. 1]</span></p>

<p class="assertion">Therefore <span data-ref="0053.g1:/ D B /">$DB$</span> is also commensurable with <span data-ref="0053.g1:/ B C /">$BC$</span>; <span class="justification">[X. 11]</span></p>

<p class="sub-clause">and <span data-ref="0053.g1:/ D B /">$DB$</span> is equal to <span data-ref="0053.g1:/ B A /">$BA$</span>;</p>

<p class="assertion">therefore <span data-ref="0053.g1:/ A B /">$AB$</span> is also commensurable with <span data-ref="0053.g1:/ B C /">$BC$</span>.</p>

<p class="sub-clause">But <span data-ref="0053.g1:/ A B /">$AB$</span> is rational;</p>

<p class="assertion">therefore <span data-ref="0053.g1:/ B C /">$BC$</span> is also rational and commensurable in length<br />
with <span data-ref="0053.g1:/ A B /">$AB$</span>.</p>

<p class="qed">Therefore etc.</p>

---

The converse of the last. If $\rho$ is a rational straight line, any rational area<br />
is of the form $k\rho^2$. If this be "applied" to $\rho$, the breadth is $k\rho$ commensurable<br />
in length with $\rho$ and therefore rational. We should reach the same result if<br />
we applied the area to *another* rational straight line $\sigma$. The breadth is then
$$\frac{k\rho^2}{\sigma} = \frac{k\rho^2}{\sigma^2}\cdot \sigma = \frac{m}{n}k\cdot \sigma \text{ or } k'\sigma\text{, say.}$$
