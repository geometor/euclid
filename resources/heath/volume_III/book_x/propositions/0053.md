### PROPOSITION 20.

*If a rational area be applied to a rational straight line, it produces as breadth a straight line rational and commensurable in length with the straight line to which it is applied.*

For let the rational area <span data-ref="0053.g1:< A C >">$AC$</span> be applied to <span data-ref="0053.g1:/ A B /">$AB$</span>, a straight line once more rational in any of the aforesaid ways, producing <span data-ref="0053.g1:/ B C /">$BC$</span> as breadth;
I say that <span data-ref="0053.g1:/ B C /">$BC$</span> is rational and commensurable in length with <span data-ref="0053.g1:/ B A /">$BA$</span>.
For on <span data-ref="0053.g1:/ A B /">$AB$</span> let the square <span data-ref="0053.g1:< A D >">$AD$</span> be described;
therefore <span data-ref="0053.g1:< A D >">$AD$</span> is rational. [X. Def. 4]
But <span data-ref="0053.g1:< A C >">$AC$</span> is also rational;
therefore <span data-ref="0053.g1:< D A >">$DA$</span> is commensurable with <span data-ref="0053.g1:< A C >">$AC$</span>.
And, as <span data-ref="0053.g1:< D A >">$DA$</span> is to <span data-ref="0053.g1:< A C >">$AC$</span>, so is <span data-ref="0053.g1:/ D B /">$DB$</span> to <span data-ref="0053.g1:/ B C /">$BC$</span>. [VI. 1]
Therefore <span data-ref="0053.g1:/ D B /">$DB$</span> is also commensurable with <span data-ref="0053.g1:/ B C /">$BC$</span>; [X. 11]
and <span data-ref="0053.g1:/ D B /">$DB$</span> is equal to <span data-ref="0053.g1:/ B A /">$BA$</span>;
therefore <span data-ref="0053.g1:/ A B /">$AB$</span> is also commensurable with <span data-ref="0053.g1:/ B C /">$BC$</span>.
But <span data-ref="0053.g1:/ A B /">$AB$</span> is rational;
therefore <span data-ref="0053.g1:/ B C /">$BC$</span> is also rational and commensurable in length with <span data-ref="0053.g1:/ A B /">$AB$</span>.

Therefore etc.

---

The converse of the last. If $\rho$ is a rational straight line, any rational area is of the form $k\rho^2$. If this be "applied" to $\rho$, the breadth is $k\rho$ commensurable in length with $\rho$ and therefore rational. We should reach the same result if we applied the area to *another* rational straight line $\sigma$. The breadth is then
$$\frac{k\rho^2}{\sigma} = \frac{k\rho^2}{\sigma^2}\cdot \sigma = \frac{m}{n}k\cdot \sigma \text{ or } k'\sigma\text{, say.}$$
