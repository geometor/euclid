PROPOSITION 20.
---------------

.. enunciation::

   If a rational area be applied to a rational straight line, it produces as breadth a straight line rational and commensurable in length with the straight line to which it is applied.

| For let the rational area :g:`$AC$ <0053.g1:< A C >>` be applied to :g:`$AB$ <0053.g1:/ A B />`, a straight
| line once more rational in any of the aforesaid
| ways, producing :g:`$BC$ <0053.g1:/ B C />` as breadth;
| I say that :g:`$BC$ <0053.g1:/ B C />` is rational and commensurable in
| length with :g:`$BA$ <0053.g1:/ B A />`.

For on :g:`$AB$ <0053.g1:/ A B />` let the square :g:`$AD$ <0053.g1:< A D >>` be described;

.. assertion:: [X. Def. 4] <X.def.4>

   therefore :g:`$AD$ <0053.g1:< A D >>` is rational.

.. subclause::

   But :g:`$AC$ <0053.g1:< A C >>` is also rational;

.. assertion::

   therefore :g:`$DA$ <0053.g1:< D A >>` is commensurable with :g:`$AC$ <0053.g1:< A C >>`.

.. subclause:: [VI. 1] <VI.1>

   And, as :g:`$DA$ <0053.g1:< D A >>` is to :g:`$AC$ <0053.g1:< A C >>`, so is :g:`$DB$ <0053.g1:/ D B />` to :g:`$BC$ <0053.g1:/ B C />`.

.. assertion:: [X. 11] <X.11>

   Therefore :g:`$DB$ <0053.g1:/ D B />` is also commensurable with :g:`$BC$ <0053.g1:/ B C />`;

.. subclause::

   and :g:`$DB$ <0053.g1:/ D B />` is equal to :g:`$BA$ <0053.g1:/ B A />`;

.. assertion::

   therefore :g:`$AB$ <0053.g1:/ A B />` is also commensurable with :g:`$BC$ <0053.g1:/ B C />`.

.. subclause::

   But :g:`$AB$ <0053.g1:/ A B />` is rational;

.. assertion::

   | therefore :g:`$BC$ <0053.g1:/ B C />` is also rational and commensurable in length
   | with :g:`$AB$ <0053.g1:/ A B />`.

.. qed::

   Therefore etc.

----

| The converse of the last. If $\rho$ is a rational straight line, any rational area
| is of the form $k\rho^2$. If this be "applied" to $\rho$, the breadth is $k\rho$ commensurable
| in length with $\rho$ and therefore rational. We should reach the same result if
| we applied the area to *another* rational straight line $\sigma$. The breadth is then

$$\frac{k\rho^2}{\sigma} = \frac{k\rho^2}{\sigma^2}\cdot \sigma = \frac{m}{n}k\cdot \sigma \text{ or } k'\sigma\text{, say.}$$
