### Proposition 23.

*A straight line commensurable with a medial straight line is medial.*

![Proposition 23](0057.g1.svg)

Let <span data-ref="0057.g1:A">$A$</span> be medial, and let <span data-ref="0057.g1:B">$B$</span> be commensurable with <span data-ref="0057.g1:A">$A$</span>;
I say that <span data-ref="0057.g1:B">$B$</span> is also medial.

For let a rational straight line <span data-ref="0057.g1:/ C D /">$CD$</span> be set out,
and to <span data-ref="0057.g1:/ C D /">$CD$</span> let the rectangular area <span data-ref="0057.g1:< C E >">$CE$</span> equal to the square on <span data-ref="0057.g1:A">$A$</span> be applied, producing <span data-ref="0057.g1:/ E D /">$ED$</span> as breadth;
therefore <span data-ref="0057.g1:/ E D /">$ED$</span> is rational and incommensurable in length with <span data-ref="0057.g1:/ C D /">$CD$</span>. [x. 22]
And let the rectangular area <span data-ref="0057.g1:< C F >">$CF$</span> equal to the square on <span data-ref="0057.g1:B">$B$</span> be applied to <span data-ref="0057.g1:/ C D /">$CD$</span>, producing <span data-ref="0057.g1:/ D F /">$DF$</span> as breadth.
Since then <span data-ref="0057.g1:A">$A$</span> is commensurable with <span data-ref="0057.g1:B">$B$</span>,
the square on <span data-ref="0057.g1:A">$A$</span> is also commensurable with the square on <span data-ref="0057.g1:B">$B$</span>.
But <span data-ref="0057.g1:< E C >">$EC$</span> is equal to the square on <span data-ref="0057.g1:A">$A$</span>,
and <span data-ref="0057.g1:< C F >">$CF$</span> is equal to the square on <span data-ref="0057.g1:B">$B$</span>;
therefore <span data-ref="0057.g1:< E C >">$EC$</span> is commensurable with <span data-ref="0057.g1:< C F >">$CF$</span>.
And, as <span data-ref="0057.g1:< E C >">$EC$</span> is to <span data-ref="0057.g1:< C F >">$CF$</span>, so is <span data-ref="0057.g1:/ E D /">$ED$</span> to <span data-ref="0057.g1:/ D F /">$DF$</span>; [VI. 1]
therefore <span data-ref="0057.g1:/ E D /">$ED$</span> is commensurable in length with <span data-ref="0057.g1:/ D F /">$DF$</span>. [x. 11]
But <span data-ref="0057.g1:/ E D /">$ED$</span> is rational and incommensurable in length with <span data-ref="0057.g1:/ D C /">$DC$</span>;
therefore <span data-ref="0057.g1:/ D F /">$DF$</span> is also rational [x. Def. 3] and incommensurable in length with <span data-ref="0057.g1:/ D C /">$DC$</span>. [x. 13]
Therefore <span data-ref="0057.g1:/ C D /">$CD$</span>, <span data-ref="0057.g1:/ D F /">$DF$</span> are rational and commensurable in square only.
