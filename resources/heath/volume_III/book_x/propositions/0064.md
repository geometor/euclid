$$y^2 + z^2 \frown y^2,$$
and
$$2yz \frown yz.$$
Therefore
$$y^2 + z^2 \smile 2yz,$$
whence
$$(y + z)^2 \smile (y^2 + z^2),$$
or
$$x^2 \smile (y^2 + z^2).$$
And $(y^2 + z^2)$ is rational;<br />
therefore $x^2$, and consequently $x$, is irrational.

But, by (2), $x$ is rational:<br />

### PROPOSITION 27.

<p class="enunciation">To find medial straight lines commensurable in square only<br />
which contain a rational rectangle.</p>

Let two rational straight lines <span data-ref="0064.g1:A">$A$</span>, <span data-ref="0064.g1:B">$B$</span> commensurable in<br />
square only be set out;<br />
let <span data-ref="0064.g1:C">$C$</span> be taken a mean proportional between<br />
<span data-ref="0064.g1:A">$A$</span>, <span data-ref="0064.g1:B">$B$</span>, <span class="justification">[VI. 13]</span><br />
and let it be contrived that,<br />
as <span data-ref="0064.g1:A">$A$</span> is to <span data-ref="0064.g1:B">$B$</span>, so is <span data-ref="0064.g1:C">$C$</span> to <span data-ref="0064.g1:D">$D$</span>. <span class="justification">[VI. 12]</span>

<p class="sub-clause">Then, since <span data-ref="0064.g1:A">$A$</span>, <span data-ref="0064.g1:B">$B$</span> are rational and com-<br />
mensurable in square only,</p>
<p class="assertion">the rectangle <span data-ref="0064.g1:A">$A$</span>, <span data-ref="0064.g1:B">$B$</span>, that is, the square on <span data-ref="0064.g1:C">$C$</span><br />
<span class="justification">[VI. 17]</span>, is medial. <span class="justification">[X. 21]</span></p>

<p class="assertion">Therefore <span data-ref="0064.g1:C">$C$</span> is medial. <span class="justification">[X. 21]</span></p>

![Proposition 27 diagram](0064.g1.svg)

<p class="sub-clause">And since, as <span data-ref="0064.g1:A">$A$</span> is to <span data-ref="0064.g1:B">$B$</span>, so is <span data-ref="0064.g1:C">$C$</span> to <span data-ref="0064.g1:D">$D$</span>,<br />
and <span data-ref="0064.g1:A">$A$</span>, <span data-ref="0064.g1:B">$B$</span> are commensurable in square only,</p>
<p class="assertion">therefore <span data-ref="0064.g1:C">$C$</span>, <span data-ref="0064.g1:D">$D$</span> are also commensurable in square only. <span class="justification">[X. 11]</span></p>

<p class="sub-clause">And <span data-ref="0064.g1:C">$C$</span> is medial;</p>
<p class="assertion">therefore <span data-ref="0064.g1:D">$D$</span> is also medial. <span class="justification">[X. 23, addition]</span></p>

<p class="assertion">Therefore <span data-ref="0064.g1:C">$C$</span>, <span data-ref="0064.g1:D">$D$</span> are medial and commensurable in square<br />
only.</p>

I say that they also contain a rational rectangle.

<p class="sub-clause">For since, as <span data-ref="0064.g1:A">$A$</span> is to <span data-ref="0064.g1:B">$B$</span>, so is <span data-ref="0064.g1:C">$C$</span> to <span data-ref="0064.g1:D">$D$</span>,</p>
<p class="assertion">therefore, alternately, as <span data-ref="0064.g1:A">$A$</span> is to <span data-ref="0064.g1:C">$C$</span>, so is <span data-ref="0064.g1:B">$B$</span> to <span data-ref="0064.g1:D">$D$</span>. <span class="justification">[V. 16]</span></p>

<p class="sub-clause">But, as <span data-ref="0064.g1:A">$A$</span> is to <span data-ref="0064.g1:C">$C$</span>, so is <span data-ref="0064.g1:C">$C$</span> to <span data-ref="0064.g1:B">$B$</span>;</p>
<p class="assertion">therefore also, as <span data-ref="0064.g1:C">$C$</span> is to <span data-ref="0064.g1:B">$B$</span>, so is <span data-ref="0064.g1:B">$B$</span> to <span data-ref="0064.g1:D">$D$</span>;</p>
<p class="assertion">therefore the rectangle <span data-ref="0064.g1:C">$C$</span>, <span data-ref="0064.g1:D">$D$</span> is equal to the square on <span data-ref="0064.g1:B">$B$</span>.</p>
