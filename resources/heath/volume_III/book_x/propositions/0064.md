$$y^2 + z^2 \frown y^2,$$
and

Therefore

whence
$$(y + z)^2 \smile (y^2 + z^2),$$
or

### PROPOSITION 27.

*To find medial straight lines commensurable in square only
which contain a rational rectangle.*

Let two rational straight lines <span data-ref="0064.g1:A">$A$</span>, <span data-ref="0064.g1:B">$B$</span> commensurable in
square only be set out;
let <span data-ref="0064.g1:C">$C$</span> be taken a mean proportional between
<span data-ref="0064.g1:A">$A$</span>, <span data-ref="0064.g1:B">$B$</span>, [VI. 13]
and let it be contrived that,
<p style="text-align: center;">as <span data-ref="0064.g1:A">$A$</span> is to <span data-ref="0064.g1:B">$B$</span>, so is <span data-ref="0064.g1:C">$C$</span> to <span data-ref="0064.g1:D">$D$</span>. <span style="float: right;">[VI. 12]</span></p>
Then, since <span data-ref="0064.g1:A">$A$</span>, <span data-ref="0064.g1:B">$B$</span> are rational and com-
mensurable in square only,
the rectangle <span data-ref="0064.g1:A">$A$</span>, <span data-ref="0064.g1:B">$B$</span>, that is, the square on <span data-ref="0064.g1:C">$C$</span>
[VI. 17], is medial. [x. 21]

Therefore <span data-ref="0064.g1:C">$C$</span> is medial. [x. 21]

![Proposition 27 diagram](0064.g1.svg)

And since, as <span data-ref="0064.g1:A">$A$</span> is to <span data-ref="0064.g1:B">$B$</span>, so is <span data-ref="0064.g1:C">$C$</span> to <span data-ref="0064.g1:D">$D$</span>,
and <span data-ref="0064.g1:A">$A$</span>, <span data-ref="0064.g1:B">$B$</span> are commensurable in square only,
therefore <span data-ref="0064.g1:C">$C$</span>, <span data-ref="0064.g1:D">$D$</span> are also commensurable in square only. [x. 11]

And <span data-ref="0064.g1:C">$C$</span> is medial;
therefore <span data-ref="0064.g1:D">$D$</span> is also medial. [x. 23, addition]

Therefore <span data-ref="0064.g1:C">$C$</span>, <span data-ref="0064.g1:D">$D$</span> are medial and commensurable in square
only.

I say that they also contain a rational rectangle.

For since, as <span data-ref="0064.g1:A">$A$</span> is to <span data-ref="0064.g1:B">$B$</span>, so is <span data-ref="0064.g1:C">$C$</span> to <span data-ref="0064.g1:D">$D$</span>,
therefore, alternately, as <span data-ref="0064.g1:A">$A$</span> is to <span data-ref="0064.g1:C">$C$</span>, so is <span data-ref="0064.g1:B">$B$</span> to <span data-ref="0064.g1:D">$D$</span>. [v. 16]

But, as <span data-ref="0064.g1:A">$A$</span> is to <span data-ref="0064.g1:C">$C$</span>, so is <span data-ref="0064.g1:C">$C$</span> to <span data-ref="0064.g1:B">$B$</span>;
therefore also, as <span data-ref="0064.g1:C">$C$</span> is to <span data-ref="0064.g1:B">$B$</span>, so is <span data-ref="0064.g1:B">$B$</span> to <span data-ref="0064.g1:D">$D$</span>;
therefore the rectangle <span data-ref="0064.g1:C">$C$</span>, <span data-ref="0064.g1:D">$D$</span> is equal to the square on <span data-ref="0064.g1:B">$B$</span>.
