Therefore <span data-ref="0065.g1:D">$D$</span> is medial. [x. 21]

And since <span data-ref="0065.g1:B">$B$</span>, <span data-ref="0065.g1:C">$C$</span> are commensurable in square only,
and, as <span data-ref="0065.g1:B">$B$</span> is to <span data-ref="0065.g1:C">$C$</span>, so is <span data-ref="0065.g1:D">$D$</span> to <span data-ref="0065.g1:E">$E$</span>,
therefore <span data-ref="0065.g1:D">$D$</span>, <span data-ref="0065.g1:E">$E$</span> are also commensurable in square only. [x. 11]

But <span data-ref="0065.g1:D">$D$</span> is medial;
therefore <span data-ref="0065.g1:E">$E$</span> is also medial. [x. 23, addition]

Therefore <span data-ref="0065.g1:D">$D$</span>, <span data-ref="0065.g1:E">$E$</span> are medial straight lines commensurable
in square only.

I say next that they also contain a medial rectangle.

For since, as <span data-ref="0065.g1:B">$B$</span> is to <span data-ref="0065.g1:C">$C$</span>, so is <span data-ref="0065.g1:D">$D$</span> to <span data-ref="0065.g1:E">$E$</span>,
therefore, alternately, as <span data-ref="0065.g1:B">$B$</span> is to <span data-ref="0065.g1:D">$D$</span>, so is <span data-ref="0065.g1:C">$C$</span> to <span data-ref="0065.g1:E">$E$</span>. [v. 16]

But, as <span data-ref="0065.g1:B">$B$</span> is to <span data-ref="0065.g1:D">$D$</span>, so is <span data-ref="0065.g1:D">$D$</span> to <span data-ref="0065.g1:A">$A$</span>;
therefore also, as <span data-ref="0065.g1:D">$D$</span> is to <span data-ref="0065.g1:A">$A$</span>, so is <span data-ref="0065.g1:C">$C$</span> to <span data-ref="0065.g1:E">$E$</span>;
therefore the rectangle <span data-ref="0065.g1:A">$A$</span>, <span data-ref="0065.g1:C">$C$</span> is equal to the rectangle <span data-ref="0065.g1:D">$D$</span>, <span data-ref="0065.g1:E">$E$</span>.
[VI. 16]

But the rectangle <span data-ref="0065.g1:A">$A$</span>, <span data-ref="0065.g1:C">$C$</span> is medial; [x. 21]
therefore the rectangle <span data-ref="0065.g1:D">$D$</span>, <span data-ref="0065.g1:E">$E$</span> is also medial.

Therefore medial straight lines commensurable in square
only have been found which contain a medial rectangle.

Q. E. D.

Euclid takes three straight lines commensurable in square only, i.e. of the
form $\rho$, $k^{\frac{1}{2}}\rho$, $\lambda^{\frac{1}{2}}\rho$, and proceeds as follows.
Take the mean proportional to $\rho$, $k^{\frac{1}{2}}\rho$, i.e. $k^{\frac{1}{4}}\rho$.
Then take $x$ such that
$$k^{\frac{1}{2}}\rho : \lambda^{\frac{1}{2}}\rho = k^{\frac{1}{4}}\rho : x \ \text{.........................................(1),}$$
so that $x = \lambda^{\frac{1}{2}}\rho / k^{\frac{1}{4}}$.
$k^{\frac{1}{4}}\rho$, $\lambda^{\frac{1}{2}}\rho / k^{\frac{1}{4}}$ are the required medial straight lines.
For $k^{\frac{1}{4}}\rho$ is medial.
Now, by (1), since $k^{\frac{1}{2}}\rho \sim \lambda^{\frac{1}{2}}\rho$,
$$k^{\frac{1}{4}}\rho \sim x,$$
whence $x$ is also medial [x. 23, addition], while $\sim k^{\frac{1}{4}}\rho$.
Next, by (1),
$$\lambda^{\frac{1}{2}}\rho : x = k^{\frac{1}{2}}\rho : k^{\frac{1}{4}}\rho$$
$$= k^{\frac{1}{4}}\rho : \rho,$$
whence
$$x \,.\, k^{\frac{1}{4}}\rho = \lambda^{\frac{1}{2}}\rho^2\text{, which is medial.}$$

The straight lines $k^{\frac{1}{4}}\rho$, $\lambda^{\frac{1}{2}}\rho / k^{\frac{1}{4}}$ of course take different forms according as
the original straight lines are of the forms (1) $a$, $\sqrt{B}$, $\sqrt{C}$, (2) $\sqrt{A}$, $\sqrt{B}$, $\sqrt{C}$,
(3) $\sqrt{A}$, $b$, $\sqrt{C}$, and (4) $\sqrt{A}$, $\sqrt{B}$, $c$.
