<p class="sub-clause">Since, as the square on <span data-ref="0071.g1:/ B A /">$BA$</span> is to<br />
the square on <span data-ref="0071.g1:/ A F /">$AF$</span>, so is <span data-ref="0071.g1:/ D C /">$DC$</span> to <span data-ref="0071.g1:/ C E /">$CE$</span>,</p>

<p class="assertion">therefore the square on <span data-ref="0071.g1:/ B A /">$BA$</span> has to<br />
the square on <span data-ref="0071.g1:/ A F /">$AF$</span> the ratio which the<br />
number <span data-ref="0071.g1:/ D C /">$DC$</span> has to the number <span data-ref="0071.g1:/ C E /">$CE$</span>;<br />
therefore the square on <span data-ref="0071.g1:/ B A /">$BA$</span> is com-<br />
mensurable with the square on <span data-ref="0071.g1:/ A F /">$AF$</span>. <span class="justification">[X. 6]</span></p>

<p class="sub-clause">But the square on <span data-ref="0071.g1:/ A B /">$AB$</span> is rational; <span class="justification">[X. Def. 4]</span></p>

<p class="assertion">therefore the square on <span data-ref="0071.g1:/ A F /">$AF$</span> is also rational; <span class="justification">[id.]</span><br />
therefore <span data-ref="0071.g1:/ A F /">$AF$</span> is also rational.</p>

<p class="sub-clause">And, since <span data-ref="0071.g1:/ D C /">$DC$</span> has not to <span data-ref="0071.g1:/ C E /">$CE$</span> the ratio which a square<br />
number has to a square number,</p>

<p class="assertion">neither has the square on <span data-ref="0071.g1:/ B A /">$BA$</span> to the square on <span data-ref="0071.g1:/ A F /">$AF$</span> the ratio<br />
which a square number has to a square number;<br />
therefore <span data-ref="0071.g1:/ A B /">$AB$</span> is incommensurable in length with <span data-ref="0071.g1:/ A F /">$AF$</span>. <span class="justification">[X. 9]</span></p>

<p class="assertion">Therefore <span data-ref="0071.g1:/ B A /">$BA$</span>, <span data-ref="0071.g1:/ A F /">$AF$</span> are rational straight lines commen-<br />
surable in square only.</p>

<p class="sub-clause">And since, as <span data-ref="0071.g1:/ D C /">$DC$</span> is to <span data-ref="0071.g1:/ C E /">$CE$</span>, so is the square on <span data-ref="0071.g1:/ B A /">$BA$</span> to<br />
the square on <span data-ref="0071.g1:/ A F /">$AF$</span>,</p>

<p class="assertion">therefore, <em>convertendo</em>, as <span data-ref="0071.g1:/ C D /">$CD$</span> is to <span data-ref="0071.g1:/ E D /">$DE$</span>, so is the square on<br />
<span data-ref="0071.g1:/ A B /">$AB$</span> to the square on <span data-ref="0071.g1:/ B F /">$BF$</span>. <span class="justification">[V. 19, Por., III. 31, I. 47]</span></p>

<p class="sub-clause">But <span data-ref="0071.g1:/ C D /">$CD$</span> has to <span data-ref="0071.g1:/ E D /">$DE$</span> the ratio which a square number has<br />
to a square number;</p>

<p class="assertion">therefore also the square on <span data-ref="0071.g1:/ A B /">$AB$</span> has to the square on <span data-ref="0071.g1:/ B F /">$BF$</span><br />
the ratio which a square number has to a square number;<br />
therefore <span data-ref="0071.g1:/ A B /">$AB$</span> is commensurable in length with <span data-ref="0071.g1:/ B F /">$BF$</span>. <span class="justification">[X. 9]</span></p>

<p class="sub-clause">And the square on <span data-ref="0071.g1:/ A B /">$AB$</span> is equal to the squares on <span data-ref="0071.g1:/ A F /">$AF$</span>, <span data-ref="0071.g1:/ F B /">$FB$</span>;</p>

<p class="assertion">therefore the square on <span data-ref="0071.g1:/ A B /">$AB$</span> is greater than the square on <span data-ref="0071.g1:/ A F /">$AF$</span><br />
by the square on <span data-ref="0071.g1:/ B F /">$BF$</span> commensurable with <span data-ref="0071.g1:/ A B /">$AB$</span>.</p>

<p class="qed">Therefore there have been found two rational straight<br />
lines <span data-ref="0071.g1:/ B A /">$BA$</span>, <span data-ref="0071.g1:/ A F /">$AF$</span> commensurable in square only and such that<br />
the square on the greater <span data-ref="0071.g1:/ A B /">$AB$</span> is greater than the square on<br />
the less <span data-ref="0071.g1:/ A F /">$AF$</span> by the square on <span data-ref="0071.g1:/ B F /">$BF$</span> commensurable in length<br />
with <span data-ref="0071.g1:/ A B /">$AB$</span>.</p>
