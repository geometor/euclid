and let it be contrived that,
as <span data-ref="0071.g1:/ D C /">$DC$</span> is to <span data-ref="0071.g1:/ C E /">$CE$</span>, so is the square on <span data-ref="0071.g1:/ B A /">$BA$</span> to the square on <span data-ref="0071.g1:/ A F /">$AF$</span>. [x. 6, Por.]
Let <span data-ref="0071.g1:/ F B /">$FB$</span> be joined.

![Proposition 29](0071.g1.svg)

Since, as the square on <span data-ref="0071.g1:/ B A /">$BA$</span> is to the square on <span data-ref="0071.g1:/ A F /">$AF$</span>, so is <span data-ref="0071.g1:/ D C /">$DC$</span> to <span data-ref="0071.g1:/ C E /">$CE$</span>, therefore the square on <span data-ref="0071.g1:/ B A /">$BA$</span> has to the square on <span data-ref="0071.g1:/ A F /">$AF$</span> the ratio which the number <span data-ref="0071.g1:/ D C /">$DC$</span> has to the number <span data-ref="0071.g1:/ C E /">$CE$</span>; therefore the square on <span data-ref="0071.g1:/ B A /">$BA$</span> is commensurable with the square on <span data-ref="0071.g1:/ A F /">$AF$</span>. [x. 6]

But the square on <span data-ref="0071.g1:/ A B /">$AB$</span> is rational; [x. Def. 4] therefore the square on <span data-ref="0071.g1:/ A F /">$AF$</span> is also rational; [id.] therefore <span data-ref="0071.g1:/ A F /">$AF$</span> is also rational.

And, since <span data-ref="0071.g1:/ D C /">$DC$</span> has not to <span data-ref="0071.g1:/ C E /">$CE$</span> the ratio which a square number has to a square number, neither has the square on <span data-ref="0071.g1:/ B A /">$BA$</span> to the square on <span data-ref="0071.g1:/ A F /">$AF$</span> the ratio which a square number has to a square number; therefore <span data-ref="0071.g1:/ A B /">$AB$</span> is incommensurable in length with <span data-ref="0071.g1:/ A F /">$AF$</span>. [x. 9]

Therefore <span data-ref="0071.g1:/ B A /">$BA$</span>, <span data-ref="0071.g1:/ A F /">$AF$</span> are rational straight lines commensurable in square only.

And since, as <span data-ref="0071.g1:/ D C /">$DC$</span> is to <span data-ref="0071.g1:/ C E /">$CE$</span>, so is the square on <span data-ref="0071.g1:/ B A /">$BA$</span> to the square on <span data-ref="0071.g1:/ A F /">$AF$</span>, therefore, *convertendo*, as <span data-ref="0071.g1:/ C D /">$CD$</span> is to <span data-ref="0071.g1:/ E D /">$DE$</span>, so is the square on <span data-ref="0071.g1:/ A B /">$AB$</span> to the square on <span data-ref="0071.g1:/ B F /">$BF$</span>. [v. 19, Por., iii. 31, i. 47]

But <span data-ref="0071.g1:/ C D /">$CD$</span> has to <span data-ref="0071.g1:/ E D /">$DE$</span> the ratio which a square number has to a square number; therefore also the square on <span data-ref="0071.g1:/ A B /">$AB$</span> has to the square on <span data-ref="0071.g1:/ B F /">$BF$</span> the ratio which a square number has to a square number; therefore <span data-ref="0071.g1:/ A B /">$AB$</span> is commensurable in length with <span data-ref="0071.g1:/ B F /">$BF$</span>. [x. 9]

And the square on <span data-ref="0071.g1:/ A B /">$AB$</span> is equal to the squares on <span data-ref="0071.g1:/ A F /">$AF$</span>, <span data-ref="0071.g1:/ F B /">$FB$</span>; therefore the square on <span data-ref="0071.g1:/ A B /">$AB$</span> is greater than the square on <span data-ref="0071.g1:/ A F /">$AF$</span> by the square on <span data-ref="0071.g1:/ B F /">$BF$</span> commensurable with <span data-ref="0071.g1:/ A B /">$AB$</span>.

Therefore there have been found two rational straight lines <span data-ref="0071.g1:/ B A /">$BA$</span>, <span data-ref="0071.g1:/ A F /">$AF$</span> commensurable in square only and such that the square on the greater <span data-ref="0071.g1:/ A B /">$AB$</span> is greater than the square on the less <span data-ref="0071.g1:/ A F /">$AF$</span> by the square on <span data-ref="0071.g1:/ B F /">$BF$</span> commensurable in length with <span data-ref="0071.g1:/ A B /">$AB$</span>.
