Let there be set out three rational straight lines <span data-ref="0076.g1:A">$A$</span>, <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span> commensurable in square only, and such that the square on <span data-ref="0076.g1:A">$A$</span> is greater than the square on <span data-ref="0076.g1:C">$C$</span> by the square on a straight line commensurable with <span data-ref="0076.g1:A">$A$</span>, [x. 29]
and let the square on <span data-ref="0076.g1:D">$D$</span> be equal to the rectangle <span data-ref="0076.g1:A">$A$</span>, <span data-ref="0076.g1:B">$B$</span>.

![Proposition 32 diagram](0076.g1.svg)

Therefore the square on <span data-ref="0076.g1:D">$D$</span> is medial ;
therefore <span data-ref="0076.g1:D">$D$</span> is also medial. [x. 21]

Let the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span> be equal to the rectangle <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span>.

Then since, as the rectangle <span data-ref="0076.g1:A">$A$</span>, <span data-ref="0076.g1:B">$B$</span> is to the rectangle <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span>, so is <span data-ref="0076.g1:A">$A$</span> to <span data-ref="0076.g1:C">$C$</span>,
while the square on <span data-ref="0076.g1:D">$D$</span> is equal to the rectangle <span data-ref="0076.g1:A">$A$</span>, <span data-ref="0076.g1:B">$B$</span>,
and the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span> is equal to the rectangle <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span>,
therefore, as <span data-ref="0076.g1:A">$A$</span> is to <span data-ref="0076.g1:C">$C$</span>, so is the square on <span data-ref="0076.g1:D">$D$</span> to the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span>.

But, as the square on <span data-ref="0076.g1:D">$D$</span> is to the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span>, so is <span data-ref="0076.g1:D">$D$</span> to <span data-ref="0076.g1:E">$E$</span> ;
therefore also, as <span data-ref="0076.g1:A">$A$</span> is to <span data-ref="0076.g1:C">$C$</span>, so is <span data-ref="0076.g1:D">$D$</span> to <span data-ref="0076.g1:E">$E$</span>.

But <span data-ref="0076.g1:A">$A$</span> is commensurable with <span data-ref="0076.g1:C">$C$</span> in square only ;
therefore <span data-ref="0076.g1:D">$D$</span> is also commensurable with <span data-ref="0076.g1:E">$E$</span> in square only. [x. 11]

*But <span data-ref="0076.g1:D">$D$</span> is medial ;*
therefore <span data-ref="0076.g1:E">$E$</span> is also medial. [x. 23, addition]

And, since, as <span data-ref="0076.g1:A">$A$</span> is to <span data-ref="0076.g1:C">$C$</span>, so is <span data-ref="0076.g1:D">$D$</span> to <span data-ref="0076.g1:E">$E$</span>,
while the square on <span data-ref="0076.g1:A">$A$</span> is greater than the square on <span data-ref="0076.g1:C">$C$</span> by the square on a straight line commensurable with <span data-ref="0076.g1:A">$A$</span>,
therefore also the square on <span data-ref="0076.g1:D">$D$</span> will be greater than the square on <span data-ref="0076.g1:E">$E$</span> by the square on a straight line commensurable with <span data-ref="0076.g1:D">$D$</span>. [x. 14]

I say next that the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span> is also medial.

For, since the rectangle <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span> is equal to the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span>,
while the rectangle <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span> is medial, [x. 21]
therefore the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span> is also medial.
