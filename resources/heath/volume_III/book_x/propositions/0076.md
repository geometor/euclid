Let there be set out three rational straight lines <span data-ref="0076.g1:A">$A$</span>, <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span><br />
commensurable in square only, and such that the square on <span data-ref="0076.g1:A">$A$</span><br />
is greater than the square on <span data-ref="0076.g1:C">$C$</span> by the square on a straight<br />
line commensurable with <span data-ref="0076.g1:A">$A$</span>, <span class="justification">[X. 29]</span><br />
and let the square on <span data-ref="0076.g1:D">$D$</span> be equal to the rectangle <span data-ref="0076.g1:A">$A$</span>, <span data-ref="0076.g1:B">$B$</span>.

<p class="assertion">Therefore the square on <span data-ref="0076.g1:D">$D$</span> is medial ;<br />
therefore <span data-ref="0076.g1:D">$D$</span> is also medial. <span class="justification">[X. 21]</span></p>

Let the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span> be equal to the rectangle <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span>.

<p class="sub-clause">Then since, as the rectangle <span data-ref="0076.g1:A">$A$</span>, <span data-ref="0076.g1:B">$B$</span> is to the rectangle <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span>,<br />
so is <span data-ref="0076.g1:A">$A$</span> to <span data-ref="0076.g1:C">$C$</span>,<br />
while the square on <span data-ref="0076.g1:D">$D$</span> is equal to the rectangle <span data-ref="0076.g1:A">$A$</span>, <span data-ref="0076.g1:B">$B$</span>,<br />
and the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span> is equal to the rectangle <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0076.g1:A">$A$</span> is to <span data-ref="0076.g1:C">$C$</span>, so is the square on <span data-ref="0076.g1:D">$D$</span> to the rectangle<br />
<span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span>.</p>

<p class="sub-clause">But, as the square on <span data-ref="0076.g1:D">$D$</span> is to the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span>, so is <span data-ref="0076.g1:D">$D$</span><br />
to <span data-ref="0076.g1:E">$E$</span> ;</p>
<p class="assertion">therefore also, as <span data-ref="0076.g1:A">$A$</span> is to <span data-ref="0076.g1:C">$C$</span>, so is <span data-ref="0076.g1:D">$D$</span> to <span data-ref="0076.g1:E">$E$</span>.</p>

<p class="sub-clause">But <span data-ref="0076.g1:A">$A$</span> is commensurable with <span data-ref="0076.g1:C">$C$</span> in square only ;</p>
<p class="assertion">therefore <span data-ref="0076.g1:D">$D$</span> is also commensurable with <span data-ref="0076.g1:E">$E$</span> in square only. <span class="justification">[X. 11]</span></p>

<p class="sub-clause">But <span data-ref="0076.g1:D">$D$</span> is medial ;</p>
<p class="assertion">therefore <span data-ref="0076.g1:E">$E$</span> is also medial. <span class="justification">[X. 23, addition]</span></p>

<p class="sub-clause">And, since, as <span data-ref="0076.g1:A">$A$</span> is to <span data-ref="0076.g1:C">$C$</span>, so is <span data-ref="0076.g1:D">$D$</span> to <span data-ref="0076.g1:E">$E$</span>,<br />
while the square on <span data-ref="0076.g1:A">$A$</span> is greater than the square on <span data-ref="0076.g1:C">$C$</span> by<br />
the square on a straight line commensurable with <span data-ref="0076.g1:A">$A$</span>,</p>
<p class="assertion">therefore also the square on <span data-ref="0076.g1:D">$D$</span> will be greater than the square<br />
on <span data-ref="0076.g1:E">$E$</span> by the square on a straight line commensurable with <span data-ref="0076.g1:D">$D$</span>.<br />
<span class="justification">[X. 14]</span></p>

I say next that the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span> is also medial.

<p class="sub-clause">For, since the rectangle <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span> is equal to the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span>,<br />
while the rectangle <span data-ref="0076.g1:B">$B$</span>, <span data-ref="0076.g1:C">$C$</span> is medial, <span class="justification">[X. 21]</span></p>
<p class="assertion">therefore the rectangle <span data-ref="0076.g1:D">$D$</span>, <span data-ref="0076.g1:E">$E$</span> is also medial.</p>
