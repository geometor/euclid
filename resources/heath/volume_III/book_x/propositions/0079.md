<p class="assertion">therefore the triangles <span data-ref="0078.g1:< A B D >">$ABD$</span>, <span data-ref="0078.g1:< A D C >">$ADC$</span> are similar both to the<br />

<p class="sub-clause">And since the triangle <span data-ref="0078.g1:< A B C >">$ABC$</span> is similar to the triangle <span data-ref="0078.g1:< A B D >">$ABD$</span>,</p>
<p class="assertion">therefore, as <span data-ref="0078.g1:/ C B /">$CB$</span> is to <span data-ref="0078.g1:/ B A /">$BA$</span>, so is <span data-ref="0078.g1:/ B A /">$BA$</span> to <span data-ref="0078.g1:/ B D /">$BD$</span> ; <span class="justification">[VI. 4]</span><br />

<p class="sub-clause">For the same reason the rectangle <span data-ref="0078.g1:/ B C /">$BC$</span>, <span data-ref="0078.g1:/ C D /">$CD$</span> is also equal<br />

<p class="sub-clause">And since, if in a right-angled triangle a perpendicular<br />
