And first that the rectangle <span data-ref="0078.g1:/ C B /">$CB$</span>, <span data-ref="0078.g1:/ B D /">$BD$</span> is equal to the square on <span data-ref="0078.g1:/ B A /">$BA$</span>.

For, since in a right-angled triangle <span data-ref="0078.g1:/ A D /">$AD$</span> has been drawn from the right angle perpendicular to the base,
therefore the triangles <span data-ref="0078.g1:< A B D >">$ABD$</span>, <span data-ref="0078.g1:< A D C >">$ADC$</span> are similar both to the whole <span data-ref="0078.g1:< A B C >">$ABC$</span> and to one another. [vi. 8]

And since the triangle <span data-ref="0078.g1:< A B C >">$ABC$</span> is similar to the triangle <span data-ref="0078.g1:< A B D >">$ABD$</span>,
therefore, as <span data-ref="0078.g1:/ C B /">$CB$</span> is to <span data-ref="0078.g1:/ B A /">$BA$</span>, so is <span data-ref="0078.g1:/ B A /">$BA$</span> to <span data-ref="0078.g1:/ B D /">$BD$</span> ; [vi. 4]
therefore the rectangle <span data-ref="0078.g1:/ C B /">$CB$</span>, <span data-ref="0078.g1:/ B D /">$BD$</span> is equal to the square on <span data-ref="0078.g1:/ A B /">$AB$</span>. [vi. 17]

For the same reason the rectangle <span data-ref="0078.g1:/ B C /">$BC$</span>, <span data-ref="0078.g1:/ C D /">$CD$</span> is also equal to the square on <span data-ref="0078.g1:/ A C /">$AC$</span>.

And since, if in a right-angled triangle a perpendicular be drawn from the right angle to the base, the perpendicular so drawn is a mean proportional between the segments of the base, [vi. 8, Por.]
therefore, as <span data-ref="0078.g1:/ B D /">$BD$</span> is to <span data-ref="0078.g1:/ D A /">$DA$</span>, so is <span data-ref="0078.g1:/ A D /">$AD$</span> to <span data-ref="0078.g1:/ D C /">$DC$</span> ;
therefore the rectangle <span data-ref="0078.g1:/ B D /">$BD$</span>, <span data-ref="0078.g1:/ D C /">$DC$</span> is equal to the square on <span data-ref="0078.g1:/ A D /">$AD$</span>. [vi. 17]

I say that the rectangle <span data-ref="0078.g1:/ B C /">$BC$</span>, <span data-ref="0078.g1:/ A D /">$AD$</span> is also equal to the rectangle <span data-ref="0078.g1:/ B A /">$BA$</span>, <span data-ref="0078.g1:/ A C /">$AC$</span>.

For since, as we said, <span data-ref="0078.g1:< A B C >">$ABC$</span> is similar to <span data-ref="0078.g1:< A B D >">$ABD$</span>,
therefore, as <span data-ref="0078.g1:/ B C /">$BC$</span> is to <span data-ref="0078.g1:/ C A /">$CA$</span>, so is <span data-ref="0078.g1:/ B A /">$BA$</span> to <span data-ref="0078.g1:/ A D /">$AD$</span>. [vi. 4]
Therefore the rectangle <span data-ref="0078.g1:/ B C /">$BC$</span>, <span data-ref="0078.g1:/ A D /">$AD$</span> is equal to the rectangle <span data-ref="0078.g1:/ B A /">$BA$</span>, <span data-ref="0078.g1:/ A C /">$AC$</span>. [vi. 16]

Q. E. D.
