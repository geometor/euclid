.. subclause::

.. subclause::

   For the same reason the rectangle :g:`BC <0078.g1:/ B C />`, :g:`CD <0078.g1:/ C D />` is also equal to the square on :g:`AC <0078.g1:/ A C />`.

.. subclause::

   And since, if in a right-angled triangle a perpendicular be drawn from the right angle to the base, the perpendicular so drawn is a mean proportional between the segments of the base, :just:`[VI. 8, Por.]`
