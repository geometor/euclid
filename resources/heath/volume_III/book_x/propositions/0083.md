Since <span data-ref="0082.g1:/ A F /">$AF$</span> is incommensurable in length with <span data-ref="0082.g1:/ F B /">$FB$</span>,
therefore the rectangle <span data-ref="0082.g1:/ B A /">$BA$</span>, <span data-ref="0082.g1:/ A F /">$AF$</span> is also incommensurable with
the rectangle <span data-ref="0082.g1:/ A B /">$AB$</span>, <span data-ref="0082.g1:/ B F /">$BF$</span>. [x. 11]

But the rectangle <span data-ref="0082.g1:/ B A /">$BA$</span>, <span data-ref="0082.g1:/ A F /">$AF$</span> is equal to the square on <span data-ref="0082.g1:/ A D /">$AD$</span>,
and the rectangle <span data-ref="0082.g1:/ A B /">$AB$</span>, <span data-ref="0082.g1:/ B F /">$BF$</span> to the square on <span data-ref="0082.g1:/ D B /">$DB$</span>;
therefore the square on <span data-ref="0082.g1:/ A D /">$AD$</span> is also incommensurable with the
square on <span data-ref="0082.g1:/ D B /">$DB$</span>.

And, since the square on <span data-ref="0082.g1:/ A B /">$AB$</span> is medial,
therefore the sum of the squares on <span data-ref="0082.g1:/ A D /">$AD$</span>, <span data-ref="0082.g1:/ D B /">$DB$</span> is also medial.
[III. 31, I. 47]

And, since <span data-ref="0082.g1:/ B C /">$BC$</span> is double of <span data-ref="0082.g1:/ D F /">$DF$</span>,
therefore the rectangle <span data-ref="0082.g1:/ A B /">$AB$</span>, <span data-ref="0082.g1:/ B C /">$BC$</span> is also double of the rectangle
<span data-ref="0082.g1:/ A B /">$AB$</span>, <span data-ref="0082.g1:/ F D /">$FD$</span>.

But the rectangle <span data-ref="0082.g1:/ A B /">$AB$</span>, <span data-ref="0082.g1:/ B C /">$BC$</span> is rational;
therefore the rectangle <span data-ref="0082.g1:/ A B /">$AB$</span>, <span data-ref="0082.g1:/ F D /">$FD$</span> is also rational. [x. 6]

But the rectangle <span data-ref="0082.g1:/ A B /">$AB$</span>, <span data-ref="0082.g1:/ F D /">$FD$</span> is equal to the rectangle <span data-ref="0082.g1:/ A D /">$AD$</span>,
<span data-ref="0082.g1:/ D B /">$DB$</span>; [Lemma]
so that the rectangle <span data-ref="0082.g1:/ A D /">$AD$</span>, <span data-ref="0082.g1:/ D B /">$DB$</span> is also rational.

Therefore two straight lines <span data-ref="0082.g1:/ A D /">$AD$</span>, <span data-ref="0082.g1:/ D B /">$DB$</span> incommensurable
in square have been found which make the sum of the squares
on them medial, but the rectangle contained by them rational.

<p align="right">Q. E. D.</p>

In this case we take [x. 31, 2nd part] the medial straight lines
$$\frac{\rho}{(1 + k^2)^{\frac{1}{4}}}, \quad \frac{\rho}{(1 + k^2)^{\frac{3}{4}}}.$$

Solve the equations
$$\left. \begin{aligned} x + y &= \frac{\rho}{(1 + k^2)^{\frac{1}{4}}} \\ xy &= \frac{\rho^2}{4(1 + k^2)^{\frac{3}{2}}} \end{aligned} \right\} \dots\dots\dots\dots\dots\dots\dots\dots\dots\dots(1).$$

Take $u$, $v$ such that, if $x$, $y$ be the result of the solution,
$$\left. \begin{aligned} u^2 &= \frac{\rho}{(1 + k^2)^{\frac{1}{4}}} \cdot x \\ v^2 &= \frac{\rho}{(1 + k^2)^{\frac{1}{4}}} \cdot y \end{aligned} \right\} \dots\dots\dots\dots\dots\dots\dots\dots\dots\dots(2),$$
and $u$, $v$ are straight lines satisfying the given conditions.

Euclid's proof is similar to the preceding.

($\alpha$) From (1) it follows [x. 18] that
$$x \mathbin{\smile} y,$$
whence
$$u^2 \mathbin{\smile} v^2,$$
and $u$, $v$ are thus incommensurable in square.
