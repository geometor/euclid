let the semicircle <span data-ref="0085.g1:( A D B )">$ADB$</span> be described on <span data-ref="0085.g1:/ A B /">$AB$</span>, and let the rest of the construction be as above.

Then, since <span data-ref="0085.g1:/ A F /">$AF$</span> is incommensurable in length with <span data-ref="0085.g1:/ F B /">$FB$</span>, [x. 18] <span data-ref="0085.g1:/ A D /">$AD$</span> is also incommensurable in square with <span data-ref="0085.g1:/ D B /">$DB$</span>. [x. 11]

And, since the square on <span data-ref="0085.g1:/ A B /">$AB$</span> is medial, therefore the sum of the squares on <span data-ref="0085.g1:/ A D /">$AD$</span>, <span data-ref="0085.g1:/ D B /">$DB$</span> is also medial. [III. 31, I. 47]

And, since the rectangle <span data-ref="0085.g1:/ A F /">$AF$</span>, <span data-ref="0085.g1:/ F B /">$FB$</span> is equal to the square on each of the straight lines <span data-ref="0085.g1:/ B E /">$BE$</span>, <span data-ref="0085.g1:/ D F /">$DF$</span>, therefore <span data-ref="0085.g1:/ B E /">$BE$</span> is equal to <span data-ref="0085.g1:/ D F /">$DF$</span>; therefore <span data-ref="0085.g1:/ B C /">$BC$</span> is double of <span data-ref="0085.g1:/ F D /">$FD$</span>, so that the rectangle <span data-ref="0085.g1:/ A B /">$AB$</span>, <span data-ref="0085.g1:/ B C /">$BC$</span> is also double of the rectangle <span data-ref="0085.g1:/ A B /">$AB$</span>, <span data-ref="0085.g1:/ F D /">$FD$</span>.

But the rectangle <span data-ref="0085.g1:/ A B /">$AB$</span>, <span data-ref="0085.g1:/ B C /">$BC$</span> is medial; therefore the rectangle <span data-ref="0085.g1:/ A B /">$AB$</span>, <span data-ref="0085.g1:/ F D /">$FD$</span> is also medial. [x. 32, Por.]

And it is equal to the rectangle <span data-ref="0085.g1:/ A D /">$AD$</span>, <span data-ref="0085.g1:/ D B /">$DB$</span>; [Lemma after x. 32] therefore the rectangle <span data-ref="0085.g1:/ A D /">$AD$</span>, <span data-ref="0085.g1:/ D B /">$DB$</span> is also medial.

And, since <span data-ref="0085.g1:/ A B /">$AB$</span> is incommensurable in length with <span data-ref="0085.g1:/ B C /">$BC$</span>, while <span data-ref="0085.g1:/ C B /">$CB$</span> is commensurable with <span data-ref="0085.g1:/ B E /">$BE$</span>, therefore <span data-ref="0085.g1:/ A B /">$AB$</span> is also incommensurable in length with <span data-ref="0085.g1:/ B E /">$BE$</span>, [x. 13] so that the square on <span data-ref="0085.g1:/ A B /">$AB$</span> is also incommensurable with the rectangle <span data-ref="0085.g1:/ A B /">$AB$</span>, <span data-ref="0085.g1:/ B E /">$BE$</span>. [x. 11]

But the squares on <span data-ref="0085.g1:/ A D /">$AD$</span>, <span data-ref="0085.g1:/ D B /">$DB$</span> are equal to the square on <span data-ref="0085.g1:/ A B /">$AB$</span>, [I. 47] and the rectangle <span data-ref="0085.g1:/ A B /">$AB$</span>, <span data-ref="0085.g1:/ F D /">$FD$</span>, that is, the rectangle <span data-ref="0085.g1:/ A D /">$AD$</span>, <span data-ref="0085.g1:/ D B /">$DB$</span>, is equal to the rectangle <span data-ref="0085.g1:/ A B /">$AB$</span>, <span data-ref="0085.g1:/ B E /">$BE$</span>; therefore the sum of the squares on <span data-ref="0085.g1:/ A D /">$AD$</span>, <span data-ref="0085.g1:/ D B /">$DB$</span> is incommensurable with the rectangle <span data-ref="0085.g1:/ A D /">$AD$</span>, <span data-ref="0085.g1:/ D B /">$DB$</span>.
