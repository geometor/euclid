According as $\rho$ is of the form $a$ or $\sqrt{A}$, we have a variety of forms for<br />
$u$, $v$, arrived at by using the same transformations as in the notes on x. 30<br />
and x. 32 (second part), e.g.
$$(1) \quad \sqrt{\frac{(a + \sqrt{C})\sqrt{B}}{2}}, \quad \sqrt{\frac{(a - \sqrt{C})\sqrt{B}}{2}};$$
$$(2) \quad \sqrt{\frac{(\sqrt{A} + \sqrt{C})\sqrt{B}}{2}}, \quad \sqrt{\frac{(\sqrt{A} - \sqrt{C})\sqrt{B}}{2}};$$
$$(3) \quad \sqrt{\frac{(\sqrt{A} + c)\sqrt{B}}{2}}, \quad \sqrt{\frac{(\sqrt{A} - c)\sqrt{B}}{2}};$$
and the expressions in (2), (3) with $b$ in place of $\sqrt{B}$.

### PROPOSITION 36.

<p class="enunciation">If two rational straight lines commensurable in square<br />
only be added together, the whole is irrational; and let it be<br />
called **binomial**.</p>

For let two rational straight lines <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> commen-<br />
<sup>5</sup> surable in square only be added<br />
together;

I say that the whole <span data-ref="0087.g1:/ A C /">$AC$</span> is ir-<br />
rational.

![Proposition 36](0087.g1.svg)

<p class="sub-clause">For, since <span data-ref="0087.g1:/ A B /">$AB$</span> is incommensurable in length with <span data-ref="0087.g1:/ B C /">$BC$</span>—<br />
<sup>10</sup> for they are commensurable in square only—<br />
and, as <span data-ref="0087.g1:/ A B /">$AB$</span> is to <span data-ref="0087.g1:/ B C /">$BC$</span>, so is the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> to the<br />
square on <span data-ref="0087.g1:/ B C /">$BC$</span>,</p>
<p class="assertion">therefore the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> is incommensurable with the<br />
square on <span data-ref="0087.g1:/ B C /">$BC$</span>. <span class="justification">[X. 11]</span></p>

<p class="sub-clause"><sup>15</sup> But twice the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> is commensurable with<br />
the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> <span class="justification">[X. 6]</span>, and the squares on <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> are<br />
commensurable with the square on <span data-ref="0087.g1:/ B C /">$BC$</span>—for <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> are<br />
rational straight lines commensurable in square only— <span class="justification">[X. 15]</span></p>
<p class="assertion">therefore twice the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> is incommensurable<br />
<sup>20</sup> with the squares on <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span>. <span class="justification">[X. 13]</span></p>

<p class="assertion">And, <em>componendo</em>, twice the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> together<br />
with the squares on <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span>, that is, the square on <span data-ref="0087.g1:/ A C /">$AC$</span> <span class="justification">[II. 4]</span>,<br />
is incommensurable with the sum of the squares on <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span>.<br />
<span class="justification">[X. 16]</span></p>

<p class="sub-clause">But the sum of the squares on <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> is rational;</p>
<p class="assertion"><sup>25</sup> therefore the square on <span data-ref="0087.g1:/ A C /">$AC$</span> is irrational,<br />
so that <span data-ref="0087.g1:/ A C /">$AC$</span> is also irrational. <span class="justification">[X. Def. 4]</span></p>

<p class="qed">And let it be called **binomial**.</p>
