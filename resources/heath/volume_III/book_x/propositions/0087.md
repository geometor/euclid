According as $\rho$ is of the form $a$ or $\sqrt{A}$, we have a variety of forms for $u$, $v$, arrived at by using the same transformations as in the notes on x. 30 and x. 32 (second part), e.g.
$$(1) \quad \sqrt{\frac{(a + \sqrt{C})\sqrt{B}}{2}}, \quad \sqrt{\frac{(a - \sqrt{C})\sqrt{B}}{2}};$$
$$(2) \quad \sqrt{\frac{(\sqrt{A} + \sqrt{C})\sqrt{B}}{2}}, \quad \sqrt{\frac{(\sqrt{A} - \sqrt{C})\sqrt{B}}{2}};$$
$$(3) \quad \sqrt{\frac{(\sqrt{A} + c)\sqrt{B}}{2}}, \quad \sqrt{\frac{(\sqrt{A} - c)\sqrt{B}}{2}};$$
and the expressions in (2), (3) with $b$ in place of $\sqrt{B}$.

### PROPOSITION 36.

*If two rational straight lines commensurable in square only be added together, the whole is irrational; and let it be called* **binomial**.

For let two rational straight lines <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> commen-
<sup>5</sup> surable in square only be added together;

I say that the whole <span data-ref="0087.g1:/ A C /">$AC$</span> is irrational.

![Proposition 36](0087.g1.svg)

For, since <span data-ref="0087.g1:/ A B /">$AB$</span> is incommensurable in length with <span data-ref="0087.g1:/ B C /">$BC$</span>—
<sup>10</sup> for they are commensurable in square only—
and, as <span data-ref="0087.g1:/ A B /">$AB$</span> is to <span data-ref="0087.g1:/ B C /">$BC$</span>, so is the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> to the square on <span data-ref="0087.g1:/ B C /">$BC$</span>,
therefore the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> is incommensurable with the square on <span data-ref="0087.g1:/ B C /">$BC$</span>. [x. 11]

<sup>15</sup> But twice the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> is commensurable with the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> [x. 6], and the squares on <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> are commensurable with the square on <span data-ref="0087.g1:/ B C /">$BC$</span>—for <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> are rational straight lines commensurable in square only— [x. 15]
therefore twice the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> is incommensurable
<sup>20</sup> with the squares on <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span>. [x. 13]

And, *componendo*, twice the rectangle <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> together with the squares on <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span>, that is, the square on <span data-ref="0087.g1:/ A C /">$AC$</span> [II. 4], is incommensurable with the sum of the squares on <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span>. [x. 16]

But the sum of the squares on <span data-ref="0087.g1:/ A B /">$AB$</span>, <span data-ref="0087.g1:/ B C /">$BC$</span> is rational;
<sup>25</sup> therefore the square on <span data-ref="0087.g1:/ A C /">$AC$</span> is irrational,
so that <span data-ref="0087.g1:/ A C /">$AC$</span> is also irrational. [x. Def. 4]

And let it be called **binomial**.
