For, if possible, let it be divided at <span data-ref="0096.g1:D">$D$</span> also, so that <span data-ref="0096.g1:/ A D /">$AD$</span>,<br />
<span data-ref="0096.g1:/ D B /">$DB$</span> are also rational straight lines commensurable in square<br />
only.

<p class="assertion">It is then manifest that <span data-ref="0096.g1:/ A C /">$AC$</span> is not the same with <span data-ref="0096.g1:/ D B /">$DB$</span>.</p>

<p class="sub-clause">For, if possible, let it be so.</p>

<p class="assertion">Then <span data-ref="0096.g1:/ A D /">$AD$</span> will also be the same as <span data-ref="0096.g1:/ C B /">$CB$</span>,<br />
and, as <span data-ref="0096.g1:/ A C /">$AC$</span> is to <span data-ref="0096.g1:/ C B /">$CB$</span>, so will <span data-ref="0096.g1:/ B D /">$BD$</span> be to <span data-ref="0096.g1:/ D A /">$DA$</span>;<br />
thus <span data-ref="0096.g1:/ A B /">$AB$</span> will be divided at <span data-ref="0096.g1:D">$D$</span> also in the same way as by the<br />
division at <span data-ref="0096.g1:C">$C$</span>:<br />
which is contrary to the hypothesis.</p>

<p class="assertion">Therefore <span data-ref="0096.g1:/ A C /">$AC$</span> is not the same with <span data-ref="0096.g1:/ D B /">$DB$</span>.</p>

<p class="assertion">For this reason also the points <span data-ref="0096.g1:C">$C$</span>, <span data-ref="0096.g1:D">$D$</span> are not equidistant<br />
from the point of bisection.</p>

<p class="assertion">Therefore that by which the squares on <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span> differ<br />
from the squares on <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> is also that by which twice<br />
the rectangle <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> differs from twice the rectangle<br />
<span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span>,<br />
because both the squares on <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span> together with twice the<br />
rectangle <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span>, and the squares on <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> together<br />
with twice the rectangle <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span>, are equal to the square<br />
on <span data-ref="0096.g1:/ A B /">$AB$</span>. <span class="justification">[II. 4]</span></p>

<p class="sub-clause">But the squares on <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span> differ from the squares on<br />
<span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> by a rational area,<br />
for both are rational;</p>
<p class="assertion">therefore twice the rectangle <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> also differs from twice<br />
the rectangle <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span> by a rational area, though they are<br />
medial <span class="justification">[X. 21]</span>:<br />
which is absurd, for a medial area does not exceed a medial<br />
by a rational area. <span class="justification">[X. 26]</span></p>

<p class="assertion">Therefore a binomial straight line is not divided at different<br />
points;<br />
therefore it is divided at one point only.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

This proposition proves the equivalent of the well-known theorem in<br />
surds that,
$$\text{if } a + \sqrt{b} = x + \sqrt{y},$$
then
$$a = x,\quad b = y,$$
and if
$$\sqrt{a} + \sqrt{b} = \sqrt{x} + \sqrt{y},$$
then
$$a = x,\quad b = y\text{ (or } a = y,\quad b = x\text{)}.$$
