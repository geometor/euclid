For, if possible, let it be divided at <span data-ref="0096.g1:D">$D$</span> also, so that <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> are also rational straight lines commensurable in square only.

It is then manifest that <span data-ref="0096.g1:/ A C /">$AC$</span> is not the same with <span data-ref="0096.g1:/ D B /">$DB$</span>.

For, if possible, let it be so.

Then <span data-ref="0096.g1:/ A D /">$AD$</span> will also be the same as <span data-ref="0096.g1:/ C B /">$CB$</span>,
and, as <span data-ref="0096.g1:/ A C /">$AC$</span> is to <span data-ref="0096.g1:/ C B /">$CB$</span>, so will <span data-ref="0096.g1:/ B D /">$BD$</span> be to <span data-ref="0096.g1:/ D A /">$DA$</span>;
thus <span data-ref="0096.g1:/ A B /">$AB$</span> will be divided at <span data-ref="0096.g1:D">$D$</span> also in the same way as by the division at <span data-ref="0096.g1:C">$C$</span>:
which is contrary to the hypothesis.

Therefore <span data-ref="0096.g1:/ A C /">$AC$</span> is not the same with <span data-ref="0096.g1:/ D B /">$DB$</span>.

For this reason also the points <span data-ref="0096.g1:C">$C$</span>, <span data-ref="0096.g1:D">$D$</span> are not equidistant from the point of bisection.

Therefore that by which the squares on <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span> differ from the squares on <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> is also that by which twice the rectangle <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> differs from twice the rectangle <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span>,
because both the squares on <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span> together with twice the rectangle <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span>, and the squares on <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> together with twice the rectangle <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span>, are equal to the square on <span data-ref="0096.g1:/ A B /">$AB$</span>. [II. 4]

But the squares on <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span> differ from the squares on <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> by a rational area,
for both are rational;
therefore twice the rectangle <span data-ref="0096.g1:/ A D /">$AD$</span>, <span data-ref="0096.g1:/ D B /">$DB$</span> also differs from twice the rectangle <span data-ref="0096.g1:/ A C /">$AC$</span>, <span data-ref="0096.g1:/ C B /">$CB$</span> by a rational area, though they are medial [x. 21]:
which is absurd, for a medial area does not exceed a medial by a rational area. [x. 26]

Therefore a binomial straight line is not divided at different points;
therefore it is divided at one point only.

Q. E. D.

---

This proposition proves the equivalent of the well-known theorem in surds that,
$$\text{if } a + \sqrt{b} = x + \sqrt{y},$$
then
$$a = x,\quad b = y,$$
and if
$$\sqrt{a} + \sqrt{b} = \sqrt{x} + \sqrt{y},$$
then
$$a = x,\quad b = y\text{ (or } a = y,\quad b = x\text{)}.$$
