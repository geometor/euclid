:title: Proposition 42 (concl.)

| For, if possible, let it be divided at :g:`$D$ <0096.g1:D>` also, so that :g:`$AD$ <0096.g1:/ A D />`,
| :g:`$DB$ <0096.g1:/ D B />` are also rational straight lines commensurable in square
| only.

.. assertion::

   It is then manifest that :g:`$AC$ <0096.g1:/ A C />` is not the same with :g:`$DB$ <0096.g1:/ D B />`.

.. subclause::

   For, if possible, let it be so.

.. assertion::

   | Then :g:`$AD$ <0096.g1:/ A D />` will also be the same as :g:`$CB$ <0096.g1:/ C B />`,
   | and, as :g:`$AC$ <0096.g1:/ A C />` is to :g:`$CB$ <0096.g1:/ C B />`, so will :g:`$BD$ <0096.g1:/ B D />` be to :g:`$DA$ <0096.g1:/ D A />`;
   | thus :g:`$AB$ <0096.g1:/ A B />` will be divided at :g:`$D$ <0096.g1:D>` also in the same way as by the
   | division at :g:`$C$ <0096.g1:C>`:
   | which is contrary to the hypothesis.

.. assertion::

   Therefore :g:`$AC$ <0096.g1:/ A C />` is not the same with :g:`$DB$ <0096.g1:/ D B />`.

.. assertion::

   | For this reason also the points :g:`$C$ <0096.g1:C>`, :g:`$D$ <0096.g1:D>` are not equidistant
   | from the point of bisection.

.. assertion::

   | Therefore that by which the squares on :g:`$AC$ <0096.g1:/ A C />`, :g:`$CB$ <0096.g1:/ C B />` differ
   | from the squares on :g:`$AD$ <0096.g1:/ A D />`, :g:`$DB$ <0096.g1:/ D B />` is also that by which twice
   | the rectangle :g:`$AD$ <0096.g1:/ A D />`, :g:`$DB$ <0096.g1:/ D B />` differs from twice the rectangle
   | :g:`$AC$ <0096.g1:/ A C />`, :g:`$CB$ <0096.g1:/ C B />`,
   | because both the squares on :g:`$AC$ <0096.g1:/ A C />`, :g:`$CB$ <0096.g1:/ C B />` together with twice the
   | rectangle :g:`$AC$ <0096.g1:/ A C />`, :g:`$CB$ <0096.g1:/ C B />`, and the squares on :g:`$AD$ <0096.g1:/ A D />`, :g:`$DB$ <0096.g1:/ D B />` together
   | with twice the rectangle :g:`$AD$ <0096.g1:/ A D />`, :g:`$DB$ <0096.g1:/ D B />`, are equal to the square
   | on :g:`$AB$ <0096.g1:/ A B />`. :just:`[II. 4] <II.4>`

.. subclause::

   | But the squares on :g:`$AC$ <0096.g1:/ A C />`, :g:`$CB$ <0096.g1:/ C B />` differ from the squares on
   | :g:`$AD$ <0096.g1:/ A D />`, :g:`$DB$ <0096.g1:/ D B />` by a rational area,
   | for both are rational;

.. assertion::

   | therefore twice the rectangle :g:`$AD$ <0096.g1:/ A D />`, :g:`$DB$ <0096.g1:/ D B />` also differs from twice
   | the rectangle :g:`$AC$ <0096.g1:/ A C />`, :g:`$CB$ <0096.g1:/ C B />` by a rational area, though they are
   | medial :just:`[X. 21] <X.21>`:
   | which is absurd, for a medial area does not exceed a medial
   | by a rational area. :just:`[X. 26] <X.26>`

.. assertion::

   | Therefore a binomial straight line is not divided at different
   | points;
   | therefore it is divided at one point only.

.. qed::

   :just:`Q. E. D.`

----

| This proposition proves the equivalent of the well-known theorem in
| surds that,

$$\text{if } a + \sqrt{b} = x + \sqrt{y},$$

then

$$a = x,\quad b = y,$$

and if

$$\sqrt{a} + \sqrt{b} = \sqrt{x} + \sqrt{y},$$

then

$$a = x,\quad b = y\text{ (or } a = y,\quad b = x\text{)}.$$
