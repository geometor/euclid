The proposition states that a binomial straight line cannot be split up into<br />
*terms* (ὀνόματα) in two ways. For, if possible, let
$$x + y = x' + y',$$
where $x$, $y$, and also $x'$, $y'$, are the *terms* of a binomial straight line, $x'$, $y'$<br />
being different from $x$, $y$ (or $y$, $x$).

One pair is necessarily more nearly equal than the other. Let $x'$, $y'$ be<br />
more nearly equal than $x$, $y$.

Then
$$(x^2 + y^2) - (x'^2 + y'^2) = 2x'y' - 2xy.$$

Now by hypothesis $(x^2 + y^2)$, $(x'^2 + y'^2)$ are rational areas, being of the form<br />
$\rho^2 + k\rho^2$;<br />
but $2x'y'$, $2xy$ are medial areas, being of the form $\sqrt{k}\cdot\rho^2$;<br />
therefore the difference of two medial areas is rational:<br />
which is impossible. [x. 26]

Therefore $x'$, $y'$ cannot be different from $x$, $y$ (or $y$, $x$).

### PROPOSITION 43.

<p class="enunciation">A first bimedial straight line is divided at one point only.</p>

Let <span data-ref="0098.g1:/ A B /">$AB$</span> be a first bimedial straight line divided at <span data-ref="0098.g1:C">$C$</span>, so<br />
that <span data-ref="0098.g1:/ A C /">$AC$</span>, <span data-ref="0098.g1:/ C B /">$CB$</span> are medial straight<br />
lines commensurable in square<br />
only and containing a rational<br />
rectangle; <span class="justification">[X. 37]</span>

![Proposition 43 diagram](0098.g1.svg)

I say that <span data-ref="0098.g1:/ A B /">$AB$</span> is not so divided at another point.

For, if possible, let it be divided at <span data-ref="0098.g1:D">$D$</span> also, so that <span data-ref="0098.g1:/ A D /">$AD$</span>,<br />
<span data-ref="0098.g1:/ D B /">$DB$</span> are also medial straight lines commensurable in square<br />
only and containing a rational rectangle.

<p class="sub-clause">Since, then, that by which twice the rectangle <span data-ref="0098.g1:/ A D /">$AD$</span>, <span data-ref="0098.g1:/ D B /">$DB$</span><br />
differs from twice the rectangle <span data-ref="0098.g1:/ A C /">$AC$</span>, <span data-ref="0098.g1:/ C B /">$CB$</span> is that by which the<br />
squares on <span data-ref="0098.g1:/ A C /">$AC$</span>, <span data-ref="0098.g1:/ C B /">$CB$</span> differ from the squares on <span data-ref="0098.g1:/ A D /">$AD$</span>, <span data-ref="0098.g1:/ D B /">$DB$</span>,<br />
while twice the rectangle <span data-ref="0098.g1:/ A D /">$AD$</span>, <span data-ref="0098.g1:/ D B /">$DB$</span> differs from twice the<br />
rectangle <span data-ref="0098.g1:/ A C /">$AC$</span>, <span data-ref="0098.g1:/ C B /">$CB$</span> by a rational area—for both are rational—</p>
<p class="assertion">therefore the squares on <span data-ref="0098.g1:/ A C /">$AC$</span>, <span data-ref="0098.g1:/ C B /">$CB$</span> also differ from the squares<br />
on <span data-ref="0098.g1:/ A D /">$AD$</span>, <span data-ref="0098.g1:/ D B /">$DB$</span> by a rational area, though they are medial :<br />
which is absurd. <span class="justification">[X. 26]</span></p>

<p class="assertion">Therefore a first bimedial straight line is not divided into<br />
its terms at different points;<br />
therefore it is so divided at one point only.</p>
