In this case, with the same hypothesis, viz. that
$$x + y = x' + y',$$
and $x', y'$ are more nearly equal than $x, y$,
we have as before
$$(x^2 + y^2) - (x'^2 + y'^2) = 2x'y' - 2xy.$$
But, from the given properties of $x, y$, and $x', y'$, it follows that $2xy, 2x'y'$ are *rational*, and $(x^2 + y^2), (x'^2 + y'^2)$ medial, areas.
Therefore the difference between two medial areas is rational:
which is impossible. [x. 26]

### PROPOSITION 44.

*A second bimedial straight line is divided at one point only.*

Let <span data-ref="0099.g1:/ A B /">$AB$</span> be a second bimedial straight line divided at <span data-ref="0099.g1:C">$C$</span>, so that <span data-ref="0099.g1:/ A C /">$AC$</span>, <span data-ref="0099.g1:/ C B /">$CB$</span> are medial straight lines commensurable in square only and containing a medial rectangle; [x. 38] it is then manifest that <span data-ref="0099.g1:C">$C$</span> is not at the point of bisection, because the segments are not commensurable in length.

I say that <span data-ref="0099.g1:/ A B /">$AB$</span> is not so divided at another point.

![Proposition 44 diagram](0099.g1.svg)

For, if possible, let it be divided at <span data-ref="0099.g1:D">$D$</span> also, so that <span data-ref="0099.g1:/ A C /">$AC$</span> is not the same with <span data-ref="0099.g1:/ D B /">$DB$</span>, but <span data-ref="0099.g1:/ A C /">$AC$</span> is supposed greater; it is then clear that the squares on <span data-ref="0099.g1:/ A D /">$AD$</span>, <span data-ref="0099.g1:/ D B /">$DB$</span> are also, as we proved above [Lemma], less than the squares on <span data-ref="0099.g1:/ A C /">$AC$</span>, <span data-ref="0099.g1:/ C B /">$CB$</span>; and suppose that <span data-ref="0099.g1:/ A D /">$AD$</span>, <span data-ref="0099.g1:/ D B /">$DB$</span> are medial straight lines commensurable in square only and containing a medial rectangle.
