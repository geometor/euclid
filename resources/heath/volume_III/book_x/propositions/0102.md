### PROPOSITION 45.

*A major straight line is divided at one and the same point only.*

Let <span data-ref="0102.g1:/ A B /">$AB$</span> be a major straight line divided at <span data-ref="0102.g1:C">$C$</span>, so that <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> are incommensurable in square and make the sum of the squares on <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> rational, but the rectangle <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> medial; [x. 39]
I say that <span data-ref="0102.g1:/ A B /">$AB$</span> is not so divided at another point.

![Proposition 45 diagram](0102.g1.svg)

For, if possible, let it be divided at <span data-ref="0102.g1:D">$D$</span> also, so that <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D B /">$DB$</span> are also incommensurable in square and make the sum of the squares on <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D B /">$DB$</span> rational, but the rectangle contained by them medial.

Then, since that by which the squares on <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> differ from the squares on <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D B /">$DB$</span> is also that by which twice the rectangle <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D B /">$DB$</span> differs from twice the rectangle <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span>, while the squares on <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> exceed the squares on <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D B /">$DB$</span> by a rational area—for both are rational—
therefore twice the rectangle <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D B /">$DB$</span> also exceeds twice the rectangle <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> by a rational area, though they are medial:
which is impossible. [x. 26]

Therefore a major straight line is not divided at different points;
therefore it is only divided at one and the same point.

Q. E. D.

---

If possible, let the major irrational straight line be divided into terms in two ways, viz. as $(x + y)$ and $(x' + y')$, where $x', y'$ are supposed to be nearer equality than $x, y$.

We have then, as in x. 42, 43,
$$(x^2 + y^2) - (x'^2 + y'^2) = 2x'y' - 2xy.$$

But, by hypothesis, $(x^2 + y^2), (x'^2 + y'^2)$ are both *rational*, so that their difference is *rational*.

Also, by hypothesis, $2x'y', 2xy$ are both *medial* areas;
therefore the difference of two medial areas is a rational area:
which is impossible. [x. 26]

Therefore etc.
