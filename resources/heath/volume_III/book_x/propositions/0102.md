### PROPOSITION 45.

<p class="enunciation">A major straight line is divided at one and the same point<br />
only.</p>

Let <span data-ref="0102.g1:/ A B /">$AB$</span> be a major straight line divided at <span data-ref="0102.g1:C">$C$</span>, so that<br />
<span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> are incommensurable in<br />
square and make the sum of the<br />
squares on <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> rational, but the<br />
rectangle <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> medial; <span class="justification">[X. 39]</span>

![Proposition 45 diagram](0102.g1.svg)

I say that <span data-ref="0102.g1:/ A B /">$AB$</span> is not so divided at another point.

For, if possible, let it be divided at <span data-ref="0102.g1:D">$D$</span> also, so that <span data-ref="0102.g1:/ A D /">$AD$</span>,<br />
<span data-ref="0102.g1:/ D B /">$DB$</span> are also incommensurable in square and make the sum<br />
of the squares on <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D B /">$DB$</span> rational, but the rectangle con-<br />
tained by them medial.

<p class="sub-clause">Then, since that by which the squares on <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> differ<br />
from the squares on <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D B /">$DB$</span> is also that by which twice the<br />
rectangle <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D B /">$DB$</span> differs from twice the rectangle <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span>,<br />
while the squares on <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> exceed the squares on <span data-ref="0102.g1:/ A D /">$AD$</span>,<br />
<span data-ref="0102.g1:/ D B /">$DB$</span> by a rational area—for both are rational—</p>
<p class="assertion">therefore twice the rectangle <span data-ref="0102.g1:/ A D /">$AD$</span>, <span data-ref="0102.g1:/ D B /">$DB$</span> also exceeds twice the<br />
rectangle <span data-ref="0102.g1:/ A C /">$AC$</span>, <span data-ref="0102.g1:/ C B /">$CB$</span> by a rational area, though they are medial :<br />
which is impossible. <span class="justification">[X. 26]</span></p>

<p class="qed">Therefore a major straight line is not divided at different<br />
points ;<br />
therefore it is only divided at one and the same point.<span class="justification">Q. E. D.</span></p>

---

If possible, let the major irrational straight line be divided into terms in<br />
two ways, viz. as $(x + y)$ and $(x' + y')$, where $x', y'$ are supposed to be nearer<br />
equality than $x, y$.

We have then, as in x. 42, 43,
$$(x^2 + y^2) - (x'^2 + y'^2) = 2x'y' - 2xy.$$

But, by hypothesis, $(x^2 + y^2), (x'^2 + y'^2)$ are both *rational*, so that their<br />
difference is *rational*.

Also, by hypothesis, $2x'y', 2xy$ are both *medial* areas;<br />
therefore the difference of two medial areas is a rational area:<br />
which is impossible. [x. 26]

Therefore etc.
