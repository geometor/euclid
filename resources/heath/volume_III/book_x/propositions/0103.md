### PROPOSITION 46.

*The side of a rational plus a medial area is divided at one point only.*

Let <span data-ref="0103.g1:/ A B /">$AB$</span> be the side of a rational plus a medial area divided at <span data-ref="0103.g1:C">$C$</span>, so that <span data-ref="0103.g1:/ A C /">$AC$</span>, <span data-ref="0103.g1:/ C B /">$CB$</span> are incommensurable in square and make the sum of the squares on <span data-ref="0103.g1:/ A C /">$AC$</span>, <span data-ref="0103.g1:/ C B /">$CB$</span> medial, but twice the rectangle <span data-ref="0103.g1:/ A C /">$AC$</span>, <span data-ref="0103.g1:/ C B /">$CB$</span> rational; [x. 40]
I say that <span data-ref="0103.g1:/ A B /">$AB$</span> is not so divided at another point.

![Proposition 46 diagram](0103.g1.svg)

For, if possible, let it be divided at <span data-ref="0103.g1:D">$D$</span> also, so that <span data-ref="0103.g1:/ A D /">$AD$</span>, <span data-ref="0103.g1:/ D B /">$DB$</span> are also incommensurable in square and make the sum of the squares on <span data-ref="0103.g1:/ A D /">$AD$</span>, <span data-ref="0103.g1:/ D B /">$DB$</span> medial, but twice the rectangle <span data-ref="0103.g1:/ A D /">$AD$</span>, <span data-ref="0103.g1:/ D B /">$DB$</span> rational.

Since then that by which twice the rectangle <span data-ref="0103.g1:/ A C /">$AC$</span>, <span data-ref="0103.g1:/ C B /">$CB$</span> differs from twice the rectangle <span data-ref="0103.g1:/ A D /">$AD$</span>, <span data-ref="0103.g1:/ D B /">$DB$</span> is also that by which the squares on <span data-ref="0103.g1:/ A D /">$AD$</span>, <span data-ref="0103.g1:/ D B /">$DB$</span> differ from the squares on <span data-ref="0103.g1:/ A C /">$AC$</span>, <span data-ref="0103.g1:/ C B /">$CB$</span>,
while twice the rectangle <span data-ref="0103.g1:/ A C /">$AC$</span>, <span data-ref="0103.g1:/ C B /">$CB$</span> exceeds twice the rectangle <span data-ref="0103.g1:/ A D /">$AD$</span>, <span data-ref="0103.g1:/ D B /">$DB$</span> by a rational area,
therefore the squares on <span data-ref="0103.g1:/ A D /">$AD$</span>, <span data-ref="0103.g1:/ D B /">$DB$</span> also exceed the squares on <span data-ref="0103.g1:/ A C /">$AC$</span>, <span data-ref="0103.g1:/ C B /">$CB$</span> by a rational area, though they are medial:
which is impossible. [x. 26]

Therefore the side of a rational plus a medial area is not divided at different points;
therefore it is divided at one point only.

Q. E. D.

---

Here, as before, if we use the same notation,
$$(x^2 + y^2) - (x'^2 + y'^2) = 2x'y' - 2xy,$$
and the areas on the left side are, by hypothesis, both medial, while the areas on the right side are both rational.
Thus the result of x. 26 is contradicted, as before.

Therefore etc.
