<span data-ref="0104.g1:/ C B /">$CB$</span> medial, and the rectangle <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span> medial and also incommensurable with the sum of the squares on them;
I say that <span data-ref="0104.g1:/ A B /">$AB$</span> is not divided at another point so as to fulfil the given conditions.

![Proposition 47 diagram](0104.g1.svg)

For, if possible, let it be divided at <span data-ref="0104.g1:D">$D$</span>, so that again <span data-ref="0104.g1:/ A C /">$AC$</span> is of course not the same as <span data-ref="0104.g1:/ B D /">$BD$</span>, but <span data-ref="0104.g1:/ A C /">$AC$</span> is supposed greater;
let a rational straight line <span data-ref="0104.g1:/ E F /">$EF$</span> be set out,
and let there be applied to <span data-ref="0104.g1:/ E F /">$EF$</span> the rectangle <span data-ref="0104.g1:< E G >">$EG$</span> equal to the squares on <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span>,
and the rectangle <span data-ref="0104.g1:< H K >">$HK$</span> equal to twice the rectangle <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span>;
therefore the whole <span data-ref="0104.g1:< E K >">$EK$</span> is equal to the square on <span data-ref="0104.g1:/ A B /">$AB$</span>. [II. 4]

Again, let <span data-ref="0104.g1:< E L >">$EL$</span>, equal to the squares on <span data-ref="0104.g1:/ A D /">$AD$</span>, <span data-ref="0104.g1:/ D B /">$DB$</span>, be applied to <span data-ref="0104.g1:/ E F /">$EF$</span>;
therefore the remainder, twice the rectangle <span data-ref="0104.g1:/ A D /">$AD$</span>, <span data-ref="0104.g1:/ D B /">$DB$</span>, is equal to the remainder <span data-ref="0104.g1:< M K >">$MK$</span>.

And since, by hypothesis, the sum of the squares on <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span> is medial,
therefore <span data-ref="0104.g1:< E G >">$EG$</span> is also medial.

And it is applied to the rational straight line <span data-ref="0104.g1:/ E F /">$EF$</span>;
therefore <span data-ref="0104.g1:/ H E /">$HE$</span> is rational and incommensurable in length with <span data-ref="0104.g1:/ E F /">$EF$</span>. [x. 22]

For the same reason
<span data-ref="0104.g1:/ H N /">$HN$</span> is also rational and incommensurable in length with <span data-ref="0104.g1:/ E F /">$EF$</span>.

And, since the sum of the squares on <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span> is incommensurable with twice the rectangle <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span>,
therefore <span data-ref="0104.g1:< E G >">$EG$</span> is also incommensurable with <span data-ref="0104.g1:< G N >">$GN$</span>,
so that <span data-ref="0104.g1:/ E H /">$EH$</span> is also incommensurable with <span data-ref="0104.g1:/ H N /">$HN$</span>. [VI. 1, x. 11]

And they are rational;
