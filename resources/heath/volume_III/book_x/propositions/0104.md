<span data-ref="0104.g1:/ C B /">$CB$</span> medial, and the rectangle <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span> medial and also in-<br />
commensurable with the sum of the squares on them;<br />
I say that <span data-ref="0104.g1:/ A B /">$AB$</span> is not divided at another point so as to fulfil<br />
the given conditions.

![Proposition 47 diagram](0104.g1.svg)

For, if possible, let it be divided at <span data-ref="0104.g1:D">$D$</span>, so that again <span data-ref="0104.g1:/ A C /">$AC$</span><br />
is of course not the same as <span data-ref="0104.g1:/ B D /">$BD$</span>, but <span data-ref="0104.g1:/ A C /">$AC$</span> is supposed greater;<br />
let a rational straight line <span data-ref="0104.g1:/ E F /">$EF$</span> be set out,<br />
and let there be applied to <span data-ref="0104.g1:/ E F /">$EF$</span> the rectangle <span data-ref="0104.g1:< E G >">$EG$</span> equal to the<br />
squares on <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span>,<br />
and the rectangle <span data-ref="0104.g1:< H K >">$HK$</span> equal to twice the rectangle <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span>;
<p class="assertion">therefore the whole <span data-ref="0104.g1:< E K >">$EK$</span> is equal to the square on <span data-ref="0104.g1:/ A B /">$AB$</span>. <span class="justification">[II. 4]</span></p>

Again, let <span data-ref="0104.g1:< E L >">$EL$</span>, equal to the squares on <span data-ref="0104.g1:/ A D /">$AD$</span>, <span data-ref="0104.g1:/ D B /">$DB$</span>, be applied<br />
to <span data-ref="0104.g1:/ E F /">$EF$</span>;
<p class="assertion">therefore the remainder, twice the rectangle <span data-ref="0104.g1:/ A D /">$AD$</span>, <span data-ref="0104.g1:/ D B /">$DB$</span>, is equal<br />
to the remainder <span data-ref="0104.g1:< M K >">$MK$</span>.</p>

<p class="sub-clause">And since, by hypothesis, the sum of the squares on <span data-ref="0104.g1:/ A C /">$AC$</span>,<br />
<span data-ref="0104.g1:/ C B /">$CB$</span> is medial,</p>
<p class="assertion">therefore <span data-ref="0104.g1:< E G >">$EG$</span> is also medial.</p>

<p class="sub-clause">And it is applied to the rational straight line <span data-ref="0104.g1:/ E F /">$EF$</span>;</p>
<p class="assertion">therefore <span data-ref="0104.g1:/ H E /">$HE$</span> is rational and incommensurable in length with<br />
<span data-ref="0104.g1:/ E F /">$EF$</span>. <span class="justification">[X. 22]</span></p>

<p class="sub-clause">For the same reason</p>
<p class="assertion"><span data-ref="0104.g1:/ H N /">$HN$</span> is also rational and incommensurable in length with <span data-ref="0104.g1:/ E F /">$EF$</span>.</p>

<p class="sub-clause">And, since the sum of the squares on <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span> is incom-<br />
mensurable with twice the rectangle <span data-ref="0104.g1:/ A C /">$AC$</span>, <span data-ref="0104.g1:/ C B /">$CB$</span>,</p>
<p class="assertion">therefore <span data-ref="0104.g1:< E G >">$EG$</span> is also incommensurable with <span data-ref="0104.g1:< G N >">$GN$</span>,</p>
<p class="assertion">so that <span data-ref="0104.g1:/ E H /">$EH$</span> is also incommensurable with <span data-ref="0104.g1:/ H N /">$HN$</span>. <span class="justification">[VI. 1, X. 11]</span></p>

<p class="sub-clause">And they are rational;</p>
