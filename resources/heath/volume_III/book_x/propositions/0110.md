Let
$$x^2 - k^2 p^2 = y^2,$$
whence, from (1),
$$pm^2 : pn^2 = x^2 : y^2,$$
and $y$ is therefore rational and $\sim x$.

The greater term of the binomial straight line is $x$ and the lesser $kp$, and
$$\frac{kp}{\sqrt{1 - \lambda^2}} + kp$$
satisfies the definition of the second binomial straight line.

The corresponding *second apotome* [x. 86] is
$$\frac{kp}{\sqrt{1 - \lambda^2}} - kp.$$

The equation of which the two expressions are the roots is
$$x^2 - \frac{2kp}{\sqrt{1 - \lambda^2}} \cdot x + \frac{\lambda^2}{1 - \lambda^2} k^2 p^2 = 0,$$
or
$$x^2 - 2ax + \lambda^2 a^2 = 0,$$
where
$$a = \frac{kp}{\sqrt{1 - \lambda^2}}.$$

### PROPOSITION 50.

<p class="enunciation">To find the third binomial straight line.</p>

Let two numbers <span data-ref="0110.g1:/ A C /">$AC$</span>, <span data-ref="0110.g1:/ C B /">$CB$</span> be set out such that the sum<br />
of them <span data-ref="0110.g1:/ A B /">$AB$</span> has to <span data-ref="0110.g1:/ C B /">$BC$</span> the ratio which a square number has<br />
to a square number, but has not to <span data-ref="0110.g1:/ A C /">$AC$</span> the ratio which a square<br />
number has to a square number.

![Proposition 50 Diagram](0110.g1.svg)

Let any other number <span data-ref="0110.g1:D">$D$</span>, not square, be set out also, and<br />
let it not have to either of the numbers <span data-ref="0110.g1:/ A B /">$BA$</span>, <span data-ref="0110.g1:/ A C /">$AC$</span> the ratio<br />
which a square number has to a square number.

Let any rational straight line <span data-ref="0110.g1:E">$E$</span> be set out,<br />
and let it be contrived that, as <span data-ref="0110.g1:D">$D$</span> is to <span data-ref="0110.g1:/ A B /">$AB$</span>, so is the square<br />
on <span data-ref="0110.g1:E">$E$</span> to the square on <span data-ref="0110.g1:/ F G /">$FG$</span>; <span class="justification">[X. 6, Por.]</span>

<p class="assertion">therefore the square on <span data-ref="0110.g1:E">$E$</span> is commensurable with the square<br />
on <span data-ref="0110.g1:/ F G /">$FG$</span>. <span class="justification">[X. 6]</span></p>

<p class="sub-clause">And <span data-ref="0110.g1:E">$E$</span> is rational;</p>

<p class="assertion">therefore <span data-ref="0110.g1:/ F G /">$FG$</span> is also rational.</p>
