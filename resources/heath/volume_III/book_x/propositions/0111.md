<p class="sub-clause">And, since <span data-ref="0110.g1:D">$D$</span> has not to <span data-ref="0110.g1:/ A B /">$AB$</span> the ratio which a square<br />
number has to a square number,</p>

<p class="assertion">neither has the square on <span data-ref="0110.g1:E">$E$</span> to the square on <span data-ref="0110.g1:/ F G /">$FG$</span> the ratio<br />
which a square number has to a square number;<br />
therefore <span data-ref="0110.g1:E">$E$</span> is incommensurable in length with <span data-ref="0110.g1:/ F G /">$FG$</span>. <span class="justification">[X. 9]</span></p>

Next let it be contrived that, as the number <span data-ref="0110.g1:/ A B /">$BA$</span> is to <span data-ref="0110.g1:/ A C /">$AC$</span>,<br />
so is the square on <span data-ref="0110.g1:/ F G /">$FG$</span> to the square on <span data-ref="0110.g1:/ G H /">$GH$</span>; <span class="justification">[X. 6, Por.]</span>

<p class="assertion">therefore the square on <span data-ref="0110.g1:/ F G /">$FG$</span> is commensurable with the square<br />
on <span data-ref="0110.g1:/ G H /">$GH$</span>. <span class="justification">[X. 6]</span></p>

<p class="sub-clause">But <span data-ref="0110.g1:/ F G /">$FG$</span> is rational;</p>

<p class="assertion">therefore <span data-ref="0110.g1:/ G H /">$GH$</span> is also rational.</p>

<p class="sub-clause">And, since <span data-ref="0110.g1:/ A B /">$BA$</span> has not to <span data-ref="0110.g1:/ A C /">$AC$</span> the ratio which a square<br />
number has to a square number,</p>

<p class="assertion">neither has the square on <span data-ref="0110.g1:/ F G /">$FG$</span> to the square on <span data-ref="0110.g1:/ G H /">$HG$</span> the ratio<br />
which a square number has to a square number;<br />
therefore <span data-ref="0110.g1:/ F G /">$FG$</span> is incommensurable in length with <span data-ref="0110.g1:/ G H /">$GH$</span>. <span class="justification">[X. 9]</span></p>

<p class="assertion">Therefore <span data-ref="0110.g1:/ F G /">$FG$</span>, <span data-ref="0110.g1:/ G H /">$GH$</span> are rational straight lines commen-<br />
surable in square only;<br />
therefore <span data-ref="0110.g1:/ F H /">$FH$</span> is binomial. <span class="justification">[X. 36]</span></p>

I say next that it is also a third binomial straight line.

<p class="sub-clause">For since, as <span data-ref="0110.g1:D">$D$</span> is to <span data-ref="0110.g1:/ A B /">$AB$</span>, so is the square on <span data-ref="0110.g1:E">$E$</span> to the<br />
square on <span data-ref="0110.g1:/ F G /">$FG$</span>,<br />
and, as <span data-ref="0110.g1:/ A B /">$BA$</span> is to <span data-ref="0110.g1:/ A C /">$AC$</span>, so is the square on <span data-ref="0110.g1:/ F G /">$FG$</span> to the square<br />
on <span data-ref="0110.g1:/ G H /">$GH$</span>,</p>

<p class="assertion">therefore, <em>ex aequali</em>, as <span data-ref="0110.g1:D">$D$</span> is to <span data-ref="0110.g1:/ A C /">$AC$</span>, so is the square on <span data-ref="0110.g1:E">$E$</span> to<br />
the square on <span data-ref="0110.g1:/ G H /">$GH$</span>. <span class="justification">[V. 22]</span></p>

<p class="sub-clause">But <span data-ref="0110.g1:D">$D$</span> has not to <span data-ref="0110.g1:/ A C /">$AC$</span> the ratio which a square number<br />
has to a square number;</p>

<p class="assertion">therefore neither has the square on <span data-ref="0110.g1:E">$E$</span> to the square on <span data-ref="0110.g1:/ G H /">$GH$</span><br />
the ratio which a square number has to a square number;<br />
therefore <span data-ref="0110.g1:E">$E$</span> is incommensurable in length with <span data-ref="0110.g1:/ G H /">$GH$</span>. <span class="justification">[X. 9]</span></p>

<p class="sub-clause">And since, as <span data-ref="0110.g1:/ A B /">$BA$</span> is to <span data-ref="0110.g1:/ A C /">$AC$</span>, so is the square on <span data-ref="0110.g1:/ F G /">$FG$</span> to<br />
