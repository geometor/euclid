And, since <span data-ref="0110.g1:D">$D$</span> has not to <span data-ref="0110.g1:/ A B /">$AB$</span> the ratio which a square number has to a square number,
neither has the square on <span data-ref="0110.g1:E">$E$</span> to the square on <span data-ref="0110.g1:/ F G /">$FG$</span> the ratio which a square number has to a square number;
therefore <span data-ref="0110.g1:E">$E$</span> is incommensurable in length with <span data-ref="0110.g1:/ F G /">$FG$</span>. [x. 9]
    Next let it be contrived that, as the number <span data-ref="0110.g1:/ A B /">$BA$</span> is to <span data-ref="0110.g1:/ A C /">$AC$</span>, so is the square on <span data-ref="0110.g1:/ F G /">$FG$</span> to the square on <span data-ref="0110.g1:/ G H /">$GH$</span>; [x. 6, Por.]
therefore the square on <span data-ref="0110.g1:/ F G /">$FG$</span> is commensurable with the square on <span data-ref="0110.g1:/ G H /">$GH$</span>. [x. 6]
    But <span data-ref="0110.g1:/ F G /">$FG$</span> is rational;
therefore <span data-ref="0110.g1:/ G H /">$GH$</span> is also rational.
    And, since <span data-ref="0110.g1:/ A B /">$BA$</span> has not to <span data-ref="0110.g1:/ A C /">$AC$</span> the ratio which a square number has to a square number,

therefore <span data-ref="0110.g1:/ F G /">$FG$</span> is incommensurable in length with <span data-ref="0110.g1:/ G H /">$GH$</span>. [x. 9]
    Therefore <span data-ref="0110.g1:/ F G /">$FG$</span>, <span data-ref="0110.g1:/ G H /">$GH$</span> are rational straight lines commensurable in square only;
therefore <span data-ref="0110.g1:/ F H /">$FH$</span> is binomial. [x. 36]
