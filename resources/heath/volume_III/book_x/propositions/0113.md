### PROPOSITION 51.

#### *To find the fourth binomial straight line.*

Let two numbers <span data-ref="0113.g1:/ A C /">$AC$</span>, <span data-ref="0113.g1:/ C B /">$CB$</span> be set out such that <span data-ref="0113.g1:/ A B /">$AB$</span> neither has to <span data-ref="0113.g1:/ C B /">$BC$</span>, nor yet to <span data-ref="0113.g1:/ A C /">$AC$</span>, the ratio which a square number has to a square number.

![Proposition 51](0113.g1.svg)

Let a rational straight line <span data-ref="0113.g1:D">$D$</span> be set out, and let <span data-ref="0113.g1:/ E F /">$EF$</span> be commensurable in length with <span data-ref="0113.g1:D">$D$</span>; therefore <span data-ref="0113.g1:/ E F /">$EF$</span> is also rational.

Let it be contrived that, as the number <span data-ref="0113.g1:/ A B /">$BA$</span> is to <span data-ref="0113.g1:/ A C /">$AC$</span>, so is the square on <span data-ref="0113.g1:/ E F /">$EF$</span> to the square on <span data-ref="0113.g1:/ F G /">$FG$</span>; [x. 6, Por.] therefore the square on <span data-ref="0113.g1:/ E F /">$EF$</span> is commensurable with the square on <span data-ref="0113.g1:/ F G /">$FG$</span>; [x. 6] therefore <span data-ref="0113.g1:/ F G /">$FG$</span> is also rational.

Now, since <span data-ref="0113.g1:/ A B /">$BA$</span> has not to <span data-ref="0113.g1:/ A C /">$AC$</span> the ratio which a square number has to a square number, neither has the square on <span data-ref="0113.g1:/ E F /">$EF$</span> to the square on <span data-ref="0113.g1:/ F G /">$FG$</span> the ratio which a square number has to a square number; therefore <span data-ref="0113.g1:/ E F /">$EF$</span> is incommensurable in length with <span data-ref="0113.g1:/ F G /">$FG$</span>. [x. 9]

Therefore <span data-ref="0113.g1:/ E F /">$EF$</span>, <span data-ref="0113.g1:/ F G /">$FG$</span> are rational straight lines commensurable in square only; so that <span data-ref="0113.g1:/ E G /">$EG$</span> is binomial.

I say next that it is also a fourth binomial straight line.

For since, as <span data-ref="0113.g1:/ A B /">$BA$</span> is to <span data-ref="0113.g1:/ A C /">$AC$</span>, so is the square on <span data-ref="0113.g1:/ E F /">$EF$</span> to the square on <span data-ref="0113.g1:/ F G /">$FG$</span>, therefore the square on <span data-ref="0113.g1:/ E F /">$EF$</span> is greater than the square on <span data-ref="0113.g1:/ F G /">$FG$</span>.
