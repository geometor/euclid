<p class="assertion">therefore <span data-ref="0149.g1:/ A E /">$AE$</span>, <span data-ref="0149.g1:/ E B /">$EB$</span> are rational straight lines commensurable<br />
in square only. <span class="justification">[X. 36]</span></p>

Let it be contrived that,<br />
as <span data-ref="0149.g1:/ A B /">$AB$</span> is to <span data-ref="0149.g1:/ C D /">$CD$</span>, so is <span data-ref="0149.g1:/ A E /">$AE$</span> to <span data-ref="0149.g1:/ C F /">$CF$</span>; <span class="justification">[VI. 12]</span>

<p class="assertion">therefore also the remainder <span data-ref="0149.g1:/ E B /">$EB$</span> is to the remainder <span data-ref="0149.g1:/ F D /">$FD$</span> as<br />
<span data-ref="0149.g1:/ A B /">$AB$</span> is to <span data-ref="0149.g1:/ C D /">$CD$</span>. <span class="justification">[V. 19]</span></p>

<p class="sub-clause">But <span data-ref="0149.g1:/ A B /">$AB$</span> is commensurable in length with <span data-ref="0149.g1:/ C D /">$CD$</span>;</p>

<p class="assertion">therefore <span data-ref="0149.g1:/ A E /">$AE$</span> is also commensurable with <span data-ref="0149.g1:/ C F /">$CF$</span>, and <span data-ref="0149.g1:/ E B /">$EB$</span> with<br />
<span data-ref="0149.g1:/ F D /">$FD$</span>. <span class="justification">[X. 11]</span></p>

<p class="sub-clause">And <span data-ref="0149.g1:/ A E /">$AE$</span>, <span data-ref="0149.g1:/ E B /">$EB$</span> are rational;</p>

<p class="assertion">therefore <span data-ref="0149.g1:/ C F /">$CF$</span>, <span data-ref="0149.g1:/ F D /">$FD$</span> are also rational.</p>

<p class="sub-clause">And, as <span data-ref="0149.g1:/ A E /">$AE$</span> is to <span data-ref="0149.g1:/ C F /">$CF$</span>, so is <span data-ref="0149.g1:/ E B /">$EB$</span> to <span data-ref="0149.g1:/ F D /">$FD$</span>. <span class="justification">[V. 11]</span></p>

<p class="assertion">Therefore, alternately, as <span data-ref="0149.g1:/ A E /">$AE$</span> is to <span data-ref="0149.g1:/ E B /">$EB$</span>, so is <span data-ref="0149.g1:/ C F /">$CF$</span> to <span data-ref="0149.g1:/ F D /">$FD$</span>.<br />
<span class="justification">[V. 16]</span></p>

<p class="sub-clause">But <span data-ref="0149.g1:/ A E /">$AE$</span>, <span data-ref="0149.g1:/ E B /">$EB$</span> are commensurable in square only;</p>

<p class="assertion">therefore <span data-ref="0149.g1:/ C F /">$CF$</span>, <span data-ref="0149.g1:/ F D /">$FD$</span> are also commensurable in square only.<br />
<span class="justification">[X. 11]</span></p>

<p class="sub-clause">And they are rational;</p>

<p class="assertion">therefore <span data-ref="0149.g1:/ C D /">$CD$</span> is binomial. <span class="justification">[X. 36]</span></p>

I say next that it is the same in order with <span data-ref="0149.g1:/ A B /">$AB$</span>.

<p class="sub-clause">For the square on <span data-ref="0149.g1:/ A E /">$AE$</span> is greater than the square on <span data-ref="0149.g1:/ E B /">$EB$</span><br />
either by the square on a straight line commensurable with<br />
<span data-ref="0149.g1:/ A E /">$AE$</span> or by the square on a straight line incommensurable<br />
with it.</p>

<p class="sub-clause">If then the square on <span data-ref="0149.g1:/ A E /">$AE$</span> is greater than the square on<br />
<span data-ref="0149.g1:/ E B /">$EB$</span> by the square on a straight line commensurable with <span data-ref="0149.g1:/ A E /">$AE$</span>,</p>

<p class="assertion">the square on <span data-ref="0149.g1:/ C F /">$CF$</span> will also be greater than the square on <span data-ref="0149.g1:/ F D /">$FD$</span><br />
by the square on a straight line commensurable with <span data-ref="0149.g1:/ C F /">$CF$</span>.<br />
<span class="justification">[X. 14]</span></p>

<p class="sub-clause">And, if <span data-ref="0149.g1:/ A E /">$AE$</span> is commensurable with the rational straight<br />
line set out, <span data-ref="0149.g1:/ C F /">$CF$</span> will also be commensurable with it, <span class="justification">[X. 12]</span></p>

<p class="assertion">and for this reason each of the straight lines <span data-ref="0149.g1:/ A B /">$AB$</span>, <span data-ref="0149.g1:/ C D /">$CD$</span> is a<br />
first binomial, that is, the same in order. <span class="justification">[X. Deff. II. 1]</span></p>

<p class="sub-clause">But, if <span data-ref="0149.g1:/ E B /">$EB$</span> is commensurable with the rational straight<br />
line set out, <span data-ref="0149.g1:/ F D /">$FD$</span> is also commensurable with it, <span class="justification">[X. 12]</span></p>

<p class="assertion">and for this reason again <span data-ref="0149.g1:/ C D /">$CD$</span> will be the same in order with<br />
<span data-ref="0149.g1:/ A B /">$AB$</span>,<br />
for each of them will be a second binomial. <span class="justification">[X. Deff. II. 2]</span></p>
