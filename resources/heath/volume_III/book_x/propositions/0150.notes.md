## Textual, Lexical & Mathematical Observations
- **Proportional construction:**
  - $AB : CD = AE : CF = EB : FD$ (VI. 12, V. 19).
  - Commensurability transfer: $AB \sim CD \implies AE \sim CF$ and $EB \sim FD$ (X. 11).
  - Alternating proportion: $AE : EB = CF : FD$ (V. 16) preserves commensurability in square only.
- **Order preservation:**
  - If $\sqrt{AE^2 - EB^2} \sim AE$, then $\sqrt{CF^2 - FD^2} \sim CF$ (X. 14).
  - If $AE$ is commensurable with the rational straight line set out $\implies CF$ is also (X. 12), making both first binomial (X. Deff. II. 1).
  - If $EB$ is commensurable with the rational straight line set out $\implies FD$ is also, making both second binomial (X. Deff. II. 2).
