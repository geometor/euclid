And let it be contrived that, as <span data-ref="0151.g1:/ A B /">$AB$</span> is to <span data-ref="0151.g1:/ C D /">$CD$</span>, so is <span data-ref="0151.g1:/ A E /">$AE$</span> to <span data-ref="0151.g1:/ C F /">$CF$</span>;

But <span data-ref="0151.g1:/ A B /">$AB$</span> is commensurable in length with <span data-ref="0151.g1:/ C D /">$CD$</span>;
therefore <span data-ref="0151.g1:/ A E /">$AE$</span>, <span data-ref="0151.g1:/ E B /">$EB$</span> are also commensurable with <span data-ref="0151.g1:/ C F /">$CF$</span>, <span data-ref="0151.g1:/ F D /">$FD$</span> respectively. [x. 11]

But <span data-ref="0151.g1:/ A E /">$AE$</span>, <span data-ref="0151.g1:/ E B /">$EB$</span> are medial;
therefore <span data-ref="0151.g1:/ C F /">$CF$</span>, <span data-ref="0151.g1:/ F D /">$FD$</span> are also medial. [x. 23]

And since, as <span data-ref="0151.g1:/ A E /">$AE$</span> is to <span data-ref="0151.g1:/ E B /">$EB$</span>, so is <span data-ref="0151.g1:/ C F /">$CF$</span> to <span data-ref="0151.g1:/ F D /">$FD$</span>, [v. 11]
and <span data-ref="0151.g1:/ A E /">$AE$</span>, <span data-ref="0151.g1:/ E B /">$EB$</span> are commensurable in square only,
<span data-ref="0151.g1:/ C F /">$CF$</span>, <span data-ref="0151.g1:/ F D /">$FD$</span> are also commensurable in square only. [x. 11]

But they were also proved medial;
therefore <span data-ref="0151.g1:/ C D /">$CD$</span> is bimedial.

I say next that it is also the same in order with <span data-ref="0151.g1:/ A B /">$AB$</span>.

For since, as <span data-ref="0151.g1:/ A E /">$AE$</span> is to <span data-ref="0151.g1:/ E B /">$EB$</span>, so is <span data-ref="0151.g1:/ C F /">$CF$</span> to <span data-ref="0151.g1:/ F D /">$FD$</span>,
therefore also, as the square on <span data-ref="0151.g1:/ A E /">$AE$</span> is to the rectangle <span data-ref="0151.g1:/ A E /">$AE$</span>, <span data-ref="0151.g1:/ E B /">$EB$</span>, so is the square on <span data-ref="0151.g1:/ C F /">$CF$</span> to the rectangle <span data-ref="0151.g1:/ C F /">$CF$</span>, <span data-ref="0151.g1:/ F D /">$FD$</span>;
therefore, alternately,
as the square on <span data-ref="0151.g1:/ A E /">$AE$</span> is to the square on <span data-ref="0151.g1:/ C F /">$CF$</span>, so is the rectangle <span data-ref="0151.g1:/ A E /">$AE$</span>, <span data-ref="0151.g1:/ E B /">$EB$</span> to the rectangle <span data-ref="0151.g1:/ C F /">$CF$</span>, <span data-ref="0151.g1:/ F D /">$FD$</span>. [v. 16]

But the square on <span data-ref="0151.g1:/ A E /">$AE$</span> is commensurable with the square on <span data-ref="0151.g1:/ C F /">$CF$</span>;
therefore the rectangle <span data-ref="0151.g1:/ A E /">$AE$</span>, <span data-ref="0151.g1:/ E B /">$EB$</span> is also commensurable with the rectangle <span data-ref="0151.g1:/ C F /">$CF$</span>, <span data-ref="0151.g1:/ F D /">$FD$</span>.

If therefore the rectangle <span data-ref="0151.g1:/ A E /">$AE$</span>, <span data-ref="0151.g1:/ E B /">$EB$</span> is rational, the rectangle <span data-ref="0151.g1:/ C F /">$CF$</span>, <span data-ref="0151.g1:/ F D /">$FD$</span> is also rational,
[and for this reason <span data-ref="0151.g1:/ C D /">$CD$</span> is a first bimedial]; [x. 37]
but if medial, medial, [x. 23, Por.]
and each of the straight lines <span data-ref="0151.g1:/ A B /">$AB$</span>, <span data-ref="0151.g1:/ C D /">$CD$</span> is a second bimedial. [x. 38]

And for this reason <span data-ref="0151.g1:/ C D /">$CD$</span> will be the same in order with <span data-ref="0151.g1:/ A B /">$AB$</span>.
