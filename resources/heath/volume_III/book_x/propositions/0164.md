For from the medial straight line <span data-ref="0164.g1:/ A B /">$AB$</span> let there be subtracted the medial straight line <span data-ref="0164.g1:/ B C /">$BC$</span> which is commensurable with <span data-ref="0164.g1:/ A B /">$AB$</span> in square only and with <span data-ref="0164.g1:/ A B /">$AB$</span> makes the rectangle <span data-ref="0164.g1:/ A B /">$AB$</span>, <span data-ref="0164.g1:/ B C /">$BC$</span> rational;

![Proposition 74](0164.g1.svg)

I say that the remainder <span data-ref="0164.g1:/ A C /">$AC$</span> is irrational; and let it be called a **first apotome of a medial straight line**.

For, since <span data-ref="0164.g1:/ A B /">$AB$</span>, <span data-ref="0164.g1:/ B C /">$BC$</span> are medial,
the squares on <span data-ref="0164.g1:/ A B /">$AB$</span>, <span data-ref="0164.g1:/ B C /">$BC$</span> are also medial.

But twice the rectangle <span data-ref="0164.g1:/ A B /">$AB$</span>, <span data-ref="0164.g1:/ B C /">$BC$</span> is rational;
therefore the squares on <span data-ref="0164.g1:/ A B /">$AB$</span>, <span data-ref="0164.g1:/ B C /">$BC$</span> are incommensurable with twice the rectangle <span data-ref="0164.g1:/ A B /">$AB$</span>, <span data-ref="0164.g1:/ B C /">$BC$</span>;
therefore twice the rectangle <span data-ref="0164.g1:/ A B /">$AB$</span>, <span data-ref="0164.g1:/ B C /">$BC$</span> is also incommensurable with the remainder, the square on <span data-ref="0164.g1:/ A C /">$AC$</span>, [cf. II. 7]
since, if the whole is incommensurable with one of the magnitudes, the original magnitudes will also be incommensurable. [X. 16]

But twice the rectangle <span data-ref="0164.g1:/ A B /">$AB$</span>, <span data-ref="0164.g1:/ B C /">$BC$</span> is rational;
therefore the square on <span data-ref="0164.g1:/ A C /">$AC$</span> is irrational;
therefore <span data-ref="0164.g1:/ A C /">$AC$</span> is irrational. [X. Def. 4]

And let it be called a **first apotome of a medial straight line.**

---

The *first apotome of a medial straight line* is the difference between straight lines of the form $k^{\frac{1}{4}}\rho, k^{\frac{3}{4}}\rho$, which are medial straight lines commensurable in square only and forming a rational rectangle.

By hypothesis, $x^2, y^2$ are medial areas.

And, since $xy$ is rational,
$$(x^2 + y^2) \smile xy$$
$$\smile 2xy,$$
whence
$$(x - y)^2 \smile 2xy.$$

But $2xy$ is rational;
therefore $(x - y)^2$, and consequently $(x - y)$, is irrational.

This irrational, which is of the form $(k^{\frac{1}{4}}\rho \sim k^{\frac{3}{4}}\rho)$, is the *first apotome of a medial straight line*; the term corresponding of course to *first bimedial*, which applies where the sign is positive.
