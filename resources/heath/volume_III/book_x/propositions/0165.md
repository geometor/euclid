### PROPOSITION 75.

<p class="enunciation">If from a medial straight line there be subtracted a medial<br />
straight line which is commensurable with the whole in square<br />
only, and which contains with the whole a medial rectangle,<br />
the remainder is irrational; and let it be called a second<br />
apotome of a medial straight line.</p>

For from the medial straight line <span data-ref="0165.g1:/ A B /">$AB$</span> let there be sub-<br />
tracted the medial straight line <span data-ref="0165.g1:/ C B /">$CB$</span> which is commensurable<br />
with the whole <span data-ref="0165.g1:/ A B /">$AB$</span> in square only and such that the rectangle<br />
<span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span>, which it contains with the whole <span data-ref="0165.g1:/ A B /">$AB$</span>, is medial; <span class="justification">[X. 28]</span>

I say that the remainder <span data-ref="0165.g1:/ A C /">$AC$</span> is irrational; and let it be called<br />
a second apotome of a medial straight line.

![Proposition 75 Diagram](0165.g1.svg)

For let a rational straight line <span data-ref="0165.g1:/ D I /">$DI$</span> be set out,<br />
let <span data-ref="0165.g1:< D E >">$DE$</span> equal to the squares on <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span> be applied to <span data-ref="0165.g1:/ D I /">$DI$</span>,<br />
producing <span data-ref="0165.g1:/ D G /">$DG$</span> as breadth,<br />
and let <span data-ref="0165.g1:< D H >">$DH$</span> equal to twice the rectangle <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span> be applied<br />
to <span data-ref="0165.g1:/ D I /">$DI$</span>, producing <span data-ref="0165.g1:/ D F /">$DF$</span> as breadth;

<p class="assertion">therefore the remainder <span data-ref="0165.g1:< F E >">$FE$</span> is equal to the square on <span data-ref="0165.g1:/ A C /">$AC$</span>.<br />
<span class="justification">[II. 7]</span></p>

<p class="sub-clause">Now, since the squares on <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span> are medial and<br />
commensurable,</p>
<p class="assertion">therefore <span data-ref="0165.g1:< D E >">$DE$</span> is also medial. <span class="justification">[X. 15 and 23, Por.]</span></p>

<p class="sub-clause">And it is applied to the rational straight line <span data-ref="0165.g1:/ D I /">$DI$</span>, producing<br />
<span data-ref="0165.g1:/ D G /">$DG$</span> as breadth;</p>
<p class="assertion">therefore <span data-ref="0165.g1:/ D G /">$DG$</span> is rational and incommensurable in length<br />
with <span data-ref="0165.g1:/ D I /">$DI$</span>. <span class="justification">[X. 22]</span></p>

<p class="sub-clause">Again, since the rectangle <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span> is medial,</p>
<p class="assertion">therefore twice the rectangle <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span> is also medial.<br />
<span class="justification">[X. 23, Por.]</span></p>
