### PROPOSITION 75.

*If from a medial straight line there be subtracted a medial straight line which is commensurable with the whole in square only, and which contains with the whole a medial rectangle, the remainder is irrational; and let it be called a* **second apotome of a medial straight line.**

For from the medial straight line <span data-ref="0165.g1:/ A B /">$AB$</span> let there be subtracted the medial straight line <span data-ref="0165.g1:/ C B /">$CB$</span> which is commensurable with the whole <span data-ref="0165.g1:/ A B /">$AB$</span> in square only and such that the rectangle <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span>, which it contains with the whole <span data-ref="0165.g1:/ A B /">$AB$</span>, is medial; [x. 28]  
I say that the remainder <span data-ref="0165.g1:/ A C /">$AC$</span> is irrational; and let it be called a **second apotome of a medial straight line.**

![Proposition 75 Diagram](0165.g1.svg)

For let a rational straight line <span data-ref="0165.g1:/ D I /">$DI$</span> be set out,  
let <span data-ref="0165.g1:< D E >">$DE$</span> equal to the squares on <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span> be applied to <span data-ref="0165.g1:/ D I /">$DI$</span>, producing <span data-ref="0165.g1:/ D G /">$DG$</span> as breadth,  
and let <span data-ref="0165.g1:< D H >">$DH$</span> equal to twice the rectangle <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span> be applied to <span data-ref="0165.g1:/ D I /">$DI$</span>, producing <span data-ref="0165.g1:/ D F /">$DF$</span> as breadth;  
therefore the remainder <span data-ref="0165.g1:< F E >">$FE$</span> is equal to the square on <span data-ref="0165.g1:/ A C /">$AC$</span>. [II. 7]

Now, since the squares on <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span> are medial and commensurable,  
therefore <span data-ref="0165.g1:< D E >">$DE$</span> is also medial. [x. 15 and 23, Por.]

And it is applied to the rational straight line <span data-ref="0165.g1:/ D I /">$DI$</span>, producing <span data-ref="0165.g1:/ D G /">$DG$</span> as breadth;  
therefore <span data-ref="0165.g1:/ D G /">$DG$</span> is rational and incommensurable in length with <span data-ref="0165.g1:/ D I /">$DI$</span>. [x. 22]

Again, since the rectangle <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span> is medial,  
therefore twice the rectangle <span data-ref="0165.g1:/ A B /">$AB$</span>, <span data-ref="0165.g1:/ B C /">$BC$</span> is also medial. [x. 23, Por.]
