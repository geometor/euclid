### PROPOSITION 76.

<p class="enunciation">If from a straight line there be subtracted a straight line<br />
which is incommensurable in square with the whole and which<br />
with the whole makes the squares on them added together<br />
rational, but the rectangle contained by them medial, the<br />
remainder is irrational; and let it be called minor.</p>

For from the straight line <span data-ref="0167.g1:/ A B /">$AB$</span> let there be subtracted the<br />
straight line <span data-ref="0167.g1:/ B C /">$BC$</span> which is incom-<br />
mensurable in square with the whole<br />
and fulfils the given conditions. <span class="justification">[X. 33]</span>

![Proposition 76 Diagram](0167.g1.svg)

I say that the remainder <span data-ref="0167.g1:/ A C /">$AC$</span> is the irrational straight line<br />
called minor.

<p class="sub-clause">For, since the sum of the squares on <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span> is rational,<br />
while twice the rectangle <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span> is medial,</p>
<p class="assertion">therefore the squares on <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span> are incommensurable with<br />
twice the rectangle <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span>;</p>

<p class="assertion">and, <em>convertendo</em>, the squares on <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span> are incommensurable<br />
with the remainder, the square on <span data-ref="0167.g1:/ A C /">$AC$</span>. <span class="justification">[II. 7, X. 16]</span></p>

<p class="sub-clause">But the squares on <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span> are rational;</p>
<p class="assertion">therefore the square on <span data-ref="0167.g1:/ A C /">$AC$</span> is irrational;<br />
therefore <span data-ref="0167.g1:/ A C /">$AC$</span> is irrational.</p>

<p class="qed">And let it be called **minor**.<span class="justification">Q. E. D.</span></p>
