### PROPOSITION 76.

*If from a straight line there be subtracted a straight line which is incommensurable in square with the whole and which with the whole makes the squares on them added together rational, but the rectangle contained by them medial, the remainder is irrational; and let it be called* **minor.**

For from the straight line <span data-ref="0167.g1:/ A B /">$AB$</span> let there be subtracted the straight line <span data-ref="0167.g1:/ B C /">$BC$</span> which is incommensurable in square with the whole and fulfils the given conditions. [x. 33]

![Proposition 76 Diagram](0167.g1.svg)

I say that the remainder <span data-ref="0167.g1:/ A C /">$AC$</span> is the irrational straight line called **minor.**

For, since the sum of the squares on <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span> is rational,  
while twice the rectangle <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span> is medial,  
therefore the squares on <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span> are incommensurable with twice the rectangle <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span>;  
and, *convertendo*, the squares on <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span> are incommensurable with the remainder, the square on <span data-ref="0167.g1:/ A C /">$AC$</span>. [II. 7, x. 16]

But the squares on <span data-ref="0167.g1:/ A B /">$AB$</span>, <span data-ref="0167.g1:/ B C /">$BC$</span> are rational;  
therefore the square on <span data-ref="0167.g1:/ A C /">$AC$</span> is irrational;  
therefore <span data-ref="0167.g1:/ A C /">$AC$</span> is irrational.

And let it be called **minor.**
