$x, y$ are here of the form found in x. 33, viz.
$$\frac{\rho}{\sqrt 2} \sqrt{1 + \frac{k}{\sqrt{1 + k^2}}}, \quad \frac{\rho}{\sqrt 2} \sqrt{1 - \frac{k}{\sqrt{1 + k^2}}}.$$

By hypothesis $(x^2 + y^2)$ is a rational, $xy$ a medial, area.  
Therefore
$$(x^2 + y^2) \smile 2xy,$$
whence
$$(x - y)^2 \smile (x^2 + y^2).$$

Therefore $(x - y)^2$, and consequently $(x - y)$, is irrational.  
The *minor* (irrational) straight line is thus of the form
$$\frac{\rho}{\sqrt 2} \sqrt{1 + \frac{k}{\sqrt{1 + k^2}}} - \frac{\rho}{\sqrt 2} \sqrt{1 - \frac{k}{\sqrt{1 + k^2}}}.$$

Observe the use of *convertendo* ($\alpha\nu\alpha\sigma\tau\rho\acute{\epsilon}\psi\alpha\nu\tau\iota$) for the inference that, since<br />
$(x^2 + y^2) \smile 2xy$, $(x^2 + y^2) \smile (x - y)^2$. The use of the word corresponds exactly<br />
to its use in proportions.

### PROPOSITION 77.

<p class="enunciation">If from a straight line there be subtracted a straight line<br />
which is incommensurable in square with the whole, and which<br />
with the whole makes the sum of the squares on them medial,<br />
but twice the rectangle contained by them rational, the remainder<br />
is irrational: and let it be called <strong>that which produces with<br />
a rational area a medial whole.</strong></p>

For from the straight line <span data-ref="0168.g1:/ A B /">$AB$</span> let there be subtracted the<br />
straight line <span data-ref="0168.g1:/ B C /">$BC$</span> which is incommensurable in square<br />
with <span data-ref="0168.g1:/ A B /">$AB$</span> and fulfils the given conditions ; <span class="justification">[X. 34]</span><br />
I say that the remainder <span data-ref="0168.g1:/ A C /">$AC$</span> is the irrational straight<br />
line aforesaid.

![Proposition 77 Diagram](0168.g1.svg)

<p class="sub-clause">For, since the sum of the squares on <span data-ref="0168.g1:/ A B /">$AB$</span>, <span data-ref="0168.g1:/ B C /">$BC$</span> is<br />
medial,<br />
while twice the rectangle <span data-ref="0168.g1:/ A B /">$AB$</span>, <span data-ref="0168.g1:/ B C /">$BC$</span> is rational,</p>
<p class="assertion">therefore the squares on <span data-ref="0168.g1:/ A B /">$AB$</span>, <span data-ref="0168.g1:/ B C /">$BC$</span> are incommensurable<br />
with twice the rectangle <span data-ref="0168.g1:/ A B /">$AB$</span>, <span data-ref="0168.g1:/ B C /">$BC$</span> ;<br />
therefore the remainder also, the square on <span data-ref="0168.g1:/ A C /">$AC$</span>, is incom-<br />
mensurable with twice the rectangle <span data-ref="0168.g1:/ A B /">$AB$</span>, <span data-ref="0168.g1:/ B C /">$BC$</span>. <span class="justification">[II. 7, X. 16]</span></p>

<p class="sub-clause">And twice the rectangle <span data-ref="0168.g1:/ A B /">$AB$</span>, <span data-ref="0168.g1:/ B C /">$BC$</span> is rational ;</p>
<p class="assertion">therefore the square on <span data-ref="0168.g1:/ A C /">$AC$</span> is irrational ;<br />
therefore <span data-ref="0168.g1:/ A C /">$AC$</span> is irrational.</p>

<p class="qed">And let it be called <strong>that which produces with a<br />
rational area a medial whole.</strong><span class="justification">Q. E. D.</span></p>
