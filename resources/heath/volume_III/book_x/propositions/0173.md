For let <span data-ref="0173.g1:/ A B /">$AB$</span> be a first apotome of a medial straight line,
and let <span data-ref="0173.g1:/ B C /">$BC$</span> be an annex to <span data-ref="0173.g1:/ A B /">$AB$</span>;
therefore <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> are medial
straight lines commensurable in
square only and such that the rectangle <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> which they
contain is rational; \[[x. 74](x.74.md)\]

![Proposition 80](0173.g1.svg)

I say that no other medial straight line can be annexed to
<span data-ref="0173.g1:/ A B /">$AB$</span> which is commensurable with the whole in square only
and which contains with the whole a rational area.

For, if possible, let <span data-ref="0173.g1:/ D B /">$DB$</span> be so annexed;
therefore <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> are medial straight lines commensurable
in square only and such that the rectangle <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> which
they contain is rational. \[[x. 74](x.74.md)\]

Now, since the excess of the squares on <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> over
twice the rectangle <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> is also the excess of the squares
on <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> over twice the rectangle <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span>,
for they exceed by the same, the square on <span data-ref="0173.g1:/ A B /">$AB$</span>, \[[II. 7](II.7.md)\]
therefore, alternately, the excess of the squares on <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span>
over the squares on <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> is also the excess of twice the
rectangle <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> over twice the rectangle <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span>.

But twice the rectangle <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> exceeds twice the rect-
angle <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> by a rational area,
for both are rational.

Therefore the squares on <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> also exceed the squares
on <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> by a rational area:
which is impossible,
for both are medial \[[x. 15 and 23, Por.](x.15.md)\], and a medial area does
not exceed a medial by a rational area. \[[x. 26](x.26.md)\]

Therefore etc.

$$\text{Q. E. D.}$$

Suppose, if possible, that the same *first apotome of a medial* straight line
can be expressed in terms of the required character in two ways, so that
$$x - y = x' - y',$$
and suppose that $x > x'$.

In this case $x^2 + y^2$, $(x'^2 + y'^2)$ are both medial areas, and $2xy$, $2x'y'$ are both
rational areas;
and
$$x^2 + y^2 - (x'^2 + y'^2) = 2xy - 2x'y'.$$

Hence x. 26 is contradicted again;
therefore etc.
