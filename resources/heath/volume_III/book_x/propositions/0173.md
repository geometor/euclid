For let <span data-ref="0173.g1:/ A B /">$AB$</span> be a first apotome of a medial straight line,<br />
and let <span data-ref="0173.g1:/ B C /">$BC$</span> be an annex to <span data-ref="0173.g1:/ A B /">$AB$</span>;
<p class="assertion">therefore <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> are medial<br />
straight lines commensurable in<br />
square only and such that the rectangle <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> which they<br />
contain is rational; <span class="justification">[X. 74]</span></p>

![Proposition 80 diagram](0173.g1.svg)

I say that no other medial straight line can be annexed to<br />
<span data-ref="0173.g1:/ A B /">$AB$</span> which is commensurable with the whole in square only<br />
and which contains with the whole a rational area.

<p class="sub-clause">For, if possible, let <span data-ref="0173.g1:/ D B /">$DB$</span> also be so annexed;</p>
<p class="assertion">therefore <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> are medial straight lines commensurable<br />
in square only and such that the rectangle <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> which<br />
they contain is rational. <span class="justification">[X. 74]</span></p>

<p class="sub-clause">Now, since the excess of the squares on <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> over<br />
twice the rectangle <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> is also the excess of the squares<br />
on <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> over twice the rectangle <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span>,<br />
for they exceed by the same, the square on <span data-ref="0173.g1:/ A B /">$AB$</span>, <span class="justification">[II. 7]</span></p>
<p class="assertion">therefore, alternately, the excess of the squares on <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span><br />
over the squares on <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> is also the excess of twice the<br />
rectangle <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> over twice the rectangle <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span>.</p>

<p class="sub-clause">But twice the rectangle <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> exceeds twice the rect-<br />
angle <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> by a rational area,<br />
for both are rational.</p>

<p class="assertion">Therefore the squares on <span data-ref="0173.g1:/ A D /">$AD$</span>, <span data-ref="0173.g1:/ D B /">$DB$</span> also exceed the squares<br />
on <span data-ref="0173.g1:/ A C /">$AC$</span>, <span data-ref="0173.g1:/ C B /">$CB$</span> by a rational area:<br />
which is impossible,<br />
for both are medial <span class="justification">[X. 15 and 23, Por.]</span>, and a medial area does<br />
not exceed a medial by a rational area. <span class="justification">[X. 26]</span></p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>

Suppose, if possible, that the same *first apotome of a medial* straight line<br />
can be expressed in terms of the required character in two ways, so that
$$x - y = x' - y',$$
and suppose that $x > x'$.

In this case $x^2 + y^2$, $(x'^2 + y'^2)$ are both medial areas, and $2xy$, $2x'y'$ are both<br />
rational areas;
and
$$x^2 + y^2 - (x'^2 + y'^2) = 2xy - 2x'y'.$$

Hence x. 26 is contradicted again;<br />
therefore etc.
