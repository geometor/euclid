### Proposition 81.

*To a second apotome of a medial straight line only one
medial straight line can be annexed which is commensurable
with the whole in square only and which contains with the
whole a medial rectangle.*

Let <span data-ref="0174.g1:/ A B /">$AB$</span> be a second apotome of a medial straight line
and <span data-ref="0174.g1:/ B C /">$BC$</span> an annex to <span data-ref="0174.g1:/ A B /">$AB$</span>;
therefore <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are medial straight
lines commensurable in square only and
such that the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> which
they contain is medial. \[[x. 75](x.75.md)\]

![Proposition 81](0174.g1.svg)

I say that no other medial straight line
can be annexed to <span data-ref="0174.g1:/ A B /">$AB$</span> which is commen-
surable with the whole in square only and
which contains with the whole a medial
rectangle.

For, if possible, let <span data-ref="0174.g1:/ B D /">$BD$</span> also be so
annexed;
therefore <span data-ref="0174.g1:/ A D /">$AD$</span>, <span data-ref="0174.g1:/ D B /">$DB$</span> are also medial straight
lines commensurable in square only and
such that the rectangle <span data-ref="0174.g1:/ A D /">$AD$</span>, <span data-ref="0174.g1:/ D B /">$DB$</span> which
they contain is medial. \[[x. 75](x.75.md)\]

Let a rational straight line <span data-ref="0174.g1:/ E F /">$EF$</span> be set out,
let <span data-ref="0174.g1:< E G >">$EG$</span> equal to the squares on <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> be applied to <span data-ref="0174.g1:/ E F /">$EF$</span>,
producing <span data-ref="0174.g1:/ E M /">$EM$</span> as breadth,
and let <span data-ref="0174.g1:< H G >">$HG$</span> equal to twice the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> be sub-
tracted, producing <span data-ref="0174.g1:/ H M /">$HM$</span> as breadth;
therefore the remainder <span data-ref="0174.g1:< E L >">$EL$</span> is equal to the square on <span data-ref="0174.g1:/ A B /">$AB$</span>,
\[[II. 7](II.7.md)\]
so that <span data-ref="0174.g1:/ A B /">$AB$</span> is the "side" of <span data-ref="0174.g1:< E L >">$EL$</span>.

Again, let <span data-ref="0174.g1:< E I >">$EI$</span> equal to the squares on <span data-ref="0174.g1:/ A D /">$AD$</span>, <span data-ref="0174.g1:/ D B /">$DB$</span> be applied
to <span data-ref="0174.g1:/ E F /">$EF$</span>, producing <span data-ref="0174.g1:/ E N /">$EN$</span> as breadth.
But <span data-ref="0174.g1:< E L >">$EL$</span> is also equal to the square on <span data-ref="0174.g1:/ A B /">$AB$</span>;
therefore the remainder <span data-ref="0174.g1:< H I >">$HI$</span> is equal to twice the rectangle
<span data-ref="0174.g1:/ A D /">$AD$</span>, <span data-ref="0174.g1:/ D B /">$DB$</span>. \[[II. 7](II.7.md)\]

Now, since <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are medial straight lines,
therefore the squares on <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are also medial.
