### PROPOSITION 81.

<p class="enunciation">To a second apotome of a medial straight line only one<br />
medial straight line can be annexed which is commensurable<br />
with the whole in square only and which contains with the<br />
whole a medial rectangle.</p>

Let <span data-ref="0174.g1:/ A B /">$AB$</span> be a second apotome of a medial straight line<br />
and <span data-ref="0174.g1:/ B C /">$BC$</span> an annex to <span data-ref="0174.g1:/ A B /">$AB$</span>;
<p class="assertion">therefore <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are medial straight<br />
lines commensurable in square only and<br />
such that the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> which<br />
they contain is medial. <span class="justification">[X. 75]</span></p>

![Proposition 81 diagram](0174.g1.svg)

I say that no other medial straight line<br />
can be annexed to <span data-ref="0174.g1:/ A B /">$AB$</span> which is commen-<br />
surable with the whole in square only and<br />
which contains with the whole a medial<br />
rectangle.

<p class="sub-clause">For, if possible, let <span data-ref="0174.g1:/ B D /">$BD$</span> also be so<br />
annexed;</p>
<p class="assertion">therefore <span data-ref="0174.g1:/ A D /">$AD$</span>, <span data-ref="0174.g1:/ D B /">$DB$</span> are also medial straight<br />
lines commensurable in square only and<br />
such that the rectangle <span data-ref="0174.g1:/ A D /">$AD$</span>, <span data-ref="0174.g1:/ D B /">$DB$</span> which<br />
they contain is medial. <span class="justification">[X. 75]</span></p>

Let a rational straight line <span data-ref="0174.g1:/ E F /">$EF$</span> be set out,<br />
let <span data-ref="0174.g1:< E G >">$EG$</span> equal to the squares on <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> be applied to <span data-ref="0174.g1:/ E F /">$EF$</span>,<br />
producing <span data-ref="0174.g1:/ E M /">$EM$</span> as breadth,<br />
and let <span data-ref="0174.g1:< H G >">$HG$</span> equal to twice the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> be sub-<br />
tracted, producing <span data-ref="0174.g1:/ H M /">$HM$</span> as breadth;
<p class="assertion">therefore the remainder <span data-ref="0174.g1:< E L >">$EL$</span> is equal to the square on <span data-ref="0174.g1:/ A B /">$AB$</span>, <span class="justification">[II. 7]</span><br />
so that <span data-ref="0174.g1:/ A B /">$AB$</span> is the “side” of <span data-ref="0174.g1:< E L >">$EL$</span>.</p>

Again, let <span data-ref="0174.g1:< E I >">$EI$</span> equal to the squares on <span data-ref="0174.g1:/ A D /">$AD$</span>, <span data-ref="0174.g1:/ D B /">$DB$</span> be applied<br />
to <span data-ref="0174.g1:/ E F /">$EF$</span>, producing <span data-ref="0174.g1:/ E N /">$EN$</span> as breadth.
<p class="sub-clause">But <span data-ref="0174.g1:< E L >">$EL$</span> is also equal to the square on <span data-ref="0174.g1:/ A B /">$AB$</span>;</p>
<p class="assertion">therefore the remainder <span data-ref="0174.g1:< H I >">$HI$</span> is equal to twice the rectangle<br />
<span data-ref="0174.g1:/ A D /">$AD$</span>, <span data-ref="0174.g1:/ D B /">$DB$</span>. <span class="justification">[II. 7]</span></p>

<p class="sub-clause">Now, since <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are medial straight lines,</p>
<p class="assertion">therefore the squares on <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are also medial.</p>
