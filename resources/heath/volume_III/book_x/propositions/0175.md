<p class="sub-clause">And they are equal to <span data-ref="0174.g1:< E G >">$EG$</span>;</p>
<p class="assertion">therefore <span data-ref="0174.g1:< E G >">$EG$</span> is also medial. <span class="justification">[X. 15 and 23, Por.]</span></p>

<p class="sub-clause">And it is applied to the rational straight line <span data-ref="0174.g1:/ E F /">$EF$</span>, producing<br />
<span data-ref="0174.g1:/ E M /">$EM$</span> as breadth;</p>
<p class="assertion">therefore <span data-ref="0174.g1:/ E M /">$EM$</span> is rational and incommensurable in length<br />
with <span data-ref="0174.g1:/ E F /">$EF$</span>. <span class="justification">[X. 22]</span></p>

<p class="sub-clause">Again, since the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> is medial,</p>
<p class="assertion">twice the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> is also medial. <span class="justification">[X. 23, Por.]</span></p>

<p class="sub-clause">And it is equal to <span data-ref="0174.g1:< H G >">$HG$</span>;</p>
<p class="assertion">therefore <span data-ref="0174.g1:< H G >">$HG$</span> is also medial.</p>

<p class="sub-clause">And it is applied to the rational straight line <span data-ref="0174.g1:/ E F /">$EF$</span>, producing<br />
<span data-ref="0174.g1:/ H M /">$HM$</span> as breadth;</p>
<p class="assertion">therefore <span data-ref="0174.g1:/ H M /">$HM$</span> is also rational and incommensurable in length<br />
with <span data-ref="0174.g1:/ E F /">$EF$</span>. <span class="justification">[X. 22]</span></p>

<p class="sub-clause">And, since <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are commensurable in square only,</p>
<p class="assertion">therefore <span data-ref="0174.g1:/ A C /">$AC$</span> is incommensurable in length with <span data-ref="0174.g1:/ C B /">$CB$</span>.</p>

<p class="sub-clause">But, as <span data-ref="0174.g1:/ A C /">$AC$</span> is to <span data-ref="0174.g1:/ C B /">$CB$</span>, so is the square on <span data-ref="0174.g1:/ A C /">$AC$</span> to the rect-<br />
angle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>;</p>
<p class="assertion">therefore the square on <span data-ref="0174.g1:/ A C /">$AC$</span> is incommensurable with the<br />
rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>. <span class="justification">[X. 11]</span></p>

<p class="sub-clause">But the squares on <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are commensurable with the<br />
square on <span data-ref="0174.g1:/ A C /">$AC$</span>,<br />
while twice the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> is commensurable with the<br />
rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>; <span class="justification">[X. 6]</span></p>
<p class="assertion">therefore the squares on <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are incommensurable with<br />
twice the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>. <span class="justification">[X. 13]</span></p>

<p class="sub-clause">And <span data-ref="0174.g1:< E G >">$EG$</span> is equal to the squares on <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>,<br />
while <span data-ref="0174.g1:< G H >">$GH$</span> is equal to twice the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>;</p>
<p class="assertion">therefore <span data-ref="0174.g1:< E G >">$EG$</span> is incommensurable with <span data-ref="0174.g1:< H G >">$HG$</span>.</p>

<p class="sub-clause">But, as <span data-ref="0174.g1:< E G >">$EG$</span> is to <span data-ref="0174.g1:< H G >">$HG$</span>, so is <span data-ref="0174.g1:/ E M /">$EM$</span> to <span data-ref="0174.g1:/ H M /">$HM$</span>; <span class="justification">[VI. 1]</span></p>
<p class="assertion">therefore <span data-ref="0174.g1:/ E M /">$EM$</span> is incommensurable in length with <span data-ref="0174.g1:/ M H /">$MH$</span>. <span class="justification">[X. 11]</span></p>

<p class="sub-clause">And both are rational;</p>
<p class="assertion">therefore <span data-ref="0174.g1:/ E M /">$EM$</span>, <span data-ref="0174.g1:/ M H /">$MH$</span> are rational straight lines commensurable<br />
in square only;<br />
therefore <span data-ref="0174.g1:/ E H /">$EH$</span> is an apotome, and <span data-ref="0174.g1:/ H M /">$HM$</span> an annex to it. <span class="justification">[X. 73]</span></p>
