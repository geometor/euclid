And they are equal to <span data-ref="0174.g1:< E G >">$EG$</span>;
therefore <span data-ref="0174.g1:< E G >">$EG$</span> is also medial. \[[x. 15 and 23, Por.](x.15.md)\]

And it is applied to the rational straight line <span data-ref="0174.g1:/ E F /">$EF$</span>, producing
<span data-ref="0174.g1:/ E M /">$EM$</span> as breadth;
therefore <span data-ref="0174.g1:/ E M /">$EM$</span> is rational and incommensurable in length
with <span data-ref="0174.g1:/ E F /">$EF$</span>. \[[x. 22](x.22.md)\]

Again, since the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> is medial,
twice the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> is also medial. \[[x. 23, Por.](x.23.md)\]

And it is equal to <span data-ref="0174.g1:< H G >">$HG$</span>;
therefore <span data-ref="0174.g1:< H G >">$HG$</span> is also medial.

And it is applied to the rational straight line <span data-ref="0174.g1:/ E F /">$EF$</span>, producing
<span data-ref="0174.g1:/ H M /">$HM$</span> as breadth;
therefore <span data-ref="0174.g1:/ H M /">$HM$</span> is also rational and incommensurable in length
with <span data-ref="0174.g1:/ E F /">$EF$</span>. \[[x. 22](x.22.md)\]

And, since <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are commensurable in square only,
therefore <span data-ref="0174.g1:/ A C /">$AC$</span> is incommensurable in length with <span data-ref="0174.g1:/ C B /">$CB$</span>.

But, as <span data-ref="0174.g1:/ A C /">$AC$</span> is to <span data-ref="0174.g1:/ C B /">$CB$</span>, so is the square on <span data-ref="0174.g1:/ A C /">$AC$</span> to the rect-
angle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>;
therefore the square on <span data-ref="0174.g1:/ A C /">$AC$</span> is incommensurable with the
rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>. \[[x. 11](x.11.md)\]

But the squares on <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are commensurable with the
square on <span data-ref="0174.g1:/ A C /">$AC$</span>,
while twice the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> is commensurable with the
rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>; \[[x. 6](x.6.md)\]
therefore the squares on <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span> are incommensurable with
twice the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>. \[[x. 13](x.13.md)\]

And <span data-ref="0174.g1:< E G >">$EG$</span> is equal to the squares on <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>,
while <span data-ref="0174.g1:< G H >">$GH$</span> is equal to twice the rectangle <span data-ref="0174.g1:/ A C /">$AC$</span>, <span data-ref="0174.g1:/ C B /">$CB$</span>;
therefore <span data-ref="0174.g1:< E G >">$EG$</span> is incommensurable with <span data-ref="0174.g1:< H G >">$HG$</span>.

But, as <span data-ref="0174.g1:< E G >">$EG$</span> is to <span data-ref="0174.g1:< H G >">$HG$</span>, so is <span data-ref="0174.g1:/ E M /">$EM$</span> to <span data-ref="0174.g1:/ H M /">$HM$</span>; \[[VI. 1](VI.1.md)\]
therefore <span data-ref="0174.g1:/ E M /">$EM$</span> is incommensurable in length with <span data-ref="0174.g1:/ M H /">$MH$</span>. \[[x. 11](x.11.md)\]

And both are rational;
therefore <span data-ref="0174.g1:/ E M /">$EM$</span>, <span data-ref="0174.g1:/ M H /">$MH$</span> are rational straight lines commensurable
in square only;
therefore <span data-ref="0174.g1:/ E H /">$EH$</span> is an apotome, and <span data-ref="0174.g1:/ H M /">$HM$</span> an annex to it. \[[x. 73](x.73.md)\]
