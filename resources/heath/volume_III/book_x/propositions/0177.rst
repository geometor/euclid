I say that no other straight line can be annexed to :g:`$AB$ <0176.g1:/ A B />` fulfilling the same conditions.

.. subclause::

   For, if possible, let :g:`$BD$ <0176.g1:/ B D />` be so annexed ;

.. assertion::

   therefore :g:`$AD$ <0176.g1:/ A D />`, :g:`$DB$ <0176.g1:/ D B />` are also straight lines incommensurable in square which fulfil the aforesaid conditions. :just:`[X. 76] <X.76>`

.. subclause::

   Now, since the excess of the squares on :g:`$AD$ <0176.g1:/ A D />`, :g:`$DB$ <0176.g1:/ D B />` over the squares on :g:`$AC$ <0176.g1:/ A C />`, :g:`$CB$ <0176.g1:/ C B />` is also the excess of twice the rectangle :g:`$AD$ <0176.g1:/ A D />`, :g:`$DB$ <0176.g1:/ D B />` over twice the rectangle :g:`$AC$ <0176.g1:/ A C />`, :g:`$CB$ <0176.g1:/ C B />`, while the squares on :g:`$AD$ <0176.g1:/ A D />`, :g:`$DB$ <0176.g1:/ D B />` exceed the squares on :g:`$AC$ <0176.g1:/ A C />`, :g:`$CB$ <0176.g1:/ C B />` by a rational area, for both are rational,

.. assertion::

   therefore twice the rectangle :g:`$AD$ <0176.g1:/ A D />`, :g:`$DB$ <0176.g1:/ D B />` also exceeds twice the rectangle :g:`$AC$ <0176.g1:/ A C />`, :g:`$CB$ <0176.g1:/ C B />` by a rational area : which is impossible, for both are medial. :just:`[X. 26] <X.26>`

.. qed::

   Therefore to a minor straight line only one straight line can be annexed which is incommensurable in square with the whole and which makes the squares on them added together rational, but twice the rectangle contained by them medial. :just:`Q. E. D.`

----

Suppose, if possible, that, with the usual notation,

$$x - y = x' - y' ;$$

and let $x$ (say) be greater than $x'$.

In this case $(x^2 + y^2)$, $(x'^2 + y'^2)$ are both *rational* areas, and $2xy$, $2x'y'$ are both *medial* areas.

But, as before,

$$(x^2 + y^2) - (x'^2 + y'^2) = 2xy - 2x'y',$$

so that the difference between two medial areas is rational : which is impossible [x. 26].

Therefore etc.

PROPOSITION 83.
---------------

.. enunciation::

   To a straight line which produces with a rational area a medial whole only one straight line can be annexed which is incommensurable in square with the whole straight line and which with the whole straight line makes the sum of the squares on them medial, but twice the rectangle contained by them rational.
