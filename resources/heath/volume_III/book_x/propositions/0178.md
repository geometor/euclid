Let <span data-ref="0178.g1:/ A B /">$AB$</span> be the straight line which produces with a rational<br />
area a medial whole,<br />
and let <span data-ref="0178.g1:/ B C /">$BC$</span> be an annex to <span data-ref="0178.g1:/ A B /">$AB$</span>;
<p class="assertion">therefore <span data-ref="0178.g1:/ A C /">$AC$</span>, <span data-ref="0178.g1:/ C B /">$CB$</span> are straight lines<br />
incommensurable in square which fulfil the given conditions.<br />
<span class="justification">[X. 77]</span></p>

![Proposition 83](0178.g1.svg)

I say that no other straight line can be annexed to <span data-ref="0178.g1:/ A B /">$AB$</span><br />
which fulfils the same conditions.

For, if possible, let <span data-ref="0178.g1:/ B D /">$BD$</span> be so annexed;
<p class="assertion">therefore <span data-ref="0178.g1:/ A D /">$AD$</span>, <span data-ref="0178.g1:/ D B /">$DB$</span> are also straight lines incommensurable in<br />
square which fulfil the given conditions. <span class="justification">[X. 77]</span></p>

<p class="sub-clause">Since then, as in the preceding cases,<br />
the excess of the squares on <span data-ref="0178.g1:/ A D /">$AD$</span>, <span data-ref="0178.g1:/ D B /">$DB$</span> over the squares on<br />
<span data-ref="0178.g1:/ A C /">$AC$</span>, <span data-ref="0178.g1:/ C B /">$CB$</span> is also the excess of twice the rectangle <span data-ref="0178.g1:/ A D /">$AD$</span>, <span data-ref="0178.g1:/ D B /">$DB$</span><br />
over twice the rectangle <span data-ref="0178.g1:/ A C /">$AC$</span>, <span data-ref="0178.g1:/ C B /">$CB$</span>,<br />
while twice the rectangle <span data-ref="0178.g1:/ A D /">$AD$</span>, <span data-ref="0178.g1:/ D B /">$DB$</span> exceeds twice the rectangle<br />
<span data-ref="0178.g1:/ A C /">$AC$</span>, <span data-ref="0178.g1:/ C B /">$CB$</span> by a rational area,<br />
for both are rational,</p>
<p class="assertion">therefore the squares on <span data-ref="0178.g1:/ A D /">$AD$</span>, <span data-ref="0178.g1:/ D B /">$DB$</span> also exceed the squares<br />
on <span data-ref="0178.g1:/ A C /">$AC$</span>, <span data-ref="0178.g1:/ C B /">$CB$</span> by a rational area:<br />
which is impossible, for both are medial. <span class="justification">[X. 26]</span></p>

<p class="assertion">Therefore no other straight line can be annexed to <span data-ref="0178.g1:/ A B /">$AB$</span><br />
which is incommensurable in square with the whole and which<br />
with the whole fulfils the aforesaid conditions;<br />
therefore only one straight line can be so annexed.</p>

<p class="qed"><span class="justification">Q. E. D.</span></p>

---

Suppose, with the same notation, that
$$x - y = x' - y'. \qquad (x > x')$$

Here, $(x^2 + y^2)$, $(x'^2 + y'^2)$ being both medial areas, and $2xy$, $2x'y'$ both<br />
rational areas,<br />
while
$$(x^2 + y^2) - (x'^2 + y'^2) = 2xy - 2x'y',$$
X. 26 is contradicted again.

Therefore etc.

### Proposition 84.

<p class="enunciation">To a straight line which produces with a medial area a<br />
medial whole only one straight line can be annexed which is<br />
incommensurable in square with the whole straight line and<br />
which with the whole straight line makes the sum of the squares</p>
