Let <span data-ref="0178.g1:/ A B /">$AB$</span> be the straight line which produces with a rational
area a medial whole,
and let <span data-ref="0178.g1:/ B C /">$BC$</span> be an annex to <span data-ref="0178.g1:/ A B /">$AB$</span>;
therefore <span data-ref="0178.g1:/ A C /">$AC$</span>, <span data-ref="0178.g1:/ C B /">$CB$</span> are straight lines
incommensurable in square which fulfil the given conditions.
\[[x. 77](x.77.md)\]

![Proposition 83](0178.g1.svg)

I say that no other straight line can be annexed to <span data-ref="0178.g1:/ A B /">$AB$</span>
which fulfils the same conditions.

For, if possible, let <span data-ref="0178.g1:/ B D /">$BD$</span> be so annexed;
therefore <span data-ref="0178.g1:/ A D /">$AD$</span>, <span data-ref="0178.g1:/ D B /">$DB$</span> are also straight lines incommensurable in
square which fulfil the given conditions. \[[x. 77](x.77.md)\]

Since then, as in the preceding cases,
the excess of the squares on <span data-ref="0178.g1:/ A D /">$AD$</span>, <span data-ref="0178.g1:/ D B /">$DB$</span> over the squares on
<span data-ref="0178.g1:/ A C /">$AC$</span>, <span data-ref="0178.g1:/ C B /">$CB$</span> is also the excess of twice the rectangle <span data-ref="0178.g1:/ A D /">$AD$</span>, <span data-ref="0178.g1:/ D B /">$DB$</span>
over twice the rectangle <span data-ref="0178.g1:/ A C /">$AC$</span>, <span data-ref="0178.g1:/ C B /">$CB$</span>,
while twice the rectangle <span data-ref="0178.g1:/ A D /">$AD$</span>, <span data-ref="0178.g1:/ D B /">$DB$</span> exceeds twice the rectangle
<span data-ref="0178.g1:/ A C /">$AC$</span>, <span data-ref="0178.g1:/ C B /">$CB$</span> by a rational area,
for both are rational,
therefore the squares on <span data-ref="0178.g1:/ A D /">$AD$</span>, <span data-ref="0178.g1:/ D B /">$DB$</span> also exceed the squares
on <span data-ref="0178.g1:/ A C /">$AC$</span>, <span data-ref="0178.g1:/ C B /">$CB$</span> by a rational area:
which is impossible, for both are medial. \[[x. 26](x.26.md)\]

Therefore no other straight line can be annexed to <span data-ref="0178.g1:/ A B /">$AB$</span>
which is incommensurable in square with the whole and which
with the whole fulfils the aforesaid conditions;
therefore only one straight line can be so annexed.

$$\text{Q. E. D.}$$

---

Suppose, with the same notation, that
$$x - y = x' - y'. \qquad (x > x')$$

Here, $(x^2 + y^2)$, $(x'^2 + y'^2)$ being both medial areas, and $2xy$, $2x'y'$ both
rational areas,
while
$$(x^2 + y^2) - (x'^2 + y'^2) = 2xy - 2x'y',$$
x. 26 is contradicted again.

Therefore etc.
