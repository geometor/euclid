### PROPOSITION 85.

*To find the first apotome.*

Let a rational straight line <span data-ref="0182.g1:A">$A$</span> be set out, and let <span data-ref="0182.g1:/ B G /">$BG$</span> be commensurable in length with <span data-ref="0182.g1:A">$A$</span>;
therefore <span data-ref="0182.g1:/ B G /">$BG$</span> is also rational.

![Proposition 85](0182.g1.svg)

Let two square numbers <span data-ref="0182.g1:/ D E /">$DE$</span>, <span data-ref="0182.g1:/ E F /">$EF$</span> be set out, and let their difference <span data-ref="0182.g1:/ F D /">$FD$</span> not be square;
therefore neither has <span data-ref="0182.g1:/ E D /">$ED$</span> to <span data-ref="0182.g1:/ D F /">$DF$</span> the ratio which a square number has to a square number.

Let it be contrived that,
as <span data-ref="0182.g1:/ E D /">$ED$</span> is to <span data-ref="0182.g1:/ D F /">$DF$</span>, so is the square on <span data-ref="0182.g1:/ B G /">$BG$</span> to the square on <span data-ref="0182.g1:/ G C /">$GC$</span>; \[[x. 6, Por.](x.6.md)\]
therefore the square on <span data-ref="0182.g1:/ B G /">$BG$</span> is commensurable with the square on <span data-ref="0182.g1:/ G C /">$GC$</span>. \[[x. 6](x.6.md)\]

But the square on <span data-ref="0182.g1:/ B G /">$BG$</span> is rational;
therefore the square on <span data-ref="0182.g1:/ G C /">$GC$</span> is also rational;
therefore <span data-ref="0182.g1:/ G C /">$GC$</span> is also rational.

And, since <span data-ref="0182.g1:/ E D /">$ED$</span> has not to <span data-ref="0182.g1:/ D F /">$DF$</span> the ratio which a square number has to a square number,
therefore neither has the square on <span data-ref="0182.g1:/ B G /">$BG$</span> to the square on <span data-ref="0182.g1:/ G C /">$GC$</span> the ratio which a square number has to a square number;
therefore <span data-ref="0182.g1:/ B G /">$BG$</span> is incommensurable in length with <span data-ref="0182.g1:/ G C /">$GC$</span>. \[[x. 9](x.9.md)\]

And both are rational;
therefore <span data-ref="0182.g1:/ B G /">$BG$</span>, <span data-ref="0182.g1:/ G C /">$GC$</span> are rational straight lines commensurable in square only;
therefore <span data-ref="0182.g1:/ B C /">$BC$</span> is an apotome. \[[x. 73](x.73.md)\]

I say next that it is also a first apotome.

For let the square on <span data-ref="0182.g1:H">$H$</span> be that by which the square on <span data-ref="0182.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0182.g1:/ G C /">$GC$</span>.

Now since, as <span data-ref="0182.g1:/ E D /">$ED$</span> is to <span data-ref="0182.g1:/ F D /">$FD$</span>, so is the square on <span data-ref="0182.g1:/ B G /">$BG$</span> to the square on <span data-ref="0182.g1:/ G C /">$GC$</span>,
therefore also, *convertendo*, \[[v. 19, Por.](v.19.md)\]
as <span data-ref="0182.g1:/ D E /">$DE$</span> is to <span data-ref="0182.g1:/ E F /">$EF$</span>, so is the square on <span data-ref="0182.g1:/ G B /">$GB$</span> to the square on <span data-ref="0182.g1:H">$H$</span>.
