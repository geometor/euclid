### PROPOSITION 85.

<p class="enunciation">To find the first apotome.</p>

Let a rational straight line <span data-ref="0182.g1:A">$A$</span> be set out,<br />
and let <span data-ref="0182.g1:/ B G /">$BG$</span> be commensurable in length with <span data-ref="0182.g1:A">$A$</span> ;
<p class="assertion">therefore <span data-ref="0182.g1:/ B G /">$BG$</span> is also rational.</p>

![Proposition 85](0182.g1.svg)

Let two square numbers <span data-ref="0182.g1:/ D E /">$DE$</span>, <span data-ref="0182.g1:/ E F /">$EF$</span> be set out, and let their<br />
difference <span data-ref="0182.g1:/ F D /">$FD$</span> not be square ;
<p class="assertion">therefore neither has <span data-ref="0182.g1:/ E D /">$ED$</span> to <span data-ref="0182.g1:/ D F /">$DF$</span> the ratio which a square<br />
number has to a square number.</p>

Let it be contrived that,<br />
as <span data-ref="0182.g1:/ E D /">$ED$</span> is to <span data-ref="0182.g1:/ D F /">$DF$</span>, so is the square on <span data-ref="0182.g1:/ B G /">$BG$</span> to the square on <span data-ref="0182.g1:/ G C /">$GC$</span> ;<br />
<span class="justification">[X. 6, Por.]</span>
<p class="assertion">therefore the square on <span data-ref="0182.g1:/ B G /">$BG$</span> is commensurable with the square<br />
on <span data-ref="0182.g1:/ G C /">$GC$</span>. <span class="justification">[X. 6]</span></p>

<p class="sub-clause">But the square on <span data-ref="0182.g1:/ B G /">$BG$</span> is rational ;</p>
<p class="assertion">therefore the square on <span data-ref="0182.g1:/ G C /">$GC$</span> is also rational ;<br />
therefore <span data-ref="0182.g1:/ G C /">$GC$</span> is also rational.</p>

<p class="sub-clause">And, since <span data-ref="0182.g1:/ E D /">$ED$</span> has not to <span data-ref="0182.g1:/ D F /">$DF$</span> the ratio which a square<br />
number has to a square number,</p>
<p class="assertion">therefore neither has the square on <span data-ref="0182.g1:/ B G /">$BG$</span> to the square on <span data-ref="0182.g1:/ G C /">$GC$</span><br />
the ratio which a square number has to a square number ;<br />
therefore <span data-ref="0182.g1:/ B G /">$BG$</span> is incommensurable in length with <span data-ref="0182.g1:/ G C /">$GC$</span>. <span class="justification">[X. 9]</span></p>

<p class="sub-clause">And both are rational ;</p>
<p class="assertion">therefore <span data-ref="0182.g1:/ B G /">$BG$</span>, <span data-ref="0182.g1:/ G C /">$GC$</span> are rational straight lines commensurable<br />
in square only ;<br />
therefore <span data-ref="0182.g1:/ B C /">$BC$</span> is an apotome. <span class="justification">[X. 73]</span></p>

I say next that it is also a first apotome.

For let the square on <span data-ref="0182.g1:H">$H$</span> be that by which the square on<br />
<span data-ref="0182.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0182.g1:/ G C /">$GC$</span>.

<p class="sub-clause">Now since, as <span data-ref="0182.g1:/ E D /">$ED$</span> is to <span data-ref="0182.g1:/ F D /">$FD$</span>, so is the square on <span data-ref="0182.g1:/ B G /">$BG$</span> to<br />
the square on <span data-ref="0182.g1:/ G C /">$GC$</span>,</p>
<p class="assertion">therefore also, <em>convertendo</em>, <span class="justification">[V. 19, Por.]</span><br />
as <span data-ref="0182.g1:/ D E /">$DE$</span> is to <span data-ref="0182.g1:/ E F /">$EF$</span>, so is the square on <span data-ref="0182.g1:/ G B /">$GB$</span> to the square on <span data-ref="0182.g1:H">$H$</span>.</p>
