### PROPOSITION 86.

*To find the second apotome.*

Let a rational straight line <span data-ref="0184.g1:A">$A$</span> be set out, and <span data-ref="0184.g1:/ G C /">$GC$</span> commensurable in length with <span data-ref="0184.g1:A">$A$</span>;
therefore <span data-ref="0184.g1:/ G C /">$GC$</span> is rational.

![Proposition 86](0184.g1.svg)

Let two square numbers <span data-ref="0184.g1:/ D E /">$DE$</span>, <span data-ref="0184.g1:/ E F /">$EF$</span> be set out, and let their difference <span data-ref="0184.g1:/ D F /">$DF$</span> not be square.

Now let it be contrived that, as <span data-ref="0184.g1:/ F D /">$FD$</span> is to <span data-ref="0184.g1:/ D E /">$DE$</span>, so is the square on <span data-ref="0184.g1:/ C G /">$CG$</span> to the square on <span data-ref="0184.g1:/ G B /">$GB$</span>. \[[x. 6, Por.](x.6.md)\]

Therefore the square on <span data-ref="0184.g1:/ C G /">$CG$</span> is commensurable with the square on <span data-ref="0184.g1:/ G B /">$GB$</span>. \[[x. 6](x.6.md)\]

But the square on <span data-ref="0184.g1:/ C G /">$CG$</span> is rational;
therefore the square on <span data-ref="0184.g1:/ G B /">$GB$</span> is also rational;
therefore <span data-ref="0184.g1:/ B G /">$BG$</span> is rational.

And, since the square on <span data-ref="0184.g1:/ G C /">$GC$</span> has not to the square on <span data-ref="0184.g1:/ G B /">$GB$</span> the ratio which a square number has to a square number,
<span data-ref="0184.g1:/ C G /">$CG$</span> is incommensurable in length with <span data-ref="0184.g1:/ G B /">$GB$</span>. \[[x. 9](x.9.md)\]

And both are rational;
therefore <span data-ref="0184.g1:/ C G /">$CG$</span>, <span data-ref="0184.g1:/ G B /">$GB$</span> are rational straight lines commensurable in square only;
therefore <span data-ref="0184.g1:/ B C /">$BC$</span> is an apotome. \[[x. 73](x.73.md)\]

I say next that it is also a second apotome.

For let the square on <span data-ref="0184.g1:H">$H$</span> be that by which the square on <span data-ref="0184.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0184.g1:/ G C /">$GC$</span>.

Since then, as the square on <span data-ref="0184.g1:/ B G /">$BG$</span> is to the square on <span data-ref="0184.g1:/ G C /">$GC$</span>, so is the number <span data-ref="0184.g1:/ E D /">$ED$</span> to the number <span data-ref="0184.g1:/ D F /">$DF$</span>,
therefore, *convertendo*,
as the square on <span data-ref="0184.g1:/ B G /">$BG$</span> is to the square on <span data-ref="0184.g1:H">$H$</span>, so is <span data-ref="0184.g1:/ D E /">$DE$</span> to <span data-ref="0184.g1:/ E F /">$EF$</span>. \[[v. 19, Por.](v.19.md)\]

And each of the numbers <span data-ref="0184.g1:/ D E /">$DE$</span>, <span data-ref="0184.g1:/ E F /">$EF$</span> is square;
therefore the square on <span data-ref="0184.g1:/ B G /">$BG$</span> has to the square on <span data-ref="0184.g1:H">$H$</span> the ratio which a square number has to a square number;
therefore <span data-ref="0184.g1:/ B G /">$BG$</span> is commensurable in length with <span data-ref="0184.g1:H">$H$</span>. \[[x. 9](x.9.md)\]

And the square on <span data-ref="0184.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0184.g1:/ G C /">$GC$</span> by the square on <span data-ref="0184.g1:H">$H$</span>;
therefore the square on <span data-ref="0184.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0184.g1:/ G C /">$GC$</span>
