### PROPOSITION 86.

<p class="enunciation">To find the second apotome.</p>

Let a rational straight line <span data-ref="0184.g1:A">$A$</span> be set out, and <span data-ref="0184.g1:/ G C /">$GC$</span> com-<br />
mensurable in length with <span data-ref="0184.g1:A">$A$</span> ;
<p class="assertion">therefore <span data-ref="0184.g1:/ G C /">$GC$</span> is rational.</p>

![Proposition 86](0184.g1.svg)

Let two square numbers <span data-ref="0184.g1:/ D E /">$DE$</span>,<br />
<span data-ref="0184.g1:/ E F /">$EF$</span> be set out, and let their<br />
difference <span data-ref="0184.g1:/ D F /">$DF$</span> not be square.

Now let it be contrived that,<br />
as <span data-ref="0184.g1:/ F D /">$FD$</span> is to <span data-ref="0184.g1:/ D E /">$DE$</span>, so is the square<br />
on <span data-ref="0184.g1:/ C G /">$CG$</span> to the square on <span data-ref="0184.g1:/ G B /">$GB$</span>. <span class="justification">[X. 6, Por.]</span>

<p class="assertion">Therefore the square on <span data-ref="0184.g1:/ C G /">$CG$</span> is commensurable with the<br />
square on <span data-ref="0184.g1:/ G B /">$GB$</span>. <span class="justification">[X. 6]</span></p>

<p class="sub-clause">But the square on <span data-ref="0184.g1:/ C G /">$CG$</span> is rational ;</p>
<p class="assertion">therefore the square on <span data-ref="0184.g1:/ G B /">$GB$</span> is also rational ;<br />
therefore <span data-ref="0184.g1:/ B G /">$BG$</span> is rational.</p>

<p class="sub-clause">And, since the square on <span data-ref="0184.g1:/ G C /">$GC$</span> has not to the square on <span data-ref="0184.g1:/ G B /">$GB$</span><br />
the ratio which a square number has to a square number,</p>
<p class="assertion"><span data-ref="0184.g1:/ C G /">$CG$</span> is incommensurable in length with <span data-ref="0184.g1:/ G B /">$GB$</span>. <span class="justification">[X. 9]</span></p>

<p class="sub-clause">And both are rational ;</p>
<p class="assertion">therefore <span data-ref="0184.g1:/ C G /">$CG$</span>, <span data-ref="0184.g1:/ G B /">$GB$</span> are rational straight lines commensurable<br />
in square only ;<br />
therefore <span data-ref="0184.g1:/ B C /">$BC$</span> is an apotome. <span class="justification">[X. 73]</span></p>

I say next that it is also a second apotome.

For let the square on <span data-ref="0184.g1:H">$H$</span> be that by which the square on<br />
<span data-ref="0184.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0184.g1:/ G C /">$GC$</span>.

<p class="sub-clause">Since then, as the square on <span data-ref="0184.g1:/ B G /">$BG$</span> is to the square on <span data-ref="0184.g1:/ G C /">$GC$</span>,<br />
so is the number <span data-ref="0184.g1:/ E D /">$ED$</span> to the number <span data-ref="0184.g1:/ D F /">$DF$</span>,</p>
<p class="assertion">therefore, <em>convertendo</em>,<br />
as the square on <span data-ref="0184.g1:/ B G /">$BG$</span> is to the square on <span data-ref="0184.g1:H">$H$</span>, so is <span data-ref="0184.g1:/ D E /">$DE$</span> to <span data-ref="0184.g1:/ E F /">$EF$</span>.<br />
<span class="justification">[V. 19, Por.]</span></p>

<p class="sub-clause">And each of the numbers <span data-ref="0184.g1:/ D E /">$DE$</span>, <span data-ref="0184.g1:/ E F /">$EF$</span> is square ;</p>
<p class="assertion">therefore the square on <span data-ref="0184.g1:/ B G /">$BG$</span> has to the square on <span data-ref="0184.g1:H">$H$</span> the ratio<br />
which a square number has to a square number ;<br />
therefore <span data-ref="0184.g1:/ B G /">$BG$</span> is commensurable in length with <span data-ref="0184.g1:H">$H$</span>. <span class="justification">[X. 9]</span></p>

<p class="sub-clause">And the square on <span data-ref="0184.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0184.g1:/ G C /">$GC$</span><br />
by the square on <span data-ref="0184.g1:H">$H$</span> ;</p>
<p class="assertion">therefore the square on <span data-ref="0184.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0184.g1:/ G C /">$GC$</span></p>
