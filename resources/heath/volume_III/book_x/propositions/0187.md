<p class="sub-clause">But <span data-ref="0185.g1:E">$E$</span> has not to <span data-ref="0185.g1:/ C D /">$CD$</span> the ratio which a square number<br />
has to a square number ;</p>
<p class="assertion">therefore neither has the square on <span data-ref="0185.g1:A">$A$</span> to the square on <span data-ref="0185.g1:/ G H /">$GH$</span><br />
the ratio which a square number has to a square number ;<br />
therefore <span data-ref="0185.g1:A">$A$</span> is incommensurable in length with <span data-ref="0185.g1:/ G H /">$GH$</span>. <span class="justification">[X. 9]</span></p>

<p class="assertion">Therefore neither of the straight lines <span data-ref="0185.g1:/ F G /">$FG$</span>, <span data-ref="0185.g1:/ G H /">$GH$</span> is<br />
commensurable in length with the rational straight line <span data-ref="0185.g1:A">$A$</span><br />
set out.</p>

Now let the square on <span data-ref="0185.g1:K">$K$</span> be that by which the square on<br />
<span data-ref="0185.g1:/ F G /">$FG$</span> is greater than the square on <span data-ref="0185.g1:/ G H /">$GH$</span>.

<p class="sub-clause">Since then, as <span data-ref="0185.g1:/ B C /">$BC$</span> is to <span data-ref="0185.g1:/ C D /">$CD$</span>, so is the square on <span data-ref="0185.g1:/ F G /">$FG$</span> to<br />
the square on <span data-ref="0185.g1:/ G H /">$GH$</span>,</p>
<p class="assertion">therefore, <em>convertendo</em>, as <span data-ref="0185.g1:/ B C /">$BC$</span> is to <span data-ref="0185.g1:/ B D /">$BD$</span>, so is the square on<br />
<span data-ref="0185.g1:/ F G /">$FG$</span> to the square on <span data-ref="0185.g1:K">$K$</span>. <span class="justification">[V. 19, Por.]</span></p>

<p class="sub-clause">But <span data-ref="0185.g1:/ B C /">$BC$</span> has to <span data-ref="0185.g1:/ B D /">$BD$</span> the ratio which a square number has<br />
to a square number ;</p>
<p class="assertion">therefore the square on <span data-ref="0185.g1:/ F G /">$FG$</span> also has to the square on <span data-ref="0185.g1:K">$K$</span> the<br />
ratio which a square number has to a square number.</p>

<p class="assertion">Therefore <span data-ref="0185.g1:/ F G /">$FG$</span> is commensurable in length with <span data-ref="0185.g1:K">$K$</span>, <span class="justification">[X. 9]</span><br />
and the square on <span data-ref="0185.g1:/ F G /">$FG$</span> is greater than the square on <span data-ref="0185.g1:/ G H /">$GH$</span> by<br />
the square on a straight line commensurable with <span data-ref="0185.g1:/ F G /">$FG$</span>.</p>

<p class="sub-clause">And neither of the straight lines <span data-ref="0185.g1:/ F G /">$FG$</span>, <span data-ref="0185.g1:/ G H /">$GH$</span> is commen-<br />
surable in length with the rational straight line <span data-ref="0185.g1:A">$A$</span> set out ;</p>
<p class="assertion">therefore <span data-ref="0185.g1:/ F H /">$FH$</span> is a third apotome. <span class="justification">[X. Deff. III. 3]</span></p>

<p class="qed">Therefore the third apotome <span data-ref="0185.g1:/ F H /">$FH$</span> has been found.<span class="justification">Q. E. D.</span></p>

Let $\rho$ be a rational straight line.<br />
Take numbers $p$, $qm^2$, $q(m^2 - n^2)$ which have not to one another the ratio<br />
of square to square.

Now let $x$, $y$ be such that
$$p : qm^2 = \rho^2 : x^2 \text{ .................................................(1)}$$
and
$$qm^2 : q(m^2 - n^2) = x^2 : y^2 \text{ ...................................(2).}$$

Then shall $(x - y)$ be a *third apotome*.

For ($\alpha$), from (1),<br />
$x$ is rational but $\smile \rho$ ................................................................(3).

And, from (2), $y$ is rational but $\smile x$.<br />
Therefore $x, y$ are rational and $\sim$,<br />
so that $(x - y)$ is an apotome.
