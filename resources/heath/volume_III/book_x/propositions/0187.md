But <span data-ref="0185.g1:E">$E$</span> has not to <span data-ref="0185.g1:/ C D /">$CD$</span> the ratio which a square number has to a square number;
therefore neither has the square on <span data-ref="0185.g1:A">$A$</span> to the square on <span data-ref="0185.g1:/ G H /">$GH$</span> the ratio which a square number has to a square number;
therefore <span data-ref="0185.g1:A">$A$</span> is incommensurable in length with <span data-ref="0185.g1:/ G H /">$GH$</span>. \[[x. 9](x.9.md)\]

Therefore neither of the straight lines <span data-ref="0185.g1:/ F G /">$FG$</span>, <span data-ref="0185.g1:/ G H /">$GH$</span> is commensurable in length with the rational straight line <span data-ref="0185.g1:A">$A$</span> set out.

Now let the square on <span data-ref="0185.g1:K">$K$</span> be that by which the square on <span data-ref="0185.g1:/ F G /">$FG$</span> is greater than the square on <span data-ref="0185.g1:/ G H /">$GH$</span>.

Since then, as <span data-ref="0185.g1:/ B C /">$BC$</span> is to <span data-ref="0185.g1:/ C D /">$CD$</span>, so is the square on <span data-ref="0185.g1:/ F G /">$FG$</span> to the square on <span data-ref="0185.g1:/ G H /">$GH$</span>,
therefore, *convertendo*, as <span data-ref="0185.g1:/ B C /">$BC$</span> is to <span data-ref="0185.g1:/ B D /">$BD$</span>, so is the square on <span data-ref="0185.g1:/ F G /">$FG$</span> to the square on <span data-ref="0185.g1:K">$K$</span>. \[[v. 19, Por.](v.19.md)\]

But <span data-ref="0185.g1:/ B C /">$BC$</span> has to <span data-ref="0185.g1:/ B D /">$BD$</span> the ratio which a square number has to a square number;
therefore the square on <span data-ref="0185.g1:/ F G /">$FG$</span> also has to the square on <span data-ref="0185.g1:K">$K$</span> the ratio which a square number has to a square number.

Therefore <span data-ref="0185.g1:/ F G /">$FG$</span> is commensurable in length with <span data-ref="0185.g1:K">$K$</span>, \[[x. 9](x.9.md)\]
and the square on <span data-ref="0185.g1:/ F G /">$FG$</span> is greater than the square on <span data-ref="0185.g1:/ G H /">$GH$</span> by the square on a straight line commensurable with <span data-ref="0185.g1:/ F G /">$FG$</span>.

And neither of the straight lines <span data-ref="0185.g1:/ F G /">$FG$</span>, <span data-ref="0185.g1:/ G H /">$GH$</span> is commensurable in length with the rational straight line <span data-ref="0185.g1:A">$A$</span> set out;
therefore <span data-ref="0185.g1:/ F H /">$FH$</span> is a third apotome. \[[x. Deff. III. 3](deff.x.3.md)\]

Therefore the third apotome <span data-ref="0185.g1:/ F H /">$FH$</span> has been found.

$$\text{Q. E. D.}$$

Let $\rho$ be a rational straight line.
Take numbers $p, qm^2, q(m^2 - n^2)$ which have not to one another the ratio of square to square.

Now let $x, y$ be such that
$$p : qm^2 = \rho^2 : x^2 \tag{1}$$
and
$$qm^2 : q(m^2 - n^2) = x^2 : y^2 \tag{2}.$$

Then shall $(x - y)$ be a *third apotome*.

For ($\alpha$), from (1),
$x$ is rational but $\smile \rho$ .................................................(3).

And, from (2), $y$ is rational but $\smile x$.
Therefore $x, y$ are rational and $\sim$,
so that $(x - y)$ is an apotome.
