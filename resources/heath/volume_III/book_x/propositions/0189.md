<p class="sub-clause">Now, since <span data-ref="0188.g1:/ D E /">$DE$</span> has not to <span data-ref="0188.g1:/ E F /">$EF$</span> the ratio which a square<br />
number has to a square number,</p>
<p class="assertion">therefore neither has the square on <span data-ref="0188.g1:/ B G /">$BG$</span> to the square on <span data-ref="0188.g1:/ G C /">$GC$</span><br />
the ratio which a square number has to a square number;<br />
therefore <span data-ref="0188.g1:/ B G /">$BG$</span> is incommensurable in length with <span data-ref="0188.g1:/ G C /">$GC$</span>. <span class="justification">[X. 9]</span></p>

<p class="sub-clause">And both are rational;</p>
<p class="assertion">therefore <span data-ref="0188.g1:/ B G /">$BG$</span>, <span data-ref="0188.g1:/ G C /">$GC$</span> are rational straight lines commensurable<br />
in square only;<br />
therefore <span data-ref="0188.g1:/ B C /">$BC$</span> is an apotome. <span class="justification">[X. 73]</span></p>

Now let the square on <span data-ref="0188.g1:H">$H$</span> be that by which the square on<br />
<span data-ref="0188.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0188.g1:/ G C /">$GC$</span>.

<p class="sub-clause">Since then, as <span data-ref="0188.g1:/ D E /">$DE$</span> is to <span data-ref="0188.g1:/ E F /">$EF$</span>, so is the square on <span data-ref="0188.g1:/ B G /">$BG$</span> to<br />
the square on <span data-ref="0188.g1:/ G C /">$GC$</span>,</p>
<p class="assertion">therefore also, *convertendo*, as <span data-ref="0188.g1:/ E D /">$ED$</span> is to <span data-ref="0188.g1:/ D F /">$DF$</span>, so is the square<br />
on <span data-ref="0188.g1:/ G B /">$GB$</span> to the square on <span data-ref="0188.g1:H">$H$</span>. <span class="justification">[V. 19, Por.]</span></p>

<p class="sub-clause">But <span data-ref="0188.g1:/ E D /">$ED$</span> has not to <span data-ref="0188.g1:/ D F /">$DF$</span> the ratio which a square number<br />
has to a square number;</p>
<p class="assertion">therefore neither has the square on <span data-ref="0188.g1:/ G B /">$GB$</span> to the square on <span data-ref="0188.g1:H">$H$</span><br />
the ratio which a square number has to a square number;<br />
therefore <span data-ref="0188.g1:/ B G /">$BG$</span> is incommensurable in length with <span data-ref="0188.g1:H">$H$</span>. <span class="justification">[X. 9]</span></p>

<p class="sub-clause">And the square on <span data-ref="0188.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0188.g1:/ G C /">$GC$</span><br />
by the square on <span data-ref="0188.g1:H">$H$</span>;</p>
<p class="assertion">therefore the square on <span data-ref="0188.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0188.g1:/ G C /">$GC$</span><br />
by the square on a straight line incommensurable with <span data-ref="0188.g1:/ B G /">$BG$</span>.</p>

<p class="sub-clause">And the whole <span data-ref="0188.g1:/ B G /">$BG$</span> is commensurable in length with the<br />
rational straight line <span data-ref="0188.g1:A">$A$</span> set out.</p>

<p class="assertion">Therefore <span data-ref="0188.g1:/ B C /">$BC$</span> is a fourth apotome. <span class="justification">[X. Deff. III. 4]</span></p>

<p class="qed">Therefore the fourth apotome has been found.<span class="justification">Q. E. D.</span></p>

Beginning with $\rho$, $k\rho$, as in x. 85, 86, we take numbers $m$, $n$ such that<br />
$(m+n)$ has not to either of the numbers $m$, $n$ the ratio of a square number to<br />
a square number.

Take $x$ such that
$$(m+n) : n = k^2\rho^2 : x^2 \text{ ..............................(1),}$$
whence
$$x = k\rho \sqrt{\frac{n}{m+n}}$$
$$= \frac{k\rho}{\sqrt{1+\lambda}}\text{, say.}$$

Then shall $(k\rho - x)$, or $\left(k\rho - \frac{k\rho}{\sqrt{1+\lambda}}\right)$, be a *fourth apotome*.
