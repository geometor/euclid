Now, since <span data-ref="0188.g1:/ D E /">$DE$</span> has not to <span data-ref="0188.g1:/ E F /">$EF$</span> the ratio which a square
number has to a square number,
therefore neither has the square on <span data-ref="0188.g1:/ B G /">$BG$</span> to the square on <span data-ref="0188.g1:/ G C /">$GC$</span>
the ratio which a square number has to a square number;
therefore <span data-ref="0188.g1:/ B G /">$BG$</span> is incommensurable in length with <span data-ref="0188.g1:/ G C /">$GC$</span>. [x. 9]
And both are rational;
therefore <span data-ref="0188.g1:/ B G /">$BG$</span>, <span data-ref="0188.g1:/ G C /">$GC$</span> are rational straight lines commensurable
in square only;
therefore <span data-ref="0188.g1:/ B C /">$BC$</span> is an apotome. [x. 73]

Now let the square on <span data-ref="0188.g1:H">$H$</span> be that by which the square on
<span data-ref="0188.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0188.g1:/ G C /">$GC$</span>.
Since then, as <span data-ref="0188.g1:/ D E /">$DE$</span> is to <span data-ref="0188.g1:/ E F /">$EF$</span>, so is the square on <span data-ref="0188.g1:/ B G /">$BG$</span> to
the square on <span data-ref="0188.g1:/ G C /">$GC$</span>,
therefore also, *convertendo*, as <span data-ref="0188.g1:/ E D /">$ED$</span> is to <span data-ref="0188.g1:/ D F /">$DF$</span>, so is the square
on <span data-ref="0188.g1:/ G B /">$GB$</span> to the square on <span data-ref="0188.g1:H">$H$</span>. [v. 19, Por.]
But <span data-ref="0188.g1:/ E D /">$ED$</span> has not to <span data-ref="0188.g1:/ D F /">$DF$</span> the ratio which a square number
has to a square number;
therefore neither has the square on <span data-ref="0188.g1:/ G B /">$GB$</span> to the square on <span data-ref="0188.g1:H">$H$</span>
the ratio which a square number has to a square number;
therefore <span data-ref="0188.g1:/ B G /">$BG$</span> is incommensurable in length with <span data-ref="0188.g1:H">$H$</span>. [x. 9]
And the square on <span data-ref="0188.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0188.g1:/ G C /">$GC$</span>
by the square on <span data-ref="0188.g1:H">$H$</span>;
therefore the square on <span data-ref="0188.g1:/ B G /">$BG$</span> is greater than the square on <span data-ref="0188.g1:/ G C /">$GC$</span>
by the square on a straight line incommensurable with <span data-ref="0188.g1:/ B G /">$BG$</span>.
And the whole <span data-ref="0188.g1:/ B G /">$BG$</span> is commensurable in length with the
rational straight line <span data-ref="0188.g1:A">$A$</span> set out.
Therefore <span data-ref="0188.g1:/ B C /">$BC$</span> is a fourth apotome. [x. Deff. III. 4]
Therefore the fourth apotome has been found.

Q. E. D.

Beginning with $\rho$, $k\rho$, as in x. 85, 86, we take numbers $m$, $n$ such that
$(m+n)$ has not to either of the numbers $m$, $n$ the ratio of a square number to
a square number.
Take $x$ such that
$$(m+n) : n = k^2\rho^2 : x^2 \text{ ..............................(1),}$$
whence
$$x = k\rho \sqrt{\frac{n}{m+n}}$$
$$= \frac{k\rho}{\sqrt{1+\lambda}}\text{, say.}$$
Then shall $(k\rho - x)$, or $\left(k\rho - \frac{k\rho}{\sqrt{1+\lambda}}\right)$, be a *fourth apotome*.
