### PROPOSITION 90.

*To find the sixth apotome.*

![Proposition 90 Diagram](0192.g1.svg)

Let a rational straight line <span data-ref="0192.g1:A">$A$</span> be set out, and three
numbers <span data-ref="0192.g1:E">$E$</span>, <span data-ref="0192.g1:/ B C /">$BC$</span>, <span data-ref="0192.g1:/ C D /">$CD$</span> not having
to one another the ratio which
a square number has to a square
number;
and further let <span data-ref="0192.g1:/ C B /">$CB$</span> also not have
to <span data-ref="0192.g1:/ B D /">$BD$</span> the ratio which a square
number has to a square number.
Let it be contrived that, as
<span data-ref="0192.g1:E">$E$</span> is to <span data-ref="0192.g1:/ B C /">$BC$</span>, so is the square on <span data-ref="0192.g1:A">$A$</span> to the square on <span data-ref="0192.g1:/ F G /">$FG$</span>,
and, as <span data-ref="0192.g1:/ B C /">$BC$</span> is to <span data-ref="0192.g1:/ C D /">$CD$</span>, so is the square on <span data-ref="0192.g1:/ F G /">$FG$</span> to the square
on <span data-ref="0192.g1:/ G H /">$GH$</span>. [x. 6, Por.]
Now since, as <span data-ref="0192.g1:E">$E$</span> is to <span data-ref="0192.g1:/ B C /">$BC$</span>, so is the square on <span data-ref="0192.g1:A">$A$</span> to the
square on <span data-ref="0192.g1:/ F G /">$FG$</span>,
therefore the square on <span data-ref="0192.g1:A">$A$</span> is commensurable with the square
on <span data-ref="0192.g1:/ F G /">$FG$</span>. [x. 6]
But the square on <span data-ref="0192.g1:A">$A$</span> is rational;
therefore the square on <span data-ref="0192.g1:/ F G /">$FG$</span> is also rational;
therefore <span data-ref="0192.g1:/ F G /">$FG$</span> is also rational.
And, since <span data-ref="0192.g1:E">$E$</span> has not to <span data-ref="0192.g1:/ B C /">$BC$</span> the ratio which a square
number has to a square number,
therefore neither has the square on <span data-ref="0192.g1:A">$A$</span> to the square on <span data-ref="0192.g1:/ F G /">$FG$</span>
the ratio which a square number has to a square number;
therefore <span data-ref="0192.g1:A">$A$</span> is incommensurable in length with <span data-ref="0192.g1:/ F G /">$FG$</span>. [x. 9]
Again, since, as <span data-ref="0192.g1:/ B C /">$BC$</span> is to <span data-ref="0192.g1:/ C D /">$CD$</span>, so is the square on <span data-ref="0192.g1:/ F G /">$FG$</span> to
the square on <span data-ref="0192.g1:/ G H /">$GH$</span>,
therefore the square on <span data-ref="0192.g1:/ F G /">$FG$</span> is commensurable with the square
on <span data-ref="0192.g1:/ G H /">$GH$</span>. [x. 6]
But the square on <span data-ref="0192.g1:/ F G /">$FG$</span> is rational;
therefore the square on <span data-ref="0192.g1:/ G H /">$GH$</span> is also rational;
therefore <span data-ref="0192.g1:/ G H /">$GH$</span> is also rational.
