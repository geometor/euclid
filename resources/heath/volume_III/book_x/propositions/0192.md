### PROPOSITION 90.

<p class="enunciation">To find the sixth apotome.</p>

![Proposition 90](0192.g1.svg)

Let a rational straight line <span data-ref="0192.g1:A">$A$</span> be set out, and three<br />
numbers <span data-ref="0192.g1:E">$E$</span>, <span data-ref="0192.g1:/ B C /">$BC$</span>, <span data-ref="0192.g1:/ C D /">$CD$</span> not having<br />
to one another the ratio which<br />
a square number has to a square<br />
number ;<br />
and further let <span data-ref="0192.g1:/ C B /">$CB$</span> also not have<br />
to <span data-ref="0192.g1:/ B D /">$BD$</span> the ratio which a square<br />
number has to a square number.

Let it be contrived that, as<br />
<span data-ref="0192.g1:E">$E$</span> is to <span data-ref="0192.g1:/ B C /">$BC$</span>, so is the square on <span data-ref="0192.g1:A">$A$</span> to the square on <span data-ref="0192.g1:/ F G /">$FG$</span>,<br />
and, as <span data-ref="0192.g1:/ B C /">$BC$</span> is to <span data-ref="0192.g1:/ C D /">$CD$</span>, so is the square on <span data-ref="0192.g1:/ F G /">$FG$</span> to the square<br />
on <span data-ref="0192.g1:/ G H /">$GH$</span>. <span class="justification">[X. 6, Por.]</span>

<p class="sub-clause">Now since, as <span data-ref="0192.g1:E">$E$</span> is to <span data-ref="0192.g1:/ B C /">$BC$</span>, so is the square on <span data-ref="0192.g1:A">$A$</span> to the<br />
square on <span data-ref="0192.g1:/ F G /">$FG$</span>,</p>
<p class="assertion">therefore the square on <span data-ref="0192.g1:A">$A$</span> is commensurable with the square<br />
on <span data-ref="0192.g1:/ F G /">$FG$</span>. <span class="justification">[X. 6]</span></p>

<p class="sub-clause">But the square on <span data-ref="0192.g1:A">$A$</span> is rational ;</p>
<p class="assertion">therefore the square on <span data-ref="0192.g1:/ F G /">$FG$</span> is also rational ;<br />
therefore <span data-ref="0192.g1:/ F G /">$FG$</span> is also rational.</p>

<p class="sub-clause">And, since <span data-ref="0192.g1:E">$E$</span> has not to <span data-ref="0192.g1:/ B C /">$BC$</span> the ratio which a square<br />
number has to a square number,</p>
<p class="assertion">therefore neither has the square on <span data-ref="0192.g1:A">$A$</span> to the square on <span data-ref="0192.g1:/ F G /">$FG$</span><br />
the ratio which a square number has to a square number ;<br />
therefore <span data-ref="0192.g1:A">$A$</span> is incommensurable in length with <span data-ref="0192.g1:/ F G /">$FG$</span>. <span class="justification">[X. 9]</span></p>

<p class="sub-clause">Again, since, as <span data-ref="0192.g1:/ B C /">$BC$</span> is to <span data-ref="0192.g1:/ C D /">$CD$</span>, so is the square on <span data-ref="0192.g1:/ F G /">$FG$</span> to<br />
the square on <span data-ref="0192.g1:/ G H /">$GH$</span>,</p>
<p class="assertion">therefore the square on <span data-ref="0192.g1:/ F G /">$FG$</span> is commensurable with the square<br />
on <span data-ref="0192.g1:/ G H /">$GH$</span>. <span class="justification">[X. 6]</span></p>

<p class="sub-clause">But the square on <span data-ref="0192.g1:/ F G /">$FG$</span> is rational ;</p>
<p class="assertion">therefore the square on <span data-ref="0192.g1:/ G H /">$GH$</span> is also rational ;<br />
therefore <span data-ref="0192.g1:/ G H /">$GH$</span> is also rational.</p>
