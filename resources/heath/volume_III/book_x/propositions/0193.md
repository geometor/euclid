<p class="assertion">therefore neither has the square on <span data-ref="0192.g1:/ F G /">$FG$</span> to the square on <span data-ref="0192.g1:/ G H /">$GH$</span><br />
the ratio which a square number has to a square number;<br />
therefore <span data-ref="0192.g1:/ F G /">$FG$</span> is incommensurable in length with <span data-ref="0192.g1:/ G H /">$GH$</span>. <span class="justification">[X. 9]</span></p>

<p class="sub-clause">And both are rational;</p>

<p class="assertion">therefore <span data-ref="0192.g1:/ F G /">$FG$</span>, <span data-ref="0192.g1:/ G H /">$GH$</span> are rational straight lines commensurable<br />
in square only;<br />
therefore <span data-ref="0192.g1:/ F H /">$FH$</span> is an apotome. <span class="justification">[X. 73]</span></p>

I say next that it is also a sixth apotome.

<p class="sub-clause">For since, as <span data-ref="0192.g1:E">$E$</span> is to <span data-ref="0192.g1:/ B C /">$BC$</span>, so is the square on <span data-ref="0192.g1:A">$A$</span> to the<br />
square on <span data-ref="0192.g1:/ F G /">$FG$</span>,<br />
and, as <span data-ref="0192.g1:/ B C /">$BC$</span> is to <span data-ref="0192.g1:/ C D /">$CD$</span>, so is the square on <span data-ref="0192.g1:/ F G /">$FG$</span> to the square<br />
on <span data-ref="0192.g1:/ G H /">$GH$</span>,</p>

<p class="assertion">therefore, <em>ex aequali</em>, as <span data-ref="0192.g1:E">$E$</span> is to <span data-ref="0192.g1:/ C D /">$CD$</span>, so is the square on <span data-ref="0192.g1:A">$A$</span> to<br />
the square on <span data-ref="0192.g1:/ G H /">$GH$</span>. <span class="justification">[V. 22]</span></p>

<p class="sub-clause">But <span data-ref="0192.g1:E">$E$</span> has not to <span data-ref="0192.g1:/ C D /">$CD$</span> the ratio which a square number<br />
has to a square number;</p>

<p class="assertion">therefore neither has the square on <span data-ref="0192.g1:A">$A$</span> to the square on <span data-ref="0192.g1:/ G H /">$GH$</span><br />
the ratio which a square number has to a square number;<br />
therefore <span data-ref="0192.g1:A">$A$</span> is incommensurable in length with <span data-ref="0192.g1:/ G H /">$GH$</span>; <span class="justification">[X. 9]</span><br />
therefore neither of the straight lines <span data-ref="0192.g1:/ F G /">$FG$</span>, <span data-ref="0192.g1:/ G H /">$GH$</span> is commen-<br />
surable in length with the rational straight line <span data-ref="0192.g1:A">$A$</span>.</p>

Now let the square on <span data-ref="0192.g1:K">$K$</span> be that by which the square on<br />
<span data-ref="0192.g1:/ F G /">$FG$</span> is greater than the square on <span data-ref="0192.g1:/ G H /">$GH$</span>.

<p class="sub-clause">Since then, as <span data-ref="0192.g1:/ B C /">$BC$</span> is to <span data-ref="0192.g1:/ C D /">$CD$</span>, so is the square on <span data-ref="0192.g1:/ F G /">$FG$</span> to<br />
the square on <span data-ref="0192.g1:/ G H /">$GH$</span>,</p>

<p class="assertion">therefore, <em>convertendo</em>, as <span data-ref="0192.g1:/ C B /">$CB$</span> is to <span data-ref="0192.g1:/ B D /">$BD$</span>, so is the square on<br />
<span data-ref="0192.g1:/ F G /">$FG$</span> to the square on <span data-ref="0192.g1:K">$K$</span>. <span class="justification">[V. 19, Por.]</span></p>

<p class="sub-clause">But <span data-ref="0192.g1:/ C B /">$CB$</span> has not to <span data-ref="0192.g1:/ B D /">$BD$</span> the ratio which a square number<br />
has to a square number;</p>

<p class="assertion">therefore neither has the square on <span data-ref="0192.g1:/ F G /">$FG$</span> to the square on <span data-ref="0192.g1:K">$K$</span><br />
the ratio which a square number has to a square number;<br />
therefore <span data-ref="0192.g1:/ F G /">$FG$</span> is incommensurable in length with <span data-ref="0192.g1:K">$K$</span>. <span class="justification">[X. 9]</span></p>

<p class="sub-clause">And the square on <span data-ref="0192.g1:/ F G /">$FG$</span> is greater than the square on <span data-ref="0192.g1:/ G H /">$GH$</span><br />
by the square on <span data-ref="0192.g1:K">$K$</span>;</p>

<p class="assertion">therefore the square on <span data-ref="0192.g1:/ F G /">$FG$</span> is greater than the square on <span data-ref="0192.g1:/ G H /">$GH$</span><br />
by the square on a straight line incommensurable in length<br />
with <span data-ref="0192.g1:/ F G /">$FG$</span>.</p>
