### PROPOSITION 98.

<p class="enunciation">The square on a first apotome of a medial straight line<br />
applied to a rational straight line produces as breadth a second<br />
apotome.</p>

Let <span data-ref="0219.g1:/ A B /">$AB$</span> be a first apotome of a medial straight line and<br />
<span data-ref="0219.g1:/ C D /">$CD$</span> a rational straight line,<br />
and to <span data-ref="0219.g1:/ C D /">$CD$</span> let there be applied <span data-ref="0219.g1:< C F E D >">$CE$</span> equal to the square on<br />
<span data-ref="0219.g1:/ A B /">$AB$</span>, producing <span data-ref="0219.g1:/ C F /">$CF$</span> as breadth;<br />
I say that <span data-ref="0219.g1:/ C F /">$CF$</span> is a second apotome.

<p class="sub-clause">For let <span data-ref="0219.g1:/ B G /">$BG$</span> be the annex to <span data-ref="0219.g1:/ A B /">$AB$</span>;</p>
<p class="assertion">therefore <span data-ref="0219.g1:/ A G /">$AG$</span>, <span data-ref="0219.g1:/ B G /">$GB$</span> are medial straight lines commensurable in<br />
square only which contain a rational rectangle. <span class="justification">[x. 74]</span></p>

To <span data-ref="0219.g1:/ C D /">$CD$</span> let there be applied <span data-ref="0219.g1:< C K H D >">$CH$</span> equal to the square on<br />
<span data-ref="0219.g1:/ A G /">$AG$</span>, producing <span data-ref="0219.g1:/ C K /">$CK$</span> as breadth, and <span data-ref="0219.g1:< K M L H >">$KL$</span> equal to the square<br />
on <span data-ref="0219.g1:/ B G /">$GB$</span>, producing <span data-ref="0219.g1:/ K M /">$KM$</span> as breadth;
<p class="assertion">therefore the whole <span data-ref="0219.g1:< C M L D >">$CL$</span> is equal to the squares on <span data-ref="0219.g1:/ A G /">$AG$</span>, <span data-ref="0219.g1:/ B G /">$GB$</span>;<br />
therefore <span data-ref="0219.g1:< C M L D >">$CL$</span> is also medial. <span class="justification">[x. 15 and 23, Por.]</span></p>

<p class="sub-clause">And it is applied to the rational straight line <span data-ref="0219.g1:/ C D /">$CD$</span>, pro-<br />
ducing <span data-ref="0219.g1:/ C M /">$CM$</span> as breadth;</p>
<p class="assertion">therefore <span data-ref="0219.g1:/ C M /">$CM$</span> is rational and incommensurable in length with<br />
<span data-ref="0219.g1:/ C D /">$CD$</span>. <span class="justification">[x. 22]</span></p>
