And it is applied to the rational straight line <span data-ref="0231.g1:/ F E /">$FE$</span>, producing <span data-ref="0231.g1:/ F M /">$FM$</span> as breadth; therefore <span data-ref="0231.g1:/ F M /">$FM$</span> is rational and incommensurable in length with <span data-ref="0231.g1:/ C D /">$CD$</span>. [X. 22]

And, since the squares on <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span> are incommensurable with twice the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>, and <span data-ref="0231.g1:< C L >">$CL$</span> is equal to the squares on <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>, and <span data-ref="0231.g1:< F L >">$FL$</span> equal to twice the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>, therefore <span data-ref="0231.g1:< C L >">$CL$</span> is incommensurable with <span data-ref="0231.g1:< F L >">$FL$</span>.

But, as <span data-ref="0231.g1:< C L >">$CL$</span> is to <span data-ref="0231.g1:< F L >">$FL$</span>, so is <span data-ref="0231.g1:/ C M /">$CM$</span> to <span data-ref="0231.g1:/ M F /">$MF$</span>; [VI. 1] therefore <span data-ref="0231.g1:/ C M /">$CM$</span> is incommensurable in length with <span data-ref="0231.g1:/ M F /">$MF$</span>. [X. 11]

And both are rational.

Therefore <span data-ref="0231.g1:/ C M /">$CM$</span>, <span data-ref="0231.g1:/ M F /">$MF$</span> are rational straight lines commensurable in square only; therefore <span data-ref="0231.g1:/ C F /">$CF$</span> is an apotome. [X. 73]

I say next that it is also a sixth apotome.

For, since <span data-ref="0231.g1:< F L >">$FL$</span> is equal to twice the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>, let <span data-ref="0231.g1:/ F M /">$FM$</span> be bisected at <span data-ref="0231.g1:N">$N$</span>, and let <span data-ref="0231.g1:/ N O /">$NO$</span> be drawn through <span data-ref="0231.g1:N">$N$</span> parallel to <span data-ref="0231.g1:/ C D /">$CD$</span>; therefore each of the rectangles <span data-ref="0231.g1:< F O >">$FO$</span>, <span data-ref="0231.g1:< N L >">$NL$</span> is equal to the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>.

And, since <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span> are incommensurable in square, therefore the square on <span data-ref="0231.g1:/ A G /">$AG$</span> is incommensurable with the square on <span data-ref="0231.g1:/ G B /">$GB$</span>.

But <span data-ref="0231.g1:< C H >">$CH$</span> is equal to the square on <span data-ref="0231.g1:/ A G /">$AG$</span>, and <span data-ref="0231.g1:< K L >">$KL$</span> is equal to the square on <span data-ref="0231.g1:/ G B /">$GB$</span>; therefore <span data-ref="0231.g1:< C H >">$CH$</span> is incommensurable with <span data-ref="0231.g1:< K L >">$KL$</span>.

But, as <span data-ref="0231.g1:< C H >">$CH$</span> is to <span data-ref="0231.g1:< K L >">$KL$</span>, so is <span data-ref="0231.g1:/ C K /">$CK$</span> to <span data-ref="0231.g1:/ K M /">$KM$</span>; [VI. 1] therefore <span data-ref="0231.g1:/ C K /">$CK$</span> is incommensurable with <span data-ref="0231.g1:/ K M /">$KM$</span>. [X. 11]

And, since the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span> is a mean proportional between the squares on <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>, and <span data-ref="0231.g1:< C H >">$CH$</span> is equal to the square on <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:< K L >">$KL$</span> equal to the square on <span data-ref="0231.g1:/ G B /">$GB$</span>, and <span data-ref="0231.g1:< N L >">$NL$</span> equal to the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>, therefore <span data-ref="0231.g1:< N L >">$NL$</span> is also a mean proportional between <span data-ref="0231.g1:< C H >">$CH$</span>, <span data-ref="0231.g1:< K L >">$KL$</span>; therefore, as <span data-ref="0231.g1:< C H >">$CH$</span> is to <span data-ref="0231.g1:< N L >">$NL$</span>, so is <span data-ref="0231.g1:< N L >">$NL$</span> to <span data-ref="0231.g1:< K L >">$KL$</span>.
