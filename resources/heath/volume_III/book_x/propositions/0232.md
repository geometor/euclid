<p class="sub-clause">And it is applied to the rational straight line <span data-ref="0231.g1:/ F E /">$FE$</span>, pro-<br />
ducing <span data-ref="0231.g1:/ F M /">$FM$</span> as breadth;</p>
<p class="assertion">therefore <span data-ref="0231.g1:/ F M /">$FM$</span> is rational and incommensurable in length<br />
with <span data-ref="0231.g1:/ C D /">$CD$</span>. <span class="justification">[X. 22]</span></p>

<p class="sub-clause">And, since the squares on <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span> are incommensurable<br />
with twice the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>,<br />
and <span data-ref="0231.g1:< C L >">$CL$</span> is equal to the squares on <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>,<br />
and <span data-ref="0231.g1:< F L >">$FL$</span> equal to twice the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>,</p>
<p class="assertion">therefore <span data-ref="0231.g1:< C L >">$CL$</span> is incommensurable with <span data-ref="0231.g1:< F L >">$FL$</span>.</p>

<p class="sub-clause">But, as <span data-ref="0231.g1:< C L >">$CL$</span> is to <span data-ref="0231.g1:< F L >">$FL$</span>, so is <span data-ref="0231.g1:/ C M /">$CM$</span> to <span data-ref="0231.g1:/ M F /">$MF$</span>; <span class="justification">[VI. 1]</span></p>
<p class="assertion">therefore <span data-ref="0231.g1:/ C M /">$CM$</span> is incommensurable in length with <span data-ref="0231.g1:/ M F /">$MF$</span>. <span class="justification">[X. 11]</span></p>

<p class="sub-clause">And both are rational.</p>
<p class="assertion">Therefore <span data-ref="0231.g1:/ C M /">$CM$</span>, <span data-ref="0231.g1:/ M F /">$MF$</span> are rational straight lines commen-<br />
surable in square only;<br />
therefore <span data-ref="0231.g1:/ C F /">$CF$</span> is an apotome. <span class="justification">[X. 73]</span></p>

I say next that it is also a sixth apotome.

For, since <span data-ref="0231.g1:< F L >">$FL$</span> is equal to twice the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>,<br />
let <span data-ref="0231.g1:/ F M /">$FM$</span> be bisected at <span data-ref="0231.g1:N">$N$</span>,<br />
and let <span data-ref="0231.g1:/ N O /">$NO$</span> be drawn through <span data-ref="0231.g1:N">$N$</span> parallel to <span data-ref="0231.g1:/ C D /">$CD$</span>;<br />
therefore each of the rectangles <span data-ref="0231.g1:< F O >">$FO$</span>, <span data-ref="0231.g1:< N L >">$NL$</span> is equal to the rect-<br />
angle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>.

<p class="sub-clause">And, since <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span> are incommensurable in square,</p>
<p class="assertion">therefore the square on <span data-ref="0231.g1:/ A G /">$AG$</span> is incommensurable with the<br />
square on <span data-ref="0231.g1:/ G B /">$GB$</span>.</p>

<p class="sub-clause">But <span data-ref="0231.g1:< C H >">$CH$</span> is equal to the square on <span data-ref="0231.g1:/ A G /">$AG$</span>,<br />
and <span data-ref="0231.g1:< K L >">$KL$</span> is equal to the square on <span data-ref="0231.g1:/ G B /">$GB$</span>;</p>
<p class="assertion">therefore <span data-ref="0231.g1:< C H >">$CH$</span> is incommensurable with <span data-ref="0231.g1:< K L >">$KL$</span>.</p>

<p class="sub-clause">But, as <span data-ref="0231.g1:< C H >">$CH$</span> is to <span data-ref="0231.g1:< K L >">$KL$</span>, so is <span data-ref="0231.g1:/ C K /">$CK$</span> to <span data-ref="0231.g1:/ K M /">$KM$</span>; <span class="justification">[VI. 1]</span></p>
<p class="assertion">therefore <span data-ref="0231.g1:/ C K /">$CK$</span> is incommensurable with <span data-ref="0231.g1:/ K M /">$KM$</span>. <span class="justification">[X. 11]</span></p>

<p class="sub-clause">And, since the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span> is a mean proportional<br />
between the squares on <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>,<br />
and <span data-ref="0231.g1:< C H >">$CH$</span> is equal to the square on <span data-ref="0231.g1:/ A G /">$AG$</span>,<br />
<span data-ref="0231.g1:< K L >">$KL$</span> equal to the square on <span data-ref="0231.g1:/ G B /">$GB$</span>,<br />
and <span data-ref="0231.g1:< N L >">$NL$</span> equal to the rectangle <span data-ref="0231.g1:/ A G /">$AG$</span>, <span data-ref="0231.g1:/ G B /">$GB$</span>,</p>
<p class="assertion">therefore <span data-ref="0231.g1:< N L >">$NL$</span> is also a mean proportional between <span data-ref="0231.g1:< C H >">$CH$</span>, <span data-ref="0231.g1:< K L >">$KL$</span>;<br />
therefore, as <span data-ref="0231.g1:< C H >">$CH$</span> is to <span data-ref="0231.g1:< N L >">$NL$</span>, so is <span data-ref="0231.g1:< N L >">$NL$</span> to <span data-ref="0231.g1:< K L >">$KL$</span>.</p>
