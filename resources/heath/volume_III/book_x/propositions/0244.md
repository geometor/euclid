### PROPOSITION 111.

<p class="enunciation">The apotome is not the same with the binomial straight line.</p>

Let <span data-ref="0244.g1:/ A B /">$AB$</span> be an apotome;<br />
I say that <span data-ref="0244.g1:/ A B /">$AB$</span> is not the same with the<br />
binomial straight line.

![Proposition 111](0244.g1.svg)

For, if possible, let it be so;<br />
let a rational straight line <span data-ref="0244.g1:/ D C /">$DC$</span> be set out,<br />
and to <span data-ref="0244.g1:/ C D /">$CD$</span> let there be applied the<br />
rectangle <span data-ref="0244.g1:< C E >">$CE$</span> equal to the square on<br />
<span data-ref="0244.g1:/ A B /">$AB$</span> and producing <span data-ref="0244.g1:/ D E /">$DE$</span> as breadth.
