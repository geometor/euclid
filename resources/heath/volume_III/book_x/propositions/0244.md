### PROPOSITION 111.

*The apotome is not the same with the binomial straight line.*

Let <span data-ref="0244.g1:/ A B /">$AB$</span> be an apotome;
I say that <span data-ref="0244.g1:/ A B /">$AB$</span> is not the same with the binomial straight line.

![Proposition 111](0244.g1.svg)

For, if possible, let it be so;
let a rational straight line <span data-ref="0244.g1:/ D C /">$DC$</span> be set out,
and to <span data-ref="0244.g1:/ C D /">$CD$</span> let there be applied the rectangle <span data-ref="0244.g1:< C E >">$CE$</span> equal to the square on <span data-ref="0244.g1:/ A B /">$AB$</span> and producing <span data-ref="0244.g1:/ D E /">$DE$</span> as breadth.

therefore <span data-ref="0244.g1:/ D F /">$DF$</span>, <span data-ref="0244.g1:/ F E /">$FE$</span> are rational straight lines commensurable in square only,
