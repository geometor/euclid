Since now the rectangle <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:G">$G$</span> is equal to the rectangle <span data-ref="0252.g1:/ B D /">$BD$</span>, <span data-ref="0252.g1:/ K H /">$KH$</span>,
therefore, proportionally, as <span data-ref="0252.g1:/ C B /">$CB$</span> is to <span data-ref="0252.g1:/ B D /">$BD$</span>, so is <span data-ref="0252.g1:/ K H /">$KH$</span> to <span data-ref="0252.g1:G">$G$</span>. [VI. 16]

But <span data-ref="0252.g1:/ B C /">$BC$</span> is greater than <span data-ref="0252.g1:/ B D /">$BD$</span>;
therefore <span data-ref="0252.g1:/ K H /">$KH$</span> is also greater than <span data-ref="0252.g1:G">$G$</span>. [V. 16, V. 14]

Let <span data-ref="0252.g1:/ K E /">$KE$</span> be made equal to <span data-ref="0252.g1:G">$G$</span>;
therefore <span data-ref="0252.g1:/ K E /">$KE$</span> is commensurable in length with <span data-ref="0252.g1:/ B C /">$BC$</span>.

And since, as <span data-ref="0252.g1:/ C B /">$CB$</span> is to <span data-ref="0252.g1:/ B D /">$BD$</span>, so is <span data-ref="0252.g1:/ H K /">$HK$</span> to <span data-ref="0252.g1:/ K E /">$KE$</span>,
therefore, *convertendo*, as <span data-ref="0252.g1:/ B C /">$BC$</span> is to <span data-ref="0252.g1:/ C D /">$CD$</span>, so is <span data-ref="0252.g1:/ K H /">$KH$</span> to <span data-ref="0252.g1:/ H E /">$HE$</span>. [V. 19, Por.]

Let it be contrived that, as <span data-ref="0252.g1:/ K H /">$KH$</span> is to <span data-ref="0252.g1:/ H E /">$HE$</span>, so is <span data-ref="0252.g1:/ H F /">$HF$</span> to <span data-ref="0252.g1:/ F E /">$FE$</span>;
therefore also the remainder <span data-ref="0252.g1:/ K F /">$KF$</span> is to <span data-ref="0252.g1:/ F H /">$FH$</span> as <span data-ref="0252.g1:/ K H /">$KH$</span> is to <span data-ref="0252.g1:/ H E /">$HE$</span>, that is, as <span data-ref="0252.g1:/ B C /">$BC$</span> is to <span data-ref="0252.g1:/ C D /">$CD$</span>. [V. 19]

But <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:/ C D /">$CD$</span> are commensurable in square only;
therefore <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span> are also commensurable in square only. [X. 11]

And since, as <span data-ref="0252.g1:/ K H /">$KH$</span> is to <span data-ref="0252.g1:/ H E /">$HE$</span>, so is <span data-ref="0252.g1:/ K F /">$KF$</span> to <span data-ref="0252.g1:/ F H /">$FH$</span>,
while, as <span data-ref="0252.g1:/ K H /">$KH$</span> is to <span data-ref="0252.g1:/ H E /">$HE$</span>, so is <span data-ref="0252.g1:/ H F /">$HF$</span> to <span data-ref="0252.g1:/ F E /">$FE$</span>,
therefore also, as <span data-ref="0252.g1:/ K F /">$KF$</span> is to <span data-ref="0252.g1:/ F H /">$FH$</span>, so is <span data-ref="0252.g1:/ H F /">$HF$</span> to <span data-ref="0252.g1:/ F E /">$FE$</span>, [V. 11]
so that also, as the first is to the third, so is the square on the first to the square on the second; [V. Def. 9]
therefore also, as <span data-ref="0252.g1:/ K F /">$KF$</span> is to <span data-ref="0252.g1:/ F E /">$FE$</span>, so is the square on <span data-ref="0252.g1:/ K F /">$KF$</span> to the square on <span data-ref="0252.g1:/ F H /">$FH$</span>.

But the square on <span data-ref="0252.g1:/ K F /">$KF$</span> is commensurable with the square on <span data-ref="0252.g1:/ F H /">$FH$</span>,
for <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span> are commensurable in square;
therefore <span data-ref="0252.g1:/ K F /">$KF$</span> is also commensurable in length with <span data-ref="0252.g1:/ F E /">$FE$</span>, [X. 11]
so that <span data-ref="0252.g1:/ K F /">$KF$</span> is also commensurable in length with <span data-ref="0252.g1:/ K E /">$KE$</span>. [X. 15]

But <span data-ref="0252.g1:/ K E /">$KE$</span> is rational and commensurable in length with <span data-ref="0252.g1:/ B C /">$BC$</span>;
therefore <span data-ref="0252.g1:/ K F /">$KF$</span> is also rational and commensurable in length with <span data-ref="0252.g1:/ B C /">$BC$</span>. [X. 12]

And, since, as <span data-ref="0252.g1:/ B C /">$BC$</span> is to <span data-ref="0252.g1:/ C D /">$CD$</span>, so is <span data-ref="0252.g1:/ K F /">$KF$</span> to <span data-ref="0252.g1:/ F H /">$FH$</span>,
alternately, as <span data-ref="0252.g1:/ B C /">$BC$</span> is to <span data-ref="0252.g1:/ K F /">$KF$</span>, so is <span data-ref="0252.g1:/ D C /">$DC$</span> to <span data-ref="0252.g1:/ F H /">$FH$</span>. [V. 16]

But <span data-ref="0252.g1:/ B C /">$BC$</span> is commensurable with <span data-ref="0252.g1:/ K F /">$KF$</span>;
therefore <span data-ref="0252.g1:/ F H /">$FH$</span> is also commensurable in length with <span data-ref="0252.g1:/ C D /">$CD$</span>. [X. 11]
