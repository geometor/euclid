<p class="sub-clause">Since now the rectangle <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:G">$G$</span> is equal to the rectangle<br />
<span data-ref="0252.g1:/ B D /">$BD$</span>, <span data-ref="0252.g1:/ K H /">$KH$</span>,</p>
<p class="assertion">therefore, proportionally, as <span data-ref="0252.g1:/ C B /">$CB$</span> is to <span data-ref="0252.g1:/ B D /">$BD$</span>, so is <span data-ref="0252.g1:/ K H /">$KH$</span> to <span data-ref="0252.g1:G">$G$</span>.<br />
<span class="justification">[VI. 16]</span></p>

<p class="sub-clause">But <span data-ref="0252.g1:/ B C /">$BC$</span> is greater than <span data-ref="0252.g1:/ B D /">$BD$</span>;</p>
<p class="assertion">therefore <span data-ref="0252.g1:/ K H /">$KH$</span> is also greater than <span data-ref="0252.g1:G">$G$</span>. <span class="justification">[V. 16, V. 14]</span></p>

Let <span data-ref="0252.g1:/ K E /">$KE$</span> be made equal to <span data-ref="0252.g1:G">$G$</span>;
<p class="assertion">therefore <span data-ref="0252.g1:/ K E /">$KE$</span> is commensurable in length with <span data-ref="0252.g1:/ B C /">$BC$</span>.</p>

<p class="sub-clause">And since, as <span data-ref="0252.g1:/ C B /">$CB$</span> is to <span data-ref="0252.g1:/ B D /">$BD$</span>, so is <span data-ref="0252.g1:/ H K /">$HK$</span> to <span data-ref="0252.g1:/ K E /">$KE$</span>,</p>
<p class="assertion">therefore, <em>convertendo</em>, as <span data-ref="0252.g1:/ B C /">$BC$</span> is to <span data-ref="0252.g1:/ C D /">$CD$</span>, so is <span data-ref="0252.g1:/ K H /">$KH$</span> to <span data-ref="0252.g1:/ H E /">$HE$</span>.<br />
<span class="justification">[V. 19, Por.]</span></p>

Let it be contrived that, as <span data-ref="0252.g1:/ K H /">$KH$</span> is to <span data-ref="0252.g1:/ H E /">$HE$</span>, so is <span data-ref="0252.g1:/ H F /">$HF$</span><br />
to <span data-ref="0252.g1:/ F E /">$FE$</span>;
<p class="assertion">therefore also the remainder <span data-ref="0252.g1:/ K F /">$KF$</span> is to <span data-ref="0252.g1:/ F H /">$FH$</span> as <span data-ref="0252.g1:/ K H /">$KH$</span> is to <span data-ref="0252.g1:/ H E /">$HE$</span>,<br />
that is, as <span data-ref="0252.g1:/ B C /">$BC$</span> is to <span data-ref="0252.g1:/ C D /">$CD$</span>. <span class="justification">[V. 19]</span></p>

<p class="sub-clause">But <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:/ C D /">$CD$</span> are commensurable in square only;</p>
<p class="assertion">therefore <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span> are also commensurable in square only.<br />
<span class="justification">[X. 11]</span></p>

<p class="sub-clause">And since, as <span data-ref="0252.g1:/ K H /">$KH$</span> is to <span data-ref="0252.g1:/ H E /">$HE$</span>, so is <span data-ref="0252.g1:/ K F /">$KF$</span> to <span data-ref="0252.g1:/ F H /">$FH$</span>,<br />
while, as <span data-ref="0252.g1:/ K H /">$KH$</span> is to <span data-ref="0252.g1:/ H E /">$HE$</span>, so is <span data-ref="0252.g1:/ H F /">$HF$</span> to <span data-ref="0252.g1:/ F E /">$FE$</span>,</p>
<p class="assertion">therefore also, as <span data-ref="0252.g1:/ K F /">$KF$</span> is to <span data-ref="0252.g1:/ F H /">$FH$</span>, so is <span data-ref="0252.g1:/ H F /">$HF$</span> to <span data-ref="0252.g1:/ F E /">$FE$</span>, <span class="justification">[V. 11]</span><br />
so that also, as the first is to the third, so is the square on the<br />
first to the square on the second; <span class="justification">[V. Def. 9]</span><br />
therefore also, as <span data-ref="0252.g1:/ K F /">$KF$</span> is to <span data-ref="0252.g1:/ F E /">$FE$</span>, so is the square on <span data-ref="0252.g1:/ K F /">$KF$</span> to the<br />
square on <span data-ref="0252.g1:/ F H /">$FH$</span>.</p>

<p class="sub-clause">But the square on <span data-ref="0252.g1:/ K F /">$KF$</span> is commensurable with the square<br />
on <span data-ref="0252.g1:/ F H /">$FH$</span>,<br />
for <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span> are commensurable in square;</p>
<p class="assertion">therefore <span data-ref="0252.g1:/ K F /">$KF$</span> is also commensurable in length with <span data-ref="0252.g1:/ F E /">$FE$</span>, <span class="justification">[X. 11]</span><br />
so that <span data-ref="0252.g1:/ K F /">$KF$</span> is also commensurable in length with <span data-ref="0252.g1:/ K E /">$KE$</span>. <span class="justification">[X. 15]</span></p>

<p class="sub-clause">But <span data-ref="0252.g1:/ K E /">$KE$</span> is rational and commensurable in length with <span data-ref="0252.g1:/ B C /">$BC$</span>;</p>
<p class="assertion">therefore <span data-ref="0252.g1:/ K F /">$KF$</span> is also rational and commensurable in length<br />
with <span data-ref="0252.g1:/ B C /">$BC$</span>. <span class="justification">[X. 12]</span></p>

<p class="sub-clause">And, since, as <span data-ref="0252.g1:/ B C /">$BC$</span> is to <span data-ref="0252.g1:/ C D /">$CD$</span>, so is <span data-ref="0252.g1:/ K F /">$KF$</span> to <span data-ref="0252.g1:/ F H /">$FH$</span>,</p>
<p class="assertion">alternately, as <span data-ref="0252.g1:/ B C /">$BC$</span> is to <span data-ref="0252.g1:/ K F /">$KF$</span>, so is <span data-ref="0252.g1:/ D C /">$DC$</span> to <span data-ref="0252.g1:/ F H /">$FH$</span>. <span class="justification">[V. 16]</span></p>

<p class="sub-clause">But <span data-ref="0252.g1:/ B C /">$BC$</span> is commensurable with <span data-ref="0252.g1:/ K F /">$KF$</span>;</p>
<p class="assertion">therefore <span data-ref="0252.g1:/ F H /">$FH$</span> is also commensurable in length with <span data-ref="0252.g1:/ C D /">$CD$</span>. <span class="justification">[X. 11]</span></p>
