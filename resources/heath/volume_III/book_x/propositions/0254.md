But <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:/ C D /">$CD$</span> are rational straight lines commensurable in square only;
therefore <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span> are also rational straight lines [X. Def. 3] commensurable in square only;
therefore <span data-ref="0252.g1:/ K H /">$KH$</span> is binomial. [X. 36]

If now the square on <span data-ref="0252.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0252.g1:/ C D /">$CD$</span> by the square on a straight line commensurable with <span data-ref="0252.g1:/ B C /">$BC$</span>,
the square on <span data-ref="0252.g1:/ K F /">$KF$</span> will also be greater than the square on <span data-ref="0252.g1:/ F H /">$FH$</span> by the square on a straight line commensurable with <span data-ref="0252.g1:/ K F /">$KF$</span>. [X. 14]

And, if <span data-ref="0252.g1:/ B C /">$BC$</span> is commensurable in length with the rational straight line set out,
so also is <span data-ref="0252.g1:/ K F /">$KF$</span>;
if <span data-ref="0252.g1:/ C D /">$CD$</span> is commensurable in length with the rational straight line set out,
so also is <span data-ref="0252.g1:/ F H /">$FH$</span>,
but, if neither of the straight lines <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:/ C D /">$CD$</span>,
then neither of the straight lines <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span>.

But, if the square on <span data-ref="0252.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0252.g1:/ C D /">$CD$</span> by the square on a straight line incommensurable with <span data-ref="0252.g1:/ B C /">$BC$</span>,
the square on <span data-ref="0252.g1:/ K F /">$KF$</span> is also greater than the square on <span data-ref="0252.g1:/ F H /">$FH$</span> by the square on a straight line incommensurable with <span data-ref="0252.g1:/ K F /">$KF$</span>. [X. 14]

And, if <span data-ref="0252.g1:/ B C /">$BC$</span> is commensurable with the rational straight line set out,
so also is <span data-ref="0252.g1:/ K F /">$KF$</span>;
if <span data-ref="0252.g1:/ C D /">$CD$</span> is so commensurable,
so also is <span data-ref="0252.g1:/ F H /">$FH$</span>;
but, if neither of the straight lines <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:/ C D /">$CD$</span>,
then neither of the straight lines <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span>.

Therefore <span data-ref="0252.g1:/ K H /">$KH$</span> is a binomial straight line, the terms of which <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span> are commensurable with the terms <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:/ C D /">$CD$</span> of the apotome and in the same ratio,
and further <span data-ref="0252.g1:/ K H /">$KH$</span> has the same order as <span data-ref="0252.g1:/ B D /">$BD$</span>.

Q. E. D.

---

This proposition, which is companion to the preceding, gives us the equivalent of the rationalisation of the denominator of
$$\frac{c^2}{\sqrt A - \sqrt B} \quad\text{or}\quad \frac{c^2}{a \sim \sqrt B}.$$
