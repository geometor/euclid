<p class="sub-clause">But <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:/ C D /">$CD$</span> are rational straight lines commensurable in<br />
square only;</p>
<p class="assertion">therefore <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span> are also rational straight lines <span class="justification">[X. Def. 3]</span><br />
commensurable in square only;<br />
therefore <span data-ref="0252.g1:/ K H /">$KH$</span> is binomial. <span class="justification">[X. 36]</span></p>

<p class="sub-clause">If now the square on <span data-ref="0252.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0252.g1:/ C D /">$CD$</span><br />
by the square on a straight line commensurable with <span data-ref="0252.g1:/ B C /">$BC$</span>,</p>
<p class="assertion">the square on <span data-ref="0252.g1:/ K F /">$KF$</span> will also be greater than the square on <span data-ref="0252.g1:/ F H /">$FH$</span><br />
by the square on a straight line commensurable with <span data-ref="0252.g1:/ K F /">$KF$</span>. <span class="justification">[X. 14]</span></p>

<p class="assertion">And, if <span data-ref="0252.g1:/ B C /">$BC$</span> is commensurable in length with the rational<br />
straight line set out,<br />
so also is <span data-ref="0252.g1:/ K F /">$KF$</span>;<br />
if <span data-ref="0252.g1:/ C D /">$CD$</span> is commensurable in length with the rational straight<br />
line set out,<br />
so also is <span data-ref="0252.g1:/ F H /">$FH$</span>,<br />
but, if neither of the straight lines <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:/ C D /">$CD$</span>,<br />
then neither of the straight lines <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span>.</p>

<p class="sub-clause">But, if the square on <span data-ref="0252.g1:/ B C /">$BC$</span> is greater than the square on <span data-ref="0252.g1:/ C D /">$CD$</span><br />
by the square on a straight line incommensurable with <span data-ref="0252.g1:/ B C /">$BC$</span>,</p>
<p class="assertion">the square on <span data-ref="0252.g1:/ K F /">$KF$</span> is also greater than the square on <span data-ref="0252.g1:/ F H /">$FH$</span> by<br />
the square on a straight line incommensurable with <span data-ref="0252.g1:/ K F /">$KF$</span>. <span class="justification">[X. 14]</span></p>

<p class="assertion">And, if <span data-ref="0252.g1:/ B C /">$BC$</span> is commensurable with the rational straight<br />
line set out,<br />
so also is <span data-ref="0252.g1:/ K F /">$KF$</span>;<br />
if <span data-ref="0252.g1:/ C D /">$CD$</span> is so commensurable,<br />
so also is <span data-ref="0252.g1:/ F H /">$FH$</span>;<br />
but, if neither of the straight lines <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:/ C D /">$CD$</span>,<br />
then neither of the straight lines <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span>.</p>

<p class="assertion">Therefore <span data-ref="0252.g1:/ K H /">$KH$</span> is a binomial straight line, the terms of<br />
which <span data-ref="0252.g1:/ K F /">$KF$</span>, <span data-ref="0252.g1:/ F H /">$FH$</span> are commensurable with the terms <span data-ref="0252.g1:/ B C /">$BC$</span>, <span data-ref="0252.g1:/ C D /">$CD$</span> of<br />
the apotome and in the same ratio,<br />
and further <span data-ref="0252.g1:/ K H /">$KH$</span> has the same order as <span data-ref="0252.g1:/ B D /">$BD$</span>.</p>

<p class="qed">Q. E. D.</p>
