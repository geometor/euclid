$$(\rho - \sqrt{k}\cdot\rho)(\lambda\rho + \lambda\sqrt{k}\cdot\rho) \sim (\lambda\rho + \lambda\sqrt{k}\cdot\rho)(\lambda'\rho - \lambda'\sqrt{k}\cdot\rho)$$

### PROPOSITION 115.

*From a medial straight line there arise irrational straight lines infinite in number, and none of them is the same as any of the preceding.*

Let <span data-ref="0258.g1:A">$A$</span> be a medial straight line;
I say that from <span data-ref="0258.g1:A">$A$</span> there arise irrational straight lines infinite in number, and none of them is the same as any of the preceding.

![Proposition 115 diagram](0258.g1.svg)

Let a rational straight line <span data-ref="0258.g1:B">$B$</span> be set out,
and let the square on <span data-ref="0258.g1:C">$C$</span> be equal to the rectangle <span data-ref="0258.g1:B">$B$</span>, <span data-ref="0258.g1:A">$A$</span>;
therefore <span data-ref="0258.g1:C">$C$</span> is irrational; [x. Def. 4]
for that which is contained by an irrational and a rational straight line is irrational. [deduction from x. 20]
And it is not the same with any of the preceding;
for the square on none of the preceding, if applied to a rational straight line produces as breadth a medial straight line.
Again, let the square on <span data-ref="0258.g1:D">$D$</span> be equal to the rectangle <span data-ref="0258.g1:B">$B$</span>, <span data-ref="0258.g1:C">$C$</span>;
therefore the square on <span data-ref="0258.g1:D">$D$</span> is irrational. [deduction from x. 20]
Therefore <span data-ref="0258.g1:D">$D$</span> is irrational; [x. Def. 4]
and it is not the same with any of the preceding, for the square on none of the preceding, if applied to a rational straight line, produces <span data-ref="0258.g1:C">$C$</span> as breadth.
Similarly, if this arrangement proceeds *ad infinitum*, it is manifest that from the medial straight line there arise irrational straight lines infinite in number, and none is the same with any of the preceding.

<p align="right">Q. E. D.</p>
