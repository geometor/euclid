### PROPOSITION 115.

<p class="enunciation">From a medial straight line there arise irrational straight<br />
lines infinite in number, and none of them is the same as any<br />
of the preceding.</p>

Let <span data-ref="0258.g1:A">$A$</span> be a medial straight line;<br />
I say that from <span data-ref="0258.g1:A">$A$</span> there arise<br />
irrational straight lines infinite in<br />
number, and none of them is the<br />
same as any of the preceding.

![Proposition 115 diagram](0258.g1.svg)

Let a rational straight line <span data-ref="0258.g1:B">$B$</span><br />
be set out,<br />
and let the square on <span data-ref="0258.g1:C">$C$</span> be equal<br />
to the rectangle <span data-ref="0258.g1:B">$B$</span>, <span data-ref="0258.g1:A">$A$</span>;

<p class="assertion">therefore <span data-ref="0258.g1:C">$C$</span> is irrational; <span class="justification">[X. Def. 4]</span></p>
<p class="sub-clause">for that which is contained by an irrational and a rational<br />
straight line is irrational. <span class="justification">[deduction from X. 20]</span></p>

<p class="assertion">And it is not the same with any of the preceding;<br />
for the square on none of the preceding, if applied to a rational<br />
straight line produces as breadth a medial straight line.</p>

Again, let the square on <span data-ref="0258.g1:D">$D$</span> be equal to the rectangle <span data-ref="0258.g1:B">$B$</span>, <span data-ref="0258.g1:C">$C$</span>;

<p class="assertion">therefore the square on <span data-ref="0258.g1:D">$D$</span> is irrational. <span class="justification">[deduction from X. 20]</span></p>

<p class="assertion">Therefore <span data-ref="0258.g1:D">$D$</span> is irrational; <span class="justification">[X. Def. 4]</span><br />
and it is not the same with any of the preceding, for the<br />
square on none of the preceding, if applied to a rational<br />
straight line, produces <span data-ref="0258.g1:C">$C$</span> as breadth.</p>

<p class="qed">Similarly, if this arrangement proceeds *ad infinitum*, it<br />
is manifest that from the medial straight line there arise<br />
irrational straight lines infinite in number, and none is the<br />
same with any of the preceding.<span class="justification">Q. E. D.</span></p>
