*It follows that, if a right angle be turned about one of the straight lines containing it the other will describe a plane.*

At any point in a straight line it is possible to draw *only one plane* which is at right angles to the straight line.

One such plane can be found by taking any two planes through the given straight line, drawing perpendiculars to the straight line in the respective planes, e.g. <span data-ref="0286.g1:/ B O /">$BO$</span>, <span data-ref="0286.g1:/ C O /">$CO$</span> in the planes <span data-ref="0286.g1:< A O B >">$AOB$</span>, <span data-ref="0286.g1:< A O C >">$AOC$</span>, each perpendicular to <span data-ref="0286.g1:/ A O /">$AO$</span>, and then drawing a plane (<span data-ref="0286.g1:< B O C >">$BOC$</span>) through the perpendiculars.

![Book XI - Proposition 5, uniqueness of perpendicular plane at a point](0286.g1.svg)

If there were another plane through <span data-ref="0286.g1:O">$O$</span> perpendicular to <span data-ref="0286.g1:/ A O /">$AO$</span>, it must meet the plane through <span data-ref="0286.g1:/ A O /">$AO$</span> and some perpendicular to it as <span data-ref="0286.g1:/ O C /">$OC$</span> in a straight line <span data-ref="0286.g1:/ O C' /">$OC'$</span> different from <span data-ref="0286.g1:/ O C /">$OC$</span>.

Then, by XI. 4, <span data-ref="0286.g1:< A O C' )">$AOC'$</span> is a right angle, and in the same plane with the right angle <span data-ref="0286.g1:< A O C )">$AOC$</span>: which is impossible.

*Next, one plane and only one can be drawn through a point outside a straight line at right angles to that line.*
