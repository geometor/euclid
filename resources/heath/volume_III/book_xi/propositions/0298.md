    In the plane <span data-ref="0297.g1:< M N >">$MN$</span>, through <span data-ref="0297.g1:H">$H$</span> in the first figure and <span data-ref="0297.g1:A">$A$</span> in the second, draw <span data-ref="0297.g1:/ K L /">$KL$</span> parallel to <span data-ref="0297.g1:/ B C /">$BC$</span>.
    Now, since <span data-ref="0297.g1:/ B C /">$BC$</span> is perpendicular to both <span data-ref="0297.g1:/ D A /">$DA$</span> and <span data-ref="0297.g1:/ D E /">$DE$</span>, <span data-ref="0297.g1:/ B C /">$BC$</span> is perpendicular to the plane <span data-ref="0297.g1:< A G >">$AG$</span>. [XI. 4]
    Therefore <span data-ref="0297.g1:/ K L /">$KL$</span>, being parallel to <span data-ref="0297.g1:/ B C /">$BC$</span>, is also perpendicular to the plane <span data-ref="0297.g1:< A G >">$AG$</span> [XI. 8], and therefore to <span data-ref="0297.g1:/ A H /">$AH$</span> which meets it and is in that plane.
    Therefore <span data-ref="0297.g1:/ A H /">$AH$</span> is perpendicular to both <span data-ref="0297.g1:/ F D /">$FD$</span> (<span data-ref="0297.g1:/ A D /">$AD$</span>) and <span data-ref="0297.g1:/ K L /">$KL$</span> at their point of intersection.
    Therefore <span data-ref="0297.g1:/ A H /">$AH$</span> is perpendicular to the plane <span data-ref="0297.g1:< M N >">$MN$</span>.

    Thus we have solved the problem in XI. 12 as well as that in XI. 11; and this direct method of drawing a perpendicular to a plane from a point *in* it is obviously preferable to Euclid's method by which the construction of a perpendicular to a plane from a point *without* it is assumed, and a line is merely drawn from a point in the plane parallel to the perpendicular obtained in XI. 11.

### PROPOSITION 12.

*To set up a straight line at right angles to a given plane from a given point in it.*

Let the plane of reference be the given plane, and <span data-ref="0298.g1:A">$A$</span> the point in it;
thus it is required to set up from the point <span data-ref="0298.g1:A">$A$</span> a straight line at right angles to the plane of reference.

![Proposition 12](0298.g1.svg)

    Let any elevated point <span data-ref="0298.g1:B">$B$</span> be conceived,
from <span data-ref="0298.g1:B">$B$</span> let <span data-ref="0298.g1:/ B C /">$BC$</span> be drawn perpendicular to the plane of reference, [XI. 11]
and through the point <span data-ref="0298.g1:A">$A$</span> let <span data-ref="0298.g1:/ A D /">$AD$</span> be drawn parallel to <span data-ref="0298.g1:/ B C /">$BC$</span>. [I. 31]
    Then, since <span data-ref="0298.g1:/ A D /">$AD$</span>, <span data-ref="0298.g1:/ C B /">$CB$</span> are two parallel straight lines,
while one of them, <span data-ref="0298.g1:/ B C /">$BC$</span>, is at right angles to the plane of reference,
therefore the remaining one, <span data-ref="0298.g1:/ A D /">$AD$</span>, is also at right angles to the plane of reference. [XI. 8]
    Therefore <span data-ref="0298.g1:/ A D /">$AD$</span> has been set up at right angles to the given plane from the point <span data-ref="0298.g1:A">$A$</span> in it.
