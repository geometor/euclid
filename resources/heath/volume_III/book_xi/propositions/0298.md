In the plane <span data-ref="0297.g1:< M N >">$MN$</span>, through <span data-ref="0297.g1:H">$H$</span> in the first figure and <span data-ref="0297.g1:A">$A$</span> in the second, draw<br />
<span data-ref="0297.g1:/ K L /">$KL$</span> parallel to <span data-ref="0297.g1:/ B C /">$BC$</span>.<br />
Now, since <span data-ref="0297.g1:/ B C /">$BC$</span> is perpendicular to both <span data-ref="0297.g1:/ D A /">$DA$</span> and <span data-ref="0297.g1:/ D E /">$DE$</span>, <span data-ref="0297.g1:/ B C /">$BC$</span> is perpendicular<br />
to the plane <span data-ref="0297.g1:< A G >">$AG$</span>. <span class="justification">[XI. 4]</span><br />
Therefore <span data-ref="0297.g1:/ K L /">$KL$</span>, being parallel to <span data-ref="0297.g1:/ B C /">$BC$</span>, is also perpendicular to the plane<br />
<span data-ref="0297.g1:< A G >">$AG$</span> <span class="justification">[XI. 8]</span>, and therefore to <span data-ref="0297.g1:/ A H /">$AH$</span> which meets it and is in that plane.<br />
Therefore <span data-ref="0297.g1:/ A H /">$AH$</span> is perpendicular to both <span data-ref="0297.g1:/ F D /">$FD$</span> (<span data-ref="0297.g1:/ A D /">$AD$</span>) and <span data-ref="0297.g1:/ K L /">$KL$</span> at their point<br />
of intersection.<br />
Therefore <span data-ref="0297.g1:/ A H /">$AH$</span> is perpendicular to the plane <span data-ref="0297.g1:< M N >">$MN$</span>.

Thus we have solved the problem in XI. 12 as well as that in XI. 11; and<br />
this direct method of drawing a perpendicular to a plane from a point *in* it is<br />
obviously preferable to Euclid's method by which the construction of a<br />
perpendicular to a plane from a point *without* it is assumed, and a line is<br />
merely drawn from a point in the plane parallel to the perpendicular obtained<br />
in XI. 11.

### PROPOSITION 12.

<p class="enunciation">To set up a straight line at right angles to a given plane<br />
from a given point in it.</p>

Let the plane of reference be the given plane,<br />
and <span data-ref="0298.g1:A">$A$</span> the point in it;<br />
thus it is required to set up from the point<br />
<span data-ref="0298.g1:A">$A$</span> a straight line at right angles to the<br />
plane of reference.

![Proposition 12](0298.g1.svg)

Let any elevated point <span data-ref="0298.g1:B">$B$</span> be conceived,<br />
from <span data-ref="0298.g1:B">$B$</span> let <span data-ref="0298.g1:/ B C /">$BC$</span> be drawn perpendicular to<br />
the plane of reference, <span class="justification">[XI. 11]</span><br />
and through the point <span data-ref="0298.g1:A">$A$</span> let <span data-ref="0298.g1:/ A D /">$AD$</span> be drawn<br />
parallel to <span data-ref="0298.g1:/ B C /">$BC$</span>. <span class="justification">[I. 31]</span>

Then, since <span data-ref="0298.g1:/ A D /">$AD$</span>, <span data-ref="0298.g1:/ C B /">$CB$</span> are two parallel straight lines,<br />
while one of them, <span data-ref="0298.g1:/ B C /">$BC$</span>, is at right angles to the plane of<br />
reference,
<p class="assertion">therefore the remaining one, <span data-ref="0298.g1:/ A D /">$AD$</span>, is also at right angles to<br />
the plane of reference. <span class="justification">[XI. 8]</span></p>

<p class="assertion">Therefore <span data-ref="0298.g1:/ A D /">$AD$</span> has been set up at right angles to the given<br />
plane from the point <span data-ref="0298.g1:A">$A$</span> in it.</p>
