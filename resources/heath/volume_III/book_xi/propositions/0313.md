Simson remarks that the angle <span data-ref="0311.g3:< B A C )">$BAC$</span> may happen to be equal to one of<br />
the other two and writes accordingly “If they [all three angles] are not [equal],<br />
let <span data-ref="0311.g3:< B A C )">$BAC$</span> be that angle which is not less than either of the other two, and is<br />
greater than one of them <span data-ref="0311.g3:< D A B )">$DAB$</span>.” He then proves, in the same way as Euclid<br />
does, that the angles <span data-ref="0311.g3:< D A B )">$DAB$</span>, <span data-ref="0311.g3:< D A C )">$DAC$</span> are greater than the angle <span data-ref="0311.g3:< B A C )">$BAC$</span>, adding<br />
finally : “But <span data-ref="0311.g3:< B A C )">$BAC$</span> is not less than either of the angles <span data-ref="0311.g3:< D A B )">$DAB$</span>, <span data-ref="0311.g3:< D A C )">$DAC$</span>; there-<br />
fore <span data-ref="0311.g3:< B A C )">$BAC$</span>, with either of them, is greater than the other.”

It would be better, as indicated by Legendre and Rausenberger, to begin<br />
by saying that, “if one of the three angles is either equal to or less than either<br />
of the other two, it is evident that the sum of those two is greater than the<br />
first. It is therefore only necessary to prove, *for the case in which one angle is<br />
greater than each of the others*, that the sum of the two latter is greater than<br />
the former.<br />
Accordingly let <span data-ref="0311.g3:< B A C )">$BAC$</span> be greater than each of the other angles.” We then<br />
proceed as in Euclid.

### PROPOSITION 21.

<p class="enunciation">Any solid angle is contained by plane angles less than four<br />
right angles.</p>

Let the angle at <span data-ref="0313.g1:A">$A$</span> be a solid angle contained by the plane<br />
angles <span data-ref="0313.g1:< B A C )">$BAC$</span>, <span data-ref="0313.g1:< C A D )">$CAD$</span>, <span data-ref="0313.g1:< D A B )">$DAB$</span>;<br />
I say that the angles <span data-ref="0313.g1:< B A C )">$BAC$</span>, <span data-ref="0313.g1:< C A D )">$CAD$</span>,<br />
<span data-ref="0313.g1:< D A B )">$DAB$</span> are less than four right angles.

For let points <span data-ref="0313.g1:B">$B$</span>, <span data-ref="0313.g1:C">$C$</span>, <span data-ref="0313.g1:D">$D$</span> be taken<br />
at random on the straight lines <span data-ref="0313.g1:/ A B /">$AB$</span>,<br />
<span data-ref="0313.g1:/ A C /">$AC$</span>, <span data-ref="0313.g1:/ A D /">$AD$</span> respectively,<br />
and let <span data-ref="0313.g1:/ B C /">$BC$</span>, <span data-ref="0313.g1:/ C D /">$CD$</span>, <span data-ref="0313.g1:/ D B /">$DB$</span> be joined.

![Book XI, Proposition 21](0313.g1.svg)

<p class="sub-clause">Now, since the solid angle at <span data-ref="0313.g1:B">$B$</span> is contained by the three<br />
plane angles <span data-ref="0313.g1:< C B A )">$CBA$</span>, <span data-ref="0313.g1:< A B D )">$ABD$</span>, <span data-ref="0313.g1:< C B D )">$CBD$</span>,</p>
<p class="assertion">any two are greater than the remaining one; <span class="justification">[XI. 20]</span><br />
therefore the angles <span data-ref="0313.g1:< C B A )">$CBA$</span>, <span data-ref="0313.g1:< A B D )">$ABD$</span> are greater than the angle<br />
<span data-ref="0313.g1:< C B D )">$CBD$</span>.</p>

<p class="assertion">For the same reason<br />
the angles <span data-ref="0313.g1:< B C A )">$BCA$</span>, <span data-ref="0313.g1:< A C D )">$ACD$</span> are also greater than the angle <span data-ref="0313.g1:< B C D )">$BCD$</span>,<br />
and the angles <span data-ref="0313.g1:< C D A )">$CDA$</span>, <span data-ref="0313.g1:< A D B )">$ADB$</span> are greater than the angle <span data-ref="0313.g1:< C D B )">$CDB$</span>;<br />
therefore the six angles <span data-ref="0313.g1:< C B A )">$CBA$</span>, <span data-ref="0313.g1:< A B D )">$ABD$</span>, <span data-ref="0313.g1:< B C A )">$BCA$</span>, <span data-ref="0313.g1:< A C D )">$ACD$</span>, <span data-ref="0313.g1:< C D A )">$CDA$</span>,<br />
<span data-ref="0313.g1:< A D B )">$ADB$</span> are greater than the three angles <span data-ref="0313.g1:< C B D )">$CBD$</span>, <span data-ref="0313.g1:< B C D )">$BCD$</span>, <span data-ref="0313.g1:< C D B )">$CDB$</span>.</p>

<p class="sub-clause">But the three angles <span data-ref="0313.g1:< C B D )">$CBD$</span>, <span data-ref="0313.g1:< B D C )">$BDC$</span>, <span data-ref="0313.g1:< B C D )">$BCD$</span> are equal to two<br />
right angles; <span class="justification">[I. 32]</span></p>
<p class="assertion">therefore the six angles <span data-ref="0313.g1:< C B A )">$CBA$</span>, <span data-ref="0313.g1:< A B D )">$ABD$</span>, <span data-ref="0313.g1:< B C A )">$BCA$</span>, <span data-ref="0313.g1:< A C D )">$ACD$</span>, <span data-ref="0313.g1:< C D A )">$CDA$</span>,<br />
<span data-ref="0313.g1:< A D B )">$ADB$</span> are greater than two right angles.</p>
