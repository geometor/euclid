Simson remarks that the angle <span data-ref="0311.g3:< B A C )">$BAC$</span> may happen to be equal to one of the other two and writes accordingly "If they [all three angles] are not [equal], let <span data-ref="0311.g3:< B A C )">$BAC$</span> be that angle which is not less than either of the other two, and is greater than one of them <span data-ref="0311.g3:< D A B )">$DAB$</span>." He then proves, in the same way as Euclid does, that the angles <span data-ref="0311.g3:< D A B )">$DAB$</span>, <span data-ref="0311.g3:< D A C )">$DAC$</span> are greater than the angle <span data-ref="0311.g3:< B A C )">$BAC$</span>, adding finally: "But <span data-ref="0311.g3:< B A C )">$BAC$</span> is not less than either of the angles <span data-ref="0311.g3:< D A B )">$DAB$</span>, <span data-ref="0311.g3:< D A C )">$DAC$</span>; therefore <span data-ref="0311.g3:< B A C )">$BAC$</span>, with either of them, is greater than the other."

It would be better, as indicated by Legendre and Rausenberger, to begin by saying that, "if one of the three angles is either equal to or less than either of the other two, it is evident that the sum of those two is greater than the first. It is therefore only necessary to prove, *for the case in which one angle is greater than each of the others*, that the sum of the two latter is greater than the former.

Accordingly let <span data-ref="0311.g3:< B A C )">$BAC$</span> be greater than each of the other angles." We then proceed as in Euclid.

### PROPOSITION 21.

*Any solid angle is contained by plane angles less than four right angles.*

Let the angle at <span data-ref="0313.g1:A">$A$</span> be a solid angle contained by the plane angles <span data-ref="0313.g1:< B A C )">$BAC$</span>, <span data-ref="0313.g1:< C A D )">$CAD$</span>, <span data-ref="0313.g1:< D A B )">$DAB$</span>;
I say that the angles <span data-ref="0313.g1:< B A C )">$BAC$</span>, <span data-ref="0313.g1:< C A D )">$CAD$</span>, <span data-ref="0313.g1:< D A B )">$DAB$</span> are less than four right angles.

For let points <span data-ref="0313.g1:B">$B$</span>, <span data-ref="0313.g1:C">$C$</span>, <span data-ref="0313.g1:D">$D$</span> be taken at random on the straight lines <span data-ref="0313.g1:/ A B /">$AB$</span>, <span data-ref="0313.g1:/ A C /">$AC$</span>, <span data-ref="0313.g1:/ A D /">$AD$</span> respectively,
and let <span data-ref="0313.g1:/ B C /">$BC$</span>, <span data-ref="0313.g1:/ C D /">$CD$</span>, <span data-ref="0313.g1:/ D B /">$DB$</span> be joined.

![Book XI, Proposition 21](0313.g1.svg)

Now, since the solid angle at <span data-ref="0313.g1:B">$B$</span> is contained by the three plane angles <span data-ref="0313.g1:< C B A )">$CBA$</span>, <span data-ref="0313.g1:< A B D )">$ABD$</span>, <span data-ref="0313.g1:< C B D )">$CBD$</span>,
any two are greater than the remaining one;
[XI. 20]
therefore the angles <span data-ref="0313.g1:< C B A )">$CBA$</span>, <span data-ref="0313.g1:< A B D )">$ABD$</span> are greater than the angle <span data-ref="0313.g1:< C B D )">$CBD$</span>.

For the same reason
the angles <span data-ref="0313.g1:< B C A )">$BCA$</span>, <span data-ref="0313.g1:< A C D )">$ACD$</span> are also greater than the angle <span data-ref="0313.g1:< B C D )">$BCD$</span>,
and the angles <span data-ref="0313.g1:< C D A )">$CDA$</span>, <span data-ref="0313.g1:< A D B )">$ADB$</span> are greater than the angle <span data-ref="0313.g1:< C D B )">$CDB$</span>;
therefore the six angles <span data-ref="0313.g1:< C B A )">$CBA$</span>, <span data-ref="0313.g1:< A B D )">$ABD$</span>, <span data-ref="0313.g1:< B C A )">$BCA$</span>, <span data-ref="0313.g1:< A C D )">$ACD$</span>, <span data-ref="0313.g1:< C D A )">$CDA$</span>, <span data-ref="0313.g1:< A D B )">$ADB$</span> are greater than the three angles <span data-ref="0313.g1:< C B D )">$CBD$</span>, <span data-ref="0313.g1:< B C D )">$BCD$</span>, <span data-ref="0313.g1:< C D B )">$CDB$</span>.

But the three angles <span data-ref="0313.g1:< C B D )">$CBD$</span>, <span data-ref="0313.g1:< B D C )">$BDC$</span>, <span data-ref="0313.g1:< B C D )">$BCD$</span> are equal to two right angles;
[I. 32]
therefore the six angles <span data-ref="0313.g1:< C B A )">$CBA$</span>, <span data-ref="0313.g1:< A B D )">$ABD$</span>, <span data-ref="0313.g1:< B C A )">$BCA$</span>, <span data-ref="0313.g1:< A C D )">$ACD$</span>, <span data-ref="0313.g1:< C D A )">$CDA$</span>, <span data-ref="0313.g1:< A D B )">$ADB$</span> are greater than two right angles.
