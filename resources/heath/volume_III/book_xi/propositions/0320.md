But they are also, by hypothesis, less than four right angles: which is absurd.
Therefore <span data-ref="0319.g1:/ A B /">$AB$</span> is not equal to <span data-ref="0319.g2:/ L O /">$LO$</span>.

I say next that neither is <span data-ref="0319.g1:/ A B /">$AB$</span> less than <span data-ref="0319.g2:/ L O /">$LO$</span>.
For, if possible, let it be so,
and let <span data-ref="0319.g2:/ O P /">$OP$</span> be made equal to <span data-ref="0319.g1:/ A B /">$AB$</span>, and <span data-ref="0319.g2:/ O Q /">$OQ$</span> equal to <span data-ref="0319.g1:/ B C /">$BC$</span>,
and let <span data-ref="0319.g2:/ P Q /">$PQ$</span> be joined.
Then, since <span data-ref="0319.g1:/ A B /">$AB$</span> is equal to <span data-ref="0319.g1:/ B C /">$BC$</span>,
<span data-ref="0319.g2:/ O P /">$OP$</span> is also equal to <span data-ref="0319.g2:/ O Q /">$OQ$</span>,
so that the remainder <span data-ref="0319.g2:/ L P /">$LP$</span> is equal to <span data-ref="0319.g2:/ Q M /">$QM$</span>.
Therefore <span data-ref="0319.g2:/ L M /">$LM$</span> is parallel to <span data-ref="0319.g2:/ P Q /">$PQ$</span>, [VI. 2]
and <span data-ref="0319.g2:< L M O >">$LMO$</span> is equiangular with <span data-ref="0319.g2:< P Q O >">$PQO$</span>; [I. 29]
therefore, as <span data-ref="0319.g2:/ O L /">$OL$</span> is to <span data-ref="0319.g2:/ L M /">$LM$</span>, so is <span data-ref="0319.g2:/ O P /">$OP$</span> to <span data-ref="0319.g2:/ P Q /">$PQ$</span>; [VI. 4]
and alternately, as <span data-ref="0319.g2:/ L O /">$LO$</span> is to <span data-ref="0319.g2:/ O P /">$OP$</span>, so is <span data-ref="0319.g2:/ L M /">$LM$</span> to <span data-ref="0319.g2:/ P Q /">$PQ$</span>. [V. 16]
But <span data-ref="0319.g2:/ L O /">$LO$</span> is greater than <span data-ref="0319.g2:/ O P /">$OP$</span>;
therefore <span data-ref="0319.g2:/ L M /">$LM$</span> is also greater than <span data-ref="0319.g2:/ P Q /">$PQ$</span>.
But <span data-ref="0319.g2:/ L M /">$LM$</span> was made equal to <span data-ref="0319.g1:/ A C /">$AC$</span>;
therefore <span data-ref="0319.g1:/ A C /">$AC$</span> is also greater than <span data-ref="0319.g2:/ P Q /">$PQ$</span>.
Since, then, the two sides <span data-ref="0319.g1:/ A B /">$AB$</span>, <span data-ref="0319.g1:/ B C /">$BC$</span> are equal to the two sides <span data-ref="0319.g2:/ P O /">$PO$</span>, <span data-ref="0319.g2:/ O Q /">$OQ$</span>,
and the base <span data-ref="0319.g1:/ A C /">$AC$</span> is greater than the base <span data-ref="0319.g2:/ P Q /">$PQ$</span>,
therefore the angle <span data-ref="0319.g1:< A B C )">$ABC$</span> is greater than the angle <span data-ref="0319.g2:< P O Q )">$POQ$</span>. [I. 25]
Similarly we can prove that the angle <span data-ref="0319.g1:< D E F )">$DEF$</span> is also greater than the angle <span data-ref="0319.g2:< M O N )">$MON$</span>,
and the angle <span data-ref="0319.g1:< G H K )">$GHK$</span> greater than the angle <span data-ref="0319.g2:< N O L )">$NOL$</span>.
Therefore the three angles <span data-ref="0319.g1:< A B C )">$ABC$</span>, <span data-ref="0319.g1:< D E F )">$DEF$</span>, <span data-ref="0319.g1:< G H K )">$GHK$</span> are greater than the three angles <span data-ref="0319.g2:< L O M )">$LOM$</span>, <span data-ref="0319.g2:< M O N )">$MON$</span>, <span data-ref="0319.g2:< N O L )">$NOL$</span>.
But, by hypothesis, the angles <span data-ref="0319.g1:< A B C )">$ABC$</span>, <span data-ref="0319.g1:< D E F )">$DEF$</span>, <span data-ref="0319.g1:< G H K )">$GHK$</span> are less than four right angles;
therefore the angles <span data-ref="0319.g2:< L O M )">$LOM$</span>, <span data-ref="0319.g2:< M O N )">$MON$</span>, <span data-ref="0319.g2:< N O L )">$NOL$</span> are much less than four right angles.
