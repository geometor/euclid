<p class="assertion">therefore the three angles <span data-ref="0319.g1:< A B C )">$ABC$</span>, <span data-ref="0319.g1:< D E F )">$DEF$</span>, <span data-ref="0319.g1:< G H K )">$GHK$</span> are equal to<br />
the three angles <span data-ref="0319.g2:< L O M )">$LOM$</span>, <span data-ref="0319.g2:< M O N )">$MON$</span>, <span data-ref="0319.g2:< N O L )">$NOL$</span>.</p>

<p class="sub-clause">But the three angles <span data-ref="0319.g2:< L O M )">$LOM$</span>, <span data-ref="0319.g2:< M O N )">$MON$</span>, <span data-ref="0319.g2:< N O L )">$NOL$</span> are equal to<br />
four right angles;</p>
<p class="assertion">therefore the angles <span data-ref="0319.g1:< A B C )">$ABC$</span>, <span data-ref="0319.g1:< D E F )">$DEF$</span>, <span data-ref="0319.g1:< G H K )">$GHK$</span> are equal to four<br />
right angles.</p>

<p class="assertion">But they are also, by hypothesis, less than four right angles:<br />
which is absurd.</p>

<p class="assertion">Therefore <span data-ref="0319.g1:/ A B /">$AB$</span> is not equal to <span data-ref="0319.g2:/ L O /">$LO$</span>.</p>

I say next that neither is <span data-ref="0319.g1:/ A B /">$AB$</span> less than <span data-ref="0319.g2:/ L O /">$LO$</span>.

For, if possible, let it be so,<br />
and let <span data-ref="0319.g2:/ O P /">$OP$</span> be made equal to <span data-ref="0319.g1:/ A B /">$AB$</span>, and <span data-ref="0319.g2:/ O Q /">$OQ$</span> equal to <span data-ref="0319.g1:/ B C /">$BC$</span>,<br />
and let <span data-ref="0319.g2:/ P Q /">$PQ$</span> be joined.

<p class="sub-clause">Then, since <span data-ref="0319.g1:/ A B /">$AB$</span> is equal to <span data-ref="0319.g1:/ B C /">$BC$</span>,<br />
<span data-ref="0319.g2:/ O P /">$OP$</span> is also equal to <span data-ref="0319.g2:/ O Q /">$OQ$</span>,<br />
so that the remainder <span data-ref="0319.g2:/ L P /">$LP$</span> is equal to <span data-ref="0319.g2:/ Q M /">$QM$</span>.</p>

<p class="assertion">Therefore <span data-ref="0319.g2:/ L M /">$LM$</span> is parallel to <span data-ref="0319.g2:/ P Q /">$PQ$</span>, <span class="justification">[VI. 2]</span><br />
and <span data-ref="0319.g2:< L M O >">$LMO$</span> is equiangular with <span data-ref="0319.g2:< P Q O >">$PQO$</span>; <span class="justification">[I. 29]</span><br />
therefore, as <span data-ref="0319.g2:/ O L /">$OL$</span> is to <span data-ref="0319.g2:/ L M /">$LM$</span>, so is <span data-ref="0319.g2:/ O P /">$OP$</span> to <span data-ref="0319.g2:/ P Q /">$PQ$</span>; <span class="justification">[VI. 4]</span><br />
and alternately, as <span data-ref="0319.g2:/ L O /">$LO$</span> is to <span data-ref="0319.g2:/ O P /">$OP$</span>, so is <span data-ref="0319.g2:/ L M /">$LM$</span> to <span data-ref="0319.g2:/ P Q /">$PQ$</span>. <span class="justification">[V. 16]</span></p>

<p class="sub-clause">But <span data-ref="0319.g2:/ L O /">$LO$</span> is greater than <span data-ref="0319.g2:/ O P /">$OP$</span>;</p>
<p class="assertion">therefore <span data-ref="0319.g2:/ L M /">$LM$</span> is also greater than <span data-ref="0319.g2:/ P Q /">$PQ$</span>.</p>

<p class="sub-clause">But <span data-ref="0319.g2:/ L M /">$LM$</span> was made equal to <span data-ref="0319.g1:/ A C /">$AC$</span>;</p>
<p class="assertion">therefore <span data-ref="0319.g1:/ A C /">$AC$</span> is also greater than <span data-ref="0319.g2:/ P Q /">$PQ$</span>.</p>

<p class="sub-clause">Since, then, the two sides <span data-ref="0319.g1:/ A B /">$AB$</span>, <span data-ref="0319.g1:/ B C /">$BC$</span> are equal to the two<br />
sides <span data-ref="0319.g2:/ P O /">$PO$</span>, <span data-ref="0319.g2:/ O Q /">$OQ$</span>,<br />
and the base <span data-ref="0319.g1:/ A C /">$AC$</span> is greater than the base <span data-ref="0319.g2:/ P Q /">$PQ$</span>,</p>
<p class="assertion">therefore the angle <span data-ref="0319.g1:< A B C )">$ABC$</span> is greater than the angle <span data-ref="0319.g2:< P O Q )">$POQ$</span>. <span class="justification">[I. 25]</span></p>

<p class="assertion">Similarly we can prove that<br />
the angle <span data-ref="0319.g1:< D E F )">$DEF$</span> is also greater than the angle <span data-ref="0319.g2:< M O N )">$MON$</span>,<br />
and the angle <span data-ref="0319.g1:< G H K )">$GHK$</span> greater than the angle <span data-ref="0319.g2:< N O L )">$NOL$</span>.</p>

<p class="assertion">Therefore the three angles <span data-ref="0319.g1:< A B C )">$ABC$</span>, <span data-ref="0319.g1:< D E F )">$DEF$</span>, <span data-ref="0319.g1:< G H K )">$GHK$</span> are greater<br />
than the three angles <span data-ref="0319.g2:< L O M )">$LOM$</span>, <span data-ref="0319.g2:< M O N )">$MON$</span>, <span data-ref="0319.g2:< N O L )">$NOL$</span>.</p>

<p class="sub-clause">But, by hypothesis, the angles <span data-ref="0319.g1:< A B C )">$ABC$</span>, <span data-ref="0319.g1:< D E F )">$DEF$</span>, <span data-ref="0319.g1:< G H K )">$GHK$</span> are<br />
less than four right angles;</p>
<p class="assertion">therefore the angles <span data-ref="0319.g2:< L O M )">$LOM$</span>, <span data-ref="0319.g2:< M O N )">$MON$</span>, <span data-ref="0319.g2:< N O L )">$NOL$</span> are much less than<br />
four right angles.</p>
