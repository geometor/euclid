But they are also equal to four right angles: which is absurd.
Therefore <span data-ref="0319.g1:/ A B /">$AB$</span> is not less than <span data-ref="0319.g2:/ L O /">$LO$</span>.
And it was proved that neither is it equal;
therefore <span data-ref="0319.g1:/ A B /">$AB$</span> is greater than <span data-ref="0319.g2:/ L O /">$LO$</span>.

Let then <span data-ref="0319.g2:/ O R /">$OR$</span> be set up from the point <span data-ref="0319.g2:O">$O$</span> at right angles to the plane of the circle <span data-ref="0319.g2:( L M N )">$LMN$</span>, [XI. 12]
and let the square on <span data-ref="0319.g2:/ O R /">$OR$</span> be equal to that area by which the square on <span data-ref="0319.g1:/ A B /">$AB$</span> is greater than the square on <span data-ref="0319.g2:/ L O /">$LO$</span>; [Lemma]
let <span data-ref="0319.g2:/ R L /">$RL$</span>, <span data-ref="0319.g2:/ R M /">$RM$</span>, <span data-ref="0319.g2:/ R N /">$RN$</span> be joined.
Then, since <span data-ref="0319.g2:/ R O /">$RO$</span> is at right angles to the plane of the circle <span data-ref="0319.g2:( L M N )">$LMN$</span>,
therefore <span data-ref="0319.g2:/ R O /">$RO$</span> is also at right angles to each of the straight lines <span data-ref="0319.g2:/ L O /">$LO$</span>, <span data-ref="0319.g2:/ M O /">$MO$</span>, <span data-ref="0319.g2:/ N O /">$NO$</span>.
And, since <span data-ref="0319.g2:/ L O /">$LO$</span> is equal to <span data-ref="0319.g2:/ O M /">$OM$</span>,
while <span data-ref="0319.g2:/ O R /">$OR$</span> is common and at right angles,
therefore the base <span data-ref="0319.g2:/ R L /">$RL$</span> is equal to the base <span data-ref="0319.g2:/ R M /">$RM$</span>. [I. 4]
For the same reason <span data-ref="0319.g2:/ R N /">$RN$</span> is also equal to each of the straight lines <span data-ref="0319.g2:/ R L /">$RL$</span>, <span data-ref="0319.g2:/ R M /">$RM$</span>;
therefore the three straight lines <span data-ref="0319.g2:/ R L /">$RL$</span>, <span data-ref="0319.g2:/ R M /">$RM$</span>, <span data-ref="0319.g2:/ R N /">$RN$</span> are equal to one another.
Next, since by hypothesis the square on <span data-ref="0319.g2:/ O R /">$OR$</span> is equal to that area by which the square on <span data-ref="0319.g1:/ A B /">$AB$</span> is greater than the square on <span data-ref="0319.g2:/ L O /">$LO$</span>,
therefore the square on <span data-ref="0319.g1:/ A B /">$AB$</span> is equal to the squares on <span data-ref="0319.g2:/ L O /">$LO$</span>, <span data-ref="0319.g2:/ O R /">$OR$</span>.
But the square on <span data-ref="0319.g2:/ L R /">$LR$</span> is equal to the squares on <span data-ref="0319.g2:/ L O /">$LO$</span>, <span data-ref="0319.g2:/ O R /">$OR$</span>,
for the angle <span data-ref="0319.g2:< L O R )">$LOR$</span> is right; [I. 47]
therefore the square on <span data-ref="0319.g1:/ A B /">$AB$</span> is equal to the square on <span data-ref="0319.g2:/ R L /">$RL$</span>;
therefore <span data-ref="0319.g1:/ A B /">$AB$</span> is equal to <span data-ref="0319.g2:/ R L /">$RL$</span>.
But each of the straight lines <span data-ref="0319.g1:/ B C /">$BC$</span>, <span data-ref="0319.g1:/ D E /">$DE$</span>, <span data-ref="0319.g1:/ E F /">$EF$</span>, <span data-ref="0319.g1:/ G H /">$GH$</span>, <span data-ref="0319.g1:/ H K /">$HK$</span> is equal to <span data-ref="0319.g1:/ A B /">$AB$</span>,
while each of the straight lines <span data-ref="0319.g2:/ R M /">$RM$</span>, <span data-ref="0319.g2:/ R N /">$RN$</span> is equal to <span data-ref="0319.g2:/ R L /">$RL$</span>;
therefore each of the straight lines <span data-ref="0319.g1:/ A B /">$AB$</span>, <span data-ref="0319.g1:/ B C /">$BC$</span>, <span data-ref="0319.g1:/ D E /">$DE$</span>, <span data-ref="0319.g1:/ E F /">$EF$</span>, <span data-ref="0319.g1:/ G H /">$GH$</span>, <span data-ref="0319.g1:/ H K /">$HK$</span> is equal to each of the straight lines <span data-ref="0319.g2:/ R L /">$RL$</span>, <span data-ref="0319.g2:/ R M /">$RM$</span>, <span data-ref="0319.g2:/ R N /">$RN$</span>.
