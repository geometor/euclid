### LEMMA.

But how it is possible to take the square on <span data-ref="0319.g2:/ O R /">$OR$</span> equal to<br />
that area by which the square on <span data-ref="0322.g1:/ A B /">$AB$</span> is<br />
greater than the square on <span data-ref="0319.g2:/ L O /">$LO$</span>, we can show<br />
as follows.

Let the straight lines <span data-ref="0322.g1:/ A B /">$AB$</span>, <span data-ref="0319.g2:/ L O /">$LO$</span> be<br />
set out,<br />
and let <span data-ref="0322.g1:/ A B /">$AB$</span> be the greater;<br />
let the semicircle <span data-ref="0322.g1:( A B C )">$ABC$</span> be described on <span data-ref="0322.g1:/ A B /">$AB$</span>,<br />
and into the semicircle <span data-ref="0322.g1:( A B C )">$ABC$</span> let <span data-ref="0322.g1:/ A C /">$AC$</span> be fitted equal to the<br />
straight line <span data-ref="0319.g2:/ L O /">$LO$</span>, not being greater than the diameter <span data-ref="0322.g1:/ A B /">$AB$</span>; <span class="justification">[IV. 1]</span><br />
let <span data-ref="0322.g1:/ C B /">$CB$</span> be joined.

![Proposition 23, Lemma](0322.g1.svg)

<p class="sub-clause">Since then the angle <span data-ref="0322.g1:< A C B )">$ACB$</span> is an angle in the semicircle<br />
<span data-ref="0322.g1:( A C B )">$ACB$</span>,</p>
<p class="assertion">therefore the angle <span data-ref="0322.g1:< A C B )">$ACB$</span> is right. <span class="justification">[III. 31]</span></p>

<p class="assertion">Therefore the square on <span data-ref="0322.g1:/ A B /">$AB$</span> is equal to the squares on<br />
<span data-ref="0322.g1:/ A C /">$AC$</span>, <span data-ref="0322.g1:/ C B /">$CB$</span>. <span class="justification">[I. 47]</span></p>

<p class="assertion">Hence the square on <span data-ref="0322.g1:/ A B /">$AB$</span> is greater than the square on<br />
<span data-ref="0322.g1:/ A C /">$AC$</span> by the square on <span data-ref="0322.g1:/ C B /">$CB$</span>.</p>

<p class="sub-clause">But <span data-ref="0322.g1:/ A C /">$AC$</span> is equal to <span data-ref="0319.g2:/ L O /">$LO$</span>.</p>

<p class="assertion">Therefore the square on <span data-ref="0322.g1:/ A B /">$AB$</span> is greater than the square on<br />
<span data-ref="0319.g2:/ L O /">$LO$</span> by the square on <span data-ref="0322.g1:/ C B /">$CB$</span>.</p>

<p class="assertion">If then we cut off <span data-ref="0319.g2:/ O R /">$OR$</span> equal to <span data-ref="0322.g1:/ B C /">$BC$</span>, the square on <span data-ref="0322.g1:/ A B /">$AB$</span> will<br />
be greater than the square on <span data-ref="0319.g2:/ L O /">$LO$</span> by the square on <span data-ref="0319.g2:/ O R /">$OR$</span>.</p>

<p class="qed"><span class="justification">Q. E. F.</span></p>
