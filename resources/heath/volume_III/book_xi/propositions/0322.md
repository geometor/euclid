### LEMMA.

But how it is possible to take the square on <span data-ref="0319.g2:/ O R /">$OR$</span> equal to that area by which the square on <span data-ref="0322.g1:/ A B /">$AB$</span> is greater than the square on <span data-ref="0319.g2:/ L O /">$LO$</span>, we can show as follows.
Let the straight lines <span data-ref="0322.g1:/ A B /">$AB$</span>, <span data-ref="0319.g2:/ L O /">$LO$</span> be set out,
and let <span data-ref="0322.g1:/ A B /">$AB$</span> be the greater;
let the semicircle <span data-ref="0322.g1:( A B C )">$ABC$</span> be described on <span data-ref="0322.g1:/ A B /">$AB$</span>,
and into the semicircle <span data-ref="0322.g1:( A B C )">$ABC$</span> let <span data-ref="0322.g1:/ A C /">$AC$</span> be fitted equal to the straight line <span data-ref="0319.g2:/ L O /">$LO$</span>, not being greater than the diameter <span data-ref="0322.g1:/ A B /">$AB$</span>; [IV. 1]
let <span data-ref="0322.g1:/ C B /">$CB$</span> be joined.

![Proposition 23, Lemma](0322.g1.svg)

Since then the angle <span data-ref="0322.g1:< A C B )">$ACB$</span> is an angle in the semicircle <span data-ref="0322.g1:( A C B )">$ACB$</span>,
therefore the angle <span data-ref="0322.g1:< A C B )">$ACB$</span> is right. [III. 31]
Therefore the square on <span data-ref="0322.g1:/ A B /">$AB$</span> is equal to the squares on <span data-ref="0322.g1:/ A C /">$AC$</span>, <span data-ref="0322.g1:/ C B /">$CB$</span>. [I. 47]
Hence the square on <span data-ref="0322.g1:/ A B /">$AB$</span> is greater than the square on <span data-ref="0322.g1:/ A C /">$AC$</span> by the square on <span data-ref="0322.g1:/ C B /">$CB$</span>.
But <span data-ref="0322.g1:/ A C /">$AC$</span> is equal to <span data-ref="0319.g2:/ L O /">$LO$</span>.
Therefore the square on <span data-ref="0322.g1:/ A B /">$AB$</span> is greater than the square on <span data-ref="0319.g2:/ L O /">$LO$</span> by the square on <span data-ref="0322.g1:/ C B /">$CB$</span>.
If then we cut off <span data-ref="0319.g2:/ O R /">$OR$</span> equal to <span data-ref="0322.g1:/ B C /">$BC$</span>, the square on <span data-ref="0322.g1:/ A B /">$AB$</span> will be greater than the square on <span data-ref="0319.g2:/ L O /">$LO$</span> by the square on <span data-ref="0319.g2:/ O R /">$OR$</span>.

<p align="right">Q. E. F.</p>
