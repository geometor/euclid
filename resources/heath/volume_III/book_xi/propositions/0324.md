(2) Suppose that <span data-ref="0319.g1:/ A B /">$AB$</span> $<$ <span data-ref="0319.g2:/ L O /">$LO$</span>.  
Make <span data-ref="0319.g2:/ O P /">$OP$</span>, <span data-ref="0319.g2:/ O Q /">$OQ$</span> (measured along <span data-ref="0319.g2:/ O L /">$OL$</span>, <span data-ref="0319.g2:/ O M /">$OM$</span>) each equal to <span data-ref="0319.g1:/ A B /">$AB$</span>.  
Thus, <span data-ref="0319.g2:/ O L /">$OL$</span>, <span data-ref="0319.g2:/ O M /">$OM$</span> being equal also, it follows that  
<span data-ref="0319.g2:/ P Q /">$PQ$</span> is $\parallel$ to <span data-ref="0319.g2:/ L M /">$LM$</span>.  
Hence <span data-ref="0319.g2:/ L M /">$LM$</span> $:$ <span data-ref="0319.g2:/ P Q /">$PQ$</span> $=$ <span data-ref="0319.g2:/ L O /">$LO$</span> $:$ <span data-ref="0319.g2:/ O P /">$OP$</span>;  
and, since <span data-ref="0319.g2:/ L O /">$LO$</span> $>$ <span data-ref="0319.g2:/ O P /">$OP$</span>,  
<span data-ref="0319.g2:/ L M /">$LM$</span>, i.e. <span data-ref="0319.g1:/ A C /">$AC$</span>, $>$ <span data-ref="0319.g2:/ P Q /">$PQ$</span>.  
Thus, in $\Delta\text{s}$ <span data-ref="0319.g2:< P O Q >">$POQ$</span>, <span data-ref="0319.g1:< A B C >">$ABC$</span>, two sides are equal to two sides, and base <span data-ref="0319.g1:/ A C /">$AC$</span> $>$ base <span data-ref="0319.g2:/ P Q /">$PQ$</span>;  
therefore <span data-ref="0319.g1:< A B C )">$\angle ABC$</span> $>$ <span data-ref="0319.g2:< P O Q )">$\angle POQ$</span>, i.e. <span data-ref="0319.g2:< L O M )">$\angle LOM$</span>.  
Similarly <span data-ref="0319.g1:< D E F )">$\angle DEF$</span> $>$ <span data-ref="0319.g2:< M O N )">$\angle MON$</span>,  
<span data-ref="0319.g1:< G H K )">$\angle GHK$</span> $>$ <span data-ref="0319.g2:< N O L )">$\angle NOL$</span>,  
and it follows by addition that  
<span data-ref="0319.g1:< A B C )">$\angle ABC$</span> $+$ <span data-ref="0319.g1:< D E F )">$\angle DEF$</span> $+$ <span data-ref="0319.g1:< G H K )">$\angle GHK$</span> $>$ (four right angles):  
which again contradicts the hypothesis.

### Case II.

(1) Suppose, if possible, that <span data-ref="0319.g1:/ A B /">$AB$</span> $=$ <span data-ref="0324.g1:/ L O /">$LO$</span>.  
Then (<span data-ref="0319.g1:/ A B /">$AB$</span> $+$ <span data-ref="0319.g1:/ B C /">$BC$</span>), or (<span data-ref="0319.g1:/ D E /">$DE$</span> $+$ <span data-ref="0319.g1:/ E F /">$EF$</span>) $=$ <span data-ref="0324.g1:/ M O /">$MO$</span> $+$ <span data-ref="0324.g1:/ O L /">$OL$</span>  
$=$ <span data-ref="0324.g1:/ M N /">$MN$</span>  
$=$ <span data-ref="0319.g1:/ D F /">$DF$</span>;  
which contradicts the hypothesis.

(2) The supposition that <span data-ref="0319.g1:/ A B /">$AB$</span> $<$ <span data-ref="0324.g1:/ L O /">$LO$</span> is even more impossible; for in this case it would result that  
<span data-ref="0319.g1:/ D E /">$DE$</span> $+$ <span data-ref="0319.g1:/ E F /">$EF$</span> $<$ <span data-ref="0319.g1:/ D F /">$DF$</span>.

### Case III.

(1) Suppose, if possible, that <span data-ref="0319.g1:/ A B /">$AB$</span> $=$ <span data-ref="0324.g1:/ L O /">$LO$</span>.  
Then, in the triangles <span data-ref="0319.g1:< A B C >">$ABC$</span>, <span data-ref="0324.g1:< L O M >">$LOM$</span>, two sides <span data-ref="0319.g1:/ A B /">$AB$</span>, <span data-ref="0319.g1:/ B C /">$BC$</span> are respectively equal to two sides <span data-ref="0324.g1:/ L O /">$LO$</span>, <span data-ref="0324.g1:/ O M /">$OM$</span>, and the bases <span data-ref="0319.g1:/ A C /">$AC$</span>, <span data-ref="0324.g1:/ L M /">$LM$</span> are equal;  
therefore <span data-ref="0319.g1:< A B C )">$\angle ABC$</span> $=$ <span data-ref="0324.g1:< L O M )">$\angle LOM$</span>.  
Similarly <span data-ref="0319.g1:< G H K )">$\angle GHK$</span> $=$ <span data-ref="0324.g1:< N O L )">$\angle NOL$</span>.  
Therefore, by addition,  
<span data-ref="0324.g1:< M O N )">$\angle MON$</span> $=$ <span data-ref="0319.g1:< A B C )">$\angle ABC$</span> $+$ <span data-ref="0319.g1:< G H K )">$\angle GHK$</span>  
$>$ <span data-ref="0319.g1:< D E F )">$\angle DEF$</span> (by hypothesis).  
But, in the triangles <span data-ref="0319.g1:< D E F >">$DEF$</span>, <span data-ref="0324.g1:< M O N >">$MON$</span>, which are equal in all respects,  
<span data-ref="0324.g1:< M O N )">$\angle MON$</span> $=$ <span data-ref="0319.g1:< D E F )">$\angle DEF$</span>.  
But it was proved that <span data-ref="0324.g1:< M O N )">$\angle MON$</span> $>$ <span data-ref="0319.g1:< D E F )">$\angle DEF$</span>:  
which is impossible.

(2) Suppose, if possible, that <span data-ref="0319.g1:/ A B /">$AB$</span> $<$ <span data-ref="0324.g1:/ L O /">$LO$</span>.  
Along <span data-ref="0324.g1:/ O L /">$OL$</span>, <span data-ref="0324.g1:/ O M /">$OM$</span> measure <span data-ref="0324.g1:/ O P /">$OP$</span>, <span data-ref="0324.g1:/ O Q /">$OQ$</span> each equal to <span data-ref="0319.g1:/ A B /">$AB$</span>.
