(2) Suppose that <span data-ref="0319.g1:/ A B /">$AB$</span> $<$ <span data-ref="0319.g2:/ L O /">$LO$</span>.<br />
Make <span data-ref="0319.g2:/ O P /">$OP$</span>, <span data-ref="0319.g2:/ O Q /">$OQ$</span> (measured along <span data-ref="0319.g2:/ O L /">$OL$</span>, <span data-ref="0319.g2:/ O M /">$OM$</span>) each equal to <span data-ref="0319.g1:/ A B /">$AB$</span>.<br />
Thus, <span data-ref="0319.g2:/ O L /">$OL$</span>, <span data-ref="0319.g2:/ O M /">$OM$</span> being equal also, it follows that<br />
<span data-ref="0319.g2:/ P Q /">$PQ$</span> is $\parallel$ to <span data-ref="0319.g2:/ L M /">$LM$</span>.<br />
Hence <span data-ref="0319.g2:/ L M /">$LM$</span> $:$ <span data-ref="0319.g2:/ P Q /">$PQ$</span> $=$ <span data-ref="0319.g2:/ L O /">$LO$</span> $:$ <span data-ref="0319.g2:/ O P /">$OP$</span>;<br />
and, since <span data-ref="0319.g2:/ L O /">$LO$</span> $>$ <span data-ref="0319.g2:/ O P /">$OP$</span>,<br />
<span data-ref="0319.g2:/ L M /">$LM$</span>, i.e. <span data-ref="0319.g1:/ A C /">$AC$</span>, $>$ <span data-ref="0319.g2:/ P Q /">$PQ$</span>.<br />
Thus, in $\Delta\text{s}$ <span data-ref="0319.g2:< P O Q >">$POQ$</span>, <span data-ref="0319.g1:< A B C >">$ABC$</span>, two sides are equal to two sides, and base<br />
<span data-ref="0319.g1:/ A C /">$AC$</span> $>$ base <span data-ref="0319.g2:/ P Q /">$PQ$</span>;<br />
therefore <span data-ref="0319.g1:< A B C )">$\angle ABC$</span> $>$ <span data-ref="0319.g2:< P O Q )">$\angle POQ$</span>, i.e. <span data-ref="0319.g2:< L O M )">$\angle LOM$</span>.<br />
Similarly <span data-ref="0319.g1:< D E F )">$\angle DEF$</span> $>$ <span data-ref="0319.g2:< M O N )">$\angle MON$</span>,<br />
<span data-ref="0319.g1:< G H K )">$\angle GHK$</span> $>$ <span data-ref="0319.g2:< N O L )">$\angle NOL$</span>,<br />
and it follows by addition that<br />
<span data-ref="0319.g1:< A B C )">$\angle ABC$</span> $+$ <span data-ref="0319.g1:< D E F )">$\angle DEF$</span> $+$ <span data-ref="0319.g1:< G H K )">$\angle GHK$</span> $>$ (four right angles):<br />
which again contradicts the hypothesis.

### Case II.

(1) Suppose, if possible, that <span data-ref="0319.g1:/ A B /">$AB$</span> $=$ <span data-ref="0324.g1:/ L O /">$LO$</span>.<br />
Then (<span data-ref="0319.g1:/ A B /">$AB$</span> $+$ <span data-ref="0319.g1:/ B C /">$BC$</span>), or (<span data-ref="0319.g1:/ D E /">$DE$</span> $+$ <span data-ref="0319.g1:/ E F /">$EF$</span>) $=$ <span data-ref="0324.g1:/ M O /">$MO$</span> $+$ <span data-ref="0324.g1:/ O L /">$OL$</span><br />
$=$ <span data-ref="0324.g1:/ M N /">$MN$</span><br />
$=$ <span data-ref="0319.g1:/ D F /">$DF$</span>;<br />
which contradicts the hypothesis.<br />
(2) The supposition that <span data-ref="0319.g1:/ A B /">$AB$</span> $<$ <span data-ref="0324.g1:/ L O /">$LO$</span> is even more<br />
impossible; for in this case it would result that<br />
<span data-ref="0319.g1:/ D E /">$DE$</span> $+$ <span data-ref="0319.g1:/ E F /">$EF$</span> $<$ <span data-ref="0319.g1:/ D F /">$DF$</span>.

### Case III.

(1) Suppose, if possible, that <span data-ref="0319.g1:/ A B /">$AB$</span> $=$ <span data-ref="0324.g1:/ L O /">$LO$</span>.<br />
Then, in the triangles <span data-ref="0319.g1:< A B C >">$ABC$</span>, <span data-ref="0324.g1:< L O M >">$LOM$</span>, two sides <span data-ref="0319.g1:/ A B /">$AB$</span>, <span data-ref="0319.g1:/ B C /">$BC$</span> are respectively<br />
equal to two sides <span data-ref="0324.g1:/ L O /">$LO$</span>, <span data-ref="0324.g1:/ O M /">$OM$</span>, and the bases<br />
<span data-ref="0319.g1:/ A C /">$AC$</span>, <span data-ref="0324.g1:/ L M /">$LM$</span> are equal;<br />
therefore <span data-ref="0319.g1:< A B C )">$\angle ABC$</span> $=$ <span data-ref="0324.g1:< L O M )">$\angle LOM$</span>.<br />
Similarly <span data-ref="0319.g1:< G H K )">$\angle GHK$</span> $=$ <span data-ref="0324.g1:< N O L )">$\angle NOL$</span>.<br />
Therefore, by addition,<br />
<span data-ref="0324.g1:< M O N )">$\angle MON$</span> $=$ <span data-ref="0319.g1:< A B C )">$\angle ABC$</span> $+$ <span data-ref="0319.g1:< G H K )">$\angle GHK$</span><br />
$>$ <span data-ref="0319.g1:< D E F )">$\angle DEF$</span> (by hypothesis).<br />
But, in the triangles <span data-ref="0319.g1:< D E F >">$DEF$</span>, <span data-ref="0324.g1:< M O N >">$MON$</span>, which<br />
are equal in all respects,<br />
<span data-ref="0324.g1:< M O N )">$\angle MON$</span> $=$ <span data-ref="0319.g1:< D E F )">$\angle DEF$</span>.<br />
But it was proved that <span data-ref="0324.g1:< M O N )">$\angle MON$</span> $>$ <span data-ref="0319.g1:< D E F )">$\angle DEF$</span>:<br />
which is impossible.

(2) Suppose, if possible, that <span data-ref="0319.g1:/ A B /">$AB$</span> $<$ <span data-ref="0324.g1:/ L O /">$LO$</span>.<br />
Along <span data-ref="0324.g1:/ O L /">$OL$</span>, <span data-ref="0324.g1:/ O M /">$OM$</span> measure <span data-ref="0324.g1:/ O P /">$OP$</span>, <span data-ref="0324.g1:/ O Q /">$OQ$</span> each equal to <span data-ref="0319.g1:/ A B /">$AB$</span>.
