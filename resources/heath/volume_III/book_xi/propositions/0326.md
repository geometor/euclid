### Case II. (<span data-ref="0326.g1:O">$O$</span> lying on <span data-ref="0326.g1:/ M N /">$MN$</span>.)

In this case, whether (1) <span data-ref="0326.g1:/ A B /">$AB$</span> $=$ <span data-ref="0326.g1:/ L O /">$LO$</span>, or (2) <span data-ref="0326.g1:/ A B /">$AB$</span> $<$ <span data-ref="0326.g1:/ L O /">$LO$</span>, a triangle cannot be formed with <span data-ref="0326.g1:/ M N /">$MN$</span> as base and each of the other sides equal to <span data-ref="0326.g1:/ A B /">$AB$</span>. In other words, the triangle <span data-ref="0326.g1:< D E F >">$DEF$</span> either reduces to a straight line or is impossible.

### Case III. (<span data-ref="0327.g1:O">$O$</span> lying outside the <span data-ref="0327.g1:< L M N >">$\Delta LMN$</span>.)

(1) Suppose, if possible, that <span data-ref="0326.g1:/ A B /">$AB$</span> $=$ <span data-ref="0327.g1:/ L O /">$LO$</span>.  
Then the triangles <span data-ref="0327.g1:< L O M >">$LOM$</span>, <span data-ref="0327.g1:< M O N >">$MON$</span>, <span data-ref="0327.g1:< N O L >">$NOL$</span> are identically equal to the triangles <span data-ref="0326.g1:< A B C >">$ABC$</span>, <span data-ref="0326.g1:< D E F >">$DEF$</span>, <span data-ref="0327.g1:< G H K >">$GHK$</span>.  
Since  
<span data-ref="0327.g1:< L O M )">$\angle LOM$</span> $+$ <span data-ref="0327.g1:< L O N )">$\angle LON$</span> $=$ <span data-ref="0327.g1:< M O N )">$\angle MON$</span>,  
<span data-ref="0327.g1:< A B C )">$\angle ABC$</span> $+$ <span data-ref="0327.g1:< G H K )">$\angle GHK$</span> $=$ <span data-ref="0327.g1:< D E F )">$\angle DEF$</span>:  
which contradicts the hypothesis.

(2) Suppose that <span data-ref="0326.g1:/ A B /">$AB$</span> $<$ <span data-ref="0327.g1:/ O L /">$OL$</span>.  
Draw, as before, on <span data-ref="0327.g1:/ L M /">$LM$</span>, <span data-ref="0327.g1:/ M N /">$MN$</span>, <span data-ref="0327.g1:/ N L /">$NL$</span> as bases triangles with vertices <span data-ref="0327.g1:P">$P$</span>, <span data-ref="0327.g1:Q">$Q$</span>, <span data-ref="0327.g1:R">$R$</span> and identically equal to the $\Delta\text{s}$ <span data-ref="0326.g1:< A B C >">$ABC$</span>, <span data-ref="0326.g1:< D E F >">$DEF$</span>, <span data-ref="0327.g1:< G H K >">$GHK$</span>.  
Next, at <span data-ref="0327.g1:N">$N$</span> on the straight line <span data-ref="0327.g1:/ N R /">$NR$</span>, make <span data-ref="0327.g1:< R N S )">$\angle RNS$</span> equal to the angle <span data-ref="0327.g1:< P L M )">$PLM$</span>, cut off <span data-ref="0327.g1:/ N S /">$NS$</span> equal to <span data-ref="0327.g1:/ L M /">$LM$</span> and join <span data-ref="0327.g1:/ R S /">$RS$</span>, <span data-ref="0327.g1:/ L S /">$LS$</span>.  
Then <span data-ref="0327.g1:< N R S >">$\Delta NRS$</span> is identically equal to <span data-ref="0327.g1:< L P M >">$\Delta LPM$</span> or <span data-ref="0326.g1:< A B C >">$\Delta ABC$</span>.  
Now  
(<span data-ref="0327.g1:< L N R )">$\angle LNR$</span> $+$ <span data-ref="0327.g1:< R N S )">$\angle RNS$</span>) $<$ (<span data-ref="0327.g1:< N L O )">$\angle NLO$</span> $+$ <span data-ref="0327.g1:< O L M )">$\angle OLM$</span>),  
that is, <span data-ref="0327.g1:< L N S )">$\angle LNS$</span> $<$ <span data-ref="0327.g1:< N L M )">$\angle NLM$</span>.  
Thus, in $\Delta\text{s}$ <span data-ref="0327.g1:< L N S >">$LNS$</span>, <span data-ref="0327.g1:< N L M >">$NLM$</span>, two sides are equal to two sides, and the included angle in the former is less than the included angle in the other.  
Therefore  
<span data-ref="0327.g1:/ L S /">$LS$</span> $<$ <span data-ref="0327.g1:/ M N /">$MN$</span>.
