### PROPOSITION 27.

*On a given straight line to describe a parallelepipedal solid similar and similarly situated to a given parallelepipedal solid.*

Let <span data-ref="0333.g1:/ A B /">$AB$</span> be the given straight line and <span data-ref="0333.g1:< C D >">$CD$</span> the given parallelepipedal solid; thus it is required to describe on the given straight line <span data-ref="0333.g1:/ A B /">$AB$</span> a parallelepipedal solid similar and similarly situated to the given parallelepipedal solid <span data-ref="0333.g1:< C D >">$CD$</span>.

![Proposition 27](0333.g1.svg)

For on the straight line <span data-ref="0333.g1:/ A B /">$AB$</span> and at the point <span data-ref="0333.g1:A">$A$</span> on it let the solid angle, contained by the angles <span data-ref="0333.g1:< B A H )">$BAH$</span>, <span data-ref="0333.g1:< H A K )">$HAK$</span>, <span data-ref="0333.g1:< K A B )">$KAB$</span>, be constructed equal to the solid angle at <span data-ref="0333.g1:C">$C$</span>, so that the angle <span data-ref="0333.g1:< B A H )">$BAH$</span> is equal to the angle <span data-ref="0333.g1:< E C F )">$ECF$</span>, the angle <span data-ref="0333.g1:< B A K )">$BAK$</span> equal to the angle <span data-ref="0333.g1:< E C G )">$ECG$</span>, and the angle <span data-ref="0333.g1:< K A H )">$KAH$</span> to the angle <span data-ref="0333.g1:< G C F )">$GCF$</span>;  
and let it be contrived that,  
as <span data-ref="0333.g1:/ E C /">$EC$</span> is to <span data-ref="0333.g1:/ C G /">$CG$</span>, so is <span data-ref="0333.g1:/ B A /">$BA$</span> to <span data-ref="0333.g1:/ A K /">$AK$</span>,  
and, as <span data-ref="0333.g1:/ G C /">$GC$</span> is to <span data-ref="0333.g1:/ C F /">$CF$</span>, so is <span data-ref="0333.g1:/ K A /">$KA$</span> to <span data-ref="0333.g1:/ A H /">$AH$</span>. [VI. 12]

as <span data-ref="0333.g1:/ E C /">$EC$</span> is to <span data-ref="0333.g1:/ C F /">$CF$</span>, so is <span data-ref="0333.g1:/ B A /">$BA$</span> to <span data-ref="0333.g1:/ A H /">$AH$</span>. [V. 22]
