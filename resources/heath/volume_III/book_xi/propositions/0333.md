### PROPOSITION 27.

<p class="enunciation">On a given straight line to describe a parallelepipedal solid<br />
similar and similarly situated to a given parallelepipedal solid.</p>

Let <span data-ref="0333.g1:/ A B /">$AB$</span> be the given straight line and <span data-ref="0333.g1:< C D >">$CD$</span> the given<br />
parallelepipedal solid ;<br />
thus it is required to describe on the given straight line <span data-ref="0333.g1:/ A B /">$AB$</span><br />
a parallelepipedal solid similar and similarly situated to the<br />
given parallelepipedal solid <span data-ref="0333.g1:< C D >">$CD$</span>.

![Proposition 27](0333.g1.svg)

For on the straight line <span data-ref="0333.g1:/ A B /">$AB$</span> and at the point <span data-ref="0333.g1:A">$A$</span> on it let<br />
the solid angle, contained by the angles <span data-ref="0333.g1:< B A H )">$BAH$</span>, <span data-ref="0333.g1:< H A K )">$HAK$</span>, <span data-ref="0333.g1:< K A B )">$KAB$</span>,<br />
be constructed equal to the solid angle at <span data-ref="0333.g1:C">$C$</span>, so that the angle<br />
<span data-ref="0333.g1:< B A H )">$BAH$</span> is equal to the angle <span data-ref="0333.g1:< E C F )">$ECF$</span>, the angle <span data-ref="0333.g1:< B A K )">$BAK$</span> equal to<br />
the angle <span data-ref="0333.g1:< E C G )">$ECG$</span>, and the angle <span data-ref="0333.g1:< K A H )">$KAH$</span> to the angle <span data-ref="0333.g1:< G C F )">$GCF$</span> ;<br />
and let it be contrived that,<br />
as <span data-ref="0333.g1:/ E C /">$EC$</span> is to <span data-ref="0333.g1:/ C G /">$CG$</span>, so is <span data-ref="0333.g1:/ B A /">$BA$</span> to <span data-ref="0333.g1:/ A K /">$AK$</span>,<br />
and, as <span data-ref="0333.g1:/ G C /">$GC$</span> is to <span data-ref="0333.g1:/ C F /">$CF$</span>, so is <span data-ref="0333.g1:/ K A /">$KA$</span> to <span data-ref="0333.g1:/ A H /">$AH$</span>. <span class="justification">[VI. 12]</span>

<p class="assertion">Therefore also, <em>ex aequali</em>,<br />
as <span data-ref="0333.g1:/ E C /">$EC$</span> is to <span data-ref="0333.g1:/ C F /">$CF$</span>, so is <span data-ref="0333.g1:/ B A /">$BA$</span> to <span data-ref="0333.g1:/ A H /">$AH$</span>. <span class="justification">[V. 22]</span></p>
