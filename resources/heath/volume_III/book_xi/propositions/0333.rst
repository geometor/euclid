PROPOSITION 27.
---------------

.. enunciation::

   On a given straight line to describe a parallelepipedal solid similar and similarly situated to a given parallelepipedal solid.

Let :g:`AB <0333.g1:/ A B />` be the given straight line and :g:`CD <0333.g1:< C D >>` the given parallelepipedal solid ; thus it is required to describe on the given straight line :g:`AB <0333.g1:/ A B />` a parallelepipedal solid similar and similarly situated to the given parallelepipedal solid :g:`CD <0333.g1:< C D >>`.

.. picture:: 0333.g1.svg
   :alt: Proposition 27

For on the straight line :g:`AB <0333.g1:/ A B />` and at the point :g:`A <0333.g1:A>` on it let the solid angle, contained by the angles :g:`BAH <0333.g1:< B A H )>`, :g:`HAK <0333.g1:< H A K )>`, :g:`KAB <0333.g1:< K A B )>`, be constructed equal to the solid angle at :g:`C <0333.g1:C>`, so that the angle :g:`BAH <0333.g1:< B A H )>` is :eq:`equal <0333.g1:< B A H ) = 0333.g1:< E C F )>` to the angle :g:`ECF <0333.g1:< E C F )>`, the angle :g:`BAK <0333.g1:< B A K )>` :eq:`equal <0333.g1:< B A K ) = 0333.g1:< E C G ); 0333.g1:< K A H ) = 0333.g1:< G C F )>` to the angle :g:`ECG <0333.g1:< E C G )>`, and the angle :g:`KAH <0333.g1:< K A H )>` to the angle :g:`GCF <0333.g1:< G C F )>` ; and let it be contrived that, as :g:`EC <0333.g1:/ E C />` is to :g:`CG <0333.g1:/ C G />`, so is :g:`BA <0333.g1:/ B A />` to :g:`AK <0333.g1:/ A K />`, and, as :g:`GC <0333.g1:/ G C />` is to :g:`CF <0333.g1:/ C F />`, so is :g:`KA <0333.g1:/ K A />` to :g:`AH <0333.g1:/ A H />`. :just:`[VI. 12] <VI.12>`

.. assertion::

   Therefore also, :term:`*ex aequali* <ex-aequali>`, as :g:`EC <0333.g1:/ E C />` is to :g:`CF <0333.g1:/ C F />`, so is :g:`BA <0333.g1:/ B A />` to :g:`AH <0333.g1:/ A H />`. :just:`[V. 22] <V.22>`

Let the parallelogram :g:`HB <0333.g1:< H B >>` and the solid :g:`AL <0333.g1:< A L >>` be completed.
