Let <span data-ref="0339.g1:< C M >">$CM$</span>, <span data-ref="0339.g1:< C N >">$CN$</span> be parallelepipedal solids on the same base<br />
<span data-ref="0339.g1:< A B >">$AB$</span> and of the same height,<br />
and let the extremities of their<br />
sides which stand up, namely<br />
<span data-ref="0339.g1:/ A F /">$AF$</span>, <span data-ref="0339.g1:/ A G /">$AG$</span>, <span data-ref="0339.g1:/ L M /">$LM$</span>, <span data-ref="0339.g1:/ L N /">$LN$</span>, <span data-ref="0339.g1:/ C D /">$CD$</span>, <span data-ref="0339.g1:/ C E /">$CE$</span>,<br />
<span data-ref="0339.g1:/ B H /">$BH$</span>, <span data-ref="0339.g1:/ B K /">$BK$</span>, not be on the same<br />
straight lines ;<br />
I say that the solid <span data-ref="0339.g1:< C M >">$CM$</span> is<br />
equal to the solid <span data-ref="0339.g1:< C N >">$CN$</span>.

For let <span data-ref="0339.g1:/ N K /">$NK$</span>, <span data-ref="0339.g1:/ D H /">$DH$</span> be pro-<br />
duced and meet one another<br />
at <span data-ref="0339.g1:R">$R$</span>,<br />
and further let <span data-ref="0339.g1:/ F M /">$FM$</span>, <span data-ref="0339.g1:/ G E /">$GE$</span> be<br />
produced to <span data-ref="0339.g1:P">$P$</span>, <span data-ref="0339.g1:Q">$Q$</span>;<br />
let <span data-ref="0339.g1:/ A O /">$AO$</span>, <span data-ref="0339.g1:/ L P /">$LP$</span>, <span data-ref="0339.g1:/ C Q /">$CQ$</span>, <span data-ref="0339.g1:/ B R /">$BR$</span> be joined.

![Proposition 30](0339.g1.svg)

<p class="assertion">Then the solid <span data-ref="0339.g1:< C M >">$CM$</span>, of which the parallelogram <span data-ref="0339.g1:< A C B L >">$ACBL$</span> is<br />
the base, and <span data-ref="0339.g1:< F D H M >">$FDHM$</span> its opposite, is equal to the solid <span data-ref="0339.g1:< C P >">$CP$</span>,<br />
of which the parallelogram <span data-ref="0339.g1:< A C B L >">$ACBL$</span> is the base, and <span data-ref="0339.g1:< O Q R P >">$OQRP$</span> its<br />
opposite;</p>
<p class="sub-clause">for they are on the same base <span data-ref="0339.g1:< A C B L >">$ACBL$</span> and of the same height,<br />
and the extremities of their sides which stand up, namely <span data-ref="0339.g1:/ A F /">$AF$</span>,<br />
<span data-ref="0339.g1:/ A O /">$AO$</span>, <span data-ref="0339.g1:/ L M /">$LM$</span>, <span data-ref="0339.g1:/ L P /">$LP$</span>, <span data-ref="0339.g1:/ C D /">$CD$</span>, <span data-ref="0339.g1:/ C Q /">$CQ$</span>, <span data-ref="0339.g1:/ B H /">$BH$</span>, <span data-ref="0339.g1:/ B R /">$BR$</span>, are on the same straight<br />
lines <span data-ref="0339.g1:/ F P /">$FP$</span>, <span data-ref="0339.g1:/ D R /">$DR$</span>. <span class="justification">[XI. 29]</span></p>

<p class="assertion">But the solid <span data-ref="0339.g1:< C P >">$CP$</span>, of which the parallelogram <span data-ref="0339.g1:< A C B L >">$ACBL$</span> is<br />
the base, and <span data-ref="0339.g1:< O Q R P >">$OQRP$</span> its opposite, is equal to the solid <span data-ref="0339.g1:< C N >">$CN$</span>,<br />
of which the parallelogram <span data-ref="0339.g1:< A C B L >">$ACBL$</span> is the base and <span data-ref="0339.g1:< G E K N >">$GEKN$</span> its<br />
opposite;</p>
<p class="sub-clause">for they are again on the same base <span data-ref="0339.g1:< A C B L >">$ACBL$</span> and of the same<br />
height, and the extremities of their sides which stand up,<br />
namely <span data-ref="0339.g1:/ A G /">$AG$</span>, <span data-ref="0339.g1:/ A O /">$AO$</span>, <span data-ref="0339.g1:/ C E /">$CE$</span>, <span data-ref="0339.g1:/ C Q /">$CQ$</span>, <span data-ref="0339.g1:/ L N /">$LN$</span>, <span data-ref="0339.g1:/ L P /">$LP$</span>, <span data-ref="0339.g1:/ B K /">$BK$</span>, <span data-ref="0339.g1:/ B R /">$BR$</span>, are on the<br />
same straight lines <span data-ref="0339.g1:/ G Q /">$GQ$</span>, <span data-ref="0339.g1:/ N R /">$NR$</span>.</p>

<p class="assertion">Hence the solid <span data-ref="0339.g1:< C M >">$CM$</span> is also equal to the solid <span data-ref="0339.g1:< C N >">$CN$</span>.</p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>

---

This proposition completes the proof of the theorem that<br />
*Two parallelepipeds on the same base and of the same height are equivalent.*

Legendre deduced the useful theorem that<br />
*Every parallelepiped can be changed into an equivalent rectangular parallele-<br />
piped having the same height and an equivalent base.*

For suppose we have a parallelepiped on the base <span data-ref="0340.g1:< A B C D >">$ABCD$</span> with <span data-ref="0340.g1:< E F G H >">$EFGH$</span> for<br />
the opposite face.
