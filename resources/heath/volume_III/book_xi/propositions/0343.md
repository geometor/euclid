For the same reason,
since the parallelepipedal solid <span data-ref="0343.g1:< Y I >">$YI$</span> has been cut by the plane <span data-ref="0343.g1:< R X >">$RX$</span> which is parallel to opposite planes,
as the base <span data-ref="0343.g1:< Y T >">$YT$</span> is to the base <span data-ref="0343.g1:< T D >">$TD$</span>, so is the solid <span data-ref="0343.g1:< Y X >">$YX$</span> to the solid <span data-ref="0343.g1:< R I >">$RI$</span>. [XI. 25]
But, as the base <span data-ref="0343.g1:< C D >">$CD$</span> is to <span data-ref="0343.g1:< D T >">$DT$</span>, so is <span data-ref="0343.g1:< Y T >">$YT$</span> to <span data-ref="0343.g1:< D T >">$DT$</span>;
therefore also, as the solid <span data-ref="0343.g1:< C F >">$CF$</span> is to the solid <span data-ref="0343.g1:< R I >">$RI$</span>, so is the solid <span data-ref="0343.g1:< Y X >">$YX$</span> to <span data-ref="0343.g1:< R I >">$RI$</span>. [V. 11]
Therefore each of the solids <span data-ref="0343.g1:< C F >">$CF$</span>, <span data-ref="0343.g1:< Y X >">$YX$</span> has to <span data-ref="0343.g1:< R I >">$RI$</span> the same ratio;
therefore the solid <span data-ref="0343.g1:< C F >">$CF$</span> is equal to the solid <span data-ref="0343.g1:< Y X >">$YX$</span>. [V. 9]
But <span data-ref="0343.g1:< Y X >">$YX$</span> was proved equal to <span data-ref="0343.g1:< A E >">$AE$</span>;
therefore <span data-ref="0343.g1:< A E >">$AE$</span> is also equal to <span data-ref="0343.g1:< C F >">$CF$</span>.

Next, let the sides standing up, <span data-ref="0343.g1:/ A G /">$AG$</span>, <span data-ref="0343.g1:/ H K /">$HK$</span>, <span data-ref="0343.g1:/ B E /">$BE$</span>, <span data-ref="0343.g1:/ L M /">$LM$</span>, <span data-ref="0343.g1:/ C N /">$CN$</span>, <span data-ref="0343.g1:/ P Q /">$PQ$</span>, <span data-ref="0343.g1:/ D F /">$DF$</span>, <span data-ref="0343.g1:/ R S /">$RS$</span>, not be at right angles to the bases <span data-ref="0343.g1:< A B >">$AB$</span>, <span data-ref="0343.g1:< C D >">$CD$</span>;
I say again that the solid <span data-ref="0343.g1:< A E >">$AE$</span> is equal to the solid <span data-ref="0343.g1:< C F >">$CF$</span>.

For from the points <span data-ref="0343.g1:K">$K$</span>, <span data-ref="0343.g1:E">$E$</span>, <span data-ref="0343.g1:G">$G$</span>, <span data-ref="0343.g1:M">$M$</span>, <span data-ref="0343.g1:Q">$Q$</span>, <span data-ref="0343.g1:F">$F$</span>, <span data-ref="0343.g1:N">$N$</span>, <span data-ref="0343.g1:S">$S$</span> let <span data-ref="0343.g1:/ K O /">$KO$</span>, <span data-ref="0343.g1:/ E T /">$ET$</span>, <span data-ref="0343.g1:/ G U /">$GU$</span>, <span data-ref="0343.g1:/ M V /">$MV$</span>, <span data-ref="0343.g1:/ Q W /">$QW$</span>, <span data-ref="0343.g1:/ F X /">$FX$</span>, <span data-ref="0343.g1:/ N Y /">$NY$</span>, <span data-ref="0343.g1:/ S I /">$SI$</span> be drawn perpendicular to the plane of reference, and let them meet the plane at the points <span data-ref="0343.g1:O">$O$</span>, <span data-ref="0343.g1:T">$T$</span>, <span data-ref="0343.g1:U">$U$</span>, <span data-ref="0343.g1:V">$V$</span>, <span data-ref="0343.g1:W">$W$</span>, <span data-ref="0343.g1:X">$X$</span>, <span data-ref="0343.g1:Y">$Y$</span>, <span data-ref="0343.g1:I">$I$</span>,
and let <span data-ref="0343.g1:/ O T /">$OT$</span>, <span data-ref="0343.g1:/ O U /">$OU$</span>, <span data-ref="0343.g1:/ U V /">$UV$</span>, <span data-ref="0343.g1:/ T V /">$TV$</span>, <span data-ref="0343.g1:/ W X /">$WX$</span>, <span data-ref="0343.g1:/ W Y /">$WY$</span>, <span data-ref="0343.g1:/ Y I /">$YI$</span>, <span data-ref="0343.g1:/ I X /">$IX$</span> be joined.
Then the solid <span data-ref="0343.g1:< K V >">$KV$</span> is equal to the solid <span data-ref="0343.g1:< Q I >">$QI$</span>,
for they are on the equal bases <span data-ref="0343.g1:< K M >">$KM$</span>, <span data-ref="0343.g1:< Q S >">$QS$</span> and of the same height, and their sides which stand up are at right angles to their bases. [First part of this Prop.]
But the solid <span data-ref="0343.g1:< K V >">$KV$</span> is equal to the solid <span data-ref="0343.g1:< A E >">$AE$</span>,
and <span data-ref="0343.g1:< Q I >">$QI$</span> to <span data-ref="0343.g1:< C F >">$CF$</span>;
for they are on the same base and of the same height, while the extremities of their sides which stand up are not on the same straight lines. [XI. 30]
