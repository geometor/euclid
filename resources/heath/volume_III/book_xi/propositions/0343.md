<p class="sub-clause">For the same reason,<br />
since the parallelepipedal solid <span data-ref="0343.g1:< Y I >">$YI$</span> has been cut by the plane<br />
<span data-ref="0343.g1:< R X >">$RX$</span> which is parallel to opposite planes,</p>
<p class="assertion">as the base <span data-ref="0343.g1:< Y T >">$YT$</span> is to the base <span data-ref="0343.g1:< T D >">$TD$</span>, so is the solid <span data-ref="0343.g1:< Y X >">$YX$</span> to the<br />
solid <span data-ref="0343.g1:< R I >">$RI$</span>. <span class="justification">[XI. 25]</span></p>

<p class="sub-clause">But, as the base <span data-ref="0343.g1:< C D >">$CD$</span> is to <span data-ref="0343.g1:< D T >">$DT$</span>, so is <span data-ref="0343.g1:< Y T >">$YT$</span> to <span data-ref="0343.g1:< D T >">$DT$</span>;</p>
<p class="assertion">therefore also, as the solid <span data-ref="0343.g1:< C F >">$CF$</span> is to the solid <span data-ref="0343.g1:< R I >">$RI$</span>, so is the<br />
solid <span data-ref="0343.g1:< Y X >">$YX$</span> to <span data-ref="0343.g1:< R I >">$RI$</span>. <span class="justification">[V. 11]</span></p>

<p class="assertion">Therefore each of the solids <span data-ref="0343.g1:< C F >">$CF$</span>, <span data-ref="0343.g1:< Y X >">$YX$</span> has to <span data-ref="0343.g1:< R I >">$RI$</span> the same<br />
ratio;<br />
therefore the solid <span data-ref="0343.g1:< C F >">$CF$</span> is equal to the solid <span data-ref="0343.g1:< Y X >">$YX$</span>. <span class="justification">[V. 9]</span></p>

<p class="sub-clause">But <span data-ref="0343.g1:< Y X >">$YX$</span> was proved equal to <span data-ref="0343.g1:< A E >">$AE$</span>;</p>
<p class="assertion">therefore <span data-ref="0343.g1:< A E >">$AE$</span> is also equal to <span data-ref="0343.g1:< C F >">$CF$</span>.</p>

Next, let the sides standing up, <span data-ref="0343.g1:/ A G /">$AG$</span>, <span data-ref="0343.g1:/ H K /">$HK$</span>, <span data-ref="0343.g1:/ B E /">$BE$</span>, <span data-ref="0343.g1:/ L M /">$LM$</span>, <span data-ref="0343.g1:/ C N /">$CN$</span>,<br />
<span data-ref="0343.g1:/ P Q /">$PQ$</span>, <span data-ref="0343.g1:/ D F /">$DF$</span>, <span data-ref="0343.g1:/ R S /">$RS$</span>, not be at right angles to the bases <span data-ref="0343.g1:< A B >">$AB$</span>, <span data-ref="0343.g1:< C D >">$CD$</span>;<br />
I say again that the solid <span data-ref="0343.g1:< A E >">$AE$</span> is equal to the solid <span data-ref="0343.g1:< C F >">$CF$</span>.

<p class="assertion">Then the solid <span data-ref="0343.g1:< K V >">$KV$</span> is equal to the solid <span data-ref="0343.g1:< Q I >">$QI$</span>,<br />

<p class="sub-clause">But the solid <span data-ref="0343.g1:< K V >">$KV$</span> is equal to the solid <span data-ref="0343.g1:< A E >">$AE$</span>,<br />
