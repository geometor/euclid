### PROPOSITION 32.

*Parallelepipedal solids which are of the same height are to one another as their bases.*

Let <span data-ref="0345.g1:< A B >">$AB$</span>, <span data-ref="0345.g1:< C D >">$CD$</span> be parallelepipedal solids of the same height;
I say that the parallelepipedal solids <span data-ref="0345.g1:< A B >">$AB$</span>, <span data-ref="0345.g1:< C D >">$CD$</span> are to one another as their bases, that is, that, as the base <span data-ref="0345.g1:< A E >">$AE$</span> is to the base <span data-ref="0345.g1:< C F >">$CF$</span>, so is the solid <span data-ref="0345.g1:< A B >">$AB$</span> to the solid <span data-ref="0345.g1:< C D >">$CD$</span>.

![Book XI, Proposition 32](0345.g1.svg)

For let <span data-ref="0345.g1:< F H >">$FH$</span> equal to <span data-ref="0345.g1:< A E >">$AE$</span> be applied to <span data-ref="0345.g1:/ F G /">$FG$</span>, [I. 45]
and on <span data-ref="0345.g1:< F H >">$FH$</span> as base, and with the same height as that of <span data-ref="0345.g1:< C D >">$CD$</span>, let the parallelepipedal solid <span data-ref="0345.g1:< G K >">$GK$</span> be completed.

Then the solid <span data-ref="0345.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0345.g1:< G K >">$GK$</span>;
for they are on equal bases <span data-ref="0345.g1:< A E >">$AE$</span>, <span data-ref="0345.g1:< F H >">$FH$</span> and of the same height. [XI. 31]

And, since the parallelepipedal solid <span data-ref="0345.g1:< C K >">$CK$</span> is cut by the plane <span data-ref="0345.g1:< D G >">$DG$</span> which is parallel to opposite planes,
therefore, as the base <span data-ref="0345.g1:< C F >">$CF$</span> is to the base <span data-ref="0345.g1:< F H >">$FH$</span>, so is the solid <span data-ref="0345.g1:< C D >">$CD$</span> to the solid <span data-ref="0345.g1:< D H >">$DH$</span>. [XI. 25]

But the base <span data-ref="0345.g1:< F H >">$FH$</span> is equal to the base <span data-ref="0345.g1:< A E >">$AE$</span>,
and the solid <span data-ref="0345.g1:< G K >">$GK$</span> to the solid <span data-ref="0345.g1:< A B >">$AB$</span>;
therefore also, as the base <span data-ref="0345.g1:< A E >">$AE$</span> is to the base <span data-ref="0345.g1:< C F >">$CF$</span>, so is the solid <span data-ref="0345.g1:< A B >">$AB$</span> to the solid <span data-ref="0345.g1:< C D >">$CD$</span>.

Therefore etc.

Q. E. D.
