### PROPOSITION 32.

<p class="enunciation">Parallelepipedal solids which are of the same height are to<br />
one another as their bases.</p>

Let <span data-ref="0345.g1:< A B >">$AB$</span>, <span data-ref="0345.g1:< C D >">$CD$</span> be parallelepipedal solids of the same height;<br />
I say that the parallelepipedal solids <span data-ref="0345.g1:< A B >">$AB$</span>, <span data-ref="0345.g1:< C D >">$CD$</span> are to one<br />
another as their bases, that is, that, as the base <span data-ref="0345.g1:< A E >">$AE$</span> is to the<br />
base <span data-ref="0345.g1:< C F >">$CF$</span>, so is the solid <span data-ref="0345.g1:< A B >">$AB$</span> to the solid <span data-ref="0345.g1:< C D >">$CD$</span>.

![Book XI, Proposition 32](0345.g1.svg)

For let <span data-ref="0345.g1:< F H >">$FH$</span> equal to <span data-ref="0345.g1:< A E >">$AE$</span> be applied to <span data-ref="0345.g1:/ F G /">$FG$</span>, <span class="justification">[I. 45]</span><br />
and on <span data-ref="0345.g1:< F H >">$FH$</span> as base, and with the same height as that of <span data-ref="0345.g1:< C D >">$CD$</span>,<br />
let the parallelepipedal solid <span data-ref="0345.g1:< G K >">$GK$</span> be completed.

<p class="assertion">Then the solid <span data-ref="0345.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0345.g1:< G K >">$GK$</span>;<br />
for they are on equal bases <span data-ref="0345.g1:< A E >">$AE$</span>, <span data-ref="0345.g1:< F H >">$FH$</span> and of the same height.<br />
<span class="justification">[XI. 31]</span></p>

<p class="sub-clause">And, since the parallelepipedal solid <span data-ref="0345.g1:< C K >">$CK$</span> is cut by the plane<br />
<span data-ref="0345.g1:< D G >">$DG$</span> which is parallel to opposite planes,</p>
<p class="assertion">therefore, as the base <span data-ref="0345.g1:< C F >">$CF$</span> is to the base <span data-ref="0345.g1:< F H >">$FH$</span>, so is the solid<br />
<span data-ref="0345.g1:< C D >">$CD$</span> to the solid <span data-ref="0345.g1:< D H >">$DH$</span>. <span class="justification">[XI. 25]</span></p>

<p class="sub-clause">But the base <span data-ref="0345.g1:< F H >">$FH$</span> is equal to the base <span data-ref="0345.g1:< A E >">$AE$</span>,<br />
and the solid <span data-ref="0345.g1:< G K >">$GK$</span> to the solid <span data-ref="0345.g1:< A B >">$AB$</span>;</p>
<p class="assertion">therefore also, as the base <span data-ref="0345.g1:< A E >">$AE$</span> is to the base <span data-ref="0345.g1:< C F >">$CF$</span>, so is the<br />
solid <span data-ref="0345.g1:< A B >">$AB$</span> to the solid <span data-ref="0345.g1:< C D >">$CD$</span>.</p>

<p class="qed">Therefore etc.<span class="justification">Q. E. D.</span></p>
