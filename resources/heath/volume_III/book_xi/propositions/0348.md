<p class="sub-clause">But the solid <span data-ref="0346.g1:< K P >">$KP$</span> is equal to the solid <span data-ref="0346.g1:< C D >">$CD$</span>,<br />

<p class="assertion">therefore the solid <span data-ref="0346.g1:< A B >">$AB$</span> has also to the solid <span data-ref="0346.g1:< C D >">$CD$</span> the ratio<br />

<p class="qed">Therefore etc. <span class="justification">Q. E. D.</span></p>

<p class="assertion">PORISM. From this it is manifest that, if four straight<br />
lines be &lt;continuously&gt; proportional, as the first is to the<br />
fourth, so will a parallelepipedal solid on the first be to the<br />
similar and similarly described parallelepipedal solid on the<br />
second, inasmuch as the first has to the fourth the ratio<br />
triplicate of that which it has to the second.</p>

---

The proof may be summarised as follows.

The three edges <span data-ref="0346.g1:/ A E /">$AE$</span>, <span data-ref="0346.g1:/ G E /">$GE$</span>, <span data-ref="0346.g1:/ H E /">$HE$</span> of the parallelepiped <span data-ref="0346.g1:< A B >">$AB$</span> which meet at<br />
<span data-ref="0346.g1:E">$E$</span>, the vertex corresponding to <span data-ref="0346.g1:R">$R$</span> in the other parallelepiped, are produced,<br />
and lengths <span data-ref="0346.g1:/ E K /">$EK$</span>, <span data-ref="0346.g1:/ E L /">$EL$</span>, <span data-ref="0346.g1:/ E M /">$EM$</span> are marked off equal respectively to the edges <span data-ref="0346.g1:/ C F /">$CF$</span>,<br />
<span data-ref="0346.g1:/ F N /">$FN$</span>, <span data-ref="0346.g1:/ F R /">$FR$</span> of <span data-ref="0346.g1:< C D >">$CD$</span>.

The parallelograms and solids are then completed as shown in the figure.

Euclid first shows that the solid <span data-ref="0346.g1:< C D >">$CD$</span> and the new solid <span data-ref="0346.g1:< P K >">$PK$</span> are equal and<br />
similar according to the criterion in XI. Def. 10, viz. that they are contained<br />
by the same number of equal and similar planes. (They are arranged in the<br />
same order, and it would be easy to prove equality by proving the equality of<br />
a pair of solid angles and then applying one solid to the other.)

We have now, by hypothesis,
$$AE : CF = EG : FN = EH : FR\text{;}$$
that is,
$$AE : EK = EG : EL = EH : EM\text{.}$$

But
$$\begin{align*}
AE : EK &= \square AG : \square GK, & \text{[VI. 1]} \\
EG : EL &= \square GK : \square KL, & \\
EH : EM &= \square HK : \square KM\text{.} &
\end{align*}$$

Again, by XI. 25 or 32,
$$\begin{align*}
\square AG : \square GK &= (\text{solid } AB) : (\text{solid } EO)\text{,} \\
\square GK : \square KL &= (\text{solid } EO) : (\text{solid } QL)\text{,} \\
\square HK : \square KM &= (\text{solid } QL) : (\text{solid } KP)\text{.}
\end{align*}$$

Therefore
$$(\text{solid } AB) : (\text{solid } EO) = (\text{solid } EO) : (\text{solid } QL) = (\text{solid } QL) : (\text{solid } KP)\text{,}$$
or the solid <span data-ref="0346.g1:< A B >">$AB$</span> is to the solid <span data-ref="0346.g1:< K P >">$KP$</span> (that is, <span data-ref="0346.g1:< C D >">$CD$</span>) in the ratio triplicate of that<br />
which the solid <span data-ref="0346.g1:< A B >">$AB$</span> has to the solid <span data-ref="0346.g1:< E O >">$EO$</span>, i.e. the ratio triplicate of that which<br />
<span data-ref="0346.g1:/ A E /">$AE$</span> has to <span data-ref="0346.g1:/ E K /">$EK$</span> (or <span data-ref="0346.g1:/ C F /">$CF$</span>).

Heiberg doubts whether the Porism appended to this proposition is<br />
genuine.
