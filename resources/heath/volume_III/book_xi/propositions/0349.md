Simson adds, as Prop. D, a useful theorem which we should have expected to find here, on the analogy of VI. 23 following VI. 19, 20, viz. that *Solid parallelepipeds contained by parallelograms equiangular to one another, each to each, that is, of which the solid angles are equal, each to each, have to one another the ratio compounded of the ratios of their sides.*

The proof follows the method of the proposition XI. 33, and we can use the same figure. In order to obtain one ratio between lines to represent the ratio compounded of the ratios of the sides, after the manner of VI. 23, we take any straight line $a$, and then determine three other straight lines $b$, $c$, $d$, such that
$$\begin{align*}
AE : CF &= a : b\text{,} \\
EG : FN &= b : c\text{,} \\
EH : FR &= c : d\text{,}
\end{align*}$$
whence $a : d$ represents the ratio compounded of the ratios of the sides.

We obtain, in the same manner as above,
$$\begin{align*}
(\text{solid } AB) : (\text{solid } EO) &= \square AG : \square GK = AE : EK = AE : CF \\
&= a : b\text{,} \\
(\text{solid } EO) : (\text{solid } QL) &= \square GK : \square KL = GE : EL = GE : FN \\
&= b : c\text{,} \\
(\text{solid } QL) : (\text{solid } KP) &= \square HK : \square KM = EH : EM = EH : FR \\
&= c : d\text{,}
\end{align*}$$
whence, by composition [V. 22],
$$\begin{align*}
(\text{solid } AB) : (\text{solid } KP) &= a : d\text{,} \\
\text{or } (\text{solid } AB) : (\text{solid } CD) &= a : d\text{.}
\end{align*}$$

### PROPOSITION 34.

*In equal parallelepipedal solids the bases are reciprocally proportional to the heights; and those parallelepipedal solids in which the bases are reciprocally proportional to the heights are equal.*

Let <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C D >">$CD$</span> be equal parallelepipedal solids;
I say that in the parallelepipedal solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C D >">$CD$</span> the bases are reciprocally proportional to the heights,
that is, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is the height of the solid <span data-ref="0350.g1:< C D >">$CD$</span> to the height of the solid <span data-ref="0350.g1:< A B >">$AB$</span>.

First, let the sides which stand up, namely <span data-ref="0350.g1:/ A G /">$AG$</span>, <span data-ref="0350.g1:/ E F /">$EF$</span>, <span data-ref="0350.g1:/ L B /">$LB$</span>, <span data-ref="0350.g1:/ H K /">$HK$</span>, <span data-ref="0350.g1:/ C M /">$CM$</span>, <span data-ref="0350.g1:/ N O /">$NO$</span>, <span data-ref="0350.g1:/ P D /">$PD$</span>, <span data-ref="0350.g1:/ Q R /">$QR$</span>, be at right angles to their bases;
I say that, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is <span data-ref="0350.g1:/ C M /">$CM$</span> to <span data-ref="0350.g1:/ A G /">$AG$</span>.

If now the base <span data-ref="0350.g1:< E H >">$EH$</span> is equal to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>,
while the solid <span data-ref="0350.g1:< A B >">$AB$</span> is also equal to the solid <span data-ref="0350.g1:< C D >">$CD$</span>,
<span data-ref="0350.g1:/ C M /">$CM$</span> will also be equal to <span data-ref="0350.g1:/ A G /">$AG$</span>.
