For parallelepipedal solids of the same height are to one another as the bases; <span style="float: right;">[XI. 32]</span>
and, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to <span data-ref="0350.g1:< N Q >">$NQ$</span>, so will <span data-ref="0350.g1:/ C M /">$CM$</span> be to <span data-ref="0350.g1:/ A G /">$AG$</span>,
and it is manifest that in the parallelepipedal solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C D >">$CD$</span> the bases are reciprocally proportional to the heights.

Next, let the base <span data-ref="0350.g1:< E H >">$EH$</span> not be equal to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>,
but let <span data-ref="0350.g1:< E H >">$EH$</span> be greater.

![Proposition 34, Diagram 1](0350.g1.svg)

Now the solid <span data-ref="0350.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0350.g1:< C D >">$CD$</span>;
therefore <span data-ref="0350.g1:/ C M /">$CM$</span> is also greater than <span data-ref="0350.g1:/ A G /">$AG$</span>.

Let then <span data-ref="0350.g1:/ C T /">$CT$</span> be made equal to <span data-ref="0350.g1:/ A G /">$AG$</span>,
and let the parallelepipedal solid <span data-ref="0350.g1:< V C >">$VC$</span> be completed on <span data-ref="0350.g1:< N Q >">$NQ$</span> as base and with <span data-ref="0350.g1:/ C T /">$CT$</span> as height.

Now, since the solid <span data-ref="0350.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0350.g1:< C D >">$CD$</span>,
and <span data-ref="0350.g1:< C V >">$CV$</span> is outside them,
while equals have to the same the same ratio, <span style="float: right;">[V. 7]</span>
therefore, as the solid <span data-ref="0350.g1:< A B >">$AB$</span> is to the solid <span data-ref="0350.g1:< C V >">$CV$</span>, so is the solid <span data-ref="0350.g1:< C D >">$CD$</span> to the solid <span data-ref="0350.g1:< C V >">$CV$</span>.

But, as the solid <span data-ref="0350.g1:< A B >">$AB$</span> is to the solid <span data-ref="0350.g1:< C V >">$CV$</span>, so is the base <span data-ref="0350.g1:< E H >">$EH$</span> to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>,
for the solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C V >">$CV$</span> are of equal height; <span style="float: right;">[XI. 32]</span>
and, as the solid <span data-ref="0350.g1:< C D >">$CD$</span> is to the solid <span data-ref="0350.g1:< C V >">$CV$</span>, so is the base <span data-ref="0350.g1:< M Q >">$MQ$</span> to the base <span data-ref="0350.g1:< T Q >">$TQ$</span> [XI. 25] and <span data-ref="0350.g1:/ C M /">$CM$</span> to <span data-ref="0350.g1:/ C T /">$CT$</span> [VI. 1];
therefore also, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is <span data-ref="0350.g1:/ M C /">$MC$</span> to <span data-ref="0350.g1:/ C T /">$CT$</span>.

But <span data-ref="0350.g1:/ C T /">$CT$</span> is equal to <span data-ref="0350.g1:/ A G /">$AG$</span>;
therefore also, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is <span data-ref="0350.g1:/ M C /">$MC$</span> to <span data-ref="0350.g1:/ A G /">$AG$</span>.
