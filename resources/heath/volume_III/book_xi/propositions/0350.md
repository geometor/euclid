<p class="assertion">For parallelepipedal solids of the same height are to<br />
one another as the bases; <span class="justification">[XI. 32]</span><br />
and, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to <span data-ref="0350.g1:< N Q >">$NQ$</span>, so will <span data-ref="0350.g1:/ C M /">$CM$</span> be to <span data-ref="0350.g1:/ A G /">$AG$</span>,<br />
and it is manifest that in the parallelepipedal solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C D >">$CD$</span><br />
the bases are reciprocally proportional to the heights.</p>

Next, let the base <span data-ref="0350.g1:< E H >">$EH$</span> not be equal to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>,<br />
but let <span data-ref="0350.g1:< E H >">$EH$</span> be greater.

![Proposition 34, Diagram 1](0350.g1.svg)

<p class="sub-clause">Now the solid <span data-ref="0350.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0350.g1:< C D >">$CD$</span>;</p>
<p class="assertion">therefore <span data-ref="0350.g1:/ C M /">$CM$</span> is also greater than <span data-ref="0350.g1:/ A G /">$AG$</span>.</p>

Let then <span data-ref="0350.g1:/ C T /">$CT$</span> be made equal to <span data-ref="0350.g1:/ A G /">$AG$</span>,<br />
and let the parallelepipedal solid <span data-ref="0350.g1:< V C >">$VC$</span> be completed on <span data-ref="0350.g1:< N Q >">$NQ$</span> as<br />
base and with <span data-ref="0350.g1:/ C T /">$CT$</span> as height.

<p class="sub-clause">Now, since the solid <span data-ref="0350.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0350.g1:< C D >">$CD$</span>,<br />
and <span data-ref="0350.g1:< C V >">$CV$</span> is outside them,<br />
while equals have to the same the same ratio, <span class="justification">[V. 7]</span></p>
<p class="assertion">therefore, as the solid <span data-ref="0350.g1:< A B >">$AB$</span> is to the solid <span data-ref="0350.g1:< C V >">$CV$</span>, so is the solid<br />
<span data-ref="0350.g1:< C D >">$CD$</span> to the solid <span data-ref="0350.g1:< C V >">$CV$</span>.</p>

<p class="sub-clause">But, as the solid <span data-ref="0350.g1:< A B >">$AB$</span> is to the solid <span data-ref="0350.g1:< C V >">$CV$</span>, so is the base<br />
<span data-ref="0350.g1:< E H >">$EH$</span> to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>,<br />
for the solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C V >">$CV$</span> are of equal height; <span class="justification">[XI. 32]</span><br />
and, as the solid <span data-ref="0350.g1:< C D >">$CD$</span> is to the solid <span data-ref="0350.g1:< C V >">$CV$</span>, so is the base <span data-ref="0350.g1:< M Q >">$MQ$</span> to<br />
the base <span data-ref="0350.g1:< T Q >">$TQ$</span> <span class="justification">[XI. 25]</span> and <span data-ref="0350.g1:/ C M /">$CM$</span> to <span data-ref="0350.g1:/ C T /">$CT$</span> <span class="justification">[VI. 1]</span>;</p>
<p class="assertion">therefore also, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is <span data-ref="0350.g1:/ M C /">$MC$</span><br />
to <span data-ref="0350.g1:/ C T /">$CT$</span>.</p>

<p class="sub-clause">But <span data-ref="0350.g1:/ C T /">$CT$</span> is equal to <span data-ref="0350.g1:/ A G /">$AG$</span>;</p>
<p class="assertion">therefore also, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is <span data-ref="0350.g1:/ M C /">$MC$</span><br />
to <span data-ref="0350.g1:/ A G /">$AG$</span>.</p>
