.. assertion::

   | For parallelepipedal solids of the same height are to
   | one another as the bases; :just:`[XI. 32] <XI.32>`
   | and, as the base :g:`$EH$ <0350.g1:< E H >>` is to :g:`$NQ$ <0350.g1:< N Q >>`, so will :g:`$CM$ <0350.g1:/ C M />` be to :g:`$AG$ <0350.g1:/ A G />`,
   | and it is manifest that in the parallelepipedal solids :g:`$AB$ <0350.g1:< A B >>`, :g:`$CD$ <0350.g1:< C D >>`
   | the bases are reciprocally proportional to the heights.

| Next, let the base :g:`$EH$ <0350.g1:< E H >>` not be equal to the base :g:`$NQ$ <0350.g1:< N Q >>`,
| but let :g:`$EH$ <0350.g1:< E H >>` be greater.

.. picture:: 0350.g1.svg
   :alt: Proposition 34, Diagram 1

.. subclause::

   Now the solid :g:`$AB$ <0350.g1:< A B >>` is equal to the solid :g:`$CD$ <0350.g1:< C D >>`;

.. assertion::

   therefore :g:`$CM$ <0350.g1:/ C M />` is also greater than :g:`$AG$ <0350.g1:/ A G />`.

| Let then :g:`$CT$ <0350.g1:/ C T />` be made equal to :g:`$AG$ <0350.g1:/ A G />`,
| and let the parallelepipedal solid :g:`$VC$ <0350.g1:< V C >>` be completed on :g:`$NQ$ <0350.g1:< N Q >>` as
| base and with :g:`$CT$ <0350.g1:/ C T />` as height.

.. subclause::

   | Now, since the solid :g:`$AB$ <0350.g1:< A B >>` is equal to the solid :g:`$CD$ <0350.g1:< C D >>`,
   | and :g:`$CV$ <0350.g1:< C V >>` is outside them,
   | while equals have to the same the same ratio, :just:`[V. 7] <V.7>`

.. assertion::

   | therefore, as the solid :g:`$AB$ <0350.g1:< A B >>` is to the solid :g:`$CV$ <0350.g1:< C V >>`, so is the solid
   | :g:`$CD$ <0350.g1:< C D >>` to the solid :g:`$CV$ <0350.g1:< C V >>`.

.. subclause::

   | But, as the solid :g:`$AB$ <0350.g1:< A B >>` is to the solid :g:`$CV$ <0350.g1:< C V >>`, so is the base
   | :g:`$EH$ <0350.g1:< E H >>` to the base :g:`$NQ$ <0350.g1:< N Q >>`,
   | for the solids :g:`$AB$ <0350.g1:< A B >>`, :g:`$CV$ <0350.g1:< C V >>` are of equal height; :just:`[XI. 32] <XI.32>`
   | and, as the solid :g:`$CD$ <0350.g1:< C D >>` is to the solid :g:`$CV$ <0350.g1:< C V >>`, so is the base :g:`$MQ$ <0350.g1:< M Q >>` to
   | the base :g:`$TQ$ <0350.g1:< T Q >>` :just:`[XI. 25] <XI.25>` and :g:`$CM$ <0350.g1:/ C M />` to :g:`$CT$ <0350.g1:/ C T />` :just:`[VI. 1] <VI.1>`;

.. assertion::

   | therefore also, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so is :g:`$MC$ <0350.g1:/ M C />`
   | to :g:`$CT$ <0350.g1:/ C T />`.

.. subclause::

   But :g:`$CT$ <0350.g1:/ C T />` is equal to :g:`$AG$ <0350.g1:/ A G />`;

.. assertion::

   | therefore also, as the base :g:`$EH$ <0350.g1:< E H >>` is to the base :g:`$NQ$ <0350.g1:< N Q >>`, so is :g:`$MC$ <0350.g1:/ M C />`
   | to :g:`$AG$ <0350.g1:/ A G />`.
