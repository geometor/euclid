Therefore in the parallelepipedal solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C D >">$CD$</span> the bases are reciprocally proportional to the heights.

Again, in the parallelepipedal solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C D >">$CD$</span> let the bases be reciprocally proportional to the heights, that is, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so let the height of the solid <span data-ref="0350.g1:< C D >">$CD$</span> be to the height of the solid <span data-ref="0350.g1:< A B >">$AB$</span>;
I say that the solid <span data-ref="0350.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0350.g1:< C D >">$CD$</span>.

Let the sides which stand up be again at right angles to the bases.

Now, if the base <span data-ref="0350.g1:< E H >">$EH$</span> is equal to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>,
and, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is the height of the solid <span data-ref="0350.g1:< C D >">$CD$</span> to the height of the solid <span data-ref="0350.g1:< A B >">$AB$</span>,
therefore the height of the solid <span data-ref="0350.g1:< C D >">$CD$</span> is also equal to the height of the solid <span data-ref="0350.g1:< A B >">$AB$</span>.

But parallelepipedal solids on equal bases and of the same height are equal to one another; <span style="float: right;">[XI. 31]</span>
therefore the solid <span data-ref="0350.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0350.g1:< C D >">$CD$</span>.

Next, let the base <span data-ref="0350.g1:< E H >">$EH$</span> not be equal to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>,
but let <span data-ref="0350.g1:< E H >">$EH$</span> be greater;
therefore the height of the solid <span data-ref="0350.g1:< C D >">$CD$</span> is also greater than the height of the solid <span data-ref="0350.g1:< A B >">$AB$</span>,
that is, <span data-ref="0350.g1:/ C M /">$CM$</span> is greater than <span data-ref="0350.g1:/ A G /">$AG$</span>.

Let <span data-ref="0350.g1:/ C T /">$CT$</span> be again made equal to <span data-ref="0350.g1:/ A G /">$AG$</span>,
and let the solid <span data-ref="0350.g1:< C V >">$CV$</span> be similarly completed.

Since, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is <span data-ref="0350.g1:/ M C /">$MC$</span> to <span data-ref="0350.g1:/ A G /">$AG$</span>,
while <span data-ref="0350.g1:/ A G /">$AG$</span> is equal to <span data-ref="0350.g1:/ C T /">$CT$</span>,
therefore, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is <span data-ref="0350.g1:/ C M /">$CM$</span> to <span data-ref="0350.g1:/ C T /">$CT$</span>.

But, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is the solid <span data-ref="0350.g1:< A B >">$AB$</span> to the solid <span data-ref="0350.g1:< C V >">$CV$</span>,
for the solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C V >">$CV$</span> are of equal height; <span style="float: right;">[XI. 32]</span>
and, as <span data-ref="0350.g1:/ C M /">$CM$</span> is to <span data-ref="0350.g1:/ C T /">$CT$</span>, so is the base <span data-ref="0350.g1:< M Q >">$MQ$</span> to the base <span data-ref="0350.g1:< Q T >">$QT$</span> [VI. 1]
and the solid <span data-ref="0350.g1:< C D >">$CD$</span> to the solid <span data-ref="0350.g1:< C V >">$CV$</span>. <span style="float: right;">[XI. 25]</span>

Therefore also, as the solid <span data-ref="0350.g1:< A B >">$AB$</span> is to the solid <span data-ref="0350.g1:< C V >">$CV$</span>, so is the solid <span data-ref="0350.g1:< C D >">$CD$</span> to the solid <span data-ref="0350.g1:< C V >">$CV$</span>;
therefore each of the solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C D >">$CD$</span> has to <span data-ref="0350.g1:< C V >">$CV$</span> the same ratio.
