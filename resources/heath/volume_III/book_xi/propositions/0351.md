<p class="assertion">Therefore in the parallelepipedal solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C D >">$CD$</span> the bases<br />
are reciprocally proportional to the heights.</p>

Again, in the parallelepipedal solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C D >">$CD$</span> let the bases<br />
be reciprocally proportional to the heights, that is, as the base<br />
<span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so let the height of the solid <span data-ref="0350.g1:< C D >">$CD$</span> be<br />
to the height of the solid <span data-ref="0350.g1:< A B >">$AB$</span>;<br />
I say that the solid <span data-ref="0350.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0350.g1:< C D >">$CD$</span>.

Let the sides which stand up be again at right angles to<br />
the bases.

<p class="sub-clause">Now, if the base <span data-ref="0350.g1:< E H >">$EH$</span> is equal to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>,<br />
and, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is the height of<br />
the solid <span data-ref="0350.g1:< C D >">$CD$</span> to the height of the solid <span data-ref="0350.g1:< A B >">$AB$</span>,</p>
<p class="assertion">therefore the height of the solid <span data-ref="0350.g1:< C D >">$CD$</span> is also equal to the<br />
height of the solid <span data-ref="0350.g1:< A B >">$AB$</span>.</p>

<p class="sub-clause">But parallelepipedal solids on equal bases and of the same<br />
height are equal to one another; <span class="justification">[XI. 31]</span></p>
<p class="assertion">therefore the solid <span data-ref="0350.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0350.g1:< C D >">$CD$</span>.</p>

<p class="sub-clause">Next, let the base <span data-ref="0350.g1:< E H >">$EH$</span> not be equal to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>,<br />
but let <span data-ref="0350.g1:< E H >">$EH$</span> be greater;</p>
<p class="assertion">therefore the height of the solid <span data-ref="0350.g1:< C D >">$CD$</span> is also greater than the<br />
height of the solid <span data-ref="0350.g1:< A B >">$AB$</span>,<br />
that is, <span data-ref="0350.g1:/ C M /">$CM$</span> is greater than <span data-ref="0350.g1:/ A G /">$AG$</span>.</p>

Let <span data-ref="0350.g1:/ C T /">$CT$</span> be again made equal to <span data-ref="0350.g1:/ A G /">$AG$</span>,<br />
and let the solid <span data-ref="0350.g1:< C V >">$CV$</span> be similarly completed.

<p class="sub-clause">Since, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is <span data-ref="0350.g1:/ M C /">$MC$</span><br />
to <span data-ref="0350.g1:/ A G /">$AG$</span>,<br />
while <span data-ref="0350.g1:/ A G /">$AG$</span> is equal to <span data-ref="0350.g1:/ C T /">$CT$</span>,</p>
<p class="assertion">therefore, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is <span data-ref="0350.g1:/ C M /">$CM$</span><br />
to <span data-ref="0350.g1:/ C T /">$CT$</span>.</p>

<p class="sub-clause">But, as the base <span data-ref="0350.g1:< E H >">$EH$</span> is to the base <span data-ref="0350.g1:< N Q >">$NQ$</span>, so is the solid<br />
<span data-ref="0350.g1:< A B >">$AB$</span> to the solid <span data-ref="0350.g1:< C V >">$CV$</span>,<br />
for the solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C V >">$CV$</span> are of equal height; <span class="justification">[XI. 32]</span><br />
and, as <span data-ref="0350.g1:/ C M /">$CM$</span> is to <span data-ref="0350.g1:/ C T /">$CT$</span>, so is the base <span data-ref="0350.g1:< M Q >">$MQ$</span> to the base <span data-ref="0350.g1:< Q T >">$QT$</span> <span class="justification">[VI. 1]</span><br />
and the solid <span data-ref="0350.g1:< C D >">$CD$</span> to the solid <span data-ref="0350.g1:< C V >">$CV$</span>. <span class="justification">[XI. 25]</span></p>

<p class="assertion">Therefore also, as the solid <span data-ref="0350.g1:< A B >">$AB$</span> is to the solid <span data-ref="0350.g1:< C V >">$CV$</span>, so is<br />
the solid <span data-ref="0350.g1:< C D >">$CD$</span> to the solid <span data-ref="0350.g1:< C V >">$CV$</span>;<br />
therefore each of the solids <span data-ref="0350.g1:< A B >">$AB$</span>, <span data-ref="0350.g1:< C D >">$CD$</span> has to <span data-ref="0350.g1:< C V >">$CV$</span> the same<br />
ratio.</p>
