## Mathematical & Editorial Analysis
- Structure of the converse argument:
  1. Given $EH : NQ = CM : AG$ and $CT = AG$.
  2. Hence $EH : NQ = CM : CT$.
  3. $EH : NQ = AB : CV$ (XI. 32).
  4. $CM : CT = \text{base } MQ : \text{base } QT$ (VI. 1) $= CD : CV$ (XI. 25).
  5. Therefore $AB : CV = CD : CV$.
  6. The conclusion $AB = CD$ follows immediately on the next page via Book V, Proposition 9.
