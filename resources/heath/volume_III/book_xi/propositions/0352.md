<p class="assertion">Therefore the solid <span data-ref="0352.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0352.g1:< C D >">$CD$</span>. <span class="justification">[V. 9]</span></p>

Now let the sides which stand up, <span data-ref="0352.g1:/ F E /">$FE$</span>, <span data-ref="0352.g1:/ B L /">$BL$</span>, <span data-ref="0352.g1:/ G A /">$GA$</span>, <span data-ref="0352.g1:/ H K /">$HK$</span>,<br />
<span data-ref="0352.g1:/ O N /">$ON$</span>, <span data-ref="0352.g1:/ D P /">$DP$</span>, <span data-ref="0352.g1:/ M C /">$MC$</span>, <span data-ref="0352.g1:/ R Q /">$RQ$</span>, not be at right angles to their bases;<br />
let perpendiculars be drawn from the points <span data-ref="0352.g1:F">$F$</span>, <span data-ref="0352.g1:G">$G$</span>, <span data-ref="0352.g1:B">$B$</span>, <span data-ref="0352.g1:K">$K$</span>, <span data-ref="0352.g1:O">$O$</span>,<br />
<span data-ref="0352.g1:M">$M$</span>, <span data-ref="0352.g1:D">$D$</span>, <span data-ref="0352.g1:R">$R$</span> to the planes through <span data-ref="0352.g1:< E H >">$EH$</span>, <span data-ref="0352.g1:< N Q >">$NQ$</span>, and let them meet<br />
the planes at <span data-ref="0352.g1:S">$S$</span>, <span data-ref="0352.g1:T">$T$</span>, <span data-ref="0352.g1:U">$U$</span>, <span data-ref="0352.g1:V">$V$</span>, <span data-ref="0352.g1:W">$W$</span>, <span data-ref="0352.g1:X">$X$</span>, <span data-ref="0352.g1:Y">$Y$</span>, <span data-ref="0352.g1:a">$a$</span>,<br />
and let the solids <span data-ref="0352.g1:< F V >">$FV$</span>, <span data-ref="0352.g1:< O a >">$Oa$</span> be completed;<br />
I say that, in this case too, if the solids <span data-ref="0352.g1:< A B >">$AB$</span>, <span data-ref="0352.g1:< C D >">$CD$</span> are equal,<br />
the bases are reciprocally proportional to the heights, that is,<br />
as the base <span data-ref="0352.g1:< E H >">$EH$</span> is to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>, so is the height of the<br />
solid <span data-ref="0352.g1:< C D >">$CD$</span> to the height of the solid <span data-ref="0352.g1:< A B >">$AB$</span>.

![Proposition 34, Diagram 2](0352.g1.svg)

<p class="sub-clause">Since the solid <span data-ref="0352.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0352.g1:< C D >">$CD$</span>,<br />
while <span data-ref="0352.g1:< A B >">$AB$</span> is equal to <span data-ref="0352.g1:< B T >">$BT$</span>,<br />
for they are on the same base <span data-ref="0352.g1:< F K >">$FK$</span> and of the same height; <span class="justification">[XI. 29, 30]</span><br />
and the solid <span data-ref="0352.g1:< C D >">$CD$</span> is equal to <span data-ref="0352.g1:< D X >">$DX$</span>,<br />
for they are again on the same base <span data-ref="0352.g1:< R O >">$RO$</span> and of the same<br />
height; <span class="justification">[id.]</span></p>
<p class="assertion">therefore the solid <span data-ref="0352.g1:< B T >">$BT$</span> is also equal to the solid <span data-ref="0352.g1:< D X >">$DX$</span>.</p>

<p class="assertion">Therefore, as the base <span data-ref="0352.g1:< F K >">$FK$</span> is to the base <span data-ref="0352.g1:< O R >">$OR$</span>, so is the<br />
height of the solid <span data-ref="0352.g1:< D X >">$DX$</span> to the height of the solid <span data-ref="0352.g1:< B T >">$BT$</span>. <span class="justification">[Part 1.]</span></p>

<p class="sub-clause">But the base <span data-ref="0352.g1:< F K >">$FK$</span> is equal to the base <span data-ref="0352.g1:< E H >">$EH$</span>,<br />
and the base <span data-ref="0352.g1:< O R >">$OR$</span> to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>;</p>
<p class="assertion">therefore, as the base <span data-ref="0352.g1:< E H >">$EH$</span> is to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>, so is the height<br />
of the solid <span data-ref="0352.g1:< D X >">$DX$</span> to the height of the solid <span data-ref="0352.g1:< B T >">$BT$</span>.</p>
