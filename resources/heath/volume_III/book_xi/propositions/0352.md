Therefore the solid <span data-ref="0352.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0352.g1:< C D >">$CD$</span>. <span style="float: right;">[V. 9]</span>

Now let the sides which stand up, <span data-ref="0352.g1:/ F E /">$FE$</span>, <span data-ref="0352.g1:/ B L /">$BL$</span>, <span data-ref="0352.g1:/ G A /">$GA$</span>, <span data-ref="0352.g1:/ H K /">$HK$</span>, <span data-ref="0352.g1:/ O N /">$ON$</span>, <span data-ref="0352.g1:/ D P /">$DP$</span>, <span data-ref="0352.g1:/ M C /">$MC$</span>, <span data-ref="0352.g1:/ R Q /">$RQ$</span>, not be at right angles to their bases;
let perpendiculars be drawn from the points <span data-ref="0352.g1:F">$F$</span>, <span data-ref="0352.g1:G">$G$</span>, <span data-ref="0352.g1:B">$B$</span>, <span data-ref="0352.g1:K">$K$</span>, <span data-ref="0352.g1:O">$O$</span>, <span data-ref="0352.g1:M">$M$</span>, <span data-ref="0352.g1:D">$D$</span>, <span data-ref="0352.g1:R">$R$</span> to the planes through <span data-ref="0352.g1:< E H >">$EH$</span>, <span data-ref="0352.g1:< N Q >">$NQ$</span>, and let them meet the planes at <span data-ref="0352.g1:S">$S$</span>, <span data-ref="0352.g1:T">$T$</span>, <span data-ref="0352.g1:U">$U$</span>, <span data-ref="0352.g1:V">$V$</span>, <span data-ref="0352.g1:W">$W$</span>, <span data-ref="0352.g1:X">$X$</span>, <span data-ref="0352.g1:Y">$Y$</span>, <span data-ref="0352.g1:a">$a$</span>,
and let the solids <span data-ref="0352.g1:< F V >">$FV$</span>, <span data-ref="0352.g1:< O a >">$Oa$</span> be completed;
I say that, in this case too, if the solids <span data-ref="0352.g1:< A B >">$AB$</span>, <span data-ref="0352.g1:< C D >">$CD$</span> are equal, the bases are reciprocally proportional to the heights, that is, as the base <span data-ref="0352.g1:< E H >">$EH$</span> is to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>, so is the height of the solid <span data-ref="0352.g1:< C D >">$CD$</span> to the height of the solid <span data-ref="0352.g1:< A B >">$AB$</span>.

![Proposition 34, Diagram 2](0352.g1.svg)

Since the solid <span data-ref="0352.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0352.g1:< C D >">$CD$</span>,
while <span data-ref="0352.g1:< A B >">$AB$</span> is equal to <span data-ref="0352.g1:< B T >">$BT$</span>,
for they are on the same base <span data-ref="0352.g1:< F K >">$FK$</span> and of the same height; <span style="float: right;">[XI. 29, 30]</span>
and the solid <span data-ref="0352.g1:< C D >">$CD$</span> is equal to <span data-ref="0352.g1:< D X >">$DX$</span>,
for they are again on the same base <span data-ref="0352.g1:< R O >">$RO$</span> and of the same height; <span style="float: right;">[id.]</span>
therefore the solid <span data-ref="0352.g1:< B T >">$BT$</span> is also equal to the solid <span data-ref="0352.g1:< D X >">$DX$</span>.

Therefore, as the base <span data-ref="0352.g1:< F K >">$FK$</span> is to the base <span data-ref="0352.g1:< O R >">$OR$</span>, so is the height of the solid <span data-ref="0352.g1:< D X >">$DX$</span> to the height of the solid <span data-ref="0352.g1:< B T >">$BT$</span>. <span style="float: right;">[Part 1.]</span>

But the base <span data-ref="0352.g1:< F K >">$FK$</span> is equal to the base <span data-ref="0352.g1:< E H >">$EH$</span>,
and the base <span data-ref="0352.g1:< O R >">$OR$</span> to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>;
therefore, as the base <span data-ref="0352.g1:< E H >">$EH$</span> is to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>, so is the height of the solid <span data-ref="0352.g1:< D X >">$DX$</span> to the height of the solid <span data-ref="0352.g1:< B T >">$BT$</span>.
