Mathematical & Editorial Analysis
---------------------------------

- Reduction from oblique solids to right solids:

  - Solid $AB$ is on the same base $FK$ and of the same height as the right solid $BT$; hence $AB = BT$ (by XI. 29, 30).
  - Similarly, oblique solid $CD$ equals right solid $DX$ on the same base $RO$ and of the same height.
  - Therefore right solid $BT =$ right solid $DX$.
  - Applying Part 1 to $BT$ and $DX$: base $FK : \text{base } OR = \text{height of } DX : \text{height of } BT$.
  - Since base $FK = \text{base } EH$ and base $OR = \text{base } NQ$, the proportionality applies directly to $EH$ and $NQ$.
