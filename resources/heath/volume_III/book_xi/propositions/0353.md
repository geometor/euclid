<p class="sub-clause">But the solids <span data-ref="0352.g1:< D X >">$DX$</span>, <span data-ref="0352.g1:< B T >">$BT$</span> and the solids <span data-ref="0352.g1:< D C >">$DC$</span>, <span data-ref="0352.g1:< B A >">$BA$</span> have the<br />
same heights respectively;</p>
<p class="assertion">therefore, as the base <span data-ref="0352.g1:< E H >">$EH$</span> is to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>, so is the height<br />
of the solid <span data-ref="0352.g1:< D C >">$DC$</span> to the height of the solid <span data-ref="0352.g1:< A B >">$AB$</span>.</p>
<p class="assertion">Therefore in the parallelepipedal solids <span data-ref="0352.g1:< A B >">$AB$</span>, <span data-ref="0352.g1:< C D >">$CD$</span> the bases<br />
are reciprocally proportional to the heights.</p>

Again, in the parallelepipedal solids <span data-ref="0352.g1:< A B >">$AB$</span>, <span data-ref="0352.g1:< C D >">$CD$</span> let the bases<br />
be reciprocally proportional to the heights,<br />
that is, as the base <span data-ref="0352.g1:< E H >">$EH$</span> is to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>, so let the height<br />
of the solid <span data-ref="0352.g1:< C D >">$CD$</span> be to the height of the solid <span data-ref="0352.g1:< A B >">$AB$</span>;<br />
I say that the solid <span data-ref="0352.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0352.g1:< C D >">$CD$</span>.

<p class="sub-clause">For, with the same construction,<br />
since, as the base <span data-ref="0352.g1:< E H >">$EH$</span> is to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>, so is the height of<br />
the solid <span data-ref="0352.g1:< C D >">$CD$</span> to the height of the solid <span data-ref="0352.g1:< A B >">$AB$</span>,<br />
while the base <span data-ref="0352.g1:< E H >">$EH$</span> is equal to the base <span data-ref="0352.g1:< F K >">$FK$</span>,<br />
and <span data-ref="0352.g1:< N Q >">$NQ$</span> to <span data-ref="0352.g1:< O R >">$OR$</span>,</p>
<p class="assertion">therefore, as the base <span data-ref="0352.g1:< F K >">$FK$</span> is to the base <span data-ref="0352.g1:< O R >">$OR$</span>, so is the height<br />
of the solid <span data-ref="0352.g1:< C D >">$CD$</span> to the height of the solid <span data-ref="0352.g1:< A B >">$AB$</span>.</p>

<p class="sub-clause">But the solids <span data-ref="0352.g1:< A B >">$AB$</span>, <span data-ref="0352.g1:< C D >">$CD$</span> and <span data-ref="0352.g1:< B T >">$BT$</span>, <span data-ref="0352.g1:< D X >">$DX$</span> have the same<br />
heights respectively;</p>
<p class="assertion">therefore, as the base <span data-ref="0352.g1:< F K >">$FK$</span> is to the base <span data-ref="0352.g1:< O R >">$OR$</span>, so is the height<br />
of the solid <span data-ref="0352.g1:< D X >">$DX$</span> to the height of the solid <span data-ref="0352.g1:< B T >">$BT$</span>.</p>

<p class="assertion">Therefore in the parallelepipedal solids <span data-ref="0352.g1:< B T >">$BT$</span>, <span data-ref="0352.g1:< D X >">$DX$</span> the bases<br />
are reciprocally proportional to the heights;<br />
therefore the solid <span data-ref="0352.g1:< B T >">$BT$</span> is equal to the solid <span data-ref="0352.g1:< D X >">$DX$</span>. <span class="justification">[Part 1.]</span></p>

<p class="sub-clause">But <span data-ref="0352.g1:< B T >">$BT$</span> is equal to <span data-ref="0352.g1:< B A >">$BA$</span>,<br />
for they are on the same base <span data-ref="0352.g1:< F K >">$FK$</span> and of the same height; <span class="justification">[XI. 29, 30]</span><br />
and the solid <span data-ref="0352.g1:< D X >">$DX$</span> is equal to the solid <span data-ref="0352.g1:< D C >">$DC$</span>. <span class="justification">[id.]</span></p>

<p class="qed">Therefore the solid <span data-ref="0352.g1:< A B >">$AB$</span> is also equal to the solid <span data-ref="0352.g1:< C D >">$CD$</span>.<span class="justification">Q. E. D.</span></p>

---

In this proposition Euclid makes two assumptions which require notice,<br />
(1) that, if two parallelepipeds are equal, and have equal bases, their heights<br />
are equal, and (2) that, if the bases of two equal parallelepipeds are unequal,<br />
that which has the lesser base has the greater height. In justification of the<br />
former statement Euclid says, according to what Heiberg holds to be the<br />
genuine reading, “for parallelepipedal solids of the same height are to one<br />
another as their bases” [XI. 32]. This apparently struck some very early<br />
editor as not being sufficient, and he added the explanation appearing in<br />
