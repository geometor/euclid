But the solids <span data-ref="0352.g1:< D X >">$DX$</span>, <span data-ref="0352.g1:< B T >">$BT$</span> and the solids <span data-ref="0352.g1:< D C >">$DC$</span>, <span data-ref="0352.g1:< B A >">$BA$</span> have the same heights respectively;
therefore, as the base <span data-ref="0352.g1:< E H >">$EH$</span> is to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>, so is the height of the solid <span data-ref="0352.g1:< D C >">$DC$</span> to the height of the solid <span data-ref="0352.g1:< A B >">$AB$</span>.
Therefore in the parallelepipedal solids <span data-ref="0352.g1:< A B >">$AB$</span>, <span data-ref="0352.g1:< C D >">$CD$</span> the bases are reciprocally proportional to the heights.

Again, in the parallelepipedal solids <span data-ref="0352.g1:< A B >">$AB$</span>, <span data-ref="0352.g1:< C D >">$CD$</span> let the bases be reciprocally proportional to the heights,
that is, as the base <span data-ref="0352.g1:< E H >">$EH$</span> is to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>, so let the height of the solid <span data-ref="0352.g1:< C D >">$CD$</span> to the height of the solid <span data-ref="0352.g1:< A B >">$AB$</span>;
I say that the solid <span data-ref="0352.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0352.g1:< C D >">$CD$</span>.

For, with the same construction,
since, as the base <span data-ref="0352.g1:< E H >">$EH$</span> is to the base <span data-ref="0352.g1:< N Q >">$NQ$</span>, so is the height of the solid <span data-ref="0352.g1:< C D >">$CD$</span> to the height of the solid <span data-ref="0352.g1:< A B >">$AB$</span>,
while the base <span data-ref="0352.g1:< E H >">$EH$</span> is equal to the base <span data-ref="0352.g1:< F K >">$FK$</span>,
and <span data-ref="0352.g1:< N Q >">$NQ$</span> to <span data-ref="0352.g1:< O R >">$OR$</span>,
therefore, as the base <span data-ref="0352.g1:< F K >">$FK$</span> is to the base <span data-ref="0352.g1:< O R >">$OR$</span>, so is the height of the solid <span data-ref="0352.g1:< C D >">$CD$</span> to the height of the solid <span data-ref="0352.g1:< A B >">$AB$</span>.

But the solids <span data-ref="0352.g1:< A B >">$AB$</span>, <span data-ref="0352.g1:< C D >">$CD$</span> and <span data-ref="0352.g1:< B T >">$BT$</span>, <span data-ref="0352.g1:< D X >">$DX$</span> have the same heights respectively;
therefore, as the base <span data-ref="0352.g1:< F K >">$FK$</span> is to the base <span data-ref="0352.g1:< O R >">$OR$</span>, so is the height of the solid <span data-ref="0352.g1:< D X >">$DX$</span> to the height of the solid <span data-ref="0352.g1:< B T >">$BT$</span>.

Therefore in the parallelepipedal solids <span data-ref="0352.g1:< B T >">$BT$</span>, <span data-ref="0352.g1:< D X >">$DX$</span> the bases are reciprocally proportional to the heights;
therefore the solid <span data-ref="0352.g1:< B T >">$BT$</span> is equal to the solid <span data-ref="0352.g1:< D X >">$DX$</span>. <span style="float: right;">[Part 1.]</span>

But <span data-ref="0352.g1:< B T >">$BT$</span> is equal to <span data-ref="0352.g1:< B A >">$BA$</span>,
for they are on the same base <span data-ref="0352.g1:< F K >">$FK$</span> and of the same height; <span style="float: right;">[XI. 29, 30]</span>
and the solid <span data-ref="0352.g1:< D X >">$DX$</span> is equal to the solid <span data-ref="0352.g1:< D C >">$DC$</span>. <span style="float: right;">[id.]</span>

Therefore the solid <span data-ref="0352.g1:< A B >">$AB$</span> is also equal to the solid <span data-ref="0352.g1:< C D >">$CD$</span>.

In this proposition Euclid makes two assumptions which require notice, (1) that, if two parallelepipeds are equal, and have equal bases, their heights are equal, and (2) that, if the bases of two equal parallelepipeds are unequal, that which has the lesser base has the greater height. In justification of the former statement Euclid says, according to what Heiberg holds to be the genuine reading, "for parallelepipedal solids of the same height are to one another as their bases" [XI. 32].
