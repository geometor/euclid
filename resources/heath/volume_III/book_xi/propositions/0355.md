But
$$\begin{aligned}
(\text{solid } AB) : (\text{solid } CV) &= \text{▱ } HE : \text{▱ } NQ, & \text{[XI. 32]} \\
\text{and}\qquad (\text{solid } CD) : (\text{solid } CV) &= \text{▱ } MQ : \text{▱ } TQ & \text{[XI. 25]} \\
&= CM : CT. & \text{[VI. 1]}
\end{aligned}$$
Therefore
$$\begin{aligned}
\text{▱ } HE : \text{▱ } NQ &= CM : CT \\
&= CM : AG.
\end{aligned}$$

Conversely (*a*), if the bases <span data-ref="0350.g1:< E H >">$EH$</span>, <span data-ref="0350.g1:< N Q >">$NQ$</span> be equal and reciprocally proportional<br />
to the heights, the heights must be equal.

Consequently
$$\text{(solid } AB\text{)} = \text{(solid } CD\text{)}. \qquad \text{[XI. 31]}$$

(*b*) If the bases <span data-ref="0350.g1:< E H >">$EH$</span>, <span data-ref="0350.g1:< N Q >">$NQ$</span> be unequal, if, e.g. ▱ <span data-ref="0350.g1:< E H >">$EH$</span> > ▱ <span data-ref="0350.g1:< N Q >">$NQ$</span>,<br />
then, since
$$\text{▱ } EH : \text{▱ } NQ = CM : AG,$$
$$CM > AG.$$

Make the same construction as before.

Then
$$\begin{aligned}
\text{▱ } EH : \text{▱ } NQ &= (\text{solid } AB) : (\text{solid } CV), & \text{[XI. 32]} \\
\text{and}\qquad CM : AG &= CM : CT \\
&= \text{▱ } MQ : \text{▱ } TQ & \text{[VI. 1]} \\
&= (\text{solid } CD) : (\text{solid } CV). & \text{[XI. 25]}
\end{aligned}$$
Therefore
$$(\text{solid } AB) : (\text{solid } CV) = (\text{solid } CD) : (\text{solid } CV),$$
whence
$$\text{(solid } AB\text{)} = \text{solid } CD. \qquad \text{[V. 9]}$$

II. Suppose that the edges terminating at the corners of the bases are not<br />
perpendicular to it.

Drop perpendiculars on the bases from the corners of the faces opposite<br />
to the bases.

We thus have two parallelepipeds equal to <span data-ref="0352.g1:< A B >">$AB$</span>, <span data-ref="0352.g1:< C D >">$CD$</span> respectively, since<br />
they are on the same bases <span data-ref="0352.g1:< F K >">$FK$</span>, <span data-ref="0352.g1:< R O >">$RO$</span> and of the same height respectively. <span class="justification">[XI. 29, 30]</span>

If then (1) the solid <span data-ref="0352.g1:< A B >">$AB$</span> is equal to the solid <span data-ref="0352.g1:< C D >">$CD$</span>,
$$\text{(solid } BT\text{)} = \text{(solid } DX\text{),}$$
and, by the first part of this proposition,
$$\text{▱ } KF : \text{▱ } OR = MX : GT,$$
or
$$\text{▱ } HE : \text{▱ } NQ = MX : GT.$$

(2) If
$$\text{▱ } HE : \text{▱ } NQ = MX : GT,$$
then
$$\text{▱ } KF : \text{▱ } OR = MX : GT,$$
so that, by the first half of the proposition, the solids <span data-ref="0352.g1:< B T >">$BT$</span>, <span data-ref="0352.g1:< D X >">$DX$</span> are equal, and<br />
consequently
$$\text{(solid } AB\text{)} = \text{(solid } CD\text{).}$$

The text of the second part of the proposition four times contains, after<br />
the words “of the same height,” the words “in which the sides which stand<br />
up are not on the same straight lines.” As Simson observed, they are inept,<br />
as the extremities of the edges may or may not be “on the same straight<br />
lines”; cf. the similar words incorrectly inserted at the end of XI. 31.

Words purporting to quote the result of the first part of the proposition<br />
are also twice inserted; but they are rejected as unnecessary and as containing<br />
an absurd expression—“(solids) in which *the heights are at right angles to their*<br />
*bases*,” as if the *heights* could be otherwise than perpendicular to the bases.
