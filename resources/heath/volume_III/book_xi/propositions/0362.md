$$\text{(solid } HL\text{)} : \text{(solid } KE\text{)} = \mathbin{▱} MN : \mathbin{▱} FD.$$ [XI. 32]

### PROPOSITION 37.

*If four straight lines be proportional, the parallelepipedal
solids on them which are similar and similarly described will
also be proportional; and, if the parallelepipedal solids on them
which are similar and similarly described be proportional, the
straight lines will themselves also be proportional.*

Let <span data-ref="0362.g1:/ A B /">$AB$</span>, <span data-ref="0362.g1:/ C D /">$CD$</span>, <span data-ref="0362.g1:/ E F /">$EF$</span>, <span data-ref="0362.g1:/ G H /">$GH$</span> be four straight lines in proportion,
so that, as <span data-ref="0362.g1:/ A B /">$AB$</span> is to <span data-ref="0362.g1:/ C D /">$CD$</span>, so is <span data-ref="0362.g1:/ E F /">$EF$</span> to <span data-ref="0362.g1:/ G H /">$GH$</span>;
and let there be described on <span data-ref="0362.g1:/ A B /">$AB$</span>, <span data-ref="0362.g1:/ C D /">$CD$</span>, <span data-ref="0362.g1:/ E F /">$EF$</span>, <span data-ref="0362.g1:/ G H /">$GH$</span> the similar
and similarly situated parallelepipedal solids <span data-ref="0362.g1:< K A >">$KA$</span>, <span data-ref="0362.g1:< L C >">$LC$</span>, <span data-ref="0362.g1:< M E >">$ME$</span>,
<span data-ref="0362.g1:< N G >">$NG$</span>;
I say that, as <span data-ref="0362.g1:< K A >">$KA$</span> is to <span data-ref="0362.g1:< L C >">$LC$</span>, so is <span data-ref="0362.g1:< M E >">$ME$</span> to <span data-ref="0362.g1:< N G >">$NG$</span>.

For, since the parallelepipedal solid <span data-ref="0362.g1:< K A >">$KA$</span> is similar to <span data-ref="0362.g1:< L C >">$LC$</span>,
therefore <span data-ref="0362.g1:< K A >">$KA$</span> has to <span data-ref="0362.g1:< L C >">$LC$</span> the ratio triplicate of that which <span data-ref="0362.g1:/ A B /">$AB$</span>
has to <span data-ref="0362.g1:/ C D /">$CD$</span>. [XI. 33]
