The edges of the parallelepiped <span data-ref="0361.g1:< H L >">$HL$</span> being respectively equal to <span data-ref="0361.g1:/ A /">$A$</span>, <span data-ref="0361.g1:/ B /">$B$</span>, <span data-ref="0361.g1:/ C /">$C$</span>,<br />
and those of the equiangular parallelepiped <span data-ref="0361.g1:< K E >">$KE$</span> being all equal to <span data-ref="0361.g1:/ B /">$B$</span>, we<br />
regard <span data-ref="0361.g1:< M N >">$MN$</span> (*not* containing the edge <span data-ref="0361.g1:/ O L /">$OL$</span> equal to <span data-ref="0361.g1:/ B /">$B$</span>) as the base of the first<br />
parallelepiped, and consequently <span data-ref="0361.g1:< F D >">$FD$</span>, equiangular to <span data-ref="0361.g1:< M N >">$MN$</span>, as the base of <span data-ref="0361.g1:< K E >">$KE$</span>.

Then the solids have the same height. [XI. 35, Por.]

Hence
$$\text{(solid } HL\text{)} : \text{(solid } KE\text{)} = \mathbin{▱} MN : \mathbin{▱} FD. \qquad \text{[XI. 32]}$$

But, since <span data-ref="0361.g1:/ A /">$A$</span>, <span data-ref="0361.g1:/ B /">$B$</span>, <span data-ref="0361.g1:/ C /">$C$</span> are in continued proportion,
$$A : B = B : C,$$
or
$$LM : EF = DE : LN.$$

Thus the sides of the equiangular ▱s <span data-ref="0361.g1:< M N >">$MN$</span>, <span data-ref="0361.g1:< F D >">$FD$</span> are reciprocally pro-<br />
portional, whence
$$\mathbin{▱} MN = \mathbin{▱} FD, \qquad \text{[VI. 14]}$$
and therefore
$$\text{(solid } HL\text{)} = \text{(solid } KE\text{)}.$$

### PROPOSITION 37.

<p class="enunciation">If four straight lines be proportional, the parallelepipedal<br />
solids on them which are similar and similarly described will<br />
also be proportional; and, if the parallelepipedal solids on them<br />
which are similar and similarly described be proportional, the<br />
straight lines will themselves also be proportional.</p>

Let <span data-ref="0362.g1:/ A B /">$AB$</span>, <span data-ref="0362.g1:/ C D /">$CD$</span>, <span data-ref="0362.g1:/ E F /">$EF$</span>, <span data-ref="0362.g1:/ G H /">$GH$</span> be four straight lines in proportion,<br />
so that, as <span data-ref="0362.g1:/ A B /">$AB$</span> is to <span data-ref="0362.g1:/ C D /">$CD$</span>, so is <span data-ref="0362.g1:/ E F /">$EF$</span> to <span data-ref="0362.g1:/ G H /">$GH$</span>;<br />
and let there be described on <span data-ref="0362.g1:/ A B /">$AB$</span>, <span data-ref="0362.g1:/ C D /">$CD$</span>, <span data-ref="0362.g1:/ E F /">$EF$</span>, <span data-ref="0362.g1:/ G H /">$GH$</span> the similar<br />
and similarly situated parallelepipedal solids <span data-ref="0362.g1:< K A >">$KA$</span>, <span data-ref="0362.g1:< L C >">$LC$</span>, <span data-ref="0362.g1:< M E >">$ME$</span>,<br />
<span data-ref="0362.g1:< N G >">$NG$</span>;<br />
I say that, as <span data-ref="0362.g1:< K A >">$KA$</span> is to <span data-ref="0362.g1:< L C >">$LC$</span>, so is <span data-ref="0362.g1:< M E >">$ME$</span> to <span data-ref="0362.g1:< N G >">$NG$</span>.

<p class="sub-clause">For, since the parallelepipedal solid <span data-ref="0362.g1:< K A >">$KA$</span> is similar to <span data-ref="0362.g1:< L C >">$LC$</span>,</p>
