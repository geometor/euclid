In this proposition it is assumed that, if two ratios be equal, the ratio<br />
triplicate of one is equal to the ratio triplicate of the other and, conversely,<br />
that, if ratios which are the triplicate of two other ratios are equal, those other<br />
ratios are themselves equal.

To avoid the necessity for these assumptions Simson adopts the alternative<br />
proof found in the MS. which Heiberg calls **b**, and also adopted by Clavius,<br />
who, however, gives Euclid's proof as well, attributing it to Theon. The<br />
alternative proof proceeds after the manner of VI. 22, thus.

I. Then, since
$$AB : CD = EF : GH,$$
we have, *ex aequali*,
$$AB : P = EF : R. \qquad \text{[V. 22]}$$
    But
$$\text{(solid } AK\text{)} : \text{(solid } CL\text{)} = AB : P, \qquad \text{[XI. 33 and Por.]}$$
and
$$\text{(solid } EM\text{)} : \text{(solid } GN\text{)} = EF : R.$$
    Therefore
$$\text{(solid } AK\text{)} : \text{(solid } CL\text{)} = \text{(solid } EM\text{)} : \text{(solid } GN\text{)}$$
