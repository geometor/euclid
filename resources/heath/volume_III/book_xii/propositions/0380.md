Suppose now, with the original notation, that
$$d^2 : {d'}^2 = X : S,$$
where $S$ is greater than $X'$.

Continue the construction of circumscribed polygons about $X'$ until the<br />
total area between the polygon and the circle is less than the difference<br />
between $S$ and $X'$, i.e. till
$$S > (\text{polygon about } X') > X'.$$

Circumscribe a similar polygon about $X$.<br />
Then
$$(\text{polygon about } X) : (\text{polygon about } X') = d^2 : {d'}^2$$
$$= X : S\text{, by hypothesis,}$$
and, alternately,
$$(\text{polygon about } X) : X = (\text{polygon about } X') : S.$$

But
$$(\text{polygon about } X) > X.$$
Therefore
$$(\text{polygon about } X') > S.$$
But
$$S > (\text{polygon about } X'):$$ <span class="justification">[above]</span>
which is impossible.

Hence $S$ cannot be *greater* than $X'$.
