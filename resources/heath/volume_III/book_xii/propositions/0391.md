Again, let the pyramids arising from the division be similarly divided,
and let this be done continually until there are left over from the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span> some pyramids which are less than the excess by which the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span> exceeds the solid <span data-ref="0390.g1:W">$W$</span>. [X. 1]

Let such be left, and let them be, for the sake of argument, <span data-ref="0390.g1:< D Q R S >">$DQRS$</span>, <span data-ref="0390.g1:< S T U H >">$STUH$</span>;
therefore the remainders, the prisms in the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span>, are greater than the solid <span data-ref="0390.g1:W">$W$</span>.

Let the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span> also be divided similarly, and a similar number of times, with the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span>;
therefore, as the base <span data-ref="0390.g1:< A B C >">$ABC$</span> is to the base <span data-ref="0390.g1:< D E F >">$DEF$</span>, so are the prisms in the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span> to the prisms in the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span>. [XII. 4]

But, as the base <span data-ref="0390.g1:< A B C >">$ABC$</span> is to the base <span data-ref="0390.g1:< D E F >">$DEF$</span>, so also is the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span> to the solid <span data-ref="0390.g1:W">$W$</span>;
therefore also, as the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span> is to the solid <span data-ref="0390.g1:W">$W$</span>, so are the prisms in the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span> to the prisms in the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span>; [V. 11]
therefore, alternately, as the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span> is to the prisms in it, so is the solid <span data-ref="0390.g1:W">$W$</span> to the prisms in the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span>. [V. 16]

But the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span> is greater than the prisms in it;
therefore the solid <span data-ref="0390.g1:W">$W$</span> is also greater than the prisms in the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span>.

But it is also less:
which is impossible.

Therefore the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span> is not to any solid less than the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span> as the base <span data-ref="0390.g1:< A B C >">$ABC$</span> is to the base <span data-ref="0390.g1:< D E F >">$DEF$</span>.

Similarly it can be proved that neither is the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span> to any solid less than the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span> as the base <span data-ref="0390.g1:< D E F >">$DEF$</span> is to the base <span data-ref="0390.g1:< A B C >">$ABC$</span>.

I say next that neither is the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span> to any solid greater than the pyramid <span data-ref="0390.g1:< D E F H >">$DEFH$</span> as the base <span data-ref="0390.g1:< A B C >">$ABC$</span> is to the base <span data-ref="0390.g1:< D E F >">$DEF$</span>.

For, if possible, let it be in that ratio to a greater solid <span data-ref="0390.g1:W">$W$</span>;
therefore, inversely, as the base <span data-ref="0390.g1:< D E F >">$DEF$</span> is to the base <span data-ref="0390.g1:< A B C >">$ABC$</span>, so is the solid <span data-ref="0390.g1:W">$W$</span> to the pyramid <span data-ref="0390.g1:< A B C G >">$ABCG$</span>.
