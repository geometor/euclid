In the two preceding propositions it has been shown how we can divide a<br />
pyramid with a triangular base into (1) two equal prisms which are together<br />
greater than half the pyramid and (2) two equal pyramids similar to the<br />
original one, and that, if this process be continued with the two pyramids,<br />
then with the four resulting pyramids, and so on, and if, further, another<br />
pyramid of the same height as the original one be similarly divided, the sub-<br />
division being made the same number of times, the sum of all the prisms in<br />
one pyramid is to the sum of all the prisms in the other as the base of the<br />
first is to the base of the second.

We can now prove in the manner of XII. 2 that the volumes of the<br />
pyramids themselves are as the bases.

Let us call the pyramids $P$, $P'$ and their respective bases $B$, $B'$.<br />
If
$$P : P' \neq B : B'\text{,}$$
suppose that
$$B : B' = P : W.$$

I. Let $W$ be $< P'$.<br />
Divide $P'$ into two prisms and two pyramids, subdivide the latter similarly,<br />
and so on, until the sum of the pyramids remaining is less than the difference<br />
between $P'$ and $W$ [X. 1], so that
$$P' > (\text{prisms in } P') > W.$$

Then divide $P$ similarly, the same number of times.<br />
Now
$$(\text{prisms in } P) : (\text{prisms in } P') = B : B' \quad \text{[XII. 4]}$$
$$= P : W\text{, by hypothesis,}$$
and, alternately,
$$(\text{prisms in } P) : P = (\text{prisms in } P') : W.$$

But
$$(\text{prisms in } P) < P\text{;}$$
therefore
$$(\text{prisms in } P') < W.$$

But, by construction,
$$(\text{prisms in } P') > W.$$

Hence $W$ cannot be less than $P'$.
