### PROPOSITION 6.

<p class="enunciation">Pyramids which are of the same height and have polygonal<br />
bases are to one another as the bases.</p>

Let there be pyramids of the same height of which the<br />
polygons <span data-ref="0396.g1:< A B C D E >">$ABCDE$</span>, <span data-ref="0396.g1:< F G H K L >">$FGHKL$</span> are the bases and the points<br />
<span data-ref="0396.g1:M">$M$</span>, <span data-ref="0396.g1:N">$N$</span> the vertices;<br />
I say that, as the base <span data-ref="0396.g1:< A B C D E >">$ABCDE$</span> is to the base <span data-ref="0396.g1:< F G H K L >">$FGHKL$</span>,<br />
so is the pyramid <span data-ref="0396.g1:< A B C D E M >">$ABCDEM$</span> to the pyramid <span data-ref="0396.g1:< F G H K L N >">$FGHKLN$</span>.

![Proposition 6](0396.g1.svg)

For let <span data-ref="0396.g1:/ A C /">$AC$</span>, <span data-ref="0396.g1:/ A D /">$AD$</span>, <span data-ref="0396.g1:/ F H /">$FH$</span>, <span data-ref="0396.g1:/ F K /">$FK$</span> be joined.

Since then <span data-ref="0396.g1:< A B C M >">$ABCM$</span>, <span data-ref="0396.g1:< A C D M >">$ACDM$</span> are two pyramids which have<br />
triangular bases and equal height,<br />
they are to one another as the bases; <span class="justification">[XII. 5]</span>
<p class="assertion">therefore, as the base <span data-ref="0396.g1:< A B C >">$ABC$</span> is to the base <span data-ref="0396.g1:< A C D >">$ACD$</span>, so is the<br />
pyramid <span data-ref="0396.g1:< A B C M >">$ABCM$</span> to the pyramid <span data-ref="0396.g1:< A C D M >">$ACDM$</span>.</p>

<p class="assertion">And, *componendo*, as the base <span data-ref="0396.g1:< A B C D >">$ABCD$</span> is to the base <span data-ref="0396.g1:< A C D >">$ACD$</span>,<br />
so is the pyramid <span data-ref="0396.g1:< A B C D M >">$ABCDM$</span> to the pyramid <span data-ref="0396.g1:< A C D M >">$ACDM$</span>. <span class="justification">[V. 18]</span></p>

But also, as the base <span data-ref="0396.g1:< A C D >">$ACD$</span> is to the base <span data-ref="0396.g1:< A D E >">$ADE$</span>, so is the<br />
pyramid <span data-ref="0396.g1:< A C D M >">$ACDM$</span> to the pyramid <span data-ref="0396.g1:< A D E M >">$ADEM$</span>. <span class="justification">[XII. 5]</span>
<p class="assertion">Therefore, *ex aequali*, as the base <span data-ref="0396.g1:< A B C D >">$ABCD$</span> is to the base<br />
<span data-ref="0396.g1:< A D E >">$ADE$</span>, so is the pyramid <span data-ref="0396.g1:< A B C D M >">$ABCDM$</span> to the pyramid <span data-ref="0396.g1:< A D E M >">$ADEM$</span>.<br />
<span class="justification">[V. 22]</span></p>

<p class="assertion">And again *componendo*, as the base <span data-ref="0396.g1:< A B C D E >">$ABCDE$</span> is to the<br />
base <span data-ref="0396.g1:< A D E >">$ADE$</span>, so is the pyramid <span data-ref="0396.g1:< A B C D E M >">$ABCDEM$</span> to the pyramid<br />
<span data-ref="0396.g1:< A D E M >">$ADEM$</span>. <span class="justification">[V. 18]</span></p>

Similarly also it can be proved that, as the base <span data-ref="0396.g1:< F G H K L >">$FGHKL$</span><br />
is to the base <span data-ref="0396.g1:< F G H >">$FGH$</span>, so is the pyramid <span data-ref="0396.g1:< F G H K L N >">$FGHKLN$</span> to the<br />
pyramid <span data-ref="0396.g1:< F G H N >">$FGHN$</span>.
