### PROPOSITION 6.

*Pyramids which are of the same height and have polygonal bases are to one another as the bases.*

Let there be pyramids of the same height of which the polygons <span data-ref="0396.g1:< A B C D E >">$ABCDE$</span>, <span data-ref="0396.g1:< F G H K L >">$FGHKL$</span> are the bases and the points <span data-ref="0396.g1:M">$M$</span>, <span data-ref="0396.g1:N">$N$</span> the vertices;
I say that, as the base <span data-ref="0396.g1:< A B C D E >">$ABCDE$</span> is to the base <span data-ref="0396.g1:< F G H K L >">$FGHKL$</span>, so is the pyramid <span data-ref="0396.g1:< A B C D E M >">$ABCDEM$</span> to the pyramid <span data-ref="0396.g1:< F G H K L N >">$FGHKLN$</span>.

![Proposition 6](0396.g1.svg)

For let <span data-ref="0396.g1:/ A C /">$AC$</span>, <span data-ref="0396.g1:/ A D /">$AD$</span>, <span data-ref="0396.g1:/ F H /">$FH$</span>, <span data-ref="0396.g1:/ F K /">$FK$</span> be joined.

Since then <span data-ref="0396.g1:< A B C M >">$ABCM$</span>, <span data-ref="0396.g1:< A C D M >">$ACDM$</span> are two pyramids which have triangular bases and equal height,
they are to one another as the bases; [XII. 5]
therefore, as the base <span data-ref="0396.g1:< A B C >">$ABC$</span> is to the base <span data-ref="0396.g1:< A C D >">$ACD$</span>, so is the pyramid <span data-ref="0396.g1:< A B C M >">$ABCM$</span> to the pyramid <span data-ref="0396.g1:< A C D M >">$ACDM$</span>.

And, *componendo*, as the base <span data-ref="0396.g1:< A B C D >">$ABCD$</span> is to the base <span data-ref="0396.g1:< A C D >">$ACD$</span>, so is the pyramid <span data-ref="0396.g1:< A B C D M >">$ABCDM$</span> to the pyramid <span data-ref="0396.g1:< A C D M >">$ACDM$</span>. [V. 18]

But also, as the base <span data-ref="0396.g1:< A C D >">$ACD$</span> is to the base <span data-ref="0396.g1:< A D E >">$ADE$</span>, so is the pyramid <span data-ref="0396.g1:< A C D M >">$ACDM$</span> to the pyramid <span data-ref="0396.g1:< A D E M >">$ADEM$</span>. [XII. 5]

Therefore, *ex aequali*, as the base <span data-ref="0396.g1:< A B C D >">$ABCD$</span> is to the base <span data-ref="0396.g1:< A D E >">$ADE$</span>, so is the pyramid <span data-ref="0396.g1:< A B C D M >">$ABCDM$</span> to the pyramid <span data-ref="0396.g1:< A D E M >">$ADEM$</span>. [V. 22]

And again *componendo*, as the base <span data-ref="0396.g1:< A B C D E >">$ABCDE$</span> is to the base <span data-ref="0396.g1:< A D E >">$ADE$</span>, so is the pyramid <span data-ref="0396.g1:< A B C D E M >">$ABCDEM$</span> to the pyramid <span data-ref="0396.g1:< A D E M >">$ADEM$</span>. [V. 18]

Similarly also it can be proved that, as the base <span data-ref="0396.g1:< F G H K L >">$FGHKL$</span> is to the base <span data-ref="0396.g1:< F G H >">$FGH$</span>, so is the pyramid <span data-ref="0396.g1:< F G H K L N >">$FGHKLN$</span> to the pyramid <span data-ref="0396.g1:< F G H N >">$FGHN$</span>.
