  $$(a_1 + a_2 + \dots + a_n) : b = (A_1 + A_2 + \dots + A_n) : B.$$

  - Recombines with $\triangle ADE : \triangle FGH$ and the inverted ratio for the second pyramid to conclude via *ex aequali* in a single stroke.
