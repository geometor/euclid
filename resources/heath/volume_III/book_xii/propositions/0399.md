If we denote by <span data-ref="0398.g1:< C A B D >">$C\text{-}ABD$</span> a pyramid with vertex <span data-ref="0398.g1:C">$C$</span> and base <span data-ref="0398.g1:< A B D >">$ABD$</span>, Euclid's argument is easily followed thus.

The $\square$<span data-ref="0398.g1:< A B E D >">$ABED$</span> being bisected by <span data-ref="0398.g1:/ B D /">$BD$</span>,
(pyramid <span data-ref="0398.g1:< C A B D >">$C\text{-}ABD$</span>) $=$ (pyramid <span data-ref="0398.g1:< C D E B >">$C\text{-}DEB$</span>) <span class="justification">[XII. 5]</span>
$\equiv$ (pyramid <span data-ref="0398.g1:< D E B C >">$D\text{-}EBC$</span>).

And, the $\square$<span data-ref="0398.g1:< E B C F >">$EBCF$</span> being bisected by <span data-ref="0398.g1:/ E C /">$EC$</span>,
(pyramid <span data-ref="0398.g1:< D E B C >">$D\text{-}EBC$</span>) $=$ (pyramid <span data-ref="0398.g1:< D E C F >">$D\text{-}ECF$</span>).

Thus (pyramid <span data-ref="0398.g1:< C A B D >">$C\text{-}ABD$</span>) $=$ (pyramid <span data-ref="0398.g1:< D E B C >">$D\text{-}EBC$</span>) $=$ (pyramid <span data-ref="0398.g1:< D E C F >">$D\text{-}ECF$</span>), and these three pyramids make up the whole prism, so that each is one-third of the prism.

And, since (pyramid <span data-ref="0398.g1:< C A B D >">$C\text{-}ABD$</span>) $\equiv$ (pyramid <span data-ref="0398.g1:< D A B C >">$D\text{-}ABC$</span>),
(pyramid <span data-ref="0398.g1:< D A B C >">$D\text{-}ABC$</span>) $= \frac{1}{3}$ (prism <span data-ref="0398.g1:< A B C >">$ABC$</span>, <span data-ref="0398.g1:< D E F >">$DEF$</span>).
