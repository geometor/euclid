But the height of the solid <span data-ref="0402.g1:< E H Q P >">$EHQP$</span> is the same with the height of the pyramid <span data-ref="0402.g1:< D E F H >">$DEFH$</span>, and the height of the solid <span data-ref="0402.g1:< B G M L >">$BGML$</span> is the same with the height of the pyramid <span data-ref="0402.g1:< A B C G >">$ABCG$</span>, therefore, as the base <span data-ref="0402.g1:< A B C >">$ABC$</span> is to the base <span data-ref="0402.g1:< D E F >">$DEF$</span>, so is the height of the pyramid <span data-ref="0402.g1:< D E F H >">$DEFH$</span> to the height of the pyramid <span data-ref="0402.g1:< A B C G >">$ABCG$</span>.

Therefore in the pyramids <span data-ref="0402.g1:< A B C G >">$ABCG$</span>, <span data-ref="0402.g1:< D E F H >">$DEFH$</span> the bases are reciprocally proportional to the heights.

Next, in the pyramids <span data-ref="0402.g1:< A B C G >">$ABCG$</span>, <span data-ref="0402.g1:< D E F H >">$DEFH$</span> let the bases be reciprocally proportional to the heights;
that is, as the base <span data-ref="0402.g1:< A B C >">$ABC$</span> is to the base <span data-ref="0402.g1:< D E F >">$DEF$</span>, so let the height of the pyramid <span data-ref="0402.g1:< D E F H >">$DEFH$</span> be to the height of the pyramid <span data-ref="0402.g1:< A B C G >">$ABCG$</span>;
I say that the pyramid <span data-ref="0402.g1:< A B C G >">$ABCG$</span> is equal to the pyramid <span data-ref="0402.g1:< D E F H >">$DEFH$</span>.

For, with the same construction, since, as the base <span data-ref="0402.g1:< A B C >">$ABC$</span> is to the base <span data-ref="0402.g1:< D E F >">$DEF$</span>, so is the height of the pyramid <span data-ref="0402.g1:< D E F H >">$DEFH$</span> to the height of the pyramid <span data-ref="0402.g1:< A B C G >">$ABCG$</span>, while, as the base <span data-ref="0402.g1:< A B C >">$ABC$</span> is to the base <span data-ref="0402.g1:< D E F >">$DEF$</span>, so is the parallelogram <span data-ref="0402.g1:< B C M A >">$BM$</span> to the parallelogram <span data-ref="0402.g1:< E F Q D >">$EQ$</span>, therefore also, as the parallelogram <span data-ref="0402.g1:< B C M A >">$BM$</span> is to the parallelogram <span data-ref="0402.g1:< E F Q D >">$EQ$</span>, so is the height of the pyramid <span data-ref="0402.g1:< D E F H >">$DEFH$</span> to the height of the pyramid <span data-ref="0402.g1:< A B C G >">$ABCG$</span>. [V. 11]

But the height of the pyramid <span data-ref="0402.g1:< D E F H >">$DEFH$</span> is the same with the height of the parallelepiped <span data-ref="0402.g1:< E H Q P >">$EHQP$</span>, and the height of the pyramid <span data-ref="0402.g1:< A B C G >">$ABCG$</span> is the same with the height of the parallelepiped <span data-ref="0402.g1:< B G M L >">$BGML$</span>;
therefore, as the base <span data-ref="0402.g1:< B C M A >">$BM$</span> is to the base <span data-ref="0402.g1:< E F Q D >">$EQ$</span>, so is the height of the parallelepiped <span data-ref="0402.g1:< E H Q P >">$EHQP$</span> to the height of the parallelepiped <span data-ref="0402.g1:< B G M L >">$BGML$</span>.

But those parallelepipedal solids in which the bases are reciprocally proportional to the heights are equal; [XI. 34]
therefore the parallelepipedal solid <span data-ref="0402.g1:< B G M L >">$BGML$</span> is equal to the parallelepipedal solid <span data-ref="0402.g1:< E H Q P >">$EHQP$</span>.

And the pyramid <span data-ref="0402.g1:< A B C G >">$ABCG$</span> is a sixth part of <span data-ref="0402.g1:< B G M L >">$BGML$</span>, and the pyramid <span data-ref="0402.g1:< D E F H >">$DEFH$</span> a sixth part of the parallelepiped <span data-ref="0402.g1:< E H Q P >">$EHQP$</span>;
