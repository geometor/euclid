- **Converse Proof Logic**:

  - Given $\text{base } ABC : \text{base } DEF = \text{height}(DEFH) : \text{height}(ABCG)$.
  - Parallelograms $BM, EQ$ have the same ratio as $\triangle ABC : \triangle DEF$.
  - Therefore $\text{base } BM : \text{base } EQ = \text{height}(EHQP) : \text{height}(BGML)$.
  - By XI. 34 (converse part), parallelepipeds with reciprocally proportional bases and heights are equal: $BGML = EHQP$.
  - Since pyramids are one-sixth of their respective parallelepipeds, equality of the pyramids follows immediately on page 400.
