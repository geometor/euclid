.. assertion::

   therefore also the prism set up on the square :g:`ABCD <0404.g1:< A B C D >>` is half of the prism set up from the square circumscribed about the circle :g:`ABCD <0404.g1:( A B C D )>` ; :just:`[cf. XI. 28, or XII. 6 and 7, Por.]`

.. subclause::

   and the cylinder is less than the prism set up from the square circumscribed about the circle :g:`ABCD <0404.g1:( A B C D )>` ;

.. assertion::

   therefore the prism set up from the square :g:`ABCD <0404.g1:< A B C D >>` and of equal height with the cylinder is greater than the half of the cylinder.
