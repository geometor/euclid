:proposition: 10

.. subclause::

   about the circle, the square :g:`$ABCD$ <0404.g1:< A B C D >>` will be half of the square circumscribed about the circle, and if we set up from the squares parallelepipedal solids of equal height with the cone, which are also called prisms, the solid set up from the square :g:`$ABCD$ <0404.g1:< A B C D >>` will be half of that set up from the square circumscribed about the circle ; for they are to one another as their bases. :just:`[XI. 32] <XI.32>`

.. subclause::

   Hence also the thirds of them are in that ratio ;

.. assertion::

   therefore also the pyramid of which the square :g:`$ABCD$ <0404.g1:< A B C D >>` is the base is half of the pyramid set up from the square circumscribed about the circle.

.. subclause::

   And the pyramid set up from the square about the circle is greater than the cone, for it encloses it.

.. assertion::

   Therefore the pyramid of which the square :g:`$ABCD$ <0404.g1:< A B C D >>` is the base and the vertex is the same with that of the cone is greater than the half of the cone.

Let the circumferences :g:`$AB$ <0404.g1:( A E B )>`, :g:`$BC$ <0404.g1:( B F C )>`, :g:`$CD$ <0404.g1:( C G D )>`, :g:`$DA$ <0404.g1:( D H A )>` be bisected at the points :g:`$E$ <0404.g1:E>`, :g:`$F$ <0404.g1:F>`, :g:`$G$ <0404.g1:G>`, :g:`$H$ <0404.g1:H>`, and let :g:`$AE$ <0404.g1:/ A E />`, :g:`$EB$ <0404.g1:/ E B />`, :g:`$BF$ <0404.g1:/ B F />`, :g:`$FC$ <0404.g1:/ F C />`, :g:`$CG$ <0404.g1:/ C G />`, :g:`$GD$ <0404.g1:/ G D />`, :g:`$DH$ <0404.g1:/ D H />`, :g:`$HA$ <0404.g1:/ H A />` be joined ;

.. assertion::

   therefore also each of the triangles :g:`$AEB$ <0404.g1:< A E B >>`, :g:`$BFC$ <0404.g1:< B F C >>`, :g:`$CGD$ <0404.g1:< C G D >>`, :g:`$DHA$ <0404.g1:< D H A >>` is greater than the half part of that segment of the circle :g:`$ABCD$ <0404.g1:( A B C D )>` which is about it.

Now, on each of the triangles :g:`$AEB$ <0404.g1:< A E B >>`, :g:`$BFC$ <0404.g1:< B F C >>`, :g:`$CGD$ <0404.g1:< C G D >>`, :g:`$DHA$ <0404.g1:< D H A >>` let pyramids be set up which have the same vertex as the cone ;

.. assertion::

   therefore also each of the pyramids so set up is, in the same manner, greater than the half part of that segment of the cone which is about it.

Thus, by bisecting the circumferences that are left, joining straight lines, setting up on each of the triangles a pyramid which has the same vertex as the cone, and doing this continually, we shall leave some segments of the cone which will be less than the excess by which the cone exceeds the third part of the cylinder. :just:`[X. 1] <X.1>`

Let such be left, and let them be the segments on :g:`$AE$ <0404.g1:/ A E />`, :g:`$EB$ <0404.g1:/ E B />`, :g:`$BF$ <0404.g1:/ B F />`, :g:`$FC$ <0404.g1:/ F C />`, :g:`$CG$ <0404.g1:/ C G />`, :g:`$GD$ <0404.g1:/ G D />`, :g:`$DH$ <0404.g1:/ D H />`, :g:`$HA$ <0404.g1:/ H A />` ;
