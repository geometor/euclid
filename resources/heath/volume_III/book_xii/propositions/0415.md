Let the circumferences <span data-ref="0414.g1:( E P F )">$EF$</span>, <span data-ref="0414.g1:( F Q G )">$FG$</span>, <span data-ref="0414.g1:( G R H )">$GH$</span>, <span data-ref="0414.g1:( H S E )">$HE$</span> be bisected at the points <span data-ref="0414.g1:P">$P$</span>, <span data-ref="0414.g1:Q">$Q$</span>, <span data-ref="0414.g1:R">$R$</span>, <span data-ref="0414.g1:S">$S$</span>,
and let <span data-ref="0414.g1:/ E P /">$EP$</span>, <span data-ref="0414.g1:/ P F /">$PF$</span>, <span data-ref="0414.g1:/ F Q /">$FQ$</span>, <span data-ref="0414.g1:/ Q G /">$QG$</span>, <span data-ref="0414.g1:/ G R /">$GR$</span>, <span data-ref="0414.g1:/ R H /">$RH$</span>, <span data-ref="0414.g1:/ H S /">$HS$</span>, <span data-ref="0414.g1:/ S E /">$SE$</span> be joined.

Therefore each of the triangles <span data-ref="0414.g1:< E P F >">$EPF$</span>, <span data-ref="0414.g1:< F Q G >">$FQG$</span>, <span data-ref="0414.g1:< G R H >">$GRH$</span>, <span data-ref="0414.g1:< H S E >">$HSE$</span> is also greater than the half part of that segment of the circle <span data-ref="0414.g1:( E F G H )">$EFGH$</span> which is about it.

Now on each of the triangles <span data-ref="0414.g1:< E P F >">$EPF$</span>, <span data-ref="0414.g1:< F Q G >">$FQG$</span>, <span data-ref="0414.g1:< G R H >">$GRH$</span>, <span data-ref="0414.g1:< H S E >">$HSE$</span> let a pyramid be set up having the same vertex with the cone;
therefore each of the pyramids so set up is also greater than the half part of that segment of the cone which is about it.

Thus, bisecting the circumferences so left, joining straight lines, setting up on each of the triangles pyramids having the same vertex with the cone,
and doing this continually,
we shall leave some segments of the cone which will be less than the excess by which the cone <span data-ref="0414.g1:< E F G H N >">$EFGHN$</span> exceeds the solid <span data-ref="0414.g1:O">$O$</span>. [^411_1]

Let such be left, and let them be the segments on <span data-ref="0414.g1:/ E P /">$EP$</span>, <span data-ref="0414.g1:/ P F /">$PF$</span>, <span data-ref="0414.g1:/ F Q /">$FQ$</span>, <span data-ref="0414.g1:/ Q G /">$QG$</span>, <span data-ref="0414.g1:/ G R /">$GR$</span>, <span data-ref="0414.g1:/ R H /">$RH$</span>, <span data-ref="0414.g1:/ H S /">$HS$</span>, <span data-ref="0414.g1:/ S E /">$SE$</span>;
therefore the remainder, the pyramid of which the polygon <span data-ref="0414.g1:< E P F Q G R H S >">$EPFQGRHS$</span> is the base and the point <span data-ref="0414.g1:N">$N$</span> the vertex, is greater than the solid <span data-ref="0414.g1:O">$O$</span>.

Let there be also inscribed in the circle <span data-ref="0414.g1:( A B C D )">$ABCD$</span> the polygon <span data-ref="0414.g1:< A T B U C V D W >">$ATBUCVDW$</span> similar and similarly situated to the polygon <span data-ref="0414.g1:< E P F Q G R H S >">$EPFQGRHS$</span>,
and let there be set up on the polygon <span data-ref="0414.g1:< A T B U C V D W >">$ATBUCVDW$</span> a pyramid having the same vertex with the cone;
of the triangles containing the pyramid of which the polygon <span data-ref="0414.g1:< A T B U C V D W >">$ATBUCVDW$</span> is the base and the point <span data-ref="0414.g1:L">$L$</span> the vertex let <span data-ref="0414.g1:< L B T >">$LBT$</span> be one,
and of the triangles containing the pyramid of which the polygon <span data-ref="0414.g1:< E P F Q G R H S >">$EPFQGRHS$</span> is the base and the point <span data-ref="0414.g1:N">$N$</span> the vertex let <span data-ref="0414.g1:< N F P >">$NFP$</span> be one;
and let <span data-ref="0414.g1:/ K T /">$KT$</span>, <span data-ref="0414.g1:/ M P /">$MP$</span> be joined.

Now, since the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span> is similar to the cone <span data-ref="0414.g1:< E F G H N >">$EFGHN$</span>,
therefore, as <span data-ref="0414.g1:/ B D /">$BD$</span> is to <span data-ref="0414.g1:/ F H /">$FH$</span>, so is the axis <span data-ref="0414.g1:/ K L /">$KL$</span> to the axis <span data-ref="0414.g1:/ M N /">$MN$</span>. [^411_2]
