But it was also proved that, as <span data-ref="0414.g1:/ T B /">$TB$</span> is to <span data-ref="0414.g1:/ B L /">$BL$</span>, so is <span data-ref="0414.g1:/ P F /">$PF$</span> to <span data-ref="0414.g1:/ F N /">$FN$</span>.

Therefore, *ex aequali*, as <span data-ref="0414.g1:/ T L /">$TL$</span> is to <span data-ref="0414.g1:/ L B /">$LB$</span>, so is <span data-ref="0414.g1:/ P N /">$PN$</span> to <span data-ref="0414.g1:/ N F /">$NF$</span>. [^413_1]

Therefore in the triangles <span data-ref="0414.g1:< L T B >">$LTB$</span>, <span data-ref="0414.g1:< N P F >">$NPF$</span> the sides are proportional;
therefore the triangles <span data-ref="0414.g1:< L T B >">$LTB$</span>, <span data-ref="0414.g1:< N P F >">$NPF$</span> are equiangular; [^413_2]
hence they are also similar. [^413_3]

Therefore the pyramid of which the triangle <span data-ref="0414.g1:< B K T >">$BKT$</span> is the base and the point <span data-ref="0414.g1:L">$L$</span> the vertex is also similar to the pyramid of which the triangle <span data-ref="0414.g1:< F M P >">$FMP$</span> is the base and the point <span data-ref="0414.g1:N">$N$</span> the vertex,
for they are contained by similar planes equal in multitude. [^413_4]

But similar pyramids which have triangular bases are to one another in the triplicate ratio of their corresponding sides. [^413_5]

Therefore the pyramid <span data-ref="0414.g1:< B K T L >">$BKTL$</span> has to the pyramid <span data-ref="0414.g1:< F M P N >">$FMPN$</span> the ratio triplicate of that which <span data-ref="0414.g1:/ B K /">$BK$</span> has to <span data-ref="0414.g1:/ F M /">$FM$</span>.

Similarly, by joining straight lines from <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:W">$W$</span>, <span data-ref="0414.g1:D">$D$</span>, <span data-ref="0414.g1:V">$V$</span>, <span data-ref="0414.g1:C">$C$</span>, <span data-ref="0414.g1:U">$U$</span> to <span data-ref="0414.g1:K">$K$</span>, and from <span data-ref="0414.g1:E">$E$</span>, <span data-ref="0414.g1:S">$S$</span>, <span data-ref="0414.g1:H">$H$</span>, <span data-ref="0414.g1:R">$R$</span>, <span data-ref="0414.g1:G">$G$</span>, <span data-ref="0414.g1:Q">$Q$</span> to <span data-ref="0414.g1:M">$M$</span>, and setting up on each of the triangles pyramids which have the same vertex with the cones,
we can prove that each of the similarly arranged pyramids will also have to each similarly arranged pyramid the ratio triplicate of that which the corresponding side <span data-ref="0414.g1:/ B K /">$BK$</span> has to the corresponding side <span data-ref="0414.g1:/ F M /">$FM$</span>, that is, which <span data-ref="0414.g1:/ B D /">$BD$</span> has to <span data-ref="0414.g1:/ F H /">$FH$</span>.

And, as one of the antecedents is to one of the consequents, so are all the antecedents to all the consequents; [^413_6]
therefore also, as the pyramid <span data-ref="0414.g1:< B K T L >">$BKTL$</span> is to the pyramid <span data-ref="0414.g1:< F M P N >">$FMPN$</span>, so is the whole pyramid of which the polygon <span data-ref="0414.g1:< A T B U C V D W >">$ATBUCVDW$</span> is the base and the point <span data-ref="0414.g1:L">$L$</span> the vertex to the whole pyramid of which the polygon <span data-ref="0414.g1:< E P F Q G R H S >">$EPFQGRHS$</span> is the base and the point <span data-ref="0414.g1:N">$N$</span> the vertex;
hence also the pyramid of which <span data-ref="0414.g1:< A T B U C V D W >">$ATBUCVDW$</span> is the base and the point <span data-ref="0414.g1:L">$L$</span> the vertex has to the pyramid of which the polygon <span data-ref="0414.g1:< E P F Q G R H S >">$EPFQGRHS$</span> is the base and the point <span data-ref="0414.g1:N">$N$</span> the vertex the ratio triplicate of that which <span data-ref="0414.g1:/ B D /">$BD$</span> has to <span data-ref="0414.g1:/ F H /">$FH$</span>.
