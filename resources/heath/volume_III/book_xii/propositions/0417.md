<p class="sub-clause">But it was also proved that, as <span data-ref="0414.g1:/ T B /">$TB$</span> is to <span data-ref="0414.g1:/ B L /">$BL$</span>, so is <span data-ref="0414.g1:/ P F /">$PF$</span><br />
to <span data-ref="0414.g1:/ F N /">$FN$</span>.</p>

<p class="assertion">Therefore, <em>ex aequali</em>, as <span data-ref="0414.g1:/ T L /">$TL$</span> is to <span data-ref="0414.g1:/ L B /">$LB$</span>, so is <span data-ref="0414.g1:/ P N /">$PN$</span> to <span data-ref="0414.g1:/ N F /">$NF$</span>.<br />
<span class="justification">[V. 22]</span></p>

<p class="assertion">Therefore in the triangles <span data-ref="0414.g1:< L T B >">$LTB$</span>, <span data-ref="0414.g1:< N P F >">$NPF$</span> the sides are<br />
proportional ;<br />
therefore the triangles <span data-ref="0414.g1:< L T B >">$LTB$</span>, <span data-ref="0414.g1:< N P F >">$NPF$</span> are equiangular ; <span class="justification">[VI. 5]</span><br />
hence they are also similar. <span class="justification">[VI. Def. 1]</span></p>

<p class="assertion">Therefore the pyramid of which the triangle <span data-ref="0414.g1:< B K T >">$BKT$</span> is the<br />
base and the point <span data-ref="0414.g1:L">$L$</span> the vertex is also similar to the pyramid<br />
of which the triangle <span data-ref="0414.g1:< F M P >">$FMP$</span> is the base and the point <span data-ref="0414.g1:N">$N$</span> the<br />
vertex,<br />
for they are contained by similar planes equal in multitude.<br />
<span class="justification">[XI. Def. 9]</span></p>

<p class="sub-clause">But similar pyramids which have triangular bases are to<br />
one another in the triplicate ratio of their corresponding sides.<br />
<span class="justification">[XII. 8]</span></p>

<p class="assertion">Therefore the pyramid <span data-ref="0414.g1:< B K T L >">$BKTL$</span> has to the pyramid <span data-ref="0414.g1:< F M P N >">$FMPN$</span><br />
the ratio triplicate of that which <span data-ref="0414.g1:/ B K /">$BK$</span> has to <span data-ref="0414.g1:/ F M /">$FM$</span>.</p>

<p class="assertion">Similarly, by joining straight lines from <span data-ref="0414.g1:A">$A$</span>, <span data-ref="0414.g1:W">$W$</span>, <span data-ref="0414.g1:D">$D$</span>, <span data-ref="0414.g1:V">$V$</span>, <span data-ref="0414.g1:C">$C$</span>, <span data-ref="0414.g1:U">$U$</span><br />

each of the triangles pyramids which have the same vertex<br />
with the cones,<br />
we can prove that each of the similarly arranged pyramids<br />
will also have to each similarly arranged pyramid the ratio<br />
triplicate of that which the corresponding side <span data-ref="0414.g1:/ B K /">$BK$</span> has to the<br />
corresponding side <span data-ref="0414.g1:/ F M /">$FM$</span>, that is, which <span data-ref="0414.g1:/ B D /">$BD$</span> has to <span data-ref="0414.g1:/ F H /">$FH$</span>.</p>
