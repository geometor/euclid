But the said cone is greater than the pyramid in it;
for it encloses it.

Therefore the solid <span data-ref="0414.g1:O">$O$</span> is also greater than the pyramid of which the polygon <span data-ref="0414.g1:< E P F Q G R H S >">$EPFQGRHS$</span> is the base and <span data-ref="0414.g1:N">$N$</span> the vertex.

But it is also less:
which is impossible.

Therefore the cone of which the circle <span data-ref="0414.g1:( A B C D )">$ABCD$</span> is the base and <span data-ref="0414.g1:L">$L$</span> the vertex has not to any solid less than the cone of which the circle <span data-ref="0414.g1:( E F G H )">$EFGH$</span> is the base and the point <span data-ref="0414.g1:N">$N$</span> the vertex the ratio triplicate of that which <span data-ref="0414.g1:/ B D /">$BD$</span> has to <span data-ref="0414.g1:/ F H /">$FH$</span>.

Similarly we can prove that neither has the cone <span data-ref="0414.g1:< E F G H N >">$EFGHN$</span> to any solid less than the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span> the ratio triplicate of that which <span data-ref="0414.g1:/ F H /">$FH$</span> has to <span data-ref="0414.g1:/ B D /">$BD$</span>.

I say next that neither has the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span> to any solid greater than the cone <span data-ref="0414.g1:< E F G H N >">$EFGHN$</span> the ratio triplicate of that which <span data-ref="0414.g1:/ B D /">$BD$</span> has to <span data-ref="0414.g1:/ F H /">$FH$</span>.

For, if possible, let it have that ratio to a greater solid <span data-ref="0414.g1:O">$O$</span>.

Therefore, inversely, the solid <span data-ref="0414.g1:O">$O$</span> has to the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span> the ratio triplicate of that which <span data-ref="0414.g1:/ F H /">$FH$</span> has to <span data-ref="0414.g1:/ B D /">$BD$</span>.

But, as the solid <span data-ref="0414.g1:O">$O$</span> is to the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span>, so is the cone <span data-ref="0414.g1:< E F G H N >">$EFGHN$</span> to some solid less than the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span>.

Therefore the cone <span data-ref="0414.g1:< E F G H N >">$EFGHN$</span> also has to some solid less than the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span> the ratio triplicate of that which <span data-ref="0414.g1:/ F H /">$FH$</span> has to <span data-ref="0414.g1:/ B D /">$BD$</span>:
which was proved impossible.
