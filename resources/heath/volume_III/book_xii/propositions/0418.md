<p class="sub-clause">is the base and the point <span data-ref="0414.g1:L">$L$</span> the vertex has also to the solid<br />
<span data-ref="0414.g1:O">$O$</span> the ratio triplicate of that which <span data-ref="0414.g1:/ B D /">$BD$</span> has to <span data-ref="0414.g1:/ F H /">$FH$</span>;</p>
<p class="assertion">therefore, as the cone of which the circle <span data-ref="0414.g1:( A B C D )">$ABCD$</span> is the base<br />
and the point <span data-ref="0414.g1:L">$L$</span> the vertex is to the solid <span data-ref="0414.g1:O">$O$</span>, so is the pyramid<br />
of which the polygon <span data-ref="0414.g1:< A T B U C V D W >">$ATBUCVDW$</span> is the base and <span data-ref="0414.g1:L">$L$</span> the<br />
vertex to the pyramid of which the polygon <span data-ref="0414.g1:< E P F Q G R H S >">$EPFQGRHS$</span> is<br />
the base and the point <span data-ref="0414.g1:N">$N$</span> the vertex ;<br />
therefore, alternately, as the cone of which the circle <span data-ref="0414.g1:( A B C D )">$ABCD$</span><br />
is the base and <span data-ref="0414.g1:L">$L$</span> the vertex is to the pyramid contained in<br />
it of which the polygon <span data-ref="0414.g1:< A T B U C V D W >">$ATBUCVDW$</span> is the base and <span data-ref="0414.g1:L">$L$</span><br />
the vertex, so is the solid <span data-ref="0414.g1:O">$O$</span> to the pyramid of which the<br />
polygon <span data-ref="0414.g1:< E P F Q G R H S >">$EPFQGRHS$</span> is the base and <span data-ref="0414.g1:N">$N$</span> the vertex. <span class="justification">[V. 16]</span></p>

<p class="sub-clause">But the said cone is greater than the pyramid in it;<br />
for it encloses it.</p>

<p class="assertion">Therefore the solid <span data-ref="0414.g1:O">$O$</span> is also greater than the pyramid of<br />
which the polygon <span data-ref="0414.g1:< E P F Q G R H S >">$EPFQGRHS$</span> is the base and <span data-ref="0414.g1:N">$N$</span> the<br />
vertex.</p>

<p class="sub-clause">But it is also less :</p>
<p class="assertion">which is impossible.</p>

<p class="assertion">Therefore the cone of which the circle <span data-ref="0414.g1:( A B C D )">$ABCD$</span> is the base<br />
and <span data-ref="0414.g1:L">$L$</span> the vertex has not to any solid less than the cone of<br />
which the circle <span data-ref="0414.g1:( E F G H )">$EFGH$</span> is the base and the point <span data-ref="0414.g1:N">$N$</span> the<br />
vertex the ratio triplicate of that which <span data-ref="0414.g1:/ B D /">$BD$</span> has to <span data-ref="0414.g1:/ F H /">$FH$</span>.</p>

<p class="assertion">Similarly we can prove that neither has the cone <span data-ref="0414.g1:< E F G H N >">$EFGHN$</span><br />
to any solid less than the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span> the ratio triplicate<br />
of that which <span data-ref="0414.g1:/ F H /">$FH$</span> has to <span data-ref="0414.g1:/ B D /">$BD$</span>.</p>

I say next that neither has the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span> to any<br />
solid greater than the cone <span data-ref="0414.g1:< E F G H N >">$EFGHN$</span> the ratio triplicate of<br />
that which <span data-ref="0414.g1:/ B D /">$BD$</span> has to <span data-ref="0414.g1:/ F H /">$FH$</span>.

<p class="sub-clause">For, if possible, let it have that ratio to a greater solid <span data-ref="0414.g1:O">$O$</span>.</p>

<p class="assertion">Therefore, inversely, the solid <span data-ref="0414.g1:O">$O$</span> has to the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span><br />
the ratio triplicate of that which <span data-ref="0414.g1:/ F H /">$FH$</span> has to <span data-ref="0414.g1:/ B D /">$BD$</span>.</p>

<p class="sub-clause">But, as the solid <span data-ref="0414.g1:O">$O$</span> is to the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span>, so is the<br />
cone <span data-ref="0414.g1:< E F G H N >">$EFGHN$</span> to some solid less than the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span>.</p>

<p class="assertion">Therefore the cone <span data-ref="0414.g1:< E F G H N >">$EFGHN$</span> also has to some solid less<br />
than the cone <span data-ref="0414.g1:< A B C D L >">$ABCDL$</span> the ratio triplicate of that which <span data-ref="0414.g1:/ F H /">$FH$</span><br />
has to <span data-ref="0414.g1:/ B D /">$BD$</span>:<br />
which was proved impossible.</p>
