Again, since from the similar $\triangle\text{s}$ <span data-ref="0419.g1:< B K L >">$BKL$</span>, <span data-ref="0419.g1:< F M N >">$FMN$</span>, and the similar $\triangle\text{s}$ <span data-ref="0419.g1:< B K T >">$BKT$</span>, <span data-ref="0419.g1:< F M P >">$FMP$</span> respectively,

<span data-ref="0419.g1:/ L B /">$LB$</span> : <span data-ref="0419.g1:/ B K /">$BK$</span> = <span data-ref="0419.g1:/ N F /">$NF$</span> : <span data-ref="0419.g1:/ F M /">$FM$</span>,
<span data-ref="0419.g1:/ B K /">$BK$</span> : <span data-ref="0419.g1:/ B T /">$BT$</span> = <span data-ref="0419.g1:/ M F /">$MF$</span> : <span data-ref="0419.g1:/ F P /">$FP$</span>,

*ex aequali*,
<span data-ref="0419.g1:/ L B /">$LB$</span> : <span data-ref="0419.g1:/ B T /">$BT$</span> = <span data-ref="0419.g1:/ N F /">$NF$</span> : <span data-ref="0419.g1:/ F P /">$FP$</span>.

Similarly
<span data-ref="0419.g1:/ L T /">$LT$</span> : <span data-ref="0419.g1:/ T B /">$TB$</span> = <span data-ref="0419.g1:/ N P /">$NP$</span> : <span data-ref="0419.g1:/ P F /">$PF$</span>.

Inverting the latter ratio and compounding it with the preceding one, we have, *ex aequali*,
<span data-ref="0419.g1:/ L B /">$LB$</span> : <span data-ref="0419.g1:/ L T /">$LT$</span> = <span data-ref="0419.g1:/ N F /">$NF$</span> : <span data-ref="0419.g1:/ N P /">$NP$</span>.

Thus in $\triangle\text{s}$ <span data-ref="0419.g1:< L T B >">$LTB$</span>, <span data-ref="0419.g1:< N P F >">$NPF$</span> the sides are proportional in pairs;
therefore (4) $\triangle\text{s}$ <span data-ref="0419.g1:< L T B >">$LTB$</span>, <span data-ref="0419.g1:< N P F >">$NPF$</span> are similar.

Thus the partial pyramids <span data-ref="0419.g1:< L B K T >">$L\text{-}BKT$</span>, <span data-ref="0419.g1:< N F M P >">$N\text{-}FMP$</span> are similar.

In exactly the same way it is proved that all the other partial pyramids are similar.

Now
(pyramid <span data-ref="0419.g1:< L B K T >">$L\text{-}BKT$</span>) : (pyramid <span data-ref="0419.g1:< N F M P >">$N\text{-}FMP$</span>) = ratio triplicate of (<span data-ref="0419.g1:/ B K /">$BK$</span> : <span data-ref="0419.g1:/ F M /">$FM$</span>).

The other partial pyramids are to one another in the same triplicate ratio.
The sum of the antecedents is therefore to the sum of the consequents in the same triplicate ratio,
i.e.
(pyramid <span data-ref="0419.g1:< L A T B U >">$L\text{-}ATBU\dots$</span>) : (pyramid <span data-ref="0419.g1:< N E P F Q >">$N\text{-}EPFQ\dots$</span>)
= ratio triplicate of ratio (<span data-ref="0419.g1:/ B K /">$BK$</span> : <span data-ref="0419.g1:/ F M /">$FM$</span>)
= ratio triplicate of ratio (<span data-ref="0419.g1:/ B D /">$BD$</span> : <span data-ref="0419.g1:/ F H /">$FH$</span>).

[The fact that Euclid makes this transition from the partial pyramids to the whole pyramids in the body of this proposition seems to me to suggest grave doubts as to the genuineness of the Porism to XII. 8, which contains a similar but rather more general extension from the case of triangular pyramids to pyramids with polygonal bases. Were that Porism genuine, Euclid would have been more likely to refer to it than to repeat here the same arguments which it contains.]

Now we are in a position to apply the method of exhaustion.

If $X$, $X'$ be the volumes of the cones, $d$, $d'$ the diameters of their bases, and if
$$(\text{ratio triplicate of } d : d') \ne X : X',$$
then must
$$(\text{ratio triplicate of } d : d') = X : O,$$
where $O$ is either less or greater than $X'$.

I. Suppose that $O$ is *less* than $X'$.

Construct in the way described a pyramid ($\Pi'$) in $X'$ leaving over portions of $X'$ together less than $(X' - O)$, so that $X' > \Pi' > O$,
and construct in $X$ a pyramid ($\Pi$), with the same vertex as $X$ has, on a polygon inscribed in its base similar to the base of $\Pi'$.

Then, by what has just been proved,
$$\begin{aligned}
\Pi : \Pi' &= (\text{ratio triplicate of } d : d') \\
&= X : O\text{, by hypothesis,}
\end{aligned}$$
and, alternately,
$$\Pi : X = \Pi' : O.$$

But $X$ includes, and is therefore greater than, $\Pi$;
therefore
$$O > \Pi'.$$
But, by construction,
$$O < \Pi'\text{:}$$
which is impossible.

Therefore
$$O\text{ cannot be less than } X'.$$
