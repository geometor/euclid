We have therefore to prove that, if <span data-ref="0437.g1:< A B C D >">$ABCD$</span>, <span data-ref="0437.g1:< A' B' C' D' >">$A'B'C'D'$</span> are two quadrilaterals inscribable in circles, and
<span data-ref="0437.g1:/ A D /">$AD$</span> = <span data-ref="0437.g1:/ B C /">$BC$</span> = <span data-ref="0437.g1:/ A' D' /">$A'D'$</span> = <span data-ref="0437.g1:/ B' C' /">$B'C'$</span>,
while <span data-ref="0437.g1:/ A B /">$AB$</span> is not greater than <span data-ref="0437.g1:/ A D /">$AD$</span>, <span data-ref="0437.g1:/ A' B' /">$A'B'$</span> = <span data-ref="0437.g1:/ C D /">$CD$</span>, and <span data-ref="0437.g1:/ A B /">$AB$</span> $>$ <span data-ref="0437.g1:/ C D /">$CD$</span> $>$ <span data-ref="0437.g1:/ C' D' /">$C'D'$</span>,
then the radius <span data-ref="0437.g1:/ O A /">$OA$</span> of the circle circumscribing the first quadrilateral is greater than the radius <span data-ref="0437.g1:/ O' A' /">$O'A'$</span> of the circle circumscribing the second.

Clavius, and Simson after him, prove this by *reductio ad absurdum*.

(1) *If <span data-ref="0437.g1:/ O A /">$OA$</span> = <span data-ref="0437.g1:/ O' A' /">$O'A'$</span>*,
it follows that $\angle s$ <span data-ref="0437.g1:< A O D )">$AOD$</span>, <span data-ref="0437.g1:< B O C )">$BOC$</span>, <span data-ref="0437.g1:< A' O' D' )">$A'O'D'$</span>, <span data-ref="0437.g1:< B' O' C' )">$B'O'C'$</span> are all equal.

Also $\angle$ <span data-ref="0437.g1:< A O B )">$AOB$</span> $>$ $\angle$ <span data-ref="0437.g1:< A' O' B' )">$A'O'B'$</span>,
$\angle$ <span data-ref="0437.g1:< C O D )">$COD$</span> $>$ $\angle$ <span data-ref="0437.g1:< C' O' D' )">$C'O'D'$</span>,
whence the four angles about <span data-ref="0437.g1:O">$O$</span> are together greater than the four angles about <span data-ref="0437.g1:O'">$O'$</span>, i.e. greater than four right angles;
which is impossible.
