We have therefore to prove that, if <span data-ref="0437.g1:< A B C D >">$ABCD$</span>, <span data-ref="0437.g1:< A' B' C' D' >">$A'B'C'D'$</span> are two quadrilaterals<br />

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; <span data-ref="0437.g1:/ A D /">$AD$</span> = <span data-ref="0437.g1:/ B C /">$BC$</span> = <span data-ref="0437.g1:/ A' D' /">$A'D'$</span> = <span data-ref="0437.g1:/ B' C' /">$B'C'$</span>,<br />

Clavius, and Simson after him, prove this by *reductio ad absurdum*.

(1) &nbsp; *If <span data-ref="0437.g1:/ O A /">$OA$</span> = <span data-ref="0437.g1:/ O' A' /">$O'A'$</span>*,<br />
it follows that $\angle s$ <span data-ref="0437.g1:< A O D )">$AOD$</span>, <span data-ref="0437.g1:< B O C )">$BOC$</span>, <span data-ref="0437.g1:< A' O' D' )">$A'O'D'$</span>, <span data-ref="0437.g1:< B' O' C' )">$B'O'C'$</span> are all equal.<br />
&nbsp; &nbsp; Also &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; $\angle$ <span data-ref="0437.g1:< A O B )">$AOB$</span> $>$ $\angle$ <span data-ref="0437.g1:< A' O' B' )">$A'O'B'$</span>,<br />
