Similarly we can prove that neither has the sphere <span data-ref="0439.g1:( D E F )">$DEF$</span> to a less sphere than the sphere <span data-ref="0439.g1:( A B C )">$ABC$</span> the ratio triplicate of that which <span data-ref="0439.g1:/ E F /">$EF$</span> has to <span data-ref="0439.g1:/ B C /">$BC$</span>.

I say next that neither has the sphere <span data-ref="0439.g1:( A B C )">$ABC$</span> to any greater sphere than the sphere <span data-ref="0439.g1:( D E F )">$DEF$</span> the ratio triplicate of that which <span data-ref="0439.g1:/ B C /">$BC$</span> has to <span data-ref="0439.g1:/ E F /">$EF$</span>.

For, if possible, let it have that ratio to a greater, <span data-ref="0439.g1:( L M N )">$LMN$</span>;
therefore, inversely, the sphere <span data-ref="0439.g1:( L M N )">$LMN$</span> has to the sphere <span data-ref="0439.g1:( A B C )">$ABC$</span> the ratio triplicate of that which the diameter <span data-ref="0439.g1:/ E F /">$EF$</span> has to the diameter <span data-ref="0439.g1:/ B C /">$BC$</span>.

But, inasmuch as <span data-ref="0439.g1:( L M N )">$LMN$</span> is greater than <span data-ref="0439.g1:( D E F )">$DEF$</span>,
therefore, as the sphere <span data-ref="0439.g1:( L M N )">$LMN$</span> is to the sphere <span data-ref="0439.g1:( A B C )">$ABC$</span>, so is the sphere <span data-ref="0439.g1:( D E F )">$DEF$</span> to some less sphere than the sphere <span data-ref="0439.g1:( A B C )">$ABC$</span>, as was before proved. [XII. 2, Lemma]

Therefore the sphere <span data-ref="0439.g1:( D E F )">$DEF$</span> also has to some less sphere than the sphere <span data-ref="0439.g1:( A B C )">$ABC$</span> the ratio triplicate of that which <span data-ref="0439.g1:/ E F /">$EF$</span> has to <span data-ref="0439.g1:/ B C /">$BC$</span>:
which was proved impossible.

Therefore the sphere <span data-ref="0439.g1:( A B C )">$ABC$</span> has not to any sphere greater than the sphere <span data-ref="0439.g1:( D E F )">$DEF$</span> the ratio triplicate of that which <span data-ref="0439.g1:/ B C /">$BC$</span> has to <span data-ref="0439.g1:/ E F /">$EF$</span>.

But it was proved that neither has it that ratio to a less sphere.

Therefore the sphere <span data-ref="0439.g1:( A B C )">$ABC$</span> has to the sphere <span data-ref="0439.g1:( D E F )">$DEF$</span> the ratio triplicate of that which <span data-ref="0439.g1:/ B C /">$BC$</span> has to <span data-ref="0439.g1:/ E F /">$EF$</span>.

Q. E. D.

It is the method of this proposition which Legendre adopted for his proof of XII. 2 (see note on that proposition).

The argument can be put very shortly. We will suppose $S, S'$ to be the volumes of the spheres, and $d, d'$ to be their diameters; and we will for brevity express the triplicate ratio of $d$ to $d'$ by $d^3 : d'^3$.

If $d^3 : d'^3 \ne S : S'$,
then $d^3 : d'^3 = S : T$,
where $T$ is the volume of some sphere either greater or less than $S'$.

I. Suppose, if possible, that $T < S'$.

Let $T$ be supposed concentric with $S'$.

As in XII. 17, inscribe a polyhedron in $S'$ such that its faces do not anywhere touch $T$;
and inscribe in $S$ a polyhedron similar to that in $S'$.
