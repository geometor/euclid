Then $S : T = d^3 : d'^3$<br />
$= (\text{polyhedron in } S) : (\text{polyhedron in } S');$<br />
or, alternately,<br />
$S : (\text{polyhedron in } S) = T : (\text{polyhedron in } S').$

And $S > (\text{polyhedron in } S);$<br />
therefore $T > (\text{polyhedron in } S').$

But, by construction, $T < (\text{polyhedron in } S'):$<br />
which is impossible.

Therefore $T \not< S'$.

II. Suppose, if possible, that $T > S'$.

Now $d^3 : d'^3 = S : T$<br />
$= X : S'$,<br />
where $X$ is the volume of some sphere less than $S$, <span class="justification">[XII. 2, Lemma]</span><br />
or, inversely, $d'^3 : d^3 = S' : X$,<br />
where $X < S$.

This is proved impossible exactly as in Part I.

Therefore $T \not> S'$.

Hence $T$, not being greater or less than $S'$, is equal to it, and<br />
$d^3 : d'^3 = S : S'$.
