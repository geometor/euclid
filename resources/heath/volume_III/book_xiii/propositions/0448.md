### LEMMA.

That the double of <span data-ref="0447.g1:/ A C /">$AC$</span> is greater than <span data-ref="0447.g1:/ B C /">$BC$</span> is to be proved thus.

If not, let <span data-ref="0447.g1:/ B C /">$BC$</span> be, if possible, double of <span data-ref="0447.g1:/ C A /">$CA$</span>.

Therefore the square on <span data-ref="0447.g1:/ B C /">$BC$</span> is quadruple of the square on <span data-ref="0447.g1:/ C A /">$CA$</span>; therefore the squares on <span data-ref="0447.g1:/ B C /">$BC$</span>, <span data-ref="0447.g1:/ C A /">$CA$</span> are five times the square on <span data-ref="0447.g1:/ C A /">$CA$</span>.

But, by hypothesis, the square on <span data-ref="0447.g1:/ B A /">$BA$</span> is also five times the square on <span data-ref="0447.g1:/ C A /">$CA$</span>; therefore the square on <span data-ref="0447.g1:/ B A /">$BA$</span> is equal to the squares on <span data-ref="0447.g1:/ B C /">$BC$</span>, <span data-ref="0447.g1:/ C A /">$CA$</span>: which is impossible. [II. 4]

Therefore <span data-ref="0447.g1:/ C B /">$CB$</span> is not double of <span data-ref="0447.g1:/ A C /">$AC$</span>.

Similarly we can prove that neither is a straight line less than <span data-ref="0447.g1:/ C B /">$CB$</span> double of <span data-ref="0447.g1:/ C A /">$CA$</span>; for the absurdity is much greater.

Therefore the double of <span data-ref="0447.g1:/ A C /">$AC$</span> is greater than <span data-ref="0447.g1:/ C B /">$CB$</span>.

**Q. E. D.**
