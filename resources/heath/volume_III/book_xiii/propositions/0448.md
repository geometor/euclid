### LEMMA.

That the double of <span data-ref="0447.g1:/ A C /">$AC$</span> is greater than <span data-ref="0447.g1:/ B C /">$BC$</span> is to be proved<br />
thus.

<p class="sub-clause">If not, let <span data-ref="0447.g1:/ B C /">$BC$</span> be, if possible, double of <span data-ref="0447.g1:/ C A /">$CA$</span>.</p>

<p class="assertion">Therefore the square on <span data-ref="0447.g1:/ B C /">$BC$</span> is quadruple of the square<br />
on <span data-ref="0447.g1:/ C A /">$CA$</span>;<br />
therefore the squares on <span data-ref="0447.g1:/ B C /">$BC$</span>, <span data-ref="0447.g1:/ C A /">$CA$</span> are five times the square<br />
on <span data-ref="0447.g1:/ C A /">$CA$</span>.</p>

<p class="sub-clause">But, by hypothesis, the square on <span data-ref="0447.g1:/ B A /">$BA$</span> is also five times<br />
the square on <span data-ref="0447.g1:/ C A /">$CA$</span>;</p>
<p class="assertion">therefore the square on <span data-ref="0447.g1:/ B A /">$BA$</span> is equal to the squares on <span data-ref="0447.g1:/ B C /">$BC$</span>, <span data-ref="0447.g1:/ C A /">$CA$</span>:<br />
which is impossible. <span class="justification">[II. 4]</span></p>

<p class="assertion">Therefore <span data-ref="0447.g1:/ C B /">$CB$</span> is not double of <span data-ref="0447.g1:/ A C /">$AC$</span>.</p>

<p class="assertion">Similarly we can prove that neither is a straight line less<br />
than <span data-ref="0447.g1:/ C B /">$CB$</span> double of <span data-ref="0447.g1:/ C A /">$CA$</span>;<br />
for the absurdity is much greater.</p>

<p class="assertion">Therefore the double of <span data-ref="0447.g1:/ A C /">$AC$</span> is greater than <span data-ref="0447.g1:/ C B /">$CB$</span>.</p>

<p class="qed">Q. E. D.</p>
