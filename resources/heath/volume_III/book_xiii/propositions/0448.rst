LEMMA.
~~~~~~

That the double of :g:`$AC$ <0447.g1:/ A C />` is greater than :g:`$BC$ <0447.g1:/ B C />` is to be proved thus.

.. subclause::

   If not, let :g:`$BC$ <0447.g1:/ B C />` be, if possible, double of :g:`$CA$ <0447.g1:/ C A />`.

.. assertion::

   Therefore the square on :g:`$BC$ <0447.g1:/ B C />` is quadruple of the square on :g:`$CA$ <0447.g1:/ C A />`; therefore the squares on :g:`$BC$ <0447.g1:/ B C />`, :g:`$CA$ <0447.g1:/ C A />` are five times the square on :g:`$CA$ <0447.g1:/ C A />`.

.. subclause::

   But, by hypothesis, the square on :g:`$BA$ <0447.g1:/ B A />` is also five times the square on :g:`$CA$ <0447.g1:/ C A />`;

.. assertion::

   therefore the square on :g:`$BA$ <0447.g1:/ B A />` is equal to the squares on :g:`$BC$ <0447.g1:/ B C />`, :g:`$CA$ <0447.g1:/ C A />`: which is impossible. :just:`[II. 4] <II.4>`

.. assertion::

   Therefore :g:`$CB$ <0447.g1:/ C B />` is not double of :g:`$AC$ <0447.g1:/ A C />`.

.. assertion::

   Similarly we can prove that neither is a straight line less than :g:`$CB$ <0447.g1:/ C B />` double of :g:`$CA$ <0447.g1:/ C A />`; for the absurdity is much greater.

.. assertion::

   Therefore the double of :g:`$AC$ <0447.g1:/ A C />` is greater than :g:`$CB$ <0447.g1:/ C B />`.

.. qed::

   Q. E. D.
