Subtract from each side the sq. on <span data-ref="0447.g1:/ A C /">$AC$</span>; then
<p align="center">(gnomon <span data-ref="0447.g1:< M N O >">$MNO$</span>) = 4 (sq. on <span data-ref="0447.g1:/ A C /">$AC$</span>)<br>
= (sq. on <span data-ref="0447.g1:/ C D /">$CD$</span>).</p>

Now, as in the last proposition,
<p align="center">□ <span data-ref="0447.g1:< C E >">$CE$</span> = 2 (□ <span data-ref="0447.g1:< B H >">$BH$</span>)<br>
= □ <span data-ref="0447.g1:< B H >">$BH$</span> + □ <span data-ref="0447.g1:< H L >">$HL$</span>.</p>

Subtracting these equals from the equals, the square on <span data-ref="0447.g1:/ C D /">$CD$</span> and the gnomon <span data-ref="0447.g1:< M N O >">$MNO$</span> respectively, we have
<p align="center">□ <span data-ref="0447.g1:< B G >">$BG$</span> = (square <span data-ref="0447.g1:< H F >">$HF$</span>),</p>
i.e.
<p align="center">(rect. <span data-ref="0447.g1:/ C D /">$CD$</span>, <span data-ref="0447.g1:/ D B /">$DB$</span>) = (sq. on <span data-ref="0447.g1:/ C B /">$CB$</span>).</p>

Here again the proposition can readily be proved by means of a figure similar to that of II. 11.

Draw <span data-ref="0449.g1:/ C A /">$CA$</span> through <span data-ref="0449.g1:C">$C$</span> at *right angles* to <span data-ref="0449.g1:/ C B /">$CB$</span> and of length equal to <span data-ref="0449.g1:/ C A /">$CA$</span> in the original figure; make <span data-ref="0449.g1:/ C D /">$CD$</span> double of <span data-ref="0449.g1:/ C A /">$CA$</span>; produce <span data-ref="0449.g1:/ A C /">$AC$</span> to <span data-ref="0449.g1:R">$R$</span> so that <span data-ref="0449.g1:/ C R /">$CR$</span> $= $ <span data-ref="0449.g1:/ C B /">$CB$</span>.

Complete the squares on <span data-ref="0449.g1:/ C B /">$CB$</span> and <span data-ref="0449.g1:/ C D /">$CD$</span>, and join <span data-ref="0449.g1:/ A D /">$AD$</span>.

Now we are given the fact that
<p align="center">(sq. on <span data-ref="0449.g1:/ A R /">$AR$</span>) = 5 (sq. on <span data-ref="0449.g1:/ C A /">$CA$</span>).</p>

But
<p align="center">5 (sq. on <span data-ref="0449.g1:/ A C /">$AC$</span>) = (sq. on <span data-ref="0449.g1:/ A C /">$AC$</span>) + (sq. on <span data-ref="0449.g1:/ C D /">$CD$</span>)<br>
= (sq. on <span data-ref="0449.g1:/ A D /">$AD$</span>).</p>

Therefore
<p align="center">(sq. on <span data-ref="0449.g1:/ A R /">$AR$</span>) = (sq. on <span data-ref="0449.g1:/ A D /">$AD$</span>),</p>
or <span data-ref="0449.g1:/ A R /">$AR$</span> $= $ <span data-ref="0449.g1:/ A D /">$AD$</span>.

Now
<p align="center">(rect. <span data-ref="0449.g1:/ K R /">$KR$</span>, <span data-ref="0449.g1:/ R C /">$RC$</span>) + (sq. on <span data-ref="0449.g1:/ A C /">$AC$</span>) = (sq. on <span data-ref="0449.g1:/ A R /">$AR$</span>)<br>
= (sq. on <span data-ref="0449.g1:/ A D /">$AD$</span>)<br>
= (sq. on <span data-ref="0449.g1:/ A C /">$AC$</span>) + (sq. on <span data-ref="0449.g1:/ C D /">$CD$</span>).</p>

Therefore
<p align="center">(rect. <span data-ref="0449.g1:/ K R /">$KR$</span> . <span data-ref="0449.g1:/ R C /">$RC$</span>) = (sq. on <span data-ref="0449.g1:/ C D /">$CD$</span>).</p>

That is,
<p align="center">(rectangle <span data-ref="0449.g1:< R E >">$RE$</span>) = (square <span data-ref="0449.g1:< C G >">$CG$</span>).</p>

Subtract the common part <span data-ref="0449.g1:< C E >">$CE$</span>, and
<p align="center">(rect. <span data-ref="0449.g1:< B G >">$BG$</span>) = (sq. <span data-ref="0449.g1:< R B >">$RB$</span>),</p>
or
<p align="center">rect. <span data-ref="0449.g1:/ C D /">$CD$</span>, <span data-ref="0449.g1:/ D B /">$DB$</span> = (sq. on <span data-ref="0449.g1:/ C B /">$CB$</span>).</p>

Heiberg, with reason, doubts the genuineness of the Lemma following this proposition.

### PROPOSITION 3.

*If a straight line be cut in extreme and mean ratio, the square on the lesser segment added to the half of the greater segment is five times the square on the half of the greater segment.*
