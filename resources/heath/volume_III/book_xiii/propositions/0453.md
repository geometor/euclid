<p class="sub-clause">
Since <span data-ref="0452.g1:/ A B /">$AB$</span> has been cut in extreme and mean ratio at <span data-ref="0452.g1:C">$C$</span>,
</p>
<p class="assertion">
therefore the rectangle <span data-ref="0452.g1:/ A B /">$AB$</span>, <span data-ref="0452.g1:/ B C /">$BC$</span> is equal to the square on <span data-ref="0452.g1:/ A C /">$AC$</span>.<br />
<span class="justification">[VI. Def. 3, VI. 17]</span>
</p>

<p class="sub-clause">
And <span data-ref="0452.g1:< C E >">$CE$</span> is the rectangle <span data-ref="0452.g1:/ A B /">$AB$</span>, <span data-ref="0452.g1:/ B C /">$BC$</span>, and <span data-ref="0452.g1:< C H >">$CH$</span> the square<br />
on <span data-ref="0452.g1:/ A C /">$AC$</span>;
</p>
<p class="assertion">
therefore <span data-ref="0452.g1:< C E >">$CE$</span> is equal to <span data-ref="0452.g1:< H C >">$HC$</span>.
</p>

<p class="sub-clause">
But <span data-ref="0452.g1:< H E >">$HE$</span> is equal to <span data-ref="0452.g1:< C E >">$CE$</span>,<br />
and <span data-ref="0452.g1:< D H >">$DH$</span> is equal to <span data-ref="0452.g1:< H C >">$HC$</span>;
</p>
<p class="assertion">
therefore <span data-ref="0452.g1:< D H >">$DH$</span> is also equal to <span data-ref="0452.g1:< H E >">$HE$</span>.
</p>

<p class="assertion">
Therefore the whole <span data-ref="0452.g1:< D K >">$DK$</span> is equal to the whole <span data-ref="0452.g1:< A E >">$AE$</span>.
</p>

<p class="sub-clause">
And <span data-ref="0452.g1:< D K >">$DK$</span> is the rectangle <span data-ref="0452.g1:/ B D /">$BD$</span>, <span data-ref="0452.g1:/ D A /">$DA$</span>,<br />
for <span data-ref="0452.g1:/ A D /">$AD$</span> is equal to <span data-ref="0452.g1:/ D L /">$DL$</span>;<br />
and <span data-ref="0452.g1:< A E >">$AE$</span> is the square on <span data-ref="0452.g1:/ A B /">$AB$</span>;
</p>
<p class="assertion">
therefore the rectangle <span data-ref="0452.g1:/ B D /">$BD$</span>, <span data-ref="0452.g1:/ D A /">$DA$</span> is equal to the square<br />
on <span data-ref="0452.g1:/ A B /">$AB$</span>.
</p>

<p class="assertion">
Therefore, as <span data-ref="0452.g1:/ D B /">$DB$</span> is to <span data-ref="0452.g1:/ B A /">$BA$</span>, so is <span data-ref="0452.g1:/ B A /">$BA$</span> to <span data-ref="0452.g1:/ A D /">$AD$</span>. <span class="justification">[VI. 17]</span>
</p>

<p class="sub-clause">
And <span data-ref="0452.g1:/ D B /">$DB$</span> is greater than <span data-ref="0452.g1:/ B A /">$BA$</span>;
</p>
<p class="assertion">
therefore <span data-ref="0452.g1:/ B A /">$BA$</span> is also greater than <span data-ref="0452.g1:/ A D /">$AD$</span>. <span class="justification">[V. 14]</span>
</p>

<p class="assertion">
Therefore <span data-ref="0452.g1:/ D B /">$DB$</span> has been cut in extreme and mean ratio at<br />
<span data-ref="0452.g1:A">$A$</span>, and <span data-ref="0452.g1:/ A B /">$AB$</span> is the greater segment.
</p>

<p class="qed">
<span class="justification">Q. E. D.</span>
</p>

We have
<p align="center">(sq. <span data-ref="0452.g1:< D H >">$DH$</span>) = (sq. <span data-ref="0452.g1:< H C >">$HC$</span>)<br />
= (rect. <span data-ref="0452.g1:< C E >">$CE$</span>), by hypothesis,<br />
= (rect. <span data-ref="0452.g1:< H E >">$HE$</span>).</p>
Add to each side the rectangle <span data-ref="0452.g1:< A K >">$AK$</span>, and
<p align="center">(rect. <span data-ref="0452.g1:< D K >">$DK$</span>) = (sq. <span data-ref="0452.g1:< A E >">$AE$</span>),<br />
or (rect. <span data-ref="0452.g1:/ B D /">$BD$</span>, <span data-ref="0452.g1:/ D A /">$DA$</span>) = (sq. on <span data-ref="0452.g1:/ A B /">$AB$</span>).</p>
The result is of course obvious from II. 11.

There is an alternative proof given in P after XIII. 6, which depends on<br />
Book V.

By hypothesis,
<p align="center"><span data-ref="0452.g1:/ B A /">$BA$</span> : <span data-ref="0452.g1:/ A C /">$AC$</span> = <span data-ref="0452.g1:/ A C /">$AC$</span> : <span data-ref="0452.g1:/ C B /">$CB$</span>,</p>
or, inversely,
<p align="center"><span data-ref="0452.g1:/ A C /">$AC$</span> : <span data-ref="0452.g1:/ A B /">$AB$</span> = <span data-ref="0452.g1:/ C B /">$CB$</span> : <span data-ref="0452.g1:/ A C /">$AC$</span>.</p>
*Componendo*,
<p align="center">(<span data-ref="0452.g1:/ A B /">$AB$</span> + <span data-ref="0452.g1:/ A C /">$AC$</span>) : <span data-ref="0452.g1:/ A B /">$AB$</span> = <span data-ref="0452.g1:/ A B /">$AB$</span> : <span data-ref="0452.g1:/ A C /">$AC$</span>,</p>
or
<p align="center"><span data-ref="0452.g1:/ D B /">$DB$</span> : <span data-ref="0452.g1:/ B A /">$BA$</span> = <span data-ref="0452.g1:/ B A /">$BA$</span> : <span data-ref="0452.g1:/ A D /">$AD$</span>.</p>

### PROPOSITION 6.

<p class="enunciation">
If a rational straight line be cut in extreme and mean ratio,<br />
each of the segments is the irrational straight line called<br />
apotome.
</p>
