Let <span data-ref="0454.g1:/ A B /">$AB$</span> be a rational straight line,<br />
let it be cut in extreme and mean<br />
ratio at <span data-ref="0454.g1:C">$C$</span>,<br />
and let <span data-ref="0454.g1:/ A C /">$AC$</span> be the greater segment;<br />
I say that each of the straight lines <span data-ref="0454.g1:/ A C /">$AC$</span>, <span data-ref="0454.g1:/ C B /">$CB$</span> is the irrational<br />
straight line called apotome.

![Book XIII, Proposition 6](0454.g1.svg)

For let <span data-ref="0454.g1:/ B A /">$BA$</span> be produced, and let <span data-ref="0454.g1:/ A D /">$AD$</span> be made half of <span data-ref="0454.g1:/ B A /">$BA$</span>.

<p class="sub-clause">Since then the straight line <span data-ref="0454.g1:/ A B /">$AB$</span> has been cut in extreme<br />
and mean ratio,<br />
and to the greater segment <span data-ref="0454.g1:/ A C /">$AC$</span> is added <span data-ref="0454.g1:/ A D /">$AD$</span> which is half<br />
of <span data-ref="0454.g1:/ A B /">$AB$</span>,</p>
<p class="assertion">therefore the square on <span data-ref="0454.g1:/ C D /">$CD$</span> is five times the square on <span data-ref="0454.g1:/ D A /">$DA$</span>. <span class="justification">[XIII. 1]</span></p>

<p class="assertion">Therefore the square on <span data-ref="0454.g1:/ C D /">$CD$</span> has to the square on <span data-ref="0454.g1:/ D A /">$DA$</span> the<br />
ratio which a number has to a number;<br />
therefore the square on <span data-ref="0454.g1:/ C D /">$CD$</span> is commensurable with the square<br />
on <span data-ref="0454.g1:/ D A /">$DA$</span>. <span class="justification">[X. 6]</span></p>

<p class="sub-clause">But the square on <span data-ref="0454.g1:/ D A /">$DA$</span> is rational,<br />
for <span data-ref="0454.g1:/ D A /">$DA$</span> is rational, being half of <span data-ref="0454.g1:/ A B /">$AB$</span> which is rational;</p>
<p class="assertion">therefore the square on <span data-ref="0454.g1:/ C D /">$CD$</span> is also rational; <span class="justification">[X. Def. 4]</span><br />
therefore <span data-ref="0454.g1:/ C D /">$CD$</span> is also rational.</p>

<p class="sub-clause">And, since the square on <span data-ref="0454.g1:/ C D /">$CD$</span> has not to the square on<br />
<span data-ref="0454.g1:/ D A /">$DA$</span> the ratio which a square number has to a square number,</p>
<p class="assertion">therefore <span data-ref="0454.g1:/ C D /">$CD$</span> is incommensurable in length with <span data-ref="0454.g1:/ D A /">$DA$</span>; <span class="justification">[X. 9]</span><br />
therefore <span data-ref="0454.g1:/ C D /">$CD$</span>, <span data-ref="0454.g1:/ D A /">$DA$</span> are rational straight lines commensurable<br />
in square only;<br />
therefore <span data-ref="0454.g1:/ A C /">$AC$</span> is an apotome. <span class="justification">[X. 73]</span></p>

<p class="sub-clause">Again, since <span data-ref="0454.g1:/ A B /">$AB$</span> has been cut in extreme and mean ratio,<br />
and <span data-ref="0454.g1:/ A C /">$AC$</span> is the greater segment,</p>
<p class="assertion">therefore the rectangle <span data-ref="0454.g1:/ A B /">$AB$</span>, <span data-ref="0454.g1:/ B C /">$BC$</span> is equal to the square on <span data-ref="0454.g1:/ A C /">$AC$</span>. <span class="justification">[VI. Def. 3, VI. 17]</span></p>

<p class="assertion">Therefore the square on the apotome <span data-ref="0454.g1:/ A C /">$AC$</span>, if applied to<br />
the rational straight line <span data-ref="0454.g1:/ A B /">$AB$</span>, produces <span data-ref="0454.g1:/ B C /">$BC$</span> as breadth.</p>

<p class="sub-clause">But the square on an apotome, if applied to a rational<br />
straight line, produces as breadth a first apotome; <span class="justification">[X. 97]</span></p>
<p class="assertion">therefore <span data-ref="0454.g1:/ C B /">$CB$</span> is a first apotome.</p>
