Let <span data-ref="0454.g1:/ A B /">$AB$</span> be a rational straight line,
let it be cut in extreme and mean ratio at <span data-ref="0454.g1:C">$C$</span>,
and let <span data-ref="0454.g1:/ A C /">$AC$</span> be the greater segment;

![Book XIII, Proposition 6](0454.g1.svg)

I say that each of the straight lines <span data-ref="0454.g1:/ A C /">$AC$</span>, <span data-ref="0454.g1:/ C B /">$CB$</span> is the irrational straight line called apotome.

For let <span data-ref="0454.g1:/ B A /">$BA$</span> be produced, and let <span data-ref="0454.g1:/ A D /">$AD$</span> be made half of <span data-ref="0454.g1:/ B A /">$BA$</span>.

Since then the straight line <span data-ref="0454.g1:/ A B /">$AB$</span> has been cut in extreme and mean ratio,
and to the greater segment <span data-ref="0454.g1:/ A C /">$AC$</span> is added <span data-ref="0454.g1:/ A D /">$AD$</span> which is half of <span data-ref="0454.g1:/ A B /">$AB$</span>,
therefore the square on <span data-ref="0454.g1:/ C D /">$CD$</span> is five times the square on <span data-ref="0454.g1:/ D A /">$DA$</span>. [XIII. 1]

Therefore the square on <span data-ref="0454.g1:/ C D /">$CD$</span> has to the square on <span data-ref="0454.g1:/ D A /">$DA$</span> the ratio which a number has to a number;
therefore the square on <span data-ref="0454.g1:/ C D /">$CD$</span> is commensurable with the square on <span data-ref="0454.g1:/ D A /">$DA$</span>. [X. 6]

But the square on <span data-ref="0454.g1:/ D A /">$DA$</span> is rational,
for <span data-ref="0454.g1:/ D A /">$DA$</span> is rational, being half of <span data-ref="0454.g1:/ A B /">$AB$</span> which is rational;
therefore the square on <span data-ref="0454.g1:/ C D /">$CD$</span> is also rational; [X. Def. 4]
therefore <span data-ref="0454.g1:/ C D /">$CD$</span> is also rational.

And, since the square on <span data-ref="0454.g1:/ C D /">$CD$</span> has not to the square on <span data-ref="0454.g1:/ D A /">$DA$</span> the ratio which a square number has to a square number,
therefore <span data-ref="0454.g1:/ C D /">$CD$</span> is incommensurable in length with <span data-ref="0454.g1:/ D A /">$DA$</span>; [X. 9]
therefore <span data-ref="0454.g1:/ C D /">$CD$</span>, <span data-ref="0454.g1:/ D A /">$DA$</span> are rational straight lines commensurable in square only;
therefore <span data-ref="0454.g1:/ A C /">$AC$</span> is an apotome. [X. 73]

Again, since <span data-ref="0454.g1:/ A B /">$AB$</span> has been cut in extreme and mean ratio,
and <span data-ref="0454.g1:/ A C /">$AC$</span> is the greater segment,
therefore the rectangle <span data-ref="0454.g1:/ A B /">$AB$</span>, <span data-ref="0454.g1:/ B C /">$BC$</span> is equal to the square on <span data-ref="0454.g1:/ A C /">$AC$</span>. [VI. Def. 3, VI. 17]

Therefore the square on the apotome <span data-ref="0454.g1:/ A C /">$AC$</span>, if applied to the rational straight line <span data-ref="0454.g1:/ A B /">$AB$</span>, produces <span data-ref="0454.g1:/ B C /">$BC$</span> as breadth.

But the square on an apotome, if applied to a rational straight line, produces as breadth a first apotome; [X. 97]
therefore <span data-ref="0454.g1:/ C B /">$CB$</span> is a first apotome.
