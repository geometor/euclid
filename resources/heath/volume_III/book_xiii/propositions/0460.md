<p class="sub-clause">But, as the circumference <span data-ref="0459.g1:( A C )">$AC$</span> is to <span data-ref="0459.g1:( C B )">$CB$</span>, so is the angle<br />
<span data-ref="0459.g1:< A E C )">$AEC$</span> to the angle <span data-ref="0459.g1:< C E B )">$CEB$</span>; <span class="justification">[VI. 33]</span></p>
<p class="assertion">therefore the angle <span data-ref="0459.g1:< A E C )">$AEC$</span> is quadruple of the angle <span data-ref="0459.g1:< C E B )">$CEB$</span>.</p>

<p class="sub-clause">And, since the angle <span data-ref="0459.g1:< E B C )">$EBC$</span> is equal to the angle <span data-ref="0459.g1:< E C B )">$ECB$</span>, <span class="justification">[I. 5]</span></p>
<p class="assertion">therefore the angle <span data-ref="0459.g1:< A E C )">$AEC$</span> is double of the angle <span data-ref="0459.g1:< E C B )">$ECB$</span>. <span class="justification">[I. 32]</span></p>

<p class="sub-clause">And, since the straight line <span data-ref="0459.g1:/ E C /">$EC$</span> is equal to <span data-ref="0459.g1:/ C D /">$CD$</span>,<br />
for each of them is equal to the side of the hexagon inscribed<br />
in the circle <span data-ref="0459.g1:( A B C )">$ABC$</span>, <span class="justification">[IV. 15, Por.]</span><br />
the angle <span data-ref="0459.g1:< C E D )">$CED$</span> is also equal to the angle <span data-ref="0459.g1:< C D E )">$CDE$</span>; <span class="justification">[I. 5]</span></p>
<p class="assertion">therefore the angle <span data-ref="0459.g1:< E C B )">$ECB$</span> is double of the angle <span data-ref="0459.g1:< E D C )">$EDC$</span>. <span class="justification">[I. 32]</span></p>

<p class="sub-clause">But the angle <span data-ref="0459.g1:< A E C )">$AEC$</span> was proved double of the angle <span data-ref="0459.g1:< E C B )">$ECB$</span>;</p>
<p class="assertion">therefore the angle <span data-ref="0459.g1:< A E C )">$AEC$</span> is quadruple of the angle <span data-ref="0459.g1:< E D C )">$EDC$</span>.</p>

<p class="sub-clause">But the angle <span data-ref="0459.g1:< A E C )">$AEC$</span> was also proved quadruple of the<br />
angle <span data-ref="0459.g1:< B E C )">$BEC$</span>;</p>
<p class="assertion">therefore the angle <span data-ref="0459.g1:< E D C )">$EDC$</span> is equal to the angle <span data-ref="0459.g1:< B E C )">$BEC$</span>.</p>

<p class="sub-clause">But the angle <span data-ref="0459.g1:< E B D )">$EBD$</span> is common to the two triangles <span data-ref="0459.g1:< B E C >">$BEC$</span><br />
and <span data-ref="0459.g1:< B E D >">$BED$</span>;</p>
<p class="assertion">therefore the remaining angle <span data-ref="0459.g1:< B E D )">$BED$</span> is also equal to the<br />
remaining angle <span data-ref="0459.g1:< E C B )">$ECB$</span>; <span class="justification">[I. 32]</span></p>
<p class="assertion">therefore the triangle <span data-ref="0459.g1:< E B D >">$EBD$</span> is equiangular with the triangle<br />
<span data-ref="0459.g1:< E B C >">$EBC$</span>.</p>

<p class="assertion">Therefore, proportionally, as <span data-ref="0459.g1:/ D B /">$DB$</span> is to <span data-ref="0459.g1:/ B E /">$BE$</span>, so is <span data-ref="0459.g1:/ E B /">$EB$</span> to <span data-ref="0459.g1:/ B C /">$BC$</span>.<br />
<span class="justification">[VI. 4]</span></p>
<p class="sub-clause">But <span data-ref="0459.g1:/ E B /">$EB$</span> is equal to <span data-ref="0459.g1:/ C D /">$CD$</span>.</p>
<p class="assertion">Therefore, as <span data-ref="0459.g1:/ B D /">$BD$</span> is to <span data-ref="0459.g1:/ D C /">$DC$</span>, so is <span data-ref="0459.g1:/ D C /">$DC$</span> to <span data-ref="0459.g1:/ C B /">$CB$</span>.</p>
<p class="sub-clause">And <span data-ref="0459.g1:/ B D /">$BD$</span> is greater than <span data-ref="0459.g1:/ D C /">$DC$</span>;</p>
<p class="assertion">therefore <span data-ref="0459.g1:/ D C /">$DC$</span> is also greater than <span data-ref="0459.g1:/ C B /">$CB$</span>.</p>
<p class="assertion">Therefore the straight line <span data-ref="0459.g1:/ B D /">$BD$</span> has been cut in extreme<br />
and mean ratio, and <span data-ref="0459.g1:/ D C /">$DC$</span> is its greater segment.</p>

<p class="qed">Q. E. D.</p>
