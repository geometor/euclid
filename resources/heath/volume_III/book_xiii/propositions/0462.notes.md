## Textual, Lexical & Mathematical Observations
- Marginal Euclidean citations:
  - `[I. 5, I. 26]`: In isosceles $\triangle FAB$, perpendicular $FH$ bisects the vertical angle $\angle AFB$ and base $AB$.
  - `[III. 26]`: Equal angles at the centre subtend equal circumferences ($\text{arc } AK = \text{arc } KB$).
- Arc relationships established:
  - $\text{arc } ABCG = \text{arc } AEDG$ (semicircles).
  - Subtracting pentagon arcs $\text{arc } ABC = \text{arc } AED$ leaves $\text{arc } CG = \text{arc } GD = \frac{1}{2}\,\text{arc } CD$, so $CG$ is the side of an inscribed decagon.
  - Similarly, $AK$ is the side of a decagon, and $AK$ is double $KM$.
  - Arcs compared: $\text{arc } CG = \text{arc } BK = \text{arc } AK = 2\,\text{arc } KM$.
