<p class="sub-clause">But, further, the circumference <span data-ref="0462.g1:( C B )">$CB$</span> is also double of the<br />
circumference <span data-ref="0462.g1:( B K )">$BK$</span>,<br />
for the circumference <span data-ref="0462.g1:( C B )">$CB$</span> is equal to <span data-ref="0462.g1:( B A )">$BA$</span>.</p>

<p class="assertion">Therefore the whole circumference <span data-ref="0462.g1:( G B )">$GB$</span> is also double<br />
of <span data-ref="0462.g1:( B M )">$BM$</span>;<br />
hence the angle <span data-ref="0462.g1:< G F B )">$GFB$</span> is also double of the angle <span data-ref="0462.g1:< B F M )">$BFM$</span>. <span class="justification">[VI. 33]</span></p>

<p class="sub-clause">But the angle <span data-ref="0462.g1:< G F B )">$GFB$</span> is also double of the angle <span data-ref="0462.g1:< F A B )">$FAB$</span>,<br />
for the angle <span data-ref="0462.g1:< F A B )">$FAB$</span> is equal to the angle <span data-ref="0462.g1:< A B F )">$ABF$</span>.</p>

<p class="assertion">Therefore the angle <span data-ref="0462.g1:< B F N )">$BFN$</span> is also equal to the angle <span data-ref="0462.g1:< F A B )">$FAB$</span>.</p>

<p class="sub-clause">But the angle <span data-ref="0462.g1:< A B F )">$ABF$</span> is common to the two triangles <span data-ref="0462.g1:< A B F >">$ABF$</span><br />
and <span data-ref="0462.g1:< B F N >">$BFN$</span>;</p>
<p class="assertion">therefore the remaining angle <span data-ref="0462.g1:< A F B )">$AFB$</span> is equal to the remaining<br />
angle <span data-ref="0462.g1:< B N F )">$BNF$</span>; <span class="justification">[I. 32]</span><br />
therefore the triangle <span data-ref="0462.g1:< A B F >">$ABF$</span> is equiangular with the triangle<br />
<span data-ref="0462.g1:< B F N >">$BFN$</span>.</p>

<p class="assertion">Therefore, proportionally, as the straight line <span data-ref="0462.g1:/ A B /">$AB$</span> is to <span data-ref="0462.g1:/ B F /">$BF$</span>,<br />
so is <span data-ref="0462.g1:/ F B /">$FB$</span> to <span data-ref="0462.g1:/ B N /">$BN$</span>; <span class="justification">[VI. 4]</span><br />
therefore the rectangle <span data-ref="0462.g1:/ A B /">$AB$</span>, <span data-ref="0462.g1:/ B N /">$BN$</span> is equal to the square on <span data-ref="0462.g1:/ B F /">$BF$</span>.<br />
<span class="justification">[VI. 17]</span></p>

<p class="sub-clause">Again, since <span data-ref="0462.g1:/ A L /">$AL$</span> is equal to <span data-ref="0462.g1:/ L K /">$LK$</span>,<br />
while <span data-ref="0462.g1:/ L N /">$LN$</span> is common and at right angles,</p>
<p class="assertion">therefore the base <span data-ref="0462.g1:/ K N /">$KN$</span> is equal to the base <span data-ref="0462.g1:/ A N /">$AN$</span>; <span class="justification">[I. 4]</span><br />
therefore the angle <span data-ref="0462.g1:< L K N )">$LKN$</span> is also equal to the angle <span data-ref="0462.g1:< L A N )">$LAN$</span>.</p>

<p class="sub-clause">But the angle <span data-ref="0462.g1:< L A N )">$LAN$</span> is equal to the angle <span data-ref="0462.g1:< K B N )">$KBN$</span>;</p>
<p class="assertion">therefore the angle <span data-ref="0462.g1:< L K N )">$LKN$</span> is also equal to the angle <span data-ref="0462.g1:< K B N )">$KBN$</span>.</p>

<p class="sub-clause">And the angle at <span data-ref="0462.g1:A">$A$</span> is common to the two triangles <span data-ref="0462.g1:< A K B >">$AKB$</span><br />
and <span data-ref="0462.g1:< A K N >">$AKN$</span>.</p>

<p class="assertion">Therefore the remaining angle <span data-ref="0462.g1:< A K B )">$AKB$</span> is equal to the<br />
remaining angle <span data-ref="0462.g1:< K N A )">$KNA$</span>; <span class="justification">[I. 32]</span><br />
therefore the triangle <span data-ref="0462.g1:< K B A >">$KBA$</span> is equiangular with the triangle<br />
<span data-ref="0462.g1:< K N A >">$KNA$</span>.</p>

<p class="assertion">Therefore, proportionally, as the straight line <span data-ref="0462.g1:/ B A /">$BA$</span> is to<br />
<span data-ref="0462.g1:/ A K /">$AK$</span>, so is <span data-ref="0462.g1:/ K A /">$KA$</span> to <span data-ref="0462.g1:/ A N /">$AN$</span>; <span class="justification">[VI. 4]</span><br />
therefore the rectangle <span data-ref="0462.g1:/ B A /">$BA$</span>, <span data-ref="0462.g1:/ A N /">$AN$</span> is equal to the square on <span data-ref="0462.g1:/ A K /">$AK$</span>.<br />
<span class="justification">[VI. 17]</span></p>

<p class="sub-clause">But the rectangle <span data-ref="0462.g1:/ A B /">$AB$</span>, <span data-ref="0462.g1:/ B N /">$BN$</span> was also proved equal to the<br />
square on <span data-ref="0462.g1:/ B F /">$BF$</span>;</p>
