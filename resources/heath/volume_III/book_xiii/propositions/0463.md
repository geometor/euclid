But, further, the circumference <span data-ref="0462.g1:( C B )">$CB$</span> is also double of the circumference <span data-ref="0462.g1:( B K )">$BK$</span>,
for the circumference <span data-ref="0462.g1:( C B )">$CB$</span> is equal to <span data-ref="0462.g1:( B A )">$BA$</span>.

Therefore the whole circumference <span data-ref="0462.g1:( G B )">$GB$</span> is also double of <span data-ref="0462.g1:( B M )">$BM$</span>;
hence the angle <span data-ref="0462.g1:< G F B )">$GFB$</span> is also double of the angle <span data-ref="0462.g1:< B F M )">$BFM$</span>. [VI. 33]

But the angle <span data-ref="0462.g1:< G F B )">$GFB$</span> is also double of the angle <span data-ref="0462.g1:< F A B )">$FAB$</span>,
for the angle <span data-ref="0462.g1:< F A B )">$FAB$</span> is equal to the angle <span data-ref="0462.g1:< A B F )">$ABF$</span>.

Therefore the angle <span data-ref="0462.g1:< B F N )">$BFN$</span> is also equal to the angle <span data-ref="0462.g1:< F A B )">$FAB$</span>.

But the angle <span data-ref="0462.g1:< A B F )">$ABF$</span> is common to the two triangles <span data-ref="0462.g1:< A B F >">$ABF$</span> and <span data-ref="0462.g1:< B F N >">$BFN$</span>;
therefore the remaining angle <span data-ref="0462.g1:< A F B )">$AFB$</span> is equal to the remaining angle <span data-ref="0462.g1:< B N F )">$BNF$</span>; [I. 32]
therefore the triangle <span data-ref="0462.g1:< A B F >">$ABF$</span> is equiangular with the triangle <span data-ref="0462.g1:< B F N >">$BFN$</span>.

Therefore, proportionally, as the straight line <span data-ref="0462.g1:/ A B /">$AB$</span> is to <span data-ref="0462.g1:/ B F /">$BF$</span>, so is <span data-ref="0462.g1:/ F B /">$FB$</span> to <span data-ref="0462.g1:/ B N /">$BN$</span>; [VI. 4]
therefore the rectangle <span data-ref="0462.g1:/ A B /">$AB$</span>, <span data-ref="0462.g1:/ B N /">$BN$</span> is equal to the square on <span data-ref="0462.g1:/ B F /">$BF$</span>. [VI. 17]

Again, since <span data-ref="0462.g1:/ A L /">$AL$</span> is equal to <span data-ref="0462.g1:/ L K /">$LK$</span>,
while <span data-ref="0462.g1:/ L N /">$LN$</span> is common and at right angles,
therefore the base <span data-ref="0462.g1:/ K N /">$KN$</span> is equal to the base <span data-ref="0462.g1:/ A N /">$AN$</span>; [I. 4]
therefore the angle <span data-ref="0462.g1:< L K N )">$LKN$</span> is also equal to the angle <span data-ref="0462.g1:< L A N )">$LAN$</span>.

But the angle <span data-ref="0462.g1:< L A N )">$LAN$</span> is equal to the angle <span data-ref="0462.g1:< K B N )">$KBN$</span>;
therefore the angle <span data-ref="0462.g1:< L K N )">$LKN$</span> is also equal to the angle <span data-ref="0462.g1:< K B N )">$KBN$</span>.

And the angle at <span data-ref="0462.g1:A">$A$</span> is common to the two triangles <span data-ref="0462.g1:< A K B >">$AKB$</span> and <span data-ref="0462.g1:< A K N >">$AKN$</span>.

Therefore the remaining angle <span data-ref="0462.g1:< A K B )">$AKB$</span> is equal to the remaining angle <span data-ref="0462.g1:< K N A )">$KNA$</span>; [I. 32]
therefore the triangle <span data-ref="0462.g1:< K B A >">$KBA$</span> is equiangular with the triangle <span data-ref="0462.g1:< K N A >">$KNA$</span>.

Therefore, proportionally, as the straight line <span data-ref="0462.g1:/ B A /">$BA$</span> is to <span data-ref="0462.g1:/ A K /">$AK$</span>, so is <span data-ref="0462.g1:/ K A /">$KA$</span> to <span data-ref="0462.g1:/ A N /">$AN$</span>; [VI. 4]
therefore the rectangle <span data-ref="0462.g1:/ B A /">$BA$</span>, <span data-ref="0462.g1:/ A N /">$AN$</span> is equal to the square on <span data-ref="0462.g1:/ A K /">$AK$</span>. [VI. 17]
