*Analysis.*

Suppose the problem solved, <span data-ref="0477.g1:A">$A$</span>, <span data-ref="0477.g1:B">$B$</span>, <span data-ref="0477.g1:C">$C$</span>, <span data-ref="0477.g1:D">$D$</span> being the angular points of the<br />
required pyramid.

Through <span data-ref="0477.g1:A">$A$</span> draw <span data-ref="0477.g1:/ E F /">$EF$</span> parallel to <span data-ref="0477.g1:/ C D /">$CD$</span>; this will make equal angles with<br />
<span data-ref="0477.g1:/ A C /">$AC$</span>, <span data-ref="0477.g1:/ A D /">$AD$</span>; and, since <span data-ref="0477.g1:/ A B /">$AB$</span> does so too, <span data-ref="0477.g1:/ E F /">$EF$</span><br />
is perpendicular to <span data-ref="0477.g1:/ A B /">$AB$</span> [Pappus has a lemma<br />
for this, p. 140, 12—24], and is therefore a<br />
tangent to the sphere (for <span data-ref="0477.g1:/ E F /">$EF$</span> is parallel to<br />
<span data-ref="0477.g1:/ C D /">$CD$</span>, the base of the triangle <span data-ref="0477.g1:< A C D >">$ACD$</span>, and<br />
therefore touches the circle circumscribing<br />
it, while it also touches the circular section<br />
<span data-ref="0477.g1:( A B )">$AB$</span> made by the plane passing through <span data-ref="0477.g1:/ A B /">$AB$</span><br />
and <span data-ref="0477.g1:/ E F /">$EF$</span> perpendicular to it).

Similarly <span data-ref="0477.g1:/ G H /">$GH$</span> drawn through <span data-ref="0477.g1:D">$D$</span> parallel<br />
to <span data-ref="0477.g1:/ A B /">$AB$</span> touches the sphere.

And the plane through <span data-ref="0477.g1:/ G H /">$GH$</span>, <span data-ref="0477.g1:/ C D /">$CD$</span> makes<br />
a circular section equal and parallel to <span data-ref="0477.g1:( A B )">$AB$</span>.

Through the centre <span data-ref="0477.g1:K">$K$</span> of that circular<br />
section, and in the plane of the section, draw <span data-ref="0477.g1:/ L M /">$LM$</span> perpendicular to <span data-ref="0477.g1:/ C D /">$CD$</span> and<br />
therefore parallel to <span data-ref="0477.g1:/ A B /">$AB$</span>. Join <span data-ref="0477.g1:/ B L /">$BL$</span>, <span data-ref="0477.g1:/ B M /">$BM$</span>.

<span data-ref="0477.g1:/ B M /">$BM$</span> is then perpendicular to <span data-ref="0477.g1:/ A B /">$AB$</span>, <span data-ref="0477.g1:/ L M /">$LM$</span>, and <span data-ref="0477.g1:/ L B /">$LB$</span> is a diameter of the sphere.<br />
Join <span data-ref="0477.g1:/ M C /">$MC$</span>.

Then <span data-ref="0477.g1:/ L M /">$LM$</span>$^2 = 2$<span data-ref="0477.g1:/ M C /">$MC$</span>$^2$,<br />
and <span data-ref="0477.g1:/ B C /">$BC$</span> $= $ <span data-ref="0477.g1:/ A B /">$AB$</span> $= $ <span data-ref="0477.g1:/ L M /">$LM$</span>,<br />
so that <span data-ref="0477.g1:/ B C /">$BC$</span>$^2 = 2$<span data-ref="0477.g1:/ M C /">$MC$</span>$^2$.

And <span data-ref="0477.g1:/ B M /">$BM$</span>, being perpendicular to the plane of the circle <span data-ref="0477.g1:( L M )">$LM$</span>, is perpen-<br />
dicular to <span data-ref="0477.g1:/ C M /">$CM$</span>,<br />
whence <span data-ref="0477.g1:/ B C /">$BC$</span>$^2 = $ <span data-ref="0477.g1:/ B M /">$BM$</span>$^2 + $ <span data-ref="0477.g1:/ M C /">$MC$</span>$^2$,<br />
so that <span data-ref="0477.g1:/ B M /">$BM$</span> $= $ <span data-ref="0477.g1:/ M C /">$MC$</span>.<br />
But <span data-ref="0477.g1:/ B C /">$BC$</span> $= $ <span data-ref="0477.g1:/ L M /">$LM$</span>;<br />
therefore <span data-ref="0477.g1:/ L M /">$LM$</span>$^2 = 2$<span data-ref="0477.g1:/ B M /">$BM$</span>$^2$.

And, since the angle <span data-ref="0477.g1:< L M B )">$LMB$</span> is right,<br />
<span data-ref="0477.g1:/ B L /">$BL$</span>$^2 = $ <span data-ref="0477.g1:/ L M /">$LM$</span>$^2 + $ <span data-ref="0477.g1:/ M B /">$MB$</span>$^2 = \frac{3}{2}$<span data-ref="0477.g1:/ L M /">$LM$</span>$^2$.

*Synthesis.*

Draw two parallel circular sections of the sphere with diameter $d'$,<br />
such that
$$d'^2 = \frac{2}{3}d^2,$$
where $d$ is the diameter of the sphere.

[This is easily done by dividing <span data-ref="0477.g1:/ B L /">$BL$</span>, any diameter of the sphere, at <span data-ref="0477.g1:P">$P$</span>, so<br />
that <span data-ref="0477.g1:/ L P /">$LP$</span> $= 2$<span data-ref="0477.g1:/ P B /">$PB$</span>, and then drawing <span data-ref="0477.g1:/ P M /">$PM$</span> at right angles to <span data-ref="0477.g1:/ L B /">$LB$</span> meeting the<br />
great circle <span data-ref="0477.g1:( L M B )">$LMB$</span> of the sphere in <span data-ref="0477.g1:M">$M$</span>. Then <span data-ref="0477.g1:/ L M /">$LM$</span>$^2 : $ <span data-ref="0477.g1:/ L B /">$LB$</span>$^2 = $ <span data-ref="0477.g1:/ L P /">$LP$</span> $:$ <span data-ref="0477.g1:/ L B /">$LB$</span> $= 2 : 3$.]

Draw sections through <span data-ref="0477.g1:M">$M$</span>, <span data-ref="0477.g1:B">$B$</span> perpendicular to <span data-ref="0477.g1:/ M B /">$MB$</span>, and in these sections<br />
respectively draw the parallel diameters <span data-ref="0477.g1:/ L M /">$LM$</span>, <span data-ref="0477.g1:/ A B /">$AB$</span>.

Lastly, in the section <span data-ref="0477.g1:( L M )">$LM$</span> draw <span data-ref="0477.g1:/ C D /">$CD$</span> through the centre <span data-ref="0477.g1:K">$K$</span> perpendicular<br />
to <span data-ref="0477.g1:/ L M /">$LM$</span>.

<span data-ref="0477.g1:< A B C D >">$ABCD$</span> is then the required regular pyramid or tetrahedron.
