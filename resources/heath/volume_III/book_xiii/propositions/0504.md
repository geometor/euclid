(3) To prove that the pentagon <span data-ref="0503.g1:< B U V C W >">$BUVCW$</span> is equiangular.
We have
<span data-ref="0503.g1:/ B V /">$BV$</span>$^2 = $ <span data-ref="0503.g1:/ B S /">$BS$</span>$^2 + $ <span data-ref="0503.g1:/ S V /">$SV$</span>$^2$
$= ($<span data-ref="0503.g1:/ B N /">$BN$</span>$^2 + $ <span data-ref="0503.g1:/ N S /">$NS$</span>$^2) + $ <span data-ref="0503.g1:/ S P /">$SP$</span>$^2$
$= $ <span data-ref="0503.g1:/ P N /">$PN$</span>$^2 + ($<span data-ref="0503.g1:/ N S /">$NS$</span>$^2 + $ <span data-ref="0503.g1:/ S P /">$SP$</span>$^2)$
$= $ <span data-ref="0503.g1:/ P N /">$PN$</span>$^2 + 3$<span data-ref="0503.g1:/ P N /">$PN$</span>$^2$,
since <span data-ref="0503.g1:/ N S /">$NS$</span> is divided in extreme and mean ratio at <span data-ref="0503.g1:P">$P$</span> [XIII. 5], so that
<span data-ref="0503.g1:/ N S /">$NS$</span>$^2 + $ <span data-ref="0503.g1:/ S P /">$SP$</span>$^2 = 3$<span data-ref="0503.g1:/ P N /">$PN$</span>$^2$. [XIII. 4]
Consequently
<span data-ref="0503.g1:/ B V /">$BV$</span>$^2 = 4$<span data-ref="0503.g1:/ P N /">$PN$</span>$^2$
$= $ <span data-ref="0503.g1:/ B C /">$BC$</span>$^2$,
or
<span data-ref="0503.g1:/ B V /">$BV$</span> $= $ <span data-ref="0503.g1:/ B C /">$BC$</span>.
The $\Delta\text{s }$ <span data-ref="0503.g1:< U B V >">$UBV$</span>, <span data-ref="0503.g1:< W B C >">$WBC$</span> are therefore equal in all respects, and
$\angle$ <span data-ref="0503.g1:< B U V )">$BUV$</span> $= \angle$ <span data-ref="0503.g1:< B W C )">$BWC$</span>.
Similarly
$\angle$ <span data-ref="0503.g1:< C V U )">$CVU$</span> $= \angle$ <span data-ref="0503.g1:< B W C )">$BWC$</span>.
Therefore the pentagon is equiangular. [XIII. 7]

(4) To prove that the sphere which circumscribes the cube also circumscribes the dodecahedron we have only to prove that, if <span data-ref="0503.g1:Z">$Z$</span> be the centre of the sphere, <span data-ref="0503.g1:/ Z U /">$ZU$</span> $= $ <span data-ref="0503.g1:/ Z B /">$ZB$</span>, for example.
Now, by **XI. 38**, <span data-ref="0503.g1:/ X P /">$XP$</span> produced meets the diagonal of the cube, and the portion of <span data-ref="0503.g1:/ X P /">$XP$</span> produced which is within the cube and the diagonal bisect one another.
And
<span data-ref="0503.g1:/ Z U /">$ZU$</span>$^2 = $ <span data-ref="0503.g1:/ Z X /">$ZX$</span>$^2 + $ <span data-ref="0503.g1:/ X U /">$XU$</span>$^2$
$= $ <span data-ref="0503.g1:/ N S /">$NS$</span>$^2 + $ <span data-ref="0503.g1:/ P S /">$PS$</span>$^2$
$= 3$<span data-ref="0503.g1:/ P N /">$PN$</span>$^2$,
as before.
Also (cf. XIII. 15)
<span data-ref="0503.g1:/ Z B /">$ZB$</span>$^2 = $ <span data-ref="0503.g1:/ Z P /">$ZP$</span>$^2 + $ <span data-ref="0503.g1:/ P B /">$PB$</span>$^2$

$= 3$<span data-ref="0503.g1:/ P N /">$PN$</span>$^2$.
Hence
<span data-ref="0503.g1:/ Z U /">$ZU$</span> $= $ <span data-ref="0503.g1:/ Z B /">$ZB$</span>.
