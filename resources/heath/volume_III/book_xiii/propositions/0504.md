(3) To prove that the pentagon <span data-ref="0503.g1:< B U V C W >">$BUVCW$</span> is equiangular.<br />
We have<br />
<span data-ref="0503.g1:/ B V /">$BV$</span>$^2 = $ <span data-ref="0503.g1:/ B S /">$BS$</span>$^2 + $ <span data-ref="0503.g1:/ S V /">$SV$</span>$^2$<br />
$= ($<span data-ref="0503.g1:/ B N /">$BN$</span>$^2 + $ <span data-ref="0503.g1:/ N S /">$NS$</span>$^2) + $ <span data-ref="0503.g1:/ S P /">$SP$</span>$^2$<br />
$= $ <span data-ref="0503.g1:/ P N /">$PN$</span>$^2 + ($<span data-ref="0503.g1:/ N S /">$NS$</span>$^2 + $ <span data-ref="0503.g1:/ S P /">$SP$</span>$^2)$<br />
$= $ <span data-ref="0503.g1:/ P N /">$PN$</span>$^2 + 3$<span data-ref="0503.g1:/ P N /">$PN$</span>$^2$,<br />
since <span data-ref="0503.g1:/ N S /">$NS$</span> is divided in extreme and mean ratio at <span data-ref="0503.g1:P">$P$</span> <span class="justification">[XIII. 5]</span>, so that<br />
<span data-ref="0503.g1:/ N S /">$NS$</span>$^2 + $ <span data-ref="0503.g1:/ S P /">$SP$</span>$^2 = 3$<span data-ref="0503.g1:/ P N /">$PN$</span>$^2$. <span class="justification">[XIII. 4]</span><br />
Consequently<br />
<span data-ref="0503.g1:/ B V /">$BV$</span>$^2 = 4$<span data-ref="0503.g1:/ P N /">$PN$</span>$^2$<br />
$= $ <span data-ref="0503.g1:/ B C /">$BC$</span>$^2$,<br />
or<br />
<span data-ref="0503.g1:/ B V /">$BV$</span> $= $ <span data-ref="0503.g1:/ B C /">$BC$</span>.<br />
The $\Delta\text{s }$ <span data-ref="0503.g1:< U B V >">$UBV$</span>, <span data-ref="0503.g1:< W B C >">$WBC$</span> are therefore equal in all respects,<br />

$\angle$ <span data-ref="0503.g1:< C V U )">$CVU$</span> $= \angle$ <span data-ref="0503.g1:< B W C )">$BWC$</span>.<br />
Therefore the pentagon is equiangular. <span class="justification">[XIII. 7]</span>
