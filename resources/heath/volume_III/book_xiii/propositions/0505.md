(6) Since <span data-ref="0503.g1:/ P N /">$PN$</span> is divided in extreme and mean ratio at <span data-ref="0503.g1:R">$R$</span>,<br />
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; <span data-ref="0503.g1:/ N P /">$NP$</span> $:$ <span data-ref="0503.g1:/ P R /">$PR$</span> $= $ <span data-ref="0503.g1:/ P R /">$PR$</span> $:$ <span data-ref="0503.g1:/ R N /">$RN$</span>.<br />
Doubling the terms, we have<br />
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; <span data-ref="0503.g1:/ N O /">$NO$</span> $:$ <span data-ref="0503.g1:/ R S /">$RS$</span> $= $ <span data-ref="0503.g1:/ R S /">$RS$</span> $: ($ <span data-ref="0503.g1:/ N R /">$NR$</span> $+ $ <span data-ref="0503.g1:/ S O /">$SO$</span>$),$<br />
so that, if <span data-ref="0503.g1:/ N O /">$NO$</span> is divided in extreme and mean ratio, the greater segment<br />
is equal to <span data-ref="0503.g1:/ R S /">$RS$</span>.

Now, since the diameter of the sphere is rational,<br />
and &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; $(\text{diam. of sphere})^2 = 3 (\text{edge of cube})^2$,<br />
the edge of the cube (i.e. <span data-ref="0503.g1:/ N O /">$NO$</span>) is rational.<br />
Consequently <span data-ref="0503.g1:/ R S /">$RS$</span> is an apotome.

[This is proved in the spurious XIII. 6 above ; Euclid assumes it, and the<br />
words purporting to quote the theorem are probably interpolated, like XIII. 6<br />
itself.]

As a matter of fact, with Mr Taylor's notation,<br />
$$l^2 = la + a^2,$$<br />
and &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; $a = \frac{\sqrt{5} - 1}{2} l$.<br />
Since, if $r$ is the radius of the circumscribing sphere, $r = \sqrt{3} \cdot \frac{l}{2}$,<br />
$$a = \frac{r}{\sqrt{3}}(\sqrt{5} - 1) = \frac{r}{3}(\sqrt{15} - \sqrt{3}).$$

**Pappus' solution.**

Here too Pappus (III. pp. 156—162) finds four circular sections of the<br />
sphere all parallel to one another and all passing through five of the vertices<br />
of the dodecahedron.

*Analysis.*

Suppose (he says) the problem solved, and let the vertices of the<br />
dodecahedron be <span data-ref="0506.g1:A">$A$</span>, <span data-ref="0506.g1:B">$B$</span>, <span data-ref="0506.g1:C">$C$</span>, <span data-ref="0506.g1:D">$D$</span>, <span data-ref="0506.g1:E">$E$</span> ; <span data-ref="0506.g1:F">$F$</span>, <span data-ref="0506.g1:G">$G$</span>, <span data-ref="0506.g1:H">$H$</span>, <span data-ref="0506.g1:K">$K$</span>, <span data-ref="0506.g1:L">$L$</span> ; <span data-ref="0506.g1:M">$M$</span>, <span data-ref="0506.g1:N">$N$</span>, <span data-ref="0506.g1:O">$O$</span>, <span data-ref="0506.g1:P">$P$</span>, <span data-ref="0506.g1:Q">$Q$</span> ;<br />
<span data-ref="0506.g1:R">$R$</span>, <span data-ref="0506.g1:S">$S$</span>, <span data-ref="0506.g1:T">$T$</span>, <span data-ref="0506.g1:U">$U$</span>, <span data-ref="0506.g1:V">$V$</span>.

Then, as before, <span data-ref="0506.g1:/ E D /">$ED$</span> is parallel to <span data-ref="0506.g1:/ F L /">$FL$</span>, and <span data-ref="0506.g1:/ A E /">$AE$</span> to <span data-ref="0506.g1:/ F G /">$FG$</span> ; therefore the<br />
planes <span data-ref="0506.g1:< A B C D E >">$ABCDE$</span>, <span data-ref="0506.g1:< F G H K L >">$FGHKL$</span> are parallel.

But, since <span data-ref="0506.g1:/ P A /">$PA$</span> is parallel to <span data-ref="0506.g1:/ B H /">$BH$</span>, and <span data-ref="0506.g1:/ B H /">$BH$</span> to <span data-ref="0506.g1:/ O C /">$OC$</span>, <span data-ref="0506.g1:/ P A /">$PA$</span> is parallel to <span data-ref="0506.g1:/ O C /">$OC$</span> ;<br />
and they are equal ; therefore <span data-ref="0506.g1:/ P O /">$PO$</span>, <span data-ref="0506.g1:/ A C /">$AC$</span> are parallel, so that <span data-ref="0506.g1:/ S T /">$ST$</span>, <span data-ref="0506.g1:/ E D /">$ED$</span> are also<br />
parallel.

Similarly <span data-ref="0506.g1:/ R S /">$RS$</span>, <span data-ref="0506.g1:/ D C /">$DC$</span> are parallel, and likewise the pairs (<span data-ref="0506.g1:/ T U /">$TU$</span>, <span data-ref="0506.g1:/ E A /">$EA$</span>),<br />
(<span data-ref="0506.g1:/ U V /">$UV$</span>, <span data-ref="0506.g1:/ A B /">$AB$</span>), (<span data-ref="0506.g1:/ V R /">$VR$</span>, <span data-ref="0506.g1:/ B C /">$BC$</span>).

Therefore the planes <span data-ref="0506.g1:< A B C D E >">$ABCDE$</span>, <span data-ref="0506.g1:< R S T U V >">$RSTUV$</span> are parallel ; and the circles<br />
<span data-ref="0506.g1:( A B C D E )">$ABCDE$</span>, <span data-ref="0506.g1:( R S T U V )">$RSTUV$</span> are equal, since the inscribed pentagons are equal.

Similarly the circles <span data-ref="0506.g1:( F G H K L )">$FGHKL$</span>, <span data-ref="0506.g1:( M N O P Q )">$MNOPQ$</span> are equal, since the pentagons<br />
inscribed in them are equal.

Now <span data-ref="0506.g1:/ C L /">$CL$</span>, <span data-ref="0506.g1:/ O U /">$OU$</span> are parallel because each is parallel to <span data-ref="0506.g1:/ K N /">$KN$</span> ;<br />
therefore <span data-ref="0506.g1:L">$L$</span>, <span data-ref="0506.g1:C">$C$</span>, <span data-ref="0506.g1:O">$O$</span>, <span data-ref="0506.g1:U">$U$</span> are in one plane.

And <span data-ref="0506.g1:/ L C /">$LC$</span>, <span data-ref="0506.g1:/ C O /">$CO$</span>, <span data-ref="0506.g1:/ O U /">$OU$</span>, <span data-ref="0506.g1:/ U L /">$UL$</span> are all equal, since they subtend angles of equal<br />
pentagons.

Also <span data-ref="0506.g1:L">$L$</span>, <span data-ref="0506.g1:C">$C$</span>, <span data-ref="0506.g1:O">$O$</span>, <span data-ref="0506.g1:U">$U$</span> are on a plane section, i.e. a circle ;<br />
therefore <span data-ref="0506.g1:< L C O U >">$LCOU$</span> is a square.

Therefore &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; <span data-ref="0506.g1:/ O L /">$OL$</span>$^2 = 2$<span data-ref="0506.g1:/ L C /">$LC$</span>$^2 = 2$<span data-ref="0506.g1:/ L F /">$LF$</span>$^2$<br />
(for <span data-ref="0506.g1:/ L C /">$LC$</span>, <span data-ref="0506.g1:/ L F /">$LF$</span> subtend angles of equal pentagons).
