And the angle <span data-ref="0506.g1:< O L F )">$OLF$</span> is right; for <span data-ref="0506.g1:/ P O /">$PO$</span>, <span data-ref="0506.g1:/ L F /">$LF$</span> are equal and parallel chords<br />
in two equal and parallel circular sections of a sphere [Pappus' lemma, p. 138,<br />
20—26].<br />
Therefore &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; <span data-ref="0506.g1:/ O F /">$OF$</span>$^2 = $ <span data-ref="0506.g1:/ O L /">$OL$</span>$^2 + $ <span data-ref="0506.g1:/ F L /">$FL$</span>$^2 = 3$<span data-ref="0506.g1:/ F L /">$FL$</span>$^2$. <span class="justification">[from above]</span><br />
And <span data-ref="0506.g1:/ O F /">$OF$</span> is a diameter of the sphere; for <span data-ref="0506.g1:/ P O /">$PO$</span>, <span data-ref="0506.g1:/ L F /">$LF$</span> are on opposite sides<br />
of the centres of the circles in which they are [Pappus' lemma, pp. 136—8].

![Proposition 17 Dodecahedron Construction Diagram](0506.g1.svg)

Now suppose $p$, $t$, $h$ to be the sides of an equilateral pentagon, triangle<br />
and hexagon in the circle <span data-ref="0506.g1:( F G H K L )">$FGHKL$</span>, $d$ the diameter of the sphere.<br />
Then &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; $d : $ <span data-ref="0506.g1:/ F L /">$FL$</span> $= \sqrt{3} : 1$ <span class="justification">[from above]</span><br />
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; $= t : h$ ; <span class="justification">[Eucl. XIII. 12]</span><br />
and it follows *alternando* (since <span data-ref="0506.g1:/ F L /">$FL$</span> $= p$) that<br />
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; $d : t = p : h$.

Now let $d'$, $p'$, $h'$ be the sides of a regular decagon, pentagon and hexagon<br />
respectively inscribed in *any one* circle.

Since, if <span data-ref="0506.g1:/ F L /">$FL$</span> be divided in extreme and mean ratio, the greater segment is<br />
equal to <span data-ref="0506.g1:/ E D /">$ED$</span>, <span class="justification">[XIII. 8]</span><br />
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; <span data-ref="0506.g1:/ F L /">$FL$</span> $:$ <span data-ref="0506.g1:/ E D /">$ED$</span> $= h' : d'$. <span class="justification">[VI. Def. 3, XIII. 9]</span>

And <span data-ref="0506.g1:/ F L /">$FL$</span> $:$ <span data-ref="0506.g1:/ E D /">$ED$</span> is the ratio of the sides of the regular pentagons inscribed<br />
in the circles <span data-ref="0506.g1:( F G H K L )">$FGHKL$</span>, <span data-ref="0506.g1:( A B C D E )">$ABCDE$</span>, and is therefore equal to the ratio of the<br />
sides of the equilateral triangles inscribed in the same circles.<br />
Therefore &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; $t : (\text{side of }\triangle\text{ in }$ <span data-ref="0506.g1:( A B C D E )">$ABCDE$</span>$) = h' : d'$.<br />
But &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; $d : t = p : h$<br />
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; $= p' : h'$ ;<br />
therefore, *ex aequali*, $d : (\text{side of }\triangle\text{ in }$ <span data-ref="0506.g1:( A B C D E )">$ABCDE$</span>$) = p' : d'$.

Now $d$ is given ;<br />
therefore the sides of the equilateral triangles inscribed in the circles <span data-ref="0506.g1:( A B C D E )">$ABCDE$</span>,<br />
<span data-ref="0506.g1:( F G H K L )">$FGHKL$</span> respectively are given, whence the radii of those circles are also<br />
given.
