Therefore
$9$ <span data-ref="0507.g1:/ C D /">$DC$</span>$^2 =$ <span data-ref="0507.g1:/ C B /">$BC$</span>$^2 = 5$ <span data-ref="0507.g1:/ C K /">$KC$</span>$^2$.
Hence <span data-ref="0507.g1:/ C K /">$KC$</span> $>$ <span data-ref="0507.g1:/ C D /">$CD$</span>.
Make <span data-ref="0507.g1:/ C L /">$CL$</span> equal to <span data-ref="0507.g1:/ C K /">$KC$</span>, draw <span data-ref="0507.g1:/ L M /">$LM$</span> at right angles to <span data-ref="0507.g1:/ A B /">$AB$</span>, and join <span data-ref="0507.g1:/ A M /">$AM$</span>, <span data-ref="0507.g1:/ M B /">$MB$</span>.
Since
<span data-ref="0507.g1:/ C B /">$CB$</span>$^2 = 5$ <span data-ref="0507.g1:/ C K /">$KC$</span>$^2$,
<span data-ref="0507.g1:/ A B /">$AB$</span>$^2 = 5$ <span data-ref="0507.g1:/ K L /">$KL$</span>$^2$.
It follows that <span data-ref="0507.g1:/ K L /">$KL$</span> ($= \sqrt{\tfrac{4}{5}} \cdot r$) is the radius of, or the side of the regular hexagon in, the circle containing the pentagonal sections of the icosahedron. [XIII. 16]
And, since
$$2r = (\text{side of hexagon}) + 2 (\text{side of decagon in same circle})$$ [XIII. 16, Por.]
<span data-ref="0507.g1:/ A K /">$AK$</span> $=$ <span data-ref="0507.g1:/ L B /">$LB$</span> $= (\text{side of decagon in the said circle})$.
But
<span data-ref="0507.g1:/ L M /">$LM$</span> $=$ <span data-ref="0507.g1:/ H K /">$HK$</span> $=$ <span data-ref="0507.g1:/ K L /">$KL$</span> $= (\text{side of hexagon in circle})$.
Therefore
<span data-ref="0507.g1:/ L M /">$LM$</span>$^2 +$ <span data-ref="0507.g1:/ L B /">$LB$</span>$^2 (=$ <span data-ref="0507.g1:/ M B /">$BM$</span>$^2) = (\text{side of pentagon in circle})^2$ [XIII. 10] $= (\text{edge of icosahedron})^2$,
and
<span data-ref="0507.g1:/ M B /">$BM$</span> $= (\text{edge of icosahedron})$.
[More shortly,
<span data-ref="0507.g1:/ H K /">$HK$</span> $= 2$ <span data-ref="0507.g1:/ C K /">$KC$</span>,
whence
<span data-ref="0507.g1:/ H K /">$HK$</span>$^2 = 4$ <span data-ref="0507.g1:/ C K /">$KC$</span>$^2$,
and
$5$ <span data-ref="0507.g1:/ C K /">$KC$</span>$^2 =$ <span data-ref="0507.g1:/ H C /">$HC$</span>$^2 = r^2$.
Also
<span data-ref="0507.g1:/ A K /">$AK$</span> $= r -$ <span data-ref="0507.g1:/ C K /">$CK$</span> $= r \left( 1 - \frac{1}{\sqrt{5}} \right)$.
Thus
<span data-ref="0507.g1:/ M B /">$BM$</span>$^2 =$ <span data-ref="0507.g1:/ H K /">$HK$</span>$^2 +$ <span data-ref="0507.g1:/ A K /">$AK$</span>$^2 = \tfrac{4}{5} r^2 + r^2 \left( 1 - \frac{1}{\sqrt{5}} \right)^2 = r^2 \left( \frac{10}{5} - \frac{2}{\sqrt{5}} \right) = \frac{r^2}{5} (10 - 2\sqrt{5})$,

<span data-ref="0507.g1:/ M B /">$BM$</span> $= \frac{r}{5} \sqrt{10(5-\sqrt{5})} = (\text{edge of icosahedron})$.]
